# Стиль flang: пройти проверку и не оставить долг

Этот навык — про то, чтобы написанное прошло сторожей и не разошлось с кодом.
Как код доказывается и почему аналогии из других языков здесь неверны — в навыке
`flang-code`, читать его первым. Разбор привычек для человека — в
`docs/guide/how-to-write-flang.ru.md`. Здесь — правила в форме указаний.

## Правила

1. **Комментариев в `.flang` не пишешь.** Лексер их выбрасывает — комментарий не
   терм, его не проверить, он тихо устареет. Объясняй **именем, типами,
   `обеспечивает` и `пример`ом**. Прибавку не пустит `scripts/no-comments-guard.sh`
   (храповик по `scripts/no-comments-debt.tsv`, крутится только вниз).

2. **Нужна пометка в коде — делай её термом, а не `//`.** Канон терм-заметки:
   **именованный `пример`** (имя — целое предложение, оно прогоняется) и рядом
   именованные `обеспечивает` / `требует` / `теорема`. Пометка едет внутри
   конструкции, которую компилятор хранит и проверяет, — разойтись с кодом не
   может.

3. **Замеры, даты, «почему так решили» — не в исходник.** Им место в `docs/`,
   `tasks/` и базе знаний `docs/zettel/` (навык `flang-zettel`).

4. **Имена не сокращаешь.** `«Разобрать запрос»`, `итог`, `элемент` — не `«разб»`,
   `акк`, `эл`. Что краснеет — `flang/scripts/name-guard.mjs`; закрытый список
   обрубков и правила Р1–Р7 — в `docs/guide/naming.ru.md`. Имя модуля —
   латиницей (оно уезжает в чужой язык печатью).

5. **Ёлочки вокруг имён функций, типов, вариантов, модулей:** `«Глубина»`,
   `модуль «Отрезок»`. Вызов — `«Имя» от а и б`. Локальные имена (параметр,
   `пусть`, элемент свёртки, поле случая) — без ёлочек.

6. **Не дублируешь.** Один исходник даёт реализацию, тесты и постусловия сразу —
   не пиши тесты рядом руками. Перечень, который дерево выводит само, руками не
   набираешь: следит `scripts/hand-written-lists-ledger.tsv`
   (`sh scripts/hand-written-lists.sh --check`).

7. **`тотальная` доказываешь дёшево.** Предпочитай `разбор` суммы типов и спуск по
   `нат` на 1 — они бесплатны при работе. `убывает <выражение>` ставит проверку в
   напечатанный код и замедляет функцию — только когда иначе никак. Пять способов
   — в навыке `flang-code` и `docs/guide/totality.ru.md`. Объявляй `нат` там, где
   значение неотрицательно.

8. **Эффекты — данные.** Логику пиши чистой функцией «вход → описание действия»;
   встречу с миром оставляй хозяину. Функции остаются `тотальная` и проверяются
   `пример`ами без файлов и сети.

9. **Имя файла — по сути, без транслита и без лишних слов.** Каталог уже даёт
   контекст. (а) Никогда транслит: русское слово латиницей (`korpus`, `svodka`)
   запрещено (правило шире имён, навык `report-plainly`). (б) Акронимы
   (http/json/tcp/api) остаются как есть — «английским» имя они не делают. (в)
   Чисто русское понятие — кириллицей + `.фп`/`.фланг`; английское — латиницей +
   `.flang`/`.fp`. (г) Академичные и лишние слова (corpus, ведомость, list) не
   кладём, если каталог и назначение ясны.

   ```
   плохо:   flang/проверки/korpus-http.flang   транслит «korpus» + лишнее слово
   хорошо:  flang/проверки/http.flang          акроним, каталог даёт контекст
   хорошо:  сводка.фп                           русское понятие → кириллица + .фп
   плохо:   svodka.flang                        «сводка» латиницей — транслит
   ```

10. **Расширение файла — любое из четырёх равноправных:** `.flang`, `.fp`, `.фп`,
    `.фланг` (головное `.flang`). Канон — `scripts/file-extensions.flang`, решения
    ADR-0016/0018. Смыкается с правилом 9: **русское имя → `.фп`/`.фланг`,
    английское имя → `.flang`/`.fp`**.

## Проверить свою работу до сдачи

```bash
LC_ALL=C.UTF-8 node flang/bin/flang.mjs check файл.flang           # типы, тотальность, примеры, доказательства
LC_ALL=C.UTF-8 node flang/bin/flang.mjs check файл.flang --proof --pretty
```

`LC_ALL=C.UTF-8` обязателен. Число в отчёте — только снятое прогоном, и рядом
сказано, чем снято (навык `report-plainly`).

Сторожа, которых нельзя оставить красными:

- `sh scripts/no-comments-guard.sh` — комментариев не прибавилось;
- `flang/scripts/name-guard.mjs` — имена в порядке;
- `sh scripts/hand-written-lists.sh --check` — рукописных перечней не завёл;
- `flang check` на файле — код 0, и `check`/`test` не расходятся
  (`scripts/check-before-run.flang`).

## Признак готовности

Инварианты стоят термами (`обеспечивает`/`пример`), а не комментарием; имена
самодокументирующие; дублей и рукописных перечней нет; `flang check` — код 0.
