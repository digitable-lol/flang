# flang

Язык поверх [FTS](https://github.com/digitable-lol/fts). Репозиторий заведён
пустым: содержимое складывает владелец.

## Состояние

Черновик. Кода здесь пока нет — на 3 августа 2026 года flang существовал только
в описаниях, ни в одном репозитории и ни в одном рабочем дереве его найти не
удалось. Этот репозиторий заведён как место, куда он ляжет.

## Лицензия — решение отложено осознанно

Файла `LICENSE` здесь намеренно нет: без него репозиторий закрыт по умолчанию,
и это верное состояние, пока выбор не сделан. Лицензия выбирается по политике
`DGT-LIC` (`docs/sdd/digitable-licensing.md` в репозитории портала), и для языка
там уже есть вывод: **язык живёт распространением**, поэтому ему нужна
разрешительная лицензия — грамматика в linguist, пакет в npm, лексер в Chroma,
расширение в Marketplace. Лицензия с порогом по выручке закрывает дистрибутивы,
pkgsrc и Homebrew; язык, который нельзя запаковать, — это язык, которым не
пользуются.

Деньги в этой схеме берутся не с языка, а с продуктов поверх него.

Когда решение принято, `LICENSE` кладётся **дословным текстом выбранной
лицензии, без единой пояснительной строки перед ним** — иначе детекторы
(GitHub licensee, SPDX-сканеры, корпоративные проверки) не опознают её и
покажут «не определена». Всё, что нужно пояснить, идёт отдельным файлом
`NOTICE`. Эта ошибка уже была допущена в `digitwm` и исправлена.

## Что учесть при наполнении

Если код переносится из другого репозитория — переносите вместе с историей или
патчами, сохраняя авторство: `git format-patch` и `git am` делают это без
потерь. Если берётся чужой код — его лицензия наследуется, и это не предмет
выбора; проверьте её до того, как код окажется в дереве.
