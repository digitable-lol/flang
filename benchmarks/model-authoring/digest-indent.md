ВЫЖИМКА СИНТАКСИСА ЯЗЫКА flang (русская поверхность)

Отступы значимы, скобок блоков нет. Имена в «ёлочках» — «Имя функции».
Комментарии — //. Файл начинается словом «модуль».

── ОБЪЯВЛЕНИЯ ВЕРХНЕГО УРОВНЯ ───────────────────────────────────────────────

ВАЖНО ПРО ОТСТУП. Слово «модуль» блока НЕ открывает: строка модуля стоит сама
по себе, а все объявления после неё начинаются с НУЛЕВОГО отступа, у левого
края. Отступы значимы только ВНУТРИ объявления. Программа, у которой
«тотальная функция» или «тип» сдвинуты вправо под «модуль», не разбирается.


  модуль «Имя модуля»
  тип «Имя» / вариант … — сумма типов
  объект «Имя» / поля — запись
  функция «Имя» … / тотальная функция «Имя» …
  процесс «Имя» …, надзор «Имя» …, прогон «Имя» … — конкурентность

── ФУНКЦИЯ ──────────────────────────────────────────────────────────────────

  тотальная функция «Длина»
    принимает элементы: список числа
    возвращает число
    пример «Три элемента»
      дано элементы равно [7, 8, 9]
      ожидается 3
    разбор элементов
      случай пусто
        то 0
      случай голова и хвост
        то 1 плюс «Длина» от хвост

Порядок частей строгий: принимает → возвращает → [убывает] → примеры → тело.
Тело — ОДНО выражение (возможно многострочное). Слова «вернуть», «конец»,
«начало» в языке нет.

«тотальная» требует доказуемого завершения: каждый рекурсивный вызов получает
либо структурно меньший аргумент (хвост списка, хвост строки, поле варианта),
либо параметр, уменьшенный на постоянный шаг и ограниченный снизу (`н минус 1`
при `если н не больше 0`). Не доказал — FLANG_NOT_TOTAL. Тип `нат` (целое ≥ 0)
делает постоянный шаг теоремой. Если убывание в арифметике (Евклид, деление
пополам), меру называет автор строкой `убывает <выражение>` между «возвращает» и
телом; мера обязана быть целой, убывать строго и не уходить ниже нуля.

── ТИПЫ ─────────────────────────────────────────────────────────────────────

  число, целое, нат, строка, признак, ничто
  список <Тип>            например: список числа, список строки
  «Имя объекта», «Имя типа»
  функция из <Тип> и <Тип> в <Тип>

Подтипизация только у чисел: нат ≤ целое ≤ число. `н делить на 2` — уже `число`,
а не `нат`.

  пусть имя равно выражение          локальное связывание, дальше следующая строка
  если условие то выражение иначе выражение
  разбор выражения / случай … / то …
  «Имя функции» от аргумент и аргумент      вызов: аргументы соединяет «и»
  значение.«поле»                    доступ к полю записи
  запись «Имя» с «поле» равным выражение и «поле» равным выражение
  вариант «Имя» с поле равным выражение и поле равным выражение
  функция «Имя»                      функция как значение; применение: ф от х

ставьте скобки):

  плюс  минус  умножить на  делить на  остаток от
  равен (равна, равно, равным)  не равен  больше  меньше  не больше  не меньше
  и  или  не                    да  нет  ничто

── ОБРАЗЦЫ ──────────────────────────────────────────────────────────────────

  разбор элементов
    случай пусто                 пустой список ИЛИ пустая строка
      то 0
    случай голова и хвост        первый элемент и остаток (у строки — первый символ)
      то …
  разбор значение
    случай вариант «Есть» с значение как зн     поле варианта связывается словом «как»
      то зн
    случай «Нет»                                вариант без полей
      то 0

Разбор обязан быть исчерпывающим, иначе FLANG_MATCH_NOT_EXHAUSTIVE.

── СУММЫ ТИПОВ И ЗАПИСИ ─────────────────────────────────────────────────────

  тип «Токен»
    вариант «Слово» содержит текст: строка
    вариант «Число» содержит значение: число, знак: строка
    вариант «Конец»

  объект «Счёт»
    «всего»: число
    «строки»: список строки

Поля варианта разделяет запятая, поля конструктора продолжает «и».

── СПИСКИ ───────────────────────────────────────────────────────────────────

  [1, 2, 3]      пустой список      длина элементы      элемент 2 в элементы
  добавить эл к элементы                                  (в конец, новый список)
  отобразить элементы как эл → эл умножить на 2
  отфильтровать элементы где эл → (эл остаток от 2) равен 0
  свёртка элементы начиная с 0 как акк и эл → акк плюс эл

Индексация с 1 и включительно. Замены элемента по номеру в языке НЕТ.

  соединить а с б        разделить текст по ","  разложить текст на символы
  содержит               начинается с            код символа текст

── ПОВЕРХНОСТЬ FTS: УТИЛИТА СО СВОЙСТВОМ ────────────────────────────────────

Файл начинается словом «категория», объект описывает поля через «является»,
утилита считает результат правилами от начального значения, свойство —
постусловие, проверяемое на каждом примере:

  категория «Продажи»

    объект Покупка
      сумма является деньгами
      «постоянный клиент» является признаком

    утилита «Рассчитать скидку»
      принимает Покупка
      возвращает деньги
      начинает с 0

      правило «Большая покупка»
        если сумма не меньше 10000
        то добавить 10 процентов от поля сумма

      свойство «Скидка ограничена»
        результат не больше 20 процентов от поля сумма

      пример «Большая покупка»
        дано сумма равна 20000
        ожидается результат равен 2000

Действие правила: «добавить <число>», «добавить N процентов от поля <имя>»,
«результат равен <число>». Условие правила продолжается словом «и».

── ПОВЕРХНОСТЬ КОНКУРЕНТНОСТИ ───────────────────────────────────────────────

  процесс «Счётчик»
    состояние «Счёт»            тип состояния — объявленный объект
    начинает с «нулевой счёт»   тотальная функция без параметров
    принимает «Команда»         тип принимаемых сообщений
    обрабатывает «шаг счёта»    тотальная функция (состояние, сообщение) → отклик

  надзор «Цех»
    процесс «Счётчик» стратегия «перезапустить»
    порог отказов 2 за 5000 миллисекунд иначе «остановить»

  прогон «два прибавления»
    семя 1
    дано «Счётчик» принимает (вариант «прибавить» с «сколько» равным 2)
    ожидается «Счётчик» равен (запись «Счёт» с «всего» равным 2)
    ожидается «Счётчик» стратегия «перезапустить» 1 раз

Обработчик возвращает объявленный автором объект-отклик с полями
«состояние» (новое состояние) и «действия» (список «Действие»). Тип «Действие»
приписывает программе сам язык; его варианты — «отправить» с полями «кому» и
«что», «остановить» с полем «почему». Остановка с причиной "норма" отказом не
считается, любая другая причина — отказ, и его видит надзор.
