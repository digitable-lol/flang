# ADR-0035. Проводник печатает строки потоком, и потому flang-tui в него не едет

**Состояние:** принято — замер сделан, проводник переписан и прогнан, раскладка

**Замер прогоном:** 13 сентября 2026, ствол `1218aa1` (выпуск 0.7.19), двоичный
flang 0.7.16, flang-tui `4117aea`, Linux.
**Рядом:** [ADR-0024](0024-the-settings-file-and-the-language-of-output.md) —
язык вывода берётся из настроек, проводник его слушает;

уроках подряд.

## Задача

`flangtutor` рисует экран сам: 72 вызова `printf`/`say`/`dim` подряд, без единого
обращения к размеру терминала. `flang-tui` — библиотека чистых тотальных функций
с другим договором: **данные плюс ширина и высота → готовые строки**. Сложить
одно с другим — не правка, а развилка, и её надо было пройти замером.

## Замер: три пути и чем за каждый платят

### Путь 1. Проводник целиком становится напечатанным двоичным

Отвергнут **ответом самого компилятора**. Проводник — это ввод-вывод целиком:
чтение строк с клавиатуры, живая печать, запуск компилятора потомком, временные
файлы. В языке такое записывается объявлением `план`, а `план` печатает ровно
одна цель:

```console
$ flang emit scripts/guards/license-guard.flang --target c --out /tmp/x
flang emit: печать отказала — FLANG_PLAN_UNSUPPORTED: цель «c» не умеет печатать
объявление «план». … Сегодня объявление «план» печатает одна цель — «js»;
исполнить его умеет ещё «flang io».
```

То есть напечатать проводник можно только в JavaScript — и поставить рядом Node.
Дерево в это же время идёт ровно в обратную сторону: задача 0049 выносит из него
последний JavaScript. Оставшийся вариант — писать двоичный руками на Go или C,
то есть завести в дереве второй язык ради того, что сегодня делают 617 строк
`sh`. Цена пути: второй язык в дереве, сборка проводника на каждой площадке,
Node у человека — против нуля сегодня.

### Путь 2. sh остаётся, раскладку считает компилятор на каждый вызов

Отвергнут **двумя числами**.

Первое — договор `flang run`. Он берёт только ПЛОСКИЙ объект скаляров:

```console
$ flang run screen.flang --function «Кадр» --args '{"строки":["абвгд","еж"], …}'
flang run: «--args» разобрать не удалось — ждался плоский объект скаляров,
вроде '{"н":10}'
```

Во flang-tui **100 тотальных функций**; из них **8 принимают список** — и это
ровно те, что укладывают экран: «Кадр», «Уложить раздел», «Окно строк»,
«Прокрутка в пределах», «Строка или пусто», «График», «Дописать замер», «Хвост
списка». Из оболочки через `flang run` они недостижимы вовсе.

Второе — цена. Обойти отказ можно, сочинив временный модуль, который
`использует «Screen»` и вписывает список литералом. Замерено:

| что | сколько |
| --- | ---: |
| один кадр через `flang run` (модуль-посредник) | **1010 мс** |
| один вызов «Полоса» через `flang run --args` | **1310 мс** |
| ВЕСЬ проводник, двенадцать уроков подряд верными ответами | **2180 мс** |

Один кадр стоит 46 % всего курса. Проводник печатает 654 строки за прогон;
даже один вызов на урок — это плюс 12 секунд к двум.

### Путь 3 (выбран). sh остаётся, и flang-tui в проводник не едет

Потому что **переносить нечего**.

| в проводнике | сколько мест |
| --- | ---: |
| знает ширину или высоту терминала (`COLUMNS`, `tput`, `stty`) | **0** |
| обрезает строку по ширине | **0** |
| рисует полосу заполнения | **0** |
| держит вкладки | **0** |
| считает прокрутку | **0** |

Договор flang-tui начинается со слов «данные ПЛЮС ШИРИНА И ВЫСОТА». У проводника
нет ни первого, ни второго входа: его вывод дописывается снизу, а прокручивает
его сам терминал. Чтобы позвать библиотеку, надо сперва завести то, что она
считает, — а это и есть смена поведения, которую та же работа запрещает
(«поведение сохранить, доказать прогоном»).

И цена смены не косметическая. Проводник существует затем, чтобы ответ судил
компилятор, а человек ВИДЕЛ вердикт: на неверном ответе это блок из пяти строк,
на уроке с доказательствами — отчёт `check --proof` целиком, длина которого
заранее неизвестна. Кадр постоянной высоты обрезал бы ровно это.

Цвет тоже не переносится: проводнику нужны `ESC[1m`, `ESC[2m`, `ESC[0m` и
`ESC[1;34m`, а «Цвет из шестнадцати» печатает `ESC[34m` — жирного, тусклого и
сброса в модуле нет. Подмена меняет байты вывода.

Подсветки в flang-tui нет вовсе: разборщик проводника красит по таблице лексера
(**647 фраз**, сверяется пробой), а такой таблицы у библиотеки экрана нет и
быть не должно.

## Решение

1. `flangtutor` остаётся сценарием `sh`. Комментарии сняты, транслитные имена
   сняты, поведение сохранено побайтово.
2. Раскладка через flang-tui **не вводится**, пока у проводника не появится
   первое место, где он знает ширину или высоту экрана.
3. Дверь описана здесь, чтобы следующий не мерил заново.

## Дверь: как это делается, когда понадобится

Не через `flang run`. Через **напечатанный C**: `flang emit <модуль> --target c`
кладёт рядом с библиотекой `flang_cli` — прогонщик со строчным договором JSON,
который списки принимает:

```console
$ echo '{"fn":"Кадр","args":[{"l":[{"s":"абвгд"},{"s":"еж"}]},{"n":"3"},{"n":"2"},
        {"n":"0"},{"s":"…"},{"s":""}]}' | ./flang_cli
{"ok":true,"value":{"l":[{"s":"аб…"},{"s":"еж"}]}}
```

Замерено: **0,033 мс** на вызов в одной трубе (1000 вызовов за 33 мс) и **2,6 мс**
на отдельный запуск. Это в 30 000 и в 390 раз дешевле пути 2 соответственно;
приём не выдуман — сам flang-tui так меряет свой предел глубины
(ярлык `пределы`).

Чем за эту дверь платят, и почему её не открывают сегодня:

- в дереве языка появляется вендоренная копия или подмодуль чужого репозитория
  (**3696 строк** flang-tui);
- проводник получает второй артефакт, который надо собрать `cc` на каждой
  площадке, — сегодня он один файл `sh` и работает везде, где есть `sh` и `awk`;
- обе упаковки придётся править: формула Homebrew и `packaging/asdf/bin/install`
  пересчитывают каталоги под `share/flang` и требуют, чтобы их было РОВНО
  столько, сколько целей у печати.

## Чем заплачено за выбранный путь

Проводник по-прежнему сам считает отступы и сам складывает строки. Когда у него
появится карта уроков сбоку, полоса пройденного или обрезка по ширине — это
придётся написать заново, и тогда откроется дверь выше. Сегодня она закрыта
осознанно: библиотека, позванная там, где нечего считать, — это зависимость без
работы.
