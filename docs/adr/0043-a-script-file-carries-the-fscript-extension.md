# ADR-0043. Скрипт носит расширение `.fscript`, программа — `.flang`

**Состояние:** решение владельца (13 сентября 2026: «.flang обычно речь о программе, а когда
у нас .fscript сразу понятно что это скрипт»), записано 17 сентября; выполняется задачей
[1415](../tasks/1415-the-fscript-extension-marks-a-script.md) (шаги Ш2–Ш3, стек оснастки);
одно место компилятора ждёт перепечатки семени и названо ниже поимённо.
**Дата:** 17 сентября 2026
**Дополняет:** [ADR-0016](0016-three-file-extensions.md) — расширения у файла языка;
[ADR-0018](0018-file-extensions-are-one-list.md) — список расширений один и живёт в
`scripts/guards/file-extensions.fscript`. Оба остаются в силе целиком.
**Основание:** задача 1415, замер 13 сентября 2026 (двоичный 0.7.19, дерево `51c2625e`);
замер 17 сентября 2026 на `main` `cbfaf3899` (ниже).
**Проверяется:** `./ярлык расширения:проверка`.

---

## Задача

В дереве два рода файлов языка, и по имени их не различить. **Программа** — функции,
типы, обещания: её проверяют (`flang check`), доказывают и печатают в цели. **Скрипт** —
тот же язык, но с `план «…»`: его зовут `flang io`, он встречается с миром через
поручения хозяина (файлы, каталоги, процессы, сеть, часы). Сегодня и то и другое —
`.flang`, и понять, что перед тобой, можно только открыв файл. Владелец просит, чтобы это
было видно по имени.

## Что такое скрипт — по прибору, не по слову

Снято в задаче 1415 (13 сентября 2026, 0.7.19, `51c2625e`):

| вопрос | ответ прибора |
|---|---|
| что делает скрипт из программы | хотя бы один `план «Имя»` со `состояние`, `начинает с`, `обрабатывает`; шаг возвращает «Продолжение» — «Сделать» с поручением, «Конец работы» или «Провал» |
| как зовут | `flang io файл [--plan Имя]`; без `--plan` при одном плане — исполняется, при нескольких — код 3 `FLANG_UNKNOWN_PLAN`; файл без плана `flang io` не исполняет |
| читает ли передняя дверь расширение | нет: `check` и `io` на копии `script.fscript` — код 0, работают (то же, что ADR-0018 нашёл для `.ерунда`) |
| читает ли расширение обход каталога | да: `flang test` над каталогом с `plain.flang` и `script.fscript` одного содержимого берёт один файл — список в `flang/self/bootstrap/corpus.flang` |
| чего скрипт не умеет сегодня | принять доводы вызова (код 2 на `--` и `--n=5`), напечатать строку на экран (`FLANG_IO_NO_SCREEN`), вынести код возврата потомка наружу («Провал» всегда 1) |

**Скрипт — файл языка, в котором есть хотя бы один `план`.** Это единственное различие,
которое прибор видит сам; всё остальное — договорённость о слове.

## Решение

1. **`.fscript` — расширение файла языка, в котором есть план.** Программы и библиотеки
   остаются `.flang` (и `.fp`, `.фп`, `.фланг` — ADR-0016, ADR-0018).
2. **Список расширений скрипта — второй закрытый список в том же файле.** В
   `scripts/guards/file-extensions.fscript` заводится тотальная функция «Расширения скрипта»
   = `[".fscript"]`; «Имя файла языка» спрашивает оба списка. Сводить два списка в один
   нельзя: «файл языка?» и «скрипт?» — разные вопросы, и ровно такое смешение чинила
   задача [0062](../tasks/0062-the-file-extensions-are-one-list.md). Каждое место отбора,
   обходящее файлы языка (лицензии, подсчёты, имена, слова, редакторы, страница `man`),
   называет оба списка целиком; за этим следит `./ярлык расширения:проверка`, как велит
   ADR-0018, пункт 5.
3. **Что расширение значит для прибора.** Для обхода — файл языка: функции скрипта
   доказываются, примеры гоняются, имена и слова сверяются так же, как у `.flang`. Для
   передней двери — ничего, и это правильно (ADR-0018, пункт 3): `flang io файл.flang`
   продолжает работать, и ни один из 87 вызовов не ломается в день переезда. Умение,
   которого нет у программы, — доводы вызова — появится с задачей
   [4143](../tasks/4143-a-plan-cannot-be-given-arguments-from-the-command-line.md), шаг 3;
   до неё расширение говорит о форме файла, а не о новом умении, и это сказано здесь вслух.
4. **Переезд — волнами, по каталогу, со сторожем зелёным после каждой.** Первая волна —
   `scripts/**` (59 файлов): это оснастка, её зовут ярлыки, работы CI и хук, и все три места
   правятся одной сменой. Вторая — `flang/scripts/**` (32). `docs/examples/**`, `fspec/`,
   `flang/test/**`, `packaging/`, `docs/site/**` — по мере, каждая волна своей задачей.
   `flang/proof/**` — по решению стека доказательств (задача 1420).
5. **Файл, который и ввозится как модуль, и несёт план, решается замером, а не словом.**
   Ввоз по пути (`из "…"`) берёт файл по имени — переезд правит путь. Ввоз по имени модуля
   ищет файл в каталоге **только с расширением `.flang`** — это строка
   `strcmp(entry->d_name + length - 6, ".flang")` в `bootstrap/flang_repl.c` (около
   строки 3204; источник — `flang/src/emit/c/flang_repl.c`), снято задачей 1415
   17 сентября 2026. Значит модуль в `.fscript` по имени не найдётся, пока это место не
   поправлено и семя не перепечатано. Такой файл остаётся `.flang` и назван в «Осталось»
   списка с этой причиной; когда место в C поправлено — переезжает, либо план выносится
   в свой файл.
6. **`ярлыки.flang` в корне не переезжает этой волной.** Он несёт планы «Целость» и «Сбор»,
   но на него ссылаются 46 файлов, включая `ярлык` (`TABLE=ярлыки.flang`) и два сторожа;
   переименование корневого файла — отдельная правка с числом, а не хвост этой.

## Цена, числом

31 место отбора (плюс 2 ждущих) получают второе слово в списке; 59 файлов `scripts/**`
переименовываются `git mv`, и вместе с ними правятся `ярлыки.flang`, работы CI, хук
`.githooks/pre-push`, реестры сторожей и документы. Правок в C для первой волны — ни одной:
двоичный берёт файл по пути (ADR-0016, ADR-0018); одно место в C, решающее по расширению
при ввозе модуля по имени, названо в «Что осталось». Точные числа «до/после» — в
задаче 1415 и в запросе слияния, который переезд делает.

## Что осталось, и это надо сказать вслух

1. **`flang/self/bootstrap/corpus.flang`**, тотальная функция «Заканчивается расширением» —
   единственное место компилятора, решающее по расширению; список из четырёх записан
   в трёх строках. Файл стоит в замыкании печати точки раскрутки: правка появится в
   собранном компиляторе только после перепечатки семени (8,5 часа). До неё
   `flang test <каталог>` пропускает `.fscript` **молча** — поэтому обход корпуса не
   смотрит скрипты, пока семя не перепечатано. Место держится в «Осталось» списка с этой
   причиной; правит его стек доказательств партией перед перепечаткой. Тот же выбор
   сделали ADR-0016 и ADR-0018 по той же причине.
2. **`bootstrap/flang_repl.c`, поиск модуля по имени** — второе место, решающее по
   расширению, и оно в C. ADR-0016 и ADR-0018 писали «правок в C не нужно ни одной», и для
   `.фп`/`.фланг` это было верно только потому, что модули с такими расширениями по имени
   никто не ввозил. Для `.fscript` это не так: девять файлов дерева и библиотека, и скрипт
   разом. Источник — `flang/src/emit/c/flang_repl.c` (стек семени и выпуска); правка там
   — своей задачей, вместе с перепечаткой.
3. **`scripts/raskrutka.sh`** — обходчик того же замыкания; правится той же работой, что
   перепечатывает семя.
4. **Доводы вызова** — 4143, шаг 3; **`#!`** у скрипта — после доводов, своей задачей
   (лексер, семя).

## Чем подтверждено — прогоном

Замеры выше — прогонами 13 и 17 сентября 2026, названы при каждом числе. Сторож
`./ярлык расширения:проверка` на `main` `cbfaf3899` — код 0. Числа переезда (сколько мест
называют `.fscript`, сколько файлов переименовано, сторож красен на порче одного места)
снимает задача 1415 и записывает в себя и в запрос слияния.

## Чего это решение НЕ делает

Не трогает `.фланг`, `.фп`, `.fp` и не пересматривает ADR-0016/0018. Не перепечатывает
семя. Не переименовывает `ярлыки.flang`, `flang/proof/**` и файлы вне первой волны.
Не обещает скрипту доводов вызова — их даёт 4143.
