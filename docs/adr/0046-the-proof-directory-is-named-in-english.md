**Состояние:** решение владельца (22 сентября 2026: «изменения сделал чтобы про латиницу
все были и понятно все было? вижу мусор все еще и нейминг говнище»), записано 22 сентября;
выполняется задачей [6421](../tasks/completed/6421-the-proof-directory-needs-a-layout-and-a-naming-rule.md).
**Дата:** 22 сентября 2026
**Отменяет исключение:** `flang/proof/**` выходит из-под исключения сторожей имён
(`scripts/guards/cyrillic-file-names-guard.sh`, `scripts/guards/translit-file-names-guard.sh`);
[ADR-0023](0023-forgeries-live-in-a-set-not-in-the-metric-corpus.md) остаётся в силе целиком — имя файла
по-прежнему ничего не решает, решает манифест.
**Основание:** задача 6421, замер 22 сентября 2026 на `main` `5a6f2698e` (ниже).
**Проверяется:** `sh scripts/guards/cyrillic-file-names-guard.sh --check`,
`sh scripts/guards/translit-file-names-guard.sh --check`, `sh scripts/доказуемость.sh`,
`sh flang/proof/checker/tests/run.sh`.

## Задача

`flang/proof` — то, ради чего написан язык: независимый проверяющий на C, сверка на Lean,
корпус записей доказательств. Это первое, что открывает человек, пришедший посмотреть, чем
доказательство здесь отличается от обещания. Открывает — и видит три схемы имён сразу.

## Замер, а не впечатление

`git ls-files flang/proof`, ствол `5a6f2698e`, 22 сентября 2026. Слова имени сверены с
закрытым списком `scripts/ledgers/file-name-words.txt`.

| | |
|---|---:|
| файлов | **936** |
| имён кириллицей | **745** |
| имён латиницей | **191** |
| из них несущих транслит русского слова | **69** |
| из них по-английски | **122** |
| различных имён файлов с кириллицей | **702** |
| различных имён каталогов с кириллицей | **58** |
| каталогов, у которых кириллица в имени | **83** |
| различных кириллических слов внутри имён | **447** |

Три схемы лежат в одном дереве и иногда в одном пути:

```
flang/proof/checker/tests/families/algebra-domains/corrupt/…
                    ↑англ.  ↑англ.  ↑англ+транслит   ↑кириллица
flang/proof/lean/RecordReader.lean   flang/proof/lean/Record.lean
```

Транслит здесь не мелочь: `lozh`, `lzhet`, `ohrana`, `zov`, `totalnost`, `psevdonim`,
`golova`, `dlina`, `raznost`, `vychislitel` — это русские слова, записанные латиницей.
По дереву такое имя — брак (задача 1428, сторож `translit-file-names-guard.sh`), и только
исключение для `flang/proof/**` держало их вне суда.

## Решение

**1. Имя файла и каталога в `flang/proof` — английское слово из закрытого списка.**
Та же норма, что по всему дереву. Новое слово вписывается в
`scripts/ledgers/file-name-words.txt` вместе с файлом.

**2. Исключение у обоих сторожей снято 22 сентября 2026, последней порцией.**
Строка «`flang/proof/**` не судится» ушла из `cyrillic-file-names-guard.sh`, и
`flang/proof` вписан в область `translit-file-names-guard.sh`. Раньше снять было нельзя:
сторож судит целиком и на половине пути покраснел бы на ещё не переведённой половине.

Числа после снятия, прогоном: сторож кириллицы — «кириллица в именах файлов: 62, все в
ведомости», код 0; сторож транслита — «латинских имён 2160, с чужими словами 107 — все в
ведомости», код 0; оба на подлоге дают код 1. В ведомость слов вписано 205 английских
слов (было 1661, стало 1866); в ведомость долга транслита — 40 имён записей корпуса, и у
них названа причина: имя записи зеркалит имя исходника `flang/test/fixtures/poddelka-*`,
а те переименовывает задача 1428.

**3. Довод прежнего исключения снят по существу, а не отменён росчерком.** Он звучал так:
имя файла — ключ записи доказательства (`manifest.tsv`, `tests/records/corpus/<имя>.record`),
и переименование рвёт ключ. Это верно, и поэтому переименование идёт **парой**: файл и
строка манифеста двигаются одним изменением, а `sh flang/proof/checker/tests/run.sh`
показывает «сошлось всё» после каждой порции. Ключ не запрещает переименование — он
запрещает переименовать файл и забыть таблицу.

**4. Верхний уровень разложен по родам.** Раньше рядом лежали спецификация, ядро, четыре
таблицы, шесть скриптов и два образца, без признака, что из этого прибор, а что справочник.

| каталог | что лежит |
|---|---|
| `checker/` | независимый проверяющий на C и его набор проб |
| `lean/` | сверка правил вывода на Lean 4 |
| `map/` | соответствие «правило ↔ лемма» |
| `tables/` | таблицы-справочники (`.tsv`) и их отпечатки |
| `probes/` | наборы проб языка: запуск, строгий режим, экран, недоказанное, поручения |
| `examples/` | образцы программ с доказательствами |
| `tools/` | скрипты и вспомогательные программы |

Корень каталога держит только спецификацию, ядро на flang и `README.md`.

## Чего решение НЕ меняет

* **Русский язык прозы остаётся.** Судится имя файла, не текст внутри. Комментарии,
  документы и сообщения об ошибках — по-русски, как были.
* **Русский язык самого flang остаётся.** `тотальная функция «Отпечаток»` — это код, а не
  имя файла.
* **Манифест подделок остаётся решающим** (ADR-0023). Имя файла — ключ строки, не признак
  класса.

## Цена и порядок

Переименование здесь ломается тихо: путь набран в работах CI, в ярлыках, в `.tsv`, в
markdown-ссылках и в `Makefile` — и ни одна из этих ссылок не проверяется компилятором.
Поэтому порядок жёсткий и порциями:

1. **сделано 22 сентября 2026:** верхний уровень, `lean/`, `checker/`, `probes/` и все
   83 каталога — 899 путей; пробы чекера после порции дают «сошлось всё», числа те же,
   что до неё (подделок 534, отвергнуто 448, третий исход 86, честных 248);
2. **сделано 22 сентября 2026:** 15 каталогов записей, названных меткой ячейки,
   620 имён файлов набора проб и расширение `.запись` → `.record` (540 файлов);
   числа приёма те же, что до порции;
3. снятие исключения у сторожей и вписывание новых слов в
   `scripts/ledgers/file-name-words.txt`.

**Долг, названный вслух:** содержимое `*.flang` под `flang/proof` не правилось ни в
порции 1, ни в порции 2 — к тексту исходника привязаны записи доказательств, и правка
одного комментария отвергает честную запись кодом 1 (измерено: `abilities.record`).
Поэтому в пяти файлах (`map/abilities.flang`, `midpoint-price.flang`,
`forgeries/transitivity.flang`, `examples/forgery-subtraction-under-precondition.flang`,
`checker/tests/records/v1-g2/type-behind-a-note.flang`) комментарии до сих пор называют
старые пути. Сюда же `flang/self/zapis.flang`, где комментарии зовут
`totalnost.запись`, `rec-structure.запись`, `rec-step.запись` и `sosedi.запись`:
`flang/self` меняет только перепечатка семени. Долг снимается ПЕРЕСЪЁМКОЙ записей
(правка исходника + новая печать), а не правкой комментария — отдельной работой.

**Второй долг, тоже названный:** `checker/tests/records/corpus/` оставлен с прежними
именами. Имена его записей зеркалят имена исходников (`flang/test/fixtures/poddelka-dlina.flang`
↔ `corpus/poddelka-dlina.record`), а `flang/test/fixtures` лежит вне `flang/proof` и под
это решение не подпадает. Транслит там снимается вместе с переименованием самих
фикстур — задача 1428.

**Третий долг:** `checker/tests/families/run-induction/letters.фп` держит кириллическое
расширение нарочно — это единственный живой образец расширения `.фп` в дереве, и на
него смотрит `scripts/guards/file-extensions.fscript` (задача 1415). Имя основы
переведено (`письма` → `letters`), расширение оставлено.

После каждой порции, кодом 0, без исключений:

```
make -C bootstrap -j4 && sh flang/proof/checker/tests/run.sh   # «сошлось всё»
sh scripts/доказуемость.sh                                     # ДОКАЗУЕМ, 4 из 4
sh .githooks/pre-push
node docs/site/build.mjs --check
```

Половина каталога по одному правилу и половина по другому хуже, чем весь каталог по
старому, — поэтому порция, начатая и не доведённая, откатывается целиком.
