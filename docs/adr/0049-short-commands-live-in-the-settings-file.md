## Решение

**1. Запись.** Короткая команда — строка файла настроек:

```
script.<имя> = <строка оболочки>
```

Приставка `script.` нужна, а раздел без приставки не годится: у файла уже есть
ключ версии, а у дерева есть команда подъёма версии. Без приставки вторая строка
перекрыла бы первую — в файле побеждает последний одноимённый ключ.

**2. Имя.** Английское: строчная латиница, цифры, дефис, двоеточие между частями
(`site:build`, `proofs:count-20`). Проверка имени — план «Целость».

**3. Вызов.** `flang run-script <имя> [доводы…]`; в этом дереве двоичный лежит в
`bootstrap/`, поэтому `bootstrap/flang run-script <имя>`. Форма `flang <имя>`
отвергнута: имя команды проекта столкнулось бы с командой двоичного (`check`,
`test`, `run`, `new`), и пришлось бы заводить правило старшинства.

**4. Исполнение.** Двоичный находит ближайший `.flangrc` от рабочего каталога
вверх (то же правило, что у ключа `unproven`), переходит в каталог этого
файла и отдаёт строку `/bin/sh -c`. Процесс двоичного замещается оболочкой,
поэтому вывод идёт сразу, а код возврата — собственный код команды. Доводы
после имени уезжают команде целиком, включая `--help` и `--version`.

**5. Перечень.** `flang run-script` без имени печатает имя и строку каждой
команды. Объяснение команды живёт в самом скрипте (объявление «короткая
команда»), как решено задачей 1416; в файле настроек его нет.

**6. Коды.** Имени нет в файле — 2 и перечень; файла нет — 2; файл не прочитан
или оболочка не запустилась — 3.

**7. Заслон свежести семени** записан в самой строке команды:
`bootstrap/flang run-script seed:freshness --what <имя> >&2 && <команда>`. Сам
заслон — тоже короткая команда, `seed:freshness`. Команд под заслоном 19 — те же,
что перечисляла функция «Ярлыки о доказательствах» на день переноса.

**8. Сборка.** Двоичный не может собрать себя, пока его нет. На свежей копии
первая команда — `make -C bootstrap`; работа CI, которая прежде полагалась на
самосборку обёртки, получила свой шаг сборки.

## Что уходит и что остаётся

Уходят `ярлык` (обёртка на `sh`, 214 строк) и `ярлыки.flang` (1099 строк).
Проверки, жившие в `ярлыки.flang`, переехали в
`scripts/shortcut-collector.fscript`: план «Целость» (каждая команда называет
существующий файл, имя английское, имя не записано дважды) и план «Сбор»
(объявление в скрипте сходится со строкой `.flangrc`).

## Чего решение не делает

* Ключи самого двоичного `--depth-limit` и `--step-limit` разбираются до имени
  команды и до неё не доезжают.
* Файл `.flangrc` из домашнего каталога коротких команд не даёт.
* Эталон `flang/self/cli.flang` команды `run-script` не знает; запись о долге —
  `flang/scripts/cli-keys-debt.json`, правка эталона — в партии печати.
* Объявления в скриптах `.sh` и `.mjs` остаются строкой комментария: это их
  прежняя форма, сменилось только имя.
