# ADR-0077. Хозяин выдаёт случайные октеты из системного источника

**Состояние:** предложено. Принимает владелец. Словарь поручений в
`flang/self/parser.flang` правлен и ждёт партии печати; хозяева правлены и
собираются без печати.
**Дата:** 7 октября 2026.
**Основание:** `flang/src/emit/c/flang_repl.c` (`io_entropy`, `io_random`,
ветки `«Случайное число»` и `«Случайные октеты»`), `flang/self/parser.flang`
(`«Варианты поручения»`, `«Имена вариантов ввода-вывода»`, узел типа
`«Поручение»`), `flang/src/emit/js/flang_host_node.js`,
`flang/src/emit/js/flang_host_browser.js`, `flang/src/emit/js/flang_io.js`,
`flang/src/emit/python/flang_io.py`, `docs/ct/spec.md`.
**Рядом:** [ADR-0007](0007-encryption-by-request-to-an-external-host.md) — там
предсказуемость `«Случайное число»` названа долгом; [ADR-0078](0078-tls-1-3-is-assembled-in-the-language-and-runs-printed.md) —
клиент TLS, которому эти октеты нужны.
**Пробы:** `flang/proof/probes/randomness/` — `bootstrap/flang run-script
randomness:probe` и `randomness:forgery`.

---

## 1. Улика

Хозяин двоичного на `«Случайное число»` без `--seed` звал `rand()` без
`srand()`. Три прогона подряд пробы `number.fscript` двоичным из ствола:

```
выпало 0.8401877167634666
выпало 0.8401877167634666
выпало 0.8401877167634666
```

Тайный ключ X25519 из такого источника предсказуем целиком. Другого источника
случайности в словаре не было.

## 2. Решение

1. **Новое поручение `«Случайные октеты»` с полем `сколько: число`.** Отклик —
   уже существующий `«Октеты»`: новый отклик словарю не нужен.
2. **Источник — `/dev/urandom` у двоичного хозяина.** `getrandom(2)` не взят:
   семя собирается `cc -std=c99 -pedantic` на четырёх тройках выпуска, а
   `getrandom` требует расширенных заголовков и есть не везде; `/dev/urandom`
   открывается одним `open` на Linux, macOS и BSD. Хозяин Node берёт
   `crypto.randomBytes`, хозяин вкладки — `crypto.getRandomValues`.
3. **Свой код отказа `FLANG_IO_ENTROPY`.** Им отвечают: источник не открылся
   или не дочитался; `сколько` не целое из [0, 65536]; прогон идёт с `--seed`.
4. **`--no-random` запрещает оба поручения** тем же `FLANG_IO_DENIED`, что и
   прежде.
5. **Под `--seed` октеты не выдаются.** Прогон с семенем обещает повториться,
   тайна, которая повторяется, тайной не является. Выдать под семенем
   «повторимые октеты» значило бы молча вернуть ту самую дыру.
6. **`«Случайное число»` без семени берёт 53 бита из того же источника**
   (7 октетов, старшие 53 бита, деление на 2^53); с семенем — mulberry32, как
   прежде, и повторимость прогонов с семенем не тронута. У хозяина Node без
   семени `Math.random` заменён на `crypto.randomBytes`, у вкладки — на
   `crypto.getRandomValues`.

## 3. Что проверено прогоном

Набор проб `flang/proof/probes/randomness/` — восемь строк: программа, ключи,
сколько прогонов, код, слово. Две строки «два прогона» запускают программу
дважды и сравнивают выводы целиком.

| строка | ждём |
|---|---|
| `octets.fscript`, один прогон | код 0, `октетов 32: …` |
| `octets.fscript`, два прогона | `два прогона разошлись` |
| `octets.fscript --no-random` | код 1, `FLANG_IO_DENIED` |
| `octets.fscript --seed 7` | код 1, `FLANG_IO_ENTROPY` |
| `too-many.fscript` (65 537 октетов) | код 1, `FLANG_IO_ENTROPY` |
| `number.fscript`, два прогона | `два прогона разошлись` |
| `number.fscript --seed 7`, два прогона | `два прогона совпали` |
| `number.fscript --no-random` | код 1, `FLANG_IO_DENIED` |

Итоги:

* двоичным, напечатанным из этих исходников без ядра (`flang emit
  flang/self/bootstrap/compiler.flang --target c --no-check`, 44 мин 43 с,
  пик 16,7 ГиБ) и собранным с новым хозяином: **проб 8, разошлось 0**;
* план `Forgery` того же набора переворачивает каждое ожидание (код 0 ↔ 1,
  «разошлись» ↔ «совпали») и обязан увидеть расхождение во всех строках:
  **проб 8, разошлось 8, подлог отвергнут**;
* двоичный ствола как отрицательный контроль: **проб 8, разошлось 6** — он
  не знает слова `«Случайные октеты»`, а `«Случайное число»` у него без семени
  одно и то же. Совпадают две строки с `--seed 7`/`--no-random` у `number`;
* хозяин отдельно, без перепечатки компилятора (семя ствола + новый
  `flang_repl.c`): `number.fscript` дал 0.20254412208983463, 0.8481999169024464,
  0.5082587560335339 в трёх прогонах; с `--seed 7` — 0.011704753153026104, как
  и двоичный ствола.

Сборка хозяина: `-std=c99 -Wall -Wextra -Werror -pedantic -O2 -flto`, ни одного
предупреждения.

## 4. Чего это решение не делает

1. **Семя не перепечатано.** Слово `«Случайные октеты»` знает только
   компилятор, напечатанный из `flang/self/parser.flang` этой правки. Двоичный
   ствола отвечает на программу с ним `FLANG_UNKNOWN_NAME: неизвестный вариант`.
   Ждёт партии печати; до неё набор проб краснеет на двоичном ствола, и это
   его ожидаемое состояние.
2. **Хозяин конкурентности (`flang/src/emit/c/flang_conc.c`) не тронут.** Его
   `«Случайное число»` — словарь `«Действие»`, а не `«Поручение»`, и он
   нарочно ведётся тем же mulberry32, что и чередование, ради повторимости.
3. **Python-хозяина планов нет**, правлен только список имён в
   `flang/src/emit/python/flang_io.py`.
4. **Машина без `/dev` (chroot, песочница)** получает `FLANG_IO_ENTROPY`, а не
   тихую замену источника.
5. **Хозяин вкладки** отстаёт от словаря на семь поручений и до этой правки
   (`bootstrap/flang run-script tab-host:check` красный на стволе); новое
   поручение в нём есть, старый долг не закрыт.
