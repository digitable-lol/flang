# ADR-0098. Ядро читает условие ветви фактом в обеих половинах и сравнивает два литерала само

**Состояние:** предложено. Принимает владелец.
**Дата:** 12 октября 2026.
**Основание:** раздел «Ограничения» в `docs/DESCRIPTION.md`, два пункта: «Условие
ветки `если` он как известный факт не использует» и «Строгое сравнение в
precondition prover на literal-аргументе не доказывает».
**Рядом:** [ADR-0027](0027-case-analysis-prints-as-a-derivation-and-is-replayed.md) —

вердикт на слове ядра называется отдельно.
**Замер:** ветка `a/the-prover-reads-the-branch-condition-and-tightens-a-literal` от
`dev` `973a31f3e`, двоичный `bootstrap/flang` 0.7.26 из этого же дерева; правленое
ядро гонялось толкователем из исходника (`flang/self/bootstrap/check-with-source-compiler.flang`,

## 1. Задача

Две программы, обе на двоичном 0.7.26 (`dev` `973a31f3e`):

```flang
модуль «Модуль целого»

тотальная функция «Модуль»
  принимает х: целое
  возвращает целое
  обеспечивает «неотрицателен» результат не меньше 0
  если х меньше 0
    то 0 минус х
    иначе х
```

`bootstrap/flang check … --proof` — «НЕ ПРОВЕРЕНО — утверждений 1: доказано 0»,
код 3. Постусловие верно для каждого целого, но ядро его не берёт.

```flang
модуль «Предусловие»

тотальная функция «Доля»
  принимает часть: число, целое: целое
  возвращает число
  требует «делитель положителен» целое больше 0
  часть делить на целое

тотальная функция «Половина»
  принимает часть: число
  возвращает число
  «Доля» от часть и 2
```

`bootstrap/flang check …` — `FLANG_PRECONDITION_CALL` «у цели этого случая нет
вида, к которому у ядра есть правило», код 1. С `требует … целое не меньше 1` тот же
вызов принимается.

### 1.1. Почему не брал разбор цели по условию

Разбор цели по условию (Р2) у ядра уже был: цель с `если` внутри делится надвое,
условие подставляется значением `да` и `нет`. Прогон ядра из исходника на цели
`(если х меньше 0 то 0 минус х иначе х) не меньше 0` назвал обе беды:

- **половина «условие истинно»** — `(0 минус х) не меньше 0` при допущении
  `х меньше 0`. Условие в допущения кладётся, но разность ядро брало только правилом
  Н12: «Л минус П» при порядке «П не больше Л» И при П в [0, К]. Здесь П = х
  отрицательно, и Н12 не проходит.
- **половина «условие ложно»** — `х не меньше 0` без единого допущения. В ложную
  половину отрицание условия не клалось вовсе. ADR-0027 так решил сознательно:
  перевод `не (х меньше у)` в `х не меньше у` ложен на не-числе, и чтение
  ложной ветви доказало бы ложь о «Сортировать» (`[0 делить на 0, 1]`).

### 1.2. Почему не брался литерал

Предусловие на месте вызова — цель `2 больше 0` после подстановки довода. У
строгого порядка ядро знало только вид «верхняя сторона — ТЕРМ»
(«Это строгий порядок термом»); верхняя сторона здесь конечный литерал, и цель
ушла в «нет вида». Вычисление замкнутой цели (Выч) её бы взяло, но снятие
предусловия зовёт ядро без программы («Место снято» — «Свести витками» с
«Нет программы»), и Выч там не зовётся. Нестрогое `2 не меньше 1` проходило другим
правилом — П1, ограниченность литерала.

## 2. Решение

### 2.1. Р8 — отрицание условия кладётся допущением ложной половины

В «Вторая по форме» ложная половина получает допущение `не У` — выбор
`если У то нет иначе да`, как язык и пишет `не`. Это то самое, что половина
предполагает, и потому верно при любом типе: в половине, где `У` заменено на
`нет`, `не У` истинно, в том числе на не-числе. Отрицание остаётся отрицанием: ни
одно прежнее правило не читает его порядком.

### 2.2. Отр1 — порядок из отрицания сравнения над сторонами без не-числа

Новое правило фактов «Порядок из отрицания сравнения»: из допущения
`не (А меньше Б)` выводится `Б не больше А`, из `не (А не больше Б)` — `Б меньше
А`, «больше» и «не меньше» зеркально, и к выведенному кладётся его зеркало. Берётся
ТОЛЬКО когда обе стороны без не-числа по построению:

- конечный литерал-число;
- имя, объявленное целостным типом (`целое`, `неотрицательное`, `сотых`,
  `тысячных` — «Целое по типу»), или названное целым фактом («Целое фактом»).

На `число` правила нет. Встречный пример: `х = 0 делить на 0`, `не (х меньше 0)`
истинно, а `х не меньше 0` ложно — на не-числе ложны обе стороны сравнения.
Минус ноль и бесконечности порядка не ломают: `не (минус ноль меньше 0)` истинно,
и `0 не больше минус ноль` истинно; вне не-числа порядок IEEE-754 линеен. Lean:
«Отр1», «Отр1-не-больше», «Отр1-на-не-числе-ложна», «Отр1-минус-ноль».

Отрицание равенства (`не (А равен Б)`) порядка не даёт, и правило его не трогает.

### 2.3. Н13 — разность из-под конечного литерала

`К минус П` неотрицательна, когда в допущениях стоит `П не больше К` или
`П меньше К`, сличаемое знак в знак, и К — конечный литерал. Дна у П не
спрашивается: при П = −∞ разность есть +∞, при конечном П точная разность не
меньше нуля, и округление знака не меняет. Конечность К нужна: при К = П = +∞
порядок есть, а разность — не-число («Н13-без-конечности-ложна»). Lean: «Н13»
и «меньше-влечёт-неБольше» (строгий порядок влечёт нестрогий).

### 2.4. Выч2 — строгое сравнение двух конечных литералов

Цель `А меньше Б` или `Б больше А`, у которой обе стороны — конечные
литералы-числа, ядро решает сравнением значений само («Свести строгим порядком
литералов») и называет правило «вычисление замкнутой цели». Ложное сравнение —
отказ «цель ЛОЖНА». Не-число и бесконечность литералом не пишутся, и
конечность спрашивается явно («Это конечный литерал»).

В записи снятия предусловия место, у которого цель — сравнение двух целых
литералов, печатается ходом `Выч ⟨цель⟩ сам` («Сравнение целых литералов записи
верно»); его проигрывает вычислитель половин сверщика. Это поднимает и прежнее
`2 не меньше 1`: оно стояло на слове ядра, теперь проигрывается.

## 3. Сужения

- На `число` ложная половина фактов-порядков не получает (Отр1); получает только
  само отрицание, которым закрывается разве что противоречие.
- Выч2 — только два ЛИТЕРАЛА. Замкнутое выражение (`1 плюс 1`, вызов функции без
  доводов) в снятии предусловия по-прежнему не считается: Выч там не зовётся.
- Печать хода Выч в записи снятия — только целые литералы из цифр; дробный
  литерал ядро снимает, а в записи место остаётся на слове ядра.
- Сверщик ходов Р8/Отр1/Н13 не знает: место, закрытое разбором по условию, в
  записи стоит правилом «разбор цели по условию» без ходов и остаётся на слове ядра
  (код сверщика 3) — как 431 такое место библиотеки по замеру ADR-0073.

## 5. Последствия

- Строк ведомости правил прибавилось четыре: Н13, Р8, Выч2, Отр1; сторож таблиц
  считает правил из ADR 99.
- Р2 больше не говорит «отрицания нет вовсе»: отрицание кладётся (Р8), порядок
  из него даёт только Отр1.
- До двоичного правка доходит перепечаткой семени (задача 6098).

## 6. Отвергнутые пути

- **Читать ложную ветвь порядком на `число` с молчаливой оговоркой.** Молча
  подразумевать «пока это число» значит доказывать ложь на `0 делить на 0`.
  Конечность, известную из оговорки цели или из охраны (список «конечные»),
  Отр1 сегодня тоже не читает: правило взяло самый узкий источник — тип и
  литерал; расширение на «конечные» верно (конечное не есть не-число), но не
  замерено и оставлено.
- **Звать Выч в снятии предусловия с программой.** Выч считает и вызовы, а ход
  Выч сверщика вызовы не разворачивает: снятие стало бы «доказано» без
  проигрыша и могло разойтись со сверщиком. Литерал против литерала считается
  без программы.
- **Разложение «не меньше» на «больше или равно».** «равен» языка отличает минус
  ноль от нуля; через отрицание сравнения ядро идёт к порядку прямо, не через
  равенство.

## 7. Что не сделано

- Ходы Р8/Отр1/Н13 в записи и приёмы сверщика для них — места остаются на слове
  ядра (задача 6098).
- Замкнутое выражение не-литерал в снятии предусловия.
- Отрицание равенства фактом-неравенством.
