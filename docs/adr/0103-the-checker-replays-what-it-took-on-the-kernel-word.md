# ADR-0103. Сверщик переигрывает ссылку на постусловие с ограничением, цель, равную ограничению, и шаг «по предположению» у теоремы над постусловием

## 1. Задача

Сверщик на C (`flang/proof/checker/checker.c`) отвечает тремя кодами: 0 — всё
доказанное проиграно заново, 1 — запись противоречит исходнику, 3 — запись не
противоречит, но часть мест сверщик взял на слово ядра. Пункт «Ограничений» называл
одну пробу и два кода. Воспроизведение 12 октября 2026 на `dev` `973a31f3e`:

```
$ bootstrap/flang check flang/proof/checker/tests/families/citation/step-by-restricted-postcondition.flang --proof
FLANG_PROOF_STEP … ограничение «таких что» постусловия «сдвиг неотрицателен» функции «Сдвиг»
на месте вызова не выведено из того, что там известно …          код 1
$ flang/proof/checker/сверщик <тот же исходник> <его запись>
НЕ ВЗЯЛСЯ (строк причин 2; мест на слово ядра 2) …               код 3
```

Половина пункта устарела: ядро сегодня отказывает этой программе кодом 1, и
справедливо — «Второй сдвиг» зовёт «Сдвиг» на любом числе, а постусловие «Сдвиг»
обещано лишь при `н не меньше 0` (на `н = -1` вторая функция возвращает −1). Запись
пробы снята прежним ядром, которое эту ложь доказывало; сверщик держал её кодом 3.
Вторая половина настоящая: честную ссылку на постусловие с ограничением сверщик не
переигрывал вовсе, даже там, где ограничение снято типом довода.

`flang/proof/forgeries`, у которых исходник на месте, каждая против своего исходника.

не проигрывает», «в этом исходнике его нет»).

Самые частые строки таблицы — не один приём, а общий вывод ядра, которого запись не
несёт («узел без правила», «переписка допущением»); переиграть их значит повторить
поиск ядра, а не сверить напечатанное. Эта работа берёт виды, у которых формат записи
уже несёт всё нужное: ссылку на постусловие с ограничением (строка пункта), цель,
равную ограничению или гипотезе (правило ядра Т1, «цель есть допущение», в трёх местах
записи).

## 2. Решение

Четыре приёма, каждый в обоих сличителях — на C и на Lean — по описанию формата
(`docs/flang/proof/record-format.md` §3.3, §3.4, §3.8), без чтения ядра.

**Общий читатель строки ограничения.** Строка `для всех X таких что R обеспечивает «И» Ц`
читается одним читателем (`ограничение_постусловия` / `«ограничениеПостусловия»`): R —
текст между ` таких что ` и ` обеспечивает «`, X — имена между `для всех ` и
` таких что `. Связанные X обязаны быть ровно параметрами функции
(`связанные_параметры`), иначе инстанция оставила бы чужое свободное имя.
Инстанция R на доводах вызова и её снятие — `ограничение_на_доводах` /
`«ограничениеНаДоводах»`: инстанция вида `Т не меньше 0`, Т неотрицательно
грамматикой Н (`неотрицательно_algebra` / `«неотр?»`) при дне у параметров
вызывающей встроенного натурального типа (тот же список имён, что `segments.tsv`).

1. **Ход «факт по свойству» берёт постусловие с ограничением** (C
   `ход_факта_свойством`, Lean `«ходФакта»`). Прежде строка с ` таких что ` давала
   беду «строка не несёт «обеспечивает»». Теперь инстанция ограничения оплачивается
   так же, как `требует` вызванной: снята в точке (`снято_в_точке` — «требует»
   вызывающей, охрана цели, доказанный факт `дано`) или постусловие фактом не
   берётся.
2. **Шаг теоремы «по свойству» постусловием с ограничением** (C `ограничение_у_вызова`
   в `шаг_постусловием`, Lean `«ограничениеУВызова»` в `«шагПостусловием»`). Снятая
   дном инстанция кладётся доказанным фактом `дано` прогона и проходит оплату хода 1.
   **Ложь, код 1**, — ровно одна: инстанция замкнута и ложна (считается без единого
   имени), а известного в точке нет вовсе — у вызывающей нет `требует`, у её
   постусловия с именем теоремы нет `таких что`, у теоремы нет допущений, место — не
   свободное утверждение, тело без `если` и без связывателей. Из пустого известного
   замкнутую ложь не выводит никакое правило, а запись числит шаг выведенным.
3. **Крюк «цель есть ограничение»** (Т1 у постусловия без ходов; C
   `цель_есть_ограничение` в `крюки_по_телу`, Lean `«цельЕстьОграничение»` в
   `«крюкиПоТелу»`): Ц с телом функции вместо `результат` есть R знак в знак (с
   точностью до объемлющих скобок сторон — `совпали_цели` / `«совпали»`). Тело без
   связывателя.
4. **Шаг «по предположению» у теоремы над постусловием** (Т1 у шага; C
   `цель_есть_гипотеза` в `сверить_шаги`, Lean `«цельЕстьГипотеза»` в `«судитьШаги»`):
   закрывающий шаг без индукции, цель с телом вместо `результат` есть одна из гипотез,
   законность которых сверена и без этого приёма — допущение записи
   (`сверить_снятие_гипотез`), ограничение постусловия из исходника, `требует` функции
   или факт объявленного натурального типа (`факт_типа`).
5. **Тот же снятый факт — в крюке «цель от вызванной»** (C `цель_от_вызванной`, Lean
   `«цельОтВызванной»`): место по объявлению, чьё тело — один вызов с простыми
   доводами, берёт и постусловие вызванной с ограничением, если инстанция снята дном.

### 2.1. Сужения

- Снятие ограничения — только формой `Т не меньше 0` и только дном встроенного
  натурального типа или `требует`/охраной/фактом `дано` в ходе 1. Ограничение иного
  вида (`больше`, конъюнкция, порядок двух доводов) остаётся на слове ядра.
- Свои отрезки пользователя дна не дают: их список читается `объявление_типа`, а
  сличитель на Lean держит свой; общий закрытый список имён один (`segments.tsv`).
- Тело со связывателем (`пусть`, `разбор`, `свёртка`, `отобразить`, `отфильтровать`,
  `случай`) ни одного из пяти приёмов не получает.
- Ложь — только замкнутая и только при пустом известном. Незамкнутое неснятое
  ограничение — «не взялся», код 3: сверщик не доиграл, а не поймал.

## 4. Встречные примеры

- Проба пункта (`н: число`, ограничение `н не меньше 0`) — ядро сегодня отказывает
  кодом 1; запись прежнего ядра сверщик держит кодом 3, а не 0: снять ограничение
  нечем. Кодом 1 её не назвать: ограничение не замкнуто.
- Замкнутое и ложное ограничение при допущении теоремы или `требует` — код 3, не 1:
  противоречивое известное выводит что угодно, и правило «противоречие» у ядра есть.
- Цель «результат не меньше 0» при теле `н плюс 1` и ограничении `н не меньше 0`
  истинна, но приёмом 3 не берётся: цель не равна ограничению знак в знак.

## 6. Отвергнутые пути

- **Объявить пробу пункта подлогом (код 1).** Сверщик не знает, что ограничение
  невыводимо: у ядра его вывод — сведение, а не дословное сличение. Назвать ложью
  недоигранное он не вправе (доктрина трёх исходов, ADR-0073).
- **Перенести снятие дном в ход «факт по свойству».** Ход общий с записанными ходами
  ядра; там дно у параметров уже вне вида записи. Снятие оставлено зовущему, ход
  принимает только снятое.
