# ADR-0106. Формула с кванторами и LaTeX входит и выходит через недоверенный переводчик

**Состояние:** предложено. Направление одобрено владельцем: «ввод и вывод на языке
кванторов и в LaTeX, в обе стороны». Принимает владелец.
**Дата:** 13 октября 2026.
**Основание:** просьба владельца; утверждения fmath
([ADR-0028](0028-fmath-is-a-proof-library-for-programs-not-a-mathlib.md)) и корпуса
доказательств читаются только как исходник flang.
**Рядом:** [ADR-0058](0058-a-foreign-language-enters-through-an-untrusted-translator.md) —
чужой язык входит недоверенным переводчиком, образец этого решения;
[ADR-0036](0036-an-exact-integer-is-a-new-kind-of-value-not-a-new-name.md) и
[ADR-0062](0062-an-exact-fraction-is-a-pair-of-exact-integers-reduced-at-the-action.md) —
точное целое и точное дробное, носители ℕ и ℚ≥0;
[ADR-0084](0084-the-kernel-rewrites-a-goal-by-proved-equality-and-a-quantifier-opens-inside-a-formula.md),
[ADR-0094](0094-a-quantifier-under-a-connective-is-proved-and-a-wrong-named-witness-is-refused.md) —
квантор внутри формулы и свидетель;
[ADR-0095](0095-ring-laws-are-one-rule-over-the-exact-integer-and-a-refusal-with-a-cause-over-number.md) —
законы кольца над точным целым.
**Проверяется:** `bootstrap/flang run-script formula:probes`;
`bootstrap/flang run-script formula:round-trip`.

---

## 1. Задача

Утверждение flang пишется словами: `для всех «x»: целое`, `утверждаем («x» плюс «y»)
равен («y» плюс «x»)`. Математик пишет `∀ x ∈ ℤ, ∀ y ∈ ℤ, x + y = y + x` или то же в
LaTeX. Нужно, чтобы формулу можно было отдать ядру, а утверждение flang — напечатать
формулой, в обе записи, и чтобы ни в одну сторону не пришлось верить переводчику на
слово.

## 2. Развилка

**А. Разборщик формул в компиляторе, рядом с `parser.flang`.** Формула стала бы
поверхностью языка. **Отвергнуто:** доверенная основа приняла бы вторую грамматику,
а правка `flang/self/**` доезжает до двоичного только перепечаткой семени — сейчас её
держит партия печати 6. Довод ADR-0058 §2 А повторяется дословно: чужую запись нельзя
делать доверенной раньше, чем замкнут круг на своей.

**Б. Переводчик вне доверенной основы, на fscript, на нынешнем двоичном.** Формулу
читает отдельная программа и печатает утверждение flang; его судит `flang check
--proof`. Обратная печать сверяется кругом. **Выбрано.** Компилятор не тронут ни
строкой, перепечатка не нужна.

**В. Языковая модель переводит формулу.** Без однозначной грамматики нет и
однозначного отказа. **Отвергнуто**; подсказчиком модель может быть и здесь (ADR-0058
§3 п. 5), но не частью переводчика.

## 3. Решение

### 3.1. Подмножество записи

| знак | с кванторами | ASCII | LaTeX | flang |
|---|---|---|---|---|
| ∀ | `∀ x ∈ ℤ,` / `∀ т : тип,` | `forall x in ZZ,` | `\forall x \in \mathbb{Z},` | `для всех «x»: целое` |
| таких что | `\|` | `\|` | `\mid` | `таких что (…)` |
| ∃ | `∃ m, P`, `∃ m := t, P` | `exists` | `\exists` | `есть такой «m»[, а именно t], что (P)` |
| → | `→ ⇒ ⟹` | `-> =>` | `\to \implies \Rightarrow` | `если A то B иначе да` |
| ↔ | `↔ ⇔ ⟺` | `<-> <=>` | `\leftrightarrow \iff` | `A равен B` |
| ∧ ∨ ¬ | `∧ ∨ ¬` | `/\ \/ ~`, `and or not` | `\land \lor \lnot` | `и притом`, `или`, `не` |
| = ≠ < ≤ > ≥ | те же | `= != < <= > >=` | `= \neq < \leq > \geq` | `равен` … `не меньше` |
| + − · / | `+ − · × /` | `+ - * /` | `+ - \cdot \times / \frac` | `плюс` … `делить на` |
| степень | `x^n`, n — число 1…16 | `^` | `x^{n}` | раскрывается умножением |
| ⊤ ⊥ | `⊤ ⊥` | `true false` | `\top \bot` | `да`, `нет` |
| ℕ ℤ ℚ≥0 | `ℕ ℤ ℚ≥0` | `NN ZZ QQ>=0` | `\mathbb{N}` … `\mathbb{Q}_{\geq 0}` | см. 3.2 |

Сверх знаков: скобки `( )`, список `[a, b]`, вызов функции `f(a, b)`, поле `p.f`,
встроенная форма `длина(x)`, строка `"…"`, имя в ёлочках `«…»`. В LaTeX имя из
нескольких букв пишется `\text{…}`, пробелы `\, \; \ ~ \quad` и `\left`/`\right`
пропускаются, `{ }` — скобки.

### 3.2. Носители — честно, какие есть

| запись | тип flang | чем это не то же самое |
|---|---|---|
| `ℕ` | `точное целое` | ничем: без потолка, кольцо доказывается правилом «кольцо точного целого» (ADR-0095) |
| `ℤ` | `целое` | **отрезок** [−(2⁵³−1), 2⁵³−1], переполнение уводит в `число`; перевод несёт об этом `примечание` |
| `ℚ≥0` | `точное дробное` | ничем внутри неотрицательных |
| `ℚ`, `ℝ`, `ℂ` | — | отказ `FLANG_FORMULA_CARRIER`: дроби без знака (ADR-0062), `число` — double |
| `: тип` | тип дословно | любой тип flang, слово в слово |

### 3.3. Грамматика однозначна, а неоднозначное — отказ

```
формула   := { "∀" имена ( "∈" носитель | ":" тип ) [ "|" тело ] "," } тело
тело      := следование [ "↔" следование ]
следование:= связка [ "→" связка ]
связка    := унарное { ("∧" | "∨") унарное }        -- знак один на всю цепочку
унарное   := "¬" унарное | "∃" имя [ ":=" сумма ] "," тело | сравнение
сравнение := сумма [ отношение сумма ]
сумма     := произведение { ("+" | "−" | "⧺") произведение }
произведение := степень { ("·" | "/") степень }     -- после "/" цепочка кончается
степень   := знаковое [ "^" число ]
знаковое  := "−" число | постфикс
постфикс  := первичное { "." имя }
первичное := число | строка | ⊤ | ⊥ | имя [ "(" аргументы ")" ] | "(" тело ")"
           | "[" аргументы "]" | "\frac" первичное первичное
```

Отказ с кодом `FLANG_FORMULA_AMBIGUOUS` стоит там, где у читателей формул нет общего
прочтения: цепочки `↔`, `→`, сравнений и `^` без скобок; `∧` и `∨` в одной цепочке;
`·` или `/` после `/`; умножение без знака (`2x`; в LaTeX — `xy`). Квантор `∀` стоит
только в начале: квантора всеобщности над носителем внутри формулы в flang нет, его
отказ — `FLANG_FORMULA_QUANTIFIER`. У `∃` нет носителя: тип свидетеля выводит ядро,
поэтому `∃ y ∈ ℤ` — тоже отказ, а не молчаливая потеря `ℤ`.

Условия `таких что` в дереве разбора flang — список без привязки к имени. Печать
ставит их на последние связанные имена (одно условие на имя), чтение кладёт каждое
на свою строку `для всех`: дерево от этого не меняется (проверено кругом, §5).

### 3.4. Переводчик вне доверенной основы

* Перевод формулы — обычный исходник flang; доверия у него ровно столько, сколько даёт
  слово ядра. Переводчик ничего не доказывает и ничего не ищет.
* Обратная печать сверяется кругом: утверждение → обе записи → чтение → перевод →
  `flang ast` самого компилятора → сличение с деревом исходного утверждения без мест
  (`span`) и без имени. Сличает разборщик компилятора, а не переводчик.
* Круг с формулы на формулу не тождествен и не обязан: `x^2` возвращается как
  `x · x`, `\frac{a}{b}` — как `a / b`, `↔` над признаками и `=` — как один `равен`.
  Тождествен круг с утверждения на утверждение, и только он сверяется.

### 3.5. Коды отказа

| код | когда |
|---|---|
| `FLANG_FORMULA_EMPTY` | формула пуста |
| `FLANG_FORMULA_SIGN` | знак вне записи |
| `FLANG_FORMULA_SYNTAX` | ждали одно, стоит другое; лишнее после формулы |
| `FLANG_FORMULA_AMBIGUOUS` | §3.3 |
| `FLANG_FORMULA_QUANTIFIER` | `∀` без носителя или внутри формулы; `∃` с носителем |
| `FLANG_FORMULA_CARRIER` | `ℚ`, `ℝ`, `ℂ`; носитель не после `∈` |
| `FLANG_FORMULA_POWER` | показатель не число 1…16 |
| `FLANG_FORMULA_MINUS` | унарный минус у выражения |
| `FLANG_FORMULA_LATEX` | команда вне подмножества LaTeX, индекс не у `ℚ`, незакрытая `{` |
| `FLANG_FORMULA_USAGE` | вызов без формулы или файла |
| `FLANG_FORMULA_FILE` | `flang ast` не разобрал файл для печати |
| `FLANG_FORMULA_OUTSIDE` | у файла есть утверждения вне записи |
| `FLANG_FORMULA_KERNEL` | ядро отвергло перевод (код `check` не 0 и не 3) |
| `FLANG_FORMULA_PROBE` | проба таблицы разошлась |
| `FLANG_FORMULA_ROUND_TRIP` | круг разошёлся |

Сообщения — по-русски, каждое называет, как написать иначе.

## 4. Устройство

Каталог `flang/foreign/formula/`:

* `notation.fscript` — лексер записи с кванторами (Юникод и ASCII), перевод LaTeX в
  эту запись, разбор в дерево, печать дерева в обе записи и в исходник flang;
* `tree.fscript` — дерево разбора утверждения (`flang ast`) в дерево формулы; что не
  ложится в запись, называется причиной;
* `run.fscript` — планы `Read`, `Print`, `Round trip` (без доводов — все `утверждение`
  дерева, с доводами — названные файлы), `Probes`;
* `probes.tsv` — пробы: запись, формула, код, ожидаемый перевод или сообщение, слово
  ядра.

Короткие команды: `formula:read`, `formula:print`, `formula:round-trip`,
`formula:probes`. Руководство — [docs/guide/formulas.ru.md](../guide/formulas.ru.md).

утверждения: разборщик ставит дереву сравнения признак `числовая` по объявлениям файла
(`«Длина» от л` числовое, если функция `«Длина»` объявлена с `возвращает число`), а в
отдельном модуле объявлений нет. Перепечатка теперь дописывается в конец исходного
файла, и признак сличается, а не вычёркивается. Отрицательный опыт: печать без скобок
у правого операнда (`а + (б + ц)` → `а + б + ц`) на `exact-ring/ring-laws.flang` даёт
«разошлось 3» и код 1 `FLANG_FORMULA_ROUND_TRIP`.

**Пробы** (`formula:probes`): 37 проб, из них 15 переводов и 22 отказа; у всех 15
переводов названо слово ядра, и все сошлись — 12 «доказано», 3 «объявлено, не
доказано»; в том числе пример владельца в обеих записях — «доказано», правило
«тождество после переписки допущением», и `(x + y)^2` над ℕ — «доказано», правило
«кольцо точного целого».
Отрицательный опыт: слово «доказано», вписанное пробе `∀ x ∈ ℤ, ¬(x < x)`, план
красит кодом `FLANG_FORMULA_PROBE`; ожидаемое сообщение, изменённое на один знак, —
тоже.

## 6. Чего нет

* **Постусловия и теоремы.** Круг идёт по объявлениям `утверждение`; `обеспечивает` у
  функций (в `flang/proof` их 6118) печатается формулой только после решения, как
  записывать `результат` — вызовом функции или отдельным именем. Не сделано.
* **Литерал над ℕ.** `2 · x` над `точное целое` ядро отвергает (`FLANG_TYPE`: точное
  целое и число не смешиваются). Литерал канона пишут нульместной функцией (ADR-0095);
  переводчик типов не выводит и литерал за функцию не прячет.
* **Квантор по элементам списка** (`для всех э из Л`) и `∀` внутри формулы в запись не
  входят.
* **ℤ без потолка и ℚ со знаком** — нет носителя в языке.
* Сверщик записей доказательства (`flang/proof/checker`) переводы не переигрывает:
  слово ядра у перевода — «на слове ядра», как у любого исходника без собранного
  сверщика.
