# ADR-0126. Законы категорий: две работы закрывают свою часть, остаток назван и получает свои этапы

**Состояние:** предложено. Принимает владелец.
**Основание:** требование владельца закрыть дыру «законы категорий проверяются на примерах, а
не доказываются в общем виде»; сводка — [`docs/trust-gaps.ru.md`](../trust-gaps.ru.md).
Этот документ — только связка. Две работы уже идут, и он их не повторяет:

- **законы объявлений становятся теоремами ядра** (ADR-0121, ещё не в стволе): из объявления
  моноида, монады и изоморфизма порождаются утверждения, которые ядро доказывает
  существующими правилами — кольцом точного целого и переписыванием допущением;
- **абстрактная теория категорий**: корпус теорем на Lean (категории, функторы, естественные
  преобразования, сопряжения, монады, пределы, Йонеда) и разрешитель равенств путей в ядре —
  этап 1 своей карты.

**Замер:** дерево `gh/dev` `f32baf155`, двоичный `bootstrap/flang` 0.7.28 из этого дерева;
`bootstrap/flang check <файл> --proof` по каждому из 29 файлов `flang/ct/**/*.flang`.

## 2. Что останется непокрытым после обеих работ

| остаток | почему не покрыт |
|---|---|
| законы функтора (тождество, композиция) для объявленных функторов | порождение законов объявлений их не порождает; Lean-корпус — об абстрактном функторе, не о функторе из исходника |
| естественность объявленных преобразований и их устройство | не порождается; устройство не сверяется |
| монада: второй закон единицы и сочетательность (порождается один закон из трёх) | не порождается |
| пятиугольник и треугольник моноидальной структуры, треугольники сопряжения, единственность у конусов | у объявлений — сетка или рукописное `обеспечивает` |
| законы над `число` | ложны на минус нуле, «не числе» и из-за округления; ADR-0095 отказывает с причиной, сетка ходит по IEEE-754 |
| законы над функциями (равенство функций) | правила экстенсиональности в ядре нет |
| связь объявления с абстрактной теоремой | Lean-корпус общий, но объявление из исходника не становится его экземпляром: «для всякой категории» не прикладывается к конкретной |
| сторона Lean у порождения законов | теоремы, что порождённое утверждение — ровно закон объявления, нет; ошибка порождения общая для ядра и `checker.c` (обе стороны порождают сами) |
| вердикт разрешителя путей | разрешитель — поиск; без записи, которую переигрывает сверщик, его ответ — слово ядра |

## 3. Решение

Каждый пункт остатка получает свой этап, и каждый этап — в той работе, которой он ближе;
новой третьей работы не заводится.

1. **Порождение расширяется** на законы функтора, естественность, все три закона монады,
   пятиугольник и треугольник, треугольники сопряжения — в работе законов объявлений, тем же
   способом: утверждение после последней строки исходника.
2. **Разрешитель путей печатает запись**: цепочку переписываний по законам, которую
   `checker.c` и второй сверщик переигрывают шагом за шагом. Ядро ищет, сверщики только
   проверяют — как у свидетеля существования.
3. **Мост к Lean-корпусу.** У порождения законов — модель на Lean: функция «объявление →
   утверждения» и теорема, что её выход есть экземпляр абстрактного закона из корпуса
   (`Cat.assoc`, `Fun.map_comp`, `NatTrans.naturality` и т. д.). Тогда абстрактная теорема
   переносится на конкретное объявление, а порождение выходит из доверенной базы.
4. **Числа.** Закон над `число` не объявляется доказанным никогда. Отказ ядра называет
   носитель и предлагает точный носитель (`точное целое`, точные десятичные); сетка
   остаётся только для поиска нарушений.
5. **Равенство функций** — правило экстенсиональности в ядре с леммой в `Rules.lean`;
   только после эталонной семантики (ADR-0136), где равенство функций определено.
6. **Доля законов** — отдельная строка ведомости: законов доказано ядром, на сетке, не
   посчитано; по всему дереву, а не по файлу.

## 4. Этапы

| этап | что | объём | измеримый итог |
|---|---|---|---|
| 1 | план-перепись законов: прогон `check --proof` по `flang/ct` и `docs/examples`, таблица «объявление × закон × вердикт»; согласовать с обеими работами, какой строкой таблицы закрывается каждый их этап | 1–2 дня | таблица с числами доказано / сетка / не посчитано; общая точка отсчёта для обеих работ |
| 2 | порождение законов функтора, естественности, монады целиком (п. 1) | 2–3 недели | строк «доказан ядром» о законе в `flang/ct` больше нуля |
| 3 | запись разрешителя путей и её переигрывание (п. 2) | 2–3 недели после разрешителя | подделка «лишний шаг пути» отвергнута обоими сверщиками |
| 4 | мост порождения к Lean-корпусу (п. 3) | 3–4 недели | теорема «порождённое = экземпляр закона» без `sorry` для моноида, функтора, монады |
| 5 | экстенсиональность (п. 5) | 2 недели после этапа 3 ADR-0136 | закон над функциями доказан |

## 5. Что отвергнуто

- **Третья отдельная работа по законам.** Остаток делится между двумя идущими работами по
  близости.
- **Доказывать законы над `число`.** Они ложны.
- **Доверять разрешителю путей без записи.** Тогда вердикт держится на слове ядра.
