# ADR-0127. Каждый ход половины в сверщике на C имеет теорему в Lean, и доверенная база растёт на эти ходы

**Состояние:** предложено. Принимает владелец.
**Дата:** 16 октября 2026.
**Рядом:** [ADR-0064](0064-every-checker-move-has-a-lean-theorem-or-a-named-debt-row.md) —
теорема или строка долга у каждого приёма; [ADR-0097](0097-the-trusted-base-of-the-checker-grows-with-its-rules-and-the-tables-guard-runs-in-ci.md) —
потолок доверенной базы.

---

## 1. Задача

Сверщик на C закрывает половину цели сам: разбор по случаям, факты из `требует` и из
обещаний вызываемых, подсчёт длин, раскрытие вызова. Эти ходы жили в `checker.c` без
теоремы в Lean, и сторож правил их не считал. Когда теоремы стали писать, нашлась дыра:
факт из `требует` применялся внутри случая, чей образец заново связывал то же имя, и
ложное постусловие переигрывалось кодом 0.

## 2. Решение

1. Ходы половины собраны в одну область `checker.c`, от зеркала отношений до чтения
   тела. Для каждой функции области в `flang/proof/lean/Half.lean` есть теорема того же
   имени; сборная теорема зависит только от `propext`, `Classical.choice` и `Quot.sound`.
2. Факты не входят в группу разбора: образец, связавший имя факта, факт не видит.
   Подделка `case-split-facts/corrupt/pattern-name-hides-required-fact` закрепляет это
   кодом 3.
3. Разбор по случаям требует покрытия типа из объявления; значение заменяется
   конструктором только при полном образце с различными именами полей. Литералы,
   решающие атомы, — целые не больше 2^53; длины считаются по не более чем 16 листьям
   с целыми не больше 2^48.
4. Две ветви вычислителя, бравшие элемент списка и символ строки по номеру, сняты:
   теоремы у них нет, и такой атом остаётся на слове ядра.
5. `lean-rules:check` читает область половины и краснеет на функции без теоремы того же
   имени. `Trap.lean` получает искажения 95–104: те же ходы без одной посылки.
6. Потолок `checker-code-lines` поднят на рост `checker.c` от этих ходов (§3), строка в
   таблице ADR-0097 §3.

## 4. Чего не сделано

- Ходы половины в запись не печатаются: сверщик читает исходник, правка печати
  потребовала бы перепечатки семени.
- Элемент списка и символ строки по номеру сверщик не вычисляет; такие места остаются
  на слове ядра, пока для них нет теоремы.
