# ADR-0139. Круг вызовов завершается по изменению размера

**Состояние:** предложено. Принимает владелец.
**Дата:** 17 октября 2026.
**Основание:** заявки 388, 399 и 382 (задачи 5958, 7718, 3536): круг взаимной
рекурсии, где довод убывает на одном ребре и проходит неизменным на другом;
круг через частичное применение с хвостом в замыкании; спуск на переменный шаг
`бит минус уровень` при `требует уровень не меньше 1`.
**Замер:** ветка `a/termination-by-size-change` от `gh/dev`, двоичный
`bootstrap/flang` 0.7.28 этого дерева и исходники компилятора, истолкованные им
(`flang/self/bootstrap/check-with-source-compiler.flang`).
**Рядом:** [ADR-0036](0036-an-exact-integer-is-a-new-kind-of-value-not-a-new-name.md)
— точное целое; раздел «Точное натуральное» `docs/flang/SPEC.md`.
**Компилятор:** правки в `flang/self/totality.flang`, `carriers.flang`,
`types.flang`, `totality-refusals.flang`; в двоичный они попадают печатью семени.

---

## 1. Что было

Проверка завершения брала круг вызовов, только если одна и та же позиция довода
строго убывала на каждом ребре круга. Довод сравнивался с параметром того же
номера. Круг, в котором `таблица` уходит хвостом в «Прочитать в», а оттуда
возвращается без изменений, отвергался, хотя каждый оборот круга укорачивает
список. Круг через применение функции-значения отвергался всегда: у такого
ребра не было доводов вовсе.

## 2. Решение

### 2.1. Граф изменения размера

Каждое ребро круга `f → g` даёт граф: дуга `i → j` значит, что довод `j`
вызова `g` есть параметр `i` функции `f` (дуга нестрогая) или его часть —
хвост, поле варианта, поле записи, элемент (дуга строгая). Графы
складываются по путям круга до замыкания. Круг принят, если у каждого графа
`f → f` из замыкания, равного своему квадрату, есть строгая дуга `i → i`
(принцип Ли — Джонса — Бен-Амрама). Позиции доводов больше не обязаны
совпадать, перестановка доводов разрешена.

Порядок проверок прежний там, где прежняя проверка что-то принимала: сначала
общая убывающая позиция, затем графы, затем меры и сторожа. Принятый графами
круг — завершение структурой, сторожа в напечатанном коде нет.

Замыкание ограничено: не больше 512 графов и не больше восьми проходов на
каждое ребро. Переполнение — отказ, а не принятие.

### 2.2. Ребро через применение

Место применения функции-значения запоминает происхождение самого значения и
доводов. Анализ потока называет, какие функции может держать значение и какие
их параметры связаны в замыкании. Ребро к такой функции получает доводы:
связанный параметр — часть применённого значения (строгая дуга от того
параметра, откуда пришло значение), прочие — доводы применения по порядку.

Замыкание `функция «Ф» с п равным х` с одним связанным доводом, который есть
строгая часть параметра, само не больше этого параметра: размер замыкания —
один узел плюс размер довода. Замыкание с несколькими связанными доводами или
с доводом, не меньшим параметра, ни с одним параметром не связано.

### 2.3. Дно от типа и шаг от требования

Параметр точного типа (`неотрицательное`, `нат`) ограничен снизу нулём своим
типом, проверка `если … не больше 0` для дна не нужна. Строка `требует` вида
`ш не меньше K` при K ≥ 1 (или `ш больше K` при K ≥ 0) делает параметр `ш`
положительным для проверки завершения так же, как такое же условие ветви:
предусловие держит вызывающий, и на входе тела оно верно.

### 2.4. Разность под условием порядка

`а минус б` при факте `б не больше а` (ветвь `если а не меньше б`) над
целыми отрезками имеет низ 0: целая разность неотрицательна. Так
`бит минус уровень` под `если бит не меньше уровень` остаётся `неотрицательное`.
NaN в целом отрезке нет, поэтому довод «на NaN обе стороны сравнения ложны»
здесь не действует.

### 2.5. Совет в отказе

Отказ с убыванием на параметр-шаг больше не советует передавать часть
аргумента и называет требование `ш не меньше 1` наравне с проверкой ветви.

## 3. Подделки

Отвергаются (`flang/self/totality-refusals.flang`, функция «Код отказа по
строкам»): круг без убывания; убывание на одном ребре и рост на другом; обмен
доводами по кругу без убывания; «качели» — хвост туда и целый довод обратно;
замыкание с целым параметром вместо хвоста; замыкание, передающее себя дальше
без убывания; спуск на переменный шаг без требования о шаге.

## 4. Чего решение не делает

- Не доказывает постусловия звеньев круга одновременной индукцией (задача
  4543): это правка ядра доказательств и сверщика, и она противоречит
  записанному в `docs/flang/rationale.md` правилу «постусловие вызванной
  берётся только доказанным».
- Не сравнивает числовые меры между функциями круга: графы строятся только
  из частей значений.
- Сверщик тотальность структурой не проигрывает и до этого решения: блоков
  тотальности для рекурсии в записи двоичный не пишет.

## 5. Предложение владельцу: обещания звеньев круга

Когда круг принят проверкой завершения, отношение «вызов f(x) зовёт g(y)»
фундировано: бесконечной цепочки вызовов нет. Тогда законна одновременная
индукция по дереву вызовов: постусловие каждого звена доказывается при
допущении постусловий всех звеньев на местах прямых вызовов, и набор
принимается целиком, только если доказаны все его члены (наибольшая
неподвижная точка: недоказанное звено снимается, проход повторяется). Это
снимает запрет из `docs/flang/rationale.md` («постусловие вызванной берётся
только доказанным») не для любых кругов, а для кругов с доказанным
завершением. Цена: правка ядра (`flang/self/proof-initial.flang` — допущения
на местах вызова соседей и для тел без `разбор`, `flang/self/proof.flang` —
неподвижная точка по кругу), новая строка записи и её проигрывание в
`flang/proof/checker/checker.c`, умение У29 в `flang/proof/map/abilities.flang`.
До решения владельца граница записана в разделе 5 `docs/flang/proof/SPEC.md`.
