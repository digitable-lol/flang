# ADR-0149. Вызов связывается там, где его связал бы свой модуль, а тёзка в одной программе — отказ

**Состояние:** предложено. Принимает владелец.
**Дата:** 17 октября 2026.
**Рядом:** [ADR-0090](0090-a-helper-of-an-imported-function-binds-in-its-own-module-or-the-link-refuses.md) —
помощник ввезённой функции связывается в её модуле; задачи 1113 (список `только` отказывает при
любом порядке ввозов), 2663 (помощник за `экспортирует`), 2761 (`--на-веру` не запускает
несвязанную программу), 9697, заявка 350.

---

## 1. Задача

Связывание сливает функции всех файлов в одну плоскую таблицу имён. Что из файла попадёт в
таблицу, решает его видимость: `экспортирует` файла и список `только` того, кто ввёз файл
первым. Помощники за `экспортирует` дотягиваются в своём модуле (задача 2663), имя вне своего
списка `только` отказано при любом порядке ввозов (задача 1113). Остались два случая.

1. **Чужой список прятал функцию, нужную другому модулю, и её место молча занимал тёзка.**
   Файл `user.flang` ввозит `«Источник»` со списком `только «Два»`, а входной файл раньше ввёз
   тот же модуль со списком `только «Раз»`. `«Два»` модуля `«Источник»` в таблицу не попадала.
   Если входной файл объявлял свою `«Два»`, вызов в теле `«Через два»` из `user.flang`
   связывался с ней: связывание не говорило ничего, `flang check` входного файла отвечал
   «ПРОВЕРЕНО САМОСТОЯТЕЛЬНО», код 0, а `«Через два»`, у которой в своём модуле доказано
   «результат равен 2», в собранной программе возвращала 7. Отказ ADR-0090 смотрит только на
   скрытые имена файла самой зовущей функции и этого не ловил; отказ задачи 1113 — только на
   имя, которое осталось вовсе несвязанным.
2. **Помощник за списком `только` не попадал в программу.** Взяв по списку функцию, которая
   зовёт соседку по своему модулю, получали `FLANG_UNKNOWN_NAME`, а при двух таких модулях с
   одноимёнными помощниками — тот же `FLANG_UNKNOWN_NAME` вместо названного тёзки.

Ядро при этом не лгало: обязательства ввезённых функций судятся заново на собранной программе,
`run` без согласия называл перехваченное постусловие недоказанным и не запускал, напечатанный
код сохранял проверку постусловия при работе. Лгали связывание и вердикт `check`.

## 2. Решение

1. **Имя в теле функции связывается так, как его связал бы её модуль.** После первого прохода
   связывание обходит каждую связанную функцию и каждое имя, которое она зовёт (вызов, ссылка на
   функцию, имя без доводов), и решает его по правилам её файла: своё объявление, иначе
   объявление модуля, ввезённого этим файлом, если имя видно этому ввозу (`экспортирует` модуля
   и список `только` этого ввоза). Найденное объявление, которого ещё нет в таблице,
   дотягивается в программу; дотянутые функции обходятся так же, до неподвижной точки. Список
   `только` по-прежнему решает, какие имена доступны ввозящему файлу, но больше не прячет
   функцию, которую зовёт её модуль или другой модуль программы своим списком.
2. **Тёзка — отказ с обоими файлами.** Если по правилам файла имя ведёт в модуль `Y`, а в
   таблице под этим именем стоит функция другого файла `Z`, — `FLANG_DUPLICATE_NAME`:
   `в файле user.flang: функция «Два» объявлена в двух модулях: rebind.flang и source.flang;
   «Через два» зовёт её из source.flang, а в программе под этим именем стоит функция из
   rebind.flang — …`. Указать модуль прямо в вызове язык не умеет, поэтому две одноимённые
   функции, которые обе нужны одной программе, разводятся переименованием. Тёзки, которых
   никто из связанных функций не зовёт, не дотягиваются и отказа не дают.
3. Отказ при запуске `--на-веру` у программы с бедами связывания уже держит задача 2761; здесь
   он не меняется.

## 3. Что это ломает и замер

Дотягивание меняет приговор только у программ, которые до правки либо отказывались
(`FLANG_UNKNOWN_NAME` на помощнике или на имени из списка, отказ ADR-0090), либо собирались с
перехватом, как в пункте 1.1. Программа, у которой каждый вызов уже связан со своим
объявлением, не получает ни одного нового имени и ни одного нового отказа.

Замер по дереву разбором текста: для каждой из 380 программ с `использует` (без программ этой пробы) — замыкание
ввозов, видимость по первому ввозу и разрешение каждого имени в ёлочках каждого файла по
правилам этого файла. Перехватов, как в пункте 1.1, — 0; имён, которые дотянулись бы, — 82
(верхняя граница: замер считает и вызовы в функциях, которые в программу не попадают). По
собранной программе зонда `flang/self/bootstrap/check-with-source-compiler.flang` (двоичный
`bootstrap/flang ast`, 10 646 функций, 29 066 вызовов, разрешимых по правилам файла) все 29 066
ведут в то объявление, которое стоит в таблице: дотягивать нечего, отказов нет. Тёзки
библиотеки (`«Шаг начала»` в `aes.flang` и `hmac.flang`, `«Прибавить единицу»` в `aes.flang`
и `math-classics-lists.flang`) одной программе вместе не нужны и отказа не дают.

Связывание из исходника над программами пробы `flang/proof/probes/same-name-functions/`
(толкователь двоичного над `flang/self/link.flang`):

| программа | связывание до правки | после правки |
|---|---|---|
| `both-full.flang` (оба модуля целиком) | `FLANG_DUPLICATE_NAME` | то же |
| `both-only.flang` (тёзка-помощник перехвачен) | `FLANG_DUPLICATE_NAME` (ADR-0090) | то же |
| `both-hidden.flang` (оба помощника за списками) | бед нет, `«Шаг»` не в программе | `FLANG_DUPLICATE_NAME` с обоими файлами |
| `rebind.flang` (пункт 1.1) | бед нет, `«Через два»` зовёт `«Два»` входа | `FLANG_DUPLICATE_NAME`, «`«Через два»` зовёт её из source.flang» |
| `two-lists.flang` (то же без своей `«Два»`) | `FLANG_UNKNOWN_NAME`: «стоит в списке, но не связано» | бед нет; прогон даёт 2 |
| `helper-only.flang` (помощник за списком) | бед нет, `«Шаг»` не в программе | бед нет; прогон даёт 2 |
| `export-helper.flang` (помощник за экспортом) | бед нет | бед нет; прогон даёт 4 |
| `trust-parse.flang` (ошибка разбора во ввозе) | `FLANG_PARSE: в файле broken.flang` | то же |
| `unused-namesakes.flang` (тёзка никому не нужен) | бед нет, `«Шаг»` не в программе | бед нет; прогон даёт 31 |

Прогон: `bootstrap/flang run flang/proof/probes/same-name-functions/run-from-source.flang
--function 'Пробы исходником' --на-веру --max-steps 20000000000 --args '{"тексты": …}'`, где
тексты — 16 файлов каталога `programs/` в порядке `«Ввозимые файлы»`, затем `«Входы проб»`,
через строку `=====`. Около 15 минут.

Таблица пробы держит слова двоичного после печати. На семени 0.7.28 из 26 строк расходятся 16:
семь закрывают задачи 2663 и 2761 (печать 8), девять — эта правка.

Цена: обход тел связанных функций, когда у программы есть ввозы. Программа без ввозов работы
не прибавляет.

## 4. Открытое

- Типы: `только` прячет и типы, а тип в сигнатуре дотянутой функции может быть скрыт тем же
  списком. Дотягивание написано для функций.
- Раннее предупреждение о тёзке при проверке самого модуля — задача 9697.
