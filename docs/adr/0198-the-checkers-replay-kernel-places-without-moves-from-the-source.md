## 1. Задача

Семь мест ядро доказывает без записанных ходов: в записи стоят только правило и строка
`по объявлению`. Сверщики их не переигрывали:

| задача | правило ядра | чего сверщику не хватало |
|---|---|---|
| `nat-order-chain` | порядок по построению | ограничение `таких что` не бралось фактом |
| `and-introduction` | разбор цели по условию | `и притом` в цели при фактах ограничения |
| `contradiction` | несовместимые допущения | несовместность ограничения свободного утверждения |
| `list-filter-length-bound` | порядок по построению (О8) | закона отбора по исходнику не было |
| `nat-maximum-bound` | разбор цели по условию | ложное условие ветви не давало обратного порядка |
| `nat-closed-power` | равенство, решённое счётом замкнутых частей | в вычислителе нет умножения; тело с `убывает` на трёх строках не читалось |
| `tree-mirror-mirror` | тождество после переписки допущением | развёртка вложенного вызова той же функции резала довод |

Записи ядра для переигрывания хватает: всё нужное есть в исходнике. Печать ядра не
меняется.

## 2. Решение

1. **Порядок по фактам.** Сравнения допущений (`таких что`, `требует`, условия ветвей) —
   рёбра графа порядка, цель — путь нужной строгости, строгий круг — несовместные факты.
   Ложное сравнение переворачивается только у заведомых чисел (целый литерал, имя
   типа-отрезка); `равен` ребра не даёт. Во втором сверщике найденный путь проверяет
   `путьВерен`, а теорема `путь-верен` (`flang/proof/checker/second/Order.lean`) говорит,
   что принятый путь даёт верное сравнение на всяком носителе с законами порядка;
   `круг-несовместен`, `ребро-из-ложного`, `отбор-не-удлиняет` — там же.
2. **Выбор по условиям.** Цель с `если У то А иначе Б` делится по истинности У, не
   глубже четырёх условий.
3. **Закон отбора** (О8): `длина (отфильтровать Л где …)` не больше `длина Л`.
4. **Вычислитель** знает `умножить на` (двоичное умножение IEEE-754, как язык) и
   читает `убывает` как объявление; тело `если`/`то`/`иначе` на своих строках собирается
   тем же сборщиком строк, что и в разборе цели.
5. **Развёртка вызова**, чей довод — вызов той же функции, берёт довод целиком.
6. **Контрпример.** Место, которое не взял ни один приём, проверяется перебором значений
   0…3 имён типа-отрезка (не больше четырёх): нашлись значения, при которых допущения
   верны, а цель ложна, — ложь записи, код 1. Место с подставленным свидетелем не
   ищется.

## 3. Цена

`checker-code-lines` поднят с 12000 до 12218 — на 218 строк кода порядка по фактам,
выбора по условиям, закона отбора и контрпримера в `checker.c`. Второй сверщик получил
модуль `Order.lean`.

## 4. Последствия

- Оба сверщика переигрывают 14 из 14 доказанных задач сравнения с Lean.
- Пять прежних подделок-лжи, которые уходили в код 3, теперь отвергаются кодом 1:
  контрпример находит ложь места без привязки к программе.
- Семья проб `kernel-replay`: 7 честных → 0, 9 подделок → 1 или 3.
