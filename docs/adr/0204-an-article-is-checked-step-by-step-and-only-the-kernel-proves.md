# ADR-0204. Статья проверяется по шагам, и доказывает только ядро

**Состояние:** предложено, исполнено: `flang/experimental/argument-check.fscript`, описание —
`docs/argument-check.md`. Принимает владелец.
**Дата:** 6 ноября 2026.
**Основание:** вопрос владельца — можно ли взять произвольную научную статью и
проверить её на все логические ошибки: морфология русского есть, через теорию
категорий можно построить распознавание ошибок и теорем в статьях и находить
неточности.
**Замер:** ветка `a/argument-checker-for-text` от `gh/dev` `c9adfde8a`, двоичный
`bootstrap/flang` этого дерева (`make -C bootstrap`). Все числа ниже сняты
прогонами плана `Check` 6 ноября 2026.
**Рядом:** [ADR-0047](0047-a-syllogism-gets-one-surface-word-not-four.md) и
[ADR-0148](0148-the-shell-judges-statements-and-syllogisms.md) — силлогизм судит ядро;
[ADR-0060](0060-russian-morphology-fills-the-dictionary-and-the-declaration-becomes-a-correction.md)
— морфология наполняет словарь;

[ADR-0167](0167-a-reasoning-names-its-formal-fallacy-and-hints-at-informal-ones.md)
— имя формальной ошибки и подсказки о неформальных.

## 1. Ответ на вопрос

**Найти все логические ошибки в произвольной статье нельзя.** Это не вопрос
объёма работы, причин три, и каждая независима:

1. **Смысл естественного языка неоднозначен.** Одно предложение статьи часто
   читается несколькими способами, и выбирает между ними контекст, которого в
   тексте нет. Переводчик, который выбрал чтение, мог выбрать не то, что имел в
   виду автор. Поэтому «ошибка в статье» всегда значит «ошибка в нашем
   прочтении статьи».
2. **Следование в общем случае неразрешимо.** Для логики первого порядка
   вопрос «следует ли B из A» неразрешим (Чёрч, Тьюринг, 1936). Разрешимы
   узкие фрагменты: силлогистика и одноместные предикаты, пропозициональная
   логика, арифметика Пресбургера. Что не попадает в такой фрагмент, может
   остаться без ответа навсегда.
3. **Большая часть ошибок в статьях — не в форме вывода.** Ошибка в выкладке,
   в данных, в эксперименте, в неявном допущении, в ссылке на чужую теорему,
   которая в этих условиях не применима. Форма рассуждения при этом
   безупречна. Такие ошибки проверкой формы не ловятся в принципе.

**Достижимо другое:** взять каждый шаг рассуждения, который удалось записать
формально, и получить о нём один из трёх ответов — следует (ядро доказало), не
следует (ядро не доказало, и найден пример против), не формализован. Третий
ответ — тоже находка: шаг, который нельзя записать, нельзя и проверить, и
рецензенту полезно знать, где такие шаги.

## 2. Замер на живом тексте

Взяты две статьи русской Википедии (CC BY-SA 4.0), получены через API
`action=query&prop=extracts&explaintext=1` 6 ноября 2026; разделы «См. также»,
«Примечания», «Литература», «Ссылки» и строки заголовков отброшены. В дерево
тексты не положены.

- «Простое число» — математическая статья: 1366 строк, 5714 слов по `wc`.
- «Силлогистика» — статья о том самом фрагменте логики, который судит ядро:
  52 строки, 956 слов по `wc`. Это самый выгодный для нас случай.

Каждый текст отдан плану `Check` целиком:

```
bootstrap/flang io flang/experimental/argument-check.fscript --plan Check --max-steps 1000000000000 -- <текст>
```

| | «Простое число» | «Силлогистика» |
| --- | ---: | ---: |
| предложений (деление по точке) | 276 | 70 |
| все слова получили чтение морфологии | 101 | 28 |
| … и у всех чтение без недостачи | 4 | 7 |
| прегруппа свела к `s` | 0 | 0 |
| формализовано как суждение | 0 | 0 |
| предложений с выводом | 10 | 4 |
| вывод следует / не следует / ядро не решило | 0 / 0 / 0 | 0 / 0 / 0 |
| вывод не формализован | 10 | 4 |
| слов (деление по пробелам и знакам) | 5536 | 1005 |
| … с чтением морфологии | 3943 | 781 |
| … с чтением без недостачи | 1521 | 335 |
| время прогона | 12 мин 10 с | 3 мин 0 с |

Что стоит за числами:

- **Деление на предложения.** Деление по точке режет сокращения: в
  «Силлогистике» 70 «предложений», из них «-греч», «Бэконом, Р», «С» —
  обрезки. В «Простом числе» наоборот: 201 строка из 1366 несёт формулу
  `{\displaystyle …}` без точки, и формулы склеиваются с соседним
  предложением, отсюда 276 «предложений».
- **Морфология читает почти всё — и почти всё не так.** Модуль ADR-0060 знает
  четыре класса словаря силлогизмов (понятие, свойство, имя, квантор) и любую
  форму относит к одному из них. Предлог «с» он читает краткой формой
  прилагательного «с, сы, са, со», глагол «изучают» — понятием или свойством
  «изучают, изучаюты». В «Силлогистике» чтение получили 781 слово из 1005,
  чтение без недостачи — 335, но правильным разбором из них можно считать
  только существительные и прилагательные. Столбец морфологии — мера покрытия
  словаря, а не мера понимания текста.
- **Прегруппа ADR-0109 не свела ни одного предложения.** Её словарь — 106
  словоформ учебного примера; на статье почти каждое предложение кончается
  «неизвестным словом».
- **Формализовано — ноль в обеих статьях.** Переводчик ждёт суждение
  «подлежащее — сказуемое» из объявленных форм, а в статье предложение длиннее,
  с глаголами, предлогами, придаточными и формулами. Первая причина отказа в
  «Простом числе»: слово, которого нет в словаре, — 261 предложение из 266 без
  вывода; «не подходит ни под один образец» — 3; строка словаря, которую
  морфология вывела из формулы («Свойство: 1;7;-1;-7, …»), — 2. В
  «Силлогистике»: слово не в словаре — 65 из 66, образец — 1.
- **Вывод.** Предложений со словом вывода или причиной — 10 и 4; все не
  формализованы, план называет первое непрочитанное слово (в «Простом числе» у
  одного — «Большинство», которое переводчик принял за местоимение).

### Тот же текст с тремя строками словаря

В «Силлогистике» есть пример Рассела: модус DARAPTI неверен, если класс
пуст. В статье он записан так: «Тогда имеем по модусу DARAPTI третьей фигуры:
Все золотые горы — золотые. Все золотые горы — горы. Следовательно, некоторые
горы золотые.» Планом на статье — «не формализовано». Если отдать те же три
предложения с тремя строками словаря (файл `flang/proof/probes/argument-check/programs/empty-class.txt`:
`Понятие: гора, горы; она.`,
`Понятие: золотая гора, золотые горы; она.`,
`Свойство: золотой, золотые; она золотая; оно золотое.`), ответ:

```
[6] Следовательно, некоторые горы золотые
    … → вывод не следует: не следует — это частный вывод из общих посылок: обе посылки
    общие, а вывод частный: общие суждения о «золотая гора» верны и тогда, когда ни одного
    такого предмета нет, а «некоторые …» утверждает, что «гора» есть; …; пример против (нашёл переводчик, проверяется подстановкой): «некий»: гора — нет,
    золотая гора — нет, золотой — нет
```

Пример против — ровно мысль Рассела: золотых гор нет, обе посылки верны
пусто, а «некоторые горы золотые» ложно. На этом примере найдена неточность
разбора формы (ADR-0167): объяснение называло пустым класс подлежащего
вывода («гора»), а пуст класс подлежащего посылок («золотая гора»). Вердикт и
пример против были верны; объяснение исправлено в этой же ветке и теперь
называет подлежащие общих посылок.

Вывод замера: **на произвольной статье сегодня проверяется ноль шагов**;
на тексте, написанном подконтрольным языком со словарём, — каждый шаг,
записанный одной из шести форм суждения силлогистики.

## 3. Решение: пять ступеней

### (а) Подконтрольный язык

Подмножество русского, где у каждого принятого предложения ровно один смысл,
как Attempto Controlled English (Fuchs, Kaljurand, Kuhn 2008): закрытый
набор форм предложения, словарь терминов, объявленный в начале текста,
однозначные правила для местоимений и кванторов. Предложение вне подмножества
не угадывается, а отвергается с причиной. Сегодня это подмножество —
шесть суждений силлогистики со словарём `Понятие:`/`Свойство:`/`Имя:`;
растёт оно отношениями (`делится на`, `больше`), числами, «если … то»,
определениями «X называется Y, если …».

Морфология и прегруппа нужны именно здесь: морфология даёт формы слова,
прегруппа — проверку, что предложение собрано из форм правильно и как связаны
его части. Теория категорий остаётся там, где она работает: прегруппа —
компактная замкнутая категория, и разбор предложения в ней — стрелка, по
которой функтор переносит предложение в формулу (Coecke, Sadrzadeh, Clark 2010).
Для подконтрольного языка такой функтор пишется в формулы ядра, а не в
векторы. Распознавать «теоремы и ошибки» в свободном тексте категорная
семантика не умеет: она переносит смысл разобранного предложения, но не
выбирает между прочтениями неоднозначного.

### (б) Строение рассуждения

Из текста выделяются утверждения, посылки и шаги «следовательно». Сегодня шаг —
предложение со словом вывода или причиной после главного («так как»), а
посылки — до трёх формализованных предложений перед ним. Дальше нужны
ссылки на ранее доказанное («по лемме 2»), определения и обозначения,
действующие до конца раздела, и посылки через абзац.

### (в) Проверка каждого шага ядром

Каждый шаг становится программой flang (`утверждение` и `следует`), её судит
`check --proof --strict`. Ответов три:

- **следует** — ядро приняло доказательство;
- **не следует** — ядро не приняло шаг, и переводчик нашёл пример против:
  набор значений «да/нет», на котором посылки верны, а вывод ложен. Пример
  ядром не проверен, но проверяется подстановкой руками, и печатается всегда;
- **не формализован** — шаг не записан; это сигнал рецензенту, а не молчание.

Если ядро не приняло, а примера против нет, ответ — «ядро не решило», и
«не следует» он не называется.

### (г) Формулы

Формулы статьи (`p = 2k + 1`, `∀n ∈ ℕ`) входят через переводчик нотации
ADR-0106 и становятся утверждениями ядра так же, как предложения. Без этой
ступени математическая статья остаётся непроверенной почти целиком: её шаги
стоят в формулах, а не в словах.

### (д) Отчёт

На каждое предложение — место в тексте (номер, а дальше и строка с
символом), что с ним сделано и почему. Итог по тексту — числа каждого ответа.

## 4. Граница доверия

- **Переводчик текста в утверждения не доверен.** Он может прочесть
  предложение не так, как его понял автор. Вердикт говорит о напечатанной
  программе, а не об исходной мысли автора.
- **Доказано только то, что доказало ядро.** «Следует» — терм, принятый ядром.
  «Не следует» — отказ ядра вместе с примером против, который нашёл
  переводчик; ядро пример не проверяет, проверяет подстановка.
- **Имя ошибки и подсказки** (ADR-0167) — разбор формы, а не вердикт.
- **Истинность посылок не проверяется.** «Следует» значит «следует из
  написанного», а не «верно».

## 5. Первая ступень сделана

`flang/experimental/argument-check.fscript`, план `Check`: текст файлом →
строка на каждое предложение (морфология, прегруппа, формализовано ли,
вердикт вывода) и итог. Устройство — `docs/argument-check.md`. Новых
переводчиков план не вводит: он связывает уже существующие — морфологию
(ADR-0060), прегруппу (ADR-0109), переводчик предложений и разбор ошибок
(ADR-0148, ADR-0167) — и зовёт ядро на каждый вывод отдельно. На тексте
`flang/proof/probes/argument-check/programs/sample.txt` (подконтрольный язык,
13 предложений): формализовано 12, выводов 4 — следует 1, не следует 3
(обращение следствия, учетверение термина, частный вывод из общих
посылок), у каждого «не следует» есть пример против.

## 6. Что нужно для следующей ступени

1. **Словарь морфологии.** Правила по окончанию не знают глаголов, предлогов,
   падежей и чередований. Нужен словарный разбор (OpenCorpora, около 400 тыс.
   лемм, CC BY-SA) как недоверенный источник форм; морфология flang остаётся
   проверкой согласования.
2. **Деление на предложения** с сокращениями и формулами.
3. **Грамматика подконтрольного языка** на прегруппе с типами из словаря, а
   не из 106 учебных словоформ, и функтор «разбор → утверждение ядра».
4. **Отношения и числа** в переводчике предложений: «делится на», «больше»,
   «чётное», и вход формул через ADR-0106.
5. **Подлог на каждую ступень** в наборе проб плана. Сегодня набор
   `flang/proof/probes/argument-check` сверяет три текста, и один из них —
   неверный вывод, который план не вправе назвать «следует».

## 7. Отвергнутые пути

- **Обещать проверку произвольной статьи.** Пункт 1 показывает, почему это
  неверно; замер в пункте 2 — что сегодня это ноль шагов.
- **Большая языковая модель как переводчик в доверенной базе.** Модель может
  быть недоверенным переводчиком, как любой другой: её выход судит ядро. Но
  доказанным её прочтение не становится, и граница пункта 4 остаётся той же.
- **Прегруппа как распознаватель ошибок.** Прегруппа проверяет строение
  предложения, а не истинность и не следование; ошибка вывода видна только
  после перевода в утверждения.
