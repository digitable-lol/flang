# ADR-0243. `flang check` без ключей называет число недоказанного, а ложное считает ошибкой

**Состояние:** предложено. Принимает владелец.
**Дата:** 16 ноября 2026.
**Основание:** issue 488, пункт 3, и три независимых разбора выпуска 0.7.40: обычный
`flang check` отвечал «проверено … замечаний нет» и кодом 0 на программе, чьё постусловие не
доказано или ложно, а `flang run` той же программе отказывал кодом 3.
**Рядом:** [ADR-0010](0010-compatibility-promise-for-0-x.md), пункт 2 — смысл кодов возврата;
[ADR-0045](0045-run-and-io-print-the-verdict-and-refuse-an-unproved-program.md) — вердикт запуска;
[ADR-0115](0115-the-exit-code-of-a-proof-check-names-what-was-proved.md) — код `check --proof`.
**Компилятор тронут:** `flang/self/bootstrap/compiler.flang`, `flang/self/proof.flang`,
`flang/self/proofterm.flang`, `flang/src/emit/c/flang_repl.c`. До программы `flang` решение
доходит пересборкой компилятора.

---

## 1. Задача

Решения, по которому `flang check` молчит о недоказанном намеренно, в записи нет. Молчание
сложилось само: `check` зовёт ядро доказательств, но печатает только ошибки, а «не доказано»
ошибкой не считалось. В итоге у одной программы было три ответа: `check` — код 0 и «замечаний
нет», `check --proof` — код 3, `run` — отказ с кодом 3. Первый ответ читается как «всё
хорошо» и расходится с ADR-0010: код 0 обещан случаю «сделано, сказать нечего».

## 2. Решение

1. Последняя строка `flang check` всегда называет три числа: доказано, проверено только на
   тестах, не доказано — и общее число постусловий и утверждений файла. Слова «замечаний нет»
   печатаются только при нуле недоказанных.
2. Недоказанное без контрпримера — предупреждение. Код остаётся 0, печатается строка
   «не доказано: N — подробности: flang check файл --proof». С ключом `--strict` (без
   `--proof`) тот же случай отвечает кодом 3: что-то не доказано или проверено только на
   тестах, а ложного нет. `--strict` вместе с `--fast` отвергается кодом 2: быстрая проверка
   ядро не спрашивает.
3. Ложное — ошибка, код 1. Ложным считается утверждение или постусловие, для которого найден
   контрпример, и замкнутое выражение (без переменных), вычисленное в «нет». Сообщение называет
   вычисленное значение.
4. Отчёт `flang check --proof` по умолчанию короткий: строка на постусловие или утверждение,
   итог, ответ независимой проверки. Прежний подробный вид печатается с ключом `--explain`.
5. Отказ доказательства без `--explain` печатается без перечня правил, которые пробовало ядро.
6. Совпадение имени с файлом каталога, который программа не ввозит, печатается только с
   `--explain`. Ввоз двух модулей с одним именем остаётся ошибкой.

7. Последняя строка короткого отчёта всегда называет, сколько доказанного повторила независимая
   проверка. С ключом `--independent` код 0 даётся, только если она повторила всё доказанное,
   иначе код 3. Файл с ввозом модулей независимая проверка пока не проверяет; отчёт называет
   эту причину.
8. `--strict` печатает прежний подробный отчёт: его текст читают сценарии сборки.

## 3. Что выбрано и что нет

Код 0 для недоказанного выбран, чтобы `check` оставался проверкой «программа разбирается,
сходится по типам и завершается» и не ломал сценарии, где постусловия дописывают постепенно.
Довод против: ADR-0010 даёт для «сделано, но проверено не всё» код 3, и `check --proof` с `run`
отвечают именно им.

Решено (22 ноября 2026): оба ответа нужны, и их разводит ключ. Обычный `check` на «не доказано,
ложного нет» отвечает 0, `check --strict` — 3. Сценарий, которому нужен код 3, добавляет ключ;
сценарии, которые ждут 0, не меняются. Прежде `--strict` без `--proof` отвергался кодом 2.

## 4. Что ломается

- Последняя строка `flang check` другая: сценарий, который сличает её целиком, надо поправить.
  Поиск слов «замечаний нет» работает как прежде на программах без недоказанного.
- Программа с ложным замкнутым утверждением или с ложным постусловием у функции без параметров
  получает код 1 вместо 0.
- Текст `flang check --proof` без ключей другой. Сценарий, который читает прежний текст, зовёт
  команду с `--explain` либо читает `--json`: поля JSON и коды возврата не менялись.
- Строки «замечание: … в соседнем модуле» без `--explain` не печатаются.

## 5. Как проверить

- `flang/proof/probes/check-verdict/` — программа на каждый случай. `expected.tsv` — ответы
  программы `flang` после пересборки компилятора:
  `flang io flang/proof/probes/check-verdict/run.fscript --plan Binary`.
- До пересборки то же проверяется исполнением исходников компилятора:
  `run-from-source.flang`, функция «Пробы исходником».
- После пересборки: `flang check` на `false-closed-statement.flang` — код 1 и «ложно: вычислено
  2, ожидалось 3»; на `unproved-postcondition.flang` — код 0 и «не доказано: 2»; на
  `proved-postcondition.flang` — «замечаний нет». `flang check --strict` на
  `unproved-postcondition.flang` и `tested-postcondition.flang` — код 3, на
  `proved-postcondition.flang` — код 0.
