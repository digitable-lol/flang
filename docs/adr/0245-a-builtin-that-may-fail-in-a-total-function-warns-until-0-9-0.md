# ADR-0245. Встроенная операция, которая может отказать, в тотальной функции — до 0.9.0 предупреждение

**Состояние:** предложено. Решение куратора о переходе; владелец может переиграть.
**Дата:** 18 ноября 2026.
**Основание:** issue #556, #600: `flang check` принимал тотальную функцию, чьё тело зовёт
встроенную операцию за её условием («подстрока» за краем строки, «голова» пустого списка,
частное слов на 0), а запуск отвечал FLANG_BUILTIN_ARGS или FLANG_OVERFLOW.
**Компилятор тронут:** `flang/self/types.flang`, `flang/src/emit/c/flang_repl.c`. Решение доезжает
до двоичного с печатью семени.

---

## 1. Решение

1. Проверка типов судит каждое место встроенной операции, которая может отказать при работе, в
   теле тотальной функции. Место снято, если условие выводится из типов, из «требует» или из
   проверки в ветви. Неснятое место даёт диагностику FLANG_NOT_TOTAL: названы функция, операция
   и причина, текст кончается словами «пока это предупреждение, станет ошибкой в 0.9.0».
2. В 0.8.0 это предупреждение. «Проверить типы» отдаёт такие места полем «предупреждения»,
   отдельно от «диагностики»; `flang check` печатает их в stderr, код возврата они не меняют.
   `flang run` и планы их не печатают.
3. С `flang check --proof --strict` эти места — ошибки наравне с прочими.
4. В 0.9.0 предупреждение станет ошибкой. Это отдельная работа: сначала из дерева вычищаются
   места в `flang/self` (246 по скану исходником, ещё 672 прогона без итога) и около 1155 в
   `scripts/`, `.githooks/`, `docs/site/`, `flang/scripts/`. Библиотека и примеры вычищены вместе
   с этим решением.
5. Дыры типов, найденные заодно, остаются ошибками сразу: вес из ветви-числа (#491) — FLANG_TYPE.

## 2. Почему не ошибка сразу

Скан исходником проверки типов насчитал больше 1400 неснятых мест в самом дереве. Ошибка сразу
означала бы, что пересобранный компилятор отвергает собственный исходник и сторожей CI.

## 3. Что ломает

Ничего в 0.8.0: код возврата `check` прежний. Под `--proof --strict` программа с неснятым местом
получает код 1.

## 4. Как проверить

Пробы `flang/proof/probes/typing-holes/programs/total-*.flang`, по функции на файл. После печати:
`check` — код 0 и предупреждение FLANG_NOT_TOTAL в stderr; `check --proof --strict` — код 1 с
FLANG_NOT_TOTAL. Контрольные пробы с проверкой в ветви и с «требует» — без предупреждений.
