# ADR-0246. Сверщик на C опровергает подделку контрпримером и отличает ноль от единицы

**Состояние:** предложено.
**Дата:** 18 ноября 2026.
**Основание:** долг проб `checker:check` (две записи с лживой ветвью) и запись «ноль равен
единице» по правилу «кольцо точного целого», которую приняли оба сверщика
([issue #607](https://github.com/digitable-lol/flang/issues/607)).
**Компилятор тронут:** нет. Тронут `flang/proof/checker/checker.c`.

---

## 1. Решение

Потолок строк кода сверщика на C (`checker-code-lines` в `flang/proof/ratchets.txt`,
ADR-0097) поднимается с 13304 до 13357 (+53). Число снимает сторож `tables-guard.fscript`
(С-6). Рост — две правки, каждая закрывает подделку.

1. **Кольцо: ноль и единица — разные многочлены (+4).** Стороны цели сравнивались печатью
   многочленов. Пустой многочлен (ноль) и многочлен из одного пустого одночлена (единица)
   печатались одинаково — пустой строкой. Подделанная запись «ноль равен единице» по
   правилу «кольцо точного целого» получала код 0 и у сверщика на C, и у сверщика на Lean;
   то же под остатком: остаток от нуля и остаток от единицы были одним атомом. Теперь
   печать пишет `0` и `1`, у обоих сверщиков (`кольцо_сумма` в C, `«печатьМногочлена»` и
   сравнение многомножеств в `Ring.lean`).
2. **Контрпример по строкам, признакам и вариантам (+49).** Поиск контрпримера к месту,
   записанному доказанным, перебирал только доводы типа-отрезка. Две записи с лживой
   ветвью («в хвосте столько же знаков», «у пустой опции значения нет») он не опровергал:
   они получали код 3 и числили ложное место доказанным. Теперь перебор берёт ещё строки
   (`""`, `"а"`, `"аб"`), признак и варианты без полей у суммы этого файла, не больше 256
   наборов; поиск зовётся и под узлом с посылками, который не проигран; на время поиска
   строка разбирается на голову и хвост. Обе записи получают код 1 с названным
   контрпримером; ещё семь подделок набора перешли так же с кода 3 на код 1.

## 2. Чего это не делает

Дыру 2718 («ветвь на месте, а цель ядру не по зубам») правка не закрывает: утверждение там
верно, контрпримера нет, а отвергнуть запись можно, только повторив в сверщике правила
сведения ядра. Проба остаётся в долге `checker:check`.

Сверщик на Lean контрпример не ищет: на пяти записях C отвечает 1, Lean — 3. Расхождения
названы в `flang/proof/tables/second-checker-disagreements.tsv`.
