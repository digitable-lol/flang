# ADR-0247. Статья судится по разметке, а ядро судит шаг после подстановки предметов

**Состояние:** предложено, исполнено: `flang/experimental/argue.fscript` с модулями
`flang/experimental/argue/`, набор проб `flang/proof/probes/argue/`, страница
`docs/site/argue.ru.md`. Принимает владелец.
**Дата:** 17 ноября 2026.
**Основание:** цель владельца — загрузить произвольный текст научной статьи на русском и
найти в нём логические дыры. Исследование 16 ноября 2026 на выпуске 0.7.40: план `Check`
из [ADR-0204](0204-an-article-is-checked-step-by-step-and-only-the-kernel-proves.md) читает
шесть видов суждений со словарём; на реферате и на настоящей аннотации формализовано 0 из 20
предложений.
**Рядом:** [ADR-0204](0204-an-article-is-checked-step-by-step-and-only-the-kernel-proves.md) —
подконтрольный русский и граница «доказывает только ядро»;
[ADR-0106](0106-a-formula-enters-and-leaves-through-an-untrusted-notation-translator.md) —
формула входит через недоверенный переводчик.
**Компилятор не тронут:** правок в `flang/self/**` и `bootstrap/**` нет.

---

## 1. Задача

Грамматика подконтрольного языка не дотягивается до научной прозы и не дотянется: в ней
придаточные, номинализации, ссылки, термины без словаря. Нужен путь, на котором flang не
читает прозу вовсе, а всё, что он утверждает, по-прежнему утверждает ядро.

## 2. Решение

1. **Логическую форму даёт внешняя разметка.** Рядом с текстом лежит файл `статья.claims`:
   словарь понятий, суждения с номером, формой и дословной цитатой, шаги «вывод [N] из [M]»,
   род шага, строки «термин» и «определение». Разметку пишет человек или языковая модель по
   инструкции `docs/examples/argue/claims-prompt.md`.
2. **Цитата сверяется с текстом.** Цитата, которой в тексте нет дословно (с точностью до
   пробелов и переносов), отклоняет разметку с номером её строки. Это единственная связь
   разметки с текстом, которую flang проверяет; верность формы смыслу он не проверяет.
3. **Квантор раскрывается подстановкой.** Форма шага — кванторы одного вида в начале
   (`все x, y:` либо `есть x:`) над формулой с `не`, `и`, `или`, `если …, то …`. Предметы
   шага: названные имена, по одному предмету на каждую переменную посылки с `есть`, по одному
   произвольному предмету на каждую переменную вывода со `все`. Посылка со `все` ставится на
   каждый набор предметов, вывод с `есть` — дизъюнкцией по всем наборам. Для этого класса форм
   множество предметов конечно, и подстановка полна: формула без кванторов выполнима ровно
   тогда, когда у исходных суждений есть модель.
4. **Ядро получает формулу без кванторов.** План перебором находит, следует ли вывод, и
   просит ядро подтвердить найденное одним из трёх способов (раздел 3). Вердикт в отчёте
   стоит только тогда, когда ядро ответило «ДОКАЗАНО».
5. **Остальные находки** — круг в графе шагов, одно слово с двумя понятиями, шаг с пометкой
   рода, вывод без посылок, покрытие текста цитатами — считает план; ядро в них не участвует,
   и отчёт не пишет при них «доказано ядром».

## 3. Граница ядра, снятая запусками

Запуски 16–17 ноября 2026, `flang check --proof --strict`, выпуск 0.7.40.

| Что дано ядру | Что отвечает ядро |
| --- | --- |
| `утверждение` над `признак`-переменными, формула-импликация, до 4 переменных | «доказано», правило «разбор случаев по внутреннему условию цели»: 75 случайных тавтологий из 75 |
| то же, 5 и больше переменных | «объявлено, не доказано»: предел ветвления ядра — 4 |
| то же с ограничением `таких что` вместо импликации | «объявлено, не доказано» |
| ложная формула, до 3 переменных | `FLANG_PROPERTY`: «опровергнуто на входе …» |
| ложная формула, 4 и больше переменных | «объявлено, не доказано», примера нет |
| замкнутая формула из `да` и `нет` | «доказано», и независимая проверка её воспроизводит |
| переменные типа-суммы «Ответ» и функция «Верно», 2–3 свободные переменные | доказано 18 из 25 и 9 из 25 случайных тавтологий |
| `теорема` с `индукция по` переменной типа «Ответ», случаи закрыты `по свойству` | принято; цепочка из 6 высказываний доказана за 4 с, из 7 — за 11 с, из 8 — за 40 с |
| лемма над `признак`-переменными с закреплёнными вызовами «Верно» от варианта, до 4 свободных | «доказано»: 80 случайных тавтологий из 80 |
| квантор над объявленным объектом внутри формулы | не снято запуском; по справочнику языка кванторы формул ходят по спискам и числам |

Отсюда три способа:

- **до 4 высказываний** — одно `утверждение` над `признак`-переменными;
- **5–7 высказываний** — дерево разбора случаев: первые высказывания разбираются теоремой с
  `индукция по`, лист из четырёх закрывается леммой над `признак`-переменными;
- **пример против** — замкнутая формула «посылки верны и вывод ложен» на найденных значениях.

Шаг, в котором после подстановки больше семи высказываний, ядру на доказательство не
отдаётся: отчёт пишет «ядро не решило». Пример против ищется до десяти высказываний.
Перед отправкой из посылок убираются те, что не связаны с выводом ни одним общим
высказыванием: лишние посылки ядро не отбрасывает само.

## 4. Что это ломает

Ничего: план `Check` остаётся. Он получил проверку посылок на совместность и поиск
противоречий через те же модули.

## 5. Чего решение не даёт

- Смешанные кванторы («у каждого есть свой») не судятся: разметка с ними отклоняется.
- Равенства, чисел и арифметики в формах нет.
- Противоречие ищется между парами суждений и среди посылок одного шага, не среди троек.
- Независимая проверка (`checker`) воспроизводит замкнутую формулу примера против; шаги,
  доказанные разбором случаев по условию цели, она не воспроизводит — они стоят на ядре.
- Настоящей подкоманды `flang argue` нет: команда — ярлык `run-script`. Подкоманде нужна
  правка `flang/self/` и пересборка компилятора.

## 6. Как проверить

```
bootstrap/flang run-script argue:probe
bootstrap/flang run-script argument-check:probe
```

Первая запускает двенадцать текстов с разметкой: учебный текст, реферат с четырьмя
заложенными ошибками, подложную цитату, двухместное отношение, условные суждения, шаг из
шести и из девяти высказываний, смешанные кванторы, противоречивые посылки, существование,
необъявленное понятие, круг из трёх шагов, цитату через перенос строки.
