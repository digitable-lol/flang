# ADR-0248. Набор пользовательских историй судится по величинам: общий ответ или опровержение

**Состояние:** предложено, исполнено: `flang/experimental/story-set.flang`,
`flang/experimental/story-set-check.fscript`, описание — `docs/story-set-check.md`.
Принимает владелец.
**Дата:** 19 ноября 2026.
**Основание:** слово владельца — сделать отдельную возможность, как сахар для
силлогизмов, но для формата пользовательской истории: искать в историях дыры, а
когда историй в каталоге много — проверять, что они не противоречат друг другу и
полны.
**Замер:** ветка `a/user-story-set-check` от `gh/dev` `5e65274e6`, двоичный
`bootstrap/flang` 0.7.40. Все числа ниже сняты прогонами 19 ноября 2026.
**Рядом:** [ADR-0050](0050-a-reasoning-is-written-as-declared-words-and-fixed-sentences.md)
— рассуждение пишется объявленными словами и закреплёнными предложениями;
[ADR-0204](0204-an-article-is-checked-step-by-step-and-only-the-kernel-proves.md)
— доказывает только ядро;
[ADR-0192](0192-the-kernel-decides-linear-arithmetic-and-the-record-carries-the-certificate.md)
— линейная арифметика в ядре; задача
[8545](../tasks/8545-a-user-story-is-a-written-form-of-a-requirement.md) — одна
история в девяти образцах.
**Компилятор не тронут:** правок в `flang/self/**` и `bootstrap/**` нет, печать
семени не нужна.

---

## 1. Что было

Одна история читается и судится: `flang/proof/probes/story/` переводит девять
образцов предложений в функцию с `требует`, `обеспечивает` и `пример`, и ядро
доказывает её цель. Задача 8545 прямо называет остаток: «цели, которую ядро
отвергает по сути, а не примером, в наборе нет» и «связи между историями в языке
нет». Две истории, из которых одна хочет скидку не больше 30, а другая — не
меньше 40, проходили обе, каждая сама по себе.

## 2. Решение

Набор историй судится **по величинам**. Для каждой величины берутся все истории
о ней, и ядру задаётся один из двух вопросов.

**Истории совместны — показывается общий ответ.** Условие истории `При X не
меньше N` значит, что она действует при входе от `N` и выше; история без условия
действует везде. Разные `N` режут вход на уровни. На каждом уровне берётся
наименьший потолок и наибольший пол из действующих там историй, и ответ — вход,
зажатый между ними. На каждую историю печатается функция с её условием, её
желанием и её показанным случаем, а тело — этот общий ответ. Ядро доказывает
цель каждой истории; доказанное — и есть свидетельство совместности.

**Истории противоречат — печатается опровержение.** Если на каком-то уровне пол
выше потолка, печатается функция с двумя условиями (`требует` потолок одной
истории, `требует` пол другой) и целью «результат меньше пола». Цель верна,
только если значений, годных обеим, нет; ядро закрывает её линейной арифметикой
([ADR-0192](0192-the-kernel-decides-linear-arithmetic-and-the-record-carries-the-certificate.md)).

Оба приговора выносит ядро. Переводчик считает границы сам, чтобы выбрать, какой
из двух вопросов задать, но строку `[противоречие]` или `[желания совместны]`
план считает подтверждённой, только когда ядро доказало все утверждения
напечатанной программы; иначе прогон кончается `FLANG_STORY_SET_CANNOT_LOOK`.

**Дыры и замечания считает переводчик**, без ядра: значения входа ниже
наименьшего условия, роль или величина без историй, величина, объявленная
по-разному, история без показанного случая или без «зачем»; односторонняя
граница и история, желание которой следует из чужого.

## 3. Чем доказано

```
$ bootstrap/flang check flang/experimental/story-set.flang
модуль «User story sets»: функций 166, из них с доказанным завершением 166; типов 7
… проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет

$ bootstrap/flang io flang/proof/probes/story-set/run.fscript --plan Binary --timeout 900000
story-set: проб 10, разошлось 0                                    код 0 (137 с)
```

**Опровержение точно на границе.** Одна и та же функция с потолком 30:

| пол | ответ ядра |
|---|---|
| 31 | доказано правилом «линейная арифметика» |
| 30 | `FLANG_PROPERTY`: постусловие нарушено на входе скидка = 30 |
| 20 | `FLANG_PROPERTY`: постусловие нарушено на входе скидка = 29 |

**Обратная проверка пробы.** В `programs/clash/discount-floor.txt` пол 40
подменён на 20 — набор покраснел: `story-set: проб 10, разошлось 2`. Подмена
снята.

**Показанный случай против набора ловит ядро.** История «потолок скидки»
показывает «при скидке 3 ответ 3», история «пол скидки» хочет не меньше 5:

```
[ядро отвергло] показанный случай против желаний набора — FLANG_EXAMPLE: пример
«тогда вход 3 ответ 3» функции «потолок скидки: в наборе»: значение не совпало с
ожидаемым: ожидалось 3, получено 5
```

## 4. Что отвергнуто

- **Судить каждую историю ещё и отдельно, тем же прогоном.** Проба это показала:
  история «малый пол комиссии» показывает «при комиссии 9 ответ 10». Одна она
  отвечает 9, а в наборе с историей «комиссия не меньше 10» — 10. Отдельный суд
  называл верный пример ложным. В наборе пример истории проверяется на общем
  ответе; отдельную историю по-прежнему судит `flang/proof/probes/story/`.
- **Опровержение над `число`.** Над числами IEEE-754 линейная арифметика ядра не
  выводит ([ADR-0192](0192-the-kernel-decides-linear-arithmetic-and-the-record-carries-the-certificate.md),
  строка «Лин✗»): три записи той же цели над `число` остались «объявлено, не
  доказано». Опровержение печатается над `неотрицательное`. Границы образцов —
  целые неотрицательные числа, поэтому пустой отрезок над ними пуст и над всеми
  числами.
- **Считать совместность самим переводчиком и ядру не показывать.** Тогда
  приговор стоял бы на слове недоверенной программы.

## 5. Чего решение не даёт

- Желание об одной величине и одной границе. Связи двух величин не читаются.
- Полнота — только по объявленному в наборе. О чём не сказано ни слова, того
  план не видит.
- «Зачем» истории в ядро не доезжает, как и в 8545.
- Слов `набор историй` в самом языке нет: план читает каталог текстов. Блок
  `история` языка (8545, ревизия 16 октября) план не читает.
