# ADR-0254. Сверщик на C проигрывает шаг индукции по списку, переписанный допущением

**Состояние:** предложено.
**Дата:** 22 ноября 2026.
**Основание:** посылка шага индукции по встроенному списку, закрытая правилом «тождество
после переписки допущением», шла в запись без ходов, и оба сверщика отвечали кодом 3 — и
на верное утверждение, и на подделанную запись с ложным. Владелец разрешил рост
рукописного C ради этой дыры.
**Компилятор тронут:** да, `flang/self/proof-record.flang` (запись меняется после пересборки
компилятора). Тронут `flang/proof/checker/checker.c`.

---

## 1. Решение

Потолок строк кода сверщика на C (`checker-code-lines` в `flang/proof/ratchets.txt`,
ADR-0097) поднимается с 13357 до 13387 (+30). Число снимает сторож `tables-guard.fscript`
(С-6). Число примитивов не меняется.

1. **Запись несёт ходы шага.** Когда цель шага после развёртки не закрывается ни общим
   решателем, ни делением по условиям, а допущение о хвосте — равенство и его левая сторона
   стоит в цели, запись пишет `замена по дано 1` и закрывает переписанную цель общим
   решателем (`«Rewrite by the hypothesis»` в `proof-record.flang`). Нового рода хода нет:
   `замена по дано N` в формате уже был, номер версии формата прежний.
2. **Переписка допущением берёт оба слова равенства (+3).** `ход_замены` резал допущение
   только по слову `равно`; допущение со словом `равен` получало отказ. Теперь разрез тот
   же, что у `закрыть тождеством`. Перед перепиской `( пустой список )` и `пустой список`
   в цели и в допущении приводятся к одному виду: довод вызова подстановка одевает в
   скобки, а допущение несёт его голым. Тексты отказов хода прежние и цель в них
   печатается как была; терм допущения в отказе «в цели нет терма» печатается в
   приведённом виде.
3. **Контрпример по спискам (+11).** Поиск контрпримера берёт у утверждения имена его
   кванторов, а не доводы функции, о которой оно говорит; список чисел и список
   натуральных перебирается значениями `пустой список`, `[1]`, `[1, 2]`; на время поиска
   вычислитель считает `приписать Г к Х` при целой ненулевой голове. Поиск зовётся и
   тогда, когда ходы в блоке есть, но хоть одна посылка осталась без них.
4. **Скобки снимаются только вне строк и имён (+16).** Первая редакция пункта 2 снимала
   скобки обычной заменой текста, в том числе внутри строки `"( пустой список )"` и внутри
   имени `«Счёт ( пустой список )»`, и принимала кодом 0 две ложные записи. Теперь
   приведение идёт по тексту слева направо и не заходит в `"…"`, `'…'` и «ёлочки», как
   закон «пустой-в-скобках» модели на Lean (вносится в ADR-0202 отдельно, вместе с моделью).

Допущение индукции по списку по-прежнему берётся только о хвосте образца, а посылки
обязаны покрывать оба варианта: эти проверки в сверщике были.

## 2. Чего это не делает

Посылку шага без ходов сверщик сам не доказывает: верное утверждение со старой записью
остаётся на коде 3. Отказ по контрпримеру получает только ложное утверждение, и только
если ложь видна на трёх перебираемых списках.

Переписка допущением заменяет терм равным ему по сравнению языка. Сравнение списков чисел
считает равными ноль и минус ноль; что переписанная цель не различает их, сверщик не
проверяет — как и ядро в правиле «тождество после переписки допущением».

Сверщик на Lean приводит `( пустой список )` к `пустой список` законом толкования
«пустой список в скобках» (ADR-0202, §2, п. 13) и честную запись `rewrite.record`
принимает кодом 0; контрпример по спискам он не ищет. Строки и имена оба сверщика
обходят одинаково (п. 4), и подделки из `free-statement-induction/brackets/` оба отвергают
кодом 1. Расхождения названы в `flang/proof/tables/second-checker-disagreements.tsv`.

## 3. Пробы

- `flang/proof/checker/tests/families/free-statement-induction/rewrite.record`: шаг
  `замена по дано 1`, `закрыть тождеством` — код 0. Запись снята ядром из исходников
  этой ветки (`flang/self/bootstrap/check-with-source-compiler.flang`). Ходами в ней
  закрыто одно утверждение — «склейка с пустым есть копия». Второе утверждение той же
  программы, «копия есть исходный», ядро этой ветки не доказывает («нет вердикта»); его
  шаг с ходами проверен только на записи, дописанной руками, и в набор проб не входит.
- Три правки этой записи (строки `P` в `flang/proof/checker/tests/probes.tsv`): допущение
  обо всём списке, снятая посылка «пусто», `закрыть истиной` вместо переписки — код 1.
- `brackets/string-literal` и `brackets/name`: ложные утверждения, которые держатся только
  на снятии скобок внутри строки и имени, — код 1 (до пункта 4 — код 0); `brackets/non-empty`,
  скобки вокруг непустого списка, — код 1 и до, и после.
- `corrupt/doubling.{flang,record}`: ложное «удвоение есть исходный» с посылкой шага без
  ходов — до правки код 3, после — код 1 с контрпримером `а = [1]`.
- Пять подделок набора перешли с кода 3 на код 1 тем же контрпримером:
  `goal-split-by-condition/p6-measure-swapped`, три записи `coverage/o9-*` и правка
  `unfold-on-constructor/built-constructor`.
