# Проверка рассуждений в тексте: что делает план и где его граница

`flang/experimental/argument-check.fscript`, план `Check`, берёт русский текст
файлом и отвечает про каждое предложение одной строкой: формализовано ли оно и,
если в нём есть вывод, следует ли вывод из посылок. Решение о плане и о том,
чего он не обещает, — [ADR-0204](adr/0204-an-article-is-checked-step-by-step-and-only-the-kernel-proves.md).

```
bootstrap/flang io flang/experimental/argument-check.fscript --plan Check --max-steps 1000000000000 -- <текст>
```

На образце подконтрольного языка `flang/proof/probes/argument-check/programs/sample.txt`:

```
bootstrap/flang run-script argument-check:demo
```

Путь берётся от корня дерева; путь, начинающийся с `/`, берётся как есть. Отчёт
печатается обычным текстом в стандартный вывод; следом хозяин `io` печатает
свою строку JSON с ходом плана.

## Что печатается

На каждое предложение — номер его места в тексте, само предложение и строка:

```
[13] Значит, Графит — металл
    морфология 3/3 (без недостач 3), прегруппа нет → вывод не следует: не следует — это обращение следствия: …; пример против (нашёл переводчик, проверяется подстановкой): «Графит»: металл — нет, …, проводит ток — да
```

- **морфология A/B (без недостач C)** — из B русских слов у A модуль
  `ru-morphology.flang` нашёл хотя бы одно чтение, у C есть чтение без
  недостачи. Модуль знает четыре класса словаря силлогизмов (понятие, свойство,
  имя, квантор) и любое слово читает как одно из них: предлог «с» он читает
  краткой формой «с, сы, са, со». Поэтому этот столбец — мера покрытия
  словаря, а не правильности разбора.
- **прегруппа s / нет** — свёл ли разбор `flang/ct/russian/parse.flang`
  предложение к типу `s`. Словарь разбора — 106 словоформ.
- **формализовано: посылка** — переводчик предложений прочёл предложение как
  одно из шести суждений силлогистики (все, ни один, некоторые, некоторые не,
  имя есть, имя не есть) со словарём из строк `Понятие:`, `Свойство:`, `Имя:`
  этого текста и того, что морфология вывела из самого предложения.
- **не формализовано: …** — первая причина переводчика. Это тоже ответ: шаг,
  который нельзя записать, нельзя и проверить.
- **вывод следует / не следует / не формализован / ядро не решило** — для
  предложения со словом вывода («следовательно», «значит», «поэтому», «итак»,
  «отсюда», «выходит») или с причиной после главного («так как», «потому что»,
  «поскольку», «ибо»). Посылками берутся до трёх формализованных предложений
  прямо перед ним; предложение, которое не формализовано, цепочку посылок
  обрывает.

Последние строки — итог по тексту и граница доверия.

## Кто что решает

- **Следует** — ядро приняло доказательство программы, которую напечатал
  переводчик (`check --proof --strict`).
- **Не следует** — ядро доказательство не приняло, и переводчик нашёл пример
  против: набор значений «да/нет», на котором посылки верны, а вывод ложен.
  Ядро пример не проверяет; он печатается, и его можно проверить подстановкой.
  Отказ ядра без примера против печатается как «ядро не доказало, а примера
  против нет», а не как «не следует».
- **Название ошибки** («обращение следствия», «учетверение термина») даёт
  разбор формы по правилам силлогистики (ADR-0167); вердикта оно не меняет.

Перевод текста в утверждения не доверен: переводчик может прочесть
предложение не так, как его понял автор. Доказано только то, что доказало ядро
о напечатанной программе.

## Набор проб

`bootstrap/flang run-script argument-check:probe` прогоняет план на трёх
текстах из `flang/proof/probes/argument-check/programs/` и сверяет строку
отчёта из `expected.tsv`: итог подконтрольного образца, объяснение примера
Рассела и неверный вывод «Все кошки — животные. Все собаки — животные.
Следовательно, все собаки — кошки», который план обязан назвать «не следует».

## Чего план не делает

- Делит текст на предложения по точке: сокращения («др.-греч.», «Ф. Бэкон»)
  режут предложение на части.
- Не читает формулы, числа, кванторы над числами, определения, ссылки на
  теоремы, глаголы кроме сказуемого суждения, придаточные кроме причины.
- Не проверяет посылки на истинность и не ищет неявных допущений.
- Не берёт посылки дальше трёх предложений назад и через абзац.
