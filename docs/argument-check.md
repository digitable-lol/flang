# Проверка рассуждений в подконтрольном русском: что делает план и где его граница

План `Check` из `flang/experimental/argument-check.fscript` берёт русский текст
файлом, сам читает его предложения и отвечает, следуют ли выводы из посылок.
Он читает узкий подконтрольный язык: шесть видов суждений силлогистики и их
соединения. Свободную научную прозу он не читает. Для неё есть другой путь —
разметка и команда `flang run-script argue`, страница
[Проверить рассуждение в тексте](site/argue.ru.md).

Возможность экспериментальная. Она запускается только из клона репозитория,
командами `flang run-script`, и в установленный выпуск не входит.

```
flang io flang/experimental/argument-check.fscript --plan Check --max-steps 1000000000000 -- <текст> --out <отчёт>
```

На образце `flang/proof/probes/argument-check/programs/sample.txt`:

```
flang run-script argument-check:demo
```

Путь берётся от корня клона; путь, начинающийся с `/`, берётся как есть. Ключ
`--out` называет файл отчёта. Без ключа отчёт выводится в стандартный вывод,
и следом `flang io` пишет туда же свою строку JSON. При перенаправлении
вывода в файл эта строка ложится поверх отчёта, поэтому в файл отчёт пишут
ключом `--out`.

## Что читается

- Словарь в начале файла: строки `Понятие:`, `Свойство:`, `Имя:`. Строка
  словаря с ошибкой пропускается, отчёт называет её номер в файле, остальной
  текст читается.
- Шесть суждений: «Все S — P», «Ни один S не P», «Некоторые S — P»,
  «Некоторые S не P», «Имя — P», «Имя не P».
- Подлежащее во множественном числе без слова «все»: «Дельфины умны» читается
  как «Все дельфины умны», если слово объявлено в словаре.
- Соединения суждений об именованном предмете: «Если А, то Б», «А, или Б»,
  «А, и Б», «Неверно, что А». Местоимение «он», «она», «оно» во второй части
  заменяется подлежащим первой.
- Слова вывода: «следовательно», «значит», «поэтому», «итак», «отсюда»,
  «выходит», «таким образом», «из этого следует», «тем самым», «отсюда
  следует», «стало быть», «в силу этого». Причина после главного: «так как»,
  «потому что», «поскольку», «ибо».

Множественное число, которого нет в словаре, план не читает: по одной форме
«киты» единственное число и род не определяются однозначно.

## Что стоит в отчёте

Отчёт начинается сводкой:

```
сводка:
  предложений 13, прочитано 12, не прочитано 1
  шагов рассуждения 4, из них проверено ядром 4
  найдено: противоречий 0, неследований 3 (обращение следствия — 1, …), шагов с противоречивыми посылками 0
  не судится: посылка не прочитана 0, вывод не формализован 0, ядро не решило 0
```

Дальше на каждое предложение — номер его места в тексте, само предложение и
строка с ответом:

```
[9] Все сплавы — металлы
    → прочитано: все x: если сплав(x), то металл(x)
[13] Значит, Графит — металл
    → вывод не следует: не следует — это обращение следствия: …
```

- **прочитано: формула** — предложение переведено в логическую форму, она
  показана.
- **не прочитано: причина** — первая причина, по которой предложение не
  переведено.
- **вывод следует (доказано ядром)** — ядро приняло доказательство шага.
- **вывод не следует** — есть случай, когда посылки верны, а вывод ложен. Для
  силлогизма названа ошибка по правилам силлогистики и показан пример против.
- **посылка [N] не прочитана: вывод не судится** — среди посылок вывода есть
  предложение, которое план не прочёл. Такой вывод не оценивается.
- **посылки [N] и [M] противоречат друг другу; вывод из них не засчитан** —
  посылки проверяются на совместность до вывода: из противоречия формально
  следует что угодно.

Посылками вывода берутся до трёх предложений перед ним, после предыдущего
вывода. Непрочитанное предложение из другого абзаца, стоящее перед ними,
посылкой не считается.

Раздел «противоречия» в конце перечисляет пары суждений, которые не могут быть
верны вместе. Пара ищется по всему тексту, а не только среди соседних
предложений.

Последняя строка — граница доверия: перевод текста в логическую форму не
проверен; доказано только то, что доказало ядро.

## Кто что решает

- **Следует** — ядро приняло доказательство программы, которую записал план
  (`flang check --proof --strict`).
- **Не следует** — для силлогизма ядро доказательство не приняло, и переводчик
  нашёл пример против; пример показан в отчёте и проверяется подстановкой. Для шага
  с соединениями план находит пример против сам, а ядро вычисляет на нём
  посылки и вывод.
- **Противоречие** — ядро приняло доказательство, что из двух суждений следует
  ложь.
- **Название ошибки** («обращение следствия», «учетверение термина») даёт
  разбор формы по правилам силлогистики; вердикта оно не меняет.

## Набор проб

`flang run-script argument-check:probe` запускает план на текстах из
`flang/proof/probes/argument-check/programs/` и сверяет строки отчёта с
`expected.tsv`. Среди текстов: непрочитанная посылка, противоречивые посылки,
противоречие между далёкими предложениями, словарь с ошибочной строкой, шесть
новых слов вывода, условные суждения и множественное подлежащее без «все».
Запуск 27 ноября 2026 года ответил «проб 16, разошлось 0» и занял около семи
минут.

## Чего план не делает

- Делит текст на предложения по точке: сокращения («др.-греч.», «Ф. Бэкон»)
  режут предложение на части.
- Не читает формулы, числа, определения, ссылки на теоремы, глаголы кроме
  сказуемого суждения, придаточные кроме причины и условия.
- Внутри «если», «или», «и» читает только суждения об именованном предмете, не
  общие.
- Не проверяет посылки на истинность и не ищет неявных допущений.
- Не берёт посылки дальше трёх предложений назад.
