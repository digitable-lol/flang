# docs/benchmarks — приборы замеров

Здесь лежат программы и сценарии, которыми меряют язык. Числа, которые выдаёт
прибор, в этом каталоге не хранятся: прибор запускают заново на текущем дереве.

| каталог | чем меряет |
|---|---|
| `proof-cost/` | цену доказательства: `count-20.flang` — повторяемый счёт по двадцати функциям из `proof-cost/functions/` (`flang run-script proofs:count-20`), пробы закрытой цели и подделки |
| `speed/` | скорость: та же работа на flang, C, JavaScript и Python (`programs/`), сборка и прогон. На 0.7.34 сборка `assemble.sh` останавливается: она ждёт напечатанный модуль под именем из названия модуля, а печать даёт файлу модуля одно имя для любой программы |
| `verdict-cache/` | кеш вердикта о доказанности; у каталога свой README |
