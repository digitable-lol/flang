# docs/benchmarks — ПРИБОРЫ замеров, а не их материал

Здесь лежит то, чем меряют сегодня. Соседние `docs/benchmark/` и
`docs/benchmark2/` (в единственном числе, с цифрой и без) — другое: это материал
двух датированных заходов замера, снятых в августе 2026 и с тех пор не
трогавшихся. Разбор пары — в [docs/benchmark/README.md](../benchmark/README.md).

| каталог | чем меряет |
|---|---|
| `proof-cost/` | цену доказательства: `count-20.flang` — повторяемый счёт по тем же двадцати функциям (11 содержательных из 20 на 11 сентября 2026), `journal.md`, пробы закрытой цели и подделки |
| `speed/` | скорость: та же работа на flang, C, JavaScript и Python (`programs/`), сборка и прогон |
| `verdict-cache/` | кеш вердикта о доказанности; у каталога свой README |

Правило простое: **прибор — сюда, запись прошедшего замера — в отчёт рядом с
`docs/` и в свой каталог материала.**
