# proof-cost/functions — двадцать функций замера цены доказательства

Материал прибора [`../count-20.flang`](../count-20.flang): двадцать небольших
функций, у каждой — постусловие (`обеспечивает`) и тело. Прибор
перечисляет этот каталог, у каждой функции спрашивает собранный компилятор,
доказано ли постусловие, а затем подменяет тело заглушкой и спрашивает снова.
Постусловие, которое при заглушке отпадает, прибор называет СОДЕРЖАТЕЛЬНЫМ;
доказанное и при заглушке — ОСЛАБЛЕННЫМ.

Запуск из корня дерева:

```sh
bootstrap/flang run-script proofs:count-20
```

Имена файлов — порядковый номер и короткое имя функции (`01-link-key.flang` …
`20-trim-spaces.flang`); прибор берёт их по порядку имён.

Пометка «[примеры файла красные]» значит: у файла как он есть сорвался пример, ведомости
нет, и вердикт взят у того же файла без примеров. Так сейчас у `11-unique.flang` и
`13-even.flang`, и это ошибки самих функций, а не прибора: `равен` в языке отличает 0 от
−0, поэтому «Уникальные» оставляет в `[0, -0, 1]` оба нуля, а «Чётное» от −4 отвечает
«нет» (`-4 остаток от 2` даёт −0). Примеры записаны так, как функция должна отвечать, и
держат эти ошибки на виду; глава [6 курса](../../../course/06-cost.md) разбирает их.
