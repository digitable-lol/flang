# Точка раскрутки: каталог `bootstrap/`

В `bootstrap/` лежит компилятор flang, напечатанный в самодостаточный C99.
Каталог нужен для одного: собрать работающий компилятор, имея только `cc` и
`make`. Как из него замыкается круг «компилятор печатает сам себя» —
[круг раскрутки](guide/bootstrap-circle.ru.md).

## Собрать и поставить

```sh
make -C bootstrap -j4
sudo make -C bootstrap install     # либо PREFIX=$HOME/.local, без sudo

flang --version
flang check путь/к/файлу.flang
flang run путь/к/файлу.flang --function «Имя» --args '{"х":21}'
```

Без `install` двоичный лежит в `bootstrap/flang`. Зависимости — `libm` и
`libpthread`. Имя команды одно на все дороги установки: `brew`, `asdf` и сборка
из исходников кладут файл `flang`.

## Что лежит в каталоге

| файл | что это |
|---|---|
| `compiler_flang.c` | компилятор: все слои на flang после связывания |
| `compiler_flang.h` | его объявления |
| `flang_repl.c` | вход для человека: `check`, `test`, `run`, `emit`, `io`, `lsp`, `repl`, `--help`, `--version` |
| `flang_runtime.c` | рантайм: значения, арена, UTF-8, встроенные формы |
| `flang_runtime.h` | заголовок рантайма и пределы, впечатанные при печати |
| `flang_cli.c` | прогонщик: JSON на входе, JSON на выходе |
| `Makefile` | сборка, `make install`, `make uninstall` |

Все семь файлов порождены и правке руками не подлежат: исходники компилятора —
на flang, в `flang/self/`, связывающий слой — `flang/self/bootstrap/compiler.flang`.
`flang_repl.c`, `flang_runtime.c`, `flang_runtime.h` и `flang_cli.c` — дословные
копии `flang/src/emit/c/*` с приписанной сверху шапкой.

## Обновление

Каталог перепечатывается в том же коммите, что и правка компилятора:

```sh
sh scripts/bootstrap-reprint.sh            # перепечатать
sh scripts/bootstrap-reprint.sh --check    # напечатать заново и сверить байт в байт
sh scripts/bootstrap-reprint.sh --bystro   # сверить только входы печати
```

Печатает двоичный, собранный из этого же каталога. Сверка краснеет на правке
исходника без перепечатки, на правке напечатанного файла руками, на пропавшем и
на лишнем файле. Сколько стоит перепечатка — [цена перепечатки](reprint-cost.md).

## Почему каталог, а не один склеенный файл

Каталог — ровно то, что печатает генератор кода в C. Склейка потребовала бы
своего кода, и сверка проверяла бы склейку, а не печать. Текстовый дифф
напечатанного C не читается: малая правка компилятора сдвигает нумерацию функций
и меток по всему файлу, поэтому каталог помечен в `.gitattributes` как
порождённый, а о расхождении говорит сверка.

Рантайм, прогонщик и вход для человека меняются отдельно от компилятора, а
`make` собирает единицы трансляции по отдельности и параллельно.
