# Куда дальше

Курс кончился. Ниже — что читать, чем перепроверять и куда идти с вопросом.

## Три вещи, которые стоит унести

**Первое.** Завершаемость доказывается массово и почти даром: 19 694 функции
дерева из 24 063 несут доказанное завершение, и 19 109 из них не проверяют при
работе ничего.

**Второе.** Поведение доказывается редко: 407 утверждений из 1 045, и на выборке
из двадцати обычных функций библиотеки ядро берёт **два случая**. Цена этого
измерена и открыта.

**Третье.** «Доказано» не значит «правильно». Функция «Чётное» несёт доказанное
обо всех входах постусловие и отвечает `false` на `−4`.

записано **почему решили так**: что померили, что оказалось ложным, какой путь
отвергли и по какому доводу.

## Как перепроверить каждое число этого курса

Курс держится на правиле «ни одного числа по памяти». Вот команды, которыми
снято всё, что в нём названо. Все прогоняются из клона репозитория языка.

```bash
# все числа страниц одним заходом: функции, тотальность, утверждения, словарь
./ярлык числа

# то же, но не переписывая файл: краснеет на первом разошедшемся числе
./ярлык числа:проверка

# весь набор проверок, включая цели печати
./ярлык тесты

# сайт документации: страницы, ссылки, подстановки, контраст подсветки
node docs/site/build.mjs --check
```

**Три команды, которые в этом списке стояли и которых больше нет.** Их удалили
вместе со второй реализацией языка, написанной на JavaScript:

| было | что с ней |
| --- | --- |
| `node flang/scripts/proof-ledger.mjs` | жива, но зовёт двоичный: сперва `make -C bootstrap` |
| `node docs/benchmark2/tools/measure20.mjs` | удалена вместе с каталогом замера |
| `node --test flang/test/digest.test.mjs` | удалена |

Числа по всему дереву этот курс поэтому берёт из `docs/site/numbers.json` — файла,
который дерево перемеряет само и сверяет отдельной проверкой, — и называет
коммит последнего пересчёта: `252606e8`, 23 августа 2026.

**И честная оговорка, которая пережила все правки.** Проверка чисел не входит в
`npm test`, и расхождение между файлом и деревом может стоять неделями. Так и
вышло с этим курсом: он пролежал четыре выпуска, называя версию `0.5.0`, потому
что пометка «перед заливкой прогоните заново» была адресована человеку, а человек
её не прочёл.

Это лучшая иллюстрация ко всему курсу: **проверка, которую никто не запускает, —
это не проверка.**

Поэтому у каждой главы курса теперь первой строкой после шапки стоит объявление
замера — строка, которую разметка не показывает, а машина читает:

```
<!-- замер: версия 0.6.2 · дерево d363b1e5 · сверено 2026-08-27 -->
```

Пометка, адресованная человеку, лежала четыре выпуска. Эту прочтёт проверка.

## Как читать репозиторий

```
flang/          сам язык
  self/         компилятор flang, написанный на flang, 56 файлов
  src/emit/     куски рантайма целей: уезжают в напечатанное дословно
  stdlib/       42 файла, 34 776 строк
  proof/        дидактические примеры доказательств, 61 файл
  test/         проверки
examples/       191 файл, из них 82 задачи LeetCode и 28 Rosetta Code
bootstrap/      двоичный компилятор на C99, без Node
docs/           документация, замеры, база знаний
  site/         собираемый сайт документации
  zettel/       база знаний, 578 заметок
```

*Счёт файлов снят `ls`/`find` 27 августа 2026. Обратите внимание: `flang/src/`
больше не «вторая реализация, на JavaScript» — её удалили, и в каталоге остались
только готовые куски рантайма для восьми целей печати.*

Полезное правило чтения, которое сэкономит вам день: **шапка файла в этом дереве
— не украшение**. В комментариях перед функцией обычно написано, что пробовали,
что не вышло и почему выбрано это. Начинайте с них.

## Как участвовать

- **`./ярлык тесты` перед любым изменением** — ноль падений. Проверка,
  пропущенная из-за отсутствия тулчейна, не считается пройденной;
- **`CHANGELOG.md` руками не править**: он печатается из тегов и тем коммитов;
- **писать только `.flang`**, JSON — единственная форма обмена;
- **улика до утверждения, числом**: не «не реализовано», а «расходится на 1020
  из 7888»;
- **снять правку и посмотреть, что покраснеет.** Не покраснело — правка ничего
  не держит.

## И одно условие, при котором всё изменится

Заметка базы знаний, которая держит весь проект:

> Революция наступит ровно тогда, когда доказательство станет дешевле тестов.

Сегодня оно дороже в 21 раз по времени и в 4,3 раза по строкам — на обычных
функциях. Там, где ядро берёт цель, оно уже дешевле в восемнадцать раз. Весь
вопрос в том, как часто берёт.

Это измеримо, это меряют, и число открыто. Спасибо, что дочитали.
