# Куда дальше

Курс кончился. Ниже — что читать, чем перепроверять и куда идти с вопросом.

## Три вещи, которые стоит унести

**Первое.** Завершаемость доказывается массово и почти даром: 19 694 функции
дерева из 24 063 несут доказанное завершение, и 19 109 из них не проверяют при
работе ничего.

**Второе.** Поведение доказывается редко: 407 утверждений из 1 045. На выборке
из двадцати обычных функций библиотеки ручной замер дал **два случая из
двадцати**, а `bootstrap/flang run-script proofs:count-20` находит
содержательное доказательство у десяти. Цена этого измерена и открыта.

**Третье.** «Доказано» не значит «правильно». Функция «Чётное» несёт доказанное
обо всех входах постусловие и отвечает `false` на `−4`.

```bash
bootstrap/flang run-script numbers:build
```

## Как перепроверить каждое число этого курса

Курс держится на правиле «ни одного числа по памяти». Вот команды, которыми
снято всё, что в нём названо. Все прогоняются из клона репозитория языка.

```bash
# все числа страниц одним заходом: функции, тотальность, утверждения, словарь
bootstrap/flang run-script numbers:build

# то же, но не переписывая файл: краснеет на первом разошедшемся числе
bootstrap/flang run-script numbers:check

# весь набор проверок, включая цели печати
bootstrap/flang run-script tests

# сайт документации: страницы, ссылки, подстановки, контраст подсветки
node docs/site/build.mjs --check
```

Числа по всему дереву этот курс берёт из `docs/site/numbers.json` — файла,
который дерево перемеряет само и сверяет отдельной проверкой. У файла две
половины: «дешёвая» (файлы, строки, версия выпуска) пересчитывается по
исходникам за секунды, «дорогая» (функции, тотальность, утверждения, словарь) —
прогоном двоичного по всем программам репозитория в несколько часов.

Что доказано о двадцати функциях выборки, считает

```bash
bootstrap/flang run-script proofs:count-20
```

**Проверка, которую никто не запускает, — это не проверка.** Поэтому у каждой
главы курса первой строкой после шапки стоит объявление замера — строка,
которую разметка не показывает, а машина читает:

```
<!-- замер: версия 0.7.24 · дерево 5604556ef · сверено 2026-10-04 -->
```

Отставшее объявление краснит `scripts/guards/stale-pages-guard.fscript`.

## Как читать репозиторий

```
flang/          сам язык
  self/         компилятор flang, написанный на flang, 64 файла
  src/emit/     куски рантайма целей: уезжают в напечатанное дословно
  stdlib/       53 файла, 33 153 строки
  proof/        доказательства и дидактические примеры, 476 файлов .flang
  test/         проверки
docs/examples/  242 файла .flang, из них 82 задачи LeetCode и 28 Rosetta Code
bootstrap/      двоичный компилятор на C99, без Node
docs/           документация и замеры
  site/         собираемый сайт документации
```

*Счёт файлов — `git ls-files`. `flang/src/` — не вторая реализация языка: в
каталоге лежат только готовые куски рантайма для десяти целей печати.*

## Как участвовать

- **`bootstrap/flang run-script tests` перед любым изменением** — ноль падений. Проверка,
  пропущенная из-за отсутствия тулчейна, не считается пройденной;
- **`CHANGELOG.md` руками не править**: он печатается из тегов и тем коммитов;
- **писать только `.flang`**, JSON — единственная форма обмена;
- **улика до утверждения, числом**: не «не реализовано», а «расходится на 1020
  из 7888»;
- **снять правку и посмотреть, что покраснеет.** Не покраснело — правка ничего
  не держит.

## И одно условие, при котором всё изменится

> Революция наступит ровно тогда, когда доказательство станет дешевле тестов.

В ручном замере оно дороже в 21 раз по времени и в 4,3 раза по строкам — на
обычных функциях. Там, где ядро берёт цель, оно уже дешевле в восемнадцать раз. Весь
вопрос в том, как часто берёт.

Это измеримо, это меряют, и число открыто. Спасибо, что дочитали.
