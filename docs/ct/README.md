# docs/ct — контракты категорной поверхности

Три страницы, на которые ссылаются, когда нужна **точная формулировка правила**, а
не объяснение:

| файл | о чём |
|---|---|
| [spec.md](spec.md) | контракт категорной поверхности: какими словами записывается каждое правило и что оно обещает |
| [sets.md](sets.md) | контракт отношений множеств — `вложение` и `пересечение` |
| [zakony.md](zakony.md) | пять объявляемых законов и пять разрешений: что из каждого свойства следует |

Читатель — тот, кто записывает правило и хочет знать его точную форму. Сами файлы
поверхности лежат в [flang/ct](../../flang/ct), проза о них — здесь и в
[docs/flang/ct](../flang/ct).
