# docs/ct — контракты категорной поверхности

Страницы, на которые ссылаются, когда нужна **точная формулировка правила**, а
не объяснение:

| файл | о чём |
|---|---|
| [spec.md](spec.md) | контракт категорной поверхности: какими словами записывается каждое правило и что оно обещает |
| [sets.md](sets.md) | контракт отношений множеств — `вложение` и `пересечение` |
| [laws.md](laws.md) | пять объявляемых законов и пять разрешений: что из каждого свойства следует |
| [limits.md](limits.md) | контракт универсальных конструкций: произведение, копроизведение, расслоённое произведение — конусы из имеющихся слов |

Читатель — тот, кто записывает правило и хочет знать его точную форму. Сами файлы
поверхности лежат в [flang/ct](../../flang/ct), проза о них — здесь и в
[docs/flang/ct](../flang/ct).

Четыре страницы, на которые ссылаются, когда нужна **точная формулировка правила**, а
| [adjunctions.md](adjunctions.md) | контракт сопряжений и леммы Йонеды: единица, коединица, треугольные тождества и представимые функторы без новых слов |
| [monoidal.md](monoidal.md) | моноидальная структура из имеющихся слов, монада как моноид в эндофункторах, стрелки Клейсли |
