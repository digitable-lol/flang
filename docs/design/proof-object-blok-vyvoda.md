## 1. Зачем блок

Место, закрытое ядром «по построению», приезжало в запись двумя строками:

```
  правило «неотрицательность по построению»
  по объявлению да
```

Довода за именем нет ни у одного из шестнадцати имён списка: `сверить_правила`
проверяет ровно то, что имя стоит в списке. Место читается человеком и чекером
одинаково — «ядро сказало», — и идёт на слово ядра.

Блок `вывод` кладёт в запись сам вывод: по строке на применение правила. Тогда
проверять есть что, и проверка эта локальная — сличение формы, подстановка и номер
строки, без всякого знания смыслов.

## 2. Форма

Блок стоит внутри блока утверждения, ниже строк `правило`/`по объявлению`, и устроен
ровно как блок ходов: строки-часовые и порядок, отступ значения не несёт.

```
    вывод цель ⟨результат не меньше 0⟩
    вывод 1 Н3 ⟨первое не меньше 0⟩ строка 4
    вывод 2 Н3 ⟨второе не меньше 0⟩ строка 4
    вывод 3 Н5 ⟨( первое плюс второе ) не меньше 0⟩ из 1 2
    вывод 4 Разв2 ⟨результат не меньше 0⟩ из 3 строка 7
    вывод конец
```

| часть | что значит |
|---|---|
| `вывод цель ⟨Ц⟩` | открывает блок и называет цель |
| `вывод N ИМЯ ⟨Ф⟩ ОСНОВАНИЕ` | шаг: правило `ИМЯ` ведомости заключает формулу `Ф` |
| `вывод конец` | закрывает блок |

`Ф` записывается формулой того же языка, что и цель, а не именем свойства. Довод —
проверяемость: словарю свойств пришлось бы верить, а формулу сличают знак в знак.

`ОСНОВАНИЕ` — одно из четырёх и только их:

| вид | когда |
|---|---|
| `сам` | лист: правилу основания не нужно (литерал, встроенная форма) |
| `строка N` | шаг опирается на строку исходника: объявление довода либо допущение функции |
| `из N` / `из N M` | шаг опирается на прежние шаги того же блока, номерами меньше своего |
| `из N строка M` | шаг опирается и на прежний шаг, и на строку (развёртка тела) |

Строка вида, которого здесь нет, отвергается вслух списком образцов строк записи, а не
пропускается молча.

## 3. Почему это переигрывание, а не доверие

Шесть свойств, и каждое проверено пробой:

1. **Цель блока сверяется с исходником**, а не берётся из записи. Она обязана знак в
   знак совпасть с хвостом постусловия `обеспечивает «имя» Ц`. Без этого блок объявлял
   бы себе цель сам и выводил бы что удобно.
2. **Последний шаг обязан заключать ровно цель.** Оборванный вывод — отказ, а не
   «почти доказано».
3. **Номера шагов считаются**, а не украшают: пропущенный или переставленный шаг виден.
4. **Каждое правило проверяет форму заключения.** Скажем, правило суммы берёт слева
   ровно два слагаемых по знаку «плюс»; вычитание под тем же именем не пройдёт.
5. **Каждое основание проверяется по существу.** Номер строки обязан указывать на
   строку названной функции и на строку нужного вида: объявление довода — для правил,
   читающих тип; допущение `требует «имя» формула` — для правил, читающих окружение;
   тело функции — для развёртки. Ссылка на прежний шаг обязана заключать ровно ту
   формулу, которой правилу не хватает.
6. **Запреты ведомости правилами не являются.** Имя, у которого в ведомости вид
   «запрет», отвергается сразу и с названной причиной: им не выводится ничего.

Сверщик при этом не приобретает ни системы типов, ни поиска: он не ищет обоснований и
не считает значений. Он знает формы и номера строк — ровно то же, что знал раньше.

## 4. Учёт

Место, чей вывод проигран, идёт в «сведений проиграно заново», а не «на слово ядра».
Приём стоит ОТДЕЛЬНОЙ веткой, а не добавочной: два приёма, снявших одно место, дали бы
снятого больше, чем мест, и тождество линейки («мест по тексту записи = долг + снятое +
проверенное по существу») рухнуло бы на честной записи. Замер на пробе семьи: без
отдельной ветки разбор цели снимал те же четыре места вторым счётом — снято 12 при
восьми местах.

Число снятого печатается теми же словами «снято со слова ядра мест», какими его
печатают соседние приёмы: линейка складывает снятое по всем приёмам, и слагаемое без
общей метки тихо выпало бы из тождества.

Знаменатель блок не двигает — и это СНЯТО ПРОГОНОМ, а не выведено из устройства. Один и
тот же набор прогнан линейкой дважды: с блоками вывода и с теми же записями, у которых
строки `вывод` вычеркнуты.

| | знаменатель | числитель | не проверено |
|---|---:|---:|---:|
| записи с блоком вывода | 10 | 8 | 0 |
| те же записи без блока | 10 | 0 | 8 |

Линейка `flang/proof/доля-корпуса.sh` числитель считает пятью слагаемыми, и переигранный
вывод — пятое: он берётся по якорю своей строки сводки и вычитается из общей суммы
«снято со слова ядра мест», чтобы место не считалось дважды. На записях без блока вывода
слагаемое это ноль, и доля корпуса от правки не двинулась ни на место — 517 из 651 до и
после.

## 5. Что написано и чего нет

Написаны правила семейств Н (неотрицательность), П (потолок), Т (цель есть допущение) и
развёртка плоского определения:

| правило | что берёт |
|---|---|
| Н1 | литерал не меньше нуля |
| Н2 | допущение «Т не меньше 0» знак в знак |
| Н3 | имя, объявленное типом с дном |
| Н4 | встроенные формы «длина Т» и «код символа Т» |
| Н5 | сумма ровно двух неотрицательных |
| П1 | литерал не выше названного потолка |
| П2 | допущение о границе, не выше названного потолка |
| П3 | имя типа точной сетки при потолке не ниже 9007199254740991 |
| П5 | разность: уменьшаемое под потолком, вычитаемое неотрицательно |
| Т1 | цель слово в слово стоит допущением функции |
| Разв2 | развёртка плоского тела: цель о «результат» переходит в цель о теле |
| Н✗ П✗ О✗ О✗✗ О✗✗✗ С✗ С✗✗ С✗3 С✗4 СС✗ Ч✗ Ч✗✗ | запреты: отказ по имени |

Семейства О (порядок), Д (дно), С (строгий порядок), СС (соседние), В (вхождение) и
Ч (начало строки) не написаны. Имя оттуда даёт НАЗВАННЫЙ отказ, а не тихий пропуск, —
значит запись с таким блоком будет отвергнута, а не принята на веру.

По замеру открытых мест (см. §6) на написанные семейства приходится 25 мест из 51, на
ненаписанные — 26.

### 8.2 Печать закрывает и два места, которые линейка держала за калькулятором

место, которое чекер закрывал вычислением и в числитель не шло, с блоком вывода уходит
в числитель. Таких мест два: `corpus-natural` «сумма пары неотрицательна» (Н3 + Н3 +
Н5 + Разв2) и `corpus-natural-ceiling` «разность пары не выходит за точный потолок»
(П3 + Н3 + П5 + Разв2). Разряд «снято калькулятором» падает с 8 до 6, и числитель на
те же два места растёт — счёт сходится, места не «перестали считать».

Остальные шесть мест этого разряда печатью не берутся: два — верны впустую от
невыполнимой посылки (`abilities` У23, `poddelka-protivorechie`), три — цели семейства

### 8.4 Согласие печати и приёма проверено ДО перепечатки, побайтно

Печать снята толкователем с правленого исходника через обёртку `«Строки утверждения
зонда»`, ровно эти байты вставлены в записи набора и прогнаны чекером: код записи не
изменился, строка сводки «Выводов факта о типе проиграно заново» выросла с 0 до 6,
«НА СЛОВО ЯДРА» у `abilities` упало с 20 до 16.

Снос печати: девять утверждений, которых правка касаться не должна (`abilities` У1,
У3, У25, У27; `boundaries` В4; `types` Т1, Т5; `binder-wall-map` «свёртка: счёт
неотрицателен»; `equality` Р5), напечатаны базовой и правленой печатью через один и тот
же толкователь — байт в байт, расхождений 0. Обратный контроль: на четырёх чинимых
местах базовая печать не даёт ни одной строки `вывод`, правленая даёт.
