# Блок «вывод» в записи доказательства: форма и переигрывание

**Основание:** [ADR-0022](../adr/0022-a-type-fact-travels-as-a-derivation.md) §3.10,
ведомость `flang/proof/ПРАВИЛА-ВЫВОДА.tsv`, задача
[6131](../../tasks/6131-sverschik-proigryvaet-blok-vyvoda.md).
**Состояние:** приём в `flang/proof/чекер/сверщик.c` написан и проверен на рукотворных
записях; печати в ядре нет (задача 6132), второй чекер `flang/proof/сверщик.flang` не
тронут.
**Проверяется:** `sh flang/proof/чекер/пробы/прогон.sh` (семья «вывод»),
`sh flang/proof/доля-корпуса.sh --набор корпус --проигрыванием`.

## 1. Зачем блок

Место, закрытое ядром «по построению», приезжало в запись двумя строками:

```
  правило «неотрицательность по построению»
  по объявлению да
```

Довода за именем нет ни у одного из шестнадцати имён списка: `сверить_правила`
проверяет ровно то, что имя стоит в списке. Место читается человеком и чекером
одинаково — «ядро сказало», — и идёт на слово ядра.

Блок `вывод` кладёт в запись сам вывод: по строке на применение правила. Тогда
проверять есть что, и проверка эта локальная — сличение формы, подстановка и номер
строки, без всякого знания смыслов.

## 2. Форма

Блок стоит внутри блока утверждения, ниже строк `правило`/`по объявлению`, и устроен
ровно как блок ходов: строки-часовые и порядок, отступ значения не несёт.

```
    вывод цель ⟨результат не меньше 0⟩
    вывод 1 Н3 ⟨первое не меньше 0⟩ строка 4
    вывод 2 Н3 ⟨второе не меньше 0⟩ строка 4
    вывод 3 Н5 ⟨( первое плюс второе ) не меньше 0⟩ из 1 2
    вывод 4 Разв2 ⟨результат не меньше 0⟩ из 3 строка 7
    вывод конец
```

| часть | что значит |
|---|---|
| `вывод цель ⟨Ц⟩` | открывает блок и называет цель |
| `вывод N ИМЯ ⟨Ф⟩ ОСНОВАНИЕ` | шаг: правило `ИМЯ` ведомости заключает формулу `Ф` |
| `вывод конец` | закрывает блок |

`Ф` записывается формулой того же языка, что и цель, а не именем свойства. Довод —
проверяемость: словарю свойств пришлось бы верить, а формулу сличают знак в знак.

`ОСНОВАНИЕ` — одно из четырёх и только их:

| вид | когда |
|---|---|
| `сам` | лист: правилу основания не нужно (литерал, встроенная форма) |
| `строка N` | шаг опирается на строку исходника: объявление довода либо допущение функции |
| `из N` / `из N M` | шаг опирается на прежние шаги того же блока, номерами меньше своего |
| `из N строка M` | шаг опирается и на прежний шаг, и на строку (развёртка тела) |

Строка вида, которого здесь нет, отвергается вслух списком образцов строк записи, а не
пропускается молча.

## 3. Почему это переигрывание, а не доверие

Шесть свойств, и каждое проверено пробой:

1. **Цель блока сверяется с исходником**, а не берётся из записи. Она обязана знак в
   знак совпасть с хвостом постусловия `обеспечивает «имя» Ц`. Без этого блок объявлял
   бы себе цель сам и выводил бы что удобно.
2. **Последний шаг обязан заключать ровно цель.** Оборванный вывод — отказ, а не
   «почти доказано».
3. **Номера шагов считаются**, а не украшают: пропущенный или переставленный шаг виден.
4. **Каждое правило проверяет форму заключения.** Скажем, правило суммы берёт слева
   ровно два слагаемых по знаку «плюс»; вычитание под тем же именем не пройдёт.
5. **Каждое основание проверяется по существу.** Номер строки обязан указывать на
   строку названной функции и на строку нужного вида: объявление довода — для правил,
   читающих тип; допущение `требует «имя» формула` — для правил, читающих окружение;
   тело функции — для развёртки. Ссылка на прежний шаг обязана заключать ровно ту
   формулу, которой правилу не хватает.
6. **Запреты ведомости правилами не являются.** Имя, у которого в ведомости вид
   «запрет», отвергается сразу и с названной причиной: им не выводится ничего.

Сверщик при этом не приобретает ни системы типов, ни поиска: он не ищет обоснований и
не считает значений. Он знает формы и номера строк — ровно то же, что знал раньше.

## 4. Учёт

Место, чей вывод проигран, идёт в «сведений проиграно заново», а не «на слово ядра».
Приём стоит ОТДЕЛЬНОЙ веткой, а не добавочной: два приёма, снявших одно место, дали бы
снятого больше, чем мест, и тождество линейки («мест по тексту записи = долг + снятое +
проверенное по существу») рухнуло бы на честной записи. Замер на пробе семьи: без
отдельной ветки разбор цели снимал те же четыре места вторым счётом — снято 12 при
восьми местах.

Число снятого печатается теми же словами «снято со слова ядра мест», какими его
печатают соседние приёмы: линейка складывает снятое по всем приёмам, и слагаемое без
общей метки тихо выпало бы из тождества.

Знаменатель блок не двигает — и это СНЯТО ПРОГОНОМ, а не выведено из устройства. Один и
тот же набор прогнан линейкой дважды: с блоками вывода и с теми же записями, у которых
строки `вывод` вычеркнуты.

| | знаменатель | числитель | не проверено |
|---|---:|---:|---:|
| записи с блоком вывода | 10 | 8 | 0 |
| те же записи без блока | 10 | 0 | 8 |

Линейка `flang/proof/доля-корпуса.sh` числитель считает пятью слагаемыми, и переигранный
вывод — пятое: он берётся по якорю своей строки сводки и вычитается из общей суммы
«снято со слова ядра мест», чтобы место не считалось дважды. На записях без блока вывода
слагаемое это ноль, и доля корпуса от правки не двинулась ни на место — 517 из 651 до и
после.

## 5. Что написано и чего нет

Написаны правила семейств Н (неотрицательность), П (потолок), Т (цель есть допущение) и
развёртка плоского определения:

| правило | что берёт |
|---|---|
| Н1 | литерал не меньше нуля |
| Н2 | допущение «Т не меньше 0» знак в знак |
| Н3 | имя, объявленное типом с дном |
| Н4 | встроенные формы «длина Т» и «код символа Т» |
| Н5 | сумма ровно двух неотрицательных |
| П1 | литерал не выше названного потолка |
| П2 | допущение о границе, не выше названного потолка |
| П3 | имя типа точной сетки при потолке не ниже 9007199254740991 |
| П5 | разность: уменьшаемое под потолком, вычитаемое неотрицательно |
| Т1 | цель слово в слово стоит допущением функции |
| Разв2 | развёртка плоского тела: цель о «результат» переходит в цель о теле |
| Н✗ П✗ О✗ О✗✗ О✗✗✗ С✗ С✗✗ С✗3 С✗4 СС✗ Ч✗ Ч✗✗ | запреты: отказ по имени |

9 сентября 2026 к ним дописаны семейства отношений — те, из-за которых печать молчала
на 22 местах корпуса (`docs/zettel/the-derivation-block-prints-for-four-of-thirty-five-places.md`):

| правило | что берёт |
|---|---|
| Д1 | дно имени из допущения «конечный литерал не больше Т» |
| Д4 | дно выбора: заявленное дно СВЕРЯЕТСЯ с донами обеих ветвей, а не берётся наименьшим |
| Д6 | написанное число не меньше самого себя |
| О1 | допущение о порядке знак в знак |
| О2 | тот же терм обеими сторонами при неотрицательности либо конечности |
| О3 | выбор: обе ветви под границей |
| О4 | литерал не выше дна верхней стороны |
| О5 | общая прибавка двигает обе стороны; позиций четыре |
| О6 | прибавление к границе неотрицательного целого литерала |
| О10 | два звена через НАЗВАННУЮ середину |
| С1 | допущение о СТРОГОМ порядке знак в знак |
| С2 | выбор: обе ветви строго под границей |
| С3 | литерал СТРОГО ниже дна верхней стороны |
| С4 | литерал не выше строгого дна, названного допущением |
| СС1 | база: выписанный список без пар соседей |
| СС2 | допущение «Л не убывает» знак в знак |
| СС3 | приписывание при видимой голове хвоста |
| СС4 | выбор: обе ветви не убывают |
| В1 | выписанный список содержит член знак в знак |
| В2 | «добавить Э к Л» и «приписать Э к Л» при том же Э |
| В3 | вхождение сохраняется при любом другом добавленном |
| В4 | выбор: обе ветви несут член |
| Ч1 | тот же терм началом самого себя |
| Ч2 | пустая приставка |
| Ч3 | левый кусок двоичной склейки |
| Ч4 | выбор: обе ветви начинаются приставкой |
| Ч6 | приставка приставки через названную середину |

**Чего НЕТ и почему — названо вслух, а не оставлено молчанием.** Д3 и Д5 заключают
дно, СЛОЖЕННОЕ либо ПЕРЕМНОЖЕННОЕ из двух: чтобы такое дно кому-то пригодилось, его
пришлось бы сосчитать, а приём считать не умеет и уметь не должен. Ч5 сличает два
ТОЧНЫХ ТЕКСТА, и точный текст надо собрать — склеить куски и посчитать длину
выписанного списка; это ровно то же вычисление. Кон2 и Кон3 читают оговорку «пока это
число», О7 — разбор случаев, О8 и О9 читают ТЕЛО и переписывают цель сами, СС5 не
заключает ничего, а кладёт два факта в окружение. Имя любого из них даёт НАЗВАННЫЙ
отказ, а не тихий пропуск.

## 5а. Сколько мест приём достаёт на корпусе — замер 9 сентября 2026

Печати этих семейств в ядре нет (задача 6132), и потому ДОЛЯ КОРПУСА от правки не
двинулась ни на место: 567 из 651 до и после. Записей с блоком `вывод` в наборе
«корпус» ноль — это сосчитано, а не предположено.

Досягаемость мерена иначе: к копиям записей корпуса блоки вывода дописаны руками, и
чекер прогнан по НАСТОЯЩИМ исходникам дерева. Из 22 мест, где ядро назвало отношение,
приём переигрывает **10**:

| запись | места | чем |
|---|---|---|
| `abilities` | У19, У20, У21, У24, У25, У26 | СС1, СС3, О1, О6, В2, В3 |
| `boundaries` | В4, В5, В6 | Н4, О2, О4 |
| `equality` | Р5 | В2 |

Оставшиеся 12 — с названной причиной у каждого:

| место | почему не берётся |
|---|---|
| `abilities` У22 | ветвь «иначе» закрыта ПРОТИВОРЕЧИЕМ допущений; правила на это нет ни у одного семейства |
| `boundaries` В7, В8, В9 | дно суммы: чтобы им воспользоваться, дно пришлось бы сложить |

| `nachalo` «выбор начинается общим началом» | тело функции написано тремя строками, и развёртка одним термом его не читает |

| `nachalo` «начинается с аб» | факт «Т ▷ Б» приходит обещанием ВЫЗВАННОЙ функции, а у оснований шага такого вида нет |
| `poddelka-order-arithmetic`, `poddelka-strict-order` три места | оговорка и охрана «пока это число» — Кон2 и Кон3 |

## 6. Сколько мест это закроет — замер

Прибор: `flang/proof/чекер/сверщик` по всем 86 записям набора «корпус», строки «НЕ
ВЗЯЛСЯ» разложены по имени правила, которое ядро поставило месту.

Открытых мест 134: утверждений 80, посылок 29, шагов 17, снятого счётом 8. Из них имя
правила принадлежит одному из восьми типовых семейств ведомости у **51 места**:

| имя правила ядра | утверждений | посылок | всего |
|---|---:|---:|---:|
| порядок по построению | 9 | 2 | 11 |
| неотрицательность по построению | 8 | 4 | 12 |
| ограниченность точным потолком по построению | 5 | 7 | 12 |
| вхождение по построению | 5 | 0 | 5 |
| порядок соседних по построению | 4 | 0 | 4 |
| строгий порядок по построению | 3 | 0 | 3 |
| начало по построению | 3 | 0 | 3 |
| цель есть допущение | 1 | 0 | 1 |
| **итого** | **38** | **13** | **51** |

Остальные 83 места блок вывода не закрывает: разбор цели по условию 23, тождество после

требует 619. **Блока вывода одного не хватает — недостаёт ещё 51 места**, и брать их
придётся у других волн.

## 7. Где не измерено

1. Замер §6 говорит, какие места ЖДУТ вывода, а не сколько выводов ядро СМОЖЕТ
   напечатать. Печати нет (задача 6132), и молчание печатника — отдельная цена; на
   прошлой волне печатник молчал на всех 49 открытых местах пяти правил, за которые он
   берётся.
2. Второй чекер `flang/proof/сверщик.flang` приёма не знает. Записи с блоком вывода он
   отвергнет как незнакомые. Пока такие записи есть только в наборе проб, это ничему не
   мешает; до печати в ядре второй чекер обязан поехать следом.
