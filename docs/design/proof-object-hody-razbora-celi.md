## 1. Общие правила формата (обязательны для печатника)

1. **Блок ходов** стоит под строками постусловия (`правило «…»`, `по объявлению нет`),
   с отступом четыре пробела, от `ход цель` до `ход конец`; номера ходов идут
   подряд с 1 (`сверщик.c`, `ход_шага`). Порядок — стек целей: после `деление`
   печатаются ВСЕ ходы да-половины до её закрытия, затем нет-половины; после
   `связка ⟨и притом⟩` — сначала левая половина, затем правая.
2. **`ход цель`** — начальная цель строит сверщик сам: постусловие из исходника, где
   `результат` заменён вызовом `«Ф» от ( п₁ ) и п₂ и …` (первый довод в скобках,
   прочие — хвостом; у функции без доводов — голое `«Ф»`). В записи цели нет.
3. **Термы в ⟨уголках⟩** обязаны совпасть с целью ПОСЛЕ нормализации сверщика
   `терм()` = `ужать(расставить(t))`: каждая скобка отделена пробелами, пробельные
   пробеги сжаты, внешняя пара скобок целиком снята (до четырёх раз). Подстановки
   (`развернуть`, `выбор`, `деление`, `подставить пусть`, `вычислить`,
   `переписать формой`) оборачивают вставляемое через `в_скобки`: составной терм с
   пробелом — в `( … )`, одно слово — голым; место, уже стоящее в скобках, вторых
   скобок не получает. Отсюда, например, `выбор ⟨если да то ( длина элементы ) иначе 0⟩`
   и `вычислить ⟨длина ( [а, б] )⟩`, а не `длина [а, б]`. Терм ищется в цели по
   пробельным краям (`есть_терм`), заменяются ВСЕ вхождения.
4. **Условие в скобках (Б2\*).** `деление ⟨У⟩` принимает цель, где условие стоит
   как `если У то …` ЛИБО `если ( У ) то …` — так ядро печатает охрану
   `если ((х остаток от 2) равен 0) то …`. Иных форм нет; `У` в ⟨уголках⟩
   печатается без внешних скобок (`деление ⟨( х остаток от 2 ) равен 0⟩`).
5. **Печатник обязан молчать, где не уверен**: не печатать цепочку (место уйдёт
   именем правила, как сегодня) лучше, чем напечатать неверный ход — неверный ход
   на честной записи = код 1 = падение доли, не соундности.

## 2. Семь новых видов: грамматика и локальная проверка

Ниже `Т`, `Л`, `Р`, `П`, `Х` — термы после нормализации; «≡» — тождество знак в
знак после `ужать`; «простой» — одно слово либо одна пара скобок целиком
(`простой`). Тексты отказов — дословно из `сверщик.c`.

### 2.1. Законы (ход `закон «имя»`, `применить_закон`)

Закон применяется к первой цели; посылок либо нет (цель закрыта), либо ровно одна
(новая первая цель). Имя вне закрытого списка — «закона «…» сверщик не знает:
список законов закрыт».

| строка записи | цель обязана быть | что сверяется | итог |
|---|---|---|---|
| `ход N закон «мера неотрицательна»` | `длина Т не меньше 0` | ровно одно « не меньше » сверху; справа литерал `0`; слева `длина Т`, Т простой | закрыта |
| `ход N закон «квадрат под оговоркой»` | `не ( ( Т минус Т ) равен 0 ) или ( ( Т умножить на Т ) не меньше 0 )` | ровно одно « или »; левый дизъюнкт начат `не `, под ним `… равен 0` с `Т минус Т` (стороны ≡); правый — `… не меньше 0` с `Т умножить на Т`, оба сомножителя ≡ Т из оговорки | закрыта |
| `ход N закон «начало склейки»` | `( соединить Л с Р ) начинается с П` | ровно одно « начинается с »; слева `соединить Л с Р` с ровно одним « с » сверху; Р не смотрится | Л ≡ П → закрыта; иначе новая цель `Л начинается с П` |
| `ход N закон «пустая приставка»` | `Т начинается с ""` | ровно одно « начинается с »; справа литерал `""` | закрыта |

Отказы: «закон «мера неотрицательна» берёт только цель вида «длина Т не меньше
0»» / «слева не мера «длина Т» с простым Т»; «закон «квадрат под оговоркой»:
слева не квадрат «е умножить на е» того же терма, что в оговорке» (и три
соседних — по каждой строгости); «закон «начало склейки»: слева не склейка
«соединить Л с Р»»; «закон «пустая приставка» берёт только цель вида «Т
начинается с ""»».

### 2.2. Форма-законы (ход `переписать формой ⟨A⟩ = ⟨B⟩ законом «имя»`, `форма_законом`)

Сверщик проверяет, что A стоит в цели, САМ пересобирает правую сторону по закону
и сверяет её с B знак в знак; лишь тогда A→B в цели. B из записи доводом не
служит («правая пересобрана как «…», а запись несёт «…»»).

| закон | A | пересобранная B |
|---|---|---|
| `«Закон признака»` | `не да` / `не нет` / `да и притом Х` / `Х и притом да` / `нет и притом Х` / `Х и притом нет` / `нет или Х` / `Х или нет` / `да или Х` / `Х или да` | `нет` / `да` / `Х` / `Х` / `нет` / `нет` / `Х` / `Х` / `да` / `да` |
| `«Вхождение в выписанный список»` | `[Э₁, …, Эн] содержит Х` | `да`, если Х ≡ одному из Э (члены сличаются термами, не считаются) |

Список закон признака закрыт (`закон_признака`): обе части обязаны быть простыми,
связка — ровно одна сверху. Печатать один закон на одну подстановку: две
подстановки — две строки. Отказ: «переписать формой законом «…»: левая сторона
«…» не той формы, какой закон требует».

### 2.3. Ходы (`ход_шага`)

| строка записи | цель обязана быть | что сверяется | итог |
|---|---|---|---|
| `ход N связка ⟨и притом⟩` | `Л и притом П` | ровно одно « и притом » сверху; Л и П простые | две цели: Л, затем П |
| `ход N связка ⟨или⟩ левая` / `… правая` | `Л или П` | ровно одно « или » сверху; Л и П простые; половина названа | одна цель: Л либо П |
| `ход N подставить пусть строка M` | любая, где стоит `имя` | строка M исходника, прочитанная как язык, — `пусть имя равно значение`; стоит в ЭТОЙ функции (`хозяин_строки`); `имя` — одно слово, не довод функции (`принимает`), не встречается в своём значении; `имя` есть в цели | цель с `имя` → `значение` (через `в_скобки`) |

Отказы: «связка ⟨или⟩: надо назвать половину — «левая» или «правая»»; «связка
⟨…⟩: половины цели «…» не обняты скобками — старшинства сверщик не знает»;
«подставить пусть: строка M исходника не вида «пусть имя равно значение», а
«…»»; «…стоит в функции «…», а не в «…»»; «имя «…» — довод функции «…»,
подстановкой его не заслонить»; «в цели «…» нет имени «…»».

**Многострочное тело с `пусть`.** `развернуть` печатается на ПОСЛЕДНЮЮ строку
тела (сам терм), затем по одному `подставить пусть строка M` на каждое имя,
которое стоит в цели; `пусть`, в цель не вошедший (свёртка из `binder-wall-map`),
хода не получает — и получить не должен: ход на имя вне цели — отказ.

## 4. Ход `вычислить ⟨T⟩ = ⟨V⟩` — граница, которая НЕ расширяется

Где уже применяется: Ф9 «Замкнутая цель» (корпус, `forms.flang:45`, golden
`семьи/половина-б/arithmetic.запись`), и в цепочках §3 — места 15 (В2), 30 (Ф1),
32 (Ф3), 43 («литерал начинается приставкой»), 45 (П2), 47 («начинается с а»):
после `деление`/`выбор` ∀-часть цели снята, остаётся наземный терм без свободных
имён (`1 не больше 1`, `( 2 не меньше 0 ) и притом ( 2 не больше 2 )`,
`длина ( [а, б] )`, `"аб" начинается с "а"`), и сверщик считает его тем же
`оценить_терм`, что держит шаги «по примеру», сверяя со записанным ⟨V⟩ значением.

Что ЗАПРЕЩЕНО и не делается этой задачей: считать терм со свободным именем (ход
сам отказывает: «терм не замкнут (свободное имя или неарифметический
конструктор) — считать нечего»), считать выписанный список с именами внутри
(`["да", "нет"] содержит результат` — отказ; для этого и заведён форма-закон
«Вхождение в выписанный список», который члены НЕ считает, а сличает), считать
ветвь `если` (для этого `выбор`). В семи новых видах §2 вычисления нет ни в одном:
все они — сличение литералов и тождество знак в знак.

**Вопрос владельцу открыт** (карта §2, «граница честности»): считать ли
«арифметику одного шага» на замкнутом терме допустимым примитивом move-replay.
Пока решения нет, примитив оставлен КАК ЕСТЬ. Если решение «нет» — места 15, 30,
32, 43, 45, 47 (и Ф9) потребуют новых законов сличения литералов («литерал
сравнения», «мера выписанного списка»), все локальные; список законов вырастет
на 2–3 имени.

## 5. Соундность: что стережёт каждый вид

`flang/proof/чекер/пробы/семьи/razbor-celi/` (вплетено в `прогон.sh`):

| вид | честная (код 0) | подделка (не 0) — чем названа |
|---|---|---|
| Б2\* деление в скобках | «Чётность» | остаток `равен 1` под охраной `равен 0` → «в цели … нет терма»; деление по подтерму → «не стоит в цели условием» |
| «мера неотрицательна» | «Мера» | `не меньше 1` → «берёт только цель вида «длина Т не меньше 0»»; закон вне списка → «сверщик не знает» |
| «квадрат под оговоркой» | «Квадрат» | `е умножить на д` → «слева не квадрат … того же терма, что в оговорке» |
| «начало склейки» | «Склейка», «Приставка» | «начинается правым куском» → «незакрытых целей 1 — первая «начало начинается с конец»»; `"аб" начинается с "б"` → «терм посчитан = нет, а запись несёт ⟨да⟩» |
| «пустая приставка» | «Тот же текст» | `начинается с "а"` → «берёт только цель вида «Т начинается с ""»» |
| «Закон признака» | «Следует» | `иначе нет` → «закрыть тождеством: у цели «нет равен да» стороны разные»; подложная B → «правая пересобрана как …» |
| «Вхождение в выписанный список» | «Ответ» | `"может"` вне набора → «левая сторона … не той формы» |
| `связка ⟨и притом⟩` | «Мера дважды» | `равен 1` → «стороны равенства разные» |
| `связка ⟨или⟩` | «Меньшее» | `равен 0` → «стороны равенства разные»; не та половина → отказ |
| `подставить пусть` | «Порог под пусть» | `пусть сколько равно 0` → «стороны равенства разные»; строка не-`пусть` → «не вида «пусть имя равно значение»» |

Рядом (семья `булева-цель`): проба на ВАКУУМНЫЙ успех узла `algebra` — все
правила посылок пусты, строка «сведение» снята; прежний сверщик отвечал код 0 и
«снято со слова ядра мест 4», не прочитав ни случая; теперь узел вне приёма,
код 3.

## 6. Что печатнику делать НЕ надо

- Не печатать цель (`ход цель` — без терма) и не печатать правую сторону
  законов (`закон «…»` — без уголков): сверщик строит их сам.
- Не печатать `подставить пусть` для имён, не вошедших в цель.
- Не печатать `вычислить` для термов со свободными именами — ход отказывает.
- Не звать `половина_закрыта`/`разбором_цели` там, где ходы напечатаны: маршрут
  `без_теоремы` (сверщик.c, гейт 4102) уже идёт мимо калькулятора при `ход цель`.
  `половина_закрыта` остаётся в сверщике до перепечатки корпуса; снять её можно,
  когда все 33 места несут цепочки (карта §3.2).
