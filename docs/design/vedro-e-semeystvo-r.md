# Ведро Е — семейство Р (разбор цели по условию): контракт печати и приёма

Проектная записка к [ADR-0027](../adr/0027-case-analysis-prints-as-a-derivation-and-is-replayed.md).
Здесь — то, по чему написаны golden-записи и черновики кода; ADR — почему так. Замер, на
котором всё стоит: 25 мест ведра Е, 16 половин, прогнанных ядром отдельно (`ПЕРЕДАЧА/stack-E/zamer.md`).

## 1. Формат

Блок стоит под утверждением без ходов и посылок, после строки `по объявлению …`, отступ четыре пробела:

```
    вывод цель ⟨если ( н больше 1 ) то ( 0 меньше результат ) иначе да⟩
    вывод 1 ГипО ⟨н больше 1⟩ сам
    вывод 2 С4 ⟨0 меньше н⟩ из 1
    вывод 3 Разв2 ⟨0 меньше результат⟩ из 2 строка 122
    вывод 4 Р1 ⟨если ( н больше 1 ) то ( 0 меньше результат ) иначе да⟩ из 1 3
    вывод конец
```

Строка шага — `вывод N ИМЯ ⟨формула⟩ ОСНОВАНИЕ`, основание ∈ {`сам`, `строка N`, `из N`, `из N M`,
`из N строка M`} — ровно то, что уже читает `разобрать_шаг_вывода` в `сверщик.c`. Формулы — в виде
`терм()` проверяющей программы, он же «Терм записи» ядра: скобки расставлены пробелами, внешняя пара снята.

## 2. Правила: что сличается

Обозначения: Ф — заключение шага; о(m) — заключение шага m; open(k) — открытые гипотезы шага k.
open(k) = ∪ open(посылок k); **ГипО** и **ГипД** добавляют себя; **Р1** и **Р4** снимают. Последний шаг блока обязан
иметь open = ∅.

| имя | форма | что сличается |
|---|---|---|
| ГипО ⟨У⟩ сам | гипотеза охраны | законна только под Р1, чья цель `если У то … иначе да` несёт ту же У (после `ужать`) |
| ГипД ⟨А⟩ строка N | гипотеза дизъюнкта | строка N — `требует «…» Л или П` функции утверждения; А — ровно левая или правая половина верхнего `или`; законна только под Р4 с той же строкой |
| Р1 ⟨если У то Ц иначе да⟩ из h m | снятие охраны | порядок посылок фиксирован: h — ГипО(сам), m — вывод ветви; разрез по `если … то … иначе …` верхнего уровня; `ужать(У)` = о(h); ветвь «иначе» — литерал `да`; `ужать(Ц)` = о(m); open(m) ⊆ {h}; результат open = open(m) \ {h} |
| Р4 ⟨Ц⟩ из m1 m2 | свод случаев | о(m1) = о(m2) = Ф; open(m1) = {h1} и open(m2) = {h2} СТРОГО, h1 ≠ h2, оба ГипД(строка N) одной строки; половины — множество: {о(h1), о(h2)} = {Л, П} строки N в любом порядке; результат open = ∅ |
| Выч ⟨Ф'⟩ сам | замкнутая половина | `половина_закрыта(Ф')` истинно — уже доверенный вычислитель половин (`да`/`нет`, `если да|нет`, `не`, `или`, `и притом`, тождество сторон `равен`, замкнутый счёт); переиспользование, не второй упроститель |
| Р3 ⟨Ф⟩ из m1 m2 | внутреннее условие | m1, m2 — Выч; В восстанавливается сличением: первое расхождение Ф и о(m1) — начало сбалансированного подтерма В в Ф, на его месте в о(m1) стоит `да`; `вставить_вместо(Ф, В, "да")` = о(m1), `вставить_вместо(Ф, В, "нет")` = о(m2) знак в знак (двухпроходная замена, как у Разв2). Формы `сам` нет; вложенный Р3 — посылка Выч + посылка Р3 |
| Р2 | то же | тем же кодом: различие «первое/внутреннее условие» — дело ядра, половины напечатаны |
| Р5 ⟨результат равен Т⟩ из h строка N | ветвь пусто | о(h) — один из четырёх фактов пустоты о Л: `пусто Л`, `( длина Л ) равен 0`, `Л равен пустой список`, `Л равен ""`; тело функции — `разбор Л` (тот же Л через `голо`, читается `найти_случай`/`тело_случая`), ветвь `случай пусто` → `то Т'`; `терм(Т')` = `терм(Т)`; N — строка `разбор` |
| Р6 ⟨результат равен Н⟩ из h строка N | свёртка над пустым | те же факты; строка N — первая строка тела вида `свёртка Л начиная с Н как …`; `терм(Н)` = правая сторона |
| Р7 | — | не печатается и отдельно не принимается: `строгий_вывода`/`порядок_вывода` читают `Г больше Е` и `Е меньше Г` как одну форму; строка таблицы остаётся описанием шага ядра со статусом «механизм» |
| Или1 ⟨Л или П⟩ из m | введение дизъюнкции слева | о(m) = `ужать(Л)` |
| Или2 ⟨Л или П⟩ из m | введение дизъюнкции справа | о(m) = `ужать(П)` |
| С4, П2 … из m | допущение из шага | как сегодня по «строка N», но допущение — о(m), строгий факт — в любой из двух записей |
| Разв2 | как сегодня | `терм(вставить_вместо(Ф, "результат", тело))` = о(m); тело в скобках ставит `в_скобки` |

## 3. Чем закрывается половина Выч

Вызовом `половина_закрыта` — вычислителя половин, которому проверяющая программа уже доверяет в приёме «разбором цели». Его список (для справки): `если да то А иначе Б`→А; `если нет то А иначе Б`→Б; `не да`→нет; `не нет`→да; `да или Х`→да; `Х или да`→да;
`нет или Х`→Х; `Х или нет`→Х; `да и притом Х`→Х; `Х и притом да`→Х; `нет и притом Х`→нет; `Х и притом нет`→нет;
`Т равен Т`→да (Т знак в знак; `равен` языка — Object.is, рефлексивно и на не-числе); лишние скобки снимаются.
Никакой арифметики над числами, никаких имён: это подстановка значения в признак, ровно то, что делает пятый ход ядра.

## 4. Подделки, которые обязаны падать кодом 1 с названной причиной

1. Р1: переставленные стороны охраны — `Гип ⟨1 больше н⟩` при цели `если ( н больше 1 ) …`.
2. Р1: `иначе` не литерал `да`.
3. Р1/Р4: гипотеза без снятия — последний шаг с open ≠ ∅.
4. Р4: обе половины в одном случае — вывод опирается на h1 и h2 разом.
5. Р4: потерянная посылка — `из 1 1`.
6. Р4: гипотеза не половина дизъюнкции строки N.
7. Р5: пустота из чужого факта — гипотеза о `хвост`, разбор по `элементы`.
8. Р5: строка N не `разбор` / ветвь пусто с другим телом.
9. Р6: начало свёртки другое.
10. Р1: гипотеза `1 меньше н` при охране `н больше 1` (переставлен только знак) — не есть охрана цели.
11. Р3: половина Выч не замкнута (`( не да ) или нет`); половины от разных условий.
12. Или1: посылка — правая половина.
13. Разв2: тело подставлено без скобок.

## 5. Печать (ядро, `zapis.flang`): пять форм и молчание

Печатник убеждается по форме исходника, что блок пройдёт у приёма, иначе не печатает ничего.
Формы: (1) охрана + пустота → ГипО/Р5|Р6/Р1; (2) внутреннее условие → Выч×2 + Р3 `из 1 2` + Разв2; (3) дизъюнкция в
допущении → ГипД×2, вывод цели из каждой (сама гипотеза, П2, Или1/Или2), Р4, Разв2; (4) охрана + отношение →
ГипО/С4|О…/Разв2/Р1 — когда есть печать семейств С/О; (5) половина «условие ложно» при `иначе да` не печатается.
Условие вызова — то же, что у «Вывод факта о типе записи»: постусловие, вердикт «доказано», ни ходов, ни посылок.
