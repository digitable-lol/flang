# Разметка рассуждения: инструкция для языковой модели и для человека

Ниже — задание, которое можно целиком отдать языковой модели вместе с текстом
статьи. Человек размечает по тем же правилам. Результат — файл `статья.claims`,
который проверяет команда `flang run-script argue`.

---

Ты размечаешь рассуждение в тексте. Твоя работа — записать, что автор
утверждает и что из чего он выводит. Оценивать, прав ли автор, не нужно: это
сделает программа. Ответ — только содержимое файла разметки, без пояснений.

## Формат файла

Одна запись — одна строка. Строка, начинающаяся с `#`, — комментарий.

```
понятие имя(x): что значит
понятие имя(x, y): что значит
понятие имя: что значит
имя Сократ, Моби
величина выручка, затраты: что измеряет
неотрицательная величина доля: что измеряет
[1] логическая форма
    цитата: слова из текста
    цитата: продолжение из другого предложения
    сила: как правило
    происхождение: модель
    вариант: другая форма той же цитаты
    почему: несколько слов
    термин: слово из цитаты = что оно здесь значит
    определение: слово из цитаты = чем автор его определил
вывод [3] из [1], [2]
вывод [5] из [4]: корреляция
вывод [7]
не суждение: слова из текста
```

- `понятие` объявляет одно понятие и число его мест: `кит(x)` — свойство
  предмета, `старше(x, y)` — отношение двух предметов, `дождь` — высказывание
  целиком. Имя пишется без пробелов, слова соединяются знаком `_`.
- `имя` объявляет названные в тексте предметы: людей, организации, объекты.
- `величина` объявляет числа, которые сравниваются: `величина спрос, запас`.
  Слово `неотрицательная` впереди говорит, что величина не бывает меньше нуля:
  доля, число людей, длительность.
- `[N]` — суждение: номер, за ним логическая форма. Номера не повторяются.
- `цитата:` — слова текста, из которых взято суждение. Обязательна. Если
  суждение собрано из двух мест (условие в соседнем предложении, пункт
  перечня), напиши вторую строку `цитата:`.
- `сила:` — слово неполной уверенности, если оно есть в тексте (правило 9).
- `не суждение:` — предложение со словом вывода, которое ничего не утверждает
  (правило 3).
- `термин:` и `определение:` — необязательные строки, о них ниже.
- `вывод [N] из [M], [K]` — автор выводит суждение N из суждений M и K.

## Логическая форма

| Запись | Смысл |
| --- | --- |
| `кит(Моби)` | Моби — кит |
| `не рыба(Моби)` | Моби не рыба |
| `кит(Моби) и умный(Моби)` | и то, и другое |
| `лампа или ток` | хотя бы одно из двух |
| `если дождь, то мокро` | условие и следствие |
| `все x: если кит(x), то зверь(x)` | все киты — звери |
| `все x: если кит(x), то не рыба(x)` | ни один кит не рыба |
| `есть x: кит(x) и белый(x)` | некоторые киты белые |
| `все x, y: если старше(x, y), то не старше(y, x)` | о любой паре |
| `все x: есть y: если студент(x), то наставник(x, y)` | у каждого студента есть наставник |
| `есть y: все x: читал(x, y)` | есть книга, которую читали все |
| `спрос < запас`, `доля >= 50 %`, `a не больше b` | сравнение величин |
| `выручка_2021 = 1,12 * выручка_2020` | выросла на 12 % |
| `цена_после = 2 * цена_до` | выросла в два раза |
| `1,5 <= кратность и кратность <= 2` | в 1,5–2 раза |
| `причина: если курит, то болеет` | курение приводит к болезни |
| `вероятно: дождь` | то же, что строка `сила: вероятно` |

Скобки группируют части: `если (а или б) и не в, то г`. Кванторы стоят только
в начале формы. `все` и `есть` могут смениться один раз: `все x: есть y: …`
или `есть y: все x: …`.

Сравнения пишутся знаками `<`, `<=`, `=`, `!=`, `>`, `>=` или словами
`меньше`, `не больше`, `равно`, `не равно`, `больше`, `не меньше`. По обе
стороны стоят числа, объявленные величины и арифметика: `+`, `-`, умножение и
деление на число, `%`. Десятичная запятая пишется без пробелов: `0,05`. Две
величины друг на друга не умножай: такое сравнение не проверяется.

Суждение, которое не раскладывается на части, записывай высказыванием без
мест: `понятие опрос_проведён: проведён опрос 412 студентов`, затем
`[4] опрос_проведён`.

Раскладывай на части всё, что участвует в выводе. Если о предмете говорят два
предложения и одно выводится из другого, заведи понятия с местами и запиши
предмет именем: `точен(МетодА)`, а не `метод_А_точен`. Высказывание без мест
прячет связь, и проверка её не увидит. Признак, что нужны места: одно и то же
слово-признак сказано о двух предметах либо в тексте есть «все», «каждый»,
«любой», «ни один», «некоторые».

## Правила

1. **Цитата дословно.** Копируй слова из текста знак в знак: те же буквы,
   регистр, знаки препинания внутри цитаты. Переносы строк и лишние пробелы
   не важны. Не исправляй опечатки и не пересказывай. Цитата — самый короткий
   кусок, в котором суждение высказано; вводное «следовательно» можно включить.
2. **Не додумывай посылок.** Записывай только то, что написано. Если вывод
   опирается на то, чего в тексте нет, не добавляй это суждение: пропуск и
   есть находка.
3. **Каждому слову вывода — запись.** Слова «следовательно», «значит»,
   «поэтому», «итак», «таким образом», «отсюда следует», «стало быть», «так
   как», «потому что», «поскольку», «ибо», «в результате», «свидетельствует
   о», «говорит о», «позволяет утверждать», «то есть», «соответственно»
   отмечают связь двух суждений. Для каждого такого слова запиши одно из
   трёх, по правилу 4: строку `вывод`, строку `вывод … : объяснение` или
   строку `не суждение:`. Посылки — суждения, на которые автор в этом месте
   опирается. Если их в тексте нет, пиши `вывод [N]` без `из`.
   `не суждение:` ставь, когда предложение ничего не утверждает: вводит
   название («Поэтому назовём его…»), объявляет раздел, ставит задачу.
4. **Какая это связь — решает правило, а не вкус.** Иди по списку сверху вниз
   и остановись на первом подходящем пункте.
   1. Автор сообщает, почему что-то произошло или почему кто-то так
      поступил, и само событие под сомнение не ставит («оценили высоко, так
      как стало удобнее», «лёд тает, так как тепло») — `: объяснение`.
      Проверка: вопрос «откуда известно, что это так?» к такому предложению
      не подходит, подходит вопрос «почему так вышло?».
   2. «То есть», «иначе говоря», «другими словами» — пересказ. Если вторая
      часть говорит то же самое, дай обеим одну форму и шага не ставь. Если
      вторая часть утверждает больше первой — это вывод, иди дальше.
   3. Вывод от части случаев ко всем — `: обобщение`. От опрошенных или
      обследованных к тем, кого не обследовали, — `: выборка`.
   4. От «p меньше 0,05», «различие значимо», «достоверно» к «эффект есть»,
      «метод действует» — `: значимость`.
   5. От «встречается вместе», «выше у тех, кто», «коррелирует» к «вызывает»,
      «влияет», «приводит к» — `: корреляция`.
   6. От чужого мнения, оценки или ссылки на источник к самому утверждению —
      `: авторитет`. Сюда же пересказ: «по мнению N, …», «как показал N, …»,
      когда автор берёт вывод у N и сам его не обосновывает.
   7. Вывод держится на определении термина, которое есть в тексте, —
      `: определение`.
   8. Вывод опирается на общее правило, которое автор не назвал, но
      очевидно считает известным («трава мокрая, значит, шёл дождь») —
      `: допущение`. Отчёт назовёт это правило как допущение автора.
   9. Всё остальное — строгий вывод, без пометки. Так помечай и вывод, в
      котором ты видишь ошибку: ошибку найдёт проверка.
5. **Одно понятие — одно имя.** Если два предложения говорят одно и то же,
   дай им одну и ту же логическую форму, даже когда слова разные. Если слова
   одинаковые, а смысл разный, заведи два понятия.
6. **Раздел «Выводы» и «Заключение».** Каждый пункт выводов — суждение, даже
   без слов-маркеров. Для каждого пункта запиши строку `вывод`: посылки —
   суждения из основной части, на которых этот пункт держится. Если в
   основной части таких суждений нет, пиши `вывод [N]` без `из`: это вывод
   без оснований.
7. **Термины.** Если автор определяет слово, добавь к суждению с определением
   строку `определение: слово = смысл`. Там, где это слово стоит дальше,
   добавь `термин: слово = смысл` и запиши смысл, в котором оно употреблено
   именно здесь. Слово бери из цитаты как написано. Смысл записывай
   одинаковыми словами, когда он один и тот же.
   Строку `термин:` ставь и без определения: для каждого ключевого слова
   статьи (оно есть в заголовке, в выводах или стоит в посылке и в выводе
   одного шага) в каждом суждении, где оно встречается. Спроси себя, о том
   же ли это слово, что в прошлый раз: «законы» природы и «законы»
   государства — два смысла.
8. **Не размечай то, что не участвует в рассуждении**: обзор литературы,
   благодарности, описание структуры статьи.
9. **Слова неполной уверенности.** «Вероятно», «возможно», «может быть»,
   «по-видимому», «предположительно», «как правило», «обычно», «часто»,
   «зачастую», «в большинстве случаев», «чаще всего», «иногда», «редко»
   записывай строкой `сила:` под суждением, а форму пиши так, как если бы
   слова не было. «Большинство» и «многие» записывай как `сила: в
   большинстве случаев` при форме со `все`. Суждение с такой строкой не
   доказывает твёрдого вывода, и проверка это покажет. Не выбрасывай эти
   слова и не превращай их в твёрдое утверждение.
10. **Причина.** «Вызывает», «приводит к», «обусловливает», «влечёт»,
    «является причиной», «из-за» записывай формой `причина: если А, то Б`.
    Из неё вместе с А следует Б. Сама она следует только из другого
    суждения о той же причине. Если автор выводит причину из того, что два
    признака встречаются вместе, ставь шагу род `корреляция`.
11. **Числа и таблицы.** Числа, на которых держится вывод, записывай
    сравнениями, а не высказыванием без мест. Число из таблицы — тоже
    суждение: цитата — строка таблицы как она стоит в тексте, форма —
    `величина = число`. Если текст называет то же число словами («в 1,5–2
    раза»), запиши и текст, и таблицу одной величиной: расхождение проверка
    найдёт как противоречие.
12. **Чужое мнение.** Когда автор пересказывает чужую позицию, чтобы с ней
    спорить, запиши её суждением с понятием вида `N_считает_что_…` и не
    смешивай с позицией автора. Когда автор принимает чужой вывод,
    запиши сам вывод и шаг рода `авторитет`.

## Пример

Текст:

```
Под надёжным сервисом мы понимаем сервис, который отвечает на каждый запрос.
Все сервисы с резервной копией надёжны. Сервис «Архив» имеет резервную копию.
Следовательно, «Архив» надёжен. Пользователи называют «Архив» надёжным, так
что он отвечает на каждый запрос. После перехода на новую базу жалоб стало
меньше, значит, новая база повысила качество.
```

Разметка:

```
понятие с_копией(x): у сервиса x есть резервная копия
понятие надёжен(x): сервис x надёжен
понятие пользователи_называют_надёжным(x): пользователи называют сервис x надёжным
понятие отвечает_на_каждый(x): сервис x отвечает на каждый запрос
понятие жалоб_меньше: после перехода на новую базу жалоб стало меньше
понятие база_повысила_качество: новая база повысила качество
имя Архив

[1] все x: если надёжен(x), то отвечает_на_каждый(x)
    цитата: Под надёжным сервисом мы понимаем сервис, который отвечает на каждый запрос
    определение: надёжным = отвечает на каждый запрос
[2] все x: если с_копией(x), то надёжен(x)
    цитата: Все сервисы с резервной копией надёжны
[3] с_копией(Архив)
    цитата: Сервис «Архив» имеет резервную копию
[4] надёжен(Архив)
    цитата: Следовательно, «Архив» надёжен
вывод [4] из [2], [3]

[5] пользователи_называют_надёжным(Архив)
    цитата: Пользователи называют «Архив» надёжным
    термин: надёжным = нравится пользователям
[6] отвечает_на_каждый(Архив)
    цитата: он отвечает на каждый запрос
вывод [6] из [5]: авторитет

[7] жалоб_меньше
    цитата: После перехода на новую базу жалоб стало меньше
[8] база_повысила_качество
    цитата: новая база повысила качество
вывод [8] из [7]: корреляция
```

Что здесь сделано по правилам: определение записано как суждение [1] и
помечено строкой `определение`; слово «надёжным» в [5] помечено другим
смыслом, потому что там оно значит мнение пользователей; у шага [6] из [5]
род `авторитет`, у шага [8] из [7] — `корреляция`; посылка «мнение
пользователей всегда верно» не добавлена, потому что её нет в тексте.

## Второй режим: правка черновика

Иногда вместе с текстом ты получаешь черновик разметки, который написала
грамматика flang. В черновике у суждения стоит главная форма, а под ней могут
стоять другие прочтения той же цитаты и помета, кто это суждение записал:

```
[7] все x: если кит(x), то зверь(x)
    цитата: Все киты — звери
    происхождение: грамматика
    вариант: есть x: кит(x) и зверь(x)
```

Строки `вариант:` и `происхождение:` на проверку не влияют: судится главная
форма. Твоя работа в этом режиме:

1. Для каждого суждения черновика реши одно из трёх. Главная форма верна —
   оставь как есть. Верен один из вариантов — поставь его главной формой, а
   прежнюю главную запиши строкой `вариант:`; помету смени на
   `происхождение: грамматика, вариант K`, где K — номер варианта по порядку.
   Ни одна форма не передаёт смысл — напиши свою, поставь
   `происхождение: модель` и строку `почему:` в несколько слов.
2. Допиши суждения для предложений, которых в черновике нет, с пометой
   `происхождение: модель`.
3. Поставь шаги и род каждого шага по правилам 3, 4 и 6. Черновик шагов
   не ставит.
4. Сведи одинаковые понятия к одному имени (правило 5). Имена понятий из
   черновика без нужды не меняй: по ним разметка сверяется с грамматикой.
   Меняй имя только тогда, когда два имени значат одно или одно имя значит
   разное.
5. Цитаты черновика не трогай. Остальные правила действуют как в первом
   режиме.
