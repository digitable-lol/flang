# Генетический алгоритм

`evolution.flang` выводит строку «доказано ядром» из случайных букв: популяция из
двадцати особей, отбор турниром из двух, скрещивание в одной точке с лучшей особью,
мутация каждого гена с вероятностью 1/14 и элита, которая переходит в следующее
поколение. Случайность — генератор Парка и Миллера `з → 48271·з mod (2³¹−1)`; его
состояние идёт вместе с популяцией, функции остаются чистыми.

```
bootstrap/flang run docs/examples/genetic/evolution.flang --function Опыт --args '{"зерно": 42, "поколений": 150}'
"доказано ядром — совпало знаков 14 из 14"
```

Сто пятьдесят поколений идут около 25 секунд; пятьдесят дают 10 знаков из 14, сто — 13.

## Что доказано, а что проверено примерами

Доказано ядром, 9 постусловий из 9:

* размер популяции сохраняется за поколение и за любое число поколений (индукцией
  по счётчику поколений);
* детей ровно столько, сколько прочих особей;
* пригодность элиты не убывает за поколение — утверждение записано ветвлением:
  если лучший ребёнок пригоднее элиты, новая элита строго пригоднее, иначе не хуже.

Завершение доказано у всех 27 функций; «Эволюция» завершается спуском счётчика
поколений на единицу.

Только примерами проверены: что элита — лучшая особь популяции, что пригодность
записана верно и что алгоритм сходится.

## Зерно снаружи

`seeded-run.flang` — план: просит у хозяина поручение «Случайное число» и берёт
из него зерно. Сто пятьдесят поколений не помещаются в предел шагов одного витка по
умолчанию, поэтому предел поднят:

```
bootstrap/flang io docs/examples/genetic/seeded-run.flang --max-steps 1000000000
bootstrap/flang io docs/examples/genetic/seeded-run.flang --seed 7 --max-steps 1000000000
```

С `--seed` случайность хозяина повторима. Вместо случайности можно взять время —
поручение «Текущее время».
