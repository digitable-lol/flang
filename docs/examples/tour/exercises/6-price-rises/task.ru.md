# Сколько раз подорожало

Функция `«Сколько раз подорожало»` считает, сколько раз цена выросла по
сравнению с предыдущей. Напишите её тело циклом: первую цену возьмите через
`разбор`, остальные обойдите строкой `для каждого` и храните предыдущую цену.

Готово, когда `flang check` отвечает «замечаний нет».
