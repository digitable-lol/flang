# Доказательства на теории категорий

Эта страница — спецификация того, как в flang пишется и проверяется теорема о
**всякой** категории: «для всякой категории C, всяких функторов F и G из C в D и
всякого естественного преобразования η из F в G верно …». Решение и довод —
[ADR-0121](../adr/0121-abstract-category-theorems-are-checked-as-path-equalities.md).

Категорная поверхность `flang/ct` (см. [docs/ct/spec.md](../ct/spec.md)) говорит о
**конкретных** категориях над типами программы и считает их законы на конечной
сетке. Здесь речь о другом: об утверждениях, в которых категория — переменная.
Такое утверждение не считается на сетке вовсе; его можно только доказать.

## Пример

```flang
теорема «Обратный единственен»
  для всякой категории C
  для всяких объектов А Б из C
  для всякой стрелки f из А в Б
  для всяких стрелок g h из Б в А
  дано «g обратна слева» (g после f) равно (единица А)
  дано «h обратна справа» (f после h) равно (единица Б)
  утверждаем g равно h
    g
    равно g после (единица Б) по единице
    равно g после (f после h) по «h обратна справа»
    равно (g после f) после h по ассоциативности
    равно (единица А) после h по «g обратна слева»
    равно h по единице
  следовательно доказано
```

Читается как в учебнике: левый обратный и правый обратный к одной стрелке
совпадают. Каждая строка цепочки — равенство соседних термов и закон, по которому
оно верно. Ядро проверяет каждую строку отдельно; поиска доказательства нет.

Естественность и функториальность пишутся так же:

```flang
теорема «Вертикальная композиция естественна»
  для всяких категорий C D
  для всяких функторов F G H из C в D
  для всякого естественного преобразования альфа из F в G
  для всякого естественного преобразования бета из G в H
  для всяких объектов А Б из C
  для всякой стрелки f из А в Б
  утверждаем (H от f) после ((бета на А) после (альфа на А)) равно ((бета на Б) после (альфа на Б)) после (F от f)
    (H от f) после ((бета на А) после (альфа на А))
    равно ((H от f) после (бета на А)) после (альфа на А) по ассоциативности
    равно ((бета на Б) после (G от f)) после (альфа на А) по естественности бета
    равно (бета на Б) после ((G от f) после (альфа на А)) по ассоциативности
    равно (бета на Б) после ((альфа на Б) после (F от f)) по естественности альфа
    равно ((бета на Б) после (альфа на Б)) после (F от f) по ассоциативности
  следовательно доказано
```

```flang
теорема «Функтор сохраняет обратную слева»
  для всяких категорий C D
  для всякого функтора F из C в D
  для всяких объектов А Б из C
  для всякой стрелки f из А в Б
  для всякой стрелки g из Б в А
  дано «обратна слева» (g после f) равно (единица А)
  утверждаем (F от g) после (F от f) равно единица (F от А)
    (F от g) после (F от f)
    равно F от (g после f) по функториальности F
    равно F от (единица А) по «обратна слева»
    равно единица (F от А) по функториальности F
  следовательно доказано
```

## Поверхность

### Теорема

Теорема о категориях — обычное объявление `теорема «Имя»`. Ядро отличает её по
первой строке блока: она начинается словами `для всякой`, `для всякого` или
`для всяких`. Порядок частей закреплён:

1. строки контекста `для всяк… …` — одна или больше;
2. гипотезы `дано «имя» <терм> равно <терм>` — ноль или больше;
3. цель `утверждаем <терм> равно <терм>`;
4. цепочка: первая строка — один терм, каждая следующая — `равно <терм> по <закон>`;
5. `следовательно доказано`.

### Контекст

| строка | вводит |
|---|---|
| `для всякой категории C` / `для всяких категорий C D` | категории |
| `для всякого объекта А из C` / `для всяких объектов А Б из C` | объекты категории |
| `для всякой стрелки f из А в Б` / `для всяких стрелок g h из Б в А` | стрелки; категория — та, где лежат концы |
| `для всякого функтора F из C в D` / `для всяких функторов F G из C в D` | функторы |
| `для всякого естественного преобразования t из F в G` / `для всяких естественных преобразований s t из F в G` | естественные преобразования; F и G — из одной категории в одну |

Концы стрелки и функторы преобразования — **термы**, а не только имена:
`для всякой стрелки u из (F от А) в Б` законна.

Имя вводится один раз и только одно на всё; имена — слова языка без ёлочек
(`f`, `альфа`, `C`) или имена в ёлочках (`«η»`). Греческие буквы язык пишет только
в ёлочках.

### Термы

| запись | смысл | тип |
|---|---|---|
| `f` | введённая стрелка | её концы |
| `единица А` | тождественная стрелка объекта | А → А |
| `g после f` | композиция «сначала f, потом g» | А → В при f: А → Б, g: Б → В |
| `F от f` | образ стрелки под функтором | F А → F Б |
| `F от А` | образ объекта | объект категории-цели F |
| `t на А` | компонента преобразования t: F ⇒ G | F А → G А |
| `G после F` | композиция функторов (в скобках перед `от`) | функтор |
| `единица C` | тождественный функтор категории C | функтор C → C |

`после` без скобок группируется вправо: `h после g после f` есть
`h после (g после f)`. Ассоциативность доказывается шагом, поэтому где скобки
меняются, их пишут явно.

Ядро выводит тип каждого терма. Композиция с несовпадающими концами, функтор,
применённый к стрелке чужой категории, преобразование между функторами с разными
концами — отказ с именем терма и строкой.

### Законы шага

Шаг `равно Т по <закон>` верен, если терм прошлой строки и Т связаны законом.

| закон | что сличается |
|---|---|
| `по ассоциативности` | термы равны после раскрытия скобок композиции |
| `по единице` | то же и после выбрасывания `единица А` из композиций |
| `по функториальности` / `по функториальности F` | то же и после проталкивания функтора внутрь: `F от (g после f)` → `(F от g) после (F от f)`, `F от (единица А)` → `единица (F от А)`, `(G после F) от f` → `G от (F от f)`, `(единица C) от f` → `f`; у названного функтора проверяется, что он есть в шаге |
| `по законам категории` | то же, что `по функториальности`, без имени |
| `по «имя»` | одна подстановка гипотезы или уже доказанной теоремы (в любую сторону) на отрезок композиции, в том числе под функтором |
| `по естественности t` | одна подстановка квадрата естественности: `(G от u) после (t на А)` ↔ `(t на Б) после (F от u)` для любого пути u из А в Б, в том числе под функтором |

Последние две — **ровно одна** подстановка. Цепочка из многих подстановок пишется
многими строками.

## Разрешитель равенств путей

Модуль ядра `flang/self/category-proofs.flang` («Category proofs»). К ядру он
подключён в одном месте — в «Обязательства» (`flang/self/obligations.flang`):
теорема о категориях даёт обязательство вида `category`, и его вердикт ставит
модуль. Ни одна другая функция ядра модулем не пользуется, и модуль не зовёт
сведение ядра.

### Нормальная форма

Терм стрелки приводится к **пути** — списку атомов, где атом есть приставка
функторов и основа: введённая стрелка или компонента `t на А`. Три уровня:

1. **раскрытие** — вложенные композиции становятся одним списком;
2. **без единиц** — `единица А` выпадает из списка (при этом помнятся концы:
   пустой путь — это `единица` своего объекта);
3. **полная** — функтор проталкивается к атомам: `F от` пути есть путь из
   `F от` атомов; `F от (единица А)` выпадает; `(G после F) от f` даёт приставку
   `G F`; тождественный функтор выпадает из приставки.

Каждый уровень — вычисление, а не поиск: он тотален, однозначен и проверяется
повторением.

### Подстановка

Подстановка гипотезы `Л равно П` в путь Х: найти в полной форме Х отрезок, равный
`P от Л` при какой-то приставке функторов P, и заменить его на `P от П`. Пустая Л
(гипотеза вида `единица А равно П`) вставляет `P от П` в стык пути, где стоит
объект `P от А`. Естественность — та же подстановка с гипотезой-схемой
`(G от u) после (t на А) = (t на Б) после (F от u)`, где путь u берётся из самого
отрезка.

Ядро находит место, приставку и сторону перебором по длине пути (это конечный
перебор, не поиск доказательства) и печатает их в запись: сверщику искать нечего.

### Почему проверка, а не решение

Задача «равны ли два пути в категории с гипотезами» в общем виде неразрешима
(к ней сводится задача равенства слов в полугруппе с соотношениями). Поэтому ядро
не решает её, а **проверяет** цепочку, которую написал автор: каждый шаг есть
вычисление нормальной формы или одна подстановка. Это и есть граница
состоятельности: всё, что ядро принимает, получено конечным числом законов
категории, функтора, естественности и гипотез.

## Что доверено и что проверено

| часть | кто проверяет |
|---|---|
| разбор поверхности и вывод типов термов | ядро; сверщик на C повторяет независимо, читая исходник |
| нормальная форма и подстановка | ядро; сверщик на C повторяет по записи |
| состоятельность каждого закона шага | лемма на Lean (`flang/ct/proofs/lean/Moves.lean`): если шаг принят, интерпретации термов в **любой** категории равны |
| модель категорий (`Category.lean`) | читается глазами: 117 строк, определения учебные (категория, функтор, естественное преобразование, изоморфизм, моно и эпи, терминальный и начальный объект, произведение, пулбэк, уравнитель, сопряжение, монада) |

Lean берёт три аксиомы своего ядра: `propext`, `Quot.sound` (через `funext`) и
`Classical.choice`; корпус и леммы обходятся первыми двумя.

### Запись доказательства

Блок записи на каждую теорему о категориях:

```
категорная теорема «Обратный единственен» строка 1
  вердикт доказано
  шагов 5
  шаг 1 строка 10 единица
  шаг 2 строка 11 гипотеза «h обратна справа» место 2 приставка ⟨⟩ назад
  шаг 3 строка 12 ассоциативность
  шаг 4 строка 13 гипотеза «g обратна слева» место 1 приставка ⟨⟩ вперёд
  шаг 5 строка 14 единица
конец категорной теоремы
```

Термов в записи нет: сверщик читает их в исходнике по номерам строк, как и цели
обычных теорем. Для подстановки запись даёт **место** (номер первого атома
отрезка в пути прошлой строки, с 1), **приставку** функторов и **сторону**;
для естественности ещё длину пути u: `естественность «t» место 2 длина 1 приставка ⟨F⟩ вперёд`.

### Подделки

Каждая обязана быть отвергнута с названной причиной:

| подделка | отказ |
|---|---|
| ложная коммутативность: `g после f равно f после g` по ассоциативности | `FLANG_CATEGORY_STEP` — пути разные |
| неверный порядок композиции в гипотезе | `FLANG_CATEGORY_STEP` — отрезка нет в пути |
| подмена функтора: `F от f` вместо `G от f` в шаге естественности | `FLANG_CATEGORY_STEP` |
| композиция с несовпадающими концами | `FLANG_CATEGORY_TYPE` |
| две подстановки в одном шаге | `FLANG_CATEGORY_STEP` |
| цепочка кончается не правой частью цели | `FLANG_CATEGORY_GOAL` |
| ссылка на гипотезу, которой нет | `FLANG_CATEGORY_NAME` |
| запись: место или приставка не те | сверщик: код 1 |

## Дальше

Этапы 2–5 расширяют поверхность, не трогая разрешитель:

- **универсальные свойства** — `дано терминальный объект Т в C`, произведение с
  проекциями и парой, пулбэк, уравнитель; закон `по единственности` (две стрелки в
  терминальный объект равны; две стрелки в произведение с равными проекциями
  равны); цель `существует единственная стрелка …`;
- **сокращение** — `дано m мономорфизм`, закон `по сокращению на m из «факт»`;
  цель `m мономорфизм`, доказываемая для произвольных `p q`;
- **промежуточные факты** — `затем «имя» Л равно П` со своей цепочкой;
- **изоморфизм как цель** — `утверждаем А изоморфно Б, а именно f и g`;
- **двойственность** — `двойственно к «теорема»`: теорема о C^op, разворот всех
  композиций;
- **сопряжения и монады** — единица, коединица и треугольные тождества в
  контексте; транспонирование как определённая стрелка;
- **Йонеда** — категория множеств и элементы; для предпорядков — уже сейчас
  (`flang/ct/yoneda-preorder.flang` считает её на сетке).

## Корпус

`flang/ct/proofs/corpus.tsv` — 32 теоремы от простых к средним: имя, раздел, этап,
на котором flang её докажет, ожидаемый ответ flang и законы, которые ей нужны.
`flang/ct/proofs/lean/` — версия каждой на Lean 4 над моделью `Category.lean`.
`flang/ct/proofs/programs/` — версии на flang, по мере того как этапы их
открывают.

```bash
bootstrap/flang run-script category-proofs:check
```

строит модель во временном каталоге, проверяет каждую теорему настоящим Lean
(`LEAN`, иначе `lean` из пути), каждую программу — двоичным `flang check --proof
--strict`, печатает таблицу и сверяет её с `corpus.tsv`: расхождение — код
`FLANG_CATEGORY_PROOFS`, `sorry` в файле или выводе Lean — отказ.
