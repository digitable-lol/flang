# Свойства во времени: перебор конечной модели

Решение — [ADR-0163](../../adr/0163-always-properties-of-a-finite-process-model-are-explored-to-a-bound-and-never-called-proved.md),
общий путь — [ADR-0125](../../adr/0125-properties-over-time-are-invariants-and-measures-and-finite-models-are-explored.md).
Код — `flang/concurrency/temporal/`.

## Модель

Модель — значение типа «Модель» модуля `explore.flang`: процессы с названными состояниями,
пределом ящика (0 — без предела), списком конечных состояний и правилами «в состоянии S,
получив письмо T, перейти в S′, отправить письма, остановиться или нет», плюс первые письма.
Модель пишется отдельно от программы; что программа ей следует, не проверяется.

Шаг модели повторяет образцовый планировщик (`SPEC.md`): готов живой процесс с непустым
ящиком; берётся любой готовый; он снимает голову ящика и по правилу переходит и рассылает
письма по порядку. Письмо в полный ящик останавливает отправителя, и его остальные письма
этого шага не уходят. Письмо остановленному процессу теряется и считается. Письмо, для
которого нет правила, снимается без действия.

## Свойство

Свойство — «Свойство» с именем и условием `всегда`. Условие — дерево «Условие»:

| вариант | верно, когда |
|---|---|
| «В состоянии» кто, этап | процесс стоит в названном состоянии |
| «Ящик не больше» кто, предел | в ящике не больше писем, чем предел |
| «Жив» кто | процесс не остановлен |
| «Письма доходят» кто | ни одно письмо к процессу не потеряно |
| «Не тупик» | неверно, что ни у кого из живых нет писем, а хоть один живой стоит не в конечном состоянии |
| «Не», «И», «Или» | связки |

## Перебор и вердикт

`«Перебрать» от модель и свойство и граница` обходит в ширину все порядки выбора, не
повторяя состояний, не глубже границы. Вердикт «Вердикт» — либо «Нарушено» с кратчайшим
встречным прогоном, либо «Не нарушено» с глубиной, числом состояний и признаком «целиком»
(фронт опустел раньше границы). Варианта «доказано» у вердикта нет. «Сказать вердикт» пишет
его для человека, и последняя строка исхода без нарушения — «это не доказательство».

## Запись

`«Запись вердикта»` даёт текст файла `records/*.exploration`: строки «ключ, табуляция,
значение» — `перебор`, `граница`, `свойство`, `исход`, затем либо строки `шаг` (процесс,
письмо, из, в, итог), либо `глубина`, `состояний`, `целиком`.

`«Сверить запись»` принимает запись, только если в ней нет слова «доказано», шапка совпадает
с моделью, при нарушении встречный прогон переигрывается шаг за шагом и в конце свойство
ложно, а при отсутствии нарушения перебор заново даёт те же числа.

## Проверка

```
bootstrap/flang run-script temporal:check     # все записи совпадают с перебором, сверены, подделки отвергнуты
bootstrap/flang run-script temporal:write     # переписать записи после правки модели
bootstrap/flang run-script temporal:forgery   # проба порчи: записи со словом «доказано» обязаны быть отвергнуты, код 1
```

Модели и закреплённые вердикты — `models/*.flang`; каждый вердикт стоит примером функции
«Перебор: …», поэтому `bootstrap/flang check models/<файл>` сверяет его при каждой проверке.
