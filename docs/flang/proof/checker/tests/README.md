# Имена файлов набора проб: один словарь на весь каталог

Набор проб сверщика (`flang/proof/checker/tests/`) с 22 сентября 2026 назван
по-английски — [ADR-0046](../../../../adr/0046-the-proof-directory-is-named-in-english.md),
задача [6421](../../../../tasks/completed/6421-the-proof-directory-needs-a-layout-and-a-naming-rule.md),
порция 2. Проза внутри файлов, язык самого flang и сообщения сверщика остались
русскими: судится ИМЯ ФАЙЛА, а не текст.

Этот файл держит словарь. Он нужен ровно затем, чтобы **одно русское понятие
звалось одним английским словом во всём каталоге**: без словаря «цель» назовут
то `goal`, то `target`, то `aim`, и по имени файла перестанет быть видно, о чём
проба. Заводишь новую пробу — берёшь слово отсюда; нет нужного — дописываешь
строку сюда И в `scripts/ledgers/file-name-words.txt` вместе с файлом.

## Метки правил и ячеек — не слова, а опознаватели

В именах стоят короткие метки: `e5-not-listed`, `t2-other-list`, `ch4-common-prefix`,
`o9-count`, `p01-foreign-variant-name`, `z7-exists-such-that`, `f10k-existence-with-a-witness`,
`k3c-move-by-substitution`, `unfold2-itself`, `repr-call`. Это **идентификаторы**,
а не транслит слов, и читаются так:

| метка | откуда | чему отвечает |
|---|---|---|
| `e<N>` | Э — `flang/proof/tables/inference-rules.tsv` | правило семейства «все элементы по построению» |
| `t<N>` | Т — та же ведомость | «цель есть допущение» |
| `o<N>` | О — та же ведомость | «порядок по построению» |
| `ch<N>` | Ч — та же ведомость | «начало по построению» |
| `finite<N>` | Кон — та же ведомость | «конечность оговоркой» |
| `repr` | Пред — та же ведомость | «представимость» |
| `unfold<N>` | Разв — та же ведомость | развёртка плоского определения |
| `p<NN>` | П | номер ПОРЧИ (мутанта) внутри набора; у `list-body-by-contents` — `f<N>`, как было |
| `z<N>` | З | строка матрицы ADR-0026 |
| `f<NN>` | Ф | форма записи из той же матрицы |
| `k<N><буква>` | К | ячейка кластера 6202/6203 (`k2b`, `k3c`, `k3cb`, `k3cv`) |

Буква семейства берётся из ведомости правил вывода, а не переводится: правило
«Э5» в прозе и `e5-…` в имени — одно и то же место.

## Что этим словарём НЕ решается

* **`records/corpus/` не переименован.** Имена его записей зеркалят имена
  исходников (`flang/test/fixtures/poddelka-dlina.flang` ↔
  `corpus/poddelka-dlina.record`), а исходники лежат ВНЕ `flang/proof` и под эту
  задачу не попадают. Транслит там остаётся до переименования самих фикстур —
  это долг задачи 1428, названный, а не забытый.
* **`run-induction/letters.фп`** держит кириллическое расширение нарочно: это
  единственный живой образец расширения `.фп` в дереве, и на него смотрит
  `scripts/guards/file-extensions.fscript` (задача 1415).
* **Комментарии внутри `*.flang` под `flang/proof`** и внутри `flang/self`
  называют старые имена. Их правка отвергает привязанную запись кодом 1
  (измерено на `abilities.record`), а правка `flang/self` требует перепечатки
  семени. Долг назван в [ADR-0046](../../../../adr/0046-the-proof-directory-is-named-in-english.md).
