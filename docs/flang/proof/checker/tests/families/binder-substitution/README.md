# Подстановка под связывателем и одноимённые `пусть`: пять ложных утверждений

Ходы `замена`, `деление` (обе формы), `нейтральный ноль`, `подставить пусть` и
`закрыть по свойству` фактом-равенством ставят в цель значение, верное при текущих значениях имён: равенство
из допущения, значение условия, посылку `таких что`, факт с оплаченным требованием. Под
связывателем (`пусть`, `разбор`, `свёртка`, `отобразить`, `отфильтровать`, `случай`,
`для всех`, `существует`) то же имя значит другое, и такая подстановка ложна. Оба
сверщика отвечают на такой ход «не взялся» (ADR-0202).

| программа | ложное утверждение | вход, на котором ложно | ходы записи |
|---|---|---|---|
| `neutral-zero.flang` | `(отобразить ряд как н → н плюс 0) равен (отобразить ряд как н → н)` при `н больше 0` | `ряд = [−0]` | `нейтральный ноль ⟨н плюс 0⟩`, `закрыть тождеством` |
| `split.flang` | `(отображение равно всем 1) или (отображение равно всем 0)` для `если э то 1 иначе 0` | `р = [да, нет]` | `деление ⟨э⟩`, `связка ⟨или⟩`, `выбор`, `закрыть тождеством` |
| `let-under-binder.flang` | «Каждому пять»: результат равен `отобразить элементы как сколько → 5` при `пусть сколько равно 5` | `элементы = [1]` | `подставить пусть` под `отобразить`, `закрыть тождеством` |
| `let-twice.flang` | «Почти всегда один»: результат равен `1` при двух `пусть сколько` | `порог = 12345.678` | `подставить пусть` по первому из двух `пусть сколько`, `закрыть тождеством` |
| `modus-ponens.flang` | постусловие «Срез каждого»: результат равен `отобразить ряд как н → н` | `н = 1`, `ряд = [−0]` | `факт по свойству` (верен при `н больше 0`), `закрыть по свойству` |

Записи — записи ядра этих программ с вердиктом `доказано` и ходами, дописанными рукой;
у вспомогательного утверждения «срез положительного есть оно само» ходы честные.
`подставить пусть` берётся ещё и только тогда, когда у имени в функции одно
связывание `пусть`: при двух ход не говорит, какое из них значит имя в цели.

Без этих проверок оба сверщика приняли бы все пять записей кодом 0, то есть ложное
утверждение — доказанным. С проверками каждая получает код 3: «под связывателем»,
у второй записи о `пусть` — «связываний 2».
