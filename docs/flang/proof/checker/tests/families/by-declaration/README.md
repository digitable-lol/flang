# Семья «по-объявлению»: места «по объявлению» переигрываются печатью ядра

Задача [9616](../../../../../../tasks/9616-the-kernel-computes-the-evidence-and-the-record-drops-it.md),
основание — [ADR-0022](../../../../../../adr/0022-a-type-fact-travels-as-a-derivation.md)
(факт о типе едет выводом) и [ADR-0027](../../../../../../adr/0027-case-analysis-prints-as-a-derivation-and-is-replayed.md)
(разбор случаев печатается выводом и переигрывается сличением). Строки ведомости
`Кон2`, `Ч5`, `Разв1` уже стояли в `flang/proof/tables/inference-rules.tsv` с леммами в
`flang/proof/lean/Rules.lean`; новых правил семья не заводит. Ловушка 15
(`Trap.lean`) — ветвь звена у Разв1 подменена ветвью «пусто»; для Ч5 стоит
ловушка 8, для Кон2 — та же лемма, что у Кон3.

## Что стережётся

Двенадцать мест корпуса стояли на слове ядра с одной причиной — «сверщик не
повторяет изъятие объявленного типа». Шесть из них закрыты здесь, и закрыты не
именем правила (см. «Чего делать НЕЛЬЗЯ» в задаче), а ПЕЧАТЬЮ ядра, которую
сверщик переигрывает шаг за шагом:

| форма | место корпуса | что печатает ядро | что сличает сверщик |
|---|---|---|---|
| оговорка «пока это число» — `не ((Т минус Т) равен 0) или Ц` | `poddelka-order-arithmetic` «икс не больше икса, пока это число» | `ГипО ⟨( х минус х ) равен 0⟩ сам` → `Кон3 ⟨х : кон⟩` → `О2` → `Разв2` → `Кон2 ⟨цель⟩ из 1 4` | Кон2 — снятие гипотезы оговорки: левый дизъюнкт есть «не ( ( Т минус Т ) равен 0 )» с одним Т знак в знак, правый — суть, выведенная под этой гипотезой и ни под чем больше (зеркало Р1 для второй записи той же охраны) |
| точный текст начинается точной приставкой | `nachalo-po-postroeniyu-chestnaya` «склейка начинается со звёздочки и двойки» | `Ч5 ⟨( соединить "*" с ( к строке ( длина [первый, второй] ) ) ) начинается с "*2"⟩ сам` → `Разв2` | обе стороны собираются знаками по закрытой грамматике (литерал, склейка точных, «к строке» от литерала-числа либо длины выписанного списка) и начало сличается; имя, вызов, ветвь — отказ поимённо |
| разбор выписанного списка | `poddelka-razbor-spiska` — три места: пусто, голова, хвост | `Выч ⟨…⟩ сам` → `Разв1 ⟨цель⟩ из 1 строка N` | строка N — строка «разбор Л» своей функции, Л выписан; ветвь — числом написанных членов; голова := первый член, хвост := список остальных; заключение — посылка с ветвью на месте «результат», как у Разв2 |
| прибавка-имя у О6 и О5 — «Е не больше ( Е плюс Б )», «( Ш плюс Е ) не больше ( Ш плюс Г )» | `poddelka-order-arithmetic` «а не больше суммы», «б не больше суммы», «прибавление общего сохраняет порядок»; `order` П3 «не убывает» | `Н3 ⟨Б не меньше 0⟩` → `Пред1 ⟨Б помещается⟩` → `П3 ⟨Б не больше 9007199254740991⟩` → `О6 ⟨…⟩ из N M K` (у О5 — порядок из гипотезы охраны); под оговоркой — после Кон3 и О2 | посылки «из N M K»: шаг N — порядок, M — «Б не меньше Д», K — «Б не больше В», Д и В целые литералы: прибавка — число в [Д, В], неотрицательное и конечное (Lean «отрезок-числом»); строка обязательства входа печатается сама из шага Пред1 |
| тело в несколько строк «если У / то А / иначе / Б» | `poddelka-razbor-vnutrennim` «либо само число, либо одна из границ» | ходы: `развернуть … строка 45 ⟨если … иначе (если …)⟩`, два `деление`, `выбор`, `связка`, `закрыть тождеством` | строки от строки развёртки до конца блока функции собираются той же дорогой, что тело случая, и сличаются с записанным термом без скобок |

Записи — ПЕЧАТЬ ЯДРА, снятая толкованием исходников `flang/self` семенем 0.7.19
(зонд `flang/self/bootstrap/zond-k7.flang`, 684–1031 с и до 30 ГиБ на
программу): семя правок `zapis.flang` не несёт, они доедут до двоичного
перепечаткой.

**В корпус эти записи не положены.** Корпус обязан быть печатью семени байт в
байт — это стережёт `sh flang/proof/corpus-share.sh --вложенность` на каждом
пуше, и две записи шага А, положенные в корпус, покрасили его в PR #21
(«РАЗОШЛАСЬ» ×2). Путь тот же, что у 6205: печать ядра живёт здесь пробой, а в
корпус ложится перепечаткой партии. Доля «после перепечатки» мерится тем же
прибором на отдельном дереве, где в корпус подложены эти четыре записи, — число
в задаче 9616.

## Чего семья НЕ закрывает

Пять мест класса «по объявлению» остались на слове ядра, и у каждого причина
своя, а не Тожд1 (перестановка соседей), как значилось в задаче: у трёх
`тождество после переписки допущением` — это длина свёртки, растущей ровно на
один (`abilities` У3, `poddelka-svyortka-shagom`), развёртка вызванных плоских
функций с проекцией поля (`equality` Р1) и разбор конструктора варианта в самой
цели (`types` Т1); у `poddelka-strict-order` — переписка длины «добавить».
Правил ведомости на них нет. Из шести мест «снято калькулятором» не закрыты
три: противоречие пары допущений (`abilities` У23, `poddelka-protivorechie` —
семейства в ведомости нет) и свёртка-признак `sources` К1. Разбор — в задаче 9616.
