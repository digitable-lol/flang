# Семья «носитель»: носитель индукции читается с объявления типа

Основание — [ADR-0026](../../../../../../adr/0026-quantifiers-over-any-type-are-a-kernel-change.md)
§2.4 и §5 шаг 1.

## Что делает сверщик

Носитель индукции (`algebra`, `segment`, `fold`) сверщик не берёт на слово
записи, а выводит из объявления довода индукции. `объявление_типа` в `checker.c`
читает его с ИСХОДНИКА: `тип «Т»` с `вариант …` — сумма; `объект «Т»` — запись;
`список`/`строка` — встроенные суммы; `тип «Т» это Х` — псевдоним, по цепочке; имя
из списка `НАТУРАЛЬНОЕ[]` — встроенный отрезок. Носитель обязан из объявления
следовать (единственная точка — `сверить_покрытие`): `segment` над доводом типа
`число` — код 1, а не уход на слово ядра. Список имён отрезка объявлен таблицей
`flang/proof/tables/segments.tsv` и сверяется с ядром и сверщиком сторожем С-5
(`flang/proof/tables-guard.fscript`).

## Что здесь лежит

| файл | класс | код | что стережёт |
|---|---|---:|---|
| `name-natural.{flang,record}` | честная | 0 | `if-over-a-segment` с заменой `неотрицательное` → `натуральное`: синоним имени отрезка |
| `alias-segment.{flang,record}` | честная | 0 | `тип «Возраст» это неотрицательное` под `segment` |
| `number-segment.flang` + `flang/proof/checker/tests/records/corpus/poddelka-nositel-chislo-segment.record` | подделка (набор, «лжёт-запись») | 1 | `segment` над доводом `число` — П1 |
| `alias-not-a-segment.flang` + `flang/proof/checker/tests/records/corpus/poddelka-nositel-psevdonim-ne-otrezok.record` | подделка (набор, «лжёт-запись») | 1 | `segment` над `тип «Мера» это число` — З2 |
| `corrupt/number-segment-lie-about-the-type.record` (к `number-segment.flang`) | подделка | 1 | запись говорит `тип «неотрицательное»`, довод объявлен `число` — П1б |
| порчей одной строки в прогоне | подделки | 1 | слово вне трёх (П2); `algebra` над отрезком |
| `list-of-numbers.{flang,record}` | честная | 0 | `для всех л обеспечивает …` при `л: список числа`, теорема `индукция по л`: печать ядра — `принцип … носитель algebra` + `объявление встроенный «список» варианты «пусто» 0 «голова и хвост» 1` |

Подделки дописывают к честной шапке принцип и две посылки; шапки записей
посчитаны по файлу и сверены с шапками, напечатанными ядром, — знак в знак.

## Чего здесь нет

Записи «объект как сумма с одним конструктором» и строки `объявление` у записи
(`объект`): ядро принципа по объекту не печатает.
