# Семья «звено разбора» — предусловие о списке на голове и хвосте

Решение — [ADR-0175](../../../../../../adr/0175-a-list-precondition-passes-to-the-head-and-tail-and-a-list-includes-itself.md).
Код — `flang/proof/checker/tests/families/case-link/`.

Функция с `требует «все положительны» для всех э из элементы: э больше 0` зовёт себя от
`хвост` и функцию с `требует х больше 0` от `голова` внутри ветви `случай голова и хвост`
разбора `разбор элементы`. Ядро снимает оба места, а запись печатает вывод:

```
    вывод цель ⟨для всех э из хвост : э больше 0⟩
    вывод 1 Т1 ⟨для всех э из элементы : э больше 0⟩ строка 15
    вывод 2 Зв0 ⟨элементы равен приписать голова к хвост⟩ строка 23
    вывод 3 Зв1 ⟨для всех э из хвост : э больше 0⟩ из 1 2
    вывод конец
```

Звено (Зв0) сверщики берут только в снятии и только когда вызов стоит в ветви этого
случая; затем Зв1 переносит свойство на хвост, Зв2 — на голову.

## Откуда запись

`case-link.record` — печать ядра, снятая двоичным, собранным из исходников `flang/self`
этой ветки (печать без ядра доказательств, `emit --no-check`, только для пробы).

## Что здесь лежит

| файл или правка | класс | код | что стережёт |
|---|---|---:|---|
| `case-link.{flang,record}` | честная | 0 | хвост (Зв1) и голова (Зв2) по звену разбора |
| правка: Зв0 указывает на строку `случай пусто` | подделка | 1 | основание звена — случай «голова и хвост» |
| правка: Зв1 заключает свойство о голове вместо хвоста | подделка | 1 | из звена следует свойство хвоста, а не любого имени |
| правка: Зв2 заключает свойство хвоста как числа | подделка | 1 | голова подставляется на место элемента |
| правка: в Зв0 голова и хвост переставлены | подделка | 1 | равенство звена читается со строки случая |
| правка: Зв0 опирается на строку другой функции | подделка | 1 | строка случая стоит в функции вызова |

## Чего здесь нет

Вложенный разбор с именованными частями (`случай голова г и хвост х`) ядро снимает, но
оба сверщика оставляют место на слове ядра: имя цели `г2` связано в теле функции раньше
вызова, а такую цель сверщики не строят (сторож «связано в теле»). Части в ёлочках
(`«г»`) звеном не берутся вовсе: второй сверщик читает их вызовом функции.
