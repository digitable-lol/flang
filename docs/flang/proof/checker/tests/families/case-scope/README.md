# Границы случая: где сверщик ищет ветвь варианта

Семья проб на записи, у которых посылка индукции по варианту сводится по ветви тела
функции. Сверщик берёт ветвь только из разбора, которым тело функции начинается, и
только на глубине его собственных случаев: случай с тем же вариантом в ветви `если`
или во вложенном разборе считает другое значение. Имя разбора сличается с переменной
индукции знак в знак или как склонение этого имени, если другого похожего довода у
функции нет.

Посылка, закрытая шагами автора (`закрыта term` с пустым правилом), принимается
только тогда, когда в записи стоит случай теоремы на этот вариант или случай `любое`.
Строка случая теоремы у утверждения с `теоремы нет` — ложь записи.

## Пробы

| файл | что | код |
|---|---|---|
| `case-in-a-branch-of-if.flang` | тело — `если`, оба разбора лежат в его ветвях; в ветви `иначе` результат −4 | 3 |
| `nested-case-found-first.flang` | вложенный разбор в ветви `«Ноль»` несёт случай `«Минус»` раньше настоящего; у `«Минус»` результат −1 | 1 |
| `premise-closed-by-absent-steps.flang` | посылка `«Ноль»` закрыта шагами автора, теоремы нет, ветвь даёт −5 | 1 |
| `theorem-case-without-a-theorem.flang` | то же, и запись приписала случай теоремы строке тела функции | 1 |
| `premise-closed-by-a-theorem-case.flang` | честная: посылка `«Ноль»` закрыта случаем теоремы по примеру | 0 |

Все четыре подделки говорят ложь: постусловие «результат не меньше 0» нарушено на
названном входе.
