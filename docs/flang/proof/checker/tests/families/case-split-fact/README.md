# Семья «деление цели с фактом условия» — Р8 и Отр1

Решение — [ADR-0186](../../../../../../adr/0186-a-case-split-on-a-condition-prints-its-halves-under-the-condition.md).
Код — `flang/proof/checker/tests/families/case-split-fact/`.

`«Большее»` отдаёт `если а больше б то а иначе б` и обещает `результат не меньше а`.
Половина «да» — `а не меньше а` (О2 над объявлением `неотрицательное`), половина «нет» —
`б не меньше а`, и она верна только потому, что `а больше б` ложно: гипотеза
`не ( а больше б )` и Отр1 со свидетелями обеих сторон. Р8 снимает обе гипотезы.

## Откуда запись

`bigger.record` — печать ядра, снятая толкованием исходников `flang/self` этой ветки
семенем (зонд `flang/self/bootstrap/check-with-source-compiler.flang`).
