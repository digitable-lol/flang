# Разбор с фактами: связанные атомы, разбор по случаям, строки, длины, вызовы

Семья проб для утверждений без теоремы, которые ядро закрывает правилами разбора цели
без записанных ходов. Сверщик повторяет разбор по исходнику сам; эта семья держит то, что
он при этом знает сверх подстановки атома литералом.

## Что сверщик делает сам

1. **Атом деления — факт половины.** В половине, где атом истинен, истинное отношение
   решает связанные атомы на тех же сторонах и против литералов: `з равен 61` делает
   `з равен 58` ложным, `н меньше 0` делает `н не меньше 0` ложным, а `н меньше 1`
   истинным. Из ложного порядка не следует ничего: у «не числа» ложны все четыре
   порядка. Истинное равенство со значением или с именем переписывает сторону.
   Факт остаётся при всех половинах ниже и решает атомы, появившиеся после свёртки
   выбора или развёртки вызова. Числа-литералы — только целые не больше 2⁵³ по
   модулю. Внутрь `( разбор … )` факт не заходит: разбор для него — один лист, и
   факт доходит до тела случая, когда разбор уже снят.
2. **Разбор по случаям.** Тело `разбор S` собирается термом, где тело каждого случая
   стоит в скобках. Выписанное значение S выбирает случай; иначе цель делится по
   случаям, и случаи обязаны покрыть все значения: образец `любое`, пара `пусто` и
   `голова и хвост` либо все варианты типа, объявленного в исходнике. S встаёт
   конструктором образца, только когда образец называет все поля варианта в порядке
   объявления разными именами; в позднем случае метки ранних исключены. Имя образца
   не вправе встречаться в цели вне разбора, в S, в фактах половины и в разборах
   внутри случая, куда встаёт конструктор.
3. **Строки.** Внутри строкового литерала знаки, кроме букв и цифр, переписываются
   экранированием `\uXXXX`; текстовые приёмы внутрь литерала не попадают.
4. **Счёт длин.** Отношение сумм и разностей мер `длина Х` и чисел решает знак
   разности: мера — целое неотрицательное конечное. Листьев в сумме не больше 16,
   число и посчитанная мера — целые не больше 2⁴⁸: тогда каждая промежуточная сумма
   меньше 2⁵³, и округление её не двигает. Законов меры (длина прибавления,
   склейки) здесь нет: ∀-закон о длине остаётся ходам ядра, его стережёт ловушка
   `forall-length-after-append`.
5. **Вычислитель.** `или` режет терм раньше `и притом`, обе — раньше отношений;
   `элемент` и `символ` считаются только внутри длины.
6. **Развёртка вызова и факты.** Незакрытая половина пробует ещё раз с вызовами,
   развёрнутыми в тело (не больше двух раз подряд); довод не вправе нести имя,
   которое образец разбора в теле связывает. Цели, которую тело не закрыло, даются
   `требует` функции и постусловия вызванных, уже проигранные сверщиком; они стоят
   фактами половины с самого начала и входят в тело случая, когда разбор снят.

Ложная цель ни одним из шагов не закрывается: место остаётся на слове ядра (код 3).
У каждого шага — теорема в `flang/proof/lean/Half.lean` (страница
`docs/lean-checks-the-inference-rules.md`, раздел «Ходы половины»).
