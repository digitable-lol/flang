# Семья «категория»: теорема о всякой категории (ADR-0130)

Исходник — обычная `теорема «И»`, первая строка блока которой начинается словами
`для всякой`, `для всякого` или `для всяких`:

```
теорема «Обратный единственен»
  для всякой категории C
  для всяких объектов А Б из C
  для всякой стрелки f из А в Б
  для всяких стрелок g h из Б в А
  дано «g обратна слева» (g после f) равно (единица А)
  дано «h обратна справа» (f после h) равно (единица Б)
  утверждаем g равно h
    g
    равно g после (единица Б) по единице
    равно g после (f после h) по «h обратна справа»
    …
  следовательно доказано
```

Запись — блок `категорная теорема «И» строка N` после блоков тотальности
(`docs/flang/proof/record-format.md`, §5а): вердикт, число шагов и на каждую
строку цепочки — закон; у подстановки гипотезы ещё место, приставка функторов и
сторона, у квадрата естественности — место, длина пути и приставка.

## Что сверяет сверщик

`сверить_категорную_теорему` (`checker.c`) и `«Категории».«судить»`
(`second/Category.lean`) читают теорему в исходнике заново и ничего не берут из
записи, кроме закона шага:

1. заголовок стоит на строке N, и это теорема о категориях;
2. контекст: категории, объекты, стрелки (концы — объекты одной категории),
   функторы, естественные преобразования (функторы с одними концами); имя — одно на
   всё;
3. гипотезы и цель — равенства термов с одинаковыми концами;
4. цепочка начинается левой частью цели, кончается правой, и стоит
   «следовательно доказано»;
5. строк `шаг` столько же, сколько строк `равно … по …`, и каждая стоит на своей
   строке исходника;
6. каждый шаг: закон записи совпадает с законом исходника, терм шага имеет концы
   цели, и закон держится — равенство нормальных форм (раскрытие, без единиц,
   полная) либо одна названная подстановка, построенная сверщиком по месту,
   приставке и стороне и сличённая с термом шага;
7. каждой теореме о категориях исходника отвечает ровно один блок.

Блок с вердиктом `отвергнуто` сверяется только по форме и доказанным не числится.

## Что здесь лежит

| файл | что это |
|---|---|
| `stage-one.flang` | десять теорем: композиция функторов (композиция и единица), тождественный функтор, единственность обратного, композиция изоморфизмов (две стороны), функтор сохраняет обратную, вертикальная композиция, склейка квадратов, горизонтальная композиция |
| `stage-one.record` | печать ядра этого исходника, снятая толкованием исходников `flang/self` (`check-with-source-compiler.flang`) |
| `forgeries.flang` | восемь подделок для ядра: ложная коммутативность, гипотеза в обратном порядке, подмена преобразования, подмена функтора, две подстановки за шаг, цепочка не дошла, нет такой гипотезы, концы не сходятся |
| `forgeries.record` | печать ядра подделок: каждая с вердиктом `отвергнуто` |

Подделки записи порождаются в `tests/probes.tsv` правкой одной строки честной
записи: чужое место, чужая приставка, чужая сторона, чужой закон, шаг не на своей
строке, выброшенный шаг, выброшенный блок.
