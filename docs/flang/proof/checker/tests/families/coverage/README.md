# Семья «покрытие»: места, которые сверщик переигрывает по телу функции

Здесь собраны места, которые сверщик проигрывает сам — крюком по телу функции
или шагом записи, названным по строке ведомости правил, — без нового правила
ведомости. Каждый приём ниже: что он берёт, честные пробы и подделки. Подделка с
пометкой «никогда не 0» получает код 3: место остаётся на слове ядра, и любой
сверщик, который принял бы её кодом 0, сломан.

## Прямая теорема «по предположению»

Прямая теорема (без «индукция по») с целью «результат не меньше 0» и единственным
шагом «по предположению» верна ровно тогда, когда тело функции неотрицательно по
построению при её предусловиях (`требует «…» Т не меньше К`): других допущений у
прямой теоремы нет. Сверщик это проигрывает (`прямая_по_предположению` в
`сверить_шаги`) тем же `неотрицательно_algebra`, что у узла `algebra`: литерал,
«длина», допущение `требует` (правило Н2), «плюс» (Н5), обе ветви «если», один шаг
развёртки плоской функции, произведение на положительный литерал (Н8, ниже).
Не сошлось — шаг на слове ядра.

| файл | класс | код | что это |
|---|---|---:|---|
| `body-not-nonnegative.{flang,record}` | подделка (никогда не 0) | 3 | тело `н минус 1` (при н = 0 даёт −1); запись — запись корпуса с пересчитанной шапкой. Копия сверщика, у которой проверка тела всегда «да», принимает её кодом 0 |

## «По примеру» с целью-свёрткой — не берётся

«По примеру» с целью-свёрткой требует от вычислителя сверщика отбора списков и
трёх слоёв функций-помощников, а разложение строк с нулевым знаком — ещё и строк
с нулём. Это второй вычислитель языка внутри сверщика; такие места остаются на
слове ядра с названной причиной.

Причина называется в самом отказе (`ПРИЧИНА_СЧЁТА` в `checker.c`): вычислитель
ставит её там, где сдаётся по решению, — на `отфильтровать … где …` и на
разложении строки с нулевым знаком, — и «вид цели … сверщику незнаком»
дописывает её через тире. Проба в прогоне ждёт код 3 и подстроку причины; копия
сверщика, которая причину не ставит, её роняет.

## Охрана и выбор с тем же условием

Постусловие «при положительном пороге ноль или один» — цель-охрана
`если порог больше 0 то (результат равен 0) или (результат равен 1) иначе да`,
а тело каждого случая — `(если порог больше 0 то К иначе 5)`. Если в цели стоит
выбор с ТЕМ ЖЕ условием, что у охраны, условие это под охраной есть «да» (Р1 и
гипотеза ГипО; Р3 — внутреннее условие совпало с внешним, хода нет), и замкнутую
цель закрывает Выч (`половина_закрыта`). Меняется только условие выбора знак в
знак (`если У то`), а не всякое вхождение текста У; связыватель в цели — отказ.
Правила Р1, ГипО, Р3, Выч в ведомости уже есть.

| файл | класс | код | что это |
|---|---|---:|---|
| `guard-same-condition.{flang,record}` | честная | 0 | функция «Порог под разбором»; запись — её блоки из записи корпуса, строки перенумерованы, шапка пересчитана |
| `guard-false-conclusion.{flang,record}` | подделка (никогда не 0) | 3 | ветвь «голова и хвост» даёт 2 — обещание ложно. Копия сверщика без замыкания (`половина_закрыта` → «да») принимает её кодом 0 |
| `guard-other-threshold.{flang,record}` | подделка (никогда не 0) | 3 | внутреннее условие `порог больше 1` — не охрана (при пороге 0,5 выходит 5). Отвергает её сличение условия знак в знак; довод здесь — пара «честная 0 / эта 3», отличающаяся одним условием |

Условие «связыватель в цели — отказ» — страховка: ни одна проба его не роняет.

## Произведение на положительный литерал (Н8)

`неотрицательно_algebra` берёт «А умножить на К» (и «К умножить на А») при
выписанном К в (0, 2⁵³−1] — правило Н8, второй способ: К не ноль и конечно,
значит «0 умножить на +∞» исключено; А — той же грамматикой.

|---|---|---:|---|
| `double-literal.{flang,record}` | честная | 0 | «Удвоить» с теоремой |
| `double-by-zero.{flang,record}` | подделка (никогда не 0) | 3 | тело «н умножить на 0»: при н = +∞ не число. Копия, берущая и ноль, — 0 |
| `double-factor-minus.{flang,record}` | подделка (никогда не 0) | 3 | тело «(н минус 5) умножить на 2»: при н = 0 выходит −10. Копия без проверки другого сомножителя — 0 |

## Свёртка под длиной (О9) по телу функции

Постусловие «результат не больше (длина Л)» без теоремы и без блока вывода (в записи
только имя правила) сверщик выводит сам по телу (`свёртка_не_длиннее`, строка О9
таблицы): тело «свёртка Л начиная с 0 как А и Э → Ш», Л в свёртке и под «длина» знак в
знак, А и Э — различные имена, Ш — «А», «А плюс К» при целом К не больше 1 или выбор из
двух таких (условие не читается). Это индукция по списку — база ноль, шаг прибавляет к
мере не больше единицы: структурный узел, вычислитель не зовётся. Место считается
узлом («разбором по случаям»), как у algebra. Зовётся ПОСЛЕ разбора цели — снятое им не
меняет породы.

|---|---|---:|---|
| `o9-count.{flang,record}` | честная | 0 | «Считать единицы»: свёртка с шагом «если … то акк плюс 1 иначе акк» |
| `o9-step-two.{flang,record}` | подделка (никогда не 0) | 3 | шаг «акк плюс 2». Копия без предела единицы — 0 |
| `o9-fold-start-one.{flang,record}` | подделка (никогда не 0) | 3 | начало 1: на пустом списке 1 больше 0. Копия без проверки нуля — 0 |
| `o9-foreign-list.{flang,record}` | подделка (никогда не 0) | 3 | свёртка по «другие», а под «длина» — «элементы». Копия без сличения списков — 0 |

## Н6 и О9 именем в блоке «вывод»

Те же правила могут приехать в записи ШАГОМ, названным по имени строки ведомости, —
и сверщик переигрывает саму формулировку, а не соглашается с именем.

**Н6** (`семейство_н`) — копара двух ветвей выбора, `[⟨1⟩,⟨2⟩] : Г×У + Г×¬У → Неотр`:
заключение «( если У то А иначе Б ) не меньше 0», посылка ⟨1⟩ — «А не меньше 0», ⟨2⟩ —
«Б не меньше 0», основание «из N M». Условие У не читается ни знаком — правилу оно
безразлично, обе ветви неотрицательны. Ветвей ровно две: вложенный выбор `выбор_вывода`
не берёт, и второй посылке было бы нечего покрывать.

**О9** (`семейство_о`) — свёртка под длиной, лист («сам»): обе «посылки» колонки 5
ведомости («начало свёртки есть НОЛЬ», «шаг прибавляет к мере не больше единицы») суть
сличения формы, подвыводов у них нет — опираться шагу не на что. Побочные ведомости
проверяются все четыре: «длина» РОВНО от одного довода, имена накопителя и элемента
непусты и различны, список свёртки совпадает с доводом длины знак в знак; левой
стороной берётся и голая свёртка, и «длина ( свёртка … )».

Форму О9 судит ОДНА функция `свёртка_под_длиной` — и крюк по телу, и шаг записи:
разойтись им нечем. Счёт по Н7 и предел О9 — одна функция `ветвь_счёта`, предел
прибавки у неё — довод.

| файл | класс | код | что это |
|---|---|---:|---|
| `n6-choice.{flang,record}` | честная | 0 | «Больший из двух»: Н3 + Н3 → Н6 → Разв2. Шапку напечатало ядро, блок «вывод» дописан руками |
| `o9-derivation.{flang,record}` | честная | 0 | «Считать чётные»: О9 сам → Разв2. Шапку напечатало ядро, блок «вывод» дописан руками |

Подделки — правки ОДНОЙ строки честной записи прямо в прогоне: программа
честна, лжёт запись, и каждой назван свой отказ подстрокой. Их девять: у Н6 — обе
посылки о ветви «то», посылки крест-накрест, имя над суммой вместо выбора, лист «сам»
вместо двух посылок; у О9 — начало свёртки не ноль, шаг «акк плюс 2», длина другого
списка, совпавшие имена накопителя и элемента, опора на строку вместо листа.

## Начало строки от вызванной (Ч6)

Постусловие «результат начинается с П» без теоремы и без блока вывода сверщик
проигрывает сам (`начало_от_вызванной`, строка Ч6 таблицы): тело — ровно один вызов
«F» от имён доводов, у F нет «требует», её постусловие «результат начинается с Б»
ПРОВЕРЕНО (реестр `доказанные_свойства`, тот же, что у хода «факт по свойству»),
и Б начинается с П — сличение двух написанных литералов, не счёт. Т ▷ Б и Б ▷ П
дают Т ▷ П. Место считается проигранным сведением. Зовётся после разбора цели и
после О9.

| файл | класс | код | что это |
|---|---|---:|---|
| `ch6-prefix.{flang,record}` | честная | 0 | «Обещает длинную приставку» и «Приставка приставки взята» |
| `ch6-foreign-prefix.{flang,record}` | подделка (никогда не 0) | 3 | цель «начинается с "аг"», а вызванная обещает "абв". Копия без сличения приставок — 0 |
| `ch6-fact-without-verdict.{flang,record}` | подделка (никогда не 0) | 3 | у вызванной «вердикт нет вердикта» — её факта в реестре нет. Копия без реестра — 0 |

Подделка «у вызванной стёрты ходы» для реестра не годится: без ходов её «начинается
с "абв"» закрывает разбор цели вычислением, и факт всё равно попадает в реестр.

## Начало строки по телу (Ч1, Ч3, Ч4)

Постусловие «результат начинается с П» (П — строковый литерал) без теоремы и без
блока вывода сверщик проигрывает сам (`начало_по_телу`), когда тело без вызовов
(`плоское_тело`: многострочное «если» склеено) начинается с П по построению: сам П
или литерал с началом П (Ч1; сличение двух написанных литералов), «соединить Л с Р»
при Л ▷ П (Ч3; Р не читается), «если У то А иначе Б» при А ▷ П и Б ▷ П (Ч4; У не
читается). Место считается проигранным сведением. Зовётся после разбора цели, О9 и
Ч6; снятое Ч6 второй раз не снимается. «Склейка начинается со «*2»» не берётся:
«"*"» не начинается с «"*2"», а счёт длины списка — второй вычислитель.

## «Результат не меньше 0» без теоремы

Постусловие «результат не меньше 0» без теоремы и без блока вывода сверщик берёт сам,
если тело неотрицательно по построению той же грамматикой, что у узла algebra и у
прямой теоремы (`прямая_по_предположению`): Н2 из «требует», Н4, Н5, Н8
(произведение на литерал) и свёртка-счёт по Н7 в `неотрицательно_algebra`: начало
неотрицательно той же грамматикой, накопитель и элемент — различные имена, шаг —
счёт по форме (`шаг_счёта`: накопитель, накопитель плюс неотрицательный литерал или
выбор из двух таких). Свёртка разбирается РАНЬШЕ «если» и «плюс»: её хвост тянется
до конца терма. Место считается узлом, как у algebra. Крюк держит такие места и
тогда, когда ядро не печатает под ними блока вывода.
