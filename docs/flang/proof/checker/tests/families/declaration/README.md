# Семья «объявление»: строка `объявление` под принципом

Ядро печатает под каждой строкой
`принцип тип «Т» по «п» носитель X база Б шаг Ш` ещё одну строку — объявление
типа довода индукции:

```
  объявление <откуда> варианты «В» N …      ← носитель algebra
  объявление <откуда> дно 0 потолок 2⁵³−1   ← носитель segment
  объявление <откуда>                       ← носитель fold
<откуда> = сумма «Т» строка L | запись «Т» строка L | встроенный «Т»
         | псевдоним «А» строка L → <откуда>
```

N у варианта — число его рекурсивных частей (полей ровно типа «Т»; поле
`список «Т»` не в счёт), варианты — в порядке объявления, L — строка объявления
в исходнике.

Что делает сверщик (`сверить_покрытие`, `сверить_строки_записи`): сличает
строку ЗНАК В ЗНАК со своей читкой того же объявления (`объявление_типа`, одна
точка для носителя и строки `объявление`) и при расхождении называет первое
расходящееся слово; строка не сразу под принципом — отказ; строки под принципом
нет вовсе — отказ «ядро обязано её печатать».

## Что здесь лежит

| файл | класс | код | откуда |
|---|---|---:|---|
| `body-forms.record` | честная | 0 | эталон: сумма «Стопка» под algebra, встроенный список под fold |
| `corpus-length.record` | честная | 0 | эталон: встроенный список под algebra |
| `segment.record` | честная | 0 | эталон: встроенный отрезок, дно и потолок |
| `name-natural.record` | честная, **рукотворная** | 0 | запись семьи `носитель` + три строки `объявление встроенный «натуральное» …` по грамматике эталона |
| `alias-segment.record` | честная, **рукотворная** | 0 | запись семьи `носитель` + строка `объявление псевдоним «Возраст» строка 3 → встроенный «неотрицательное» …` |
| `corrupt/p01`…`p12` | подделка | 1 | эталоны: чужое имя варианта, лишний, недостающий, чужая арность, чужая строка объявления, запись вместо суммы, segment при сумме, две строки, другое дно, другой потолок, сумма у встроенного, сумма под fold |
| `corrupt/p13`, `p14` | подделка | 1 | рукотворные от псевдонима: чужая строка псевдонима; псевдоним пропущен |

Эталоны напечатаны зондом по коду ядра (толкованием исходников `flang/self`).
Подделки прогоняет `tests/run.fscript`: код 1 И названное расхождение, и ни одной
«не узнана».

## Чего здесь нет

- Честной записи с `запись «Т»` (`объект`) нет: ядро не даёт принципа
  по объекту (матрица ADR-0026, ф02), строка для него — только грамматикой.
- Встроенная `строка` под algebra печатается теми же вариантами, что список
  (`«пусто» 0 «голова и хвост» 1`) — по коду ядра (`proof-initial.flang`
  «Объявление строки»); эталона нет.
- Цепочка псевдонимов длиннее одного звена — только грамматикой.
