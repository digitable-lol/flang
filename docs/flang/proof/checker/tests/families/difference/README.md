# Семья «разность»: разность под записанным порядком (правило Н12)

Задача [1403](../../../../../../tasks/completed/1403-vychitanie-pod-predusloviem.md),
основание — [ADR-0032](../../../../../../adr/0032-one-missing-rule-and-three-other-logics.md)
§2. Строка ведомости `Н12`, лемма «Н12» и две леммы-соседки в
`flang/proof/lean/Rules.lean`, ловушки 9 и 10 в `Trap.lean`.

## Что стережётся

`Л минус П : неотр` выводится ТОЛЬКО из трёх вещей сразу: вычитаемое не меньше
нуля (посылка 1), вычитаемое не больше конечного литерала (посылка 2) и в
допущениях функции стоит порядок «П не больше Л» либо зеркало «Л не меньше П»
(побочное условие, читается со строки `требует` исходника). Без потолка ложно на
«+∞ минус +∞», без дна — на «−∞ минус −∞», без порядка — на «2 минус 3».
