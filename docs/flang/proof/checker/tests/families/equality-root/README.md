# Равенство не корень формулы

Сравнения связывают теснее `и притом` и `или`: `М и притом М равно М и притом М` читается
как `М и притом (М равно М) и притом М`. Разрез формулы по знаку `равно` ищет знак сверху
скобок и о старшинстве не знает: у этой формулы он находит стороны `М и притом М` и
`М и притом М` — одинаковые.

`conjunction-equal-to-itself.flang`: утверждение «связка равна себе» для `М` =
`«Мал» от х` (`х меньше 98765.4321`) ложно при `х = 100000`: `нет и притом да и притом нет`
есть `нет`. Запись закрывает его одним ходом `закрыть тождеством`.

Разрез по `равно`, `равен` и знакам порядка оба сверщика берут, только когда сравнение —
корень формулы: сверху нет `или`, `и притом`, `то`, `иначе`, формула не начинается с `не`
и `если` (`кореньСравнения`, `корень_сравнения`). Это касается `закрыть тождеством`,
модус-поненса `закрыть по свойству` и допущения хода `замена`. Без этой проверки оба
сверщика приняли бы запись кодом 0; с ней она получает код 1.
