# Семья «перебор»: свободное утверждение над конечной суммой

Правило Инд6, [ADR-0075](../../../../../../adr/0075-a-free-statement-gets-segment-induction-integer-tightening-and-enumeration.md) §2.3.
Свободное утверждение `для всех ц: «Цвет»` без теоремы ядро перебирает по
вариантам суммы без поля своего типа. Запись несёт принцип `носитель algebra`
с посылкой на каждый вариант; сверщик сводит утверждение к постусловию
вызванной функции и проигрывает каждую посылку.

| файл | класс | код | что это |
|---|---|---:|---|
| `colour.{flang,record}` | честная | 0 | «номер цвета не больше трёх», три посылки проиграны |
| посылка «Синий» вместо «Жёлтый» | подделка | 1 | вариант подменён |
| посылка «Жёлтый» убрана | подделка | 1 | вариант пропущен |
