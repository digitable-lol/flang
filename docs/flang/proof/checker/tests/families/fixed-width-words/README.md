# Семья «слова фиксированной ширины»: Сл1 и Сл2

Основание — [ADR-0112](../../../../../../adr/0112-fixed-width-integers-live-in-the-language.md) §3.1.

## Что делает сверщик

Шаг `Сл1 ⟨( к числу Т ) не меньше 0⟩ строка N` и шаг
`Сл2 ⟨( к числу Т ) не больше К⟩ строка N` сверщик не берёт на слово записи.
`правило_сл` в `checker.c` читает строку N исходника: она обязана лежать в той
же функции и объявлять довод `Т` беззнаковым словом `u8`, `u16`, `u32` или
`u64`. У Сл2 целый литерал `К` обязан быть не меньше `2^w − 1` для ширины `w`
объявления. Знаковые слова (`i8` … `i64`) правила не закрывают.

## Что здесь лежит

| файл | класс | код | что стережёт |
|---|---|---:|---|
| `unsigned-bounds.{flang,record}` | честная | 0 | `к числу` над `u8` в [0, 255], над `u32` — не больше 2^53 − 1 |
| порчей одной строки в прогоне | подделка | 1 | потолок 254 у `u8` |
| порчей одной строки в прогоне | подделка | 1 | основание Сл1 на строке, которая довод не объявляет |
| порчей одной строки в прогоне | подделка | 1 | нижняя граница выдана правилом Сл2 |
| порчей одной строки в прогоне | подделка | 1 | основание Сл2 взято из строки чужой функции |

Запись `unsigned-bounds.record` напечатана ядром исходного компилятора.
