# Семья «свободное утверждение индукцией по списку»

Решение — [ADR-0189](../../../../../../adr/0189-a-free-statement-over-a-list-is-proved-by-induction.md).
Код — `flang/proof/checker/tests/families/free-statement-induction/`.

Свободное утверждение «если `«Найти» от л и н` ложно, то `«Отобрать» от л и н` пуст»
ядро доказывает индукцией по списку `л`, а запись печатает под каждой посылкой цепочку
ходов:

```
  посылка «голова и хвост» вид step вариант «голова и хвост» …
    ход цель
    ход дано 1 предположение по «хвост»
    ход 1 развернуть ⟨«Найти» от ( приписать голова к хвост ) и н⟩ строка 10 ⟨…⟩
    ход 2 развернуть ⟨«Отобрать» от ( приписать голова к хвост ) и н⟩ строка 23 ⟨…⟩
    ход 3 деление ⟨голова равен н⟩
    …
    ход 10 закрыть дано 1
    ход конец
```

Оба сверщика строят цель посылки сами (`приписать голова к хвост` вместо `л`), берут
допущение только о хвосте и разворачивают вызов лишь на строке `то` под случаем того же
разбора первого параметра.

## Откуда запись

`free.record` и `theorem.record` — печать ядра, снятая двоичным, собранным из исходников
`flang/self` этой ветки (печать без ядра доказательств, `emit --no-check`, только для
пробы).

## Что здесь лежит

| файл или правка | класс | код | что стережёт |
|---|---|---:|---|
| `free.{flang,record}` | честная | 0 | утверждение без теоремы: обе посылки ходами |
| `theorem.{flang,record}` | честная | 0 | теорема без случая «пусто»: база сведена ядром, шаг `по предположению` снят ходами |
| `corrupt/lie.{flang,record}` | подделка | 1 | ложное соседнее утверждение («длина равна 1») под той же цепочкой |
| правка: допущение о голове | подделка | 1 | допущение индукции — только о хвосте |
| правка: развёртка на строке другого случая | подделка | 1 | строка развёртки — под случаем того же конструктора |
| правка: `закрыть дано 1` в базе | подделка | 1 | в базе допущения нет |
| правка: посылка «голова и хвост» снята | подделка | 1 | посылки покрывают оба варианта |
