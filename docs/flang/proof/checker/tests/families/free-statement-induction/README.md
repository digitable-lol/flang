# Семья «свободное утверждение индукцией по списку»

Решение — [ADR-0189](../../../../../../adr/0189-a-free-statement-over-a-list-is-proved-by-induction.md).
Код — `flang/proof/checker/tests/families/free-statement-induction/`.

Свободное утверждение «если `«Найти» от л и н` ложно, то `«Отобрать» от л и н` пуст»
ядро доказывает индукцией по списку `л`, а запись печатает под каждой посылкой цепочку
ходов:

```
  посылка «голова и хвост» вид step вариант «голова и хвост» …
    ход цель
    ход дано 1 предположение по «хвост»
    ход 1 развернуть ⟨«Найти» от ( приписать голова к хвост ) и н⟩ строка 10 ⟨…⟩
    ход 2 развернуть ⟨«Отобрать» от ( приписать голова к хвост ) и н⟩ строка 23 ⟨…⟩
    ход 3 деление ⟨голова равен н⟩
    …
    ход 10 закрыть дано 1
    ход конец
```

Оба сверщика строят цель посылки сами (`приписать голова к хвост` вместо `л`), берут
допущение только о хвосте и разворачивают вызов лишь на строке `то` под случаем того же
разбора первого параметра.

## Откуда запись

`free.record` и `theorem.record` — печать ядра, снятая двоичным, собранным из исходников
`flang/self` этой ветки (печать без ядра доказательств, `emit --no-check`, только для
пробы).

## Что здесь лежит

| файл или правка | класс | код | что стережёт |
|---|---|---:|---|
| `free.{flang,record}` | честная | 0 | утверждение без теоремы: обе посылки ходами |
| `theorem.{flang,record}` | честная | 0 | теорема без случая «пусто»: база сведена ядром, шаг `по предположению` снят ходами |
| `corrupt/lie.{flang,record}` | подделка | 1 | ложное соседнее утверждение («длина равна 1») под той же цепочкой |
| правка: допущение о голове | подделка | 1 | допущение индукции — только о хвосте |
| правка: развёртка на строке другого случая | подделка | 1 | строка развёртки — под случаем того же конструктора |
| правка: `закрыть дано 1` в базе | подделка | 1 | в базе допущения нет |
| правка: посылка «голова и хвост» снята | подделка | 1 | посылки покрывают оба варианта |
| `rewrite.record` | честная | 0 | шаг закрыт перепиской допущением: `замена по дано 1`, затем `закрыть тождеством` |
| правка `rewrite.record`: допущение обо всём списке | подделка | 1 | допущение индукции — только о хвосте |
| правка `rewrite.record`: посылка «пусто» снята | подделка | 1 | без базы посылки не покрывают варианты |
| правка `rewrite.record`: переписка допущением заменена на `закрыть истиной` | подделка | 1 | цель шага без переписки не тождество |
| `corrupt/doubling.{flang,record}` | подделка | 1 | ложное «удвоение есть исходный» с посылкой шага без ходов: контрпример `а = [1]` |
| `brackets/string-literal.{flang,record}` | подделка | 1 на Lean, 0 на C | скобки внутри строки `"( пустой список )"` — часть значения |
| `brackets/name.{flang,record}` | подделка | 1 на Lean, 0 на C | функция «Счёт ( пустой список )» — не функция «Счёт пустой список» |
| `brackets/non-empty.{flang,record}` | подделка | 1 | скобки вокруг непустого списка `( приписать 0 к ( пустой список ) )` не делают его пустым |

## Шаг, закрытый перепиской допущением

Исходник `rewrite.record` — `flang/proof/probes/lean-parity-gaps/programs/bare-list-variable.flang`.
Цель «`«Копия» от а` равен `а`» после развёртки на `приписать голова к хвост` содержит левую
сторону допущения о хвосте; ход `замена по дано 1` ставит на её место правую, и стороны
совпадают:

```
  посылка «голова и хвост» вид step вариант «голова и хвост» …
    ход цель
    ход дано 1 предположение по «хвост»
    ход 1 развернуть ⟨«Копия» от ( приписать голова к хвост )⟩ строка 27 ⟨…⟩
    ход 2 замена по дано 1
    ход 3 закрыть тождеством
    ход конец
```

Перед перепиской `( пустой список )` и `пустой список` считаются одним термом: довод
вызова подстановка одевает в скобки, а допущение несёт его голым.

Сверщик на Lean приводит `( пустой список )` к `пустой список` только вне строк и имён в
«ёлочках»: внутри них скобки — часть значения или имени. Сверщик на C приводит простой
заменой текста и потому принимает подделки `brackets/string-literal` и `brackets/name`
кодом 0: обе записи закрывают ложное утверждение одной перепиской допущением, которую
даёт только приведение внутри строки или имени.

Посылку без ходов сверщик на C не проигрывает. Если хоть одна посылка осталась без ходов,
он ищет контрпример по кванторам утверждения; список чисел перебирается значениями
`пустой список`, `[1]`, `[1, 2]`. Найденный контрпример — код 1. Сверщик на Lean
контрпример по спискам не ищет: `corrupt/doubling.record` он оставляет на коде 3.
Расхождения названы в `flang/proof/tables/second-checker-disagreements.tsv`.

`rewrite.record` снята ядром из исходников. Ходами в ней закрыто утверждение «склейка с
пустым есть копия»; «копия есть исходный» ядро не доказывает, в записи у него «нет
вердикта».
