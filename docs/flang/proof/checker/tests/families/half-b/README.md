# Золотые сертификаты семей С3/С4/С5

Рукотворные сертификаты (исходник + запись), которыми проверено, что след
семей **С3 «длина»** (ход `переписать формой`, законы Д1–Д5), **С4 «элемент по
номеру»** (тот же ход, закон «Развернуть элемент по номеру», Э1–Э4) и
**С5 «замкнутая арифметика»** (ход `вычислить`) проигрывается чекером
(`сверщик`) существующими ходами. Это цели проверки для печати ядра и защита от
регресса, тем же приёмом, что у С1/С2 (`neighbours.*`, `reflexive.*` и `corrupt/` в
`flang/proof/checker/tests/families/`).

**В прогон эти фикстуры НЕ вплетены** — гонять напрямую:

    make -s -C flang/proof/checker
    ./flang/proof/checker/сверщик <исходник.flang> <запись>

## Верные сертификаты → КОД 0

- `length.flang` / `length.record` — С3, 5 мест (У4 «Знаки текста» Д4, У5
  «Дописать в конец» Д1, У6 «Дописать в начало» Д2, У7 «Склейка строк» Д3,
  «Единицы»/С3 Д5). Тела и постусловия сняты знак в знак с
  `flang/proof/map/abilities.flang:32,73,84,95` и
  `flang/proof/map/substantive.flang:28` (взято ТОЛЬКО постусловие «С3
  сохранение» из трёх — С1/С2 той же функции про другое). Цепочка
  `развернуть → переписать формой → закрыть тождеством`. Прогон: КОД 0,
  15 ходов проиграно.
- `element.flang` / `element.record` — С4, 7 мест (Э1 голова приписанного, Э2
  дважды приписанное, Э3 дописанное — двумя записями номера, Э4 выписанный
  список — прямо и под приписыванием). Тела и постусловия сняты знак в знак с
  `flang/test/fixtures/element-po-nomeru-chestnaya.flang` (честная половина
  переписки) — переписан только заголовок модуля. Цепочка
  `развернуть → переписать формой (раз или дважды) → закрыть тождеством`.
  Прогон: КОД 0, 24 хода проиграно.
- `arithmetic.flang` / `arithmetic.record` — С5, 1 место («Замкнутая цель»/Ф9).
  Тело и постусловие сняты знак в знак с `flang/proof/map/forms.flang:35`.
  Цепочка `вычислить → закрыть тождеством`. Прогон: КОД 0, 2 хода проиграно.
  Второе место семьи, «Модули»/К1 (`flang/proof/map/sources.flang:3`), —
  постусловие С ПРИНЦИПОМ; этой семьёй оно не берётся, нужна семья С7.

## Порча хода → КОД 1 с называнием (`corrupt/`)

- `corrupt/length-wrong-law.record` — ход `переписать формой` на теле
  «добавить» подан законом «Мера склейки» вместо «Мера прибавления»; чекер
  называет: «левая сторона «длина ( добавить что к элементы )» не той формы,
  какой закон требует».
- `corrupt/element-index-swapped.record` — арифметика литерального номера
  (Э2, К минус 1) подменена на месте: записано «элемент 2 …» вместо «элемент
  1 …»; чекер называет: «правая пересобрана как «элемент 1 в ( приписать
  второй к элементы )», а запись несёт «элемент 2 в ( приписать второй к
  элементы )»».
- `corrupt/arithmetic-wrong-value.record` — ход `вычислить` подан с неверным
  значением (5 вместо 4); чекер называет: «терм посчитан = 4, а запись несёт
  ⟨5⟩».
