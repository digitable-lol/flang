# Тело ветвлением: многострочное «если», «пусть», поле результата, разбор суммы

Семья проб для утверждений без теоремы, которые ядро закрывает правилами «разбор цели
по условию» и «разбор случаев по внутреннему условию цели», когда тело функции написано
ветвлением на нескольких строках.

## Что сверщик делает сам

Записи у таких утверждений нет ничего, кроме имени правила: ходов ядро не печатает.
Сверщик повторяет разбор по исходнику.

1. **Тело читается по отступам.** Строка `если У`, под ней на одном отступе `то А` и
   `иначе Б`; ветвь сама бывает ветвлением на отступ глубже. Тело собирается одним
   термом `если ( У ) то ( А ) иначе ( Б )`, скобки ставит отступ, а не старшинство.
   Строки `пусть имя равно значение` перед телом подставляются с конца, не больше
   восьми. Строки глубже выражения — его продолжение; метка `то` или `иначе` без
   хвоста несёт блок строк ниже; тело `разбор` собирается по случаям (семья
   `case-split-facts`). Ветвь не на своём отступе — отказ «не берусь».
2. **`результат` заменяется телом.** Поле результата (`результат.«поле»`) берётся из
   ветвей: у выписанной записи — значение поля, у имени — `имя.«поле»`; ветвление
   переносится на поле ветвей.
3. **Цель делится по условию.** Сначала первое условие цели, у которого снято
   отрицание; не закрылось — первый атом связки `и притом`/`или` вне ветвлений. Атом
   подставляется литералом `да` и `нет` во всех признанных местах, и обе половины
   обязаны закрыться. Глубина деления — четыре. Связыватель в цели, кроме разбора, —
   отказ. Связанные атомы решает факт половины (семья `case-split-facts`).
4. **Разбор суммы в булевой цели узла.** У посылки узла `algebra` образец случая
   (`вариант «Есть» с значение равным зн`) встаёт на место разбираемого довода, если
   имена образца в цели не встречаются; затем цель закрывается тем же делением.

Ложная цель ни одним из шагов не закрывается: место остаётся на слове ядра (код 3), а
не принимается.

## Пробы

| файл | что | код |
|---|---|---|
| `lexer-step.flang` | девять честных утверждений: многострочное «если», «пусть», атом связки, поле записи | 0 |
| `corrupt/lexer-step-lies.flang` | пять ложных утверждений тех же форм, «доказано» подложено в запись | 3 |
| `option-flag.flang` | разбор суммы, булева цель, посылки «разбор цели по условию» и «вычисление замкнутой цели» | 0 |
| `corrupt/option-flag-lies.flang` | узел честного утверждения подложен под ложное | 3 |

Прогон: `bootstrap/flang run-script checker:check`.
