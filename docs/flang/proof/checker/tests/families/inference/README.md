# Семья «вывод»: факт о типе едет в записи выводом

Основание — [ADR-0022](../../../../../../adr/0022-a-type-fact-travels-as-a-derivation.md)
§3.10 и [ADR-0025](../../../../../../adr/0025-the-ceiling-leaves-the-type-and-becomes-an-obligation.md):
потолок точного типа — обязательство на зовущем, и П3 получает посылку Пред1.

## Что здесь лежит

| файл | что это |
|---|---|
| `inference.flang` | восемь функций — по одной на вид вывода: сумма двух объявленных, литерал, встроенная мера, довод под допущением, цель словом в слово допущением, имя точной сетки, разность под потолком, литерал под потолком |
| `inference.record` | честная запись: у каждого утверждения блок вывода, всего одиннадцать правил ведомости; у «довода под точным потолком» — строка `обязательство вход «ц» …`, шаги Пред1 → П3 `из 1` → Разв2 |
| `repr-call.flang`, `repr-call.record` | честная: «Разность под потолком» с двумя точными доводами (Пред1, П3, Н3, П5, Разв2), два обязательства входа; в том же файле два зовущих (литералами; своим доводом `нат`) и пример с `дано` — закрытие обязательств переигрывается по ним |
| `repr-call-nothing-to-close-with.flang`, `repr-call-nothing-to-close-with.record` | честная: тот же файл плюс зовущий, подающий выражение `длина т` (ядро типизирует его как `нат`) — сверщику закрыть обязательство нечем, третий исход с названной причиной |
| `corrupt/p3-without-premise.record` | подделка: П3 с основанием `строка N`, без посылки Пред1 |
| `corrupt/repr-call-above.flang`, `corrupt/repr-call-above.record` | подделка: зовущий подставляет литерал `9007199254740992` — выше К_предст; исходник свой, ядро такой файл не типизирует (FLANG_TYPE), сверщик обязан поймать сам |
| `corrupt/subtraction-by-prohibition.record` | вычитание названо запретом ведомости |
| `corrupt/subtraction-disguised-as-a-sum.record` | вычитание выдано за сумму |
| `golden/strict-order.record`, `golden/builtin-emptiness.record`, `golden/case-breakdown.record`, `golden/corpus-hof.record` | ADR-0027, семейство Р: четыре записи корпуса (исходники `flang/test/fixtures/poddelka-{strict-order,builtin-emptiness-fact,razbor-sluchaev}.flang`, `flang/proof/examples/corpus-hof.flang`) с блоками `вывод`, какими их ДОЛЖНО печатать ядро: гипотезы ГипО (охрана, «сам») и ГипД (дизъюнкт, «строка N») с учётом открытых гипотез, Р1/Р4 их снимают; Р5/Р6 читают тело; С4/П2 берут гипотезу «из шага»; Выч ×2 → Р3 сличением половин; Или1/Или2. Тринадцать подделок собираются порчей строк в прогоне |
| `golden/order-arithmetic.record` | запись рукотворная: корпусная `poddelka-order-arithmetic.record` с блоком у «Рефлексивность под охраной» :35 — ГипО `( х минус х ) равен 0` → Кон3 `х : кон` → О2 → Разв2 → Р1; две подделки Кон3 (разность не «Т минус Т»; конечность о другом терме) — в прогоне |

Записи РУКОТВОРНЫЕ: сверщик читает блок вывода и строку `обязательство вход`
независимо от того, печатает ли их ядро. Шапки записей посчитаны по файлу
(строк, знаков, два отпечатка, sha256).

## Мерило

Честная `inference.record` — код 0, восемь мест сняты со слова ядра («выводов факта о типе
проиграно заново 8»), долг ноль. `repr-call` — код 0, одно место снято. `repr-call-nothing-to-close-with`
— код 3, место на слове ядра, причина названа строкой «обязательство входа … сверщик
закрыть не смог». Подделки — код 1, и причину называет проверка вывода либо сверка
обязательств, а не имя файла. Ещё двадцать четыре подделки собираются порчей одной
строки честной записи прямо в прогоне (`tests/probes.tsv`, семья «вывод»): на каждый
вид отказа своя проба и своя названная причина; семь из них — о посылке П3 и
обязательстве входа.
