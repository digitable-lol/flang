# Семья «ужатие целостью»: строгое дно целого ужимается на единицу

Правило Цел3, [ADR-0075](../../../../../../adr/0075-a-free-statement-gets-segment-induction-integer-tightening-and-enumeration.md) §2.2.
Постусловие «результат не меньше 1» при `требует а больше 0` и `а: неотрицательное`
едет в записи выводом: `Т1 ⟨а больше 0⟩`, `Цел2 ⟨а : цел⟩`, `Цел3 ⟨а не меньше 1⟩ из 1 2`,
`Разв2`. Сверщик проверяет Цел3: строгая посылка о том же Т с целым литералом К,
заключение ровно «Т не меньше К плюс 1», вторая посылка — «Т : цел» шагом Цел1 или
Цел2. Свободное утверждение того же файла доказано ядром по объявлению, вывода у
него нет, и место остаётся на слове ядра.

| файл | класс | код | что это |
|---|---|---:|---|
| `positive.{flang,record}` | честная | 3 | вывод постусловия проигран, свободное утверждение на слове ядра |
| Цел3 «не меньше 2» | подделка | 1 | ужатие на два |
| Н3 на месте Цел2 | подделка | 1 | без целости |
| Т1 «а не меньше 0» | подделка | 1 | нестрогое допущение |
| исходник с `а: число` | подделка | 1 | Цел2 над доводом без целости |
