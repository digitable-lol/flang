# Семья «приёмы ядра без ходов»: места, которые сверщики переигрывают сами

Ядро доказывает семь задач из сравнения с Lean (`docs/lean-parity.md`) и не печатает
под ними ни ходов, ни блока вывода: в записи стоят только правило и строка
`по объявлению`. Оба сверщика — на C (`flang/proof/checker/checker.c`) и на Lean
(`flang/proof/checker/second/`) — переигрывают такие места по исходнику.

| приём | где в сверщике на C | где во втором | задачи |
|---|---|---|---|
| порядок по фактам: сравнения ограничения — рёбра, цель — путь, строгий круг — несовместные факты | `порядок_по_фактам` | `Order.lean`, `порядокПоФактам` | `order-chain`, `and-split`, `contradiction` |
| выбор по условиям: цель с `если У то А иначе Б` делится по истинности У | `порядок_разбором` | `Order.lean`, `порядокРазбором` | `maximum` |
| закон отбора: `длина (отфильтровать Л где …)` не больше `длина Л` | `пф_закон_отбора` | `Order.lean`, `пфЗаконОтбора` | `filter-length` |
| счёт замкнутой цели: умножение, мера `убывает`, тело `если`/`то`/`иначе` на своих строках | `отношение_термов`, `вычислить_тело` | `Evaluator.lean`, `отношение`, `тела` | `closed-power` |
| развёртка вызова, чей довод — вызов той же функции | `развернуть_вариантом` | `Body.lean`, `развернутьВариантом` | `mirror` |
| контрпример: значения 0…3 имён типа-отрезка, при которых допущения верны, а цель ложна | `пф_контрпример` | `Node.lean`, `контрпример` | подделки |

## Почему порядок по фактам верен на двоичных числах

Истинное сравнение бывает только у двух чисел, не «не числа»: у не-числа любое
сравнение ложно. Поэтому ребро берётся из истинного сравнения всегда, а из ложного
(условие ветви, которое не выполнилось) — только если обе стороны заведомо числа:
целый литерал или имя с типом-отрезком (`неотрицательное`, `нат` …). `равен` ребра не
даёт: равенство языка — Object.is, и «не число» равно себе. Цель `а не больше а` без
пути берётся только у заведомого числа.

Во втором сверщике путь, который нашёл поиск, проверяет `путьВерен`, и теорема
`путь-верен` (`Order.lean`) говорит: на всяком носителе с законами `МодельПорядка`, где
верны все рёбра, принятый путь даёт верное сравнение концов; `круг-несовместен` — что
строгий круг при верных рёбрах невозможен; `ребро-из-ложного` — где нужна полнота
порядка; `отбор-не-удлиняет` — закон отбора. `порядокЦелых` показывает, что законы
выполнимы.

## Что здесь лежит

Исходники — копии задач `flang/proof/parity/programs/`, записи — печать ядра 0.7.32.
Подделки строит набор проб правкой исходника (запись переподписывается) или записи.

| файл | класс | код | что это |
|---|---|---:|---|
| `order-chain` | честная | 0 | цепочка через две середины |
| `and-split` | честная | 0 | `и притом` в цели |
| `contradiction` | честная | 0 | строгий круг в допущениях |
| `filter-length` | честная | 0 | отбор не удлиняет список |
| `closed-power` | честная | 0 | `(«Степень двойки» от 10) равен 1024` |
| `maximum` | честная | 0 | постусловие с выбором по условию тела и цели |
| `mirror` | честная | 0 | двойное зеркало дерева, индукция и `по предположению` |
| `order-chain`, правка цели | подделка | 1 | цель перевёрнута — контрпример |
| `and-split`, правка цели | подделка | 1 | вторая половина ложна — контрпример |
| `contradiction`, правка допущений | подделка | 1 | допущения совместны — контрпример |
| `maximum`, правка цели | подделка | 1 | ветвь «иначе» ложна — контрпример из тела |
| `filter-length`, закон наоборот | подделка | 3 | закона нет, место на слове ядра |
| `closed-power`, `равен 1000` | подделка | 3 | место на слове ядра |
| `mirror`, `равен («Зеркало» от д)` | подделка | 3 | место на слове ядра |
| `maximum-over-number` | подделка записи | 3 | над `число` ложное условие не переворачивается |
| `reflexive-over-number` | подделка записи | 3 | над `число` `а не больше а` не берётся |

Последние две записи ядро печатает честно (`нет вердикта`: ядро над `число` их не
доказывает); подделка вписывает в них вердикт и правило.
