# Семья «включение списков» — Вкл1 и Вкл2

Решение — [ADR-0175](../../../../../../adr/0175-a-list-precondition-passes-to-the-head-and-tail-and-a-list-includes-itself.md).
Код — `flang/proof/checker/tests/families/list-inclusion/`.

`для всех м из а: результат содержит м` при теле `а` (Вкл1), `приписать н к а` и
`добавить н к а` (Вкл1, затем Вкл2). Новый элемент `приписать` — В2 (раньше печать знала
только `добавить`).

## Откуда запись

`inclusion.record` — печать ядра, снятая толкованием исходников `flang/self` семенем
(зонд `flang/self/bootstrap/check-with-source-compiler.flang`).

## Что здесь лежит

| файл или правка | класс | код | что стережёт |
|---|---|---:|---|
| `inclusion.{flang,record}` | честная | 0 | пять доказанных — Вкл1, Вкл2, В2 — проиграны заново; «Копия» стоит сеткой: включение рекурсией ядро не доказывает |
| правка: Вкл1 о носителе с прибавкой | подделка | 1 | носитель Вкл1 — тот же список, что у квантора |
| правка: посылка Вкл2 о другом списке | подделка | 1 | посылка Вкл2 — включение того же носителя без прибавки |
| правка: Вкл2 заключает носитель без прибавки | подделка | 1 | Вкл2 берёт только `приписать` и `добавить` |
