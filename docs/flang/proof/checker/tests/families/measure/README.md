# Семья «мера»: длина прибавленного списка и свёртки, растущей на один

Задача [6432](../../../../../../tasks/6432-measure-projection-and-declared-sums-close-five-kernel-word-places.md),
решение — [ADR-0042](../../../../../../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2:
семейство **М** ведомости. Строки `М1` и `М2` — в `flang/proof/tables/inference-rules.tsv`,
леммы «М1», «М2», «М2-пустое-начало» — в `flang/proof/lean/Rules.lean`, ловушки
18 (М1 без единицы) и 19 (М2 без посылки о шаге) — в `Trap.lean`.

## Что стережётся

Ядро доказывает меру по построению давно (правило 4, «мера списка»), а три места
корпуса стояли на слове ядра: строки ведомости не было. Шаг М1 или М2 переписывает
ОДНУ сторону отношения посылки равным ей значением — вторая сторона та же знак в
знак, а то, какой сторона была, сверщик пересобирает сам:

| место корпуса | что печатает ядро | что сличает сверщик |
|---|---|---|
| `poddelka-strict-order` «в отданном списке есть хотя бы одно число» | `Н4` ⟨( длина элементы ) не меньше 0⟩ → `Д6` → `Д3` ⟨( ( длина элементы ) плюс 1 ) не меньше 1⟩ → `С3` → `М1` ⟨( длина ( добавить 0 к элементы ) ) больше 0⟩ → `Разв2` | М1: сторона «( длина Л ) плюс 1» стала «длина ( добавить Э к Л )» |
| `abilities` У3 «свёртка растит длину ровно на один» | `Выч` ⟨( длина элементы ) равен ( длина элементы )⟩ → `М2` ⟨( длина ( свёртка … → добавить эл к акк ) ) равен …⟩ → `Разв2` | М2: шаг «добавить Х к акк» растит накопитель на один, начало пусто — мера свёртки есть длина списка |
| `poddelka-svyortka-shagom` «нулей ровно столько, сколько элементов» | то же, шаг — «Дописать нуль» от акк; своё тело зовёт — `Разв3` вместо `Разв2` | М2: у «Дописать нуль» постусловие «( длина результат ) равен ( ( длина звенья ) плюс 1 )» ПРОВЕРЕНО раньше в той же записи (реестр доказанного) |

Подделка того же файла «Ложь именем витка» держит «плюс 1» допущением `требует`,
а не доказанным обещанием, — ядро её не доказывает, и шаг М2 с «Удвоить» сверщик
отвергает.

| файл | класс | код | что это |
|---|---|---:|---|
| `strict-order.запись` | честная, печать ядра | 0 | место корпуса `poddelka-strict-order` (зонд 836 с, пик 50,6 ГиБ); М1 у :66; Lean принимает блок целиком |
| `abilities.запись` | честная, печать ядра | 0 | места корпуса `abilities` У3 (М2, у :44) и У23 (Пр1, семья «противоречие»); зонд 2694 с, пик 51,7 ГиБ |
| `svyortka-shagom.запись` | честная, печать ядра | 0 | место корпуса `poddelka-svyortka-shagom` (зонд 841 с, пик 49,7 ГиБ); М2 с шагом-вызовом у :48, своё тело — Разв3 |
| порчей одной строки в `run.sh` (`podd_p`) | подделки | 1 | М1: мера чужого списка; посылка другого отношения. М2: шаг не растит накопитель; начало не пусто; шаг-вызов без доказанного «плюс 1» (Удвоить) |
