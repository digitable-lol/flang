# Знак нуля: три тождества, ложные над `число`

`равен` языка сравнивает числа как `Object.is`: минус ноль и ноль — разные значения,
а «не число» равно самому себе. Поэтому над `число` ложны три тождества, которые
верны над целыми:

| программа | тождество | вход, на котором ложно |
|---|---|---|
| `flang/proof/forgeries/negative-zero/zero-times-a.flang` | `0 умножить на а` равен `0` | `а = −5`: результат −0 |
| `flang/proof/forgeries/negative-zero/a-plus-zero.flang` | `а плюс 0` равен `а` | `а = −0`: результат +0 |
| `flang/proof/forgeries/negative-zero/a-minus-a.flang` | `а минус а` равен `0` | `а` бесконечно или не число |

Ядро ни одно из трёх не доказывает: записи ядра лежат в наборе подделок
`flang/proof/forgeries/manifest.tsv` с классом `program-lies`. Записи этой семьи
(`*-proved.record`) приписывают каждому тождеству доказательство ходами
«развернуть» и «закрыть тождеством» (у второго — ещё «нейтральный ноль»); оба
сверщика отвечают на них «НЕ СОШЛОСЬ».

Вычислитель сверщиков сравнивает числа тем же правилом, что язык: два числа равны,
когда равны и их знаки, и «не число» равно «не числу».
