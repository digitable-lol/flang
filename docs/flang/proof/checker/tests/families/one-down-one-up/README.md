# Семья «единица туда и обратно» — спуск на единицу и подъём в шаге индукции по отрезку

Решение — [ADR-0188](../../../../../../adr/0188-one-down-and-one-up-is-the-same-natural-and-the-floor-holds-two-zeros.md).
Код — `flang/proof/checker/tests/families/one-down-one-up/`.

«Счёт» с телом `если н не больше 0 то н иначе 1 плюс («Счёт» от (н минус 1))` и теорема
индукцией по `а: неотрицательное` для «(«Счёт» от а) равен а». В посылке «спуск» после
переписки допущением остаётся `1 плюс ( а минус 1 )` против `а`; там `а` целое не меньше 1,
и обе стороны — одно число (правило Тожд5). Оба сверщика делают эту замену сами и только в
посылке «спуск»: на дне `а` может быть минус нулём, и `( −0 минус 1 ) плюс 1` есть плюс ноль.

Сверх того оба сверщика читают посылку «дно» при `а` = 0: стороны, замкнутые нулём и
посчитанные разными, — ложь записи.

## Откуда запись

`count.record` написан рукой по контракту формата; проба исходным компилятором
(`flang/self/bootstrap/check-with-source-compiler.flang`, 21 октября 2026) печатает ту же
запись знак в знак (шапку сняли счётом сверщика).

| файл | класс | код | что стережёт |
|---|---|---:|---|
| `count.{flang,record}` | честная | 0 | Тожд5 в посылке «спуск» |
| `corrupt/plus-one.{flang,record}` | подделка | 1 | ложный сосед «равен (а плюс 1)»: дно при а = 0 — «0» против «0 плюс 1» |
| `corrupt/two-up.{flang,record}` | честная, не проиграна | 3 | «2 плюс (а минус 1)» в шаге Тожд5 не берёт |
| `corrupt/at-the-floor.{flang,record}` | честная, не проиграна | 3 | `(н минус 1) плюс 1` на дне правилом не берётся (там возможен −0) |

## Чего здесь нет

Постусловие с носителем `segment` и целью-равенством («Нули» из заявки 410) сверщики не
переигрывают: их приём для `segment` знает только `результат не меньше 0`.
