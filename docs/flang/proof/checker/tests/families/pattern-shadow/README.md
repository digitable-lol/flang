# Тень образца: имя образца совпадает с параметром функции

Семья проб на записи, которые ядро печатает для ложного постусловия, когда образец
разбора связывает имя параметра функции. В функции `«Ловушка»` с параметрами `х` и `я`
случай `«Полный» с х как х` вводит новое `х` — поле варианта; постусловие говорит о
параметре `х`. На входе `х = 1`, `я = Полный(-1)` тело возвращает `нет`, и
постусловие `если х больше 0 то (результат равен да) иначе да` нарушено.

## Что сверщик делает сам

Записи у такого утверждения нет ничего, кроме имени правила «разбор цели по
условию». Сверщик повторяет разбор по исходнику и подставляет образец случая на место
разбираемого довода только тогда, когда имена образца в цели не встречаются. Здесь
имя образца `х` в цели встречается, поэтому случай `«Полный»` он не закрывает.

## Пробы

| файл | что | код |
|---|---|---|
| `short-case.flang` | случай записан без слова `вариант`; сверщик не находит случая на вариант и называет запись ложью | 1 |
| `variant-case.flang` | случай записан со словом `вариант`; узел вердикта не проигран, место остаётся на слове ядра | 3 |
