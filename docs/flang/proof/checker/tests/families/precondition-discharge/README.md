# Семья «снятие предусловия» — место вызова, цель и вывод (5332, 6438)

Решение — [ADR-0038](../../../../../../adr/0038-a-precondition-is-discharged-by-a-printed-derivation.md)
§3.1–3.2. Код — `flang/proof/checker/tests/families/precondition-discharge/`.

У `требует` два лица. Внутри тела вызываемой оно — допущение (им доказывается
постусловие, сверщик читает его строкой `требует`, Т1). На каждом месте
вызова оно — обязательство: предусловие вызванной после подстановки доводов
обязано следовать из того, что вызывающей известно. Ядро это обязательство
доказывает («Снять предусловия», `flang/self/proofterm.flang`) и теперь
печатает в запись блоком:

```
снятие «довод неотрицателен» функции «Корень под требованием» зовёт «Корень из неотрицательного» строка 46 столбец 3
  вид precondition-at-call
  вердикт доказано
  правило «цель есть допущение»
    вывод цель ⟨х не меньше 0⟩
    вывод 1 Т1 ⟨х не меньше 0⟩ строка 42
    вывод конец
конец снятия
```

Сверщик (`сверить_снятие`) цель берёт не из записи, а строит сам: в строке 46
со столбца 3 обязан стоять вызов «Корня из неотрицательного» внутри «Корня под
требованием», у вызванной — `требует «довод неотрицателен» довод не меньше 0`, и
цель — это формула с доводом `х` на месте параметра. Вывод проигрывают прежние
приёмы: блок `вывод` (Т1, семья Н) и ход «факт по свойству» — обещание
вызванной, тем путём, каким переигрывается восьмой ход, с его оплатой
`требует` вызванной.

## Откуда записи

`three-feeds.запись` — ПЕЧАТЬ ЯДРА, снятая толкованием исходников `flang/self`
семенем (зонд `flang/self/bootstrap/zond-k7.flang`): семя ещё не перепечатано и
блока снятия не печатает. `unpaid-callee.запись` — рукотворная: программе с
неоплаченным `требует` ядро записи не печатает вовсе (`FLANG_PRECONDITION_CALL`),
а подделка изображает запись, будто оплата была.

## Как собрана рукотворная запись

`unpaid-callee.запись` снята ядром (зонд) с честного двойника — тот же файл, где
у «Тождества под требованием» довод `(0 плюс 1)`: ядро снимает оба места
(внутреннее — Н1, Н1, Н5; внешнее — обещанием вызванной, блок без вывода, потому
что у вызванной есть своё `требует`). Затем правлены три вещи: шапка
перепривязана к подделке (строк, знаков, два многочленных отпечатка — функциями
ядра «Отпечаток текста» с «Первым»/«Вторым» множителем и модулем, SHA-256), у
внутреннего места вывод снят (цель `( 0 минус 1 ) не меньше 0` не выводится
ничем), а внешнему месту вписан ход «факт по свойству «тождество неотрицательно»».
Сверщик отвечает кодом 1 ровно одной причиной: «предусловие «х не меньше 0»
вызванной «Тождество под требованием» в точке вызова не снято — инстанция
«( 0 минус 1 ) не меньше 0» не снята ни «требует» вызывающей, ни охраной цели,
ни доказанным фактом».
