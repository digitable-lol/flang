# Семья «ходы записи»: каждое доказанное утверждение несёт вывод

Задача 5908, решение [ADR-0057](../../../../../../adr/0057-a-derivation-is-printed-as-a-reasoning-a-human-reads.md).
Печать записи (`flang/self/proof-record.flang`) пишет ходы и шаги вывода там, где раньше
стояло одно имя правила; сверщик на C и второй сверщик на Lean проигрывают их заново.

## Что проигрывается

| место | ходы или шаги | что проверяет сверщик |
|---|---|---|
| поле результата `результат.«п» равен …` при теле `запись «Т» с …` | `развернуть`, `переписать формой … законом «Поле выписанной записи»`, `закрыть тождеством` | в цели `результат.«п»` разведено в `результат .«п»` до подстановки вызова; закон берёт значение поля, названного в выписанной записи ровно раз (лемма «ПолЗ1» в `flang/proof/lean/Rules.lean`) |
| вызов другой функции с доводом-словом | `развернуть ⟨«Г» от Д⟩ строка L ⟨ТЕЛО⟩` | доводы вызова встают на места параметров `«Г»`; параметр или имя довода, связанные внутри тела, — отказ |
| тело, у которого первая строка открывает скобку | `развернуть ⟨ВЫЗОВ⟩ строка L ⟨ТЕЛО⟩` | строки тела склеиваются до закрытия скобки, как их читает язык |
| длина выписанного списка | `вычислить ⟨длина ( [ … ] )⟩ = ⟨N⟩` | N — число членов верхнего уровня |
| счёт замкнутой цели | `развернуть`, затем `вычислить ⟨Ц⟩ = ⟨да⟩` и `закрыть истиной` | цель считается по исходнику |
| свёртка `накопитель плюс ( длина Э )` | `Н1`, `Н7`, `Разв2` | шаг свёртки держит знак: длина не меньше нуля (Н4, Н5) |
| `( длина ( отфильтровать Л где … ) ) не больше ( длина Л )` при составном `Л` | `О8`, `Разв2` | `Л` — терм до верхнего `где` |
| факт по свойству вызванной с `требует` | `развернуть`, `факт по свойству`, `закрыть по свойству` | требование `0 не больше Х` либо `Х не меньше 0` снято, когда `Х` — довод функции, объявленный типом с дном, и имя не связано в её теле |

## Что здесь лежит

| файл | класс | код | что это |
|---|---|---:|---|
| `account.record` | честная, печать ядра | 0 | поле выписанной записи |
| `socrates.record` | честная, печать ядра | 0 | вложенные развёртки и закрытие по свойству |
| `ladder-as-table.record` | честная, печать ядра | 0 | тело в три строки и длина выписанного списка |
| `filter-of-a-built-list.record` | честная, рукотворная | 0 | О8 над `приписать 0 к числа` |
| `fold-total.record` | честная, печать ядра | 0 | Н7 с длиной элемента |
| `discount.record` | честная, печать ядра | 3 | оплата требования дном; снятие предусловия без вывода остаётся на слове ядра |
| `forged/duplicate-field.*` | подделка | 1 | поле названо дважды |
| `forged/swapped-field.*` | подделка | 1 | поле ведёт не к заявленному значению |
| `forged/unfold-without-arguments.*` | подделка | 1 | развёртка без подстановки довода |
| `forged/unpaid-precondition.*` | подделка | 1 | требование с литералом дном не оплачено |
| порчей в прогоне | подделки | 1 | правая сторона закона поля, тело вложенной развёртки, длина списка, список О8, шаг свёртки с вычитанием |

Честные записи, кроме `filter-of-a-built-list.record`, сняты зондом
`flang/self/bootstrap/check-with-source-compiler.flang`; она и подделки `forged/*.record`
написаны руками, шапка посчитана тем же счётом, что у сверщика.
