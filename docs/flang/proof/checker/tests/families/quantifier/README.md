# Семья «квантор»: имена за «для всех» — списком (ADR-0026 К2/К6)

Форма:

- исходник: `для всех а и б обеспечивает «И» …`; вложенное `для всех а для всех б
  обеспечивает …` — то же самое;
- запись: в блоке постусловия сразу после `  вид postcondition` строка
  `  для всех «а» «б» строка N` (N — строка постусловия, имена в порядке написания).

Что делает сверщик: имена за «для всех» читает СПИСКОМ (`имена_квантора`, иначе
`для всех а и б` с индукцией по «б» получало бы ложный отказ — матрица ADR-0026,
З3); принцип обязан идти по одному из названных; строка записи
сличается знак в знак; стоять она обязана сразу после `вид postcondition`.

## Строки нет — что тогда

Строка квантора обязательна (`СТРОКИ_КВАНТОРОВ_ОБЯЗАТЕЛЬНЫ` = 1 в `checker.c`):
постусловие с квантором без строки `для всех «…» строка N` — код 1, и при одном
имени, и при двух. За отсутствие строки «проверено» не выдаётся (подделка p4).
Так же обязательна строка `объявление` под принципом индукции.

## Что здесь лежит

Записи РУКОТВОРНЫЕ, кроме `one-name.record` — печати ядра.

| файл | класс | код | что это |
|---|---|---:|---|
| `two-names.{flang,record}` | честная | 0 | `для всех дно и стопка`; запись корпуса с пересчитанной шапкой и строкой `для всех «дно» «стопка» строка N`. Индукция по «стопка» — по ВТОРОМУ имени |
| `name-outside-the-list.flang` | исходник подделки | — | та же строка — `для всех дно` |
| `one-name.record` | честная | 0 | печать ядра `flang/proof/examples/corpus-length.flang` со строками `объявление` и `для всех «элементы» строка N` |
| `strict-honest.record` | честная | 0 | запись семьи «объявление» `corpus-length` + строка `для всех` — полная запись |
| `strict-without-line.record` | подделка | 1 | та же без строки `для всех` |
| `strict-without-declaration.record` | подделка | 1 | `one-name.record` без строки `объявление` под принципом |
| `corrupt/p1`…`p3` | подделка | 1 | пропущено имя, лишнее имя, другой порядок |
| `corrupt/p4` | подделка | 1 | строки нет при двух именах в исходнике — никогда не 0 |
| `corrupt/p5`, `p6` | подделка | 1 | чужая строка постусловия; строка не сразу после `вид postcondition` |
| `corrupt/p7` | подделка | 1 | исходник `для всех дно`, принцип по «стопка» — индукция по имени вне списка |
| `corrupt/p8` | подделка | 1 | строка `для всех` при постусловии без квантора (`binder-wall-map`, строка 60) |

Шапки записей с изменённым исходником посчитаны по файлу (строк, знаков, два
многочленных отпечатка, SHA-256) тем же счётом, что сверяет `сверить_шапку`.

## Чего здесь нет

- Имя в ёлочках с « и » внутри (`«а и б»`) список рвёт — в корпусе таких имён нет.
- Повтор имени (`для всех а и а`) отвергает ядро; сверщик отдельной проверки не
  держит.
