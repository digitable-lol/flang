# Семья «по телу без ходов»: разбор суммы, развёртка на конструкторе списка, равенство по телу

Ядро закрывает эти места правилами «тождество после переписки допущением», «разбор цели
по условию» и «вычисление замкнутой цели» и не печатает под ними ходов. Оба сверщика —
на C (`flang/proof/checker/checker.c`) и на Lean (`flang/proof/checker/second/`) —
переигрывают их по исходнику (ADR-0198, §5).

| приём | где в сверщике на C | где во втором |
|---|---|---|
| посылка с правилом тождества в булевом домене узла разбора суммы | `правило_вне_домена` | `Node.lean`, `правилоВнеДомена` |
| образец ветви «любое» у варианта с полями, имя поля не занято целью и доводом | `образец_любого` | `Node.lean`, `образецЛюбого` |
| развёртка на `пустой список`, на `[Г, …]`, на доводе — вызове плоской функции | `развернуть_вариантом`, `развернуть_пустым`, `развернуть_плоское_метками` | `Body.lean`, `развернутьВариантом`, `развернутьПустым`, `развернутьПлоскоеМетками` |
| вызов в хвосте терма берётся в скобки для развёртки вглубь | `вызов_в_скобки` | `Body.lean`, `вызовВСкобки` |
| листья равенства сличает `тождественны` | `равенство_правилами` | `Node.lean`, `равенствоПравилами` |
| место без принципа: тело вместо `результат` и те же переписки | `тождество_по_телу` | `Node.lean`, `тождествоПоТелу` |

## Что здесь лежит

Записи — печать ядра. Подделки строит набор проб правкой исходника (запись
переподписывается) или записи.

| файл | класс | код | что это |
|---|---|---:|---|
| `shapes` | честная | 0 | «круглая, либо углы есть»: два варианта идут в ветвь «любое» |
| `lists` | честная | 0 | длина после приписывания (по телу) и после вставки (индукция по списку) |
| `box` | честная | 0 | ветвь «любое» у варианта с полем `н`, довод назван `м` |
| `shapes`, без посылки «Треугольник» | подделка | 1 | разбор не покрывает варианта |
| `lists`, `плюс 2` | подделка | 3 | ложная переписка по телу |
| `lists`, ветвь «иначе» без головы | подделка | 3 | шаг индукции не сходится |
| `lists`, база `[значение, значение]` | подделка | 3 | развёртка выписанного списка даёт 2 против 1 |
| `box`, довод назван `н` | подделка | 3 | имя поля совпадает с доводом; без проверки имени запись принималась бы кодом 0 |
