# Семья «ограничение»: «таких что» и допущения теоремы (ADR-0026 К5)

Форма записи:

| где в исходнике | строка записи | где в записи |
|---|---|---|
| `для всех н таких что P обеспечивает …` | `таких что ⟨P⟩ строка N` | сразу под `для всех «н» строка N` |
| теорема: `дано н: T таких что P` | `дано «н» строка N`, затем `допущение ⟨P⟩ строка N` | в теореме |
| теорема: `дано P` (гипотеза) | `допущение ⟨P⟩ строка N` (строки `дано «…»` нет) | в теореме |
| шаг `по предположению`, закрытый допущением J | суффикс ` допущение J` у строки шага | — |

Что делает сверщик: ограничение постусловия и каждое допущение сличает с
исходником как терм; номер строки и порядок допущений сличает разметка теоремы
(исходник даёт метку «допущение N»); у шага с ` допущение J` проверяет, что J
есть среди допущений записи. Сам вывод цели из допущения сверщик не
переигрывает — место на слове ядра, как у всякого «по предположению»; поэтому
честные записи здесь дают код 3, а не 0.

Строки нет при ограничении или допущении в исходнике — код 1 всегда: «проверено»
без строки не выдаётся, и ограничение не отбрасывается молча (запись матрицы
ADR-0026 З10 — принцип без ограничения над ограниченным квантором — код 1).

Гипотеза теоремы `дано P` обязана быть допущением утверждения: стоять в «таких
что», в «требует» или в объявленном типе. Гипотеза, которой у постусловия нет, —
код 1, «не является допущением утверждения».

## Что здесь лежит

Исходники — эталонные входы квантора, байт в байт. Записи РУКОТВОРНЫЕ; шапки
посчитаны по файлу тем же счётом, что сверяет `сверить_шапку`.

| файл | класс | код | что это |
|---|---|---:|---|
| `f09-restricted.{flang,record}` | честная | 3 | постусловие с «таких что», без теоремы; запись З10 + строки `для всех`/`таких что` |
| `k2bk-theorem-such-that.{flang,record}` | честная | 3 | теорема `дано н: неотрицательное таких что н больше 0`, шаг `по предположению допущение 1` |
| `k2b-direct-theorem-hypothesis.{flang,record}` | подделка | 1 | теорема с гипотезой `дано н больше 0`, которой у постусловия нет |
| `corrupt/z10-restriction-lost` | подделка | 1 | запись З10 матрицы как есть |
| `corrupt/other-restriction` | подделка | 1 | `таких что ⟨н больше 1⟩` |
| `corrupt/restriction-not-under-the-quantifier` | подделка | 1 | строка `таких что` выше `для всех` |
| `corrupt/assumption-outside-the-list` | подделка | 1 | шаг закрыт допущением 2 при одном допущении |
| `corrupt/assumption-lost` | подделка | 1 | нет строки `допущение` у `дано … таких что …` |
| `corrupt/other-assumption` | подделка | 1 | `допущение ⟨н больше 1⟩` |
| `corrupt/hypothesis-without-assumption-line` | подделка | 1 | гипотеза `дано н больше 0` без строки `допущение` |

## Чего здесь нет

- Ограничение в свободном утверждении (`утверждение … для всех н: T таких что P`)
  — в семье «утверждение».
- Вывод цели из допущений «при фактах» сверщик не переигрывает (новых законов
  арифметики эта семья не вводит; `н > 0 ⇒ н − 1 ≥ 0` — ADR-0027).
