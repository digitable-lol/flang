# Семья «rewrite»: склейка строк — моноид, переписка по доказанному утверждению

Задача 4722, решение [ADR-0040](../../../../../../adr/0040-a-simplifier-rewrites-by-proved-equalities-and-prints-every-step.md)
с поправкой задачи о встроенной склейке. Записи РУКОТВОРНЫЕ: ядро этих ходов
ещё не печатает — сбор доказанных равенств и печать шагов (4722 п.3–4) идут
правкой `flang/self` и доедут перепечаткой. Шапки посчитаны по файлу тем же
счётом, что у сверщика (строки, знаки, два отпечатка, sha256).

## Три закона склейки — законы формы

Встроенная `соединить А с Б` определения в языке не имеет: ядру нечего
развернуть, а индукция по строке (задача 7359) закона не докажет без того же
встроенного равенства — шаг «( голова ++ хвост ) ++ Б» упирается в
ассоциативность склейки с головой. Поэтому законы моноида склейки — законы
формы встроенной функции, как «Мера склейки» у её длины. Ход
`переписать формой ⟨Л⟩ = ⟨П⟩ законом «…»`; правую сторону сверщик собирает из
левой сам, одним применением:

| закон | левая | правая | лемма Lean |
|---|---|---|---|
| «Склейка ассоциативна» | `соединить ( соединить А с Б ) с В` | `соединить А с ( соединить Б с В )` | «Скл1», «Скл1-терм» |
| «Пустая склейка слева» | `соединить "" с А` | `А` | «Скл2», «Скл2-терм» |
| «Пустая склейка справа» | `соединить А с ""` | `А` | «Скл3», «Скл3-терм» |

Отказ склейки на стыке половин суррогатной пары (цели с UTF-16) и на октете
продолжения (цели с октетами) у обеих сторон каждого закона один и тот же; в
модели Lean отказа нет, и это граница модели, названная у «Скл1».

## Переп1 — переписка по доказанному утверждению

```
ход K переписать по свойству «И» строка M ⟨Л'⟩ = ⟨П'⟩ подстановка «х» ⟨т⟩ …
```

Законность инстанции проверяет путь хода `факт по свойству` (К3c): строка M —
заголовок `утверждение «И»`, «И» проверено по существу РАНЬШЕ (реестр), круг
обоих уровней, пары ровно по одной на связанное имя в их порядке, захват имён.
Сверх него переписка требует: у «И» нет `таких что` (ограничение снимается в
точке, а переписка идёт по всем вхождениям, и под связывателем цели имя значит
другое); цель «И» — голое равенство «Л равен П» (не «не равен», не связка, не
выбор); запись несёт ровно ту инстанцию, что собрал сверщик, ориентацией «И» —
слева направо; левая стоит в цели. Лемма «Переп1» (и «Переп1-термТ»,
«Переп1-термЧ» на терме), ловушки 80 и 81.

Связывания одной строкой (`для всех а: Т и б: У и ц: В`) путь инстанции
теперь читает все — по « и » верхнего уровня, как сверка блока (5144); прежде он
брал только первое имя, и пары «по одной на каждое» не сходились.

## Что лежит

| файл | класс | код | что это |
|---|---|---:|---|
| `concat-laws.{flang,запись}` | честная | 0 | ассоциативность и две нейтрали склейки — по ходу формы на каждое |
| `rewrite-by-statement.{flang,запись}` | честная | 0 | «Четыре части» — две переписки по «склейка ассоциативна» с нетождественными подстановками; «Приклеить пустое» — переписка по «пустая строка нейтральна справа» (имя несёт слово «строка») |
| `concat-false.flang` | — | — | исходник двух лживых записей ниже |
| `forged/commutative-law.record` | подделка | 1 | закон «Склейка перестановочна» — не из списка |
| `forged/nonempty-unit.record` | подделка | 1 | «Пустая склейка справа» у `соединить а с "х"` — левая не той формы |
| `forged/unproven-statement.record` | подделка | 1 | «склейка ассоциативна» не доказана в записи — «не доказано РАНЬШЕ» |
| `forged/restricted-rewrite.{flang,запись}` | подделка | 1 | у утверждения `таких что` — правилом не берётся |
| `forged/or-rewrite.{flang,запись}` | подделка | 1 | цель утверждения — связка `(…) или нет`, не голое равенство |
| `forged/negated-rewrite.{flang,запись}` | подделка | 1 | «(длина "аб") не равен 3» доказано счётом; разрез по слову прочёл бы его равенством «( длина "аб" ) не» = «3», и ложное «длина "аб" не больше 1» закрылось бы счётом «3 больше 1» |

Ещё пять подделок прогон порождает правкой строки честной записи (`podd_p`):
правая ассоциативности с перестановкой; инстанция, не та, что даёт
подстановка; ориентация справа налево; подстановка, захватывающая имя; левая
инстанции, которой в цели нет; утверждение, переписывающее само себя (круг).

## Отрицательный контроль

Каждая новая проверка вынута из копии сверщика по одной, набор проб прогнан
этой копией (15 сентября 2026):

| вынуто | что покраснело |
|---|---|
| сверка `""` у «Пустая склейка справа» | `nonempty-unit` принята КОДОМ 0 |
| сличение инстанции с записью | «инстанция не та» и «справа налево» приняты КОДОМ 0 |
| хвост « не» у голого равенства | `negated-rewrite` — ложное обещание принято КОДОМ 0 |
| «левая стоит в цели» | тот же код 1, причина другая — проба ловит причину |
| отказ по `таких что` | тот же код 1 (ограничение не снято в точке), причина другая |

## Чего здесь нет

- Ветки голого равенства «связка или выбор сверху» пробой не держатся:
  утверждение, чья цель — связка или выбор без скобок, сверщик доказанным не
  проигрывает (связка требует скобок, «Закон признака» — простых частей), и
  сделать из него подделку сегодня нечем. Вынутая, эта ветка не роняет ни одной
  пробы; стоит она на день, когда такое утверждение станет доказуемым.
- Печати ядра: ядро законов склейки и шага Переп1 ещё не печатает.
- Строк ведомости `tables/inference-rules.tsv`: сторож С-1 пускает строку только с
  опорой в ядре, и строки Переп1, Скл1–Скл3 встанут вместе с правилом ядра.
