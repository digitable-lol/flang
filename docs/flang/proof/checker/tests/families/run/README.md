# Семья «прогон»: утверждение о последовательности шагов

Основание — [ADR-0032](../../../../../../adr/0032-one-missing-rule-and-three-other-logics.md)
§3.1. Сверщик читает строку `прогон «Ф» шаг «Ш» строка N` и сверяет её с
исходником.

## Что такое прогон здесь

Один шаг — функция «В ящик» (образ одноимённой из `flang/concurrency/scheduler.flang`,
чьё постусловие «письмо прибавляется ровно одно» доказано, ADR-0017 §2).
Последовательность шагов — свёртка «Все в ящик» по списку писем. Утверждение о
ней — свободное (ADR-0026 §11 п. 3), связывает два имени:

```
утверждение «за прогон ящик растёт ровно на число писем»
  для всех письма: список «Письмо»
  для всех ящик: список «Письмо»
  утверждаем (длина («Все в ящик» от ящик и письма)) равен ((длина ящик) плюс (длина письма))
```

Ни одного особого слова языка в исходнике нет: последовательность шагов пишется
свёрткой. Постусловие свёртки «писем прибавляется ровно столько, сколько
положено» ядро доказывает правилом «тождество после переписки допущением», а
свободное утверждение о свёртке — правилом «цель есть допущение» (сведением к
постусловию свёртки); `bootstrap/flang check --proof` отвечает «утверждений 3:
доказано 3». Ходов индукции по прогону запись не несёт, и сверщик держит место на
слове ядра.

## Строка «прогон» и что сверяет сверщик

`прогон «Все в ящик» шаг «В ящик» строка 24` стоит в блоке `вид statement`
сразу под связываниями (`для всех` / `таких что`). Сверщик читает с исходника:
на строке 24 от края стоит объявление функции «Все в ящик»; тело её — свёртка;
свёртка зовёт «В ящик»; цель утверждения зовёт «Все в ящик». Расхождение — код 1
с названной причиной. Индукцию по прогону сверщик не переигрывает: честные
записи остаются на слове ядра, код 3, никогда 0.

## Что здесь лежит

| файл | класс | код | что стережёт |
|---|---|---|---|
| `letters-in-turn.flang` + `letters-in-turn.record` | честная (печать ядра) | 3 | утверждение без функции — на слове ядра |
| `with-a-run.record` | честная, РУКОТВОРНАЯ (запись ядра плюс строка «прогон») | 3 | строка прочитана и сверена; ни одной «не узнана» |
| `corrupt/foreign-step.record` | подделка | 1 | шаг назван чужой — «свёртка не зовёт шаг «Ящик»» |
| `corrupt/not-a-fold.record` | подделка | 1 | прогоном назван «В ящик» — «тело функции не свёртка» |
| `corrupt/wrong-line.record` | подделка | 1 | строка 17 — «не объявление функции «Все в ящик»» |
| `corrupt/goal-does-not-call.record` | подделка | 1 | назван «Только письма» (свёртка тем же шагом) — «цель утверждения его не зовёт» |
| порчей строки в прогоне | подделка | 1 | строка «прогон» под `вид postcondition` — «стоит не сразу под строкой «для всех»» |

Функция «Только письма» в исходнике нужна только последней порче: это тоже
свёртка тем же шагом, и отличить её от «Все в ящик» можно лишь по цели.
