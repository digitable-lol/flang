# Семья «спуск формой»: индукция по отрезку в свободном утверждении

Правило Инд5, [ADR-0075](../../../../../../adr/0075-a-free-statement-gets-segment-induction-integer-tightening-and-enumeration.md) §2.1.
Принцип у свободного утверждения `для всех п: неотрицательное` строится формой:
посылка «дно» — цель при допущении «п не больше 0», посылка «спуск» — цель при
допущении «п больше 0» и допущении индукции на «п минус 1». В записи носитель
`segment-form`.

Сверщик требует этот носитель только у свободного утверждения и `segment` только
у постусловия, требует ровно две посылки («дно» вида base, «спуск» вида step) и
проигрывает их сам: вызов «Ф» от п с телом из одного `если` и дном на нуле
разворачивается ветвью дна либо ветвью спуска, затем равенство сличается с
перепиской допущением индукции, а неотрицательность — по построению. Посылку,
которую ядро закрыло правилом Кол5 (сумма над отрезком с литералами, ADR-0075
§6), сверщик не переигрывает: место остаётся на слове ядра, код 3.

| файл | класс | код | что это |
|---|---|---:|---|
| `descent.{flang,record}` | честная | 0 | «спуск даёт ноль» (тождество) и «сумма до неотрицательна» (неотрицательность), оба узла проиграны |
| запись без посылки «дно» | подделка | 1 | шаг без базы |
| запись без посылки «спуск» | подделка | 1 | база без шага |
| `segment` вместо `segment-form` | подделка | 1 | спуск с тела у свободного утверждения |
| `segment-form` в `case-split-segment/00-untouched` | подделка | 1 | спуск формой у постусловия |
| исходник с целью «равен 1» | подделка | 1 | стороны дна замкнуты и разные |
| `literal-sum.{flang,record}` | честная | 3 | проба задачи 7367 без теоремы: `((а плюс 1) плюс 2) равен (а плюс (1 плюс 2))` на `а: неотрицательное` ядро закрывает правилом Кол5 (ADR-0075 §6) под именем «тождество после переписки допущением»; у сверщика приёма Кол5 нет — место на слове ядра, запись исходнику не противоречит |
| `literal-sum-induction.{flang,record}` | честная | 3 | та же цель теоремой `индукция по а`: носитель `segment-form`, посылки «дно» и «спуск» закрыты Кол5; сверщик сличает «( а плюс 1 ) плюс 2» с «а плюс 3» и честно не берётся — 3 места на слове ядра |
