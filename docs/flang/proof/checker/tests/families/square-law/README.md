# Закон квадрата и Т без скобок

Закон ядра «квадрат под оговоркой» закрывает цель
`не ((Т минус Т) равен 0) или (Т умножить на Т) не меньше 0` без посылок: где `Т минус Т`
не ноль, `Т` не конечно, а квадрат конечного неотрицателен. Сверщики узнают `Т` разрезом
текста по `минус` и по `умножить на` и о старшинстве знаков не знают.

`square-without-brackets.flang`: `Т` = `а плюс (б минус 12345.678)` стоит без скобок.
`а плюс (б минус К) минус а плюс (б минус К)` читается `((а плюс (б минус К)) минус а)
плюс (б минус К)`, то есть `2 × (б минус К)`, а `а плюс (б минус К) умножить на а плюс
(б минус К)` — `а плюс ((б минус К) умножить на а) плюс (б минус К)`. При `а = −1`,
`б = 12345.678` оговорка ложна, а правая часть равна `−1`: утверждение ложно. Запись
закрывает его одним ходом `закон «квадрат под оговоркой»`.

Оба сверщика берут закон, только когда `Т` — одно слово либо одна пара скобок. Без этой
проверки оба приняли бы запись кодом 0; с ней она получает код 1.
