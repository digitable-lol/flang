# Факт из чужой цели

Ход `факт по свойству` вносит в прогон экземпляр доказанного раньше утверждения, когда
оплачено его требование либо ограничение `таких что`. Оплата бывает охраной первой цели:
в цели `если У то А иначе да` условие `У` верно там, где нужна `А`. Такой факт верен
только для этой цели.

`fact-from-another-goal.flang`: утверждение «срез всякого есть оно само» —
`(если н больше 0 то (1 равен 1) иначе да) и притом ((«Срез» от н) равен н)`, где
`«Срез» от н` есть `н плюс 0`. Оно ложно при `н = −0`: `−0 плюс 0` есть `+0`. Запись
делит цель связкой, вносит факт «срез положительного есть оно само» (ограничение
`н больше 0` оплачено охраной первой половины), закрывает первую половину делением и
выбором, а вторую — тем же фактом, хотя там `н больше 0` никто не обещал.

Факт живёт до следующего хода: любой ход, кроме `факт` и `закрыть по свойству`, его
снимает. Без этого оба сверщика приняли бы запись кодом 0; с этим она получает код 1:
«факта не внесено».
