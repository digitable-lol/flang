# Семья «строка по знакам»: склейка разложения (Тожд3) и свёртка по знакам строки (Инд4)

Основание — [ADR-0040](../../../../../../adr/0040-a-simplifier-rewrites-by-proved-equalities-and-prints-every-step.md)
§2.5. Строки ведомости `Тожд3` и `Инд4`, леммы «Тожд3», «Инд4», «Инд4-знак» и
встречные примеры «Тожд3-со-связкой-ложна», «Инд4-чужой-список-ложна» в
`flang/proof/lean/Rules.lean`, искажения 60 и 61 в `Trap.lean`.

## Что стережётся

* **Тожд3** — `соединить (разложить Т на символы) по ""` есть `Т`. Связка — ровно
  литерал пустой строки, внутри — разложение ровно одного довода. В записи — ход
  `переписать формой ⟨…⟩ = ⟨Т⟩ законом «Склейка разложения»`, и сверщик
  пересобирает правую сторону сам (`форма_законом`).
* **Инд4** — тело функции `свёртка (разложить Т на символы) …`, где `Т` —
  строка-параметр: принцип свёртки по числу витков, элемент витка объявлен знаком
  (строкой длиной 1), пройденный кусок — списком знаков, а в цели `Т` заменяется
  склейкой пройденного куска. Свёртка по знакам ДРУГОЙ строки и свёртка по кускам
  `разделить` принципа по строке не получают.
