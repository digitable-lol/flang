# Чтение теорем и принципов индукции

Пробы на записи ядра, которые сверщики раньше называли противоречием исходнику, хотя
противоречия не было.

- Место утверждения ищется по номеру строки из заголовка блока записи, а не по
  тексту строки: одно и то же постусловие (`обеспечивает «правилен» …`) бывает
  написано в нескольких функциях, и тип переменной индукции берётся из `принимает`
  той функции, которой принадлежит строка.
- Имя в ёлочках делится на части только вне ёлочек: тип `«Норма и носитель»` в
  `для всех пара: «Норма и носитель»` остаётся одним именем.
- Запись (`объект`) для принципа индукции — сумма из одного варианта с именем
  самой записи, как её печатает ядро; у свободного утверждения сведение посылки не
  требует ветви функции.
- Пример по ветви, тело которой — вызов, сверяется значением: вызов считается
  вычислителем сверщика и сличается с `ожидается`; не считается — место остаётся
  на слове ядра.

| файл | что | код |
|---|---|---|
| `same-claim-in-four-functions.flang` | постусловие «правилен» в четырёх функциях, индукция по встроенному списку | 3 |
| `object-name-with-and.flang` | запись `«Норма и носитель»` в связывании утверждения | 3 |
| `induction-over-an-object.flang` | индукция по записи `«Пара норм»` | 3 |
| `function-named-like-its-record.flang` | функция «Язык» строит `запись «Язык»` | 0 |
| `example-through-a-call.flang` | пример на ветви `«Сцепить» от …` | 0 |
| `example-through-a-wrong-call.flang` | ветвь-вызов отдаёт не то, что ждёт пример | 3 |
