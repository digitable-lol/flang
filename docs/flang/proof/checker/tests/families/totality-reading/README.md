# Чтение вызовов в теле функции

Тотальность композицией сверщики проверяют по программе: список зовомых
пересобирается из тела функции. Тело читается как код: строковые литералы
(`"…"`, `'…'`, `"""…"""`), примечания `//` и `/* … */` стираются до чтения, ёлочное
имя остаётся целиком. Вызовом считается имя в ёлочках со словом `от` после него,
сама функция или функция, объявленная в исходнике. Конструкторы — `вариант «…»`,
`случай «…»`, `запись «…»` — и поле `.«…»` вызовами не считаются: функция может
строить запись своего же имени, и это не самовызов.

| файл | что | код |
|---|---|---|
| `guillemet-in-a-string.flang` | ёлочка и `/*` внутри строкового литерала, настоящий вызов после него | 0 |
| `record-named-like-its-function.flang` | функция «Язык» строит `запись «Язык»` | 0 |
| `self-call-after-a-guillemet.flang` | самовызов после ёлочки в строке при записи «самовызова нет» | 1 |
