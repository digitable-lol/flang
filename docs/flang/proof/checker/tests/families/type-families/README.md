# Семья «семейства отношений»: порядок, строгий порядок, соседние, вхождение, начало

Ведомость правил — [`flang/proof/tables/inference-rules.tsv`](../../../../../../../flang/proof/tables/inference-rules.tsv);
форма блока `вывод` задана типами `flang/proof/lean/Record.lean` (см. README сверщика).

## Зачем

Кроме «Т не меньше 0» и «Т не больше ЛИТЕРАЛ» блок `вывод` несёт цели, которые ядро
закрывает порядком, строгим порядком, порядком соседних, вхождением и началом
строки. Здесь стоят правила этих семейств и пробы на них.

## Что здесь лежит

| файл | что это |
|---|---|
| `families.flang` | двадцать пять функций — по одной на вид вывода пяти семейств отношений и семейства дна |
| `families.record` | честная запись: у каждого утверждения блок вывода |
| `corrupt/strict-from-non-strict.flang`, `.record` | допущение НЕСТРОГОЕ, а вывод назван строгим: постусловие на таком исходнике ложно |
| `corrupt/membership-of-another-member.flang`, `.record` | в список кладут одно, а вхождение заключают о другом |
| `corrupt/neighbours-without-the-assumption.flang`, `.record` | допущение о голове хвоста из исходника убрано, а список объявлен неубывающим |

Три подделки лгут ИСХОДНИКОМ, а не записью: тело либо допущение правится так, что
утверждение на нём ложно, а отпечаток пересчитывается честно. Ловит их не ведомость
отпечатков, а сам приём — чтением строки исходника.

Записи РУКОТВОРНЫЕ: сверщик читает эти блоки независимо от того, печатает ли их ядро.

## Мерило

Честная запись — код 0, все двадцать пять мест сняты со слова ядра («выводов факта о
типе проиграно заново 25»), долг ноль. Три подделки исходником — код 1, и причину
называет проверка вывода. Ещё двадцать три подделки собираются порчей одной строки
честной записи прямо в прогоне (`tests/probes.tsv`, «семейства»): на каждый
вид отказа своя проба и своя названная причина.
