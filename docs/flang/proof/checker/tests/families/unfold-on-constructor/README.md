# Развёртка вызова на выписанном конструкторе

Семья проб на записи, которые ядро печатает, когда у вызванной функции тело —
`разбор` довода, а на месте довода стоит выписанное значение: конструктор
варианта, `приписать Х к Л`, вариант без своей ветви (`случай любое`), разбор с
вложенным разбором другого параметра. Правила — Разв4, Разв5, Разв6, Инд7 и
запрет Разв✗ ([ADR-0112](../../../../../../adr/0112-the-kernel-unfolds-a-call-on-a-built-constructor.md)).

## Что сверщик делает сам

Записи у таких утверждений нет ничего, кроме имени правила. Сверщик подставляет
тело функции на место `результат`, разворачивает вызов по выписанному конструктору
(своя ветвь, ветвь «любое», ветвь звена для `приписать`), разносит разбор по
разбору, у которого образцы не связывают имён, и закрывает цель тем же булевым
замыканием, что и разбор цели по условию. У свободного утверждения с теоремой
индукцией посылка шага закрывается тем же замыканием, а допущение индукции стоит
в нём фактом.

## Пробы

| файл | что | код |
|---|---|---|
| `built-constructor.flang` | запись ядра в исходниках: одиннадцать постусловий доказаны, ложное «ложь» — нет | 0 |
| то же с правкой исходника | пять подделок: ноль вместо головы, рекурсивный вызов без «Сменить», ноль в поле вложенной ветви, красный в ветви «любое», записанное значение в ветви «иначе» | 3 |
| `two-argument-match.flang` | теорема индукцией, шаг через функцию с вложенным разбором по двум доводам; сверщик закрывает посылку шага с допущением индукции фактом | 0 |
| то же, теорема обещает «да» | база «Ноль» посчитана: «нет» против «да» | 1 |
| `field-twice.flang` | запись двоичного 0.7.28: поле сведено второй раз под именами вызванной, ложное постусловие объявлено доказанным | 3 |
