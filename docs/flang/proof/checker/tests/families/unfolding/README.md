# Семья «развёртка»: вызов, поле выписанного конструктора, разбор суммы в цели

Задача [6432](../../../../../../tasks/6432-measure-projection-and-declared-sums-close-five-kernel-word-places.md),
решение — [ADR-0042](../../../../../../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.
Строки `Разв3`, `К↑` и расширенная `Разв1` — в `flang/proof/tables/inference-rules.tsv`;
леммы «Разв3», «К↑», «Разв1-сумма» — в `Rules.lean`; ловушки 20–22 — в
`Trap.lean`. ADR-0022 §3.8 («деструктор не входит») сужен ровно на поле
ЗНАЧЕНИЯ, построенного тут же: поле неизвестного значения — по-прежнему запрет.

## Что стережётся

| место корпуса | что печатает ядро | что сличает сверщик |
|---|---|---|
| `equality` Р1 «круг: достали то же, что положили» | `Выч` ⟨н равен н⟩ → `К↑` ⟨( вариант «Коробка» с «внутри» равным н ) .«внутри» равен н⟩ → `Разв3` «Положить в коробку» → `Разв3` «Достать из коробки» → `Разв3` своё тело | К↑: сторона — поле выписанного конструктора, равное стороне посылки; Разв3: один вызов развёрнут телом вызванной (плоским), доводы на местах параметров; «результат» — своим телом, которое зовёт |
| `types` Т1 «разбор в постусловии» | `Выч` ⟨н равен н⟩ → `Разв1` ⟨разбор ( вариант «Успех» с «значение» равным н ) случай …⟩ → `Разв2` | Разв1 «из N»: разбор выписанного конструктора — ветвь своего варианта, поле на месте связанного имени; цель-разбор читается всеми строками под `обеспечивает` |

## Круг через коробку допущением (приёмка Lean К↑ и Разв3 в прогоне)

`box-round-trip-by-assumption.flang` + `.запись` — честная пара, запись
РУКОТВОРНАЯ. Блок печати ядра у «Круг через коробку» (`equality.запись`) базой
ставит шаг `Выч ⟨н равен н⟩`, а вычислитель половин модель Lean не повторяет, и
сверка вердиктов (`flang/proof/lean/run.sh`) ставит весь блок «вне приёмки»
на первом же шаге — до К↑ и Разв3 она не доходит. Здесь та же функция с
допущением `требует «н равно себе» н равен н`, и база — `Т1` с этой строки; за
ней те же К↑ и три Разв3. Сверщик — код 0, Lean — «принял» весь блок: так
приёмка К↑ и Разв3 проверяется в самом прогоне, а не пробой вне набора
(задача 6432, «Ход работы»).
