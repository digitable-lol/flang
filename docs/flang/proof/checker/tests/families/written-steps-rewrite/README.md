# Семья «переписка выписанными шагами» — равенства шагов «затем» переписывают цель

Решение — [ADR-0187](../../../../../../adr/0187-a-theorem-step-equality-rewrites-the-goal-of-the-closing-step.md).
Код — `flang/proof/checker/tests/families/written-steps-rewrite/`.

Теорема «квадрат» (`Мет` от `Разв` — пометка развития) выписывает три равенства постусловиями функций и закрывается
свободным утверждением «шаг», которое к исходной цели не прикладывается, а к цели,
переписанной этими равенствами, — прикладывается:

```
    шаг 1 строка 52 промежуточный по свойству «разв» свойство строка 26 правило «цель есть допущение»
    шаг 2 строка 53 промежуточный по свойству «отр» свойство строка 14 правило «цель есть допущение»
    шаг 3 строка 54 промежуточный по свойству «об» свойство строка 20 правило «цель есть допущение»
    шаг 4 строка 55 закрывающий по свойству «шаг» свойство строка 35 правило «переписка цели выписанными шагами»
```

Оба сверщика проигрывают каждый выписанный шаг (равенство — постусловие на вызове
внутри него) и переписку закрывающего шага.

## Откуда запись

`square.record` — печать ядра, снятая компилятором этой ветки, запущенным из исходников
(`flang/self/bootstrap/check-with-source-compiler.flang`, только для пробы); строка
`исходник` названа путём файла семьи от корня дерева (так запись сличает и `checker:second`). Записи подделок в `corrupt/` — та же печать,
у которой исходник правлен, а шапка пересчитана.

## Что здесь лежит

| файл или правка | класс | код | что стережёт |
|---|---|---:|---|
| `square.{flang,record}` | честная | 0 | переписка цели тремя выписанными равенствами |
| правка: правило переписки на шаге 1 | подделка | 1 | правило стоит только на закрывающем шаге |
| правка: правило переписки у теоремы «шаг» (одна ссылка на постусловие «мет») | подделка | 1 | переписывать нечем — равенств до шага нет |
| `corrupt/foreign-equalities.{flang,record}` | подделка | 1 | выписанные равенства не касаются цели |
| `corrupt/other-root.{flang,record}` | подделка | 1 | переписанная цель — вызов другой функции, чем у утверждения |

## Чего здесь нет

Проекции поля под вызовом (`(«Отразить» от возможности).опора`): постусловие вида
`результат.опора равно возможности` при теле-записи второй сверщик сам не проигрывает,
и семья держит переписку на вариантах. Переписку под проекцией ядро проверяет пробой
`flang/proof/probes/written-steps` (квадрат из заявки 407).
