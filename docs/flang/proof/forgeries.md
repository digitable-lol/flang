# Набор подделок

Подделка — пара «исходник и запись доказательства», в которой заявлено ложное.
Набор проверяет саму проверяющую программу: принять подделку она не вправе.
Набор объявлен списком `flang/proof/forgeries/manifest.tsv`; имя файла класса не
назначает.

## Манифест

Первая строка — заголовок, дальше по строке на подделку, три колонки через
табуляцию:

| колонка | что в ней |
|---|---|
| `source` | путь к исходнику от корня дерева |
| `record` | путь к записи доказательства; лежит в `flang/proof/checker/tests/records/corpus/` |
| `class` | `record-lies` либо `program-lies` |

Классов два, и требования у них разные:

- `record-lies` — запись противоречит исходнику: объявляет доказанным то, чего
  записанные ходы не проигрывают. Проверяющая программа обязана ответить кодом 1;
  код 0 — провал набора. Обязательства такой записи в числитель доли не идут, а
  из знаменателя выносятся как недостижимые.
- `program-lies` — ложна программа, а запись честна: в ней записано, что на
  ложной половине ядро ничего не доказало, и всё, что оно доказало на честной
  половине того же файла. Верен код 0 либо 3; код 1 — провал: честная половина
  перестала доказываться.

## Кто читает манифест

| читатель | что берёт |
|---|---|
| `flang/proof/checker/tests/run.sh` | класс каждой записи корпуса и ожидаемый по нему код |
| `flang/proof/replay-share.fscript` | какие места вынести из знаменателя доли |
| `scripts/provability.fscript` | проверки 3 и 4 вердикта: набор пойман целиком и не усох |

Запись корпуса с именем `poddelka-*` или `forgery-*`, которой нет в манифесте,
красит прогон: подделка мимо списка не заводится. Убыль строк ловит
[храповик](ratchets.md), ключ `forgeries`.

## Как добавить подделку

1. Положить исходник и снятую запись; запись — в каталог корпуса.
2. Дописать строку в манифест.
3. Поднять `forgeries` в `flang/proof/ratchets.txt`.
4. Прогнать `bootstrap/flang io scripts/provability.fscript --plan Verdict --timeout 900000`.

## Что стережёт каждая подделка

| запись | класс | правило, которое она не даёт ослабить |
|---|---|---|
| `forgery-binder-hides-the-condition` | `program-lies` | правило, снимающее стену связывателя, не вправе доказать заведомо ложное |
| `forgery-if-without-descent` | `program-lies` | принцип по отрезку не даётся телу-«если», у которого убывания нет |
| `poddelka-builtin-emptiness-fact` | `program-lies` | встроенная пустота «пусто Л» есть тот же факт, что «(длина Л) равен 0», и не шире |
| `poddelka-dlina` | `program-lies` | три точные меры длины — голова, звено, склейка — по паре половин на каждый факт |
| `poddelka-dno-proizvedeniya` | `program-lies` | дно произведения берётся лишь при строго положительном дне ОБОИХ сомножителей |
| `poddelka-element-po-nomeru` | `program-lies` | переписка «элемент N в …» идёт только по построению списка |
| `poddelka-integrality-from-fact` | `program-lies` | целость, сказанная фактом, не даёт ни знака, ни потолка, ни целости соседнему терму |
| `poddelka-istinnaya-vetv` | `program-lies` | у цели-выбора с истинной ветвью ветвь «то» обязана быть литералом «да» |
| `poddelka-konyunkciya` | `program-lies` | конъюнкция выводится, только когда доказаны ОБЕ половины |
| `poddelka-krug-pri-rabote` | `program-lies` | развязка постусловий не снимает сторожа круга в НАПЕЧАТАННОМ коде |
| `poddelka-lozhnaya-polovina` | `program-lies` | допущением становится условие ТОЛЬКО истинной половины |
| `poddelka-mera-dliny-stroki` | `program-lies` | список точных мер длины строки закрыт тремя формами |
| `poddelka-nachalo-po-postroeniyu` | `program-lies` | начало по построению: ни правый кусок склейки, ни одна ветвь, ни сличение не с начала |
| `poddelka-ogovorka-o-konechnosti` | `program-lies` | оговорка о конечности читается ядром лишь в четырёх названных границах |
| `poddelka-order-arithmetic` | `program-lies` | у рефлексивности и монотонности сложения есть посылка про не-число |
| `poddelka-porjadok-sosednih` | `program-lies` | порядок соседних по построению не читает ложную ветвь фактом |
| `poddelka-protivorechie` | `program-lies` | список несовместимых пар закрыт: на совместимых допущениях правило молчит |
| `poddelka-ravenstvo-v-tele-ne-dokazyvaet` | `program-lies` | разрешение сличать в теле — не разрешение выводить равенство |
| `poddelka-razbor-sluchaev` | `program-lies` | разбор случаев сводит цель ДВАЖДЫ, а не кладёт дизъюнкт в факты |
| `poddelka-razbor-spiska` | `program-lies` | разбор списка по построению: две двери, и ветвь выбирается точно |
| `poddelka-razbor-vnutrennim` | `program-lies` | разбор внутренним условием требует ОБЕИХ половин |
| `poddelka-razdvoenie-diz` | `program-lies` | расщепляется РОВНО конъюнкция в допущении, а не дизъюнкция |

| `poddelka-slova-celey` | `program-lies` | экранирование имён у восьми целей печати: занятое слово не ломает печать |
| `poddelka-slovo-o-dokazannosti` | `program-lies` | сильное слово о доказанности нельзя сказать про слабое основание |

| `poddelka-sortirovka-ne-ubyvaet` | `program-lies` | «сортировка не убывает» ложно на «не числе» и обязано остаться недоказанным |

| `poddelka-svyortka-shagom` | `program-lies` | шаг свёртки стоит под связывателем: внешнее равенство витку не подсунуть |
| `poddelka-vhozhdenie` | `program-lies` | вхождение по построению: «добавить э к л» не говорит ничего про «д» |
| `poddelka-nositel-chislo-segment` | `record-lies` | носитель segment над доводом типа «число»: отрезка с дном у него нет, и принцип по нему ядро не печатает |
| `poddelka-nositel-psevdonim-ne-otrezok` | `record-lies` | носитель segment над псевдонимом к «число» (тип «Мера» это число): объявление читается по цепочке, отрезка там нет |
| `poddelka-raznost-bez-poryadka` | `record-lies` | разность под порядком (правило Н12): вывод «( цена минус скидка ) не меньше 0» подсунут трём функциям, у которых допущения «скидка не больше цена» нет — оно о другой паре, перевёрнуто либо отсутствует; проверяющая программа обязана назвать «порядок не записан» |
| `poddelka-razv2-sebya` | `record-lies` | развёртка Разв2 спрашивает о захвате имён: тело «э» встаёт под квантор цели «для всех э из [1, 2] : не ( э больше результат )», и связанное э цели ловит свободное э тела; при э = 0 обещание ложно |
| `poddelka-razv3-raznost` | `record-lies` | развёртка Разв3 подставляет доводы разом: «Разность» от б и а при теле «а минус б» есть «б минус а», а подстановка по одному дала бы «а минус а»; при а = 0, б = 1 результат 1, обещано 0 |
