# Храповики доказуемости

`flang/proof/ratchets.txt` держит семь чисел, ниже которых (или выше которых)
дерево опускаться не вправе. Строка — ключ и число через пробел; комментариев и
заголовка в файле нет.

| ключ | что считает | как сверяется | кто читает |
|---|---|---|---|
| `forgeries` | строк в [манифесте подделок](forgeries.md) | замер не меньше числа | `scripts/provability.fscript`, проверка 4 |
| `forgery-numerator` | обязательств, доказанных на честных половинах подделочных файлов | замер не меньше числа | там же |
| `forgery-probes` | проб на подлог в `flang/proof/checker/tests/run.sh` | замер не меньше числа | там же |
| `trap-kinds` | строк `removed` в [таблице ловушки](checker/tests/trap/README.md) | замер не меньше числа | `scripts/provability.fscript`, проверка 1 |
| `trap-goals-on-kernel-word` | строк `kept` в той же таблице | замер не меньше числа | там же |
| `checker-code-lines` | строк кода в `flang/proof/checker/checker.c` без комментариев и пустых | замер не больше числа | `flang/proof/tables-guard.fscript`, проверка С-6 |
| `checker-primitives` | имён в массиве `ПРИМИТИВЫ[]` проверяющей программы | замер равен числу | там же |

`flang/proof/corpus-share.sh` печатает `forgeries` и `forgery-numerator` рядом со
своим замером, чтобы просадку было видно там же, где число.

## Что делает вердикт при нарушении

- Число в прогоне ниже храповика — проверка 1 или 4 отвечает «НЕТ», вердикт
  «НЕ ДОКАЗУЕМ».
- Ключа в файле нет — проверка 4 отвечает «НЕТ»: храповик не называет всех чисел.
- Файла нет — вердикт «не смог измерить».

## Как менять число

Первые пять ключей крутятся только вверх: прибавилась подделка, проба или строка
таблицы — число поднимается в том же коммите. `checker-code-lines` поднимается
только вместе с решением (ADR), которое называет, сколько строк оно разрешает;
строка кода сверх потолка красит проверка С-6.

Проверить другое число, не трогая дерево:

```sh
FLANG_TRAP_RATCHET=/путь/копия.txt bootstrap/flang io scripts/provability.fscript --plan Verdict --timeout 900000
TABLES_RATCHETS=/путь/копия.txt bootstrap/flang io flang/proof/tables-guard.fscript --max-steps 4000000000 --timeout 900000 -- С-6
```
