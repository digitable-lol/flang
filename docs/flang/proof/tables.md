# Таблицы доказательного слоя: `flang/proof/tables/`

Четыре таблицы, у каждой первая строка — заголовок, разделитель — табуляция,
комментариев нет. Их читают программы; прозу о строках держат страницы `docs/`.

## `inference-rules.tsv` — правила вывода

| колонка | что в ней |
|---|---|
| `name` | имя правила, единственное в таблице (Н1, О✗, Разв3, …); им же названа лемма в `flang/proof/lean/Rules.lean` |
| `family` | семейство: Н Кон П Пред О Д С СС В Ч Разв Т Р Инд Тожд Э Св Пр М |
| `kind` | `rule` либо `ban` — запрет, которым не выводится ничего |
| `kernel-rule` | имя, которое ядро кладёт в поле `rule` записи; несколько — через `\|`; `—` — в поле `rule` не попадает |
| `anchor` | `proof-kernel.flang:СТРОКА «Имя функции»` — место ядра, которое это и делает |
| `status` | как ядро относится к тексту решения: `code`, `code-wider`, `code-stricter`, `code-narrower`, `not-in-adr`, `not-in-code` |

Посылки, заключение, побочные условия и категорная запись каждого правила —
[правила вывода](inference-rules.md).

Читатели: `flang/proof/tables-guard.sh` (проверки С-1, С-2, С-4), `flang/proof/lean/run.sh`
(лемма на каждую строку), `scripts/four-coverages.fscript` (покрытие формализации),
`flang/scripts/kernel-lines-to-trust.fscript` (число строк), `scripts/report-provenance.fscript`
(версия семантики).

`inference-rules.digest` — sha256 таблицы, «версия семантики» в шапке вердикта.
Правка таблицы без пересъёма красит С-4; переснять — отдельное действие руками:

```sh
sha256sum flang/proof/tables/inference-rules.tsv | cut -d' ' -f1 > flang/proof/tables/inference-rules.digest
```

## `segments.tsv` — имена встроенного отрезка

| колонка | что в ней |
|---|---|
| `name` | как отрезок [0, 2⁵³−1] пишется в подписи `принимает х: имя` |
| `floor` | нижняя граница, литерал |
| `ceiling` | верхняя граница, литерал; равна «Точному потолку» ядра |
| `integrality` | `integer` либо `fractional` |

Проверка С-5 сличает список с «Названо натуральным» ядра и с `НАТУРАЛЬНОЕ[]`
проверяющей программы на C в обе стороны. Точные десятичные типы, `вес` и
`целое` — не этот отрезок и в таблицу не входят.

## `abilities.tsv` — умения ядра

| колонка | что в ней |
|---|---|
| `number` | номер умения (У1 … У28); под этим номером умение описано в `docs/flang/proof/SPEC.md` |
| `rule` | правило ядра, которому умение принадлежит |
| `anchor` | подстрока, обязанная стоять в `flang/self/proof-kernel.flang` |
| `evidence` | имя функции-улики в `flang/proof/map/abilities.flang` |

Читает `scripts/guards/kernel-abilities-guard.fscript`: ядро, описание и улики
обязаны сходиться на каждой строке.

## `consistency-violations.tsv` — известные нарушения состоятельности

Колонки `key` и `state` (`open` либо `closed`); что стоит за каждым именем —
[известные нарушения состоятельности](known-soundness-violations.md).
