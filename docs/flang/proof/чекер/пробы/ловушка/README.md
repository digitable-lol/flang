# Ловушка проверки 1 «калькулятор снят?» — по одной цели на каждый вид обязательства

Читает её `scripts/доказуемость.sh` (проверка 1). Основание — задача 3781 (ловушка
вместо грепа по имени функции) и ячейка К11 кластера 6202/6203 (9 сентября 2026,
ветка `r/k11-lovushka-po-vidam` от `gh/dev e12837854`).

## Что здесь лежит

| файл | что это |
|---|---|
| `ВИДЫ.tsv` | таблица целей: вид · ждём (`на слове` / `снята`) · исходник · запись · цель · след · признак · код · пометка; шапка файла объясняет колонки. Пометка — чем запись отличается от печати ядра: сегодня одна такая («домен охраны», `ohrana.запись`, правило посылки «Пусто» правлено руками — задача 6204); прибор пометку не читает, читает человек |
| `ХРАПОВИК.txt` | два числа, ниже которых таблица опускаться не вправе: `видов 34` (строк «снята») и `на слове 3` |

Сами пары исходник+запись здесь НЕ лежат: таблица указывает на готовые пробы
дерева — `пробы/семьи/**` и `пробы/записи/Ч*/**`, все ВНЕ корпуса
(`пробы/записи/корпус`), поэтому доля-проигрыванием от ловушки не зависит
(замер: 567 / 651 до и после К11).

## Две половины

**Решающая — «на слове».** Две ∀-цели записи `Ч365/П1-цель-не-равенство`
(«сумма наоборот», «длина растёт на один») доказуемы только вычислением; чекер
обязан оставить их на слове ядра и назвать поимённо строкой «за узел не взялся».
Снял хоть одну — калькулятор в дереве есть.

Третья «не бери» (ячейка К3b, 10 сентября 2026, решение overagent'а — вариант
(а)) — утверждение с несколькими связываниями в ОДНОЙ строке `для всех а: Т и
б: У` (`семьи/утверждение/несколько-связываний`). Формы записи для такой строки
контракт кванторов не называет, сверщик её не читает — и потому ОБЯЗАН оставить
цель на слове ядра с названной причиной: снял бы — значит угадал. Когда контракт
даст этой форме строку записи и сверщик начнёт её читать, цель не удаляется, а
ЗАМЕНЯЕТСЯ другой «не бери»: храповик «на слове» крутится только вверх.

**Обратная — «снята».** 34 цели, по одной на вид обязательства, который чекер
переигрывает сегодня. Виды сняты по коду `сверщик.c`, а не по прозе:

| откуда в коде | виды |
|---|---|
| `без_теоремы` → `проиграть_узел` / `_algebra` / `_fold` | узел segment; algebra — все пять доменов цели: неотрицательность, булева цель, тождество с развёрткой по конструктору, порядок «не больше» и охрана «если У то Ц иначе да» (семья `семьи/algebra-domeny`, К11+); fold |
| `сверить_покрытие` + `объявление_типа` (6203) | носитель с объявления: синоним имени отрезка; псевдоним к отрезку |
| `разбором_цели` | разбор цели по условию |
| `проиграть_блок` (ходы) | соседи; развёртка и закрыть тождеством; деление и выбор |
| `сверить_теорему` → шаги автора | по примеру в случае; по свойству; вне случая (подстановка тела); над списочным телом (оглавление) |
| `шаг_вывода` — семейства ведомости | Н, П, Пред→П3, Т, Разв, О, Д, С, СС, В, Ч |
| `сверить_обязательства` (6202) | обязательство входа, закрытое зовущим |
| `сверить_тотальность` / `сверить_рекурсию` | composition, structure, step |
| `сторож_ложной_переписки` / сличение | тождество знак в знак («сумма трёх») |
| `сверить_высказывание` → `сверить_теорему` → `проиграть_узел` (К3b) | утверждение без функции: сведение к постусловию вызываемой функции (`семьи/утверждение/ф05к-утверждение`) |

Каждая цель «снята» проверяется четырьмя вещами: код чекера равен ожидаемому;
имя цели в выводе чекера НЕ названо (названное имя — беда либо «на слове ядра»);
след вида стоит в записи (иначе цель тихо перестала быть этого вида); признак
вида стоит в сводке (счётчик больше нуля). Любое расхождение — проверка 1
«НЕТ» с именем вида.

## Чего здесь нет

Вид «утверждение без функции» (ADR-0026, К3) — придёт вместе с формой записи от
стека B.
