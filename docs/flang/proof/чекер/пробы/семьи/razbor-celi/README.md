# Разбор цели по условию: семь локальных ходов и условие в скобках (задача 6127)

Золотой сертификат и подделки к новым видам хода/закона сверщика, которыми
места правила «разбор цели по условию» проигрываются ХОДАМИ записи, а не
калькулятором (`половина_закрыта`). Спека формата строк и того, что сверщик
проверяет на каждом ходе, — `docs/design/proof-object-hody-razbora-celi.md`;
это контракт печатнику ядра. Записи здесь РУКОТВОРНЫЕ: печати «разбор цели» в
`zapis.flang` ещё нет (другой стек), поэтому шапки сняты счётом самого сверщика
(строк, знаков, два многочленных отпечатка, SHA-256), а цепочки — по спеке.

Вплетены в `прогон.sh` (семья «разбор цели»); гонять и напрямую:

    make -s -C flang/proof/чекер
    ./flang/proof/чекер/сверщик flang/proof/чекер/пробы/семьи/razbor-celi/razbor.flang \
        flang/proof/чекер/пробы/семьи/razbor-celi/razbor.запись

## Честная запись → КОД 0 проигрыванием

`razbor.flang` / `razbor.запись` — 11 функций, 11 постусловий, по одному на вид.
Прогон: КОД 0, «сведений проиграно заново 11 (ходов проверено 57)», «Узлов
«разбор цели по условию» проиграно заново 0» — калькулятор не зван ни разу.

| функция | вид хода / закона | что проверяется локально |
|---|---|---|
| «Чётность» | `деление ⟨У⟩` при `если ( У ) то` в цели (Б2\*) | условие в скобках стоит в цели условием; заменяется на да/нет |
| «Мера» | `закон «мера неотрицательна»` | цель `длина Т не меньше 0`, Т простой, справа литерал 0 |
| «Квадрат» | `закон «квадрат под оговоркой»` | `не ( ( Т минус Т ) равен 0 ) или ( ( Т умножить на Т ) не меньше 0 )`: четыре Т знак в знак, два нуля |
| «Склейка» | `закон «начало склейки»` | `( соединить Л с Р ) начинается с П`, Л ≡ П — закрыта |
| «Приставка» | `закон «начало склейки»` + `вычислить` | Л ≠ П — остаётся `Л начинается с П`, литералы доводит `вычислить` |
| «Тот же текст» | `закон «пустая приставка»` | цель `Т начинается с ""` |
| «Следует» | `переписать формой … законом «Закон признака»` | ровно одна подстановка из закрытого списка `не да`/`не нет`/`нет или Х`/`да или Х`/… |
| «Ответ» | `переписать формой … законом «Вхождение в выписанный список»` | `[Э₁, …] содержит Х` → `да`, Х знак в знак — член списка |
| «Мера дважды» | `связка ⟨и притом⟩` | цель — связка ровно двух простых половин; обе идут целями |
| «Меньшее» | `связка ⟨или⟩ левая\|правая` | цель — дизъюнкция двух простых половин; названная идёт целью |
| «Порог под пусть» | `подставить пусть строка N` | строка N этой функции — `пусть имя равно значение`; имя одно слово, не довод, в цели стоит |

## Подделки → КОД 1, каждая названа

- `порча/lozh.flang` / `порча/lozh.запись` — те же 11 функций с ЛОЖНЫМИ
  постусловиями под теми же цепочками: остаток `равен 1` под охраной `равен 0`;
  `не меньше 1` под законом меры; `е умножить на д` под законом квадрата;
  склейка «начинается правым куском»; `"аб" начинается с "б"`; `начинается с "а"`
  под законом пустой приставки; `иначе нет` в импликации; `"может"` вне набора;
  `равен 1` в конъюнкции; `равен 0` в дизъюнкции; `пусть сколько равно 0`.
  Сверщик отвергает КАЖДОЕ, называя причину («закон … не подошёл», «незакрытых
  целей 1 — первая «начало начинается с конец»», «терм посчитан = нет, а запись
  несёт ⟨да⟩», «левая сторона … не той формы», «стороны равенства разные»).
- Восемь порч ОДНОЙ строки честной записи (порождаются в `прогон.sh`): деление
  по подтерму вместо условия; закон вне списка; не та половина у `или`;
  `подставить пусть` на строку не-`пусть`; подложная правая сторона у «Закона
  признака»; левая сторона вхождения не из цели; «квадрат под оговоркой» и
  «начало склейки» названы не над своей формой.

Отдельно, рядом с семьёй `булева-цель`: проба на ВАКУУМНЫЙ успех узла
`algebra` — правила всех посылок стёрты, строка «сведение» снята; прежний
сверщик давал КОД 0 и «снято со слова ядра мест 4», не прочитав ни случая,
теперь узел вне приёма, четыре места на слове ядра, КОД 3.
