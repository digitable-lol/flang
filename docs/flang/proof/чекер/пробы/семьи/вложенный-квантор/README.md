# Семья «вложенный квантор»: ∀∀ и ∀∃ (правило Св1)

Задача [5957](../../../../../../tasks/5957-nested-quantifiers-over-elements-are-not-sayable.md),
основание — [ADR-0026](../../../../../../docs/adr/0026-quantifiers-over-any-type-are-a-kernel-change.md)
§11 п.15. Строка ведомости `Св1`, лемма «Св1» и встречный пример
«Св1-без-посылки-ложно» в `flang/proof/lean/Правила.lean`, искажение 12 в
`Ловушка.lean`. Правила семейства Э — в соседней семье «все-элементы» (п.14).

## Что стережётся

Тело квантора по элементам — снова ЦЕЛЬ, а не только выражение:

```
обеспечивает «каждый с каждым положителен» для всех х из результат: для всех м из результат: м больше 0
обеспечивает «каждый есть в исходных»     для всех х из результат: есть такой м, а именно х, что элементы содержит м
```

Разбор даётся РЕКУРСИЕЙ: тело после `:` разбирает тот же «Разобрать цель», что и
цель целиком, поэтому вложение любой глубины не требует новой формы. Правила
семейства Э при этом не меняются; внутрь правил добавлен один ход — **Св1**:
цель `есть такой м, а именно Т, что У` закрывается доказательством `У[м:=Т]`.
Подстановка заперта, если `У` связывает `м` или имя, свободное в `Т`.

Печать идёт ВГЛУБЬ: шаги вложенного квантора стоят ПЕРЕД шагом, который их
сводит, с пересчитанными номерами посылок («Сдвинуть шаги записи»).

## Имя связанной: `у` языком занято

Обе программы сперва были написаны с именем `у`, и обе не разобрались:
`FLANG_PARSE: неожиданное 'у' — это слово занято языком, именем оно быть не
может`. Имена здесь потому `х` и `м` — те же, какими пользуется семья
«существование». Это не ограничение кванторов, а общее правило языка, и в семье
оно записано, чтобы следующий не потратил на него прогон зонда.

## Откуда записи

Записи — ПЕЧАТЬ ЯДРА, снятая толкованием исходников `flang/self` семенем (зонд
`flang/self/bootstrap/zond-k7.flang`, около 10 минут и 12 ГиБ на программу).
Семя ещё не перепечатано и на обеих программах отвечает `FLANG_PARSE`.

## Почему у ∀∃ блока нет — замер, а не замысел

Подстановка записи («Вставить вместо записи») ищет имя ПО ПРОБЕЛЬНЫМ КРАЯМ, а в
форме `есть такой м, а именно х, что У` имя элемента стоит словом `х,` — с
запятой — и потому не подставляется: свидетелем остаётся сам `х`, тела
`элементы содержит х` в допущениях нет, и шагов не выходит ни одного. Развести
запятые пробелами, как разведено двоеточие, НЕЛЬЗЯ: сверщик читает `, а именно `
с запятой вплотную (`разобрать_существование`) и разведённой записи не примет.
Закрывается это подстановкой, знающей запятую, — отдельной работой; до тех пор
ядро такую цель доказывает, а место честно стоит на слове ядра.
