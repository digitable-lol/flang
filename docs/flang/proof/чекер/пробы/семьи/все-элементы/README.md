# Семья «все элементы»: квантор по элементам списка (семейство Э)

Задача [6206](../../../../../../tasks/6206-forall-over-list-elements-is-not-sayable.md),
основание — [ADR-0026](../../../../../../docs/adr/0026-quantifiers-over-any-type-are-a-kernel-change.md)
§11 п.14. Строки ведомости `Э1`–`Э4`, леммы «Э1», «Э2», «Э3-приписать»,
«Э3-добавить», «Э4» и встречный пример «Э2-чужое-свойство-ложно» в
`flang/proof/lean/Правила.lean`, искажение 11 в `Ловушка.lean`.

## Что стережётся

Цель `для всех э из Л: П` ядро выводит ТОЛЬКО по построению списка `Л`, и список
случаев закрыт:

* **Э1** — `Л` пустой: элементов нет, свойство не читается вовсе;
* **Э2** — `Л` есть `отфильтровать Л' где х → У`, и `У` совпадает с `П` с точностью
  до имени связанной. Чужое `У` — отказ (ловушка 11);
* **Э3** — `Л` есть `добавить Х к Л'` либо `приписать Х к Л'`: свойство о `Х`
  доказывается обычной целью, о `Л'` — этим же правилом. Подстановка `П[э:=Х]`
  заперта, если `П` где-либо связывает `э` или имя, свободное в `Х`;
* **Э4** — `Л` есть `если У то А иначе Б`: обе ветви обязаны нести свойство.

Гипотеза индукции и предусловие — правилом допущения (Т1), не новым случаем.
Выписанный список с элементами, `отобразить` и вызов чужой функции семейством Э
не выводятся: у них нет правила.

## Откуда записи

Записи — ПЕЧАТЬ ЯДРА, снятая толкованием исходников `flang/self` семенем (зонд
`flang/self/bootstrap/zond-k7.flang`, около 10 минут и 12–14 ГиБ на программу).
Семя ещё не перепечатано: `bootstrap/flang check` на всех программах этой семьи
отвечает `FLANG_PARSE` («неожиданное `для всех`»), потому что квантор в цели ему
пока незнаком. После перепечатки записи сличить с печатью семени побайтно —
расхождение будет значить, что семя печатает не то, что исходник.

## Чего здесь нет

- Самой программы `чужой-предикат.flang` с её собственной записью: вычислитель её
  НЕ пропускает — постусловие-квантор считается на примере `[3, 0, 5]` и выходит
  ложным (`FLANG_PROPERTY: нарушено свойство «все положительны»`, снято зондом).
  Записи у неё поэтому нет, и подделкой она служит только чужой записью.
- Цели ловушки проверки 1 (`пробы/ловушка/ВИДЫ.tsv`) — строка «вывод по семейству Э»
  указывает на `отбор-положительных`; она же стережёт, что сверщик не перестанет
  за этот вид браться.
