# Семья «объявление»: строка `объявление` под принципом (6203-Ш2)

Ячейка A-Ш2 кластера 6202/6203 (10 сентября 2026, ветка `r/a-sh2` от `gh/dev
71af9d679`). По проекту 6203 (шаг Ш2) ядро печатает под каждой строкой
`принцип тип «Т» по «п» носитель X база Б шаг Ш` ещё одну строку — объявление
типа довода индукции:

```
  объявление <откуда> варианты «В» N …      ← носитель algebra
  объявление <откуда> дно 0 потолок 2⁵³−1   ← носитель segment
  объявление <откуда>                       ← носитель fold
<откуда> = сумма «Т» строка L | запись «Т» строка L | встроенный «Т»
         | псевдоним «А» строка L → <откуда>
```

N у варианта — число его рекурсивных частей (полей ровно типа «Т»; поле
`список «Т»` не в счёт), варианты — в порядке объявления, L — строка объявления
в исходнике. Правило «сверщик раньше ядра»: сверщик читает строку до того, как
ядро начнёт её печатать.

Что делает сверщик (`сверить_покрытие`, `сверить_строки_записи`): сличает
строку ЗНАК В ЗНАК со своей читкой того же объявления (`объявление_типа`, одна
точка для Ш0 и Ш2) и при расхождении называет первое расходящееся слово; строка
не сразу под принципом — отказ; записи без строки (весь корпус сегодня)
принимаются, как до Ш2.

## Чего здесь нет (названо, не спрятано)

- Честной записи с `запись «Т»` (`объект`) нет: ядро сегодня не даёт принципа
  по объекту (матрица ADR-0026, ф02), строка для него — только грамматикой.
- Встроенная `строка` под algebra печатается теми же вариантами, что список
  (`«пусто» 0 «голова и хвост» 1`) — прочитано по коду ядра B
  (`proof-initial.flang` «Объявление строки»), эталона нет.
- Цепочка псевдонимов длиннее одного звена — только грамматикой.
- После перепечатки ядра (партия №1) — сличить печать ядра с этой семьёй:
  `diff` 28 записей корпуса обязан показать только строки `объявление`.
