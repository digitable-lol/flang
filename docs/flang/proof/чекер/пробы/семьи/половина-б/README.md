# Золотые сертификаты семей С3/С4/С5 (задача 4122, Половина Б)

Рукотворные сертификаты (исходник + запись), которыми проверено, что след
семей **С3 «длина»** (ход `переписать формой`, законы Д1–Д5), **С4 «элемент по
номеру»** (тот же ход, закон «Развернуть элемент по номеру», Э1–Э4) и
**С5 «замкнутая арифметика»** (ход `вычислить`) проигрывается СЕГОДНЯШНИМ
чекером (`сверщик`) — без правки ядра и без перепечатки. Три хода уже влиты
задачами 4105–4107; это цели проверки для печати (задача 4119) и защита от
регресса, тем же приёмом, каким 4104 сделал С1/С2 (`../sosedi.*`,
`../refleksiv.*`, `../порча/`).

**В `прогон.sh` эти фикстуры НЕ вплетены** — гонять напрямую:

    make -s -C flang/proof/чекер
    ./flang/proof/чекер/сверщик <исходник.flang> <запись>

## Верные сертификаты → КОД 0

- `dlina.flang` / `dlina.запись` — С3, 5 мест (У4 «Знаки текста» Д4, У5
  «Дописать в конец» Д1, У6 «Дописать в начало» Д2, У7 «Склейка строк» Д3,
  «Единицы»/С3 Д5). Тела и постусловия сняты знак в знак с
  `flang/proof/map/abilities.flang:63,73,84,95` и
  `flang/proof/map/substantive.flang:37` (взято ТОЛЬКО постусловие «С3
  сохранение» из трёх — С1/С2 той же функции про другое). Цепочка
  `развернуть → переписать формой → закрыть тождеством`. Прогон: КОД 0,
  15 ходов проиграно.
- `element.flang` / `element.запись` — С4, 7 мест (Э1 голова приписанного, Э2
  дважды приписанное, Э3 дописанное — двумя записями номера, Э4 выписанный
  список — прямо и под приписыванием). Тела и постусловия сняты знак в знак с
  `flang/test/fixtures/element-po-nomeru-chestnaya.flang` (честная половина
  переписки, задача 4107) — переписан только заголовок модуля. Цепочка
  `развернуть → переписать формой (раз или дважды) → закрыть тождеством`.
  Прогон: КОД 0, 24 хода проиграно.
- `arithmetic.flang` / `arithmetic.запись` — С5, 1 место («Замкнутая цель»/Ф9).
  Тело и постусловие сняты знак в знак с `flang/proof/map/forms.flang:45`.
  Цепочка `вычислить → закрыть тождеством`. Прогон: КОД 0, 2 хода проиграно.
  Второе место семьи по плану, «Модули»/К1 (`flang/proof/map/sources.flang:23`)
  — постусловие С ПРИНЦИПОМ, гейт 4102 его не берёт (нужна работа С7, задача
  4122 её не делает) — граница названа, не выдумана.

## Порча хода → КОД 1 с называнием (`порча/`)

- `порча/dlina-ne-tot-zakon.запись` — ход `переписать формой` на теле
  «добавить» подан законом «Мера склейки» вместо «Мера прибавления»; чекер
  называет: «левая сторона «длина ( добавить что к элементы )» не той формы,
  какой закон требует».
- `порча/element-podmena-nomera.запись` — арифметика литерального номера
  (Э2, К минус 1) подменена на месте: записано «элемент 2 …» вместо «элемент
  1 …»; чекер называет: «правая пересобрана как «элемент 1 в ( приписать
  второй к элементы )», а запись несёт «элемент 2 в ( приписать второй к
  элементы )»».
- `порча/arithmetic-ne-to-znachenie.запись` — ход `вычислить` подан с неверным
  значением (5 вместо 4); чекер называет: «терм посчитан = 4, а запись несёт
  ⟨5⟩».
