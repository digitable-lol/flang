# Семья «противоречие»: пара несовместимых допущений закрывается шагом Пр1

Задача [6812](../../../../../../tasks/6812-a-contradictory-pair-of-assumptions-is-a-ledger-family.md),
решение — [ADR-0042](../../../../../../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2:
список семейств ведомости открыт ровно на семейство **Пр**. Строка `Пр1` стоит в
`flang/proof/ПРАВИЛА-ВЫВОДА.tsv`, лемма «Пр1» и встречный пример
«Пр1-без-перестановки-совместна» — в `flang/proof/lean/Правила.lean`, ловушка 17 —
в `Ловушка.lean`, случай «Пр1» — в `Приёмка.lean` и `Состоятельность.lean`.

## Что стережётся

Правило 8 ядра («несовместимые допущения») закрывало два места корпуса, а в
записи под ними не было ни шага: цель снимал калькулятор сверщика. Теперь ядро
печатает вывод, и сверщик переигрывает его сличением:

    вывод цель ⟨Ц⟩
    вывод 1 Т1 ⟨А меньше Б⟩ строка N
    вывод 2 Т1 ⟨Б не больше А⟩ строка M
    вывод 3 Пр1 ⟨Ц⟩ из 1 2
    вывод конец

Обе посылки — листы Т1 допущений функции (`требует`); Пр1 проверяет, что первая —
строгая «меньше», а вторая — те же стороны, переставленные, знак в знак. Цель
любая: вместе посылки ложны при любых значениях, не-число делает ложными обе.
