# Семья «развёртка»: вызов, поле выписанного конструктора, разбор суммы в цели

Задача [6432](../../../../../../tasks/6432-measure-projection-and-declared-sums-close-five-kernel-word-places.md),
решение — [ADR-0042](../../../../../../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.
Строки `Разв3`, `К↑` и расширенная `Разв1` — в `flang/proof/ПРАВИЛА-ВЫВОДА.tsv`;
леммы «Разв3», «К↑», «Разв1-сумма» — в `Правила.lean`; ловушки 20–22 — в
`Ловушка.lean`. ADR-0022 §3.8 («деструктор не входит») сужен ровно на поле
ЗНАЧЕНИЯ, построенного тут же: поле неизвестного значения — по-прежнему запрет.

| место корпуса | что печатает ядро | что сличает сверщик |
|---|---|---|
| `equality` Р1 «круг: достали то же, что положили» | `Выч` ⟨н равен н⟩ → `К↑` ⟨( вариант «Коробка» с «внутри» равным н ) .«внутри» равен н⟩ → `Разв3` «Положить в коробку» → `Разв3` «Достать из коробки» → `Разв3` своё тело | К↑: сторона — поле выписанного конструктора, равное стороне посылки; Разв3: один вызов развёрнут телом вызванной (плоским), доводы на местах параметров; «результат» — своим телом, которое зовёт |
