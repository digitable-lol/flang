# Семья «семейства отношений»: порядок, строгий порядок, соседние, вхождение, начало

Задача [6131](../../../../../../tasks/6131-sverschik-proigryvaet-blok-vyvoda.md),
ведомость правил — [`flang/proof/ПРАВИЛА-ВЫВОДА.tsv`](../../../../ПРАВИЛА-ВЫВОДА.tsv),
форма блока и границы приёма — в
[docs/design/proof-object-blok-vyvoda.md](../../../../../../docs/design/proof-object-blok-vyvoda.md).

## Зачем

Блок `вывод` умел два вида цели — «Т не меньше 0» и «Т не больше ЛИТЕРАЛ». Всё, что
ядро закрывает порядком, строгим порядком, порядком соседних, вхождением и началом
строки, приёму было незнакомо, и имя оттуда давало отказ. Здесь стоят сами эти правила
и пробы на них.

## Что здесь лежит

| файл | что это |
|---|---|
| `semeystva.flang` | двадцать пять функций — по одной на вид вывода пяти семейств отношений и семейства дна |
| `semeystva.запись` | честная запись: у каждого утверждения блок вывода |
| `порча/strogiy-iz-nestrogogo.flang`, `.запись` | допущение НЕСТРОГОЕ, а вывод назван строгим: постусловие на таком исходнике ложно |
| `порча/vhozhdenie-drugogo-chlena.flang`, `.запись` | в список кладут одно, а вхождение заключают о другом |
| `порча/sosedi-bez-dopushcheniya.flang`, `.запись` | допущение о голове хвоста из исходника убрано, а список объявлен неубывающим |

Три подделки лгут ИСХОДНИКОМ, а не записью: тело либо допущение правится так, что
утверждение на нём ложно, а отпечаток пересчитывается честно. Ловит их не ведомость
отпечатков, а сам приём — чтением строки исходника.

Записи РУКОТВОРНЫЕ: печать этих семейств в ядре ещё не написана (задача 6132), и приём
обязан ехать первым.

## Мерило

Честная запись — код 0, все двадцать пять мест сняты со слова ядра («выводов факта о
типе проиграно заново 25»), долг ноль. Три подделки исходником — код 1, и причину
называет проверка вывода. Ещё двадцать три подделки собираются порчей одной строки
честной записи прямо в прогоне (`прогон.sh`, раздел «семейства отношений»): на каждый
вид отказа своя проба и своя названная причина.
