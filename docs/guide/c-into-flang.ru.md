# Код на C в flang: перевод, проверка ядром, круг и черновик спеки

Переводчик читает функции на C, печатает их перевод на flang и отдаёт перевод ядру.
Каждый вердикт здесь — о **переводе**: «перевод функции X обладает свойством P». Чтобы
вердикт о переводе что-то говорил о самом C, перевод печатается обратно в C и сверяется
с исходником на сетке входов. Решение и его границы —
[ADR-0058](../adr/0058-a-foreign-language-enters-through-an-untrusted-translator.md).

## Как позвать

```
bootstrap/flang run-script foreign-c:demo     # корпус flang/foreign/c/corpus, отчёт и вердикт
bootstrap/flang run-script foreign-c:census   # доля функций C дерева, попадающих в подмножество
```

Нужны `clang` и `cc` с `-fsanitize=undefined`. Временные файлы — под `FLANG_TMP`.

## Что лежит в корпусе

* `corpus/*.c` — чужой код, как есть.
* `corpus/claims.tsv` — что человек утверждает о функции: строки `requires` и `ensures`,
  записанные выражением flang над параметрами (имена в ёлочках) и словом `результат`.
* `corpus/expected.tsv` — чего ждать по каждой функции: `bug` и утверждение, которое
  обязано сломаться; `proved` — всё обязано доказаться; `open` — код верен, ядро доказать
  не может, и контрпримера быть не должно.

## Что печатает отчёт по каждой функции

1. **Перевод** — целиком, тем текстом, который судит ядро. Параметры `int` несут
   требования `INT_MIN`…`INT_MAX`. Строки `обязательство N · строка L: …` — места, где C
   не определён: результат арифметики вне `int`, делитель ноль, конец функции без
   `return`.
2. **Утверждения и вердикты.** У каждого — слово ядра («доказано ядром» / «не доказано
   ядром») и, если на сетке нашёлся вход, где утверждение ложно, — сам вход, что сделал
   на нём C и что сказал на нём `flang run` по переводу.
3. **Круг C → flang → C.** Сколько входов сетки вне требований, на скольких значения
   сошлись, на скольких C остановлен санитайзером и обязательство это назвало.
   Расхождение — это ошибка перевода, и план краснеет.
4. **Черновик спецификации.** Строки `обеспечивает`, помеченные `ВЫВЕДЕНО из перевода` и
   основанием. Хвост строки говорит, что с ней: доказано ядром, отброшено контрпримером
   или ВОПРОС ЧЕЛОВЕКУ — ядро не доказало, а сетка не опровергла.
5. **Подделки переводчика.** Три ложных переводчика: роняет первую ветвь `if`, сдвигает
   первую константу на единицу, переставляет операнды первой некоммутативной операции.
   Каждый обязан разойтись с C на круге.

## Подмножество C

Функции `int f(int, …)`; `return`, `if`/`else`, блоки, локальные `int` с начальным
значением; литералы `int`, `+ - * / %`, сравнения, `&& || !`, унарные `-`, `+`, `?:`.
На всём прочем переводчик отказывает и называет строку и конструкцию.

## Как читать «не доказано»

«Не доказано ядром» — не «ошибка». Ядро не берёт условие ветви фактом, поэтому
обязательство «делитель не ноль» за проверкой `if (count <= 0) return 0;` остаётся
недоказанным, хотя верно. Ошибкой исход становится, когда сетка нашла вход, на котором
утверждение ложно, и `flang run` на нём назвал нарушенное свойство.
