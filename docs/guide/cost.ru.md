# Сколько стоит вызов функции

Страница отвечает на вопрос: как узнать, сколько шагов, памяти и времени
занимает функция. Способов два: измерить один запуск и получить верхнюю
границу для любого размера входа.

## Измерить один запуск

Ключ `--cost` добавляет к выводу `flang run` строку с ценой. Файл
`docs/examples/proofs/total.flang`:

```bash
flang run total.flang --function Итог --args '{"цены": [100, 50], "доставка": 30}' --cost
```

```
доказано: утверждений 1
180
цена прогона: шагов 52, пик памяти 21446656 байт, секунд 0.066134
```

Первые две строки — обычный вывод: доказанные постусловия и результат. Третья
идёт в поток ошибок. «Цена прогона» в ней — цена этого запуска; память и
секунды от запуска к запуску немного меняются:

- шаги — тот же счётчик, который ограничивает ключ `--max-steps`;
- память и секунды включают запуск интерпретатора: разбор и проверку файла.

Программа, сгенерированная командой `flang emit --target c --cli`, отвечает на
запрос с полем `"cost":"1"` полями `"steps"`, `"handed"`, `"reserved"`,
`"depth"` и `"seconds"`.

## Для разработчиков языка: граница до запуска

Эта часть работает в клоне репозитория. Команда выводит верхнюю границу числа
шагов многочленом от размеров входа:

```bash
bootstrap/flang run-script cost docs/examples/proofs/total.flang \
  --function 'Итог' --sizes '|цены|=100'
```

```
цена «Итог»
  …
  шагов толкователя (flang run) ≤ 20·|цены| + 21
  шагов напечатанного C ≤ |цены| + 1 …
  вызовов функции ≤ |цены| + 1
  действий с миром: нет
при размерах |цены|=100:
  flang run: шагов ≤ 2021
  напечатанный C: шагов ≤ 101
```

Команда отвечает одной строкой JSON; выше показано её поле `result` с
развёрнутыми переносами строк. «Толкователь» в выводе — интерпретатор `flang run`, «напечатанный C» —
сгенерированный код на C. Для списка из ста цен интерпретатор сделает не больше
2021 шага. Настоящий запуск не дороже границы, но бывает намного дешевле.

| Ключ | Что делает |
| --- | --- |
| `--function «Имя»` | функция, для которой считается граница |
| `--all` | все функции файла, по строке на функцию |
| `--sizes 'н=20,\|xs\|=100'` | подставить размеры и вывести числа; без ключа выводятся только многочлены |
| `--profile <файл>` | перевести шаги в секунды и байты по профилю машины |
| `--promise 'многочлен'` | код возврата 1, если заявленная цена меньше выведенной |

Размеры называются так: `н` — значение числа `н`; `|s|` — байты строки `s`;
`|xs|` — длина списка `xs`; `|xs[]|` — размер его элемента.

Профиль машины выводит `bootstrap/flang run-script cost:calibrate`: секунды на
шаг интерпретатора и сгенерированного C. Сохраните вывод в
`scripts/cost/profiles/<машина>.profile`. Профиль получают на той машине, где
программа будет работать.

Границу проверяют две команды. `bootstrap/flang run-script cost:validate`
сравнивает границу с измеренным на наборе функций и нескольких размерах.
`bootstrap/flang run-script cost:forgery` убеждается, что заниженная цена
отвергается.
