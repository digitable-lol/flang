# Формула с кванторами и LaTeX: записать, перевести, проверить ядром

Утверждение flang можно написать привычной математической записью — с кванторами
или в LaTeX — и получить из неё утверждение на flang, которое судит ядро. И обратно:
любое утверждение flang, которое ложится в эту запись, печатается в обе записи.
Переводчик стоит вне доверенной основы: верить надо слову ядра, а не переводчику.
Решение и его границы — [ADR-0106](../adr/0106-a-formula-enters-and-leaves-through-an-untrusted-notation-translator.md).

## Как позвать

```
bootstrap/flang run-script formula:read '∀ x ∈ ℤ, ∀ y ∈ ℤ, x + y = y + x'
bootstrap/flang run-script formula:read --latex '\forall x \in \mathbb{Z},\ \forall y \in \mathbb{Z},\ x + y = y + x'
bootstrap/flang run-script formula:print flang/stdlib/fmath.flang
bootstrap/flang run-script formula:probes
bootstrap/flang run-script formula:round-trip
```

`formula:read` принимает ещё `--name <имя>` (имя утверждения) и `--out <файл.flang>`
(оставить перевод в файле; без ключа он пишется во временный каталог и стирается).

## Что печатает перевод

```
запись с кванторами: ∀ x ∈ ℤ, ∀ y ∈ ℤ, x + y = y + x
LaTeX: \forall x \in \mathbb{Z},\ \forall y \in \mathbb{Z},\ x + y = y + x
перевод на flang (вне доверенной основы; судит ядро, ADR-0106):
модуль «Formula»

примечание "ℤ читается как «целое»: отрезок [−(2⁵³−1), 2⁵³−1], а не всё ℤ; переполнение уводит в «число»"

утверждение «формула»
  для всех «x»: целое
  для всех «y»: целое
  утверждаем («x» плюс «y») равен («y» плюс «x»)

слово ядра (flang check --proof), код 0:
  утверждение «формула» — доказано сведением цели с телом функции: правило «тождество после переписки допущением», …
```

Код возврата: 0 — ядро приняло перевод (доказан он или «объявлено, не доказано»,
сказано в слове ядра); 1 — формула не прочиталась (код `FLANG_FORMULA_*`) или ядро
отказало переводу (`FLANG_FORMULA_KERNEL`).

## Запись

| смысл | с кванторами | ASCII | LaTeX | flang |
|---|---|---|---|---|
| для всех | `∀ x ∈ ℤ,` | `forall x in ZZ,` | `\forall x \in \mathbb{Z},` | `для всех «x»: целое` |
| тип flang | `∀ т : строка,` | то же | `\forall \text{т} : \text{строка},` | `для всех «т»: строка` |
| таких что | `∀ y ∈ ℤ \| y > x,` | то же | `\mid` | `таких что (…)` |
| существует | `∃ m, P` | `exists m, P` | `\exists m,\ P` | `есть такой «m», что (P)` |
| с названным значением | `∃ m := a, P` | то же | `\exists m := a,\ P` | `есть такой «m», а именно «a», что (P)` |
| и, или, не | `∧ ∨ ¬` | `/\ \/ ~`, `and or not` | `\land \lor \lnot` | `и притом`, `или`, `не` |
| следует | `→` | `->`, `=>` | `\to`, `\implies` | `если A то B иначе да` |
| равносильно | `↔` | `<->` | `\leftrightarrow`, `\iff` | `A равен B` |
| сравнения | `= ≠ < ≤ > ≥` | `= != < <= > >=` | `= \neq < \leq > \geq` | `равен`, `не равен`, `меньше`, … |
| действия | `+ − · /` | `+ - * /` | `+ - \cdot /`, `\frac{a}{b}` | `плюс`, `минус`, `умножить на`, `делить на` |
| степень | `x^2` | то же | `x^{2}` | `«x» умножить на «x»` |
| длина | `длина(л)` | то же | `\text{длина}(\text{л})` | `длина «л»` |
| вызов функции | `Счёт(л, 1)` | то же | `\text{Счёт}(\text{л}, 1)` | `«Счёт» от «л» и 1` |
| поле | `п.смертен` | то же | `п.\text{смертен}` | `«п».«смертен»` |
| истина, ложь | `⊤ ⊥` | `true false` | `\top \bot` | `да`, `нет` |

Носители после `∈`: `ℕ` — `точное целое` (без потолка), `ℤ` — `целое` (**отрезок**
[−(2⁵³−1), 2⁵³−1], а не всё ℤ), `ℚ≥0` (`\mathbb{Q}_{\geq 0}`) — `точное дробное`.
Голого `ℚ` нет: дроби в языке неотрицательны. `ℝ` и `ℂ` — отказ. Любой другой тип
пишется через двоеточие так, как он пишется в flang: `∀ л : список «Письмо», …`.

Имя из нескольких букв, с пробелом или совпадающее со словом записи берётся в
ёлочки: `«предмет посылки 2»`. В LaTeX имя из нескольких букв — только `\text{…}`:
`xy` там читается произведением, и переводчик откажет.

## Чего запись не читает, и почему отказ

Неоднозначное не читается наугад, а отказывается с кодом и подсказкой:

| формула | код | сообщение |
|---|---|---|
| `x > 0 ∧ x < 5 ∨ x = 7` | `FLANG_FORMULA_AMBIGUOUS` | «∧» и «∨» без скобок неоднозначны: напишите (A ∧ B) ∨ C или A ∧ (B ∨ C) |
| `x = x = x` | `FLANG_FORMULA_AMBIGUOUS` | цепочка сравнений без скобок неоднозначна |
| `A → B → C` | `FLANG_FORMULA_AMBIGUOUS` | цепочка «→» без скобок неоднозначна |
| `x / y · x` | `FLANG_FORMULA_AMBIGUOUS` | после «/» знак «·» или «/» без скобок неоднозначен |
| `2x` | `FLANG_FORMULA_AMBIGUOUS` | умножение без знака не читается — напишите 2 · x |
| `∀ x ∈ ℝ, …` | `FLANG_FORMULA_CARRIER` | ℝ в flang нет: «число» — double IEEE-754 |
| `∃ y ∈ ℤ, …` | `FLANG_FORMULA_QUANTIFIER` | у «∃» в flang нет носителя: тип выводит ядро |
| `n^n` | `FLANG_FORMULA_POWER` | в flang нет возведения в степень |
| `-x` | `FLANG_FORMULA_MINUS` | унарного минуса у выражения в flang нет |
| `\sqrt{x}` | `FLANG_FORMULA_LATEX` | команда \sqrt вне подмножества LaTeX |

Полный список проб с точными сообщениями — `flang/foreign/formula/probes.tsv`.

## Ядро судит перевод, а не формулу

Перевод — обычный исходник flang. Ядро может его доказать, не доказать или отвергнуть:

```
bootstrap/flang run-script formula:read '∀ x ∈ ℕ, ∀ y ∈ ℕ, (x + y)^2 = x^2 + x · y + y · x + y^2'
  → доказано, правило «кольцо точного целого»
bootstrap/flang run-script formula:read '∀ x ∈ ℤ, ¬(x < x)'
  → объявлено, не доказано
bootstrap/flang run-script formula:read '∀ x ∈ ℕ, ∀ y ∈ ℕ, (x + y)^2 = x^2 + 2 · x · y + y^2'
  → FLANG_TYPE: «mul»: точное целое и число не смешиваются
```

Последний отказ — не ошибка переводчика: число `2` в flang — `число`, а не `точное
целое`, и ядро это говорит. Литерал над ℕ записывают нульместной функцией
(ADR-0095).

## Обратно: утверждение flang в обе записи

```
bootstrap/flang run-script formula:print flang/stdlib/fmath.flang
утверждений 4, напечатано 4
утверждение «сумма неотрицательных неотрицательна»
  ∀ а : неотрицательное, ∀ б : неотрицательное, а + б ≥ 0
  \forall \text{а} : \text{неотрицательное},\ \forall \text{б} : \text{неотрицательное},\ \text{а} + \text{б} \geq 0
```

`formula:round-trip` проходит по всем `утверждение` дерева: печатает каждое в обе
записи, читает напечатанное обратно, переводит в flang и сверяет дерево разбора
самого компилятора (`flang ast`) с исходным — без мест в файле и имени. Сошлось —
печать честна; не легло в запись — названа причина; разошлось — план красный.
Прогон 13 октября 2026: сошлось 129 из 137, вне записи 8 (конструктор варианта и
`соединить … по …`), разошлось 0; 19 минут. Файлы можно назвать после имени
команды — тогда круг идёт только по ним.
