# Как писать на flang

Шесть привычек, по которым пишется стандартная библиотека. Каждая показана на
одной функции:

```flang
модуль «Цены»

тотальная функция «Цена после скидки»
  принимает цена: неотрицательное, скидка: неотрицательное
  возвращает число
  требует «скидка не больше цены» скидка не больше цена
  обеспечивает «цена не уходит в минус» результат не меньше 0
  пример «сто минус двадцать»
    дано цена равно 100
    дано скидка равно 20
    ожидается 80
  цена минус скидка
```

```bash
$ flang check price.flang
модуль «Цены»: функций 1, из них с доказанным завершением 1; типов 0
price.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
```

## 1. Имя говорит, что делает функция

Функцию объясняют четыре вещи: имя, типы, `обеспечивает` и `пример`. Если по
ним не видно, что она делает, правят их, а не приписывают пояснение сбоку.

- Имя — из предметной области и без сокращений: `«Цена после скидки»`, а не
  `«Расчёт»`; `цена`, а не `ц`.
- Имена функций, типов, вариантов и модулей пишутся в ёлочках: `«Цена после
  скидки»`. Внутри ёлочек лексер видит одно имя, а не набор слов. Параметры и
  имена из `пусть` ёлочек не требуют.
- Вызов: `«Цена после скидки» от 100 и 20`.

## 2. Обещание и пример вместо комментария

Комментарии `//` и `/* */` лексер выбрасывает: их никто не проверяет, и они
расходятся с кодом молча. То, что в других языках пишут комментарием, здесь
пишут так, чтобы это проверялось:

| Что хочется написать | Где это пишут |
| --- | --- |
| «результат никогда не отрицателен» | `обеспечивает «цена не уходит в минус» результат не меньше 0` |
| «скидка не должна быть больше цены» | `требует «скидка не больше цены» скидка не больше цена` |
| «на 100 и 20 выходит 80» | `пример «сто минус двадцать»` |

Имя обещания и примера — целое предложение. Оно попадает в отчёты и в отказы.

## 3. Самый узкий тип

Объявляйте `неотрицательное` там, где значение не бывает отрицательным. Это
даёт компилятору границы: постусловие функции выше доказано из одних типов и
строки `требует`. Отчёт `flang check price.flang --proof` говорит:

```
постусловие «цена не уходит в минус» функции «Цена после скидки» — доказано по объявленным типам аргументов: цель сведена правилом «неотрицательность по построению» …
```

Уберите строку `требует` — и `flang check` найдёт вход, на котором обещание
ложно, код возврата 1:

```
FLANG_EXAMPLE: FLANG_PROPERTY: постусловие «цена не уходит в минус» функции «Цена после скидки» нарушено на входе цена = 0, скидка = 1 — посчитано вычислителем на этом входе
```

## 4. `тотальная` — самым дешёвым способом

`тотальная` значит: функция завершается на любом входе, и компилятор это
доказывает. Способы — от дешёвого к дорогому:

1. без рекурсии, `свёртка` или `цикл` по списку — доказывать нечего;
2. рекурсия по части значения (хвост списка, поле варианта) — доказано
   структурой;
3. спуск по параметру `неотрицательное` на постоянный шаг — доказано, проверки
   при работе нет;
4. объявленная мера `убывает …` — проверка остаётся в программе и стоит
   времени. Берите её, когда первых трёх не хватает.

Подробно — [Тотальные функции](totality.ru.md).

## 5. Действия — данными

Функция не читает файл и не ходит в сеть. Она возвращает поручение — значение
вида «прочитай этот файл», — а выполняет его `flang io`. Поэтому логика
остаётся тотальной и проверяется обычными примерами, без файлов и без сети.
Как это устроено — [Где кончается flang и начинается хозяин](../site/host-boundary.ru.md).

## 6. Проверить до запуска

```bash
flang check price.flang          # разбор, типы, завершение, примеры
flang check price.flang --proof  # что доказано, а что нет
flang run price.flang --function "Цена после скидки" --args '{"цена": 100, "скидка": 20}'
```

`flang check` без ключей отвечает «замечаний нет» и тогда, когда обещание
проверено только на примерах. Что именно доказано, показывает `--proof`; его
код возврата 3 значит, что недоказанное осталось.

## Имена файлов

У исходника четыре равноправных расширения: `.flang`, `.fp`, `.фп`, `.фланг`.
Русское имя файла пишут кириллицей (`налог.фп`), английское — латиницей
(`tax.flang`). Русское слово латиницей (`nalog.flang`) не пишут: его не
прочтёт ни русский читатель, ни иностранец.
