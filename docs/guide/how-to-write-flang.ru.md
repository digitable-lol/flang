# Как писать на flang

Какой код на flang считается хорошим? Ниже шесть привычек, по которым написана
стандартная библиотека. Все показаны на одной функции. Сохраните её в
`price.flang`:

```flang
модуль «Цены»

тотальная функция «Цена после скидки»
  принимает цена: неотрицательное, скидка: неотрицательное
  возвращает число
  требует «скидка не больше цены» скидка не больше цена
  обеспечивает «цена не уходит в минус» результат не меньше 0
  пример «сто минус двадцать»
    дано цена равно 100
    дано скидка равно 20
    ожидается 80
  цена минус скидка
```

```bash
$ flang check price.flang
модуль «Цены»: функций 1, из них с доказанным завершением 1; типов 0
price.flang: проверено — доказано 1, проверено только на тестах 0, не доказано 0 (постусловий и утверждений 1); замечаний нет
```

Вторая строка считает постусловия: одно доказано. «Замечаний нет» читается как
«ошибок нет»: синтаксис, типы, завершение и тесты прошли.

## 1. Имя говорит, что делает функция

Функцию объясняют четыре вещи: имя, типы, `обеспечивает` и `пример`. Если по
ним не видно, что она делает, исправьте их. Пояснение сбоку не поможет.

- Имя берут из предметной области и не сокращают: `«Цена после скидки»`
  вместо `«Расчёт»`, `цена` вместо `ц`.
- Имена функций, типов, вариантов и модулей пишутся в ёлочках. Внутри ёлочек
  компилятор видит одно имя, даже если в нём несколько слов.
- Параметры и имена из `пусть` ёлочек не требуют.
- Вызов: `«Цена после скидки» от 100 и 20`.

## 2. Постусловие и тест вместо комментария

Комментарии `//` и `/* */` компилятор пропускает. Их никто не проверяет,
поэтому они незаметно расходятся с кодом. То, что в других языках пишут
комментарием, здесь пишут проверяемой строкой:

| Что хочется написать | Где это пишут |
| --- | --- |
| «результат никогда не отрицателен» | `обеспечивает «цена не уходит в минус» результат не меньше 0` |
| «скидка не должна быть больше цены» | `требует «скидка не больше цены» скидка не больше цена` |
| «на 100 и 20 выходит 80» | `пример «сто минус двадцать»` |

`обеспечивает` — постусловие, `требует` — предусловие, `пример` — тест. Имя
каждого из них — целое предложение: оно попадает в отчёты и в сообщения об
ошибках.

## 3. Самый узкий тип

Объявляйте `неотрицательное` там, где значение не бывает отрицательным. Тип
даёт компилятору границы. Постусловие функции выше доказано из одних типов и
строки `требует`:

```bash
$ flang check price.flang --proof
модуль «Цены»: функций 1, завершение доказано у 1
постусловие «цена не уходит в минус» функции «Цена после скидки» — доказано
…
price.flang: проверено — доказано 1, проверено только на тестах 0, не доказано 0, ложно 0 (постусловий и утверждений 1); независимая проверка повторила 1 из 1 — код возврата 0
```

«Доказано» значит: для любых аргументов. Последняя строка добавляет, что
независимая проверка повторила это доказательство («1 из 1»).

Уберите строку `требует`, и `flang check` найдёт аргументы, на которых
постусловие ложно. Код возврата 1:

```
FLANG_EXAMPLE: FLANG_PROPERTY: постусловие «цена не уходит в минус» функции «Цена после скидки» нарушено на входе цена = 0, скидка = 1 — посчитано вычислителем на этом входе
```

## 4. `тотальная` — самым дешёвым способом

Слово `тотальная` перед функцией требует: она завершается на любых аргументах,
и компилятор это доказывает. Способы, от дешёвого к дорогому:

1. без рекурсии, `свёртка` или `цикл` по списку — доказывать нечего;
2. рекурсия по части значения (хвост списка, поле варианта) — доказано по
   строению данных;
3. счёт вниз по параметру `неотрицательное` на постоянный шаг — доказано,
   проверки во время выполнения нет;
4. строка `убывает …` — компилятор доказывает убывание только в простых
   случаях, в остальных проверка остаётся в программе и занимает время. Берите
   её, когда первых трёх не хватает.

Подробно — [Как компилятор доказывает завершение функции](totality.ru.md).

## 5. Действия — данными

Функция не читает файл и не обращается к сети. Она возвращает эффект — значение
вида «прочитай этот файл». Выполняет его команда `flang io`. Поэтому логика
всегда завершается и проверяется обычными тестами, без файлов и без сети.

Как это устроено — [Граница между flang и хостом](../site/host-boundary.ru.md).

## 6. Проверить до запуска

```bash
flang check price.flang          # синтаксис, типы, завершение, тесты
flang check price.flang --proof  # что доказано, а что нет
flang run price.flang --function "Цена после скидки" --args '{"цена": 100, "скидка": 20}'
```

`flang check` без ключей отвечает «замечаний нет» и тогда, когда постусловие
проверено только на тестах. Что доказано, показывает `--proof`. Его код
возврата 3 сообщает: остались постусловия без доказательства.

## Имена файлов

У исходника четыре равноправных расширения: `.flang`, `.fp`, `.фп`, `.фланг`.
Русское имя файла пишут кириллицей (`налог.фп`), английское — латиницей
(`tax.flang`). Русское слово латиницей (`nalog.flang`) не пишут: его не поймёт
ни русский читатель, ни иностранец.
