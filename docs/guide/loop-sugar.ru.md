# Циклы: хранимые значения и `дальше`

Блок `цикл` позволяет функции пройти список или повторять шаг, пока верно
условие, и хранить между шагами несколько значений — как цикл `for` или `while`
в Python. До `check` блок разворачивается в обычный flang: в свёртку или в новую
тотальную функцию. Правил ядра здесь нет, поэтому доказательства, записи и
сверщики судят развёрнутый текст как любую другую программу. Решение —
[ADR-0206](../adr/0206-a-loop-with-kept-state-expands-to-a-fold-or-a-total-function.md).

```
bootstrap/flang run-script sugar:expand -- задача.flang развёрнутое.flang
bootstrap/flang check --proof развёрнутое.flang
```

## Блок

```
цикл «Сужение»
  пока лево меньше право
  убывает право минус лево плюс 1
  храним лево: число равным 1, право: число равным длина элементы, лучшее: число равным 0
  в конце лучшее
  пусть итог равно ...
  если слева меньше справа
    то дальше: лево станет лево плюс 1, лучшее станет итог
    иначе дальше: право станет право минус 1, лучшее станет итог
```

| строка | смысл |
|---|---|
| `для каждого х[: тип] из список` | пройти список; тип нужен, если ветвь выходит раньше |
| `пока условие` | повторять, пока условие верно |
| `убывает мера` | мера цикла `пока`; при работе её проверяет сторож |
| `шагов не больше n, иначе v` | запас шагов цикла `пока` и значение, когда он кончился; сторожа нет |
| `храним имя: тип равным начало, …` | значения, которые живут между шагами |
| `в конце значение` | значение, когда кончился список или условие |
| `дальше: имя станет значение, …` | следующий шаг; неназванные хранимые не меняются |

Ветвь без `дальше` — ответ цикла: это ранний выход.

## Во что разворачивается

| цикл | разворот | завершение |
|---|---|---|
| `для каждого`, тело кончается одним `дальше` | `свёртка` с записью `«Имя — состояние»` | по построению |
| `для каждого` с ранним выходом | функция с `разбор` по остатку списка | структурой |
| `пока` с `шагов не больше` | функция с запасом `неотрицательное`, который убывает на единицу | точным шагом |
| `пока` с `убывает` | функция с объявленной мерой | объявленной мерой |

Новая функция принимает те параметры объемлющей, которые цикл упоминает, затем
хранимые значения, и возвращает то же, что объемлющая. Тело цикла видит эти
параметры, свои хранимые значения и свой элемент; имя, связанное `пусть` до
цикла, входит через `храним`.

`bootstrap/flang run-script sugar:demo` разворачивает три задачи LeetCode,
записанные циклами (`flang/sugar/tasks.flang`), и сличает вердикт `check --proof`
каждой с вердиктом исходного решения в `docs/examples/leetcode`.
