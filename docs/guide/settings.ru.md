# Настройки: файл `.flangrc`

flang читает файл настроек `.flangrc`. В нём выбирается язык, которым flang
отвечает человеку, поверхность заготовок, цвет в терминале и язык страницы
`man flang`.

Страница описывает, **что уже работает и что ещё нет**, и говорит это прямо в
каждом разделе: часть решения написана, часть ждёт работы, названной в
[ADR-0022](../adr/0022-the-settings-file-and-the-language-of-output.md).

## Как выглядит файл

```
# Строка — «ключ = значение». Пробелы вокруг знака не важны.
# Строка, начинающаяся с «#», — примечание.

язык = ru
поверхность = ru
цвет = авто
страница = ru
```

Незнакомый ключ и негодное значение пропускаются молча. Это не небрежность, а
обещание: файл, написанный для нового flang, обязан работать на старом.

## Ключи

| ключ | значения | что делает |
| --- | --- | --- |
| `язык` | `ru` `en` `eo` `zh` | язык, которым flang отвечает человеку |
| `поверхность` | `ru` `en` `eo` `zh` | какой поверхностью `flang new` пишет заготовку |
| `цвет` | `да` `нет` `авто` | цвет в терминале |
| `страница` | `ru` `en` | язык страницы `man flang` |

Коды языков — те же четыре, что у поверхностей записи (см.
[Четыре поверхности](surfaces.ru.md)), и это не совпадение: второго списка кодов
в языке нет.

**Что из этого работает сегодня.** Читать файл и разрешать его по старшинству
умеет `sh scripts/flangrc.sh`. Сам компилятор настройки пока не читает и
отвечает по-русски всегда — это задача
[5413](../../tasks/5413-the-compiler-cannot-be-told-which-language-to-speak.md).
Языков вывода, кроме русского, пока нет ни одного: их 811 строк текста на язык,
и место, куда их класть, заводит задача
[8161](../../tasks/8161-messages-live-in-the-binary-so-a-new-language-costs-a-reprint.md).

## Где файл ищется

Два места, и оба названы:

1. **`.flangrc` проекта** — от рабочего каталога вверх. Подъём обрывается на
   первом каталоге, где лежит `.flangrc`, `.git` или `flang.package`, и этот
   каталог последний.
2. **`~/.flangrc`** — файл человека на этой машине.

Дальше подъёма нет ни при каком исходе: ни выше дома, ни выше корня файловой
системы.

**Из этого следует главное свойство: дальний файл не перекрывает ближний.** Раз
`.flangrc` сам обрывает подъём, взять файл, лежащий выше, пройдя мимо
ближнего, поиск не может.

Проверяется прогоном:

```
sh scripts/flangrc-guard.sh            # оба обещания поиска
sh scripts/flangrc-guard.sh --подлог   # а способна ли эта проверка покраснеть
```

## Что старше чего

```
довод командной строки → переменная среды → .flangrc проекта
  → .flangrc дома → локаль → умолчание
```

Чем ближе источник к рукам человека в эту минуту, тем он старше. Локаль
(`LC_ALL`, затем `LC_MESSAGES`, затем `LANG`) стоит предпоследней: она говорит о
машине, а не о flang. Локали `C` и `POSIX` кодом языка не считаются, и тогда
решает умолчание — `ru`.

Переменные среды: `FLANG_LANG`, `FLANG_SURFACE`, `FLANG_COLOR`, `FLANG_MANPAGE`.
Имена латиницей, потому что `bash` и `dash` кириллическое имя переменной не
принимают вовсе — присваивание отвечает «command not found». Ключи самого файла
при этом русские: файл читает flang, а не оболочка.

## Посмотреть, что вышло

```
$ sh scripts/flangrc.sh
язык = ru
поверхность = ru
цвет = авто
страница = ru

$ sh scripts/flangrc.sh --откуда
язык = ru   (/путь/к/проекту/.flangrc)
цвет = авто   (умолчание)

$ sh scripts/flangrc.sh язык
ru

$ sh scripts/flangrc.sh --места
/путь/к/проекту/src
/путь/к/проекту
остановка: настройки найдены: /путь/к/проекту/.flangrc
```

## При первом запуске вопроса не будет

flang не спрашивает, на каком языке говорить. Он берёт язык из локали и говорит
одной строкой, что взял и как поменять. Три причины, и все три проверяемы:

* **вопрос некому задать** — flang сплошь и рядом работает без терминала: в
  конвейере, в сборке, из редактора. Вопрос там повесил бы работу;
* **вопрос сам на каком-то языке** — спросить «на каком языке говорить?» можно
  только на уже выбранном;
* **спрашивать нечего** — локаль отвечает верно почти всегда, а несогласного
  одна строка отсылает к `.flangrc`.

## Чего в файле нет

**Ключа «писать только русскими словами» или «только английскими» нет.** Все
четыре поверхности записи принимаются одновременно, и смешивать их законно —
это свойство языка, а не недосмотр, и сужать его файл настроек не будет. Ключ
`поверхность` говорит лишь о том, какими словами `flang new` пишет заготовку.

Подробности — [Четыре поверхности](surfaces.ru.md).
