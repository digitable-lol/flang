# Зачем это нужно

Здесь правило написано один раз и в той форме, которую читает человек из предметной области, а не
только программист (фрагмент [`docs/examples/library-api/lib/fine.flang`](../examples/library-api/lib/fine.flang)):

```flang
объект «Просроченная выдача»
  «дней просрочки»: число
  «книга редкая»: признак

тотальная функция «Рассчитать штраф»
  принимает «выдача»: «Просроченная выдача»
  возвращает число
  обеспечивает «Штраф ограничен» результат не больше 500
  пример «Вернули вовремя»
    дано «выдача» равно (запись «Просроченная выдача» с «дней просрочки» равным 0 и «книга редкая» равным нет)
    ожидается 0
  пример «Две недели и редкая книга»
    дано «выдача» равно (запись «Просроченная выдача» с «дней просрочки» равным 14 и «книга редкая» равным да)
    ожидается 500
  пусть «дней» равно («выдача».«дней просрочки»)
  пусть «редкая» равно («выдача».«книга редкая»)
  пусть «за просрочку» равно если «дней» больше 0 то 50 иначе 0
  пусть «за долгую» равно если «дней» не меньше 14 то 150 иначе 0
  пусть «за редкую» равно если («редкая» равен да) и притом («дней» больше 0) то 300 иначе 0
  («за просрочку» плюс «за долгую») плюс «за редкую»
```

Фигурных скобок, стрелок и точек с запятой нет: вложенность задают отступы, операции записаны
словами, а имена из нескольких слов берутся в кавычки-ёлочки.

Рядом с телом функции записаны ещё три вещи. **Примеры** — часть объявления, а не тесты в
соседнем файле: `flang test` находит их сам. **`обеспечивает`** — постусловие: утверждение о
результате на любом входе. **`тотальная`** — слово, которое проверяет компилятор. Он либо
доказывает завершение сам (композицией, структурой или точным шагом по неотрицательному целому),
либо требует, чтобы убывающее выражение назвал автор (`убывает`), и тогда вставляет проверку во
время выполнения. Второе — не доказательство: `flang check` возвращает 0, `flang check --proof` —
3, а запуск останавливается с ошибкой `FLANG_MEASURE`, если выражение не убыло. Способ у каждой
функции называет `flang check --proof --explain`; подробно —
[«Как компилятор доказывает завершение функции»](totality.ru.md).

Из одного исходника получаются реализация, примеры и проверки на десяти языках. Строка
`обеспечивает` становится постусловием напечатанного кода.

```bash
flang emit docs/examples/library-api/lib/fine.flang --target python --out вывод
```

даёт `вывод/fine.py`, и проверки постусловия в нём нет. Ядро доказало «Штраф ограничен» для
всех входов (`flang check docs/examples/library-api/lib/fine.flang --proof --explain`:
«доказано сведением цели с телом функции», код 0), а доказанное постусловие в код не
печатается. С ключом `--no-check` ядро не запускается, и тогда в `вывод/fine.py` стоит:

```python
    # постусловие «Штраф ограничен»
    if not rt.post(
        ctx, rt.lte(ctx, _t5, rt.number(500.0)), "Штраф ограничен", "Рассчитать штраф"
    ):
        raise rt.fail(
            "FLANG_PROPERTY",
            "нарушено свойство «Штраф ограничен» функции «Рассчитать штраф»",
        )
```

`FLANG_PROPERTY` — код ошибки самого языка, и текст сообщения тоже его. Служба на Python,
служба на Go и программа на C, напечатанные из этой функции, ответят на один и тот же вход
одной и той же ошибкой.
