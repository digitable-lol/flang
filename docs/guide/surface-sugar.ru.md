# Во что переписываются циклы и классы

Как писать циклы и классы, показывает страница тура
[Циклы, классы, интерфейсы](../site/tour-loops-and-classes.ru.md). Здесь ответ
на другой вопрос: во что компилятор переписывает `цикл`, `класс` и
`интерфейс`, чем доказано завершение и какие бывают ошибки.

Компилятор переписывает эти записи в обычный flang: функции, записи, типы с
вариантами. Потом он проверяет результат: типы, завершение, доказательства.
Сообщение об ошибке называет строку вашего файла.

Английского написания у слов `цикл`, `класс`, `интерфейс`, `метод` нет.

## Заголовок в одну строку

```flang
тотальная функция «Меньшее из двух» принимает первый: число, второй: число возвращает число
```

То же, что три строки: `тотальная функция «Меньшее из двух»`, `принимает …`,
`возвращает …`. Без параметров: `функция «Ноль» возвращает число`.

## Цикл

Файл `countdown.flang`:

```flang
модуль «Счёт»

тотальная функция «Сумма до» принимает н: число возвращает число
  пример «от одного до четырёх»
    дано н равно 4
    ожидается 10
  цикл «Сложение»
    пока осталось больше 0
    убывает осталось
    храним осталось: число равным н, сумма: число равным 0
    в конце сумма
    дальше: осталось станет осталось минус 1, сумма станет сумма плюс осталось
```

```bash
$ flang check countdown.flang --proof
…
  «Сумма до»  доказано композицией: рекурсии нет, …
  «Сложение»  доказано объявленной мерой: убывает «осталось»; спуск ядром не выведен — на веру: мера объявлена автором, сторож считает её при работе на каждом витке — 1 место
…
```

В файле одна функция, в отчёте две. Цикл `«Сложение»` стал отдельной функцией,
которая вызывает саму себя. Значения из строки `храним` стали её параметрами.
Вторая строка отчёта говорит: убывание выражения из строки `убывает` не
доказано, оно проверяется при каждом шаге цикла.

На дробном аргументе проверка срабатывает, код возврата 1:

```bash
$ flang run countdown.flang --function "Сумма до" --args '{"н": 2.5}'
доказано: утверждений 0
FLANG_MEASURE: тотальная функция «Сложение»: мера на вызове «Сложение» — «осталось» — перестала быть целой. …
```

Каждый вид цикла переписывается по-своему:

| Цикл | Во что переписан | Чем доказано завершение |
|---|---|---|
| `для каждого`, тело кончается одним `дальше` | `свёртка` по записи из значений `храним` | список конечен |
| `для каждого` с выходом раньше конца | функция с `разбор` по остатку списка | остаток короче списка |
| `пока` со строкой `шагов не больше` | функция со счётчиком, который уменьшается на единицу | счётчик типа `неотрицательное` |
| `пока` со строкой `убывает` | функция со строкой `убывает` | проверкой во время выполнения |

Ветка без `дальше` даёт результат цикла сразу: так выходят раньше конца. Имя,
объявленное через `пусть` до цикла, попадает в цикл через `храним`.

Подробно о способах доказательства —
[Как компилятор доказывает завершение функции](totality.ru.md).

## Класс

Файл `account.flang`:

```flang
модуль «Счета»

класс «Счёт»
  владелец: строка
  остаток: число
  всегда «остаток не отрицателен» остаток не меньше 0

  метод «Положить» принимает сумма: число
    требует «сумма не отрицательна» сумма не меньше 0
    пример «сто и ещё двадцать»
      дано этот равно запись «Счёт» с владелец равным "Аня" и остаток равным 100
      дано сумма равно 20
      ожидается запись «Счёт» с владелец равным "Аня" и остаток равным 120
    остаток станет остаток плюс сумма

  метод «Пусто ли» возвращает признак
    пример «на новом счёте пусто»
      дано этот равно запись «Счёт» с владелец равным "Аня" и остаток равным 0
      ожидается да
    остаток равен 0
```

```bash
$ flang run account.flang --function "Счёт: Положить" --args '{"этот": {"владелец": "Аня", "остаток": 10}, "сумма": 30}'
доказано: утверждений 1
{"владелец":"Аня","остаток":40}
```

Класс переписан в запись `объект «Счёт»` и функции `«Счёт: Положить»`,
`«Счёт: Пусто ли»` с первым параметром `этот`. Изменяемого состояния нет:

- имя поля в методе читается из `этот`;
- метод, который кончается строками `поле станет значение`, возвращает новую
  запись `«Счёт»`; остальные поля копируются;
- строка `всегда` даёт каждому методу предусловие. Методу, который возвращает
  `«Счёт»`, она даёт и постусловие о результате.

«Утверждений 1» в выводе — постусловие метода `«Положить»`: компилятор его
доказал.

Вызов из кода: `«Счёт: Положить» от счёт и 30`. Отрицательная сумма нарушает
`требует`, и `flang run` отвечает `FLANG_PRECONDITION` с кодом возврата 1.

## Интерфейс

Файл `shapes.flang`:

```flang
модуль «Фигуры»

интерфейс «Фигура»
  метод «Площадь» возвращает число
  метод «Название» возвращает строка
    обеспечивает «название не пусто» (длина результат) больше 0
    "фигура"

класс «Квадрат» есть «Фигура»
  сторона: число
  метод «Площадь» возвращает число
    пример «квадрат со стороной 3»
      дано этот равно запись «Квадрат» с сторона равным 3
      ожидается 9
    сторона умножить на сторона
  метод «Название» возвращает строка
    "квадрат"

класс «Прямоугольник» есть «Фигура»
  ширина: число
  высота: число
  метод «Площадь» возвращает число
    пример «два на пять»
      дано этот равно запись «Прямоугольник» с ширина равным 2 и высота равным 5
      ожидается 10
    ширина умножить на высота
```

```bash
$ flang test shapes.flang
shapes.flang: примеров 2, прошло 2, не прошло 0
```

Интерфейс переписан в `тип «Фигура»`. У типа по варианту на каждый класс файла
со словами `есть «Фигура»`. Методы стали функциями `«Фигура: Площадь»` и
`«Фигура: Название»` с `разбор` по классам.

Метод без тела обязателен для каждого класса. Метод с телом — реализация по
умолчанию. Строка `обеспечивает` у метода интерфейса переносится на метод
каждого класса.

## Ошибки

Код возврата `flang check` — 1. Сообщение называет строку и столбец.

| Код | Когда |
|---|---|
| `FLANG_SUGAR_LOOP` | нет строки `в конце`; нет ни `для каждого`, ни `пока`; у `пока` нет границы; `дальше` меняет имя не из `храним` |
| `FLANG_SUGAR_HEADER` | `возвращает` раньше `принимает`; слово повторено; после слова ничего нет |
| `FLANG_SUGAR_CLASS` | строка класса — не поле, не `всегда`, не `метод`; `станет` меняет поле, которого нет; поле объявлено дважды |
| `FLANG_SUGAR_INTERFACE` | класс не объявил обязательный метод; заголовок метода класса отличается от заголовка в интерфейсе; у интерфейса нет классов |

Например, цикл без строки `в конце`:

```
FLANG_SUGAR_LOOP в файле no-end.flang, строка 11, столбец 7: цикл «Сделка»: нет строки «в конце …»: цикл не говорит, что он отдаёт, когда кончается
```
