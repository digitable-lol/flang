# Циклы, классы, интерфейсы и заголовок в одну строку

В flang нет изменяемых переменных, но цикл и класс написать можно. Компилятор
разворачивает эти четыре записи в обычный flang — свёртку, тотальную функцию,
`объект`, `тип` с вариантами — и проверяет развёрнутый текст: типы,
завершение и доказательства. Ошибка называет строку вашего исходника.

Английского написания у слов `цикл`, `класс`, `интерфейс`, `метод` нет.

## Заголовок в одну строку

```
тотальная функция «Меньшее из двух» принимает первый: число, второй: число возвращает число
```

То же, что три строки: `тотальная функция «Меньшее из двух»`, `принимает …`,
`возвращает …`. Без параметров: `функция «Ноль» возвращает число`.

## Цикл по списку

Положите в `stock.flang`:

```flang
модуль «Сделка»

тотальная функция «Лучшая прибыль» принимает цены: список числа возвращает число
  пример «купить за 1, продать за 6»
    дано цены равно [7, 1, 5, 3, 6, 4]
    ожидается 5
  разбор цены
    случай пусто
      то 0
    случай голова и хвост
      цикл «Сделка»
        для каждого цена из хвост
        храним минимум: число равным голова, прибыль: число равным 0
        в конце прибыль
        пусть сегодня равно цена минус минимум
        пусть ниже равно если цена меньше минимум то цена иначе минимум
        пусть лучше равно если сегодня больше прибыль то сегодня иначе прибыль
        дальше: минимум станет ниже, прибыль станет лучше
```

```bash
$ flang check stock.flang
модуль «Сделка»: функций 1, из них с доказанным завершением 1; типов 1
stock.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет

$ flang run stock.flang --function "Лучшая прибыль" --args '{"цены": [7, 1, 5, 3, 6, 4]}'
доказано: утверждений 0
5
```

| Строка цикла | Что значит |
|---|---|
| `для каждого х из список` | пройти список; `х: тип` нужен, когда ветвь выходит раньше |
| `храним имя: тип равным начало, …` | значения, которые живут между шагами |
| `в конце значение` | ответ, когда список кончился |
| `дальше: имя станет значение, …` | следующий шаг; неназванные хранимые остаются как были |

Ветвь без `дальше` — ответ цикла, то есть ранний выход. Имя, связанное `пусть`
до цикла, входит в цикл через `храним`.

## Цикл `пока`

Циклу `пока` нужна граница: без неё завершение не доказать, и компилятор
отказывает кодом `FLANG_SUGAR_LOOP`. Границ две.

**`убывает мера`** — целое неотрицательное выражение, которое уменьшается на
каждом шаге:

```flang
модуль «Счёт»

тотальная функция «Сумма до» принимает н: число возвращает число
  пример «от одного до четырёх»
    дано н равно 4
    ожидается 10
  цикл «Сложение»
    пока осталось больше 0
    убывает осталось
    храним осталось: число равным н, сумма: число равным 0
    в конце сумма
    дальше: осталось станет осталось минус 1, сумма станет сумма плюс осталось
```

```bash
$ flang run countdown.flang --function "Сумма до" --args '{"н": 4}'
доказано: утверждений 0
10
```

Меру проверяют при работе. На дробном входе `{"н": 2.5}` она перестаёт быть
целой, и вместо зацикливания приходит отказ `FLANG_MEASURE`, код возврата 1.

**`шагов не больше n, иначе v`** — запас шагов и ответ, когда запас кончился.
Проверки при работе нет: запас убывает на единицу, и завершение доказано.

```flang
модуль «Binary search»

тотальная функция «Двоичный поиск» принимает элементы: список числа, цель: число возвращает число
  пример «Один элемент»
    дано элементы равно [5]
    дано цель равно 5
    ожидается 0
  цикл «Поиск»
    пока низ не больше верх
    шагов не больше длина элементы, иначе -1
    храним низ: число равным 1, верх: число равным длина элементы
    в конце -1
    пусть сумма равно низ плюс верх
    пусть середина равно (сумма минус (сумма остаток от 2)) делить на 2
    пусть значение равно элемент середина в элементы
    если значение равен цель
      то середина минус 1
      иначе если значение меньше цель
        то дальше: низ станет середина плюс 1
        иначе дальше: верх станет середина минус 1
```

```bash
$ flang run search.flang --function "Двоичный поиск" --args '{"элементы": [1, 3, 5, 7], "цель": 5}'
доказано: утверждений 0
2
```

Во что разворачивается цикл и чем доказано завершение:

| Цикл | Разворот | Завершение |
|---|---|---|
| `для каждого`, тело кончается одним `дальше` | `свёртка` по записи хранимых значений | по построению |
| `для каждого` с ранним выходом | функция с `разбор` по остатку списка | структурой списка |
| `пока` с `шагов не больше` | функция с запасом, который убывает на единицу | точным шагом |
| `пока` с `убывает` | функция с объявленной мерой | мерой, проверка при работе |

## Класс

Положите в `account.flang`:

```flang
модуль «Счета»

класс «Счёт»
  владелец: строка
  остаток: число
  всегда «остаток не отрицателен» остаток не меньше 0

  метод «Положить» принимает сумма: число
    требует «сумма не отрицательна» сумма не меньше 0
    пример «сто и ещё двадцать»
      дано этот равно запись «Счёт» с владелец равным "Аня" и остаток равным 100
      дано сумма равно 20
      ожидается запись «Счёт» с владелец равным "Аня" и остаток равным 120
    остаток станет остаток плюс сумма

  метод «Пусто ли» возвращает признак
    пример «на новом счёте пусто»
      дано этот равно запись «Счёт» с владелец равным "Аня" и остаток равным 0
      ожидается да
    остаток равен 0
```

```bash
$ flang run account.flang --function "Счёт: Положить" --args '{"этот": {"владелец": "Аня", "остаток": 10}, "сумма": 30}'
доказано: утверждений 1
{"владелец":"Аня","остаток":40}
```

Класс — это `объект «Счёт»` и функции `«Счёт: Положить»`, `«Счёт: Пусто ли»`
с первым параметром `этот`. Изменяемого состояния нет:

- поле в методе пишется голым именем и читается из `этот`;
- метод, который кончается строками `поле станет значение`, возвращает новый
  `«Счёт»`; неназванные поля переходят как были;
- `всегда` даёт каждому методу `требует`, а методу, который возвращает
  `«Счёт»`, — ещё `обеспечивает` о результате. Здесь оно доказано: это и есть
  «утверждений 1» в выводе.

Вызов из кода: `«Счёт: Положить» от счёт и 30`. Отрицательная сумма нарушает
`требует`, и `run` отвечает `FLANG_PRECONDITION`, код возврата 1.

## Интерфейс

```flang
модуль «Фигуры»

интерфейс «Фигура»
  метод «Площадь» возвращает число
  метод «Название» возвращает строка
    обеспечивает «название не пусто» (длина результат) больше 0
    "фигура"

класс «Квадрат» есть «Фигура»
  сторона: число
  метод «Площадь» возвращает число
    пример «квадрат со стороной 3»
      дано этот равно запись «Квадрат» с сторона равным 3
      ожидается 9
    сторона умножить на сторона
  метод «Название» возвращает строка
    "квадрат"

класс «Прямоугольник» есть «Фигура»
  ширина: число
  высота: число
  метод «Площадь» возвращает число
    пример «два на пять»
      дано этот равно запись «Прямоугольник» с ширина равным 2 и высота равным 5
      ожидается 10
    ширина умножить на высота
```

```bash
$ flang test shapes.flang
shapes.flang: примеров 2, прошло 2, не прошло 0
```

Интерфейс — это `тип «Фигура»` с вариантом на каждый класс файла, который
говорит `есть «Фигура»`, и функции `«Фигура: Площадь»`, `«Фигура: Название»` с
`разбор` по классам. Метод без тела обязателен для класса; метод с телом —
реализация по умолчанию. `обеспечивает` у метода интерфейса ложится на метод
каждого класса.

## Отказы

Код возврата `check` — 1; сообщение называет строку и столбец.

| Код | Когда |
|---|---|
| `FLANG_SUGAR_LOOP` | нет `в конце`; нет ни `для каждого`, ни `пока`; у `пока` нет границы; `дальше` меняет имя не из `храним` |
| `FLANG_SUGAR_HEADER` | `возвращает` раньше `принимает`; слово сказано дважды; после слова ничего нет |
| `FLANG_SUGAR_CLASS` | строка класса — не поле, не `всегда`, не `метод`; `станет` меняет поле, которого нет; поле названо заново |
| `FLANG_SUGAR_INTERFACE` | класс не дал обязательный метод; заголовок метода класса не тот, что в интерфейсе; у интерфейса нет классов |

Например, цикл без строки `в конце`:

```
FLANG_SUGAR_LOOP в файле no-end.flang, строка 11, столбец 7: цикл «Сделка»: нет строки «в конце …»: цикл не говорит, что он отдаёт, когда кончается
```
