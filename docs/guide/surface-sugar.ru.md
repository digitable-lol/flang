# Сахар: цикл, заголовок в одну строку, класс и интерфейс

Четыре короткие записи, которые компилятор разворачивает в обычный flang до того, как
текст прочтёт лексер: в свёртку, в тотальную функцию, в `объект`, `тип` с вариантами и
функции. Правил ядра здесь нет; типы, завершаемость, доказательства и оба сверщика судят
развёрнутый текст как любую другую программу. Решения —
[ADR-0206](../adr/0206-a-loop-with-kept-state-expands-to-a-fold-or-a-total-function.md) и
[ADR-0208](../adr/0208-a-class-is-a-record-its-methods-and-a-closed-variant-and-nothing-mutable.md).

Разворот — модуль `«Surface sugar»` (`flang/self/sugar.flang`). Развёрнутый текст можно
прочесть глазами:

```
bootstrap/flang run-script sugar:expand -- задача.flang развёрнутое.flang
```

Беда в развёрнутом тексте называет строку и столбец исходника: строку тела цикла или
метода, а для строк, которые разворот сделал сам, — строку `цикл «…»`, `метод «…»` или
заголовка.

## Заголовок в одну строку

```
тотальная функция «Меньшее из двух» принимает первый: число, второй: число возвращает число
```

то же, что три строки `тотальная функция «Меньшее из двух»`, `принимает …`, `возвращает …`.
Без параметров: `функция «Ноль» возвращает число`.

## Цикл: хранимые значения и `дальше`

```
цикл «Сужение»
  пока лево меньше право
  убывает право минус лево плюс 1
  храним лево: число равным 1, право: число равным длина элементы, лучшее: число равным 0
  в конце лучшее
  пусть итог равно …
  если слева меньше справа
    то дальше: лево станет лево плюс 1, лучшее станет итог
    иначе дальше: право станет право минус 1, лучшее станет итог
```

| строка | что значит |
|---|---|
| `для каждого х[: тип] из список` | пройти список; тип нужен, когда ветвь выходит раньше |
| `пока условие` | повторять, пока условие верно |
| `убывает мера` | мера цикла `пока`; её проверяют при работе |
| `шагов не больше n, иначе v` | запас шагов цикла `пока` и ответ, когда запас кончился; проверки при работе нет |
| `храним имя: тип равным начало, …` | значения, которые живут между шагами |
| `в конце значение` | ответ, когда кончился список или условие стало ложным |
| `дальше: имя станет значение, …` | следующий шаг; неназванные хранимые остаются как были |

Ветвь без `дальше` — ответ цикла, то есть ранний выход.

| цикл | во что разворачивается | чем доказано завершение |
|---|---|---|
| `для каждого`, тело кончается одним `дальше` | `свёртка` по записи `«Имя — состояние»` | по построению |
| `для каждого` с ранним выходом | функция с `разбор` по остатку списка | структурой |
| `пока` с `шагов не больше` | функция с запасом `неотрицательное`, который убывает на единицу | точным шагом |
| `пока` с `убывает` | функция с объявленной мерой | объявленной мерой |

Новая функция берёт параметры объемлющей функции, которые цикл упоминает, и хранимые
значения. Имя, связанное `пусть` до цикла, входит в цикл через `храним`.

## Класс

```
класс «Счёт»
  владелец: строка
  остаток: число
  всегда «остаток не отрицателен» остаток не меньше 0

  метод «Положить» принимает сумма: число
    требует «сумма не отрицательна» сумма не меньше 0
    остаток станет остаток плюс сумма
```

Класс — это `объект «Счёт»` и функции `«Счёт: Положить»` с первым параметром `этот`.
Поле в методе пишется голым именем и становится `этот.остаток`. Метод, который кончается
строками `поле станет значение`, возвращает новый `«Счёт»`; неназванные поля переходят
как были. `всегда` даёт каждому методу `требует`, а методу, который возвращает `«Счёт»`, —
ещё `обеспечивает` о результате. Вызов: `«Счёт: Положить» от счёт и 30`.

## Интерфейс

```
интерфейс «Фигура»
  метод «Площадь» возвращает число
  метод «Название» возвращает строка
    обеспечивает «название не пусто» (длина результат) больше 0
    "фигура"

класс «Квадрат» есть «Фигура»
  сторона: число
  метод «Площадь» возвращает число
    сторона умножить на сторона
```

Интерфейс — это `тип «Фигура»` с вариантом на каждый класс файла, который говорит
`есть «Фигура»`, и функции `«Фигура: Площадь»` с `разбор` по классам. Метод без тела
обязателен; метод с телом — по умолчанию. `обеспечивает` у метода интерфейса — закон:
он ложится на метод каждого класса и на `«Фигура: Название»`.

## Отказы

| код | когда |
|---|---|
| `FLANG_SUGAR_LOOP` | у цикла нет `в конце`, нет ни `для каждого`, ни `пока`, у `пока` нет границы, `дальше` меняет имя не из `храним` |
| `FLANG_SUGAR_HEADER` | `возвращает` раньше `принимает`; слово сказано дважды; после слова ничего нет |
| `FLANG_SUGAR_CLASS` | строка класса — не поле, не `всегда`, не `метод`; `станет` меняет поле, которого нет; поле названо заново |
| `FLANG_SUGAR_INTERFACE` | класс не дал обязательный метод; заголовок метода класса не тот, что в интерфейсе; у интерфейса нет классов |

Пробы — `flang/proof/probes/surface-sugar`: на каждую форму программа с сахаром и её
развёрнутый текст дают один вердикт `check --proof`, и на каждую неверную форму — отказ со
строкой и столбцом.
