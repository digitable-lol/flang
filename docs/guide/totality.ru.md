# Как компилятор доказывает завершение функции

Чем компилятор доказывает, что функция со словом `тотальная` завершится на
любых аргументах, и что делать, когда он не смог? Это свойство называют
тотальностью. Короткое введение с упражнением —
[Всегда завершающиеся функции](../site/tour-termination.ru.md).

| | `тотальная функция` | обычная `функция` |
| --- | --- | --- |
| рекурсия | должна убывать одним из трёх способов ниже | любая |
| завершение не доказано | ошибка `FLANG_NOT_TOTAL`, файл не проходит проверку | проверки нет |
| вызов из `тотальная` | можно | нельзя |
| `flang facts` | вычисляет | не вычисляет |
| обработчик процесса | годится | нужна строка `с запасом N витков` |

## Ошибка, которую вы увидите первой

Файл `countdown.flang`:

```flang refused
модуль «Проба»

тотальная функция «Обратный отсчёт»
  принимает н: число
  возвращает число
  если н равен 0
    то 0
    иначе «Обратный отсчёт» от (н минус 1)
```

```bash
$ flang check countdown.flang
модуль «Проба»: функций 1, из них с доказанным завершением 0; типов 0
без доказанного завершения: «Обратный отсчёт»
FLANG_NOT_TOTAL в файле countdown.flang, строка 8, столбец 11: тотальная функция «Обратный отсчёт»: рекурсивный вызов «Обратный отсчёт» не убывает — аргумент 1 («н» sub 1) уменьшает параметр «н», но снизу «н» ничем не ограничен: добавьте проверку вида «если н не больше 0». …
countdown.flang: не проверено — замечаний 1
```

Сообщение называет вызов, причину и исправление. Запись `«н» sub 1` в нём
означает `н минус 1`. Для аргумента −1 условие `равен 0` не выполнится никогда, и
вызовы не закончатся. Код возврата 1.

Замените `равен 0` на `не больше 0`, и файл проходит проверку.

## Три способа убывать

### 1. По части значения

Вызов получает хвост списка, поле варианта или поле записи. Объявлять ничего не
нужно. Файл `length.flang`:

```flang
модуль «Проба»

тотальная функция «Число элементов»
  принимает элементы: список числа
  возвращает число
  пример «три элемента»
    дано элементы равно [7, 8, 9]
    ожидается 3
  разбор элементы
    случай пусто
      то 0
    случай голова и хвост
      то 1 плюс («Число элементов» от хвост)
```

```bash
$ flang check length.flang --proof
…
  «Число элементов»  доказано структурой: аргумент 1 («элементы») на каждом витке становится частью себя; цепочка частей конечного дерева обрывается сама, сторожа нет
…
```

«Доказано структурой» значит: `хвост` короче списка, а список конечен.
Последние слова строки сообщают, что проверки во время выполнения нет.

Две функции, которые вызывают друг друга, проверяются так же. Достаточно,
чтобы на каждом круге вызовов какой-то параметр становился частью себя. Файл
`read.flang`:

```flang
модуль «Проба»

тип «Номер»
  вариант «Первый»
  вариант «Следующий» содержит пред: «Номер»

тотальная функция «Прочитать»
  принимает таблица: список неотрицательное, номер: «Номер»
  возвращает неотрицательное
  разбор таблица
    случай пусто
      то 0
    случай голова и хвост
      то «Прочитать в» от хвост и номер и голова

тотальная функция «Прочитать в»
  принимает ост: список неотрицательное, номер: «Номер», г: неотрицательное
  возвращает неотрицательное
  разбор номер
    случай «Первый»
      то г
    случай вариант «Следующий» с пред как п
      то «Прочитать» от ост и п
```

Список уходит в `«Прочитать в»` хвостом и возвращается тем же. Каждый круг
укорачивает его на элемент.

### 2. Число, которое уменьшается на постоянный шаг

Нужны две вещи: аргумент вызова меньше параметра на константу, и есть ветка,
которая останавливает счёт. Файл `factorial.flang`:

```flang
модуль «Проба»

тотальная функция «Произведение до»
  принимает н: неотрицательное
  возвращает число
  пример «до пяти»
    дано н равно 5
    ожидается 120
  если н не больше 1
    то 1
    иначе н умножить на («Произведение до» от (н минус 1))
```

```bash
$ flang check factorial.flang --proof
…
  «Произведение до»  доказано точным шагом: аргумент 1 («н») объявлен натуральным и убывает на 1; дно и потолок даёт тип, внутри потолка шаг точен — сторожа нет
…
```

Тип `неотрицательное` — целое от 0 до 2⁵³−1. Он даёт нижнюю и верхнюю границу,
поэтому проверки во время выполнения нет.

С параметром типа `число` та же функция тоже проходит. Отчёт тогда говорит
«доказано постоянным шагом … 1 место». Одна проверка остаётся в программе: на
очень больших числах с плавающей точкой вычитание единицы не меняет значение.

Шагом может быть и параметр. Для него нужно `требует` со строгой границей и
ветка, под которой разность остаётся неотрицательной. Файл `step.flang`:

```flang
модуль «Проба»

тотальная функция «Сколько шагов»
  принимает н: неотрицательное, ш: неотрицательное
  возвращает число
  требует «шаг положителен» ш не меньше 1
  пример «десять по три»
    дано н равно 10
    дано ш равно 3
    ожидается 3
  если н не меньше ш
    то 1 плюс («Сколько шагов» от (н минус ш) и ш)
    иначе 0
```

Вызов стоит в ветке `если н не меньше ш`. В ветке `иначе` условия `н меньше ш`
компилятор тип разности не сужает, и проверка типов не проходит.

### 3. Строка `убывает`

Бывает, что уменьшается выражение от нескольких параметров. Его называют в
строке `убывает …` сразу после `возвращает`. Так написан двоичный поиск в
[`docs/examples/measure/binary-search.flang`](../examples/measure/binary-search.flang):
там убывает `верх минус низ плюс 1`.

Компилятор смотрит на каждый рекурсивный вызов и даёт один из трёх ответов.

**Доказано.** Выражение — параметр типа `неотрицательное`, вызов передаёт его
минус константу. Файл `two.flang`:

```flang
модуль «Проба»

тотальная функция «Через два»
  принимает н: неотрицательное
  возвращает число
  убывает н
  если н не больше 1
    то н
    иначе «Через два» от (н минус 2)
```

```bash
$ flang check two.flang --proof
…
  «Через два»  доказано точным шагом: аргумент 1 («н») объявлен натуральным и убывает на 2; дно и потолок даёт тип, внутри потолка шаг точен — сторожа нет
…
```

**Ошибка.** Вызов заведомо не уменьшает выражение: передано само имя,
`н плюс 1` или `3 умножить на н`. Файл `forever.flang`:

```flang refused
модуль «Проба»

тотальная функция «Вечность»
  принимает н: число
  возвращает число
  убывает н
  «Вечность» от (н плюс 1)
```

```bash
$ flang check forever.flang
…
FLANG_NOT_TOTAL в файле forever.flang, строка 7, столбец 3: тотальная функция «Вечность»: мера «н» на вызове «Вечность» не убывает — аргумент «н» плюс 1 не меньше меры при любом её неотрицательном значении … перепишите вызов или меру
forever.flang: не проверено — замечаний 1
```

«Мера» в сообщении — выражение из строки `убывает`. Код возврата 1.

**Проверка во время выполнения.** В остальных случаях компилятор убывание не
доказывает. Он вставляет в программу проверку на каждый вызов. Файл
`closing.flang`:

```flang
модуль «Проба»

тотальная функция «Сближение»
  принимает низ: число, верх: число
  возвращает число
  убывает верх минус низ
  если верх не больше низ
    то низ
    иначе «Сближение» от (низ плюс 2) и верх
```

`flang check closing.flang` отвечает «замечаний нет». Запуск останавливается:

```bash
$ flang run closing.flang --function "Сближение" --args '{"низ": 0, "верх": 5}'
доказано: утверждений 0
FLANG_MEASURE: тотальная функция «Сближение»: мера на вызове «Сближение» — «верх» минус «низ» — ушла ниже нуля. Мера обязана оставаться неотрицательной …
```

От 0 до 5 шагом два разность идёт 5, 3, 1, −1. Выражение обязано оставаться
целым и неотрицательным, поэтому на −1 приходит ошибка. Код возврата 1.

Отчёт показывает, сколько таких проверок осталось в программе:

```bash
$ flang check closing.flang --proof
…
  «Сближение»  доказано объявленной мерой: убывает «верх» минус «низ»; спуск ядром не выведен — на веру: мера объявлена автором, сторож считает её при работе на каждом витке — 1 место
…
  сторожей в рантайме: 1 место
…
```

Обе строки говорят одно: убывание принято без доказательства и проверяется при
каждом вызове. Последняя строка считает такие места по всему файлу.

Если завершение нужно доказать полностью, пишите первым или вторым способом.

## Счёт вверх до границы

Файл `up.flang`:

```flang refused
модуль «Проба»

тотальная функция «Счёт вверх»
  принимает н: число, предел: число
  возвращает число
  если н не меньше предел
    то н
    иначе «Счёт вверх» от (н плюс 1) и предел
```

```bash
$ flang check up.flang
…
FLANG_NOT_TOTAL в файле up.flang, строка 8, столбец 11: тотальная функция «Счёт вверх»: рекурсивный вызов «Счёт вверх» не убывает — аргумент 1 («н» add 1) увеличивает параметр «н»; аргумент 2 («предел») — это сам параметр «предел», а не его часть. …
up.flang: не проверено — замечаний 1
```

Запись `«н» add 1` означает `н плюс 1`. Параметр `предел` сам по себе границей не
считается: он приходит в каждый вызов тем же. Назовите расстояние до предела
строкой `убывает предел минус н` и дайте обоим параметрам тип `неотрицательное`:

```flang
модуль «Проба»

тотальная функция «Счёт вверх»
  принимает н: неотрицательное, предел: неотрицательное
  возвращает неотрицательное
  убывает предел минус н
  если н не меньше предел
    то н
    иначе «Счёт вверх» от (н плюс 1) и предел
```

```bash
$ flang check up.flang --proof --explain
…
  «Счёт вверх»  доказано объявленной мерой: убывает «предел» минус «н»; спуск выведен ядром на каждом витке (1) — сторожа нет
```

Спуск ядро доказывает само: вызов стоит в ветви, где `н` меньше `предел`, значит
`предел минус н` уменьшается на единицу и не уходит ниже нуля. Проверки при
работе такой функции не нужно.

С типом `число` та же строка принимается без доказательства и проверяется при
каждом вызове во время работы: выше 2⁵³ прибавка единицы числа не меняет, и вызов может не
кончиться. Счёт вниз работает с обоими типами.

Строку обходят рекурсией по списку её символов: форма `разложить … на символы`
даёт такой список. Пример —
[`docs/examples/rosetta/reverse-string.flang`](../examples/rosetta/reverse-string.flang).

## Где требуется доказанное завершение

**`flang facts`.** Команда отвечает, верно ли утверждение о данных, и не должна
зависнуть. Обычную функцию она не вычисляет. Файл `digits.flang`:

```flang
модуль «Проба»

функция «Цифр в числе»
  принимает число: число
  возвращает число
  если число меньше 10
    то 1
    иначе 1 плюс («Цифр в числе» от («Цифр в числе» от число))
```

```bash
$ flang facts digits.flang --claims '["«Цифр в числе» от 5 равно 1"]'
{"ok":false,"results":[{"claim":"«Цифр в числе» от 5 равно 1","holds":false,"why":"функция «Цифр в числе» не помечена как «тотальная»; факт-чекинг допускает только тотальные функции — иначе ответ может не наступить", …,"status":"refused"}]}
```

Поле `why` называет причину. Код возврата 1.

**Обработчик процесса.** Сервер на flang работает бесконечно, но каждый вызов
обработчика обязан завершиться. Обработчик без `тотальная` и без строки
`с запасом N витков` не проходит проверку:

```bash
$ flang check docs/examples/web/shortener/handler-without-budget.flang
…
FLANG_HANDLER_NOT_TOTAL в файле docs/examples/web/shortener/handler-without-budget.flang, строка 13, столбец 1: обработчик «шаг разбора» процесса «Разборщик» не помечен тотальным, и запаса витков процесс не называет: строки «с запасом N витков» нет. …
…
docs/examples/web/shortener/handler-without-budget.flang: не проверено — замечаний 2
```

Вторая ошибка в том же выводе, `FLANG_UNCOVERED_FAILURE`, говорит о следствии:
процесс может упасть, а перезапустить его некому. Код возврата 1.
