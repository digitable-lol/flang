# Как писать документацию

Читатель страницы — программист, который знает Python, TypeScript или Rust и не
знает, как flang устроен внутри. Он пришёл за языком. Слова, которыми мы
разговариваем между собой, ему ничего не говорят.

## Одно понятие — одно слово

| Не писать | Писать |
|---|---|
| `обещание`, `гарантия`, `свойство`, `postcondition` | постусловие |
| `precondition`, `требование` | предусловие |
| `prover`, `доказывалка`, `проверяющий` | ядро доказательств (дальше «ядро») |
| `сверщик`, `сверка` | независимая проверка; программа `checker` |
| `ведомость` | отчёт о доказательствах |
| `сетка` | «проверено только на тестах»; само слово — только в цитате вывода, с переводом |
| `на веру`, `на слове` | без доказательства; принято без перепроверки |
| `печать`, `напечатать`, `перепечатка` | генерация кода, сгенерировать; пересборка компилятора |
| `поручение` | эффект (команда для хоста) |
| `хозяин` | хост |
| `сторож` | проверка во время выполнения (в коде) / автоматическая проверка (в CI) |
| `отказ`, `беда`, `замечание` | ошибка (предупреждение — если не роняет код возврата) |
| `довод` (функции) | аргумент |
| `двоичный`, `бинарник` | компилятор, программа `flang` |
| `прогон`, `прогнать` | запуск, запустить |
| `снят`, `замер` | удалён; измерено |
| `дыра` | известная ошибка проверки типов |
| `семя`, `партия`, `приёмка`, `крюк`, `опись`, `носитель`, `ствол`, `вливание` | только в разделе «Разработка» |
| «тотальная функция» в прозе | всегда завершающаяся функция; `тотальная` — только как ключевое слово |

## Чего нет в тексте для посетителя

- Номеров решений (ADR), задач и запросов на слияние; sha коммитов; дат правок;
  числа строк файла.
- Команд `bootstrap/flang …` и путей `flang/self/…`, `flang/proof/…`: у того, кто
  поставил flang, их нет. Пишите `flang …`.
- Истории («раньше было», «с версии такой-то») — ей место на странице выпусков.
- Слов заглавными буквами.
- Слов «честно», «молча», «вслух», «поимённо»; слов «живёт», «едет», «несёт»,
  «зовёт» о программах.
- Оборота «это не X, а Y» чаще одного раза на раздел; перечислений тройками,
  пафоса, вступлений ни о чём.

## Фраза, страница, пример

- Фраза — до двадцати слов и одна мысль. Абзац — до четырёх строк.
- Страница одного вида — учебник, рецепт, справочник или объяснение — и отвечает
  на один вопрос. Вопрос назван в первых двух строках.
- Новый термин вводится один раз и через знакомое: «`разбор` — сопоставление с
  образцом (`match`)». В конце страницы не больше трёх ссылок.
- Пример — целый файл с `модуль`. Имя файла стоит над блоком, блок помечен
  языком `flang`. Под ним команда и вывод, полученный запуском нынешнего
  компилятора; пропуск обозначен «…». Вывод длиннее восьми строк сокращается.
- Каждая показанная строка вывода объяснена обычными словами. Внутреннее слово
  из вывода компилятора переводится сразу под блоком.
- Перед сдачей каждый пример запущен, а посторонний человек пересказывает
  страницу за минуту.
- Английская пара страницы (`*.md` рядом с `*.ru.md`) переписывается вместе с
  русской, тем же смыслом.
- В меню `docs/site/sitemap.mjs` меняются только строки своих страниц.

## Что из этого проверяет машина

Слова из таблицы, номера, даты, sha, пути разработчика, число строк, слова
заглавными, два имени одного понятия на одной странице и блок кода без пометки
языка на учебной странице ищет `scripts/guards/jargon-guard.fscript`. Он читает
страницы меню сайта, кроме раздела «Разработка», их английские пары, `README.md`,
`docs/README.ru.md`, `packaging/flang.1`, `docs/tutor/` и заметки о выпусках
новее 0.7.40. Блоки кода и HTML-комментарии не считаются; слово из таблицы внутри
`кода в строке` не считается тоже, а номер или путь — считается.

У каждой страницы в разделе `долг` файла `docs/jargon.json` записан потолок —
сколько находок на ней было, когда проверку включили. Одна страница — одна
строка. Больше потолка — красно. Меньше потолка — тоже красно, пока потолок не
опущен: выигрыш записывается. У новой страницы потолок — ноль.

```sh
bootstrap/flang run-script jargon:changed   # только страницы, тронутые веткой: секунды
bootstrap/flang run-script jargon:mine      # то же и список находок на этих страницах
bootstrap/flang run-script jargon:list      # все страницы, каждая находка с номером строки
bootstrap/flang run-script jargon:lower     # опустить потолки до нынешних чисел; поднять ими нельзя
bootstrap/flang run-script jargon:check     # полная проверка — та, что идёт в CI
bootstrap/flang run-script jargon:forgery   # проба порчи: копия страницы с номером решения обязана уронить проверку
```

Список находок своих страниц с номерами строк — одной строкой (ответ плана
приходит как JSON, `sed` разворачивает его в текст):

```sh
bootstrap/flang run-script jargon:mine 2>&1 | sed -n 's/^{"error":"//p; s/^{"plan":"[^"]*","result":"//p' | sed 's/","\(diagnostics\|orders\)":.*//; s/\\n/\n/g; s/\\"/"/g'
```

«Свои» — тронутые веткой относительно `dev`, включая ещё не закоммиченное. Пока
ветка меняет сам сценарий проверки или меню сайта, обход полный.
