Прежняя опись назвала `benchmarks` самым дешёвым заходом с доводом «ярлыки зовут
их без доводов». **Довод неверен, и это видно двумя прогонами.**

**Ни один из трёх файлов `benchmarks` ярлык не зовёт вообще.** В `ярлыки.flang`
их нет:


Зовут их руками, и **с доводами** — так это и записано в дереве:

* `docs/emptiness-of-what-is-proved.md:51` — `node $W/schyot.mjs <модуль>.flang`,

Дальше по файлам.

**`tasks.mjs` (181) — не долг**, разобран в куче 2.

**`work.mjs` (158) заперт дважды.**

1. Дырой 1: первый довод — каталог сборки, которого до `assemble.sh` не
   существует, и константой он быть не может.
2. **Его вывод — секундомер, и «сошлось знак в знак» для него недостижимо в
   принципе.** Файл печатает миллисекунды: `медиана`, `минимум`, `максимум`. Два
   прогона одного и того же `work.mjs` не сойдутся друг с другом, не то что с
   двойником. Сверять у него можно только поле `ответы` (контрольные суммы всех
   восьми сборок) и `расхождения`. Это надо знать заранее: тот, кто возьмётся, не
   получит доказательства того вида, каким закрыли сторожа жаргона.

**`count-library.mjs` (240) переписуем, и машинерия для него в дереве уже
лежит** — `benchmarks/proof-cost/count-20.flang` (1 341 строка) делает ровно то

каталог, отбор файлов по расширению и вид отчёта.

Заперт он не языком, а **ценой сверки**. Замер 26 августа 2026, ворота

## Порядок работ, из этой описи следующий

1. **Доводы плану (дыра 1)** — отпирает 3 файла `scripts`, 3 файла `flang/conc`
   и оба долговых файла `benchmarks`. По-прежнему самый крупный рычаг.
2. **Перепечатать точку раскрутки (дыра 2)** — слова «Удалить файл» и «Завести
   временный каталог» в словаре уже есть; отпирает узел сайта, 9 файлов,
   3 572 строки.
3. **Четыре сторожа с просмотрами** — по заходу на файл; просмотров в наборе
   образцов не будет никогда, смещения пересчитываются руками.
4. **`count-library.mjs`** — писать с `count-20.flang` как с образца, и заранее
   считать часы на сверку.

Потолок называется так и только так: **28 файлов долга из 54.** Остальные
двадцать шесть — вывод компилятора (7), граница с чужой средой и замеряемый
материал (10) и каталог тестов, которого «нет и не будет» (9). Значит «всё
написано на flang» в этом дереве означает «весь наш код на flang, кроме рантайма
чужой цели, восьми хозяев целей и мостов в чужие среды» — и писать это надо
именно так.
