# Задачи с проверкой

Выдуманная задача протухает в первый же день. Поэтому упражнения этой главы —
из дерева языка: **82 решённые задачи LeetCode**, у каждой есть исполняемые
примеры, и каждая проверяется той же командой, что и остальной курс.

```bash
ls flang/examples/leetcode/*.flang | wc -l
```

```
82
```

Машинный указатель — `flang/examples/leetcode/index.json`: номер задачи, русское
и английское название, файл, главная функция, признак тотальности, категория.
Категорий двенадцать: графы, деревья, динамика, жадность, матрица, окно,
перебор, поиск, списки, стек, строки, числа.

```json
"решено": 82,
"тотальных решений": 81
```

**Восемьдесят одно решение из восьмидесяти двух несёт доказанное завершение.**

## Одно решение читается целиком в одном файле — и это решение, а не удобство

Каждый файл корпуса **самодостаточен нарочно**. Связывание модулей в языке
работает, но оно **сливает объявления вместе с примерами** чужого модуля: файл,
подключивший `flang/stdlib/lists.flang`, при `flang test` печатает 46 примеров
библиотеки, и решение перестаёт быть решением одной задачи.

Цена самодостаточности названа честно: помощники повторяются. «Приписать в
начало списка» заведено заново в девяти файлах, тип `«Дерево»` объявлен семью,
«Есть число» — тремя.

## Как проверять свою работу

Три команды, и они те же, что во всём курсе:

```bash
flang check ваше-решение.flang          # типы, завершаемость, ядро, примеры
flang test  ваше-решение.flang          # только примеры
flang check ваше-решение.flang --proof  # ведомость доказательства
```

Пример — часть программы. Не сошёлся — `check` отвечает `FLANG_EXAMPLE` и
ненулевым кодом, и печатать такую программу компилятор откажется.

## Порядок работы, который экономит время

1. **Напишите функцию без пометки `тотальная`.** Пусть сперва заработают
   примеры.
2. **Поставьте `тотальная`.** Не прошло — читайте [главу 04](04-kogda-ne-dokazyvaetsya.md):
   переписать `разбор`ом, объявить меру, дать топливо или снять пометку.
3. **Добавьте одно постусловие.** Не тавтологию. Спросите ведомость.
4. **Не получилось доказать — не расстраивайтесь.** По [замеру](06-cena.md) это
   норма: ядро берёт два случая из двадцати.

## Четыре задачи, которые на flang не выражаются — и почему

Это самое полезное в корпусе, потому что причина названа точно, а не «пока не
сделали».

| № | Задача | Чего не хватает |
| --- | --- | --- |
| 146 | LRU Cache | изменяемое состояние, объекты с методами |
| 155 | Min Stack | то же |
| 232 | Implement Queue using Stacks | объект, помнящий операции |
| 295 | Find Median from Data Stream | состояние между вызовами + замена элемента по номеру |

Общий корень один: **условие сформулировано как набор операций над
разделяемым состоянием, живущим между вызовами**. Функция в flang — чистое
отображение аргументов в результат. Переписать «состояние в аргументе, состояние
в результате» можно, но это уже другая задача, и соответствия условию не будет.

Отдельно про 295: куча требует **замены элемента по номеру** — просеивание
меняет ячейку на месте, — а её в языке нет. Чтение по номеру появилось, замена
— нет.

И честная поправка, записанная в самом указателе: **из двенадцати задач,
числившихся невыразимыми, восемь решены**. Список невыразимого — не приговор, а
снимок, и его проверяют.

## Задача этой главы

Решите LeetCode 66 «Plus One» (прибавить единицу к числу, записанному списком
цифр) — или любую задачу, которой нет в корпусе.

Требования:

1. `flang check` возвращает 0;
2. функция помечена `тотальная`;
3. не меньше трёх примеров, из них один — граничный (пустой список, перенос
   через все разряды);
4. одно постусловие, и оно не тавтология.

**Проверка:**

```bash
flang check plus-one.flang --proof
```

Ищите в выводе три строки:

```
модуль «…»: функций N, из них с доказанным завершением N
```

```
примеров 3, прошло 3, не прошло 0
```

```
утверждений 1: доказано …
```

Если третья строка говорит «сетка 1» — это законный результат, а не провал.
Запишите, какое утверждение вы хотели доказать и почему ядро его не взяло: это
и есть навык, ради которого писалась [глава 06](06-cena.md).
