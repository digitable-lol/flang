# Куда дальше

Курс кончился. Ниже — что читать, чем перепроверять и куда идти с вопросом.

## Три вещи, которые стоит унести

**Первое.** Завершаемость доказывается массово и почти даром: 7445 функций
дерева из 9687 несут доказанное завершение, и 7190 из них не проверяют при
работе ничего.

**Второе.** Поведение доказывается редко: 236 утверждений из 395, и на выборке
из двадцати обычных функций библиотеки ядро берёт **два случая**. Цена этого
измерена и открыта.

**Третье.** «Доказано» не значит «правильно». Функция «Чётное» несёт доказанное
обо всех входах постусловие и отвечает `false` на `−4`.

записано **почему решили так**: что померили, что оказалось ложным, какой путь

## Как перепроверить каждое число этого курса

Курс держится на правиле «ни одного числа по памяти». Вот команды, которыми
снято всё, что в нём названо. Все прогоняются из клона репозитория языка.

```bash
# корпус: функции, тотальность, утверждения, аксиомы, чем несётся обещание (~52 с)
node flang/scripts/proof-ledger.mjs

# все числа сайта одним заходом; --check краснеет на первом разошедшемся
node docs/site/site-numbers.mjs --check

# цена доказательств на сегодняшнем дереве
node docs/benchmark2/tools/measure20.mjs
node docs/benchmark2/tools/reasons.mjs

# 149 понятий и покрытие четырёх поверхностей
node docs/site/surfaces-run.mjs

# аксиом ноль — отдельным тестом
node --test flang/test/digest.test.mjs

# весь набор проверок, включая цели печати
./ярлык тесты

# сайт документации: страницы, ссылки, подстановки, контраст подсветки
node docs/site/build.mjs --check
```

**И сразу честная оговорка про эти команды.** На день выпуска курса
`node docs/site/site-numbers.mjs --check` **красный**: записанные в
`docs/site/numbers.json` числа отстали от дерева на шесть ключей.

```
корпус.функций:      в numbers.json 9648, в дереве 9687
корпус.тотальных:    в numbers.json 7428, в дереве 7445
корпус.обычных:      в numbers.json 2220, в дереве 2242
корпус.безПроверок:  в numbers.json 7173, в дереве 7190
корпус.строк:        в numbers.json 128455, в дереве 129140
носители.композиция: в numbers.json 6925, в дереве 6942
```

Курс называет **числа дерева**, а не числа файла: 9687 и 7445. Лечится это одной
командой — `./ярлык numbers`, — но эта проверка не входит в `npm test`, и потому
расхождение может стоять неделями.

Это, кстати, лучшая иллюстрация ко всему курсу: **проверка, которую никто не
запускает, — это не проверка.**

## Как читать репозиторий

```
flang/          сам язык
  src/          вторая реализация, на JavaScript. Её выбрасывают
  self/         компилятор flang, написанный на flang
  stdlib/       19 файлов, 390 функций
  examples/     144 файла, из них 82 задачи LeetCode и 28 Rosetta Code
  proof/        дидактические примеры доказательств, 41 файл
  test/         проверки
bootstrap/      двоичный компилятор на C99, без Node
docs/           документация, замеры, база знаний
  site/         собираемый сайт документации
  zettel/       база знаний, 201 заметка
```

Полезное правило чтения, которое сэкономит вам день: **шапка файла в этом дереве
— не украшение**. В комментариях перед функцией обычно написано, что пробовали,
что не вышло и почему выбрано это. Начинайте с них.

## Как участвовать

- **`npm test` перед любым изменением** — ноль падений. Тест, пропущенный из-за
  отсутствия тулчейна, не считается пройденным;
- **`CHANGELOG.md` руками не править**: он печатается из тегов и тем коммитов;
- **писать только `.flang`**, JSON — единственная форма обмена;
- **улика до утверждения, числом**: не «не реализовано», а «расходится на 1020
  из 7888»;
- **снять правку и посмотреть, что покраснеет.** Не покраснело — правка ничего
  не держит.

## И одно условие, при котором всё изменится

Заметка базы знаний, которая держит весь проект:

> Революция наступит ровно тогда, когда доказательство станет дешевле тестов.

Сегодня оно дороже в 21 раз по времени и в 4,3 раза по строкам — на обычных
функциях. Там, где ядро берёт цель, оно уже дешевле в восемнадцать раз. Весь
вопрос в том, как часто берёт.

Это измеримо, это меряют, и число открыто. Спасибо, что дочитали.
