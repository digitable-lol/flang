# Виды чисел и что о них доказывает ядро

Страница отвечает на два вопроса: какие числа есть в языке и библиотеке и какие
законы арифметики ядро доказывает о каждом. Каждая строка таблиц снята
`bootstrap/flang check <файл> --proof` на пробе, описанной ниже таблицы.

## Что есть

| вид | где | представление |
| --- | --- | --- |
| `число` | язык | IEEE-754 double |
| `неотрицательное` (`нат`) | язык | целое из [0, 2⁵³−1] |
| `целое` | язык | целое из [−(2⁵³−1), 2⁵³−1] |
| `вес` (`стоимость`) | язык | [0, +∞] |
| `сотых`, `тысячных` | язык | целое число сотых или тысячных долей, не меньше нуля |
| длинное целое | `flang/stdlib/bignum.flang`, модуль «Bignum» | список разрядов по основанию 2²², младший первым; без знака |
| дробь | `flang/stdlib/rationals.flang`, модуль «Rationals» | знак, числитель и знаменатель — длинные целые, дробь всегда сокращена |
| нумерал Чёрча | `docs/examples/numbers/church-numerals.flang` | функция, применяющая другую функцию n раз |

## Что доказывает ядро о встроенных числах

Проба — функция, у которой закон записан постусловием. Например, перестановка
слагаемых:

```flang
тотальная функция «Сумма двух»
  принимает первое: сотых, второе: сотых
  возвращает число
  обеспечивает «перестановка слагаемых» результат равен (второе плюс первое)
  пример «два и три»
    дано первое равно 2
    дано второе равно 3
    ожидается 5
  первое плюс второе
```

| закон | `число` | `неотрицательное` | `целое` | `вес` | `сотых`, `тысячных` |
| --- | --- | --- | --- | --- | --- |
| `а + б = б + а` | доказано | доказано | доказано | доказано | доказано |
| `а × б = б × а` | доказано | доказано | доказано | доказано | доказано |
| `(а + б) + в = а + (б + в)` | нет | нет | нет | нет | нет |
| `(а × б) × в = а × (б × в)` | нет | нет | нет | нет | нет |
| `а + б ≥ а` | отвергнуто: NaN | доказано | нет | нет | доказано |
| `а ≥ 0` | отвергнуто: NaN | доказано | нет | доказано | доказано |
| `max(а, б) ≥ а` | нет | нет | нет | нет | нет |
| `а / б ≥ 0` | отвергнуто: NaN | нет | нет | нет | нет |
| `а mod б ≥ 0` | отвергнуто: NaN | нет | нет | нет | нет |

Почему так.

* **Перестановка** — правило ядра «одинаковы до порядка соседей»: два сына одного
  узла `плюс` или `умножить на` сличаются в любом порядке. Это верно и для IEEE-754.
* **Сочетательность не доказывается ни для одного вида.** Для `число` она ложна
  (`(0.1 + 0.1) + 0.6 = 0.8`, `0.1 + (0.1 + 0.6) = 0.7999999999999999`). Для
  `неотрицательное` ложна тоже, когда сумма выходит за 2⁵³:
  `flang run` даёт `(1 + 2) + 9007199254740991 = 9007199254740994` и
  `1 + (2 + 9007199254740991) = 9007199254740992`. С предусловием «каждое слагаемое
  не больше миллиона» она верна, но и тогда не доказывается: правила, которое
  переставляет скобки, у ядра нет.
* **Порядок.** «Максимум не меньше первого» не доказывается ни на одном виде: ядро
  не читает условие `если` фактом в ветви. Доказывается та же мысль, записанная с
  ветвлением в самом постусловии:
  `если б больше а то (результат больше а) иначе (результат не меньше а)`.
* **Деление.** `делить на` даёт `число` на любом виде; `0 / 0` и `х mod 0` — NaN,
  поэтому неотрицательность частного и остатка без предусловия неверна.
* **Моноиды и объявленные свойства** (`моноид «…»`, `свойство «коммутативность»`)
  двоичный не судит: `flang check --proof` на такой программе отвечает кодом 2 и
  словами «в программе объявлено то, чьи законы бинарник не считает — monoids,
  properties».

## Дроби

`flang/stdlib/rationals.flang`: сложение, вычитание, умножение, деление,
противоположная, сравнение, равенство, запись строкой и гармоническая сумма как
пример. Деление требует ненулевого делителя предусловием; «Дробь из целых»
требует знаменателя не меньше единицы.

Доказано ядром 13 постусловий из 13, среди них:

* ноль не бывает отрицательным — у результата сокращения, у противоположной, у
  произведения;
* произведение и частное отрицательны только при разных знаках;
* знак дроби из целых — знак числителя.

Законы алгебры записаны постусловиями в `docs/examples/numbers/rational-laws.flang`.
Ни один не доказан, все семь держатся только примерами:

| закон | ответ ядра | почему |
| --- | --- | --- |
| перестановка слагаемых и множителей | проверено только примерами | сложение дробей зовёт функции «Bignum», а правило перестановки знает только встроенные `плюс` и `умножить на` |
| перестановка скобок | проверено только примерами | правила для скобок нет даже у встроенных чисел |
| прибавить ноль, минус на минус | проверено только примерами | нужно раскрыть «Сократить» и «НОД», а ядро не держит фактов о делимости |
| дробь не меньше самой себя | проверено только примерами | то же |

Не доказывается и «сумма двух неотрицательных неотрицательна»: знак суммы выводится
из двух постусловий вызванных функций, а сцеплять два постусловия в одно ядро не
умеет. В модуле этого постусловия нет.

Дроби и длинные целые запускаются `flang run` только с `--на-веру`: в «Bignum» два
постусловия («ширина не меньше каждой длины», «меньшее минус большее — ноль»)
держатся на примерах, и вердикт о замыкании программы — «не доказано».

Десятичные с фиксированной точкой уже есть — `сотых` и `тысячных`; что о них
доказано, сказано в таблице выше.

## Нумералы Чёрча

Выражаются. Функция-значение пишется `функция «Имя»`, захват аргументов —
`функция «Имя» с н равным …`; анонимных функций нет, и каждая ступень нумерала
названа:

```flang
тотальная функция «Следующее»
  принимает н: функция из (функция из числа в число) и числа в число, ф: функция из числа в число, х: число
  возвращает число
  ф от (н от ф и х)
```

`flang run docs/examples/numbers/church-numerals.flang --function "Два на три"`
печатает `6`; сложение печатает `5`. Нумералы мономорфны — носитель `число`.
Возведение в степень (`н м`) требует применить нумерал к нумералу, и проверка
типов отказывает:

```
FLANG_TYPE … аргумент 1 применения «н»: ожидался функция из числа в число,
получен функция из (функция из числа в число) и числа в число
```

Для степени нужен полиморфный тип нумерала, а параметров типа у типа функции нет.
