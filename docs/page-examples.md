# Проверка примеров на страницах

Пример на странице документации — обещание читателю: скопируете, и он соберётся.
Обещание держит проверка страниц, написанная на flang:

```bash
bootstrap/flang run-script docs:examples
```

Она работает так:

1. Берёт перечень страниц у `git ls-files`: `README.md`, `DESCRIPTION.md` и все
   `.md` под `docs/`, кроме `docs/tasks/` — там описаны ошибки, и примеры в них
   показывают поломку.
2. Вынимает из каждой страницы блоки с оградой ```` ```flang ````.
3. Кладёт целые программы одной страницы в свой временный каталог, по файлу на
   блок, и зовёт на каждом `flang check`. Блоки одной страницы лежат рядом,
   поэтому второй блок может ввозить модуль, объявленный первым; блоки разных
   страниц друг друга не видят.
4. Сверяет код возврата с видом блока и печатает итог.

## Вид блока

| Ограда | Вид | Что требуется |
| --- | --- | --- |
| ```` ```flang ````, в блоке есть строка `модуль «…»` | программа | код 0 или 2 |
| ```` ```flang ````, строки `модуль` нет | отрывок | ничего, блок не гоняется |
| ```` ```flang refused ```` | ожидаемый отказ | код 1 |
| ```` ```flang fragment ```` | отрывок со строкой модуля | ничего, блок не гоняется |
| любая другая ограда | вывод, команды, данные | ничего |

Код 2 значит «проверено не до конца»: разбор, типы, завершаемость и примеры
прошли, а правила части объявлений — категорий, монад, процессов — двоичный
компилятор не судит и говорит об этом в выводе. Такой блок засчитывается.

Второе слово ограды подсветку не выключает: и сайт, и GitHub берут язык по
первому слову.

## Что печатает итог

```
Страниц: P. Блоков flang: N — программ A, ожидаемых отказов R, отрывков F.
Не сошлось: K.
  страница, блок n: ждали …, получили …
Понятий в словаре: C. В блоках flang: X. В проверенных программах: Y.
Без проверенного примера:
  …
```

Блок нумеруется по порядку оград ```` ```flang ```` на своей странице, отрывки
тоже в счёт. Код возврата ненулевой, когда не сошёлся хотя бы один блок.

Вторая половина итога — покрытие языка примерами. Понятия берутся из таблиц
[словаря](glossary.md); понятие считается показанным, если хоть одно его
написание стоит словом языка в программе, прошедшей проверку. Слова внутри имён
в ёлочках и внутри строковых литералов не считаются. Список «без проверенного
примера» — то, что читатель найдёт в словаре, но не увидит работающим ни на
одной странице.

Временный каталог заводится под `FLANG_TMP`, а без этой переменной — под `/tmp`.
