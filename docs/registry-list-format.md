# Список реестра: формат файла `registry.list`

Реестр flang — список имён, а не склад кода
([ADR-0059](adr/0059-the-registry-is-a-ledger-of-names-not-a-store-of-code.md)).
Весь реестр — один текстовый файл; этот документ закрепляет его формат для всех,
кто его пишет или читает: установщика (`scripts/package-install.fscript`),
инструментов реестра (`scripts/registry-tool.fscript`), печати страницы
(`scripts/site/registry-page.fscript`) и любой службы, которая раздаёт список по
сети. Разбор написан один раз — `flang/stdlib/registry.flang`, функция
«Разобрать реестр»; всё ниже — пересказ того, что делает она.

Образец — [`scripts/registry-example/registry.list`](../scripts/registry-example/registry.list).

## Файл

- Текст в UTF-8, строки разделены `\n` (`\r` перед ним допускается и снимается).
- Строка, пустая после обрезки пробелов, и строка, начинающаяся с `#`, —
  пропускаются. Первой строкой принято писать шапку-комментарий:

  ```
  # реестр flang, схема 1: имя | версия | отпечаток sha256 | адрес | нужды
  ```

  Её печатает «Шапка реестра» из `registry.flang`; читатель на неё не опирается.
- Любая другая строка — запись. Одна негодная запись делает негодным весь файл:
  разбор отвечает списком бед, а не частичным результатом.

## Запись

Поля разделены знаком `|`; пробелы по краям каждого поля обрезаются. Полей четыре
или пять — пятое (нужды) можно опустить, пустое оно или нет значения не имеет.

```
имя | версия | отпечаток | адрес | нужды
Множество строк | 1.1.0 | a9a776e1…2effc2 | sets-1.1.0.flang-package | Списки: в пределах 1.x; Логика: в пределах 1.x
```

| поле | что в нём | правило |
|---|---|---|
| имя | имя пакета — то, что стоит в `модуль «…»` и в `использует «…»` | непустое; пробелы внутри допустимы; знак `|` — нет |
| версия | три числа через точку: старшая, средняя, младшая | только цифры и точки, ровно три части (`1.2.0`); предвыпусков и букв нет |
| отпечаток | `sha256` файла пакета целиком, байт в байт | 64 знака `0-9a-f`; установщик сверяет его с телом ответа до записи на диск |
| адрес | где лежит файл пакета | см. «Адрес» ниже |
| нужды | чего этот пакет требует от других имён | `имя: диапазон`, через `; `; пусто — ничего не требует |

Одно имя может стоять в нескольких записях — по записи на версию. Две записи с
одним именем и одной версией — ошибка составителя; разбор её не ловит, выбор
версии возьмёт первую встреченную.

## Адрес

Адрес — полный URL (`http://…` или `https://…`) либо **относительный путь**.
Относительный путь считается **от каталога, в котором лежит сам список**: у
списка `http://host/flang/registry.list` адрес `sets-1.1.0.flang-package` значит
`http://host/flang/sets-1.1.0.flang-package`; у списка, прочитанного с диска
из `scripts/registry-example/registry.list`, тот же адрес значит
`scripts/registry-example/sets-1.1.0.flang-package`. Правило одно для сети и
для диска, и именно поэтому образец можно раздать любым файловым сервером из
его каталога без переписывания адресов.

Служба, раздающая список, обязана отдавать по тем же адресам и сами пакеты:
`GET` → код 200 и тело файла. Любой другой код установщик считает отказом.
Тип содержимого (`Content-Type`) не читается.

## Нужды и диапазоны

Нужда — `имя: диапазон`; несколько нужд разделяются точкой с запятой. Диапазонов
четыре, и других разбор не принимает:

| запись | значит |
|---|---|
| `любая` | любая версия |
| `ровно 1.2.3` | ровно эта версия (голое `1.2.3` читается так же) |
| `не ниже 1.2.3` | эта версия или старше |
| `в пределах 1.x`, `в пределах 1.2.x` | та же старшая (и средняя) часть, младшие любые |

Правило выбора — наибольшая версия, годная сразу всем нуждам по этому имени;
одна версия на имя; ромб поднимается до неё. Нужды самих пакетов читаются из
этого же поля, нужды проекта — из файла `flang.needs` рядом с программой, в том
же синтаксисе, по нужде на строку (или через `;`).

## Что реестр не несёт

Подписи автора нет: отпечаток говорит «файл не правили после сборки», а не «файл
от того, о ком вы думаете». Кода в списке нет: за ним установщик ходит один раз
по адресу, сверяет отпечаток и кладёт исходник в замок программы (`flang lock`);
дальше сборка в сеть не ходит.
