# flang 0.7.14 — release notes

Собрано прогоном `git log v0.7.13..gh/dev` (~40 коммитов) и чтением
`docs/design/`. Где источника не нашлось — сказано прямо, а не придумано.

Главная линия релиза — **доля корпуса, проверенная независимым чекером (линейка
Г4), выросла с ~5 % до 60,78 %**: чекер учится проигрывать заново всё больше
готовых доказательств ядра, а не верить им на слово. Вердикт `доказуемость`
по-прежнему **НЕ ДОКАЗУЕМ** — в чекере остаётся запасной калькулятор
(`перепиской`); его снятие требует отдельной волны и ещё одной перепечатки семени.

---

## Добавлено

- **Сертификат тотальности КОМПОЗИЦИИ [Ш3].** Двоичный печатает в запись
  доказательства сертификат «функция завершается, потому что рекурсии нет —
  только вызовы уже завершённых»; независимый `сверщик` проигрывает его заново
  (`сверить_тотальность`), а не верит имени правила. Топо-независимо (2 прохода +
  детект цикла). Семя перепечатано, корпус регенерирован (82 записи). Доля
  корпуса поднялась с ~5 % до 47,33 %. Коммиты `ff1dc5b7`, `cbac34ce`,
  `fba02c9a`.
- **Прибор доли-проигрыванием [Ш5].** `sh flang/proof/доля-корпуса.sh
  --проигрыванием` считает честно: числитель — обязательства, РЕАЛЬНО
  проигранные заново; знаменатель — ВСЕ обязательства корпуса (проигранные,
  снятые на слово ядра и обязательства отвергнутых записей). Ни одна запись не
  выпадает. Коммит `00a56ba5`, честный знаменатель `682006f5`.
- **Сертификат тотальности РЕКУРСИИ — виды structure/step.** Чекер проигрывает
  доказательства завершения по структуре (спуск по варианту индуктивного типа)
  и по шагу (убывающая мера ≥ 0); двоичный печатает узлы с полным свидетелем
  (убывающий довод, дно, витки, самовызов). Сквозной прогон зелёный на
  именованных индуктивных типах. **Честно:** на текущем корпусе прирост доли ≈ 0
  — корпус доказывает завершение рекурсии над встроенным `список` типовым
  законом, а не этими сертификатами; способность влита как задел. Коммиты
  `4bfbd217`, `d1bbbf94` (перепечатка семени).
- **Кредит числителя за проверенное ПО СУЩЕСТВУ.** Шаги «по примеру»/«по
  свойству», которые чекер уже проверяет вычислением (6 проверок чтением
  исходника, сторож честности не даёт соврать), теперь идут в числитель доли, а
  не только в знаменатель — прежде это была несогласованность линейки. Печать
  доли даёт разбивку (ходами / по существу). Доля 47,33 % → **60,78 %**.
  Знаменатель неизменен, доверенная база не растёт, перепечатка не нужна. Коммит
  `f5ca9e8f`.
- **Межмодульная линковка сертификата тотальности** (`--набор`/`--зависимость`):
  доверие набору записей — только по проигранному носителю, многозаписьное
  замыкание. На текущем корпусе 0 мест (проспективно). Коммит `4743a313`.

## Изменено

- **Теория категорий: `flang/cat` → `flang/ct`**, проза в `docs/ct`. Коммиты
  `acca80a3`, `8142524b`.
- **Чистка примеров и проверок:** убраны `//`-комментарии из 192 файлов с
  дедупом (`bfd86834`); `http.flang` — таблица данных вместо 55 записей
  (`853d2f01`).

## Известные ограничения (честно)

- **`доказуемость` = НЕ ДОКАЗУЕМ.** В чекере остаётся калькулятор `перепиской`
  (+ `половина_закрыта`), который часть целей пересчитывает вместо проигрывания.
  Пока он есть — вердикт отрицательный (гейт Г7).
- **Порог Г4 = 95 % на этом корпусе не гарантирован.** Подделки корпуса нарочно
  держатся в знаменателе (анти-накрутка) и в числитель попасть не могут —
  структурный потолок доли ≈ 91–96 %, порог 95 % лежит внутри вилки.
- Рекурсия structure/step покрыта в чекере, но корпус её паттерн (именованные
  индуктивные типы) почти не использует — прирост доли от неё ≈ 0.
