# flang: что готово и что осталось до 1.0

flang — язык, на котором программу пишут и доказывают в одном файле. Эта
страница коротко говорит, что уже работает и чего не хватает до выпуска 1.0.

## Что готово

- Компилятор написан на flang и собирается одной командой `make -C bootstrap`.
- `flang check` проверяет типы, завершение функций, примеры и постусловия.
- Отдельная программа `checker` перепроверяет записи доказательств без
  компилятора.
- `flang emit` создаёт код на C, C++, Go, Rust, Java, JavaScript, TypeScript,
  Elixir, Python и C#.
- В библиотеке есть списки, строки, JSON, даты, HTTP, TLS, PostgreSQL, SQLite
  и Redis.
- Чужой модуль подключается ссылкой в строке импорта и фиксируется в
  `flang.lock`.
- Готовые сборки для Linux и macOS лежат в каждом выпуске.

## Что осталось до 1.0

Выпуск 1.0 выйдет, когда выполнятся семь условий. Сроков нет.

| № | Условие | Сегодня |
|---|---|---|
| 1 | Компилятор собирается из своих исходников, и сборки совпадают | совпадают; проверка должна держаться при каждом изменении |
| 2 | Пересборка компилятора занимает меньше часа | от 80 минут |
| 3 | Доказано, что проверка доказательств не принимает ложного | доказано для части видов доказательств |
| 4 | Нет известных ошибок проверки типов | из 46 найденных открыта одна |
| 5 | Коды ошибок и формат записи доказательства не меняются незаметно | за этим следят автоматические проверки |
| 6 | Чужой модуль подключается одной строкой | работает; подписи автора нет |
| 8 | Сгенерированный код C проверен по формальному описанию языка | на базовом наборе примеров — полностью, на всех примерах — частично |

Условия под номером 7 нет: его убрали, остальные номера оставили прежними.
