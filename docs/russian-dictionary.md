# Русский словарь: признаки словоформы

Модуль `flang/ct/russian/dictionary/features.flang` отвечает, чем может быть русская словоформа:
лемма, часть речи, падеж, род, число, лицо, время и пометы. Если форма читается несколькими
способами, он отдаёт все чтения. Если слова нет, список пуст.

```
$ flang run flang/ct/russian/dictionary/features.flang --function '«Признаки слова строками»' --args '{"форма":"семью"}'
"семью семья существительное вин ж ед * * неодуш словарь\nсемью семь числительное тв * * * * * словарь\n"
```

В строке чтения десять полей через пробел: форма, лемма, часть речи, падеж, род, число, лицо,
время, пометы через запятую, источник. Звёздочка значит, что такого признака у формы нет.

## Откуда слова

Без подготовки модуль знает немного: предлоги с падежами, которых они требуют, союзы, частицы,
личные местоимения и несколько частых слов. Остальное он угадывает по окончанию и помечает такие
чтения источником «догадка»:

```
$ flang run flang/ct/russian/dictionary/features.flang --function '«Признаки слова строками»' --args '{"форма":"интерсубъективностью"}'
"интерсубъективностью интерсубъективность существительное тв ж ед * * * догадка\n"
```

Полный словарь — около 390 тысяч лемм — собирается отдельно из открытого словаря OpenCorpora.

## Собрать словарь

```
flang io scripts/russian-dictionary/build.fscript --timeout 1800000 -- <каталог словаря>
```

План скачивает выгрузку словаря (17 МБ), проверяет её контрольную сумму и строит в названном
каталоге файлы данных: около 12 МБ, две-три минуты. Нужны `curl`, `bzip2`, `sort`, `sha256sum`
и GNU awk. Уже скачанный файл можно передать вторым доводом. Ключ `--timeout` нужен, потому что
сборка подолгу ничего не печатает.

Каталог словаря держите вне дерева flang. Словарь OpenCorpora распространяется по лицензии
CC BY-SA 3.0, собранные данные — тоже: в каталоге появится файл `LICENSE.txt` с источником и
лицензией. Передавая данные дальше, сохраните его.

## Разметить текст

План читает текст и пишет таблицу признаков всех его слов:

```
flang io flang/ct/russian/dictionary/words.fscript --plan Words -- <каталог словаря> <текст> <таблица>
```

Пути считаются от корня дерева flang; полный путь берётся как есть. На тексте «Стали мы семью.»
таблица выходит такой:

```
стали сталь существительное род ж ед * * неодуш словарь
стали сталь существительное дат ж ед * * неодуш словарь
стали сталь существительное предл ж ед * * неодуш словарь
стали сталь существительное им ж мн * * неодуш словарь
стали сталь существительное вин ж мн * * неодуш словарь
стали стать глагол * * мн * прош сов,неперех словарь
мы мы местоимение им * мн 1 * * словарь
семью семья существительное вин ж ед * * неодуш словарь
семью семь числительное тв * * * * * словарь
```

В конце план говорит, сколько словоформ получили признаки:

```
словоформ: 3; с признаками: 3 (по словарю: 3, по догадке: 0); без признаков: 0
разных слов: 3; из них без признаков: 0, по догадке: 0
```

Если каталога словаря нет, план скажет об этом и ответит своими словами и догадкой.

Четвёртым доводом можно назвать вторую таблицу — короткую, по строке на лемму и часть речи:

```
стали|сталь|сущ|род ж ед;дат ж ед;предл ж ед;им ж мн;вин ж мн
стали|стать|глагол|мн *
```

Таблицу читает чистая функция `«Признаки слова по таблице» от форма и таблица`: ей передают форму
и текст таблицы, она возвращает список чтений.

## Что учесть

- Буква ё читается как е, регистр не различается: «Ёж» и «еж» — одно слово.
- Роль слова записана пометой: «связка», «бытийный», «квантор», «отрицание», «условие», «следствие»,
  «кратк». У предлога пометы называют падежи, которых он требует: «при-род», «при-вин».
- Частот слов в словаре нет. Чтения, которые сам словарь называет редкими — устаревшие, разговорные,
  имена собственные, сокращения, — несут помету «редк» и у слова со строчной идут последними.
- Словарь не выбирает между чтениями. «Стали» — и глагол, и существительное; какое чтение верно
  в предложении, решает грамматика.
- Составное слово через дефис, которого нет в словаре целиком, читается по последней части и
  получает помету «составное».
- На статью в полторы-две тысячи слов план работает 10–20 секунд и занимает 1–3 ГБ памяти.
