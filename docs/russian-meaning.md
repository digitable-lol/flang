# Логическая форма русского предложения из его разбора

flang разбирает русское предложение грамматикой и по разбору строит логическую
форму — ту же запись, что стоит в строке `[N] форма` разметки `.claims`. Языковая
модель для этого не нужна. Про предложение, форму которого построить нельзя,
программа называет причину.

Программа лежит в `flang/ct/russian/meaning.flang`, разбор даёт
`flang/ct/russian/sentence.flang`. Чтение целого текста — в
`flang/ct/russian/meaning-text.flang`, сверка разметки с грамматикой —
в `flang/experimental/argue/crosscheck.flang`.

## Прочитать предложение

```
$ flang run flang/ct/russian/meaning.flang --function «Прочитать» --args '{"предложение":"Все киты — млекопитающие."}'
"форма: все x: если кит(x), то млекопитающее(x)"
```

Перед ответом `run` печатает строку о доказанных утверждениях. Ещё примеры:

| Предложение | Ответ |
| --- | --- |
| Сократ смертен. | `форма: смертный(сократ)` |
| Сократ не смертен | `форма: не смертный(сократ)` |
| Некоторые киты плавают | `форма: есть x: кит(x) и плавать(x)` |
| Никакой кит не плавает | `форма: все x: если кит(x), то не плавать(x)` |
| Киты не являются рыбами | `форма: все x: если кит(x), то не рыба(x)` |
| Существуют белые киты | `форма: есть x: кит(x) и белый(x)` |
| Киты и дельфины дышат | `форма: все x: (если кит(x), то дышать(x)) и (если дельфин(x), то дышать(x))` |
| Если дождь идёт, то Сократ не плавает | `форма: если идти(дождь), то не плавать(сократ)` |
| Сократ может плавать | `форма: плавать(сократ)` |

Понятие называется словарной формой слова: «киты» и «китов» дают понятие `кит`,
«смертен» — понятие `смертный`. Имена предметов пишутся строчными буквами.

Слова открытых классов приходят из словаря. Функция `«Прочитать со словарём»`
принимает его вторым доводом: строки `форма=лемма,часть,падеж,род,число,лицо,время,пометы`.

## Несколько чтений

Грамматика часто даёт несколько разборов. Разборы с одной и той же формой
сливаются, разные формы называются все:

```
$ flang run flang/ct/russian/meaning.flang --function «Прочитать» --args '{"предложение":"Иерархия затрудняет достижение статуса"}'
"форм 2: затруднять(иерархия, достижение) | все x: если иерархия(x), то затруднять(x, достижение)"
```

Здесь два чтения подлежащего в единственном числе: названный предмет и всякий
предмет этого рода. Грамматика их не различает, поэтому возвращаются оба.
Первой стоит форма самого простого разбора.

Если разных форм больше двенадцати, ответ — `не построено: слишком много чтений: N`
и первые три формы.

## Когда форма не строится

| Предложение | Ответ |
| --- | --- |
| Он смертен | `не построено: отсылка: «он»` |
| Сократ бормочет | `не построено: неизвестное слово: «бормочет»` |
| кита китов | `не построено: нет сказуемого` |

Отсылка без предыдущего предложения не разрешается. Числа запись `.claims`
этим путём не выражает. Причины грамматики — неизвестное слово, нет сказуемого,
слова не связываются — передаются как есть.

## Как форма собирается

Разбор — дерево: у каждого слова есть главное слово и роль. Правило сборки
выбирается по роли:

| Роль | Что она даёт |
| --- | --- |
| подлежащее | предмет или род предметов, о котором говорит сказуемое |
| определение, родительное, предложное определение | ещё один признак того же предмета |
| «все», «каждый», «некоторые», «никакой» при имени | квантор |
| именная часть при связке | признак, сказанный о подлежащем |
| прямое дополнение | второе место понятия: `иметь(архив, копия)` |
| дополнение в косвенном падеже | место понятия: `обладать(система, память)` |
| группа с предлогом, которым слово управляет | место понятия, предлог входит в имя: `состоять_из(система, узел)` |
| прочие обстоятельства: место, время, образ действия | в форму не входят, в разметке стоят уточнением |
| «может», «должен», «можно» с инфинитивом | форму даёт инфинитив, слово записано уточнением силы |
| «не» при сказуемом | отрицание |
| однородные сказуемые и подлежащие | «и» либо «или» между суждениями |
| придаточное с «если», «когда» | условие |
| придаточное с «так как», «поскольку» | оба суждения утверждаются |
| причастный оборот, придаточное с «который» | признак предмета |
| деепричастный оборот | ещё один признак подлежащего |

## Что входит в понятие

Имя понятия — словарная форма сказуемого. Дополнение становится местом понятия:

| Предложение | Ответ |
| --- | --- |
| Архив имеет резервную копию | `форм 2: иметь(архив, копия) \| все x: если архив(x), то иметь(x, копия)` |
| Система состоит из равноправных узлов | `форм 2: состоять_из(система, узел) \| все x: если система(x), то состоять_из(x, узел)` |
| Алгоритм зависит от размера сети | `форм 2: зависеть_от(алгоритм, размер) \| все x: если алгоритм(x), то зависеть_от(x, размер)` |
| Сбой приводит к ошибке | `форм 2: приводить_к(сбой, ошибка) \| все x: если сбой(x), то приводить_к(x, ошибка)` |
| Система обладает большой памятью | `форм 2: обладать(система, память) \| все x: если система(x), то обладать(x, память)` |
| Система работает в сети | `форм 2: работать(система) \| все x: если система(x), то работать(x)` |

«Из узлов» — часть смысла слова «состоит», а «в сети» при слове «работает» —
обстоятельство места. Различает их список пар «слово + предлог» в
`meaning.flang`: «состоять из», «зависеть от», «приводить к», «относиться к»,
«свидетельствовать о», «указывать на» и ещё около двухсот. Пары нет в списке —
группа с предлогом остаётся обстоятельством. В словаре сведений об управлении
нет, поэтому список неполон: на выборке из ста групп с предлогом он не назвал
управляемой ни одной лишней, но пропустил 12 из 26 управляемых.

## Разметить текст целиком

```
$ flang run-script russian-meaning:markup -- text.txt text.claims
```

Без второго довода разметка печатается на экран. Текст примера:

```
Система состоит из равноправных узлов. Алгоритм зависит от размера сети.
Система не содержит центральных узлов. Система работает в сети. Сократ может плавать.
```

Суждения разметки:

```
[1] состоять_из(система, узел)
    цитата: Система состоит из равноправных узлов
    происхождение: грамматика
    вариант: все x: если система(x), то состоять_из(x, узел)
[1а] равноправный(узел)
    цитата: Система состоит из равноправных узлов
    происхождение: грамматика
[2] зависеть_от(алгоритм, размер)
    цитата: Алгоритм зависит от размера сети
    происхождение: грамматика
    вариант: все x: если алгоритм(x), то зависеть_от(x, размер)
[2а] род_сеть(размер)
    цитата: Алгоритм зависит от размера сети
    происхождение: грамматика
[3] не содержать(система, узел)
    цитата: Система не содержит центральных узлов
    происхождение: грамматика
    вариант: все x: если система(x), то не содержать(x, узел)
    # уточнение: узел + центральный
[4] работать(система)
    цитата: Система работает в сети
    происхождение: грамматика
    вариант: все x: если система(x), то работать(x)
    # уточнение: работать + в_сеть
[5] плавать(сократ)
    цитата: Сократ может плавать
    происхождение: грамматика
    # уточнение: плавать + сила «может»
```

Как это читать:

- `[N]` — главная форма: форма первого разбора. Строки `вариант:` — остальные
  прочтения той же цитаты.
- `происхождение: грамматика` говорит, кто записал суждение. Тот, кто правит
  разметку, меняет помету на `грамматика, вариант K` или `модель`.
- `[1а]` — то, что сказано о слове внутри предложения: узлы равноправны. Это
  отдельное суждение с той же цитатой. Имя `род_сеть` значит «чего: сети».
- Под отрицанием и условием такое суждение не выносится: из «не содержит
  центральных узлов» не следует, что узлы центральные. Признак остаётся
  строкой `# уточнение: узел + центральный`.
- `# уточнение:` — то, что в форму не вошло: обстоятельство, сила суждения.
  Для проверки это комментарий.
- Предложение, которое не прочитано, стоит комментарием с причиной:
  `# [N] не прочитано: неизвестное слово: «бормочет» — «Сократ бормочет»`.

В шапке разметки объявлены понятия и имена. Если одно слово стоит и понятием
(`система(x)`), и именем (`работать(система)`), под шапкой стоит пометка:

```
# слово «система» стоит и понятием, и именем предмета: оставьте одно чтение
```

Такие суждения между собой не связаны: из «все системы работают» не следует
`работать(система)`. Свести слово к одному чтению должен тот, кто правит
разметку.

### Отсылки и шаги вывода

На тексте `flang/proof/probes/russian-meaning/sample.txt`:

```
Все киты — млекопитающие. Киты не являются рыбами. Моби — кит.
Следовательно, Моби — млекопитающее. Моби не является рыбой, так как Моби — млекопитающее.
Все рыбы плавают. Значит, Моби плавает. Он дышит.
```

конец разметки такой:

```
# [9] отсылка разрешена предположительно: он = моби
[9] дышать(моби)
    цитата: Он дышит
    происхождение: грамматика
# шаг к [4]: посылки в тексте не названы, взяты суждения от прошлого вывода
вывод [4] из [1], [2], [3]
вывод [5] из [6]
# шаг к [8]: посылки в тексте не названы, взяты суждения от прошлого вывода
вывод [8] из [5], [6], [7]
```

Местоимение заменяется ближайшим именем того же рода и числа из этого или
предыдущего предложения; подлежащее предпочитается. Это предположение, и над
суждением стоит пометка.

Шаг вывода дают слова «следовательно», «значит», «поэтому», «так как»,
«поскольку». Когда слово вывода стоит в начале предложения, посылками взяты все
суждения от прошлого вывода, и над шагом стоит пометка.

Текст режется на предложения по точке. Точка после инициала, после сокращения
вроде «рис.» или «табл.» и внутри дробного числа предложение не кончает.

## Сверить разметку с грамматикой

Форму суждения в `.claims` обычно пишет языковая модель, и форма может не
соответствовать цитате. Сверка читает цитату грамматикой и сравнивает формы.
Равносильность в обе стороны проверяет ядро доказательств, строки не сравниваются.

```
$ flang run-script argue:crosscheck -- flang/proof/probes/argue-crosscheck/claims/forgeries.claims "" table.tsv
суждений 19: подтверждено 8, с предположительной отсылкой 1, из черновика 2, неверная помета 1, только пояснение 1, расходится 4, понятия не сопоставлены 1, не прочтено 1, не решено 0
```

Второй довод — файл со строками словаря, здесь он пуст. Третий — файл таблицы;
без него таблица печатается на экран.

| Ответ | Что он значит |
| --- | --- |
| подтверждено грамматикой | форма разметки равносильна одной из форм грамматики; названо, которой и из скольких |
| подтверждено с предположительной отсылкой | то же, но местоимение цитаты заменено по догадке |
| расходится | понятия те же, а форма не равносильна ни одной форме грамматики |
| понятия не сопоставлены | у грамматики есть понятия, которых в форме разметки нет |
| грамматика не прочла | цитата не разобрана либо чтений слишком много; названа причина |
| взято из черновика грамматики | у суждения помета `происхождение: грамматика`, и его форма есть среди форм грамматики |
| помета происхождения неверна | помета говорит «грамматика», а такой формы у грамматики нет |
| совпало только пояснение | понятие без мест совпало с цитатой по пояснению, устройство его не проверено |

Четыре суждения этого примера испорчены нарочно, и сверка ловит все четыре:

| Цитата | Форма в разметке | Форма грамматики |
| --- | --- | --- |
| Все киты — млекопитающие | `все x: если млекопитающее(x), то кит(x)` | `все x: если кит(x), то млекопитающее(x)` |
| Киты не являются рыбами | `все x: если кит(x), то рыба(x)` | `все x: если кит(x), то не рыба(x)` |
| Некоторые киты плавают | `все x: если кит(x), то плавает(x)` | `есть x: кит(x) и плавать(x)` |
| Если дождь идёт, то Сократ не плавает | `если не плавает(Сократ), то идёт_дождь` | `если идти(дождь), то не плавать(сократ)` |

Формы не обязаны совпадать по записи: цитата «Киты не являются рыбами» с формой
`все x: если рыба(x), то не кит(x)` подтверждена.

Понятия и имена предметов сопоставляются двумя способами, и таблица это называет:

- по словарной форме: `смертен = смертный(x) (по лемме)`,
  `Матрица = матрица (по лемме)`;
- по пояснению в строке `понятие`: для `понятие идёт_дождь: дождь идёт` грамматика
  читает пояснение и получает `идёт_дождь = идти(дождь) (по пояснению)`.

Совпадение по пояснению понятия без мест значит одно: пояснение и цитата
читаются одинаково. Внутреннее устройство такого понятия сверка не видит, и
ответ об этом говорит отдельно: «совпало только пояснение».

## Что проверено, а что нет

- **Проверено пробами:** предложения, короткие тексты и ожидаемые ответы —
  `flang io flang/proof/probes/russian-meaning/run.fscript --plan Binary`;
  ответы сверки, подделки и отсылка —
  `flang io flang/proof/probes/argue-crosscheck/run.fscript --plan Binary`.
- **Проверено ядром:** равносильность двух форм в сверке.
- **Не проверено ничем:** что форма грамматики передаёт смысл предложения так, как
  понял бы человек. Правила сборки написаны руками, а из нескольких разборов
  верный не выбирается.

Чего программа не умеет: числа и количества, цель («чтобы»), равенство двух
предметов, кванторы большинства («многие»), однородные дополнения. Слова
«может» и «должен» в форму не входят: форма сильнее сказанного, слово стоит
только в уточнении. Содержание придаточного после «показал, что» в форму не
попадает. Имя собственное узнаётся по словарю, заглавная буква не учитывается.
