# Логическая форма русского предложения из его разбора

flang разбирает русское предложение грамматикой и по разбору строит логическую
форму — ту же запись, что стоит в строке `[N] форма` разметки `.claims`. Языковая
модель для этого не нужна. Грамматика пока читает узкий круг предложений; про
остальные она называет причину.

Программа лежит в `flang/ct/russian/meaning.flang`. Сверка разметки с грамматикой —
в `flang/experimental/argue/crosscheck.flang`.

## Прочитать предложение

```
$ flang run flang/ct/russian/meaning-parses.flang --function «Прочитать» --args '{"предложение":"Все киты — млекопитающие."}'
доказано: утверждений 12
"форма: все x: если кит(x), то млекопитающее(x)"
```

Ещё примеры. Слева предложение, справа ответ:

| Предложение | Ответ |
| --- | --- |
| Сократ смертен. | `форма: смертный(Сократ)` |
| Если идёт дождь, то дорога мокрая. | `форма: если дождь, то мокрый(дорога)` |
| Некоторые киты белые | `форма: есть x: кит(x) и белый(x)` |
| Ни один кит не рыба | `форма: все x: если кит(x), то не рыба(x)` |
| Сократ не является рыбой | `форма: не рыба(Сократ)` |
| Все сервисы с резервной копией надёжны | `форма: все x: если сервис(x) и с_резервный_копия(x), то надёжный(x)` |
| Сервис «Архив» имеет резервную копию | `форма: иметь_резервный_копия(Архив)` |
| Рыбы кита белые | `форма: все x: если рыба(x) и род_кит(x), то белый(x)` |
| мама читает книгу | `форма: читать_книга(мама)` |

Понятие называется словарной формой слова: «киты», «кита» и «китов» дают одно
понятие `кит`, «смертен» и «смертны» — понятие `смертный`.

Если предложение читается несколькими способами, ответ называет все формы:
`форм 2: … | …`. Выбор между ними программа не делает.

## Когда форма не строится

Ответ называет причину:

| Предложение | Ответ |
| --- | --- |
| Он смертен | `не построено: отсылка: «Он»` |
| Сократ может плавать | `не построено: модальность: «может»` |
| Три кита белые | `не построено: число: «Три»` |
| Сократ шьёт | `не построено: неизвестное слово «шьёт»` |
| мама даёт брату книгу | `не построено: неизвестная конструкция: два дополнения: «даёт»` |

Отсылка — слова «он», «это», «данный», «такой»: форма не знает, о чём они.
Модальность — «может», «должен», «возможно». Число — цифры и числительные. В записи
`.claims` для них нет средств.

## Как форма собирается

Разбор даёт каждому слову тип и связывает слова, чьи типы сократились. У каждой
части речи своё правило сборки:

| Слово | Что оно даёт |
| --- | --- |
| существительное | признак предмета: `кит(x)` |
| имя | названный предмет: `Сократ` |
| прилагательное при существительном | ещё один признак того же предмета |
| существительное в родительном падеже после другого | признак `род_…` того же предмета |
| предлог с существительным после другого | признак `с_…`, `без_…` того же предмета |
| «все», «каждый», «некоторые», «ни один» | квантор над признаком |
| глагол, краткое прилагательное | сказуемое: признак, сказанный о подлежащем |
| тире, «это», «является» | сказуемое из существительного справа |
| «не» | отрицание сказуемого |
| «если», «то», «и», «или» | связка двух суждений |

Подлежащее во множественном числе без квантора читается как «все»: «Киты умны» —
`все x: если кит(x), то умный(x)`. Подлежащее в единственном числе читается как
названный предмет: «Дорога мокрая» — `мокрый(дорога)`.

Нарицательное дополнение входит в имя понятия: «имеет резервную копию» —
`иметь_резервный_копия`. Имя в дополнении даёт отношение: «Иван любит Марию» —
`любить(Иван, Марию)`. Имя в косвенном падеже остаётся как в тексте.

## Разметить текст целиком

План читает текст и пишет к нему разметку: суждения, цитаты и шаги вывода.

```
$ flang run-script russian-meaning:markup -- flang/proof/probes/russian-meaning/sample.txt sample.claims
```

Текст примера:

```
Все киты — млекопитающие. Ни одно млекопитающее не рыба. Моби — кит.
Следовательно, Моби — млекопитающее. Моби не рыба, так как Моби — млекопитающее.
Все рыбы плавают. Значит, Моби плавает. Он может дышать.
```

Конец разметки:

```
[7] все x: если рыба(x), то плавать(x)
    цитата: Все рыбы плавают
[8] плавать(Моби)
    цитата: Моби плавает
# [9] не построено: отсылка: «Он» — «Он может дышать»
# шаг к [4]: посылки в тексте не названы, взяты суждения от прошлого вывода
вывод [4] из [1], [2], [3]
вывод [5] из [6]
# шаг к [8]: посылки в тексте не названы, взяты суждения от прошлого вывода
вывод [8] из [5], [6], [7]
```

Шаг вывода дают слова «следовательно», «значит», «поэтому», «итак», «так как»,
«поскольку», «потому что». Когда посылка названа в том же предложении («так как …»),
она и записана. Когда слово вывода стоит в начале предложения, посылками взяты все
суждения от прошлого вывода, и над шагом стоит пометка: это предположение, его
стоит перечитать.

Такую разметку принимает проверка рассуждений:

```
$ flang run-script argue -- flang/proof/probes/russian-meaning/sample.txt --claims sample.claims --out sample.md
отчёт записан: sample.md; находок: 2; шагов: 3, следует: 1, не следует: 2, ядро не решило: 0
```

Шаг `[8] из [5], [6], [7]` не следует: из того, что все рыбы плавают, а Моби не
рыба, не выходит, что Моби плавает.

## Сверить разметку с грамматикой

Форму суждения в `.claims` обычно пишет языковая модель, и форма может не
соответствовать цитате. Сверка читает цитату грамматикой и сравнивает две формы.
Равносильность в обе стороны проверяет ядро доказательств, строки не сравниваются.

```
$ flang run-script argue:crosscheck -- flang/proof/probes/argue-crosscheck/claims/forgeries.claims "" table.tsv
суждений 11: подтверждено грамматикой 5, расходится 5, грамматика не прочла 1, ядро не решило 0
```

Второй довод — файл с добавочными строками словаря, здесь он пуст. Третий — файл
таблицы; без него таблица печатается на экран.

Ответов три:

| Ответ | Что он значит |
| --- | --- |
| подтверждено грамматикой | грамматика прочла цитату и получила равносильную форму |
| расходится | формы не равносильны; таблица показывает обе |
| грамматика не прочла | цитату грамматика не разобрала; названа причина |

В этом примере четыре суждения испорчены нарочно, и сверка ловит все четыре:

| Цитата | Форма в разметке | Форма грамматики |
| --- | --- | --- |
| Все киты — млекопитающие | `все x: если млекопитающее(x), то кит(x)` | `все x: если кит(x), то млекопитающее(x)` |
| Сократ не рыба | `рыба(Сократ)` | `не рыба(Сократ)` |
| Некоторые киты белые | `все x: если кит(x), то белый(x)` | `есть x: кит(x) и белый(x)` |
| Если идёт дождь, то дорога мокрая | `если мокрая_дорога, то идёт_дождь` | `если дождь, то мокрый(дорога)` |

Формы не обязаны совпадать по записи. Цитата «Ни один кит не рыба» с формой
`все x: если рыба(x), то не кит(x)` подтверждена: грамматика даёт
`все x: если кит(x), то не рыба(x)`, и ядро доказывает, что формы равносильны.

Понятия разметки и грамматики могут называться по-разному. Сверка сопоставляет их
двумя способами и пишет в таблице, что сопоставление сделано:

- по словарной форме: `смертен = смертный(x) (по лемме)`;
- по пояснению в строке `понятие`: для `понятие идёт_дождь: идёт дождь` грамматика
  читает пояснение и получает `идёт_дождь = дождь (по пояснению)`.

Если сопоставить понятия не удалось, ответ — «расходится» с причиной
`понятия не сопоставлены: …`. Причина `понятия те же, логическая форма другая`
значит, что слова совпали, а логика нет.

## Что проверено, а что нет

- **Проверено пробами:** предложения и ожидаемые формы — `flang run-script
  russian-meaning:probe`; пары «цитата и форма» на все три ответа сверки —
  `flang run-script argue-crosscheck:probe`.
- **Проверено ядром:** равносильность двух форм в сверке. Ответ «расходится»
  опирается на случай, когда одна форма верна, а другая нет; ядро этот случай
  пересчитывает.
- **Не проверено ничем:** что форма грамматики передаёт смысл предложения так, как
  понял бы человек. Правила сборки написаны руками.

Чего программа пока не умеет: однородные члены («киты и дельфины»), придаточные
с «который», причастные обороты, обстоятельства места и времени, глаголы с двумя
дополнениями. Словарь мал: слово вне словаря останавливает чтение предложения.
