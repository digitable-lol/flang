# Какие конструкции русского предложения читает грамматика

Эта страница — мера покрытия грамматики из `flang/ct/russian/sentence.flang`. Виды
конструкций взяты не из головы, а из раздела «Синтаксис» справочника: А. Н. Тихонов,
Р. И. Хашимов, «Энциклопедический словарь-справочник лингвистических терминов и
понятий. Русский язык», в 2 т., М.: Флинта: Наука, 2014. Из примерно девятисот статей
раздела оставлены те, что называют вид конструкции предложения: члены предложения,
виды сказуемого, типы простого предложения, однородные и обособленные члены, вводные
и вставные слова, виды придаточных, бессоюзие, чужая речь, способы связи слов. Статьи
о теории, истории языка, интонации и тексте в опись не вошли.

У каждого вида указано название статьи, том и страница. Определения не переписаны:
вид назван так, как его называет справочник, а примеры придуманы для этой описи.

## Как проверяется

Каждый пример лежит в таблице проб `flang/proof/probes/russian-sentence/expected.tsv`
вместе с ролью связи, которая должна найтись в разборе. Вид считается прочитанным,
когда разбираются все его примеры и в разборе есть эта роль; «частично» — когда
разбирается только часть примеров. Пробы гоняет одна команда:

```
flang run-script russian-sentence:probe
```

Слова примеров берутся из пробного словаря `flang/ct/russian/sample-dictionary.flang`.
Прочитанный вид значит, что грамматика строит для примера дерево с нужной связью;
что это дерево первое среди разборов, не проверяется.

Видов в описи 94. Читаются 89, частично — 1, не читаются 4.

Не читаются: инфинитивное предложение («Решить задачу.»), повеление («Рассмотрите
задачу.»), слово-предложение («Да.») и парцелляция — отдельная часть предложения
после точки («И задачу.»). Частично читается вопрос: «Работает ли система?» —
да, «Почему система работает?» — нет.
