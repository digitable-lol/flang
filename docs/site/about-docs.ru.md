# Как устроена документация

Версия документации — это версия языка: сейчас **{{выпуск.версия}}**. Отдельной
нумерации у документов нет намеренно: два номера разъезжаются, один — нет.

## Подвал

Внизу каждой страницы стоят две строки, и ставит их сборка, а не человек.

Первая — о проекте: кто делает язык, под какой лицензией, где дерево, куда нести
ошибку.

```
Язык делает Digitable (Marat Zimnurov) · лицензия BSD 2-Clause, © 2026,
дословный текст — LICENSE в корне дерева · исходники —
github.com/digitable-lol/flang · об ошибке — issues того же репозитория
```

Ни один факт в ней не набран. Правообладатель, год и имя лицензии читаются
из `LICENSE`, оба адреса — из `package.json`; имя лицензии из файла сверяется с
полем `license` пакета, и расхождение роняет сборку. Набранный год протух бы
1 января, а набранный адрес — в день переезда репозитория, и оба протухли бы
молча.

Вторая — о самой странице: к какой версии языка она относится и на каком дереве
снята.

```
Документация flang 0.5.0 · дерево 83a0b5d от 2026-08-18 · собрано 2026-08-18
```

Все три значения в примере — образец формата, а не сегодняшние: настоящие стоят
внизу той страницы, которую вы читаете.

Коммит и дата берутся у `git rev-parse --short HEAD` и
`git log -1 --date=short` во время сборки, версия — из `package.json`. В
выгрузке без `.git` (`git archive`) строка честно говорит, что дерева не
назвала, вместо того чтобы назвать неверное.

## Знак в шапке

Знак языка нарисован в самой сборке и вставлен в разметку каждой страницы: ни
файла картинки, ни запроса на сторону — сайт обязан открываться без сети целиком,
а не почти целиком. Своего цвета у знака нет, он берёт цвет буквы рядом и потому
переворачивается вместе с тёмной темой сам. Мера — 24 пикселя: на ней он
проверен, и ниже неё его ставить нельзя.

## Даты в тексте

Дата стоит в прозе только там, где она часть факта: «выпуск 0.4.8 от 9 августа
2026», «замер снят на такой-то машине такого-то числа». Отметки о ходе работы —
«правка сделана 16 августа», «было верно ещё утром и перестало быть верным к
вечеру» — из текстов убраны. На вопрос «к чему относится эта страница» отвечает
строка происхождения, и отвечает точнее.

## Числа

Число на странице не набирается. В тексте стоит подстановка
`{{!корпус.функций}}`, а значение приезжает при сборке из `docs/site/numbers.json`
— одно число, одно место. Большое число можно попросить разрядами:
`{{!корпус.строк|разрядами}}` даёт {{корпус.строк|разрядами}}.

Замер снимается одной командой:

```
./ярлык numbers
```

Все программы репозитория меряет `flang/scripts/proof-ledger.mjs` — тот же
измеритель, что и у проверки чисел. Беглый счёт вместо него врёт: связывание
импортов приписывает функции модуля каждому, кто этот модуль ввозит, и ответ
вырастает вдвое.

Записанное не имеет права протухнуть:

```
./ярлык numbers:check
```

перемеряет дерево заново и краснеет на первом разошедшемся числе. Поэтому числа
в `numbers.json` — это не «числа на какой-то день», а числа ЭТОГО дерева, того
самого, чей коммит стоит внизу страницы. Сегодня это {{корпус.функций}} функций,
написанных на flang, и {{утверждения.доказано}} доказанных ядром утверждений — и
ни одна страница не вправе назвать других.

## Поиск

Поиск идёт целиком в браузере: сайт лежит на GitHub Pages, сервера за ним нет.
Указатель собирает сборка (`docs/site/poisk.mjs`) и кладёт рядом со страницами
одним файлом `poisk-ukazatel.js`; ищет по нему `poisk.js` — свой, без единой
библиотеки, как и разбор markdown.

В указателе лежит не весь текст. Полный текст всех страниц — около 1,8 миллиона
знаков, почти три мегабайта: указатель такого веса грузился бы дольше, чем
читается страница, ради которой его открыли. Поэтому в записи страницы стоят
заголовок, раздел, все подзаголовки и **первые 700 знаков** текста. Отрезание
оправдано укладом дерева, а не только весом: заметка базы знаний начинается с
утверждения, а страница сайта — с того, о чём она. Точный вес указателя
печатает сборка, отдельной строкой рядом с числом страниц.

Указатель подгружается при первом касании поля, а не с каждой страницей:
пришедшему читать он не нужен, а загруженный один раз лежит в кеше браузера.

Про русский язык здесь два правила. «Ё» и «е» для поиска — одна буква: в дереве
есть и «свёртка», и «свертка», а в словаре языка они стоят соседними ячейками
одной строки. И слово сравнивается по основе, а не целиком, — набравший
«свёртка» находит «свёртке», набравший «тотальность» находит «тотальную».

Без JavaScript поля поиска нет вовсе: оно размечено `hidden` и открывается
скриптом. Страница при этом остаётся тем же, чем была, — боковое оглавление на
месте, читается всё. Поле, которое принимает буквы и не отвечает, хуже
отсутствующего.

## Чем это стерегут

| Команда | Что не даёт сделать |
|---|---|
| `./ярлык numbers:check` | оставить на сайте число, разошедшееся с деревом |
| `./ярлык site:check` | завести страницу без английской пары, сослаться в никуда, оставить подстановку без значения, сломать поиск, оставить на главной пример кода, которого в дереве больше нет |
| `./ярлык links:check` | сломать переименованием ссылку на файл дерева |
| `./ярлык glossary:check` | разойтись словарю страницы и таблице поверхностей |

## Где что лежит

Тексты — в `docs/`, карта страниц — `docs/site/sitemap.mjs`, сборка —
`node docs/site/build.mjs`. Печатаемая страница правится не в `.md`, а в своём
печатнике: [журнал вливаний](changelog.html) —
`scripts/build-changelog-page.mjs`, [журнал коммитов](journal.html) —
`scripts/build-changelog.mjs`, [выпуски](releases.html) —
`scripts/build-releases-page.mjs` вместе с заметками в
`docs/release-notes.json`.
