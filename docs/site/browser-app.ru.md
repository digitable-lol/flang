# Приложение в браузере

«Градины» — приложение во вкладке, написанное на flang. Наберите число цифрами, нажмите
«пуск» — и число идёт по правилу Коллатца: чётное делится пополам, нечётное умножается на три и
плюс один. «Шаг» двигает на такт, «бег» считает сам, пока не остановят.

Браузер flang не исполняет: программа печатается в JavaScript, и во вкладку едет напечатанный
модуль. Исходники лежат в репозитории, в `docs/examples/web/browser-app/`.

## Запустить

Из корня клона репозитория:

```sh
sh docs/examples/web/build.sh
flang io docs/examples/web/stand.flang --max-orders 100000 --trust
# открыть http://127.0.0.1:8908/docs/examples/web/browser-app/index.html
```

Первая команда печатает приложение в JavaScript рядом со страницей (`flang emit --target js
--no-cli`), вторая поднимает стенд — программу на flang, которая отдаёт файлы по HTTP. Ни Node,
ни npm не нужны. Ключ `--trust` обязателен: часть обещаний стенда проверена примерами, а не
доказана, и без ключа `flang io` такую программу не запускает.

В 0.7.34 печать называет модуль с русским именем `program.js` (91 788 байт), а страница
приложения просит `gradiny.js` и получает от стенда 404. Скопируйте напечатанный файл под этим
именем. Работа приложения в самом браузере для этой страницы не проверялась.

## Из чего оно состоит

| что | где | строк |
|---|---|---:|
| приложение: состояние, шаги, экран | `docs/examples/web/browser-app/hailstone.flang` | 256 |
| разметка, без единой строки JavaScript | `docs/examples/web/browser-app/index.html` | 88 |
| хозяин вкладки, общий для всех страниц | `flang/src/emit/js/flang_host_browser.js` | 1822 |
| стенд, отдающий страницу | `docs/examples/web/stand.flang` | 395 |

В приложении 16 функций, все тотальные, и 31 пример:

```sh
$ flang check docs/examples/web/browser-app/hailstone.flang
модуль «Градины»: функций 16, из них с доказанным завершением 16; типов 5
$ flang test docs/examples/web/browser-app/hailstone.flang
docs/examples/web/browser-app/hailstone.flang: примеров 31, прошло 31, не прошло 0
```

Страница подключает хозяина одним тегом и называет ему модуль:

```html
<script type="module" src="../../../../flang/src/emit/js/flang_host_browser.js"
        данные-модуль="./gradiny.js"></script>
```

## Как программа говорит с вкладкой

Программа — это `план`: состояние, начальная функция и обработчик откликов.

```
план «Градины»
  состояние «Полёт»
  начинает с «Начать»
  обрабатывает «Дальше»
```

Обработчик ничего не делает сам. Он получает отклик хозяина и возвращает следующее поручение:

| отклик хозяина | что отвечает программа |
|---|---|
| «Пока ничего», «Показано» | показать экран, затем ждать событие |
| «Случилось» с откуда и значение | применить нажатие к состоянию и показать экран |
| «Срок вышел» | сделать один шаг и показать экран |
| «Сбой» с код и сообщение | закончить отказом с тем же кодом |

Поручений два. `«Показать» с место равным "экран" и текст равным …` кладёт текст в место
страницы, помеченное `данные-место`. `«Ждать событие» с срок равным 350` значит «разбуди на
действии человека или через 350 мс, что раньше»; срок 0 — ждать только человека. Так одно
ожидание покрывает оба источника событий, кнопки и часы.

Три следствия такого устройства:

- **Программа не знает про DOM.** Она называет место строкой, которую придумала сама, и отдаёт
  текст. Разметку она не строит: `innerHTML` хозяин не использует.
- **Тотальность цела.** «Шаг градины» — тотальная функция, а завершается ли вся
  последовательность Коллатца, неизвестно. Шаг повторяет не программа, а человек или часы:
  незавершаемость живёт в цикле хозяина.
- **Вкладка не замирает.** Пока программа ждёт событие, стек пуст; будит её хозяин.

## Какие цели печатают план

Программу с объявлением `план` печатают `c`, `go`, `js`, `python`, `rust` и `ts`. Цели `cpp`,
`csharp`, `elixir` и `java` отказывают кодом `FLANG_PLAN_UNSUPPORTED`.
