# Проверенная функция внутри чужой программы на C без libc

Как вызвать функцию, проверенную на flang, из ядра ОС, загрузчика или прошивки —
оттуда, где нет libc? Ключ `--freestanding` у `flang emit --target c` генерирует
C, которому нужен только компилятор C.

Обычный сгенерированный C для этого не годится. Он приносит свою библиотеку
времени выполнения, а она вызывает `malloc`, потоки и сигналы.

## Пример: заголовок пакета из одного слова

Первое слово заголовка IPv4 хранит версию, длину заголовка и полную длину
пакета. Сохраните в `header.flang`:

```flang
модуль «Заголовок пакета»

объект «Заголовок»
  «версия»: u32
  «длина заголовка»: u32
  «полная длина»: u32

тотальная функция «Версия»
  принимает слово: u32
  возвращает u32
  пример «четвёртая версия»
    дано слово равно u32 1157627924
    ожидается u32 4
  слово сдвиг вправо на 28

тотальная функция «Длина заголовка»
  принимает слово: u32
  возвращает u32
  пример «пять слов»
    дано слово равно u32 1157627924
    ожидается u32 5
  (слово сдвиг вправо на 24) побитовое и 15

тотальная функция «Полная длина»
  принимает слово: u32
  возвращает u32
  пример «двадцать»
    дано слово равно u32 1157627924
    ожидается u32 20
  слово побитовое и 65535

тотальная функция «Разобрать»
  принимает слово: u32
  возвращает «Заголовок»
  пусть «в» равно («Версия» от слово)
  пусть «д» равно («Длина заголовка» от слово)
  пусть «п» равно («Полная длина» от слово)
  запись «Заголовок» с «версия» равным «в» и «длина заголовка» равным «д» и «полная длина» равным «п»
```

`u32` — машинное слово в 32 бита, как `uint32_t` в C. `объект` — запись
(`struct`). Сгенерируйте C:

```bash
flang emit header.flang --target c --freestanding --out kernel
ls kernel
```

```
flang_freestanding.h  zagolovok_paketa.c  zagolovok_paketa.h
```

Файлов три. `zagolovok_paketa.h` — прототипы для вашего кода,
`zagolovok_paketa.c` — сами функции, `flang_freestanding.h` — общие определения.
Имена в C — это имя модуля и имя функции латиницей.

В заголовке:

```c
typedef struct {
  uint32_t versiya;
  uint32_t dlina_zagolovka;
  uint32_t polnaya_dlina;
} zagolovok_paketa_zagolovok_t;

uint32_t zagolovok_paketa_versiya(uint32_t p0_slovo);
uint32_t zagolovok_paketa_dlina_zagolovka(uint32_t p0_slovo);
uint32_t zagolovok_paketa_polnaya_dlina(uint32_t p0_slovo);
zagolovok_paketa_zagolovok_t zagolovok_paketa_razobrat(uint32_t p0_slovo);
```

Слово стало `uint32_t`, запись — структурой, которая передаётся по значению.

## Собрать без libc и проверить

```bash
gcc -std=c99 -Wall -Wextra -Werror -ffreestanding -nostdlib -c kernel/zagolovok_paketa.c -o header.o
nm -u header.o
```

Обе команды ничего не выводят. Пустой вывод `nm -u` значит, что объектному
файлу не нужен ни один внешний символ. Так же код собирается для другой
архитектуры, например `riscv64-linux-gnu-gcc` с теми же ключами.

## Вызвать из своего кода

```c
#include "zagolovok_paketa.h"

int is_ipv4(uint32_t first_word) {
  return zagolovok_paketa_versiya(first_word) == 4;
}
```

Добавьте `kernel` в пути заголовков (`-Ikernel`) и слинкуйте `header.o` со
своей программой.

## Что во что превращается

| flang | C |
| --- | --- |
| `u8`, `u16`, `u32`, `u64` | `uint8_t`, `uint16_t`, `uint32_t`, `uint64_t` |
| `признак` | `bool` |
| `число`, `целое`, `неотрицательное` | `int64_t`; только целые значения до 2⁵³ по модулю |
| `объект` | `struct`, передаётся по значению |
| `тип` с вариантами | `struct` с полем `tag` и `union` полей вариантов |
| `пусть`, `если`, `разбор`, вызов функции | обычные операторы C |

Действия над словами считаются так же, как в обычном flang. `плюс`, `минус` и
`умножить на` при переполнении дают ошибку. `плюс … с переполнением` считает по
модулю 2ʷ. Сдвиг на величину не меньше ширины слова — ошибка.

## Функция, в которой возможна ошибка

Сохраните в `wrap.flang`:

```flang
модуль «Заворот»

тотальная функция «Сумма с заворотом»
  принимает а: u64, б: u64
  возвращает u64
  а плюс б с переполнением

тотальная функция «Сумма с отказом»
  принимает а: u8, б: u8
  возвращает u8
  а плюс б
```

```bash
flang emit wrap.flang --target c --freestanding --out kernel
```

В `kernel/zavorot.h`:

```c
uint64_t zavorot_summa_s_zavorotom(uint64_t p0_a, uint64_t p1_b);
fl_fs_status zavorot_summa_s_otkazom(uint8_t p0_a, uint8_t p1_b, uint8_t *out);
```

Первая функция ошибиться не может и возвращает ответ напрямую. Вторая возвращает
код, а ответ записывает в последний аргумент `out`:

```c
uint8_t sum;
if (zavorot_summa_s_otkazom(200, 100, &sum) != FL_FS_OK) {
  /* 200 + 100 не помещается в u8 */
}
```

| Код | Когда |
| --- | --- |
| `FL_FS_OK` | ответ лежит в `out` |
| `FL_FS_OVERFLOW` | результат не поместился в слово |
| `FL_FS_DIVIDE_BY_ZERO` | деление или остаток от нуля |
| `FL_FS_SHIFT` | сдвиг на величину не меньше ширины слова |
| `FL_FS_PRECONDITION` | аргументы нарушают предусловие (`требует`) |
| `FL_FS_POSTCONDITION` | нарушено постусловие, которое ядро доказательств не доказало |
| `FL_FS_RANGE` | `число` вышло за 2⁵³, или `неотрицательное` получило отрицательное значение |
| `FL_FS_BAD_TAG` | в аргументе вариант с неизвестной меткой `tag` |
| `FL_FS_NO_CASE` | `разбор` не нашёл подходящего случая |

Доказанное постусловие в коде не проверяется. Предусловие проверяется всегда:
аргументы приходят из чужого кода.

## Что не поддержано

Генерация останавливается на первой функции, которую нельзя перевести, и
называет её. Сохраните в `list.flang`:

```flang
модуль «Список в ядре»

тотальная функция «Сумма списка»
  принимает «числа»: список числа
  возвращает число
  свёртка «числа» начиная с 0 как «сумма» и «х» → «сумма» плюс «х»
```

```bash
flang emit list.flang --target c --freestanding --out kernel
```

```
… FLANG_FREESTANDING_UNSUPPORTED: функция «Сумма списка», параметр «числа» типа «список»: поддержаны
признак, слова u8, u16, u32 и u64, число (только целое), неотрицательное, целое, записи и суммы типов из
них; …
```

Не поддержаны:

- строки и списки — им нужна динамическая память;
- дробные числа и деление над `число` — им нужен `double`; слова `u8`…`u64` делить можно;
- рекурсивные функции — глубина стека должна быть известна заранее;
- знаковые слова `i8`…`i64` и `точное целое`;
- функции без пометки `тотальная`, `план` и `процесс`.

Большую запись компилятор C может копировать вызовом `memcpy`. Если `nm -u`
показал `memcpy` или `memset`, дайте их в своём ядре.
