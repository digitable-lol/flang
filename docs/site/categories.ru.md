# Категории и функторы

Сверх функций и типов в flang есть объявления структур: `моноид`, `монада`, `морфизм`,
`категория`, `функтор`, `преобразование`, `изоморфизм`. Объявление говорит, какие законы
обязаны выполняться, а компилятор отвечает, что с каждым законом сделано: доказан ядром обо
всех значениях или посчитан на конечной сетке значений из примеров.

## Монада: три закона доказывает ядро

Монада объявляется типом и двумя функциями — `возврат` и `соединение`:

```flang
модуль «Maybe»

тип «Возможно» от «А»
  вариант «Ничего»
  вариант «Нечто» содержит значение: «А»

тотальная функция «Обернуть» от «А»
  принимает значение: «А»
  возвращает «Возможно» от «А»
  пример «число в обёртке»
    дано значение равно 5
    ожидается вариант «Нечто» с значение равным 5
  вариант «Нечто» с значение равным значение

тотальная функция «Сплющить» от «А»
  принимает вложенное: «Возможно» от («Возможно» от «А»)
  возвращает «Возможно» от «А»
  пример «две обёртки становятся одной»
    дано вложенное равно вариант «Нечто» с значение равным (вариант «Нечто» с значение равным 5)
    ожидается вариант «Нечто» с значение равным 5
  пример «пустое остаётся пустым»
    дано вложенное равно вариант «Ничего»
    ожидается вариант «Ничего»
  разбор вложенное
    случай вариант «Ничего»
      то вариант «Ничего»
    случай вариант «Нечто» с значение как внутри
      то внутри

монада «Возможно» от «А»
  возврат «Обернуть»
  соединение «Сплющить»
```

```
$ flang check --proof maybe.flang
…
законы как утверждения (ядро судит о ВСЕХ значениях носителя, а не о написанных):
  закон «Возможно — левая единица» — доказано сведением цели с телом функции: …
  закон «Возможно — правая единица» — доказано индукцией по «Возможно»: …
  закон «Возможно — ассоциативность связывания» — доказано индукцией по «Возможно»: …
  законов утверждениями 3: доказано ядром 3, не доказано 0
…
$ echo $?
0
```

Доказаны все три закона, включая ассоциативность. Сетка при этом тоже считается, но только
ищет контрпример. Примеры у `возврат` или `соединение` обязательны: без них сетку строить не из
чего, и компилятор отказывает кодом `FLANG_MONAD`.

`flang check` без ключа печатает об этой монаде только сетку — «ПОСЧИТАНО НА СЕТКЕ, не
доказано». Что доказало ядро, показывает `check --proof`.

## Функтор списка: два закона доказаны

Законы `отобразить` — тождество и слияние двух отображений в одно — записываются
утверждениями, и ядро их доказывает:

```flang
модуль «List functor»

утверждение «отображение тождеством не меняет список»
  для всех а: список числа
  утверждаем (отобразить а как э → э) равен а

утверждение «два отображения есть одно»
  для всех а: список числа
  утверждаем ((отобразить (отобразить а как э → э плюс 1) как э → э умножить на 2)
    равен (отобразить а как э → (э плюс 1) умножить на 2))
```

```
$ flang check --proof listmap.flang
…
  утверждений 2: доказано 2 (из них без теоремы 2), сетка 0, объявлено, не доказано 0
$ echo $?
0
```

## Моноид: законы считаются на сетке

```flang
модуль «Monoids»

тотальная функция «Сложить»
  принимает первое: число, второе: число
  возвращает число
  пример «два числа»
    дано первое равно 2
    дано второе равно 3
    ожидается 5
  первое плюс второе

тотальная функция «Обратить»
  принимает значение: число
  возвращает число
  пример «положительное»
    дано значение равно 3
    ожидается -3
  0 минус значение

моноид «Сумма»
  носитель число
  операция «Сложить»
  единица 0
  обратный элемент «Обратить»

тотальная функция «Склеить»
  принимает первая: строка, вторая: строка
  возвращает строка
  пример «две части»
    дано первая равно "аб"
    дано вторая равно "вг"
    ожидается "абвг"
  соединить первая с вторая

моноид «Склейка»
  носитель строка
  операция «Склеить»
  единица ""
```

`обратный элемент` превращает моноид в группу; отдельного слова «группа» в языке нет.

```
$ flang check monoid.flang
моноид «Сумма»: сетка 5 значений, троек 125, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ, не доказано
моноид «Склейка»: сетка 4 значений, троек 64, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ, не доказано
…
```

Здесь ядро законов не доказывает, и `check --proof` говорит почему: «законов утверждениями 8:
доказано ядром 0, не доказано 8», код 3. У «Суммы» причина в носителе: `число` двоичное,
сложение округляет, и сумма не сочетательна выше 2⁵³; отчёт советует носитель `точное целое`.
«Посчитано на сетке» — не «доказано»: пять значений это пять значений, шестое может закон
нарушить.

## Категория: объекты, стрелки и своё равенство

Категория — набор объектов, стрелок между ними и правило, по которому два значения объекта
считаются равными. Кусок из `flang/ct/order-shipment.flang` — заказ, отгрузка, накладная:

```
морфизм «отгрузить» из «Заказ» в «Отгрузка»
  даёт «Отгрузить заказ»
  закон «номер отгрузки берётся из суммы заказа»
    пример «обычный заказ»
      дано заказ равно запись «Заказ» с сумма равным 500
      ожидается запись «Отгрузка» с номер равным 500

морфизм «выписать» из «Отгрузка» в «Накладная»
  даёт «Выписать накладную»

морфизм «оформить» это «выписать» после «отгрузить»

единица «Заказ»
единица «Отгрузка»
единица «Накладная»

категория «Отгрузки»
  морфизм «отгрузить»
  морфизм «выписать»
  морфизм «оформить»
  объект «Заказ» даёт «Заказы равны»
  объект «Отгрузка» даёт «Отгрузки равны»
  объект «Накладная» даёт «Накладные равны»
```

`даёт` у морфизма называет функцию, которая его считает. `даёт` у объекта называет функцию
равенства значений этого объекта; из неё выводится равенство стрелок.

Считаются три вещи: объявленное равенство есть эквивалентность (рефлексивно, симметрично,
транзитивно), композиция его уважает, композиция ассоциативна. У преобразования считается
коммутативность квадрата, у изоморфизма — обратимость. Значения берутся из примеров при
стрелках, и отчёт называет размер сетки:

```
$ flang check flang/ct/order-shipment.flang
категория «Отгрузки»: сетка 5 значений на 3 объектах, троек стрелок 7, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ, не доказано
изоморфизм «Отгрузка и накладная»: сетка 2 значений, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ, не доказано
модуль «Order shipment»: функций 6, из них с доказанным завершением 6; типов 3
flang/ct/order-shipment.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
```

## Нарушение — отказ, и печать отменяется

Равенство, которое равенством не является, компилятор отвергает и показывает пару значений:

```
$ flang check flang/test/fixtures/binary-rules/equality-not-symmetric.flang
категория «Отгрузки»: сетка 4 значений на 2 объектах, троек стрелок 0, нарушений 1 — ПОСЧИТАНО НА СЕТКЕ, не доказано;
оборвано: объявленное равенство не эквивалентность: …
FLANG_EQUALITY_NOT_SYMMETRIC в файле …/equality-not-symmetric.flang, строка 37, столбец 1: категория «Отгрузки»:
равенство на «Заказ» не симметрично: {"сумма":500} и {"сумма":0} — нет, а {"сумма":0} и {"сумма":500} — да
$ echo $?
1
```

`flang emit` на таком файле отвечает «печать отменена — программа не проходит проверку» и не
пишет ни одного файла.

Устройство объявлений тоже сверяется. Незамкнутая категория, квадрат преобразования, который
не коммутирует, — отказы с кодом 1:

| беда | код диагностики |
|---|---|
| равенство не симметрично | `FLANG_EQUALITY_NOT_SYMMETRIC` |
| композиция собрана из стрелки, которой нет в категории | `FLANG_CATEGORY_NOT_CLOSED` |
| квадрат преобразования не коммутирует | `FLANG_TRANSFORM_NOT_NATURAL` |
| у монады нет ни одного примера | `FLANG_MONAD` |

Категория без объявленного равенства не считается вовсе, и компилятор говорит это словами:
«НЕ СЧИТАЛАСЬ — своего равенства не объявлено».

## Что с чем делается

| объявление | что делает компилятор |
|---|---|
| `монада` | три закона доказывает ядро обо всех значениях; сетка ищет контрпример |
| утверждения о `отобразить` по списку | тождество и слияние доказывает ядро |
| `функтор`, `преобразование` | законы выписываются утверждениями ядру; недоказанные названы поимённо |
| `моноид` | законы выписываются утверждениями; на `число` и `строка` не доказаны, считаются на сетке |
| `категория` с равенством, `изоморфизм` | законы считаются на сетке, размер сетки назван |
| `категория` без равенства | не считается, сказано словами |
| закон при стрелке | прогоняется как пример командой `flang test` |

У функтора и преобразования доля доказанного видна в том же разделе `check --proof`: на
`flang/ct/yoneda-preorder.flang` это «законов утверждениями 9: доказано ядром 9, не доказано 0».

Полная форма каждого объявления и коды диагностик — `docs/ct/spec.md` в репозитории; примеры —
каталог `flang/ct/`.
