# Служба flang для ИИ-помощника

Двоичный `flang` умеет говорить с помощником по протоколу MCP: JSON-RPC по
стандартным потокам, по сообщению на строку. Службу запускает помощник, а не
человек: запущенная руками, она молча ждёт сообщений — это не зависание.

## Как подключить

Впишите в файл настройки помощника:

```json
{"mcpServers": {"flang": {"command": "flang", "args": ["--mcp-mode"], "env": {}}}}
```

Проверьте, что двоичный отвечает:

```bash
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}' | flang --mcp-mode
```

```json
{"jsonrpc":"2.0","id":1,"result":{"protocolVersion":"2025-06-18","capabilities":{"tools":{}},"serverInfo":{"name":"flang","version":"0.6.0"}}}
```

## Какие средства доступны

Их два, и `tools/list` называет ровно их.

| Средство | Принимает | Что отвечает |
|---|---|---|
| `flang_check` | `source` — текст программы целиком | разбор, типы, доказанное завершение и отчёт о доказательствах — весь, без сокращения |
| `flang_prove` | `source` и `claim` — имя обещания из `обеспечивает «имя» …` | чем это обещание доказано — или та же причина отказа, какую видит человек |

## Что приезжает в ответе

Поля «ок» в ответе нет. Вердиктов пять, и они не сводятся друг к другу:

| Слово в ответе | Что значит |
|---|---|
| `доказано` | утверждение обо всех входах |
| `доказано индукцией по «Т»` | то же обо всех значениях типа «Т» |
| `сетка N` | посчитано на N значениях автора. Это не доказательство |
| `объявлено, не доказано` | утверждение высказано, доказательства при нём нет |
| `НАРУШЕНО` | ложь, уже найденная примером автора |

Словарь этих слов служба присылает в каждом ответе — помощнику не надо помнить
его между вызовами.

## Пример обмена

Запрос — `tools/call` со средством `flang_prove`, программой и именем обещания:

```json
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"flang_prove",
 "arguments":{"source":"…","claim":"скидка не больше 30"}}}
```

Программа в `source`:

```flang
модуль «Скидка»

тотальная функция «Скидка»
  принимает разряд: строка
  возвращает число
  обеспечивает «скидка не больше 30» результат не больше 30
  пример «постоянный покупатель»
    дано разряд равно "постоянный"
    ожидается 30
  если разряд равен "постоянный"
    то 30
    иначе 0
```

Ответ (текст поля `content`, хвост после словаря вердиктов):

```
постусловие «скидка не больше 30» функции «Скидка» — доказано сведением цели с
телом функции: правило «ограниченность точным потолком по построению»,
объявленные типы аргументов не понадобились — утверждение обо ВСЕХ входах, а не
о написанных; теоремы при нём нет и не нужно
```

## Когда программа не разобралась

Отчёта о доказательствах не будет, и служба говорит почему — «не разобрано» это
не «не доказано»:

```
Программа НЕ ПРОШЛА проверку языка, и ведомость доказательства поэтому не
печатается. Это не «не доказано» — это «не разобрано или не сошлось по типам».

FLANG_PARSE, строка 7, столбец 3: пример «два» требует строку 'ожидается'
```

## Когда средство названо неверно

Служба не молчит и не делает вид, что поняла:

```json
{"jsonrpc":"2.0","id":3,"error":{"code":-32602,"message":"служба flang не знает средства «flang_nonexistent». Их два: flang_check и flang_prove"}}
```

## Чего служба не делает

Она не мешает помощнику написать неверное. Она отнимает у него возможность
назвать неверное правильным: «эта функция корректна» — предложение, а `доказано`
в ответе — результат прогона.

Двух вопросов служба не умеет: «что сломается, если это поменять» и «согласуются
ли требования между собой». Оба требуют запуска процесса из цикла службы, а
цикл сегодня несёт один эффект.
