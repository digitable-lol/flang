# flang для тех, кто знает Rust или TypeScript

Чем flang похож на знакомые языки, чего в нём нет и что есть сверх них? Ниже
таблица соответствий, один пример на трёх языках и два списка отличий. Подробно
каждая конструкция разобрана в [туре по языку](tour-functions.html).

## Таблица соответствий

| Что нужно | Rust | TypeScript | flang |
| --- | --- | --- | --- |
| функция | `fn f(x: f64) -> f64` | `function f(x: number): number` | `функция «Ф»`, строки `принимает х: число` и `возвращает число` |
| неизменяемое имя | `let x = 1;` | `const x = 1;` | `пусть х равно 1` |
| структура | `struct` | `interface`, `type` | `объект` |
| тип-сумма | `enum` с данными | объединение с полем-меткой | `тип` со строками `вариант` |
| сопоставление с образцом | `match` | `switch` по метке | `разбор` и строки `случай` |
| «может не быть» | `Option<T>` | `T \| undefined` | свой тип с двумя вариантами |
| ошибка как значение | `Result<T, E>` | объединение или `throw` | свой тип: вариант с результатом и вариант с причиной |
| обобщённый тип | `enum Maybe<T>` | `type Maybe<T>` | `тип «Возможно» от «А»` |
| трейт, интерфейс | `trait` и `impl` | `interface` и `class` | `интерфейс` и `класс … есть «…»` |
| `map`, `filter`, `fold` | методы итератора | методы массива | `отобразить`, `отфильтровать`, `свёртка` |
| тест | `#[test]` в модуле `tests` | Jest, Vitest | `пример` внутри функции |
| запуск тестов | `cargo test` | `npm test` | `flang test файл.flang` |
| проверка без запуска | `cargo check` | `tsc --noEmit` | `flang check файл.flang` |
| импорт | `use` | `import` | `использует «Модуль»` |
| пакет | крейт, `Cargo.toml` | пакет npm | один файл `.flang-package`, команда `flang package` |
| новый проект | `cargo new` | `npm init` | `flang new имя` |
| комментарий | `//` | `//` | `//` |
| код ошибки компилятора | `E0308` | `TS2322` | `FLANG_TYPE` и другие с приставкой `FLANG_` |

Ошибка компилятора состоит из кода, файла, строки, столбца и текста на русском.
Каждый код описан в [справочнике кодов](diagnostics.html).

## Один пример на трёх языках

Стоимость доставки: самовывоз бесплатный, курьер стоит 200 и ещё 20 за
километр. Файл `delivery-cost.flang`:

```flang insert docs/examples/tour/compare/delivery-cost.flang
модуль «Comparison»

тип «Способ»
  вариант «Самовывоз»
  вариант «Курьером» содержит километров: неотрицательное

тотальная функция «Стоимость доставки»
  принимает способ: «Способ»
  возвращает число
  обеспечивает «стоимость не отрицательна» результат не меньше 0
  пример «курьером за пять километров»
    дано способ равно вариант «Курьером» с километров равным 5
    ожидается 300
  разбор способ
    случай вариант «Самовывоз»
      то 0
    случай вариант «Курьером» с километров как километров
      то 200 плюс километров умножить на 20
```

```text insert output: check docs/examples/tour/compare/delivery-cost.flang
$ flang check docs/examples/tour/compare/delivery-cost.flang
модуль «Comparison»: функций 1, из них с доказанным завершением 1; типов 1
docs/examples/tour/compare/delivery-cost.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
```

То же на Rust:

```rust
enum Method {
    Pickup,
    Courier { km: u32 },
}

fn delivery_cost(method: &Method) -> u32 {
    match method {
        Method::Pickup => 0,
        Method::Courier { km } => 200 + km * 20,
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn courier_five_km() {
        assert_eq!(delivery_cost(&Method::Courier { km: 5 }), 300);
    }
}
```

И на TypeScript:

```typescript
type Method =
  | { kind: "pickup" }
  | { kind: "courier"; km: number };

function deliveryCost(method: Method): number {
  switch (method.kind) {
    case "pickup":
      return 0;
    case "courier":
      return 200 + method.km * 20;
  }
}

console.assert(deliveryCost({ kind: "courier", km: 5 }) === 300);
```

Три отличия видны сразу:

- тест в flang записан внутри функции и запускается при каждой проверке;
- строки `обеспечивает` в Rust и TypeScript нет. Это постусловие: результат не
  меньше нуля при любых аргументах;
- слово `тотальная` требует от компилятора доказать, что функция завершается.

Постусловие компилятор доказал сам:

```text insert output: check docs/examples/tour/compare/delivery-cost.flang --proof 2>&1 | grep "постусловие"
$ flang check docs/examples/tour/compare/delivery-cost.flang --proof 2>&1 | grep "постусловие"
  постусловие «стоимость не отрицательна» функции «Стоимость доставки» — доказано индукцией по «Способ»: база 2 случая, шаг при допущении на частях (0 случаев), правила сведения: неотрицательность по построению — утверждение обо ВСЕХ входах типа «Способ», а не о написанных
```

«Доказано индукцией по „Способ“» значит: разобраны оба варианта типа, и в
каждом результат не отрицателен. Утверждение относится ко всем значениям, а
тест с пятью километрами — один частный случай.

## Чего в flang нет

Каждая строка проверена запуском компилятора.

| Привычное | Что отвечает компилятор | Что писать |
| --- | --- | --- |
| изменяемая переменная, `let mut`, `x = x + 1` | `FLANG_PARSE` | `пусть` с новым именем, `свёртка` или `цикл` со строкой `храним` |
| исключения, `throw`, `panic!` | слова для этого нет | тип с вариантом для ошибки и `разбор` у вызывающего |
| `null`, `undefined` | `FLANG_TYPE`, если тип результата другой | тип с вариантами «есть» и «нет» |
| лямбда как значение: `let f = \|x\| x * 2` | `FLANG_UNKNOWN_NAME` | объявленная функция, переданная как `функция «Имя»` |
| наследование классов | `FLANG_PARSE` | `интерфейс` и несколько классов |
| знаки `+`, `*`, `==` | `FLANG_PARSE` | слова `плюс`, `умножить на`, `равен` |
| подстановка в строку: `` `Привет, ${имя}` `` | строка остаётся как написана | `соединить ["Привет, ", имя] по ""` |
| цикл без границы: `while (true)` | `FLANG_SUGAR_LOOP` | `пока` со строкой `шагов не больше` или `убывает` |

Тело после стрелки в `отобразить`, `отфильтровать` и `свёртка` писать можно:
`отобразить цены как цена → цена умножить на 2`. Сохранить такое тело в
переменную или передать в свою функцию нельзя.

Файлы, сеть и время функция не трогает сама. Она возвращает описание действия,
а выполняет его команда `flang io`. Подробности —
[Граница между flang и хостом](host-boundary.html).

## Что есть сверх

| Возможность | Что даёт | Где читать |
| --- | --- | --- |
| `тотальная` | компилятор доказывает, что функция завершится на любых аргументах | [Всегда завершающиеся функции](tour-termination.html) |
| `требует` и `обеспечивает` | предусловие и постусловие; компилятор ищет контрпример и пробует доказать | [Первое доказательство](first-proof.html) |
| `теорема` | доказательство по шагам, когда компилятор не справился сам | [Первое доказательство](first-proof.html) |
| типы `неотрицательное`, `целое`, `сотых` | значение вне типа отвергается при вызове | [Свои типы](tour-types.html) |
| `flang emit` | из одной программы получается код на C, JavaScript и других языках | [Генерация кода](emit-walkthrough.html) |

## Что удивляет в первый день

- Ключевые слова русские, имена пишутся в ёлочках: `«Стоимость доставки»`.
  Есть и английское написание ключевых слов, оно описано в
  [справочнике](language.html).
- Номера элементов списка и символов строки начинаются с единицы.
- Аргументы вызова разделяет слово `и`: `«Ф» от а и б`. Логическое «и»
  пишется `и притом`.
- Тип `число` — `f64`. Деление на ноль не останавливает программу: результат
  равен `Infinity`.
