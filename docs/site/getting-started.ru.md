# Первая программа

Как написать функцию на flang, проверить её и запустить? Четыре шага: файл,
проверка, тесты, запуск. Нужен установленный `flang` —
[как его поставить](install.html).

## Написать

Файл `hello.flang`:

```flang
модуль «Привет»

тотальная функция «Удвоить»
  принимает н: неотрицательное
  возвращает число
  обеспечивает «удвоенное не меньше исходного» результат не меньше н
  пример «дважды два»
    дано н равно 2
    ожидается 4
  н плюс н
```

Что делает каждая часть:

| Часть | Привычное название | Что с ней делает компилятор |
| --- | --- | --- |
| `тотальная` | функция, которая всегда завершается | доказывает завершение; не смог — файл не проходит проверку |
| `принимает` / `возвращает` | типы параметров и результата | проверяет до запуска |
| `обеспечивает` | постусловие (`ensures`) | пробует доказать его для всех входов; имя в `«…»` обязательно, по нему постусловие называется в сообщениях |
| `пример` | unit-тест внутри функции | выполняет при каждой проверке |
| последняя строка | тело функции | — |

Имена модулей, функций и тестов пишутся в кавычках-ёлочках `«…»`. Кавычки `"`
и `'` для имён не подходят: по ёлочкам компилятор отличает ваше имя от
ключевого слова.

## Проверить

```bash
flang check hello.flang
```

```text
модуль «Привет»: функций 1, из них с доказанным завершением 1; типов 0
hello.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
```

Код возврата 0. Вторая строка перечисляет пять проверок: синтаксис («разбор»),
типы, завершение функций, доказательства («ядро») и тесты («примеры»).
«Замечаний нет» читается как «ошибок нет».

Компилятор отвечает по-русски при любом написании ключевых слов. Слова из
вашего кода он цитирует как есть.

### Зачем параметру тип `неотрицательное`

Замените в `hello.flang` тип параметра на `число` и повторите проверку:

```bash
flang check hello.flang
```

Ответ компилятора:

```text
модуль «Привет»: функций 1, из них с доказанным завершением 1; типов 0
FLANG_BOUND_ON_NAN в файле hello.flang, строка 6, столбец 3: постусловие
«удвоенное не меньше исходного» функции «Удвоить» ЛОЖНО, и контрпример назван:
«н» объявлен типом «число», а «не число» живёт в этом типе и стоит ВНЕ ПОРЯДКА
…
hello.flang: не проверено — замечаний 1
```

Код возврата 1. Тип `число` — число с плавающей точкой, в него входит NaN
(«не число» в сообщении). NaN не больше и не меньше любого числа, поэтому
постусловие для него ложно. Тип `неотрицательное` — целое от 0 до 2⁵³−1, NaN
в нём нет. Верните `неотрицательное`.

## Запустить тесты

```bash
flang test hello.flang
```

```text
hello.flang: примеров 1, прошло 1, не прошло 0
```

Код возврата 0. В файле один тест («пример»), он прошёл.

## Запустить функцию

```bash
flang run hello.flang --function Удвоить --args '{"н": 21}'
```

```text
доказано: утверждений 1
42
```

Код возврата 0. Первая строка: единственное постусловие файла доказано. Вторая —
результат. Если в файле есть постусловие без доказательства, `run` ничего не
вычисляет.

В командной строке имя функции пишется без ёлочек. Ключ `--args` принимает
объект JSON, его ключи — имена параметров из строки `принимает`. Значение
каждого аргумента проверяется по объявленному типу до вычисления:

```bash
flang run hello.flang --function Удвоить --args '{"н": -3}'
```

```text
доказано: утверждений 1
FLANG_TYPE: вызов функции «Удвоить»: аргумент «н»: -3 вне неотрицательное
```

Код возврата 1. Число −3 не входит в тип `неотрицательное`, функция не
вычислялась.

## Посмотреть, что доказано

Ключ `--proof` добавляет к проверке отчёт о доказательствах:

```bash
flang check hello.flang --proof
```

Отчёт длинный. Про эту программу в нём две главные записи:

```text
…
чем несётся обещание «тотальная»:
  «Удвоить»  доказано композицией: рекурсии нет, …
…
  постусловие «удвоенное не меньше исходного» функции «Удвоить» — доказано по объявленным
типам аргументов: … — утверждение обо ВСЕХ входах, а не о написанных; теоремы при
нём нет и не нужно
…
```

Код возврата 0. Первая запись («обещание „тотальная“») относится к завершению:
рекурсии в функции нет, поэтому она завершается. Вторая относится к
постусловию: оно доказано из типа параметра для всех входов, тест с двойкой —
частный случай. «Теорема» — доказательство, написанное руками; здесь оно не
понадобилось.

Что делать, когда компилятор не доказал постусловие сам, показывает
[Первое доказательство](first-proof.html).

## Код на другом языке

Команда `flang emit hello.flang --target c --out ./out` генерирует из программы
проект на C; он собирается командой `make -C ./out`. Целевых языков
{{цели.словом}}: {{цели.список}}. По шагам —
[Генерация кода на C и JavaScript](emit-walkthrough.html).
