# Как читать отчёт о доказательствах

Страница отвечает на вопрос: что значит каждая часть вывода
`flang check <файл> --proof`. Вывод ниже получен от `flang {{выпуск.версия}}`,
длинные строки перенесены, `…` отмечает пропуск.

## Из чего состоит отчёт

Файл `docs/examples/proofs/three-answers.flang`:

```flang insert docs/examples/proofs/three-answers.flang
модуль «Три ответа»

тотальная функция «Сдача»
  принимает внесено: неотрицательное, цена: неотрицательное
  требует «денег хватает» цена не больше внесено
  возвращает число
  обеспечивает «сдача не отрицательна» результат не меньше 0
  пример «сто за девяносто»
    дано внесено равно 100
    дано цена равно 90
    ожидается 10
  внесено минус цена

тотальная функция «Удвоить»
  принимает х: целое
  возвращает число
  обеспечивает «результат чётный» (результат остаток от 2) равно 0
  пример «единица»
    дано х равно 1
    ожидается 2
  х умножить на 2

тотальная функция «Утроить»
  принимает х: целое
  возвращает число
  обеспечивает «результат кратен трём» (результат остаток от 3) равно 0
  х умножить на 3
```

```bash
flang check three-answers.flang --proof; echo "код $?"
```

```
── ведомость доказательства модуля «Три ответа» ──
слова ведомости, и они не взаимозаменяемы:
…
чем несётся обещание «тотальная»:
…
что высказано и чем это несётся:
…
итог:
…
чем получен каждый шаг (правило и основания — строками записи доказательства):
…
three-answers.flang: независимо, сверщиком, проиграно 1 из 1 доказанных; на слове ядра 0 …
three-answers.flang: НЕ ПРОВЕРЕНО — утверждений 3: доказано 1, … — код возврата 3
код 3
```

Заголовки написаны внутренними словами компилятора. Перевод:

| Заголовок в выводе | Что под ним |
| --- | --- |
| `ведомость доказательства` | отчёт о доказательствах, название всего вывода |
| `слова ведомости` | словарь ответов, одинаковый для всех файлов |
| `чем несётся обещание «тотальная»` | чем доказано завершение каждой функции |
| `законы` | законы объявленных структур: `моноид`, `монада` |
| `что высказано и чем это несётся` | ответ на каждое постусловие |
| `принято на веру` | что принято без доказательства |
| `итог` | счётчики по файлу |
| `чем получен каждый шаг` | шаги каждого доказательства |

Две последние строки — итог независимой проверки и общий ответ с кодом
возврата. Дальше разделы разобраны по порядку.

## Завершение функций

Слово `тотальная` перед функцией требует доказать, что она завершается на
любом входе. В файле `docs/examples/proofs/termination.flang` пять функций, по
одной на каждый способ доказательства:

```flang insert docs/examples/proofs/termination.flang
модуль «Завершение»

тотальная функция «Вдвое»
  принимает х: число
  возвращает число
  х умножить на 2

тотальная функция «Сумма списка»
  принимает ряд: список числа
  возвращает число
  разбор ряд
    случай пусто
      то 0
    случай голова первый и хвост остальные
      первый плюс («Сумма списка» от остальные)

тотальная функция «Отсчёт»
  принимает н: неотрицательное
  возвращает число
  если н не больше 0
    то 0
    иначе 1 плюс («Отсчёт» от (н минус 1))

тотальная функция «Отсчёт дробного»
  принимает н: число
  возвращает число
  если н не больше 0
    то 0
    иначе 1 плюс («Отсчёт дробного» от (н минус 1))

тотальная функция «Шагов до края»
  принимает место: число, край: число
  возвращает число
  убывает край минус место
  если место не меньше край
    то 0
    иначе 1 плюс («Шагов до края» от (место плюс 1) и край)
```

```bash
flang check termination.flang --proof
```

```
чем несётся обещание «тотальная»:
  «Вдвое»            доказано композицией: рекурсии нет …
  «Сумма списка»     доказано структурой: аргумент 1 («ряд») на каждом витке
                     становится частью себя … сторожа нет
  «Отсчёт»           доказано точным шагом: аргумент 1 («н») объявлен натуральным
                     и убывает на 1 … сторожа нет
  «Отсчёт дробного»  доказано постоянным шагом: … на IEEE-754 шаг не всегда меняет
                     число, поэтому сторож, 1 место
  «Шагов до края»    доказано объявленной мерой: убывает «край» минус «место»;
                     спуск ядром не выведен — на веру: … 1 место
```

Слово `сторож` в выводе — проверка во время выполнения, «виток» — один рекурсивный
вызов.

| В выводе | Что это значит | Проверка во время выполнения |
| --- | --- | --- |
| `композицией` | рекурсии нет | нет |
| `структурой` | рекурсивный вызов получает часть аргумента: хвост списка, поле | нет |
| `точным шагом` | аргумент типа `неотрицательное` уменьшается на 1 | нет |
| `постоянным шагом` | аргумент типа `число` уменьшается на постоянную | есть |
| `объявленной мерой` | уменьшается выражение из строки `убывает` | есть |

`число` — binary64. Выше 2⁵³ вычитание единицы его не меняет, поэтому в двух
последних случаях компилятор оставляет проверку в коде.

Слова «спуск ядром не выведен — на веру» у последней функции значат:
завершение принято без доказательства. Что из этого следует для остального
отчёта — [Чему вы доверяете](trust.html#известная-ошибка-функция-с-убывает).

Функция, завершение которой не доказано, — ошибка `FLANG_NOT_TOTAL`, отчёта при
ней нет. Если функция и правда может работать без конца, уберите слово
`тотальная`.

## `обеспечивает`: постусловие и три ответа

Раздел «что высказано и чем это несётся» отвечает на каждое постусловие. В
`three-answers.flang` есть все три ответа:

```
что высказано и чем это несётся:
  постусловие «сдача не отрицательна» функции «Сдача» — доказано по объявленным
  типам аргументов: цель сведена правилом «неотрицательность по построению» …
  постусловие «результат чётный» функции «Удвоить» — сетка 1 значение (примеры
  функции): нарушений на них нет … Это не доказательство …
  постусловие «результат кратен трём» функции «Утроить» — объявлено, не
  доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата …
```

| В выводе | Что это значит | Во время выполнения |
| --- | --- | --- |
| `доказано` | верно для всех входов объявленных типов | проверки нет, если у функции есть `пример` |
| `сетка N` | прошло на N тестах функции; о других входах ничего не известно | проверка при каждом возврате |
| `объявлено, не доказано` | нет ни доказательства, ни тестов | проверка при каждом возврате |

Словом «сетка» компилятор называет ответ «проверено только на тестах».

Два последних постусловия верны: удвоенное целое чётно, утроенное кратно трём.
Ядро их не вывело. Что с этим делать —
[Если не доказалось](proof-refused.html).

После слова «доказано» стоит способ:

| В выводе | Что это значит |
| --- | --- |
| `по объявленным типам аргументов` | хватило типов и предусловий, теорема не нужна |
| `сведением цели с телом функции` | постусловие получено из тела функции |
| `индукцией по «Т»` | индукция по значениям типа «Т» |
| `терм принят ядром, N шагов` | проверена теорема, написанная в файле |

## Счётчики

```
итог:
  функций 3: тотальных 3, обычных 0
  обещание несёт: композиция 3, структура 0, точный шаг 0, постоянный шаг 0, объявленная мера 0
  сторожей в рантайме: 0 мест
  законов на сетке: 0 (значений в сетках 0); на веру: 0
  утверждений 3: доказано 1 (из них без теоремы 1, объявленным типом 1), сетка 1,
  объявлено, не доказано 1
```

- первая строка: у всех трёх функций завершение доказано;
- вторая: каким способом, по числу функций на способ;
- третья: сколько проверок завершения осталось в коде;
- четвёртая: законы структур, в этом файле их нет;
- пятая: из трёх постусловий доказано одно, одно прошло только на тестах, у
  одного нет ничего.

## Шаги доказательства

```
чем получен каждый шаг (правило и основания — строками записи доказательства):
  утверждение «сдача не отрицательна» функции «Сдача» строка 7
    правило «неотрицательность по построению»
    вывод цель ⟨результат не меньше 0⟩
    вывод 1 Н3 ⟨цена не меньше 0⟩ строка 4
    …
    вывод 5 Разв2 ⟨результат не меньше 0⟩ из 4 строка 12
```

Каждая строка `вывод` — один шаг: номер, короткое имя правила, полученный факт
и то, из чего он получен. `строка 4` — строка исходника, `из 4` — шаг с этим
номером. Шаг 1 берёт из типа `неотрицательное`, что цена не меньше нуля.
Шаг 5 подставляет тело функции вместо слова `результат`.

Эти же шаги компилятор пишет в файл по ключу `--record`. Формат файла —
[Запись доказательства](record-format.html).

## Две последние строки

```
three-answers.flang: независимо, сверщиком, проиграно 1 из 1 доказанных; на слове ядра 0 …
three-answers.flang: НЕ ПРОВЕРЕНО — утверждений 3: доказано 1, … — код возврата 3
```

Первая — итог независимой проверки. Отдельная программа `checker` (в выводе
«сверщик») повторила одно доказательство из одного. Если первое число меньше
второго, часть доказанного держится только на ядре. Подробно —
[Чему вы доверяете](trust.html#строка-n-из-m-независимая-проверка).

Вторая — общий ответ и код возврата:

| Команда | Код 0 | Код 1 | Код 3 |
| --- | --- | --- | --- |
| `flang check файл` | ошибок нет; недоказанное постусловие допускается | ошибка | — |
| `flang check файл --proof` | всё доказано | ошибка | что-то не доказано |
| `flang check файл --proof --strict` | постусловия есть, и все доказаны | постусловие опровергнуто | что-то не доказано или постусловий нет |

В CI ставьте `flang check файл --proof --strict`.

## Отчёт для программ

`flang check файл --proof --json` выводит тот же отчёт одной строкой JSON.
Постусловия лежат в массиве `claims`, ответ — в поле `verdict`: `proved` у
доказанного. Завершение функций — в массиве `functions`, счётчики — в `totals`.
