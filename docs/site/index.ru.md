# flang — язык, в котором компилятор доказывает свойства программы

flang — чистый функциональный язык со статическими типами. Вы пишете, что
функция обещает, а компилятор доказывает это для всех входов — или прямо
говорит, что не смог.

```flang
модуль «Пример»

тотальная функция «Сумма»
  принимает числа: список неотрицательное
  возвращает число
  обеспечивает «сумма не отрицательна» результат не меньше 0
  пример «один, два, три»
    дано числа равно [1, 2, 3]
    ожидается 6
  разбор числа
    случай пусто
      то 0
    случай голова и хвост
      то голова плюс («Сумма» от хвост)
```

```bash
$ flang check sum.flang
модуль «Пример»: функций 1, из них с доказанным завершением 1; типов 0
sum.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет

$ flang run sum.flang --function Сумма --args '{"числа": [1, 2, 3]}'
доказано: утверждений 1
6
```

Что здесь произошло:

- `тотальная` — компилятор доказал, что функция завершается: рекурсия идёт по
  хвосту списка.
- `обеспечивает` — доказано индукцией по списку. Сумма неотрицательных не
  отрицательна для любого списка, а не только для `[1, 2, 3]`.
- `пример` — тест внутри функции; он прогоняется при каждой проверке.

Замените `плюс` на `минус` и уберите пример. Обещание станет ложным, доказать
его нельзя, и `run` откажется считать, код возврата 3:

```
не доказано: утверждений 1: доказано 0, сетка 0, на веру 1 — запуск только по явному согласию: --на-веру
```

## Что есть в языке

| Вы пишете | Что делает компилятор |
| --- | --- |
| `тотальная` | доказывает, что функция завершается; не смог — файл отвергнут |
| `требует` | проверяет условие в каждой точке вызова и на входе `flang run` |
| `обеспечивает` | доказывает обещание для всех входов; у каждого обещания один из трёх вердиктов: «доказано», «сетка N» (только на примерах), «объявлено, не доказано» |
| `пример` | прогоняет как тест при каждой проверке |
| `теорема` | проверяет доказательство, записанное по шагам |
| `цикл`, `класс`, `интерфейс` | разворачивает в свёртки, записи и функции и проверяет развёрнутое |

Значения неизменяемы. У функций нет побочных действий: если программе нужен
файл, сеть или экран, она возвращает поручение как данные, а выполняет его
`flang io`.

Одна программа печатается на {{цели.словом}} языков: {{цели.список}}. Доказанные
проверки в напечатанный код не попадают.

Ключевые слова — слова, а не значки, и у каждого есть русское и английское
написание. Компилятор flang написан на flang и собирает сам себя.
