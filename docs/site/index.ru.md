# flang — язык, где компилятор доказывает, что программа не зациклится

**flang — чистый функциональный язык со строгой статической типизацией, в
котором доказательство обязательно и идёт до запуска.** Значения неизменяемы;
побочных действий у программы нет — ввод-вывод возвращается данными, а исполняет
его хозяин. Слово `тотальная` перед функцией — обещание, что она завершится на
любом входе, и доказывает его **компилятор**, а не человек. Слово `обеспечивает`
— обещание о результате, и ядро закрывает его про **все входы**, а не про
написанные примеры. Аксиом в ядре ноль, и это проверяется прогоном:
`flang io flang/scripts/kernel-forgeries.flang --plan «Аксиом ноль»` отвечает
кодом 0.

Язык самоприменим: компилятор flang написан на flang, печатает сам себя и ещё в
{{цели.словом}} целевых языков. На flang же написаны стандартная библиотека,
планировщик, надзор и связь между узлами — свой слой процессов вместо OTP/BEAM.
Записывается словами, а не значками; ключевые слова есть в русской и английской
раскладках.

Положите в `privet.flang`:

```flang
модуль «Привет»

тотальная функция «Удвоить»
  принимает н: число
  возвращает число
  н плюс н
```

Проверьте и запустите — вот что печатает компилятор:

```bash
$ flang check privet.flang
модуль «Привет»: функций 1, из них с доказанным завершением 1; типов 0
privet.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет

$ flang run privet.flang --function Удвоить --args '{"н": 21}'
42
```

Код возврата 0. Если завершаемость доказать не удалось — код 1, отказ с именем,
строкой и столбцом, и файл не собран.

## Установка

```bash
brew install digitable-lol/tap/flang
flang --version
```

Вторая команда отвечает `flang {{выпуск.версия}}`. Остальные пути — asdf, из
исходников, через npm — на странице [Установка](install.html).

## Что язык умеет сегодня

| Что есть | Где граница |
| --- | --- |
| **Доказательство завершаемости**: `тотальная` перед функцией проверяется компилятором, а не человеком | циклов и изменяемых переменных в языке нет; не доказал — отказывается собирать файл |
| **Утверждения о поведении**: `обеспечивает` — обещание о результате, которое ядро доказывает про все входы, а не про примеры | ядро принимает не всякое утверждение; сколько принято — строкой ниже |
| **Печать в {{цели.словом}} целевых языков**: {{цели.список}} | сокеты, часы и таблицу процессов компилятор не печатает |
| **[Процессы и надзор](processes.html)**: процессы, надзор, обратное давление, планировщик написан на самом flang | объявления `процесс` и `надзор` двоичный компилятор не судит |
| **[PostgreSQL](database.html) и SQLite**: протокол PostgreSQL собран и разобран, файл базы SQLite читается | у PostgreSQL вход только `trust` и пароль открытым текстом; в SQLite чтение есть, записи нет |
| **HTTP**: разбор и печать запросов и ответов, заголовки, коды, адреса, процентное кодирование | сокета нет: байты приносит и уносит хозяин, язык их только считает |
| **Своя криптография**: SHA-256, HMAC, AES-128 в режимах CTR и GCM, X25519, чтение сертификата X.509 | TLS не собран: https исполняет внешний curl |

Что из этого доказано: {{корпус.тотальных}} функций из {{корпус.функций}} в
дереве языка завершаются доказанно, а из {{утверждения.высказано}} утверждений о
поведении ядро закрыло {{утверждения.доказано}} — граница проведена явно на
странице [Что доказано, а что нет](what-is-proved.html).

## Чем это отличается от Coq и Lean

**Не тем, что здесь доказывает машина, а там человек.** Писать доказательство
руками можно и здесь: слово `теорема` с шагами `дано`, `утверждаем`,
`затем … по свойству «…»`, `индукция по …` и `следовательно доказано` —
структурное доказательство в духе Isar из Isabelle, а не скрипт из тактик. Таких
теорем в дереве языка **182**, из них **55** в стандартной библиотеке
(`grep -rac '^\s*теорема ' flang --include=*.flang`, сумма по `awk`; ключ `-a`
обязателен — без него `flang/conc/link.flang` пропускается молча).

Разница в том, **что остаётся руке**. Ядро закрывает утверждение само —
двенадцатью правилами, — и написанная теорема нужна только на остаток. В
вердикте это стоит отдельным числом. Замер на `flang/stdlib/sha1.flang` с его
импортами
(`flang check --proof`): `утверждений 177: доказано 114 … из них без теоремы 54` —
почти половина доказанного закрыта без единой написанной строки. В Coq и Lean
такого числа нет: там на каждое утверждение пишут либо терм, либо тактику. Какие
обещания ядро берёт само, разобрано формой за формой:
[какие обещания ядро берёт](kak-dokazat.html).

Вторая разница настоящая и не в нашу пользу: программу из Coq и Lean чаще
*извлекают* в другой язык, чем пишут на ней службу, — зато за тридцать лет там
накоплены десятки тысяч готовых лемм, а здесь библиотека доказанного только
набирается. Ядро берёт не всякое утверждение, и чего оно не берёт — названо
поимённо: [зачем доказательства и как они устроены](proofs.html).
