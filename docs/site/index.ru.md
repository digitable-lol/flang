# flang — язык, в котором компилятор доказывает постусловия функций

flang — чистый функциональный язык со статическими типами. Рядом с функцией вы
записываете условие на её результат — постусловие. Компилятор доказывает его
для всех входов или сообщает, что доказательства нет.

Файл `sum.flang`:

```flang
модуль «Пример»

тотальная функция «Сумма»
  принимает числа: список неотрицательное
  возвращает число
  обеспечивает «сумма не отрицательна» результат не меньше 0
  пример «один, два, три»
    дано числа равно [1, 2, 3]
    ожидается 6
  разбор числа
    случай пусто
      то 0
    случай голова и хвост
      то голова плюс («Сумма» от хвост)
```

```bash
flang check sum.flang
```

```text
модуль «Пример»: функций 1, из них с доказанным завершением 1; типов 0
sum.flang: проверено — доказано 1, проверено только на тестах 0, не доказано 0 (постусловий и утверждений 1); замечаний нет
```

Код возврата 0. Вторая строка перечисляет пройденные проверки. «Ядро» в ней —
часть компилятора, которая проверяет доказательства. «Замечаний нет» читается
как «ошибок нет».

```bash
flang run sum.flang --function Сумма --args '{"числа": [1, 2, 3]}'
```

```text
доказано: утверждений 1
6
```

Первая строка: единственное постусловие файла доказано. Вторая — результат.

Что сделал компилятор:

- `тотальная` — доказал, что функция завершается: рекурсия идёт по хвосту
  списка, а он короче самого списка.
- `обеспечивает` — доказал постусловие индукцией по списку. Оно верно для
  любого списка неотрицательных чисел, `[1, 2, 3]` — частный случай.
- `пример` — выполнил тест, записанный внутри функции. Тесты выполняются при
  каждой проверке.

Замените в `sum.flang` слово `плюс` на `минус` и повторите проверку:

```bash
flang check sum.flang
```

Ответ компилятора:

```text
модуль «Пример»: функций 1, из них с доказанным завершением 1; типов 0
FLANG_EXAMPLE: пример «один, два, три» функции «Сумма»: FLANG_PROPERTY: нарушено свойство «сумма не отрицательна» функции «Сумма»
sum.flang: не проверено — замечаний 1
```

Код возврата 1. Постусловие («свойство» в сообщении) нарушилось уже на тесте:
для хвоста `[2, 3]` функция вернула −1. Такой файл `flang run` не запускает.

## Что есть в языке

| Вы пишете | Что делает компилятор |
| --- | --- |
| `тотальная` | доказывает, что функция завершается; не смог — файл не проходит проверку |
| `требует` | проверяет предусловие в каждом месте вызова и на входе `flang run` |
| `обеспечивает` | доказывает постусловие для всех входов; не смог — сообщает, что оно проверено только на тестах или не проверено вовсе |
| `пример` | выполняет как тест при каждой проверке |
| `теорема` | проверяет доказательство, записанное по шагам |
| `цикл`, `класс`, `интерфейс` | переписывает в свёртки, записи и функции и проверяет результат |

Значения неизменяемы. У функций нет побочных действий. Если программе нужен
файл, сеть или экран, функция возвращает эффект — описание действия в виде
данных. Выполняет эффекты команда `flang io`.

Из одной программы генерируется код на {{цели.словом}} языках: {{цели.список}}.
Для доказанных постусловий проверок в сгенерированном коде нет.

Ключевые слова пишутся словами, у каждого есть русское и английское написание.
Компилятор flang написан на flang и собирает сам себя.

## Для каких задач и чем отличается

flang подходит для логики, где ошибка стоит дорого: расчёты, разбор форматов,
правила доступа. Её пишут на flang, доказывают и генерируют из неё библиотеку.

| Сравнение | Отличие flang |
| --- | --- |
| Dafny | те же предусловия и постусловия, но решателя SMT нет: компилятор применяет фиксированный набор правил, остальное вы доказываете теоремой по шагам |
| Lean, Coq | проверяет программы и не рассчитан на математику; тактик и автоматического поиска доказательства нет |
| Rust | Rust проверяет типами владение памятью; flang доказывает завершение и условия на значения, изменяемого состояния в нём нет |

Доказательства перепроверяет отдельная программа, пока не все: доказательство
из примера выше она не перепроверяет, и отчёт `flang check --proof` об этом
сообщает. Синтаксис до версии 1.0 может меняться. Подробности —
[Что доказано, а что нет](what-is-proved.html).
