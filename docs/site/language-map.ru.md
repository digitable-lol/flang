# Карта конструкций языка

Каждое слово языка — узел. Сплошная стрелка значит «внутри первого пишется
второе». Пунктирная значит «первое даёт второе» или «первое ссылается на
второе». Какую конструкцию брать под какое действие — на странице
[Какую конструкцию когда брать](which-construct.html).

## Как читать

| Узел | Что значит |
| --- | --- |
| прямоугольник с заливкой | понятие [словаря языка](glossary.html); на карте стоит ровно один раз |
| скруглённый прямоугольник | конструкция, которой в словаре нет |
| овал с пометкой «слой N» | ссылка на понятие, нарисованное в слое N |
| овал без пометки | подпись: что подаётся на вход или получается на выходе |

## Сверка со словарём

по одному разу; расхождения нет. Сверх словаря на карте 22 узла: это
конструкции, которые есть в [спецификации](spec.html), а в словаре их нет.
