# Теоремы по шагам

Страница отвечает на вопрос: как самому написать доказательство, когда
компилятор не нашёл его без подсказки. Здесь пять рецептов, по одному на вид
теоремы. Файлы лежат в `docs/examples/proofs`, все проходят `flang check`.

Теорема во flang — запись шагов, которые ядро проверяет по одному. Тактик и
поиска, как в Lean или Coq, нет.

## Скелет теоремы

```flang fragment
теорема «имя постусловия»
  дано параметр: тип
  утверждаем то же, что после имени в обеспечивает
  обоснование
  следовательно доказано
```

- имя теоремы совпадает с именем постусловия: так они связаны;
- `дано` перечисляет параметры функции с теми же типами;
- `утверждаем` повторяет условие из `обеспечивает` слово в слово.

Обоснований три вида:

| Обоснование | Когда брать |
| --- | --- |
| `индукция по` и `по предположению` или `по примеру` | функция обходит аргумент строкой `разбор` |
| `по свойству «имя»` | функция вызывает другую, у которой нужное постусловие доказано |
| шаги `затем … по закону «правило» из …` | нужна цепочка фактов |

## 1. Индукция по своему типу

Функция считает высоту стопки от заданного дна. Теорема ведёт индукцию по
стопке, её случаи повторяют случаи `разбор`. Файл `stack-height.flang`:

```flang insert docs/examples/proofs/stack-height.flang
модуль «Высота стопки»

тип «Стопка»
  вариант «Пусто»
  вариант «Звено» содержит голова: число, хвост: «Стопка»

тотальная функция «Высота от дна»
  принимает стопка: «Стопка», дно: число
  возвращает число
  требует «дно неотрицательно» дно не меньше 0
  для всех стопка обеспечивает «высота от дна неотрицательна» результат не меньше 0
  пример «пустая от нуля»
    дано стопка равно вариант «Пусто»
    дано дно равно 0
    ожидается 0
  разбор стопка
    случай вариант «Пусто»
      то дно
    случай вариант «Звено» с голова как г и хвост как х
      то («Высота от дна» от х и дно) плюс 1

теорема «высота от дна неотрицательна»
  дано стопка: «Стопка»
  дано дно: число
  утверждаем результат не меньше 0
  индукция по стопка
    случай вариант «Пусто»
      то по предположению
    случай вариант «Звено» с голова как г и хвост как х
      то по предположению
  следовательно доказано

тотальная функция «Высота»
  принимает стопка: «Стопка»
  возвращает число
  для всех стопка обеспечивает «высота неотрицательна» результат не меньше 0
  пример «у пустой стопки высоты нет»
    дано стопка равно вариант «Пусто»
    ожидается 0
  «Высота от дна» от стопка и 0

теорема «высота неотрицательна»
  дано стопка: «Стопка»
  утверждаем результат не меньше 0
  по свойству «высота от дна неотрицательна»
  следовательно доказано
```

```bash
flang check stack-height.flang --proof
```

```
постусловие «высота от дна неотрицательна» функции «Высота от дна» — доказано
индукцией по «Стопка»: база 1 случай, шаг при допущении на частях (1 случай) …
постусловие «высота неотрицательна» функции «Высота» — доказано: терм принят
ядром, 1 шаг, … основания: постусловие «высота от дна неотрицательна» …
```

В пустой стопке результат равен дну, и `по предположению` берёт предусловие.
В звене результат на единицу больше высоты хвоста, и `по предположению` берёт
то же утверждение для хвоста.

Индукция идёт по типу с вариантами, по списку, по строке и по
`неотрицательное`. Для `неотрицательное` пишется `индукция по н убывает н`, а
функция обязана вызывать себя от `н минус 1`. По `число` индукции нет.

Если случай покрывает одно значение и у функции есть тест с этим значением, на
него можно сослаться: `то по примеру «пустая от нуля»`.

## 2. Ссылка на доказанное постусловие

Вторая функция в том же файле, «Высота», вызывает первую. Её теорема занимает
одну строку: `по свойству «высота от дна неотрицательна»`.

`по свойству` подставляет постусловие вызванной функции: её параметры
заменяются аргументами вызова, слово `результат` — самим вызовом. Вторая
строка вывода выше называет это постусловие после слова «основания».

## 3. Цепочка шагов

Функция возвращает первый аргумент. Предусловия говорят: он не больше второго,
а второй не больше десяти. Теорема выписывает цепочку по шагу на строку. Файл
`chain.flang`:

```flang insert docs/examples/proofs/chain.flang
модуль «Через середину»

тотальная функция «Меньшее из пары»
  принимает а: число, б: число
  требует «а не больше б» а не больше б
  требует «б не больше десяти» б не больше 10
  возвращает число
  обеспечивает «результат не больше десяти» результат не больше 10
  пример «три и семь»
    дано а равно 3
    дано б равно 7
    ожидается 3
  а

теорема «результат не больше десяти»
  дано а: число
  дано б: число
  утверждаем результат не больше 10
  затем а не больше б по закону «О1» из строки 5
  затем б не больше 10 по закону «О1» из строки 6
  затем а не больше 10 по закону «О10» из 1 и 2
  по закону «Разв2» из 3 и строки 13
  следовательно доказано
```

```bash
flang check chain.flang --proof
```

```
постусловие «результат не больше десяти» функции «Меньшее из пары» — доказано:
терм принят ядром, 4 шага …
```

Шаг пишется так: `затем факт по закону «правило» из опор`. Опора — строка
исходника (`из строки 5`) или номер предыдущего шага (`из 1 и 2`). Последний
шаг без слова `затем` завершает доказательство. Правил шесть:

| Правило | Что даёт |
| --- | --- |
| `Н1` | литерал не меньше нуля: `0 не меньше 0` |
| `Н3` | `х не меньше 0` из строки, где это сказано: предусловие или тип `неотрицательное` |
| `Н5` | сумма двух неотрицательных неотрицательна |
| `О1` | `а не больше б` из строки, где это сказано |
| `О10` | из `а не больше б` и `б не больше в` следует `а не больше в` |
| `Разв2` | подставляет тело функции вместо слова `результат` |

Номер строки в опоре меняется, когда вы правите файл выше теоремы. Компилятор
это замечает: шаг с неверной строкой даёт ошибку `FLANG_PROOF_STEP`.

## 4. Утверждение без функции

`утверждение` говорит о всех значениях типа и не привязано к постусловию. Ядро
доказывает его само, теорема нужна не всегда. Файл `statements.flang`:

```flang insert docs/examples/proofs/statements.flang
модуль «Утверждения»

тотальная функция «Удвоить каждое»
  принимает ряд: список числа
  возвращает список числа
  разбор ряд
    случай пусто
      то пустой список
    случай голова первый и хвост остальные
      то приписать (первый умножить на 2) к («Удвоить каждое» от остальные)

утверждение «удвоение сохраняет длину»
  для всех ряд: список числа
  утверждаем (длина («Удвоить каждое» от ряд)) равен (длина ряд)

утверждение «два отображения есть одно»
  для всех ряд: список числа
  утверждаем ((отобразить (отобразить ряд как э → э плюс 1) как э → э умножить на 2)
    равен (отобразить ряд как э → (э плюс 1) умножить на 2))

утверждение «порядок транзитивен»
  для всех а: точное целое и б: точное целое и ц: точное целое
  утверждаем если а больше б и притом б больше ц то а больше ц иначе да

утверждение «общее слагаемое сохраняет порядок»
  для всех а: точное целое и б: точное целое и ц: точное целое
  утверждаем если а не меньше б то (а плюс ц) не меньше (б плюс ц) иначе да
```

```bash
flang check statements.flang --proof
```

```
утверждение «удвоение сохраняет длину» — доказано индукцией по «список» …
утверждение «два отображения есть одно» — доказано сведением цели с телом функции:
правило «переписка доказанными равенствами» …
утверждение «порядок транзитивен» — доказано по объявленным типам аргументов …
утверждение «общее слагаемое сохраняет порядок» — доказано по объявленным типам аргументов …
```

Все четыре доказаны без теоремы: свойство рекурсивной функции над списком,
слияние двух `отобразить` в одно, два неравенства над `точное целое`.

Тип здесь решает. Те же неравенства над `число` ядро не докажет: `число` —
binary64, и сложение в нём округляет.

## 5. Законы моноида и монады

Объявите структуру, и её законы станут утверждениями о всех значениях. Файл
`maybe-monad.flang`:

```flang insert docs/examples/proofs/maybe-monad.flang
модуль «Монада может быть»

тип «Возможно» от «А»
  вариант «Ничего»
  вариант «Нечто» содержит значение: «А»

тотальная функция «Обернуть» от «А»
  принимает значение: «А»
  возвращает «Возможно» от «А»
  вариант «Нечто» с значение равным значение

тотальная функция «Сплющить» от «А»
  принимает вложенное: «Возможно» от («Возможно» от «А»)
  возвращает «Возможно» от «А»
  пример «два слоя дают один»
    дано вложенное равно вариант «Нечто» с значение равным (вариант «Нечто» с значение равным 5)
    ожидается вариант «Нечто» с значение равным 5
  пример «пустой внешний слой»
    дано вложенное равно вариант «Ничего»
    ожидается вариант «Ничего»
  разбор вложенное
    случай вариант «Ничего»
      то вариант «Ничего»
    случай вариант «Нечто» с значение как внутри
      то внутри

монада «Возможно» от «А»
  возврат «Обернуть»
  соединение «Сплющить»
```

```bash
flang check maybe-monad.flang --proof
```

```
закон «Возможно — левая единица» — доказано сведением цели с телом функции …
закон «Возможно — правая единица» — доказано индукцией по «Возможно» …
закон «Возможно — ассоциативность связывания» — доказано индукцией по «Возможно» …
законов утверждениями 3: доказано ядром 3, не доказано 0
```

Все три закона монады доказаны. У `моноид` так же доказываются ассоциативность
и обе единицы, если значения имеют тип `точное целое`. Над `число` законы
моноида не доказываются: сложение binary64 не ассоциативно.

## Порядок работы

1. Напишите постусловие и запустите `flang check файл --proof`.
2. «Доказано» — теорема не нужна.
3. `FLANG_PROPERTY` — постусловие ложно на найденном входе: исправьте код или
   постусловие.
4. Другой ответ — сначала попробуйте рецепты страницы
   [Если не доказалось](proof-refused.html), потом пишите теорему.

Полный синтаксис теоремы — в [Справочнике конструкций](language.html#теорема).
