# Доказательство руками

Большинство постусловий ядро — prover, часть компилятора — доказывает само.
Когда `flang check --proof` отвечает «сетка N» или «объявлено, не доказано»
([три ответа](how-proofs-work.html#обеспечивает-постусловие-и-три-ответа)),
постусловие можно доказать теоремой. Ядро проверяет каждый её шаг и ничего не
ищет само. Все программы ниже проходят `flang check`, отчёты под ними — вывод
`flang {{выпуск.версия}}`.

## Скелет теоремы

```flang fragment
теорема «имя постусловия»
  дано параметр: тип
  утверждаем то же, что после имени в обеспечивает
  обоснование
  следовательно доказано
```

Теорема привязана к постусловию по имени. `утверждаем` повторяет постусловие
слово в слово, `дано` перечисляет параметры функции с теми же типами.
Обоснований три вида:

| Приём | Когда брать |
| --- | --- |
| `индукция по` + `по предположению` / `по примеру` | функция обходит свой аргумент `разбор`ом |
| `по свойству «имя»` | функция зовёт другую, у которой постусловие уже доказано |
| шаги `затем … по закону «правило» из …` | нужна цепочка фактов, которую ядро само не строит |

## Индукция

Функция считает высоту стопки от заданного дна. Дно неотрицательно по
предусловию, значит и результат неотрицателен. Без теоремы ядро отвечает
«сетка 1 значение». Теорема ведёт индукцию по стопке, её случаи повторяют
случаи `разбор`а:

```flang
модуль «Высота стопки»

тип «Стопка»
  вариант «Пусто»
  вариант «Звено» содержит голова: число, хвост: «Стопка»

тотальная функция «Высота от дна»
  принимает стопка: «Стопка», дно: число
  возвращает число
  требует «дно неотрицательно» дно не меньше 0
  для всех стопка обеспечивает «высота от дна неотрицательна» результат не меньше 0
  пример «пустая от нуля»
    дано стопка равно вариант «Пусто»
    дано дно равно 0
    ожидается 0
  разбор стопка
    случай вариант «Пусто»
      то дно
    случай вариант «Звено» с голова как г и хвост как х
      то («Высота от дна» от х и дно) плюс 1

теорема «высота от дна неотрицательна»
  дано стопка: «Стопка»
  дано дно: число
  утверждаем результат не меньше 0
  индукция по стопка
    случай вариант «Пусто»
      то по предположению
    случай вариант «Звено» с голова как г и хвост как х
      то по предположению
  следовательно доказано
```

```
постусловие «высота от дна неотрицательна» функции «Высота от дна» — доказано
индукцией по «Стопка»: база 1 случай, шаг при допущении на частях (1 случай),
правила сведения: цель есть допущение; неотрицательность по построению —
утверждение обо ВСЕХ входах типа «Стопка», а не о написанных
```

В пустой стопке результат — само дно, и `по предположению` берёт предусловие.
В звене результат на единицу больше высоты хвоста, и `по предположению` берёт
то же утверждение для хвоста.

Если случай покрывает одно значение (`случай вариант «Пусто»`, `случай пусто`,
`случай 0`) и у функции есть пример с этим значением, можно сослаться на него:
`то по примеру «пустая от нуля»`.

Индукция идёт по типу с вариантами, по списку и по `неотрицательное` — тогда
пишется `индукция по н убывает н`, а функция обязана спускаться ровно на
единицу. По `число` индукции нет. Что отвечает ядро, когда форма не та, —
[Ядро отказало](proof-refused.html).

## Свойство вызванной функции

Добавим к тому же модулю функцию, тело которой — вызов «Высоты от дна». Довод
в одну строку: у вызванной функции нужное постусловие уже доказано.

```flang fragment
тотальная функция «Высота»
  принимает стопка: «Стопка»
  возвращает число
  для всех стопка обеспечивает «высота неотрицательна» результат не меньше 0
  пример «у пустой стопки высоты нет»
    дано стопка равно вариант «Пусто»
    ожидается 0
  «Высота от дна» от стопка и 0

теорема «высота неотрицательна»
  дано стопка: «Стопка»
  утверждаем результат не меньше 0
  по свойству «высота от дна неотрицательна»
  следовательно доказано
```

```
постусловие «высота неотрицательна» функции «Высота» — доказано: терм принят
ядром, 1 шаг, правило «цель есть допущение», основания: постусловие «высота от
дна неотрицательна» функции «Высота от дна» — утверждение обо ВСЕХ входах
```

`по свойству` подставляет постусловие вызванной функции: её параметры —
аргументами вызова, `результат` — самим вызовом. С обеими теоремами
`flang check --proof --strict` отвечает кодом 0, без них — кодом 3.

## Цепочка шагов

Функция возвращает первый аргумент. Предусловия говорят, что он не больше
второго, а второй не больше десяти. Ядро само эту цепочку не собирает; теорема
выписывает её по шагу на строку:

```flang
модуль «Через середину»

тотальная функция «Меньшее из пары»
  принимает а: число, б: число
  требует «а не больше б» а не больше б
  требует «б не больше десяти» б не больше 10
  возвращает число
  обеспечивает «результат не больше десяти» результат не больше 10
  пример «три и семь»
    дано а равно 3
    дано б равно 7
    ожидается 3
  а

теорема «результат не больше десяти»
  дано а: число
  дано б: число
  утверждаем результат не больше 10
  затем а не больше б по закону «О1» из строки 5
  затем б не больше 10 по закону «О1» из строки 6
  затем а не больше 10 по закону «О10» из 1 и 2
  по закону «Разв2» из 3 и строки 13
  следовательно доказано
```

```
постусловие «результат не больше десяти» функции «Меньшее из пары» — доказано:
терм принят ядром, 4 шага — утверждение обо ВСЕХ входах
```

Шаг — это `затем факт по закону «правило» из опор`. Опора — строка исходника
(`из строки 5`: предусловие; `из строки 13`: тело) или номер предыдущего шага
(`из 1 и 2`). Последний шаг без `затем` закрывает цель. Правил шесть:

| Правило | Что даёт |
| --- | --- |
| `Н1` | литерал не меньше нуля: `0 не меньше 0` |
| `Н3` | `х не меньше 0` из строки, где это сказано: предусловие или тип `неотрицательное` |
| `Н5` | сумма двух неотрицательных неотрицательна (из двух шагов) |
| `О1` | `а не больше б` из строки, где это сказано |
| `О10` | из `а не больше б` и `б не больше в` — `а не больше в` |
| `Разв2` | подставляет тело функции вместо `результат` и закрывает цель |

Шаг, который не сошёлся, ядро называет. Здесь шаг 1 сослался на строку 6
вместо строки 5:

```
FLANG_PROOF_STEP в файле m3.flang, строка 19, столбец 3: теорема «результат не
больше десяти»: шаг 1 (О1, строка 6): О1 — допущение даёт «б не больше 10», а
заключено «а не больше б»
```

## Утверждение без функции

`утверждение` — теорема о всех значениях типа, не привязанная к постусловию.
Ядро доказывает его само, в том числе индукцией по списку:

```flang
модуль «Утверждения»

тотальная функция «Удвоить каждое»
  принимает ряд: список числа
  возвращает список числа
  разбор ряд
    случай пусто
      то пустой список
    случай голова первый и хвост остальные
      то приписать (первый умножить на 2) к («Удвоить каждое» от остальные)

утверждение «удвоение сохраняет длину»
  для всех ряд: список числа
  утверждаем (длина («Удвоить каждое» от ряд)) равен (длина ряд)

утверждение «два отображения есть одно»
  для всех ряд: список числа
  утверждаем ((отобразить (отобразить ряд как э → э плюс 1) как э → э умножить на 2)
    равен (отобразить ряд как э → (э плюс 1) умножить на 2))

утверждение «порядок транзитивен»
  для всех а: точное целое и б: точное целое и ц: точное целое
  утверждаем если а больше б и притом б больше ц то а больше ц иначе да

утверждение «общее слагаемое сохраняет порядок»
  для всех а: точное целое и б: точное целое и ц: точное целое
  утверждаем если а не меньше б то (а плюс ц) не меньше (б плюс ц) иначе да
```

```
$ flang check --proof utverzhdeniya.flang
  утверждение «удвоение сохраняет длину» — доказано индукцией по «список»: база
  1 случай, шаг при допущении на частях (1 случай) …
  утверждение «два отображения есть одно» — доказано … правило «переписка
  доказанными равенствами» … основания: … закон «Слияние отображений» …
  утверждение «порядок транзитивен» — доказано по объявленным типам аргументов …
  утверждение «общее слагаемое сохраняет порядок» — доказано по объявленным
  типам аргументов …
  утверждений 4: доказано 4 (из них индукцией 1) (из них без теоремы 3,
  объявленным типом 2), сетка 0, объявлено, не доказано 0
```

Что здесь доказано:

- свойство рекурсивной функции над списком — индукцией по списку;
- законы функтора списка: слияние двух `отобразить` в одно и
  `(отобразить а как э → э) равен а`;
- линейные неравенства и равенства многочленов над `точное целое`.

Тип важен. Те же два неравенства над `число` остаются «объявлено, не
доказано»: `число` — float, и сложение в нём округляет.

## Законы моноида и монады

Объявите структуру — и ядро судит её законы как утверждения обо всех
значениях:

```flang
модуль «Монада может быть»

тип «Возможно» от «А»
  вариант «Ничего»
  вариант «Нечто» содержит значение: «А»

тотальная функция «Обернуть» от «А»
  принимает значение: «А»
  возвращает «Возможно» от «А»
  вариант «Нечто» с значение равным значение

тотальная функция «Сплющить» от «А»
  принимает вложенное: «Возможно» от («Возможно» от «А»)
  возвращает «Возможно» от «А»
  пример «два слоя дают один»
    дано вложенное равно вариант «Нечто» с значение равным (вариант «Нечто» с значение равным 5)
    ожидается вариант «Нечто» с значение равным 5
  пример «пустой внешний слой»
    дано вложенное равно вариант «Ничего»
    ожидается вариант «Ничего»
  разбор вложенное
    случай вариант «Ничего»
      то вариант «Ничего»
    случай вариант «Нечто» с значение как внутри
      то внутри

монада «Возможно» от «А»
  возврат «Обернуть»
  соединение «Сплющить»
```

```
$ flang check --proof monada.flang; echo "код $?"
  закон «Возможно — левая единица» — доказано сведением цели с телом функции …
  закон «Возможно — правая единица» — доказано индукцией по «Возможно» …
  закон «Возможно — ассоциативность связывания» — доказано индукцией по
  «Возможно»: база 2 случая, шаг при допущении на частях (0 случаев) …
  законов утверждениями 3: доказано ядром 3, не доказано 0
код 0
```

Все три закона монады доказаны. У `моноид` так же доказываются ассоциативность
и обе единицы — над `точное целое`. Над `число` ядро отказывает и называет
причину:

```
закон «Сумма — ассоциативность» — ядром НЕ доказан и доказан не будет: носитель
— двоичное «число» …, где сложение и умножение округляют, сумма не сочетательна
выше 2⁵³, а ноль не нейтрален к минус нулю; объявите носитель «точное целое»
```

## Когда руками не доказать

Шесть правил шага не покрывают вычитание. Постусловие `результат не меньше 0`
при теле `ширина минус длина` и предусловии `ширина не меньше длина` над
`число` верно, но ни ядро, ни теорема из этих правил его не доказывают. Оно
остаётся сеткой и проверяется при работе после каждого возврата; программа
при этом собирается. Если проверки быть не должно, поменяйте запись: объявите
параметры `неотрицательное` или сформулируйте постусловие иначе —
[Что ядро доказывает само](what-the-kernel-accepts.html).

## Порядок работы

1. Напишите постусловие и спросите `flang check --proof`.
2. «Доказано» — теорема не нужна.
3. `FLANG_EXAMPLE: FLANG_PROPERTY` — постусловие ложно на найденном входе:
   чините функцию или постусловие.
4. «Сетка» или «объявлено, не доказано» — сначала попробуйте
   [переписать постусловие](what-the-kernel-accepts.html), потом пишите
   теорему.
5. Ядро отвергло теорему — [Ядро отказало: чья это ошибка](proof-refused.html).

Полный синтаксис теоремы — в [Справочнике конструкций](language.html#теорема).
