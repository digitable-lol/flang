# Сравнение на классических леммах

Страница отвечает на вопрос: какие леммы из учебников Coq и Lean ядро flang
доказывает само. Взяты 75 лемм про натуральные числа и списки. Каждая
переписана на flang функцией с постусловием и проверена `flang {{выпуск.версия}}`.

## Итог

| | Лемм | Доказано | Только тесты | Не записывается |
| --- | ---: | ---: | ---: | ---: |
| Арифметика | 54 | 22 | 31 | 1 |
| Списки | 21 | 8 | 13 | 0 |
| Всего | 75 | 30 | 44 | 1 |

«Только тесты» значит: постусловие прошло на тестах функции, для всех входов
оно не доказано. В Coq или Lean доказана каждая из 75.

Одна лемма записана несколькими постусловиями, поэтому постусловий больше, чем
лемм: 107, из них доказано 57.

## Как переводился `nat`

В Coq и Lean леммы сформулированы над `nat`: точным типом без NaN,
бесконечностей и дробей. `число` во flang — binary64, и над ним половина этих
лемм ложна:

```
5 не больше (5 плюс (0 минус 1))                    →  false
(9007199254740994 минус 1) плюс 1                   →  9007199254740992
(0 делить на 0) не больше (0 делить на 0)           →  false
```

Поэтому на месте `nat` везде стоит `неотрицательное`: целое от 0 до 2⁵³−1.

## Почему лемма не доказывается

У 44 недоказанных лемм восемь причин.

**1. Ассоциативность и дистрибутивность — четыре леммы.** Ядро сравнивает две
стороны равенства как выражения и переставляет только два операнда одного
`плюс` или `умножить`. Скобки оно не переставляет: для binary64 ассоциативность
ложна. Над `точное целое` те же равенства доказываются —
[пример](manual-proofs.html#4-утверждение-без-функции).

**2. Нейтральный элемент — семь лемм.** `а плюс 0` и `а` для ядра разные
выражения. Правила «убрать ноль» или «убрать единицу» для тела функции нет.

**3. Неравенства — шесть лемм.** Порядок ядро берёт из типа `неотрицательное`:
рефлексивность, транзитивность, «слагаемое не больше суммы» доказаны. Из двух
неравенств равенство оно не выводит, поэтому антисимметрия не доказана. Границы
остатка доказываются, когда делитель записан числом, и не доказываются, когда
он аргумент.

**4. Остатки, чётность, делимость — семь лемм.** Правил про остаток, кроме его
границ, у ядра нет. «Чётность — нулевой остаток по два» доказана: это
определение, постусловие совпало с телом. «Сумма чётных чётна» — нет.

**5. Наибольший общий делитель — пять лемм.** Алгоритм Евклида уменьшает
аргумент на остаток от деления. Такой шаг проверка завершения не понимает, и
функция объявлена без слова `тотальная`. Обе ветви определения доказаны как
постусловия, следствия из них — нет.

**6. Перестановка аргументов минимума и максимума — две леммы.** Нужно сравнить
два вызова одной функции, а ядро знает о вызове только доказанные постусловия —
[Вызовы](what-the-kernel-accepts.html#5-вызовы-нужно-доказанное-постусловие-вызываемой-функции).

**7. Равенство списков — девять лемм.** Про склейку, обращение и отображение
ядро доказывает длину результата. Равенство самих списков доказано в двух
случаях: склейка с пустым списком справа и отображение тождественной функцией.

**8. Вхождение элемента — четыре леммы.** Связи между `содержит` и доступом по
номеру у ядра нет.

Ещё одна лемма, «алгоритм Евклида завершается», постусловием не записывается.
Завершение во flang — свойство определения функции, за него отвечает слово
`тотальная`.

## Что из этого следует

- Точный тип доказывает много без усилий. Из 37 доказанных постусловий
  арифметики 17 получены из одного объявления типа `неотрицательное`.
- Определение доказывается, следствия из него — редко. Ядро берёт то, что
  написано в теле функции, и мало из того, что из тела следует.
- Про списки ядро считает длины и почти не доказывает равенства списков.

Lean и Coq доказывают все эти леммы, потому что в них доказательство пишет
человек и возможна любая индукция. Чем flang отличается от них по устройству —
[flang для знающих Lean и Dafny](flang-for-lean-and-dafny-users.html).

## Для разработчиков языка: как повторить

Файлы с леммами лежат в клоне репозитория:

```sh
bootstrap/flang check flang/stdlib/math-classics.flang --proof
bootstrap/flang check flang/stdlib/math-classics-lists.flang --proof
```

```
утверждений 70: доказано 37 (из них без теоремы 37, объявленным типом 17), сетка 33, объявлено, не доказано 0
утверждений 37: доказано 20 (из них без теоремы 20), сетка 17, объявлено, не доказано 0
```

Словом «сетка» компилятор называет ответ «проверено только на тестах».
