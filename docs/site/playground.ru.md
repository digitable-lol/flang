# Песочница

```playground
Песочнице нужен JavaScript и браузер с WebAssembly. Без них те же проверки делает
компилятор в терминале: flang check файл.flang --proof.
```

Здесь можно писать на flang и сразу видеть результат: слева редактор, справа ответ
компилятора. Устанавливать ничего не нужно. Компилятор собран в WebAssembly и работает в
этой вкладке; текст на сервер не уходит.

## С чего начать

Над редактором стоят плитки сетапов. Сетап — готовая раскладка под одно занятие: стартовая
программа, то, что показано справа, и главная кнопка. Главную кнопку нажимает и
Ctrl+Enter.

| Сетап | Что справа | Адрес |
|---|---|---|
| Первая программа | значение функции и таблица тестов | `#setup=first` |
| Доказательства | каждое постусловие и утверждение со статусом | `#setup=proof` |
| Тесты | таблица: тест, вход, ожидалось, получено | `#setup=tests` |
| Генерация кода | та же программа на C, Go, Rust и ещё семи языках | `#setup=emit` |
| Рассуждение по-русски | следует ли заключение из посылок | `#setup=reasoning` |
| Формула | формула с ∀ и ∃, её перевод на flang и проверка | `#setup=formula` |
| Свой текст | что flang прочитал в тексте и где рассуждение ошибается | `#setup=prose` |
| Свой язык (DSL) | правила скидок, калькулятор и автомат заказа со страницы [Свой язык за 30 минут](dsl.html) | `#setup=dsl` |
| C → flang | перевод функции на C и проверка результата | `#setup=c` |
| Python → flang | перевод функции на Python и проверка результата | `#setup=python` |

Адрес сетапа можно дописать к адресу страницы и отправить ссылкой. Кнопка «Поделиться»
кладёт в ссылку ещё и текст из редактора — после знака `#`, который браузер серверу не
передаёт.

## Редактор

Пока вы набираете, песочница проверяет текст сама: через полсекунды после правки
срабатывает главная кнопка сетапа. Программу с `использует` она так не проверяет: с
библиотекой проверка занимает около десяти секунд, поэтому её запускает кнопка.

Ошибка показана одним сообщением справа. В редакторе подчёркнуто слово, на которое
указал компилятор, а код ошибки (`FLANG_…`) ведёт на её строку в
[справочнике кодов](diagnostics.html). Кнопка «строка N» ставит курсор на место ошибки.

Клавиши:

- Tab вставляет два пробела, а при выделении сдвигает выделенные строки; Shift+Tab убирает
  отступ;
- Enter сохраняет отступ и добавляет его после строки, которая открывает блок
  (`функция`, `пример`, `разбор`, `случай`);
- `<<` превращается в `«»` с курсором внутри, `>>` — в `»`.

Текст каждого сетапа сохраняется в браузере на каждую правку и возвращается после
перезагрузки страницы. Кнопка «Сбросить» возвращает стартовую программу. Текст из ссылки
важнее черновика: ссылка открывает то, что в ней записано.

## Что показано справа

**Результат** (сетап «Первая программа»). Кнопка «Запустить» вычисляет функцию и запускает
тесты. Имя функции и аргументы стоят в полях над редактором. Если поля пусты, берутся
первая функция текста и аргументы её первого теста.

**Доказательства.** По строке на каждое постусловие (`обеспечивает`) и утверждение.
Щелчок по строке ведёт к её месту в исходнике. Статусы:

- «доказано» — верно на всех входах, а не только на написанных тестах;
- «проверено только на тестах» — нарушений не нашлось, но это не доказательство;
- «не доказано» — нет ни доказательства, ни тестов, либо ядро не смогло вывести цель;
- «опровергнуто» — показан вход, на котором утверждение ложно.

Рядом стоят вкладки «Формулы» (утверждения в записи с ∀ и ∃) и «Рисунки» (дерево
доказательства, стрелки категории, законы моноида, круги для множеств).

**Тесты.** Тест во flang — это `пример` внутри функции. В таблице у каждого теста вход,
ожидаемое и полученное значение. Несошедшийся тест отмечает свою строку в редакторе.

**Код** (сетап «Генерация кода»). Программа на выбранном языке — её генерирует команда
`flang emit`. Язык и файл выбираются кнопками над кодом. Файлы библиотеки времени
выполнения копируются в результат как есть, поэтому названы только их имена.

**Вывод** (сетап «Рассуждение по-русски»). Словарь (`Понятие:`, `Свойство:`, `Имя:`),
посылки и заключение после слова «Следовательно». Ответ — «следует» или «не следует» с
контрпримером.

**Свой язык** (сетап «Свой язык (DSL)»). Три маленьких языка со страницы
[Свой язык за 30 минут](dsl.html): правила скидок, калькулятор выражений и автомат заказа.
Сначала открыты правила скидок; калькулятор и автомат заказа выбираются в списке примеров.
Кнопка «Проверить» показывает, что доказано о правилах, «Запустить» считает скидку, «Тесты»
прогоняют примеры.

**Перевод** (сетап «C → flang»). Функция на C становится программой на flang, и flang
сразу её проверяет. Переполнение `int` и деление на ноль превращаются в условия, которые
нужно доказать. Переводчик понимает `int`, `struct` из полей `int`, `bool` как результат
функции (с `#include <stdbool.h>`; `true` становится `да`, `false` — `нет`), `if`/`else`,
`while`, `for` и `return`. Строки `#include` для `stdbool.h`, `stdint.h`, `limits.h` и
`stddef.h` пропускаются; другие заголовки, указатели, массивы и дробные числа переводчик
не берёт и говорит, чем их заменить. Если flang не смог сам доказать, что цикл
заканчивается, ответ так и говорит: функция переведена, а доказанное доказано при
условии, что цикл закончился.

Перевод в обе стороны. Свои программы flang переводит на 10 языков сам — это сетап
«Генерация кода». Обратный перевод, с чужого языка во flang, пока есть для C и Python.

**Рассуждение** (сетап «Свой текст»). Сюда вставляют свой текст на русском: абзац из
статьи, аргумент из спора, несколько фраз со словом «следовательно» — до 6000 знаков и 40
предложений. Кнопка «Проверить рассуждение» читает каждое предложение и проверяет две
вещи: вытекает ли вывод из того, что сказано до него, и не спорят ли утверждения друг с
другом. Кнопка «Пример» ставит в редактор короткий текст с двумя такими ошибками.

У каждого предложения в ответе стоит цветная пометка:

- зелёная «понято» — предложение понято и участвует в проверке;
- жёлтая «ничего не утверждает» — предложение понято, но утверждения в нём нет, например
  «Тёплое летнее утро.»;
- серая «не понято» — песочница не смогла прочесть предложение; рядом сказано почему;
- серая «слишком длинное» — в предложении больше 30 слов, его надо разбить.

Под пометкой видно, как песочница записала смысл предложения, или почему оно не вошло в
проверку: незнакомое слово, слишком много способов прочесть фразу, слово вроде «он» или
«это», которое отсылает к другому предложению, или оборот, который грамматика не знает.
Если предложение не понято, напишите его проще: одно утверждение в предложении, прямой
порядок слов, полные слова вместо «он» и «это», без оговорок вроде «как известно».
Непонятое предложение проверку не ломает: остальной текст проверен без него.

Рамка ответа зелёная, если в понятых предложениях ошибок нет, красная, если ошибки
найдены, и серая, если не понято ни одно предложение. Ниже, в разделе «Что найдено»,
перечислены сами ошибки: вывод не следует, противоречие, круг в рассуждении, слово,
которое по дороге меняет смысл, вывод без посылок.

Нейросети здесь нет: текст читают словарь и правила русской грамматики. Поэтому на
обычном тексте понятой оказывается обычно только часть предложений. Длинную статью
проверяют на своём компьютере командой `flang run-script argue` в копии репозитория;
как устроена проверка, рассказано на странице
[Проверить рассуждение в тексте](argue.html).

Словарь русских слов — OpenCorpora. Его данные лежат на сайте рядом с песочницей и
распространяются по лицензии CC BY-SA 3.0; код flang — по своей лицензии. Песочница
скачивает только те файлы словаря, которые нужны словам текста. Сам текст никуда не
отправляется.

На вкладке «Терминал» в каждом сетапе лежит вывод компилятора в том виде, в каком его
выводит команда в терминале.

## Как песочница понимает текст

Что перед ней, песочница решает по первой значащей строке; пустые строки и комментарии
`//` не в счёт.

- Строка начинается с `модуль`, `module`, `категория` или `category` — это программа на
  flang. Её проверяет `flang check --proof`.
- Строка начинается с `∀`, `∃`, `\forall`, `\exists`, `forall` или `exists` — это
  формула. Переводчик делает из неё утверждение flang, и его проверяет ядро
  доказательств. Если формула не читается, названа причина: «цепочка сравнений без
  скобок неоднозначна», «ℝ в flang нет».
- Любой другой текст — рассуждение по-русски. Переводчик строит из него программу, а
  ядро решает, следует ли заключение из посылок.

После ядра запись доказательства заново проходит отдельная программа `checker`, тоже
собранная в WebAssembly. Это независимая проверка: доказанное подтверждено дважды.

Модули библиотеки названы по-английски: `использует «Lists»`, а не `использует
«Списки»`. Если модуль назван иначе, песочница подскажет похожие имена.

## Примеры

Силлогизм Barbara: заключение выводится из посылок.

```text playground Силлогизм Barbara — следует
Понятие: человек, люди.
Понятие: грек, греки.
Свойство: смертен, смертны.

Все люди смертны. Все греки — люди. Следовательно, все греки смертны.
```

Теорема о списке: сумма пустого списка — ноль, длина списка не отрицательна, а
приписанный в начало элемент удлиняет список на один. Всё доказано для всех списков.

```flang playground Теорема о списке
модуль «Списки»

тотальная функция «Сумма»
  принимает л: список число
  возвращает число
  разбор л
    случай пусто
      то 0
    случай голова и хвост
      то голова плюс («Сумма» от хвост)

утверждение «сумма пустого списка — ноль»
  утверждаем («Сумма» от пустой список) равна 0

утверждение «длина списка не отрицательна»
  для всех л: список число
  утверждаем (длина л) не меньше 0

утверждение «приписанный элемент удлиняет список на один»
  для всех л: список число
  для всех э: число
  утверждаем (длина (приписать э к л)) равна ((длина л) плюс 1)
```

Моноид с законами: склейка строк ассоциативна, а пустая строка — её единица. Законы
моноида компилятор проверяет на значениях из примеров операции; на рисунке — квадрат
ассоциативности и треугольники единицы.

```flang playground Моноид с законами
модуль «Склейка строк»

тотальная функция «Склеить»
  принимает а: строка, б: строка
  возвращает строка
  пример «два слова»
    дано а равно "мир"
    дано б равно "ок"
    ожидается "мирок"
  пример «с пустой строкой»
    дано а равно ""
    дано б равно "ум"
    ожидается "ум"
  соединить [а, б] по ""

моноид «Склейка»
  носитель строка
  операция «Склеить»
  единица ""
```

Категория с квадратом: функтор переводит рубли в копейки, и квадрат «выставить счёт,
потом перевести» = «перевести, потом выставить» обязан коммутировать.

```flang playground Категория с квадратом
модуль «Заказы и счета»

объект «Заказ»
  рубли является числом

объект «Счёт»
  рубли является числом

объект «Заказ в копейках»
  копейки является числом

объект «Счёт в копейках»
  копейки является числом

тотальная функция «Выставить»
  принимает заказ: «Заказ»
  возвращает «Счёт»
  пример «три рубля — счёт на тринадцать»
    дано заказ равно запись «Заказ» с рубли равным 3
    ожидается запись «Счёт» с рубли равным 13
  запись «Счёт» с рубли равным (заказ.рубли плюс 10)

тотальная функция «Выставить в копейках»
  принимает заказ: «Заказ в копейках»
  возвращает «Счёт в копейках»
  пример «триста копеек — счёт на тысячу триста»
    дано заказ равно запись «Заказ в копейках» с копейки равным 300
    ожидается запись «Счёт в копейках» с копейки равным 1300
  запись «Счёт в копейках» с копейки равным (заказ.копейки плюс 1000)

тотальная функция «Заказы равны»
  принимает а: «Заказ», б: «Заказ»
  возвращает признак
  а.рубли равен б.рубли

тотальная функция «Счета равны»
  принимает а: «Счёт», б: «Счёт»
  возвращает признак
  а.рубли равен б.рубли

тотальная функция «Заказы в копейках равны»
  принимает а: «Заказ в копейках», б: «Заказ в копейках»
  возвращает признак
  а.копейки равен б.копейки

тотальная функция «Счета в копейках равны»
  принимает а: «Счёт в копейках», б: «Счёт в копейках»
  возвращает признак
  а.копейки равен б.копейки

тотальная функция «Заказ в копейки»
  принимает заказ: «Заказ»
  возвращает «Заказ в копейках»
  пример «три рубля — триста копеек»
    дано заказ равно запись «Заказ» с рубли равным 3
    ожидается запись «Заказ в копейках» с копейки равным 300
  запись «Заказ в копейках» с копейки равным (заказ.рубли умножить на 100)

  принимает счёт: «Счёт»

    ожидается запись «Счёт в копейках» с копейки равным 1300
  запись «Счёт в копейках» с копейки равным (счёт.рубли умножить на 100)

морфизм «выставить» из «Заказ» в «Счёт»
  даёт «Выставить»

морфизм «выставить в копейках» из «Заказ в копейках» в «Счёт в копейках»
  даёт «Выставить в копейках»

единица «Заказ»
единица «Счёт»
единица «Заказ в копейках»
единица «Счёт в копейках»

  объект «Заказ» даёт «Заказы равны»
  объект «Счёт» даёт «Счета равны»

категория «Копейки»
  морфизм «выставить в копейках»
  объект «Заказ в копейках» даёт «Заказы в копейках равны»
  объект «Счёт в копейках» даёт «Счета в копейках равны»

функтор «В копейки» из «Рубли» в «Копейки»
  объект «Заказ» отображается в «Заказ в копейках» даёт «Заказ в копейки»
  объект «Счёт» отображается в «Счёт в копейках» даёт «Счёт в копейки»
  морфизм «выставить» отображается в морфизм «выставить в копейках»
```

Множества: буквы слов как множества строк, их пересечение и вложение. На рисунке —
круги Эйлера — Венна с буквами в своих областях.

```flang playground Множества — вложение и пересечение
модуль «Буквы»

тотальная функция «Гласные»
  возвращает список строки
  ["а", "е", "и", "о", "у"]

тотальная функция «Буквы слова мир»
  возвращает список строки
  ["м", "и", "р"]

тотальная функция «Буквы слова ум»
  возвращает список строки
  ["у", "м"]

тотальная функция «Пересечение»
  принимает первое: список строки, второе: список строки
  возвращает список строки
  отфильтровать первое где э → второе содержит э

тотальная функция «Вложение»
  принимает меньшее: список строки, большее: список строки
  возвращает признак
  (длина (отфильтровать меньшее где э → не (большее содержит э))) равна 0

утверждение «общие буквы мира и гласных — гласные»
  утверждаем «Вложение» от («Пересечение» от («Буквы слова мир») и («Гласные»)) и («Гласные»)

утверждение «у слов мир и ум общая только м»
  утверждаем («Пересечение» от («Буквы слова мир») и («Буквы слова ум»)) равно ["м"]
```

Формула с кванторами в LaTeX: коммутативность сложения целых. Откройте её в сетапе
«Формула».

```text playground Формула ∀ в LaTeX
\forall x \in \mathbb{Z},\ \forall y \in \mathbb{Z},\ x + y = y + x
```

Формула с кванторами в записи Юникода: умножение целых перестановочно.

```text playground Формула ∀ — умножение перестановочно
∀ x ∈ ℤ, ∀ y ∈ ℤ, x * y = y * x
```

Функция на C с `bool`: проверка, читается ли число одинаково слева направо и справа
налево. `bool` становится признаком flang, `false` — значением `нет`. Перевод записывает
условия: делитель не ноль, умножение и сложение не выходят за границы `int`. Про цикл
`while` ответ честно говорит, что его завершение flang сам не доказал, поэтому доказанное
доказано при условии, что цикл закончился; часть условий о границах `int` остаётся
недоказанной.

```c playground Палиндром на C — bool и цикл
#include <stdbool.h>

bool isPalindrome(int x) {
    if (x < 0 || (x % 10 == 0 && x != 0)) {
        return false;
    }
    int reversed = 0;
    while (x > reversed) {
        reversed = reversed * 10 + x % 10;
        x /= 10;
    }
    return x == reversed || x == reversed / 10;
}
```

Функция на C, переведённая во flang. `clamp` доказывается целиком. У `midpoint`
условие «`lo + hi` не выше INT_MAX» ядро не доказывает, и тогда песочница считает
функцию на границах `int`: при `lo = hi = 2147483647` условие нарушено. Это настоящая
ошибка C, и перевод её не прячет.

```c playground Функция на C — перевод во flang
int clamp(int x, int lo, int hi)
{
    if (x < lo)
        return lo;
    if (x > hi)
        return hi;
    return x;
}

int midpoint(int lo, int hi)
{
    return (lo + hi) / 2;
}
```

Утверждение следствия: из «все люди смертны» и «Сократ смертен» не следует, что
Сократ — человек. Песочница показывает контрпример.

Функции на Python, переведённые во flang. Целые числа в Python не ограничены сверху,
поэтому перевод не добавляет границ. Большее из двух чисел доказывается целиком:

```python playground Python — большее из двух
def max_of_two(a: int, b: int) -> int:
    if a > b:
        return a
    return b
```

Число-палиндром: цикл `while` кончается, потому что `x` уменьшается на каждом
`x //= 10`. Ядро этого само не выводит, поэтому конец цикла остаётся без доказательства и
проверяется во время работы; страница пишет «доказано не всё».

```python playground Python — число-палиндром
def is_palindrome(x: int) -> bool:
    if x < 0 or (x % 10 == 0 and x != 0):
        return False
    rev = 0
    while x > rev:
        rev = rev * 10 + x % 10
        x //= 10
    return x == rev or x == rev // 10
```

Сумма от 1 до n циклом `for` по `range`. Её конец тоже проверяется во время работы:

```python playground Python — сумма от 1 до n
def sum_to(n: int) -> int:
    total = 0
    for i in range(1, n + 1):
        total += i
    return total
```

## Как это устроено

Во вкладке работают те же программы, что и в терминале, собранные в WebAssembly:
компилятор `flang` с ядром доказательств и программа независимой проверки `checker`.
Запускаются они в отдельном потоке, поэтому страница не замирает.

Файлы лежат в памяти вкладки: ваш текст, временный каталог и библиотека. Библиотеку
песочница скачивает, только если в тексте есть `использует`.

Первый запуск скачивает компилятор, около 10 МБ; справа показана доля скачанного. Дальше
он берётся из кеша браузера. Пределы запуска: 3 000 000 шагов на вычисление и 120 секунд на
команду.

## Чего в песочнице нет

- **Процессов.** В WebAssembly нет `fork` и `exec`, поэтому компилятор не может сам
  запустить независимую проверку; её запускает обвязка следом, вторым модулем.
- **Сети и файлов машины.** Сокетов нет, файлы — только в памяти вкладки.
- **Независимой проверки программ с `использует`.** Ей нужны записи доказательств
  ввезённых модулей; песочница их не строит.
- **Квадратов естественных преобразований на рисунке.** Компоненты преобразования
  (`морфизм … из функтора … в функтор …`) не попадают в дерево разбора `flang ast`, и
  нарисовать квадрат не из чего; отметка закона при этом есть в итоге.
- **64-битного адреса.** Модуль собран под `wasm32`: памяти не больше 4 ГиБ, а
  вшитый предел шагов 8·10¹² в 32-битный `size_t` не влезает и становится
  2 770 894 848 — об этом при сборке предупреждает `clang`.
