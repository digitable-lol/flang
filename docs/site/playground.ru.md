# Песочница

Здесь flang проверяет текст прямо во вкладке: силлогизм, записанный словами, формулу с
кванторами ∀ и ∃ или программу на flang с утверждениями, теоремами и законами.
Компилятор с ядром доказательств собран в WebAssembly и работает в браузере; на сервер
не уходит ничего, а ссылка «Поделиться» несёт текст в адресе после `#`, который браузер
серверу не отправляет.

```playground
Песочнице нужен JavaScript и браузер с WebAssembly. Без них те же проверки делает
двоичный компилятор: flang check файл.flang --proof.
```

## Что вы увидите

Ответ разложен по четырём вкладкам.

- **Итог** — одна строка о главном и список утверждений с отметками:
  - «Доказано для всех значений» — каждое утверждение верно на всех входах, а не только
    на написанных примерах;
  - «Проверено только на примерах» — нарушений не нашлось, но для остальных значений
    это не доказательство;
  - «Не следует: вот контрпример» — показан вход, на котором утверждение ложно;
  - «Не доказано» — у утверждения нет ни доказательства, ни примеров;
  - «Ошибка в строке N» — строка отмечена в редакторе, по кнопке с номером курсор
    встаёт на неё.

  Под итогом свёрнуты подробности: что сказала независимая проверка доказательства и
  полный вывод компилятора, как в терминале.
- **Формулы** — каждое утверждение программы записью с кванторами и в LaTeX.
- **Формула → flang** — поле для формулы с ∀ / ∃ или в LaTeX: она переводится на flang и
  сразу проверяется.
- **Рисунки** — диаграммы того, что объявлено: объекты и стрелки категории, квадраты
  функтора, законы моноида, круги Эйлера — Венна для множеств и дерево доказательства.
  У каждого рисунка стоит отметка «доказано», «на примерах» или «нарушено».

## Что во что превращается

Песочница сама решает, что перед ней, по началу текста.

- Текст начинается с `модуль` или `категория` — это программа на flang. Её проверяет
  `flang check --proof --json`; итог собирается из машинного ответа компилятора, а не из
  его текста.
- Текст начинается с `∀`, `∃`, `\forall` или `\exists` — это формула. Переводчик
  формул (`flang/foreign/formula`) делает из неё утверждение flang, и его проверяет
  ядро. Если формула не читается, переводчик называет причину: «цепочка сравнений без
  скобок неоднозначна», «ℝ в flang нет» и так далее.
- Любой другой текст — рассуждение по-русски: словарь (`Понятие:`, `Свойство:`,
  `Имя:`), посылки и заключение после слова «Следовательно». Переводчик
  `flang/proof/probes/syllogism/sentences/translator.flang` строит из него программу, а
  ядро решает, следует ли заключение из посылок.

После ядра запись доказательства проигрывает заново отдельная программа
(`flang/proof/checker/checker.c`, тоже в WebAssembly). Если она сошлась, доказанное
стоит не только на слове компилятора.

## Примеры

Силлогизм Barbara: заключение выводится из посылок.

```text playground Силлогизм Barbara — следует
Понятие: человек, люди.
Понятие: грек, греки.
Свойство: смертен, смертны.

Все люди смертны. Все греки — люди. Следовательно, все греки смертны.
```

Теорема о списке: сумма пустого списка — ноль, длина списка не отрицательна, а
приписанный в начало элемент удлиняет список на один. Всё доказано для всех списков.

```flang playground Теорема о списке
модуль «Списки»

тотальная функция «Сумма»
  принимает л: список число
  возвращает число
  разбор л
    случай пусто
      то 0
    случай голова и хвост
      то голова плюс («Сумма» от хвост)

утверждение «сумма пустого списка — ноль»
  утверждаем («Сумма» от пустой список) равна 0

утверждение «длина списка не отрицательна»
  для всех л: список число
  утверждаем (длина л) не меньше 0

утверждение «приписанный элемент удлиняет список на один»
  для всех л: список число
  для всех э: число
  утверждаем (длина (приписать э к л)) равна ((длина л) плюс 1)
```

Моноид с законами: склейка строк ассоциативна, а пустая строка — её единица. Законы
моноида компилятор проверяет на значениях из примеров операции; на рисунке — квадрат
ассоциативности и треугольники единицы.

```flang playground Моноид с законами
модуль «Склейка строк»

тотальная функция «Склеить»
  принимает а: строка, б: строка
  возвращает строка
  пример «два слова»
    дано а равно "мир"
    дано б равно "ок"
    ожидается "мирок"
  пример «с пустой строкой»
    дано а равно ""
    дано б равно "ум"
    ожидается "ум"
  соединить [а, б] по ""

моноид «Склейка»
  носитель строка
  операция «Склеить»
  единица ""
```

Категория с квадратом: функтор переводит рубли в копейки, и квадрат «выставить счёт,
потом перевести» = «перевести, потом выставить» обязан коммутировать.

```flang playground Категория с квадратом
  запись «Счёт в копейках» с копейки равным (заказ.копейки плюс 1000)

тотальная функция «Заказы равны»

  а.рубли равен б.рубли

  возвращает признак

тотальная функция «Счета в копейках равны»

  возвращает «Заказ в копейках»

  запись «Заказ в копейках» с копейки равным (заказ.рубли умножить на 100)
```

Множества: буквы слов как множества строк, их пересечение и вложение. На рисунке —
круги Эйлера — Венна с буквами в своих областях.

```flang playground Множества — вложение и пересечение
модуль «Буквы»

тотальная функция «Гласные»
  возвращает список строки
  ["а", "е", "и", "о", "у"]

тотальная функция «Буквы слова мир»
  возвращает список строки
  ["м", "и", "р"]

тотальная функция «Буквы слова ум»
  возвращает список строки
  ["у", "м"]

тотальная функция «Пересечение»
  принимает первое: список строки, второе: список строки
  возвращает список строки
  отфильтровать первое где э → второе содержит э

тотальная функция «Вложение»
  принимает меньшее: список строки, большее: список строки
  возвращает признак
  (длина (отфильтровать меньшее где э → не (большее содержит э))) равна 0

утверждение «общие буквы мира и гласных — гласные»
  утверждаем «Вложение» от («Пересечение» от («Буквы слова мир») и («Гласные»)) и («Гласные»)

утверждение «у слов мир и ум общая только м»
  утверждаем («Пересечение» от («Буквы слова мир») и («Буквы слова ум»)) равно ["м"]
```

Формула с кванторами в LaTeX: коммутативность сложения целых. Её же можно ввести на
вкладке «Формула → flang».

```text playground Формула ∀ в LaTeX
\forall x \in \mathbb{Z},\ \forall y \in \mathbb{Z},\ x + y = y + x
```

Утверждение следствия: из «все люди смертны» и «Сократ смертен» не следует, что
Сократ — человек. Песочница показывает контрпример.

```text playground Утверждение следствия — не следует
Понятие: человек, люди.
Свойство: смертен, смертны.
Имя: Сократ.

Все люди смертны. Сократ смертен. Следовательно, Сократ — человек.
```

Утверждение о своём типе, доказанное индукцией; на вкладке «Рисунки» — дерево
доказательства: база, шаг и правило каждого случая.

```flang playground Утверждение с теоремой — индукция по типу
модуль «Своё натуральное»

тип «Нат»
  вариант «Ноль»
  вариант «Следующий» содержит пред: «Нат»

тотальная функция «К числу»
  принимает н: «Нат»
  возвращает число
  разбор н
    случай вариант «Ноль»
      то 0
    случай вариант «Следующий» с пред как п
      то («К числу» от п) плюс 1

утверждение «шаг растит счёт на один»
  для всех н: «Нат»
  утверждаем («К числу» от (вариант «Следующий» с пред равным н)) равно ((«К числу» от н) плюс 1)

теорема «шаг растит счёт на один»
  дано н: «Нат»
  утверждаем («К числу» от (вариант «Следующий» с пред равным н)) равно ((«К числу» от н) плюс 1)
  индукция по н
    случай вариант «Следующий» с пред как п
      то по предположению
  следовательно доказано
```

Функция с постусловием: обещание `обеспечивает` доказывается для всех входов.

```flang playground Функция с постусловием
модуль «Привет»

тотальная функция «Удвоить»
  принимает н: неотрицательное
  возвращает число
  обеспечивает «удвоенное не меньше исходного» результат не меньше н
  пример «дважды два»
    дано н равно 2
    ожидается 4
  н плюс н
```

Ложное утверждение: при `н = 0` удвоение не больше исходного. Доказательства нет, и
песочница отвечает «Не доказано».

```flang playground Ложное утверждение — не доказано
модуль «Ложное»

утверждение «удвоение всегда больше»
  для всех н: неотрицательное
  утверждаем (н плюс н) больше н
```

У блоков программ на flang на других страницах документации стоит ссылка «запустить в
песочнице»: она открывает эту страницу с текстом блока в адресе.

## Как это устроено

| что | где | чем собрано |
|---|---|---|
| компилятор с ядром | `playground/flang.wasm` | `bootstrap/*.c`, `clang --target=wasm32-wasi` |
| независимая проверка доказательств | `playground/checker.wasm` | `flang/proof/checker/checker.c`, тем же `clang` |
| переводчик рассуждений | `playground/reasoning.js` | `bootstrap/flang emit --target js` |
| переводчик формул | `playground/formula.js` | `flang/foreign/formula/browser.fscript`, `bootstrap/flang emit --target js` |
| библиотека | `playground/library.tar` | `flang/stdlib/*.flang` и `flang/core/*.flang` |
| обвязка WASI | `playground/flang_host_browser.js` | `flang/src/emit/js/flang_host_browser.js` |
| страница песочницы | `playground.js` | `docs/site/playground.js` |

Файлы каталога `playground/` собирает шаг сборки сайта (`bootstrap/flang run-script
playground:build`); в дереве их нет. Обвязка WASI держит файловую систему в памяти
вкладки: исходник пользователя, библиотеку (её песочница скачивает, только если в
тексте есть `использует`) и временный каталог `/tmp`. Компилятор работает в отдельном
потоке (Web Worker), страница при этом не замирает.

Подсветка в редакторе берёт ключевые слова из таблицы лексера
(`flang/self/lexer.flang`, функция «Куски таблицы»): сборка сайта кладёт их на страницу,
второго списка слов нет. Формулы в LaTeX рисует KaTeX, его страница берёт с
`cdn.jsdelivr.net`; без сети формула остаётся исходником LaTeX. Рисунки — SVG, который
страница строит сама из дерева разбора (`flang ast`) и машинного ответа компилятора.

Та же обвязка работает и под Node, без браузера:

```sh
node flang/src/emit/js/flang_host_browser.js docs/site/out/playground "$(cat текст.txt)"
node flang/src/emit/js/flang_host_browser.js docs/site/out/playground --json "$(cat текст.txt)"
```

Код возврата у неё тот же, что у проверки: 0 — следует или доказано, 1 — не следует,
3 — не доказано. С `--json` она печатает весь разобранный ответ — тот, из которого
страница строит итог и рисунки.

Этим путём сборка сайта и пробует песочницу (`bootstrap/flang run-script playground:probe`,
план `scripts/site/playground-probe.fscript`): Barbara обязана «следовать», и
независимая проверка обязана сойтись с записью; утверждение следствия — «не следует» с
кодом 1; ложное утверждение — код 3 и ни одного «доказано»; формула в LaTeX — перевод на flang,
доказательство и сошедшаяся независимая проверка.

## Чего в песочнице нет

- **Процессов.** В WebAssembly нет `fork` и `exec`, поэтому компилятор не может сам
  запустить независимую проверку; её запускает обвязка следом, вторым модулем.
- **Сети и файлов машины.** Сокетов нет, файлы — только в памяти вкладки.
- **Независимой проверки программ с `использует`.** Ей нужны записи доказательств
  ввезённых модулей; песочница их не строит.
- **Квадратов естественных преобразований на рисунке.** Компоненты преобразования
  (`морфизм … из функтора … в функтор …`) не попадают в дерево разбора `flang ast`, и
  нарисовать квадрат не из чего; отметка закона при этом есть в итоге.
- **64-битного адреса.** Модуль собран под `wasm32`: памяти не больше 4 ГиБ, а
  вшитый предел шагов 8·10¹² в 32-битный `size_t` не влезает и становится
  2 770 894 848 — об этом при сборке предупреждает `clang`.
