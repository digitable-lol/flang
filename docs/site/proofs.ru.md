# Что такое доказательство во flang

Страница отвечает на вопрос: что значит слово «доказано» в выводе компилятора
и когда оно вам нужно. Читать пять минут. Попробовать то же руками по шагам —
урок [Первое доказательство](first-proof.html).

## Тест и доказательство

Тест проверяет входы, которые вы придумали. Доказательство отвечает про все
входы сразу. Во flang оба пишутся внутри функции:

| Строка | Что это | В других языках |
| --- | --- | --- |
| `пример` | тест с конкретными аргументами | unit-тест |
| `требует` | предусловие: что обязан обеспечить вызывающий | `requires` в Dafny |
| `обеспечивает` | постусловие: что верно для результата | `ensures` в Dafny |

Файл `docs/examples/proofs/discount.flang`:

```flang insert docs/examples/proofs/discount.flang
модуль «Discount»

тотальная функция «Цена со скидкой»
  принимает цена: неотрицательное, скидка: неотрицательное
  требует «скидка не больше цены» скидка не больше цена
  возвращает число
  обеспечивает «в минус не уходим» результат не меньше 0
  пример «сто минус десять»
    дано цена равно 100
    дано скидка равно 10
    ожидается 90
  цена минус скидка
```

```bash
flang check discount.flang --proof
```

```
постусловие «в минус не уходим» функции «Цена со скидкой» — доказано по
объявленным типам аргументов: цель сведена правилом «неотрицательность по
построению» — утверждение обо ВСЕХ входах, а не о написанных; теоремы при
нём нет и не нужно
```

Тест говорит про один вход: 100 и 10. Строка «доказано» говорит про любую цену
и любую скидку не больше цены. Доказательство нашёл компилятор. От вас
понадобились типы аргументов и строка `требует`.

Часть компилятора, которая ищет доказательства, называется ядром доказательств,
дальше — «ядро». Оно работает по закрытому списку правил. У ядра 20 правил.
Название правила стоит в выводе: здесь это «неотрицательность по построению».

## Четыре ответа компилятора

На каждое постусловие компилятор даёт один из четырёх ответов:

| В выводе | Что это значит | Что делать |
| --- | --- | --- |
| `доказано` | верно для всех входов объявленных типов | ничего |
| `сетка N` | прошло на N тестах, доказательства нет | [доказать или оставить проверкой](proof-refused.html) |
| `объявлено, не доказано` | нет ни доказательства, ни тестов | то же |
| `FLANG_PROPERTY … нарушено на входе` | найден вход, на котором постусловие ложно | исправить код или постусловие |

Словом «сетка» компилятор называет ответ «проверено только на тестах».

Последний ответ — ошибка: файл не проходит проверку. Как компилятор сам
находит такой вход и как это исправить предусловием — разделы 1 и 2 урока
[Первое доказательство](first-proof.html).

Предусловие проверяется при компиляции в каждом месте вызова. Во время
выполнения — один раз, там, где данные приходят снаружи. Недоказанное
постусловие проверяется при каждом возврате из функции, и `flang run` запускает
такую программу только с ключом `--trust`.

Доказанное постусловие в сгенерированный код не попадает, если у функции есть
хотя бы один `пример`. У функции без тестов проверка остаётся и для
доказанного постусловия.

## Когда доказательство нужно

Пишите постусловие там, где ошибка стоит дорого, а условие короткое:

- границы: сумма не отрицательна, индекс внутри списка, процент не больше ста;
- длины: результат той же длины, что и вход;
- разбор вариантов: каждому входу соответствует ответ;
- деньги и счётчики на точных типах: `неотрицательное`, `точное целое`.

Тестом обойдитесь там, где свойство длинное или ядро его не выводит: порядок
после сортировки, свойства чисел с плавающей точкой, работа с внешним миром.

## Чего «доказано» не значит

Доказательство связывает код с постусловием. Верно ли постусловие описывает
задачу, решаете вы: функция, которая всегда возвращает 0, тоже проходит
проверку «результат не меньше 0».

За словом «доказано» стоят ядро, компилятор и компилятор C. Часть доказательств
повторяет вторая, независимая программа. Какая часть и где у проверки известная
ошибка — [Чему вы доверяете](trust.html).

flang не заменяет Lean или Coq. Он доказывает пред- и постусловия программ;
произвольные теоремы ему недоступны. Сравнение —
[flang для знающих Lean и Dafny](flang-for-lean-and-dafny-users.html).
