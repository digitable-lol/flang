# Реестр пакетов

Реестр flang — это **список имён**, а не склад кода. Список — строчный файл:
в каждой строке пять полей через знак «|», и больше в ней ничего нет. На вопрос
«какая версия пакета годится» реестр отвечает **адресом**, по которому лежит
пакет, а не самим пакетом; имя получает версию только здесь, в списке; ни одного
нового слова в языке реестр не заводит. Ни сервера, ни базы, ни учётных записей
для этого не нужно — и по решению их нет. Довод целиком:
[ADR-0059](../adr/0059-the-registry-is-a-ledger-of-names-not-a-store-of-code.md).

## Список лежит файлом по постоянному адресу

```
https://digitable-lol.github.io/flang/registry.list
```

Это обычный файл, раздаваемый по HTTP. Программа на flang берёт его тем
поручением, которое у языка уже есть, — «Запросить»:

```
вариант «Запросить» с способ равным "GET"
  и адрес равным "https://digitable-lol.github.io/flang/registry.list"
  и тело равным ""
```

На сайте лежит копия того же файла из дерева
[`scripts/registry-example/registry.list`](../../scripts/registry-example/registry.list)
— знак в знак, и кладёт её туда та же сборка, что печатает эту страницу.

## Пять полей

| поле | что в нём |
|---|---|
| имя | имя пакета — то, что стоит в `использует` |
| версия | три числа через точку: старшая, средняя, младшая |
| отпечаток | `sha256` файла пакета |
| адрес | где лежит файл пакета |
| нужды | чего пакет требует от других имён; пусто — ничего |

Нужда пишется как `имя: диапазон`, нужды разделяются точкой с запятой.
Диапазонов четыре: `любая`, `ровно 1.2.3`, `не ниже 1.2.3`, `в пределах 1.x`.
Разбор списка и выбор версии написаны и доказаны в
[`flang/stdlib/registry.flang`](../../flang/stdlib/registry.flang); сдаётся выбор
прогоном плана, а не командой двоичного — нового слова реестр не заводит нигде.

## Отпечаток сверен с файлом при печати

Отпечаток — единственное, на чём держится доверие к чужому пакету, и портится
он молча. Поэтому тот же прогон, который печатает таблицу, пересчитывает
`sha256` каждого адреса и сличает с полем «отпечаток». Разошёлся хоть один
знак — страница не печатается вовсе: прогон отвечает числом выхода 1 и
`FLANG_REESTR_OTPECHATOK`, называет запись, оба отпечатка и адрес, а сборка
сайта краснеет на нём и до читателя не доезжает.

Проверка заведена не впрок: отпечатки в примере однажды разошлись с
файлами, и увидеть это было некому — реестр не звала ни одна работа сборки
(задача [4909](../tasks/4909-the-registry-resolution-rule-has-no-guard-and-example-fingerprints-rotted.md)).
