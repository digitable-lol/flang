# Роадмап

Здесь нет сроков — ни кварталов, ни дат. Порядок и зависимости названы, потому
что они известны; сроки не названы, потому что они неизвестны, и обещание без
покрытия хуже молчания.

Каждое число ниже получено прогоном, и рядом стоит команда, которая его печатает.
Перемерьте, если не верите. Бинарник при этом мерьте **в чистом каталоге**:
собранный лежит рядом с исходниками, `make` видит его свежее и отвечает «nothing
to be done», а замер тогда показывает вчерашний день.

## Сделано

**Ядро доказательства написано на самом flang, аксиом ноль.** Пустота списка
аксиом держится тестом, а не обещанием: тихо добавить аксиому нельзя.

**Корпус измерен, а не оценён** — `node docs/site/site-numbers.mjs`:

| | |
|---|---:|
| Функций в корпусе | 7997 |
| Из них тотальных | 6126 |
| Утверждений высказано | 153 |
| Доказано ядром | 132 |
| Опровергнуто ядром | 0 |
| Аксиом | 0 |

**Печать в восемь целей**: `c`, `csharp`, `elixir`, `go`, `java`, `js`,
`python`, `rust`. **У всех восьми есть близнец на flang** — последний, `js`,
закрыт; без близнеца не осталось ни одной.

**Двоичный собирается одним `cc`, без Node.** Перемерено 18 августа на чистой
выгрузке (`git archive HEAD` в пустой каталог): один вызов компилятора на четыре
файла `.c`, ни одного предупреждения под `-std=c99 -Wall -Wextra -Werror
-pedantic -O2`, ни одной внешней зависимости кроме `libm` и `libpthread`.
Занимает это **71 с** процессорного времени (68,7 пользовательского и 2,5
системного по `/usr/bin/time -v`) и даёт бинарник в **6 999 040 байт**
(cc 15.2.0, Linux 7.0.0). Время плавает с загрузкой машины, байты — нет: тот же
день, та же выгрузка, а ведомость `bootstrap/README.md` намерила ≈90 с при тех
же байтах. Флага `-flto`, который стоит в `Makefile`, при одном вызове не нужно:
единица трансляции и так одна.

**Печать компилятора самим собой сошлась побайтово.** `node
scripts/bootstrap-c.mjs --check` связывает исходники на flang (**3502 функции,
313 типов**), печатает их в C и сверяет с тем, что лежит в `bootstrap/`:
**7 файлов, 12 841 265 байт, расхождений 0**. Сверяются байты, а не сборка,
поэтому проверка идёт всегда и не требует `cc`.

**Вычислитель втянут в двоичный.** `flang run` и `flang test` считают им — без
Node и без `cc`. Проверено на свежесобранном бинарнике: `flang run
flang/stdlib/higher-order.flang --function 'Удвоить' --args '{"х":21}'` печатает
`42`, код возврата 0. Ведомость `check --proof` двоичный печатает сам, и
`emit --target c` — тоже. Оболочка `repl` вычислитель пока **не зовёт**: она
печатает сессию в C и собирает системным `cc`; нет `cc` — не выключается, а
проверяет разбор, типы и завершаемость и говорит об этом при запуске. Разница
названа, потому что «есть оболочка» и «есть вычислитель» — разные обещания.

**Что двоичный умеет, перечнем.** Снято прогоном бинарника, собранного в чистом
каталоге, а не взято из справки: `check`, `test`, `run`, `emit`, `repl`,
`--help`, `--version`, и без аргументов — прогонщик JSON на входе и JSON на
выходе. Прогнано по одной:

| команда | прогон | ответ |
|---|---|---|
| `check` | `check flang/stdlib/higher-order.flang` | функций 34, с доказанным завершением 34; замечаний нет |
| `check --proof` | то же с `--proof` | **ведомость печатается**: 65 строк против 2 без ключа |
| `test` | `test flang/stdlib/higher-order.flang` | примеров 55, прошло 55, не прошло 0 |
| `run` | `run … --function 'Удвоить' --args '{"х":21}'` | `42`, код 0 |
| `emit` | `emit flang/examples/rosetta/merge-sort.flang --target c` | напечатано файлов 6, байт 277 469; собралось `make` |
| `repl` | `repl` без `cc` | не выключается, проверяет разбор, типы и завершаемость |

`--proof` **больше не пропускается молча** — это было верно ещё утром
18 августа и перестало быть верным к вечеру. У `emit` из бинарника одна
названная граница: таблицу объявленных типов строит слой эталона, поэтому
аргументы прогонщика объявленным типам не сверяются, и бинарник об этом
говорит сам, а не молчит.

**Своя альтернатива OTP**: процессы, надзор, горячая замена, планировщик.

**Четыре поверхности записи** — русская, английская, эсперанто, китайская. Из
149 понятий словаря на всех четырёх открыто 132; дырявых понятий 17, и они
названы поимённо (`npm run surfaces:check`, `npm run glossary:check`).

**Кода на flang** — 116 303 строки в 753 файлах:
`find . -name '*.flang' | xargs cat | wc -l`.

## Делается сейчас

**Граница входа у напечатанной программы.** Сам двоичный аргументы типам уже
сверяет: `Факториал` объявлен на `нат`, и на −3 он отвечает
`FLANG_TYPE: аргумент «н»: -3 вне нат` с кодом 1, как эталон. А вот у
программы, напечатанной через `emit`, эта граница пуста: таблицу объявленных
типов строит слой типов эталона, которого в двоичном нет, и двоичный
предупреждает об этом прямо при печати. Пока не сведено — за вход напечатанной
программы отвечает вызывающий.

**Английская версия сайта.** Собственные страницы сайта переведены; страницы
руководства, замеров и спецификаций — пока только по-русски.

## Не начато

Это главная часть страницы. Ниже — то, чего нет, и порядок, в котором оно
блокирует друг друга.

**Пакетов нет вовсе.** Библиотека подключается относительным путём
(`использует «Модуль» из "путь"`). Нет версий, нет замка́, нет воспроизводимой
сборки. Это блокирует всё, что ниже: библиотеку без пакетов нельзя ни раздать,
ни обновить.

**Библиотека мала**: 13 файлов, 5110 строк (`ls flang/stdlib/*.flang`). Нет
сети, нет времени, нет базы данных. Список того, что есть, короче списка того,
чего нет.

**Прикладного кода почти нет.** Бэкенд — один пример на 7 файлов и 563 строки
(`examples/library-api`). Фронтенд — демонстрация в браузере, а не приложение.

## Решено не делать

Отказ — это решение, и у каждого есть довод. Если довод рухнет, рухнет и отказ.

**Замыканий не будет.** Захват окружения ломает анализ завершаемости и прямую
печать в C, Go и Rust. Функции первого класса при этом есть — через
дефункционализацию (Reynolds, 1972): компилятор заменяет функцию-значение меткой
и разбором по меткам. Так написана `flang/stdlib/higher-order.flang`. Замыкание
и функция первого класса — разные вещи, и отвергнута только первая.

**Двух версий одной библиотеки в одной программе не будет.** Ромб зависимостей
решается подъёмом версии, а не сосуществованием. Довод разобран в
[Модульности и пакетах](modules.html).

**Полной модели Unison не будет.** Хранить код в базе вместо файлов значит
завести собственный редактор, собственный хостинг и потерять git. Половину
Unison — адресацию по содержимому — берём; вторую половину не берём, и причина
названа там же.

## Что здесь не обещано

Ни одного срока. Порядок работ — да, зависимости — да, даты — нет.

Страница обновляется вместе с деревом: числа на ней сторожит
`npm run numbers:check`, а `npm run site:check` не даст ей уехать без
английской пары.
