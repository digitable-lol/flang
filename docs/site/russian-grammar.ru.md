# Грамматика русского на прегруппах

Здесь показано, как на flang разобрать русское предложение: у каждого слова есть
тип, типы перемножаются, и предложение грамматично, если произведение
сворачивается в один тип `s` — «предложение». Это прегрупповая грамматика
Ламбека. Программа лежит в `flang/ct/russian/`.

Входов два. `«Разобрать»` из `parse.flang` отвечает одним вердиктом на простое
предложение из слов своего словаря. `«Разборы»` из `sentence.flang` читает
предложения научной прозы: с предложными группами в любом месте, однородными
членами, придаточными, оборотами, скобками и числами — и возвращает все
разборы, а не один.

## Разобрать предложение статьи

```
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"В статье раскрываются основные вопросы."}'
доказано: утверждений 9
"разборов 1: в: r · n[предл ж ед 3]ˡ; статье: n[предл ж ед 3]; раскрываются: rʳ · s[мн 3] · n[им мн 3]ˡ; основные: a[им мн]; вопросы: a[им мн]ʳ · n[им мн 3]; связи: вопросы→основные определение, раскрываются→вопросы подлежащее, в→статье предлог, раскрываются→в обстоятельство"
```

Первая строка — сколько утверждений о программе доказано; `run` выводит её
перед ответом. В ответе три части: сколько разборов, тип каждого слова и связи.
Связь пишется «главное→зависимое роль»: `раскрываются→вопросы подлежащее`.

Если предложение читается несколькими способами, возвращаются все. Здесь
предложная группа относится либо к глаголу, либо к существительному:

```
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"Мама в доме читает книгу."}'
доказано: утверждений 9
"разборов 2: мама: n[им ж ед 3]; в: r · n[предл м ед 3]ˡ; доме: n[предл м ед 3]; читает: rʳ · n[им ж ед 3]ʳ · s[ед 3] · n[вин ж ед 3]ˡ; книгу: n[вин ж ед 3]; связи: читает→книгу дополнение, в→доме предлог, читает→в обстоятельство, читает→мама подлежащее || мама: n[им ж ед 3] · rˡ; в: r · n[предл м ед 3]ˡ; доме: n[предл м ед 3]; читает: n[им ж ед 3]ʳ · s[ед 3] · n[вин ж ед 3]ˡ; книгу: n[вин ж ед 3]; связи: читает→книгу дополнение, в→доме предлог, мама→в предложное определение, читает→мама подлежащее"
```

Разборы разделены знаком `||`. Программа не выбрасывает ни одного, но ставит
их по порядку: первым идёт предпочтительный. Предпочтение простое — меньше
сумма расстояний между связанными словами; дороже стоят дополнение перед
сказуемым, подлежащее после него, предложная группа при существительном,
приложение и сказуемое без связки. Это догадка о порядке, а не выбор: остальные
разборы идут следом.

Слово вывода получает свою связь. По ней шаг рассуждения видно без словаря:

```
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"Следовательно, система работает."}'
доказано: утверждений 9
"разборов 1: следовательно: вывод; система: n[им ж ед 3]; работает: n[им ж ед 3]ʳ · s[ед 3]; связи: работает→система подлежащее, система→следовательно вывод"
```

## Когда разбора нет

Ответ называет причину и слово, на котором разбор остановился:

```
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"Мама читает книга."}'
доказано: утверждений 9
"не разобрано: неверный падеж, слово «книга»"
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"Автор рассматривает систему, который решает задачу."}'
доказано: утверждений 9
"не разобрано: нет согласования по роду, числу или лицу, слово «решает»"
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"Мама читает куздру."}'
доказано: утверждений 9
"не разобрано: неизвестное слово, слово «куздру»"
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать подробно»' --args '{"предложение":"Мама книгу."}'
доказано: утверждений 9
"не разобрано: нет сказуемого"
```

| Причина | Что значит |
| --- | --- |
| `неизвестное слово` | у слова нет признаков: его нет ни в закрытых списках, ни в словаре |
| `нет сказуемого` | нет ни глагола, ни краткой формы, ни тире, ни «это» |
| `нет согласования по роду, числу или лицу` | без проверки согласования предложение разбирается |
| `неверный падеж` | без проверки падежей предложение разбирается |
| `неверный падеж и нет согласования` | разбирается только без обеих проверок |
| `слова не связываются в предложение` | слова известны, но целого разбора нет |
| `превышен предел работы` | разбор остановлен: предложение слишком многозначно |
| `предложение длиннее предела` | в предложении больше 60 слов |

Причины про согласование и падеж ищутся только в предложениях до 12 слов. В
длинном предложении без этих проверок разбирается почти всё, и такая причина
ничего бы не говорила.

Слово, названное в ответе, — первое, до которого не дотянулся ни один кусок
разбора, начатый с начала предложения. Часто это место ошибки, но не всегда.

## Ответ для программы

`«Разборы»` возвращает тот же ответ значением, а не строкой:

```
$ flang run flang/ct/russian/sentence.flang --function '«Разборы»' --args '{"предложение":"Система не является проблемой."}'
доказано: утверждений 9
{"вариант":"Разобрано","разборы":[{"слова":["система","не","является","проблемой"],"леммы":["система","не","являться","проблема"],"части":["сущ","частица перед","глагол","сущ"],"типы":["n[им ж ед 3]","частица перед","n[им ж ед 3]ʳ · s[ед 3] · n[тв ж ед 3]ˡ","n[тв ж ед 3]"],"строй":[[{"вид":"n","падеж":"им","род":"ж","число":"ед","лицо":"3","сопряжение":0}],[],[{"вид":"n","падеж":"им","род":"ж","число":"ед","лицо":"3","сопряжение":1},{"вид":"s","падеж":"*","род":"*","число":"ед","лицо":"3","сопряжение":0},{"вид":"n","падеж":"тв","род":"ж","число":"ед","лицо":"3","сопряжение":-1}],[{"вид":"n","падеж":"тв","род":"ж","число":"ед","лицо":"3","сопряжение":0}]],"связи":[{"главное":3,"зависимое":4,"роль":"дополнение в творительном"},{"главное":3,"зависимое":1,"роль":"подлежащее"},{"главное":3,"зависимое":2,"роль":"частица перед"}]}],"сверх":{"цены":[3],"пометы":[["","","отрицание",""]],"вид":"предложение"},"всего":1,"работа":4}
```

| Поле | Что в нём |
| --- | --- |
| `разборы` | список разборов; о полях разбора — ниже |
| `всего` | сколько разборов у предложения на самом деле |
| `работа` | сколько пар кусков предложения пришлось сравнить |
| `сверх` | по разборам: `цены` — цена разбора, по которой они упорядочены, и `пометы` слов — `отрицание`, `заглавное`, `имя`, `сравнение`; `вид` — `предложение` или `назывное` |

В каждом разборе шесть полей, списки идут по словам предложения:

| Поле разбора | Что в нём |
| --- | --- |
| `слова` | слова предложения строчными буквами |
| `леммы` | начальная форма каждого слова |
| `части` | часть речи; у слова, которое в разборе не участвует, — его роль |
| `типы` | тип слова строкой, как в `«Разобрать подробно»` |
| `строй` | тот же тип списком простых типов: вид, падеж, род, число, лицо и сопряжение (1 — правое, −1 — левое, 0 — сама буква) |
| `связи` | главное слово, зависимое слово и роль; слова названы номерами с единицы |

`«Разборы»` отдаёт не больше восьми разборов, а `всего` считает все, вместе
с теми, что различаются только чтением слова при тех же связях; такие в список
второй раз не попадают. Больше
отдаст `«Разборы по словарю»` — число разборов у неё третий аргумент. Когда
разбора нет, вариант ответа — `Не разобрано` с полями `причина`, `слово`,
`место` и `работа`.

## Разбор для перевода в логическую форму

Тому, кто строит из разбора логическую форму, удобнее запись по словам. Её
отдаёт `«Разборы для смысла»` (предложение, словарь, сколько разборов выписать):

```
$ flang run flang/ct/russian/sentence.flang --function '«Разборы для смысла по пробному словарю»' --args '{"предложение":"Система не является проблемой."}'
доказано: утверждений 9
{"разборы":[{"слова":[{"слово":"система","лемма":"система","часть":"сущ","тип":[{"вид":"n","падеж":"им","род":"ж","число":"ед","лицо":"3","сопряжение":0}]},{"слово":"не","лемма":"не","часть":"не","тип":[]},{"слово":"является","лемма":"являться","часть":"связка","тип":[{"вид":"n","падеж":"им","род":"ж","число":"ед","лицо":"3","сопряжение":1},{"вид":"s","падеж":"*","род":"*","число":"ед","лицо":"3","сопряжение":0},{"вид":"n","падеж":"тв","род":"ж","число":"ед","лицо":"3","сопряжение":-1}]},{"слово":"проблемой","лемма":"проблема","часть":"сущ","тип":[{"вид":"n","падеж":"тв","род":"ж","число":"ед","лицо":"3","сопряжение":0}]}],"связи":[{"левое":3,"правое":4},{"левое":1,"правое":3}],"роли":["дополнение в творительном","подлежащее"],"стыки":[{"откуда":3,"гнездо":3,"куда":4,"паз":1},{"откуда":1,"гнездо":1,"куда":3,"паз":1}],"пометы":["","","отрицание",""],"приставные":[{"главное":3,"зависимое":2,"роль":"частица перед"}],"цена":3}],"всего":1,"причина":"","слово":"","вид":"предложение"}
```

| Поле | Что в нём |
| --- | --- |
| `слова` | у каждого слова: слово, лемма, часть речи и тип списком простых типов |
| `связи` | пары номеров слов, чьи типы сократились: левое слово и правое |
| `роли` | роль каждой связи, в том же порядке |
| `стыки` | какой простой тип с каким сократился: `откуда` и `гнездо` — левое слово и номер простого типа в его типе, `куда` и `паз` — правое слово и номер в его типе |
| `пометы` | по словам: `отрицание` — перед словом стоит «не», `заглавное` — слово с заглавной буквы не в начале предложения, `имя` — словарь считает слово именем собственным |
| `приставные` | связи слов без типа: частицы, вставки, вводные слова — главное слово, зависимое и роль |
| `цена` | цена разбора; разборы идут от дешёвого к дорогому |

У самой записи есть ещё поле `вид`: `предложение`, `назывное` или пусто, если
разбора нет.

Часть речи здесь уточнена по лемме и по роли: `квантор` («каждый», «все»),
`модальное` («может», «можно», «необходимо»), `связка` («является», «быть»),
`бытийный` («существует»), `местоимение`, `числительное`, `имя` — слово с
пометой `имя` или `заглавное`, `родительный`
— существительное в родительном при другом имени, `сказ_прил` — прилагательное
в составе сказуемого. У слова, которое в разборе не участвует, тип пуст, а
часть речи — само слово для «не», «то», «ни» и роль для остальных.

Местоимение получает тип именной группы, и разбор из-за него не падает: к чему
оно отсылает, грамматика не решает. Единственное число подлежащего она тоже не
толкует: «иерархия затрудняет» — и про одну иерархию, и про всякую.

Единица текста без сказуемого — заголовок, обрывок, строка таблицы — получает
причину `нет сказуемого`. По ней такую единицу отличают от предложения.

## Как читать тип

| Запись | Что значит |
| --- | --- |
| `n[им ж ед 3]` | именная группа: именительный падеж, женский род, единственное число, третье лицо |
| `a[вин мн]` | определение: прилагательное или причастие |
| `s[ед 3]` | сказуемое со всем, что к нему относится |
| `r` | предлог со своей именной группой |
| `d` | наречие |
| `i`, `g` | инфинитив и деепричастие со своими зависимыми |
| `c` | подчинительный союз со своим предложением |
| `&` | сочинительный союз со словом, которое он присоединяет |
| `q` | числительное |
| `aʳ` | ждёт `a` слева: `a · aʳ` сокращается |
| `aˡ` | ждёт `a` справа: `aˡ · a` сокращается |

Тип слова — его собственная буква и по одному сопряжённому на каждое зависимое
слово: слева от буквы стоят те, что ждут зависимое слева, справа — те, что ждут
справа. В `раскрываются: rʳ · s[мн 3] · n[им мн 3]ˡ` глагол ждёт предложную
группу слева и подлежащее справа.

Слова, которые сами в разборе не участвуют, вместо типа несут роль: `частица
перед`, `частица после`, `вставка` (скобки и ссылки вида [12]), `инициал`,
`вводное`, `вывод`, `союз в начале`.

Роли связей: `подлежащее`, `дополнение`, `дополнение в родительном`,
`дополнение в дательном`, `дополнение в творительном`, `именная часть`,
`инфинитив`, `обстоятельство`, `определение`, `обособленное определение`,
`родительное`, `предложное определение`, `приложение`, `количество`,
`предлог`, `союз`, `однородное`, `изъяснительное`, `придаточное`,
`придаточное определительное`, `деепричастный оборот`, `подлежащее при связке`,
`вводное`, `вывод`, `пояснение`, `сравнение`, `содержание`, `косвенная речь`,
`источник`.

Три роли нужны тому, кто строит из разбора смысл. `содержание` — связь союза
«что» с глаголом придаточного: всё, что под ней, — сказанное или подуманное, а
не утверждение автора. `косвенная речь` — связь глагола речи или мысли
(«показал», «считает», «отмечает») с таким придаточным; чьи это слова,
говорит подлежащее глагола. `источник` — «как показывает автор», «по мнению
автора», «согласно данным»: на кого ссылается предложение.

## Что читается

На каждую строку таблицы есть предложения, которые должны разбираться, и
предложения с ошибкой, которые не должны. Все они записаны в таблице
`expected.tsv` набора проб `russian-sentence`.

| Конструкция | Пример |
| --- | --- |
| предложная группа и наречие в любом месте | Автор в статье рассматривает проблему. |
| согласованное определение | Автор рассматривает важную научную проблему. |
| цепочка родительных | Автор рассматривает проблему формирования системы управления. |
| однородные члены с «и», «или», «а также», через запятую | Автор рассматривает проблему, задачу и систему. |
| однородные сказуемые | Автор рассматривает проблему и решает задачу. |
| придаточное с «что» | Автор считает, что система работает. |
| придаточное с «который» | Автор рассматривает систему, в которой работает узел. |
| придаточное с «если», «так как», «поскольку» | Если система работает, то автор решает задачу. |
| причастный оборот | Автор рассматривает вопросы, связанные с эволюцией системы. |
| деепричастный оборот | Рассматривая проблему, автор решает задачу. |
| связка и тире | Система — это узел. Система является проблемой. |
| сказуемое без связки | Дорога мокрая. Сократ не рыба. Если идет дождь, то дорога мокрая. |
| приложение с именем и между тире | Сервис Архив имеет резервную копию. Одно из направлений — сети — переживает становление. |
| парный союз «как …, так и» | Автор рассматривает как систему, так и задачу. |
| «и» в значении «также» | В статье рассматриваются и задачи. |
| сказуемое с мерой | Расходы были равны 10 %. |
| краткая форма и страдательный залог | Задача сложна. Задача была решена автором. |
| отрицание | Автор не решает задачи. |
| вводные слова и слова вывода | Автор, например, рассматривает проблему. Поэтому система работает. |
| скобки и ссылки | Автор рассматривает систему (узел) и задачу. Автор рассматривает систему [12]. |
| числа, единицы, числительные | Автор рассматривает три основных типа систем. Доля системы составляет 10 %. |
| инфинитив при глаголе и при «можно», «необходимо» | Эту задачу можно решать. |
| сравнение | Автор рассматривает систему как узел. Система важнее задачи. |
| устойчивые сочетания | Автор рассматривает систему в качестве узла. |
| пояснение после двоеточия в любом падеже | Автор выделяет три задачи: систему, узел и сеть. Задача решена: система работает. |
| сравнительный оборот с «чем», «более … чем» | Система работает лучше, чем узел. Система более сложна, чем узел. |
| косвенная речь и ссылка на источник | Автор показывает, что система работает. По мнению автора, система работает. |
| назывное и неполное предложение | Введение. Первый узел работает быстро, второй — медленно. |
| обособленное приложение, повтор союза | Автор, брат мамы, читает книгу. Автор рассматривает и систему, и узел, и сеть. |
| перенос внутри слова | Автор рассматривает сис-тему. |

Полный перечень видов конструкций по справочнику — с названием статьи, томом и
страницей, примерами и ответом грамматики — на странице
[«Какие конструкции русского предложения читает грамматика»](https://github.com/digitable-lol/flang/blob/dev/docs/russian-syntax-coverage.md):
из 94 видов читаются 89.

## Откуда берутся признаки слов

Тип слова выводится из его части речи и признаков. У открытых классов —
существительных, прилагательных, глаголов, наречий — признаки даёт словарь:

```
$ flang run flang/ct/russian/sentence.flang --function '«Признаки слова»' --args '{"форма":"задачи"}'
доказано: утверждений 9
[{"лемма":"задача","часть":"сущ","падеж":"род","род":"ж","число":"ед","лицо":"*","время":"*","прочее":"*"},{"лемма":"задача","часть":"сущ","падеж":"им","род":"ж","число":"мн","лицо":"*","время":"*","прочее":"*"},{"лемма":"задача","часть":"сущ","падеж":"вин","род":"ж","число":"мн","лицо":"*","время":"*","прочее":"*"}]
```

У неизвестного слова список пуст. Сейчас `«Признаки слова»` читает маленький
пробный словарь `sample-dictionary.flang`: в нём только слова примеров этой
страницы и проб. Свой словарь передают функции `«Разборы по словарю»`: её
второй аргумент — список строк вида
`форма=лемма,часть,падеж,род,число,лицо,время,пометы`.

```flang fragment
«Разборы по словарю» от "Мама спит." и ["мама=мама,сущ,им,ж,ед", "спит=спать,глагол,*,*,ед,3,наст"] и 8
```

| Поле | Значения |
| --- | --- |
| часть | `сущ`, `мест`, `прил`, `прич`, `кр_прил`, `кр_прич`, `глагол`, `инф`, `деепр`, `нареч`, `комп`, `числ`, `предик` |
| падеж | `им`, `род`, `дат`, `вин`, `тв`, `предл` |
| род, число, лицо | `м`, `ж`, `с`; `ед`, `мн`; `1`, `2`, `3` |
| время | `наст`, `прош`, `буд` |
| пометы | через пробел: `перех` — переходный, `страд` — страдательный, `возвр` — возвратный, `неизм` — несклоняемое, `местоим` — местоименное прилагательное, `сокр` — сокращение |

Звёздочка или пропущенный хвост значит «не задано». У формы с несколькими
чтениями строк несколько.

Словарь можно передать и таблицей: по строке на чтение, десять полей через
пробел — форма, лемма, часть речи полным словом, падеж, род, число, лицо,
время, пометы через запятую, источник. Её читают `«Разборы по таблице
признаков»` и `«Разобрать по таблице признаков»`:

```
$ flang run flang/ct/russian/sentence.flang --function '«Разобрать по таблице признаков»' --args '{"предложение":"Мама спит.","таблица":"мама мама существительное им ж ед * * одуш словарь\nспит спать глагол * * ед 3 наст несов,неперех словарь"}'
доказано: утверждений 9
"разборов 1: мама: n[им ж ед 3]; спит: n[им ж ед 3]ʳ · s[ед 3]; связи: спит→мама подлежащее"
```

Закрытые классы — предлоги с их падежами, союзы, частицы, вводные слова, слова
вывода, устойчивые сочетания — записаны в `lexicon.flang` и словарю не
отдаются. Число, слово латиницей и текст в кавычках считаются именем в любом
падеже. Неизвестное слово с заглавной буквы не в начале предложения — тоже.

## Сколько это стоит

`flang run` перед запуском проверяет саму программу, поэтому одно предложение
занимает около десяти секунд, а длинное — минуты. Для статьи целиком программу
стоит собрать в исполняемый файл:

```
$ flang emit flang/ct/russian/sentence.flang --target c --out build/russian --cli
$ make -C build/russian
$ printf '%s\n' '{"fn":"Разобрать подробно","args":[{"s":"Мама читает книгу."}]}' | build/russian/flang_cli
{"ok":true,"value":{"s":"разборов 1: мама: n[им ж ед 3]; читает: n[им ж ед 3]ʳ · s[ед 3] · n[вин ж ед 3]ˡ; книгу: n[вин ж ед 3]; связи: читает→книгу дополнение, читает→мама подлежащее"}}
```

Собранная программа читает запросы по одному на строку. На двенадцати научных
статьях она отвечала на предложение за 0,17 секунды в середине и не дольше
1,9 секунды, считая запуск процесса.

Для страницы в браузере ту же программу собирают в JavaScript:

```
$ flang emit flang/ct/russian/sentence.flang --target js --out build/russian-js
```

Функции разбора чистые и переводятся без правок. Вызванная внутри процесса,
JavaScript-версия отвечала на те же предложения за 0,02 секунды в середине;
дольше секунды думала над 29 предложениями из 1338, дольше двух — над шестью,
длиной от 33 до 58 слов.

Разбор не зависает. Он считает, сколько пар кусков предложения сравнил, и на
40 000 пар останавливается с причиной `превышен предел работы`. На двенадцати
статьях в предел упёрлись 11 предложений из 1338.

## Что проверено, а что нет

- **Доказано** для всех входов: сопряжение и умножение типов сохраняют длину
  так, как должны, а одна свёртка тип не удлиняет. Это видно в
  `flang check flang/ct/russian/pregroup.flang --proof`: доказано 9 из 9.
  Независимая проверка доказательств (`FLANG_CHECKER`) повторила 2 из них,
  остальные 7 проверены только ядром.
- **Посчитано на примерах:** законы прегруппы — ассоциативность умножения,
  `(aˡ)ʳ = a`, `aˡ · a → 1` — в `flang/ct/russian/category.flang`. Отчёт
  `--proof` по этому файлу: утверждений 7, доказано 0, посчитано на примерах 7;
  код возврата 3.
- **Проверено пробами** простых предложений: 75 предложений, 39 грамматичных
  и 36 нет. Запуск: `flang run-script russian-grammar:probe`.
- **Проверено пробами** научной прозы: 201 предложение на 113 видов
  конструкций, 154 должно разбираться и 47 нет. Запуск:
  `flang run-script russian-sentence:probe`.
- **Замерено на двенадцати научных статьях**, 1338 единиц текста: строка статьи
  или её часть до точки; признаки слов дал словарь OpenCorpora. Со сказуемым
  целиком разобрано 645 единиц. Ещё 285 — заголовки и подписи, которые
  разбираются как назывные предложения; 69 единиц не разобраны и сказуемого не
  имеют: строки таблиц, формулы, списки литературы. 131 единица содержит
  слово, которого нет в словаре. Прежняя `«Разобрать»` на тех же единицах не
  разобрала ни одной.
- **Разборов много.** Из 645 разобранных предложений со сказуемым у 83 разбор
  один, ещё у 381 первый разбор строго предпочтительнее второго, у 181 первые
  разборы равноценны. Чаще всего расходятся: место предложной группы или
  наречия, слово, к которому относится родительный, подлежащее и дополнение
  при форме, одинаковой в именительном и винительном, определение или
  сказуемое, состав однородных членов. На 30 предложениях, размеченных
  вручную, первый разбор верен у 19.
- **Не проверено ничем:** что причина, по которой разбора нет, названа та,
  которую назвал бы человек. Тексты статей в репозитории не лежат, поэтому
  замер на статьях командой из репозитория не повторить.

Чего грамматика пока не читает:

- вопросы со словом-вопросом («Почему система работает?») и повеление;
- инфинитивное предложение («Решить задачу.») и часть предложения, отделённую
  точкой («И задачу.»);
- прилагательное и причастие вместо существительного («учащиеся», «следующее»),
  кроме случаев после предлога и после местоименного слова;
- дательный падеж при глаголе, которого нет в списке, если форма слова читается
  и как другой падеж;
- формулы, строки таблиц, списки литературы.

Буква ё читается как е: слова в словаре ищутся в записи через «е».

## Простой вердикт: «Разобрать»

`«Разобрать»` из `parse.flang` знает 141 словоформу своего словаря и отвечает
одним вердиктом:

```
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"Мама читает книгу."}'
доказано: утверждений 11
"грамматично: мама: n[им ж ед 3]; читает: n[им ед 3]ʳ · s · n[вин]ˡ; книгу: n[вин ж ед 3]; связи: мама—читает, читает—книгу"
```

Порядок слов свободный, как в русском:

```
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"книгу мама читает"}'
доказано: утверждений 11
"грамматично: книгу: n[вин ж ед 3]; мама: n[им ж ед 3]; читает: n[им ед 3]ʳ · n[вин]ʳ · s; связи: мама—читает, книгу—читает"
```

Неграмматичное предложение получает причину:

```
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"мама читает книга"}'
доказано: утверждений 11
"не грамматично: неверный падеж"
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"мама читают книгу"}'
доказано: утверждений 11
"не грамматично: нет согласования по роду, числу или лицу"
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"мама книгу"}'
доказано: утверждений 11
"не грамматично: нет сказуемого"
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"мама шьёт"}'
доказано: утверждений 11
"не грамматично: неизвестное слово «шьёт»"
```

Причин пять: неверный падеж; нет согласования по роду, числу или лицу; нет
сказуемого; неизвестное слово; `типы слов не сводятся к s` — всё остальное.
Обстоятельство в середине предложения этот вход не принимает, а `«Разборы»`
принимает:

```
$ flang run flang/ct/russian/parse.flang --function «Разобрать» --args '{"предложение":"мама в доме читает"}'
доказано: утверждений 11
"не грамматично: типы слов не сводятся к s"
```

В этом входе глагол записывается тем, чего он ждёт, и программа сама строит
типы на все порядки слов:

```flang fragment
«Переходный» от "читает" и («Подлежащее настоящего» от "ед" и "3") и "вин"
```

Какие типы получились у слова, показывает `«Типы слова»`:

```
$ flang run flang/ct/russian/parse.flang --function '«Типы слова»' --args '{"слово":"читает"}'
доказано: утверждений 11
"s · n[им ед 3]ˡ; n[им ед 3]ʳ · s; s · n[вин]ˡ · n[им ед 3]ˡ; n[им ед 3]ʳ · s · n[вин]ˡ; n[вин]ʳ · n[им ед 3]ʳ · s; s · n[им ед 3]ˡ · n[вин]ˡ; n[вин]ʳ · s · n[им ед 3]ˡ; n[им ед 3]ʳ · n[вин]ʳ · s"
```
