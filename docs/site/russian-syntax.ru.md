# Разбор высказывания по графу понятий

Модуль `flang/ct/russian/syntax.flang` проверяет разбор русского высказывания.
Разбор пишется в текстовом файле. Каждая строка — одно утверждение. Модуль сверяет
утверждение с двумя источниками: понятие ищет в срезе графа понятий «Русской
грамматики» (1980), а пометы словоформ берёт из словаря
[грамматики на прегруппах](russian-grammar.html).

## Строка разбора

Строка записана так: `роль: содержание`. Роль — всё до первого `: `.

- `Высказывание: …` — текст, который разбирается.
- `Уровень: <понятие>` — ступень осознания сверху вниз. Обычный порядок: речь,
  письменная речь, монологическая речь, текст, контекст, конситуация, высказывание.
  Каждая следующая ступень связана стрелкой графа с одной из прежних — сама или
  через родителей. Нет связи — вывод «Разрыв уровней».
- `Согласование в роде, числе и падеже: <зависимое> → <главное>` — сверка помет двух
  словоформ. Так же пишется `Координация в числе и лице: …`. Категории берутся из
  роли: «роде», «числе», «падеже», «лице». Роль без них сверяет все четыре.
- `Опоры нет: <что>` — в графе нет понятия. Строка попадает в вывод как есть.
- Любая другая роль — содержание считается именем понятия. Вывод называет понятие,
  его параграф, цитату и путь от общего понятия к частному. Имени нет — вывод
  «Нет в графе».

Категория сверяется, только если пометы есть у обеих словоформ. У множественного
числа рода нет, и род не сверяется. Если не сверилась ни одна категория, связь
считается несогласованной. Словоформы нет в словаре — вывод «Нет помет».

## Запуск

Итог разбора одной строкой:

```sh
flang run flang/ct/russian/syntax.flang --function '«Итог разбора»' \
  --args "$(jq -Rs '{"текст разбора": .}' flang/ct/russian/syntax-texts/first-sentence.dsl)"
```

```
"опор 25, сверок 11, без опоры 4, разрывов 0, нет в графе 0, нет помет 0, не согласовано 0"
```

Функция `«Разобрать высказывание»` с теми же аргументами печатает разбор целиком —
список JSON. Три вида записей из него:

```json
{"вариант":"Опора","роль":"Уровень","узел":"письменная речь","место":"§ 1890","цитата":"Языковое общение людей (языковая коммуникация), как непосредственное, устное, так и письменное, осуществляется в форме, которую можно назвать потоком речи или просто речью.","путь":"речь → письменная речь"}
{"вариант":"Связь форм","сверка":{"роль":"Согласование в роде, числе и падеже","зависимое":"русский","главное":"язык","проверено":[{"название":"род","общие":["мужской род"]},{"название":"число","общие":["единственное число"]},{"название":"падеж","общие":["именительный падеж","винительный падеж"]}],"согласовано":true}}
{"вариант":"Опоры нет","что":"запятая между частями — Правила 1956 года, § 143; правил знаков в графе нет"}
```

Разрыв ступеней выглядит так:

```sh
flang run flang/ct/russian/syntax.flang --function '«Итог разбора»' \
  --args '{"текст разбора": "Уровень: речь\nУровень: схема 4. N₁ — N₁"}'
```

```
"опор 1, сверок 0, без опоры 0, разрывов 1, нет в графе 0, нет помет 0, не согласовано 0"
```

Схема предложения не связана с речью ни одной стрелкой.

Пометы одной словоформы показывает `«Найти пометы»`:

```sh
flang run flang/ct/russian/syntax.flang --function '«Найти пометы»' --args '{"словоформа":"системой"}'
```

```json
{"вариант":"Найдены","найденные":[{"разряд":"род","значение":"женский род"},{"разряд":"число","значение":"единственное число"},{"разряд":"падеж","значение":"творительный падеж"},{"разряд":"лицо","значение":"3 лицо"}]}
```

## Примеры

Три первых предложения Введения «Русской грамматики» разобраны в
`flang/ct/russian/syntax-texts/`:

| Файл | Высказывание | Строк | Итог |
|---|---|---:|---|
| `first-sentence.dsl` | «Современный русский литературный язык — один из самых богатых языков мира, …» | 41 | 25 опор, 11 сверок помет, 4 строки без опоры |
| `second-sentence.dsl` | «Он не только обслуживает все сферы национальной жизни русского народа, но и служит …» | 23 | 15 опор, 6 сверок помет, 1 строка без опоры |
| `third-sentence.dsl` | «Роль русского языка в современном мире постоянно возрастает: как один из …» | 24 | 15 опор, 7 сверок помет, 1 строка без опоры |

Во всех трёх файлах ступени связаны, имена понятий найдены, пометы согласованы.

## Откуда данные

Понятия лежат в `flang/ct/russian/syntax-graph.flang`. Это срез графа понятий
«Русской грамматики»: 97 понятий и 126 стрелок. В срез входят понятия, названные в
трёх файлах, и все их родители по стрелкам «вид», «входит в», «является», «деление».
У каждого понятия — параграф грамматики и одна дословная цитата из него.

Пометы — род, число, падеж и лицо — модуль читает из словаря
`flang/ct/russian/lexicon.flang`, того же, по которому грамматика на прегруппах
разбирает предложение. Своей таблицы помет у модуля нет. Словоформы трёх разборов
записаны в словарь, и теперь в нём шесть падежей: добавлен творительный (`тв`).
Как записать новое слово, сказано на [странице грамматики](russian-grammar.html).

## Границы

- Срез сделан под три примера. Новое понятие в разборе требует нового среза, новая
  словоформа — строки в словаре.
- Правил знаков препинания и понятий морфологии в графе нет. Такие строки
  размечаются «Опоры нет».
- Сверка помет не выбирает омоним. Она ищет общее значение категории среди всех
  чтений словоформы, которые записаны в словаре.
- Словарь записывает чтения слова, которое стоит в разобранных предложениях.
  Чтений омонимов из других слов в нём нет.
- У существительного в словаре стоит третье лицо: с ним координируется глагол.
