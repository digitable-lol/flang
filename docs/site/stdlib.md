# Standard library reference

The standard library is written in flang and is checked the same way as your
program: types, termination, unit tests (`пример`) and postconditions. It has
<!-- СНЯТО 2026-10-04 файлов flang/stdlib/*.flang = 53 --> 53 modules, one file
each in `flang/stdlib/`. This page lists every module and every function in it.

## Which module for which task

| Task | Module |
| --- | --- |
| length, slice, search, sort a list of numbers | [Lists](#lists) |
| map, filter, reduce, sort with your own comparison | [Higher order](#higher-order) |
| split, replace, trim, change case, pad a string | [Strings](#strings) |
| a value that may be absent (Optional) | [Optional](#optional) |
| success or error with a reason (Result) | [Result](#result) |
| a map from string keys | [Hash map](#hash-map) (fast), [Tree map](#tree-map), [Dictionary](#dictionary) (small) |
| parse and print JSON | [JSON](#json) |
| integers of any size | [Bignum](#bignum) |
| dates, times, ISO-8601 | [Date and time](#date-and-time) |
| HTTP requests and responses | [Requests and responses](#requests-and-responses) |
| command-line flags of your program | [CLI](#cli) |

| PostgreSQL, Redis, SQLite | [Postgres](#postgres), [Redis](#redis), [SQLite](#sqlite) |
| hashes, HMAC, password hashing | [SHA-256](#sha-256), [HMAC](#hmac), [Key derivation](#key-derivation) |

## Importing a module

`использует` is the import. A module is imported by its name, without a path:

```flang
модуль «Моя программа»
  использует «Lists»
```

This brings in the whole module, and the generated code contains all of it. To
import only some functions, name them after `только`:

```flang
  использует «Lists» только «Сумма»
```

`только` does not bring in the functions that the named function calls. You
have to name them too, or import the whole module. Importing «Двоичный поиск»
without «Поиск в диапазоне», which it calls:

```
$ flang check imp1.flang
модуль «Моя программа»: функций 1, из них с доказанным завершением 0; типов 0; файлов вместе с импортами 2
без доказанного завершения: «Двоичный поиск»
место указано строкой и столбцом, но без файла: вместе с импортами проверено файлов 2, а диагностика компилятора имени файла не несёт
FLANG_UNKNOWN_NAME, строка 328, столбец 3: неизвестная функция «Поиск в диапазоне»
FLANG_NOT_TOTAL, строка 328, столбец 3: тотальная функция «Двоичный поиск» вызывает неизвестную функцию «Поиск в диапазоне»: завершение доказать нельзя
imp1.flang: не проверено — замечаний 2
```

Here `imp1.flang` is the two lines `модуль «Моя программа»` and
`  использует «Lists» только «Двоичный поиск»`. The line numbers point into
`flang/stdlib/lists.flang`, not into your file.

The unit tests of an imported function are run in your program too, so they
also need their functions. `использует «Higher order» только «Свернуть»` fails
on the tests of «Свернуть», which call «Сложить», «Умножить» and «Большее»:

```
$ flang check imp2.flang
модуль «Моя программа»: функций 5, из них с доказанным завершением 5; типов 0; файлов вместе с импортами 4
место указано строкой и столбцом, но без файла: вместе с импортами проверено файлов 4, а диагностика компилятора имени файла не несёт
FLANG_UNKNOWN_NAME, строка 131, столбец 3: пример «Сумма»: аргумент «ф»: функции «Сложить» нет
FLANG_UNKNOWN_NAME, строка 136, столбец 3: пример «Произведение той же свёрткой»: аргумент «ф»: функции «Умножить» нет
FLANG_UNKNOWN_NAME, строка 141, столбец 3: пример «Максимум той же свёрткой»: аргумент «ф»: функции «Большее» нет
imp2.flang: не проверено — замечаний 3
```

## How to read the tables

| Column | What it is |
| --- | --- |
| function | the name to call; `от «А»` means a generic function over the type `«А»` |
| takes, returns | the signature, copied from the source |
| guarantee | the label of the function's first postcondition (`обеспечивает`), copied from the source; `—` means the function has no postcondition, and its behaviour is shown only by its unit tests in the source |

The labels are in Russian, like the code. A label says what the postcondition
states; whether the prover has proved it is printed by
`bootstrap/flang check flang/stdlib/<file> --proof`.

Every function terminates on every input (`тотальная`), except seven marked
"not total": «НОД», «НОК», «Цифры» and «Сумма цифр» in Numbers, and three
functions in Math classics.

Lists, strings, numbers, Optional and Result, map/filter/reduce, maps and JSON. Each section ends with a sample program that passes `flang check`.

The module works on the bytes of the file (a `список числа`); it does not open
files. A program that needs a file is a `план`: it returns the command
«Прочитать октеты из файла», the runtime (`flang io`) reads the file and calls
the plan again with the bytes.

Create a sample database with Python's `sqlite3`. The page size is set so that
your numbers match the ones below:

```bash
python3 -c "import sqlite3; c=sqlite3.connect('база.db'); \
  c.execute('pragma page_size=1024'); c.execute('vacuum'); \
  c.execute('create table люди(имя text, лет integer)'); \
  c.executemany('insert into люди values (?,?)', [('Аня',31),('Боря',44),('Вера',7)]); \
  c.commit()"
```

Save this as `заголовок.flang` next to `база.db`:

```flang
модуль «Заголовок базы»
  использует «SQLite»

тип «Ход»
  вариант «Начало»
  вариант «Ждём октеты»

тотальная функция «Начало хода»
  возвращает «Ход»
  вариант «Начало»

тотальная функция «Отчёт»
  принимает октеты: список числа
  возвращает строка
  соединить [
      "это база SQLite: ", (если («Это база SQLite» от октеты) то "да" иначе "нет"),
      "\nразмер страницы: ", (к строке («Размер страницы» от октеты)),
      "\nстраниц: ", (к строке («Страниц в базе» от октеты)),
      "\nтаблицы: ", (соединить («Имена таблиц» от октеты) по ", ")
    ] по ""

тотальная функция «Дальше»
  принимает ход: «Ход», отклик: «Отклик»
  возвращает «Продолжение»
  разбор ход
    случай вариант «Начало»
      то вариант «Сделать» с поручение равным (вариант «Прочитать октеты из файла» с путь равным "база.db") и потом равным (вариант «Ждём октеты»)
    случай вариант «Ждём октеты»
      то разбор отклик
        случай вариант «Октеты» с октеты как октеты
          то вариант «Конец работы» с значение равным («Отчёт» от октеты)
        случай любое
          то вариант «Провал» с код равным "FLANG_IO_ORDER" и сообщение равным "ждали октетов"

план «Заголовок»
  состояние «Ход»
  начинает с «Начало хода»
  обрабатывает «Дальше»
```

Run it. `flang io` runs a plan only when all its postconditions, including those
of the imported modules, are proved; SQLite has unproved ones, so the run needs
`--trust`. `jq -r .result` prints only the result:

```
$ flang io заголовок.flang --trust | jq -r .result
на веру: доказанность не считалась — запуск по ключу --trust
это база SQLite: да
размер страницы: 1024
страниц: 2
таблицы: люди
```

**Known limit:** the header, the schema and the table names can be read, but
reading row values runs out of the step limit while decoding UTF-8. The example
plan `docs/examples/db/sqlite-read.flang`, which also prints the rows of a
table, stops like this on the same 2 KiB database (saved as `obrazec.db` next to
the plan):

```
$ flang io docs/examples/db/sqlite-read.flang --trust
на веру: доказанность не считалась — запуск по ключу --trust
{"error":"функция «Кодовые точки из байтов» исчерпала лимит шагов (10000000) на глубине вызовов 9","diagnostics":[{"code":"FLANG_RECURSION_LIMIT","message":"функция «Кодовые точки из байтов» исчерпала лимит шагов (10000000) на глубине вызовов 9","severity":"error","span":{"line":90,"column":1}}]}
```

Until this is fixed, use the module for the header and the schema, not for the
contents.
