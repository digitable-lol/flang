## Как подключить модуль

`использует` — это импорт (`import`). Имя модуля пишется по-английски, как в
каталоге выше. Путь к файлу не нужен.

Файл `sum.flang`:

```flang
модуль «Сумма до предела»
  использует «Lists»

тотальная функция «Сумма чисел до предела»
  принимает предел: число
  возвращает число
  пример «До пяти»
    дано предел равно 5
    ожидается 15
  «Сумма» от («Числа до» от предел)
```

```
$ flang check sum.flang
модуль «Сумма до предела»: функций 39, из них с доказанным завершением 39; типов 1; файлов вместе с импортами 2
sum.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
```

Первая строка считает функции вместе с модулем: все функции Lists и одна ваша.
Вторая перечисляет, что проверено: синтаксис, типы, завершение функций,
постусловия и тесты. Тесты модуля выполняются вместе с вашими, поэтому
программа с большим модулем (AES, TLS client) проверяется несколько минут.

### Русского имени у модуля нет

Замените в `sum.flang` имя модуля на «Списки»:

```
$ flang check sum.flang
…
FLANG_IMPORT_NOT_FOUND в файле sum.flang, строка 1, столбец 1: не найден модуль «Списки»: ни рядом с файлом, ни выше по каталогам, ни в библиотеке компилятора
FLANG_UNKNOWN_NAME в файле sum.flang, строка 10, столбец 3: неизвестная функция «Сумма»
…
sum.flang: не проверено — замечаний 5
```

Модуля «Списки» нет: списки — это «Lists». Русское слово рядом с именем в
каталоге — подсказка для поиска по сайту. В строке `использует` пишется
английское имя.

### Часть модуля

Слово `только` подключает названные функции и те, которые они вызывают:

```flang
  использует «Lists» только «Двоичный поиск»
```

С такой строкой в программу попадают «Двоичный поиск» и две функции, которые
ему нужны. Тесты остальных функций Lists не выполняются, и проверка идёт
быстрее.

### Запуск программы с модулем

`flang run` вычисляет одну функцию. Перед этим он смотрит, все ли постусловия
программы и её модулей доказаны:

```
$ flang run sum.flang "«Сумма чисел до предела»" 5
не доказано: утверждений 66: доказано 42, сетка 24, на веру 0 — запуск только по явному согласию: --на-веру
…
$ flang run sum.flang "«Сумма чисел до предела»" 5 --trust
на веру: доказанность не считалась — запуск по ключу --trust
15
```

Первая команда остановилась с кодом возврата 3: не все постусловия Lists
доказаны. Два числа в её выводе — сколько постусловий доказано и сколько
проверено только на тестах. Ключ `--trust` запускает программу без этой
проверки; недоказанные постусловия тогда проверяются во время выполнения.

## Сколько доказано

Постусловие (`обеспечивает`) — утверждение о результате функции. Компилятор
доказывает его для любых аргументов. Где доказать не удалось, постусловие
проверяется на значениях из тестов и во время выполнения.
