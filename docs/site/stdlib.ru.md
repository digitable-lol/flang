# Справочник стандартной библиотеки

Библиотека лежит рядом с компилятором и написана на самом flang. Каждая её функция проходит тот же путь, что ваша программа: разбор, типы, завершаемость, примеры. Ниже — раздел на модуль и таблица на все его функции.

`использует` — это импорт. Модуль подключается по имени, путь писать не нужно:

```flang
модуль «Моя программа»
  использует «Lists»
```

Модуль приходит ЦЕЛИКОМ, и напечатанный код несёт его весь. Нужна одна функция — назовите её:

```flang
  использует «Lists» только «Сумма»
```

`только` не досчитывает зависимости названной функции. Позовёте `«Двоичный поиск»` без `«Поиск в диапазоне»` — компилятор ответит так:

```
FLANG_UNKNOWN_NAME, строка 569, столбец 3: неизвестная функция «Поиск в диапазоне»
FLANG_NOT_TOTAL, строка 569, столбец 3: тотальная функция «Двоичный поиск» вызывает неизвестную функцию «Поиск в диапазоне»: завершение доказать нельзя
```

Допишите недостающее имя через запятую — или подключайте модуль целиком.

В таблицах ниже столбцы «принимает» и «возвращает» — подпись из исходника, слово в слово. Столбец «что делает» — постусловие функции, строка `обеспечивает` из её объявления, тоже слово в слово. Оттуда в нём авторские обороты: «довод» значит аргумент, «октеты» — байты.

## С чего начать

Девять модулей закрывают почти всё, что пишется каждый день. У каждого — целая программа, которую можно скопировать и проверить.

### Lists

Списки любых значений и списки чисел: длина, срез, промежуток, поиск, свёртки, сортировка.

Импорт: `использует «Lists»`.

| функция | принимает | возвращает | что делает |
| --- | --- | --- | --- |
| `«Длина» от «А»` | `элементы: список «А»` | `число` | счёт звеньев сходится со встроенной длиной |
| `«Приписать в начало» от «А»` | `первый: «А», элементы: список «А»` | `список «А»` | приписывание удлиняет список ровно на один |
| `«Соединить списки» от «А»` | `первый: список «А», второй: список «А»` | `список «А»` | длина соединения есть сумма длин |
| `«Обратить» от «А»` | `элементы: список «А»` | `список «А»` | обращение не теряет и не добавляет элементов |
| `«Отбросить первые» от «А»` | `элементы: список «А», сколько: число` | `список «А»` | при неположительном сколько не отброшено ничего |
| `«Взять первые» от «А»` | `элементы: список «А», сколько: число` | `список «А»` | целое N внутри длины даёт ровно N |
| `«Срез» от «А»` | `элементы: список «А», начало: число, конец: число` | `список «А»` | срез от первого до последнего есть весь список |
| `«Числа до»` | `предел: число` | `список числа` | предел стоит в промежутке |
| `«Числа от и до»` | `начало: число, конец: число` | `список числа` | промежуток, начатый не выше единицы, доходит до конца |
| `«Элемент»` | `элементы: список числа, индекс: число` | `число` | на целом номере внутри списка обход сходится со встроенной формой |
| `«Индекс»` | `элементы: список числа, значение: число` | `число` | найденное место держит искомое, а ноль значит: не найдено |
| `«Содержит число»` | `элементы: список числа, значение: число` | `признак` | встроенная форма и обход по индексу согласны |
| `«Списки равны»` | `первый: список числа, второй: список числа` | `признак` | пустому равен только пустой |
| `«Поиск в диапазоне»` | `элементы: список числа, цель: число, низ: число, верх: число, витков: неотрицательное` | `число` | отрезок из одного места отдаёт это место, когда оно держит цель |
| `«Двоичный поиск»` | `элементы: список числа, цель: число` | `число` | ненулевое место держит цель |
| `«Все не меньше»` | `элементы: список числа, порог: число` | `признак` | пустому списку годится любой порог |
| `«Любой не меньше»` | `элементы: список числа, порог: число` | `признак` | пустому списку не годится ни один порог |
| `«Минимум»` | `элементы: список числа` | `число` | наименьшее взято из самого списка, а на пустом это ноль |
| `«Максимум»` | `элементы: список числа` | `число` | наибольшее взято из самого списка, а на пустом это ноль |
| `«Сумма»` | `элементы: список числа` | `число` | сумма неотрицательных не меньше наибольшего из них |
| `«Произведение»` | `элементы: список числа` | `число` | произведение чисел не меньше единицы не меньше наибольшего из них |
| `«Вставить по порядку»` | `значение: число, элементы: список числа` | `список числа` | вставка удлиняет список ровно на один |
| `«Вставками по порядку»` | `элементы: список числа` | `список числа` | вставками не теряется и не добавляется ни одного элемента |
| `«Сортировать»` | `элементы: список числа` | `список числа` | сортировка не теряет и не добавляет элементов |
| `«Уникальные»` | `элементы: список числа` | `список числа` | первый элемент переживает отсев и остаётся первым, а пустой список остаётся пустым |
| `«Считать вхождения»` | `элементы: список числа, значение: число` | `число` | счёт не ноль ровно тогда, когда значение в списке |
| `«Без значения»` | `элементы: список числа, значение: число` | `список числа` | удалено ровно столько, сколько было вхождений |
| `«Сжать в пары»` | `первые: список числа, вторые: список числа` | `список «Пара чисел»` | пар ровно столько, сколько в коротком из списков |
| `«Сжать суммами»` | `первые: список числа, вторые: список числа` | `список числа` | сумм ровно столько, сколько в коротком из списков |

Пример целиком — проверяется командой `flang check`:

```flang
модуль «Проба списков»
  использует «Lists»

тотальная функция «Сумма чисел до предела»
  принимает предел: число
  возвращает число
  пример «До пяти»
    дано предел равно 5
    ожидается 15
  «Сумма» от («Числа до» от предел)
```

### Strings

Строка как данные: разбиение, замена, регистр, префикс и суффикс, вопросы о знаке, дополнение до ширины.

Импорт: `использует «Strings»`.

| функция | принимает | возвращает | что делает |
| --- | --- | --- | --- |
| `«Приписать строку в начало»` | `первая: строка, элементы: список строки` | `список строки` | приписывание удлиняет список ровно на один |
| `«Соединить строки»` | `части: список строки, разделитель: строка` | `строка` | склейка начинается первой частью |
| `«Разбить по символу»` | `текст: строка, разделитель: строка` | `список строки` | разбиение даёт хотя бы одну часть |
| `«Заменить»` | `текст: строка, что: строка, чем: строка` | `строка` | кусков по новому разделителю не меньше, чем было по старому |
| `«Считать символ»` | `текст: строка, буква: строка` | `число` | ноль ровно тогда, когда вхождения нет |
| `«Позиция подстроки»` | `текст: строка, часть: строка` | `число` | ноль значит нет вхождения |
| `«Начинается с»` | `текст: строка, префикс: строка` | `признак` | начинается с — это когда кусок ПЕРЕД первым вхождением пуст |
| `«Заканчивается на»` | `текст: строка, суффикс: строка` | `признак` | отрезал суффикс, приклеил обратно — исходное |
| `«Заглавная буква»` | `буква: строка` | `строка` | строчная латинская буква поднимается ровно на 32 кода |
| `«Строчная буква»` | `буква: строка` | `строка` | заглавная латинская буква опускается ровно на 32 кода |
| `«В верхний регистр»` | `текст: строка` | `строка` | верхний регистр не меняет длины |
| `«В нижний регистр»` | `текст: строка` | `строка` | нижний регистр не меняет длины |
| `«Символы»` | `текст: строка` | `список строки` | символов ровно столько, какова длина строки |
| `«Обратить строку»` | `текст: строка` | `строка` | обращение не удлиняет строку |
| `«Палиндром»` | `текст: строка` | `признак` | разложить на знаки и склеить обратно — ответ тот же |
| `«Повторить»` | `текст: строка, раз: число` | `строка` | положительный повтор начинается исходным текстом |
| `«Обрезать слева»` | `текст: строка` | `строка` | приставить обратно отнятые пробелы — получить исходное |
| `«Обрезать справа»` | `текст: строка` | `строка` | дописать обратно отнятые пробелы — получить исходное |
| `«Обрезать пробелы»` | `текст: строка` | `строка` | убраны только пробелы |
| `«Первый символ»` | `текст: строка` | `строка` | первый символ длиной не больше знака |
| `«Последний символ»` | `текст: строка` | `строка` | последний символ длиной не больше знака |
| `«Это цифра»` | `знак: строка` | `признак` || для цифры поиск вхождением и поиск позицией отвечают одно |
| `«Это пробел»` | `знак: строка` | `признак` || для пробела поиск вхождением и поиск позицией отвечают одно |
| `«Это латинская буква»` | `знак: строка` | `признак` | латинская буква — это ровно тот знак, у которого меняется регистр |
| `«Только цифры»` | `текст: строка` | `признак` | убери из текста все десять цифр — у одних цифр не останется ничего |
| `«Цифра числом»` | `знак: строка` | `число` | неотрицательный ответ показывает на тот самый знак |
| `«Сколько дополнить»` | `ширина: неотрицательное, набрано: неотрицательное` | `число` | дополнение — это ровно недостача, а при достатке ноль |
| `«Дополнить слева»` | `текст: строка, ширина: неотрицательное, знак: строка` | `строка` | исходное целиком стоит в дополненном слева |
| `«Дополнить справа»` | `текст: строка, ширина: неотрицательное, знак: строка` | `строка` | дополненное справа начинается исходным |
| `«Без знака»` | `текст: строка, знак: строка` | `строка` | нечего убирать — текст не тронут |
| `«Урезать»` | `текст: строка, предел: неотрицательное` | `строка` | урезанное — начало исходного |

Пример целиком — проверяется командой `flang check`:

```flang
модуль «Проба строк»
  использует «Strings»

тотальная функция «Слово задом наперёд»
  принимает текст: строка
  возвращает строка
  пример «Слово»
    дано текст равно " шалаш "
    ожидается "шалаш"
  «Обратить строку» от («Обрезать пробелы» от текст)
```

### Numbers

Числа: знак, модуль, целочисленное деление, НОД и НОК, степень, факториал, цифры.

Импорт: `использует «Numbers»`.

| функция | принимает | возвращает | что делает |
| --- | --- | --- | --- |
| `«Абсолютное значение»` | `число: число` | `число` | модуль не меньше самого числа и не меньше противоположного ему |
| `«Знак»` | `число: число` | `число` | знак читает порядок: у положительного единица, у отрицательного минус единица, у нуля ноль |
| `«Минимум двух»` | `первое: число, второе: число` | `число` | минимум — одно из двух чисел и не больше каждого сравнимого с ним |
| `«Максимум двух»` | `первое: число, второе: число` | `число` | максимум — одно из двух чисел и не меньше каждого сравнимого с ним |
| `«Ограничить»` | `число: число, снизу: число, сверху: число` | `число` | ограничение отдаёт либо само число, либо одну из границ |
| `«Целочисленное деление»` | `делимое: число, делитель: число` | `число` | частное и остаток восстанавливают делимое |
| `«Целая часть»` | `значение: число` | `число` | целая часть — само число без остатка от единицы |
| `«Чётное»` | `число: число` | `признак` | чётность есть делимость на два |
| `«Делится на»` | `число: число, делитель: число` | `признак` | делимость — это ровно то, что деление нацело восстанавливает число |
| `«НОД»` | `первое: число, второе: число` | `число` | общий делитель и правда делит оба числа |
| `«НОК»` | `первое: число, второе: число` | `число` | общее кратное и правда делится на оба числа |
| `«Степень»` | `основание: число, показатель: неотрицательное` | `число` | единица в любой степени — единица |
| `«Факториал»` | `число: неотрицательное` | `число` | факториал не меньше единицы |
| `«Цифры»` | `число: число` | `список числа` | цифра хотя бы одна |
| `«Сумма цифр»` | `число: число` | `число` | у однозначного целого сумма цифр — оно само |

Пример целиком — проверяется командой `flang check`:

```flang
модуль «Проба чисел»
  использует «Numbers»

тотальная функция «Доля в процентах»
  принимает часть: число, целое: число
  возвращает число
  пример «Половина»
    дано часть равно 1
    дано целое равно 2
    ожидается 50
  «Ограничить» от («Целочисленное деление» от (часть умножить на 100) и целое) и 0 и 100
```

### Optional

Значение, которого может не быть: «Есть» или «Нет» над любым типом.

Импорт: `использует «Optional»`.

Типы модуля: `«Возможно»`.

| функция | принимает | возвращает | что делает |
| --- | --- | --- | --- |
| `«Обернуть» от «А»` | `значение: «А»` | `«Возможно» от «А»` | обёрнутое значение всегда есть |
| `«Есть значение» от «А»` | `опция: «Возможно» от «А»` | `признак` | значение есть ровно тогда, когда опция — не пустая |
| `«Значение или запасное» от «А»` | `опция: «Возможно» от «А», запасное: «А»` | `«А»` | у пустой опции берётся запасное, у полной — ровно то, что внутри |
| `«Первый элемент» от «А»` | `элементы: список «А»` | `«Возможно» от «А»` | первый элемент есть ровно у непустого списка |
| `«Первый элемент или запасное» от «А»` | `элементы: список «А», запасное: «А»` | `«А»` | у пустого списка — запасное, у непустого — ровно первый элемент |
| `«Последний элемент» от «А»` | `элементы: список «А»` | `«Возможно» от «А»` | последний элемент есть ровно у непустого списка |
| `«Последний элемент или запасное» от «А»` | `элементы: список «А», запасное: «А»` | `«А»` | у пустого списка — запасное, у непустого — ровно последний элемент |
| `«Найти не меньше»` | `элементы: список числа, порог: число` | `«Возможно» от числа` | значение есть ровно тогда, когда в списке нашлось не меньшее порога, и оно само не меньше порога |
| `«Найти не меньше или запасное»` | `элементы: список числа, порог: число, запасное: число` | `число` | нашли — не меньше порога, не нашли — запасное |
| `«Умножить значение»` | `опция: «Возможно» от числа, множитель: число` | `«Возможно» от числа` | умножение не создаёт и не теряет значения |
| `«Первый удвоенный или запасное»` | `элементы: список числа, запасное: число` | `число` | первый удваивается, а у пустого списка берётся запасное |

Пример целиком — проверяется командой `flang check`:

```flang
модуль «Проба опции»
  использует «Optional»

тотальная функция «Первое или ноль»
  принимает элементы: список числа
  возвращает число
  пример «Пустой список»
    дано элементы равно пустой список
    ожидается 0
  «Первый элемент или запасное» от элементы и 0
```

### Result

Итог вычисления: успех со значением или ошибка с причиной.

Импорт: `использует «Result»`.

Типы модуля: `«Результат»`.

| функция | принимает | возвращает | что делает |
| --- | --- | --- | --- |
| `«Успешный результат» от «Значение» и «Беда»` | `значение: «Значение»` | `«Результат» от «Значение» и «Беда»` | успешный результат успешен |
| `«Ошибочный результат» от «Значение» и «Беда»` | `сообщение: «Беда»` | `«Результат» от «Значение» и «Беда»` | ошибочный результат не успешен |
| `«Успешно» от «Значение» и «Беда»` | `итог: «Результат» от «Значение» и «Беда»` | `признак` | успех узнаётся по варианту, и только по нему |
| `«Успех или запасное» от «Значение» и «Беда»` | `итог: «Результат» от «Значение» и «Беда», запасное: «Значение»` | `«Значение»` | у успеха берётся ровно его значение, у ошибки — запасное |
| `«Сообщение или пусто» от «Значение»` | `итог: «Результат» от «Значение» и строки` | `строка` | у успеха сообщение пусто, у ошибки — ровно её сообщение |
| `«Безопасное деление»` | `делимое: число, делитель: число` | `«Результат» от числа и строки` | деление успешно ровно при ненулевом делителе |

Пример целиком — проверяется командой `flang check`:

```flang
  возвращает число
```

### Higher order

Функции-значения: отобразить, отфильтровать, свернуть, сортировать по своему порядку.

| `«Обратить знаки»` | `элементы: список числа` | `список числа` | обращение знаков сохраняет длину списка |
| `«Заглавная точка»` | `текст: строка` | `строка` | точка удлиняет строку ровно на один знак |

### Dictionary

Словарь строка → строка списком связей. Поиск линейный: на тысяче ключей ведёт себя как список на тысячу элементов.

Импорт: `использует «Dictionary»`.

Типы модуля: `«Связь»`.

| функция | принимает | возвращает | что делает |
| --- | --- | --- | --- |
| `«Ключ связи»` | `связь: «Связь»` | `строка` | ключ связи — это ключ, записанный в связи |
| `«Значение связи»` | `связь: «Связь»` | `строка` | значение связи — это значение, записанное в связи |
| `«Есть ключ»` | `словарь: список «Связь», искомый: строка` | `признак` | ключ найден ровно тогда, когда он есть среди ключей |
| `«Взять или запасное»` | `словарь: список «Связь», искомый: строка, запасное: строка` | `строка` | чего нет среди ключей, того и не взято: отдаётся запасное |
| `«Убрать»` | `словарь: список «Связь», искомый: строка` | `список «Связь»` | удаление не удлиняет словарь |
| `«Положить»` | `словарь: список «Связь», ключ: строка, значение: строка` | `список «Связь»` | после записи словарь непуст |
| `«Ключи»` | `словарь: список «Связь»` | `список строки` | ключей ровно столько, сколько связей |
| `«Значения»` | `словарь: список «Связь»` | `список строки` | значений ровно столько, сколько связей |
| `«Размер»` | `словарь: список «Связь»` | `число` | размер словаря неотрицателен |

Пример целиком — проверяется командой `flang check`:

### Hash map

## Что написано последним

Пять модулей моложе остальных. У каждого сказано, что он умеет и чего не умеет.

| Модуль | Умеет | Не умеет |
| --- | --- | --- |
| `«AES»` | Шифрует и расшифровывает AES-128: один блок, поток в режиме CTR, режим GCM с выработкой и проверкой тега. | Ключей длиннее 128 бит нет, и ключ здесь не вырабатывается — берите его из «Вывод ключа» или «X25519». |
| `«X25519»` | Считает общий ключ двух сторон: умножает точку Curve25519 на скаляр — и на образующую, и на чужой открытый ключ. | Подписи Ed25519 здесь нет, и случайного скаляра модуль не берёт: секрет приходит аргументом. |

Модуль читает **октеты** — список байтов файла. Открывать файл он не умеет и не
должен: байты приносит план. План — это программа, которая шаг за шагом
поручает работу с миром хозяину (`flang io`) и получает от него отклик; ниже
поручение одно — «Прочитать октеты из файла».

Готовьте файл-образец сторонней `sqlite3` — тогда есть с чем сверять. Размер
страницы задан явно, чтобы числа ниже совпали с вашими:

```bash
python3 -c "import sqlite3; c=sqlite3.connect('база.db'); \
  c.execute('pragma page_size=1024'); c.execute('vacuum'); \
  c.execute('create table люди(имя text, лет integer)'); \
  c.executemany('insert into люди values (?,?)', [('Аня',31),('Боря',44),('Вера',7)]); \
  c.commit()"
```

```flang
модуль «Заголовок базы»
  использует «SQLite»

тип «Ход»
  вариант «Начало»
  вариант «Ждём октеты»

тотальная функция «Начало хода»
  возвращает «Ход»
  вариант «Начало»

тотальная функция «Отчёт»
  принимает октеты: список числа
  возвращает строка
  соединить [
      "это база SQLite: ", (если («Это база SQLite» от октеты) то "да" иначе "нет"),
      "\nразмер страницы: ", (к строке («Размер страницы» от октеты)),
      "\nстраниц: ", (к строке («Страниц в базе» от октеты)),
      "\nтаблицы: ", (соединить («Имена таблиц» от октеты) по ", ")
    ] по ""

тотальная функция «Дальше»
  принимает ход: «Ход», отклик: «Отклик»
  возвращает «Продолжение»
  разбор ход
    случай вариант «Начало»
      то вариант «Сделать» с поручение равным (вариант «Прочитать октеты из файла» с путь равным "база.db") и потом равным (вариант «Ждём октеты»)
    случай вариант «Ждём октеты»
      то разбор отклик
        случай вариант «Октеты» с октеты как октеты
          то вариант «Конец работы» с значение равным («Отчёт» от октеты)

план «Заголовок»
  состояние «Ход»

```

```json
{"plan":"Заголовок","result":"это база SQLite: да\nразмер страницы: 1024\nстраниц: 2\nтаблицы: люди","orders":1}
```

**Чего этот модуль сегодня не даст.** Заголовок, схема и имена таблиц читаются;
на значениях строк вычисление упирается в предел шагов. План
[`examples/db/sqlite-read.flang`](https://github.com/digitable-lol/flang/blob/main/examples/db/sqlite-read.flang),
который печатает ещё и строки таблицы, на базе в 2 КиБ отвечает так:

```
FLANG_RECURSION_LIMIT: функция «Кодовые точки из байтов» исчерпала лимит шагов (10000000) на глубине вызовов 19
```

Раскодирование UTF-8 идёт байт за байтом рекурсией, и на каждой ячейке заново.
Пока это так, читать через модуль стоит заголовок и схему, а не содержимое.

### Wire

Общая половина двоичного протокола: октет, целое в сетевом порядке, строка с нулём на конце, резка потока на куски.

Импорт: `использует «Wire»`.

Типы модуля: `«Печать»`, `«Набор байтов»`, `«Разбор целого»`, `«Разбор строки»`, `«Разбор числа»`.
