# Ветвление, разбор и рекурсия

Как выбрать одно из двух значений и как обойти список своей функцией, без
готовых `свёртка` и `отобразить`? Третья страница тура, на 5–10 минут. Перед
ней — [Списки и строки](tour-lists-and-strings.html).

## Один файл, три функции

Сохраните в `delivery.flang`:

```flang insert docs/examples/tour/branching/delivery.flang
модуль «Доставка»

тотальная функция «Цена доставки»
  принимает сумма: число, срочно: признак
  возвращает число
  пример «дешёвый заказ»
    дано сумма равно 500
    дано срочно равно нет
    ожидается 300
  пример «дорогой заказ везём бесплатно»
    дано сумма равно 3000
    дано срочно равно нет
    ожидается 0
  пример «срочный всегда платный»
    дано сумма равно 3000
    дано срочно равно да
    ожидается 600
  если срочно
    то 600
    иначе если сумма не меньше 3000
      то 0
      иначе 300

тотальная функция «Самая дорогая»
  принимает цены: список числа
  возвращает число
  пример «из трёх»
    дано цены равно [100, 250, 50]
    ожидается 250
  пример «в пустом списке — ноль»
    дано цены равно []
    ожидается 0
  разбор цены
    случай пусто
      то 0
    случай голова и хвост
      пусть остальные равно «Самая дорогая» от хвост
      если голова больше остальные то голова иначе остальные

тотальная функция «Есть бесплатные»
  принимает цены: список числа
  возвращает признак
  пример «ноль в середине»
    дано цены равно [100, 0, 50]
    ожидается да
  пример «все платные»
    дано цены равно [100, 50]
    ожидается нет
  разбор цены
    случай пусто
      то нет
    случай голова и хвост
      то (голова равен 0) или («Есть бесплатные» от хвост)
```

## `если` возвращает значение

`если … то … иначе …` — выражение, как `if` в Rust или `? :` в TypeScript.
Ветка `иначе` обязательна: значение нужно в обоих случаях. Запись в одну строку
и в несколько строк равноправны, обе есть в файле.

Условия пишутся словами:

| Слово | Знак |
| --- | --- |
| `больше`, `меньше` | `>`, `<` |
| `не меньше`, `не больше` | `>=`, `<=` |
| `равен`, `не равен` | `==`, `!=` |
| `и притом`, `или`, `не` | `&&`, `\|\|`, `!` |

Логическое «и» пишется двумя словами, `и притом`: одиночное `и` разделяет
аргументы вызова. Параметр типа `признак` сам служит условием: `если срочно`.

## `разбор` по списку

`разбор` — сопоставление с образцом, как `match` в Rust. У списка два образца:

- `случай пусто` — список пуст;
- `случай голова и хвост` — в списке есть первый элемент (`голова`) и
  остальные (`хвост`).

Компилятор требует оба случая. Забыть пустой список не получится.

## Рекурсия

`«Самая дорогая»` вызывает саму себя от хвоста списка. Хвост короче списка,
поэтому вызовы рано или поздно дойдут до случая `пусто`. Компилятор видит это
сам и считает завершение доказанным: в первой строке вывода «с доказанным
завершением 3».

После строки `случай голова и хвост` можно сначала назвать значения через
`пусть`, а результат записать последней строкой.

```text insert output: run docs/examples/tour/branching/delivery.flang --function "Самая дорогая" --args '{"цены": [3, 9, 4]}'
$ flang run docs/examples/tour/branching/delivery.flang --function "Самая дорогая" --args '{"цены": [3, 9, 4]}'
доказано: утверждений 0
9
```

```text insert output: run docs/examples/tour/branching/delivery.flang --function "Цена доставки" --args '{"сумма": 3500, "срочно": false}'
$ flang run docs/examples/tour/branching/delivery.flang --function "Цена доставки" --args '{"сумма": 3500, "срочно": false}'
доказано: утверждений 0
0
```

Значения `да` и `нет` в JSON пишутся `true` и `false`.

## Что выбрать для обхода списка

| Задача | Форма |
| --- | --- |
| одно значение по всему списку | `свёртка` |
| новый список той же длины | `отобразить` |
| часть элементов | `отфильтровать` |
| остановиться раньше конца или смотреть на соседние элементы | `разбор` и рекурсия |

## Проверьте себя

Функция `«Сколько дороже»` считает цены выше порога. В заготовке
`count-above.flang` второй случай всегда отвечает нулём. Замените его рекурсией:

```flang refused insert docs/examples/tour/exercises/3-count-above/stub/count-above.flang
модуль «Упражнение 3»

тотальная функция «Сколько дороже»
  принимает цены: список числа, порог: число
  возвращает число
  пример «две цены выше ста»
    дано цены равно [100, 250, 50, 300]
    дано порог равно 100
    ожидается 2
  пример «в пустом списке — ноль»
    дано цены равно []
    дано порог равно 100
    ожидается 0
  разбор цены
    случай пусто
      то 0
    случай голова и хвост
      то 0
```
