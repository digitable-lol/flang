# Функции и тесты

Как записать функцию, вызвать из неё другую и проверить обе тестами? Это первая
из шести страниц тура по языку, на 5–10 минут. Нужен установленный `flang` и
пройденная [Первая программа](getting-started.html).

## Файл с двумя функциями

Сохраните в `price.flang`:

```flang insert docs/examples/tour/functions/price.flang
модуль «Prices»

тотальная функция «Цена со скидкой»
  принимает цена: число, скидка: число
  возвращает число
  пример «десять процентов от двухсот»
    дано цена равно 200
    дано скидка равно 10
    ожидается 180
  пример «без скидки цена та же»
    дано цена равно 200
    дано скидка равно 0
    ожидается 200
  пусть вычет равно цена умножить на скидка делить на 100
  цена минус вычет

тотальная функция «К оплате»
  принимает цена: число, скидка: число, доставка: число
  возвращает число
  пример «товар со скидкой и доставка»
    дано цена равно 200
    дано скидка равно 10
    дано доставка равно 50
    ожидается 230
  («Цена со скидкой» от цена и скидка) плюс доставка
```

Что здесь записано:

| Строка | Что это | В других языках |
| --- | --- | --- |
| `принимает цена: число, скидка: число` | параметры с типами, через запятую | `fn f(price: f64, discount: f64)` в Rust |
| `пример «имя»` с `дано` и `ожидается` | тест: аргументы и ожидаемый результат | `#[test]`, `test(...)` в Jest |
| `пусть вычет равно …` | имя для значения; изменить его потом нельзя | `let` в Rust, `const` в TypeScript |
| `«Цена со скидкой» от цена и скидка` | вызов функции: аргументы идут после `от` через `и` | `price_with_discount(price, discount)` |
| последняя строка тела | результат функции; слова `return` нет | последнее выражение блока в Rust |

Арифметика пишется словами: `плюс`, `минус`, `умножить на`, `делить на`,
`остаток от`. Порядок действий обычный, скобки ставятся как в математике.

Тип `число` — число с плавающей точкой (`f64` в Rust, `number` в TypeScript).
Ещё есть `строка` и `признак` со значениями `да` и `нет` (`bool`).

## Проверить

```text insert output: check docs/examples/tour/functions/price.flang
$ flang check docs/examples/tour/functions/price.flang
модуль «Prices»: функций 2, из них с доказанным завершением 2; типов 0
docs/examples/tour/functions/price.flang: проверено — доказано 0, проверено только на тестах 0, не доказано 0 (постусловий и утверждений 0); замечаний нет
```

Первая строка считает объявления: функций две, для обеих компилятор доказал,
что они завершаются. Вторая перечисляет пять пройденных проверок по порядку:
синтаксис, типы, завершение, доказательства и тесты («примеры»). «Замечаний
нет» читается как «ошибок нет». Код возврата 0.

Команда `flang test` запускает одни тесты:

```text insert output: test docs/examples/tour/functions/price.flang
$ flang test docs/examples/tour/functions/price.flang
docs/examples/tour/functions/price.flang: примеров 3, прошло 3, не прошло 0
```

Тестов («примеров») в файле три, все прошли.

## Запустить

```text insert output: run docs/examples/tour/functions/price.flang --function "К оплате" --args '{"цена": 1000, "скидка": 15, "доставка": 300}'
$ flang run docs/examples/tour/functions/price.flang --function "К оплате" --args '{"цена": 1000, "скидка": 15, "доставка": 300}'
доказано: утверждений 0
1150
```

Имя функции в командной строке пишется без ёлочек. Аргументы передаются
объектом JSON, ключи — имена параметров. Первая строка вывода сообщает, сколько
постусловий в файле доказано: здесь их нет. Вторая строка — результат.

Аргумент не того типа до функции не доходит:

```text insert output: run docs/examples/tour/functions/price.flang --function "К оплате" --args '{"цена": "сто", "скидка": 15, "доставка": 300}'
$ flang run docs/examples/tour/functions/price.flang --function "К оплате" --args '{"цена": "сто", "скидка": 15, "доставка": 300}'
доказано: утверждений 0
FLANG_TYPE: вызов функции «К оплате»: аргумент «цена» не соответствует типу число
$ echo $?
1
```

Строка `"сто"` не подходит параметру типа `число`. Функция не вычислялась, код
возврата 1.

## Имя, занятое языком

Часть русских слов занята языком: `к`, `по`, `процент`, `список`. Параметр с
таким именем компилятор отвергает в том месте, где имя использовано:

```text
FLANG_PARSE … неожиданное 'процент' — это слово занято языком, именем оно быть не может …
```

Переименуйте параметр или возьмите имя в ёлочки: `«процент»`. Все занятые слова
перечислены в [словаре языка](glossary.html).

## Проверьте себя

Допишите тело функции `«Стоимость заказа»`: цена, умноженная на число штук,
плюс доставка. Заготовка `total-price.flang`:

```flang refused insert docs/examples/tour/exercises/1-total-price/stub/total-price.flang
модуль «Exercise 1»

тотальная функция «Стоимость заказа»
  принимает цена: число, штук: число, доставка: число
  возвращает число
  пример «три по сто и доставка»
    дано цена равно 100
    дано штук равно 3
    дано доставка равно 50
    ожидается 350
  пример «ноль штук — только доставка»
    дано цена равно 100
    дано штук равно 0
    дано доставка равно 50
    ожидается 50
  0
```

Пока вместо тела стоит `0`, оба теста не проходят:

```text insert output: check docs/examples/tour/exercises/1-total-price/stub/total-price.flang
$ flang check docs/examples/tour/exercises/1-total-price/stub/total-price.flang
модуль «Exercise 1»: функций 1, из них с доказанным завершением 1; типов 0
FLANG_EXAMPLE: пример «три по сто и доставка» функции «Стоимость заказа»: значение не совпало с ожидаемым: ожидалось 350, получено 0
FLANG_EXAMPLE: пример «ноль штук — только доставка» функции «Стоимость заказа»: значение не совпало с ожидаемым: ожидалось 50, получено 0
docs/examples/tour/exercises/1-total-price/stub/total-price.flang: не проверено — замечаний 2
$ echo $?
1
```

Строка `FLANG_EXAMPLE` называет тест, ожидаемое значение и полученное. Задание
выполнено, когда `flang check` отвечает «замечаний нет».
