# Списки и строки

Как пройти по списку, если в языке нет изменяемых переменных, и как собрать
строку из частей? Вторая страница тура, на 5–10 минут. Перед ней —
[Функции и тесты](tour-functions.html).

## Три прохода по списку

Сохраните в `cart.flang`:

```flang insert docs/examples/tour/lists/cart.flang
модуль «Cart»

тотальная функция «Сумма корзины»
  принимает цены: список числа
  возвращает число
  пример «три товара»
    дано цены равно [100, 250, 50]
    ожидается 400
  пример «пустая корзина»
    дано цены равно []
    ожидается 0
  свёртка цены начиная с 0 как сумма и цена → сумма плюс цена

тотальная функция «Цены со скидкой»
  принимает цены: список числа, скидка: число
  возвращает список числа
  пример «минус десять процентов»
    дано цены равно [100, 250]
    дано скидка равно 10
    ожидается [90, 225]
  отобразить цены как цена → цена минус (цена умножить на скидка делить на 100)

тотальная функция «Дорогие»
  принимает цены: список числа, порог: число
  возвращает список числа
  пример «дороже ста»
    дано цены равно [100, 250, 50, 300]
    дано порог равно 100
    ожидается [250, 300]
  отфильтровать цены где цена → цена больше порог

тотальная функция «Сколько дорогих»
  принимает цены: список числа, порог: число
  возвращает число
  пример «два из четырёх»
    дано цены равно [100, 250, 50, 300]
    дано порог равно 100
    ожидается 2
  длина («Дорогие» от цены и порог)
```

Тип `список числа` — список чисел (`Vec<f64>` в Rust, `number[]` в TypeScript).
Значение пишется в квадратных скобках: `[100, 250, 50]`, пустой список — `[]`.

Три формы обходят список, каждая знакома по другим языкам:

| Форма | Что делает | В других языках |
| --- | --- | --- |
| `свёртка цены начиная с 0 как сумма и цена → …` | сводит список к одному значению | `reduce`, `fold` |
| `отобразить цены как цена → …` | строит список той же длины | `map` |
| `отфильтровать цены где цена → …` | оставляет подходящие элементы | `filter` |

`свёртка` работает как `reduce`. Она начинает с `0` и на каждом шаге получает
накопленное значение (`сумма`) и очередной элемент (`цена`). Выражение после
стрелки даёт новое накопленное значение. Стрелку можно набрать `→`, `->` или `=>`.

`длина` возвращает число элементов. Ей можно передать результат другой функции,
как в `«Сколько дорогих»`.

```text insert output: test docs/examples/tour/lists/cart.flang
$ flang test docs/examples/tour/lists/cart.flang
docs/examples/tour/lists/cart.flang: примеров 5, прошло 5, не прошло 0
```

```text insert output: run docs/examples/tour/lists/cart.flang --function Дорогие --args '{"цены": [100, 250, 50, 300], "порог": 200}'
$ flang run docs/examples/tour/lists/cart.flang --function Дорогие --args '{"цены": [100, 250, 50, 300], "порог": 200}'
доказано: утверждений 0
[250,300]
```

Список в аргументах — массив JSON, результат тоже выводится массивом.

## Строки

Сохраните в `receipt.flang`:

```flang insert docs/examples/tour/lists/receipt.flang
модуль «Receipt»

тотальная функция «Строка чека»
  принимает название: строка, цена: число
  возвращает строка
  пример «чай за сто двадцать»
    дано название равно "чай"
    дано цена равно 120
    ожидается "чай: 120 ₽"
  соединить [название, ": ", (к строке цена), " ₽"] по ""

тотальная функция «Число слов»
  принимает текст: строка
  возвращает число
  пример «три слова»
    дано текст равно "зелёный чай листовой"
    ожидается 3
  длина (разделить текст по " ")

тотальная функция «Первое слово»
  принимает текст: строка
  возвращает строка
  пример «первое из трёх»
    дано текст равно "зелёный чай листовой"
    ожидается "зелёный"
  элемент 1 в (разделить текст по " ")

тотальная функция «Чек»
  принимает названия: список строки
  возвращает строка
  пример «два товара через запятую»
    дано названия равно ["зелёный чай", "мёд"]
    ожидается "зелёный, мёд"
  соединить (отобразить названия как название → «Первое слово» от название) по ", "
```

| Форма | Что делает | В других языках |
| --- | --- | --- |
| `соединить [а, б, в] по ""` | склеивает список строк через разделитель | `join` |
| `разделить текст по " "` | режет строку на список строк | `split` |
| `к строке цена` | превращает число в строку | `to_string()`, `String(x)` |
| `элемент 1 в список` | берёт элемент по номеру | `list[0]` |

Число само строкой не становится: `соединить` принимает только строки, поэтому
цена проходит через `к строке`.

Номера начинаются с единицы. Номер за пределами списка останавливает программу
с ошибкой `FLANG_BUILTIN_ARGS`; проверка файла такую ошибку заранее не находит.

```text insert output: run docs/examples/tour/lists/receipt.flang --function Чек --args '{"названия": ["чёрный чай", "мёд"]}'
$ flang run docs/examples/tour/lists/receipt.flang --function Чек --args '{"названия": ["чёрный чай", "мёд"]}'
доказано: утверждений 0
"чёрный, мёд"
```

Строка выводится в кавычках, как в JSON.

Остальные операции над списками и строками собраны на странице
[Операции языка](operations.html).

`long-words.flang`:
