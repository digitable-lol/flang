# Циклы, классы, интерфейсы

Как записать привычный цикл и класс на языке без изменяемых переменных? Шестая,
последняя страница тура, на 5–10 минут. Перед ней — [Свои типы](tour-types.html).

`цикл`, `класс` и `интерфейс` — сокращённые записи. Компилятор переписывает их
в то, что вы уже знаете: функции, записи, типы с вариантами и `разбор`. Потом
он проверяет результат как обычно.

## Циклы

Сохраните в `savings.flang`:

```flang insert docs/examples/tour/loops/savings.flang
модуль «Savings»

тотальная функция «Средняя цена» принимает цены: список числа возвращает число
  пример «три цены»
    дано цены равно [100, 250, 100]
    ожидается 150
  пример «пустой список»
    дано цены равно []
    ожидается 0
  цикл «Подсчёт»
    для каждого цена из цены
    храним сумма: число равным 0, штук: число равным 0
    в конце если штук равен 0 то 0 иначе сумма делить на штук
    дальше: сумма станет сумма плюс цена, штук станет штук плюс 1

тотальная функция «Месяцев копить» принимает цель: число, взнос: число возвращает число
  пример «тысяча по триста — четыре месяца»
    дано цель равно 1000
    дано взнос равно 300
    ожидается 4
  пример «цель уже достигнута»
    дано цель равно 0
    дано взнос равно 300
    ожидается 0
  цикл «Копилка»
    пока осталось больше 0
    убывает осталось
    храним осталось: число равным цель, месяцев: число равным 0
    в конце месяцев
    пусть остаток равно если осталось больше взнос то осталось минус взнос иначе 0
    дальше: осталось станет остаток, месяцев станет месяцев плюс 1
```

Заголовок функции здесь записан одной строкой: `принимает` и `возвращает` идут
сразу после имени. Так можно писать любую функцию.

Строки цикла:

| Строка | Что значит | В других языках |
| --- | --- | --- |
| `для каждого цена из цены` | пройти по списку | `for price in prices` |
| `пока условие` | повторять, пока условие верно | `while` |
| `храним сумма: число равным 0, …` | значения, которые меняются от шага к шагу | `let mut sum = 0` |
| `дальше: сумма станет …, штук станет …` | новые значения для следующего шага | присваивания в теле цикла |
| `в конце выражение` | результат цикла, когда он закончился | значение после цикла |

Циклу `пока` нужна граница, иначе его завершение не доказать. Строка
`убывает осталось` называет выражение, которое обязано уменьшаться на каждом
шаге, как в [четвёртой странице тура](tour-termination.html). Другая граница —
строка `шагов не больше 100, иначе -1`: предел числа шагов и ответ, когда он
исчерпан.

## Класс и интерфейс

Сохраните в `shop.flang`:

```flang insert docs/examples/tour/loops/shop.flang
модуль «Shop»

класс «Корзина»
  покупатель: строка
  сумма: число
  всегда «сумма не отрицательна» сумма не меньше 0

  метод «Добавить» принимает цена: число
    требует «цена не отрицательна» цена не меньше 0
    пример «к ста добавили двадцать»
      дано этот равно запись «Корзина» с покупатель равным "Аня" и сумма равным 100
      дано цена равно 20
      ожидается запись «Корзина» с покупатель равным "Аня" и сумма равным 120
    сумма станет сумма плюс цена

  метод «Пуста ли» возвращает признак
    пример «в новой корзине пусто»
      дано этот равно запись «Корзина» с покупатель равным "Аня" и сумма равным 0
      ожидается да
    сумма равен 0

интерфейс «Скидка»
  метод «Вычет» принимает сумма: число возвращает число
  метод «Название» возвращает строка
    "скидка"

класс «Процентная» есть «Скидка»
  процентов: число
  метод «Вычет» принимает сумма: число возвращает число
    пример «десять процентов от тысячи»
      дано этот равно запись «Процентная» с процентов равным 10
      дано сумма равно 1000
      ожидается 100
    сумма умножить на процентов делить на 100
  метод «Название» возвращает строка
    "процентная"

класс «Купон» есть «Скидка»
  рублей: число
  метод «Вычет» принимает сумма: число возвращает число
    пример «купон на двести»
      дано этот равно запись «Купон» с рублей равным 200
      дано сумма равно 1000
      ожидается 200
    если рублей больше сумма то сумма иначе рублей

тотальная функция «К оплате» принимает сумма: число, скидка: «Скидка» возвращает число
  пример «купон на двести с тысячи»
    дано сумма равно 1000
    дано скидка равно вариант «Купон» с значение равным (запись «Купон» с рублей равным 200)
    ожидается 800
  сумма минус («Скидка: Вычет» от скидка и сумма)
```

```text insert output: check docs/examples/tour/loops/shop.flang
$ flang check docs/examples/tour/loops/shop.flang
модуль «Shop»: функций 8, из них с доказанным завершением 8; типов 4
docs/examples/tour/loops/shop.flang: проверено — доказано 1, проверено только на тестах 0, не доказано 0 (постусловий и утверждений 1); замечаний нет
```

Первая строка вывода считает то, во что переписан файл: восемь функций и
четыре типа. Что откуда взялось:

| Вы пишете | Компилятор получает |
| --- | --- |
| `класс «Корзина»` с полями | запись `«Корзина»` |
| `метод «Добавить»` | функцию `«Корзина: Добавить»` с первым параметром `этот` |
| `сумма станет …` в конце метода | новую запись `«Корзина»`; остальные поля копируются |
| `всегда «имя» условие` | условие на вход каждого метода и на запись, которую метод вернул |
| `интерфейс «Скидка»` | тип `«Скидка»` с вариантом на каждый класс `есть «Скидка»` |
| метод интерфейса | функцию `«Скидка: Вычет»` с `разбор` по классам |

Метод интерфейса без тела обязателен для каждого класса. Метод с телом —
реализация по умолчанию: `«Купон»` не объявляет `«Название»` и получает
`"скидка"`.

Метод вызывается как функция, объект идёт первым аргументом:

```text insert output: run docs/examples/tour/loops/shop.flang --function "Корзина: Добавить" --args '{"этот": {"покупатель": "Аня", "сумма": 100}, "цена": 50}'
$ flang run docs/examples/tour/loops/shop.flang --function "Корзина: Добавить" --args '{"этот": {"покупатель": "Аня", "сумма": 100}, "цена": 50}'
доказано: утверждений 1
{"покупатель":"Аня","сумма":150}
```

Метод вернул новую корзину; прежняя не изменилась. «Утверждений 1» в первой
строке — условие `всегда` для результата метода: компилятор доказал его для
всех аргументов.

Строка `требует` в методе — предусловие. Отрицательная цена его нарушает:

```text insert output: run docs/examples/tour/loops/shop.flang --function "Корзина: Добавить" --args '{"этот": {"покупатель": "Аня", "сумма": 100}, "цена": -5}'
$ flang run docs/examples/tour/loops/shop.flang --function "Корзина: Добавить" --args '{"этот": {"покупатель": "Аня", "сумма": 100}, "цена": -5}'
доказано: утверждений 1
FLANG_PRECONDITION: не выполнено требование «цена не отрицательна» функции «Корзина: Добавить»
$ echo $?
1
```

Метод не вычислялся, код возврата 1.

Значение интерфейса создаётся как вариант с полем `значение`, см. тест функции
`«К оплате»`. Наследования классов в языке нет.

## Проверьте себя

Функция `«Сколько раз подорожало»` считает, сколько раз цена выросла по
сравнению с предыдущей. Напишите её тело циклом. Заготовка `price-rises.flang`:

```flang refused insert docs/examples/tour/exercises/6-price-rises/stub/price-rises.flang
модуль «Exercise 6»

тотальная функция «Сколько раз подорожало» принимает цены: список числа возвращает число
  пример «два роста из четырёх изменений»
    дано цены равно [100, 120, 90, 90, 150]
    ожидается 2
  пример «одна цена — роста нет»
    дано цены равно [100]
    ожидается 0
  пример «пустой список»
    дано цены равно []
    ожидается 0
  0
```

храните предыдущую цену.
