# Всегда завершающиеся функции

Что значит слово `тотальная` перед функцией и что делать, когда компилятор
отвечает `FLANG_NOT_TOTAL`? Четвёртая страница тура, на 5–10 минут. Перед ней —
[Ветвление, разбор и рекурсия](tour-branching-and-recursion.html).

`тотальная функция` — функция, про которую компилятор доказал: она завершится
на любых аргументах. В Rust и TypeScript такой проверки нет, там бесконечную
рекурсию находят при запуске.

## Рекурсия, которая может не закончиться

Сохраните в `countdown.flang`:

```flang refused insert docs/examples/tour/termination/refused/countdown.flang
модуль «Countdown»

тотальная функция «Сумма до»
  принимает н: число
  возвращает число
  пример «до трёх»
    дано н равно 3
    ожидается 6
  если н равен 0
    то 0
    иначе н плюс («Сумма до» от (н минус 1))
```

Тест проходит: 3 + 2 + 1 = 6. Проверка — нет:

```text insert output: check docs/examples/tour/termination/refused/countdown.flang
$ flang check docs/examples/tour/termination/refused/countdown.flang
модуль «Countdown»: функций 1, из них с доказанным завершением 0; типов 0
без доказанного завершения: «Сумма до»
FLANG_NOT_TOTAL в файле docs/examples/tour/termination/refused/countdown.flang, строка 11, столбец 19: тотальная функция «Сумма до»: рекурсивный вызов «Сумма до» не убывает — аргумент 1 («н» sub 1) уменьшает параметр «н», но снизу «н» ничем не ограничен: добавьте проверку вида «если н не больше 0». Передавайте часть аргумента: хвост списка из образца «голова и хвост», поле варианта из образца, поле записи или элемент коллекции
docs/examples/tour/termination/refused/countdown.flang: не проверено — замечаний 1
$ echo $?
1
```

Компилятор прав. Для аргумента −1 условие `н равен 0` не выполнится никогда, и
вызовы пойдут дальше: −2, −3, … Сообщение называет вызов (строка 11), параметр
и причину: «снизу `н` ничем не ограничен». Запись `«н» sub 1` в нём означает
`н минус 1`. Код возврата 1.

## Исправление: тип с нижней границей

Тип `неотрицательное` — целое от 0 до 2⁵³−1 (ближе всего `u64` в Rust). С ним
и с условием `не больше 0` отрицательных аргументов не бывает:

```flang insert docs/examples/tour/termination/countdown.flang
модуль «Countdown»

тотальная функция «Сумма до»
  принимает н: неотрицательное
  возвращает число
  пример «до трёх»
    дано н равно 3
    ожидается 6
  если н не больше 0
    то 0
    иначе н плюс («Сумма до» от (н минус 1))
```

```text insert output: check docs/examples/tour/termination/countdown.flang
$ flang check docs/examples/tour/termination/countdown.flang
модуль «Countdown»: функций 1, из них с доказанным завершением 1; типов 0
docs/examples/tour/termination/countdown.flang: проверено — доказано 0, проверено только на тестах 0, не доказано 0 (постусловий и утверждений 0); замечаний нет
```

Отчёт о доказательствах говорит, чем доказано завершение:

```text insert output: check docs/examples/tour/termination/countdown.flang --proof 2>&1 | grep "Сумма до"
$ flang check docs/examples/tour/termination/countdown.flang --proof 2>&1 | grep "Сумма до"
$ echo $?
1
```

Аргумент уменьшается на единицу и ограничен типом снизу и сверху. Два
последних слова строки значат: проверка во время выполнения не нужна.

Отрицательный аргумент отвергается при вызове, код возврата 1:

```text insert output: run docs/examples/tour/termination/countdown.flang --function "Сумма до" --args '{"н": -3}'
$ flang run docs/examples/tour/termination/countdown.flang --function "Сумма до" --args '{"н": -3}'
доказано: утверждений 0
FLANG_TYPE: вызов функции «Сумма до»: аргумент «н»: -3 вне неотрицательное
$ echo $?
1
```

## Когда убывание не видно по записи

Сохраните в `steps.flang`:

```flang insert docs/examples/tour/termination/steps.flang
модуль «Steps»

тотальная функция «НОД»
  принимает а: число, б: число
  возвращает число
  убывает б
  пример «двенадцать и восемнадцать»
    дано а равно 12
    дано б равно 18
    ожидается 6
  если б равен 0
    то а
    иначе «НОД» от б и (а остаток от б)

функция «Шагов до единицы»
  принимает н: число
  возвращает число
  пример «шесть приходит к единице за восемь шагов»
    дано н равно 6
    ожидается 8
  если н не больше 1
    то 0
    иначе если (н остаток от 2) равен 0
      то 1 плюс («Шагов до единицы» от (н делить на 2))
      иначе 1 плюс («Шагов до единицы» от (3 умножить на н плюс 1))
```

```text insert output: check docs/examples/tour/termination/steps.flang
$ flang check docs/examples/tour/termination/steps.flang
модуль «Steps»: функций 2, из них с доказанным завершением 1; типов 0
без доказанного завершения: «Шагов до единицы»
docs/examples/tour/termination/steps.flang: проверено — доказано 0, проверено только на тестах 0, не доказано 0 (постусловий и утверждений 0); замечаний нет
```

В файле два других способа.

**Строка `убывает б`.** В алгоритме Евклида второй аргумент уменьшается, но по
записи `а остаток от б` компилятор этого не видит. Строка `убывает` называет
выражение, которое обязано уменьшаться на каждом вызове:

```text insert output: check docs/examples/tour/termination/steps.flang --proof 2>&1 | grep "НОД"
$ flang check docs/examples/tour/termination/steps.flang --proof 2>&1 | grep "НОД"
$ echo $?
1
```

Вторая половина строки значит: убывание не доказано, оно проверяется при
каждом вызове во время выполнения. На дробных числах проверка
срабатывает, и вместо бесконечной рекурсии приходит ошибка:

```text insert output: run docs/examples/tour/termination/steps.flang --function НОД --args '{"а": 1.5, "б": 0.4}'
$ flang run docs/examples/tour/termination/steps.flang --function НОД --args '{"а": 1.5, "б": 0.4}'
не доказано: утверждений 0: доказано 0, сетка 0, на веру 0; законов на сетке 0, на веру 1 — запуск только по явному согласию: --trust
недоказанное — поимённо, словами отчёта о доказательствах:
  1. завершение «НОД» — на веру: спуск объявленной меры ядром не выведен, завершение функции не доказано; сторож считает меру при работе
«на веру» закрывается так: за утверждением не стоит ни одной пробы: посчитать его хоть примерами, доказать — теоремой
отчёт о доказательствах целиком, с правилами и у доказанных тоже: flang check docs/examples/tour/termination/steps.flang --proof
$ echo $?
3
```

**Функция без слова `тотальная`.** Закончится ли `«Шагов до единицы»` для
любого числа, не знает никто: это открытая задача математики. Такую функцию
объявляют просто `функция`. Компилятор проверяет в ней типы и тесты, а о
завершении сообщает: «без доказанного завершения».

Вызвать обычную функцию из `тотальная` нельзя, это тоже ошибка
`FLANG_NOT_TOTAL`.

## Что выбрать

| Способ | Когда | Цена |
| --- | --- | --- |
| `разбор` по списку или своему типу | функция обходит данные по частям | нет |
| тип `неотрицательное` и шаг на единицу | счёт вниз до нуля | нет |
| строка `убывает выражение` | убывание есть, но не видно по записи | проверка при каждом вызове |
| `функция` без `тотальная` | алгоритм может не закончиться | её нельзя вызвать из `тотальная` |

Пробуйте способы сверху вниз.

## Проверьте себя

Функция `«Цифр в числе»` отбрасывает последнюю цифру, пока число не станет
меньше десяти. Заготовка `digits.flang` не проходит проверку:

```flang refused insert docs/examples/tour/exercises/4-digits/stub/digits.flang
модуль «Exercise 4»

тотальная функция «Цифр в числе»
  принимает н: число
  возвращает число
  пример «в сорока двух две цифры»
    дано н равно 42
    ожидается 2
  пример «в семёрке одна»
    дано н равно 7
    ожидается 1
  если н меньше 10
    то 1
    иначе 1 плюс («Цифр в числе» от ((н минус (н остаток от 10)) делить на 10))
```

```text insert output: check docs/examples/tour/exercises/4-digits/stub/digits.flang
$ flang check docs/examples/tour/exercises/4-digits/stub/digits.flang
модуль «Exercise 4»: функций 1, из них с доказанным завершением 0; типов 0
без доказанного завершения: «Цифр в числе»
FLANG_NOT_TOTAL в файле docs/examples/tour/exercises/4-digits/stub/digits.flang, строка 14, столбец 19: тотальная функция «Цифр в числе»: рекурсивный вызов «Цифр в числе» не убывает — аргумент 1 («н» sub «н» mod 10 div 10) не выведен ни из одного параметра. Передавайте часть аргумента: хвост списка из образца «голова и хвост», поле варианта из образца, поле записи или элемент коллекции
docs/examples/tour/exercises/4-digits/stub/digits.flang: не проверено — замечаний 1
$ echo $?
```

Аргумент вызова не похож ни на «параметр минус единица», ни на часть списка.
Добавьте одну строку, чтобы проверка прошла.
