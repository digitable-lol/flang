# Устранение неполадок

Слева — что видно на экране, дальше — отчего это и что набрать. Сообщения
приведены дословно.

## Установка и сборка

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `flang: command not found` после `make -C bootstrap` | сборка кладёт двоичный в `bootstrap/flang`, а не в `PATH` | `sudo make -C bootstrap install` или зовите `./bootstrap/flang` |
| `flang: command not found` после установки одной строкой | `~/.local/bin` нет в `PATH` | добавьте в профиль оболочки `export PATH="$HOME/.local/bin:$PATH"` |
| `cc: command not found` при сборке из клона | нет компилятора C | `sudo apt install build-essential` (Fedora — `sudo dnf install gcc make`, Alpine — `apk add build-base`, macOS — `xcode-select --install`) |
| `make: command not found` при сборке из клона | `make` не поставлен | соберите одним вызовом `cc` — [Установка](install.html#из-исходников) |
| `flang --version` отвечает не строкой `flang <версия>` | раньше на `PATH` стоит LLVM Flang, компилятор Фортрана с тем же именем | поставьте каталог нашего `flang` в `PATH` первым или зовите его полным путём |
| Оболочка отвечает `вычислять нечем: не найден libcompiler_flang.a` | двоичный поставлен без библиотеки, выражения считать нечем | укажите каталог с `libcompiler_flang.a` в `FLANG_LIB_DIR`, с заголовками — в `FLANG_INCLUDE_DIR` |

## Проверка отвечает не про то

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `место указано строкой и столбцом, но без файла` | вместе с импортами проверено несколько файлов. Беда во ввезённом модуле несёт путь в тексте: `в файле …/сосед.flang:`; беда без пути — в вашем файле | проверьте названный модуль отдельно: `flang check сосед.flang` |
| `FLANG_IMPORT_NOT_FOUND: не найден модуль «Имя»: ни рядом с файлом, ни выше по каталогам, ни в библиотеке компилятора` | поиск по имени модуля файла не нашёл — либо файл нашёлся, но не прошёл проверку | назовите путь: `использует «Имя» из "путь/файл.flang"`; затем проверьте сам модуль |
| `не проверено — … не печатается у программы с замечаниями` | `check --proof` печатает отчёт о доказательствах только у программы без замечаний | почините замечания выше этой строки |
| `FLANG_RECURSION_LIMIT` у `flang check` на большом файле | кончился предел шагов проверяющего | `flang check файл.flang --step-limit N` |
| Код возврата 5 | прогон дошёл до предела памяти (по умолчанию три четверти памяти машины) | `--memory-limit N`, например `--memory-limit 16G` |

## `run` или `io` не запускает программу

```
не доказано: … — запуск только по явному согласию: --trust
```

Код возврата 3. `flang run` и `flang io` перед запуском проверяют доказательства
и не запускают программу, у которой гарантии не доказаны или есть замечания.
Строка называет первое замечание.

| Что нужно | Что набрать |
| --- | --- |
| Увидеть все замечания | `flang check файл.flang` |
| Запустить всё равно, один раз | `--unproven warn` — предупредит и запустит; `--trust` — запустит без проверки доказательств |
| Запускать всё равно всегда | `unproven = warn` в `.flangrc` |

## Прогон упирается в предел

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `FLANG_RECURSION_LIMIT: функция «Имя» исчерпала лимит шагов (N) на глубине вызовов M`, код 1 | кончился предел шагов вычисления | `--max-steps N` у `run`, `test`, `io` |
| `FLANG_RECURSION_LIMIT: функция «Имя» превысила предел глубины вызовов (N) на глубине M` | кончился предел глубины вызовов | `--max-depth N`, а лучше переписать рекурсию свёрткой |
| План остановился, не дойдя до конца | у `flang io` предел — 10 000 поручений за прогон | `--max-orders N` |

Увидеть сообщение на маленьком пределе:

```bash
flang run docs/examples/rosetta/factorial.flang --function 'Факториал' --args '{"н":30}' --max-steps 3
```

```
доказано: утверждений 0
FLANG_RECURSION_LIMIT: функция «Факториал» исчерпала лимит шагов (3) на глубине вызовов 1
```

Код возврата 1.

## Печать программы с процессами отказывает

Планировщик процессов печатается не во все цели:

| Цель | Что происходит |
| --- | --- |
| `c`, `elixir`, `js`, `ts` | планировщик печатается, код 0 |
| `cpp`, `csharp`, `go`, `java`, `python`, `rust` | печать отказывает, код 1, ни одного файла не записано |

Отказ выглядит так:

```
flang emit: печать отказала — у цели «go» нет планировщика конкурентности, а в программе
объявлена конкурентность (процессов 3, надзоров 1, прогонов 3), первый — процесс «Приёмная».
```

Печатайте такую программу в `c`, `elixir`, `js` или `ts`:

```bash
flang emit ваш-файл.flang --target elixir --out ./вывод
```

## Языковой сервер в редакторе

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Редактор настроен, подсказок и подчёркиваний нет | редактор не может запустить `flang lsp`: двоичного нет в `PATH` | проверьте команду сервера в настройках редактора — [Настройка редактора](editor.html) |
| Подсветки нет в Emacs | подсветка есть только для Vim, Neovim и VS Code | диагностику даёт сервер или `flang check` на клавише — см. ту же страницу |

Проверить, отвечает ли сервер:

```bash
printf 'Content-Length: 75\r\n\r\n{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"capabilities":{}}}' | flang lsp --stdio
```

Сервер жив, если печатает `Content-Length: …` и ответ с `"capabilities"`.
