# Если не работает

Что делать, когда `flang` не ставится, не запускается или отвечает непонятно?
Слева в таблицах — что видно на экране, дальше — причина и что набрать.
Сообщения приведены дословно.

## Установка и сборка

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `flang: command not found` после `make -C bootstrap` | сборка создаёт программу `bootstrap/flang` и не добавляет её в `PATH` | `sudo make -C bootstrap install` или вызывайте её по пути `./bootstrap/flang` |
| `flang: command not found` после установки одной строкой | каталога `~/.local/bin` нет в `PATH` | добавьте в профиль оболочки `export PATH="$HOME/.local/bin:$PATH"` |
| `cc: command not found` при сборке из клона | нет компилятора C | `sudo apt install build-essential` (Fedora — `sudo dnf install gcc make`, Alpine — `apk add build-base`, macOS — `xcode-select --install`) |
| `make: command not found` при сборке из клона | `make` не установлен | соберите одним вызовом `cc` — [Установка](install.html#из-исходников) |
| `flang --version` отвечает не строкой `flang <версия>` | в `PATH` первым стоит LLVM Flang, компилятор Фортрана с тем же именем | поставьте каталог нашего `flang` в `PATH` первым или вызывайте его полным путём |

## Проверка сообщает не о том файле

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `место указано строкой и столбцом, но без файла` | вместе с импортами проверено несколько файлов. Ошибка в импортированном модуле идёт с путём: `в файле …/сосед.flang:`. Ошибка без пути относится к вашему файлу | проверьте названный модуль отдельно: `flang check сосед.flang` |
| `FLANG_IMPORT_NOT_FOUND: не найден модуль «Имя»: ни рядом с файлом, ни выше по каталогам, ни в библиотеке компилятора` | файл модуля не найден по имени либо найден, но не прошёл проверку | укажите путь: `использует «Имя» из "путь/файл.flang"`; затем проверьте сам модуль |
| `не проверено — … у программы с замечаниями` | отчёт о доказательствах ключ `--proof` выводит только для файла без ошибок | исправьте ошибки, названные выше этой строки |
| `FLANG_RECURSION_LIMIT` у `flang check` на большом файле | компилятор исчерпал предел шагов | `flang check файл.flang --step-limit N` |
| Код возврата 5 | достигнут предел памяти (по умолчанию три четверти памяти машины) | `--memory-limit N`, например `--memory-limit 16G` |

## `run` или `io` не запускает программу

Первая строка ответа выглядит так:

```text
не доказано: … — запуск только по явному согласию: --на-веру
```

Код возврата 3. Команды `flang run` и `flang io` перед запуском проверяют
доказательства. Программу с недоказанным постусловием или с ошибкой проверки
они не запускают. Следующие строки ответа называют каждое такое постусловие.
`--на-веру` — русское написание ключа `--trust`.

| Что нужно | Что набрать |
| --- | --- |
| Увидеть все ошибки | `flang check файл.flang` |
| Запустить один раз | `--unproven warn` — предупредит и запустит; `--trust` — запустит без проверки доказательств |
| Запускать всегда | `unproven = warn` в файле настроек `.flangrc` |

Как довести постусловие до «доказано» — [Первое доказательство](first-proof.html).

## Вычисление упирается в предел

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `FLANG_RECURSION_LIMIT: функция «Имя» исчерпала лимит шагов (N) на глубине вызовов M`, код 1 | исчерпан предел шагов вычисления | `--max-steps N` у `run`, `test`, `io` |
| `FLANG_RECURSION_LIMIT: функция «Имя» превысила предел глубины вызовов (N) на глубине M` | исчерпан предел глубины вызовов | `--max-depth N`; надёжнее переписать рекурсию свёрткой |
| `flang io` остановился раньше конца программы | предел — 10 000 эффектов за один запуск | `--max-orders N` |

Увидеть первое сообщение можно на маленьком пределе. Команда выполняется в
клоне репозитория:

```bash
flang run docs/examples/rosetta/factorial.flang --function 'Факториал' --args '{"н":30}' --max-steps 3
```

```text
доказано: утверждений 0
FLANG_RECURSION_LIMIT: функция «Факториал» исчерпала лимит шагов (3) на глубине вызовов 1
```

Код возврата 1.

## Генерация кода для программы с процессами не проходит

Планировщик процессов есть не во всех целевых языках:

| Целевой язык | Что происходит |
| --- | --- |
| `c`, `elixir`, `js`, `ts` | код генерируется, код возврата 0 |
| `cpp`, `csharp`, `go`, `java`, `python`, `rust` | ошибка, код возврата 1, ни одного файла не записано |

Сообщение об ошибке, команда выполняется в клоне репозитория:

```bash
flang emit docs/examples/service-on-processes/service.flang --target go --out ./out-go
```

```text
…
flang emit: печать отказала — у цели «go» нет планировщика конкурентности, а в программе
объявлена конкурентность (процессов 3, надзоров 1, прогонов 3), первый — процесс «Приёмная».
…
```

Код возврата 1. «Печать отказала» читается как «генерация кода не выполнена»,
«цель» — целевой язык. Для такой программы выбирайте `c`, `elixir`, `js` или
`ts`.

## Языковой сервер в редакторе

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Редактор настроен, подсказок и подчёркиваний нет | редактор не может запустить `flang lsp`: программы `flang` нет в `PATH` | проверьте команду сервера в настройках редактора — [Настройка редактора](editor.html) |
| Подсветки нет в Emacs | подсветка есть только для Vim, Neovim и VS Code | ошибки показывает сервер или `flang check` по клавише — см. ту же страницу |

Проверить, отвечает ли сервер:

```bash
printf 'Content-Length: 75\r\n\r\n{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"capabilities":{}}}' | flang lsp --stdio
```

```text
Content-Length: 311

{"jsonrpc":"2.0","id":1,"result":{"capabilities":{…},"serverInfo":{"name":"flang-lsp","version":"0.1.0"}}}
```

Код возврата 0. Сервер работает, если в ответе есть `"capabilities"`.
