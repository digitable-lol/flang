# Что доказано в самом flang

Страница отвечает на вопрос: сколько функций и постусловий доказано в коде
самого языка. Компилятор, стандартная библиотека и примеры написаны на flang и
проверяются тем же ядром, что и ваши программы.

Всего в репозитории {{корпус.файлов}} файлов на flang, в них
{{корпус.функций}} функций. Числа на странице подставляются при сборке сайта
из полной проверки репозитория. Она идёт несколько часов, поэтому числа могут
отставать от кода на несколько дней.

| Чем доказано завершение | Функций | Проверка во время выполнения |
| --- | ---: | --- |
| Рекурсии нет | {{носители.композиция}} | нет |
| Рекурсия по части аргумента: хвост списка, поле | {{носители.структура}} | нет |
| `неотрицательное` уменьшается на 1 | {{носители.точныйШаг}} | нет |
| `число` уменьшается на постоянную | {{носители.постоянныйШаг}} | есть |
| Объявленная мера (`убывает`) | {{носители.мера}} | есть |

В двух последних строках уменьшается `число`, то есть binary64: при большом
`х` выражение `х минус 1` равно `х`. Поэтому компилятор оставляет в коде
проверку.

Остальные {{корпус.обычных}} функций объявлены без слова `тотальная`. Трём из
них завершаться не положено: это главный цикл интерпретатора, который выполняет
чужую программу.

Строка про объявленную меру связана с известной ошибкой проверки. О ней —

## Собственный код компилятора проверен не целиком

`flang check` останавливает проверку, которая превысила предел шагов, с кодом
`FLANG_RECURSION_LIMIT`. На самых больших файлах компилятора это случается
раньше, чем проверены все тесты и доказательства. Предел поднимает ключ
`--step-limit N`.

Файлы с объявленными категориями и процессами проверяются частично. Компилятор
пишет об этом в выводе и завершается с кодом 2.

## Как проверить самому

| Что | Команда |
| --- | --- |
| Отчёт о доказательствах одного файла | `flang check <файл> --proof` |
| То же в JSON | `flang check <файл> --proof --json` |
| Код 0, только если всё доказано | `flang check <файл> --proof --strict` |
