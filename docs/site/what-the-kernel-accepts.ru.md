# Какие постусловия prover доказывает

Вы написали `обеспечивает` (postcondition), запустили `flang check файл --proof`,
и в строке про него нет слова «доказано». На этой странице — какие записи
постусловия prover доказывает и как переписать ту, которую он не доказал.

Если проверка вместо этого падает с кодом ошибки, читайте
[Ядро отказало: чья это ошибка](proof-refused.html).

Слова, которые используются ниже:

| Слово | Что значит |
| --- | --- |
| prover | часть компилятора, которая доказывает постусловия; в выводе компилятора он называется «ядро» |
| guard (условие) | условие `У` в постусловии вида `если У то Ц иначе да`: утверждение `Ц` должно быть верно только тогда, когда верно `У` |
| enum | `тип` с `вариант`ами |

Каждое утверждение на этой странице проверено прогоном `flang check --proof` на
маленьких пробных файлах текущим компилятором. В каждом разделе — код и строка,
которую напечатал отчёт о доказательствах.

## Сначала прочтите итог

Последняя строка отчёта считает результаты:

```
утверждений 18: доказано 13, условно 0, сетка 4, объявлено, не доказано 1, отвергнуто 0, нарушено 0
```

| В отчёте написано | Что это значит | Что делать |
| --- | --- | --- |
| `доказано` | верно для всех возможных входов | ничего |
| `условно` (в строке постусловия: «НО ПРИ УСЛОВИИ») | доказано, но доказательство опирается на постусловие другой функции, которое само не доказано | доказать то постусловие |
| `сетка N` | проверено только на N ваших примерах, как unit-тестами; доказательства нет | переписать одной из форм ниже |
| `объявлено, не доказано` | нет ни доказательства, ни примеров; рантайм проверяет его после каждого вызова | переписать или оставить проверку в рантайме |

Считайте только `доказано`. `сетка` и `объявлено` — оба «не доказано»; разница
лишь в том, есть ли у функции примеры.

## Быстрая таблица

| Вы написали | Доказывается? | Что писать вместо | Раздел |
| --- | --- | --- | --- |
| утверждение об одной ветви тела-`если` без условия | нет | `если <условие этой ветви> то <утверждение> иначе да` | [1](#1-тело-с-ветвлением-условие-ветви-в-guard) |
| `(длина результат) больше 0` или `пусто результат` под условием | нет | равенство конкретному значению: `результат равен "…"`, `результат равен пустой список` | [2](#2-под-условием-пишите-равенство-значению) |
| `а не больше результат` при `а: число` | файл отвергнут: `FLANG_BOUND_ON_NAN` | объявить `а: неотрицательное` или `требует а не меньше 0` | [3](#3-неравенства-зависят-от-типов-аргументов) |
| условие с перевёрнутым сравнением (`1 не больше место`, а в теле `место не меньше 1`) | нет | условие ровно как в теле | [3](#3-неравенства-зависят-от-типов-аргументов) |
| строгое неравенство (`меньше`, `больше`) над аргументами | нет | нестрогое (`не больше`) или замкнутая цель | [3](#3-неравенства-зависят-от-типов-аргументов), [4](#4-цель-без-свободных-имён-вычисляется) |
| утверждение о результате рекурсивной функции без постусловия | нет | дописать постусловие вызываемой функции | [5](#5-вызовы-prover-берёт-доказанные-постусловия-вызываемой-функции) |
| утверждение про `(свёртка …) плюс 0` или про свёртку, связанную через `пусть` | нет | свёртка как всё тело | [6](#6-свёртка-должна-быть-всем-телом) |
| свёртка по полю: `свёртка куча.свободные` | нет | передать список аргументом | [6](#6-свёртка-должна-быть-всем-телом) |
| утверждение об одном варианте аргумента-enum | да, с условием | `если отклик равен (вариант «Пока ничего») то … иначе да` | [7](#7-enum-условие-равенством-варианту) |
| `разбор` внутри постусловия | не разбирается | условие равенством варианту | [7](#7-enum-условие-равенством-варианту) |
| вызов предиката как цель | иногда | попробовать другую форму: с `равен да` и без | [8](#8-цель-признак-пробуйте-обе-формы) |
| утверждение под условием, которое тело не проверяет | нет | дизъюнкция с условием самого тела | [9](#9-условие-которого-нет-в-теле) |

## 1. Тело с ветвлением: условие ветви — в guard

Если тело начинается с `если`, prover разбивает цель по условию тела.
Утверждению про одну ветвь нужно условие, которое эту ветвь называет.

```flang
тотальная функция «Имя кода»
  принимает код: число
  возвращает строка
  обеспечивает «g1 охрана слово в слово» если (код меньше 1) или (код больше 3) то (результат равен "неизвестный") иначе да
  обеспечивает «g2 без охраны» (результат равен "неизвестный") или (код не меньше 1)
  обеспечивает «g4 охрана своими словами» если код меньше 1 то (результат равен "неизвестный") иначе да
  обеспечивает «g5 двойник» не ((код меньше 1) или (код больше 3)) или (результат равен "неизвестный")
  обеспечивает «g6 вторая ветвь иначе» если не ((код меньше 1) или (код больше 3)) то (если код равен 1 то (результат равен "первый") иначе да) иначе да
  пример «чужой»
    дано код равно 7
    ожидается "неизвестный"
  пример «первый»
    дано код равно 1
    ожидается "первый"
  если (код меньше 1) или (код больше 3)
    то "неизвестный"
    иначе если код равен 1 то "первый" иначе "второй"
```

```
постусловие «g1 охрана слово в слово» … доказано сведением цели с телом функции: правило «разбор цели по условию»
постусловие «g2 без охраны» … сетка 2 значения (примеры функции)
постусловие «g4 охрана своими словами» … доказано сведением цели с телом функции: правило «разбор цели по условию»
постусловие «g5 двойник» … доказано сведением цели с телом функции: правило «разбор случаев по внутреннему условию цели»
постусловие «g6 вторая ветвь иначе» … доказано сведением цели с телом функции: правило «разбор цели по условию»
```

Что следует из прогона:

- условие можно скопировать из тела как есть (`g1`) или взять более узкое
  условие, из которого условие тела следует (`g4`);
- доказываются и `если У то Ц иначе да`, и `не (У) или (Ц)` (`g1`, `g5`);
- утверждение про ветвь `иначе` пишется с отрицанием условия, внутреннее `если`
  вкладывается так же (`g6`);
- без условия (`g2`) утверждение не доказано, хотя оно верно.

Цепочки `иначе если` поглубже работают так же. На теле
`если код равен 200 … иначе если код равен 404 … иначе если код равен 500 …`
утверждения про вторую и третью ветви доказались и с полным путём
(`если не (код равен 200) то (если не (код равен 404) то …`), и только с
условием самой ветви (`если код равен 500 то …`).

## 2. Под условием пишите равенство значению

Prover сличает результат со значением, которое отдаёт ветвь. Свойства этого
значения он не выводит: ни длину строкового литерала, ни пустоту списка.

```flang
обеспечивает «g3 длина под охраной» если (код меньше 1) или (код больше 3) то ((длина результат) больше 0) иначе да
```

```
постусловие «g3 длина под охраной» … сетка 2 значения (примеры функции)
```

То же с пустотой:

```flang
тотальная функция «Пустой при нуле»
  принимает корень: число, все: список числа
  возвращает список числа
  обеспечивает «e1 предикат пусто» если корень не больше 0 то (пусто результат) иначе да
  обеспечивает «e2 равенство пустому» если корень не больше 0 то (результат равен пустой список) иначе да
  обеспечивает «e3 равенство без охраны» (результат равен пустой список) или (корень больше 0)
  пример «ноль»
    дано корень равно 0
    дано все равно [1]
    ожидается пустой список
  если корень не больше 0
    то пустой список
    иначе все
```

```
постусловие «e1 предикат пусто» … сетка 1 значение (примеры функции)
постусловие «e2 равенство пустому» … доказано сведением цели с телом функции: правило «разбор цели по условию»
постусловие «e3 равенство без охраны» … сетка 1 значение (примеры функции)
```

Правило: условие из тела (раздел 1) плюс равенство тому, что отдаёт ветвь. Одного
равенства (`e3`) мало. Значение может быть любым термом этой ветви, не только
литералом: `результат равен (весь минус сколько)` при теле `весь минус сколько`
доказано.

## 3. Неравенства зависят от типов аргументов

### В `число` живёт NaN

`число` — double по IEEE-754, а NaN не упорядочен: `(0 делить на 0) не больше
(0 делить на 0)` — `false`. Поэтому `а не больше (а плюс б)` ложно, когда `а` —
NaN, и компилятор отвергает файл целиком:

```
FLANG_BOUND_ON_NAN в файле nan.flang, строка 6, столбец 3: постусловие «n1 а число» функции «Сумма чисел» ЛОЖНО, и контрпример назван: «а» объявлен типом «число», а «не число» живёт в этом типе …
```

Сообщение называет три способа починки, и все три доказываются:

```flang
тотальная функция «Сумма двух»
  принимает а: неотрицательное, б: неотрицательное
  возвращает число
  обеспечивает «m1 а не больше суммы» а не больше результат
  обеспечивает «m2 б не больше суммы» б не больше результат
  а плюс б

тотальная функция «Сумма с требованием»
  принимает а: число, б: неотрицательное
  возвращает число
  требует «а неотрицательно» а не меньше 0
  обеспечивает «h1 при требовании» а не больше результат
  а плюс б

тотальная функция «Сумма с оговоркой»
  принимает а: число, б: неотрицательное
  возвращает число
  обеспечивает «h2 с оговоркой» не ((а минус а) равен 0) или (а не больше результат)
  а плюс б
```

```
постусловие «m1 а не больше суммы» … доказано по объявленным типам аргументов: цель сведена правилом «порядок по построению»
постусловие «h1 при требовании» … доказано по объявленным типам аргументов: цель сведена правилом «порядок по построению»
постусловие «h2 с оговоркой» … доказано по объявленным типам аргументов: цель сведена правилом «порядок по построению»
```

Прибавляемому значению `б` нужны и нижняя, и верхняя граница:
`5 не больше (5 плюс (0 минус 1))` — `false`, а `−∞ плюс +∞` — NaN.
`неотрицательное` даёт обе. Если одно и то же значение прибавлено к обеим
сторонам, prover доказывает неравенство под условием:

```flang
обеспечивает «h3 общая прибавка» если (о не больше п) то ((общее плюс о) не больше результат) иначе да
```

при теле `общее плюс п` доказано.

`(а минус б) плюс б равен а` для double не закон:
`((9007199254740994 минус 1) плюс 1) равен 9007199254740994` — `false`. Чтобы
сказать «ничего не потеряно», пишите равенство терму ветви:
`результат равен (весь минус сколько)`.

### Сторона неравенства — в утверждении и в условии

В **утверждении** сторона не важна: доказываются и
`(длина результат) не меньше (длина х)`, и `(длина х) не больше (длина результат)`,
и `результат не меньше а`, и `а не больше результат`.

В **условии** важна. Условие пишется ровно так, как в теле:

```flang
тотальная функция «Порог»
  принимает место: число
  возвращает число
  обеспечивает «r1 охрана как в теле» если место не меньше 1 то (результат равен место) иначе да
  обеспечивает «r2 охрана зеркалом» если 1 не больше место то (результат равен место) иначе да
  если место не меньше 1
    то место
    иначе 1
```

```
постусловие «r1 охрана как в теле» … доказано сведением цели с телом функции: правило «разбор цели по условию»
постусловие «r2 охрана зеркалом» … объявлено, не доказано
```

### Строгие неравенства

Строгое неравенство, в котором остались аргументы, не доказывается:
`результат больше (а минус 1)` при теле `а плюс б` остаётся «объявлено, не
доказано». Для остатка пишите нестрогую границу:

```flang
тотальная функция «Остаток бит целый»
  принимает ч: неотрицательное
  возвращает число
  обеспечивает «q2 остаток неотрицательного» результат меньше 65536
  обеспечивает «q3 остаток неотрицательного не больше» результат не больше 65535
  ч остаток от 65536
```

```
постусловие «q2 остаток неотрицательного» … объявлено, не доказано
постусловие «q3 остаток неотрицательного не больше» … доказано по объявленным типам аргументов: цель сведена правилом «ограниченность точным потолком по построению»
```

С `ч: число` та же функция отвергается с `FLANG_BOUND_ON_NAN`.

## 4. Цель без свободных имён вычисляется

Если в цели ничего не зависит от аргументов, prover её просто вычисляет, и
годится любое сравнение, строгое тоже:

```flang
тотальная функция «Пять»
  возвращает число
  обеспечивает «z1 замкнутая строго» результат меньше 6
  обеспечивает «z2 замкнутая больше» результат больше 0
  5

тотальная функция «Метка»
  возвращает список числа
  обеспечивает «z3 длина литерала» (длина результат) равен 3
  [100, 101, 114]
```

```
постусловие «z1 замкнутая строго» … доказано вычислением замкнутой цели: свободных имён в ней не осталось, значит значение у неё одно, и вычисление отвечает про него целиком
постусловие «z3 длина литерала» … доказано сведением цели с телом функции: правило «тождество после переписки допущением»
```

Любой функции, которая отдаёт константу или список констант, можно бесплатно
записать значение, длину и границы.

## 5. Вызовы: prover берёт доказанные постусловия вызываемой функции

Тело рекурсивной функции не разворачивается. Если тело её вызывает, prover знает
о результате только то, что говорят **доказанные** постусловия этой функции:

```flang
тотальная функция «Копия без»
  принимает х: список число
  возвращает список число
  разбор х
    случай пусто
      то пустой список
    случай голова и хвост
      то приписать голова к («Копия без» от хвост)

тотальная функция «Копия с»
  принимает х: список число
  возвращает список число
  обеспечивает «k1 длина копии» (длина результат) равен (длина х)
  разбор х
    случай пусто
      то пустой список
    случай голова и хвост
      то приписать голова к («Копия с» от хвост)

тотальная функция «Верх без»
  принимает х: список число
  возвращает список число
  обеспечивает «k2 верх над голым звеном» (длина результат) равен (длина х)
  «Копия без» от х

тотальная функция «Верх с»
  принимает х: список число
  возвращает список число
  обеспечивает «k3 верх над звеном с обещанием» (длина результат) равен (длина х)
  «Копия с» от х
```

```
постусловие «k1 длина копии» … доказано индукцией по «список»: база 1 случай, шаг при допущении на частях (1 случай)
постусловие «k2 верх над голым звеном» … объявлено, не доказано
постусловие «k3 верх над звеном с обещанием» … доказано сведением цели с телом функции: правило «цель есть допущение»
```

Поэтому, когда утверждение не доказано, посмотрите, что зовёт тело, и дайте
вызываемой функции постусловие, которое нужно утверждению. Постусловие,
проверенное только на примерах, не поможет: компилятор передаёт вызывающему
постусловие вызываемой функции, только если оно доказано («Дописать факт
вызванного» в `flang/self/proofterm.flang`).

Нерекурсивная функция без постусловий — не помеха: если `«Без обещания»` с телом
`приписать 0 к х`, то у вызывающей утверждение
`(длина результат) равен ((длина х) плюс 1)` доказано.

### Теорема по свойству вызываемой функции

Если тело — вызов, а у вызываемой функции есть нужное постусловие, утверждение
закрывает теорема в один шаг. Она работает и на голом вызове, и на вызове,
связанном через `пусть`. Здесь у `«Копия»` есть постусловие
`«копия той же длины»`: `(длина результат) не больше (длина х)`.

```flang
тотальная функция «Голый вызов»
  принимает х: список число
  возвращает список число
  обеспечивает «t1 голый вызов» (длина результат) не больше (длина х)
  «Копия» от х

теорема «t1 голый вызов»
  дано х: список число
  утверждаем (длина результат) не больше (длина х)
  по свойству «копия той же длины»
  следовательно доказано
```

```
постусловие «t1 голый вызов» … доказано: терм принят ядром, 1 шаг, правило «цель есть допущение», основания: постусловие «копия той же длины» функции «Копия»
```

Теорема, которая не прошла, отвергает весь файл: код возврата 1 и никакого
отчёта о доказательствах.

```
FLANG_PROOF_STEP в файле g3.flang, строка 22, столбец 3: шаг 1, теорема «t1 голый вызов»: не выведено заключение из постусловия «копия той же длины» функции «Копия» …
g3.flang: не проверено — ведомость не печатается у программы с замечаниями
```

Добавляйте теоремы по одной.

## 6. Свёртка должна быть всем телом

Утверждение про `свёртка` prover доказывает индукцией по свёртке — и когда шаг
записан на месте, и когда он вынесен в функцию:

```flang
тотальная функция «Счёт лямбдой»
  принимает х: список число
  возвращает число
  обеспечивает «f7 счёт лямбдой» результат равен (длина х)
  свёртка х начиная с 0 как акк и эл → акк плюс 1
```

```
постусловие «f7 счёт лямбдой» … доказано индукцией по СВЁРТКЕ тела: начало 1 случай, виток при допущении о накопителе «акк» (1 случай)
```

Только когда свёртка — всё тело и идёт по аргументу:

| Тело | Результат |
| --- | --- |
| `свёртка х начиная с 0 как акк и эл → «Счёт шагом» от акк и эл` | доказано |
| `(свёртка х … ) плюс 0` | объявлено, не доказано |
| `пусть н равно (свёртка х …)`, затем `н` | объявлено, не доказано |
| `свёртка куча.свободные …` (поле аргумента) | объявлено, не доказано |

Чинится это в программе: сделайте свёртку телом отдельной функции, которая
принимает список аргументом, и вызывайте её.

Если у шага есть ветви и нужно сказать что-то про одну из них, вынесите шаг в
функцию, где накопитель — аргумент. Тогда к шагу применим раздел 1.

Не доказывается и в такой форме: `результат не меньше 0` для суммы по
`список неотрицательное` (и с шагом на месте, и с шагом-функцией).

## 7. Enum: условие равенством варианту

Тело-`разбор` по аргументу-enum разбивается условием, которое сравнивает
аргумент с вариантом:

```flang
тип «Ответ»
  вариант «Пока ничего»
  вариант «Текст» содержит текст: строка

тотальная функция «Текст ответа»
  принимает отклик: «Ответ»
  возвращает строка
  обеспечивает «v2 равенство варианту» если отклик равен (вариант «Пока ничего») то (результат равен "") иначе да
  разбор отклик
    случай «Пока ничего»
      то ""
    случай вариант «Текст» с текст как т
      то т
```

```
постусловие «v2 равенство варианту» … доказано сведением цели с телом функции: правило «разбор цели по условию»
```

`разбор` внутри самого постусловия не разбирается; пишите вместо него такое
условие.

Вариант **с полями** тоже годится: каждому полю дайте значение через
функцию-аксессор того же аргумента. Проба
`docs/examples/proof-probes/variant-with-fields.flang` пишет одно утверждение
многими способами:

```
$ flang check docs/examples/proof-probes/variant-with-fields.flang --proof
…
утверждений 23: доказано 18 (из них индукцией 2) (из них без теоремы 16), сетка 5, объявлено, не доказано 0
```

| Как написано | Результат |
| --- | --- |
| аргумент сравнивается с вариантом без полей | доказано |
| аргумент сравнивается с вариантом с полями, поле заполнено аксессором (`«Вес груза» от «груз»`) или литералом | доказано |
| условие с отрицанием: `если не («груз» равен (вариант «Пусто»)) то …` | доказано |
| результат вызова сравнивается с вариантом без полей | доказано |
| результат вызова сравнивается с вариантом с полями, или с отрицанием | сетка |
| второе утверждение под `иначе` вместо `да` | сетка у варианта с полями |

Для списка `разбор` с `пусто` и `голова и хвост` разбивается условием
`если х равен пустой список то …` и условием `если (длина х) равен 0 то …`;
доказываются оба.

Если у enum ровно один вариант, его поле читается в постусловии через точку:
`результат равен ход.найдено` доказано.

## 8. Цель-признак: пробуйте обе формы

Цель — вызов предиката — можно написать голой или с `равен да`. В пробах обе
формы чаще всего доказывались, но в `variant-with-fields.flang` голая форма
«без полей цель голым признаком» осталась `сетка`, а то же утверждение с
`равен да` доказано. Не доказалась одна форма — попробуйте другую.

Утверждение, которое читает результат в обратную сторону, от условия к ответу,
доказывается как любое другое: при теле `(ч больше 10) и притом (ч меньше 20)`
доказаны и `если результат то (ч больше 10) иначе да`, и
`если (ч больше 10) и притом (ч меньше 20) то (результат равен да) иначе да`.

Ложное утверждение получает то же «объявлено, не доказано», что и верное, с
которым prover не справился. Прежде чем переписывать утверждение, проверьте, что
оно верно: напишите пример, который бы его сломал.

## 9. Условие, которого нет в теле

Условие разбивает цель, только если тело проверяет то же условие. При теле
`если первое меньше второе то второе иначе первое` (аргументы `неотрицательное`):

| Утверждение | Результат |
| --- | --- |
| `результат не меньше первое` | объявлено, не доказано |
| `если (первое больше 0) и притом (второе больше 0) то (результат не меньше первое) иначе да` | объявлено, не доказано |
| `(не (первое меньше второе)) или (результат не меньше первое)` | объявлено, не доказано |
| `(первое меньше второе) или (результат не меньше первое)` | доказано |

Пишите утверждение по исходам условия самого тела.

## 10. Конъюнкции

Конъюнкция в утверждении (`Ц1 и притом Ц2`) может доказаться целиком: в пробах
`если ч равен 0 то ((результат равен 1) и притом (результат больше 0)) иначе да`
доказана. Если не доказалась — разбейте её на отдельные строки `обеспечивает`:
prover разберёт каждую отдельно, и отчёт покажет, в какой части дело.

Конъюнкцию в **условии** разбивать нельзя: `если А и притом Б то В` и
`если А то В` — разные утверждения, и второе сильнее. Дизъюнкцию в условии
разбить можно без изменения смысла: `если (А или Б) то В` — то же, что два
утверждения `если А то В` и `если Б то В`.

## Чего отчёт не говорит

У недоказанного утверждения без теоремы отчёт всегда печатает один и тот же
текст, какой бы ни была причина:

```
объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
```

Какого правила не хватило, он не говорит. Отказ с перечнем видов цели, которые
prover умеет, приходит только для написанной вами теоремы (см.
[Ядро отказало](proof-refused.html)).

## Примеры не делают доказательства

Пример, добавленный к утверждению, переводит его из «объявлено, не доказано» в
«сетка», а не в «доказано»:

```
постусловие «k4 с примером» … сетка 1 значение (примеры функции)
```

«Объявлено» не хуже «сетки»: рантайм проверяет его на каждом настоящем вызове,
а `сетка` говорит лишь, что прошли ваши примеры.

## Проверьте, что доказанное утверждение не пустое

Утверждение, верное при любом теле, ничего не доказывает. Чтобы проверить,
замените тело заглушкой того же типа и снимите отчёт заново. Если утверждение
всё ещё доказано, о функции оно ничего не говорит.

Берите две заглушки: нулевую (`0`, `""`, `нет`, пустой список) и ненулевую
(`1`, `"я"`, `да`, `["я"]`). Утверждение вида `… то результат равен да иначе да`
переживает заглушку `да` и падает только на `нет`. Заменяйте по одной функции:
если заглушки стоят в двух функциях сразу, утверждение, которое упоминает
другую, может выглядеть пустым, хотя это не так.

## Большие файлы и предел шагов

Файлу с большим числом утверждений может не хватить шагов: проверка
останавливается с `FLANG_RECURSION_LIMIT` и отчёта не печатает. Поднять предел на
один прогон — ключ `--step-limit N` (кириллицей `--предел-шагов`); значение по
умолчанию вшито в двоичный файл (`FL_MAX_STEPS` в `bootstrap/flang_runtime.h`).

## Порядок работы

1. Запустите `flang check <файл> --proof` и сохраните последнюю строку отчёта.
2. У тела с ветвлением добавьте условия из тела (разделы 1 и 2).
3. Где есть неравенство, поменяйте тип аргументов на `неотрицательное` или
   добавьте `требует` (раздел 3).
4. Для оставшегося посмотрите на вызываемые функции и дайте им постусловия,
   которые нужны утверждению (раздел 5).
5. Снимите отчёт заново и сравните число `доказано` с сохранённой строкой. Не
   выросло — откатите правку.
