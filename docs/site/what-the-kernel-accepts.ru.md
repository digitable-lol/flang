# Что ядро умеет

Справочник отвечает на вопрос: какие записи постусловия ядро доказывает само и
как переписать ту, которую оно не доказало. Под каждым примером стоит вывод
`flang check файл --proof` от `flang {{выпуск.версия}}`. Файлы лежат в
`docs/examples/proofs/kernel`.

Имена постусловий в примерах начинаются с метки (`g1`, `e2`), чтобы на них
было удобно ссылаться в тексте.

## Таблица форм

| Вы написали | Доказывается | Что писать | Раздел |
| --- | --- | --- | --- |
| утверждение об одной ветви `если` без условия | нет | `если <условие ветви> то <утверждение> иначе да` | [1](#1-тело-с-ветвлением-добавьте-условие-ветви) |
| `(длина результат) больше 0` или `пусто результат` под условием | нет | равенство значению: `результат равен пустой список` | [2](#2-под-условием-пишите-равенство-значению) |
| `а не больше результат` при `а: число` | ошибка `FLANG_BOUND_ON_NAN` | `а: неотрицательное` или `требует а не меньше 0` | [3](#3-неравенства-зависят-от-типов) |
| условие с переставленными сторонами сравнения | нет | условие в том же виде, что в теле | [3](#3-неравенства-зависят-от-типов) |
| строгое неравенство над аргументами | нет | нестрогое: `не больше` | [3](#3-неравенства-зависят-от-типов) |
| утверждение о результате рекурсивной функции без постусловия | нет | постусловие у вызываемой функции | [5](#5-вызовы-нужно-доказанное-постусловие-вызываемой-функции) |
| `(свёртка …) плюс 0`, свёртка через `пусть`, свёртка по полю | нет | свёртка как всё тело отдельной функции | [6](#6-свёртка-должна-быть-всем-телом) |
| утверждение об одном варианте аргумента | да, с условием | `если отклик равен (вариант «…») то … иначе да` | [7](#7-тип-с-вариантами-условие-равенством-варианту) |
| `разбор` внутри постусловия | нет | условие равенством варианту | [7](#7-тип-с-вариантами-условие-равенством-варианту) |

Без переписывания ядро доказывает и свободные утверждения: свойства функций над
списками, линейные неравенства над `точное целое`, законы моноида и монады.
Примеры — [Теоремы по шагам](manual-proofs.html#4-утверждение-без-функции).

## 1. Тело с ветвлением: добавьте условие ветви

Если тело начинается с `если`, ядро разбирает постусловие по условию тела.
Утверждению про одну ветвь нужно условие, которое эту ветвь называет. Файл
`branch-condition.flang`:

```flang insert docs/examples/proofs/kernel/branch-condition.flang
модуль «Branch condition»

тотальная функция «Имя кода»
  принимает код: число
  возвращает строка
  обеспечивает «g1 охрана слово в слово» если (код меньше 1) или (код больше 3) то (результат равен "нет") иначе да
  обеспечивает «g2 без охраны» (результат равен "нет") или (код не меньше 1)
  обеспечивает «g4 охрана своими словами» если код меньше 1 то (результат равен "нет") иначе да
  обеспечивает «g5 двойник» не ((код меньше 1) или (код больше 3)) или (результат равен "нет")
  обеспечивает «g6 ветвь иначе» если не ((код меньше 1) или (код больше 3)) то (результат равен "есть") иначе да
  пример «чужой»
    дано код равно 7
    ожидается "нет"
  пример «первый»
    дано код равно 1
    ожидается "есть"
  если (код меньше 1) или (код больше 3)
    то "нет"
    иначе "есть"
```

```
постусловие «g1 охрана слово в слово» … доказано сведением цели с телом функции: правило «разбор цели по условию» …
постусловие «g2 без охраны» … сетка 2 значения (примеры функции) …
постусловие «g4 охрана своими словами» … доказано сведением цели с телом функции …
постусловие «g5 двойник» … доказано … правило «разбор случаев по внутреннему условию цели» …
постусловие «g6 ветвь иначе» … доказано сведением цели с телом функции …
```

Словом «сетка» компилятор называет ответ «проверено только на тестах».

- условие можно скопировать из тела (`g1`) или взять более узкое (`g4`);
- доказываются обе записи: `если У то Ц иначе да` и `не (У) или (Ц)` (`g1`, `g5`);
- утверждение про ветвь `иначе` пишется с отрицанием условия (`g6`);
- без условия (`g2`) верное утверждение остаётся недоказанным.

## 2. Под условием пишите равенство значению

Ядро сравнивает результат со значением, которое возвращает ветвь. Свойства
этого значения оно не выводит: ни длину строки, ни пустоту списка. Файл
`empty-at-zero.flang`:

```flang insert docs/examples/proofs/kernel/empty-at-zero.flang
модуль «Equality to a value»

тотальная функция «Пустой при нуле»
  принимает корень: число, все: список числа
  возвращает список числа
  обеспечивает «e1 предикат пусто» если корень не больше 0 то (пусто результат) иначе да
  обеспечивает «e2 равенство пустому» если корень не больше 0 то (результат равен пустой список) иначе да
  обеспечивает «e3 равенство без охраны» (результат равен пустой список) или (корень больше 0)
  пример «ноль»
    дано корень равно 0
    дано все равно [1]
    ожидается пустой список
  если корень не больше 0
    то пустой список
    иначе все
```

```
постусловие «e1 предикат пусто» … сетка 1 значение (примеры функции) …
постусловие «e2 равенство пустому» … доказано сведением цели с телом функции …
постусловие «e3 равенство без охраны» … сетка 1 значение (примеры функции) …
```

Нужны обе части: условие из тела и равенство тому, что возвращает ветвь.
Одного равенства (`e3`) мало. Значением может быть любое выражение ветви:
`результат равен (весь минус сколько)` при теле `весь минус сколько` доказано.

## 3. Неравенства зависят от типов

`число` — binary64, и NaN в нём не упорядочен. Поэтому `а не больше (а плюс
б)` ложно, когда `а` равно NaN. Такое постусловие компилятор отвергает с
ошибкой `FLANG_BOUND_ON_NAN`. Сообщение называет три исправления, и все три
доказываются. Файл `sum-bounds.flang`:

```flang insert docs/examples/proofs/kernel/sum-bounds.flang
модуль «Sum bounds»

тотальная функция «Сумма двух»
  принимает а: неотрицательное, б: неотрицательное
  возвращает число
  обеспечивает «m1 а не больше суммы» а не больше результат
  обеспечивает «m2 б не больше суммы» б не больше результат
  а плюс б

тотальная функция «Сумма с требованием»
  принимает а: число, б: неотрицательное
  возвращает число
  требует «а неотрицательно» а не меньше 0
  обеспечивает «h1 при требовании» а не больше результат
  а плюс б

тотальная функция «Сумма с оговоркой»
  принимает а: число, б: неотрицательное
  возвращает число
  обеспечивает «h2 с оговоркой» не ((а минус а) равен 0) или (а не больше результат)
  а плюс б
```

```
постусловие «m1 а не больше суммы» … доказано по объявленным типам аргументов: цель сведена правилом «порядок по построению» …
постусловие «h1 при требовании» … доказано по объявленным типам аргументов …
постусловие «h2 с оговоркой» … доказано по объявленным типам аргументов …
```

Прибавляемому значению нужны обе границы, нижняя и верхняя. Тип
`неотрицательное` даёт обе.

`(а минус б) плюс б равен а` для binary64 неверно выше 2⁵³. Чтобы сказать
«ничего не потеряно», пишите равенство выражению ветви.

В утверждении стороны сравнения можно менять местами: `результат не меньше а`
и `а не больше результат` доказываются одинаково. В условии нельзя. Файл
`threshold.flang`:

```flang insert docs/examples/proofs/kernel/threshold.flang
модуль «Threshold»

тотальная функция «Порог»
  принимает место: число
  возвращает число
  обеспечивает «r1 охрана как в теле» если место не меньше 1 то (результат равен место) иначе да
  обеспечивает «r2 охрана зеркалом» если 1 не больше место то (результат равен место) иначе да
  если место не меньше 1
    то место
    иначе 1
```

```
постусловие «r1 охрана как в теле» … доказано сведением цели с телом функции …
постусловие «r2 охрана зеркалом» … объявлено, не доказано …
```

Строгое неравенство над аргументами не доказывается. Для остатка пишите
нестрогую границу. Файл `remainder-bound.flang`:

```flang insert docs/examples/proofs/kernel/remainder-bound.flang
модуль «Remainder bound»

тотальная функция «Остаток бит целый»
  принимает ч: неотрицательное
  возвращает число
  обеспечивает «q2 остаток неотрицательного» результат меньше 65536
  обеспечивает «q3 остаток неотрицательного не больше» результат не больше 65535
  ч остаток от 65536
```

```
постусловие «q2 остаток неотрицательного» … объявлено, не доказано …
постусловие «q3 остаток неотрицательного не больше» … доказано по объявленным типам аргументов:
цель сведена правилом «ограниченность точным потолком по построению» …
```

## 4. Постусловие без аргументов вычисляется

Если постусловие не зависит от аргументов, ядро его вычисляет. Подходит любое
сравнение, строгое тоже. Файл `closed-goal.flang`:

```flang insert docs/examples/proofs/kernel/closed-goal.flang
модуль «Closed goal»

тотальная функция «Пять»
  возвращает число
  обеспечивает «z1 замкнутая строго» результат меньше 6
  обеспечивает «z2 замкнутая больше» результат больше 0
  5

тотальная функция «Метка»
  возвращает список числа
  обеспечивает «z3 длина литерала» (длина результат) равен 3
  [100, 101, 114]
```

```
постусловие «z1 замкнутая строго» … доказано вычислением замкнутой цели …
постусловие «z3 длина литерала» … доказано сведением цели с телом функции …
```

Функции, которая возвращает константу, можно записать значение, длину и
границы без усилий.

## 5. Вызовы: нужно доказанное постусловие вызываемой функции

Тело рекурсивной функции ядро в место вызова не подставляет. О результате
вызова оно знает только то, что говорят доказанные постусловия вызванной
функции. Файл `copy-length.flang`:

```flang insert docs/examples/proofs/kernel/copy-length.flang
модуль «Copy length»

тотальная функция «Копия без»
  принимает х: список число
  возвращает список число
  разбор х
    случай пусто
      то пустой список
    случай голова и хвост
      то приписать голова к («Копия без» от хвост)

тотальная функция «Копия с»
  принимает х: список число
  возвращает список число
  обеспечивает «k1 длина копии» (длина результат) равен (длина х)
  разбор х
    случай пусто
      то пустой список
    случай голова и хвост
      то приписать голова к («Копия с» от хвост)

тотальная функция «Верх без»
  принимает х: список число
  возвращает список число
  обеспечивает «k2 верх над голым звеном» (длина результат) равен (длина х)
  «Копия без» от х

тотальная функция «Верх с»
  принимает х: список число
  возвращает список число
  обеспечивает «k3 верх над звеном с обещанием» (длина результат) равен (длина х)
  «Копия с» от х
```

```
постусловие «k1 длина копии» … доказано индукцией по «список» …
постусловие «k2 верх над голым звеном» … объявлено, не доказано …
постусловие «k3 верх над звеном с обещанием» … доказано сведением цели с телом функции:
правило «цель есть допущение» …
```

У «Копии без» постусловия нет, и утверждение о её результате (`k2`) не
доказано. У «Копии с» оно есть и доказано, поэтому `k3` проходит. Постусловие,
проверенное только на тестах, вызывающей функции не помогает.

Нерекурсивную функцию без постусловий ядро подставляет само.

Если ядро не применило постусловие вызванной функции, сошлитесь на него
теоремой в одну строку. Файл `call-by-property.flang`:

```flang insert docs/examples/proofs/kernel/call-by-property.flang
модуль «Property of the called»

тотальная функция «Копия»
  принимает х: список число
  возвращает список число
  обеспечивает «копия той же длины» (длина результат) не больше (длина х)
  разбор х
    случай пусто
      то пустой список
    случай голова и хвост
      то приписать голова к («Копия» от хвост)

тотальная функция «Голый вызов»
  принимает х: список число
  возвращает список число
  обеспечивает «t1 голый вызов» (длина результат) не больше (длина х)
  «Копия» от х

теорема «t1 голый вызов»
  дано х: список число
  утверждаем (длина результат) не больше (длина х)
  по свойству «копия той же длины»
  следовательно доказано
```

```
постусловие «t1 голый вызов» … доказано: терм принят ядром, 1 шаг, правило «цель есть допущение»,
основания: постусловие «копия той же длины» функции «Копия» …
```

Теорема с ошибкой отвергает весь файл: код возврата 1, отчёта нет. Добавляйте
теоремы по одной.

## 6. Свёртка должна быть всем телом

Утверждение про `свёртка` ядро доказывает индукцией по свёртке. Файл
`fold-count.flang`:

```flang insert docs/examples/proofs/kernel/fold-count.flang
модуль «Count by fold»

тотальная функция «Счёт лямбдой»
  принимает х: список число
  возвращает число
  обеспечивает «f7 счёт лямбдой» результат равен (длина х)
  свёртка х начиная с 0 как акк и эл → акк плюс 1
```

```
постусловие «f7 счёт лямбдой» … доказано индукцией по СВЁРТКЕ тела: начало 1 случай,
виток при допущении о накопителе «акк» (1 случай) …
```

«Виток» в выводе — один шаг свёртки. Работает это, только когда свёртка
занимает всё тело и идёт по аргументу:

| Тело | Ответ |
| --- | --- |
| `свёртка х начиная с 0 как акк и эл → «Счёт шагом» от акк и эл` | доказано |
| `(свёртка х … ) плюс 0` | не доказано |
| `пусть н равно (свёртка х …)`, затем `н` | не доказано |
| `свёртка куча.свободные …` (поле аргумента) | не доказано |

Исправляется это в программе: сделайте свёртку телом отдельной функции,
которая принимает список аргументом, и вызывайте её.

## 7. Тип с вариантами: условие равенством варианту

Тело `разбор` по аргументу ядро разбирает по условию, которое сравнивает
аргумент с вариантом. Файл `variant-answer.flang`:

```flang insert docs/examples/proofs/kernel/variant-answer.flang
модуль «Variant answer»

тип «Ответ»
  вариант «Пока ничего»
  вариант «Текст» содержит текст: строка

тотальная функция «Текст ответа»
  принимает отклик: «Ответ»
  возвращает строка
  обеспечивает «v2 равенство варианту» если отклик равен (вариант «Пока ничего») то (результат равен "") иначе да
  разбор отклик
    случай «Пока ничего»
      то ""
    случай вариант «Текст» с текст как т
      то т
```

```
постусловие «v2 равенство варианту» … доказано сведением цели с телом функции:
правило «разбор цели по условию» …
```

`разбор` внутри самого постусловия не поддерживается: пишите вместо него такое
условие.

Для списка подходят оба условия: `если х равен пустой список то …` и
`если (длина х) равен 0 то …`.

## 8. Вызов предиката и конъюнкция

Постусловие — вызов предиката — пишется двумя способами: само по себе и с
`равен да`. Не доказалась одна запись — попробуйте другую.

Конъюнкцию `Ц1 и притом Ц2` ядро часто доказывает целиком. Если не доказало,
разбейте её на отдельные строки `обеспечивает`. Отчёт покажет, в какой части
дело.

Конъюнкцию в условии разбивать нельзя: `если А и притом Б то В` слабее, чем
`если А то В`. Дизъюнкцию в условии разбить можно: `если (А или Б) то В`
равносильно паре `если А то В` и `если Б то В`.

## Чего отчёт не говорит

У недоказанного постусловия без теоремы отчёт пишет один и тот же текст при
любой причине:

```
объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата …
```

Какого правила не хватило, он не сообщает. Ложное постусловие получает тот же
ответ, что и верное, которое ядро не вывело. Прежде чем переписывать
постусловие, напишите тест, который бы его нарушил.

Файлу с большим числом постусловий может не хватить шагов: проверка
останавливается с `FLANG_RECURSION_LIMIT`. Предел поднимает ключ
`--step-limit N`.

## Порядок работы

1. Запустите `flang check файл --proof` и запомните последнюю строку отчёта.
2. У тела с ветвлением добавьте условия из тела (разделы 1 и 2).
3. Где есть неравенство, смените тип аргументов на `неотрицательное` или
   добавьте `требует` (раздел 3).
4. Для оставшегося дайте вызываемым функциям нужные постусловия (раздел 5).
5. Запустите проверку снова и сравните число доказанных. Не выросло — верните
   правку назад.
