# 0028. У узла разобранной программы нет своей суммы типов, и спуск по ключу словаря не считается убыванием

## Шаги воспроизведения

1. Модуля с суммой типов узла в компиляторе нет:

```
ls flang/self/ast.flang
```

2. Чтение поля узла по строковому ключу объявлено отдельно в каждом слое:

```
grep -rla '^тотальная функция «Взять поле' flang/self | wc -l
```

3. Обход дерева через такое чтение проверка завершаемости отвергает:

```
bootstrap/flang check docs/examples/proof-probes/typed-ast-generic-descent-is-refused.flang
```

## Что происходит

```
$ ls flang/self/ast.flang
ls: cannot access 'flang/self/ast.flang': No such file or directory      код 2
$ grep -rla '^тотальная функция «Взять поле' flang/self | wc -l
9
$ bootstrap/flang check docs/examples/proof-probes/typed-ast-generic-descent-is-refused.flang
FLANG_NOT_TOTAL … рекурсивный вызов «Узлов в значении» не убывает — аргумент 1
(«Взять поле пробы» от «узел», "cond") не выведен ни из одного параметра
… не проверено — замечаний 4                                             код 1
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

Разобранная программа — обобщённое «Значение» из `flang/core/json.flang`: вид
узла записан строкой в поле, поле достаётся поиском по ключу. Проверка
завершаемости не знает, что найденное по ключу меньше исходного, поэтому
рекурсия по дереву остаётся без доказательства во всех слоях, которые его
читают.

## Что должно быть

По ADR-0013 (`docs/adr/0013-a-typed-node-enters-through-a-door-at-the-layer-boundary.md`)
типизированный узел живёт внутри одного слоя: на входе слоя перевод из
«Значения» в сумму типов, на выходе — обратно; между слоями и на диске форма
прежняя, печать в JSON не меняется. Верность перевода держит круговое
свойство: значение, переведённое туда и обратно, равно исходному. Образец
такого перевода проходит проверку с кодом 0:
`docs/examples/proof-probes/typed-ast-door.flang`.

Остались шаги 3–7 из ADR-0013:

- шаг 3 — модуль с суммами типов, записями-нагрузками и обоими переводами,
  который пока никто не ввозит;
- шаг 4 — первый слой целиком, `flang/self/totality.flang`;
- шаг 5 — записи-нагрузки для рёбер, где узел передаётся неизменным, по образцу
  `flang/test/fixtures/razrez-kruga/`;
- шаги 6–7 — остальные слои и разбор, строящий типизированный узел напрямую.

Ограничения, снятые замером (`docs/zettel/typed-ast-typing-alone-fixes-one-recursion-edge-in-six.md`,
`docs/zettel/typed-ast-the-real-tree-has-29-kinds-and-list-is-two-different-nodes.md`):

- сумм нужно две: `list` и `record` — это по два разных узла под одной строкой
  (тип и выражение);
- имя «Узел» занято в `flang/stdlib/automaton.flang` и `flang/core/parser.flang`;
  «Может быть узел» уже объявлен в `flang/self/emit-c.flang` — его ввозить;
- типизация снимает только спуски по ключу; рёбра, где узел едет неизменным,
  требуют шага 5;
- до шага 4 решить, сводятся ли девять копий «Взять поле» в один модуль.

## Обходной путь

Обходы дерева объявляются обычными функциями, без доказанного завершения.

## Когда задача сделана

Шаг 3: новый модуль проходит `bootstrap/flang check <модуль> --proof` с кодом 0,
круговое свойство в нём — доказанное утверждение. Шаг 4: число функций с
доказанным завершением в `flang/self/totality.flang` выросло, снятое одним
двоичным до и после; напечатанный JSON разбора не изменился ни в одном байте.
Обе пробы из `docs/examples/proof-probes/` отвечают как сегодня: образец — код 0,
обход по ключу — код 1.

## Где живёт правка

Шаг 3 — новый файл в `flang/self/`. Шаги 4–7 — `flang/self/totality.flang`,
затем `flang/self/types.flang`, `flang/self/emit-c.flang` и остальные читатели
узла, в конце `flang/self/parser.flang`. Проверяется всё текущим двоичным; в
сам двоичный правка попадает только пересборкой семени (bootstrap regeneration).
