# 0037. Проверка английской пары ограничена docs/site/, и страницы сайта из других каталогов без пары проходят сборку

## Шаги воспроизведения

1. Перечислить источники карты сайта вне `docs/site/`, у которых нет английской
   пары (русская страница с именем вида x.ru.md ждёт x.md; страница с именем вида x.md без
   `.ru` пары не имеет вовсе):

```
grep -o "из: '[^']*'" docs/site/sitemap.mjs | sed "s/из: '//;s/'$//" | grep -v '^docs/site/' \
| while read f; do case "$f" in *.ru.md) [ -f "${f%.ru.md}.md" ] || echo "нет пары: $f";; *) echo "нет пары: $f";; esac; done
```

2. Собрать сайт с проверкой:

```
node docs/site/build.mjs --check
```

3. Смотреть: перечень из шага 1 не пуст, а проверка из шага 2 отвечает кодом 0
   и не называет ни одной из этих страниц.

## Что происходит

```
$ <команда шага 1> | wc -l
16                                                               код 0
$ node docs/site/build.mjs --check
Проверка прошла: страниц 833 (из них заметок 721, английских 47), …   код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Среди шестнадцати — `docs/flang/SPEC.md`, `docs/glossary.md`, `docs/wasm-via-c.md`,
`docs/overview.ru.md`, `CHANGELOG.md`. Причина в `docs/site/build.mjs`, строки
187–194: константа `СВОИ = 'docs/site/'` и условие
`обязана = с.из.startsWith(СВОИ) && !с.печатается` — беда «нет английской пары»
поднимается только для страниц из `docs/site/`. Граница объявлена одной
строкой в другом файле (`docs/site/sitemap.mjs`, строка 15: «для страниц вне
`docs/site/` пара берётся по наличию»), довода при ней нет.

## Что должно быть

Сайт печатается двумя языковыми версиями (`docs/site/sitemap.mjs`, раздел
английских половин в `docs/site/build.mjs`). Проверка `--check` обязана
краснеть на любой странице карты без английской пары, из какого бы каталога
она ни бралась; исключения (`печатается`, страницы, для которых пара не
нужна по решению) объявлены в карте сайта словами, с доводом, а не молчаливой
границей по каталогу.

## Обходной путь

Перечень из шага 1 прогоняется руками; сборка о нём не напоминает.

## Когда задача сделана

```
node docs/site/build.mjs --check                                 код 0
```

при том, что у каждой страницы карты вне `docs/site/` либо есть английская
пара, либо в карте стоит объявленное исключение с доводом. Проба порчи: снять
английскую пару у любой страницы вне `docs/site/` (например, переименовать
`docs/guide/limits.md`) — проверка обязана покраснеть и назвать файл. Команда
шага 1 после поправки карты и написания пар печатает пустой перечень или
только объявленные исключения.

## Где живёт правка

`docs/site/build.mjs` (константа `СВОИ`, условие `обязана`, строки 187–194) и
`docs/site/sitemap.mjs` (комментарий строки 15, поле `печатается` у страниц);
английские редакции для страниц из перечня шага 1 — рядом с русскими, в тех
же каталогах `docs/`. Правка не касается двоичного, пересборка семени
(bootstrap regeneration) не нужна.

Отдельная задача, здесь не решается: проверка обратной ссылки — документ в
`docs/` называет каталог с кодом, который описывает, и каждый каталог с кодом
описан хотя бы одним документом.
