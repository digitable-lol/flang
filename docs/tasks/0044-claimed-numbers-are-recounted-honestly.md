# 0044. Числа сайта несут графу условно доказанного, но страницы о доказанном её не показывают, а вердикта numbers:check нет

## Шаги воспроизведения

1. Спросить возраст чисел сайта:

```
sh scripts/guards/published-vs-tree.sh --числа
```

2. Поискать графу условно доказанного в числах сайта, в измерителе и на
   страницах о доказанном:

```
grep -c 'приУсловии' docs/site/numbers.json docs/site/site-numbers.mjs docs/site/proofs.ru.md docs/site/proofs.md
```

3. Сравнить с итоговой строкой сегодняшнего двоичного на любом файле:

```
bootstrap/flang check docs/examples/proof-probes/typed-ast-door.flang --proof
```

## Что происходит

```

  дорогие ключи сняты 2026-10-08 на 9f0181997: с тех пор коммитов 13, файлов .flang сдвинулось 0

```

Версия: flang 0.7.25, прогон 11 октября 2026.

Двоичный считает «условно» отдельно от «доказано», измеритель
`docs/site/site-numbers.mjs` пишет эту графу ключом `утверждения.приУсловии`
(строка 305), и в `docs/site/numbers.json` после пересъёмки 8 октября 2026
(коммит 41f322ea6) ключ стоит со значением 43 при `утверждения.доказано` 8238.
Строки «они описывают дерево, которого нет» проверка возраста больше не
печатает. Чего нет: страницы `docs/site/proofs.ru.md` и `docs/site/proofs.md`
графу не показывают, а `bootstrap/flang run-script numbers:check` своего
вердикта на этом дереве не дал — последний записанный прогон (ведомость
`scripts/ledgers/uncalled-guards.json`, 6 сентября 2026) красен кодом 1 за
6864 с, и с тех пор его никто не повторял (задачи 1277 и 1464).

## Что должно быть

Число «доказано» на сайте совпадает с прогоном сегодняшнего двоичного по
сегодняшнему дереву, рядом стоит отдельное число «условно». `docs/zero-bug-policy.md`:
число ценно только снятое прогоном. Если число доказанного после пересъёмки
упало, об этом сказано прямо на странице `docs/site/proofs.ru.md` и в
`CHANGELOG.md`: раньше условное считалось доказанным.

## Обходной путь

Числу сайта не верить; спрашивать двоичный: `bootstrap/flang check <файл> --proof`
печатает итог по файлу с графой «условно».

## Когда задача сделана

```
$ sh scripts/guards/published-vs-tree.sh --числа
```

не печатает строку «они описывают дерево, которого нет» (так уже сегодня).
В `docs/site/numbers.json` есть ключ условно доказанного (так уже сегодня:
`утверждения.приУсловии`), и страницы `docs/site/proofs.ru.md` и
`docs/site/proofs.md` его показывают (`grep -c 'приУсловии'` на обеих не 0).
`bootstrap/flang run-script numbers:check` отвечает кодом 0 и краснеет, если
число на странице разошлось с измерителем; его время и код записаны в
ведомости незваных сторожей.

## Где живёт правка

Страницы `docs/site/proofs.ru.md` и `docs/site/proofs.md` — подставить ключ
`утверждения.приУсловии` рядом с «доказано»; `docs/site/numbers.json` —
пересъёмка командой `bootstrap/flang run-script numbers:build` (прогон
двоичного по всему корпусу, часы), если число на странице разошлось.
Пересборка семени (bootstrap regeneration) не нужна: двоичный графу уже печатает.

Отдельная задача, здесь не решается: измеритель чисел написан на JavaScript и
переезжает на flang в задаче 4412.

Следующий шаг — `docs/site/proofs.ru.md` и `docs/site/proofs.md`: строка о
доказанном получает число «при условии» из ключа `утверждения.приУсловии`, как
страницы уже берут `утверждения.доказано`. Краснеющая сегодня проба: `grep -c
'приУсловии' docs/site/proofs.ru.md docs/site/proofs.md` печатает 0 и 0 (прогон
11 октября 2026).
