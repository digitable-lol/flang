# 0044. Числа сайта о доказанном сняты старым двоичным и не отделяют условно доказанное

## Шаги воспроизведения

1. Спросить возраст чисел сайта:

```
sh scripts/guards/published-vs-tree.sh --числа
```

2. Поискать в числах сайта графу условно доказанного:

```
grep -ac 'услов' docs/site/numbers.json
grep -ac 'услов' docs/site/site-numbers.mjs
```

3. Сравнить с итоговой строкой сегодняшнего двоичного на любом файле:

```
bootstrap/flang check docs/examples/proof-probes/typed-ast-door.flang --proof
```

## Что происходит

```
$ sh scripts/guards/published-vs-tree.sh --числа
  (дорогие ключи — корпус.функций, утверждения.*, носители.*, сторож.*,
   словарь.* — здесь НЕ проверены: им нужен прогон двоичного по корпусу.)
  дорогие ключи сняты 2026-08-23 на 252606e8: с тех пор коммитов 4553, файлов .flang сдвинулось 1653
    значит они описывают дерево, которого нет. Пересъёмка — bootstrap/flang run-script numbers:build
    (прогон двоичного по корпусу, часы), и она ждёт перепечатки семени.
опубликованное сходится с деревом                                       код 0
$ grep -ac 'услов' docs/site/numbers.json
0
$ grep -ac 'услов' docs/site/site-numbers.mjs
0
$ bootstrap/flang check docs/examples/proof-probes/typed-ast-door.flang --proof
… утверждений 14: доказано 14, условно 0, сетка 0, объявлено, не доказано 0,
отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0   код 0
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

Двоичный давно считает «условно» отдельно от «доказано». Измеритель
`docs/site/site-numbers.mjs` этой графы не читает, а ключи `утверждения.*`,
`корпус.функций`, `корпус.тотальных`, `носители.*`, `сторож.*`, `словарь.*` в
`docs/site/numbers.json` остались от прогона двоичным, который условного не
различал. Страницы `docs/site/index.ru.md`, `docs/site/index.md`,
`docs/site/proofs.ru.md`, `docs/site/proofs.md`, `docs/site/roadmap.md`
подставляют эти ключи в текст.

## Что должно быть

Число «доказано» на сайте совпадает с прогоном сегодняшнего двоичного по
сегодняшнему дереву, рядом стоит отдельное число «условно». `docs/zero-bug-policy.md`:
число ценно только снятое прогоном. Если число доказанного после пересъёмки
упало, об этом сказано прямо на странице `docs/site/proofs.ru.md` и в
`CHANGELOG.md`: раньше условное считалось доказанным.

## Обходной путь

Числу сайта не верить; спрашивать двоичный: `bootstrap/flang check <файл> --proof`
печатает итог по файлу с графой «условно».

## Когда задача сделана

```
$ sh scripts/guards/published-vs-tree.sh --числа
```

не печатает строку «они описывают дерево, которого нет»: дата и коммит дорогих
ключей — день и коммит пересъёмки. В `docs/site/numbers.json` есть ключ
условно доказанного (`grep -ac 'услов' docs/site/numbers.json` не 0), и
страницы `docs/site/proofs.ru.md` и `docs/site/proofs.md` его показывают.
`bootstrap/flang run-script numbers:check` отвечает кодом 0 и краснеет, если число на странице
разошлось с измерителем.

## Где живёт правка

`docs/site/site-numbers.mjs` — читать графу «условно» из итога двоичного и
писать её ключом; `docs/site/numbers.json` — пересъёмка командой `bootstrap/flang run-script numbers:build`
(прогон двоичного по всему корпусу, часы); страницы `docs/site/proofs.ru.md`,
`docs/site/proofs.md`, `docs/site/index.ru.md`, `docs/site/index.md`,
`docs/site/roadmap.md`; оговорка о возрасте в `scripts/guards/published-vs-tree.sh`.
Пересборка семени (bootstrap regeneration) не нужна: двоичный графу уже печатает.

Отдельная задача, здесь не решается: измеритель чисел написан на JavaScript и
переезжает на flang в задаче 4412.
