# 0051. Ядро заново обходит тело функции на каждом месте вызова, и проверка файла без обещаний идёт дольше минуты

## Шаги воспроизведения

1. Файл из дерева без единого `обеспечивает`: `scripts/site/releases.flang`
   (327 строк, 26 функций, 30 примеров).
2. Команда:

```
timeout 60 bootstrap/flang check scripts/site/releases.flang
```

3. Смотреть код возврата и строку хода «шагов … идёт …».

## Что происходит

```
$ timeout 60 bootstrap/flang check scripts/site/releases.flang
шагов 2 265 471 777 из 4 000 000 000 000 (0 %), идёт «Проверить доказательства с кешем», 225 МиБ
шагов 3 984 970 282 из 4 000 000 000 000 (0 %), идёт «Проверить доказательства с кешем», 233 МиБ
                                                                  код 124
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026. Числа шагов и памяти —
с одного прогона: строки хода печатаются по времени, а не по счёту шагов.

Доказывать в файле нечего, шаги уходят на нормализацию и развёртку вызовов.
«Правило развёртки» в `flang/self/proof-kernel.flang` на каждом месте вызова
спрашивает `«Есть вызов» от («Взять поле» от «функция» и "body")` — полный
рекурсивный обход тела вызываемой функции. Ответ зависит только от самой
функции и один на весь прогон, а считается при каждой развёртке заново.
Соседние два места той же природы уже исправлены: «Переписать до неподвижной»
выходит, когда терм перестал меняться, а «Прогоны для ядра» прогоняет только
примеры функций, названных в обоснованиях.

## Что должно быть

Признак «тело функции не содержит вызовов» считается один раз на функцию и
дальше читается из посчитанного. Вердикт ни одного утверждения при этом не
меняется: признак — функция от неизменного тела.

## Обходной путь

Ждать: проверка завершается, только долго. Для быстрого ответа без ядра —
`bootstrap/flang check <файл> --fast` (код возврата 4, ядро и примеры не
запускаются).

## Когда задача сделана

- `bootstrap/flang check scripts/site/releases.flang` отвечает кодом 0, и число
  шагов в последней строке хода заметно меньше, чем до правки; оба числа
  записаны в сообщении коммита.
- `bootstrap/flang check flang/stdlib/json.flang --proof` до и после правки
  даёт один и тот же вердикт по каждому утверждению — отчёты о доказательствах
  сверены поимённо, расхождений ноль.
- У функции, хранящей признак, есть пример на функцию с плоским телом и на
  функцию с вызовом в теле.

## Где живёт правка

`flang/self/proof-kernel.flang`: «Правило развёртки», «Есть вызов», место
вызова в «Развернуть телом»; посчитанный признак удобно держать в «Состоянии
ядра» или класть в описание функции при подготовке программы. До двоичного
правка доезжает только пересборкой семени (bootstrap regeneration), поэтому
замер «после» возможен лишь на пересобранном двоичном.
