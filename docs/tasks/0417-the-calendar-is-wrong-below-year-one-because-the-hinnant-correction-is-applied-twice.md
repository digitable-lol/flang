# 0417. Дата из числа дней неверна для дней раньше 0001-01-01

## Шаги воспроизведения

1. Программа:

```flang
модуль «Круг календаря»
  использует «Date and time» из "flang/stdlib/datetime.flang"

функция «Круг»
  принимает дни: число
  возвращает число
  «Дней от эпохи» от («Дата из дней» от дни)
```

2. Команда, файл лежит в корне дерева:

```
bootstrap/flang run <файл> --function '«Круг»' --args '{"дни": -719834}' --trust
```

3. Смотреть напечатанное число: оно обязано совпасть с поданным.

## Что происходит

```
$ bootstrap/flang run <файл> --function '«Круг»' --args '{"дни": -719834}' --trust
-719833                                                          код 0
$ … --args '{"дни": -719163}'
-719163                                                          код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

День −719163 — это 0001-01-01; на нём и выше круг сходится, ниже — нет.
Причина: формула Хиннанта рассчитана на деление с усечением к нулю и сама
поправляет его слагаемыми `− 399` и `− 146096`. Здесь делит «Деление вниз»,
которое уже округляет вниз, и поправка применяется второй раз.

## Что должно быть

«Дней от эпохи» от («Дата из дней» от д) равно д для любого целого д, в том
числе ниже 0001-01-01. Сейчас обе функции оговаривают, что ниже этой даты
ничего не обещают.

## Обходной путь

Не подавать даты раньше 0001-01-01.

## Когда задача сделана

Круг из шагов воспроизведения возвращает поданное число на −719834 и на всём
отрезке от −720200 до −719163. Оговорка «не ниже 0001-01-01» снята с обеих
функций, `bootstrap/flang check flang/stdlib/datetime.flang` отвечает кодом 0,
число доказанных утверждений файла не упало. У каждой функции есть пример с
днём ниже 0001-01-01.

## Где живёт правка

`flang/stdlib/datetime.flang`: «Дней от эпохи» (строка с `сдвинутый минус 399`)
и «Дата из дней» (строка с `сдвиг минус 146096`) — убрать поправку, оставить
«Деление вниз». Библиотека читается двоичным с диска, перепечатка семени не
нужна.
