# 1013. Лист линейной арифметики — вызов с любым хвостом

## Шаги воспроизведения

1. Исходник `probe.flang`:

```flang
модуль «Лист вызова с хвостом»

функция «Ф»
  принимает а: неотрицательное
  возвращает неотрицательное
  а

утверждение «частное не ниже нуля»
  для всех а: неотрицательное
  утверждаем («Ф» от а делить на -1) не меньше 0
```

2. Запись `probe.record` (написана руками; строки `строк`, `знаков`, `отпечаток`, `отпечаток256` — по исходнику):

```
запись доказательства 1
исходник finds/L1-linear-call-leaf-with-tail.flang
строк 11
знаков 223
отпечаток 431093408 63263863
ядро 2
утверждений 1
отпечаток256 5ca9780c089f554856e621df8a0e3b4817ac7cd28b3ac37cf4e89a914f994cec

утверждение «частное не ниже нуля» строка 8
  вид statement
  для всех «а» ⟨неотрицательное⟩ строка 9
  вердикт доказано
  теоремы нет
  правило «линейная арифметика»
  по объявлению да
    ход цель
    ход 1 носитель «неотрицательное»
    ход 2 доказать ⟨(«Ф» от а делить на -1) не меньше 0⟩
    ход 3 дно ⟨«Ф» от а делить на -1⟩ множитель 1
    ход 4 отрицание множитель 1
    ход 5 противоречие
    ход конец
конец утверждения

конец записи
```

3. `flang/proof/checker/сверщик probe.flang probe.record`, затем
   `flang/proof/checker/second/out/второй-сверщик probe.flang probe.record`.

## Что происходит

Оба сверщика отвечают `ПРОВЕРЕНО`, код 0.

Версия: flang 0.7.34, `checker.c` и второй сверщик ствола `001d8df7c`.

Утверждение ложно: при `а = 1` частное равно −1.

`ла_лист` (`checker.c`) и `«лаЛист»` (`Linear.lean`) считают листом носителя всё, что начинается с `«Ф» от `.



## Что должно быть

Лист-вызов — вызов с простыми доводами, после которых ничего не стоит.

## Обходной путь

Обхода нет. Ядро таких записей не пишет: дыра открыта тому, кто пишет запись сам.

## Когда задача сделана

Оба сверщика отвечают на эту запись кодом 1 либо 3; запись лежит подделкой в
`flang/proof/checker/tests/families/` со строкой в `flang/proof/checker/tests/probes.tsv`, и
`make -C flang/proof/checker пробы` отвечает «сошлось всё».

## Где живёт правка

`flang/proof/checker/checker.c` (`ла_лист`), `flang/proof/checker/second/Linear.lean` (`«лаЛист»`). Печать семени не нужна.
