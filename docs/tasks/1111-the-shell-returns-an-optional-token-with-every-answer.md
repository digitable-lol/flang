# 1111. Оболочка не принимает токен перед выражением, и программе нечем связать ответ с запросом

Заявка: https://github.com/digitable-lol/flang/issues/111

## Шаги воспроизведения

1. Подать оболочке три выражения через конвейер, без терминала.
2. Подать выражение с токеном `17^` перед ним.
3. Смотреть, чем ответы отличаются друг от друга, и код возврата.

## Что происходит

```
$ printf '2 плюс 2\n"привет"\nдлина [1,2,3]\n.выход\n' | bootstrap/flang repl
4
"привет"
3                                                                код 0
$ printf '17^ 2 плюс 2\n.выход\n' | bootstrap/flang repl
FLANG_LEX, строка 1, столбец 3: недопустимый символ '^'          код 1
```

Версия: flang 0.7.23. Дата прогона: 3 октября 2026.

Три ответа идут тремя строками без единой приметы: связать ответ с посланным
выражением нечем. Строку с токеном отвергает лексер.

## Что должно быть

Необязательный токен перед выражением, который оболочка возвращает в начале
ответа, — как в GDB/MI. Человек его не пишет и вида не замечает.

```
» 17^ 2 плюс 2
17^ 4
» 18^ к числу "ой"
18^ FLANG_BUILTIN_ARGS: …
```

## Обходной путь

Программа дописывает за выражением строковый литерал и ждёт, когда оболочка
напечатает его обратно. Метка попадает в историю и в `.исходник`, а на
многострочном объявлении её нельзя послать, пока не закрыта пустая строка.

## Когда задача сделана

```
$ printf '17^ 2 плюс 2\n.выход\n' | bootstrap/flang repl
17^ 4                                                            код 0
```

1. Строка вида `<цифры>^ <выражение>` вычисляется, и ответ начинается с того
   же `<цифры>^`.
2. Отказ несёт тот же токен: на `18^ к числу "ой"` первая строка ответа
   начинается на `18^ `, код 1.
3. Строка без токена не изменилась: прогон из шага 1 печатает ровно три строки
   `4`, `"привет"`, `3` и даёт код 0 — так он отвечает и сегодня.
4. Токен не попадает ни в историю, ни в `.исходник`: после строки с токеном
   `.исходник` печатает выражение без `<цифры>^`, и `.сохранить <файл>` пишет
   в файл то же без токена.
5. У многострочного объявления (его закрывает пустая строка) токен стоит на
   первой строке и возвращается один раз, с ответом:
   `17^ объявлено: тотальная функция «Удвоить» — завершение доказано`.

На каждый пункт — проба с прогоном оболочки через конвейер. Пробы 1, 2, 4 и 5
красны на сегодняшнем двоичном и зелены после правки; проба 3 зелена и сегодня
и обязана остаться зелёной — она ловит, если токен тронет вид без токена.

## Где живёт правка

`flang/src/emit/c/flang_repl.c`: токен снимается со строки до лексера, разбор
языка не меняется. В двоичное правка попадает пересборкой семени (bootstrap
regeneration): она переносит файл в `bootstrap/flang_repl.c`.
