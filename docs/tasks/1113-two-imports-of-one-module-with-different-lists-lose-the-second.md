# 1113. Два ввоза одного модуля с разными списками теряют второй молча

Заявка: https://github.com/digitable-lol/flang/issues/113

## Шаги воспроизведения

Из корня дерева, каталог `/tmp/repro-1113` пустой.

1. `/tmp/repro-1113/first.flang`:

   ```
   модуль «First»
     использует «Strings» из "<дерево>/flang/stdlib/strings.flang" только «Повторить»

   тотальная функция «Трижды»
     принимает что: строка
     возвращает строка
     «Повторить» от что и 3
   ```

2. `/tmp/repro-1113/second.flang`:

   ```
   модуль «Second»
     использует «Strings» из "<дерево>/flang/stdlib/strings.flang" только «Соединить строки», «Шаг склейки строк»

   тотальная функция «Склеить»
     принимает а: строка, б: строка
     возвращает строка
     «Соединить строки» от [а, б] и ""
   ```

3. `/tmp/repro-1113/both.flang`:

   ```
   модуль «Both»
     использует «First» из "first.flang"
     использует «Second» из "second.flang"

   тотальная функция «Проба»
     возвращает строка
     «Склеить» от («Трижды» от "а") и "б"
   ```

4. `flang check` на каждом из трёх файлов.
5. Переставить две строки `использует` в `/tmp/repro-1113/both.flang` и
   прогнать `flang check` снова.

## Что происходит

```
$ flang check /tmp/repro-1113/first.flang     код 0
$ flang check /tmp/repro-1113/second.flang    код 0
$ flang check /tmp/repro-1113/both.flang      код 1
FLANG_UNKNOWN_NAME, строка 7, столбец 3: неизвестная функция «Повторить»

после перестановки строк:
$ flang check /tmp/repro-1113/both.flang      код 1
FLANG_UNKNOWN_NAME, строка 7, столбец 3: неизвестная функция «Соединить строки»
```

Список того ввоза, до которого обход дошёл вторым, отбрасывается. После
перестановки строк невидимой становится другая функция. Отказ говорит
«неизвестная функция» про имя, которое стоит в списке `только` соседнего
файла, и файла не называет. Версия: `flang 0.7.22`. Прогон 27 сентября 2026.

## Что должно быть

Результат проверки не зависит от порядка строк `использует`. Одно из двух:
списки складываются, и каждый модуль видит своё; либо отказ называет
столкновение — какой модуль ввезён дважды, из каких файлов и с какими
списками.

## Обходной путь

Ввозить модуль везде с одним и тем же списком `только` — объединением всех
нужных имён.

## Когда задача сделана

`flang check /tmp/repro-1113/both.flang` даёт один и тот же ответ при обеих перестановках
строк `использует`: код 0, либо отказ, называющий столкновение. Проба держит
обе перестановки и пять модулей самого дерева, которые ввозят «Strings» с
разными списками.

## Где живёт правка

Связывание модулей — `flang/self/link.flang`, самосборная часть. Правка
доезжает до двоичного только перепечаткой и вносится в партию печати
(задача 2200).
