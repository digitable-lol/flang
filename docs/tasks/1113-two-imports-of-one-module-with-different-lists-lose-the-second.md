# 1113. Два импорта одного модуля с разными списками «только» молча теряют второй список

Заявка: https://github.com/digitable-lol/flang/issues/113

## Шаги воспроизведения

Три файла в одном пустом каталоге; `<дерево>` — корень репозитория.

```flang
модуль «First»
  использует «Strings» из "<дерево>/flang/stdlib/strings.flang" только «Повторить»

тотальная функция «Трижды»
  принимает что: строка
  возвращает строка
  «Повторить» от что и 3
```

```flang
модуль «Second»
  использует «Strings» из "<дерево>/flang/stdlib/strings.flang" только «Соединить строки», «Шаг склейки строк»

тотальная функция «Склеить»
  принимает а: строка, б: строка
  возвращает строка
  «Соединить строки» от [а, б] и ""
```

```flang
модуль «Both»
  использует «First» из "first.flang"
  использует «Second» из "second.flang"

тотальная функция «Проба»
  возвращает строка
  «Склеить» от («Трижды» от "а") и "б"
```

Проверить каждый файл, затем поменять местами две строки `использует` в
третьем и проверить его снова.

## Что происходит

```
$ bootstrap/flang check first.flang                              код 0
$ bootstrap/flang check second.flang                             код 0
$ bootstrap/flang check both.flang                               код 1
FLANG_UNKNOWN_NAME, строка 7, столбец 3: неизвестная функция «Соединить строки»

после перестановки строк «использует»:
$ bootstrap/flang check both.flang                               код 1
FLANG_UNKNOWN_NAME, строка 7, столбец 3: неизвестная функция «Повторить»
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Список `только` того импорта, до которого обход дошёл вторым, отбрасывается.
Отказ говорит «неизвестная функция» об имени, которое стоит в списке соседнего
файла, и файла не называет.

## Что должно быть

Результат проверки не зависит от порядка строк `использует`. Либо списки
складываются и каждый модуль видит своё, либо отказ называет столкновение:
какой модуль импортирован дважды, из каких файлов и с какими списками.

## Обходной путь

Импортировать модуль везде с одним и тем же списком `только` — объединением
всех нужных имён.

## Когда задача сделана

Проверка третьего файла даёт один ответ при обеих перестановках строк
`использует`: код 0 либо отказ, называющий столкновение. Проба в дереве держит
обе перестановки.

## Где живёт правка

`flang/self/link.flang` — связывание модулей. До двоичного правка доезжает
пересборкой семени.
