# 1116. Команда test не исполняет блоки «прогон», и ложное ожидание проходит с кодом 0

Заявка: https://github.com/digitable-lol/flang/issues/116

## Шаги воспроизведения

1. Взять `flang/concurrency/examples/counter.flang`: два примера функций и два
   блока `прогон`, оба ждут у процесса «Счётчик» состояние 5.
2. В копии файла заменить в обоих блоках ожидаемое состояние на 999:

```
ожидается «Счётчик» равен (запись «Счёт» с «всего» равным 999)
```

3. Прогнать `bootstrap/flang test` на оригинале и на копии.

## Что происходит

```
$ bootstrap/flang test flang/concurrency/examples/counter.flang
flang/concurrency/examples/counter.flang: примеров 2, прошло 2, не прошло 0     код 0
$ bootstrap/flang test <копия с ожиданием 999>
<копия>: примеров 2, прошло 2, не прошло 0                                       код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Блоки `прогон` не исполняются и в счёт не входят: считаются только примеры
функций. Ложное ожидание от верного не отличить. Разбор при этом строку
`ожидается` в блоке требует.

## Что должно быть

`flang test` исполняет блоки `прогон`, сверяет `ожидается` и на ожидании 999
отвечает «не прошло» с ненулевым кодом. Обещано в
`docs/flang/concurrency/SPEC.md`, раздел «Прогон — это пример»: прогоны идут в
тот же вывод `flang test`, что и примеры функций.

## Обходной путь

Обходного пути нет.

## Когда задача сделана

1. Копия с ожиданием 999 даёт «не прошло 2» и ненулевой код; оригинал — «прошло
   4» и код 0.
2. Пока исполнять блоки нечем, команда называет неисполненные блоки числом и
   отвечает кодом 3: программа с блоками `прогон` с кодом 0 из `flang test` не
   выходит.

Проба в дереве держит оба случая — верное ожидание и ложное.

## Где живёт правка

Счёт и код возврата — `flang/src/emit/c/flang_repl.c`. Исполнение блоков
требует слоя процессов в двоичном (задача 1104). Обе правки доезжают до
двоичного пересборкой семени (bootstrap regeneration).
