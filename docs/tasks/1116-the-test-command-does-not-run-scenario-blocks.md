# 1116. Команда `test` не исполняет блоки `прогон`

Заявка: https://github.com/digitable-lol/flang/issues/116

## Шаги воспроизведения

1. Объявить процесс «Счётчик», который прибавляет пришедшее число к
   состоянию.
2. Объявить блок `прогон`: послать процессу `прибавить 2` и написать
   `ожидается … равным 999`.
3. Прогнать `flang test`.

Текст программы — в заявке.

## Что происходит

```
$ flang test probe.flang
probe.flang: примеров 0, прошло 0, не прошло 0          код 0
```

Прогон не исполняется и в счёт не входит. То же отвечает программа с верным
ожиданием: ложное от верного не отличить. Разбор при этом строку `ожидается`
требует — писать её обязательно, а проверяет её никто. Версия: `flang 0.7.22`.
Прогон 27 сентября 2026.

## Что должно быть

`flang test` исполняет прогон, сверяет `ожидается` и на ожидании 999 отвечает
«не прошло 1» с ненулевым кодом. Обещание — `docs/flang/conc/SPEC.md`, раздел
«Прогон — это пример»: прогоны идут в тот же вывод `flang test`, что и примеры
функций.

## Обходной путь

Нет. Проверить ожидание прогона двоичным нечем.

## Когда задача сделана

1. Ложное ожидание даёт «не прошло 1» и ненулевой код, верное — «прошло 1» и
   код 0.
2. До тех пор, пока исполнять нечем: команда называет неисполненные прогоны
   числом и отвечает кодом 3. Программа с блоками `прогон` кодом 0 из
   `flang test` не выходит.

Пробы — оба случая, ложное ожидание и верное.

## Где живёт правка

Счёт и код возврата — `flang/src/emit/c/flang_repl.c`; пункт 2 доезжает
быстрым пересевом. Исполнение прогонов требует слоя процессов в двоичном —
работа партии печати вместе с задачей 1104.
