# 1137. «не меньше» двух не-чисел останавливает интерпретатор

## Шаги воспроизведения

1. Программа:

```flang
модуль «П»

тотальная функция «Сам с собой»
  принимает х: число
  возвращает признак
  пример «единица не меньше себя»
    дано х равно 1
    ожидается да
  х не меньше х

функция «Не число»
  возвращает признак
  «Сам с собой» от (0 делить на 0)
```

2. `bootstrap/flang run nan.flang --function '«Не число»' --trust`
3. Смотреть вывод и код возврата.

## Что происходит

```
$ bootstrap/flang run nan.flang --function '«Не число»' --trust
FLANG_PROPERTY: нарушено свойство «равные числа проходят нестрогое сравнение» функции «Сравнить»
                                                                  код 1
```

Версия: flang 0.7.25.

Постусловие функции «Сравнить» в `flang/self/interpret.flang` говорит: если
`левое равен правое` и операция `gte`, то результат `да`. `равен` в языке
сравнивает не-числа как равные, а `не меньше` по IEEE-754 на не-числе ложно,
поэтому постусловие ложно на не-числе, и проверка постусловия при работе
останавливает интерпретатор. Ядро это постусловие не доказывает (на отдельном
исходнике — «объявлено, не доказано»); ложное «доказано» здесь не выдаётся.

## Что должно быть

`х не меньше х` на не-числе даёт `нет`, как `х не больше х` уже даёт `нет`.
Постусловие «Сравнить» либо исключает не-число, либо снимается.

## Обходной путь

Писать `б не больше а` вместо `а не меньше б`: ветвь `lte` постусловия не
имеет. Так делает оракул опровергателя (`docs/flang/proof/falsifier.md`).

## Когда задача сделана

Программа выше печатает `false` с кодом 0.

## Где живёт правка

`flang/self/interpret.flang`, функция «Сравнить». Правка самосборной части —
до двоичного доезжает только перепечаткой.
