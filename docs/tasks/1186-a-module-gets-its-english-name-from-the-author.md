# 1186. Проверка английских имён модулей красна на 19 модулях, а каталоги вне её списка не проверяются вовсе

## Шаги воспроизведения

1. Прогнать проверку правила Р7 (`docs/guide/naming.ru.md`: у модуля есть
   английское имя):

```
bootstrap/flang run-script module-names:check
```

2. Посмотреть, какие каталоги она читает:

```
grep -an "ls-files" scripts/guards/module-name-guard.fscript
```

## Что происходит

```
$ bootstrap/flang run-script module-names:check
{"error":"У МОДУЛЯ НЕТ АНГЛИЙСКОГО ИМЕНИ — напечатанный файл будет назван
 транслитом. Новых нарушений 19, и они не записаны в долг
  · docs/editors/vim/checks/probe-error.flang — модуль «Проба беды» …
  · docs/examples/usage/discount.flang — модуль «Скидка» …
  · docs/site/search.flang — модуль «Указатель поиска сайта» …
  · flang/self/emit-cpp.flang — модуль «Печать в C++» …
  · flang/self/emit-ts.flang — модуль «Печать в TypeScript» …
  …",…}                                                           код 1
```

Версия: flang 0.7.23.

Из 19 нарушений 2 лежат в `docs/editors`, 14 в `docs/examples`, 1 в `docs/site`,
2 в `flang/self`. Ещё 63 модуля записаны в долг в самой проверке (функция
«Долг»). Проверка читает только `flang/stdlib`, `flang/core`, `flang/self`,
`docs/examples` и остальные программы под `docs`. Модули в `flang/proof`,
`flang/test`, `flang/scripts`, `flang/concurrency`, `fspec`, `scripts` она не
открывает: каталог вне списка не краснеет, а сколько модулей осталось вне
проверки, отчёт не называет.

## Что должно быть

Правило Р7: новый модуль без английского имени проверку не проходит. Проверка
зелена на дереве, а её отчёт печатает охват числом: сколько модулей проверено
и сколько исключено, и для каждого исключённого каталога назван довод.

## Обходной путь

Автор называет модуль английскими словами сам; напечатанный файл получает имя
из имени модуля.

## Когда задача сделана

```
bootstrap/flang run-script module-names:check                                   код 0
```

Строка отчёта говорит «новых 0, надгробий 0» и называет число проверенных
модулей и число исключённых; сумма сходится с числом файлов дерева с шапкой
`модуль`. Пробный модуль с русским именем в проверяемом каталоге даёт код 1 и
назван поимённо; тот же модуль с английским именем даёт код 0.

## Где живёт правка

`scripts/guards/module-name-guard.fscript`: «Команда корпуса» (список каталогов),
«Долг», строка отчёта. Имена модулей в `docs/examples`, `docs/editors`,
`docs/site` правятся в самих файлах, пересборка семени (bootstrap regeneration)
не нужна. Модули под `flang/self` переименовываются только вместе с пересборкой
семени; до неё их вписывают в «Долг». Имя модуля конкурентности в цели C ищет
по транслиту `scripts/seed/new-binary-acceptance.fscript` (строка с
`konkurentnost`): она правится тем же изменением, что и имя.
