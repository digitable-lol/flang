# 1219. Комментарии занимают больше трети строк в скриптах оболочки из scripts, а должны меньше пятой части

## Шаги воспроизведения

1. Посчитать строки-комментарии и все строки в скриптах оболочки каталога
   `scripts`:

```
git ls-files -z 'scripts/*.sh' 'scripts/**/*.sh' | sort -zu \
  | xargs -0 awk '/^[[:space:]]*#/{c++} {t++} END{print c, t}'
```

2. Смотреть отношение первого числа ко второму.

## Что происходит

```
$ git ls-files -z 'scripts/*.sh' 'scripts/**/*.sh' | sort -zu | xargs -0 awk '/^[[:space:]]*#/{c++} {t++} END{print c, t}'
2201 6169                                                         код 0
$ git ls-files 'scripts/*.sh' 'scripts/**/*.sh' | sort -u | wc -l
9
```

Двоичный flang в замере не участвует.

2201 из 6169 — это 36 %. Ниже 20 % только два файла из 9:
`scripts/targets/identical-declarations.sh` (17 %) и
`scripts/targets/target-collisions.sh` (15 %). Самые тяжёлые —
`scripts/guards/published-vs-tree.sh` (41 %),
`scripts/guards/overlong-string-guard.sh` (41 %).
Один `scripts/bootstrap-reprint.sh` несёт 1346 строк комментариев из 2201.

## Что должно быть

Комментариев меньше 20 % строк. Шапка каждого скрипта отвечает на три вопроса:
что он делает, как его звать (ключи), какие у него коды возврата. История
правок и замеров в шапку не пишется: для неё есть сообщения коммитов.

## Обходной путь

Не требуется: на работу скриптов комментарии не влияют.

## Когда задача сделана

- команда из шагов даёт отношение меньше 20 %;
- код скриптов не изменён: вывод
  `grep -v '^[[:space:]]*#' <файл> | grep -v '^[[:space:]]*$'` до и после
  правки совпадает у каждого файла;
- строки-приметы проверки чисел (комментарий со словом СНЯТО и датой) не
  потеряны: в скриптах оболочки из `scripts` их сегодня ноль, все четыре
  живут в планах `.fscript`, и
  `bootstrap/flang io scripts/guards/prose-numbers-guard.fscript --plan Check` отвечает кодом 0;
- числа строк оболочки в `docs/tree-inventory.md` пересняты,
  `bootstrap/flang run-script inventory:check` отвечает кодом 0.

## Где живёт правка

Скрипты оболочки в `scripts`, `scripts/guards`, `scripts/seed`,
`scripts/targets`, `scripts/ledgers`; числа в
`docs/tree-inventory.md`. Пересборка семени (bootstrap regeneration) не нужна.

`scripts/bootstrap-reprint.sh` и `scripts/seed-fingerprint` эта задача не
правит. Если первый оставить как есть, доля ниже 20 % недостижима вовсе: его
1346 комментариев при 3592 строках держат общую долю не ниже 21,8 % даже при
нулевых комментариях у остальных 8 файлов. Значит решение одно из двух —
править его шапки тоже или мерить долю без него — и принимается в начале работы.

Справка, на которую ссылается сообщение `.githooks/pre-push.fscript`: обход
`git push --no-verify` законен в трёх случаях: пушится рабочая ветка, которую
не сливают напрямую в `dev`; чинится сам хук; дерево заведомо красно по
названному долгу, и пушащий об этом знает. Во всех прочих случаях обход
перекладывает проверку на CI.
