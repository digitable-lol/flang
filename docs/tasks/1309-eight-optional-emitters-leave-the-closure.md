# 1309. Замыкание компилятора ввозит все десять печатников, и выигрыш от выноса девяти необязательных не замерен

## Шаги воспроизведения

1. Посмотреть ввозы компилятора:

```
sed -n 5,14p flang/self/bootstrap/compiler.flang
```

2. Убедиться, что печатники, кроме C, больше никто из замыкания не ввозит:

```
grep -ln "использует «Печать в Go»" flang/self/*.flang flang/self/bootstrap/*.flang
```

3. Смотреть: десять строк `использует «Печать в …»` в одном файле; для Go
   (и так же для остальных восьми) единственный ввоз — сам `flang/self/bootstrap/compiler.flang`.

## Что происходит

```
$ sed -n 5,14p flang/self/bootstrap/compiler.flang
  использует «Печать в C»
  использует «Печать в C++»
  использует «Печать в Go»
  использует «Печать в Rust»
  использует «Печать в Java»
  использует «Печать в JavaScript»
  использует «Печать в TypeScript»
  использует «Печать в Elixir»
  использует «Печать в Python»
  использует «Печать в C#»                                        код 0
$ grep -ln "использует «Печать в Go»" flang/self/*.flang flang/self/bootstrap/*.flang
flang/self/bootstrap/compiler.flang                               код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Семя печатается целью C; остальные девять печатников (файлы `flang/self/emit-cpp.flang`
… `flang/self/emit-csharp.flang`, по одному на цель) входят в замыкание только через эти строки и
доказываются ядром при каждой пересборке семени (bootstrap regeneration).
Сколько времени пересборки они отнимают, не измерено: цена доказательства
зависит от содержания условий, а не от их числа, и по счёту обязательств её
предсказать нельзя. `emit-c` вынести нельзя — его ввозят как общую библиотеку
разбора многие файлы замыкания.

## Что должно быть

Известно, сколько стоит пересборка семени с замыканием без девяти печатников
против полного, и по этому числу принято и записано решение (ADR): выносить
или оставить. Если выносить — `flang/self/bootstrap/compiler.flang` ввозит только «Печать в C», а
способ, которым `flang emit --target go` и остальные цели остаются доступны
(своя сборка двоичного с полным замыканием либо иной, отдельно описанный путь),
назван в решении; справка `flang emit --help` обещает десять целей, и это
обещание либо держится, либо меняется тем же решением.

## Обходной путь

Обходного пути нет: пересборка идёт с полным замыканием.

## Когда задача сделана

Два прогона проверки замыкания ядром, полный и без девяти печатников, с
временем каждого записаны в решении (ADR в `docs/adr/`), и решение принято.
Если решено выносить:

```
grep -c "использует «Печать в" flang/self/bootstrap/compiler.flang     → 1
bootstrap/flang emit docs/examples/rosetta/hundred-doors.flang --target c --out <каталог>   код 0
```

и путь к остальным целям, названный решением, проходит на той же программе.
Проба: проверка, которая краснеет, если в `flang/self/bootstrap/compiler.flang` вернётся ввоз
необязательного печатника.

## Где живёт правка

`flang/self/bootstrap/compiler.flang`, строки 5–14 (ввозы) и функции печати по
целям, которые их вызывают; таблица целей в `bootstrap/flang_repl.c`
(`EMIT_TARGET_TABLE`) разрешает цель по имени функции во время работы. Список
файлов замыкания строит `closure_files` в `scripts/bootstrap-reprint.sh`.
Правка в файлах под flang/self доезжает до двоичного только пересборкой семени.

Отдельная задача, здесь не решается: подгрузка печатника в готовый двоичный
без пересборки — новая возможность языка, а не перестановка файлов.
