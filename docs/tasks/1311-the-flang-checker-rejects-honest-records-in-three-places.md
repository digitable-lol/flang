# 1311. Проверяющая программа на flang отвергает честную запись, расходясь с программой на C в трёх местах

## Шаги воспроизведения

В дереве две независимые проверяющие программы (proof checker): на C —
`flang/proof/checker/checker.c`, и на flang — `flang/proof/checker.flang`,
её зовёт `flang/proof/check.fscript`.

1. Взять честную запись из набора и её исходник:
   `flang/proof/checker/tests/records/corpus/precondition.record`,
   `flang/proof/examples/precondition.flang`.
2. Проверить программой на C:

```
cc -std=c99 -O1 -o <каталог>/checker-c flang/proof/checker/checker.c
<каталог>/checker-c flang/proof/examples/precondition.flang flang/proof/checker/tests/records/corpus/precondition.record
```

3. Проверить программой на flang:

```
bootstrap/flang io flang/proof/check.fscript --timeout 1200000 -- \
  flang/proof/examples/precondition.flang \
  flang/proof/checker/tests/records/corpus/precondition.record
```

4. Сосчитать, знает ли программа на flang новые формы ходов:

```
grep -ac 'и дно' flang/proof/checker.flang
grep -ac 'требованием' flang/proof/checker.flang
grep -rla 'и дно' flang/proof/checker/tests/records | wc -l
grep -rla 'закрыть требованием' flang/proof/checker/tests/records | wc -l
```

## Что происходит

```
$ <каталог>/checker-c … precondition.flang … precondition.record
ПРОВЕРЕНО — запись сошлась с исходником, и всё доказанное проиграно заново:
утверждений 3, шагов сверено с исходником 3, … Числятся доказанными 2.   код 0
$ grep -ac 'и дно' flang/proof/checker.flang
0
$ grep -ac 'требованием' flang/proof/checker.flang
0
$ grep -rla 'и дно' flang/proof/checker/tests/records | wc -l
5
$ grep -rla 'закрыть требованием' flang/proof/checker/tests/records | wc -l
6
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026, ствол `09bc6880`.

```
$ bootstrap/flang io flang/proof/check.fscript … precondition.flang … precondition.record
НЕ СОШЛОСЬ: теорема «высота от дна неотрицательна», сведение: развёртка: в цели
«(«Высота от дна» от (вариант «Пусто»)) не меньше 0» нет терма
««Высота от дна» от (вариант «Пусто») и дно»; ход «ход 2 закрыть требованием
«дно неотрицательно» строка 10» стоит до «ход цель»; ход конец стоит без
«ход цель»; … теорема «удвоенное неотрицательно», строка 57: запись говорит
«по предположению правило «неотрицательность по построению»», а в исходнике
написано «по предположению»                                              код 1
```

Версия: flang 0.7.23. Прогон 2 октября 2026: 1 274 с (21 мин 14 с) одним
потоком, пик памяти 1,21 ГиБ (`/usr/bin/time -v`).

Запись содержит строки вида `ход 1 развернуть ⟨… и дно⟩` и
`ход 2 закрыть требованием «дно неотрицательно»`. Мест расхождения три.
Программа на flang не находит терм с хвостом «и дно» при развёртке
(«Развернуть по телу»); ход «закрыть требованием» она не признаёт ходом
закрытия — он «стоит до „ход цель“», и следом «ход конец стоит без „ход цель“»
(«Ход закрытия»); на теореме «удвоенное неотрицательно» запись говорит
«по предположению правило «…»», а программа ждёт «по предположению» без правила.

## Что должно быть

На честной записи обе программы отвечают одним кодом. `docs/flang/proof/SPEC.md`
описывает одну форму записи, и проверяющая программа обязана либо проиграть
ход, либо отказать названной причиной как подделке — но не отвергать честное.
Для хода «закрыть требованием» нужно решение владельца: проигрывать требование
по-настоящему либо отвечать отдельным исходом «не проверено»; принять ход на
веру нельзя — это принятие без проверки.

Номер формата в первой строке записи остался `запись доказательства 1`, хотя
форма выросла; ADR-0010 обещает менять номер при изменении формата.

## Обходной путь

Проверять записи программой на C. Короткая команда `proof-record:check` идёт
через программу на flang (`flang/proof/forgeries/run.fscript` зовёт
`check.fscript`), но её собственные записи новых ходов не содержат: ни «и дно»,
ни «закрыть требованием» в `flang/proof/forgeries/` не встречается ни разу.

## Когда задача сделана

Команда из шага 3 отвечает кодом 0 на `precondition.record` и на остальных
честных записях каталога `flang/proof/checker/tests/records/corpus/` с ходами
«и дно» и «закрыть требованием» — и на теореме, где запись называет правило
при «по предположению». Прогон `flang/proof/forgeries/run.fscript` отвечает
кодом 0, подделки отвергнуты как раньше. В каталоге `flang/proof/forgeries/`
есть подделка с ложным ходом «закрыть требованием», и программа на flang её
отвергает.

## Где живёт правка

`flang/proof/checker.flang`: «Развернуть по телу» (хвост «и дно»), «Ход закрытия»
(слово «требованием»); подделки и их перечень в `flang/proof/forgeries/`.
Программу читает двоичный с диска через `flang/proof/check.fscript`, пересборка
семени (bootstrap regeneration) не нужна.
