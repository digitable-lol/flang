# 1311. Проверяющая программа на flang отвергает честные записи с ходами «и дно» и «закрыть требованием»

## Шаги воспроизведения

В дереве две независимые проверяющие программы (proof checker): на C —
`flang/proof/checker/checker.c`, и на flang — `flang/proof/checker.flang`,
её зовёт `flang/proof/check.sh`.

1. Взять честную запись из набора и её исходник:
   `flang/proof/checker/tests/records/corpus/precondition.record`,
   `flang/proof/examples/precondition.flang`.
2. Проверить программой на C:

```
cc -std=c99 -O1 -o <каталог>/checker-c flang/proof/checker/checker.c
<каталог>/checker-c flang/proof/examples/precondition.flang flang/proof/checker/tests/records/corpus/precondition.record
```

3. Проверить программой на flang:

```
sh flang/proof/check.sh flang/proof/examples/precondition.flang flang/proof/checker/tests/records/corpus/precondition.record
```

4. Сосчитать, знает ли программа на flang новые формы ходов:

```
grep -ac 'и дно' flang/proof/checker.flang
grep -ac 'требованием' flang/proof/checker.flang
grep -rla 'и дно' flang/proof/checker/tests/records | wc -l
grep -rla 'закрыть требованием' flang/proof/checker/tests/records | wc -l
```

## Что происходит

```
$ <каталог>/checker-c … precondition.flang … precondition.record
ПРОВЕРЕНО — запись сошлась с исходником, и всё доказанное проиграно заново:
утверждений 3, шагов сверено с исходником 3, … Числятся доказанными 2.   код 0
$ grep -ac 'и дно' flang/proof/checker.flang
0
$ grep -ac 'требованием' flang/proof/checker.flang
0
$ grep -rla 'и дно' flang/proof/checker/tests/records | wc -l
5
$ grep -rla 'закрыть требованием' flang/proof/checker/tests/records | wc -l
6
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

```
$ sh flang/proof/check.sh … precondition.flang … precondition.record
ход 2 закрыть требованием …                                            код 1
```

Версия: flang 0.7.23. Не перепроверено: прогон дольше минуты.

Запись содержит строки вида `ход 1 развернуть ⟨… и дно⟩` и
`ход 2 закрыть требованием «дно неотрицательно»`. Программа на flang не
находит терм с хвостом «и дно» при развёртке и отвечает «закрыть „требованием“
сверщику неизвестно» в функции «Ход закрытия».

## Что должно быть

На честной записи обе программы отвечают одним кодом. `flang/proof/SPEC.md`
описывает одну форму записи, и проверяющая программа обязана либо проиграть
ход, либо отказать названной причиной как подделке — но не отвергать честное.
Для хода «закрыть требованием» нужно решение владельца: проигрывать требование
по-настоящему либо отвечать отдельным исходом «не проверено»; принять ход на
веру нельзя — это принятие без проверки.

Номер формата в первой строке записи остался `запись доказательства 1`, хотя
форма выросла; ADR-0010 обещает менять номер при изменении формата.

## Обходной путь

Проверять записи программой на C. Ярлыки `запись:проверка` и
`сведение:проверка` идут через программу на flang, но их собственные записи
новых ходов не содержат.

## Когда задача сделана

Команда из шага 3 отвечает кодом 0 на `precondition.record` и на остальных
честных записях каталога `flang/proof/checker/tests/records/corpus/` с ходами
«и дно» и «закрыть требованием». `sh flang/proof/forgeries/run.sh` и
`sh flang/proof/forgeries/reduction.sh` отвечают кодом 0, подделки отвергнуты
как раньше. В каталоге `flang/proof/forgeries/` есть подделка с ложным ходом
«закрыть требованием», и программа на flang её отвергает.

## Где живёт правка

`flang/proof/checker.flang`: «Развернуть по телу» (хвост «и дно»), «Ход закрытия»
(слово «требованием»); подделки и их перечень в `flang/proof/forgeries/`.
Программу читает двоичный с диска через `flang/proof/check.sh`, пересборка
семени (bootstrap regeneration) не нужна.
