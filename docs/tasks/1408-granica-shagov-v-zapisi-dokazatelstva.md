# 1408. «Завершится за N» — в запись, а не только в анализ

Решение: [ADR-0033](../docs/adr/0033-termination-is-not-a-bound-on-steps.md) §4–§5.

**Порога ADR-0026 у этой задачи нет:** граница шагов — утверждение о входах
одной функции, под тем единственным квантором, который в языке уже есть.
**Доставка** правки ядра — только партией перепечатки ADR-0026 §11; отдельной
перепечатки ради этой задачи не бывает (ADR-0032 §2.4).

## Чем измерено

Прогоны 11 сентября 2026, двоичный `bootstrap/flang` 0.7.17, ветка
`r/adr-otklik-otkaz` от `gh/dev` `2c40752d0`.

- Запись доказательства функции «Сумма до» (`убывает н`, спуск на единицу)
  несёт узел `принцип тип «неотрицательное» по «н» носитель segment база 1 шаг 1`
  и `объявление встроенный «неотрицательное» дно 0 потолок 9007199254740991`.
  Числа вызовов в записи нет; проверяющая программа сверяет только, что вызов в
  ветви спуска — `н минус 1` (`flang/proof/чекер/сверщик.c:4915`).
- Оценка витков многочленом есть (`flang/self/bounded.flang`), но в
  `obligations.flang`, `proof-kernel.flang`, `proofterm.flang`,
  `proof-initial.flang`, `сверщик.c` — 0 вхождений. Её потребляют только
  планировщик-эталон (`conc.flang:1890`) и множество отказов
  (`failures.flang:1408`).
- Числовая рекурсия оценки не получает («Причина числовая»,
  `bounded.flang:470`) — ровно та, у которой узел завершаемости знает дно и шаг.

## Что сделать

1. **Сперва замер, не код.** Двумя числами: сколько функций набора
   (те же 651 обязательство) получили бы оценку сегодняшним `bounded.flang`, и
   у скольких из оставшихся узел завершаемости — отрезок с дном и шагом, из
   которого число вызовов выводится в одну строку. Второе число — доля, которую
   даст правило из шага 2.
2. **Правило для числовой рекурсии** (ADR-0033 §4, часть А): из дна, шага и
   потолка — «вызовов не больше (н − дно) / шаг + 1»; витки одного вызова — из
   оценки тела. Решить и записать явно: многочлен от **значения** н, а не от
   размера (`bounded.flang:368` считает размер числа самим числом).
3. **Новый вид узла в записи** (часть Б): «оценка витков <многочлен>» с
   посылками по ветвям тела, по образцу узла отрезка
   (`flang/self/proof-initial.flang:2100–2126`). Строка в
   `flang/proof/ПРАВИЛА-ВЫВОДА.tsv` и лемма Lean на каждое правило — ADR-0022 §8А.
4. **Переигрывание** (часть В): проверяющая программа пересчитывает многочлен
   по телу из исходника и сверяет с записью. Читать новый узел она обязана
   **раньше**, чем ядро начнёт его печатать, — условие партии перепечатки.
5. **Проба на подлог:** запись с заниженным многочленом отвергается кодом 1.

## Чего не делать

- Не печатать в запись секунды. Секунды — задача 1409, и только для названной
  машины.
- Не трогать `flang/self/**` до замера шага 1 и вне партии перепечатки.
- Не считать предел шагов (`--max-steps`, `FLANG_RECURSION_LIMIT`) границей: он
  обрыв, а не доказательство (ADR-0033 §7).
- Не обещать долю: узел не сдвигает 96,01 % — он добавляет новый вид
  обязательства, а не доказывает старые.

## Как поймём, что сделано

Запись пробы «Сумма до» содержит строку с многочленом; `сверщик` даёт код 0 и
называет узел переигранным; подделка с заниженной оценкой — код 1; набор проб —
«сошлось всё»; `sh scripts/доказуемость.sh` — ДОКАЗУЕМ, доля не ниже 96,01 %.
