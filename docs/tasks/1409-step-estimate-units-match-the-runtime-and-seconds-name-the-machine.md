# 1409. Оценку витков функции не печатает ни одна команда, и с шагами рантайма она не сверена

## Шаги воспроизведения

1. Найти в справке команду или ключ, печатающие оценку витков функции:

```
bootstrap/flang --help | grep 'витк'
bootstrap/flang check --help | grep -c 'витк'
```

2. Снять постоянную машины — единственное, что о витках печатается:

```
bootstrap/flang --machine
```

## Что происходит

```
$ bootstrap/flang --help | grep 'витк'
  flang --machine [<файл>]           постоянная этой машины: витков в секунду
$ bootstrap/flang check --help | grep -c 'витк'
0                                                                 код 1
$ bootstrap/flang --machine
машина
  ядер: …
  занято ядер: …
  свободно ядер: …
  витков в секунду, разбор: …
  витков в секунду, лексер: …
  разброс: …
  …                                                               код 0
```

Оценка считается в `flang/self/bounded.flang` («Оценить витки»), но наружу её
не выводит ни одна команда. Единицы у оценки и у рантайма разные: оценка берёт
встроенную форму над строкой за один виток, а `fl_charge` в
`flang/src/emit/c/flang_runtime.c` заряжает ту же форму длиной. Сходятся ли
два счёта на настоящих обработчиках, не проверено ни одним прогоном.
Постоянных машины две, они различаются между собой и зависят от загрузки;
команды, которая перемножает оценку и постоянную, нет.

## Что должно быть

ADR-0033 (`docs/adr/0033-termination-is-not-a-bound-on-steps.md`), §2.3–§2.4
и §4, части Д и Е:

1. Команда или ключ у `flang check` печатает для каждой функции
   «витков ≤ многочлен» либо «оценки нет» с причиной.
2. На обработчиках дерева с постоянной оценкой многочлен сравнён со счётчиком
   `ctx->steps` на тех же входах: сколько сошлось, сколько разошлось и во
   сколько раз. Если расходятся, в ADR-0033 §9 записано, какой из двух
   счётчиков ограничивает запись доказательства (это условие задачи 1408).
3. Команда берёт оценку и файл постоянной от `--machine` и печатает секунды
   двумя числами, по обеим постоянным, с загрузкой, при которой постоянная
   снята.

Оценку длиной строки не заряжать: длина строки статически не выводится.
Секунды без названия машины и без разброса не печатать. Результат не называть
границей времени отклика (ADR-0033 §5.1).

## Обходной путь

Обходного пути нет: оценку функции получить нечем.

## Когда задача сделана

Для функции «Сумма до» команда печатает строку «витков ≤ …», и та же команда с
файлом постоянной печатает секунды двумя числами и загрузку. Напечатаны числа
по дереву: сошлось и разошлось по единицам; постоянных, растущих и без оценки
среди программ с `процесс`. У печати оценки есть пример, который краснеет,
если строка «витков ≤ …» пропадёт из вывода.

## Где живёт правка

Ключ и печать — `flang/self/cli.flang` и `flang/self/bounded.flang`; перевод в
секунды — рядом с `--machine` в `flang/src/emit/c/flang_repl.c`. Обе правки
доезжают до двоичного только пересборкой семени (bootstrap regeneration).
Решение о единицах — текстом в ADR-0033 §9.
