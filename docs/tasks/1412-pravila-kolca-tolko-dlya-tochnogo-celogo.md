# 1412. Пять правил кольца — только для нового типа

Решение: [ADR-0036](../adr/0036-an-exact-integer-is-a-new-kind-of-value-not-a-new-name.md) §3 и §11 п. 4.

**Порог: [1411](1411-nositel-tochnogo-celogo-eto-novyy-vid-znacheniya.md).
До выбранного представления задача не начинается.**

## Чем измерено

Прогон `flang check --proof --строго` 13 сентября 2026, двоичный 0.7.19. Пять
законов кольца, записанных постусловиями при параметрах `целое`:

| закон | исход |
|---|---|
| коммутативность | **доказано** («тождество после переписки допущением») |
| ассоциативность | объявлено, не доказано |
| дистрибутивность | объявлено, не доказано |
| нейтральный ноль | объявлено, не доказано |
| обратный по сложению | объявлено, не доказано |

Итог: `утверждений 5: доказано 1, объявлено, не доказано 4`. **Замена типа на
`сотых` и на `неотрицательное` даёт тот же счёт 1 из 5** — носитель у всех трёх
один и тот же double.

**Чего нет в ведомости поимённо.** `flang/proof/tables/inference-rules.tsv` (199 строк:
85 правил и 12 запретов) несёт семейство Тожд из двух строк: Тожд1 — перестановка
операндов ОДНОГО узла, Тожд2 — нейтральный ноль с ОБЯЗАТЕЛЬНОЙ посылкой `0 < Т`
(без неё правило ложно на минус нуле). Ассоциативности, дистрибутивности,
обратного по сложению и нейтральной единицы нет ни строкой, и шапка ведомости
говорит почему: «`плюс` на `число` в IEEE-754 не ассоциативен, значит моноида
нет».

## Что сделать

1. Завести пять строк ведомости и пять лемм в `flang/proof/lean/Rules.lean`
   (там сегодня 105 лемм) — **вместе с кодом**, как заведены Тожд1 и Тожд2.
2. Каждое правило ограничить новым типом. **На `число` они не распространяются**,
   и проба §15 п. 2 решения это стережёт.
3. Деление и остаток в правила НЕ вносить: кольцо целых не поле. Сказать это в
   тексте отказа, а не умолчать.
4. Попросить строку бюджета в `flang/proof/checker/ratchet.txt` (потолок 7188).
   Оценка по образцу ADR-0029 — +150…+250 строк кода сверщика; **это оценка, и
   настоящая цена называется после эталона записи.**

## Как поймём, что сделано

Проба из пяти законов на новом типе даёт `доказано 5`; та же проба на `число`
даёт `доказано 1`; программа, объявляющая ассоциативность для `число`, кода 0 не
получает. У каждой новой строки ведомости колонка «опора» называет живую строку
ядра, и сторож С-1 это подтверждает.

## Чего задача НЕ делает

Не обещает роста доли корпуса: новый тип в корпусе не используется, пока на нём
ничего не написано (ADR-0036 §11 п. 7). Не трогает правил о `число`.

## Чем кончилось

Приём задачи — «проба из пяти законов на новом типе даёт `доказано 5`; та же проба на
`число` даёт `доказано 1`». Прогон 22 сентября 2026: пробы в дереве нет
(`git ls-files | grep -i 'ring-rules|kolca|кольц'` находит только саму задачу), нового типа
тоже (см. 1908). Не сделана; ветка `a/1412-ring-rules-exact-integer` на сервере не живёт.
