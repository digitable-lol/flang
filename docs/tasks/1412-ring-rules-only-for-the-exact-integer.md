# 1412. Правил кольца для точного целого нет, а нейтральная единица не выводится ни на одном типе

## Шаги воспроизведения

1. Программа:

```flang
модуль «Законы кольца на целом»

утверждение «сложение перестановочно»
  для всех а: целое и б: целое
  утверждаем (а плюс б) равен (б плюс а)

утверждение «сложение сочетательно»
  для всех а: целое и б: целое и ц: целое
  утверждаем ((а плюс б) плюс ц) равен (а плюс (б плюс ц))

утверждение «умножение распределительно»
  для всех а: целое и б: целое и ц: целое
  утверждаем (а умножить на (б плюс ц)) равен ((а умножить на б) плюс (а умножить на ц))

утверждение «у сложения есть обратный»
  для всех а: целое
  утверждаем (а плюс (0 минус а)) равен 0

утверждение «единица нейтральна при умножении»
  для всех а: целое
  утверждаем (а умножить на 1) равен а
```

2. Команда: `bootstrap/flang check <файл> --proof --strict`.
3. Смотреть вердикт каждого утверждения и код возврата.

## Что происходит

```
$ bootstrap/flang check <файл> --proof --strict
  утверждение «сложение перестановочно» — доказано … правило «тождество после переписки допущением»
  утверждение «сложение сочетательно» — объявлено, не доказано
  утверждение «умножение распределительно» — объявлено, не доказано
  утверждение «у сложения есть обратный» — объявлено, не доказано
  утверждение «единица нейтральна при умножении» — объявлено, не доказано
  утверждений 5: доказано 1 (из них без теоремы 1), сетка 0, объявлено, не доказано 4
                                                                 код 3
```

У `целое`, `неотрицательное` и `число` один носитель — двоичное число с
плавающей точкой. Сочетательность и распределительность на нём ломает
округление, обратный по сложению — бесконечность; в
`flang/proof/tables/inference-rules.tsv` они стоят запретами Тожд✗, Тожд✗✗ и
Тожд✗✗✗, и отказ на них верен. Правилами они станут только на точном целом
(`точное целое`). Нейтральная единица на сегодняшнем
носителе `число` верна только на конечных значениях и бесконечностях: в модели
(`flang/proof/lean/Model.lean`, «равен» и «умножить») «не число» не равно
ничему, даже себе, а `минус ноль умножить на 1` округляется в `кон 0`, который
минус нулю не равен. На этих двух значениях пятое утверждение ложно, и правила у
единицы тоже нет.

## Что должно быть

ADR-0036 §11 п. 4: правила кольца пишутся только для точного целого —
сочетательность и перестановочность `плюс` и `умножить`, распределительность,
нейтральный ноль, нейтральная единица, обратный по сложению. Каждое — строкой
перечня правил и леммой Lean, заводимыми вместе с кодом ядра. На `число`
правила не распространяются. Деление и остаток в правила не входят: кольцо
целых не поле, и текст отказа говорит это прямо.

## Что уже есть

Правило `Кол1` в `flang/self/proof-kernel.flang` («Сумма точных сошлась» и
соседние функции): обе стороны цели расплющиваются в набор листьев суммы и
сличаются с точностью до порядка и кратности. Правило включается, только если
каждый лист обеих сторон — имя, объявленное `точное целое`; выписанный список
вроде `[7, 0, 0]` против `[7]` правило гасит (строка `Кол✗` перечня правил).
Своего печатаемого имени у правила нет: в записи стоит «тождество после
переписки допущением».

Та же программа, где `целое` заменено на `точное целое`, на двоичном даёт:

```
$ bootstrap/flang check <файл> --proof --strict
  утверждение «сложение перестановочно» — доказано …
  утверждение «сложение сочетательно» — доказано по объявленным типам аргументов …
  утверждение «умножение распределительно» — объявлено, не доказано …
```

`умножить` над точным целым перестановочностью доказывается, сочетательность
`умножить` — нет. Ядро без разбора двоичным гоняет проба
`flang/proof/probes/ring-laws/` (`bootstrap/flang io
flang/proof/probes/ring-laws/run.fscript --plan Binary`): «кольцо на точном
целом: доказано 2 из 2, отвергнуто 6 из 6» — шесть отрицательных контролей
(`целое`, смесь с `число`, ложная цель, неканонические разряды) не проходят.

## Что осталось

1. Сочетательность `умножить`, распределительность, нейтральный ноль,
   нейтральная единица и обратный по сложению над точным целым.
2. Леммы Lean у строк `Кол1` и `Кол✗` нет: в `flang/proof/lean/Model.lean` нет
   носителя «точное целое», лемма над ℤ требует нового носителя модели.

## Обходной путь

Перестановку операндов и нейтральный ноль с посылкой `а больше 0` ядро выводит
уже сейчас. Остальное — теоремой при утверждении либо проверкой при работе.

## Когда задача сделана

Программа из шагов воспроизведения с `точное целое` вместо `целое` даёт
«доказано» на всех пяти утверждениях и код 0; она же на `целое` даёт прежний
счёт, и утверждение о сочетательности на `целое` кода 0 не получает. У каждой
новой строки перечня правил колонка `anchor` называет живую функцию ядра:
`bootstrap/flang io flang/proof/tables-guard.fscript --plan 'Tables guard'
--max-steps 4000000000 --timeout 900000` отвечает кодом 0 (без `--timeout` сосед
`rules-match.fscript --list-only` молчит дольше 30 с, хозяин его обрывает, и
сторож краснеет не по делу). У каждой строки перечня — лемма в
`flang/proof/lean/Rules.lean`. Пробы лежат в `flang/proof/probes/ring-laws/`.

## Где живёт правка

- `flang/self/proof-kernel.flang`: правила кольца; новые функции — в конце
  файла, чтобы не сдвинуть опоры перечня правил;
- `flang/proof/tables/inference-rules.tsv` и `flang/proof/tables-guard.fscript`:
  строки правил и семейство «Кол»;
- `docs/flang/proof/inference-rules.md`, `docs/flang/proof/tables.md`: проза
  правил;
- `flang/proof/lean/Model.lean`, `flang/proof/lean/Rules.lean`: носитель и
  леммы;
- `flang/proof/probes/ring-laws/`: пробы.

Правки под `flang/self` доезжают до двоичного только пересборкой семени
(bootstrap regeneration).
