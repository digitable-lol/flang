# 1412. Правил кольца для точного целого нет, а нейтральная единица не выводится ни на одном типе

## Шаги воспроизведения

1. Программа:

```flang
модуль «Законы кольца на целом»

утверждение «сложение перестановочно»
  для всех а: целое и б: целое
  утверждаем (а плюс б) равен (б плюс а)

утверждение «сложение сочетательно»
  для всех а: целое и б: целое и ц: целое
  утверждаем ((а плюс б) плюс ц) равен (а плюс (б плюс ц))

утверждение «умножение распределительно»
  для всех а: целое и б: целое и ц: целое
  утверждаем (а умножить на (б плюс ц)) равен ((а умножить на б) плюс (а умножить на ц))

утверждение «у сложения есть обратный»
  для всех а: целое
  утверждаем (а плюс (0 минус а)) равен 0

утверждение «единица нейтральна при умножении»
  для всех а: целое
  утверждаем (а умножить на 1) равен а
```

2. Команда: `bootstrap/flang check <файл> --proof --strict`.
3. Смотреть вердикт каждого утверждения и код возврата.

## Что происходит

```
$ bootstrap/flang check <файл> --proof --strict
  утверждение «сложение перестановочно» — доказано … правило «тождество после переписки допущением»
  утверждение «сложение сочетательно» — объявлено, не доказано
  утверждение «умножение распределительно» — объявлено, не доказано
  утверждение «у сложения есть обратный» — объявлено, не доказано
  утверждение «единица нейтральна при умножении» — объявлено, не доказано
  утверждений 5: доказано 1 (из них без теоремы 1), сетка 0, объявлено, не доказано 4
                                                                 код 3
```

Версия: flang 0.7.23. Дата прогона: 3 октября 2026.

У `целое`, `неотрицательное` и `число` один носитель — двоичное число с
плавающей точкой. Сочетательность и распределительность на нём ломает
округление, обратный по сложению — бесконечность; в
`flang/proof/tables/inference-rules.tsv` они стоят запретами Тожд✗, Тожд✗✗ и
Тожд✗✗✗, и отказ на них верен. Правилами они станут только на точном целом,
а этого типа в языке нет (задача 1908). Нейтральная единица на сегодняшнем
носителе верна только на конечных значениях и бесконечностях: в модели
(`flang/proof/lean/Model.lean`, «равен» и «умножить») «не число» не равно
ничему, даже себе, а `минус ноль умножить на 1` округляется в `кон 0`, который
минус нулю не равен. На этих двух значениях пятое утверждение ложно, и правила у
единицы тоже нет.

## Что должно быть

ADR-0036 §11 п. 4: правила кольца пишутся только для точного целого —
сочетательность и перестановочность `плюс` и `умножить`, распределительность,
нейтральный ноль, нейтральная единица, обратный по сложению. Каждое — строкой
перечня правил и леммой Lean, заводимыми вместе с кодом ядра. На `число`
правила не распространяются. Деление и остаток в правила не входят: кольцо
целых не поле, и текст отказа говорит это прямо.

## Обходной путь

Перестановку операндов и нейтральный ноль с посылкой `а больше 0` ядро выводит
уже сейчас. Остальное — теоремой при утверждении либо проверкой при работе.

## Когда задача сделана

Программа из шагов воспроизведения с точным целым вместо `целое` даёт «доказано
5», код 0; она же на `число` даёт прежний счёт, и утверждение о
сочетательности на `число` кода 0 не получает. У каждой новой строки перечня
правил колонка `anchor` называет живую функцию ядра:
`bootstrap/flang io flang/proof/tables-guard.fscript` отвечает кодом 0. Пробы
лежат рядом с `flang/proof/checker/tests/families/statement/ring-laws-provable.flang`,
и `bootstrap/flang io flang/proof/checker/tests/run.fscript` (ярлык
`checker:check`) отвечает кодом 0: честные записи приняты, подделки отвергнуты.

Нейтральную единицу можно завести раньше, на сегодняшнем носителе, но только с
посылкой, отсекающей «не число» и минус ноль, — той же по роли, с какой ядро
выводит нейтральный ноль (`а больше 0` в `ring-laws-provable.flang`). Без
посылки пятое утверждение не истинно, и «доказано» на нём требовать нельзя.

## Где живёт правка

- `flang/self/proof-kernel.flang`: «Свести равенство» — новые случаи рядом с
  «Слагаемое без нуля» и «Нейтральный ноль сошёлся»;
- `flang/self/proof-record.flang`: «Слагаемое без нуля записи» и печать хода в записи
  доказательства;
- `flang/proof/checker/checker.c` и `flang/proof/checker.flang`: чтение нового
  хода, список ходов в них закрытый;
- `flang/proof/tables/inference-rules.tsv` и `flang/proof/lean/Rules.lean`:
  строка правила и лемма. Лемме о единице нужны посылки: модель допускает целые
  сверх 2⁵³, и округление их двигает, а на «не числе» и минус нуле «равен»
  ложно.

Потолок строк кода независимой проверяющей программы (proof checker) записан в
`flang/proof/ratchets.txt` ключом `checker-code-lines` (сегодня 8127); строку
бюджета просить до работы. Правки под `flang/self` доезжают до двоичного только
пересборкой семени (bootstrap regeneration). Пять правил, кроме единицы, ждут
задачу 1908.
