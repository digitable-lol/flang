# 1415. Расширение «.fscript» не знают пять мест отбора: ввоз модуля по имени и обход каталога его пропускают

## Шаги воспроизведения

1. Спросить проверку расширений, сколько мест ещё не называют расширение
   скрипта:

```
bootstrap/flang run-script file-extensions:check
```

2. Два файла в одном каталоге. Модуль в файле скрипта:

```flang
модуль «Полка»

тотальная функция «Двойка»
  возвращает число
  2
```

   и программа, которая ввозит его по имени:

```flang
модуль «Читатель»
  использует «Полка»

тотальная функция «Четвёрка»
  возвращает число
  («Двойка») плюс («Двойка»)
```

3. Команда, первый файл назван lib.fscript:

```
bootstrap/flang check <каталог>/by-name.flang
```

## Что происходит

```
$ bootstrap/flang run-script file-extensions:check
… расширения сведены: списка два (языка: .flang, .fp, .фп, .фланг; скрипта:
.fscript), мест отбора 43 — все называют оба целиком; ждут своей работы 5, и
каждое названо в «Осталось»; …                                     код 0
$ bootstrap/flang check <каталог>/by-name.flang
FLANG_IMPORT_NOT_FOUND … строка 1, столбец 1: не найден модуль «Полка»: ни
рядом с файлом, ни выше по каталогам, ни в библиотеке компилятора
<каталог>/by-name.flang: не проверено — замечаний 3                 код 1
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

Пять ждущих мест перечислены в функции «Осталось» файла
`scripts/guards/file-extensions.fscript`. Четыре из них отбирают файлы по
расширению и расширения скрипта не называют:

- `flang/src/emit/c/flang_repl.c`, `repl_place_read` — ввоз по имени берёт из
  каталога только файлы «.flang»;
- `flang/self/bootstrap/corpus.flang`, «Заканчивается расширением» — по этому
  списку `flang test` обходит каталог; список в функции сегодня из четырёх
  расширений, и `flang test` по каталогу из трёх файлов (`.flang`, `.flang`,
  `.fscript`) отвечает «файлов 2, взято 1, отказано 1»;
- `scripts/bootstrap-reprint.sh` — `find` по трём расширениям;
- `scripts/editors/vscode-highlight-check.fscript` — «Три расширения».

Пятое, `scripts/ledgers/cyrillic-file-names-debt.txt`, расширение только
цитирует именем файла.

## Что должно быть

ADR-0018 (`docs/adr/0018-file-extensions-are-one-list.md`): расширения названы
в одном месте, и каждое место отбора берёт списки целиком. Файл «.fscript» —
файл языка: его функции доказываются, примеры прогоняются, модуль ввозится так
же, как из «.flang». Молчаливый пропуск файла при обходе недопустим.

## Обходной путь

Ввозить модуль по пути: строка `использует «Полка» из "lib.fscript"` проходит
проверку с кодом 0. Файлы «.fscript» подавать `flang test` и `flang check` по
одному, а не каталогом.

## Когда задача сделана

```
bootstrap/flang check <каталог>/by-name.flang                       код 0
bootstrap/flang run-script file-extensions:check     → «ждут своей работы 1» (остаётся только
                                   файл со списком кириллических имён), код 0
```

`flang test` по каталогу с одним файлом «.flang» и одним «.fscript» отвечает
«файлов 2». У «Заканчивается расширением» есть пример с именем на «.fscript»;
он краснеет, если расширение пропадёт из списка. Пять мест перенесены из
«Осталось» в «Места отбора».

## Где живёт правка

`flang/self/bootstrap/corpus.flang` и `flang/src/emit/c/flang_repl.c` доезжают
до двоичного только пересборкой семени (bootstrap regeneration);
`scripts/bootstrap-reprint.sh` правится той же работой. Остальные два места и
перенос записей в `scripts/guards/file-extensions.fscript` пересборки не
требуют.

Отдельная задача, здесь не решается: 90 файлов с объявлением `план` остаются
под расширением «.flang» (счёт — `git grep -l -E '^план «' -- '*.flang'`).
