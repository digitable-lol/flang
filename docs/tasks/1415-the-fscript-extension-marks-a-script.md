## Зачем

Отличать скрипт от программы глазами по имени файла — настоящая польза, и
владелец назвал её прямо.

## Порог входа

**Пороги — 4143 и 1414, и это не формальность.**

У `flang io` нет доводов командной строки: единственный отбор — `--plan 'Имя'`,
а «над чем работать» передают файлом запроса с заранее известным именем
(`scripts/registry-tool.fscript`, шапка: «чтобы поискать другое имя, файл запроса
надо переписать»). Пока это так, файл с расширением `.fscript` НЕ является
скриптом ни в каком смысле, кроме написанного на нём слова: его нельзя позвать
с доводами и нельзя сделать исполняемым с пользой.

Переименование до взятия обоих порогов — это 31 правка ради буквы в имени,
без единого нового умения. Так и записано здесь, чтобы следующий не начал с
конца.

## Шаги

- **Ш0 — дождаться 4143 (шаги 2–3) и ответа 1414.** Без них задача не
  начинается.
- **Ш1 — решить, что такое скрипт.** Расширение обязано что-то ЗНАЧИТЬ для
  прибора, а не только для глаза: либо `.fscript` зовётся иначе (`flang io` без
  `--plan`), либо принимает доводы, либо исполняется через `#!`. Выбрать одно и
  записать почему.
- **Ш2 — цена числом.** Пройти все 31 место и назвать, какие из них о
  расширении ПРОГРАММЫ, а какие о расширении СКРИПТА: это разные списки, и
  сводить их в один — та же ошибка, которую чинила 0062.
- **Ш3 — правка**, по одному месту на коммит, со сторожем зелёным после
  каждого.

### 1. Что такое скрипт в этом языке — по прибору, а не по слову

Скрипт — файл языка, в котором есть хотя бы один `план`: `план «Имя»` со
`состояние «Тип»`, `начинает с «Ф»` и `обрабатывает «Ш»`; шаг возвращает
«Продолжение» — «Сделать» с поручением (их 22: файлы, каталоги, процессы, сеть,
часы, случайность), «Конец работы» или «Провал». Поручения исполняет хозяин,
функции остаются тотальными и проверяются примерами без файлов и сети
(`docs/site/cli.ru.md`, раздел `io`; `docs/flang/SPEC.md:1155`).

| вопрос | ответ прибора (0.7.19, `51c2625e`) |
|---|---|
| как зовут | `flang io файл [--plan Имя]`. Без `--plan` при одном плане — исполняется: `flang io flang/test/fixtures/plany/00-tselyj.flang` → `{"plan":"Работа","result":1,…}`, код 0. При нескольких — код 3, `FLANG_UNKNOWN_PLAN` «планов несколько («Выписать имена», …) — назовите нужный» (`flang/scripts/name-guard.fscript`, 4 плана). При нуле — код 3, «в программе нет ни одного плана: исполнять нечего» (`flang/stdlib/lists.flang`) |
| что может скрипт и не может программа | встретиться с миром. У функции есть только аргументы и результат (`flang/self/link.flang:17–19`); файл без плана `flang io` не исполняет — код 3. Программу зовут `flang run --function --args`, `flang check`, `flang test` |
| чего не может скрипт сегодня | принять доводы вызова (код 2 на `--` и на `--n=5`); напечатать строку на экран (`FLANG_IO_NO_SCREEN`); вынести код возврата потомка наружу («Провал» — всегда 1); исполниться через `#!` — лексер отвергает первую же строку: `FLANG_LEX … строка 1, столбец 1: недопустимый символ '#'`, код 1 и у `check`, и у `io`. Ровно эти четыре нехватки перечислены в шапке `ярлык` как причина, по которой ярлыки — на оболочке |
| читается ли расширение | у передней двери — нет: `check` и `io` на копии `script.fscript` отвечают кодом 0 и работают. У обхода — да: каталог с `plain.flang` и `script.fscript` (одно содержимое) → `flang test` «файлов 1, взято 1, отказано 0» — второй файл **пропущен молча**, это та самая беда ADR-0018 |

### 2. Что расширение обязано ЗНАЧИТЬ для прибора — выбор

Три варианта задачи, каждый проверен прогоном выше:

* **(а) «зовётся иначе»** — не покупает ничего: `flang io` уже решает по
  содержимому (один план / несколько / ни одного), и расширение здесь только
  дублирует то, что прибор знает точнее.
* **(в) «исполняется через `#!`»** — требует правки лексера
  (`flang/self/lexer.flang`: пропускать первую строку, начинающуюся с `#!`) и
  перепечатки семени; до неё двоичный такой файл не прочтёт. Это отдельная
  задача первой стопки — трёхшаговый порядок AGENTS.md, правило 2.
* **(б) «принимает доводы»** — это и есть 4143, шаг 3: хозяин отдаёт отклик
  «Доводы» на поручение «Прочитать доводы» (поручение в словаре есть,
  `parser.flang:6613`, не применено нигде). Единственный из трёх вариантов, что
  даёт скрипту умение, которого нет у программы, и ровно то, чего не хватает
  `ярлыку` (пункт 1 его шапки).

**Решение: `.fscript` значит «файл с планом, который зовут `flang io` и которому
передают доводы вызова».** Пока 4143 шаг 3 не сделан, у слова нет предмета, и
переименовывать нечего: 32 правки и 1242 строки ссылок (ниже) купили бы букву в
имени. `#!` — желательное дополнение, но после (б) и своей задачей.

Что расширение обязано значить для **обхода**, независимо от (б): `.fscript` —
файл языка. Его функции доказываются, примеры гоняются, имена и слова сверяются
так же, как у `.flang`, — все 169 скриптов дерева несут функции. Значит в
`scripts/guards/file-extensions.fscript` заводится **второй закрытый список**
«Расширения скрипта» = `[".fscript"]`, а «Имя файла языка» спрашивает оба;
сводить их в один список нельзя — это разные вопросы, и ровно такое смешение
чинила 0062. У передней двери по-прежнему берётся что дают (ADR-0018, п. 2):
`flang io файл.flang` продолжает работать, переезд не ломает ни одного из 87
вызовов, пока они не переписаны.
