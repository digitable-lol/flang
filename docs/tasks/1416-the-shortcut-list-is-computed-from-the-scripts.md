# 1416. Перечень ярлыков записан дважды — в самих скриптах и рукописной таблицей в корне

## Шаги воспроизведения

1. Посчитать ярлыки в таблице:

```
bootstrap/flang run ярлыки.flang --function '«Сколько ярлыков»' --trust
```

2. Собрать те же ярлыки из объявлений в скриптах и сличить с таблицей:

```
bootstrap/flang io scripts/shortcut-collector.fscript --plan Сбор --max-orders 20000 --trust
```

3. Смотреть поле `result` второго ответа: сколько ярлыков есть и в таблице, и в
   скриптах, и сколько только в таблице.

## Что происходит

```
$ bootstrap/flang run ярлыки.flang --function '«Сколько ярлыков»' --trust
149                                                               код 0
$ bootstrap/flang io scripts/shortcut-collector.fscript --plan Сбор --max-orders 20000 --trust
… "result":"скриптов обойдено 1259, с объявлениями прочитано по отбору; объявлений 144;
целей в таблице 149: сошлось знак в знак 144, расходится 0, только в таблице 5
  только в таблице: сборка
  только в таблице: умения:улики
  только в таблице: доказуемость
  только в таблице: двоичный:приёмка
  только в таблице: тесты","orders":2690 …                       код 0, 13 с
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

У 144 ярлыков два экземпляра: объявление в скрипте (строка `# ярлык «имя» …` в
`.sh`, функция «Объявление ярлыка имя» в `.flang` и `.fscript`) и запись в
функции «Все ярлыки» файла `ярлыки.flang`. `./ярлык` читает только таблицу.
Пять ярлыков объявить в скрипте нельзя: у `сборка` скрипта нет (это `make -C
bootstrap`), у `тесты` вместо файла образец `flang/test/*.test.mjs`, у
`умения:улики` ключ стоит перед путём, а сборщик понимает только порядок
«исполнитель, путь, доводы»; `доказуемость` и `двоичный:приёмка` в скрипты не
перенесены.

## Что должно быть

Источник один — объявление в скрипте. `./ярлык` печатает и запускает то, что
собрано из скриптов; новый скрипт с объявлением даёт новый ярлык без правки
файлов в корне. В `ярлыки.flang` остаётся сборщик и те ярлыки, у которых
скрипта нет вовсе.

## Обходной путь

Править ярлык в двух местах — в скрипте и в таблице. Расхождение между ними
ловит план «Сбор»: он называет разошедшийся ярлык поимённо и отвечает кодом 1.
Его зовёт `bootstrap/flang run-script scripts:check`.

## Когда задача сделана

- план «Сбор» отвечает «только в таблице 0» либо называет только ярлыки без
  скрипта (`сборка`), и в `ярлыки.flang` записей ровно столько;
- `./ярлык` без доводов печатает те же 149 имён, что и до правки;
- проба: в каталог `scripts/` положен новый скрипт с объявлением — `./ярлык`
  показывает его ярлык, хотя ни `ярлыки.flang`, ни `ярлык` не правились; скрипт
  убран — ярлык исчез;
- вызов `./ярлык <имя>` не стал заметно дольше: сегодня чтение таблицы стоит
  около 4 с, обход дерева сборщиком — 13 с, и платить 13 с на каждый вызов
  нельзя.

## Где живёт правка

`ярлыки.flang` (функция «Все ярлыки», строки 8–737), `ярлык` (оболочка, которая
спрашивает таблицу), `scripts/shortcut-collector.fscript` (научить форме «ключи
перед путём» и образцу вместо файла), объявления в скриптах для `доказуемость`
и `двоичный:приёмка`. Всё это скрипты, читаются двоичным с диска; пересборка
семени (bootstrap regeneration) не нужна.

Отдельная задача, здесь не решается: четвёртое поле ярлыка «срок» — задача 4107.
