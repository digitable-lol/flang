# 1417. В «ярлыки.flang» остаются строки длиннее 120 знаков — разбор не принимает перенос внутри утверждения и записи

## Шаги воспроизведения

1. Посчитать длинные строки:

```
awk 'length>120' ярлыки.flang | wc -l
awk '{if(length>m)m=length}END{print m}' ярлыки.flang
```

2. Проверить, даёт ли разбор перенести утверждение. Программа:

```flang
модуль «Перенос»

тотальная функция «Ноль или больше»
  принимает н: неотрицательное
  возвращает число
  обеспечивает «ноль или положительно» (результат равен 0)
    или (результат больше 0)
  пример «ноль»
    дано н равно 0
    ожидается 0
  н
```

```
bootstrap/flang check <файл>
```

## Что происходит

```
$ awk 'length>120' ярлыки.flang | wc -l
20
$ awk '{if(length>m)m=length}END{print m}' ярлыки.flang
269
$ bootstrap/flang check <файл>
FLANG_PARSE в файле <файл>, строка 7, столбец 5: не разобрана конструкция: неожиданное ''
<файл>: не проверено — замечаний 1                                код 1
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

То же утверждение одной строкой проходит проверку с кодом 0. Перенос списка
параметров после запятой отвечает «ожидалось имя параметра», код 1.

Из 20 длинных строк две — куски строкового литерала внутри
`соединить [ … ] по ""` (строки с `scripts/seed/new-binary-acceptance.fscript` и с планом
«Целость»); их можно разбить на куски уже сегодня. Остальные 18 разбор
перенести не даёт: `обеспечивает …` с `или`, цепочка полей
`запись «Ярлык» с … и …` в `дано`, литерал в `дано` и `ожидается` примера,
`отфильтровать … где …`, список параметров в `принимает`, `вариант … с … и …`.
Что переносится, а что нет, разобрано в
`docs/zettel/a-record-literal-cannot-wrap-but-a-bracketed-list-can.md`.

## Что должно быть

В `ярлыки.flang` нет строк длиннее 120 знаков. Раскладка не меняет смысла:
перечень, который печатает `./ярлык`, совпадает знак в знак с перечнем до
раскладки.

## Обходной путь

Читать файл с переносом строк в редакторе. Длинный строковый литерал вне
примера разбивается на куски через `соединить [ … ] по ""`.

## Когда задача сделана

Выбрано и записано одно из двух:

1. разбор принимает продолжение строки в перечисленных конструкциях, файл
   разложен, и `awk 'length>120' ярлыки.flang | wc -l` печатает 0;
2. остаток признан пределом: две строки-литерала разбиты, команда печатает 18,
   и это число стоит потолком в проверке, которая краснеет при росте.

В обоих случаях вывод `./ярлык` до и после совпадает (`cmp`, код 0),
`grep -c 'запись «Ярлык» с «имя»' ярлыки.flang` печатает то же число, что до
правки (сегодня 153), `./ярлык задачник:проверка` отвечает кодом 0. При первом
исходе программа из шагов воспроизведения проходит `check` с кодом 0 и стоит
примером разбора.

## Где живёт правка

Раскладка — `ярлыки.flang`, пересборка семени (bootstrap regeneration) не
нужна. Перенос строк в разборе — `flang/self/parser.flang`; эта правка
доезжает до двоичного только пересборкой семени, и применять перенос в
`ярлыки.flang` можно лишь после неё, отдельным изменением.
