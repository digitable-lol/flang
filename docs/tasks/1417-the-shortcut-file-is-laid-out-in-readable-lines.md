# 1417. В «.flangrc» 54 строки длиннее 120 знаков — перенести их разбор настроек не даёт

Короткие команды переехали из снятой таблицы ярлыков в `.flangrc` (задача
1416): одна команда — одна строка `script.<имя> = <команда>`. Перечень печатает
`flang run-script`, прежней оболочки ярлыков больше нет.

## Шаги воспроизведения

1. Посчитать длинные строки и самую длинную:

```
awk 'length>120' .flangrc | wc -l
awk '{if(length>m)m=length}END{print m}' .flangrc
```

2. Спросить меру длины у самого компилятора:

```
bootstrap/flang lint .flangrc
```

3. Прочитать «Пара из строки» в `scripts/settings-file.flang` — чем режется
   файл настроек на строки.

## Что происходит

```
$ awk 'length>120' .flangrc | wc -l
54
$ awk '{if(length>m)m=length}END{print m}' .flangrc
244
$ bootstrap/flang lint .flangrc
flang lint: файлов 0; max-line-length 120: 0; max-conditional-depth 2: 0; не разобрано 0
.flangrc: не исходник flang, пропущен                               код 0
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

В файле 170 строк, из них 153 — короткие команды, и все 54 длинные строки
короткими командами и являются. Самая длинная — 244 знака
(`script.search:discriminating`), за ней 243 (`script.changelog:check`) и 241
(`script.proofs:report`).

Перенести строку нельзя ни одним способом: «Пара из строки» режет текст по
`"\n"`, и строка без знака равенства парой не становится — продолжения строки
разбор настроек не знает вовсе. Предел `max-line-length = 120` объявлен в этом
же файле, но на него не распространяется: `flang lint` обходит только исходники
flang, а имена с точкой в начале не обходит и подавно. Значит, 120 знаков здесь
не стережёт никто.

## Что должно быть

В `.flangrc` нет строк длиннее 120 знаков, и предел стережётся прогоном.
Раскладка не меняет смысла: перечень, который печатает `flang run-script`,
совпадает знак в знак с перечнем до раскладки.

## Обходной путь

Читать файл с переносом строк в редакторе.

## Когда задача сделана

Выбрано и записано одно из двух:

1. разбор настроек принимает продолжение строки, файл разложен, и
   `awk 'length>120' .flangrc | wc -l` печатает 0;
2. остаток признан пределом: число стоит потолком в проверке, которая краснеет
   при росте, и `.flangrc` попадает под эту проверку.

В обоих случаях `bootstrap/flang run-script` печатает те же 153 строки знак в
знак (`cmp`, код 0), `bootstrap/flang run-script scripts:check` отвечает кодом 0.
При первом исходе у «Пара из строки» есть пример с перенесённым значением.

## Где живёт правка

Раскладка — `.flangrc`. Разбор продолжения строки —
`scripts/settings-file.flang` («Пара из строки») и чтение настроек в
`flang/src/emit/c/flang_repl.c`; вторая правка доезжает до двоичного только
пересборкой семени (bootstrap regeneration), и раскладывать `.flangrc` можно
лишь после неё, отдельным изменением. Сторож длины для файлов не-исходников —
`scripts/guards/flangrc-guard.fscript`.
