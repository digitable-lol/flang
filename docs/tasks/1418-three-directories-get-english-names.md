## Грабли, на которые я наступил сегодня — не повторять

1. **Ведомость долей.** У `flang/conc` 33 строки в
   `scripts/ledgers/proved-share-ledger.txt`. Путь в строке — последнее поле;
   md5 считается от СОДЕРЖИМОГО и при переезде не меняется, так что правится
   только столбец пути. Не сделать — `pol-dokazannogo-sverka.sh` скажет
   «ЛИШНЯЯ СТРОКА … есть в описи, а в дереве обязательств нет».
2. **Порядок.** Сторож описи перечисляет файлы через `git ls-files`: пока новые
   пути не под версионным контролем, он их НЕ ВИДИТ. Сперва `git add`, потом
   прогонять.
3. **Приметы и проза правятся ПОРОЗНЬ.** В комментарии `<!-- СНЯТО … = N -->`
   число слитно, в прозе рядом — с разделителем разрядов. Одной заменой по
   строке чинить нельзя: сторож ответит «примета оторвалась от прозы».
4. **Числа README сверяет другой прибор** — `published-vs-tree.sh`, а не сторож
   примет. Сторож примет может быть зелен, пока облако красно.
5. **Не запускать параллельно git-команды по одному рабочему дереву**: `git
   reset --hard` из соседнего разбора затирает несохранённые правки.
