# 1419. Дешёвая половина: 61 файл вне «flang/proof»

Решение владельца: имена файлов — по-английски, **БЕЗ транслита**. Не
`obhod.sh`, а `walk.sh`.

**Эта задача — только безопасная часть.** Опасная (`flang/proof/**`, 647 файлов)
вынесена в 1420 нарочно, и смешивать их нельзя.

## Чем измерено

Замеры 13 сентября 2026, дерево `dev` `fcd4a9554`. Считано так:

```sh
find . -path ./.git -prune -o -type f -print | grep -P '[А-Яа-яЁё][^/]*$'
```

| где | файлов |
|---|---:|
| всего в дереве | **708** |
| в `flang/proof/**` | **647** |
| **вне `flang/proof/**`** | **61** |

Из 647 внутри `flang/proof`: 607 — в `flang/proof/чекер/пробы/`, 40 — прочие.
Вся эта часть — задача 1420.

Шестьдесят один файл вне `proof/` — это `flang/проверки/*` (`жаргон.flang`,
`обход.sh`, `ведомость.txt`, `владение-состоянием.sh` и соседи), заметки
`docs/zettel/` с кириллическими именами, отдельные скрипты.

## Зачем

Кириллическое имя файла ломает пути в чужой оснастке, в архивах поставки и в
адресах сайта; правило «имена файлов в дереве — английские» записано в приёмной
и уже действует (см. 0062, раздел «Осторожно»).

Правило это про ИМЯ ФАЙЛА, а не про язык кода: кириллические ключевые слова и
расширение `.фланг` остаются, и трогать их здесь нечего.

## Порог входа

Порога нет. Но **1418 двигает те же файлы**: `flang/проверки` переезжает в
`flang/test` целиком. Два переименования одного файла в двух задачах обязаны не
столкнуться — согласовать порядок с исполнителем 1418 до первого коммита.

## Шаги

- **Ш0 — перепись.** Все 61 имя выписать с путями и против каждого поставить
  предлагаемое английское имя. Транслит в предложении — брак: `обход.sh` → `walk.sh`,
  а не `obhod.sh`. Перечень показать владельцу ДО правки: имя даёт автор
  (правило задачи 1186).
- **Ш1 — для каждого файла найти всех, кто на него ссылается.** Заметки
  `docs/zettel/`, сторожа, `ярлыки.flang`, надзор `.github/**`.
- **Ш2 — правка по одному файлу на коммит:** `git mv` плюс правка всех ссылок в
  том же коммите. После каждого — `sh .githooks/pre-push` зелен.
- **Ш3 — сторож**, запрещающий кириллическое имя файла вне `flang/proof/**`,
  иначе через неделю их снова станет больше.

## Как поймём, что сделано

Команда из раздела «Чем измерено», сужённая до «вне `flang/proof`», печатает
**0**; сторож Ш3 краснеет на нарочно заведённом кириллическом имени; сторожа
дерева зелены; доля доказуемости не шелохнулась.

## Чего задача НЕ делает

**Не трогает `flang/proof/**` — ни одного файла.** Это 1420, и у неё цена
ошибки другая. Не переименовывает каталоги (это 1418). Не трогает кириллические
имена ВНУТРИ кода — модули, функции, ключевые слова.
