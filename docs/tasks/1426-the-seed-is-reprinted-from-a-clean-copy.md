# 1426. Отпечаток семени не называет коммит, из которого семя напечатано

## Шаги воспроизведения

```
grep -a '^коммит' scripts/seed-fingerprint
bootstrap/flang io scripts/seed/seed-freshness.fscript --plan Check --timeout 300000
```

## Что происходит

```
$ grep -a '^коммит' scripts/seed-fingerprint
коммит дерево-правлено
$ bootstrap/flang io scripts/seed/seed-freshness.fscript --plan Check --timeout 300000
ОТПЕЧАТОК СНЯТ С ПРАВЛЕНОГО ДЕРЕВА.
Входы печати в том дереве отличались от его коммита, поэтому коммит и не
назван. Из чего напечатано семя — неизвестно, и узнать это уже неоткуда.
                                                                 код 3
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Семя (`bootstrap/`) напечатано пересборкой (bootstrap regeneration) в рабочей
копии, которую в это время правили. Отпечаток входов печати снят с дерева, не
совпадавшего ни с одним коммитом.

## Что должно быть

В `scripts/seed-fingerprint` строка `коммит` называет коммит, который есть в
стволе, и проверка свежести семени выносит суждение, а не отказывается.
Порядок пересборки — `docs/reprint-runs-start-from-a-clean-tree.md`.

## Обходной путь

Судить без знания происхождения: `FLANG_SEED_LAG_KNOWN=1` перед той же командой.
Суждение тогда опирается на допущение, а не на сверку.

## Когда задача сделана

```
bootstrap/flang io scripts/seed/seed-freshness.fscript --plan Check --timeout 300000
```

не отказывается судить, а `git cat-file -e` на значении строки `коммит`
отвечает кодом 0. `sh scripts/bootstrap-reprint.sh --bystro` даёт ноль
расхождений.

## Где живёт правка

Правки кода нет: нужна пересборка семени из свежей копии на фиксированном
коммите ствола, в которую до конца печати никто не пишет
(`sh scripts/bootstrap-reprint.sh`, часы на одном ядре). Перед печатью
проверить, что семя не правлено руками: `git diff --quiet HEAD -- bootstrap
scripts/seed-fingerprint` отвечает кодом 0. После печати перевыпустить
разошедшиеся записи доказательств.
