# 1428. В дереве остаются файлы и каталоги с именами транслитом

## Шаги воспроизведения

1. Посчитать имена, записанные в долг проверки транслита, и разложить их по
   каталогам:

```
bootstrap/flang io scripts/guards/translit-file-names-guard.fscript --plan Проверка
grep -av "^#" scripts/ledgers/translit-file-names-debt.txt | grep -ac .
grep -av "^#" scripts/ledgers/translit-file-names-debt.txt | grep -a . | cut -d/ -f1-3 | sort | uniq -c
```

## Что происходит

```
$ bootstrap/flang io scripts/guards/translit-file-names-guard.fscript --plan Проверка
… "result":"транслит в именах файлов: латинских имён …, с чужими словами 102 — все в ведомости, новых нет" …
                                                                  код 0
$ grep -av "^#" scripts/ledgers/translit-file-names-debt.txt | grep -ac .
102
$ … | cut -d/ -f1-3 | sort | uniq -c
     57 flang/test/fixtures
     40 flang/proof/checker
      5 flang/test/…            (uzel-osnastka.flang, uzel-osnastka.mjs и три *-uzla, *-celi .test.mjs)
```

Имена в долге держатся не осторожностью, а связями:

- 57 файлов в `flang/test/fixtures` и 40 записей в `flang/proof/checker` — имя
  файла служит ключом записи доказательства и снимков (`record-oracle.json`,
  `record-grid.json`), запись повторяет имя исходника;
- оснастка узла и три пробы на Node названы в `flang/self/emit-js.flang` и в
  документации по конкурентности.

Проверке транслита нужно чуть больше 8 ГиБ памяти: под пределом
`ulimit -v 8388608` она отвечает «FLANG_MEMORY: недостаточно памяти», код 1.

## Что должно быть

В области проверки транслита нет ни одного латинского имени из русских слов,
записанных латиницей: долг пуст либо в нём остались только собственные имена
(например `zhi-shi.fts` — название правила орфографии).

## Названный шаг: имена КАТАЛОГОВ, которых сторож пока не видит

Сторож транслита берёт имя `sed 's#.*/##; s#[.][^.]*$##'`, то есть каталоги
отрезает начисто (задача 3106 — про ту же слепоту у сторожа кириллицы, там она
уже снята). Пока он на каталоги не смотрит, их имена в счёт не идут. Счёт снят
руками: в его областях (`scripts`, `flang/test`, `flang/scripts`, `flang/proof`,
`docs/site`, `.github`) **184 каталога**, и в их именах **56 слов
вне закрытого списка**. Решение по каждому слову — здесь, одно на слово:

| род | сколько | слова | решение |
|---|---|---|---|
| настоящий транслит | **9** | `korpus`, `kruga`, `naslediye`, `oblast`, `plany`, `razrez`, `slovar`, `snimok`, `zapis` | **переименовать**, это и есть предмет этой задачи |
| обычные английские слова | **39** | `algebra`, `api`, `applicable`, `audit`, `citation`, `corrupt`, `demo`, `docs`, `domains`, `editors`, `elements`, `executed`, `fixtures`, `github`, `golden`, `issue`, `ledgers`, `lib`, `linguist`, `models`, `negative`, `patterns`, `profile`, `programs`, `promo`, `regular`, `scripts`, `sentences`, `shop`, `sql`, `subscription`, `template`, `tests`, `tools`, `unsatisfiable`, `user`, `utilities`, `web`, `workflows` | **в закрытый список** `scripts/ledgers/file-name-words.txt` |
| придуманные имена оснастки FTS | **6** | `ftsc`, `ftsmap`, `ftspec`, `ftsynth`, `gacascade`, `gasearch` | **в ведомость долга с доводом**: это имена чужой оснастки, не транслит русского слова, и переименовывать их — менять чужую раскладку |
| обозначения версий | **2** | `v1`, `g2` | **в ведомость долга с доводом**: не слова, а метки опыта (`v1-g2`) |

**Почему это не вписано в ведомости до расширения сторожа.** Ведомость долга транслита
сверяется В ОБЕ СТОРОНЫ: запись, которой расхождения больше нет, красна —
«ЗАПИСЬ ВЕДОМОСТИ ПЕРЕЖИЛА ФАЙЛ ИЛИ ДОЛГ». Пока сторож каталогов не видит,
расхождения по ним для него не существует, и восемь записей о каталогах стали бы
мёртвыми — то есть красными. А 39 слов в закрытый список значило бы разрешить
слова для области, которой не судит ни одна проверка. Поэтому решения стоят
здесь, а исполняются **вместе** с расширением сторожа на каталоги: сперва он
начинает их видеть, потом ведомости принимают записи.

## Обходной путь

Не нужен: имена работают. Новое транслитное имя проверка не пропускает, старые
перечислены в `scripts/ledgers/translit-file-names-debt.txt` с причиной.

## Когда задача сделана

```
grep -av "^#" scripts/ledgers/translit-file-names-debt.txt | grep -ac .
```

печатает 0 или число собственных имён, у каждого из которых причина названа;
`bootstrap/flang run-script transliteration:check` отвечает кодом 0, `bootstrap/flang run-script transliteration:forgery` — кодом 1;
сторож видит имена каталогов, и решения из таблицы выше исполнены. Переименование каждой группы идёт одним коммитом вместе со
всеми ссылками, записями и снимками — половина переименования оставляет
проверки зовущими несуществующий файл.

## Где живёт правка

- `flang/test/fixtures/**` вместе с `flang/proof/checker/tests/records/corpus/**`,
  `flang/proof/forgeries/manifest.tsv` и снимками — снимки правятся пересъёмкой;
- `flang/test/*.mjs`, `flang/test/uzel-osnastka.flang` и их упоминания;
- `scripts/ledgers/translit-file-names-debt.txt` — строка уходит вместе с файлом.

Имена в `flang/self/emit-js.flang` — самосборная часть:
их правка доезжает только пересборкой семени (bootstrap regeneration), поэтому
её стоит класть в ту партию, где пересборка и так назначена.

Отдельная задача, здесь не решается: перенос скриптов оболочки из `scripts/` на
flang — задача 5821.
