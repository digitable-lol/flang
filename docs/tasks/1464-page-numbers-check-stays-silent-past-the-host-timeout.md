# 1464. Проверка чисел страниц молчит дольше срока хозяина

## Шаги воспроизведения

1. Прогнать проверку чисел страниц прямо:

```
node docs/site/site-numbers.mjs --check
```

2. Прогнать сторож отставших страниц целиком и прочесть строку про `numbers:check`:

```
bootstrap/flang io scripts/guards/stale-pages-guard.fscript --на-веру --plan 'Страницы не отстали' --timeout 900000
```

## Что происходит

```
$ node docs/site/site-numbers.mjs --check
                                   ни байта вывода за 4426 с, прогон не кончился
$ bootstrap/flang io scripts/guards/stale-pages-guard.fscript … --timeout 900000
Страницы не отстали: расхождений 0.
  · numbers:check — НЕ СПРОШЕНО: FLANG_IO_TIMEOUT — программа «node» молчала
    дольше 900000 мс и оборвана хозяином (--timeout).
    Красить дерево за это нечестно                                       код 0
```

Версия: flang 0.7.24. Дата прогона: 4 октября 2026. Дерево `5604556ef`.

`--timeout` у `flang io` — это срок **тишины** процесса, 900 с в работе
`stale-pages`. Проверка чисел не печатает ни байта пока считает, и хозяин
обрывает её раньше, чем она успевает сказать хоть что-нибудь. Поэтому из
четырёх проверок семьи (`site:check`, `numbers:check`, `releases:page:check`,
`dictionary:check`) одна не высказывается НИ РАЗУ — ни зелёным, ни красным.

Сторож про это не врёт: находка уходит в «не спрошено», а не в беды, и работа
остаётся зелёной со строкой вслух. Но проверка, которая не отвечает никогда, —
это выключенная проверка.

**Чего здесь НЕ мерено:** сколько проверка идёт до конца. Прогон на 4426 с
(1 ч 14 мин) оборван руками, своего ответа он не дал и ни байта не напечатал;
4426 с — пол, а не время работы.

## Что должно быть

`numbers:check` в семье «отставших страниц» отвечает — зелёным или красным.
Путей два, и выбор между ними — отдельное решение:

1. **Проверка печатает ход.** Пока считает, пишет строку на файл (как это
   делает сам `flang io` строкой «шагов …»): тогда срок тишины не истекает, и
   `--timeout 900000` хватает.
2. **Семья зовёт её не процессом, а по частям.** Числа страниц делятся на
   «дешёвые» (файлы, строки, версия) и «дорогие» (функции, тотальность,
   утверждения, словарь) — у них и провенанс разный
   (`docs/course/13-where-next.md`). Дешёвую половину семья спрашивает каждый
   раз, дорогую — отдельной работой по метке.

## Обходной путь

Гонять `node docs/site/site-numbers.mjs --check` руками, своим сроком, и не
ждать ответа от работы `stale-pages`.

## Когда задача сделана

- `bootstrap/flang io scripts/guards/stale-pages-guard.fscript --на-веру --plan
  'Страницы не отстали' --timeout 900000` отвечает кодом 0 и **без** строки
  «НЕ СПРОШЕНО»;
- время прогона `numbers:check` названо числом — своим прогоном, а не оценкой;
- отрицательный контроль: разойтись одному числу в `docs/site/numbers.json` —
  семья обязана покраснеть и назвать `numbers:check`.

## Где живёт правка

`docs/site/site-numbers.mjs` (печать хода), `scripts/guards/stale-pages-guard.fscript`
(«Семья»), `.github/workflows/ci.yml` — только если дорогая половина уедет в
свою работу. Перепечатка семени не нужна.
