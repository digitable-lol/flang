# 1505. README рядом с кодом — указатели, проза в `docs/`

Слова владельца (23 сентября 2026): «не надо README этот так держать, оно должно быть
в docs, посмотри другие папки как там лежат наши README».

Образец уклада — `flang/proof/checker/README.md`: рядом с кодом шесть строк указателя,
проза — в `docs/` по зеркальному пути. Завёл уклад коммит `fd938232f` (13 сентября
2026), он же перенёс 34 документа и оставил 33 указателя.

## Гипотеза до замера

Названа прежде, чем считать: **10–15 файлов вне `docs/`, из них указателей 1–3,
прозаических 8–12, и большинство прозаических — в `examples/` и `packaging/`.**

Промах по всем трём числам. Файлов оказалось втрое больше (41), указателей — вдесятеро
больше (30), а `examples/` в переписи нет вовсе: его README перевели в указатели
раньше, коммитом `fd938232f`.

## Перепись

Команда (ствол `gh/main` `38105062f`, 23 сентября 2026):

```sh
git ls-files '*README.md' | grep -v '^docs/' | while read f; do
  printf '%6s  %s\n' "$(wc -l < "$f")" "$f"
done | sort -rn
```

Указателем считается файл с хвостом образца — `проза о н(ём|их) — в \`docs/\``:

```sh
git ls-files '*README.md' | grep -v '^docs/' \
  | xargs grep -lE 'проза о н(ём|их) — в `docs/`' | wc -l
```

| что | сколько |
|---|---:|
| `README.md` в дереве всего | 112 |
| из них под `docs/` | 71 |
| **вне `docs/`** | **41** |
| из них указателей по образцу | 30 |
| **держат прозу** | **11** |

## Чем меряется «проза»

Не объёмом и не тем, «так принято». Прозу от ярлыка отличает **протухаемость**: числа,
ссылки на задачи и ADR, таблицы — всё, что расходится с деревом, когда дерево правят.
Ради этого прозу и сводят в одно место: `sh scripts/guards/prose-numbers-guard.sh`
чинит числа там, где они лежат, а не там, где их переписали от руки.

Замер по одиннадцати (числа — `grep -oE '\b[0-9]+\b' | wc -l`, задачи — `docs/(tasks|adr)/`,
таблицы — строки на `|`):

| файл | стр. | чисел | задач | таблиц | решение |
|---|---:|---:|---:|---:|---|
| `README.md` | 365 | 130 | 11 | 27 | оставлен |
| `bootstrap/README.md` | 200 | 132 | 0 | 16 | чужой |
| `flang/proof/checker/tests/families/plan/README.md` | 77 | 20 | 2 | 15 | **переехал** |
| `flang/proof/checker/tests/families/run-induction/README.md` | 37 | 12 | 2 | 4 | **переехал** |
| `flang/concurrency/README.md` | 24 | 1 | 0 | 5 | **переехал** |
| `fspec/README.md` | 10 | 0 | 0 | 0 | оставлен |
| `packaging/asdf/README.md` | 7 | 0 | 0 | 0 | оставлен |

## Укладов в дереве два, а не один

Это надо назвать прямо, потому что перепись сперва показала «11 нарушителей», а их не 11.

- **Уклад А — указатель в `docs/`** (30 файлов): заголовок, две строки ссылки на
  зеркальный путь, хвост «проза о них — в `docs/`». Своих утверждений ноль.
- **Уклад Б — двуязычный ярлык каталога** (6 файлов): шапка
  `**[Documentation](…)** · **[Документация](…)**` и одно предложение на двух языках.
  Ведёт не на зеркальный файл, а на страницу сайта, где проза и лежит. Шестнадцать
  README **под** `docs/` носят ту же шапку — форма в дереве законная, не самодеятельность.
- **Проза без уклада** (5 файлов): документ с числами, таблицами и ссылками на задачи.

Коммит `fd938232f` уже принял это решение и записал его: «`flang/stdlib/README.md` и
`flang/proof/map/README.md` были указателями изначально и оставлены как есть».

## Что сделано

Переехали трое — те, у кого проза, ноль входящих ссылок (`git grep -F <путь>` вне
`docs/`, `CHANGELOG.md` и `changelog.json` — пусто у всех трёх) и ни одного прибора,
читающего файл:

| было | стало |
|---|---|
| `flang/concurrency/README.md` | `docs/flang/concurrency/README.md` |
| `flang/proof/checker/tests/families/plan/README.md` | `docs/flang/proof/checker/tests/families/plan/README.md` |
| `flang/proof/checker/tests/families/run-induction/README.md` | `docs/flang/proof/checker/tests/families/run-induction/README.md` |

На месте кода — указатель по образцу, шесть строк. Ссылки сведены в обе стороны, семь
целей проверены поимённо:

- внутри переехавших приставка `docs/` снята, глубина та же:
  `../../../../../../docs/tasks/` → `../../../../../../tasks/`, то же для `adr/`;
- `../../docs/flang/conc/*.md` → `../conc/*.md`;
- `[прогон](../run/README.md)` в «прогон-индукции» после переезда ведёт уже не на
  указатель у кода, а на зеркало `docs/…/families/run/README.md` — на прозу, которую
  строка и обещает;
- шапка `concurrency` говорила «Здесь лежит КОД. Проза о нём — в `docs/flang/conc/`» —
  после переезда это была бы ложь; стало «Код — в `flang/concurrency/`; остальная проза
  о нём — в `docs/flang/conc/`».

Стало: 41 `README.md` вне `docs/`, указателей **33**, прозаических **8**.

## Что оставлено и почему

Причина у каждого измеренная — прибор, печать семени или чужое владение.

1. **`README.md` (корень, 365 строк)** — лицо склада: его рендерят GitHub и npm, файл
   и есть прибор чтения. `git grep` даёт 84 ссылающихся файла вне `docs/`. Он назван
   маской сторожа жаргона (`docs/jargon.json:247`, долг 0) и стоит в `NOT_SEED`
   (`scripts/bootstrap-reprint.sh:482`). Свести его в `docs/` — оставить склад без первой
   страницы. Сверка его содержимого с деревом — отдельная задача 6518.

2. **`bootstrap/README.md` (200 строк)** — чужая работа: перенесён в
   `docs/bootstrap/README.md` веткой `a/hook-and-readme`, не моей.

3. **`fspec/README.md` (10 строк)** — путь набран внутри **печатаемой части семени**:
   `flang/src/emit/c/flang_repl.c:18004` и байт в байт тот же текст в
   `bootstrap/flang_repl.c`. Справка `flang help`, раздел «Спеки предметной области»,
   говорит «Подробнее — `fspec/README.md`». Выпотрошить файл в указатель значит послать
   читателя справки на пустую страницу, а починить справку нечем, кроме перепечатки
   семени, — она идёт (5190). Сверх того файл — маска сторожа жаргона
   (`docs/jargon.json:262`) с долгом 1.

4. **`packaging/asdf/README.md` (7 строк)** — **читается прибором**:
   `scripts/guards/asdf-plugin-guard.fscript` открывает его (`Прочитать файл`,
   `../../packaging/asdf/README.md`) и сверяет с одноимённым файлом чужого подмодуля
   `packaging/asdf-plugin/`. Нет файла — отказ `FLANG_PLAGIN_NECHEM_SMOTRET`. Его же
   проверяет `.github/workflows/release.yml:403`. Содержимое — не проза о коде, а
   сверяемый байт.

5. **`flang/stdlib/README.md` (7 строк)** — уклад Б, 0/0/0 по замеру. Путь набран
   в `flang/self/bootstrap/corpus.flang:400,445` — печатаемая часть семени; литерал
   там проверяет отбор по расширению («не .flang не берётся») и файла не читает, но
   трогать соседство с идущей перепечаткой незачем ради нуля протухающего.

6. **`flang/proof/map/README.md` (7 строк)** — уклад Б, 0/0/0. Прозы о карте целей
   тут нет: она в `docs/proof-goal-map.md`, куда файл и ведёт.

7. **`flang/proof/checker/tests/families/README.md` (7 строк)** — уклад Б, 0/0/0.
   Проза о наборе проб — в `docs/flang/proof/checker/README.md`, раздел «Набор проб».

8. **`flang/proof/checker/tests/families/if-branch/README.md` (7 строк)** — то же.

Подмодули `packaging/homebrew-tap` и `packaging/asdf-plugin` в переписи не значатся:
`git ls-files` их README не отдаёт, это отдельные склады.

- **`docs/flang/conc/` отстал от переименования кода.** Каталог кода стал
