# 1571. Объявленный замер страниц курса набирается руками

## Шаги воспроизведения

1. Спросить прибор подъёма версии, куда версия вытекает:

```
bootstrap/flang run-script version
```

2. Спросить сторож отставших страниц, что он считает отставшим:

```
bootstrap/flang io scripts/guards/stale-pages-guard.fscript --на-веру --plan 'Страницы не отстали' --timeout 900000
```

## Что происходит

```
$ bootstrap/flang run-script version
текущая версия (источник scripts/release/emit-package.flang): 0.7.24

вытекает в:
  flang/src/emit/c/flang_repl.c  FLANG_VERSION 0.7.24
  packaging/flang.1               .TH flang 0.7.24
  packaging/homebrew/flang.rb  version 0.7.24
  .flangrc                      version 0.7.24, …
  packaging/homebrew-tap/Formula/flang.rb  НЕ РАЗВЁРНУТ: …
  packaging/asdf-plugin/  НЕ РАЗВЁРНУТ: …                         код 0
```

Версия: flang 0.7.24. Дата прогона: 4 октября 2026.

Прибор знает шесть целей подстановки и ни одной страницы документации. А
объявление замера стоит на **семнадцати** страницах — пятнадцать файлов
`docs/course/**` (восемнадцатое объявление второе в `13-where-next.md`) плюс
`docs/site/how-proofs-work.md` и `docs/site/how-proofs-work.ru.md`:

```
<!-- замер: версия 0.7.24 · дерево 5604556ef · сверено 2026-10-04 -->
```

Правка 4 октября 2026 переснимала эти замеры с 0.7.22 на 0.7.24 и тронула
**17 файлов, 22 места** (18 объявлений и 4 расшифровки с строкой `flang N.N.N`)
— все руками. То же было 27 сентября (0.6.2 → 0.7.22, коммит `7d2e531f2`) и
будет на каждом следующем выпуске.

**Почему это не просто подстановка `{{выпуск.версия}}`.** Объявление замера —
не номер версии, а провенанс: версия, дерево и день, которыми вывод на странице
действительно снят. Подставлять туда текущую версию прибором без прогона значит
лгать: страница скажет «сверено сегодня», а вывод будет вчерашним. Поэтому
прибор нужен не подставляющий, а **переснимающий**: тот, что прогоняет команды
страницы, сверяет вывод знак в знак и переписывает объявление только там, где
сошлось, а где разошлось — называет место.

## Что должно быть

Объявление замера на странице переписывает прибор, а не рука, и переписывает
его только после прогона: команды страницы прогнаны, вывод сверен, расхождения
названы поимённо. У `docs/course/` половина такого прибора уже есть —
`docs/course/check.flang` вынимает из страниц блоки с оградой `flang` и зовёт на
них `flang check`. Чего в нём нет: пар «команда — её вывод» (ограда `bash` и
следующая за ней ограда без языка) и переписывания объявления.

## Обходной путь

Править семнадцать файлов руками на каждом выпуске, сверяя вывод прогоном. На
0.7.24 так и сделано: 22 места, две расшифровки разошлись и переписаны
(`flang --help` оброс двумя командами, `emit --target c` подрос с 429 761 до
469 318 байт).

## Когда задача сделана

- есть короткая команда, которая на чистом дереве отвечает «страницы пересняты:
  файлов N, расхождений 0» и сама правит объявления замера;
- отрицательный контроль: подменить в расшифровке одну цифру — прибор обязан
  назвать файл, строку и то, что ожидалось;
- `bootstrap/flang io scripts/guards/stale-pages-guard.fscript --на-веру --plan
  'Страницы не отстали'` отвечает кодом 0 сразу после прогона прибора, без
  правок руками.

## Где живёт правка

`docs/course/check.flang` (или новый план рядом с ним), `.flangrc` (короткая
команда), `scripts/release/bump-version.fscript` — если решено звать прибор
переснятия из подъёма версии. Перепечатка семени не нужна.
