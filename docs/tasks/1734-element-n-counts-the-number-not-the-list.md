# 1734. Оценка числа шагов у «элемент N в СПИСОК» берёт часть от номера, а не от списка

## Шаги воспроизведения

```
grep -an 'У элемента список стоит вторым' flang/self/totality.flang
grep -an '"элемент"))$' flang/self/bounded.flang
grep -an '«Первый аргумент» от «узел»' flang/self/bounded.flang
```

## Что происходит

```
$ grep -an 'У элемента список стоит вторым' flang/self/totality.flang
1302:  пример «У элемента список стоит вторым»
$ grep -an '"элемент"))$' flang/self/bounded.flang
531:  («имя» равен "хвост") или ((«имя» равен "голова") или («имя» равен "элемент"))
$ grep -an '«Первый аргумент» от «узел»' flang/self/bounded.flang
549:          то «Глубже на один» от («Происхождение» от («Первый аргумент» от «узел») и «среда»)
```

Двоичный flang оценку числа шагов не печатает, и дефект читается по исходнику.

Два прохода читают одну форму по-разному. Анализ завершаемости
(`flang/self/totality.flang`) считает частью значения второй аргумент
`элемент` — список. Оценка числа шагов (`flang/self/bounded.flang`,
«Происхождение» и «Разбирающая форма») для всех разбирающих форм, включая
`элемент`, берёт первый аргумент — у `элемент` это сам номер. Поэтому функция,
у которой спуск идёт по списку в `элемент N в СПИСОК`, для завершаемости
убывает, а для оценки — нет, и многочлена не получает.

## Что должно быть

Оба прохода считают частью один и тот же аргумент — список. Функция, которой
завершаемость доказана спуском по `элемент N в СПИСОК`, получает оценку числа
шагов.

## Обходной путь

Писать спуск через `хвост` или `разбор` списка: эти формы оба прохода читают
одинаково.

## Когда задача сделана

В `flang/self/bounded.flang` форма `элемент` берёт часть от второго аргумента (списка), и при
функции есть пример на эту форму. Снят замер до и после: сколько функций дерева
получили оценку, которой у них не было. `bootstrap/flang check` на
`flang/self/bounded.flang` даёт прежний вердикт.

## Где живёт правка

`flang/self/bounded.flang`, разбор формы `элемент`. До двоичного правка доезжает
пересборкой семени (bootstrap regeneration).
