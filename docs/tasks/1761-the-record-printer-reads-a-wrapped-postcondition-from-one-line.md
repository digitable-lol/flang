# 1761. Печать записи читает перенесённое постусловие с одной строки и не даёт ему ходов

## Шаги воспроизведения

1. Программа `flang/proof/checker/tests/families/postcondition-rewrite/wrapped-goals.flang`:
   постусловие `обеспечивает «пустое не меняет» (результат⏎    равен текст)` и цепочка из
   семнадцати вызовов, перенесённая внутри скобок (ADR-0105).
2. Запись — ядром из исходника: `bootstrap/flang run
   flang/self/bootstrap/check-with-source-compiler.flang --function 'Проверить исходным
   компилятором' --trust --args '{"путь":…,"текст":…}'`.
3. Сверщики: `flang/proof/checker/сверщик` и `flang/proof/checker/second/out/второй-сверщик`
   на исходнике и записи.

## Что происходит

Ведомость ядра: «утверждений 2: доказано 2 (из них без теоремы 2)». В записи у
постусловия «пустое не меняет» правило «переписка доказанными равенствами» без единого
хода (у того же постусловия в одну строку — `chain-of-eighteen.record` — ходы
`развернуть`, `переписать формой`, `закрыть тождеством` есть). Оба сверщика отвечают 3:
«правило ядра «переписка доказанными равенствами» без записанных ходов — место на слове
ядра»; цепочка, опирающаяся на это постусловие, — тоже 3. Замер 13 октября 2026.

## Что должно быть

Печать записи (`flang/self/proof-record.flang`) читает цель обещания до закрытия скобок,
как разборщик и оба сверщика (ADR-0105, `docs/flang/proof/record-format.md`,
«Соглашения»), и даёт ему те же ходы, что однострочному; оба сверщика — 0.

## Обходной путь

Писать постусловие одной строкой; переносить только цель утверждения.

## Когда задача сделана

Запись `wrapped-goals.record`, перепечатанная ядром, — код 0 у обоих сверщиков; строка
`probes.tsv` о ней ждёт код 0.

## Где живёт правка

`flang/self/proof-record.flang` (чтение строки исходника для обещания); до двоичного —
перепечаткой семени.

Следующий шаг: найти в `flang/self/proof-record.flang` место, где печать ходов обещания
берёт цель со строки исходника, и дочитать её до закрытия скобок тем же правилом, что
`до_закрытия_скобок` в `flang/proof/checker/checker.c`; проба, которая красна сегодня, —
строка `probes.tsv` о `wrapped-goals.record` с кодом 0 вместо нынешнего 3.
