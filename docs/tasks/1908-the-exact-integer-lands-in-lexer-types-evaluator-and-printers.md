# 1908. Точного целого нет в коде: ни типа, ни вычислителя, ни печати в цели

## Шаги воспроизведения

1. Программа с типом, который принят в ADR-0036
   (`docs/adr/0036-an-exact-integer-is-a-new-kind-of-value-not-a-new-name.md`, §11):

```flang
модуль «Exact integer probe»

тотальная функция «Сумма»
  принимает а: точное целое, б: точное целое
  возвращает точное целое
  а плюс б
```

2. Команды:

```
bootstrap/flang check <файл>
grep -ac 'точное целое' flang/self/lexer.flang flang/self/parser.flang flang/self/interpret.flang flang/self/emit-c.flang
```

## Что происходит

```
$ bootstrap/flang check <файл>
FLANG_UNKNOWN_NAME в файле <файл>, строка 4, столбец 23: имя «целое» не
связано: …
<файл>: не проверено — замечаний 1                                код 1
$ grep -ac 'точное целое' flang/self/lexer.flang flang/self/parser.flang flang/self/interpret.flang flang/self/emit-c.flang
flang/self/lexer.flang:0
flang/self/parser.flang:0
flang/self/interpret.flang:0
flang/self/emit-c.flang:0                                         код 1
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Решение принято, представление значения выбрано (задача 1411, закрыта), кода
нет. В `flang/self/types.flang` слова «точное целое» стоят только в имени
примера.

## Что должно быть

По ADR-0036 §11: точное целое — новый тип рядом с `целое`; носитель `целое` не
меняется; новый тип не входит в числовое вложение и принимает `число` только
названным переводом; литерал `42` остаётся `число`. По ADR-0040 §2.6
(`docs/adr/0040-a-simplifier-rewrites-by-proved-equalities-and-prints-every-step.md`)
на нём работают правила упрощения. Деление и остаток правилами кольца не
покрываются.

## Обходной путь

Считать в `целое` или `неотрицательное`: это машинные числа IEEE-754, законы
кольца над ними ядро не доказывает.

## Когда задача сделана

Программа из шагов воспроизведения проходит `bootstrap/flang check` с кодом 0,
исполняется `bootstrap/flang run` и печатается `bootstrap/flang emit` во все
цели; напечатанное собирается и даёт тот же ответ. Сумма двух значений выше
2⁵³ точна, и у функции есть такой пример. Присваивание `число` в точное целое
без перевода отвергается проверкой типов. Цена по файлам названа числами: время
проверки своего дерева до и после.

## Где живёт правка

`flang/self/lexer.flang` и `flang/self/parser.flang` (слово типа и литерал),
`flang/self/types.flang` (новый тип вне вложения), `flang/self/interpret.flang`
(вычислитель, быстрый путь для малых значений), `flang/self/proof-kernel.flang`
(только то, что нужно правилам задачи 1412), печать в цели — задача 1413. Всё под
`flang/self`, до двоичного доезжает только пересборкой семени (bootstrap
regeneration). Слово вводится в два захода: сначала компилятор узнаёт имя и
семя пересобирается, потом имя применяется в дереве.
