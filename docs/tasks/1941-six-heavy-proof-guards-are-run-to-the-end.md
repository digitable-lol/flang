# 1941. Пять тяжёлых проверок доказательств ни разу не прогнаны до конца с замером времени, памяти и кода возврата

## Шаги воспроизведения

1. Пять ярлыков из `ярлыки.flang`:

| ярлык | команда |
|---|---|
| `спеки:подлог` | `bootstrap/flang io fspec/forgery.flang --timeout 600000` |
| `доказательства:ведомость` | `bootstrap/flang io flang/scripts/proof-ledger.fscript --plan 'Свод корпуса' --timeout 3600000 --max-steps 400000000000 --max-orders 100000 --на-веру` |
| `доказательства:свод` | `bootstrap/flang io flang/scripts/ledger-summary.fscript --plan 'Свод' --timeout 900000` |
| `пустота:порча` | `bootstrap/flang io flang/scripts/emptiness-guard.fscript --plan 'Порча' --timeout 900000` |
| `доказанное:порча` | `bootstrap/flang io flang/scripts/proven-guard.fscript --plan 'Порча' --timeout 900000` |

2. Посмотреть, что о них записано в описи проверок:

```
grep -a -F -e 'спеки:подлог' -e 'доказательства:ведомость' -e 'доказательства:свод' \
  -e 'пустота:порча' -e 'доказанное:порча' docs/ci-inventory.md \
  | awk -F'|' '/^\|/{print $3 "|" $4 "|" $5 "|" $6}'
```

Столбцы: цель, код, время, код без заслона свежести семени.

## Что происходит

```
$ grep … docs/ci-inventory.md | awk …
 `спеки:подлог` | 1 | 3 с | 1
 `доказательства:ведомость` | 1 | 2 с | обрыв 600 с
 `доказательства:свод` | 1 | 2 с | обрыв 600 с
 `пустота:порча` | 1 | 2 с | 1
 `доказанное:порча` | 1 | 2 с | 1                                  код 0
```

Дата прогона: 30 сентября 2026. Сами пять проверок сегодня не запускались:
каждая идёт от минут до часа и дольше.

Ни у одной из пяти в описи нет прогона, дошедшего до конца: две оборваны по
сроку в 600 секунд, три остановились за 2–3 секунды кодом 1 на старом
двоичном. Пика памяти нет ни у одной. Опись снята двоичным 0.6.2; команда
ярлыка `доказательства:ведомость` с тех пор заменена, а шестой ярлык того же
ряда, `доказательства:пустота`, из `ярлыки.flang` убран, хотя строка о нём в
описи осталась.

## Что должно быть

У каждой из пяти проверок в `docs/ci-inventory.md` стоит строка, снятая
прогоном текущего двоичного: код возврата, время в секундах, пик памяти.
Правило «число ценно только снятое прогоном» — `docs/zero-bug-policy.md`.

## Обходной путь

Обходного пути нет: ответа этих проверок на текущем дереве никто не знает.

## Когда задача сделана

Каждая из пяти команд прогнана до конца под `/usr/bin/time -v`, по одной или
по две одновременно, и в `docs/ci-inventory.md` у неё записано «код N,
T секунд, пик G ГиБ». Проверка, которая не уложилась в свой срок, записана
со сроком и причиной — «померена, не уложилась», а не оставлена без строки.
Строка об убранном ярлыке `доказательства:пустота` из описи снята.
`bootstrap/flang run-script inventory:check` отвечает кодом 0.

## Где живёт правка

`docs/ci-inventory.md`. Кода задача не меняет, пересборка семени (bootstrap
regeneration) не нужна. Пять прогонов независимы, их можно раздать разным
исполнителям; если проверка окажется красной, на неё заводится своя задача.
