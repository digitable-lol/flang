# 2018. Предложение вне набора образцов отвергается как необъявленное слово

Это первая из трёх бед на одном примере владельца; соседние —
[3791](3791-the-reasoning-verdict-does-not-name-the-missing-middle-term.md) (средний терм) и
[3272](3272-the-reasoning-verdict-does-not-name-the-premise-that-is-missing.md) (недостающая
посылка). Эта беда стоит раньше них: пока текст не прочитан, до приговора дело не доходит.

## Шаги воспроизведения

Язык здесь знать не нужно: надо собрать двоичный и написать три предложения по-русски.

1. Собрать двоичный (около двух минут):

   ```sh
   make -C bootstrap -j4 CFLAGS='-std=c99 -O2' flang
   ```

2. Написать в корне дерева файл `diplom.txt` ровно так, как такое рассуждение пишет человек —
   три предложения и ничего больше:

   ```sh
   cat > diplom.txt <<'EOF'
   Все студенты учатся хорошо. Николай учится хорошо. Давайте дадим ему красный диплом.
   EOF
   ```

3. Позвать судью:

   ```sh
   bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Judge -- diplom.txt
   ```

4. Смотреть код возврата и поле `error` ответа. По строкам его читает

   ```sh
   bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Judge -- diplom.txt \
     | sed -n 2p | python3 -c 'import json,sys;print(json.load(sys.stdin)["error"])'
   ```

5. Дописать словарь (три строки и пустая строка перед предложениями) и позвать снова —
   посмотреть, что осталось:

   ```sh
   cat > diplom.txt <<'EOF'
   Понятие: студент, студенты.
   Свойство: учится хорошо, учатся хорошо.
   Имя: Николай.

   Все студенты учатся хорошо. Николай учится хорошо. Давайте дадим ему красный диплом.
   EOF
   ```

## Что происходит

Шаг 3, три предложения как есть:

```
$ bootstrap/flang io .../syllogism/sentences/run.fscript --plan Judge -- diplom.txt
текст не прочитан:
предложение 1 «Все студенты учатся хорошо.»: слово «студенты» не объявлено: впишите его в
словарь строкой «Понятие: …», «Свойство: …» или «Имя: …»
предложение 2 «Николай учится хорошо.»: слово «Николай» не объявлено: впишите его в словарь
строкой «Понятие: …», «Свойство: …» или «Имя: …»
предложение 3 «Давайте дадим ему красный диплом.»: слово «Давайте» не объявлено: впишите его
в словарь строкой «Понятие: …», «Свойство: …» или «Имя: …»
в рассуждении нет заключения: последнее предложение начинается со слова «Следовательно,»
                                                                                     код 1
```

Шаг 5, словарь дописан:

```
$ bootstrap/flang io .../syllogism/sentences/run.fscript --plan Judge -- diplom.txt
текст не прочитан:
предложение 3 «Давайте дадим ему красный диплом.»: слово «Давайте» не объявлено: впишите его
в словарь строкой «Понятие: …», «Свойство: …» или «Имя: …»
в рассуждении нет заключения: последнее предложение начинается со слова «Следовательно,»
                                                                                     код 1
```

Неверного тут два.

Первое: про предложение 3 сказано не о том. «Давайте дадим ему красный диплом.» —
побудительное предложение, оно не подходит ни под один из шести образцов §6
[ADR-0050](../adr/0050-a-reasoning-is-written-as-declared-words-and-fixed-sentences.md), и
никакая строка словаря этого не исправит: вписав «Давайте» как понятие, свойство или имя,
человек получит отказ снова. Нужные слова у переводчика есть — «предложение не подходит ни
под один образец: ждали подлежащее и сказуемое из объявленных форм»
(`sentences/translator.flang:580`), — но ветвь с ними достижима только когда объявлены ВСЕ
слова предложения (`translator.flang:579`), а необъявленное слово побеждает всегда.

Второе: строка «в рассуждении нет заключения: последнее предложение начинается со слова
«Следовательно,»» утверждает о тексте неправду — последнее предложение этого текста со слова
«Следовательно,» как раз не начинается. Половина после двоеточия написана как факт, а должна
быть требованием: «последнее предложение обязано начинаться…». Та же беда в соседней строке
того же места (`translator.flang:706`) написана верно: ««Следовательно,» стоит только в
последнем предложении».

Версия: `flang 0.7.23`. Прогон 2 октября 2026.

## Что должно быть

Прогон шага 3 на трёх предложениях владельца отвечает отказом, который называет беды своими
именами и ни одной не выдумывает:

* предложение 3 — не суждение: ни один образец не подошёл, и образцы перечислены или названо
  место, где они перечислены; совета вписать «Давайте» в словарь нет;
* в рассуждении нет пометки заключения: последнее предложение обязано начинаться словом
  «Следовательно,» (требование, а не ложное утверждение о тексте);
* слова, которые словарной строкой поправимы («студенты», «Николай»), названы по-прежнему.

## Обходной путь

Нет. Совет из отказа ведёт по кругу: впиши «Давайте» в словарь — получишь отказ о слове
«дадим», и так до конца предложения. Чтобы текст прочитался, человек должен сам догадаться,
что побудительное предложение в рассуждение не входит, и заменить его на «Следовательно, …».

## Когда задача сделана

Прогон шага 3 на трёх предложениях владельца, без словаря, печатает отказ с двумя названными
бедами (предложение 3 не суждение; пометки заключения нет) и ни одного совета про слово
«Давайте»; код 1. В наборе `flang/proof/probes/syllogism/sentences/` стоит этот текст и строка
о нём в `expected.tsv`, так что проба краснеет, если отказ опять свалит беду на слово:

```sh
bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Binary
```

Сегодня этот прогон отвечает `syllogism/sentences: проб 14, разошлось 0`, код 0.

## Где живёт правка

`flang/proof/probes/syllogism/sentences/translator.flang`: разбор по словам и образцам в
строках 578—582 (порядок бед: образец раньше слова, когда ни один образец не подошёл ни при
каком словаре) и строка 706 (слова о пометке заключения). Плюс `expected.tsv` и новый текст в
`texts/`. Переводчик лежит вне `flang/self/**` и вне доверенной базы — перепечатки семени
правка не требует.
