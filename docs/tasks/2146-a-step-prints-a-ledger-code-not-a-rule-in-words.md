# 2146. Шаг назван кодом, а не правилом

Строка шага несёт короткий код ведомости. Словесная формулировка стоит только у
утверждения в целом, и в ведомости `flang/proof/tables/inference-rules.tsv` она не у всех.

Решение — [ADR-0057](../adr/0057-a-derivation-is-printed-as-a-reasoning-a-human-reads.md).

## Шаги воспроизведения

1. `bootstrap/flang check --proof flang/proof/probes/user-programs/programs/discount.flang`
2. Смотреть строки шагов в разделе `чем получен каждый шаг`.
3. `awk -F'\t' 'NR>1 && $4=="—"' flang/proof/tables/inference-rules.tsv | wc -l`

## Что происходит

```
  утверждение «цена не ушла в минус» функции «Цена со скидкой» строка 7
    правило «неотрицательность по построению»
    вывод цель ⟨результат не меньше 0⟩
    вывод 1 Н3 ⟨скидка не меньше 0⟩ строка 4
    вывод 2 Пред1 ⟨скидка помещается⟩ строка 4
    вывод 3 П3 ⟨скидка не больше 9007199254740991⟩ из 2
    вывод 4 Н12 ⟨( цена минус скидка ) не меньше 0⟩ из 1 3
    вывод 5 Разв2 ⟨результат не меньше 0⟩ из 4 строка 12
                                                                                   код 0
```

Ведомость правил вывода, снято 2026-10-11 на flang 0.7.25 командами шагов 1 и 3:

| мера | число |
|---|---:|
| строк правил в `flang/proof/tables/inference-rules.tsv` (без шапки) | 118: правил 102, запретов 16 |
| правил без формулировки (прочерк в `kernel-rule`) | 17 |
| строк шага человеку на `discount.flang` с кодом правила | 5 из 5 |
| строк шага человеку на `discount.flang` со словесной формулировкой | 0 из 5 |

Код `Разв2` — из числа 17 без формулировки: в ведомости у него прочерк
(`awk -F'\t' '$1=="Разв2"' flang/proof/tables/inference-rules.tsv`), и назвать этот шаг
словами нечем ни человеку, ни печати.

Третья форма строки шага (`шаг N строка M … правило «…»`) словесную формулировку несёт, но
на пробах силлогистики `flang/proof/probes/syllogism/` различных формулировок в ней две на
18 строк, и 15 из 18 названы одной — «цель есть допущение», в том числе там, где шаг
по смыслу есть модус поненс через охрану.

## Что должно быть

У каждой из 118 строк ведомости — словесная формулировка, и строка шага печатает её рядом
с кодом. Код остаётся: по нему ищут правило и сверяют с Lean.

## Обходной путь

Искать код в `flang/proof/tables/inference-rules.tsv` руками; у 15 правил не найдётся.

## Когда задача сделана

`awk -F'\t' 'NR>1 && $4=="—"' flang/proof/tables/inference-rules.tsv` ничего не печатает
(сегодня — 17 строк), и на `discount.flang` каждая строка шага несёт формулировку правила
словами. Сторож `flang/proof/tables-guard.fscript` краснеет на прочерк в колонке `kernel-rule`.

## Где живёт правка

`flang/proof/tables/inference-rules.tsv` (+ отпечаток `.digest`), `flang/self/proof-record.flang`,
раздел ведомости в `flang/self`, сторож `flang/proof/tables-guard.fscript`.

## Следующий шаг

Вписать формулировку в колонку `kernel-rule` семнадцати строк ведомости (первая —
`Разв2`, якорь `proof-kernel.flang:1324 «Правило развёртки»`), затем в
`flang/self/proof-record.flang` печатать её рядом с кодом в строке `вывод N`. Проба,
которая краснеет сегодня: `awk -F'\t' 'NR>1 && $4=="—"' flang/proof/tables/inference-rules.tsv | wc -l`
печатает 17, а не 0.
