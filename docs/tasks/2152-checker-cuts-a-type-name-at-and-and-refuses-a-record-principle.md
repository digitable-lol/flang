# 2152. Сверщик обрывает имя типа в ёлочках на « и » и не принимает принцип записи, которым ядро закрывает свободное утверждение

Заявка: https://github.com/digitable-lol/flang/issues/415

Причина 1: в исходнике `«Норма и носитель»` сверщик читает как `⟨«Норма⟩`. Причина 2: ядро закрывает посылку по единственному «варианту» записи, а сверщик ищет объявление суммы и находит вариантов 0.

## Шаги воспроизведения

1. Программа and-name.flang:

```flang
модуль «Repro checker conjunction in type name»

объект «Норма и носитель»
  номер является неотрицательное

утверждение «номер пары неотрицателен»
  для всех пара: «Норма и носитель»
  утверждаем пара.номер не меньше 0
```

2. Программа plain-name.flang:

```flang
модуль «Repro checker plain type name»

объект «Пара норм»
  номер является неотрицательное

утверждение «номер пары неотрицателен»
  для всех пара: «Пара норм»
  утверждаем пара.номер не меньше 0
```

3. `bootstrap/flang check and-name.flang --proof --record and-name.запись`, затем `flang/proof/checker/сверщик --строго and-name.flang and-name.запись`.
4. `bootstrap/flang check plain-name.flang --proof --record plain-name.запись`, затем `flang/proof/checker/сверщик --строго plain-name.flang plain-name.запись`.

## Что происходит

```

код 0
$ flang/proof/checker/сверщик --строго and-name.flang and-name.запись
НЕ СОШЛОСЬ: утверждение «номер пары неотрицателен»: строка записи «для всех «пара» ⟨«Норма и носитель»⟩ строка 7», а исходник даёт «для всех «пара» ⟨«Норма⟩ строка 7» — после «пара»: «⟨«Норма» вместо «⟨«Норма⟩»
код 1

$ bootstrap/flang check plain-name.flang --proof --строго --record plain-name.запись
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Сверщик читает имя в ёлочках целиком и принимает принцип записи с одной посылкой; на обоих файлах код 0 или 3.

## Обходной путь

Нет.

## Когда задача сделана

`flang/proof/checker/сверщик --строго and-name.flang and-name.запись` и то же для plain-name.flang — код 0 или 3. Подделка: посылок у записи две — код 1.

## Где живёт правка

`flang/proof/checker/checker.c`. Без печати семени.
