# 2227. Свёртка с накопителем «список неотрицательное» и телом того же типа даёт «список числа»

Заявка: https://github.com/digitable-lol/flang/issues/376

Тип результата `свёртка` расширяется до `число` / `список числа`, даже когда тело возвращает накопитель без изменений. Без свёртки узкий тип держится.

## Шаги воспроизведения

1. Программа `narrow-fold.flang`:

```flang
модуль «Узкий свёрткой»

тотальная функция «Накопитель как есть»
  принимает л: список неотрицательное, новые: список неотрицательное
  возвращает список неотрицательное
  свёртка новые начиная с л как акк и н → акк

тотальная функция «Литерал в накопитель»
  принимает л: список неотрицательное, новые: список неотрицательное
  возвращает список неотрицательное
  свёртка новые начиная с л как акк и н → добавить 0 к акк

тотальная функция «Элемент в узкое»
  принимает новые: список неотрицательное
  возвращает неотрицательное
  свёртка новые начиная с 0 как акк и н → н

тотальная функция «Элемент в функцию»
  принимает новые: список неотрицательное
  возвращает список неотрицательное
  свёртка новые начиная с [] как акк и н → «Одно» от н

тотальная функция «Одно»
  принимает н: неотрицательное
  возвращает список неотрицательное
  [н]
```

2. `bootstrap/flang check narrow-fold.flang`.

## Что происходит

```
$ bootstrap/flang check narrow-fold.flang
narrow-fold.flang: не проверено — замечаний 3
FLANG_TYPE в файле narrow-fold.flang, строка 6, столбец 3: функция «Накопитель как есть» объявлена как список неотрицательного, а тело даёт список числа
FLANG_TYPE в файле narrow-fold.flang, строка 11, столбец 3: функция «Литерал в накопитель» объявлена как список неотрицательного, а тело даёт список числа
FLANG_TYPE в файле narrow-fold.flang, строка 16, столбец 3: функция «Элемент в узкое» объявлена как неотрицательное, а тело даёт число
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

`свёртка` с началом типа `Т` и телом типа `Т` имеет тип `Т`; элемент сохраняет объявленный тип элементов списка. Все пять функций проходят `check`.

## Обходной путь

Расширить тип номеров до `число` по всей программе.

## Когда задача сделана

`bootstrap/flang check narrow-fold.flang` — код 0. Подделка: тело `акк плюс н` над `неотрицательное` по-прежнему даёт `число`.

## Где живёт правка

`flang/self/types.flang` — вывод типа формы `свёртка`. Ждёт печати семени.
