# 2241. Ядро сводит значение поля выписанного конструктора второй раз под именами вызванной функции и доказывает ложное постусловие

Ветвь `случай вариант «К» с п как х` над выписанным конструктором связывает `х` со
значением поля, а ядро сводит это значение ещё раз в окружении вызванной функции,
где стоят её параметры. Имя зовущего, совпавшее с параметром вызванной,
подменяется вторично.

## Шаги воспроизведения

1. Программа `flang/proof/checker/tests/families/unfold-on-constructor/field-twice.flang`:

```flang
модуль «Field twice»

тип «Ч»
  вариант «Ноль»
  вариант «След» содержит прежний: «Ч»

тотальная функция «Прежнее»
  принимает н: «Ч»
  возвращает «Ч»
  пример «ноль»
    дано н равно вариант «Ноль»
    ожидается вариант «Ноль»
  разбор н
    случай вариант «Ноль»
      то вариант «Ноль»
    случай вариант «След» с прежний как п
      то п

тотальная функция «Ложь»
  принимает н: «Ч»
  возвращает «Ч»
  обеспечивает «ложь» результат равно вариант «След» с прежний равным н
  «Прежнее» от (вариант «След» с прежний равным н)
```

2. `bootstrap/flang check --proof --strict field-twice.flang`.

## Что происходит

```
  постусловие «ложь» функции «Ложь» — доказано сведением цели с телом функции: правило «тождество после переписки допущением», …
field-twice.flang: ДОКАЗАНО — утверждений 1: доказано 1, … — код возврата 0
field-twice.flang: независимо, сверщиком, проиграно 0 из 1 доказанных; на слове ядра 1 — код сверщика 3
```

Верно `результат равно н`. С параметром `м` вместо `н` у «Ложь» постусловие не
доказывается.

## Что должно быть

Значение поля, уже сведённое в окружении зовущего, кладётся в окружение ветви как
есть (запрет Разв✗, ADR-0133).

## Когда задача сделана

На семени после печати `check --proof` на `field-twice.flang` — «объявлено, не
доказано»; строка `kernel-unfolds-a-field-twice-under-the-callee-names` в
`flang/proof/tables/consistency-violations.tsv` — `closed`.

## Где живёт правка

`flang/self/proof-kernel.flang`, «Связь из значения». Ждёт печати семени.
