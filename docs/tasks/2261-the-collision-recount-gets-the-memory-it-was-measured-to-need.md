# 2261. Пересчёт столкновений имён на flang не доведён до конца, и его время и память записаны по старому замеру

## Шаги воспроизведения

1. Ярлык `столкновения:пересчёт` зовёт проверку столкновений имён на flang по
   всему дереву:

```
bootstrap/flang io scripts/guards/name-collision-guard.fscript --на-веру
```

2. Что о его цене записано в дереве:

```
grep -an '37,8\|40 ГБ' scripts/guards/name-collision-guard.fscript
grep -an 'столкновения:пересчёт' docs/ci-inventory.md
```

## Что происходит

```
$ grep -an '37,8\|40 ГБ' scripts/guards/name-collision-guard.fscript
109://     бед 5 — код 1; 30 мин 01 с, 37,8 ГБ памяти в пике
135:// ЦЕНА, И ОНА ЖЕ ПРИГОВОР ЗАМЕНЕ. Обход дерева на flang стоит 30 минут и 37,8
137:// съедает почти весь предел ворот (40 ГБ): проход по стволу, который вырастет
$ grep -an 'столкновения:пересчёт' docs/ci-inventory.md
97:| 29 | `столкновения:пересчёт` | обрыв | 240 с, переспрос 780 с |  | не уложилась ни в 4 минуты, ни в 13 …
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Сам пересчёт сегодня не перепроверен: по записи в файле он идёт около
тридцати минут и берёт около 40 ГБ. Числа в файле сняты на дереве, которое с
тех пор выросло, а в `docs/ci-inventory.md` у ярлыка вместо кода возврата
стоит «обрыв».

## Что должно быть

Ярлык доходит до конца под названным пределом памяти, и в дереве записаны
сегодняшние код возврата, время и пик памяти. Его ответ сверен с ответом
ярлыка `столкновения:проверка` (`flang/scripts/link-collision-guard.mjs --дерево`):
обе проверки называют одни и те же столкновения; расхождение передаётся в
задачу 7192.

## Обходной путь

Столкновения проверяет ярлык `столкновения:проверка` на JavaScript, он идёт
секунды.

## Когда задача сделана

```
scripts/memory-limit.sh --predel <замеренный пик с запасом> -- bootstrap/flang run-script name-collisions:recount
```

доходит до конца с названным кодом. В `docs/ci-inventory.md` в строке ярлыка
вместо «обрыв» стоят код, время и пик памяти этого прогона. В
`scripts/guards/name-collision-guard.fscript` нет ни «37,8 ГБ», ни «предел
ворот (40 ГБ)»: `grep -ac '37,8\|40 ГБ' scripts/guards/name-collision-guard.fscript`
печатает 0. Список столкновений совпадает со списком ярлыка
`столкновения:проверка` либо разница записана в задаче 7192.

## Где живёт правка

`scripts/guards/name-collision-guard.fscript` (записанные числа цены),
`docs/ci-inventory.md` (строка ярлыка), описание ярлыка в `ярлыки.flang`
(«тридцать минут против пяти секунд»). Это сценарий и документы, пересборка
семени (bootstrap regeneration) не нужна.

Отдельная задача, здесь не решается: снос `flang/scripts/link-collision-guard.mjs`
и переключение ярлыка `столкновения:проверка` — задача 0049.
