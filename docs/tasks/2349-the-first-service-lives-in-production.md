# 2349. Ни одна служба на flang не живёт в работе — условие 7 дороги к 1.0 не считает часов

Заявка: `docs/road-to-1-0.md`, раздел 7 «Службы, которые живут в работе».

## Шаги воспроизведения

1. Открыть `docs/road-to-1-0.md`, раздел 7: «Чего нет. Ни одной службы в работе».
2. Спросить машину разработки: `systemctl --user list-units 'flang-*'`.
3. Что смотреть: перечень служб пуст; ни адреса, ни даты запуска, ни журнала
   поломок назвать нечего.

## Что происходит

```
$ systemctl --user list-units 'flang-*'
0 loaded units listed.                                   код 0
```

Версия: `flang 0.7.30`.

Примеры служб (`docs/examples/service/`, `service-on-processes/`, `web/`)
проверяются `flang test`, но ни один не запущен надолго, не перезапускается
после падения и не ведёт журнала. Часы условия 7 стоят.

## Что должно быть

Служба на flang, запущенная под надзором (`systemd --user`, перезапуск при
отказе), с адресом, страницей здоровья, журналом запросов и пробой здоровья по
расписанию; в дереве — страница, где названы службы, дни их жизни и журнал
происшествий. Это дословно пункт «Как узнаем, что взято» условия 7.

## Обходной путь

Нет.

## Когда задача сделана

- `flang test flang/services/registry` — все примеры проходят;
  `flang check flang/services/registry/core.flang --proof` — ни одного
  утверждения со статусом «не доказано».
- `systemctl --user is-active flang-registry` отвечает `active`, а
  `curl http://127.0.0.1:8766/health` — строками `работает: да`, `запросов: N`,
  `отказов: N`.
- `docs/services-in-production.md` называет службу, адрес, дату запуска,
  коммит двоичного и ведёт журнал происшествий; раздел 7 `docs/road-to-1-0.md`
  ссылается на неё.
- Таймер `flang-registry-health.timer` раз в пять минут дописывает строку в
  `health.log` каталога службы; строка `FAIL` в нём — это и есть проба, которая
  краснеет, когда служба перестаёт отвечать.

## Где живёт правка

`flang/services/registry/` (ядро, план службы, проба здоровья), `scripts/services/`
(установка и единицы systemd), `docs/services-in-production.md`,
`docs/road-to-1-0.md`. Перепечатки самосборной части не требует: служба
исполняется хозяином `flang io` нынешнего двоичного.
