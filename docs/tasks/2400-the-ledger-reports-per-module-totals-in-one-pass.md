# 2400. Ведомость не даёт итогов по ввезённым модулям

## Шаги воспроизведения

1. Программа, ввозящая модуль с сеткой: наименьшая —

```flang
модуль «Проба дробей»
  использует «Rationals» из "<дерево>/flang/stdlib/rationals.flang"

тотальная функция «Счёт записью»
  возвращает число
  1
```

   (`Rationals` тянет `Bignum`; образец побольше — из задачи 7080).
2. Команды:

```
bootstrap/flang run <файл> --function "Счёт записью"
bootstrap/flang check <файл> --proof --json
bootstrap/flang check flang/stdlib/bignum.flang --proof --json
```

## Что происходит

Вердикт считает по замыканию, ведомость — по входному файлу:

| что спросили | ответ |
|---|---|
| `run` | «утверждений 22: доказано 20, сетка 2» |
| `check <файл> --proof --json` | `totals.claims.total` = 0 |
| `check flang/stdlib/bignum.flang --proof --json` | утверждений 9, доказано 7, сетка 2 |

Снято 2026-10-11 на flang 0.7.25 на программе из шага 1: `check --proof --json`
отвечает за 10,6 с, ключи верхнего уровня отчёта — `ledger, module, functions,
laws, assumed, totals, obligations`, ключа с итогами по модулям нет,
`totals.claims.total` = 0, в `functions` одна функция входного файла.

Чтобы назвать модуль с его числами, отказу приходится спрашивать ведомость
ОТДЕЛЬНО на каждый ввезённый модуль. Это измерено при работе над задачей 7080
(сегодня не переснято): отказ на той же пробе шёл **19,8 с**, а с вопросом на
каждый модуль — **38,3 с** (медиана трёх прогонов). Поэтому в отказе остались
только имена модулей, без чисел.

## Что должно быть

`«Ведомость по итогам»` (`flang/self/bootstrap/compiler.flang`) обходит
замыкание один раз и кладёт рядом с итогами входного файла итоги по каждому
ввезённому модулю: путь, утверждений, доказано, сетка. Тогда поимённый отказ
печатает числа без второго прохода, а `check --proof --json` отдаёт их всем
остальным приборам.

## Чего задача НЕ делает

Не меняет того, что ведомость входного файла остаётся про входной файл: раздел
«только своё из файла» нужен для `--strict` и для доли корпуса. Речь о
ДОБАВЛЕНИИ итогов по модулям, а не о замене фильтра.

## Когда сделана

`check <файл> --proof --json` на пробе из 7080 показывает итоги по
`flang/stdlib/bignum.flang` и `flang/stdlib/rationals.flang`; отказ `run`
печатает числа модулей; время отказа остаётся в пределах прежних 19,8 с — то
есть второго прохода нет. Правка живёт во входе печати семени, значит доезжает
перепечаткой.

## Следующий шаг

`flang/self/bootstrap/compiler.flang`, функция «Ведомость по итогам»: добавить к
записи отчёта поле с итогами по каждому ввезённому модулю (путь, утверждений,
доказано, сетка), собранное за тот же обход замыкания. Проба, которая краснеет
сегодня: `check --proof --json` на программе из шага 1 не несёт ключа с итогами
по `flang/stdlib/rationals.flang` и `flang/stdlib/bignum.flang`.
