# 2510. У 116 кодов отказа из 129 нет английского шаблона, и при language = en они отвечают по-русски

## Шаги воспроизведения

1. `bootstrap/flang run-script messages:check`
2. Программа с отказом, у кода которого нет строки в `flang/messages/catalog.tsv`,
   например `FLANG_BUILTIN_ARGS`, и `FLANG_LANG=en bootstrap/flang check <файл>`
   на двоичном, перепечатанном после ADR-0102.

## Что происходит

```
$ bootstrap/flang run-script messages:check
каталог сообщений: строк 138; кодов FLANG_* с шаблоном 13 из 129 в исходниках компилятора (имена переменных среды не в счёт), без шаблона 116; …
                                                                               код 0
```

Снято 12 октября 2026 на ветке ADR-0102, flang 0.7.26. Рамка строки отказа
(«in file …, line …, column …») английская у всех кодов, текст после двоеточия —
только у 13 кодов и только у тех их текстов, что сошлись с шаблоном. У
`FLANG_PRECONDITION_CALL`, `FLANG_PROOF_*` и `FLANG_BOUND_ON_NAN` переведена
рамка, объяснение ядра печатается по-русски. Итог `flang test`, ответы `run`,
`io`, `lint` и справка `--help` не переведены вовсе.

## Что должно быть

По ADR-0102 у каждого кода, который видит человек, — строка каталога с
шаблоном на каждом языке заголовка; непереведённое печатается по-русски, а не
пустотой, так что работа идёт по частям, от частых кодов к редким.

## Обходной путь

Код `FLANG_*` один на всех языках: английский разбор кода — на
`docs/site/diagnostics.md`.

## Когда задача сделана

`bootstrap/flang run-script messages:check` печатает «без шаблона 0»;
`bootstrap/flang run-script messages:forgery` зелен.

## Где живёт правка

`flang/messages/catalog.tsv` — данные, перепечатки не требует. Строки итога
других команд — `flang/src/emit/c/flang_repl.c` (`msg_printf` вместо `printf`),
это доезжает до двоичного перепечаткой.

**Следующий шаг.** Шаблоны `FLANG_BUILTIN_ARGS` (35 мест в исходниках) и
`FLANG_IO_*` (около ста мест вместе), затем итог `flang test`
(«примеров N, прошло M, не прошло K»).
