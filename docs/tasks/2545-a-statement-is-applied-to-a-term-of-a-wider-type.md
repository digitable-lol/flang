# 2545. Утверждение прикладывается к терму более широкого типа

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/statement-cited-at-a-wider-type.flang`:

```flang
модуль «Утверждение приложено к более широкому типу»

утверждение «неотрицательное не ниже нуля»
  для всех х: неотрицательное
  утверждаем х не меньше 0

тотальная функция «Как есть»
  принимает ы: целое
  возвращает число
  для всех ы таких что ы равен -1234567 обеспечивает «целое не ниже нуля» результат не меньше 0
  ы

теорема «целое не ниже нуля»
  дано ы: целое
  утверждаем результат не меньше 0
  по свойству «неотрицательное не ниже нуля»
  следовательно доказано
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/statement-cited-at-a-wider-type.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/statement-cited-at-a-wider-type.flang --function 'Как есть' --args '{"ы":-1234567}'`

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/typing-holes/programs/statement-cited-at-a-wider-type.flang --proof
… ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — … доказано
$ bootstrap/flang run flang/proof/probes/typing-holes/programs/statement-cited-at-a-wider-type.flang --function 'Как есть' --args '{"ы":-1234567}'
FLANG_PROPERTY: нарушено свойство «целое не ниже нуля» функции «Как есть»                                  код 1
```

Версия: flang 0.7.34.

Утверждение `для всех х: неотрицательное` — `х не меньше 0` приложено шагом `по свойству` к `ы: целое`.
«Приложить утверждение» (`flang/self/proofterm.flang`) сличает форму и проверяет `таких что`, но не объявленный
тип переменной. Проходит и для `число`.

## Что должно быть

После сличения тип подставленного терма обязан быть объявленным типом переменной утверждения, либо факты типа
(дно, потолок, целость) выводятся побочными целями на месте.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check flang/proof/probes/typing-holes/programs/statement-cited-at-a-wider-type.flang --proof` не числит ложное утверждение доказанным.
Проба — строки этой программы в `flang/proof/probes/typing-holes/expected.tsv`
и строка ведомости `flang/proof/tables/typing-holes.tsv`: сегодня они держат ответ
двоичного 0.7.34, после правки строка `proof` меняется, строка ведомости — на `закрыта`.

## Где живёт правка

`flang/self/proofterm.flang`, «Приложить утверждение» и «Приложить утверждение при подстановке». Правки в этой ветке
нет. Требует печати семени.
