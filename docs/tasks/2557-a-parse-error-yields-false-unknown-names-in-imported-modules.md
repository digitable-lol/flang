# 2557. Ошибка разбора в модуле даёт ложные FLANG_UNKNOWN_NAME в строках ввезённого модуля, и ни у одной диагностики нет файла

Заявка: https://github.com/digitable-lol/flang/issues/406

`а.flang` с занятым словом `закон` именем параметра ввозит `б.flang`, который сам проверяется чисто. Кроме `FLANG_PARSE` приходят два `FLANG_UNKNOWN_NAME` на строку 14 — строку `б.flang`.

## Шаги воспроизведения

1. Программа `в.flang`:

```flang
модуль «C»

тип «Истинность»
  вариант «Истина»
  вариант «Ложь»
```

2. Программа `б.flang`:

```flang
модуль «B»
  использует «C» из "в.flang"

тотальная функция «Всегда истина»
  принимает н: неотрицательное
  возвращает «Истинность»
  пример «ноль»
    дано н равно 0
    ожидается вариант «Истина»
  вариант «Истина»

утверждение «всегда истина»
  для всех н: неотрицательное
  утверждаем («Всегда истина» от н) равно вариант «Истина»
```

3. Программа `а.flang`:

```flang
модуль «A»
  использует «B» из "б.flang"

тотальная функция «Предписание»
  принимает закон: неотрицательное
  возвращает неотрицательное
  закон
```

4. `bootstrap/flang check а.flang`.

## Что происходит

```
$ bootstrap/flang check а.flang
а.flang: не проверено — замечаний 3
место указано строкой и столбцом, но без файла: вместе с импортами проверено файлов 3, а диагностика компилятора имени файла не несёт
FLANG_PARSE, строка 7, столбец 3: не разобрана конструкция: неожиданное 'закон' — это слово занято языком, именем оно быть не может: напишите имя в ёлочках («закон») или переименуйте; а если слово попало в форму лишним — уберите его
FLANG_UNKNOWN_NAME, строка 14, столбец 15: неизвестная функция «Всегда истина»
FLANG_UNKNOWN_NAME, строка 14, столбец 43: неизвестный конструктор варианта «Истина»
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

После `FLANG_PARSE` — только она и то, что из неё следует в том же файле; утверждения ввезённых модулей в неполной программе не проверяются. У каждой диагностики — файл. Место `FLANG_PARSE` — строка, где слово впервые стоит именем.

## Обходной путь

Нет.

## Когда задача сделана

`bootstrap/flang check а.flang` — одна `FLANG_PARSE` с файлом `а.flang` и строкой 5.

## Где живёт правка

`flang/self/link.flang`, `flang/self/parser.flang`, `flang/src/emit/c/flang_repl.c` (печать места). Ждёт печати семени.
