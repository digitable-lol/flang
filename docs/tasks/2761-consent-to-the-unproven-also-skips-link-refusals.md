# 2761. Ключ --на-веру запускает программу, которую связывание отказало

Заявка: найдено при закрытии https://github.com/digitable-lol/flang/issues/349

`--на-веру` обещан как согласие запустить программу, чьи утверждения не
доказаны. На деле он снимает и отказ связывания: программа с
`FLANG_DUPLICATE_NAME` под этим ключом запускается, и какая из двух
одноимённых функций ответит, решает порядок строк `использует`.

## Шаги воспроизведения

Файлы `step-first.flang` и `own-step.flang` из
`flang/proof/probes/import-helper-binding/programs/`, рядом третий:

```flang
модуль «Своя и В»
  использует «В» из "step-first.flang"

тотальная функция «Шаг»
  возвращает строка
  "своё"
```

## Что происходит

```
$ bootstrap/flang run own-and-v.flang --function «Шаг»
не доказано: … замечаний проверки 1, первое — FLANG_DUPLICATE_NAME: функция «Шаг»
объявлена в двух модулях: …/step-first.flang и …/own-and-v.flang — запуск только по
явному согласию: --на-веру                                                код 3
$ bootstrap/flang run own-and-v.flang --function «Шаг» --на-веру
на веру: доказанность не считалась — запуск по ключу --на-веру
"в"                                                                       код 0
```

Ответила функция из `step-first.flang`, а не та, что объявлена во входном файле.
`flang test` и `flang emit` на том же файле отказывают с кодом 1.

Версия: flang 0.7.25 (`bootstrap/flang` из дерева), снято 11 октября 2026.

## Что должно быть

`--на-веру` снимает только недоказанность. Беда связывания, разбора или типов
останавливает запуск с кодом 1 при любом ключе, как у `flang test` и
`flang emit`.

## Обходной путь

Перед `run --на-веру` звать `flang check` того же файла и смотреть на его код.

## Когда задача сделана

`run own-and-v.flang --function «Шаг» --на-веру` даёт код 1 и
`FLANG_DUPLICATE_NAME`; строка о `run` под `--на-веру` в пробе
`import-helper-binding` добавлена и зелена.

## Где живёт правка

Оболочка двоичного: `flang/src/emit/c/flang_repl.c`, ветка запуска по
`--на-веру` — замечания проверки там считаются недоказанностью. Доезжает
пересборкой семени без перепечатки.
