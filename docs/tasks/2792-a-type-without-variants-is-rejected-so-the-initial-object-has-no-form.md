# 2792. Тип без вариантов разбор отвергает, и начальный объект на поверхности записать нечем

## Шаги воспроизведения

1. Программа:

   ```flang
   модуль «Initial object»

   тип «Ничто»
   ```

2. `bootstrap/flang check repro-b.flang`

## Что происходит

```
$ bootstrap/flang check repro-b.flang
FLANG_PARSE в файле repro-b.flang, строка 3, столбец 1: не разобрана конструкция: тип без вариантов и без 'это'
repro-b.flang: не проверено — замечаний 1                      код 1
```

Версия: flang 0.7.25.

## Что должно быть

Терминальный объект записывается типом с одним пустым вариантом
(`docs/ct/limits.md`). Его двойник — тип без вариантов: стрелка из него в любой
объект — `разбор` без единого `случай`, и исчерпывающность такого разбора
доказывается пустотой. Решить надо одно из двух и записать довод: либо тип без
вариантов законен (тогда `разбор` по нему без ветвей обязан собираться), либо
начальный объект на поверхности не нужен и это сказано в `docs/ct/limits.md`
границей, а не задачей.

## Обходной путь

Нет: тип с одним вариантом — не начальный объект (в него есть стрелка из
всякого объекта, а из него — не ровно одна).

## Когда задача сделана

Либо программа выше — код 0, и функция из «Ничто» в число с пустым `разбор`
проходит `flang check`; либо в `docs/ct/limits.md` строка «начального объекта
нет» стоит в разделе границ с доводом, а эта задача закрыта как `rejected`.

## Где живёт правка

`flang/self/parser.flang` («Разобрать тип»), `flang/self/types.flang`
(исчерпывающность разбора). Требует перепечатки семени.
