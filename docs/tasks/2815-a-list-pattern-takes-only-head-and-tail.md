# 2815. Образец непустого списка принимает только имена «голова и хвост», а другие имена дают FLANG_PARSE «у случай нет тела то»

Заявка: https://github.com/digitable-lol/flang/issues/414

`случай первое и остальные` отвергается разбором с сообщением, которое не называет причину.

## Шаги воспроизведения

1. Программа pattern.flang:

```flang
модуль «PatternNames»

тотальная функция «Первый»
  принимает числа: список число
  возвращает число
  пример «первый из двух»
    дано числа равно [7, 8]
    ожидается 7
  разбор числа
    случай пусто
      то 0
    случай первое и остальные
      то первое
```

2. `bootstrap/flang check pattern.flang`.

## Что происходит

```
$ bootstrap/flang check pattern.flang
pattern.flang: не проверено — замечаний 1
FLANG_PARSE в файле pattern.flang, строка 12, столбец 5: у 'случай' нет тела 'то'
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Любые имена в образце `случай X и Y`, как у полей варианта `с поле как имя`; либо диагностика «в образце списка имена — только «голова и хвост»».

## Обходной путь

`пусть начало равно голова` перед вложенным `разбор`.

## Когда задача сделана

`bootstrap/flang check pattern.flang` — код 0; имя образца, совпавшее с параметром, по-прежнему не доказывает ложного (проба задачи 8634).

## Где живёт правка

`flang/self/parser.flang`, `flang/self/proof-initial.flang` (имена посылки). Ждёт печати семени.

## Правка

Причина: образец со строчным именем разбирался как связывание любого значения,
и `и` после имени оставалось без места. «Образец именем и остатком» в
`flang/self/parser.flang` читает `имя и имя` как образец непустого списка с
теми же узлами `cons`, что `голова г и хвост х`, поэтому ядро и проверка
исчерпываемости ничего нового не видят. Подсказка отказа образца называет и эту
форму.

Проба `flang/proof/probes/parse-and-import`, строка
`list-pattern-with-own-names.flang`: двоичный 0.7.28 — `FLANG_PARSE «у 'случай'
нет тела 'то'»`, код 1. Исходный компилятор (`bootstrap/flang run flang/self/bootstrap/check-with-source-compiler.flang` по исходникам ветки (свой вход на несколько файлов, `--trust`), 16 октября 2026): «ГОДНО». Узел образца тот
же, что у `голова первое и хвост остальные`, поэтому затенение имени параметра
(задача 8634) судится прежним путём.
