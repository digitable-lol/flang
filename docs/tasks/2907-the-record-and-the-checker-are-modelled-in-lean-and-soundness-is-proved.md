# 2907. Терм, запись и приёмка — данные Lean; «принят — значит верно» — теорема

Решение: [ADR-0041](../adr/0041-the-checker-is-proved-sound-against-a-mechanised-semantics.md).
Пишется в НОВЫХ файлах `flang/proof/lean/`; `Модель.lean` и `Правила.lean` не
правятся (их правит партия Э).

## Чем измерено

13 сентября 2026: `Модель.lean` 421 строка (значения, округление «грубое»,
списки, суммы, тексты, суждение «Судим»), `Правила.lean` 110 теорем по одной на
строку ведомости, `Ловушка.lean` 14 искажений; `сверщик.c` 6982 строки кода,
13 правил в `шаг_вывода`; формат записи — `ЧИТАТЬ.md` прозой; Lean на машине не
установлен (`прогон.sh` — код 2).

## Что сделать — по порядку ADR-0041 §2.4

1. `Терм.lean`: индуктивный терм в объёме ведомости и `оценить`; показать, что
   леммы `Правила.lean` переформулируются через `оценить` (хотя бы для семей Н, П,
   Т, Э) без потери.
2. `Запись.lean`: индуктивная запись по `ЧИТАТЬ.md`; расхождения прозы с
   `сверщик.c` — списком в задачу 1313 §3.
3. `Приёмка.lean`: `Принят` и разрешимая `принят?` для правил с приёмом в C — по
   одному, начиная с Т1/Т2, Н, Кон1, Э1–Э4; число покрытых правил — в шапку задачи.
4. `Состоятельность.lean`: теорема `Принят з → Судим (допущения з) (цель з)` для
   покрытого подмножества; подмножество названо.
5. Сверка вердиктов C ↔ Lean на 216 честных и 459 подделках — в `прогон.sh`,
   красит при расхождении; каждое расхождение — задачей.
6. Слово: `docs/road-to-1-0.md` §3 — числом; `docs/lean-checks-the-inference-rules.md`
   — новый раздел; `ЧИТАТЬ.md` ссылается на `Запись.lean`.

## Чего не делать

Не править `сверщик.c` иначе как чиня расхождение, найденное сверкой; не
верифицировать C как программу; не переписывать сверщик на Lean; не обещать
теорему о вычислителе (`interpret.flang`) — это §2.3 ADR-0041.

## Как поймём, что сделано

`прогон.sh` собирает четыре новых файла; теорема принята для N правил из 13,
N назван; сверка вердиктов — расхождений 0 или каждое задачей; §3
`road-to-1-0.md` переписан числом.
