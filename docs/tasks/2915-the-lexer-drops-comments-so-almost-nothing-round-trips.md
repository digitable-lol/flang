# 2915. Нет команды, печатающей разобранный файл обратно в исходный текст, и лексер теряет комментарии

## Шаги воспроизведения

1. Программа:

```flang
модуль «Заметка»

// пояснение к функции
тотальная функция «Один»
  возвращает число
  1
```

2. Команды:

```
bootstrap/flang print <файл>
bootstrap/flang format <файл>
bootstrap/flang tokens <файл>
bootstrap/flang ast <файл> | grep -ac "пояснение"
```

3. Смотреть: есть ли команда обратной печати и есть ли комментарий среди
   токенов и в дереве разбора.

## Что происходит

```
$ bootstrap/flang print <файл>
flang: неизвестная команда «print». «flang --help» — что умеет бинарник.   код 2
$ bootstrap/flang format <файл>
flang: неизвестная команда «format». «flang --help» — что умеет бинарник.  код 2
$ bootstrap/flang tokens <файл>
1:1	слово module
1:8	ёлочка Заметка
1:17	/
4:1	слово total
4:11	слово function
…                                                                 код 0
$ bootstrap/flang ast <файл> | grep -ac "пояснение"
0
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

Среди пятнадцати команд `flang --help` обратной печати нет. После токенов первой
строки сразу идут токены четвёртой: строка с комментарием не даёт ни одного
токена. Так написано и в `flang/self/lexer.flang` («строки из одного
комментария не дают ни отступа, ни токенов»); блочный комментарий лексер
узнаёт только затем, чтобы пропустить. Поэтому из потока токенов файл с
комментарием не восстановить при любой печати.

## Что должно быть

Команда двоичного печатает из разбора тот же текст, что был на входе:

```
bootstrap/flang <обратная печать> <файл> | diff - <файл>          код 0
```

Расхождение означает, что разбор что-то потерял: комментарий, форму
экранирования в строке, пробелы. Проверка сравнивает текст, а не вердикт, и
поэтому ловит всё, чего разбор не удержал.

## Обходной путь

Обходного пути нет. Потери разбора видны только косвенно — по тому, что
программа после разбора ведёт себя иначе.

## Когда задача сделана

- команда обратной печати есть в `flang --help`, и на программе из шагов
  воспроизведения `diff` отвечает кодом 0;
- есть короткая команда `.flangrc`, которая прогоняет печать по исходникам
  дерева и печатает, сколько файлов сошлось целиком из скольких и сколько
  строк из скольких; она отвечает кодом 1, когда число сошедшихся файлов
  упало;
- если держать комментарии в разборе окажется дороже пользы, задача закрывается
  числом: сколько файлов не сходится только из-за комментариев и во что
  обошлась бы правка.

## Где живёт правка

`flang/self/lexer.flang` (выдавать комментарий токеном), `flang/self/parser.flang`
(удержать его в дереве), новая функция печати и команда в `flang/self/cli.flang`.
Всё это самосборная часть: до двоичного правка доезжает только пересборкой
семени (bootstrap regeneration). Короткая команда и прогон по дереву —
скрипты, пересборки не требуют.
