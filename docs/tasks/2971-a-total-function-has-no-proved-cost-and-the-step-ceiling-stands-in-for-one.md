# 2971. У тотальной функции нет доказанной оценки цены, и потолок шагов пересборки семени вписан числом от руки

## Шаги воспроизведения

1. Спросить, что компилятор говорит о завершении функций файла:

```
bootstrap/flang check flang/proof/kernel.flang --proof
```

2. Поискать в спецификации форму, которой записывается оценка цены:

```
grep -ac 'стоит не более' docs/flang/SPEC.md
```

3. Посмотреть, откуда берётся предел шагов пересборки семени (bootstrap
   regeneration):

```
grep -an '^MAX_STEPS=\|^MEASURED_COST=' scripts/bootstrap-reprint.sh
grep -an 'define FL_MAX_STEPS' bootstrap/flang_runtime.h
```

## Что происходит

```
$ bootstrap/flang check flang/proof/kernel.flang --proof
  «Вердикт цепочки»  доказано структурой: аргумент 1 («звенья») на каждом витке
                     становится частью себя; цепочка частей конечного дерева
                     обрывается сама, сторожа нет
  функций 9: тотальных 9, обычных 0
  обещание несёт: композиция 7, структура 2, точный шаг 0, постоянный шаг 0, объявленная мера 0
                                                                        код 0
$ grep -ac 'стоит не более' docs/flang/SPEC.md
0
$ grep -an '^MAX_STEPS=\|^MEASURED_COST=' scripts/bootstrap-reprint.sh
292:MEASURED_COST=2508501226319
293:MAX_STEPS=8000000000000
$ grep -an 'define FL_MAX_STEPS' bootstrap/flang_runtime.h
11:#define FL_MAX_STEPS 8000000000000
131:#define FL_MAX_STEPS 1000000
```

Снято 2026-10-11 на flang 0.7.25: все четыре ответа те же.

С тех пор принят [ADR-0083](../adr/0083-cost-is-known-before-the-run.md) («цена
известна до прогона»): анализатор `scripts/cost/` и ключ `flang run --cost` печатают
границу шагов и памяти многочленом от размеров входа с пометкой «выведено» или
«оценено». Это ответ на вопрос «сколько», но не доказанное обязательство в языке:
ядро его не проверяет, в запись доказательства граница не попадает (это задача 1408),
а предел перепечатки семени анализатор не читает — `MAX_STEPS` по-прежнему вписан
числом. Задача сужается до двух оставшихся частей ниже.

Отчёт называет, чем доказано завершение каждой функции, но оценки числа шагов
не даёт: доказательство говорит «конечно», а не «сколько». Счётчик шагов в
рантайме — бюджет одного прогона, а не признак зацикливания. Бюджет пересборки
семени и измеренная цена прошлого прогона вписаны в сценарий числами; когда
дерево вырастает, пересборка упирается в предел и число поднимают рукой. Второй
`FL_MAX_STEPS` (строка 131) к пересборке не относится: это `#ifndef`-подстановка
для напечатанного C, 1 000 000 шагов.

## Что должно быть

Работа начинается со спецификации: что считать доказанной ценой.

- Оценка сверху записывается обязательством вида «стоит не более <выражение>
  от <довод>», и ядро проверяет её тем же спуском, которым доказывает
  завершение: цена тела не больше суммы цен частей. Многочлен ADR-0083 — готовый
  кандидат на правую часть; решить в спецификации, как «выведено» анализатора
  соотносится с обязательством ядра. Цену этой работы над ядром
  и грамматикой измерить до начала (задачи 1313 и 2159 — о размере проверяющей
  программы).
- Непроверяемую «примерную оценку» не заводить.
- До появления доказанной оценки предел шагов пересборки считается при запуске
  из записанной цены прошлого дошедшего прогона с названным множителем, а не
  вписывается в исходник.

## Обходной путь

Поднять `MAX_STEPS` в `scripts/bootstrap-reprint.sh` и пересобрать двоичный с
новым `FL_MAX_STEPS`, либо дать прогону предел общим ключом `--step-limit N`.

## Когда задача сделана

- В `scripts/bootstrap-reprint.sh` нет строки `MAX_STEPS=<число>`: предел
  выводится из записанной цены. Проба: записанная цена, заниженная вдвое, даёт
  предел вдвое меньше.
- В `docs/flang/SPEC.md` описана форма оценки цены, и на
  `flang/proof/kernel.flang` команда `bootstrap/flang check … --proof` печатает
  для функций со структурным спуском доказанную оценку рядом со словом о
  завершении. Программа с заниженной оценкой получает отказ и ненулевой код.
- В дереве нет числа-предела, у которого не названы команда замера и её дата.

## Где живёт правка

`scripts/bootstrap-reprint.sh` (вывод предела) — сценарий, пересборка семени не
нужна. Форма оценки — `docs/flang/SPEC.md`, `flang/self/parser.flang`,
`flang/self/totality.flang`, `flang/self/proof.flang`; эта часть доезжает до
двоичного только пересборкой семени. Анализатор цены — `scripts/cost/` (ADR-0083).

## Следующий шаг

Дешёвая половина первой: `scripts/bootstrap-reprint.sh`, строки 292–293 — считать
`MAX_STEPS` из `MEASURED_COST` с названным множителем вместо вписанного числа.
Проба, которая краснеет сегодня: `grep -an '^MAX_STEPS=' scripts/bootstrap-reprint.sh`
находит строку с числом. Вторая половина начинается с раздела в `docs/flang/SPEC.md`
о форме «стоит не более …»: `grep -ac 'стоит не более' docs/flang/SPEC.md` даёт 0.
