# 3045. Вычислитель сверщиков читает цепочку знаков не как язык

## Шаги воспроизведения

1. Исходник `probe.flang`:

```flang
модуль «Проба счёта»

утверждение «счёт»
  утверждаем (10 минус 2 плюс 3) равен 5
```

2. Запись `probe.record` (написана руками; строки `строк`, `знаков`, `отпечаток`, `отпечаток256` — по исходнику):

```
запись доказательства 1
исходник finds/E1-eval-minus-plus.flang
строк 5
знаков 82
отпечаток 562893412 479329012
ядро 2
утверждений 1
отпечаток256 ab8b94af1cb98ae2dafeb795bf8a02f17eb3f9e689fdb48c1f8e994723bb341e

утверждение «счёт» строка 3
  вид statement
  вердикт доказано
  теоремы нет
  правило «тождество после переписки допущением»
  по объявлению нет
    ход цель
    ход 1 вычислить ⟨(10 минус 2 плюс 3) равен 5⟩ = ⟨да⟩
    ход 2 закрыть истиной
    ход конец
конец утверждения

конец записи
```

3. `flang/proof/checker/сверщик probe.flang probe.record`, затем
   `flang/proof/checker/second/out/второй-сверщик probe.flang probe.record`.

## Что происходит

Оба сверщика отвечают `ПРОВЕРЕНО`, код 0.

Версия: flang 0.7.34, `checker.c` и второй сверщик ствола `001d8df7c`.

Утверждение ложно: язык считает `(10 минус 2) плюс 3`, это 11.

Вычислитель режет терм по первому найденному верхнему знаку и получает `10 минус (2 плюс 3)`. На C `умножить на`
режется раньше `минус`, а нулевое произведение не приводится к плюс нулю.

Тем же корнем принимаются оба: `(10 минус 2 минус 3) равен 11`, `(0.1 плюс 0.2 плюс 0.3) равен (0.1 плюс (0.2 плюс 0.3))`,
та же цель правилом «вычисление замкнутой цели» без ходов; только C: `(10 умножить на 2 минус 10) равен -80`,
`не ((-1 умножить на 0) равен 0)`; только второй сверщик:
`(-0 минус 7 плюс -3 плюс 9007199254740992) не больше 4503599627370497`.

## Что должно быть

Цепочка режется по последнему верхнему `плюс`/`минус`, затем по последнему `умножить на`/`делить на`; нулевое
произведение приводится к плюс нулю; смешанная цепочка без скобок, которую сверщик не читает как язык, — код 3.

## Обходной путь

Обхода нет. Ядро таких записей не пишет: дыра открыта тому, кто пишет запись сам.

## Когда задача сделана

Оба сверщика отвечают на эту запись кодом 1 либо 3; запись лежит подделкой в
`flang/proof/checker/tests/families/` со строкой в `flang/proof/checker/tests/probes.tsv`, и
`make -C flang/proof/checker пробы` отвечает «сошлось всё».

## Где живёт правка

`flang/proof/checker/checker.c` (`оценить_терм`), `flang/proof/checker/second/Evaluator.lean`. Печать семени не нужна.
