# 3046. Форма «ход» не доходит до читателя

Ядро пишет вывод в двух формах: `вывод` (шаг с кодом правила) и `ход` (развернуть,
переписать формой, закрыть тождеством). В запись уходят обе. В раздел для человека —
только первая.

Решение — [ADR-0057](../adr/0057-a-derivation-is-printed-as-a-reasoning-a-human-reads.md).

## Шаги воспроизведения

1. `bootstrap/flang check --proof --record /tmp/r flang/proof/probes/user-programs/programs/positives.flang`
2. Сличить блок третьего утверждения в `/tmp/r` с тем же утверждением в разделе
   `чем получен каждый шаг`.

## Что происходит

В записи — три хода с местом и законом переписки:

```
утверждение «длина сохраняется» функции «Удвоить все» строка 16
  правило «тождество после переписки допущением»
    ход цель
    ход 1 развернуть ⟨«Удвоить все» от ( числа )⟩ строка 20 ⟨отобразить числа как число → число умножить на 2⟩
    ход 2 переписать формой ⟨длина (отобразить числа ...)⟩ = ⟨длина числа⟩ законом «Мера построения»
    ход 3 закрыть тождеством
    ход конец
```

В разделе для человека от этого остаётся одна строка:

```
  утверждение «длина сохраняется» функции «Удвоить все» строка 16
    правило «тождество после переписки допущением»
                                                                                   код 0
```

Корпус 47 файлов (14 программ `user-programs` и 33 примера `docs/examples/guide`):
строк `ход` в записях 40, из них реальных ходов 22; напечатано человеку 0.
Реальных шагов формы `вывод` за тот же прогон 20, и все 20 напечатаны.
Форма `ход` не смоделирована и в Lean: `flang/proof/lean/Record.lean` в шапке говорит, что
моделирует только то, что сверщик читает «когда переигрывает блок `вывод`».

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

## Что должно быть

Либо раздел для человека печатает ходы наравне с выводами, либо форм остаётся одна.
Две формы, из которых одна невидима, читателю неотличимы от пробела в доказательстве.

## Обходной путь

Звать `--record` и читать файл записи.

## Когда задача сделана

На `positives.flang` раздел `чем получен каждый шаг` у утверждения «длина сохраняется»
печатает три хода; по корпусу из 47 файлов число ходов человеку равно 22 — числу ходов
в записях.

## Где живёт правка

`flang/self/zapis.flang` (печать), раздел ведомости в `flang/self`; при выборе «одна форма» —
`flang/self/proofterm.flang` и `flang/proof/checker/checker.c`.
