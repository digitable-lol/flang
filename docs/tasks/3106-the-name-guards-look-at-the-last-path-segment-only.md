# 3106. Сторожа имён смотрят только последнее звено пути

## Шаги воспроизведения

1. Положить файл с латинским именем в каталог с кириллическим именем и спросить
   оба сторожа имён:

   ```sh
   mkdir -p 'docs/проба-каталога' && printf '# proba\n' > 'docs/проба-каталога/file.md'
   git add 'docs/проба-каталога/file.md'
   bootstrap/flang io scripts/guards/cyrillic-file-names-guard.fscript --plan Проверка
   bootstrap/flang io scripts/guards/translit-file-names-guard.fscript --plan Проверка
   ```

## Что происходит

```
$ bootstrap/flang io scripts/guards/cyrillic-file-names-guard.fscript --plan Проверка
… "кириллица в именах файлов: 5, все в ведомости — новых нет"                  код 0
```

Сторож зелен на подложенном каталоге. Причина — в его же запросе к дереву:

```
git ls-files | grep -P '[А-Яа-яЁё][^/]*$'
```

Выражение `[^/]*$` прибивает поиск к **последнему звену пути**: кириллица в
каталоге под него не попадает. У сторожа транслита то же: он берёт имя
`sed 's#.*/##; s#[.][^.]*$##'`, то есть каталоги отрезает начисто.

**Числом, как это выглядело на деле.** Задача 1419 переименовывала кириллические
имена. Кроме 55 имён, которые сторож видел, в дереве лежали **шесть
кириллических каталогов** и под ними **пять файлов** с латинскими именами — ни
один из двух сторожей их не считал, и оба были зелены. Нашлось это руками, при
сверке `ls-files | grep -P '[А-Яа-яЁё]'` (кириллица где угодно в пути) против
`ls-files | grep -P '[А-Яа-яЁё][^/]*$'`: 61 против 56.

## Что должно быть

Сторож судит **весь путь**, а не последнее звено: кириллица в каталоге —
такая же находка, и в ответе стоит путь целиком. План «Подлог» ловит оба случая:
и кириллическое имя файла, и кириллический каталог при латинском имени файла.

## Обходной путь

Обходного пути нет: пока выражение прибито к последнему звену, каталог не
увидеть ничем, кроме ручной сверки.

## Когда задача сделана

Прибор в обе стороны: подложенный каталог с кириллическим именем краснеет с
путём, убранный — зеленеет; план «Подлог» краснеет на обоих подложенных путях,
а не только на имени файла. Старый сторож на том же подлоге зелен — это и есть
мера того, что починка нужна.

## Где живёт правка

`scripts/guards/cyrillic-file-names-guard.fscript`. У сторожа транслита
(`scripts/guards/translit-file-names-guard.fscript`) каталоги остаются вне счёта,
и это названо числом, а не забыто: в его областях (`scripts`, `flang/test`,
`flang/scripts`, `flang/proof`, `docs/site`, `docs/zettel`, `.github`) **184
каталога**, и в их именах **56 слов вне закрытого списка**. Из них 39 — обычные
английские слова, которым место в списке (`algebra`, `api`, `audit`, `demo`,
`docs`, `editors`, `fixtures`, `golden`, `ledgers`, `models`, `patterns`,
`programs`, `scripts`, `tests`, `tools`, `workflows` и другие); **девять —
настоящий транслит** (`korpus`, `kruga`, `naslediye`, `oblast`, `plany`,
`razrez`, `slovar`, `snimok`, `zapis`); **шесть — придуманные имена оснастки FTS**
(`ftsc`, `ftsmap`, `ftspec`, `ftsynth`, `gacascade`, `gasearch`); два —
обозначения версий (`v1`, `g2`). Расширение сторожа транслита на каталоги — это
56 решений по словам, а не одно регулярное выражение, и потому отдельный шаг:
девять транслитных каталогов идут переименованием (задача 1428), остальные —
записью в закрытый список или в ведомость долга с доводом.
