# 3258. Опись JavaScript называет 54 файла при 49 в дереве, а опись дерева ссылается на раздел карты, которого нет

## Шаги воспроизведения

1. Сосчитать файлы и строки JavaScript в дереве:

```
git ls-files '*.mjs' '*.js' | wc -l
git ls-files '*.mjs' '*.js' | xargs wc -l | tail -1
```

2. Сравнить с заголовком и итоговой таблицей описи и с описью дерева:

```
head -1 docs/javascript-inventory.md
grep -n 'ДОЛГ\*\* |' docs/javascript-inventory.md
grep -n '^## Куча' docs/javascript-inventory.md
grep -n 'Вне языка' docs/tree-inventory.md
grep -c 'Вне языка' ROADMAP.md
```

## Что происходит

```
$ git ls-files '*.mjs' '*.js' | wc -l
49
$ git ls-files '*.mjs' '*.js' | xargs wc -l | tail -1
  22965 total
$ head -1 docs/javascript-inventory.md
# Опись JavaScript в дереве: 54 файла, из них долг — 28
$ grep -n 'ДОЛГ\*\* |' docs/javascript-inventory.md
132:| **ДОЛГ** | **28** | **13 467** |
$ grep -n '^## Куча' docs/javascript-inventory.md
139:## Куча 1. Не долг: это вывод языка — 7 файлов, 8 180 строк
175:## Куча 2. Не долг: чужая среда и замеряемый материал — 7 файлов, 1 604 строки
203:## Куча 3. `flang/test/**` — 9 файлов, 1 991 строка
239:## Куча 4. ДОЛГ — 28 файлов, 13 467 строк
$ grep -n 'Вне языка' docs/tree-inventory.md
65:| `docs/ROADMAP.md`, раздел «Вне языка» | 54 файла на JavaScript, 25 487 строк |
$ grep -c 'Вне языка' ROADMAP.md
0                                                                 код 1
```

Двоичный в прогоне не участвует.

В дорожной карте раздела «Вне языка» нет, но `docs/tree-inventory.md` на него ссылается — и числами того
раздела (54 файла, 25 487 строк). В `docs/javascript-inventory.md` заголовок и
итоговая таблица по кучам (7 + 10 + 9 + 28 = 54 файла) описывают состав, которого
в дереве нет: файлов 49. Та же опись расходится сама с собой: заголовки четырёх
куч дают 7 + 7 + 9 + 28 = 51, у кучи 2 в заголовке 7 файлов и 1 604 строки, а в
итоговой таблице — 10 и 1 849.

Число строк сошлось: 22 965 стоит дважды — `docs/javascript-inventory.md:75` и
`docs/tree-inventory.md:87`, — и оба раза одинаково.

## Что должно быть

Каждое число про JavaScript записано в дереве один раз, в
`docs/javascript-inventory.md`, с командой, которой оно снято; остальные
документы ссылаются на опись и числа не повторяют. Заголовок, итоговая таблица по
кучам и заголовки самих куч отвечают сегодняшним 49 файлам и сходятся между собой.
Ссылок на несуществующий раздел карты нет.

## Обходной путь

Считать командами из шага 1 и не верить числам в документах.

## Когда задача сделана

Заголовок `docs/javascript-inventory.md` называет то же число файлов, что
первая команда шага 1; сумма итоговой таблицы по кучам и сумма заголовков куч
равны ему же.
`grep -c 'Вне языка' docs/tree-inventory.md` печатает 0. Число строк
JavaScript стоит в дереве в одном месте; рядом с ним и с числом файлов в
заголовке есть отметка снятого числа, которую сверяет
`scripts/guards/prose-numbers-guard.fscript`: проверка краснеет, когда число
расходится с деревом.

## Где живёт правка

`docs/javascript-inventory.md` и `docs/tree-inventory.md`. Пересборка семени
(bootstrap regeneration) не нужна. Задача 0049 сносит JavaScript из дерева
целиком; если она закроется раньше, опись уходит вместе с ним.
