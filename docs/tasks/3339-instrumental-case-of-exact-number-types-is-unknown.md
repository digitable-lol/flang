# 3339. Поле «является неотрицательным» и «является целым» даёт FLANG_UNKNOWN_NAME: творительный падеж понят только у числа, строки и признака

Заявка: https://github.com/digitable-lol/flang/issues/404

`поле является числом`, `строкой`, `признаком` проходят; `является целым` и `является неотрицательным` — «неизвестный тип», хотя `является неотрицательное` (именительный) проходит.

## Шаги воспроизведения

1. Программа field.flang:

```flang
модуль «P»

объект «А»
  поле является неотрицательным
```

2. `bootstrap/flang check field.flang`.

## Что происходит

```
$ bootstrap/flang check field.flang
field.flang: не проверено — замечаний 1
FLANG_UNKNOWN_NAME в файле field.flang, строка 3, столбец 1: неизвестный тип «неотрицательным»
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Творительный падеж понимается у всех встроенных типов: `целым`, `неотрицательным`, `сотых`/`тысячных` и прочих точных.

## Обходной путь

`поле: неотрицательное`.

## Когда задача сделана

`bootstrap/flang check field.flang` — код 0; то же для `целым`.

## Где живёт правка

`flang/core/parser.flang` — таблица «Перевод» падежей типов, и её двойник в разборе `flang/self`. Ждёт печати семени.
