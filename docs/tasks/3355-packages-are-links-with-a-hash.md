# 3355. Импорт по адресу https не работает: связывание склеивает адрес с каталогом файла, а реестр и установка по имени остаются

## Шаги воспроизведения

1. Программа `q.flang`:

   ```
   модуль «Проба ссылки»
     использует «Логика» из "https://example.org/logic.flang"

   тотальная функция «Один»
     возвращает число
     пример «один»
       ожидается 1
     1
   ```

2. `bootstrap/flang check q.flang`

## Что происходит

```
$ bootstrap/flang check q.flang
FLANG_IMPORT_NOT_FOUND в файле q.flang, строка 1, столбец 1: не найден модуль «Логика»: …/https:/example.org/logic.flang (ENOENT: no such file or directory, …)
q.flang: не проверено — замечаний 1                       код 1
```

Версия: flang 0.7.32.

## Что должно быть

По [ADR-0214](../adr/0214-a-package-is-a-link-with-a-hash-and-there-is-no-registry.md):
адрес `https://…` в импорте скачивается при первой сборке один раз, его
`sha256` и исходник ложатся в `flang.lock`, тело — в кеш
`$XDG_CACHE_HOME/flang/links/`; следующие сборки берут исходник из замка без
сети. Адрес без записи и без сети — `FLANG_LINK_OFFLINE`; разошедшийся отпечаток
в замке или в кеше — `FLANG_LINK_CHANGED`. Импорты скачанного файла
разбираются транзитивно. Установка по имени и её сторожа сняты (ADR-0214 §6).

## Обходной путь

Скачать файл руками, положить рядом с программой и импортировать по
относительному пути; `flang lock` запрёт его исходник.

## Когда задача сделана

Сторож скачивания по адресу (ADR-0214 §7) зелёный на чистом HOME: сборка по
адресу file://, вторая сборка без сети и без исходников даёт тот же замок знак в
знак, подмена тела — `FLANG_LINK_CHANGED`, адрес без записи без сети —
`FLANG_LINK_OFFLINE`; его подлог краснеет. Работа CI заменяет
`package-install`.

## Где живёт правка

`flang/self/link.flang` и `flang/src/emit/c/flang_repl.c` — печать семени;
снятие установки — `scripts/package-install.fscript`, сторож и работа CI
`package-install`, `docs/road-to-1-0.md` (условие 6) — без печати.

## Чем закрыта

`использует «X» из "https://…"` и `из "file://…"`: хозяин спрашивает путь
модуля у связывания, берёт тело из замка, иначе из кеша, иначе скачивает,
пишет запись в `flang.lock` и тело в кеш (ADR-0214 §2). Коды
`FLANG_LINK_FETCH`, `FLANG_LINK_OFFLINE`, `FLANG_LINK_CHANGED`. `flang install`,
его движок, сторож и работа CI `package-install`, ключ `registry` сняты. Служба
реестра, `flang/stdlib/registry.flang` и `scripts/registry-example/` остаются
при службе (ADR-0214 §6).

Сторож `bootstrap/flang run-script link-import:check` — 28 шагов, зелёный на
двоичном, собранном из `flang/src/emit/c/flang_repl.c` поверх семени ветки;
на двоичном семени — красный (бед 14 из 27). `link-import:forgery` красный, как
и должен. Работа CI `link-import` гоняет обе на `bootstrap/flang` и зеленеет
после печати.
