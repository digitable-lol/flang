# 3404. Команды двоичного flang install нет — установщик пакетов зовётся только из дерева flang

## Шаги воспроизведения

1. Спросить у двоичного команду установки:

```
bootstrap/flang install
```

2. Позвать установщик из каталога вне дерева:

```
cd /tmp && flang run-script package:install проба/proba.flang Логика
```

## Что происходит

```
$ bootstrap/flang install
flang: неизвестная команда «install». «flang --help» — что умеет бинарник.   код 2
$ cd /tmp && flang run-script package:install проба/proba.flang Логика
flang run-script: файла «.flangrc» нет ни в рабочем каталоге, ни выше до корня проекта   код 3
```

Снято 24 октября 2026 на flang 0.7.30. Установщик есть и работает
(`scripts/package-install.fscript`, задача 3403, ADR-0168), но он — план в
`scripts/`, и `run-script` находит его только через `.flangrc` дерева. Двоичный,
поставленный `install.sh`, формулой Homebrew или плагином asdf, дерева рядом не
имеет.

## Что должно быть

`flang install <программа.flang> [<имя>[: <диапазон>]]... [--registry <адрес>]
[--accept-unproven]` — та же дорога, что у плана: нужды в `flang.needs`, список
реестра по адресу, выбор версии, сверка `sha256` до записи, файлы рядом с
программой, `flang check`, `flang lock`. Коды отказа те же `FLANG_INSTALL_*`
(`docs/site/packages.ru.md`, «Коды отказов установщика»).

## Обходной путь

Клонировать дерево flang и звать `bootstrap/flang run-script package:install
<абсолютный путь программы> …` из его корня.

## Когда задача сделана

```
$ flang install проба/proba.flang 'Множество строк: не ниже 1.1'
поставлено пакетов: 3 …                                                код 0
```

из каталога, где нет `.flangrc` дерева, а двоичный поставлен без дерева; сторож
`package-install:check` гоняет обе дороги — план и команду — и сравнивает их
замки знак в знак; подлог `package-install:forgery` красен для обеих.

## Где живёт правка

`flang/self/cli.flang` (разбор команды и справка), исполнитель в
`flang/src/emit/c/flang_repl.c` — либо двоичный несёт план установщика с собой
(`share/flang/scripts/package-install.fscript`, как несёт библиотеку) и `flang
install` зовёт `flang io` над ним. Второй путь не трогает `flang/self/**` и не
требует перепечатки; первый требует печати семени (партия 9c).

## Чем закрыта

Ветка `a/flang-install-command` (вход печати 9c), ADR-0168 §6, принят владельцем
25 октября 2026. Выбран путь «диспетчер в C зовёт план рядом с двоичным»:
`install_command` в `flang/src/emit/c/flang_repl.c` ищет
`<каталог двоичного>/../scripts/package-install.fscript`, иначе
`../share/flang/scripts/package-install.fscript` (его туда кладёт выпуск —
`scripts/release/release-in-c.fscript`, «Копия движка установки»), делает путь
программы абсолютным, берёт ключ `registry` из ближайшего `.flangrc`, отдаёт
свой путь в `FLANG_BINARY` и зовёт `io_file` в кратком режиме (итог строками,
отказ `КОД: причина`). Нет движка — `FLANG_INSTALL_ENGINE`. План ввозит
`Registry` по имени, поэтому работает и у поставленного двоичного.
`flang/self/cli.flang`: «Справка установки», `install` в «Известные команды» и
«Зарезервированные имена пакетов» (18).

Проба: `package-install:command` (план `Command` сторожа
`scripts/guards/package-install-guard.fscript`, двоичный из `FLANG_BINARY`) —
`flang install` под пустым HOME ставит пакет, и его замок сходится знак в знак
с замком движка, позванного через `flang io`. Снята на двоичном, собранном из
исходника `flang/src/emit/c/flang_repl.c` поверх семени 0.7.30. В CI встаёт
вместе с печатью 9c, когда команда появится в `bootstrap/flang`.

Прогоны 25 октября 2026 (журналы — у линии пакетов):

| что | факт |
|---|---|
| `package-install:command`, двоичный семени 0.7.30 (отрицательный контроль) | код 1, `FLANG_INSTALL_PROBE`, бед 3 из 25: «неизвестная команда «install»» |
| `package-install:command`, двоичный из исходника ветки | код 0, 25 шагов, замки команды и движка знак в знак |
| двоичный из исходника один, без `scripts/` рядом | `FLANG_INSTALL_ENGINE`, код 1 |
| двоичный вне дерева, движок и библиотека в `<приставка>/share/flang/`, пустой HOME, две установки | код 0 оба раза, `flang.lock` 111 100 байт знак в знак |
| то же со службы реестра `http://127.0.0.1:8766/registry.list` | код 0 оба раза, замок совпал с замком по файлу списка |

## Прежний следующий шаг

Решить, несёт ли двоичный план с собой (тогда правка — `install.sh`,
`packaging/**` и ярлык в `flang_repl.c`) или команда пишется в `cli.flang`.
Проба, которая краснеет сегодня: `bootstrap/flang install` отвечает кодом 2.
