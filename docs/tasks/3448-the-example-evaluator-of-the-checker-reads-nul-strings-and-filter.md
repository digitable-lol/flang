# 3448. Два умения вычислителя примера

Решение: [ADR-0042](../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.

Места: `corpus-bytes` — 1 шаг «по примеру» (строка с нулевым знаком);
`corpus-cforms` — 3 шага (`отфильтровать`). В сверщике строки значений примера —
C-строки до нуля, и `отфильтровать` вычислитель примера не знает. Сделать: строка
значения хранит длину (нулевой знак — обычный знак), `отфильтровать` — по
уравнению вычислителя (`«отбор»` в `Модель.lean` уже есть); ловушка «калькулятор
снят» обязана остаться зелёной — вычислением закрывается только замкнутый пример;
пробы и порча. Граница нулевого байта уже проходилась деревом (задача 9350) —
прочитать её раньше, чем писать.
