# 3448. Два умения вычислителя примера

Решение: [ADR-0042](../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.

Места: `corpus-bytes` — 1 шаг «по примеру» (строка с нулевым знаком);
`corpus-cforms` — 3 шага (`отфильтровать`). В сверщике строки значений примера —
C-строки до нуля, и `отфильтровать` вычислитель примера не знает. Сделать: строка
значения хранит длину (нулевой знак — обычный знак), `отфильтровать` — по
уравнению вычислителя (`«отбор»` в `Модель.lean` уже есть); ловушка «калькулятор
снят» обязана остаться зелёной — вычислением закрывается только замкнутый пример;
пробы и порча. Граница нулевого байта уже проходилась деревом (задача 9350) —
прочитать её раньше, чем писать.

## Ход работы

14 сентября, исполнитель a, ветка `a/6432-6812-3448-last-places` (от main `d8b82eaf`).

**Нулевой знак.** Строка значения держит нуль двумя байтами C0 80 («изменённый
UTF-8», как в Java): строка Си его не обрезает, а знаком он остаётся одним —
`длина_знаков`, `подстрока_знаков`, равенство и вхождение идут прежним кодом.
ADR-0042 §2 предлагал хранить длину при строке; довод за перекодировку — цена:
+2 строки кода против переписи всех строковых операций вычислителя. Байт C0 в
UTF-8 не встречается никогда, и спутать его со знаком исходника нельзя. Вид 6
(«длину знаю, строки не отдаю», Ч7104) больше не заводится.

**Отбор.** «отфильтровать Л где х → У» — звено остаётся на «да», уходит на «нет»,
иное У — «не берусь»; хвост отбора, как у свёртки, отношением не режется.

**Что осталось — и почему не здесь.** У corpus-cforms за отбором стоит цепочка,
которой ADR не называл: «Первая из меток» — `разбор «метки»` по звену («случай
голова и хвост»), её итог — вариант с полем («вариант «Есть число» с «значение»
равным …»), а «Метка или ноль» разбирает этот вариант со связыванием поля. Это
ещё два умения вычислителя — разбор списка по звену и вариант с полями, —
≈ 30–40 строк кода сверх бюджета ADR-0042 (+180, съедено 166). Отказ называет
стену поимённо («в счёте встретился разбор списка по звену»). Решение — за
владельцем: третье умение строкой бюджета ADR либо три шага остаются пределом.
