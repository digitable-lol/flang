# 3449. Третье и четвёртое умения вычислителя примера

Решение: [ADR-0042](../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2 —
правило, а не вынос из знаменателя. Предшественница — задача
[3448](3448-the-example-evaluator-of-the-checker-reads-nul-strings-and-filter.md):
она научила вычислитель нулевому знаку и отбору и назвала стену, в которую
упёрся `corpus-cforms`, — «в счёте встретился разбор списка по звену».

Места: `corpus-cforms` — три шага «по примеру» («у каждой формы с помощником
есть арность», «синоним ведёт в форму с помощником», «разрешение синонима — один
шаг»). За отбором стоит цепочка «Первая из меток» — `разбор «метки»` по звену, её
итог — вариант с полем («вариант «Есть число» с «значение» равным …»), а
«Метка или ноль» разбирает этот вариант со связыванием поля.

Сделать: вычислитель считает `разбор` посчитанного списка (пусто — ветвь
`случай пусто`, звено — ветвь `случай голова и хвост` с первым звеном и
остатком) и вариант с полями (сборка — поля считаются, разбор — ветвь своего
варианта, поля на местах связанных имён). Строка ведомости «Выч», леммы Lean
«Выч-звено» и «Выч-вариант», ловушки из диапазона 50–59, согласованная подделка и
честная проба в наборе проб сверщика; строки кода — строкой бюджета в
`ХРАПОВИК.txt` с доводом.
