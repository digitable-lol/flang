# 3501. Рекурсивная функция с разбором не раскрывается на конструкторе своего варианта, а нерекурсивная раскрывается

Заявка: https://github.com/digitable-lol/flang/issues/411

`«Чередовать» от (вариант «След» с прежний равным н)` по определению равно `«Сменить» от («Чередовать» от н)` — ровно правая часть постусловия. Для нерекурсивной функции того же вида ядро этот шаг делает.

## Шаги воспроизведения

1. Программа unfold.flang:

```flang
модуль «Unfold recursive on constructor»

тип «Ч»
  вариант «Ноль»
  вариант «След» содержит прежний: «Ч»

тип «Ст»
  вариант «А»
  вариант «Б»

тотальная функция «Сменить»
  принимает сторона: «Ст»
  возвращает «Ст»
  пример «а в б»
    дано сторона равно вариант «А»
    ожидается вариант «Б»
  разбор сторона
    случай вариант «А»
      то вариант «Б»
    случай вариант «Б»
      то вариант «А»

тотальная функция «Чередовать»
  принимает н: «Ч»
  возвращает «Ст»
  пример «ноль»
    дано н равно вариант «Ноль»
    ожидается вариант «А»
  разбор н
    случай вариант «Ноль»
      то вариант «А»
    случай вариант «След» с прежний как прежний
      то «Сменить» от («Чередовать» от прежний)

тотальная функция «Шаг»
  принимает н: «Ч»
  возвращает «Ст»
  обеспечивает «шаг раскрывается» результат равно «Сменить» от («Чередовать» от н)
  пример «от ноля»
    дано н равно вариант «Ноль»
    ожидается вариант «Б»
  «Чередовать» от (вариант «След» с прежний равным н)

тотальная функция «Нерекурсивная»
  принимает н: «Ч»
  возвращает «Ст»
  пример «ноль»
    дано н равно вариант «Ноль»
    ожидается вариант «А»
  разбор н
    случай вариант «Ноль»
      то вариант «А»
    случай вариант «След» с прежний как прежний
      то «Сменить» от вариант «А»

тотальная функция «Шаг нерекурсивной»
  принимает н: «Ч»
  возвращает «Ст»
  обеспечивает «шаг нерекурсивной раскрывается» результат равно «Сменить» от вариант «А»
  пример «от ноля»
    дано н равно вариант «Ноль»
    ожидается вариант «Б»
  «Нерекурсивная» от (вариант «След» с прежний равным н)
```

2. `bootstrap/flang check unfold.flang --proof`.

## Что происходит

```
$ bootstrap/flang check unfold.flang --proof
  постусловие «шаг раскрывается» функции «Шаг» — сетка 1 значение (примеры функции): нарушений НЕ ИСКАЛИ — прогона примеров не было, посчитано только их число. Это не доказательство — теоремы при утверждении нет
  постусловие «шаг нерекурсивной раскрывается» функции «Шаг нерекурсивной» — доказано сведением цели с телом функции: правило «тождество после переписки допущением», объявленные типы аргументов не понадобились — утверждение обо ВСЕХ входах, …
unfold.flang: ПРОВЕРЕНО С ОПОРОЙ, И ОПОРА НЕ СУДИЛАСЬ (спросить: --строго) — утверждений 2: доказано 1, условно 0, сетка 1, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
код 0
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Вызов рекурсивной функции на конструкторе раскрывается один раз (ι-редукция), рекурсивный вызов внутри остаётся вызовом.

## Обходной путь

Законы на конкретных замкнутых значениях.

## Когда задача сделана

`bootstrap/flang check unfold.flang --proof` — «доказано 2», код 0. Подделка: правая часть `«Чередовать» от н` — не доказано.

## Где живёт правка

`flang/self/proof-kernel.flang` — разворот на конструкторе. Ждёт печати семени.
