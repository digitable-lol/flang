# 3536. FLANG_NOT_TOTAL на «бит минус уровень» под «если бит не меньше уровень» называет «бит» неограниченным снизу и советует не ту проверку

Заявка: https://github.com/digitable-lol/flang/issues/382

`бит` объявлен `неотрицательное`, вызов стоит под `если бит не меньше уровень`, а `требует` даёт `уровень не меньше 1`. Отказ говорит «снизу «бит» ничем не ограничен» и советует `если бит не больше 0`; настоящая причина — первая строка: `бит минус уровень` имеет тип `целое`.

## Шаги воспроизведения

1. Программа `descent.flang`:

```flang
модуль «Спуск по битам 2»

тотальная функция «Спуск то»
  принимает бит: неотрицательное, уровень: неотрицательное
  возвращает число
  требует «уровень положителен» уровень не меньше 1
  пример «восемь по три»
    дано бит равно 8
    дано уровень равно 3
    ожидается 2
  если бит не меньше уровень
    то 1 плюс («Спуск то» от (бит минус уровень) и уровень)
    иначе 0

тотальная функция «Спуск мерой»
  принимает бит: число, уровень: число
  возвращает число
  требует «уровень положителен» уровень не меньше 1
  убывает бит
  пример «восемь по три»
    дано бит равно 8
    дано уровень равно 3
    ожидается 2
  если бит не меньше уровень
    то 1 плюс («Спуск мерой» от (бит минус уровень) и уровень)
    иначе 0
```

2. `bootstrap/flang check descent.flang`.

## Что происходит

```
$ bootstrap/flang check descent.flang
descent.flang: не проверено — замечаний 2
FLANG_TYPE в файле descent.flang, строка 12, столбец 35: аргумент «бит» функции «Спуск то»: ожидался неотрицательное, получен целое
FLANG_NOT_TOTAL в файле descent.flang, строка 12, столбец 16: тотальная функция «Спуск то»: рекурсивный вызов «Спуск то» не убывает — аргумент 1 («бит» sub «уровень») уменьшает параметр «бит» на «уровень», но снизу «бит» ничем не ограничен: …
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Диагностика называет настоящую причину (вычитание не сохраняет «неотрицательное») и не советует бесполезной проверки. Лучше — `а минус б` под условием `а не меньше б` имеет тип `неотрицательное`, а при `б не меньше 1` это строгий спуск без сторожа.

## Обходной путь

`убывает бит` над `число` — со сторожем во время работы.

## Когда задача сделана

`bootstrap/flang check descent.flang` — «Спуск то» с доказанным завершением, код 0; подделка без `требует` про уровень — `FLANG_NOT_TOTAL` с верной причиной.

## Где живёт правка

`flang/self/totality.flang` (отказ и спуск), `flang/self/types.flang` (тип разности). Ждёт печати семени.
