# 3600. Работники печати простаивают, а горячая часть стадии суда идёт по порядку

## Шаги воспроизведения

1. Журнал печати 11 на gpu (`/home/u/b-print-b11-print.log`): `/usr/bin/time` — 112 % CPU,
   строк «раздача: работников» нет ни одной, а рецепт звал `emit` с `FLANG_TICKS_OUT`
   (строка «поимённая ведомость расхода печати компилятора»).
2. `fl_spread_allowed` в `flang/src/emit/c/flang_runtime.c` выключает раздачу при
   непустой `FLANG_TICKS_OUT`.
3. Замер раздачи на печатнике семени 11 с `FLANG_JOBS=16` (отладочный вывод раздачи) и
   выборка `perf` по главному потоку на стадии «Проверить доказательства».

## Что происходит

- Печать 11 не раздала ни одного отображения: рецепт печати отдаёт `emit` поимённую
  ведомость, а при ней раздачи нет.
- Там, где раздача есть, она почти ничего не даёт: «Вклады обязательств» — 13 927
  обязательств за 35 с при 16 работниках. Стадию суда держит снятие предусловий без
  теорем («Снять предусловия» → «Закрыть без теорем»), которое идёт по порядку, и
  80 % его времени — подготовка вычислителя («Подготовить») заново для каждой замкнутой
  части равенства: всю программу из 11 796 функций, с проверкой повтора имён поиском по
  списку (квадрат по числу функций).
- На стадии «Напечатать связанное» печатник для каждого вызова строит список имён всех
  функций («Есть функция с именем»), а анализ потока («Теги узла-ссылки») ищет описание
  функции по списку для каждого узла программы, хотя нужно оно только ссылкам.

## Что должно быть

Печать укладывается в час на 16 ядрах gpu; вывод печати побайтово тот же, что у суда по
порядку и у прежнего печатника.

## Когда задача сделана

- `bootstrap/flang run-script spread:check` — 12 требований, среди них раздача при
  `FLANG_TICKS_OUT`; рантайм, выключающий раздачу при ведомости, краснеет.
- Печатник, собранный из напечатанного с правкой, печатает то же дерево побайтово так же,
  как печатник семени 11, и одинаково при `FLANG_JOBS=1` и `FLANG_JOBS=16`.
- Оценка печати по стадиям с правкой на 16 ядрах gpu — не больше 3600 с.

## Где живёт правка

`flang/src/emit/c/flang_runtime.c` (раздача и ведомость), `flang/self/interpret.flang`,
`flang/self/proof-kernel.flang`, `flang/self/totality.flang`, `flang/self/emit-c.flang`,
`flang/concurrency/bench/spread-map.fscript`, ADR-0218 §5.

## Чем закрыта

Ветка `a/spread-workers-engage`: ведомость при раздаче (`flang_runtime.c`, `spread:check` —
12 требований), подготовка вычислителя один раз на равенство, поиск без списка имён в
печатнике и анализе потока. Замер и оценка — ADR-0218 §5. Последний пункт «Когда задача
сделана» — оценка (около 2900 с на gpu), замер даст печать 13.
