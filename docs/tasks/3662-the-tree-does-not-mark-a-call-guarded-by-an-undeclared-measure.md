# 3662. Дерево `flang ast` не отмечает вызов, который печать сторожит мерой без объявления

## Шаги воспроизведения

1. Программа `implicit-measure.flang`:

```
модуль «Implicit measure»

тотальная функция «Сумма до»
  принимает н: число
  возвращает число
  если н не больше 0
    то 0
    иначе н плюс («Сумма до» от (н минус 1))
```

2. Команды:

```
bootstrap/flang run implicit-measure.flang --function 'Сумма до' --args '{"н":1e17}'
bootstrap/flang ast implicit-measure.flang
bootstrap/flang run-script translation:validate -- --path implicit-measure.flang
```

3. Смотреть: ответ вычислителя, узел `call` в дереве, строку «СИМВОЛЬНО НЕ СОШЛОСЬ».

## Что происходит

```
$ bootstrap/flang run implicit-measure.flang --function 'Сумма до' --args '{"н":1e17}'
FLANG_MEASURE: тотальная функция «Сумма до»: мера не убыла — аргумент 1 вызова
«Сумма до» не стал меньше параметра «н». …                     код 1
```

Язык сторожит спуск: вычислитель и напечатанный C (`если шаг < н то шаг иначе «мера убывает»`)
отказывают `FLANG_MEASURE`, когда довод рекурсивного вызова не стал меньше параметра. В дереве
`flang ast` у этого вызова поля `descent` нет: о стороже говорит только строка прозы в `measures`
верхнего уровня. Эталон `flang/proof/lean/Semantics/Json.lean` ставит сторожа по `descent`, поэтому
здесь его не ставит: на `н = 1e17` он считает, пока не кончится топливо, а символьное дерево
эталона расходится с деревом C. Проверка перевода говорит «СИМВОЛЬНО НЕ СОШЛОСЬ», и функция
остаётся на свидетелях. В `docs/examples` так у 12 функций (`tutorial` «Сумма до», «Чанки кусками»
в `web/shortener` и `service-on-processes`, «Шагов Коллатца в пределе»).

Версия: flang 0.7.34.

## Что должно быть

Каждый вызов, который печать и вычислитель сторожат мерой, несёт в дереве `descent` с теми же
полями, что у объявленной меры (`current`, `next`, `calleeParams`, `proved`), — тогда эталон
проверяет меру теми же тремя условиями и деревья сходятся (`docs/translation-validation.ru.md`,
«Символьное сравнение»).

## Обходной путь

Объявить меру словом `убывает`: такой вызов дерево отмечает.

## Когда задача сделана

`bootstrap/flang run-script translation:validate -- --path implicit-measure.flang` отвечает
«символьно не сошлось 0», и «Сумма до» стоит среди доказанных символьно.

## Где живёт правка

Печать дерева в `flang/self` (отметка спуска у вызова с выведенной мерой). Правка под `flang/self`
доезжает до двоичного перепечаткой самосборной части.
