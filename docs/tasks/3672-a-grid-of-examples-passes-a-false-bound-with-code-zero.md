# 3672. «Сетка» недоказанного постусловия — только примеры автора: ложная граница, которую пример не задевает, проходит с «нарушено 0» и кодом 0

Заявка: https://github.com/digitable-lol/flang/issues/409

`check --proof` без `--строго` отвечает кодом 0 и «ПРОВЕРЕНО С ОПОРОЙ» на постусловии `результат не больше 510` при теле, дающем 511 на любом `значение больше 100`. Строка называет сеткой одно значение примера и пишет «прогона примеров не было», хотя примеры `check` прогоняет и постусловие на них проверяет. Ядро это постусловие не берёт: вызывающему оно фактом не становится, и `run` без `--на-веру` отказывает.

## Шаги воспроизведения

1. Программа `grid.flang`:

```flang
модуль «GridProbe»

тотальная функция «Прямо»
  принимает значение: число
  возвращает неотрицательное
  обеспечивает «ложная граница прямо» результат не больше 510
  пример «три прямо»
    дано значение равно 3
    ожидается 0
  если значение больше 100 то 511 иначе 0
```

2. `bootstrap/flang check grid.flang --proof`.

## Что происходит

```
$ bootstrap/flang check grid.flang --proof
  постусловие «ложная граница прямо» функции «Прямо» — сетка 1 значение (примеры функции): нарушений НЕ ИСКАЛИ — прогона примеров не было, посчитано только их число. Это не доказательство — теоремы при утверждении нет
grid.flang: ПРОВЕРЕНО С ОПОРОЙ, И ОПОРА НЕ СУДИЛАСЬ (спросить: --строго) — утверждений 1: доказано 0, условно 0, сетка 1, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
код 0
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Для числовых аргументов сетка берёт края и степени двойки (0, 1, −1, 2^k, 2^k ± 1, 2^53 − 1) и найденный контрпример печатает «НАРУШЕНО» с кодом 1. Строка о сетке говорит правду о том, что прогнано.

## Обходной путь

`--строго`: код 3.

## Когда задача сделана

`bootstrap/flang check grid.flang --proof` — «НАРУШЕНО … значение = 101 (или другое)», код 1. Верная граница 511 — по-прежнему доказана.

## Где живёт правка

`flang/self/bootstrap/compiler.flang` («Опровержения постусловий»); пробы — `flang/proof/probes/strict/programs/false-bound-*.flang`, `bound-*.flang`, `int-midpoint-overflows.flang`. Ждёт печати семени.
