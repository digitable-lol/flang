# 3740. Проверка emit-law:check не сходится за разумный срок: в её корпусе файлы, чья проверка сама длится минуты

## Шаги воспроизведения

1. Команда ярлыка `emit-law:check` из `.flangrc` (в ведомости она с ключом
   `--на-веру`; `--trust` — его латинский двойник, ADR-0045):

```
timeout 60 bootstrap/flang io scripts/targets/emit-law.fscript --trust
```

2. Один файл из её корпуса отдельно:

```
timeout 60 bootstrap/flang check flang/stdlib/datetime.flang
```

3. Смотреть код возврата: 124 означает, что минута кончилась раньше вердикта.
4. Тот же прогон с пятью минутами — столько ей отводит раздел «Когда задача
   сделана»: `timeout 300 bootstrap/flang io scripts/targets/emit-law.fscript --trust`.

## Что происходит

```
$ timeout 60 bootstrap/flang io scripts/targets/emit-law.fscript --trust
на веру: доказанность не считалась — запуск по ключу --trust
                                                                 код 124
$ timeout 60 bootstrap/flang check flang/stdlib/datetime.flang
шагов 517 089 575 из 4 000 000 000 000 (0 %), идёт «Проверить доказательства с кешем», 144 МиБ
                                                                 код 124
$ timeout 300 bootstrap/flang io scripts/targets/emit-law.fscript --trust
                                                      код 124 за 300,05 с
```

Корпус проверки — пятнадцать путей, набранных руками в `scripts/targets/emit-law.fscript`
(функция с постусловием «списки дерева на месте»): восемь из `flang/stdlib/` и семь из
`docs/examples/`. Каждый файл проходит `flang check` и `flang emit` отдельными
процессами. Уже `check` одного `flang/stdlib/datetime.flang` не укладывается в минуту,
так что проверка целиком стоит десятки минут и в наборе быстрых проверок не запускается.
Сверх того шесть путей корпуса ведут в несуществующий каталог docs/examples/cat/
(файлы теории категорий лежат в `flang/ct/`), и перепись `sh scripts/guards/hand-written-lists.sh`
называет эту строку: `ПУТИ scripts/targets/emit-law.fscript:25   6 из 15   нет:
docs/examples/cat/crdt-merge.flang … order-shipment.flang` (код 0).

## Что должно быть

`bootstrap/flang run-script emit-law:check` отвечает кодом 0 или 1 за время, за которое её действительно
будут гонять перед отправкой (порядка минуты), — иначе закон, который она стережёт,
никем не проверяется. Заголовок `scripts/targets/emit-law.fscript` обещает: «код
возврата 0 — два входа одного двоичного судят одинаково; 1 — разошлись».

## Обходной путь

Гонять проверку без ограничения времени в отдельном долгом прогоне; либо сократить
корпус в собственной копии сценария до файлов, чья проверка укладывается в секунды.

## Когда задача сделана

```
timeout 300 bootstrap/flang io scripts/targets/emit-law.fscript --trust
                                                                 код 0
```

Все пути корпуса существуют в дереве (перепись `sh scripts/guards/hand-written-lists.sh`
эту строку больше не называет). Причина медленности названа числом: сколько секунд
стоит каждый файл корпуса и какой из них держит общую цену. Проба: у функции корпуса
есть пример, который краснеет, если в корпус попадает файл дороже названного порога,
либо проверка получает ключ предела времени на файл и отвечает кодом 1 с именем
файла, а не молчит.

## Где живёт правка

`scripts/targets/emit-law.fscript`: функция корпуса (постусловия «списки дерева на
месте», «слияние CRDT на месте») и функции, строящие вызовы «суд зовётся check» и
«печать зовётся emit». Если дорог сам `flang check` библиотечных файлов, правка уходит
в ядро доказательств (`flang/self/`) и доезжает до двоичного только пересборкой семени
(bootstrap regeneration); правка одного сценария пересборки не требует.

Отдельная задача, здесь не решается: цена независимой проверяющей программы (proof
checker) за `запись:проверка` — задача 8466; `точка:проверка` — задача 6267.
