# 3791. Отказ рассуждения не называет средний терм

## Шаги воспроизведения

Язык здесь знать не нужно: надо собрать двоичный и написать текст по-русски.

1. Собрать двоичный (около двух минут):

   ```sh
   make -C bootstrap -j4 CFLAGS='-std=c99 -O2' flang
   ```

2. Написать в корне дерева файл `diplom.txt`. Первые три строки — словарь: какие слова
   употреблены и в каких формах (этого требует §6
   [ADR-0050](../adr/0050-a-reasoning-is-written-as-declared-words-and-fixed-sentences.md));
   после пустой строки — три предложения:

   ```sh
   cat > diplom.txt <<'EOF'
   Понятие: студент, студенты.
   Свойство: учится хорошо, учатся хорошо.
   Имя: Николай.

   Все студенты учатся хорошо. Николай учится хорошо. Следовательно, Николай — студент.
   EOF
   ```

3. Позвать судью:

   ```sh
   bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Judge -- diplom.txt
   ```

4. Смотреть код возврата и поле `result`. Ответ приходит одной строкой JSON; по строкам его
   читает

   ```sh
   bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Judge -- diplom.txt \
     | sed -n 2p | python3 -c 'import json,sys;print(json.load(sys.stdin)["result"])'
   ```

## Что происходит

```
$ bootstrap/flang io .../syllogism/sentences/run.fscript --plan Judge -- diplom.txt
1. посылка: Все студенты учатся хорошо.
2. посылка: Николай учится хорошо.
3. заключение: Следовательно, Николай — студент.
НЕ СЛЕДУЕТ: предложение 3 «Следовательно, Николай — студент.» не выведено из посылок 1, 2
ядро: FLANG_PROOF_STEP, строка 16 проверенной программы — цель не выведена из допущений теоремы
пример против, подсказка переводчика, ядром не проверена — «Николай»: студент — нет,
учится хорошо — да                                                                    код 1
```

Ответ верен и бесполезен: он говорит, что вывода нет, и не говорит, чего в рассуждении не
хватает. «Учится хорошо» стоит сказуемым в обеих посылках — средний терм не распределён ни в
одной, и именно это губит вывод. Слов «средний терм» в ответе нет.

Тот же ответ, слово в слово по форме, приходит на беду другой породы — когда у посылок вообще
нет общего терма («Все студенты учатся хорошо. Николай — спортсмен. Следовательно, Николай
учится хорошо.»): `НЕ СЛЕДУЕТ … не выведено из посылок 1, 2`, `FLANG_PROOF_STEP`, пример
против, код 1. Различить две беды по ответу нельзя.

Слова «средний терм» в наборе нет ни одного раза: `grep -ric средн flang/proof/probes/syllogism/`
— 0 строк; `grep -c терм …/sentences/translator.flang` — 0.

Версия: `flang 0.7.23`. Прогон 2 октября 2026.

## Что должно быть

Отказ называет беду поимённо, одной строкой рядом с «НЕ СЛЕДУЕТ»: средний терм рассуждения
назван и сказано, что с ним не так — не распределён ни в одной посылке, либо его нет вовсе.
§6 ADR-0050 обещает при отказе только пример против; имени беды не обещает никто, поэтому это
не починка, а недостающая работа — она и просится картой «Чего в языке нет вовсе».

Распределённость среднего терма считается по уже разобранным суждениям, до зова ядра:
у переводчика на руках `список «Judgment»` с формой («All», «None», «Some», «Some not», «Is»),
подлежащим и сказуемым каждого предложения. Ядро для этого править не надо.

## Обходной путь

Читать строку «пример против»: в ней видно, какие признаки предмета посылки не вынуждают.
В примере выше `студент — нет, учится хорошо — да` означает, что Николай может учиться хорошо
и не быть студентом. Беду из этого надо догадаться самому; словами она не названа.

## Когда задача сделана

Прогон шага 3 на `diplom.txt` печатает строку, которая называет средний терм и его беду, и
код остаётся 1. В наборе `flang/proof/probes/syllogism/sentences/` стоит текст с этой бедой и
строка о нём в `expected.tsv`, так что проба краснеет, если имя беды из ответа уйдёт:

```sh
bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Binary
```

Сегодня этот прогон отвечает `syllogism/sentences: проб 14, разошлось 0`, код 0.

## Где живёт правка

`flang/proof/probes/syllogism/sentences/translator.flang` — функция «Verdict of» (ветвь
«Does not follow») и новая чистая функция о распределённости по `список «Judgment»`;
`flang/proof/probes/syllogism/sentences/expected.tsv` и новый текст в `texts/`. Переводчик
лежит вне `flang/self/**` и вне доверенной базы, поэтому перепечатки семени правка не требует:
двоичный её получает пересборкой `bootstrap`.
