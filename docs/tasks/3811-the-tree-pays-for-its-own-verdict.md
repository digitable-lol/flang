# 3811. Инструменты дерева и его точка входа «ярлыки.flang» не проходят вердикт о доказанности и запускаются на веру

## Шаги воспроизведения

1. Спросить вердикт точки входа, не запуская работы (плана с таким именем
   нет, двоичный считает вердикт и останавливается):

```
bootstrap/flang io ярлыки.flang --plan НетТакогоПлана1234
bootstrap/flang check ярлыки.flang --proof
```

2. Посчитать инструменты, записанные в долг:

```
bootstrap/flang io scripts/guards/run-verdict-debt-guard.fscript --plan Проверка
```

## Что происходит

```
$ bootstrap/flang io ярлыки.flang --plan НетТакогоПлана1234
не доказано: утверждений 17: доказано 14, сетка 3, на веру 0 — запуск только по явному согласию: --trust
                                                                  код 3
$ bootstrap/flang check ярлыки.flang --proof
  постусловие «названный судьёй ярлык существует» функции «Судит о доказательствах» — сетка 3 значения …
  постусловие «файл узнан только по четырём окончаниям» функции «Слово о файле» — сетка 3 значения …
  постусловие «всякое из четырёх окончаний узнано» функции «Слово о файле» — сетка 3 значения …
$ bootstrap/flang io scripts/guards/run-verdict-debt-guard.fscript --plan Проверка
  записей в ведомости: 51
  потолок записей: 51
  вызовов с ключом «--на-веру»: 92, без ключа: 131
  записей, которых в дереве не зовут: 1 (flang/proof/probes/orders/programs/arguments.fscript)
СОШЛОСЬ: согласие названо ровно там, где нужно                    код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

`./ярлык` работает (код 0) только потому, что зовёт двоичный с ключом
`--на-веру`. В `flang/scripts/run-verdict-debt.tsv` записан 51 инструмент
дерева, который вердикта не проходит; больше всего их в `scripts/guards` (23)
и `flang/scripts` (9). Учёт долга устроен и проверяется: вызов каждого такого
инструмента называет ключ, число записей ограничено потолком в
`flang/scripts/run-verdict-debt-ceiling.tsv`, проверка стоит в
`.githooks/pre-push.fscript`.

Два постусловия «Слова о файле» после подстановки тела функции становятся
тождественно истинными (`не Д или Д`), но ядро доказательств этого не узнаёт.
У записи `flang/proof/probes/orders/programs/arguments.fscript` причина другая: постусловие говорит
`результат содержит …`, а правил вывода о слове `содержит` для подстроки нет.
Причины остальных записей не разобраны; столбец «секунд» ведомости показывает,
сколько стоит вердикт каждого.

## Что должно быть

Инструменты дерева проходят тот же вердикт, которого ADR-0045 требует от
любой программы перед `run` и `io`, и запускаются без `--на-веру`.

## Обходной путь

Ключ `--на-веру` в командной строке каждого такого вызова; он уже стоит.

## Когда задача сделана

- `bootstrap/flang io ярлыки.flang --plan НетТакогоПлана1234` отвечает
  «доказано: утверждений N», и `ярлык` зовёт двоичный без `--на-веру`;
- в `flang/scripts/run-verdict-debt.tsv` не осталось записей, действующий
  потолок в `flang/scripts/run-verdict-debt-ceiling.tsv` равен 0;
- каждая снятая запись опускает потолок тем же изменением, а утверждение
  остаётся содержательным: доказанное постусловие не заменено повтором тела;
- проверка из шага 2 отвечает кодом 0 и печатает «записей, которых в дереве
  не зовут: 0»; она краснеет, если ключ вернулся к инструменту, которого нет
  в ведомости, или исчез у записанного.

Работа делится по записям ведомости: один инструмент — одно изменение.

## Где живёт правка

Сами инструменты: `ярлыки.flang`, `ярлык`, планы в `scripts/guards`,
`flang/scripts`, `scripts/site` и остальные файлы из
`flang/scripts/run-verdict-debt.tsv`; вызовы в `.github/workflows` и
`ярлыки.flang`. Переписать тело или постусловие инструмента — без пересборки
семени. Новое правило ядра (тождественно истинная цель после подстановки
тела, подстрока в `содержит`) живёт в каталоге `flang/self` и доезжает до двоичного
только пересборкой семени (bootstrap regeneration).

Отдельная задача, здесь не решается: проверка долга не читает вызовы из
`.githooks` и остаётся зелёной при записи ведомости, которую в дереве никто
не зовёт.
