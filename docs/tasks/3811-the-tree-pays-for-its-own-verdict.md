# 3811. 49 инструментов дерева не проходят вердикт о доказанности и запускаются на веру

## Шаги воспроизведения

1. Спросить вердикт одного записанного в долг инструмента, не запуская работы
   (плана с таким именем нет, двоичный считает вердикт и останавливается), и
   посмотреть, какое утверждение его держит:

```
bootstrap/flang io flang/proof/probes/orders/programs/arguments.fscript --plan НетТакогоПлана1234
bootstrap/flang check flang/proof/probes/orders/programs/arguments.fscript --proof
```

2. Посчитать инструменты, записанные в долг:

```
bootstrap/flang io scripts/guards/run-verdict-debt-guard.fscript --plan Проверка
```

## Что происходит

```

не доказано: утверждений 1: доказано 0, сетка 1, на веру 0 — запуск только по явному согласию: --trust
                                                                  код 3
$ bootstrap/flang check flang/proof/probes/orders/programs/arguments.fscript --proof
  постусловие «в отчёте названо число доводов» функции «Отчёт» — сетка 2 значения
  (примеры функции): нарушений НЕ ИСКАЛИ … Это не доказательство — теоремы при
  утверждении нет
$ bootstrap/flang io scripts/guards/run-verdict-debt-guard.fscript --plan Проверка
  записей в ведомости: 49
  потолок записей: 49
  вызовов с ключом «--на-веру»: 88, без ключа: 218
  целей найдено в дереве: 157, вызовов: 306
  вызовов на переменной (имени цели нет): 2 в 2 файлах, записано 2
  записей, которых в дереве не зовут: 1 (flang/proof/probes/orders/programs/arguments.fscript)
СОШЛОСЬ: согласие названо ровно там, где нужно                     код 0
```

В `flang/scripts/run-verdict-debt.tsv` записано 49 инструментов дерева, которые
вердикта не проходят; больше всего их в `scripts/guards` (23) и `flang/scripts`
(9). Каждый такой вызов называет ключ `--на-веру`: из 88 вызовов 51 стоит в
`.flangrc`, 29 в `.github/workflows`, остальные в прочих файлах дерева. Учёт
долга устроен и проверяется: число записей ограничено потолком в
`flang/scripts/run-verdict-debt-ceiling.tsv`, проверка стоит в
`.githooks/pre-push.fscript`.

У записи `flang/proof/probes/orders/programs/arguments.fscript` причина названа:
постусловие говорит `результат содержит …`, а правил вывода о слове `содержит`
для подстроки нет. Причины остальных записей не разобраны; столбец «секунд»
ведомости показывает, сколько стоит вердикт каждого, и разброс велик —
`flang/scripts/proof-ledger.fscript` 1762 с и `flang/scripts/word-guard.fscript`
1732 с против 0,2 с у пробы доводов.

## Что должно быть

Инструменты дерева проходят тот же вердикт, которого ADR-0045 требует от
любой программы перед `run` и `io`, и запускаются без `--на-веру`.

## Обходной путь

Ключ `--на-веру` в командной строке каждого такого вызова; он уже стоит.

## Когда задача сделана

- в `flang/scripts/run-verdict-debt.tsv` не осталось записей, действующий
  потолок в `flang/scripts/run-verdict-debt-ceiling.tsv` равен 0;
- каждая снятая запись опускает потолок тем же изменением, а утверждение
  остаётся содержательным: доказанное постусловие не заменено повтором тела;
- проверка из шага 2 отвечает кодом 0 и печатает «записей, которых в дереве
  не зовут: 0»;
- `bootstrap/flang io scripts/guards/run-verdict-debt-guard.fscript --plan Подлог`
  по-прежнему отвечает «подлог пойман»: сторож краснеет и когда ключ стоит у
  цели, которой в ведомости нет, и когда у записанной цели ключа не стало.

Работа делится по записям ведомости: один инструмент — одно изменение.

## Где живёт правка

Сами инструменты: планы в `scripts/guards`, `flang/scripts`, `scripts/site` и
остальные файлы из `flang/scripts/run-verdict-debt.tsv`; вызовы — короткие
команды `script.*` в `.flangrc` и шаги в `.github/workflows`. Переписать тело
или постусловие инструмента — без пересборки семени. Новое правило ядра
(подстрока в `содержит`) живёт в каталоге `flang/self` и доезжает до двоичного
только пересборкой семени (bootstrap regeneration).

Отдельная задача, здесь не решается: проверка долга не читает вызовы из
`.githooks` и остаётся зелёной при записи ведомости, которую в дереве никто
не зовёт.
