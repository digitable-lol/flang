# 3967. Сверщик отвечает «НЕ СОШЛОСЬ» на индукцию по встроенному списку, которую ядро называет доказанной

Заявка: https://github.com/digitable-lol/flang/issues/391

Ядро доказывает «правилен» индукцией по «список». Сверщик ищет объявление типа довода в исходнике, не находит его у встроенного `список` и называет причину «такого довода у функции нет».

## Шаги воспроизведения

1. Программа predicate.flang:

```flang
модуль «Проба предиката»

тип «Эндпойнт»
  вариант «Простаивает»
  вариант «Ждут» содержит очередь: список неотрицательное

тотальная функция «Правилен»
  принимает эп: «Эндпойнт»
  возвращает признак
  пример «простой»
    дано эп равно вариант «Простаивает»
    ожидается да
  разбор эп
    случай «Простаивает»
      то да
    случай вариант «Ждут» с очередь как о
      то (длина о) больше 0

тотальная функция «Простой»
  принимает н: неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «любой»
    дано н равно 1
    ожидается вариант «Простаивает»
  вариант «Простаивает»

тотальная функция «Из одного»
  принимает н: неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «один»
    дано н равно 1
    ожидается вариант «Ждут» с очередь равным [1]
  вариант «Ждут» с очередь равным [н]

тотальная функция «Снять первого»
  принимает о: список неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «два»
    дано о равно [4, 5]
    ожидается вариант «Ждут» с очередь равным [5]
  разбор о
    случай пусто
      то вариант «Простаивает»
    случай голова и хвост
      то «По хвосту» от хвост

тотальная функция «По хвосту»
  принимает ост: список неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «пусто»
    дано ост равно []
    ожидается вариант «Простаивает»
  разбор ост
    случай пусто
      то вариант «Простаивает»
    случай голова и хвост
      то вариант «Ждут» с очередь равным ост
```

2. `bootstrap/flang check predicate.flang --proof --строго`.
3. `bootstrap/flang check predicate.flang --proof --record predicate.запись`, затем `flang/proof/checker/сверщик predicate.flang predicate.запись`.

## Что происходит

```
$ bootstrap/flang check predicate.flang --proof --строго
predicate.flang: ДОКАЗАНО — утверждений 4: доказано 4, условно 0, сетка 0, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
predicate.flang: НЕЗАВИСИМО НЕ ПРОВЕРЕНО — сверщик не сошёлся с записью (код 1; файлу с ввозом сверщику нужны записи ввезённых модулей ключом --зависимость): все 4 доказанных стоят на слове ядра
код 0
$ flang/proof/checker/сверщик predicate.flang predicate.запись
НЕ СОШЛОСЬ: теорема «правилен»: у довода «о» объявления типа в исходнике нет — строке «объявление встроенный «список» варианты «пусто» 0 «голова и хвост» 1» сверять не с чем
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Сверщик проигрывает индукцию по встроенному `список` по доводу функции и отвечает кодом 0 (или 3, если чего-то не взялся проверить).

## Обходной путь

Нет.

## Когда задача сделана

`flang/proof/checker/сверщик predicate.flang predicate.запись` — код 0 или 3, не 1. Подделка: запись с индукцией по несуществующему доводу — код 1.

## Где живёт правка

`flang/proof/checker/checker.c` — объявления встроенных типов при сверке принципа. Без печати семени.
