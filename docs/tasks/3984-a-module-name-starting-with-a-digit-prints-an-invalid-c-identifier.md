# 3984. Модуль с именем, начинающимся с цифры, печатается в C, который не собирается

## Шаги воспроизведения

1. Программа из дерева с модулем «100 doors»:
   `docs/examples/rosetta/hundred-doors.flang`.
2. Напечатать в C и собрать:

```
bootstrap/flang emit docs/examples/rosetta/hundred-doors.flang --target c --out <каталог>
make -C <каталог>
```

То же даёт `docs/examples/rosetta/hundred-doors-english.flang`.

## Что происходит

```
$ bootstrap/flang emit docs/examples/rosetta/hundred-doors.flang --target c --out <каталог>
                                                                  код 0
$ make -C <каталог>
100_doors.h:7:9: error: macro names must be identifiers
100_doors.c:21:11: error: invalid suffix '_doors_pripisat_v_nachalo' on integer constant
                                                                  код 2
```

Снято 2026-10-11 на flang 0.7.25; [ADR-0081](../adr/0081-printed-code-follows-the-canon-of-its-target.md)
(печать по канону цели) закрепляет транслитерацию в ASCII-идентификаторы, но о
ведущей цифре не говорит.

Имя модуля становится приставкой всех имён C: `100_doors_call`,
`100_doors_entry`, страж заголовка `100_DOORS_H`. Идентификатор C с цифры
начинаться не может (C99 §6.4.2.1).

## Что должно быть

`emit --target c` печатает программу, которая собирается `make` с кодом 0,
для любого допустимого имени модуля. Цели `go` и `js` ту же программу печатают
и собирают без ошибок.

## Обходной путь

Назвать модуль так, чтобы имя не начиналось с цифры.

## Когда задача сделана

```
bootstrap/flang emit docs/examples/rosetta/hundred-doors.flang --target c --out <каталог>
make -C <каталог>                                                код 0
```

То же для `hundred-doors-english.flang`. У функции, строящей приставку, есть
пример с именем «100 doors», и он краснеет, если ведущая цифра вернётся.

## Где живёт правка

`flang/self/emit-c.flang`: «Змейка» (строит имя из слов), «Префикс программы»,
«Обойти занятое целью C». До двоичного правка доезжает перепечаткой семени.

## Следующий шаг

`flang/self/emit-c.flang`, «Префикс программы»: если первый знак приставки — цифра,
ставить перед ней подчёркивание или букву (и то же для стража заголовка), с примером
на имени «100 doors». Проба, которая краснеет сегодня: `make -C <каталог>` после
`emit docs/examples/rosetta/hundred-doors.flang --target c` — две ошибки выше, код 2.
