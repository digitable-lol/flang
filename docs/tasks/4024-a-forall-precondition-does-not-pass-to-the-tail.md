# 4024. Предусловие «для всех э из элементы» не переходит на хвост из образца, и рекурсия по списку с инвариантом отвергается FLANG_PRECONDITION_CALL

Заявка: https://github.com/digitable-lol/flang/issues/389

После `разбор элементы … случай голова и хвост` вызов самой себя от `хвост` не снимает `для всех э из хвост: P`, хотя `хвост` — часть `элементы`. То же внутри `отобразить нити как з → …`: для `з` предусловие списка не берётся.

## Шаги воспроизведения

1. Программа `tail.flang`:

```flang
модуль «Проба хвоста»

тотальная функция «Сумма положительных»
  принимает элементы: список неотрицательное
  требует «все положительны» для всех э из элементы: э больше 0
  возвращает число
  пример «два»
    дано элементы равно [1, 2]
    ожидается 3
  разбор элементы
    случай пусто
      то 0
    случай голова и хвост
      то голова плюс («Сумма положительных» от хвост)
```

2. `bootstrap/flang check tail.flang`.

## Что происходит

```
$ bootstrap/flang check tail.flang
tail.flang: не проверено — замечаний 1
FLANG_PRECONDITION_CALL в файле tail.flang, строка 14, столбец 23: вызов «Сумма положительных» в функции «Сумма положительных» не снимает предусловие «все положительны»: все элементы по построению не проходят: список цели собран не так, чтобы свойство стояло у каждого его элемента по построению. Выв …
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

При `разбор Л … случай голова и хвост` из допущенного `для всех х из Л: P(х)` выводятся `P(голова)` и `для всех х из хвост: P(х)`; в теле `отобразить Л как з → …` известно `P(з)`.

## Обходной путь

Вложить инвариант в тип (обязательное поле «первая») или перенести условие в импликацию постусловия.

## Когда задача сделана

`bootstrap/flang check tail.flang --proof` — код 0. Подделка: предусловие о другом списке, чем разбираемый, — `FLANG_PRECONDITION_CALL`. `P(голова)` доступен в ветви и доказывает `обеспечивает` о голове.

## Где живёт правка

`flang/self/proofterm.flang` — снятие предусловий на месте вызова. Ждёт печати семени.
