# 4028. Условие ветви «то» не становится фактом и на точных типах: «если а больше б то а иначе б» доказано «не меньше а» и не доказано «не меньше б»

Заявка: https://github.com/digitable-lol/flang/issues/390

Над `число` условие ветви фактом быть не может (на NaN ложны обе стороны сравнения). Над `неотрицательное`, `целое`, точными дробями и `длина` NaN недостижим, но условие ветви `то` ядро по-прежнему не берёт, а `не У` ветви `иначе` берёт.

## Шаги воспроизведения

1. Программа max.flang:

```flang
модуль «Проба большего»

тотальная функция «Большее»
  принимает а: неотрицательное, б: неотрицательное
  возвращает неотрицательное
  обеспечивает «не меньше первого» результат не меньше а
  обеспечивает «не меньше второго» результат не меньше б
  пример «три и пять»
    дано а равно 3
    дано б равно 5
    ожидается 5
  если а больше б то а иначе б
```

2. `bootstrap/flang check max.flang --proof`.

## Что происходит

```
$ bootstrap/flang check max.flang --proof
  постусловие «не меньше первого» функции «Большее» — доказано по объявленным типам аргументов: цель сведена правилом «разбор цели по условию» — утверждение обо ВСЕХ входах, а не о написанных; теоремы при нём нет и не нужно
  постусловие «не меньше второго» функции «Большее» — сетка 1 значение (примеры функции): нарушений НЕ ИСКАЛИ — прогона примеров не было, посчитано только их число. Это не доказательство — теоремы при утверждении нет
max.flang: ПРОВЕРЕНО С ОПОРОЙ, И ОПОРА НЕ СУДИЛАСЬ (спросить: --строго) — утверждений 2: доказано 1, условно 0, сетка 1, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
код 0
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

В `если У то А иначе Б` условие `У` — факт в ветви `то`, когда операнды сравнения точных типов. Над `число` поведение прежнее. Решение записывается ADR рядом с ADR-0098.

## Обходной путь

Повторить сравнение так, чтобы нужный факт стоял в ветви `иначе`.

## Когда задача сделана

`bootstrap/flang check max.flang --proof` — оба постусловия доказаны; «Снять первого» с `если (длина хвост) равно 0` доказано. Подделка `если а больше б то б иначе а` — не доказано. Тот же файл над `число` — без изменений.
