# 4046. Примеры проверки спек не прогоняет ни один ярлык, и доходит ли их прогон до конца, не измерено

## Шаги воспроизведения

1. Сосчитать примеры в проверке спек и ярлыки, которые её зовут:

```
grep -ac '^ *пример ' fspec/guard.flang
grep -ao '"спеки:[^"]*"' ярлыки.flang | sort -u
```

2. Прогнать примеры:

```
bootstrap/flang test fspec/guard.flang
```

## Что происходит

```
$ grep -ac '^ *пример ' fspec/guard.flang
138
$ grep -ao '"спеки:[^"]*"' ярлыки.flang | sort -u
"спеки:подлог"
"спеки:проверка"
$ timeout 60 bootstrap/flang test fspec/guard.flang
шагов 4 227 138 949 из 4 000 000 000 000 (0 %), идёт «Прогон примеров исходников», 353 МиБ
                                                                        код 124
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026. За минуту прогон не
кончился и был снят; дошёл бы он до конца и за какое время — не перепроверено:
прогон дольше минуты.

Ярлык `спеки:проверка` зовёт `bootstrap/flang io fspec/guard.flang --на-веру`:
это исполнение плана, примеры при нём не считаются. Ярлык `спеки:подлог` зовёт
`fspec/forgery.flang`. Примеры самого `fspec/guard.flang` не запускает ничто.
Прежний двоичный обрывал этот прогон на пределе в миллиард шагов отказом
FLANG_RECURSION_LIMIT; у сегодняшнего предел выше, и за минуту прогон проходит
четыре миллиарда шагов без отказа.

## Что должно быть

Примеры проверки спек прогоняются до конца ярлыком с кодом 0: проверка, о
которой неизвестно, работает ли она сама, ничего не удостоверяет. Справка
`bootstrap/flang test --help` называет ключи `--max-steps N` и `--max-depth N`
— ими предел задаётся, если умолчания не хватит.

## Обходной путь

Обходного пути нет: примеры не запускаются нигде.

## Когда задача сделана

В `ярлыки.flang` есть ярлык `спеки:примеры`, он зовёт
`bootstrap/flang test fspec/guard.flang` с названным пределом шагов, доходит до
конца с кодом 0 и печатает число прошедших примеров — 138 или столько, сколько
их в файле в тот день. В описании ярлыка названы время и память прогона.
Нарочно испорченный пример делает ярлык красным. Если прогон не доходит и с
поднятым пределом, примеры разложены по нескольким файлам либо в задаче записан
прогон, показывающий, что именно мешает.

## Где живёт правка

`ярлыки.flang` — новый ярлык; при необходимости `fspec/guard.flang` — деление
примеров по файлам. Оба файла двоичный читает с диска, пересборка семени
(bootstrap regeneration) не нужна.
