# 4096. «Числа до» из lists.flang стоит квадрат шагов под flang test и run — её обещания пересчитывают её же

Заявка: https://github.com/digitable-lol/flang/issues/160 — программа из
заявки зовёт «Числа до» от числа лексем файла.

## Шаги воспроизведения

1. Программа:

   ```
   модуль «Проба»
     использует «Lists» из "lists.flang" только «Числа до»

   тотальная функция «Синтетика числами до»
     принимает сколько: число
     возвращает число
     длина («Числа до» от сколько)
   ```

   рядом копия `flang/stdlib/lists.flang`.
2. `flang run probe.flang --trust --function "«Синтетика числами до»" --args '{"сколько": N}'`
   для N = 100, 200, 400, 500, 1000.
3. Смотреть время и пик памяти (`/usr/bin/time -f '%e s %M KB'`).

## Что происходит

```
N=100   8,58 с
N=200   9,98 с
N=400  18,39 с
N=500  24,30 с   347 900 КБ
N=1000 78,74 с   370 472 КБ                                код 0
```

Подготовка прогона — 7,45–8,20 с: функция, сразу возвращающая 0, — 8,20 с,
«Номера до» ниже от 250 — 7,45 с.
Рекурсия того же вида без обещаний («Номера до», `принимает предел: нат`,
`добавить предел к («Номера до» от (предел минус 1))`) от 4000 — 7,62 с.
В программе из заявки на 1243 лексемах прогон кончился
`FLANG_RECURSION_LIMIT: функция «Числа до без проверок» исчерпала лимит шагов
(40000000)`.

Версия: flang 0.7.22, двоичный ветки `a/160-memory-limit-for-the-interpreter`.

## Что должно быть

Вызов «Числа до» от n — линейное число шагов. Причина квадрата: вычислитель
проверяет `обеспечивает` при каждом вызове, а два обещания «Числа до» («от
положительного предела промежуток есть предыдущий с дописанным пределом» и
«промежуток пуст или есть предыдущий с дописанным пределом») зовут «Числа до»
от `предел минус 1` — через копию без обещаний, «Числа до без проверок». Каждый
уровень рекурсии пересчитывает весь промежуток заново.

## Обходной путь

Своя функция промежутка без обещаний, зовущих её же (пример выше).

## Когда задача сделана

Тот же прогон от 1000 укладывается в подготовку плюс секунды, а не минуту;
обещания «Числа до» либо доказаны и не проверяются при работе, либо
переписаны без вызова самой функции. Замер N = 500 и 1000 — в теле коммита.

## Где живёт правка

`flang/stdlib/lists.flang` (обещания) — доезжает без перепечатки; либо
вычислитель в `flang/self/interpret.flang` перестаёт проверять доказанные
обещания — тогда только перепечаткой.
