# 4107. У записи «Короткая команда» нет поля срока, и перечень 153 команд не говорит, сколько идёт каждая

Короткие команды переехали из снятой таблицы ярлыков в `.flangrc` (задача 1416).
Запись теперь зовётся «Короткая команда» и живёт в
`scripts/shortcut-collector.fscript`; перечень печатает `flang run-script`.

## Шаги воспроизведения

1. Посмотреть поля записи:
   `grep -n -A3 '^объект «Короткая команда»' scripts/shortcut-collector.fscript`.
2. Напечатать перечень: `bootstrap/flang run-script`.
3. Смотреть, есть ли при команде срок.

## Что происходит

```
$ grep -n -A3 '^объект «Короткая команда»' scripts/shortcut-collector.fscript
4:объект «Короткая команда»
5-  «имя»: строка
6-  «команда»: строка
                                                                 код 0
$ bootstrap/flang run-script
короткие команды проекта (<дерево>/.flangrc):

  build                 sh scripts/bootstrap-reprint.sh --telo && make -C bootstrap …
  scripts:check         bootstrap/flang io scripts/shortcut-collector.fscript --plan Целость …
  licenses:check        bootstrap/flang io scripts/guards/license-guard.fscript
  …
звать: flang run-script <имя> [доводы…]                          код 0
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

В перечне 153 короткие команды, у каждой имя и команда, срока нет ни у одной.
Команды при этом идут от секунды до десятков минут. Своим пределом времени
обзавелись 36 из 153 — ключ `--timeout` внутри самой команды; это потолок
прогона, а не снятый срок, и перечень его не показывает.

Слова «зачем» в перечне тоже нет: они переехали в функции
«Объявление короткой команды <имя>» внутри самих скриптов, и таких объявлений
113 на 153 команды. Срок словами назван в одном объявлении из 113
(`link-collisions:check` — «тридцать минут против пяти секунд»).

## Что должно быть

У записи «Короткая команда» есть третье, обязательное поле — срок в секундах,
снятый прогоном. «Срок не снят» записывается явным значением и отличается от
забытого поля. Перечень `flang run-script` печатает срок рядом с именем.
Прогон, вышедший за объявленный срок вдвое, говорит об этом строкой в конце,
иначе числа устареют молча.

## Обходной путь

Звать команду под `timeout` и мерить руками. `docs/ci-inventory.md` для этого
больше не годится: опись снята 25 августа 2026 двоичным 0.6.2 и считает 82
цели в таблице ярлыков — файла, которого в дереве нет.

## Когда задача сделана

```
$ bootstrap/flang run-script
  build                 <срок>   sh scripts/bootstrap-reprint.sh --telo && …
  …                                                              код 0
```

У каждой строки перечня стоит срок либо явное «не снят». У «Команда из пары»
есть пример со сроком; у сверки целости — постусловие, что срок задан у каждой
записи, и оно краснеет на команде без срока.
`bootstrap/flang run-script scripts:check` отвечает кодом 0. Команда, нарочно
объявленная со сроком вдвое меньше настоящего, печатает строку о превышении.

## Где живёт правка

`.flangrc` — третье поле в строке короткой команды;
`scripts/shortcut-collector.fscript` — `объект «Короткая команда»`,
«Команда из пары», сверка целости; `flang/src/emit/c/flang_repl.c` — печать
перечня и замер времени прогона. Последняя правка доезжает до двоичного только
пересборкой семени (bootstrap regeneration). Сроки снимать прогоном.
