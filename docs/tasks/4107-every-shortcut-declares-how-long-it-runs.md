# 4107. У записи «Ярлык» нет поля срока, и перечень ярлыков не говорит, сколько идёт каждая команда

## Шаги воспроизведения

1. Посмотреть поля записи: `grep -n -A3 '^объект «Ярлык»' ярлыки.flang`.
2. Напечатать перечень: `./ярлык`.
3. Смотреть, есть ли при ярлыке срок.

## Что происходит

```
$ grep -n -A3 '^объект «Ярлык»' ярлыки.flang
3:объект «Ярлык»
4-  «имя»: строка
5-  «команда»: строка
6-  «зачем»: строка
                                                                 код 0
$ ./ярлык
ярлыки этого дерева (список — в ярлыки.flang):

сборка                     собрать двоичный компилятор из точки раскрутки
ярлыки                     целость перечня с двух сторон: …
лицензии:проверка          SPDX-метка у каждого файла, который уезжает в пакет
…                                                                код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

В перечне 149 ярлыков, у каждого имя и «зачем», срока нет ни у одного.
Команды при этом идут от секунды до десятков минут. Три ярлыка называют время
словами внутри «зачем»: `семя:быстро` («за полсекунды вместо часа»),
`столкновения:пересчёт` («тридцать минут»), `опубликованное:сверка`.

## Что должно быть

У записи «Ярлык» есть четвёртое, обязательное поле — срок в секундах, снятый
прогоном. «Срок не снят» записывается явным значением и отличается от
забытого поля. Перечень `./ярлык` печатает срок рядом с «зачем». Прогон,
вышедший за объявленный срок вдвое, говорит об этом строкой в конце, иначе
числа устареют молча.

## Обходной путь

Читать срок в `docs/ci-inventory.md`, где он снят для части проверок, либо
звать команду под `timeout`.

## Когда задача сделана

```
$ ./ярлык
сборка                     <срок>   собрать двоичный компилятор из точки раскрутки
…                                                                код 0
```

У каждой строки перечня стоит срок либо явное «не снят». У функции «Перечень»
есть пример со сроком; у «Все ярлыки» — постусловие, что срок задан у каждой
записи, и оно краснеет на ярлыке без срока. `./ярлык ярлыки` отвечает кодом 0.
Ярлык, нарочно объявленный со сроком вдвое меньше настоящего, печатает строку
о превышении.

## Где живёт правка

`ярлыки.flang`: `объект «Ярлык»`, «Все ярлыки», «Перечень»; оболочка `ярлык` —
замер времени прогона и строка о превышении. Сроки брать из
`docs/ci-inventory.md`, недостающие снимать прогоном. Оба файла читаются с
диска, пересборка семени (bootstrap regeneration) не нужна.
