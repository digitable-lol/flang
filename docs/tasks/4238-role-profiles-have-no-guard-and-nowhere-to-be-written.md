# 4238. Профили роли ничем не стережутся: математику не ввозится Fmath, а назвать профиль негде

## Шаги воспроизведения

1. Пустой каталог, примета корня и программа, которая зовёт модуль утверждений:

```
mkdir proba && cd proba && git init -q
printf 'модуль «Проба»\n\nиспользует «Fmath»\n' > use-fmath.flang
printf 'profile = mathematician\n' > .flangrc
```

2. Проверить её:

```
flang check use-fmath.flang
```

3. Спросить у читателя настроек, какой профиль взят:

```
flang run-script settings
```

4. Создать новый проект и посмотреть, куда в нём пишется профиль:

```
flang new proba2 && ls -a proba2
```

## Что происходит

```
$ flang check use-fmath.flang
flang: модуль «Fmath» библиотеки не входит в профиль «mathematician» (…/proba/.flangrc) — по имени
не ввозится; допишите его в «modules» или выберите другой профиль
FLANG_IMPORT_NOT_FOUND в файле use-fmath.flang, строка 1, столбец 1: не найден модуль «Fmath»:
ни рядом с файлом, ни выше по каталогам, ни в библиотеке компилятора
use-fmath.flang: не проверено — замечаний 1                                             код 1
```

`Fmath` — единственный модуль библиотеки, который держит отдельные `утверждение` (их четыре);
остальные 52 модуля не держат ни одного. Именно он и есть «проверялка с аксиомами», за которой
профиль `mathematician` берут, и именно его этот профиль отказывается ввозить.

```
$ flang run-script settings
language = ru   (…/.flangrc)
…
lint = refuse   (…/.flangrc)                                                            код 0
```

Строк тринадцать: читатель `scripts/flangrc.fscript` держит обеспечение
«there are exactly thirteen keys», и ключей профиля — `profile`, `modules`, `profile.<имя>` —
среди этих тринадцати нет. Какой профиль взят, читатель не говорит никогда.

```
$ flang new proba2 && ls -a proba2
.  ..  README.md  flang.package  fspec  proba2.flang                                    код 0
```

Файлов у нового проекта девять, `.flangrc` среди них нет. Манифест `flang.package` несёт три
поля — `имя`, `версия`, `источник`; с тремя ключами профиля не пересекается ни одно.

Ещё два замера на том же двоичном:

| что считали | число |
| --- | --- |
| модулей в `flang/stdlib` | 53 |
| профилей в `flang/stdlib/profiles.flangrc` | 3 |
| модулей в объединении трёх профилей | 51 — вне всех `Fmath` и `Samples` |
| проверок и сторожей, которые читают `profiles.flangrc` | 0 |
| ключей, которые называет `flang --help` | 0 из 16 |

Версия: `flang 0.7.23`.

## Что должно быть

[ADR-0054](../adr/0054-a-profile-in-the-settings-file-selects-library-modules.md) обещает три
профиля, которые «приходят с языком», и
[страница настроек](../guide/settings.ru.md) называет `mathematician` набором «числа, длинные
целые, дроби, классические задачи, статистика, логика». Набор, за которым идёт доказывающий,
обязан нести модуль утверждений: `Fmath` входит в `mathematician`.

Дальше профиль обязан быть виден и защищён:

* `flang run-script settings` называет действующий профиль и модули, которые он даёт.
* Сторож краснеет, если имя в `profiles.flangrc` не отвечает ни одному модулю библиотеки
  и если модуль библиотеки не входит ни в один профиль.
* `flang new` пишет `.flangrc` со строкой `profile = programmer` — чтобы слово, которое меняют,
  стояло на виду, а не искалось в документации.

Третий пункт — развилка уровня устройства языка, и она решена отдельно:
[ADR-0055](../adr/0055-a-role-preset-is-named-in-the-project-settings-not-in-the-package-manifest.md).

## Обходной путь

Дописать модуль руками поверх профиля:

```
profile = mathematician
modules = Fmath
```

Прогон после этого зелёный, код 0. Обход работает для всех трёх профилей; того, что набор
неполон, он не лечит — следующий проект наступит на то же.

## Когда задача сделана

1. Прогон из шагов воспроизведения даёт код 0 без строки `modules`:

```
$ printf 'profile = mathematician\n' > .flangrc && flang check use-fmath.flang
use-fmath.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет   код 0
```

2. Чужой профиль по-прежнему отказывает внятно — то же на `programmer`:

```
$ printf 'profile = programmer\n' > .flangrc && flang check use-fmath.flang
flang: модуль «Fmath» библиотеки не входит в профиль «programmer» (…) — по имени не ввозится;
допишите его в «modules» или выберите другой профиль                                      код 1
```

3. Новая проба `scripts/guards/profiles-guard.fscript` с двумя планами:
   `Проверка` — каждое имя в `profiles.flangrc` отвечает модулю библиотеки, и каждый модуль
   библиотеки входит хотя бы в один профиль; `Подлог` — порченый `profiles.flangrc`
   (имя `Нетмодуля` в профиль, модуль вынут из всех профилей) краснит план `Проверка`.
   Проба зовётся коротким именем `profiles:check` и `profiles:forgery` из `.flangrc`.

4. `flang run-script settings` печатает строку профиля: имя профиля, файл, откуда оно взято,
   и число модулей, которые он даёт. Обеспечение числа ключей в `scripts/flangrc.fscript`
   переписано с тринадцати на шестнадцать.

5. `flang new <имя>` создаёт `.flangrc` со строкой `profile = programmer`; проба на это —
   в том же стороже.

## Где живёт правка

| файл | что меняется |
| --- | --- |
| `flang/stdlib/profiles.flangrc` | `Fmath` в `mathematician`; `Samples` в `programmer` и `analyst` |
| `scripts/guards/profiles-guard.fscript` | новый сторож, два плана |
| `scripts/flangrc.fscript` | три ключа профиля в `Keys`, строка профиля в выводе |
| `scripts/settings-file.flang` | те же три ключа в спеке файла настроек |
| `docs/guide/settings.ru.md` | набор `mathematician` назван с модулем утверждений |
| `.flangrc` | короткие имена `profiles:check`, `profiles:forgery` |

Первые шесть доезжают до двоичного быстрым пересевом: ни один не трогает `flang/self/**`.
Строка `profile = programmer` в `flang new` живёт в `flang/src/emit/c/flang_repl.c` рядом с
остальными файлами нового проекта — тоже без перепечатки самосборной части.
