# 4246. Архивы выпуска ничем не подписаны: скачавший flang не может проверить, что архив собрал проект

## Шаги воспроизведения

1. `gh release view v0.7.32 --repo digitable-lol/flang --json assets --jq '.assets[].name'`
2. Смотреть, есть ли рядом с архивом файл подписи (`.minisig`, `.sig`, `.asc`).

## Что происходит

У архивов выпуска есть только `sha256` в формуле Homebrew и в плагине asdf;
он говорит «архив не испорчен», а не «архив собрал проект»: кто подменил
архив, подменит и отпечаток рядом.

## Что должно быть

Ключ проекта: открытая половина встроена в двоичный и названа в документации,
тайная хранится у владельца вне машин сборки. Ключ подписывает архивы выпуска
(формат minisign, `flang/stdlib/ed25519.flang` и `minisign.flang` уже в
библиотеке), а `install.sh`, формула и плагин проверяют подпись. Одно ADR и
одна команда владельца для подписи.

## Обходной путь

Нет: сверка `sha256` из того же источника, что и архив.

## Когда задача сделана

Архив выпуска лежит с подписью; `install.sh` с подменённым архивом и
подогнанным `sha256` отказывает, с настоящим — ставит.

## Где живёт правка

`scripts/release/`, `install.sh`, формула Homebrew, плагин asdf, ADR; без печати,
если открытый ключ лежит рядом со скриптами установки, а не в двоичном.
