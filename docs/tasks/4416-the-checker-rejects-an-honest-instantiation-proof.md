# 4416. На силлогизме ядро сказало «доказано», сверщик — «НЕ СОШЛОСЬ»

Два судьи. **Ядро** — проверка доказательств внутри компилятора (`flang check
--proof`, `flang/self/proof-kernel.flang`). **Сверщик** — отдельная программа на C
(`flang/proof/checker/checker.c`), которая ядру не верит и сама перечитывает
**запись**: текстовый файл, где ядро печатает, чем закрыто каждое утверждение
(`flang check <файл> --proof --record <запись>`, печать — `flang/self/zapis.flang`).
Коды сверщика: 0 — проверил сам; 3 — «не взялся», место оставлено на слове ядра;
1 — нашёл ложь.

## Шаги воспроизведения

1. Программы: проба `flang/proof/probes/syllogism/programs/honest.flang` (силлогизм
   словом `следует`, ADR-0047) и файл задачи 5309 из раздела «Как это выглядит
   сегодня» (он же `flang/proof/checker/tests/families/statement/syllogism-socrates.flang`).
2. Команды:
   ```
   make -C bootstrap -j8
   cc -std=c99 -Wall -Wextra -Werror -pedantic -O2 -o flang/proof/checker/сверщик flang/proof/checker/checker.c
   bootstrap/flang check <файл> --proof --record <запись>
   flang/proof/checker/сверщик <файл> <запись> "$(sha256sum <файл> | cut -d' ' -f1)"
   ```
3. Смотреть: код возврата обоих и первую строку ответа сверщика.

### Кто неправ при коде 1 — сверщик, и не в правиле вывода

Отвергнутый шаг — не логический, а **разметка теоремы**: сверщик сличает, на каких
строках исходника стоят части теоремы, с тем, что о них говорит запись.

* **Что говорит запись.** Теорема на строке 20; «следовательно доказано да».
* **Что это значит в языке.** ADR-0047: `следует «И»` = `теорема «И»` плюс
  подразумеваемое `следовательно доказано`. Разборщик так и делает:
  `flang/self/parser.flang:7855`, «Разобрать теорему» ставит полю «доказано»
  значение довода «следствие», а довод равен да ровно для слова `следует`
  (`parser.flang:4978`). Ядро получает то же дерево, что от `теорема` +
  `следовательно доказано` (зонд `zond-5309.flang`, задача 5309).
  Запись сказала правду о каждой строке.
* **Что ждал сверщик** (`checker.c` на `gh/dev`):
  * `сверить_разметку_теоремы`, строка 8581: строка заголовка обязана быть
    буквально `теорема «И»`;
  * `разметка_теоремы`, строка 597: заголовком считается только строка,
    начинающаяся с `теорема `, а строка `следовательно доказано`
    (`вид_строки_теоремы`, 587) обязана стоять в исходнике.

  Слова `следует` сверщик не знал вовсе: его ввела перепечатка 25 сентября
  (0.7.22), а сверщик с тех пор не правился.

Значит ядро право, запись верна, а сверщик не умел прочесть слово поверхности. Правило
вывода здесь ни при чём, и в `flang/self/**` править нечего.

Та же слепота давала вторую беду, хуже ложной тревоги. Пусть запись **прячет**
теорему, написанную словом `следует`: блок теоремы заменён на `теоремы нет`. Такой
подлог прежний сверщик не называл. Сторожа `без_теоремы` (строка 8858) и
`сверить_полноту` (8545) искали в исходнике только `теорема «И»`. Замер на той же
пробе: прежний сверщик — код 3, новый — код 1 с причиной «в записи сказано «теоремы
нет», а в исходнике теорема «Сократ смертен» написана».

### Кто неправ при коде 3 — никто; сверщику не хватает приёма (задача 2748)

Код 3 — не ложь, а «не взялся». Цепочка причин одна.

1. Утверждение «все люди смертны» (`для всех кто: «Человек» утверждаем («Смертен»
   от кто)`) ядро закрыло правилом «цель есть допущение» (Γ, A ⊢ A). Допущение
   A здесь — инстанция доказанного постусловия вызванной. У «Смертен» есть
   постусловие «всякий человек смертен»: `результат`, доказанное вычислением
   замкнутой цели: тело `да`. Подстановка `результат := «Смертен» от кто` даёт
   ровно цель. Факты собирает `flang/self/proofterm.flang` («Постусловия
   вызванных» → «Факты вызванной» → «Дописать факт вызванного», строки 3323–3360).
   Берутся только уже доказанные постусловия, поэтому круга нет. Сличает
   `proof-kernel.flang:8229` («Есть допущением»), правило ставит строка 9645.
   **Вывод верен.**
2. Запись печатает только `правило «цель есть допущение»` и `по объявлению нет`.
   Какой факт совпал с целью, она не называет, и сверщику переигрывать нечего.
   Ни один приём в `крюки_по_телу` (`checker.c`, 8807) такую цель не берёт, и
   место уходит на слово ядра. Причина при этом печатается неверная:
   «сверщик не повторяет изъятие объявленного типа», хотя значение «нет»
   (`счёт_породы` проверяет только наличие строки «по объявлению»). Это ровно
   задача 2748.
3. Раз «все люди смертны» не проверено по существу, в реестр доказанного оно не
   входит. Шаг `по свойству «все люди смертны»` и ход `факт по свойству` честно
   уходят на слово ядра (код 3, так задумано коммитом `3485ec344`).

## Что должно быть

Сверщик читает исходник по той же грамматике, что и язык: `следует «И»` —
заголовок теоремы с подразумеваемым `следовательно доказано` (ADR-0047). На честной
записи он не отвечает 1, а незаконченную `теорему` и спрятанную `следует`-теорему
отвергает.

## Обходной путь

Для кода 1 не нужен: он снят. Код 3 остаётся на всех пяти программах таблицы
выше. Обхода нет: сверщик честно оставляет утверждение на слове ядра.

## Когда задача сделана

* **Сделано:** `сверщик honest.flang <запись>` не даёт 1. Проба `4416: силлогизм
  словом «следует»` в `tests/run.sh` краснеет, если ложная тревога вернётся.
  Проба `4416: «теорема» без «следовательно доказано»` краснеет, если правку
  расширят на `теорему`.
* **Не сделано — согласие судей кодом 0.** Задача 2748, предложение ниже.

## Где живёт правка

* Сделанное — `flang/proof/checker/checker.c`, до двоичного не едет: сверщик
  собирается отдельно.
* **Партии печати `flang/self/**` править нечего:** запись на обоих файлах верна.
* **Предложение, 14 строк кода, в потолок не входит (остаток 0).** Сверщик
  доучивается приёму «цель — вызов, чьё доказанное постусловие есть `результат`».
  Черновик прогнан во времянке, в дерево не внесён:

  ```c
  static int цель_от_вызванной(Сверка *s, Сп строки, const char *цель) {
    char *ц = ужать(терм(цель)), *f = в_ёлочках(ц, 1), *l; long a, b, i; int k; Сп дов;
    if (!*f || !начинается(ц, fmt("«%s» от ", f)) || все_требования_функции(строки, f).n ||
        (a = блок_функции(строки, f, &b)) < 1) return 0;
    дов = доводы_вызова(хвост_после(ц, fmt("«%s» от ", f)));
    for (k = 0; k < дов.n; k++) if (!имя_вывода(ужать(дов.e[k]))) return 0;
    for (i = a; i < b; i++) {
      l = как_читает_язык(часть(строки, i));
      if (начинается(l, "обеспечивает «") && среди(s->доказанные_свойства, в_ёлочках(l, 1)) &&
          strcmp(ужать(терм(хвост_после(l, fmt("обеспечивает «%s» ", в_ёлочках(l, 1))))), "результат") == 0) return 1;
    }
    return 0;
  }
  ```

  Эта функция и вызов в `крюки_по_телу` после `начало_по_телу` (тем же видом, что
  соседи) — это 7603 → 7617. Замер черновиком:
  * файл 5309: 3 → **0**; `removal-strict.flang`: 3 → 0;
  * `honest.flang`, `conditional.flang`, `chain.flang`: остаются 3;
  * набор проб: подделок принято 0, честных отвергнуто 0; ожидания меняются
    ровно у двух проб силлогизма.

  На `honest.flang` остаётся вторая причина: «его цель ни при какой подстановке
  доводов функции того же типа не совпала с целью шага». Шаг `по свойству` у
  теоремы над СВОБОДНЫМ утверждением сверщик подставляет доводами функции
  (`чья`), а у такой теоремы функции нет: подставлять надо её `дано`. Это
  отдельная правка, её размер не мерян.

  Потолок поднимает владелец строкой бюджета в `flang/proof/checker/ratchet.txt`.
  Другой путь — печать `flang/self/zapis.flang` называет совпавший факт
  (имя постусловия, чья функция, инстанция), и тогда сверщику хватит сличения.
  Решать владельцу вместе с 2748.
