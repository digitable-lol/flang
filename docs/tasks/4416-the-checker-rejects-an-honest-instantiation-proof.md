# 4416. Шаг «по свойству» в теореме над свободным утверждением проверяющая программа не переигрывает

## Шаги воспроизведения

1. Программа из дерева: `flang/proof/probes/syllogism/programs/honest.flang`.
   Теорема в ней написана словом `следует` над утверждением, у которого нет
   функции:

```flang
утверждение «все люди смертны»
  для всех кто: «Человек»
  утверждаем («Смертен» от кто)

следует «Сократ смертен»
  дано сократ: «Человек»
  утверждаем («Смертен» от сократ)
  по свойству «все люди смертны»
```

2. Доказать, записать доказательство, собрать независимую проверяющую программу
   (proof checker) и отдать ей запись:

```
bootstrap/flang check flang/proof/probes/syllogism/programs/honest.flang --proof --record <запись>
cc -O1 -o <сверщик> flang/proof/checker/checker.c
<сверщик> flang/proof/probes/syllogism/programs/honest.flang <запись>
```

## Что происходит

```
$ bootstrap/flang check …/honest.flang --proof --record <запись>
… ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — утверждений 3: доказано 3 …          код 0
$ <сверщик> …/honest.flang <запись>
НЕ ВЗЯЛСЯ (строк причин 2; мест на слово ядра 2): утверждение «все люди
смертны»: значение «по объявлению нет» — …; теорема «Сократ смертен»: шаг «по
свойству «все люди смертны»» — утверждение, но оно не проверено по существу
раньше этой теоремы; …                                            код 3
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Причин две. Первая — утверждение «все люди смертны» не переиграно; это задача
2748. Вторая остаётся и после неё. Если научить проверяющую программу первой
причине (приём «цель — вызов, чьё доказанное постусловие есть `результат`»),
соседний файл `flang/proof/checker/tests/families/statement/syllogism-socrates.flang`
получает код 0, а `honest.flang` — по-прежнему код 3:

```
НЕ ВЗЯЛСЯ (строк причин 1; мест на слово ядра 1): теорема «Сократ смертен»:
шаг «по свойству «все люди смертны»» — утверждение, но его цель ни при какой
подстановке доводов функции того же типа не совпала с целью шага
```

Функция `шаг_утверждением` подставляет в цитируемое утверждение доводы функции,
к которой относится теорема. У теоремы над свободным утверждением функции нет,
подставлять нужно имена из её `дано`.

## Что должно быть

Шаг `по свойству «У»` в теореме без функции проверяющая программа переигрывает
подстановкой имён из `дано` теоремы в связанные имена утверждения «У». На
`honest.flang` ответ — «ПРОВЕРЕНО», код 0, мест на слове ядра нет (ADR-0022,
ADR-0047).

## Обходной путь

Обходного пути нет: записать ту же теорему при функции (как в
`syllogism-socrates.flang`) значит отказаться от слова `следует` над свободным
утверждением.

## Когда задача сделана

После задачи 2748 команды из шагов воспроизведения дают от проверяющей программы
«ПРОВЕРЕНО», код 0, и «НА СЛОВО ЯДРА: посылок и утверждений 0, шагов 0». Проба
`syllogism-follows` в `flang/proof/checker/tests/run.sh` ждёт кода 0 вместо 3.
Подделка — запись, где шаг ссылается на утверждение о другом доводе (подстановка
из `дано` не даёт цель шага), — получает код 1. `sh flang/proof/tables-guard.sh`
зелен: строк кода не больше потолка.

## Где живёт правка

`flang/proof/checker/checker.c`, функция `шаг_утверждением`; ожидания проб —
`flang/proof/checker/tests/run.sh`; если строк кода станет больше потолка —
`flang/proof/checker/ratchet.txt`. Проверяющая программа собирается отдельно,
пересборка семени (bootstrap regeneration) не нужна.

### Две части правки

**Часть 1 — приём `цель_постусловием`, шестой крюк в `крюки_по_телу`.** Цель свободного
утверждения есть САМ вызов ⟨«Г» от связанные⟩, а у «Г» стоит постусловие, проверенное
сверщиком ПО СУЩЕСТВУ раньше, инстанция которого и есть эта цель. Своего сличения приём не
несёт: инстанцию строит ход `факт по свойству` (привязка по ребру, арность, захват имени,
оплата `требует`, оба сторожа круга), замыкает её `закрыть по свойству` модус-поненсом —
те же примитивы, что у `шаг_постусловием`. Места приём снимает только когда прогон кончил
без бед и без целей. Сверх примитивов приём проверяет ТИПЫ: каждый довод вызова обязан быть
связанным именем утверждения, чей объявленный тип знак в знак тот же, что у параметра «Г» на
его месте, — иначе постусловие говорит обо ВСЕХ входах ДРУГОГО множества, чем утверждение.
`o.функция` оставлена пустой нарочно: `снято_в_точке` считает `требует` этой функции
законными допущениями тела, а здесь вызванная и «чья» — одна и та же функция, и её
собственное предусловие оплатило бы само себя; при пустом имени требований не находится ни
одного, и вызванная с `требует` приёмом не берётся вовсе.

**Часть 2 — `шаг_утверждением` подставляет связанные имена доказываемого утверждения.**
Прежде кандидатами подстановки были только параметры функции, к которой относится теорема;
у теоремы над свободным утверждением они зовутся иначе (`кто` против `сократ`), и подстановка
ими цели шага не давала. Теперь к кандидатам добавлены связанные имена САМОГО доказываемого
свободного утверждения с их объявленными типами. Тип читается из строки `для всех` этого
утверждения, а НЕ из строки `дано` теоремы: `дано` вправе назвать тип, которого у параметра
функции нет, — на этом живёт подлог `statement/corrupt/k3c-wrong-type`, и первая редакция
правки, бравшая тип из `дано`, этот подлог ПРИНЯЛА кодом 0 (замер: «подделок 629 … ПРИНЯТО
кодом 0 — 1»). Чтение типа из утверждения закрыло брешь и заодно выключило ветку у постусловий:
`МЕСТО_ВЫСКАЗЫВАНИЯ` там пусто.

**Приговор «ложь», а не «не взялся».** Ядро подстановку НЕ ИЩЕТ: цель утверждения сличается
с целью места как образец с термом (`proofterm.flang:1245` `«Сличить с образцом»`,
`1246`–`1248` «Ядро подставляет, а не ищет»), сличение одно и однозначно, и при неудаче шаг у
ядра не выводится вовсе. Значит у КОРНЯ образца выбора нет: корень цели утверждения — узел
вызова, связанным именем он быть не может, и сличиться он способен единственно с вызовом ТОЙ
ЖЕ функции ТОЙ ЖЕ арности. Голова или арность не та — шаг не вывелся бы и у ядра, а запись
числит его закрывающим: это ложь записи, код 1. Сужено до случая, где перебор полон: только
свободное утверждение, только ЗАКРЫВАЮЩИЙ шаг (у промежуточного ядро сличает образец с
выписанным термом, а не с целью), только цель без `результат`, оба терма — вызовы, и перебор
выше вообще был. Несовпадение ВНУТРИ доводов остаётся «не взялся»: там связанное имя вправе
уйти в составной терм, и неудача перебора по именам ещё не неудача сличения.
