# 4497. flang check молчит, когда весь список передаётся в функцию на каждый номер того же списка

Заявка: https://github.com/digitable-lol/flang/issues/160, пункт 2.

## Шаги воспроизведения

1. Программа — три функции из заявки: «Вид лексемы» берёт `элемент номер в
   лексемы`, «Слово языка на месте имени» зовёт её шесть раз, передавая весь
   список `лексемы`, а «Слова языка вместо имён» зовёт «Слово языка на месте
   имени» внутри `отфильтровать («Числа до» от (длина лексемы)) где номер → …`.
2. `flang check программа.flang`.
3. Смотреть вывод и код возврата.

## Что происходит

```
$ flang check probe.flang
модуль «Проба 160»: функций 125, из них с доказанным завершением 125; типов 13; файлов вместе с импортами 4
probe.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
                                                                        код 0
```

Версия: flang 0.7.22, двоичный из семени ветки
`a/160-memory-limit-for-the-interpreter`, 27 сентября 2026.

## Что должно быть

Предупреждение (не отказ, код 0 остаётся) с местом и словами: «список
`лексемы` передаётся целиком в функцию, которая зовётся на каждый номер того же
списка» — и то же для `элемент N в СПИСОК` внутри обхода того же `СПИСОК`.

Важно для текста предупреждения: сама передача и `элемент N в` стоят
постоянное время (SPEC, раздел «Стоимость встроенных форм», абзац про передачу
списка; замер там же: 4000 записей — 10,14 с при 7,6 с подготовки). Квадрат в
заявке дали не они, а «Числа до» с обещаниями, которые пересчитывают её же, и
память вычислителя, которую он не отдавал на глубокой стопке (обе причины и
правка второй — в коммите этой ветки). Предупреждение поэтому обязано говорить
о рисунке обхода, а не обещать, что «передача копирует список».

## Обходной путь

Одна свёртка с окном из последних четырёх лексем вместо обхода по номерам.
Защиту от падения машины даёт предел памяти прогона (`--memory-limit`, код 5).

## Когда задача сделана

`flang check` на программе из заявки печатает предупреждение с местом вызова
«Слово языка на месте имени» и кодом 0; на программе со свёрткой по окну
предупреждения нет. Проба-план в `flang/proof/probes/` держит оба случая.

## Где живёт правка

Анализ — в `flang/self/` (проход проверки рядом с `totality.flang`), значит
правка доезжает до двоичного только перепечаткой семени, быстрого пересева
для неё нет.
