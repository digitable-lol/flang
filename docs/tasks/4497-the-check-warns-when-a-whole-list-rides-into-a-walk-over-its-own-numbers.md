# 4497. flang check молчит, когда весь список передаётся в функцию на каждый номер того же списка

Заявка: https://github.com/digitable-lol/flang/issues/160, пункт 2.

## Шаги воспроизведения

1. Программа (путь к библиотеке — от места, где лежит файл):

```flang
модуль «Проба обхода по номерам»
  использует «Lists» из "flang/stdlib/lists.flang"

тотальная функция «Сосед больше»
  принимает числа: список числа, номер: число
  возвращает признак
  если (номер меньше 2) или (номер больше (длина числа))
    то нет
    иначе (элемент номер в числа) больше (элемент (номер минус 1) в числа)

тотальная функция «Подъёмы»
  принимает числа: список числа
  возвращает список числа
  пример «один подъём»
    дано числа равно [3, 1, 2]
    ожидается [3]
  отфильтровать («Числа до» от (длина числа)) где номер → «Сосед больше» от числа и номер
```

2. Команда: `bootstrap/flang check <файл>`.
3. Смотреть, есть ли замечание о функции «Подъёмы», и код возврата.

## Что происходит

```
$ bootstrap/flang check <файл>
модуль «Проба обхода по номерам»: функций 40, из них с доказанным завершением 40; типов 1; файлов вместе с импортами 2
<файл>: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
                                                                 код 0
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Программа из заявки устроена так же: функция получает весь список лексем и
номер, а зовётся внутри `отфильтровать («Числа до» от (длина лексемы)) где
номер → …`. На файле в три тысячи лексем её прогон занял всю память машины.

## Что должно быть

Предупреждение с местом, код возврата остаётся 0: «список `числа` передаётся
целиком в функцию, которая зовётся на каждый номер того же списка». То же для
`элемент номер в числа` внутри обхода номеров того же списка.

Текст говорит о рисунке обхода и не утверждает, что передача копирует список:
передача списка и `элемент N в` стоят постоянное время (`docs/flang/SPEC.md`,
раздел «Стоимость встроенных форм»). Квадрат дают «Числа до» с постусловиями,
которые пересчитывают её же, и глубина стопки вычислителя.

## Обходной путь

Одна свёртка с окном из последних элементов вместо обхода по номерам. От
исчерпания памяти машины защищает предел памяти прогона: ключ `--memory-limit`,
на пределе — код 5.

## Когда задача сделана

`bootstrap/flang check` на программе из шагов воспроизведения печатает
предупреждение с местом вызова «Сосед больше» внутри «Подъёмы», код 0. На той
же задаче, написанной свёрткой, предупреждения нет. Оба случая держит проба в
`flang/proof/probes`: она краснеет, если предупреждение пропадёт или появится
на свёртке.

## Где живёт правка

Новый проход проверки в `flang/self`, рядом с `flang/self/totality.flang`:
искать вызов, которому передан список, внутри обхода по «Числа до» от длины
того же списка. До двоичного правка доезжает только пересборкой семени
(bootstrap regeneration).
