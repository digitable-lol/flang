# 4540. Ведомость примеров корпуса записана порядком обхода

## Шаги воспроизведения

1. Посмотреть, чем ведомость заполняется:

```
grep -n -- '--ledger' flang/test/обход-примеров.sh
```

2. Посмотреть, в каком порядке в ней идут каталоги `docs/`:

```
cut -f1 flang/test/examples-ledger.txt | grep '^docs/' | awk -F/ '{print $2}' | uniq -c
```

3. Сверить ведомость с деревом (прогон корпуса, десятки минут на машине без
   нагрузки):

```
sh flang/test/обход-примеров.sh
```

## Что происходит

Ведомость пишется **одной строкой обходчика** и без сортировки:

```
( cd "$root" && "$tool" test . --ledger || true ) | sed 's#^./##' > "$out"
```

Сверяется она `diff -u`, то есть **порядок значим**. А порядок — сырой порядок
обхода: внутри одного каталога файлы идут по алфавиту, а сами каталоги — в том
порядке, в котором их отдаёт файловая система (`benchmarks` может встать перед
`benchmark`, кириллический путь — в конец блока). Значит ведомость зависит не
только от состава дерева, но и от того, как каталоги легли в этой выкладке, и
при том же составе расходится порядком.

Работа `corpus-examples` в `.github/workflows/binary.yml` закрыта меткой
(`startsWith(github.ref, 'refs/tags/')`), и в проверках заявок стоит `skipping`.
Поэтому заявок она не красит, **а на метке покраснеет** — ровно перед выпуском.

## Что должно быть

Ведомость сходится с деревом: `diff -u` между записанной ведомостью и свежим
`flang test . --ledger` пуст, и работа `corpus-examples` на метке зелена.

## Обходной путь

Обходного пути нет: сверка идёт `diff -u`, и подогнать порядок руками нельзя —
его печатает сам обход.

## Когда задача сделана

`flang test . --ledger`, снятый на машине **без нагрузки**, даёт файл, который
`diff -u` сводит с записанной ведомостью без расхождений, и `sh
flang/test/обход-примеров.sh` отвечает кодом 0. Снимать — там же, где потом
берётся приговор: порядок зависит от выкладки, и ведомость, снятая на одной
машине, на другой может не сойтись. Место для этого — порядок выпуска перед
меткой.

## Где живёт правка

`flang/test/examples-ledger.txt` — пересъёмка. Обходчик
`flang/test/обход-примеров.sh` менять не нужно; если решат сделать порядок
независимым от выкладки, это отдельная задача про сортировку вывода `--ledger`,
и тогда ведомость станет сверяемой на любой машине.
