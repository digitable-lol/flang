# 4543. Постусловие у звена круга взаимной рекурсии не доказывается, хотя тот же спуск у самозова доказан индукцией

## Шаги воспроизведения

1. Программа: один спуск по одному типу, сначала самозовом, затем кругом из двух функций.

```flang
модуль «Круг обещаний»

тип «Цепь»
  вариант «Пусто цепи»
  вариант «Звено цепи» содержит «дальше»: «Цепь»

функция «Ход сам»
  принимает «ц»: «Цепь»
  возвращает число
  обеспечивает «ход сам неотрицателен» результат не меньше 0
  разбор «ц»
    случай «Пусто цепи»
      то 0
    случай вариант «Звено цепи» с «дальше» как «дальше»
      то «Ход сам» от «дальше»

функция «Ход раз»
  принимает «ц»: «Цепь»
  возвращает число
  обеспечивает «ход раз неотрицателен» результат не меньше 0
  разбор «ц»
    случай «Пусто цепи»
      то 0
    случай вариант «Звено цепи» с «дальше» как «дальше»
      то «Ход два» от «дальше»

функция «Ход два»
  принимает «ц»: «Цепь»
  возвращает число
  обеспечивает «ход два неотрицателен» результат не меньше 0
  «Ход раз» от «ц»
```

2. Команда: `bootstrap/flang check <файл> --proof`.
3. Смотреть вердикты трёх постусловий и код возврата.

## Что происходит

```
$ bootstrap/flang check <файл> --proof
постусловие «ход сам неотрицателен» функции «Ход сам» — доказано индукцией по «Цепь»: база 1 случай, шаг при допущении на частях (1 случай) …
постусловие «ход раз неотрицателен» функции «Ход раз» — объявлено, не доказано: ни теоремы, ни примеров …
постусловие «ход два неотрицателен» функции «Ход два» — объявлено, не доказано: ни теоремы, ни примеров …
<файл>: НЕ ПРОВЕРЕНО — утверждений 3: доказано 1, … объявлено, не доказано 2 …   код 3
```

Версия: flang 0.7.23. Дата прогона: 30 сентября 2026.

Индукция по объявленной сумме даёт допущение на частях только самозову. У звена круга
рекурсивный зов идёт соседу; правило «по свойству» берёт постусловие вызванного, но
у него своего вердикта нет — он сам ждёт соседа. Одновременной индукции по всем
звеньям круга в ядре нет: среди умений в `flang/proof/map/abilities.flang` хода по
кругу нет.

## Что должно быть

«Ход раз» и «Ход два» доказаны индукцией по «Цепь» так же, как «Ход сам», код
возврата 0: спуск, тип и цель те же, отличается только адресат зова. Стандартный
приём — одновременная индукция по кругу: все звенья доказываются вместе, допущение на
частях даётся всем сразу. Если ход признаётся неподъёмным, это должно быть сказано
там, где читают до написания кода: в правилах для авторов, одной строкой — обещание у
звена круга доказано быть не может, выноси его на внешний вход круга.

## Обходной путь

Вынести постусловие из круга на функцию-вход, которая зовёт круг и сама в нём не
состоит, либо не писать обещание у звеньев. Так и был починен горячий цикл
вычислителя.

## Когда задача сделана

Проба выше отвечает кодом 0, у всех трёх постусловий вердикт «доказано индукцией по
«Цепь»». В `flang/proof/map/abilities.flang` появляется умение про круг, и
`./ярлык умения:улики` его доказывает. Число батутов (trampolines) в напечатанном
компиляторе не убывает. Проба на круг из двух функций лежит в наборе проверяющей
программы и краснеет, если звену снова достаётся «объявлено, не доказано».

Второй честный исход: ход признан неподъёмным, в задаче стоит замер цены, а правило
«в круг обещаний не писать» записано в правилах для авторов.

## Где живёт правка

`flang/self/proof-kernel.flang` («Допущением или индукцией по прогону», «Свести
индукцией по прогону»), `flang/self/proof.flang` («Индукция ядра», «Шаг индукции»),
`flang/self/proofterm.flang` («Проверить индукцию», «Проверить индукцию по сумме»).
Всё под `flang/self/`, поэтому до двоичного правка доезжает только пересборкой
семени (bootstrap regeneration).
