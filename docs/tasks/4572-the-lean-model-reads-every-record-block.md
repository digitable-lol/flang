# 4572. Модель Lean читает не всю запись доказательства, а состоятельность сверщика связана с моделью сверкой вердиктов, а не выводом

## Шаги воспроизведения

1. `make -C flang/proof/checker second` — собрать модель и второй сверщик.
2. `bootstrap/flang run-script lean-model:blocks` — перепись блоков корпуса
   `flang/proof/checker/tests/records/corpus/`: какие блоки модель читает, какие вне её.
3. Что смотреть: строку «доля вне модели» и строки «ВНЕ по правилам».

## Что происходит

```
$ bootstrap/flang run-script lean-model:blocks
записей корпуса 100, исходника в дереве нет у 0
блоков с доказательством 601: модель читает 80 (блок вывода), вне модели 521
…
ВНЕ по правилам: Р5 2, М2 1
вне модели: 521 блоков из 601 с доказательством (86.69 %), и 3 шагов ВНЕ внутри читаемых
```

Модель (`flang/proof/lean/Acceptance.lean`) судит только блок `вывод`; ходы,
посылки индукции, тотальности, снятия, категорные теоремы стоят вне неё. Внутри
блоков вывода шаги Р5/Р6/Разв1 по телу, которое читатель не собрал в терм, и М2
с шагом свёртки — вызовом функции (реестр доказанных постусловий) уходят в «ВНЕ».
Чтение текста записи (`RecordReader.lean`) стоит вне теоремы. Связь `checker.c`
с моделью — сверка вердиктов на наборе проб (`flang/proof/lean/run.fscript`), а не
теорема о сверщике.

Версия: `flang 0.7.31` (`origin/dev` `a5890e700`), прогон 27 октября 2026.

## Что должно быть

`docs/road-to-1-0.md`, условие 3, «Как узнаем, что взято»: блоков «вне модели»
нет, и утверждение о состоятельности самого сверщика доказано выводом.

## Обходной путь

Нет. Сегодня доверие к сверщику держится на сверке вердиктов двух реализаций
(`checker:second`, `run.fscript`) и на пробах на подлог.

## Когда задача сделана

- `bootstrap/flang run-script lean-model:blocks` печатает долю вне модели 0 и
  «ВНЕ по правилам: —».
- Формат записи описан функцией Lean (`flang/proof/lean/RecordFormat.lean`), и
  леммы о форме связывают читатель с ним; сверка формы по корпусу в той же
  переписи даёт расхождений 0.
- Реестр доказанных постусловий — в модели: приём М2 с шагом-вызовом принят
  леммой «М2-реестр», сторож `lean-rules:check` это видит.
- Теорема «если опорный сверщик принял запись, каждый шаг — применение правила
  модели» закрыта без `sorry`; долг — в таблице
  `flang/proof/tables/lean-soundness-debt.tsv`, и сторож `lean-soundness:check` не
  даёт ему расти молча.

## Где живёт правка

`flang/proof/lean/**`, `flang/proof/checker/second/**`, `flang/proof/tables/`,
`.flangrc`, `docs/road-to-1-0.md`, `docs/four-coverages.md`. Перепечатка не нужна:
`flang/self/**` не трогается.
