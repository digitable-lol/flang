# 4573. Проверяющая программа отвечает кодом 1 на честных записях пяти модулей библиотеки: типы чужого модуля и тёзки в наборе

Слова. Ядро — проверка доказательств внутри компилятора (`flang check --proof
--record`). Независимая проверяющая программа (proof checker) —
`flang/proof/checker/checker.c`, читает исходник и запись ядра сама; коды: 0 —
проверила, 3 — не взялась, 1 — нашла ложь. Набор — записи модулей, которые
файл ввозит, поданные ключами `--зависимость ИСХОДНИК ЗАПИСЬ`.

## Шаги воспроизведения

1. Программы: `flang/stdlib/hmac.flang` (тип «Свод sha256» объявлен в
   `flang/stdlib/sha256.flang`), `flang/stdlib/postgres.flang` и
   `flang/stdlib/redis.flang` (типы «Разбор целого», «Разбор строки», «Разбор
   числа» из `flang/stdlib/wire.flang`), `flang/stdlib/tls.flang` и
   `flang/stdlib/tls-handshake.flang` (в наборе две функции «Шаг начала»:
   `flang/stdlib/hmac.flang`, строка 60, и `flang/stdlib/aes.flang`, строка 1143;
   две «Цифра 16» — в `flang/stdlib/der.flang` и `flang/stdlib/sha256.flang`).
2. Команды из корня дерева, каталог R — временный вне дерева; набор — все
   модули по транзитивному замыканию строк `использует`, у каждого своя запись:

```
make -C flang/proof/checker
bootstrap/flang check flang/stdlib/<ф>.flang --proof --record R/<ф>.record
flang/proof/checker/сверщик --зависимость flang/stdlib/<з>.flang R/<з>.record … flang/stdlib/<ф>.flang R/<ф>.record
```

3. Смотреть код возврата и строки после `НЕ СОШЛОСЬ:`.

## Что происходит

```
$ flang/proof/checker/сверщик --зависимость … flang/stdlib/hmac.flang R/hmac.record
НЕ СОШЛОСЬ: … довод «свод» объявлен типом «Свод sha256» — принципа индукции нет …
… объявления типа в исходнике нет — строке «объявление сумма «Свод sha256» …» сверять не с чем   код 1
$ flang/proof/checker/сверщик --зависимость … flang/stdlib/tls.flang R/tls.record
НЕ СОШЛОСЬ: в наборе два разных определения «Шаг начала» — имя не различает, кому верить   код 1
```

Версия: flang 0.7.22. Не перепроверено: печать записи ядром для `flang/stdlib/hmac.flang` и
`flang/stdlib/sha256.flang` не укладывается в минуту (код 124), проверка сама по себе быстрая.

Причины две. Строка записи `объявление сумма «Т» строка N` у типа из чужого
модуля не называет модуль, а проверяющая программа ищет объявление только в
своём исходнике (`flang/proof/checker/checker.c`, сообщение «объявления типа в исходнике нет»):
набор сегодня служит только тотальности (ADR-0048). Реестр набора в
`предпроход` (там же, сообщение «в наборе два разных определения») держит
голое имя функции без модуля и без списков `только` из `использует`, и тёзки из
разных модулей считаются противоречием. Ни в одном из пяти случаев запись не
лжёт. Остальные коды 1 на библиотеке сняты: строковые литералы читаются
дословно, нульместные вызовы модулей и продолжения строк разбираются как в
языке; подделка «(длина "a:b") равен 5» отвечает кодом 1 (проверено сегодня на
flang 0.7.23).

## Что должно быть

Честная запись ядра — код 0 или код 3 с названной причиной, не код 1
(доктрина трёх исходов, `flang/proof/checker/README.md`). Объявление типа из
модуля, названного в `использует`, находится в исходнике поданного набора;
функция набора различается парой «модуль + имя», и тёзки из разных модулей
не спорят.

## Обходной путь

Обходного пути нет: код 1 остаётся при любом наборе.

## Когда задача сделана

Прогон из шагов воспроизведения на hmac, postgres, redis, tls,
tls-handshake с набором отвечает кодом 0 или 3, кодом 1 — ни один.
`sh flang/proof/checker/tests/run.sh` — «сошлось всё», принятых кодом 0 подделок 0,
отвергнутых честных 0; в семействах проб есть честная запись с типом чужого
модуля и честная с тёзками в наборе, и у каждой подделка (объявление подменено,
тёзка подсунута вместо вызванной) — код 1. Ответы на прежние записи дерева
с исходником — байт в байт прежние. `LEAN=~/.elan/bin/lean sh flang/proof/lean/run.sh`
— «сошлось всё».

## Где живёт правка

Проверяющая программа: `flang/proof/checker/checker.c` — сверка строки
«объявление» у принципа индукции (сообщение «объявления типа в исходнике нет»)
и реестр набора `предпроход`; потолок строк — `flang/proof/checker/ratchet.txt`;
храповик подделок — `flang/proof/forgeries/ratchet.txt`; пробы —
`flang/proof/checker/tests/run.sh` и `flang/proof/checker/tests/families/`.
Если строке «объявление» нужен модуль, печать записи — `flang/self/zapis.flang`,
и эта половина доезжает до двоичного только пересборкой семени (bootstrap
regeneration); правка на C её не требует.

Отдельная задача, здесь не решается: прогон доли доказанного
(`scripts/provability.fscript`) подаёт проверяющей программе набор по
транзитивному замыканию `использует`, и после этого решается, включать ли
библиотеку в набор доли.
