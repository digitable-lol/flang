# 4580. check --proof на файле с категорией отвечает кодом 2 «закон не посчитан ни на одном значении», хотя check тот же закон посчитал

Заявка: https://github.com/digitable-lol/flang/issues/401

`check` печатает «троек стрелок 1, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ» и код 0. `check --proof` на том же файле печатает ту же строку, а следом «закон не посчитан ни на одном значении», код 2 и без ведомости.

## Шаги воспроизведения

1. Программа `point.flang`:

```flang
модуль «Point»

тип «Один»
  вариант «Точка»

тотальная функция «Точки равны»
  принимает первая: «Один», вторая: «Один»
  возвращает признак
  обеспечивает «любые две точки равны» результат
  пример «точка равна себе»
    дано первая равно вариант «Точка»
    дано вторая равно вариант «Точка»
    ожидается да
  да

тотальная функция «В точку»
  принимает точка: «Один»
  возвращает «Один»
  пример «точка переходит в точку»
    дано точка равно вариант «Точка»
    ожидается вариант «Точка»
  вариант «Точка»

морфизм «в точку» из «Один» в «Один»
  даёт «В точку»

единица «Один»

категория «Терминальная»
  морфизм «в точку»
  объект «Один» даёт «Точки равны»
```

2. `bootstrap/flang check point.flang --proof`.

## Что происходит

```
$ bootstrap/flang check point.flang --proof
категория «Терминальная»: сетка 1 значений на 1 объектах, троек стрелок 1, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ, не доказано
законы этих объявлений НЕ СЧИТАЛИСЬ — категория «Терминальная»: устройство сверено, а закон не посчитан ни на одном значении, и ответ «замечаний нет» читался бы как «закон проверен», а это неправда
код 2
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

`check` и `check --proof` сходятся в оценке закона категории; под `--proof` ведомость печатается, законы категории на сетке — своим разделом.

## Обходной путь

Держать функции с `обеспечивает` в модуле без категорной поверхности.

## Когда задача сделана

`bootstrap/flang check point.flang --proof` — ведомость с «любые две точки равны» доказано, закон категории — «сетка», код 0.

## Где живёт правка

`flang/self/bootstrap/compiler.flang` (сводка законов), `flang/src/emit/c/flang_repl.c`. Ждёт печати семени.
