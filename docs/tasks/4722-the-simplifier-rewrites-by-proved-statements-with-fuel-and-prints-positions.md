# 4722. Переп1: переписка по доказанному утверждению, с топливом и позицией

Решение: [ADR-0040](../adr/0040-a-simplifier-rewrites-by-proved-equalities-and-prints-every-step.md).
Начинается **после задачи 4058** (те же файлы ядра, печати и сверщика) и рядом с
7359 (без индукции по строке «склейка ассоциативна» не докажется даже с Переп1).

## Чем измерено

13 сентября 2026, двоичный 0.7.19, дерево `5837f53f`. «Переписать до неподвижной»
(`proof-kernel.flang:5498`) переписывает только равенствами из фактов функции;
переписки по доказанным утверждениям нет; позиции переписки запись не печатает.
Пробы ADR-0039 §2: «склейка ассоциативна», «пустая строка нейтральна справа» —
объявлено, не доказано.

## Что сделать

1. Строка ведомости **Переп1** (посылки: утверждение `У` доказано на предыдущем
   витке; терм по позиции совпадает с `Л[x:=t]`; заключение — цель с `П[x:=t]` на
   той же позиции) и лемма Lean «замена равного равным»; ловушка — переписка
   недоказанным. ПЕРВЫМИ.
2. Приём сверщика: путь в терме, сличение обеих сторон подстановкой текстом,
   проверка, что запись утверждения `У` в том же корпусе — код 0 (как у п.13
   ADR-0026). Не больше 60 строк кода (бюджет ADR-0040 §3). РАНЬШЕ печати.
3. Ядро: сбор доказанных равенств вида `Л равен П` из утверждений программы и
   ввезённых модулей; ориентация слева направо; обход терма детерминированный;
   топливо `ПРЕДЕЛ_ПЕРЕПИСКИ` по образцу `ПРЕДЕЛ_РАЗВЁРТКИ`, отказ «предел
   переписки» — своим текстом; захват имён — сторож как у Э3/Э5; включение в
   «Нормализовать» после четырёх нынешних переписок.
4. Печать `zapis.flang`: шаг `Переп1` с именем утверждения, подстановкой и
   позицией; проверить сразу беду подстановки по пробельным краям (ADR-0026 §11
   п.15).
5. Пробы — новая семья `переписка`: честные (ассоциативность склейки при
   доказанной индукцией лемме из 7359; нейтраль пустой строки; закон монады из
   `flang/ct`, если 7359 и 6752 готовы), подделки (чужая позиция; недоказанное
   утверждение; перевёрнутая ориентация; захват).
6. Цена прохода `check --proof` на `flang/stdlib` до/после — числом; рост больше
   десятой — ограничить топливо и назвать.

## Чего не делать

Встроенную AC-нормализацию; переписку недоказанным; поиск (E-графы,
конгруэнтное замыкание); переписку справа налево. `bootstrap/**` не трогать.

### Порядок по зависимостям

1. **Lean и сверщик раньше ядра** (ADR-0040 §6, п.1–2 задачи): леммы, ловушки,
   приём сверщика, рукотворные записи. `flang/self` не тронут — вливается до
   перепечатки.
2. **Ядро и печать** (п.3–4) — правкой `flang/self`, отдельной веткой «⏸ после
   перепечатки». Строки ведомости Переп1 и Скл1–Скл3 встают вместе с ней:
   сторож С-1 пускает строку только с опорой в `proof-kernel.flang`.
3. **Законы поверхности утверждениями** (6752 Ш1–Ш2) — после п.2: они
   потребители упрощателя.
4. **Законы над целыми** — после точного целого (задача 1908, ADR-0036); её ведёт
   другой исполнитель, здесь она не делается. До неё законы моноида над `число`
   ложны по существу (6752 Ш0), и ядро их не доказывает.

### Поправка к ADR-0040 §2.3: законы склейки — правила о встроенной форме

ADR-0040 §2.3 ждал «склейка ассоциативна» индукцией по строке (7359) и
переписки Переп1 по доказанному так утверждению. Это не сходится: у встроенной
`соединить` в языке нет определения, которое ядро развернуло бы, и индукция по
строке упирается в то же встроенное равенство — шаг
«( голова ++ хвост ) ++ Б = голова ++ ( хвост ++ Б )» и есть ассоциативность
склейки с головой. Дорога через `разложить … на символы` добавляет к нему ещё
равенство о склейке списка знаков. Значит любое доказательство о `соединить`
стоит на лемме о встроенной форме, и прямая лемма — самая короткая: три закона
моноида склейки законами формы (как «Мера склейки» у её длины), каждый — лемма
Lean о модели, где текст — список знаков. Переп1 нужен по-прежнему — для законов
над функциями автора, доказанных утверждениями.

Граница модели названа у леммы «Скл1»: в языке склейка отказывает на стыке
половин суррогатной пары (цели с UTF-16) и на октете продолжения (цели с
октетами), в модели отказа нет; обе стороны каждого закона отказывают на одних
и тех же входах.

### Сделано веткой `a/4722-rewrite-by-proved-statements` (п.1 и п.2)

- **Lean.** `Rules.lean`: «Скл1», «Скл2», «Скл3», «равен-есть-равенство»,
  «Переп1», «Переп1-текст» и встречные примеры к ловушкам. `Term.lean`:
  «Скл1-терм»…«Скл3-терм», «Переп1-термТ», «Переп1-термЧ» — следствия
  «подстановкаТ» и «подстановка». `Trap.lean`: искажения 80–84. Прогон
  `flang/proof/lean/run.sh`: искажений 37, Lean отверг 37; аксиомы — три
  стандартные; лемм в файле 153 (было 142); сверка вердиктов C ↔ Lean —
  расхождений 0, «сошлось всё».
- **Сверщик.** Ход `переписать по свойству «И» строка M ⟨Л'⟩ = ⟨П'⟩ подстановка …`
  (Переп1): законность инстанции — путь хода `факт по свойству`, сверх него —
  голое равенство, без `таких что`, инстанция знак в знак, левая — в цели. Три
  закона формы склейки. Связывания одной строкой (`для всех а: Т и б: У`) путь
  инстанции теперь читает все. Строк кода 7397 → 7445 (+48) — в счёт ADR-0040
  (+60); потолок `ratchet.txt` поднят ровно на съеденное, 7481 → 7529.
- **Пробы** — семья `rewrite` (`flang/proof/checker/tests/families/rewrite/`,
  описание в `docs/`): честных 2 — код 0, подделок 12 — код 1 с названной
  причиной. Набор проб над `main` `1392ba3d9`: подделок 509 → 521, честных
  236 → 238, подделок, принятых кодом 0, — 0, «сошлось всё».
- **Отрицательный контроль**: вынутая сверка `""` у нейтрали — подделка принята
  кодом 0; вынутое сличение инстанции — две подделки приняты кодом 0; вынутый
  хвост « не» — ложное обещание принято кодом 0; две проверки (левая в цели,
  отказ по `таких что`) держат причину, а не код. Ветки «связка или выбор над
  равенством» пробой не держатся — такое утверждение сверщик доказанным не
  проигрывает; это сказано в описании семьи.
- **Находка в своей же проверке.** Первая версия Переп1 резала равенство по
  слову `равен`: «(длина "аб") не равен 3», доказанное счётом, читалось
  равенством «( длина "аб" ) не» = «3», и ложное «длина "аб" не больше 1»
  переписывалось в «3 больше 1» и закрывалось счётом. Копия без проверки хвоста
  « не» принимает эту запись кодом 0; подделка `negated-rewrite` держит.
