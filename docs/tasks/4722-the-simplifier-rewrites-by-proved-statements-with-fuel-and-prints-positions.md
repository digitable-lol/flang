# 4722. Переп1: переписка по доказанному утверждению, с топливом и позицией

Решение: [ADR-0040](../adr/0040-a-simplifier-rewrites-by-proved-equalities-and-prints-every-step.md).
Начинается **после задачи 4058** (те же файлы ядра, печати и сверщика) и рядом с
7359 (без индукции по строке «склейка ассоциативна» не докажется даже с Переп1).

## Чем измерено

13 сентября 2026, двоичный 0.7.19, дерево `5837f53f`. «Переписать до неподвижной»
(`proof-kernel.flang:5498`) переписывает только равенствами из фактов функции;
переписки по доказанным утверждениям нет; позиции переписки запись не печатает.
Пробы ADR-0039 §2: «склейка ассоциативна», «пустая строка нейтральна справа» —
объявлено, не доказано.

## Что сделать

1. Строка ведомости **Переп1** (посылки: утверждение `У` доказано на предыдущем
   витке; терм по позиции совпадает с `Л[x:=t]`; заключение — цель с `П[x:=t]` на
   той же позиции) и лемма Lean «замена равного равным»; ловушка — переписка
   недоказанным. ПЕРВЫМИ.
2. Приём сверщика: путь в терме, сличение обеих сторон подстановкой текстом,
   проверка, что запись утверждения `У` в том же корпусе — код 0 (как у п.13
   ADR-0026). Не больше 60 строк кода (бюджет ADR-0040 §3). РАНЬШЕ печати.
3. Ядро: сбор доказанных равенств вида `Л равен П` из утверждений программы и
   ввезённых модулей; ориентация слева направо; обход терма детерминированный;
   топливо `ПРЕДЕЛ_ПЕРЕПИСКИ` по образцу `ПРЕДЕЛ_РАЗВЁРТКИ`, отказ «предел
   переписки» — своим текстом; захват имён — сторож как у Э3/Э5; включение в
   «Нормализовать» после четырёх нынешних переписок.
4. Печать `zapis.flang`: шаг `Переп1` с именем утверждения, подстановкой и
   позицией; проверить сразу беду подстановки по пробельным краям (ADR-0026 §11
   п.15).
5. Пробы — новая семья `переписка`: честные (ассоциативность склейки при
   доказанной индукцией лемме из 7359; нейтраль пустой строки; закон монады из
   `flang/ct`, если 7359 и 6752 готовы), подделки (чужая позиция; недоказанное
   утверждение; перевёрнутая ориентация; захват).
6. Цена прохода `check --proof` на `flang/stdlib` до/после — числом; рост больше
   десятой — ограничить топливо и назвать.

## Чего не делать

Встроенную AC-нормализацию; переписку недоказанным; поиск (E-графы,
конгруэнтное замыкание); переписку справа налево. `bootstrap/**` не трогать.

## Как поймём, что сделано

Пункты 1–5 ADR-0040 §6 — числами: две пробы ADR-0039 §2 доказаны; подделки код 1;
Lean принял лемму и отверг ловушку; сверщик +≤60 строк; ДОКАЗУЕМ; цена прохода в
пределах десятой.
