# 4722. Равенства над строками не доказываются — ядро не переписывает цель по доказанным утверждениям и законам склейки

## Шаги воспроизведения

1. Программа из дерева,
   `flang/proof/checker/tests/families/rewrite/concat-laws.flang`:

```flang
модуль «Законы склейки»

утверждение «склейка ассоциативна»
  для всех а: строка и б: строка и ц: строка
  утверждаем (соединить (соединить а с б) с ц) равен (соединить а с (соединить б с ц))

утверждение «пустая строка нейтральна слева»
  для всех а: строка
  утверждаем (соединить "" с а) равен а

утверждение «пустая строка нейтральна справа»
  для всех а: строка
  утверждаем (соединить а с "") равен а
```

2. Команды:

```
bootstrap/flang check flang/proof/checker/tests/families/rewrite/concat-laws.flang --proof
bootstrap/flang check flang/proof/checker/tests/families/rewrite/rewrite-by-statement.flang --proof
grep -c 'Переп1\|переписать по свойству' flang/self/proof-kernel.flang flang/self/proof-record.flang flang/proof/tables/inference-rules.tsv
```

## Что происходит

```
$ bootstrap/flang check …/concat-laws.flang --proof
  утверждение «склейка ассоциативна» — объявлено, не доказано: ни теоремы, ни примеров. …
  утверждение «пустая строка нейтральна слева» — объявлено, не доказано: …
  утверждение «пустая строка нейтральна справа» — объявлено, не доказано: …
  утверждений 3: доказано 0, сетка 0, объявлено, не доказано 3    код 3
$ bootstrap/flang check …/rewrite-by-statement.flang --proof
  утверждений 4: доказано 0, сетка 2, объявлено, не доказано 2    код 3
$ grep -c 'Переп1\|переписать по свойству' …
flang/self/proof-kernel.flang:0
flang/self/proof-record.flang:0
flang/proof/tables/inference-rules.tsv:0
```

Версия: flang 0.7.25, прогон 11 октября 2026.

«Переписать до неподвижной» в `flang/self/proof-kernel.flang` переписывает цель
только равенствами из фактов самой функции. Доказанное утверждение программы
или ввезённого модуля в цель не подставляется, законов о встроенной склейке
`соединить` у ядра нет, а место переписки в записи доказательства не
печатается.

## Что должно быть

ADR-0040: ядро применяет правило «замена равного равным» (Переп1) по уже
доказанным равенствам, слева направо, с ограничением числа шагов и своим
текстом отказа при его исчерпании; три закона склейки (Скл1–Скл3) — правила о
встроенной форме; каждый шаг печатается в запись с именем утверждения,
подстановкой и позицией, и независимая проверяющая программа (proof checker)
его переигрывает.

## Обходной путь

Обходного пути нет: утверждение остаётся проверкой при работе программы.

## Когда задача сделана

- обе команды `check … --proof` из шагов отвечают «доказано» на «склейка
  ассоциативна» и «пустая строка нейтральна справа», код 0;
- запись, напечатанная двоичным для этих программ, принята программой
  `flang/proof/checker/checker.c` с кодом 0 И НЕ ВПУСТУЮ: пока свежая запись
  `concat-laws.record` не несёт ни одного «вердикт доказано», сверщик отвечает
  на ней кодом 0 со словами «ПРОВЕРЕНО ВПУСТУЮ», и один код возврата здесь
  ничего не различает. Различает число: в отчёте сверщика «сведений проиграно
  заново» равно 3 на `concat-laws` и 4 на `rewrite-by-statement`, а «Числятся
  доказанными» — 3 и 4 (столько даёт запись, лежащая рядом с пробами);
- шесть подделок из `flang/proof/checker/tests/families/rewrite/forged`
  (`commutative-law`, `nonempty-unit`, `unproven-statement`,
  `restricted-rewrite`, `or-rewrite`, `negated-rewrite`) по-прежнему отвергаются
  с кодом 1; две из них сняты с
  `flang/proof/checker/tests/families/rewrite/concat-false.flang`;
- в `flang/proof/tables/inference-rules.tsv` стоят строки Переп1 и Скл1–Скл3,
  `bootstrap/flang io flang/proof/tables-guard.fscript --max-steps 4000000000
  --timeout 900000` отвечает кодом 0;
- четыре подделки Переп1 — переписка недоказанным утверждением, чужая позиция,
  перевёрнутая ориентация, захват имени — уже стоят строками
  `flang/proof/checker/tests/probes.tsv` в семействе `rewrite`; заводить их
  заново не нужно, нужно чтобы после правки каждая по-прежнему отвечала кодом 1;
- время `check --proof` по файлам `flang/stdlib` до и после снято числом;
  рост больше десятой части — ограничение шагов ужесточено и названо.

Не делать: нормализацию по ассоциативности и коммутативности, переписку
справа налево, поиск доказательства.

## Где живёт правка

`flang/self/proof-kernel.flang`: сбор доказанных равенств, обход терма,
ограничение числа шагов, включение в «Нормализовать»; `flang/self/proof-record.flang`:
печать шага. Обе правки доезжают до двоичного только пересборкой семени
(bootstrap regeneration). `flang/proof/tables/inference-rules.tsv` и подделки
пересборки не требуют, но строка правила принимается проверкой таблицы только
вместе с опорой в ядре.

Леммы Lean (`flang/proof/lean/Rules.lean`) и приём шага в `flang/proof/checker/checker.c` уже
стоят в дереве, пробы к ним — в `flang/proof/checker/tests/families/rewrite`;
заново их писать не нужно.

Записи `concat-laws.record` и `rewrite-by-statement.record` в дереве не
перепечатаны: в них правило «тождество после переписки допущением», свежие

`probes.tsv` правкой sed.

**13 октября 2026** (ветка `a/rewrite-long-chains`, ADR-0092 §7): ведомость
называет «Предел переписки» при исчерпании; правила переписки собираются только у
функций, вызванных в цели (раньше — со всей программы на каждую попытку); замер
`check --proof` по `flang/stdlib`: 5041 с на 0.7.26 и 5247 с на первой печати партии
шесть (ADR-0092 §7.3). Обе правки — в исходнике ядра, до печати партии 7 двоичный их
не несёт.

Рост меньше десятой части, предел шагов не ужесточался. Правило «только у
вызванных функций» (ADR-0092 §7) вернуло то, что переписка забрала у партии 6:
против 0.7.27 быстрее всех стали `websocket.flang` (550 → 395 с) и `uuid.flang`
(499 → 345 с).

Оговорка: «сведений проиграно заново» на `rewrite-by-statement` — 6, а
критерий называет 4, снятые с записи в дереве; свежая запись несёт строку
«тотальностей 2», которой у записи в дереве нет. Записи пробы и их подделки
не перепечатаны.
