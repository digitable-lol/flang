# 4735. Строка «вложен объект» в теле объекта роняет двоичный вместо отказа или разбора

## Шаги воспроизведения

1. Программа вложенный.flang:

   ```flang
   модуль «Вложенный»

   объект «Заказ»
     номер является числом
     вложен объект «Адрес»
       город является строкой

   тотальная функция «Номер»
     принимает заказ: «Заказ»
     возвращает число
     заказ.номер
   ```

2. `flang check вложенный.flang`

## Что происходит

```
$ flang check вложенный.flang
FLANG_PROPERTY: нарушено свойство «узел разобрать поле записи зовётся named» функции «Разобрать поле записи»
…
FLANG_CLI: компилятор не связал сессию
вложенный.flang: не проверено — замечаний 1        код 1
```

Версия: flang 0.7.25, прогон 11 октября 2026. С `вложена структура` то же самое.

## Что должно быть

Либо разбор вложенного объекта как поля с типом записи, либо отказ разбора
`FLANG_PARSE` с местом и словами «старое слово, программу из него не составить»
(так `вложен объект` описан в DESCRIPTION.md, раздел «Старые слова»). Нарушенное
постусловие самого компилятора — дефект компилятора, а не программы.

## Обходной путь

Объявить вложенную запись отдельным `объект` и сослаться на неё полем.

## Когда задача сделана

`flang check вложенный.flang` отвечает названным отказом разбора либо принимает
программу; проба с этой программой стоит в наборе проб разбора.

## Где живёт правка

`flang/self/parser.flang` («Разобрать поле записи»); требует перепечатки семени.

**Следующий шаг.** Отказ разбора написан в исходнике: «Разобрать поле записи» на
`вложен объект` и `вложена структура` отвечает `FLANG_PARSE` с местом и словами «старое
слово, программу из него не составить». Набор проб разбора
`flang/proof/probes/nested-object/` (обе формы и обходной путь отдельным объектом) гонит
разборщик из исходника: `bootstrap/flang io flang/proof/probes/nested-object/run.fscript
--plan Binary --timeout 900000` — «проб 3, разошлось 0». До двоичного правка доезжает
печатью семени; после неё — прогнать `bootstrap/flang check` на программе из шагов и
закрыть задачу.
