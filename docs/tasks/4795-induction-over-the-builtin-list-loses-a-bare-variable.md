# 4795. Индукция по встроенному списку не доказывает равенство, где переменная индукции стоит голой: «Копия» от а равен а

Равенство двух вызовов индукцией по списку доказывается. Равенство, в котором на одной
стороне переменная индукции стоит без вызова (`f(а) равен а`), — нет: в базе на её место
встаёт значение «пусто», а другая сторона после развёртки даёт `пустой список`, и ядро их
не сличает; в шаге голая переменная не читается как `приписать голова к хвост`. На
объявленном типе с вариантами то же равенство доказывается.

## Шаги воспроизведения

1. Программа `flang/proof/probes/lean-parity-gaps/programs/bare-list-variable.flang`:

```flang
модуль «Голая переменная индукции по списку»

тотальная функция «Склеить»
  принимает первый: список числа, второй: список числа
  возвращает список числа
  пример «два и один»
    дано первый равно [1, 2]
    дано второй равно [3]
    ожидается [1, 2, 3]
  разбор первый
    случай пусто
      то второй
    случай голова и хвост
      то приписать голова к («Склеить» от хвост и второй)


тотальная функция «Копия»
  принимает элементы: список числа
  возвращает список числа
  пример «два»
    дано элементы равно [1, 2]
    ожидается [1, 2]
  разбор элементы
    случай пусто
      то пустой список
    случай голова и хвост
      то приписать голова к («Копия» от хвост)

утверждение «копия есть исходный»
  для всех а: список числа
  утверждаем («Копия» от а) равен а

утверждение «склейка с пустым есть копия»
  для всех а: список числа
  утверждаем («Склеить» от а и пустой список) равен («Копия» от а)
```

2. `bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/bare-list-variable.flang --proof --strict; echo $?`
3. Сосед на своём типе: `flang/proof/probes/category-laws-judged/programs/row-monoid.flang`
   («единица справа» доказана) против `list-monoid.flang` (не доказана).

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/bare-list-variable.flang --proof --strict
  утверждение «копия есть исходный» — объявлено, не доказано: ни теоремы, ни примеров …
  утверждение «склейка с пустым есть копия» — доказано индукцией по «список»: база 1 случай, шаг при допущении на частях (1 случай) …
… НЕ УДАЛОСЬ ДОКАЗАТЬ — ОБЪЯВЛЕНО, НЕ ДОКАЗАНО — утверждений 2: доказано 1 …                код 3
```

Теорема автора с `индукция по а` отвечает `FLANG_PROOF_INDUCTION_CASES … не разобраны и
ядром не закрыты «пусто» … разбор не покрывает значение пусто` и `FLANG_PROOF_INDUCTION_STEP
… шаг «голова и хвост» не сведён к допущениям на части «хвост»`, код 1
(`flang/proof/parity/programs/list-append-empty-by-hand.flang`).

Версия: flang 0.7.34 (`bootstrap/flang` из дерева, метка v0.7.34).

## Что должно быть

В посылках индукции по встроенному списку переменная индукции подставляется конструктором
везде, в том числе голая: в базе — `пустой список`, в шаге — `приписать голова к хвост`, и
обе записи пустого списка (значение базы и литерал) сличаются как один терм.
`(«Копия» от а) равен а` и `(«Склеить» от а и пустой список) равен а` — «доказано индукцией
по «список»», код 0.

Какое правило и где встанет. В `flang/self/proof-kernel.flang` — у «Разбор по
приписанному» (строка 1093, Разв4) и «Имя конструктора образца» (строка 1138, Инд1):
подстановка переменной индукции в цель посылки и приведение значения базы к литералу
пустого списка перед сличением («Одинаковы до порядка соседей», строка 320). В
`flang/proof/tables/inference-rules.tsv` — строка `Инд8` семьи `Инд` после `Инд7`:
«переменная индукции по списку читается конструктором».

## Обходной путь

Обхода на встроенном списке нет. На объявленном типе («Ряд» с вариантами «Конец» и
«Звено») то же утверждение доказывается.

## Когда задача сделана

`bootstrap/flang run-script lean-parity:gaps` краснеет на строке `bare-list-variable.flang`
(«утверждений 2: доказано 2», код 0). `bootstrap/flang run-script category-laws:probe`
краснеет на `list-monoid.flang` («доказано ядром 3»). В `flang/proof/parity/corpus.tsv`
`list-append-empty` переходит в `auto`; `list-reverse-append` и `list-reverse-reverse` —
после этой задачи и задачи 9211.

## Где живёт правка

`flang/self/proof-kernel.flang`, `flang/proof/tables/inference-rules.tsv`, оба сверщика.
