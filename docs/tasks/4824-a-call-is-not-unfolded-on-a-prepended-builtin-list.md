# 4824. Ядро не разворачивает функцию с разбором на «приписать Х к Л» встроенного списка, хотя на своём варианте разворачивает

Заявка: https://github.com/digitable-lol/flang/issues/402

«первое — приписанное» доказано на своём списке («Звено») и не доказано на встроенном: `«Первое или ноль» от (приписать значение к остаток)` не сводится в ветвь `голова и хвост`.

## Шаги воспроизведения

1. Программа `prepend.flang`:

```flang
модуль «Разворот на приписать»

тип «Свой список»
  вариант «Конец»
  вариант «Звено» содержит значение: неотрицательное, дальше: «Свой список»

тотальная функция «Первое или ноль»
  принимает элементы: список неотрицательное
  возвращает неотрицательное
  пример «пусто»
    дано элементы равно []
    ожидается 0
  разбор элементы
    случай пусто
      то 0
    случай голова и хвост
      то голова

тотальная функция «Первое после приписать»
  принимает значение: неотрицательное, остаток: список неотрицательное
  возвращает неотрицательное
  обеспечивает «первое — приписанное» результат равен значение
  пример «три»
    дано значение равно 3
    дано остаток равно [1]
    ожидается 3
  «Первое или ноль» от (приписать значение к остаток)

тотальная функция «Первое своего или ноль»
  принимает звенья: «Свой список»
  возвращает неотрицательное
  пример «конец»
    дано звенья равно вариант «Конец»
    ожидается 0
  разбор звенья
    случай «Конец»
      то 0
    случай вариант «Звено» с значение как значение
      то значение

тотальная функция «Первое своего после звена»
  принимает значение: неотрицательное, остаток: «Свой список»
  возвращает неотрицательное
  обеспечивает «первое — приписанное» результат равен значение
  пример «три»
    дано значение равно 3
    дано остаток равно вариант «Конец»
    ожидается 3
  «Первое своего или ноль» от (вариант «Звено» с значение равным значение и дальше равным остаток)
```

2. `bootstrap/flang check prepend.flang --proof`.

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Вызов функции, тело которой `разбор` по списку, на аргументе `приписать Х к Л` (и `[Х, …]`) разворачивается в ветвь `голова и хвост` с `голова := Х`, `хвост := Л`.

## Обходной путь

Свой тип-список вместо встроенного.

## Когда задача сделана

`bootstrap/flang check prepend.flang --proof` — «доказано 2», код 0. Подделка `результат равен 0` — не доказано.

## Где живёт правка

`flang/self/proof-kernel.flang` — разворот на конструкторе. Ждёт печати семени.
