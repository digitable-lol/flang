# 4850. Checker называет ложью тождество, доказанное ходом «вычислить» над незамкнутым термом

## Шаги воспроизведения

1. Программа `open.flang`:

```flang
модуль «Probe»

тотальная функция «Ф»
  принимает н: неотрицательное
  возвращает число
  обеспечивает «равен себе» н равен н
  0
```

2. `bootstrap/flang check open.flang --proof --strict --record open.rec`, затем
   `flang/proof/checker/сверщик open.flang open.rec`.
3. Смотреть коды возврата обеих команд.

## Что происходит

```
$ bootstrap/flang check open.flang --proof --strict --record open.rec
open.flang: ДОКАЗАНО — утверждений 1: доказано 1, … — код возврата 0          код 0
$ flang/proof/checker/сверщик open.flang open.rec
НЕ СОШЛОСЬ: утверждение «равен себе», сведение: вычислить «н»: терм не замкнут
(свободное имя или неарифметический конструктор) — считать нечего             код 1
```

Версия: flang 0.7.23.

В записи ядро пишет ходы `вычислить ⟨н⟩ = ⟨н⟩` и `закрыть тождеством`
(правило «тождество после переписки допущением»). Утверждение верно на любом
входе: `равен` сравнивает значения целиком, и `н равен н` истинно. Ход
`вычислить` checker принимает только над замкнутым термом и потому называет
запись ложью. То же с `длина` и с `плюс`: `(н плюс 1) равен (н плюс 1)`.

Когда всё утверждение взято в скобки — `(н равен н)` или `((н) равен (н))`, —
ядро режет его по слову `равен` без учёта скобок и пишет в запись
несбалансированные термы: `вычислить ⟨(н⟩ = ⟨н)⟩`. Checker отвечает «НЕ
СОШЛОСЬ: … вычислить: в цели «н равен н» нет терма «( н»». Ложного «доказано»
такая запись не даёт: `(н равен (н плюс 1))` и `((н плюс 1) равен н)` ядро не
доказывает. Опровергатель нашёл 20 программ обоих видов на 13 874 проверенных
(охота с зерном 20261001).

## Что должно быть

Код 1 checker — только для записи, которая утверждает неверное. Здесь ядро пишет в
запись сбалансированные термы, а для тождества — ход без `вычислить` над
свободным именем; либо checker принимает `вычислить` над термом, совпадающим со
своей парой знак в знак, либо отвечает кодом 3.

## Обходной путь

Нет: автор утверждения ничего не делает неверно.

## Когда задача сделана

`сверщик open.flang open.rec` отвечает кодом 0 или 3. Опровергатель
(`bootstrap/flang run-script falsifier:check`) перестаёт находить причину
двух причин `checker-calls-it-a-lie/НЕ СОШЛОСЬ: утверждение «…», сведение:
вычислить …`, и их строки уходят из
`flang/proof/probes/falsifier/expected-failures.tsv`.

## Где живёт правка

`flang/self/proofterm.flang` (какие ходы ядро пишет для тождества) — правка
самосборной части, доезжает перепечаткой; либо `flang/proof/checker/checker.c`
(ход «вычислить»).
