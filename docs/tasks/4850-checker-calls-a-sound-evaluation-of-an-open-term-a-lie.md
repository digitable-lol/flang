# 4850. Checker называет ложью тождество в скобках, доказанное ходом «вычислить»

## Шаги воспроизведения

1. Программа `open.flang`:

```flang
модуль «Probe»

тотальная функция «Ф»
  принимает н: неотрицательное
  возвращает число
  обеспечивает «равен себе» (н равен н)
  0
```

2. `bootstrap/flang check open.flang --proof --strict --record open.rec`, затем
   `flang/proof/checker/сверщик open.flang open.rec`.
3. Смотреть коды возврата обеих команд.

## Что происходит

```
$ bootstrap/flang check open.flang --proof --strict --record open.rec
open.flang: ДОКАЗАНО — утверждений 1: доказано 1, … — код возврата 0          код 0
$ flang/proof/checker/сверщик open.flang open.rec
НЕ СОШЛОСЬ: утверждение «равен себе», сведение: вычислить: в цели «н равен н»
нет терма «( н»                                                               код 1
```

Версия: flang 0.7.25, checker собран из `flang/proof/checker/checker.c` того же
дерева.

Когда всё утверждение взято в скобки — `(н равен н)` или `((длина б)) равен
((длина б))`, — ядро режет его по слову `равен` без учёта скобок и пишет в запись
несбалансированные термы: `вычислить ⟨(н⟩ = ⟨н)⟩`. Checker не находит такого
терма в цели и называет запись ложью. Утверждение верно на любом входе. Ложного
«доказано» такая запись не даёт: `(н равен (н плюс 1))` и `((н плюс 1) равен н)`
ядро не доказывает. Тождество без скобок (`н равен н`) checker принимает кодом 0.

## Что должно быть

Код 1 checker — только для записи, которая утверждает неверное. Здесь ядро пишет в
запись сбалансированные термы, а для тождества — ход без `вычислить` над
свободным именем; либо checker принимает `вычислить` над термом, совпадающим со
своей парой знак в знак, либо отвечает кодом 3.

## Обходной путь

Нет: автор утверждения ничего не делает неверно.

## Когда задача сделана

`сверщик open.flang open.rec` отвечает кодом 0 или 3. Опровергатель
(`bootstrap/flang run-script falsifier:hunt`) перестаёт находить причину
`checker-calls-it-a-lie/НЕ СОШЛОСЬ: утверждение «…», сведение: вычислить: в цели
«…» нет терма «…»`, и её строка уходит из
`flang/proof/probes/falsifier/expected-failures.tsv`.

## Где живёт правка

`flang/self/proofterm.flang` (какие ходы ядро пишет для тождества) — правка
самосборной части, доезжает перепечаткой; либо `flang/proof/checker/checker.c`
(ход «вычислить»).
