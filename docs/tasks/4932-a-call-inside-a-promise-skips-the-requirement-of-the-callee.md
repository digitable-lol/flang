# 4932. Вызов в тексте обещания обходит требование вызванной

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/requirement-skipped-inside-a-promise.flang`:

```flang
модуль «Требование вызванной в тексте обещания»

тотальная функция «Положительное как есть»
  принимает а: число
  требует «довод положителен» а больше 0
  возвращает число
  обеспечивает «итог положителен» результат больше 0
  а

тотальная функция «Единица»
  принимает х: число
  возвращает число
  обеспечивает «вызванная положительна» («Положительное как есть» от х) больше 0
  1
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/requirement-skipped-inside-a-promise.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/requirement-skipped-inside-a-promise.flang --function 'Единица' --args '{"х":-5}'`

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/typing-holes/programs/requirement-skipped-inside-a-promise.flang --proof
… ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — … доказано
$ bootstrap/flang run flang/proof/probes/typing-holes/programs/requirement-skipped-inside-a-promise.flang --function 'Единица' --args '{"х":-5}'
FLANG_PROPERTY: нарушено свойство «итог положителен» функции «Положительное как есть»                                  код 1
```

Версия: flang 0.7.34.

Обещание `(«Положительное как есть» от х) больше 0` зовёт функцию при `х = −5`, вне её `требует`. Места снятия
предусловий собираются только из тела («Места функции», `flang/self/proofterm.flang`), а «Постусловия вызванных»
дают инстанцию постусловия любому вызову в заключении. При запуске `требует` на таком вызове тоже не считается.
То же в свободном `утверждение` с `по свойству` и через сахар `класс` с `всегда`.

## Что должно быть

Вызов в тексте `обеспечивает`, `утверждение`, `требует`, `затем` — место снятия предусловия, как вызов в теле;
постусловие вызванной даёт факт только при снятом `требует`.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check flang/proof/probes/typing-holes/programs/requirement-skipped-inside-a-promise.flang --proof` не числит ложное утверждение доказанным.
Проба — строки этой программы в `flang/proof/probes/typing-holes/expected.tsv`
и строка ведомости `flang/proof/tables/typing-holes.tsv`: сегодня они держат ответ
двоичного 0.7.34, после правки строка `proof` меняется, строка ведомости — на `закрыта`.

## Где живёт правка

`flang/self/proofterm.flang`, «Места функции» и «Постусловия вызванных»; вычислитель — проверка `требует` при счёте
постусловия. Правки в этой ветке нет. Требует печати семени.
