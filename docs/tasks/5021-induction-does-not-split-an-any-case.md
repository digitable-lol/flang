# 5021. Индукция по типу с вариантами не доказывает постусловие, если часть вариантов собрана в «случай любое»

Заявка: https://github.com/digitable-lol/flang/issues/405

С явно перечисленными вариантами «не красный» доказан индукцией по «Цвет»; та же функция с `случай любое` — «сетка».

## Шаги воспроизведения

1. Программа `any-case.flang`:

```flang
модуль «Случай любое в доказательстве»

тип «Цвет»
  вариант «Красный»
  вариант «Зелёный»
  вариант «Синий»

тотальная функция «Красный ли»
  принимает цвет: «Цвет»
  возвращает признак
  пример «красный»
    дано цвет равно вариант «Красный»
    ожидается да
  разбор цвет
    случай «Красный»
      то да
    случай любое
      то нет

тотальная функция «Не красный через любое»
  принимает цвет: «Цвет»
  возвращает «Цвет»
  обеспечивает «не красный» («Красный ли» от результат) равен нет
  пример «синий»
    дано цвет равно вариант «Синий»
    ожидается вариант «Синий»
  разбор цвет
    случай «Синий»
      то вариант «Синий»
    случай любое
      то вариант «Зелёный»

тотальная функция «Не красный явно»
  принимает цвет: «Цвет»
  возвращает «Цвет»
  обеспечивает «не красный» («Красный ли» от результат) равен нет
  пример «синий»
    дано цвет равно вариант «Синий»
    ожидается вариант «Синий»
  разбор цвет
    случай «Синий»
      то вариант «Синий»
    случай «Красный»
      то вариант «Зелёный»
    случай «Зелёный»
      то вариант «Зелёный»
```

2. `bootstrap/flang check any-case.flang --proof`.

## Что происходит

```
$ bootstrap/flang check any-case.flang --proof
  постусловие «не красный» функции «Не красный через любое» — сетка 1 значение (примеры функции): нарушений НЕ ИСКАЛИ — прогона примеров не было, посчитано только их число. Это не доказательство — теоремы при утверждении нет
  постусловие «не красный» функции «Не красный явно» — доказано индукцией по «Цвет»: база 3 случая, шаг при допущении на частях (0 случаев), правила сведения: тождество после переписки допущением — утверждение обо ВСЕХ входах типа «Цвет», а …
any-case.flang: ПРОВЕРЕНО С ОПОРОЙ, И ОПОРА НЕ СУДИЛАСЬ (спросить: --строго) — утверждений 2: доказано 1, условно 0, сетка 1, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
код 0
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

`случай любое` раскрывается в оставшиеся варианты, и цель доказывается для каждого.

## Обходной путь

Расписать все варианты явно.

## Когда задача сделана

`bootstrap/flang check any-case.flang --proof` — «не красный» доказан индукцией по «Цвет», база 3 случая. Подделка: `вариант «Красный»` в `случай любое` — не доказано.

## Где живёт правка

`flang/self/proof-initial.flang` — принцип индукции. Ждёт печати семени.
