# 5204. Ярлык «guards:check» обещает смотреть каждый файл проверок дерева, а смотрит три

## Шаги воспроизведения

1. `bootstrap/flang run-script guards:check`
2. `grep -oE '(bootstrap/flang io|node|sh) [^ =]+' .flangrc | awk '{print $NF}' | sort -u | wc -l`
3. `grep -n 'script.guards:check' .flangrc`
4. Обратная проба: испортить первую строку любого сторожа на `.fscript`
   (`scripts/guards/homebrew-formula-guard.fscript`) и позвать ярлык снова.

## Что происходит

```
$ bootstrap/flang run-script guards:check
файлов проверок «*.test.mjs» в дереве 3; заводятся 3; НЕ ЗАВОДЯТСЯ 0; досмотреть не удалось 0     код 0 за 15 с
$ grep -oE '(bootstrap/flang io|node|sh) [^ =]+' .flangrc | awk '{print $NF}' | sort -u | wc -l
111
$ sed -i '1s/^/СЛОМАНО /' scripts/guards/homebrew-formula-guard.fscript
$ bootstrap/flang run-script guards:check
файлов проверок «*.test.mjs» в дереве 3; заводятся 3; НЕ ЗАВОДЯТСЯ 0; досмотреть не удалось 0     код 0
```

Объявление ярлыка в самом сценарии (функция «Объявление короткой команды
guards:check» в `flang/scripts/guards-start.fscript`) обещает: «каждый файл
проверок дерева ЗАВОДИТСЯ; не завёлся — назван поимённо и дословно». Отбор в том
же сценарии идёт только по образцу `*.test.mjs`, поэтому из 111 файлов команд,
стоящих за ярлыками `.flangrc`, просмотрены три. Обратная проба это и
показывает: сторож на `.fscript`, нарочно сломанный так, что не заводится, не
назван, и ярлык по-прежнему отвечает кодом 0.

Версия: flang 0.7.23, 2 октября 2026.

## Что должно быть

Ярлык пробует завести каждый файл команды, названный в `.flangrc`, и берёт
их список из самого `.flangrc`, а не из второго списка. Пока охват неполон,
объявление ярлыка называет то, что просмотрено на деле.

## Обходной путь

Нет: незаводящуюся проверку находят, только позвав её ярлык руками.

## Когда задача сделана

- `bootstrap/flang run-script guards:check` называет число просмотренных файлов, и оно равно
  числу различных файлов команд в `.flangrc`;
- обратная проба: проверка, нарочно сломанная так, что не заводится (например
  `scripts/guards/homebrew-formula-guard.fscript` с испорченной первой строкой),
  названа поимённо, код возврата не 0.

## Где живёт правка

`flang/scripts/guards-start.fscript` (отбор файлов по образцу `*.test.mjs`,
строка итога и функция объявления ярлыка), запись `script.guards:check` в
`.flangrc`. Перепечатка не нужна.
