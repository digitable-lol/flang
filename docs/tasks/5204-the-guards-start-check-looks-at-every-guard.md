# 5204. Ярлык «сторожа:проверка» обещает смотреть каждый файл проверок дерева, а смотрит три

## Шаги воспроизведения

1. `bootstrap/flang run-script guards:check`
2. `grep -oE '"(bootstrap/flang io|node|sh) [^" ]+' ярлыки.flang | awk '{print $NF}' | sort -u | wc -l`
3. `grep -n -A4 '"сторожа:проверка"' ярлыки.flang`

## Что происходит

```
$ bootstrap/flang run-script guards:check
файлов проверок «*.test.mjs» в дереве 3; заводятся 3; НЕ ЗАВОДЯТСЯ 0; досмотреть не удалось 0     код 0
$ grep -oE '"(bootstrap/flang io|node|sh) [^" ]+' ярлыки.flang | awk '{print $NF}' | sort -u | wc -l
103
```

Поле «зачем» ярлыка говорит: «каждый файл проверок дерева заводится; не завёлся —
назван поимённо и дословно». Отбор в `flang/scripts/guards-start.fscript` идёт
только по образцу `*.test.mjs`, поэтому из ста с лишним файлов команд, стоящих за
ярлыками, просмотрены три. Проверка на `.fscript`, которая перестала
заводиться, даёт тот же ответ и код 0.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Ярлык пробует завести каждый файл команды, названный в `ярлыки.flang`, и берёт
их список из самого `ярлыки.flang`, а не из второго списка. Пока охват неполон,
поле «зачем» называет то, что просмотрено на деле.

## Обходной путь

Нет: незаводящуюся проверку находят, только позвав её ярлык руками.

## Когда задача сделана

- `bootstrap/flang run-script guards:check` называет число просмотренных файлов, и оно равно
  числу различных файлов команд в `ярлыки.flang`;
- обратная проба: проверка, нарочно сломанная так, что не заводится (например
  `scripts/guards/homebrew-formula-guard.fscript` с испорченной первой строкой),
  названа поимённо, код возврата не 0.

## Где живёт правка

`flang/scripts/guards-start.fscript` (отбор файлов по образцу `*.test.mjs` и
строка итога), запись ярлыка `сторожа:проверка` в `ярлыки.flang`. Перепечатка
не нужна.
