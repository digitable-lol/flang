# 5243. В языке нет точного дробного — деление над точными значениями не определено

## Шаги воспроизведения

1. Программа:

   ```
   модуль «Деление точных»

   тотальная функция «Половина»
     возвращает точное целое
     [1] делить на [2]
   ```

2. `bootstrap/flang check <файл>`
3. Смотреть вывод и код возврата.

## Что происходит

```
$ bootstrap/flang check division-over-exact-is-refused.flang
над точным целым «div» не определено: точное целое знает «плюс», «минус» и «умножить на»   код 1
```

Версия: flang 0.7.24, семя партии печати 2. Дата прогона: 4 октября 2026.
Рядом — `(0.1 плюс 0.2) плюс 0.3` → `0.6000000000000001`, `0.1 плюс (0.2 плюс 0.3)` → `0.6`.

## Что должно быть

Тип `точное дробное`: пара канонических точных целых, сокращаемая при каждом
действии, с `плюс`, `минус`, `умножить на`, `делить на` и порядком; записанный
литерал сверяется на канон при проверке типов; отказы ниже нуля и на нулевую
дробь — словом, не значением. Над точным целым — `остаток от`. Разбор и доводы —
ADR-0062.

## Обходной путь

Нет: деление над точными значениями не выражается, остаток — тоже.

## Когда задача сделана

- `flang/self`: тип, лексер, разборщик, вычислитель — есть в ветке, четыре
  `check` зелёные (65 с, 74 с, 188 с, 13 с).
- Семя перепечатано, набор проб `flang/proof/probes/exact-fraction/` снят
  измерительным двоичным и `expected.tsv` заполнена замером, не предсказанием.
- Печать в десять целей — отдельной задачей, как 1413 для точного целого.

## Где живёт правка

`flang/self/interpret.flang` (деление разрядов, НОД, дробь, остаток),
`flang/self/types.flang` (вид, канон литерала, счёт), `flang/self/lexer.flang`,
`flang/self/parser.flang`, `flang/proof/probes/exact-fraction/`, ADR-0062.
