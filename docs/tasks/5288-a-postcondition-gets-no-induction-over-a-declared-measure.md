# 5288. Постусловие функции с объявленной мерой не доказывается индукцией по мере, а спуск меры «н минус счётчик» не выводится

Функция, которая спускается на единицу по аргументу `неотрицательное`, получает и
доказанное завершение, и индукцию для своего постусловия. Функция с `убывает М`, где мера —
выражение (`н минус счётчик`) или спуск идёт через вызов (`«Половина» от н`), не получает
ни того, ни другого: спуск «на веру» со сторожем, постусловие — «сетка».

## Шаги воспроизведения

1. Программа `flang/proof/probes/lean-parity-gaps/programs/induction-over-a-declared-measure.flang`:

```flang
модуль «Индукция по объявленной мере»

тотальная функция «Дойдёт»
  принимает н: неотрицательное, счётчик: число
  возвращает признак
  обеспечивает «счёт доходит до предела» результат равен да
  убывает н минус счётчик
  пример «с нуля до трёх»
    дано н равно 3
    дано счётчик равно 0
    ожидается да
  если не (счётчик меньше н)
    то да
    иначе «Дойдёт» от н и (счётчик плюс 1)
```

2. `bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/induction-over-a-declared-measure.flang --proof --strict; echo $?`
3. Сосед с точным шагом: `flang/proof/probes/lean-parity-gaps/programs/induction-over-an-exact-step.flang` — то же постусловие,
   спуск `осталось минус 1`.
4. Спуск через вызов: `flang/proof/probes/lean-parity-gaps/programs/declared-measure-through-a-call.flang`.

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/induction-over-a-declared-measure.flang --proof --strict
  «Дойдёт»  доказано объявленной мерой: убывает «н» минус «счётчик»; спуск ядром не выведен — на веру: мера объявлена автором, сторож считает её при работе на каждом витке — 1 место
  постусловие «счёт доходит до предела» функции «Дойдёт» — сетка 1 значение (примеры функции) …
… НЕ УДАЛОСЬ ДОКАЗАТЬ — ОПОРА НЕ СУДИЛАСЬ — утверждений 1: доказано 0 … сетка 1 …           код 3
$ bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/induction-over-an-exact-step.flang --proof --strict
  постусловие «счёт доходит до предела» функции «Дойдёт» — доказано индукцией по «неотрицательное»: база 1 случай, шаг при допущении на убывшем «осталось» (1 случай) …
… ДОКАЗАНО — утверждений 1: доказано 1 …                                                    код 0
```

Версия: flang 0.7.34 (`bootstrap/flang` из дерева, метка v0.7.34).

## Что должно быть

1. Спуск меры `А минус Б` на витке, где условие ветви даёт `Б меньше А`, а вызов заменяет
   `Б` на `Б плюс К` при целом положительном `К`, выводится ядром — сторожа нет.
2. Спуск через вызов выводится из доказанного постусловия вызванной функции
   (`результат меньше значение` при `значение не меньше 1`).
3. Постусловие функции с доказанным спуском меры доказывается индукцией по мере: допущение —
   постусловие на каждом рекурсивном вызове тела (вполне упорядоченная индукция, в Lean —
   `fun_induction` и `Nat.strongRecOn`). Мера, принятая «на веру», допущения не даёт:
   вердикт «условно».

Какое правило и где встанет. Спуск — в `flang/self/totality.flang`, у «Шаг спуска
объявленной меры» (строка 4697, Мер1): две новые формы шага. Индукция — в
`flang/self/proof-kernel.flang`, у «Отрезок даёт принцип утверждению» (строка 7263, Инд5),
и в `flang/self/proof.flang`, «Индукция ядра» (строка 1840). В
`flang/proof/tables/inference-rules.tsv` — строки `Мер2` («спуск разности при растущем
вычитаемом»), `Мер3` («спуск через постусловие вызванной») семьи `Мер` и `Инд10`
(«индукция по объявленной мере») семьи `Инд`.

## Обходной путь

Заменить меру запасом шагов по объявленному типу: `«Отсчёт»` с параметром `осталось: «Нат»`
— `flang/proof/parity/programs/loop-countdown-while-by-hand.flang`, код 0.

## Когда задача сделана

`bootstrap/flang run-script lean-parity:gaps` краснеет на строках
`induction-over-a-declared-measure.flang` («утверждений 1: доказано 1», код 0) и
`declared-measure-through-a-call.flang` («сторожей в рантайме: 0 мест»). В
`flang/proof/parity/corpus.tsv` `loop-countdown-while` переходит из `by-hand` в `auto`;
`nat-halving-measure` — после этой задачи и правила о границе частного `(н минус (н остаток от 2)) делить на 2 не больше н`.

## Где живёт правка

`flang/self/totality.flang`, `flang/self/proof-kernel.flang`, `flang/self/proof.flang`,
`flang/proof/tables/inference-rules.tsv`, оба сверщика. Требует печати семени.
