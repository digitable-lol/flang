# 5295. «НЕ СОШЛОСЬ» сверщика не меняет приговора и кода: check --proof --строго печатает «ДОКАЗАНО» и код 0, а совет называет ввоз у файла без ввоза

Найдено при разборе заявок 391, 415 и 416. Сверщик отвечает кодом 1 — «запись противоречит исходнику», — а приговор остаётся «ДОКАЗАНО», код 0. Строка о сверщике объясняет расхождение ввозом («файлу с ввозом сверщику нужны записи ввезённых модулей ключом --зависимость»), хотя ввоза в файле нет.

## Шаги воспроизведения

1. Программа predicate.flang:

```flang
модуль «Проба предиката»

тип «Эндпойнт»
  вариант «Простаивает»
  вариант «Ждут» содержит очередь: список неотрицательное

тотальная функция «Правилен»
  принимает эп: «Эндпойнт»
  возвращает признак
  пример «простой»
    дано эп равно вариант «Простаивает»
    ожидается да
  разбор эп
    случай «Простаивает»
      то да
    случай вариант «Ждут» с очередь как о
      то (длина о) больше 0

тотальная функция «Простой»
  принимает н: неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «любой»
    дано н равно 1
    ожидается вариант «Простаивает»
  вариант «Простаивает»

тотальная функция «Из одного»
  принимает н: неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «один»
    дано н равно 1
    ожидается вариант «Ждут» с очередь равным [1]
  вариант «Ждут» с очередь равным [н]

тотальная функция «Снять первого»
  принимает о: список неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «два»
    дано о равно [4, 5]
    ожидается вариант «Ждут» с очередь равным [5]
  разбор о
    случай пусто
      то вариант «Простаивает»
    случай голова и хвост
      то «По хвосту» от хвост

тотальная функция «По хвосту»
  принимает ост: список неотрицательное
  возвращает «Эндпойнт»
  обеспечивает «правилен» «Правилен» от результат
  пример «пусто»
    дано ост равно []
    ожидается вариант «Простаивает»
  разбор ост
    случай пусто
      то вариант «Простаивает»
    случай голова и хвост
      то вариант «Ждут» с очередь равным ост
```

2. `bootstrap/flang check predicate.flang --proof --строго`.

## Что происходит

```
$ bootstrap/flang check predicate.flang --proof --строго
predicate.flang: ДОКАЗАНО — утверждений 4: доказано 4, условно 0, сетка 0, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
predicate.flang: НЕЗАВИСИМО НЕ ПРОВЕРЕНО — сверщик не сошёлся с записью (код 1; файлу с ввозом сверщику нужны записи ввезённых модулей ключом --зависимость): все 4 доказанных стоят на слове ядра
код 0
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Код 1 сверщика под `--строго` делает приговор «НЕ ДОКАЗАНО — сверщик не сошёлся» с ненулевым кодом; без `--строго` строка о сверщике стоит в приговоре, а не после него. Причина «файлу с ввозом» печатается только у файла с ввозом.

## Обходной путь

Звать сверщик отдельно и смотреть его код.

## Когда задача сделана

`bootstrap/flang check predicate.flang --proof --строго` при сверщике с кодом 1 — ненулевой код и названная причина. Пока заявка 391 открыта, этот файл и есть проба.

## Где живёт правка

`flang/src/emit/c/flang_repl.c` (и `bootstrap/flang_repl.c`) — сводка `--proof`; `flang/messages/catalog.tsv`.
