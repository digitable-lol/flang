# 5309. Силлогизм должен читаться как силлогизм

Решения приняты.
[ADR-0047](../adr/0047-a-syllogism-gets-one-surface-word-not-four.md): из четырёх
предложенных слов поверхности — `род`, `закон`, `факт`, `следует` — в язык вошло
одно, `следует`.
[ADR-0050](../adr/0050-a-reasoning-is-written-as-declared-words-and-fixed-sentences.md):
рассуждение записывается объявленными словами и закрытым набором предложений, без
словаря русской морфологии в языке.

## Шаги воспроизведения

1. `wc -l flang/proof/probes/syllogism/programs/honest.flang`
2. `bootstrap/flang io flang/proof/probes/syllogism/run.fscript --plan Binary`
3. `bootstrap/flang check flang/proof/probes/syllogism/programs/removal-strict.flang --proof`
4. `bootstrap/flang run-script word:occupancy род закон факт`

## Что происходит

```
$ wc -l flang/proof/probes/syllogism/programs/honest.flang
23
$ bootstrap/flang io flang/proof/probes/syllogism/run.fscript --plan Binary
syllogism: проб 6, разошлось 0                                           код 0
$ bootstrap/flang check …/programs/removal-strict.flang --proof
ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — утверждений 2: доказано 2, условно 0 …        код 0
$ bootstrap/flang run-script word:occupancy род закон факт
«род»    голым именем 43 — СЛОМАЕТСЯ столько мест
«закон»  ЗАНЯТО: слово уже ключевое — конструкция «lawBlock»; цепочкой 9
«факт»   голым именем 0 — свободно                                       код 1
```

Силлогизм о Сократе — 23 строки: тип, функция-предикат с постусловием, два
утверждения и `следует`. Вошедшее слово сняло одну строку и обвязку не снимает:
`род` и `факт` в язык не вошли, а `закон` занят языком — так зовётся закон
морфизма, который двоичный СЧИТАЕТ НА СЕТКЕ, и второе значение свело бы под одним
словом «посчитано» и «доказано».

Рассуждение не является словом языка: переводчик
`flang/proof/probes/syllogism/sentences/translator.flang` стоит ПЕРЕД компилятором.
Что понадобится печати, чтобы его убрать, перечислено в ADR-0050 §9.

Занятость `род` — 43 голых имени в пяти файлах:
`flang/scripts/link-collision-tree.fscript` (14),
`scripts/guards/name-collision-guard.fscript` (14),
`flang/scripts/name-guard.fscript` (9), `fspec/guard.flang` (4),
`flang/stdlib/registry.flang` (2); три из них — живые сторожа. Ключевое слово в
flang не может быть именем, и компилятор говорит это дословно: «это слово занято
языком, именем оно быть не может». Лечится переименованием в ёлочки, но это 43
правки в чужом коде за одну сэкономленную строку.

Версия: flang 0.7.23.

## Что лежит в дереве и зелено

* `flang/proof/probes/syllogism/` — шесть программ против `expected.tsv` в двух
  столбцах: слово в ответе двоичного и слово в ответе компилятора, напечатанного
  в JavaScript (план `JavaScript`, каталог печати — в `PRINTED_COMPILER`).
  Столбцы не слиты нарочно: таблица сверяет две реализации, и расхождение между
  ними останется видимым. Коды прогонов двоичным: `honest` 0, `removal` 1,
  `forgery` 1, `chain` 0, `removal-strict` 0, `conditional` 3.
* `flang/proof/probes/syllogism/assumptions/` — 19 программ, посылки
  допущениями, 30 проб: ядро и независимая проверяющая программа. Силлогизм о
  Сократе, Barbara, Celarent, Darii, Ferio доказаны; пять ошибочных модусов и
  Barbara без среднего шага отвергнуты кодом 1 с именем шага; Camestres
  доказывается только опровержением (`утверждаем нет`) — введения отрицания у
  ядра нет. Проверяющая программа на двух формах отвечает кодом 3 («выводы из
  допущений не переигрываю»), на двух — кодом 1.
* `flang/proof/probes/syllogism/sentences/` — переводчик и 62 текста: 28
  правильных форм дают «СЛЕДУЕТ: предложение 3 выведено из посылок 1, 2», 22
  ошибочных — «НЕ СЛЕДУЕТ …» с примером против, 12 — отказ прочесть текст
  (необъявленное слово, несогласованная форма, образец вне набора, беда словаря).
  `--plan Binary --max-steps 40000000` — проб 62, разошлось 0, код 0, 43 с.
* `fspec/spec/43-syllogism-overdue-subscription.flang` — пример предметной
  области: `check --proof` даёт утверждений 2, доказано 2, код 0 за 0,10 с.
  Написан двумя функциями нарочно: свободное утверждение в каталоге спек
  `fspec/guard.flang` прочесть не умеет и говорит это строкой 253: у утверждений
  отчёта не читаются поля `of`, `name` или `verdict`. Это беда сторожа, а не
  свойство языка.
* Все три набора стоят шагами в `.github/workflows/binary.yml`.

Полный перебор 256 модусов четырёх фигур — замер ADR-0050 §3 на порождённых
текстах; в дереве этих текстов нет, своим прогоном он не повторяется.

## Что осталось

1. **Слово для рода — выбор владельца:** оставить `тип`, заплатить 43
   переименования или взять другое слово. Занятость спрашивается ДО правки
   грамматики, а не после.
2. **Дыра `removal-strict`:** в этой форме заключение от посылки НЕ ЗАВИСИТ.
   Посылка `утверждение «все люди смертны»` и постусловие предиката «всякий
   человек смертен» говорят одно и то же дважды, ядро берёт постусловие, и
   снесённая посылка заключения не роняет — шаг 3 выше. Снять постусловие —
   заключение выводится только через посылку, но сама посылка становится
   «объявлено, не доказано», и файл уходит кодом 3 («доказано ПРИ УСЛОВИИ»,
   `conditional.flang`). Выбор между двумя состояниями — не про слово
   поверхности, ни один сахар его не снимает.
3. **Рассуждение как файл языка** — последний пункт ADR-0050 §9: вид файла со
   своим разбором, разворачивающийся в то же, что печатает план `Translate`.

## Чего задача НЕ делает

Не заводит логику высказываний и не трогает ядро: слово поверхности обязано
разворачиваться в то, что ядро уже умеет. Не разворачивается — это не сахар,
а новое правило вывода, и оно идёт отдельной задачей с ADR. Согласие двух судей
на силлогизме даёт проверяющая программа, а не слово поверхности; гипотезу
теоремы с утверждением сверяет ядро (`FLANG_PROOF_CLAIM_MISMATCH`).

## Фальсификатор

**Слово берётся только после `word:occupancy`.** Есть у слова голые вхождения вне
проб этой задачи — слово не берётся: ломается каждое такое место. Проба
различает: `word:occupancy род` печатает 43 и отвечает кодом 1, `факт` — 0.

**Изъятие посылки.** `removal.flang` (посылка снесена, теорема оставлена) обязан
отвечать кодом 1 «ни одного шага» — отвечает. `removal-strict.flang` обязан
перестать отвечать «доказано 2»; строка таблицы ходит храповиком и пока ждёт
«доказано 2», пункт 2 открыт и назван вслух.

## Когда задача сделана

1. Строка `removal-strict.flang` в `expected.tsv` ждёт НЕ «доказано 2» —
   снесённая посылка роняет заключение и в этой форме, — и
   `bootstrap/flang io flang/proof/probes/syllogism/run.fscript --plan Binary`
   отвечает кодом 0 с новым ожиданием.
2. Выбор слова для рода записан в ADR: слово взято и `word:occupancy` по нему
   печатает 0 голых имён, либо `тип` оставлен и это сказано вслух.
3. Решение о рассуждении как файле языка принято или отвергнуто в ADR; принято —
   разбор такого файла даёт то же дерево, что печатает план `Translate`.

## Где живёт правка

Слова поверхности — `flang/self/lexer.flang` и `flang/self/parser.flang`; до
двоичного правка там доезжает только перепечаткой семени
(`sh scripts/bootstrap-reprint.sh`). Пробы и таблицы —
`flang/proof/probes/syllogism/**`, шаги — `.github/workflows/binary.yml`, пример
— `fspec/spec/`.
