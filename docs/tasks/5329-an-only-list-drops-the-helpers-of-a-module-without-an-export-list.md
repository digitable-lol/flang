# 5329. Список «только» теряет помощников модуля без списка «экспортирует»

## Шаги воспроизведения

1. lib.flang:

   ```flang
   модуль «Цены»

   тотальная функция «Скидка»
     принимает цена: число
     возвращает число
     цена делить на 10

   тотальная функция «Цена со скидкой»
     принимает цена: число
     возвращает число
     цена минус («Скидка» от цена)
   ```

2. app.flang:

   ```flang
   модуль «Касса»
     использует «Цены» из "lib.flang" только «Цена со скидкой»

   тотальная функция «Итог»
     возвращает число
     «Цена со скидкой» от 100
   ```

3. `flang run app.flang --function «Итог»`

## Что происходит

```
FLANG_UNKNOWN_NAME, строка 11, столбец 15: неизвестная функция «Скидка»
```

Код 1. Если в lib.flang есть строка `экспортирует «Цена со скидкой»`, та же программа
отвечает `90` — это починила задача 2663. Без списка экспорта «только» отрезает и
помощника, которого зовёт ввезённая функция. Так же отказывает ввоз стандартной
библиотеки: `использует «Unicode case folding» только «Равны без учёта регистра»` —
«неизвестная функция «Ключ без регистра»»; `использует «Unicode graphemes» только
«Графемы»` — «неизвестная запись «Ход графем»». Без «только» те же вызовы работают.

Версия: flang 0.7.29 (двоичный партии печати 8, 18 октября 2026). На 0.7.28 ответ тот же.

## Что должно быть

«только» ограничивает имена, видимые в ввозящем файле, а не то, с чем связывается
ввезённая функция внутри своего модуля.

## Обходной путь

Ввозить модуль без «только» или дописать в модуль строку `экспортирует`.

## Когда задача сделана

Пара из шагов отвечает `90`; прямой вызов «Скидки» из app.flang — FLANG_UNKNOWN_NAME;
три ввоза Юникода с «только» проходят check; пары стоят в пробе
`flang/proof/probes/import-helper-binding/`.

## Где живёт правка

`flang/self/link.flang`; доезжает до двоичного перепечаткой.
