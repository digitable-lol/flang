# 5439. Примеры и постусловия самих сторожей не проверяет никто, и один пример был ложным месяц

## Шаги воспроизведения

```
git stash list
git show e490d646d:scripts/guards/traceability-guard.fscript > /tmp/proba.fscript
grep -n -A 3 'пример «Номер после двоеточия»' /tmp/proba.fscript
grep -rn 'flang check' .github/workflows/*.yml .githooks/pre-push.fscript | grep -c 'scripts/guards'
ls scripts/guards/*.fscript | wc -l
```

## Что происходит

```
    дано запрос равно "flang/proof/map/abilities.flang:11"
    ожидается 34
0
49
```

Версия: flang 0.7.23. Дата прогона: 4 октября 2026.

Коммит `e490d646d` заменил в `scripts/guards/traceability-guard.fscript` все
вхождения `abilities.flang:34` на `abilities.flang:11` и не поправил
`ожидается 34` у примера «Номер после двоеточия». Пример стал ложным: вход
`:11` даёт 11. Прогон `bootstrap/flang check` на этом файле с того дня
отвечает кодом 1 — и никто этого не видел, потому что ни одна работа CI и ни
один хук не зовут `flang check` по `scripts/guards/`. Сторожей там 49 (замер
`ls scripts/guards/*.fscript | wc -l`, 4 октября 2026), зовов проверки — ноль
(замер грепом по `.github/workflows/*.yml` и `.githooks/pre-push.fscript`, тот
же день).

Беда не в одном примере: беда в том, что примеры сторожей — единственное, что
стоит между сторожем и молчаливой поломкой, и их не прогоняет никто. Сколько
ещё сторожей красны своим же `flang check` — НЕ МЕРЕНО: обход по 49 файлам не
снят, цена одного прогона на самом большом из них 40 с (замер 4 октября 2026
на `traceability-guard.fscript`).

## Что должно быть

1. Перепись: `flang check` по всем 49 сторожам, с кодом и ценой у каждого.
   Красные — поимённо, с причиной.
2. Прогон по сторожам стоит в CI либо в хуке перед пушем — там, где цена
   позволяет, и с храповиком на тех, кто красен по делу.
3. Ложный пример в `traceability-guard.fscript` закрыт (сделано веткой задачи
   1407: `ожидается 11`).

## Обходной путь

Звать `bootstrap/flang check scripts/guards/<имя>.fscript` руками перед
правкой сторожа. Это и есть то, чего в дереве нет.

## Когда задача сделана

1. Есть прогон, который проверяет примеры сторожей, и он позван — его видит
   `bootstrap/flang run-script guard-calls:check`.
2. У прогона есть проба порчи: ложный пример в сторожа — прогон краснеет.
3. Перепись красных сторожей записана ведомостью, и расти ей нельзя.

## Где живёт правка

- `.github/workflows/` либо `.githooks/pre-push.fscript` — место зова;
- `scripts/ledgers/` — ведомость красных, если долг остаётся;
- `scripts/guards/traceability-guard.fscript` — ложный пример (закрыт).
