# 5520. Правило «кольцо точного целого» не заходит под «остаток от»: (а плюс б) остаток от м и (б плюс а) остаток от м для ядра разные

Заявка: https://github.com/digitable-lol/flang/issues/379

Под `умножить на` кольцо нормализует аргументы, под `остаток от` — нет. Нужна не теория остатка, а конгруэнция: равные по кольцу аргументы дают равный остаток.

## Шаги воспроизведения

1. Программа `remainder.flang`:

```flang
модуль «Кольцо под остатком»

утверждение «без остатка»
  для всех а: точное целое
  для всех б: точное целое
  утверждаем (а плюс б) равно (б плюс а)

утверждение «под остатком»
  для всех а: точное целое
  для всех б: точное целое
  для всех м: точное целое
  утверждаем ((а плюс б) остаток от м) равно ((б плюс а) остаток от м)

утверждение «под умножением»
  для всех а: точное целое
  для всех б: точное целое
  для всех м: точное целое
  утверждаем ((а плюс б) умножить на м) равно ((б плюс а) умножить на м)
```

2. `bootstrap/flang check remainder.flang --proof`.

## Что происходит

```
$ bootstrap/flang check remainder.flang --proof
  утверждение «без остатка» — доказано сведением цели с телом функции: правило «кольцо точного целого», объявленные типы аргументов не понадобились — утверждение обо ВСЕХ входах, а не о написанных; теоремы при нём нет и не нужно
  утверждение «под остатком» — объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
  утверждение «под умножением» — доказано сведением цели с телом функции: правило «кольцо точного целого», объявленные типы аргументов не понадобились — утверждение обо ВСЕХ входах, а не о написанных; теоремы при нём нет и не нужно
remainder.flang: НЕ ПРОВЕРЕНО — утверждений 3: доказано 2, условно 0, сетка 0, объявлено, не доказано 1, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 3
remainder.flang: НЕЗАВИСИМО НЕ ПРОВЕРЕНО — сверщик не сошёлся с записью (код 1; файлу с ввозом сверщику нужны записи ввезённых модулей ключом --зависимость): все 2 доказанных стоят на слове ядра
код 3
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

При сведении к многочлену `остаток от` (и другие непрозрачные для кольца формы) становится атомом, который сравнивается по нормальной форме своих аргументов. «под остатком» доказано.

Доказывать свойства до взятия остатка.
