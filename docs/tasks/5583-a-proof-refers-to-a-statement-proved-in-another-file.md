# 5583. Запись доказательства со ссылкой на утверждение из другого файла независимая проверка отвергает

Ссылка `по свойству «имя»` на доказанное утверждение работает внутри одного
файла у ядра и у независимой проверяющей программы
(`flang/proof/checker/checker.c`). Если утверждение подключено из другого файла
словом `использует`, ядро по-прежнему отвечает «доказано», а проверяющая
программа на той же записи — «не сошлось». Решение и разбор —
`docs/adr/0048-a-lemma-reference-exists-and-stops-at-the-file-boundary.md`.

## Шаги воспроизведения

1. Файл lemma.flang:

   ```
   модуль «Лемма»

   утверждение «сложение перестановочно»
     для всех а: число и б: число
     утверждаем (а плюс б) равен (б плюс а)
   ```

2. Файл two-files.flang рядом:

   ```
   модуль «Проба»

   использует «Лемма» из "lemma.flang"

   тотальная функция «Сумма»
     принимает а: число, б: число
     возвращает число
     обеспечивает «сумма не зависит от порядка» результат равен (б плюс а)
     а плюс б

   теорема «сумма не зависит от порядка»
     дано а: число
     дано б: число
     утверждаем результат равен (б плюс а)
     по свойству «сложение перестановочно»
     следовательно доказано
   ```

3. `bootstrap/flang check --proof --strict --record two-files.record two-files.flang`
4. `cc -std=c99 -O2 -o sv flang/proof/checker/checker.c && ./sv two-files.flang two-files.record`

## Что происходит

```
$ bootstrap/flang check --proof --strict --record two-files.record two-files.flang
two-files.flang: ДОКАЗАНО — утверждений 1: доказано 1, условно 0, сетка 0, … — код возврата 0
$ grep 'по свойству' two-files.record
    шаг 1 строка 15 закрывающий по свойству «сложение перестановочно» свойство строка 0 правило «цель есть допущение»
    ход 2 факт по свойству «сложение перестановочно» строка 3 подстановка «а» ⟨а⟩ «б» ⟨б⟩
$ ./sv two-files.flang two-files.record
НЕ СОШЛОСЬ: теорема «сумма не зависит от порядка», сведение: факт по свойству «сложение перестановочно»: постусловие не доказано РАНЬШЕ этой цели — фактом брать нельзя (круг или обратный порядок)     код 1
```

`свойство строка 0` — заголовок утверждения искали в строках входного файла и
не нашли. `строка 3` — строка файла lemma.flang, о котором запись не говорит
ничего: в шапке записи один исходник и один отпечаток.

Второй дефект того же места, не перепроверено: утверждение без строки
`для всех`, на которое ссылаются в том же файле, даёт ход с пустой
подстановкой, и проверяющая программа отвечает кодом 1 «ход … неполон»
(ADR-0048, раздел 5.3-трижды).

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Запись честного доказательства со ссылкой через границу файла проверяющая
программа переигрывает и отвечает кодом 0 (ADR-0048, раздел 6):

1. ядро не печатает `свойство строка 0`;
2. шапка записи называет каждый привлечённый файл: `привлечён «путь» отпечаток256 …`;
3. привязка шага и ход называют файл: `свойство файл «путь» строка N`,
   `факт по свойству «И» файл «путь» строка N подстановка …`;
4. блок леммы едет в записи потребителя, и проверка круга работает между
   файлами так же, как внутри файла;
5. проверяющая программа сверяет отпечатки названных файлов и берёт цель леммы
   из названного исходника; ключи `--зависимость` и `--набор` подключены к
   разделу доказательств, а не только тотальности;
6. ход без пар подстановки либо не печатает слова `подстановка`, либо
   принимается разбором.

Нового слова поверхности не заводить; текст леммы в запись не класть; молчать
про `строка 0` проверяющую программу не учить.

## Обходной путь

Держать утверждение в том же файле, что и ссылку на него.

## Когда задача сделана

- на пробе из шагов воспроизведения ядро отвечает кодом 0, проверяющая
  программа — кодом 0, и число «шагов по свойству проверено по существу» в её
  отчёте выросло на этот шаг;
- правка lemma.flang после печати записи роняет сверку;
- в `flang/proof/checker/tests/families/statement/corrupt/` лежат подделки,
  каждая отвергается: чужой отпечаток; файл не назван в шапке; `строка 0`;
  ссылка на лемму из непривлечённого файла; пустая подстановка;
- честная проба на ссылку между файлами лежит в
  `flang/proof/checker/tests/families/statement/`.

## Где живёт правка

Требует перепечатки самосборной части:

- `flang/self/zapis.flang`: «Номер утверждения записи» (отдаёт 0, когда лемма в
  другом файле), «Привязка шага записи», печать шапки записи и ходов
  `факт по свойству`;
- `flang/self/proofterm.flang`: «Утверждение по имени», «Факт утверждения» —
  нести путь исходника леммы;
- `flang/self/link.flang`: «Донести утверждения разбора» — добавить путь файла;
- `flang/self/proof.flang`: вердикт `proved-conditional` при основании из
  другого файла.

Без перепечатки:

- `flang/proof/checker/checker.c`: `факт_утверждения`, `шаг_утверждением`,
  `сверить_шаг_свойством`, `предпроход`, разбор шапки записи и ключей
  `--зависимость`, `--набор`;
- `docs/flang/proof/SPEC.md`, строка таблицы о `по свойству «имя»`: сказать,
  что оно ссылается и на утверждение.

Правки `flang/self/**` идут в общую партию перепечатки (задача 2200).
