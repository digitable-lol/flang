# 5703. Утверждение, ложное на значении из примера вызываемой функции, получает «объявлено, не доказано», а не «нарушено»

Заявка: https://github.com/digitable-lol/flang/issues/381

Утверждение `не («Родитель» от а и а)` ложно при каждом `а`, а пример «Родителя» прямо даёт контрпример `а = 3`. Отчёт пишет «ни теоремы, ни примеров» и «нарушено 0»; простой `check` — «замечаний нет», код 0.

## Шаги воспроизведения

1. Программа `false.flang`:

```flang
модуль «Ложь при примере»

тотальная функция «Родитель»
  принимает а: неотрицательное, б: неотрицательное
  возвращает признак
  пример «сам себе родитель»
    дано а равно 3
    дано б равно 3
    ожидается да
  а не больше б

утверждение «антирефлексивность»
  для всех а: неотрицательное
  утверждаем не («Родитель» от а и а)
```

2. `bootstrap/flang check false.flang --proof`.

## Что происходит

```
$ bootstrap/flang check false.flang --proof
  утверждение «антирефлексивность» — объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
false.flang: НЕ ПРОВЕРЕНО — утверждений 1: доказано 0, условно 0, сетка 0, объявлено, не доказано 1, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 3
код 3
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

`нарушено 1` с названным контрпримером: значения из примеров вызываемых функций подставляются в переменные утверждения, и утверждение, вычисленное в `нет`, приходит «НАРУШЕНО». Это не меняет того, что ядро доказывает.

## Обходной путь

Нет: ложь видна только во время работы на пришедшем входе.

## Когда задача сделана

`bootstrap/flang check false.flang --proof` — «нарушено 1 … при а = 3», код 1. Верное утверждение `«Родитель» от а и а` остаётся «объявлено, не доказано» или доказанным.

## Где живёт правка

`flang/self/proof.flang` — вердикт утверждения; `flang/self/grid.flang` — значения сетки. Ждёт печати семени.
