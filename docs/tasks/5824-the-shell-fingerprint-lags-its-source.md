# 5824. Отпечаток оболочки отстал от исходника

Оболочка называет в `flang --version` восемь знаков sha256 своего исходника
`flang/src/emit/c/flang_repl.c`, посчитанного без строки самого отпечатка.
Число стоит в исходнике строкой `#define FLANG_SHELL_ID`, руками его не ставят:
его считает проба. После коммита `d697b26a0` («отпечаток оболочки догнал
исходник: 9f361fce») файл правили ещё шесть раз (`97d65cb34`, `019660517`,
`228ac8bea`, `3922b0e65`, `acead8c6d`, `4451f435d`), а строку не обновляли.

## Шаги воспроизведения

1. Дерево `gh/dev` `f6e8fe734`, двоичный собран из него: `make -C bootstrap -j8`.
2. Команды:

   ```
   bootstrap/flang io scripts/repl-probe.fscript --plan Fingerprint
   grep -n '^#define FLANG_SHELL_ID' flang/src/emit/c/flang_repl.c bootstrap/flang_repl.c
   bootstrap/flang --version
   bootstrap/flang io scripts/repl-probe.fscript --plan Check --timeout 120000
   ```

3. Смотреть: три числа — посчитанное, записанное и названное двоичным — и код
   возврата пробы.

То же самое отвечала и прежняя проба `sh scripts/repl-probe.sh` (код 1 за 80 с),
из-за чего её перенос на план в задаче 5821 откладывался.

Версия: `flang 0.7.23`. Дата прогона: 30 сентября 2026.

## Что должно быть

Три числа совпадают, проба отвечает кодом 0. Обещание записано в задаче 3636 и
в заметке `docs/zettel/the-release-number-cannot-say-what-is-inside-the-binary.md`:
по `--version` человек узнаёт, из какого исходника собрана оболочка. Пока число
в строке старое, двоичные, собранные из шести разных состояний исходника,
называют себя одинаково.

## Обходной путь

Обхода нет: сверить оболочку с исходником можно только пересчётом —
`bootstrap/flang io scripts/repl-probe.fscript --plan Fingerprint`.

## Когда задача сделана

`bootstrap/flang io scripts/repl-probe.fscript --plan Check --timeout 120000`
отвечает кодом 0 и строкой «зелен  отпечаток: исходник, строка и двоичный
сошлись». Показано, что это достижимо: на копии дерева, где в обоих файлах
поставлено `cc2ccbee` и двоичный пересобран, проба дала код 0 за 88 с.
Проба же и краснеет, если строка отстанет снова.

Чтобы отставание не повторялось, проба должна зваться там, где её увидят, —
сегодня её не зовёт ни хук, ни работа CI.

## Где живёт правка

`flang/src/emit/c/flang_repl.c`, строка `#define FLANG_SHELL_ID`, и копия в
`bootstrap/flang_repl.c`. Файл копируется в семя дословно, поэтому правка
доезжает до двоичного быстрым пересевом семени (ярлык `семя:освежить`),
перепечатка самосборной части не нужна. Число для строки — вывод плана
`Fingerprint` на том дереве, где правка делается: от самой строки оно не зависит.

Тем же заходом — комментарий над строкой (269-я строка исходника): он велит
звать пробу под именем, которого в дереве нет с задачи 1428, а с задачи 5821
нет и самой оболочки. Верная команда —
`bootstrap/flang io scripts/repl-probe.fscript --plan Fingerprint`. Править
комментарий отдельно от строки нельзя: любая правка файла меняет отпечаток.
