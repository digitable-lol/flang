# 5825. Проводник отвергает верный ответ в каждом уроке

`flang/bin/flangtutor` дописывает к ответу ученика функцию «Проверка урока»,
зовёт `flang run` и сравнивает вывод с ожидаемым значением из урока. Вывод он
берёт вместе с потоком ошибок (`2>&1`, строка 382). С 18 сентября 2026
(`6fbdffc19`, задача 6427, ADR-0045) `flang run` перед вычислением пишет в поток
ошибок строку вердикта — «доказано: утверждений N». Значение перестало совпадать
с ожидаемым, и проводник отказывает на верном ответе.

## Шаги воспроизведения

1. Ответ первого урока — три строки из его раздела «впиши»:

   ```
   Урок
   х умножить на 2
   .
   ```

2. Команда:

   ```
   printf 'Урок\nх умножить на 2\n.\n' | NO_COLOR= FLANG_TUTOR_STATE=нет sh flang/bin/flangtutor --только 1
   ```

3. Смотреть: последние строки вывода и код возврата.

## Что происходит

```
$ printf 'Урок\nх умножить на 2\n.\n' | NO_COLOR= FLANG_TUTOR_STATE=нет sh flang/bin/flangtutor --только 1
…
ваш ответ целиком, как его прочитал проводник:
    модуль «Урок»

    тотальная функция «Удвоить»
      принимает х: число
      возвращает число
      х умножить на 2

проверка урока ждала 42, а вышло:
доказано: утверждений 0
42
попробуйте ещё раз — пропуски спрашиваются заново.
⟨1⟩ имя модуля » ввод кончился, а урок 1 не пройден.                              код 1
```

Причина видна одним прогоном — строка вердикта идёт в поток ошибок, значение в
обычный вывод:

```
$ bootstrap/flang run lesson.flang --function '«Проверка урока»' 2>/dev/null
42
$ bootstrap/flang run lesson.flang --function '«Проверка урока»' 2>&1 >/dev/null
доказано: утверждений 0
```

Проба проводника (`bootstrap/flang io scripts/tutor-probe.fscript --plan Check
--timeout 120000`) красна: «целиком: код 1», «урок N: свой верный ответ дал
код 1» для N от 1 до 12, «сеанс: ввод владельца дал код 1», «место: после
первого урока … не записана единица» — всё следствия одной причины. Прежняя
`sh scripts/tutor-probe.sh` отвечала тем же (код 1 за 131 с).

Версия: `flang 0.7.23`. Дата прогона: 30 сентября 2026.

## Что должно быть

Верный ответ урока принимается: `docs/tutor/README.md` и ADR-0035 обещают, что
урок проходится ответом из его же раздела «впиши», а судит компилятор.

## Обходной путь

Обхода нет: проводником сегодня нельзя пройти ни одного урока.

## Когда задача сделана

`bootstrap/flang io scripts/tutor-probe.fscript --plan Check --timeout 120000`
не печатает ни одной строки «свой верный ответ дал код», «целиком: код»,
«сеанс:» и «место:». Показано, что это достижимо: на копии дерева, где строка
382 читает только обычный вывод (`2>/dev/null` вместо `2>&1`) и закрыта задача
5826, проба дала код 0. Она же краснеет, если дефект вернётся.

## Где живёт правка

`flang/bin/flangtutor`, строка 382 — значение брать из обычного вывода, а поток
ошибок показывать ученику только при отказе. Двоичный не трогается: ни пересев,
ни перепечатка не нужны.
