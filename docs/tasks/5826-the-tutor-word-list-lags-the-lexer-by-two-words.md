# 5826. Список слов проводника отстал от лексера на два слова

Проводник подсвечивает слова языка и отвечает ученику «понял: слова языка: …».
Список слов он держит у себя — `LANGUAGE_WORDS` в `flang/bin/flangtutor` — и
обязан совпадать с таблицей лексера «Куски таблицы» в `flang/self/lexer.flang`.
Коммит `33859c9f2` добавил в лексер слово силлогизма «следует» и его английскую
пару «follows»; список проводника не обновили.

## Шаги воспроизведения

1. Дерево `gh/dev` `f6e8fe734`.
2. Команды — те же два конвейера, которыми список снимался всегда:

   ```
   sed -n '/^тотальная функция «Куски таблицы»/,/^  \]/p' flang/self/lexer.flang \
     | grep '^    "' | sed 's/^    "|//; s/|",\{0,1\}$//' | tr '|' '\n' | sed 's/:.*//' | grep -v '^$' > lexer.txt
   sed -n "/^LANGUAGE_WORDS='/,/^'/p" flang/bin/flangtutor | grep -v "'" | tr -d '\n' | tr '|' '\n' | grep -v '^$' > tutor.txt
   wc -l lexer.txt tutor.txt
   diff lexer.txt tutor.txt
   ```

3. Смотреть: число строк и разницу.

## Что происходит

```
$ wc -l lexer.txt tutor.txt
  649 lexer.txt
  647 tutor.txt
$ diff lexer.txt tutor.txt
510,511d509
< следует
< follows                                                                         код 1
```

Проба проводника называет то же своей строкой:

```
слова: список слов в flangtutor разошёлся с таблицей лексера («Куски таблицы» в flang/self/lexer.flang):
< следует
< follows
```

Версия: `flang 0.7.23`. Дата прогона: 30 сентября 2026.

## Что должно быть

Списки совпадают слово в слово и по порядку. Это одна из семи проверок пробы
проводника (ADR-0035): иначе подсветка и ответ «понял: слова языка» врут про
слово, которое лексер знает, а проводник нет.

## Обходной путь

Обхода нет. Следствие сегодня узкое: «следует» и «follows» в ответе ученика не
подсвечиваются и не попадают в «понял: слова языка».

## Когда задача сделана

`bootstrap/flang io scripts/tutor-probe.fscript --plan Check --timeout 120000`
печатает «зелен  слова: 649 фраз лексера — те же в проводнике» и не печатает
строки «слова: список слов в flangtutor разошёлся». Проба краснеет, если списки
разойдутся снова.

Долговечнее — не держать второй список вовсе, а снимать его из лексера при
сборке или при запуске проводника; тогда расходиться будет нечему.

## Где живёт правка

`flang/bin/flangtutor`, блок `LANGUAGE_WORDS` (строки 105–171): вставить
`следует|follows|` после «теорема»-группы в том же порядке, что в лексере.
Двоичный не трогается.
