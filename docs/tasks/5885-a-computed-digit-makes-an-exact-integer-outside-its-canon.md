# 5885. Посчитанный разряд даёт точное целое вне канона

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/exact-integer-from-computed-digit.flang`:

```flang
модуль «Точное целое из посчитанного разряда»

тотальная функция «Нуль»
  возвращает точное целое
  []

тотальная функция «Из числа»
  принимает х: число
  возвращает точное целое
  [х]

тотальная функция «С нулём»
  принимает а: точное целое
  возвращает точное целое
  обеспечивает «ноль нейтрален» результат равен а
  а плюс («Нуль»)

тотальная функция «Не ниже нуля»
  принимает а: точное целое
  возвращает точное целое
  обеспечивает «точное не ниже нуля» результат не меньше («Нуль»)
  а

тотальная функция «Ноль разрядом»
  принимает х: число
  возвращает точное целое
  «С нулём» от («Из числа» от х)

тотальная функция «Минус семь точным»
  принимает х: число
  возвращает точное целое
  «Не ниже нуля» от («Из числа» от х)
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/exact-integer-from-computed-digit.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/exact-integer-from-computed-digit.flang --function 'Ноль разрядом' --args '{"х":0}'`

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/typing-holes/programs/exact-integer-from-computed-digit.flang --proof
… ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — … доказано
$ bootstrap/flang run flang/proof/probes/typing-holes/programs/exact-integer-from-computed-digit.flang --function 'Ноль разрядом' --args '{"х":0}'
FLANG_PROPERTY: нарушено свойство «ноль нейтрален» функции «С нулём»                                  код 1
```

Версия: flang 0.7.34.

`[х]` при `х: число` проверка типов принимает как `точное целое` («Разрядами точного» в `flang/self/types.flang`
пускает любой `список числа`). Получаются `[0]`, `[4194304]`, `[-7]`, `[0.5]`. Равенство сравнивает записи без
приведения к канону: `[0] плюс []` есть `[]`, и `[] равен [0]` ложно. Отрицательный разряд действия не отвергают:
`--function 'Минус семь точным' --args '{"х":-7}'` нарушает доказанное «точное не ниже нуля».
ADR-0036 §11.2 обещает, что число в новый тип без названного перевода не втекает.

## Что должно быть

Либо список с разрядом не литералом в `точное целое` не втекает (нужен названный перевод), либо равенство и порядок
приводят операнды к канону, а разряд вне [0, 2²²) или не целый — отказ действия. Решение за владельцем: проба
`flang/proof/probes/exact-integer/programs/canon-is-enforced-at-the-action.flang` сегодня опирается на втекание.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check flang/proof/probes/typing-holes/programs/exact-integer-from-computed-digit.flang --proof` не числит ложное утверждение доказанным.
Проба — строки этой программы в `flang/proof/probes/typing-holes/expected.tsv`
и строка ведомости `flang/proof/tables/typing-holes.tsv`: сегодня они держат ответ
двоичного 0.7.34, после правки строка `proof` меняется либо запуск отвечает отказом действия, строка ведомости — на `закрыта`.

## Где живёт правка

`flang/self/types.flang` («Разрядами точного», «Порок разряда узла») либо `flang/self/interpret.flang` и рантаймы
целей печати. Правки в этой ветке нет. Требует печати семени.
