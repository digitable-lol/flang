# 5908. Запись несёт имя правила, а не вывод

Раздел `чем получен каждый шаг` обещает «правило и основания — строками записи
доказательства». У большинства утверждений в нём стоит ровно одна строка — имя правила.
Ни цели, ни посылок, ни места: читать нечего, и развернуть нечего.

Решение — [ADR-0057](../adr/0057-a-derivation-is-printed-as-a-reasoning-a-human-reads.md):
форма вывода одна, у каждого доказанного утверждения есть шаги, у каждого шага —
правило словами и кодом, посылки, подстановка и место в исходнике.

## Шаги воспроизведения

1. Программа — `flang/proof/probes/user-programs/programs/account.flang` (21 строка по `wc -l`;
   запись доказательства в своей шапке считает 22).
2. `bootstrap/flang check --proof --record /tmp/r flang/proof/probes/user-programs/programs/account.flang`
3. Смотреть раздел `чем получен каждый шаг` и блоки `утверждение` в записи `/tmp/r`.
4. Для второй половины беды — `word-lengths.flang`: в записи у утверждения
   `длин столько же, сколько слов` вывод есть, а в разделе для человека его нет.

## Что происходит

```
$ bootstrap/flang check --proof flang/proof/probes/user-programs/programs/account.flang
...
чем получен каждый шаг (правило и основания — строками записи доказательства):
  утверждение «владелец не меняется» функции «Пополнить» строка 10
    правило «тождество после переписки допущением»
  утверждение «остаток при переименовании цел» функции «Переименовать» строка 20
    правило «тождество после переписки допущением»
                                                                                   код 0
```

Тот же пробел в самой записи — блок утверждения кончается, не начав вывода:

```
утверждение «владелец не меняется» функции «Пополнить» строка 10
  вид postcondition
  вердикт доказано
  теоремы нет
  правило «тождество после переписки допущением»
  по объявлению нет
конец утверждения
```

У другой части утверждений вывод в записи ЕСТЬ, а до человека не доходит: раздел
отбирает строки по началу и формы `ход` в отборе нет
(`flang/src/emit/c/flang_repl.c`, строки 9183–9185 пускают только `правило «`,
`шаг `, `вывод `, `случай `, `посылка `, `сведение «`). Запись того же прогона:

```
утверждение «длин столько же, сколько слов» функции «Длины» строка 15
  правило «тождество после переписки допущением»
  по объявлению нет
    ход цель
    ход 1 развернуть ⟨«Длины» от ( слова )⟩ строка 19 ⟨отобразить слова как слово → длина слово⟩
    ход 2 переписать формой ⟨длина (отобразить слова как слово → длина слово)⟩ = ⟨длина слова⟩ законом «Мера построения»
    ход 3 закрыть тождеством
    ход конец
конец утверждения
```

Корпус 47 файлов — 14 программ `flang/proof/probes/user-programs/programs/` и
33 примера `docs/examples/guide/`:

| мера | число |
|---|---:|
| доказанных утверждений | 53 |
| блоков утверждения в записях | 60 |
| блоков с хотя бы одним шагом любой формы | 27 |
| доказанных со строкой шага в разделе для человека | 18 |
| доказанных, у которых в разделе одна строка — имя правила | 35 |
| из этих 35: вывод в записи есть, но формой `ход` | 9 |
| из этих 35: вывода в записи нет вовсе | 26 |
| реальных шагов человеку (без строк `цель` и `конец`) | 62 |
| реальных шагов в записях | 84 |
| строк формы `ход` в записях | 40 |

Вторая половина — те 26, у которых вывода нет и в записи. По правилу:

| правило | число |
|---|---:|
| тождество после переписки допущением | 10 |
| вычисление замкнутой цели | 5 |
| неотрицательность по построению | 4 |
| цель есть допущение | 3 |
| порядок по построению | 2 |
| разбор цели по условию | 1 |
| равенство, решённое счётом замкнутых частей | 1 |

У десяти с правилом «тождество после переписки допущением» упор назван точно.
Печать строит вывод из исходника: `«Ходы тождества постусловия записи»` разворачивает
вызов и переписывает цель до тождества. Разворот не происходит, потому что
`«Терм записи»` держит `результат.«владелец»` одним словом, и
`«Вставить вместо записи» … "результат" …` внутрь этого слова не заходит. Снято
прогоном на `account.flang` (двоичный 0.7.24):

```
«Терм записи» от "результат.«владелец» равен счёт.«владелец»"
  → "результат.«владелец» равен счёт.«владелец»"
«Вставить вместо записи» от (терм) и "результат" и "«Пополнить» от ( счёт ) и сумма"
  → "результат.«владелец» равен счёт.«владелец»"      (подстановки не было)
«Переписка до тождества записи» от (цель после развёртки)
  → ходы [], стоп да, закрыта НЕТ
«Ходы тождества постусловия записи» → пустой список
```

Независимый сверщик при этом отвечает `ПРОВЕРЕНО` и кодом 0: он не переигрывает запись,
а выводит утверждение из исходника заново. То есть пробел в записи вердикт не роняет —
и потому не виден ничем, кроме чтения глазами.

Версия: flang 0.7.24. Дата прогона: 4 октября 2026.

## Что должно быть

Справка `check --help` называет `--record` файлом, который «читает и человек». У записи,
где стоит одно имя правила, человеку читать нечего. У каждого доказанного утверждения
обязан быть вывод: цель, шаги, у каждого шага — имя правила словами, посылки (номерами
прежних шагов или местом в исходнике) и строка исходника, из которой шаг взят. Вывод,
который в записи уже есть, обязан доходить до раздела для человека.

## Обходной путь

Читать саму запись `--record`, а не раздел: у 9 утверждений из 35 вывод там есть
формой `ход`. У остальных 26 обходного пути нет — увидеть, из чего получено
утверждение, можно только прочитав тело функции и угадав, какое из 112 правил
ведомости `flang/proof/tables/inference-rules.tsv` сработало.

## Когда задача сделана

Прогон на том же корпусе из 47 файлов: у каждого из 53 доказанных утверждений в разделе
`чем получен каждый шаг` стоит не меньше одной строки шага, и в каждой такой строке есть
имя правила словами, посылки и строка исходника. Проба краснеет, если хотя бы у одного
доказанного утверждения в разделе осталась одна строка.

## Где живёт правка

Правка разложена на три части, и ни одна не делается в одном файле.

1. **Девять утверждений, у которых вывод уже есть.** Отбор строк раздела —
   `flang/src/emit/c/flang_repl.c` (строки 9183–9185) и его близнец в семени
   `bootstrap/flang_repl.c`; формы `ход` в отборе нет. Либо форма `ход`
   добавляется в отбор, либо, по решению ADR-0057 §3.1, формы сводятся к одной —
   но форму `ход` разбирает независимый сверщик (`flang/proof/checker/checker.c`:
   `ход цель`, `ход конец`, `ход N …`, `ход дано`, `ход факт по свойству`), и
   переименование формы — правка в двух читателях сразу.
2. **Двадцать шесть, у которых вывода нет.** `flang/self/proof-record.flang`:
   `«Терм записи»` и `«Вставить вместо записи»` (доступ к полю одним словом),
   `«Форма для левой записи»` (закона на поле записи-литерала нет). Любой новый
   закон переписки обязан быть добавлен и в сверщик: `закон_формы_есть` и
   `форма_законом` в `flang/proof/checker/checker.c` держат ЗАКРЫТЫЙ список
   законов, и запись с законом вне списка сверщик отвергает.
3. **Слова правил.** `flang/proof/tables/inference-rules.tsv` — задача 2146.

Доезжает перепечаткой самосборной части: правка в `flang/self/**` до двоичного
иначе не доходит, и замер «стало» снимается только после перепечатки.
