# 5931. Файл настроек говорит по-английски

## Шаги воспроизведения

1. Открыть `.flangrc` ствола `d88fb4efb`.
2. Прочитать ключи: `язык`, `поверхность`, `цвет`, `страница`, `версия`, `имя`,
   `лицензия`, `склад`, `беды`, `недоказанное`; слова `авто` и `отказ`.

## Что происходит

Ключи и слова русские, два из них — `склад` и `беды` — не понятны без
объяснения. В шапке файла стоит строка-комментарий.

Версия: `flang 0.7.22`. Дата прогона: 27 сентября 2026.

## Чем сняты читатели

Поиск по стволу `d88fb4efb` образцами чтения, а не по памяти:
`«Значение ключа» от … и "<ключ>"`, `flangrc.sh <ключ>`, `flangrc_klyuch`,
`sverit_klyuch`, `s/^<ключ>[`, `\s*<ключ>\s*=`, `ключи.get('<ключ>')`,
`define UNPROVEN_KEY`, разнос ключей в `bump-version.fscript`.
Ответ: **47 строк в 23 файлах**; сверх того списки ключей в
`scripts/settings-file.flang` и копия C-части в `bootstrap/`.

Два места первая опись пропустила, нашлись чтением рабочих процессов: подлог
версии в `release.yml` и `install-path.yml` пишет ключ через `sed`.

## Что сделано

1. `.flangrc` — десять английских ключей, строки-комментария нет.
2. Двоичный читает `unproven`. Старую запись `недоказанное = …` и старые слова
   принимает и одной строкой в поток ошибок называет замену. Стоят обе записи —
   читается английская, про старую сказано «не читается». Доставлено быстрым
   пересевом `sh scripts/seed/seed-refresh.sh`.
3. `scripts/flangrc.sh` заменён планом `scripts/flangrc.fscript`,
   `scripts/guards/flangrc-guard.sh` — планом `scripts/guards/flangrc-guard.fscript`
   (планы `Check` и `Forgery`). Оба проходят вердикт без `--trust`.
4. `scripts/settings-file.flang` сведён к четырём общим именам, которые ввозят
   десять программ; решение о значении, старшинство и старые имена переехали в
   читателя.
5. Источник значений: функции «Адрес склада» и «Адрес бед» в
   `scripts/release/emit-package.flang` зовутся «Адрес репозитория» и «Адрес
   задач»; комментарии из файла сняты.
6. Таблица проб `flang/proof/probes/unproven/expected.tsv` несёт строку
   заголовка и данные. Проб было 22, стало 32.

## Как устроена проверка мест

План `Check` ведёт читателя сам: каждое поручение читателя он отдаёт хозяину, а
на «Прочитать доводы» и «Прочитать переменную среды» подставляет свой ответ —
доводы пробы и «переменной нет». Поэтому проба не зависит от среды машины и не
разбирает JSON. Игрушечные деревья строятся во временном каталоге; на
настоящем дереве началом поиска служат корень и каждое имя первого уровня.

План `Forgery` судит дерево, у которого вынута примета корня: подъём обязан
выйти к чужому файлу, а проверка — назвать место вне дерева.

Снятие правки: у копии читателя вынуто условие «корень проекта». Без согласия
копия не запускается вовсе — код 3, её останавливает собственный пример
функции. С `--trust` план `Check` отвечает кодом 1 и называет четыре
расхождения.

## Таблица проб недоказанного

Поля: программа, путь (`run` или `io`), строка для `.flangrc`, значение
`FLANG_UNPROVEN`, ключи команды, ожидаемый код возврата, слово в выводе.
Прочерк значит «ничего». Слово проверяется вместе с кодом: «работает» и
«работает, назвав ключ, который человек набрал» — разные исходы с одним кодом.
Строки со старым ключом держат обещание совместимости: код тот же, что был, и
в выводе стоит замена.

## Прогоны по ключам

Двоичный 0.7.22 после пересева, недоказанная программа
`flang/proof/probes/unproven/programs/unproven.flang`:

| `.flangrc` | код | что сказано |
| --- | ---: | --- |
| `unproven = refuse` | 3 | запуск только по явному согласию |
| `unproven = warn` | 0 | запуск по настройке «unproven = warn», ответ 42 |
| `unproven = allow` | 0 | на веру, ответ 42 |
| `unproven = allowed` | 2 | такого значения у «unproven» нет |
| `недоказанное = разрешение` | 0 | замените её на «unproven = allow», ответ 42 |
| `недоказанное = отказ` | 3 | замените её на «unproven = refuse» |
| обе записи: старая `разрешение`, новая `refuse` | 3 | старая не читается |

Остальные девять ключей читает `scripts/flangrc.fscript`; у каждого два
значения дали два разных ответа, код 0: `language` en и zh, `surface` en и eo,
`color` always и never, `page` en и ru, `version` 1.2.3 и 4.5.6, `name`,
`license`, `repository`, `issues`.

`language = en` меняет язык проводника: `flangtutor --список` печатает
«lesson 1 · A module, a function, a call» вместо «урок 1 · Модуль, функция,
вызов». Язык самого компилятора ключ не меняет — задача 5413.

файла проводник не брал. Путь исправлен.
