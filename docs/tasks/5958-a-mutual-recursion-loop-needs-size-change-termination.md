# 5958. Цикл взаимной рекурсии, где аргумент строго убывает на одном ребре и не растёт на другом, отвергается FLANG_NOT_TOTAL

Заявка: https://github.com/digitable-lol/flang/issues/388

Проверка завершения требует одного и того же строго убывающего аргумента на каждом ребре цикла и сопоставляет аргументы по позиции. Здесь `таблица` убывает на ребре «Прочитать» → «Прочитать в» и передаётся без изменений обратно, а `номер` убывает на обратном ребре.

## Шаги воспроизведения

1. Программа `mutual.flang`:

```flang
модуль «Взаимная рекурсия»

тип «Номер»
  вариант «Первый»
  вариант «Следующий» содержит пред: «Номер»

тотальная функция «Прочитать»
  принимает таблица: список неотрицательное, номер: «Номер»
  возвращает неотрицательное
  пример «первый»
    дано таблица равно [7, 8]
    дано номер равно вариант «Первый»
    ожидается 7
  разбор таблица
    случай пусто
      то 0
    случай голова и хвост
      то «Прочитать в» от хвост и номер и голова

тотальная функция «Прочитать в»
  принимает ост: список неотрицательное, номер: «Номер», г: неотрицательное
  возвращает неотрицательное
  пример «первый»
    дано ост равно []
    дано номер равно вариант «Первый»
    дано г равно 7
    ожидается 7
  разбор номер
    случай «Первый»
      то г
    случай вариант «Следующий» с пред как п
      то «Прочитать» от ост и п
```

2. `bootstrap/flang check mutual.flang`.

## Что происходит

```
$ bootstrap/flang check mutual.flang
mutual.flang: не проверено — замечаний 1
FLANG_NOT_TOTAL в файле mutual.flang, строка 18, столбец 10: в цикле «Прочитать» → «Прочитать в» нет аргумента, который убывает на каждом вызове: «Прочитать» → «Прочитать в» убывает по аргументу 1 (параметр «таблица»); «Прочитать в» → «Проч …
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Цикл принимается, если в нём есть цепочка передачи значения, которая ни на одном ребре не растёт и хотя бы на одном строго убывает (size-change termination), с учётом перестановки доводов.

## Обходной путь

Слить функции в одну с вложенным `разбор`.

## Когда задача сделана

`bootstrap/flang check mutual.flang` — код 0, завершение структурой, сторожей 0; то же с переставленными доводами. Подделка: «Прочитать в» передаёт обратно `таблица` целиком и не убывает по номеру — `FLANG_NOT_TOTAL`.

## Где живёт правка

`flang/self/totality.flang` — проверка циклов. Ждёт печати семени.
