# 5979. Машинный вид ведомости не несёт хода доказательства

`--proof --json` объявлен справкой как «ведомость машинным видом». Текстовый вид печатает
раздел `чем получен каждый шаг`, запись — блоки `вывод` и `ход`; машинный вид не несёт
ни того, ни другого.

Решение — [ADR-0057](../adr/0057-a-derivation-is-printed-as-a-reasoning-a-human-reads.md).

## Шаги воспроизведения

1. `bootstrap/flang check --proof --json flang/proof/probes/user-programs/programs/positives.flang`
2. Смотреть массив `claims`: какие поля у утверждения.

## Что происходит

У доказанного постусловия ровно десять полей, и ни одно не несёт шага:

```
{"kind": "постусловие", "name": "все положительны", "of": "Только положительные",
 "forall": null, "verdict": "proved", "by": "declaration", "byType": false,
 "grid": 1, "steps": 0, "says": "доказано сведением цели с телом функции: правило
 «все элементы по построению», ..."}
                                                                                   код 0
```

Поле `steps` равно 0 у того же утверждения, у которого текстовый вид печатает два шага
(`вывод 1 Э2 …`, `вывод 2 Разв2 …`): `steps` считает написанные автором строки `затем`,
а не шаги вывода. Корпус 47 файлов (14 программ `user-programs` и 33 примера
`docs/examples/guide`), снятый 11 октября 2026 прогоном `check --proof` и
`check --proof --json` по каждому файлу: строк `вывод N` в текстовом виде 20,
сумма поля `steps` в JSON 2 — и обе единицы считают строку `затем` в теореме,
а не шаг вывода.

Версия: flang 0.7.25, дерево 1149c78f7.

## Что должно быть

У каждого утверждения в JSON — массив шагов: имя правила, формулировка цели шага, номера
посылок, строка исходника. Либо справка перестаёт звать этот вид ведомостью и называет,
чего в нём нет.

## Обходной путь

Разбирать текст записи `--record` самому.

## Когда задача сделана

`bootstrap/flang check --proof --json` на `positives.flang` отдаёт у утверждения
«все положительны» массив из двух шагов с правилами `Э2` и `Разв2`; число шагов в JSON
по корпусу из 47 файлов равно числу реальных шагов в записях.

## Где живёт правка

`flang/self/proof-ledger.flang` или тот модуль `flang/self`, который печатает ведомость
машинным видом; поля шага — `flang/self/proofterm.flang`.

## Следующий шаг

Найти в `flang/self` функцию, которая печатает поле `steps` машинного вида (поиск по
строке `"steps"`), и рядом с ней функцию, которая печатает строки `вывод N` текстового
вида; первая должна отдавать массив из тех же шагов. Проба, которая краснеет сегодня:
`bootstrap/flang check --proof --json flang/proof/probes/user-programs/programs/positives.flang`
— у утверждения «все положительны» нет массива шагов с правилами `Э2` и `Разв2`.
Доезжает только перепечаткой самосборной части.
