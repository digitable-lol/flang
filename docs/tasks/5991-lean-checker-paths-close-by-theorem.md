# 5991. Пути опорного сверщика на Lean стоят строками «нет модели», и сторож не требует, чтобы теорема строки «доказано» говорила о своём пути

## Шаги воспроизведения

1. `bootstrap/flang run-script lean-soundness:check` — перепись путей приёмки второго
   сверщика (`flang/proof/checker/second/`) по таблице
   `flang/proof/tables/lean-soundness-debt.tsv`.
2. Что смотреть: строку «путей приёмки второго сверщика … нет модели …».

## Что происходит

```
$ bootstrap/flang run-script lean-soundness:check
путей приёмки второго сверщика 50: доказано 1, нет модели 49, sorry 0; sorry в файлах модели и сверщика 0; потолок без модели 49
```

Из 50 путей теоремой судится один (`«Суд».«выводом»`). Строка `доказано` проходит,
если её причина называет любую теорему, которая есть в любом файле `flang/proof/lean/`
или `flang/proof/checker/second/`, — даже теорему не о том пути и даже из файла, который
второй сверщик не собирает.

Версия: `flang 0.7.32` (`origin/dev` `bc1652ff4`), прогон 2 ноября 2026.

## Что должно быть

Каждый путь приёмки второго сверщика судится теоремой: если путь принял, то то, что
запись этим путём утверждает, следует из окружения (исходника, допущений, реестра).
Строка `доказано` называет теорему из файлов сборки второго сверщика, и утверждение
этой теоремы называет сам путь.

## Обходной путь

Нет: строки «нет модели» держат долг названным, но не уплаченным.

## Когда задача сделана

- `bootstrap/flang run-script lean-soundness:check` печатает «нет модели 0»; пока не
  0 — потолок в стороже («Ceiling») равен числу строк «нет модели», и каждое его
  снижение видно в истории.
- Строка `доказано`, чья теорема в своём утверждении путь не называет или стоит в файле
  вне сборки второго сверщика, красит сторож; подлог 5
  `bootstrap/flang run-script lean-soundness:forgery` это ловит.
- `sorry` и новых аксиом нет; второй сверщик собирается
  (`make -C flang/proof/checker second`).
- `bootstrap/flang run-script checker:second` на корпусе: расхождений 0, записей,
  которые опорный сверщик принимал, не меньше.

## Где живёт правка

`flang/proof/checker/second/**`, `flang/proof/checker/Makefile`,
`flang/proof/lean/soundness-guard.fscript`, `flang/proof/tables/lean-soundness-debt.tsv`,
`docs/road-to-1-0.md`, `docs/flang/proof/tables.md`. Перепечатка не нужна:
`flang/self/**` не трогается.
