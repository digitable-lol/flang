# 6094. Курс не входит в сборку сайта, и набранную в главах версию никто не сверяет

Главы курса лежат в `docs/course/` и публикуются отдельно, на портал
Digitable. Сайт документации собирается по карте `docs/site/sitemap.mjs`
(`node docs/site/build.mjs`), и версию на его страницах подставляет сборка из
`docs/site/numbers.json`.

## Шаги воспроизведения

1. `grep -c course docs/site/sitemap.mjs docs/site/sitemap.flang docs/site/build.mjs docs/site/build.flang`
2. `grep -l '0\.7\.22' docs/course/*.md | wc -l`
3. `bootstrap/flang --version`

## Что происходит

```
$ grep -c course docs/site/sitemap.mjs docs/site/sitemap.flang docs/site/build.mjs docs/site/build.flang
docs/site/sitemap.mjs:0
docs/site/sitemap.flang:0
docs/site/build.mjs:0
docs/site/build.flang:0
$ grep -l '0\.7\.22' docs/course/*.md | wc -l
15
$ bootstrap/flang --version
flang 0.7.23
```

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Главы курса собираются сайтом: сборка отказывает на ссылке в никуда, а версия
на страницах курса подставляется, а не набирается.

До работы нужно решение владельца: порталу нужны шапка Hugo и портальные
адреса ссылок, сборке сайта — первый заголовок `#` и адреса вида `*.html`.
Либо курс живёт в одном месте, либо у него появляется печать под вторую цель,
как у страницы выпусков (`scripts/site/releases-page.fscript`).

## Обходной путь

Править версию в главах руками при каждом выпуске.

## Когда задача сделана

1. Решение владельца о месте курса записано.
2. В карте сайта есть раздел курса и строка на каждую главу.
3. Шапка Hugo (блок `---` в начале главы) на страницу сайта не попадает.
4. Ссылки между главами вида `02-first-program.md` ведут на собранные
   страницы.
5. Набранная версия заменена подстановкой `{{выпуск.версия}}`.

```sh
node docs/site/build.mjs --check
grep -c course docs/site/sitemap.mjs
```

Первая команда — код 0, вторая — не ноль.

## Где живёт правка

`docs/site/sitemap.mjs` и `docs/site/sitemap.flang` (раздел и строки глав),
`docs/site/build.mjs` и `docs/site/build.flang` (снятие шапки Hugo),
`docs/course/*.md` (ссылки, подстановка версии). Перепечатка не нужна.
