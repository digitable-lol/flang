# 6098. Постусловие, закрытое разбором по условию с отрицанием ветви, сверщик не переигрывает, а двоичный его ещё не доказывает

ADR-0098 научил ядро класть отрицание условия в ложную половину разбора (Р8),
выводить из него порядок над сторонами без не-числа (Отр1), брать разность
из-под конечного литерала (Н13) и сравнивать два литерала в снятии
предусловия (Выч2). Правка стоит в исходнике `flang/self`; двоичный её не
знает до перепечатки семени, а сверщик ходов Р8, Отр1 и Н13 не знает вовсе.

## Шаги воспроизведения

1. `flang/proof/probes/branch-condition-and-literal-order/programs/absolute-integer.flang`.
2. `bootstrap/flang check <файл> --proof --record <запись>` и
   `flang/proof/checker/сверщик <файл> <запись>`.

## Что происходит

```
$ bootstrap/flang check absolute-integer.flang --proof
… утверждений 1: доказано 0, … объявлено, не доказано 1 …   код 3
```

Версия: flang 0.7.26 (`dev` `973a31f3e`). Ядро из исходника
(`check-with-source-compiler.flang`) доказывает то же постусловие, но запись
несёт `правило «разбор цели по условию»` без ходов, и сверщик отвечает
«НЕ ВЗЯЛСЯ … место на слове ядра», код 3.

## Что должно быть

После перепечатки семени — `доказано`, код 0; запись несёт ходы ГипО/Р8/Отр1/Н13,
и сверщик их проигрывает, код 0.

## Обходной путь

Нет; постусловие считает рантайм на каждом возврате.

## Когда задача сделана

`bootstrap/flang io flang/proof/probes/branch-condition-and-literal-order/run.fscript --plan Binary`
— «разошлось 0»; сверщик на записи `absolute-integer.flang` — код 0.

## Где живёт правка

`flang/self/proof-record.flang` (ходы в блоке вывода), `flang/proof/checker/checker.c`
(приёмы Р8, Отр1, Н13; потолок строк С-6 уже превышен — нужен ADR о потолке),
леммы приёмки в `flang/proof/lean/Acceptance.lean`. Двоичный — перепечаткой семени.

## Следующий шаг

Перепечатать семя с правкой ADR-0098 и снять пробу; затем печатать ход Р8 в
блоке вывода разбора по условию по образцу ГипО и дописать приём сверщика.
