# 6127. Вычислитель «половина_закрыта» остаётся в сверщике, хотя на записях корпуса он не снимает ни одного места

Места «разбор цели по условию» должны проигрываться локальными ходами самой
записи (`ход цель …`), а не вычислением цели внутри сверщика. Грамматика ходов
и что сверщик проверяет на каждом — `docs/design/proof-object-hody-razbora-celi.md`.
Ходы в записях корпуса есть, вычислитель из сверщика не убран.

## Шаги воспроизведения

1. `make -C flang/proof/checker`
2. Прогнать сверщик по записям корпуса и сложить поля сводки:

   ```sh
   for r in flang/proof/checker/tests/records/corpus/*.record; do
     s=$(sed -n 2p "$r" | sed 's/^исходник //')
     flang/proof/checker/сверщик "$s" "$r" | tail -1
   done | grep -o 'Узлов «разбор цели по условию» проиграно заново [0-9]* (снято со слова ядра мест [0-9]*)\|булевой веткой снято мест [0-9]*' | sort | uniq -c
   ```

3. `grep -c 'половина_закрыта' flang/proof/checker/checker.c`
4. `cat flang/proof/checker/tests/records/corpus/*.record | grep -c 'ход цель'`

## Что происходит

```
записей 91
     91 булевой веткой снято мест 0
     91 Узлов «разбор цели по условию» проиграно заново 0 (снято со слова ядра мест 0)
$ grep -c 'половина_закрыта' flang/proof/checker/checker.c
21
$ cat flang/proof/checker/tests/records/corpus/*.record | grep -c 'ход цель'
548
```

Вычислитель зовётся из четырёх мест `checker.c` (строки 4179, 4838, 5817,
6712), но на 91 записи корпуса не закрывает им ни одного узла.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Узел «разбор цели по условию» принимается только по ходам записи. Вычислителя
цели, который сверщик зовёт вместо ходов, нет.

## Обходной путь

Не нужен: вердикт корпуса от вычислителя не зависит.

## Когда задача сделана

1. `половина_закрыта` убрана из `checker.c`, либо про каждое из четырёх мест
   вызова показано пробой, какая честная запись без него не проходит.
2. `sh flang/proof/checker/tests/run.sh` — «сошлось всё»; семья проб
   `flang/proof/checker/tests/families/goal-breakdown/` по-прежнему принимает
   честные записи и отвергает подделки.
3. Сумма по корпусу из шага 2 не изменилась: ноль узлов, ноль мест.
4. Потолок в `flang/proof/checker/ratchet.txt` опущен до нового числа строк.
5. Записано решение владельца о ходе `вычислить ⟨T⟩ = ⟨V⟩`: остаётся ли он
   только для замкнутого терма без свободных имён.

## Где живёт правка

`flang/proof/checker/checker.c`: функция `половина_закрыта` и места её вызова;
`flang/proof/checker/ratchet.txt`. Печать ходов — `flang/self/zapis.flang`,
функция «Ходы разбора цели постусловия записи»; она уже в двоичном, перепечатка
не нужна.
