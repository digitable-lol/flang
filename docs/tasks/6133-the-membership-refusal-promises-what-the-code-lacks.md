# 6133. Текст отказа правила вхождения обещает условие «закрытая форма искомого», которого правило не проверяет

Логика правила верна, неверен его текст: отказ, комментарий над правилом и код
говорят три разные вещи.

## Шаги воспроизведения

1. `grep -n 'ЗАКРЫТАЯ форма' -A3 flang/self/proof-kernel.flang`
2. `grep -n 'функция «Свести вхождением»' -A1 flang/self/proof-kernel.flang`
3. Файл-проба vh.flang:

   ```
   тотальная функция «Кладёт функцию в список»
     принимает л: список (функция из числа в число), ф: функция из числа в число
     возвращает список (функция из числа в число)
     обеспечивает «функция стоит в списке» результат содержит ф
     добавить ф к л
   ```

4. `bootstrap/flang check vh.flang --proof`

## Что происходит

```
$ grep -n 'ЗАКРЫТАЯ форма' -A3 flang/self/proof-kernel.flang
276:    " И у искомого обязана быть ЗАКРЫТАЯ форма: литерал-скаляр, конструкция, запись, выписанный список",
277-    " или имя, объявленный тип которого известен и не есть функция —",
278-    " равенство значений вычислителя на функции ложно даже с самой собой,",
279-    " и правило, бравшее имя без объявления, доказало бы ложь о списке функций"] по ""
$ grep -n 'функция «Свести вхождением»' -A1 flang/self/proof-kernel.flang
6218:функция «Свести вхождением»
6219-  принимает «цель»: «Значение», «отчёт»: «Состояние ядра»
$ bootstrap/flang check vh.flang --proof
    вывод 1 В2 ⟨( добавить ф к л ) содержит ф⟩ сам
    вывод 2 Разв2 ⟨результат содержит ф⟩ из 1 строка 5
vh.flang: ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — утверждений 1: доказано 1, …     код 0
```

Отказ запрещает искомое-имя с типом функции. Правило объявлений не получает
(в подписи только цель и отчёт), формы искомого не спрашивает и закрывает
именно этот случай. Комментарий над правилом говорит: «ФОРМЫ искомого правило
не спрашивает, и спрашивать её не нужно». Довод отказа «равенство на функции
ложно даже с самой собой» неверен: значения-функции сличаются по имени и
захваченным полям.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Текст функции «Отказ вхождения», комментарий над «Свести вхождением» и подпись
правила говорят одно и то же. Дешёвый путь — убрать из отказа четыре строки об
условии. Сужать правило проверкой формы не нужно: случай с функцией оно
закрывает верно. Выбор за владельцем ядра.

## Обходной путь

Не нужен: вердикт верен, неверно только сообщение.

## Когда задача сделана

1. `grep -c 'ЗАКРЫТАЯ форма' flang/self/proof-kernel.flang` — 0, либо правило
   получает объявления и проверяет форму, и на это есть подделка.
2. Проба из шага 3 по-прежнему отвечает «доказано 1», код 0.
3. В `flang/proof/tables/inference-rules.tsv` у строк В1–В4 снята пометка
   «Обещанного „закрытой формы“ в коде нет», отпечаток
   `flang/proof/tables/inference-rules.digest` переснят,
   `sh flang/proof/tables-guard.sh` отвечает кодом 0.

Аксиому о равенстве функций не заводить.

## Где живёт правка

`flang/self/proof-kernel.flang`, функции «Отказ вхождения» и «Свести
вхождением» — только перепечаткой самосборной части.
`flang/proof/tables/inference-rules.tsv` и его отпечаток — без перепечатки.
