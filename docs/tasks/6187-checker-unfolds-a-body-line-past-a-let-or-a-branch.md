# 6187. Развёртка берёт строку тела мимо «пусть» и ветви

## Шаги воспроизведения

1. Исходник `probe.flang`:

```flang
модуль «Развёртка мимо пусть»

функция «Ф»
  принимает а: число
  возвращает число
  пусть б равно а плюс 1
  б умножить на 2

утверждение «тело без пусть»
  для всех а: число и б: число
  утверждаем («Ф» от а) равен (б умножить на 2)
```

2. Запись `probe.record` (написана руками; строки `строк`, `знаков`, `отпечаток`, `отпечаток256` — по исходнику):

```
запись доказательства 1
исходник finds/U1-unfold-line-after-let.flang
строк 12
знаков 235
отпечаток 147830480 257141027
ядро 2
утверждений 1
отпечаток256 792b9e050370d85e7b97077b0ee0ae3acef655b3322d927a51dbc6977a49d6d6

утверждение «тело без пусть» строка 9
  вид statement
  для всех «а» ⟨число⟩ строка 10
  для всех «б» ⟨число⟩ строка 10
  вердикт доказано
  теоремы нет
  правило «тождество после переписки допущением»
  по объявлению нет
    ход цель
    ход 1 развернуть ⟨«Ф» от а⟩ строка 7 ⟨б умножить на 2⟩
    ход 2 закрыть тождеством
    ход конец
конец утверждения

конец записи
```

3. `flang/proof/checker/сверщик probe.flang probe.record`, затем
   `flang/proof/checker/second/out/второй-сверщик probe.flang probe.record`.

## Что происходит

Оба сверщика отвечают `ПРОВЕРЕНО`, код 0.

Версия: flang 0.7.34, `checker.c` и второй сверщик ствола `001d8df7c`.

Утверждение ложно: при `а = 1`, `б = 7` слева 4, справа 14.

Ход `развернуть … строка 7 ⟨б умножить на 2⟩` сверяет только, что строка стоит в названной функции; `б` тела связано
`пусть`, а `б` утверждения — свободное имя.

Тем же корнем принимается `(«Ф» от а) равен 2`, где развёрнута одна строка ветви `иначе`.

## Что должно быть

Развёртка без варианта берётся, только когда названная строка — единственная строка тела (`одна_строка_тела` в
`checker.c` уже есть) либо тело собрано целиком; `пусть` выше строки — отказ.

## Обходной путь

Обхода нет. Ядро таких записей не пишет: дыра открыта тому, кто пишет запись сам.

## Когда задача сделана

Оба сверщика отвечают на эту запись кодом 1 либо 3; запись лежит подделкой в
`flang/proof/checker/tests/families/` со строкой в `flang/proof/checker/tests/probes.tsv`, и
`make -C flang/proof/checker пробы` отвечает «сошлось всё».

## Где живёт правка

`flang/proof/checker/checker.c`, ветвь развёртки без варианта; `flang/proof/checker/second/Moves.lean`. Печать семени не нужна.
