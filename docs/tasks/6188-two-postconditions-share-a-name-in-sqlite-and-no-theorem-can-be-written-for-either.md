# 6188. Два постусловия в sqlite.flang носят одно имя, и теорему нельзя написать ни для одного

## Шаги воспроизведения

1. `grep -n 'номер страницы неотрицателен' flang/stdlib/sqlite.flang`
2. То же на файле-пробе amb.flang:

   ```
   тотальная функция «Первая»
     принимает н: число
     возвращает число
     обеспечивает «ответ неотрицателен» результат не меньше 0
     если н меньше 0 то 0 иначе н

   тотальная функция «Вторая»
     принимает н: число
     возвращает число
     обеспечивает «ответ неотрицателен» результат не меньше 0
     если н меньше 0 то 0 иначе н

   теорема «ответ неотрицателен»
     дано н: число
     утверждаем результат не меньше 0
     следовательно доказано
   ```

3. `bootstrap/flang check amb.flang --proof`

## Что происходит

```
$ grep -n 'номер страницы неотрицателен' flang/stdlib/sqlite.flang
605:  обеспечивает «номер страницы неотрицателен» результат не меньше 0
611:  обеспечивает «номер страницы неотрицателен» результат не меньше 0
$ bootstrap/flang check amb.flang --proof
FLANG_PROOF_AMBIGUOUS в файле amb.flang, строка 13, столбец 1: теорема «ответ неотрицателен» закрывала бы сразу 2 постусловия («Первая», «Вторая»), и выбрать нельзя. Дайте постусловиям разные имена     код 1
```

Одноимённые постусловия стоят у функций «Правый потомок» (строка 602) и
«Потомок ячейки» (строка 608). В ведомости файла приговор у обоих —
`declared`, то есть ни одно из них сейчас не доказано: развести имена значит
открыть дорогу теореме, а не отнять уже доказанное.

Версия: flang 0.7.23.

## Что должно быть

У каждого постусловия файла своё имя, и теорему при нём можно написать.

## Обходной путь

Нет, пока имена не разведены.

## Когда задача сделана

1. `grep -c 'номер страницы неотрицателен' flang/stdlib/sqlite.flang` — не
   больше 1 (сейчас 2).
2. Теорема, поставленная при каждом из двух разведённых имён, принимается:
   `bootstrap/flang check flang/stdlib/sqlite.flang --proof` без
   `FLANG_PROOF_AMBIGUOUS`. Нужны обе половины: та же теорема на нынешнем файле
   `FLANG_PROOF_AMBIGUOUS` получать ДОЛЖНА — иначе проверяется не то.
3. `bootstrap/flang check flang/stdlib/sqlite.flang` — код 0. Сейчас он тоже 0,
   так что это охрана от отката, а не признак сделанного.
4. `bootstrap/flang check flang/stdlib/sqlite.flang --proof --json`:
   `totals.claims.proved` не меньше 92 — столько у файла сейчас. Всего
   приговоров 168: 87 `proved` и 5 `proved-induction` (вместе и дают 92), 44
   `grid`, 32 `declared`. Прогон стоит 7 мин 59 с и 1,0 ГиБ, код 3 — такой же,
   как сейчас.

## Где живёт правка

`flang/stdlib/sqlite.flang`, функции «Правый потомок» и «Потомок ячейки».
Перепечатка не нужна.
