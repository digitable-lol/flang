# 6201. Живые файлы дерева ссылаются на файлы удалённой реализации на JavaScript, и проверка ссылок этого не видит

Вторая реализация языка (каталоги `flang/src` и `flang/bin`, файлы `.mjs`) из
дерева удалена. Ссылки на её файлы и строки остались в документах, скриптах,
рабочих процессах CI и комментариях исходников.

## Шаги воспроизведения

```sh
git ls-files 'flang/src/*.mjs' 'flang/bin/*.mjs' | wc -l
git grep -l 'flang/\(src\|bin\)/[a-z0-9/-]*\.mjs' -- . \
  ':!docs/archive' ':!docs/zettel' ':!docs/tasks' ':!CHANGELOG.md' ':!changelog.json' \
  ':!docs/site/changelog.md' ':!docs/journal-carried-out-of-sources.md' | wc -l
```

## Что происходит

```
$ git ls-files 'flang/src/*.mjs' 'flang/bin/*.mjs' | wc -l
0
$ git grep -l … | wc -l
86
```

Файлов нет, а вне летописи (архив, заметки, задачи, журналы изменений) их
называют 86 файлов, 300 упоминаний. Больше всего: `docs/*.md` — 12,
`flang/src/emit/c` — 6, `flang/scripts` — 5, `.github/workflows` — 5,
`docs/adr` — 4, `bootstrap` — 4, `scripts/site` — 3, `scripts/guards` — 3,
`scripts/registry-example` — 3, `flang/src/emit/js` — 3. Среди них
`docs/HANDOFF.md` и `.github/workflows/ci.yml`.

Проверка ссылок (`bootstrap/flang run-script links:check`) смотрит только `.md`
(функция «Markdown дерева»), пропускает цитаты и пропускает целиком файл, у
которого в первых восьми строках стоит месяц с годом (функция «Дата в шапке»).
Комментарии в `.flang`, `.c`, `.yml` и датированные отчёты она не видит.

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

## Что должно быть

Вне летописи путь удалённого файла либо не упоминается, либо рядом с ним
сказано, что файл удалён, и назван живой источник того же довода. Новое
упоминание несуществующего пути красит проверку.

## Обходной путь

Нет.

## Когда задача сделана

1. По каждому из 86 файлов решено одно из трёх: это летопись (оставить);
   действующий довод (переписать на живой файл или снять); указание что-то
   сделать с несуществующим файлом (снять). Команда из шагов воспроизведения
   выдаёт только файлы, где рядом с путём стоит явное «удалён».
2. Комментарии с путями удалённых файлов в `flang/src/emit/**` и их копиях в
   `bootstrap/` сняты.
3. Есть проверка, которая краснеет на новом упоминании несуществующего пути в
   комментарии `.flang` и в датированном отчёте; показана на подлоге.

Пересъёмки чисел, снятых удалёнными пробами, задача не требует: от неё
отказались в самом дереве. «Ноль мест из 303» и «13 из 303» названы
предположением в `docs/integer-closed-under-addition.md` (врезка шапки и
раздел 5), коэффициент печати в C 1,80× — в `docs/native-x86-backend.md`
(врезка шапки). Величины, чьё значение объясняется устройством JavaScript,
разобраны в `docs/adr/0025-the-ceiling-leaves-the-type-and-becomes-an-obligation.md`,
раздел 2.

## Где живёт правка

Файлы из вывода команды. Проверка — `scripts/guards/link-guard.fscript`
(функции «Запись о прошлом» и «Markdown дерева») либо отдельный план рядом.
Правка `flang/src/emit/**` требует перепечатки самосборной части, остальное —
нет.
