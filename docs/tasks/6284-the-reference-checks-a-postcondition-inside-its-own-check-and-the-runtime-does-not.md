# 6284. Эталон проверяет постусловие внутри проверки постусловия, а рантайм нет — на функции, чьё постусловие зовёт её саму, эталон не кончает вычисление

## Шаги воспроизведения

1. Программа `self.flang`:

   ```
   модуль «Постусловие зовёт свою функцию»

   тотальная функция «Тот же»
     принимает н: число
     возвращает число
     обеспечивает «повтор не меняет» («Тот же» от результат) равен результат
     пример «пять»
       дано н равно 5
       ожидается 5
     н
   ```

2. Рантайм: `bootstrap/flang run self.flang --function '«Тот же»' --args '{"н": 5}'`.
3. Эталон: `bootstrap/flang ast self.flang > self.json`, затем из `flang/proof/lean` с собранными
   модулями `Binary64`, `Semantics/Eval`, `Semantics/Json`:
   `lean --run Semantics/Run.lean examples self.json`.
4. Запись и сверщики: `bootstrap/flang check self.flang --proof --record self.record`,
   `flang/proof/checker/сверщик self.flang self.record`,
   `flang/proof/checker/second/out/второй-сверщик self.flang self.record`.
5. Модель: `bootstrap/flang run-script lean-model:blocks -- --verbose`, строки вида
   `тотальность` с вердиктом `ОТВЕРГ`.

## Что происходит

```
$ bootstrap/flang run self.flang --function '«Тот же»' --args '{"н": 5}'
доказано: утверждений 1
5                                                                       код 0

$ lean --run Semantics/Run.lean examples self.json
self.json	Тот же	пять	топливо

$ grep -A3 '^тотальность' self.record
тотальность «Тот же» строка 3
  вид composition
  самовызова нет
  конец тотальности

$ flang/proof/checker/сверщик self.flang self.record
ПРОВЕРЕНО — запись сошлась с исходником, и всё доказанное проиграно заново   код 0

$ flang/proof/checker/second/out/второй-сверщик self.flang self.record
ПРОВЕРЕНО — утверждений 1, доказанных 1, блоки вывода приняты               код 0
```

Версия: `flang 0.7.34`.

Что делает каждая сторона.

- **Эталон** (`«вызватьТело»` в `flang/proof/lean/Semantics/Eval.lean`) после тела вычисляет
  каждое постусловие функции, при каждом вызове, доказано оно или нет. Постусловие зовёт
  функцию, вызов снова вычисляет постусловие; запас глубины кончается при любом его размере.
- **Рантайм** доказанное постусловие не вычисляет: в примере выше оно доказано ядром, и вызов
  возвращает `5`. Недоказанное он вычисляет после возврата, но вызов функции изнутри этой
  проверки возвращает значение, не проверяя постусловие ещё раз. Видно это на программе с
  недоказанным постусловием того же вида:

  ```
  функция «Следующее»
    принимает элементы: список числа
    возвращает список числа
    обеспечивает «повтор даёт то же» («Следующее» от результат) равен результат
    свёртка элементы начиная с пустой список как акк и эл → приписать эл к акк

  $ bootstrap/flang run unproved.flang --function '«Следующее»' --args '{"элементы": [1,2]}' --trust
  FLANG_PROPERTY: нарушено свойство «повтор даёт то же» функции «Следующее»   код 1
  ```

  Проверка кончилась и ответила: внутренний вызов вернул перевёрнутый список, круга не было.
  По какому правилу рантайм обрывает круг (не проверяет постусловия внутри проверки вовсе или
  только у той же функции), по исходнику `flang/self/interpret.flang` не установлено.
- **Печать блока тотальности** пишет в блок зовы тела; зовы из `обеспечивает` в блок не
  попадают, поэтому блок говорит `самовызова нет`.
- **Оба сверщика** судят блок по зовам тела и принимают его.
- **Модель Lean** (`«принятьКомпозицию»`, `flang/proof/lean/Semantics/Termination.lean`) стоит на
  эталоне и такой блок отвергает: «круг зовов через постусловие функции». В корпусе
  `flang/proof/checker/tests/records/corpus/` таких блоков пять: `krug-tuda-i-obratno`
  («Переворот», «Меньшее», «Большее»), `order` («Удвоить монотонно»),
  `poddelka-krug-pri-rabote` («Переворот хитрец»).

## Что должно быть

Эталон и рантайм дают один исход на одном входе: эталон — модель, против которой сверяется
напечатанный код ([ADR-0212](../adr/0212-each-runtime-function-the-print-calls-has-a-model-in-the-reference-and-is-checked-through-its-callers.md)),
и на ней же стоит теорема о блоке тотальности
([ADR-0228](../adr/0228-the-model-reads-a-composition-totality-by-the-reference-evaluator.md)).
Какая сторона права, эта задача не решает. Цена каждого выбора:

1. **Эталон перенимает правило рантайма** (постусловие внутри проверки постусловия не
   вычисляется; доказанное не вычисляется). Нужно: установить правило рантайма по исходнику и
   записать его; дать вычислителю эталона признак «идёт проверка» либо список доказанных
   постусловий; передоказать леммы о запасе (`Semantics/Fuel.lean`) и теорему о композиции с
   новым `«вызватьТело»`; перемерить сверку перевода (`Semantics/Validate.lean`). Пять блоков
   корпуса модель тогда примет. Постусловие перестаёт быть частью значения вызова в модели:
   вложенный вызов возвращает значение, о котором постусловие не проверено.
2. **Рантайм и запись перенимают правило эталона** (постусловие — часть вызова всегда).
   Нужно: печать блока тотальности называет зовы из `обеспечивает`; оба сверщика считают круг
   через постусловие самовызовом; проверка отвергает функцию, чьё постусловие зовёт её саму
   без убывания. Это правка `flang/self/**` и перепечатка; программы, где постусловие говорит
   о повторном применении функции (`обращение обращения — исходное`), перестают проходить
   как композиция и требуют теоремы вместо постусловия.
3. **Стороны остаются разными, расхождение названо.** Нужно: модель тотальности судит тело
   без постусловий (свой вариант `«вызватьТело»` в `Termination.lean`), и теорема говорит о
   вычислении без проверок. Дешевле всего; теорема тогда слабее того, что вычисляет эталон.

## Обходной путь

Обхода нет: блоки стоят в переписи строкой `ОТВЕРГ`, в читаемые они посчитаны.

## Когда задача сделана

`lean --run Semantics/Run.lean examples self.json` и `bootstrap/flang run` дают на примере
«пять» один исход, и перепись `bootstrap/flang run-script lean-model:blocks` печатает у вида
`тотальность` `ОТВЕРГ 0` — либо эти пять блоков отвергают и оба сверщика.

## Где живёт правка

Выбор 1 и 3 — `flang/proof/lean/Semantics/**`, печати не требует. Выбор 2 —
`flang/self/**` (печать блока, проверка завершения, вычислитель) и оба сверщика, требует
перепечатки самосборной части.
