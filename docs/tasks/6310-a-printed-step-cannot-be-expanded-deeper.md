# 6310. Шаг нельзя развернуть глубже

Шаг напечатан одной строкой. Спросить у двоичного «почему этот шаг верен» и получить
вывод уровнем ниже нечем.

Решение — [ADR-0057](../adr/0057-a-derivation-is-printed-as-a-reasoning-a-human-reads.md).

## Шаги воспроизведения

1. `bootstrap/flang check --help | grep -ciE 'explain|разверн|почему|глубже'`
2. `bootstrap/flang --help` — смотреть список команд.

## Что происходит

```
$ bootstrap/flang check --help | grep -ciE 'explain|разверн|почему|глубже'
0
```

Команд у двоичного 15 (`flang --help`), ключей у `check` шесть: `--proof`, `--json`,
`--strict`, `--record`, `--fast` и три предела прогона. Ключа, который берёт одно
утверждение или один шаг и печатает его вывод подробнее, нет; команды — тоже.

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

## Что должно быть

Ключ вида `check --proof --шаг «имя утверждения»` печатает вывод одного утверждения
с разворотом каждого шага: какое правило, какие посылки, из каких строк исходника они
взяты и во что развёрнуто тело функции. Без такого ключа «читаемый ход» упирается в
одну строку на шаг.

## Обходной путь

Нет. Запись `--record` несёт ровно те же строки, что раздел для человека, и уровнем
ниже не идёт.

## Когда задача сделана

Прогон ключа на `flang/proof/probes/user-programs/programs/discount.flang` печатает для
шага `вывод 4 Н12` его посылки с местом в исходнике и формулировку правила; без ключа
вывод прежний знак в знак.

## Где живёт правка

`flang/self/cli.flang` (ключ), раздел ведомости в `flang/self`, `flang/self/proofterm.flang`.
