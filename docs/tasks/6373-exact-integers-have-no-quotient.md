# 6373. Над точным целым нет частного: «делить на» не определено, дробь из двух переменных не построить, по разрядам не разобрать

Заявка: https://github.com/digitable-lol/flang/issues/380

Остаток над точным целым считается делением разрядов, а само частное получить нечем. Нет и названного перевода точное целое ↔ число, о котором говорит диагностика.

## Шаги воспроизведения

1. Программа `shift.flang`:

```flang
модуль «Сдвиг вправо»

тотальная функция «Делением»
  принимает а: точное целое, б: точное целое
  возвращает точное целое
  а делить на б

тотальная функция «Через дробь»
  принимает а: точное целое, б: точное целое
  возвращает точное целое
  целая часть [а, б]

тотальная функция «По разрядам»
  принимает а: точное целое
  возвращает точное целое
  разбор а
    случай пусто
      то а
    случай голова и хвост
      то хвост
```

2. `bootstrap/flang check shift.flang`.

## Что происходит

```
$ bootstrap/flang check shift.flang
shift.flang: не проверено — замечаний 7
FLANG_TYPE в файле shift.flang, строка 6, столбец 5: над точным целым «div» не определено: точное целое знает «плюс», «минус», «умножить на» и «остаток от»
FLANG_TYPE в файле shift.flang, строка 11, столбец 15: точное дробное записано не в каноне: обе половины точного дробного — списки разрядов: числитель и знаменатель
FLANG_BUILTIN_ARGS в файле shift.flang, строка 11, столбец 15: аргумент 1 формы «целая часть»: ожидался точное дробное, получен список точного целого
FLANG_TYPE: образец «пусто» применим к списку и строке, а разбирается точное целое
FLANG_TYPE: образец «голова и хвост» применим к списку и строке, а разбирается точное целое
FLANG_UNKNOWN_NAME в файле shift.flang, строка 20, столбец 10: имя «хвост» не связано: имя вводят 'принимает', 'пусть' или образец 'случай'; а действия языка ('плюс', 'минус', 'умножить на', 'делить на', 'остаток от') пишутся МЕЖДУ значения …
FLANG_MATCH_NOT_EXHAUSTIVE в файле shift.flang, строка 16, столбец 3: разбор точное целое перечислением не исчерпать: добавьте случай «любое»
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

`а делить нацело на б` (или `частное от`) над точным целым даёт точное целое; деление на ноль — отказ `FLANG_PROPERTY`. Правило ядра: `(а частное б) умножить на б плюс (а остаток от б) равно а` при `б больше 0`. Решение записывается ADR.

## Обходной путь

Держать слово в `число` до 2^53 и писать сдвиг рекурсией по битам.

## Когда задача сделана

`bootstrap/flang run shift.flang --function «Делением»` на `[0, 0, 524288]` и `[2]` даёт `[0, 0, 262144]`; `check` принимает «Делением» без замечаний.

## Где живёт правка

`flang/self/types.flang`, `flang/self/builtins.flang`, рантаймы печати. Ждёт печати семени.
