# 6417. Checker не принимает гипотезу-конъюнкцию, которая стоит в «таких что» утверждения

## Шаги воспроизведения

1. Программа both.flang:

```flang
модуль «Probe»

объект «Предмет»
  «человек»: признак
  «смертен»: признак

утверждение «утверждение»
  для всех предмет: «Предмет» таких что предмет.«человек» и притом предмет.«смертен»
  утверждаем предмет.«человек»

следует «утверждение»
  дано предмет: «Предмет»
  дано (предмет.«человек» и притом предмет.«смертен»)
  утверждаем предмет.«человек»
  по предположению
```

2. `bootstrap/flang check both.flang --proof --strict --record both.rec`, затем
   `flang/proof/checker/сверщик both.flang both.rec`.
3. Смотреть коды возврата обеих команд.

## Что происходит

```
$ bootstrap/flang check both.flang --proof --strict --record both.rec
both.flang: ДОКАЗАНО — утверждений 1: доказано 1, … — код возврата 0
both.flang: НЕЗАВИСИМО НЕ ПРОВЕРЕНО — сверщик не сошёлся с записью (код 1; …):
все 1 доказанных стоят на слове ядра                                           код 0
$ flang/proof/checker/сверщик both.flang both.rec
НЕ СОШЛОСЬ: теорема «утверждение»: гипотеза ⟨предмет.«человек» и притом
предмет.«смертен»⟩ строки 13 не является допущением утверждения — её нет ни в
«таких что», ни в «требует», ни в объявленном типе                             код 1
```

Версия: flang 0.7.25, дерево 1149c78f7, прогон 11 октября 2026; checker собран из
`flang/proof/checker/checker.c` того же дерева. Строка причины
`checker-calls-it-a-lie/НЕ СОШЛОСЬ: теорема «…»: гипотеза ⟨… и притом …⟩` стоит в
`flang/proof/probes/falsifier/expected-failures.tsv` (строка 4).

Гипотеза теоремы совпадает с ограничением утверждения знак в знак. Ядро сверяет
гипотезы с допущениями (задача 5311) и принимает такую теорему. Checker
раскладывает «таких что» на отдельные члены `и притом` и ищет гипотезу среди
них; гипотеза-конъюнкция ни с одним членом не совпадает, и checker называет
запись ложью. Гипотеза из одного члена (`дано предмет.«человек»`) проходит
обе проверки.

Так пишет посылки переводчик рассуждений (ADR-0050): посылка в «таких что»,
та же посылка в `дано`. Посылка, которая сама есть конъюнкция, даёт код 1 на
честном доказательстве. Опровергатель находит это на шаблоне силлогизма
(`logic/base`, номер 44 при зерне 20261001), где посылка вида
`(предмет.«человек» и притом предмет.«человек»)`.

## Что должно быть

Код 1 checker — только для записи, которая утверждает неверное. Гипотеза, которая
есть конъюнкция членов «таких что» (или совпадает с ограничением целиком),
принимается так же, как гипотеза из одного члена; либо checker отвечает кодом 3.

## Обходной путь

Записывать конъюнкцию в `дано` отдельными гипотезами, по одной на член.

## Когда задача сделана

`сверщик both.flang both.rec` отвечает кодом 0 или 3. Опровергатель
(`bootstrap/flang run-script falsifier:check`) перестаёт находить причину
`checker-calls-it-a-lie/НЕ СОШЛОСЬ: теорема «…»: гипотеза ⟨предмет.«…» и притом
предмет.«…»⟩ строки N не является допущением утверждения`, её строка уходит из
`flang/proof/probes/falsifier/expected-failures.tsv`, а подлог
(`falsifier:forgery`) переносится на номера с другой известной находкой.

## Где живёт правка

`flang/proof/checker/checker.c` — сверка гипотез теоремы с допущениями
утверждения; приёмка Lean (`flang/proof/lean/`) и вторая реализация
(`flang/proof/checker/second/Theorem.lean`, ADR-0076) — тот же приём, если они
его судят.

## Следующий шаг

В `flang/proof/checker/checker.c` найти место, где гипотеза теоремы ищется среди членов
«таких что» (текст отказа «не является допущением утверждения»), и перед поиском по
членам сравнить гипотезу с ограничением целиком и с конъюнкцией его членов. Проба,
которая краснеет сегодня: `сверщик both.flang both.rec` отвечает кодом 1, а должен
0 или 3.
