# 6418. Развёртка по варианту берёт случай чужого разбора

## Шаги воспроизведения

1. Исходник `probe.flang`:

```flang
модуль «Развёртка внутреннего разбора»

тип «Дерево»
  вариант «Лист»
  вариант «Узел» содержит левое: «Дерево», правое: «Дерево»

функция «Ф»
  принимает д: «Дерево»
  возвращает число
  разбор д
    случай вариант «Лист»
      то 0
    случай вариант «Узел» с левое как л и правое как п
      то разбор л
        случай вариант «Лист»
          то 1
        случай вариант «Узел» с левое как лл и правое как пп
          то 2

утверждение «лист даёт один»
  утверждаем («Ф» от (вариант «Лист»)) равен 1
```

2. Запись `probe.record` (написана руками; строки `строк`, `знаков`, `отпечаток`, `отпечаток256` — по исходнику):

```
запись доказательства 1
исходник finds/U3-unfold-inner-match.flang
строк 22
знаков 505
отпечаток 446594270 378223637
ядро 2
утверждений 1
отпечаток256 036cdc51aface59b5a19a61e7edea90fb7a0a416de217a2ee78057a1bb2bc0fe

утверждение «лист даёт один» строка 20
  вид statement
  вердикт доказано
  теоремы нет
  правило «тождество после переписки допущением»
  по объявлению нет
    ход цель
    ход 1 развернуть ⟨«Ф» от (вариант «Лист»)⟩ строка 16 ⟨1⟩
    ход 2 закрыть тождеством
    ход конец
конец утверждения

конец записи
```

3. `flang/proof/checker/сверщик probe.flang probe.record`, затем
   `flang/proof/checker/second/out/второй-сверщик probe.flang probe.record`.

## Что происходит

Сверщик на C отвечает `ПРОВЕРЕНО`, код 0; второй сверщик отвечает кодом 3.

Версия: flang 0.7.34, `checker.c` и второй сверщик ствола `001d8df7c`.

Утверждение ложно: `«Ф» от (вариант «Лист»)` есть 0.

Строка 16 — случай `«Лист»` вложенного разбора по `л`, а не разбора параметра. У списков проверка привязки к
разбору первого параметра в `checker.c` есть, у вариантов — нет; второй сверщик отвечает «над строкой не случай
разбора первого параметра».

Тем же корнем принимаются разбор по значению другой функции и разбор по второму параметру.

## Что должно быть

Развёртка по варианту берёт только случай разбора первого параметра, как развёртка по списку.

## Обходной путь

Обхода нет. Ядро таких записей не пишет: дыра открыта тому, кто пишет запись сам.

## Когда задача сделана

Оба сверщика отвечают на эту запись кодом 1 либо 3; запись лежит подделкой в
`flang/proof/checker/tests/families/` со строкой в `flang/proof/checker/tests/probes.tsv`, и
`make -C flang/proof/checker пробы` отвечает «сошлось всё».

## Где живёт правка

`flang/proof/checker/checker.c`, развёртка по варианту. Печать семени не нужна.
