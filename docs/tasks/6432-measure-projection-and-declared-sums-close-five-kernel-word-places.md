# 6432. М1, М2, Разв3, К↑, Разв1 для суммы

Решение: [ADR-0042](../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.

## Места

`abilities` У3, `poddelka-svyortka-shagom` «нулей ровно столько, сколько элементов»,
`poddelka-strict-order` «в отданном списке есть хотя бы одно число» — М1/М2;
`equality` Р1 — Разв3 и К↑; `types` Т1 — Разв1 для суммы автора. Таблица и
причины — задача 9616, раздел «Что осталось до 100 %».

## Что сделать

Для каждого правила по порядку партии: строка `flang/proof/ПРАВИЛА-ВЫВОДА.tsv` →
лемма `Правила.lean` + ловушка `Ловушка.lean` → случай в `Приёмка.lean` и
`Состоятельность.lean` (ADR-0041) → приём `сверщик.c` → печать `zapis.flang` →
запись места толкованием (зонд `zond-k7`), сверщик код 0 → порча — код 1.
Коды записей-подделок «лжёт-программа» (`НАБОР.tsv`) обязаны остаться прежними.

## Как поймём, что сделано

Пять мест переиграны на печати ядра (пробы); `прогон.sh` — «сошлось всё»; Lean —
сверка вердиктов без расхождений; бюджет ADR-0042 §3 соблюдён.
