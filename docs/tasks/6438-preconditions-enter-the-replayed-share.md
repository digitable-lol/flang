# 6438. Снятие переигрывается и считается

Решение: [ADR-0038](../adr/0038-a-precondition-is-discharged-by-a-printed-derivation.md) §3.2–3.3.
Ш0 — до печати корпуса задачей 5332 (условие партии ADR-0026 §11).

## Чем измерено

13 сентября 2026: сверщик `flang/proof/чекер/сверщик.c` — 6982 строки кода,
потолок 7188; читает `требует` исходника как допущение (около строки 1011) и
проверяет оплату `требует` у вызванной для восьмого хода (около 980–1015);
блока снятия в записи не существует, приёма — тоже. Линейка доли
(`flang/proof/доля-корпуса.sh`, `flang/self/proof.flang`) собирает числитель из
постусловий (1729). Сегодня 629 / 651 = 96,62 %.

## Что сделать

1. **Ш0 — приём блока снятия** в сверщике по образцу приёма утверждения: цель,
   место, имя; вывод — существующими шагами (Т1/Т2, Н, факт обещания вызванной).
   Формы, которых в словаре нет, — замерить и назвать; заводить по общему порядку
   (строка ведомости, лемма Lean, ловушка, приём). Бюджет ADR-0038 §3.5: +80 строк
   кода на обе задачи.
2. Подделки: подменённая посылка; чужое место; снятие, названное для вызванной с
   неоплаченным `требует` — все код 1 с причиной; в `прогон.sh` и `НАБОР.tsv`.
3. Доля: знаменатель получает снятия, числитель — переигранные; линейка печатает
   ДВЕ доли рядом (старую и новую) до сходимости; порог 95 % — на новую только
   после печати корпуса и приёма (ADR-0038 §3.3). Недостижимые — по ADR-0023.
4. Пересъёмка записей корпуса печатью ядра (толкованием), сверка
   `доля-корпуса.sh --вложенность`.
5. Слово: 1729 — раздел «Отменено ADR-0038 в части обязательства»; числа
   `README.md`, `docs/DESCRIPTION.md`, `docs/ROADMAP.md`,
   `docs/road-to-one-hundred-measured.md` — прибором.

## Чего не делать

- Не вычислять снятие в сверщике («калькулятор снят» — ловушка проверки 1).
- Не сливать две доли в одну раньше сходимости.
- Не трогать `bootstrap/**`.

## Как поймём, что сделано

Честная запись — код 0, подделки — код 1; `sh flang/proof/чекер/пробы/прогон.sh`
— «сошлось всё»; новая доля напечатана и не ниже 95 % после пересъёмки;
`sh scripts/доказуемость.sh` — ДОКАЗУЕМ; строк кода сверщика на обе задачи
прибавилось не больше 80; `ХРАПОВИК.txt` поднят ровно на съеденное.
