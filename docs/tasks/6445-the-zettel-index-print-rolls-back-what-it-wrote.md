# 6445. Печать указателя базы знаний пишет прямо в файл указателя и при обрыве оставляет его недописанным

## Шаги воспроизведения

1. `grep -n 'Записать файл' docs/zettel/zettel-index.flang | cut -c1-90`
2. `grep -c 'вариант «Провал»' docs/zettel/zettel-index.flang`
3. `bootstrap/flang run-script zettel-index:build`, затем
   `git status --porcelain -- docs/zettel/`: код возврата и что стало с файлом.

## Что происходит

```
$ grep -n 'Записать файл' docs/zettel/zettel-index.flang | cut -c1-90
295:      вариант «Сделать» с поручение равным (вариант «Записать файл» с путь равным («Фай
$ grep -c 'вариант «Провал»' docs/zettel/zettel-index.flang
9
$ bootstrap/flang run-script zettel-index:build                              код 0
{"plan":"Указатель базы знаний напечатан из заметок","result":"указатель напечатан в
README.md: заметок 725, без раздела 0, знаков 121022","orders":728,…}
$ git status --porcelain -- docs/zettel/
 M docs/zettel/README.md
```

Запись одна, последняя, и идёт сразу в файл указателя: хозяин открывает цель
`fopen(путь, "wb")` и обрезает её на месте, без времянки и переноса. Две ветви
отказа (`FLANG_INDEX_NOT_WRITTEN` и `FLANG_IO_ORDER` после записи) срабатывают
уже после попытки записи и прежнего содержимого не возвращают. Обрыв во время
записи оставляет недописанный файл.

Версия: flang 0.7.23, 2 октября 2026.

## Что должно быть

Обрыв или отказ в любой точке оставляет прежний указатель нетронутым.

## Обходной путь

После неудачного прогона `git checkout -- docs/zettel/` и повторить печать.

## Когда задача сделана

- `bootstrap/flang run-script zettel-index:build`, оборванный сигналом на середине, оставляет
  `git status --porcelain -- docs/zettel/` пустым;
- пояснение короткой команды `zettel-index:build` в самом
  `docs/zettel/zettel-index.flang` говорит, что она пишет в дерево.

## Где живёт правка

`docs/zettel/zettel-index.flang`, шаг с поручением «Записать файл» (строка 295)
и две ветви отказа после него: писать во временный файл рядом и переносить
поверх, либо восстанавливать прежнее содержимое. Поручения переименования в
словаре нет, перенос делается поручением «Запустить процесс». В том же файле —
«Объявление короткой команды zettel-index:build». Перепечатка не нужна.
