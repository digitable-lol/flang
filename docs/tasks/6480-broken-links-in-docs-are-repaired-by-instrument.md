# 6480. Проверка ссылок на стволе отвечает кодом 1: в документах стоят пути, которых нет в дереве

## Шаги воспроизведения

1. `LC_ALL=C.UTF-8 bootstrap/flang run-script links:check`
2. Смотреть последнюю строку вывода и код возврата. Прогон идёт около трёх
   минут.

## Что происходит

```
$ LC_ALL=C.UTF-8 bootstrap/flang run-script links:check
сторож ссылок ОТКАЗЫВАЕТ, битых 1 из 5355, устаревших исключений 0, в цитатах пропущено 1, в записях о прошлом 186:
  · docs/flang/proof/record-format.md: ссылка в никуда → ../../design/proof-object-blok-vyvoda.md     код 1
```

От 104 битых и 108 устаревших исключений, снятых на 0.7.23, к 11 октября 2026
осталась одна ссылка: коммит 26fc34d43 снял мёртвые пути и устаревшие строки
исключений, а `docs/flang/proof/record-format.md` (описание формата записи для
второй реализации сверщика, ADR-0076, коммит b99af39db) в строке 460 ссылается
на `docs/design/proof-object-blok-vyvoda.md`, которого в дереве нет. Ствол
по-прежнему красный, и новая битая ссылка в нём неотличима от этой.

Починить прибором нечего: у `scripts/guards/link-guard.fscript` ровно один
план, «Ссылки не ведут в никуда», он только читает и ни одного файла не пишет;
правка — рукой.

Устаревшие исключения — строки
`scripts/ledgers/link-guard-known-not-a-path.tsv`, прикрывающие имена, которых
в документах больше нет; сегодня их ноль. Строка ведомости снимает путь с суда,
то есть кода 0 можно добиться дописыванием строк, а не правкой дерева; мёртвая
строка не гасит ничего и делает список бед нечитаемым — красный сторож прячет
новое среди старого.

Версия: flang 0.7.25, дерево 1149c78f7.

## Что должно быть

`bootstrap/flang run-script links:check` в чистой копии ствола отвечает кодом 0: каждая ссылка
Markdown и каждый путь в кавычках ведут на файл дерева, устаревших исключений
нет.

## Обходной путь

Читать список битых ссылок глазами и отличать старые от новых.

## Когда задача сделана

`bootstrap/flang run-script links:check` в чистой копии ствола — код 0, «битых 0»,
«устаревших исключений 0».

## Где живёт правка

Файлы, названные прогоном. Адрес, уехавший вместе с файлом, правится в самой
ссылке. Имя, которое файлом дерева не является (имя пробы, обозначение
расширения), пишется без кавычек кода либо получает строку с доводом в
`scripts/ledgers/link-guard-known-not-a-path.tsv`. Правила чтения — в
`scripts/guards/link-guard.fscript`. Перепечатка не нужна.

## Следующий шаг

В `docs/flang/proof/record-format.md`, строка 460, заменить ссылку на
`../../design/proof-object-blok-vyvoda.md` ссылкой на живой источник того же довода —
раздел о блоке «вывод» в `docs/flang/proof/checker/README.md` или
`docs/adr/0022-a-type-fact-travels-as-a-derivation.md`. Проба, которая краснеет
сегодня: `bootstrap/flang run-script links:check` — «битых 1», код 1.
