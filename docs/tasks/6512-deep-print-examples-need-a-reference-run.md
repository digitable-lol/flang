# 6512. Функциям глубокой печати нечем снять примеры: нет связи между куском напечатанного и функцией, которая его произвела

«Печать вызова», «Печать если», «Печать функции», «Шаг цепочки» в
`flang/self/emit-c.flang` и их двойники с именем языка в названии («Печать скаляра
Python», «Печать числа Go») в `flang/self/emit-python.flang`,
`flang/self/emit-csharp.flang`, `flang/self/emit-java.flang`,
`flang/self/emit-go.flang` возвращают фрагмент целевого языка в сотни знаков.
Ожидаемое значение собирается пятью-десятью вложенными вызовами и из тела
глазами не выводится.

## Шаги воспроизведения

1. `bootstrap/flang run --help | grep -n 'args'`
2. Программа с вложенной записью — так устроены доводы печатающих функций
   («Печать вызова» берёт «Состояние» с «Контекстом» внутри):

```flang
модуль «Проба вложенного довода»

объект «Контекст»
  «имя»: строка

объект «Состояние»
  «контекст»: «Контекст»

тотальная функция «Имя состояния»
  принимает ход: «Состояние»
  возвращает строка
  пример «имя берётся из контекста»
    дано ход равно (запись «Состояние» с «контекст» равным (запись «Контекст» с «имя» равным "а"))
    ожидается "а"
  (ход.«контекст»).«имя»
```

3. `bootstrap/flang run <файл> --function '«Имя состояния»' --args '{"ход":{"контекст":{"имя":"а"}}}'`,
   затем то же с плоским доводом `'{"ход":"а"}'`.

## Что происходит

```
$ bootstrap/flang run --help | grep -n 'args'
1:flang run <файл.flang> --function «Имя» [--args '{"н":10}'] [--max-steps N]
17:  --args '{…}'       аргументы: ПЛОСКИЙ объект скаляров, вроде '{"н":10}'.
$ bootstrap/flang run <файл> --function '«Имя состояния»' --args '{"ход":{"контекст":…}}'
flang run: «--args» разобрать не удалось — ждался плоский объект скаляров,
вроде '{"н":10}'                                                       код 2
$ bootstrap/flang run <файл> --function '«Имя состояния»' --args '{"ход":"а"}'
FLANG_TYPE: вызов функции «Имя состояния»: аргумент «ход» не соответствует
типу «Состояние»                                                       код 1
```

Вложенную запись ключ `--args` не принимает, а плоской подмены у неё нет,
поэтому эталонный вывод одной печатающей функции прогоном не снять.
Инструмента, который сопоставляет куски вывода `flang emit` с функциями печати,
в дереве нет.

Версия: flang 0.7.23.

## Что должно быть

Примеры функций глубокой печати выписываются из снятого прогоном вывода:
небольшая программа на flang печатается в цель, куски напечатанного
сопоставляются с функциями, которые их произвели, и становятся примерами.

## Обходной путь

Нет: вывести значение из тела, снять его пробным вызовом или пробным файлом с
падающими примерами на этих функциях не удаётся.

## Когда задача сделана

- в дереве есть инструмент «кусок вывода — функция печати», и им выписаны
  примеры хотя бы для одного файла печати;
- `bootstrap/flang test` на этом файле проходит все примеры;
- приговоры постусловий файла до и после совпали: ни одно доказанное не стало
  недоказанным.

Ключ `--max-steps` у `flang emit` впечатывает предел в напечатанную программу, а
бюджет самой печати не поднимает; примеры расходуют тот же бюджет — мерить на
файле, где запас есть.

## Где живёт правка

Новый инструмент в `flang/scripts/` или `scripts/targets/`, короткая команда —
строкой `script.<имя>` в `.flangrc` и объявлением «Объявление короткой команды
<имя>» в самом инструменте; примеры — в `flang/self/emit-*.flang`. Примеры в
`flang/self/**` доезжают до двоичного перепечаткой самосборной части.
