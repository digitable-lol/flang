# 6526. Проверка страницы выпусков отвечает кодом 0 на клоне без тегов, где сверять не с чем

## Шаги воспроизведения

1. `grep -n 'клон без тегов' scripts/site/releases-page-verify.fscript | cut -c1-60`
2. `git clone --no-tags --single-branch .` в сторонний каталог, положить туда
   собранный `bootstrap/flang` и прогнать
   `bootstrap/flang run-script releases:page:check`.
3. Там же подменить заголовок первого выпуска на несуществующий —
   `## 9.9.9 — 1 января 1999` в `docs/site/releases.ru.md` и
   `docs/site/releases.md` — и прогнать ещё раз.

## Что происходит

```
$ grep -n 'клон без тегов' scripts/site/releases-page-verify.fscript | cut -c1-60
83:      " — клон без тегов."] по "")
$ bootstrap/flang run-script releases:page:check          (клон без тегов)
{"plan":"Страница выпусков сверена с тегами","result":"Сверка пропущена: тегов видно 0, заметок 40 — клон без тегов.",…}     код 0
$ bootstrap/flang run-script releases:page:check          (там же, с подлогом)
{"plan":"Страница выпусков сверена с тегами","result":"Сверка пропущена: тегов видно 0, заметок 40 — клон без тегов.",…}     код 0
$ bootstrap/flang run-script releases:page:check          (то же дерево с тегами, их 57)
{"plan":"Страница выпусков сверена с тегами","result":"Сверка прошла: выпусков 40, расхождений 0.",…}     код 0
```

Ветвь «тегов не видно» строит `вариант «Конец работы»`, то есть успех. Строка
«Сверка пропущена…» теперь печатается в поле `result` (прогон 11 октября 2026),
но код остаётся 0, и подложенный выпуск, которого нет ни в одном теге, ответа не
меняет: «сверено и сошлось» от «сверять не с чем» отличает только чтение вывода.

Зовёт эту проверку никто: она числится в `scripts/ledgers/uncalled-guards.json`;
в `.github/workflows/release.yml` её имя стоит только в комментарии (строка 219).

Версия: flang 0.7.25, дерево 1149c78f7.

## Что должно быть

Код 0 — сверено и сошлось, 1 — сверено и разошлось, 3 — сверять не с чем.
Так `flang io` отвечает на `вариант «Не проверено»`, и так уже устроена
`scripts/seed/bootstrap-point-by-binary.fscript`.

## Обходной путь

Читать вывод глазами и искать «Сверка пропущена».

## Когда задача сделана

- на клоне без тегов `bootstrap/flang run-script releases:page:check` отвечает кодом 3 и
  называет причину в выводе;
- пример в файле проверки ждёт `вариант «Не проверено»` на нуле тегов и краснеет
  (`FLANG_EXAMPLE`), если ветвь вернуть к «Конец работы»;
- проба: подлог заголовка выпуска на клоне без тегов даёт код 3, а не 0;
- та же ветвь проверена у соседнего ярлыка `releases:page`.

## Где живёт правка

`scripts/site/releases-page-verify.fscript`, ветвь в строке 83 и её пример.
Перепечатка не нужна.

## Следующий шаг

В `scripts/site/releases-page-verify.fscript`, строка 83: заменить `вариант «Конец
работы»` на `вариант «Не проверено»` с той же строкой причины и поправить пример
ветви. Проба, которая краснеет сегодня: `releases:page:check` на клоне
`git clone --no-tags --single-branch` отвечает кодом 0, а должен 3.
