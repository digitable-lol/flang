# 6526. Проверка страницы выпусков отвечает кодом 0 на клоне без тегов, где сверять не с чем

## Шаги воспроизведения

1. `grep -n 'клон без тегов' scripts/site/releases-page-verify.fscript | cut -c1-60`
2. Прогоном: `git clone --no-tags . <копия>`, в копии `make -C bootstrap` и
   `bootstrap/flang run-script releases:page:check`.

## Что происходит

```
$ grep -n 'клон без тегов' scripts/site/releases-page-verify.fscript | cut -c1-60
91:    то вариант «Конец работы» с значение равным (соединить ["Сверка
```

Ветвь «тегов не видно» строит `вариант «Конец работы»`, то есть успех. Прогон
на клоне без тегов, записанный при последней проверке:

```
$ bootstrap/flang run-script releases:page:check
Сверка пропущена: тегов видно 0, заметок 37 — клон без тегов.            код 0
```

Версия: flang 0.7.23, 30 сентября 2026 — строка 91; прогон на клоне не
перепроверен.

## Что должно быть

Код 0 — сверено и сошлось, 1 — сверено и разошлось, 3 — сверять не с чем.
Так `flang io` отвечает на `вариант «Не проверено»`, и так уже устроена
`scripts/seed/bootstrap-point-by-binary.fscript`.

## Обходной путь

Читать вывод глазами и искать «Сверка пропущена».

## Когда задача сделана

- на клоне без тегов `bootstrap/flang run-script releases:page:check` отвечает кодом 3 и
  называет причину;
- пример в файле проверки ждёт `вариант «Не проверено»` на нуле тегов и краснеет
  (`FLANG_EXAMPLE`), если ветвь вернуть к «Конец работы»;
- та же ветвь проверена у соседнего ярлыка `выпуски:страница`.

## Где живёт правка

`scripts/site/releases-page-verify.fscript`, ветвь в строке 91 и её пример.
Перепечатка не нужна.
