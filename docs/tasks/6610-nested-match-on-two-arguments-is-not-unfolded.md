# 6610. Вызов функции с вложенным разбором по двум доводам не разворачивается, даже когда оба довода — конструкторы

Заявка: https://github.com/digitable-lol/flang/issues/408
Заявка: https://github.com/digitable-lol/flang/issues/413

Шаг индукции «следующий не равен себе прежнему» сводится одним разворотом «Наты равны» по обоим доводам к допущению, но ядро его не делает (заявка 408). Постусловие о поле результата доказано при одном `разбор` и уходит на сетку при втором вложенном (заявка 413).

## Шаги воспроизведения

1. Программа `nat-eq.flang`:

```flang
модуль «Eq»

тип «Нат»
  вариант «Ноль»
  вариант «Следующий» содержит пред: «Нат»

тотальная функция «Наты равны»
  принимает а: «Нат», б: «Нат»
  возвращает признак
  пример «ноль»
    дано а равно вариант «Ноль»
    дано б равно вариант «Ноль»
    ожидается да
  разбор а
    случай вариант «Ноль»
      то разбор б
        случай вариант «Ноль»
          то да
        случай вариант «Следующий» с пред как другой
          то нет
    случай вариант «Следующий» с пред как п
      то разбор б
        случай вариант «Ноль»
          то нет
        случай вариант «Следующий» с пред как другой
          то «Наты равны» от п и другой

утверждение «следующий не равен себе прежнему»
  для всех н: «Нат»
  утверждаем («Наты равны» от (вариант «Следующий» с пред равным н) и н) равно нет

теорема «следующий не равен себе прежнему»
  дано н: «Нат»
  утверждаем («Наты равны» от (вариант «Следующий» с пред равным н) и н) равно нет
  индукция по н
    случай вариант «Следующий» с пред как п
      то по предположению
  следовательно доказано
```

2. Программа `two-levels.flang`:

```flang
модуль «Repro nested case projection»

тип «Сторона»
  вариант «Есть»
  вариант «Нет»

тип «Обёртка»
  вариант «Обёрнуто» содержит число_поля: неотрицательное, метка: «Сторона»

тотальная функция «Число обёртки»
  принимает обёртка: «Обёртка»
  возвращает неотрицательное
  пример «пять»
    дано обёртка равно вариант «Обёрнуто» с число_поля равным 5 и метка равным вариант «Есть»
    ожидается 5
  разбор обёртка
    случай вариант «Обёрнуто» с число_поля как число_обёртки и метка как метка_обёртки
      то число_обёртки

тотальная функция «Один уровень»
  принимает левая: «Сторона», число_входа: неотрицательное
  возвращает «Обёртка»
  обеспечивает «один уровень сохраняет число» «Число обёртки» от результат равно число_входа
  пример «есть»
    дано левая равно вариант «Есть»
    дано число_входа равно 5
    ожидается вариант «Обёрнуто» с число_поля равным 5 и метка равным вариант «Есть»
  разбор левая
    случай вариант «Есть»
      то вариант «Обёрнуто» с число_поля равным число_входа и метка равным вариант «Есть»
    случай вариант «Нет»
      то вариант «Обёрнуто» с число_поля равным число_входа и метка равным вариант «Нет»

тотальная функция «Два уровня»
  принимает левая: «Сторона», правая: «Сторона», число_входа: неотрицательное
  возвращает «Обёртка»
  обеспечивает «два уровня сохраняют число» «Число обёртки» от результат равно число_входа
  пример «есть есть»
    дано левая равно вариант «Есть»
    дано правая равно вариант «Есть»
    дано число_входа равно 5
    ожидается вариант «Обёрнуто» с число_поля равным 5 и метка равным вариант «Есть»
  разбор левая
    случай вариант «Есть»
      то разбор правая
        случай вариант «Есть»
          то вариант «Обёрнуто» с число_поля равным число_входа и метка равным вариант «Есть»
        случай вариант «Нет»
          то вариант «Обёрнуто» с число_поля равным число_входа и метка равным вариант «Нет»
    случай вариант «Нет»
      то разбор правая
        случай вариант «Есть»
          то вариант «Обёрнуто» с число_поля равным число_входа и метка равным вариант «Нет»
        случай вариант «Нет»
          то вариант «Обёрнуто» с число_поля равным число_входа и метка равным вариант «Нет»
```

3. `bootstrap/flang check nat-eq.flang --proof`.
4. `bootstrap/flang check two-levels.flang --proof`.

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Вызов разворачивается, когда все доводы, по которым идёт вложенный `разбор`, — конструкторы; постусловие функции с вложенным разбором доказывается разбором случаев по обоим параметрам.

## Обходной путь

Утверждать строение, а не неравенство; отдельный закон без входа на каждый случай.

## Когда задача сделана

`bootstrap/flang check nat-eq.flang --proof` и `two-levels.flang` — код 0, все утверждения доказаны. Подделка: в одном листе другое значение поля — не доказано.

`flang/self/proof-kernel.flang`, `flang/self/proof-initial.flang`. Ждёт печати семени.
