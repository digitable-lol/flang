# 6627. Модель не читает посылку индукции, закрытую правилом ядра без ходов — четыре правила и шаги автора держат 8 блоков вне модели

## Шаги воспроизведения

1. `bootstrap/flang run-script lean-model:blocks -- --verbose`.
2. Строки вида `утверждение-посылки-без-ходов`: у каждой в последнем столбце — сколько
   посылок блока стоят без ходов и чем они закрыты.

## Что происходит

Посылка записи `посылка «…» … закрыта reduction шагов 0 правило «П»` либо
`закрыта term шагов 1 правило «П»` несёт только имя правила ядра. Ходов под ней нет, и
второй сверщик принимает её, только когда утверждение целиком закрыл другой путь:
`«проигратьУзел»` (узлы по телу функции, у утверждения с теоремой), `«крюкиПоТелу»` (у
утверждения без теоремы) либо шаги автора `«Теорема».«судитьШаги»`. У всех трёх в
`flang/proof/tables/lean-soundness-debt.tsv` стоит «нет модели». Теорема о посылках
(«посылки-покрывают-варианты») судит у таких блоков покрытие вариантов типа, а не сами
посылки.

Блоков посылок в корпусе 45; у 39 хотя бы одна посылка стоит без ходов, у 6 ходы стоят под
каждой. Из 39 модель читает 26 видом `утверждение-по-построению`: теоремы
«неотрицательность-по-построению» (15 блоков, из них в 4 посылку основания закрыл шаг автора
«по примеру»: в 3 модель вычислила функцию на единственном значении варианта, в 1 — прошла
путь варианта при любых прочих доводах, `«база-по-пути-верна»`),
«ограниченность-по-построению» (3 блока), «порядок-по-построению» (1 блок, вместе с
потолком), «разбор-цели-по-условию» (2 блока: каждое постусловие держится на каждом пути
дерева тела, ADR-0236 §11) и «тождество-длин» (5 блоков: длины сторон равенства совпали на
каждом пути, ADR-0236 §12)
([ADR-0236](../adr/0236-the-model-reads-claims-closed-by-kernel-rules-by-construction.md)).
Ещё 5 блоков модель читает видом `утверждение-примером`: функция одного довода типа-суммы,
у которой все варианты без полей, вычислена на каждом варианте (ADR-0236 §6).
Чем закрыты посылки без ходов в остальных 8 блоках (блок считается у каждого правила,
которое в нём встретилось):

| правило ядра | блоков, где оно закрывает посылку без ходов | из них других правил в блоке нет |
|---|---|---|
| «неотрицательность по построению» | 3 | 2 |
| «тождество после переписки допущением» | 4 | 0 |
| «ограниченность точным потолком по построению» | 0 | 0 |
| «разбор цели по условию» | 1 | 0 |
| «порядок по построению» | 1 | 0 |
| правила нет: шаг автора (`закрыта term … правило «»`) | 5 | 0 |

Те же блоки по набору того, чем закрыты их посылки без ходов:

| набор | блоков |
|---|---|
| только «неотрицательность по построению» | 2 |
| «неотрицательность по построению» и шаг автора | 1 |
| «тождество после переписки допущением» и шаг автора | 3 |
| «тождество после переписки допущением» и «разбор цели по условию» | 1 |
| «порядок по построению» и шаг автора | 1 |

Из 8 блоков 5 — с теоремой исходника, 3 — без.

Три блока «тождество и шаг автора» (`svyortka-prefiks-chestnaya`) модель не берёт: тело —
свёртка, узлов свёртки дерево правила не читает. Блок «тождество и разбор цели» — «вставка
удлиняет ровно на один» (`corpus-lists`): длина там — вызов своей функции «Длина», а не
встроенная `длина` (ADR-0236 §12).

Блок «неотрицательность и шаг автора» «позиция неотрицательна» (`corpus-hof`) модель не
берёт: в теле `«Позиция где»` стоит применение довода-функции, у обхода тела узла применения
нет, и пройти путь варианта не по чему (ADR-0236 §6). «Порядок и шаг автора» — «позиция не
выходит за список» той же функции: порядок по построению модель берёт только у строкового
довода при разборе по нему (ADR-0236 §9).

Два блока «только неотрицательность» модель не берёт: это подделки с доводом без дна
(`poddelka-nositel-chislo-segment`, `poddelka-nositel-psevdonim-ne-otrezok`), которые
отвергают оба сверщика. `corpus-factorial` (спуск — произведение довода на допущение) модель
читает по условию ветви: довод-отрезок, для которого `н не больше 1` ложно, больше нуля.

Те же правила держат 3 из 5 блоков вида `утверждение-на-слове` (утверждение без посылок,
закрытое правилом ядра без шагов в записи): «порядок по построению» 1, «тождество после
переписки допущением» 1, «начало по построению» 1
([ADR-0234](../adr/0234-the-model-reads-a-claim-closed-by-example-on-a-function-without-parameters.md) §4).
Три блока «на слове» с правилом «неотрицательность по построению» и три с правилом «разбор
цели по условию» (`honest-modus-ponens-by-guard`) модель читает.

## Что должно быть

Каждое из пяти правил — теорема о модели: посылка, которую правило закрывает, верна в
эталонном вычислителе на всех значениях варианта при допущении индукции. Теоремы о
«неотрицательности по построению», «ограниченности точным потолком по построению» и
«порядке по построению» (длина результата не больше длины строкового довода при разборе по
нему) есть; о «разборе цели по условию» — для постусловия целиком, когда рядом не стоит
другое правило ядра; о «тождестве после переписки допущением» — для постусловия
`(длина результат) равен …` над встроенной `длина`, на доводах короче 2⁴⁸.
Шаг автора «по примеру» у варианта без полей модель читает вычислением функции с одним
доводом на единственном значении варианта (`«пример-на-значении»`), у функции с несколькими
доводами — путём варианта `пусто` по дереву цели при любых прочих доводах
(`«база-по-пути-верна»`); у варианта с полями и у шага «по предположению» под посылкой без
правила модели нет.

## Обходной путь

Обхода нет: блоки стоят в переписи видом `утверждение-посылки-без-ходов`, во второе число
(«судится путём с теоремой») не входят.

## Когда задача сделана

Перепись печатает вид `утверждение-посылки-без-ходов` с числом 0, и потолок «вне модели»
шага CI опущен на число блоков, которые модель прочла.

## Где живёт правка

`flang/proof/lean/**` и `flang/proof/checker/second/**`; печати не требует.
