# 6631. Объявленный тип поля записи в доказательство не входит: «неотрицательное» у довода доказывает цель, у поля — нет

## Шаги воспроизведения

1. Файл-проба с доводом:

   ```
   функция «Величина довода»
     принимает н: неотрицательное
     возвращает число
     обеспечивает «не меньше нуля» результат не меньше 0
     н
   ```

2. Файл-проба с полем:

   ```
   объект «Мера»
     «величина»: неотрицательное

   функция «Величина меры»
     принимает мера: «Мера»
     возвращает число
     обеспечивает «не меньше нуля» результат не меньше 0
     мера.«величина»
   ```

3. `bootstrap/flang check <проба> --proof --strict` на каждой, смотреть
   последнюю строку и код возврата.

## Что происходит

```
$ bootstrap/flang check pole-dovod.flang --proof --strict | tail -1
pole-dovod.flang: ДОКАЗАНО — утверждений 1: доказано 1, условно 0, сетка 0, объявлено, не доказано 0, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 0
$ bootstrap/flang check pole-zapisi.flang --proof --strict | tail -1
pole-zapisi.flang: НЕ УДАЛОСЬ ДОКАЗАТЬ — ОБЪЯВЛЕНО, НЕ ДОКАЗАНО — утверждений 1: доказано 0, условно 0, сетка 0, объявлено, не доказано 1, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 3
```

У довода цель сведена правилом «неотрицательность по построению». Из
объявления записи факт о значении поля ядро не берёт.

Версия: flang 0.7.23.

## Что должно быть

Цель `результат не меньше 0` при теле `мера.«величина»` и поле, объявленном
`неотрицательное`, доказана: это факт об объявлении, а не вычисление. Правило
честно: при построении записи поле уже сверяется с объявленным типом, и ни
отрицательный литерал, ни значение типа `число` в него не проходят —
`FLANG_TYPE`, код 1.

## Обходной путь

Передавать значение поля отдельным доводом с типом `неотрицательное` либо
дописывать примеры: цель тогда опирается на сетку, а не на доказательство.

## Когда задача сделана

- вторая проба отвечает «ДОКАЗАНО», код 0, и независимый проверяющий
  переигрывает её запись;
- подделка — то же поле объявлено `число` — остаётся недоказанной, код 3;
- обе пробы лежат в наборе проб и краснеют, если правило снять или расширить
  до типа `число`.

## Где живёт правка

`flang/self/proof-kernel.flang`: рядом с правилом «неотрицательность по
построению» нужен шаг «поле записи несёт объявленный тип». Если запись
доказательства получает новую форму шага — её читает
`flang/proof/checker/checker.c`. Требует перепечатки самосборной части.
