# 6661. Свой вариант «Сбой» сталкивается со встроенным «Отклик», но только когда модуль ввезён

Заявка: https://github.com/digitable-lol/flang/issues/400

Модуль с типом «Итог» и вариантом «Сбой» сам по себе проходит. Ввоз его в другой модуль и построение варианта там сталкивает «Сбой» со встроенным типом «Отклик», которого автор не объявлял; места отказа без файла.

## Шаги воспроизведения

1. Программа `итог.фп`:

```flang
модуль «Итоги»

тип «Итог»
  вариант «Готово» содержит значение: неотрицательное
  вариант «Сбой» содержит причина: строка

тотальная функция «Готово ли»
  принимает итог: «Итог»
  возвращает признак
  пример «готово»
    дано итог равно вариант «Готово» с значение равным 1
    ожидается да
  разбор итог
    случай вариант «Готово» с значение как значение
      то да
    случай вариант «Сбой» с причина как причина
      то нет
```

2. Программа `один-импорт.фп`:

```flang
модуль «Один импорт»
  использует «Итоги» из "итог.фп"

тотальная функция «Сбойный»
  принимает н: неотрицательное
  возвращает «Итог»
  пример «сбой»
    дано н равно 1
    ожидается вариант «Сбой» с причина равным "нет"
  вариант «Сбой» с причина равным "нет"
```

3. `bootstrap/flang check один-импорт.фп`.

## Что происходит

```
$ bootstrap/flang check один-импорт.фп
один-импорт.фп: не проверено — замечаний 5
место указано строкой и столбцом, но без файла: вместе с импортами проверено файлов 2, а диагностика компилятора имени файла не несёт
FLANG_TYPE: вариант «Сбой» объявлен и в «Итог», и в «Отклик»: имена вариантов должны быть уникальны
FLANG_TYPE, строка 10, столбец 3: конструктор «Сбой» требует поле «код» (строка)
FLANG_TYPE, строка 10, столбец 3: конструктор «Сбой» требует поле «сообщение» (строка)
FLANG_TYPE, строка 10, столбец 3: вариант «Сбой» типа «Отклик» не имеет поля «причина»
FLANG_TYPE, строка 10, столбец 3: функция «Сбойный» объявлена как «Итог», а тело даёт «Отклик»
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Встроенные типы ввода-вывода не попадают в пространство имён программы, которая ими не пользуется, или не мешают одноимённым вариантам автора; одинаковый ответ с ввозом и без. Если столкновение запрещено, отказ называет файл и строку объявления автора.

## Обходной путь

Переименовать вариант («Сбой ядра»).

## Когда задача сделана

`bootstrap/flang check один-импорт.фп` — код 0, как `check итог.фп`.

## Где живёт правка

`flang/self/link.flang`, `flang/self/io.flang`, `flang/self/types.flang`. Ждёт печати семени.
