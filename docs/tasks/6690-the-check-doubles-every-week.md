# 6690. Цена проверки разборщика не записывается по неделям, и её рост замечают, когда сборка уже красная

## Шаги воспроизведения

1. Снять цену проверки разборщика:

```
/usr/bin/time -f 'код %x, пик %M КиБ, %e с' bootstrap/flang check flang/self/parser.flang
```

2. Найти в дереве ряд таких замеров по неделям:

```
git ls-files 'docs/*.tsv' 'scripts/ledgers/*.tsv'
```

## Что происходит

```
$ /usr/bin/time -f 'код %x, пик %M КиБ, %e с' bootstrap/flang check flang/self/parser.flang
модуль «Парсер flang»: функций 910, из них с доказанным завершением 585; типов 72; файлов вместе с импортами 5
flang/self/parser.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
код 0, пик 4410192 КиБ, 238.64 с
```

Снято 11 октября 2026 на дереве 1149c78f7 (flang 0.7.25); на 0.7.23 тот же
прогон стоил 3 650 472 КиБ и 362,64 с при 880 функциях — пик вырос на пятую
часть, и сказать, за счёт чего, нечем. Ряда замеров в дереве нет. `docs/reprint-ledger.tsv` ведёт заходы побайтовой
сверки и перепечатки семени, и ни одна из ведомостей `scripts/ledgers/` цену
проверки не пишет. Значит рост цены замечает только тот, кто помнит прошлое
число наизусть, а причину каждый раз ищут заново.

Версия: flang 0.7.25, дерево 1149c78f7. ADR-0083 даёт цену функции до прогона
(`flang run --cost`), но ряда по неделям для цены проверки не ведёт.

## Что должно быть

В дереве лежит ведомость: тот же файл, та же команда, строка в неделю — пик
памяти, время, версия двоичного. По ней видно, дорожает ли проверка быстрее,
чем растёт дерево.

## Обходной путь

Мерить руками, когда сборка в CI упала по памяти или по шагам.

## Когда задача сделана

В ведомости не меньше четырёх недельных точек, и рядом сказано числами:

- какая доля роста приходится на рост дерева, какая — на саму проверку;
- что растёт: расход на утверждение, на функцию или на строку;
- какой предел будет пробит первым — память раннера GitHub, предел памяти
  двоичного по умолчанию или предел шагов `FL_MAX_STEPS` в
  `bootstrap/flang_runtime.h`.

## Где живёт правка

Новая ведомость рядом с `docs/reprint-ledger.tsv`; инструмент замера — в
`flang/scripts/` или `scripts/`, короткая команда — в `.flangrc`. Перепечатка
не нужна.

## Следующий шаг

Завести `docs/check-cost-ledger.tsv` (дата, дерево, версия, файл, функций, пик КиБ,
секунд) с двумя строками, которые уже есть в этой задаче, и план
`scripts/check-cost.fscript`, который снимает строку командой из шага 1 и дописывает
её. Проба, которая различает работу сегодня: `git ls-files 'docs/*.tsv'` не называет
ведомости цены проверки.
