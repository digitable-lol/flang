# 6704. Ведомость заходов перепечатки заполняется руками, и никто не проверяет, что заход в неё попал

## Шаги воспроизведения

1. Спросить дерево, какой дошедший заход оно называет:

```
grep -n '35 ч 45' scripts/bootstrap-reprint.sh
grep -c '128700\|128 700' docs/reprint-ledger.tsv
```

2. Сверить цену, которую дерево называет человеку, с ведомостью:

```
grep -rn '8 ч 34 мин' scripts/seed/*.fscript scripts/bootstrap-reprint.sh
awk -F'\t' '$2=="печать" && $3=="дошла"{s=$4} END{print s}' docs/reprint-ledger.tsv
```

## Что происходит

```
$ grep -n '35 ч 45' scripts/bootstrap-reprint.sh
289:# первый дошедший …, шёл 35 ч 45 мин. Вершина цепи суда —
$ grep -c '128700\|128 700' docs/reprint-ledger.tsv
0
```

Шапка `scripts/bootstrap-reprint.sh` называет дошедший заход длиной
35 ч 45 мин, а строки о нём в ведомости нет. Ведомость заполняется руками после
захода (её собственная шапка), и проверки, что заход в неё попал, нет ни одной.

Из-за этого цену перепечатки берут не из ведомости, а из прозы. Места дерева
называют 8 ч 34 мин и ссылаются при этом на ведомость, которая такой цены
последнего дошедшего захода не подтверждает:

```
scripts/bootstrap-reprint.sh:3402          «Цена последнего дошедшего захода — 8 ч 34 мин (docs/reprint-ledger.tsv).»
scripts/seed/seed-freshness.fscript:266    «Перепечатка стоит 8 ч 34 мин одного ядра (docs/reprint-ledger.tsv)»
```

Пропущенная строка **сверки** даёт ту же беду с другим знаком: по шапке самой
ведомости «без записи следующий не узнает, что сверка была, и свежесть сверки
останется красной при сделанной работе». То есть пропуск сверки даёт не
слепоту, а **ложную красноту** — сторожа, красного при сделанной работе,
перестают читать.

## Что должно быть

Полнота ведомости проверяется прибором, а не памятью того, кто вёл заход.
Прибор краснеет в двух случаях:

- дерево называет дошедший заход, а строки о нём в ведомости нет;
- место в дереве называет цену со ссылкой на `docs/reprint-ledger.tsv`, а
  ведомость этой цены не подтверждает.

## Обходной путь

Сверять глазами ведомость против шапки `scripts/bootstrap-reprint.sh`.

## Когда задача сделана

```
bootstrap/flang io scripts/guards/<имя>.fscript --plan Проверка
bootstrap/flang io scripts/guards/<имя>.fscript --plan Подлог
```

Первый прогон отвечает кодом 0 на дереве, где ведомость полна, и кодом 1 с
названием пропущенного захода на сегодняшнем. Второй — проба порчи, без которой
сторожа не отличить от выключенного
(`bootstrap/flang io scripts/guards/guards-without-forgery-probe.fscript` обязан остаться
зелёным).

Строка о заходе 35 ч 45 мин при этом в ведомости появляется.

## Где живёт правка

Новый сторож в `scripts/guards/`, зов — в `.githooks/pre-push.fscript` либо в
`ci.yml`, и строка в `docs/reprint-ledger.tsv`. Пересборка семени не нужна.

**Каких чисел для этой строки нет.** Из восьми полей ведомости по заходу
35 ч 45 мин известны: «печать», «дошла», секунды (128 700 с) и потолок шагов
4 000 000 000 000 (`MAX_STEPS` в `scripts/bootstrap-reprint.sh`). Нет **пика
памяти** и **байтов вывода**: их даёт только журнал того захода
(`/usr/bin/time -v` и размер напечатанного). Если журнала нет, поля пишутся
прочерком и словами «пик не замерен», как в других строках ведомости без замера.
