# 6752. Законы моноида, монады, функтора и блоки «закон» не судятся: ложное ожидание в блоке проходит, файлы категорий отвечают кодом 2

Решение принято: `docs/adr/0039-a-law-of-the-category-surface-is-a-statement-about-the-carrier.md` —
закон становится утверждением о носителе, сетка значений ищет контрпример.
Работа не начата.

## Шаги воспроизведения

1. `bootstrap/flang check flang/ct/monoid-and-monad.flang --proof; echo $?`
2. Проба: копия `flang/ct/order-shipment.flang`, в строке 47 (первый пример
   закона «номер отгрузки берётся из суммы заказа») ожидание 500 заменено на 777.
   `bootstrap/flang check <проба> --proof; echo $?`
3. Код каждого файла: `for f in flang/ct/*.flang flang/ct/modules/*.flang; do bootstrap/flang check $f --proof >/dev/null 2>&1; echo "$? $f"; done`

## Что происходит

```
$ bootstrap/flang check flang/ct/monoid-and-monad.flang --proof
ведомость не печатается: в программе объявлено то, чьи законы бинарник не считает — monoids, monads   код 2
$ bootstrap/flang check <проба> --proof
категория «Отгрузки»: сетка 6 значений на 3 объектах, троек стрелок 8, нарушений 0 — ПОСЧИТАНО НА СЕТКЕ, не доказано   код 2
```

Все 17 файлов `flang/ct` (13 в корне, 4 в `modules/`) отвечают кодом 2. Проба с
ложным ожиданием отвечает тем же кодом 2, что и подлинник: ложный пример
закона не назван.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

По ADR-0039: объявление моноида, монады, функтора, изоморфизма, естественного
преобразования и блок «закон» порождают утверждения о носителе. Код 0 — закон
доказан, 1 — нарушен и названо значение, 3 — не удалось доказать. Код 2
остаётся только за устройство преобразований.

## Обходной путь

Записывать закон свободным утверждением (`утверждение «…»`, `для всех`,
`утверждаем`) рядом с объявлением. Примеры блоков «закон» в такой записи
доказываются уже сегодня; контрпример утверждение без примеров не ищет.

## Когда задача сделана

1. Утверждения порождаются из объявлений моноида (ассоциативность, нейтраль
   слева и справа, обратный), функтора (тождество, композиция), монады (три
   закона), изоморфизма (два круга), естественного преобразования (квадрат) и
   блока «закон»; имя — имя закона, место — объявление.
2. Пример блока «закон» становится примером утверждения: проба с 777 отвечает
   кодом 1 и называет значение.
3. К сетке законов над числовыми носителями добавлены `−0`, `+∞`, `−∞`,
   `не число`, `2⁵³ ± 1`; найденное нарушение — код 1 со значениями. Квадрат
   «в копейки» из `flang/ct/natural-square.flang` ложен на 0,2 рубля и обязан
   быть назван.
4. Утверждения законов печатаются в запись доказательства, и независимый
   проверяющий их переигрывает; в его коде прибавилось не больше 30 строк.
   Подделки: закон о другом носителе; запись без примера, который есть в
   исходнике, — код 1.
5. Файлы `flang/ct` отвечают кодами 0, 1, 3 по существу законов;
   `docs/ct/spec.md` переписан там, где обещал сетку.
6. Законы считаются отдельной долей рядом с долей доказанных утверждений
   (ADR-0039, раздел 5).

Не входит: упрощатель и индукция по строке
(`docs/adr/0040-a-simplifier-rewrites-by-proved-equalities-and-prints-every-step.md`);
законы над `число` переписыванием «как над натуральными» не доказываются.

Что мешает истинным законам доказаться как утверждениям (не перепроверено,
снято на 0.7.19 по 95 законам дерева; полная таблица — в истории этого файла):
разбор по варианту значения монады; выбор `если` по порядку; индукция по
списку в утверждении; равенство записи, собранной из полей значения, самому
значению; нет правила о встроенной `соединить` (задача 4722); свёртка над
выписанным списком; нет правила «Т минус 0 есть Т».

## Где живёт правка

`flang/self/types.flang`, `flang/self/obligations.flang` (порождение
утверждений), `flang/self/proof-kernel.flang` (сетка с краями),
`flang/proof/checker/checker.c` (место объявления и имя закона),
`docs/ct/spec.md`. Требует перепечатки самосборной части.
