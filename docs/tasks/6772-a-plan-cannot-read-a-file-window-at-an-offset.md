# 6772. План читает окно файла со смещения

Вид: **возможность** (feature request), не дефект.

Заявка: https://github.com/digitable-lol/flang/issues/161 (пункт 1)

Большой файл обходят указателем: прочитать окно фиксированного размера со
смещения, разметить окно чистой функцией, сдвинуть указатель, повторить.
Память — одно окно, размер файла роли не играет. Сегодня план так не может:
файл читается только целиком.

## Шаги воспроизведения

1. План, первое поручение которого — чтение окна:

   ```
   тотальная функция «Дальше окна»
     принимает ход: «Шаг окна», отклик: «Отклик»
     возвращает «Продолжение»
     разбор ход
       случай вариант «Начало»
         то вариант «Сделать» с поручение равным (вариант «Прочитать октеты из файла» с путь равным "r7.txt" и смещение равным 0 и сколько равным 1048576) и потом равным (вариант «Ждём окно»)
       случай вариант «Ждём окно»
         то вариант «Конец работы» с значение равным "окно"
   ```

   Целиком (с типом «Шаг окна», началом, примером и объявлением `план`) — 29
   строк, по образцу `docs/examples/io/binary-file-round-trip.flang`; строка 22 —
   поручение выше.
2. `flang check window.flang`.

## Что происходит

```
$ flang check window.flang
модуль «Window probe»: функций 2, из них с доказанным завершением 2; типов 4
FLANG_TYPE в файле window.flang, строка 22, столбец 48: вариант «Прочитать октеты из файла» типа «Поручение» не имеет поля «смещение»
FLANG_TYPE в файле window.flang, строка 22, столбец 48: вариант «Прочитать октеты из файла» типа «Поручение» не имеет поля «сколько»
window.flang: не проверено — замечаний 2                          код 1
```

Версия: `flang 0.7.22`, двоичный из семени ствола `7b3a73873`. Прогон 27
сентября 2026.

Словарь поручений — `«Варианты поручения»` в
`flang/self/parser.flang:6614` (список на строке 6621), поручений **23**.
Файловых семь: «Прочитать файл», «Записать файл», «Прочитать октеты из файла»,
«Записать октеты в файл», «Удалить файл», «Перечислить каталог», «Завести
временный каталог». Оба чтения — файл целиком, одним откликом. По кускам
читаются только соединения («Прочитать из соединения», «Прочитать октеты из
соединения»).

Заявка ссылается на `parser.flang:758` — это другой список, `«Имена вариантов
ввода-вывода»` (строка 752): 39 имён поручений, откликов и продолжений вместе,
по которым разбор ставит признак «программе нужен ввод-вывод». Сверкой двух
списков в нём нет девяти имён из словаря: поручений «Показать», «Ждать
событие», «Прочитать доводы», «Размер экрана» и откликов «Показано»,
«Случилось», «Срок вышел», «Доводы», «Экран». Прогоном последствие не снято;
новое поручение надо вписать в оба списка.

Цена чтения целиком сегодня, `flang io`, план «Прочитать файл» и один
`разделить … по` над содержимым: файл 10 516 638 байт — 1,83 с, пик 128 388 КБ;
файл 1 115 401 байт — 0,29 с, пик 28 936 КБ. Память растёт вместе с файлом.

## Что должно быть

Поручение чтения окна и отклик с признаком конца, например:

```
поручение «Прочитать окно файла» содержит путь: строка, смещение: число, сколько: число
отклик    «Окно файла»          содержит октеты: список числа, конец: признак
```

- `октеты` — не больше `сколько` октетов, начиная с `смещение` (от нуля);
- `конец` — `да`, если окно дошло до конца файла или смещение за ним; тогда
  `октеты` может быть пустым;
- отрицательное или дробное `смещение`/`сколько` — отклик «Сбой» с кодом, а не
  падение хозяина;
- права те же, что у «Прочитать октеты из файла» (`read_files` хозяина,
  `io_path`).

Отдельное поручение, а не два новых поля у «Прочитать октеты из файла»:
вариант строится всеми полями, и новое поле сломало бы каждую программу, которая
уже строит этот вариант. Таких файлов в дереве 6 (`grep -rl` по `.flang` и
`.fscript`). Тот же довод записан в `parser.flang` у «Запустить процесс с
вводом».

Имена выше — предложение. Имя отклика надо проверить на столкновение
(`«Свободен для словаря»`, `parser.flang:6686`): в stdlib уже есть функция
«Кусок октетов», поэтому слово «кусок» здесь не взято.

## Обходной путь

Два, оба плохие:

1. Прочитать файл целиком — память равна файлу (числа выше).
2. Напечатать чистые функции в C (`flang emit … --target c --no-cli`) и
   написать свой хозяин с `pread`, как сделал автор заявки. Работает, но цикл
   «окно → функция → сдвиг» живёт вне языка.

## Когда задача сделана

1. Проба из «Шагов воспроизведения», переписанная на новое поручение:
   `flang check` — код 0.
2. `flang io` по файлу в 1 115 401 байт окнами по 1 048 576: два поручения,
   второе отвечает `конец` = `да`, сумма длин окон равна размеру файла, пик
   памяти не растёт с размером файла (прогнать на 10× файле и сравнить пик).
3. Проба порчи: `смещение` равно -1 — отклик «Сбой», код хозяина назван.
4. Сторожа словаря зелены с новыми числами:
   `scripts/guards/io-dictionary-copies-guard.fscript` («поручений 24,
   откликов 22»), `scripts/guards/tab-host-guard.fscript`.

## Где живёт правка

Порядок трёхшаговый (AGENTS.md, правило 2): ввести слово, перепечатать,
применить.

**Шаг 1 — ввести, `flang/self/**`, нужна полная перепечатка семени:**

- `flang/self/parser.flang:6597` `«Узел типа поручения»` — вариант и его поля;
- `flang/self/parser.flang:6602` `«Узел типа отклика»` — отклик;
- `flang/self/parser.flang:6614`–`6621` `«Варианты поручения»` (23 → 24) и
  `6623`–`6630` `«Варианты отклика»` (21 → 22) — список, пример, `обеспечивает`;
- `flang/self/parser.flang:752`–`759` `«Имена вариантов ввода-вывода»`;
- приметы `СНЯТО` с числами словаря в `flang/self/io.flang:18`–`22` (строки 6620, 6629, 6638 у `parser.flang`).

Перепечатка — `sh scripts/bootstrap-reprint.sh`. Последний дошедший заход
23–25 сентября 2026 шёл **35 ч 45 мин** (коммит `6f98e66e8`), предыдущий
10–11 сентября — 7 ч 28 мин (`docs/reprint-cost.md`). Закладывать сутки и больше.

**Шаг 3 — применить, копируемые части, второй перепечатки НЕ нужно:**

- `flang/src/emit/c/flang_repl.c:15644` `io_perform` — ветка рядом с
  «Прочитать октеты из файла» (строка 15748), `pread`/`fseek`; это хозяин
  `flang io`. Доезжает до двоичного быстрым пересевом `bootstrap/flang run-script seed:refresh`;
- `flang/src/emit/c/flang_conc.c:1731` `fl_conc_perform` — ветка рядом со
  строкой 1882; это хозяин напечатанного C с процессами. Попадает в вывод
  `flang emit` сразу: рантайм берётся из `flang/src/emit/c` при печати;
- `flang/src/emit/js/flang_io.js:90`, `flang/src/emit/js/flang_host_node.js:331`,
  `flang/src/emit/js/flang_host_browser.js`, `flang/src/emit/python/flang_io.py`;
- копии словаря в документации: `docs/ct/spec.md:1007`, `docs/flang/SPEC.md:1165`.

Здесь нужна одна перепечатка, а не две, как в задаче 6375: применение живёт
только в копируемых хозяевах, а не в `flang/self/**`.

## Цена

Шаг 1 — пять списков в одном файле и примеры, меньше дня работы, плюс одна
полная перепечатка (сутки и больше). Шаг 3 — пять хозяев и два сторожа, день-два.
