# 6772. План не может прочитать окно файла со смещения: файл читается только целиком

Заявка: https://github.com/digitable-lol/flang/issues/161 (пункт 1)

Это возможность, а не дефект. Большой файл обходят указателем: прочитать окно
со смещения, разметить его чистой функцией, сдвинуть указатель. По кускам
сегодня читаются только соединения.

## Шаги воспроизведения

1. Файл-проба window.flang:

   ```
   модуль «Window probe»

   тип «Шаг окна»
     вариант «Начало»
     вариант «Ждём окно»

   тотальная функция «Начало окна»
     возвращает «Шаг окна»
     вариант «Начало»

   тотальная функция «Дальше окна»
     принимает ход: «Шаг окна», отклик: «Отклик»
     возвращает «Продолжение»
     разбор ход
       случай вариант «Начало»
         то вариант «Сделать» с поручение равным (вариант «Прочитать октеты из файла» с путь равным "r7.txt" и смещение равным 0 и сколько равным 1048576) и потом равным (вариант «Ждём окно»)
       случай вариант «Ждём окно»
         то вариант «Конец работы» с значение равным "окно"

   план «Окно»
     состояние «Шаг окна»
     начинает с «Начало окна»
     обрабатывает «Дальше окна»
   ```

2. `bootstrap/flang check window.flang`

## Что происходит

```
$ bootstrap/flang check window.flang
модуль «Window probe»: функций 2, из них с доказанным завершением 2; типов 4
FLANG_TYPE в файле window.flang, строка 16, столбец 48: вариант «Прочитать октеты из файла» типа «Поручение» не имеет поля «смещение»
FLANG_TYPE в файле window.flang, строка 16, столбец 48: вариант «Прочитать октеты из файла» типа «Поручение» не имеет поля «сколько»
window.flang: не проверено — замечаний 2                          код 1
```

В словаре 23 поручения и 21 отклик; оба файловых чтения отдают файл целиком
одним откликом.

Версия: flang 0.7.23, 2 октября 2026.

## Что должно быть

Отдельное поручение и отклик, например:

```
поручение «Прочитать окно файла» содержит путь: строка, смещение: число, сколько: число
отклик    «Окно файла»          содержит октеты: список числа, конец: признак
```

- `октеты` — не больше `сколько` октетов начиная со `смещение` (от нуля);
- `конец` — да, если окно дошло до конца файла или смещение за ним;
- отрицательное или дробное `смещение` или `сколько` — отклик «Сбой» с кодом;
- права те же, что у «Прочитать октеты из файла».

Новые поля у существующего поручения не годятся: вариант строится всеми
полями, и каждая программа, которая его уже строит, перестала бы проверяться.
Имена — предложение; имя отклика проверить на столкновение функцией
«Свободен для словаря».

## Обходной путь

Читать файл целиком — память растёт вместе с файлом. Либо напечатать чистые
функции в C (`flang emit --target c --no-cli`) и написать свой исполнитель с
`pread`: цикл «окно, функция, сдвиг» тогда живёт вне языка.

## Когда задача сделана

1. Проба, переписанная на новое поручение: `bootstrap/flang check` — код 0.
2. `flang io` читает файл окнами: последнее окно отвечает `конец` = да, сумма
   длин окон равна размеру файла, пик памяти на файле в десять раз больше тот
   же.
3. `смещение` равно -1 — отклик «Сбой» с названным кодом.
4. `scripts/guards/io-dictionary-copies-guard.fscript` зелен с числами
   «поручений 24, откликов 22».

## Где живёт правка

Ввести слово — `flang/self/parser.flang`, нужна перепечатка самосборной части:
функции «Узел типа поручения», «Узел типа отклика», «Варианты поручения»,
«Варианты отклика» (списки, примеры, постусловия о длине) и «Имена вариантов
ввода-вывода». Новое имя вписывается во все списки.

Исполнить — без второй перепечатки:

- `flang/src/emit/c/flang_repl.c`, функция `io_perform`, ветка рядом с
  «Прочитать октеты из файла»; доезжает до двоичного короткой командой
  `seed:refresh`;
- `flang/src/emit/c/flang_conc.c`, функция `fl_conc_perform`;
- `flang/src/emit/js/flang_io.js`, `flang/src/emit/js/flang_host_node.js`,
  `flang/src/emit/js/flang_host_browser.js`, `flang/src/emit/python/flang_io.py`;
- копии словаря в `docs/ct/spec.md` и `docs/flang/SPEC.md`.
