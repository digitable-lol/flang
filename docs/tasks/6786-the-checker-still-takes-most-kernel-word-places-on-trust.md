# 6786. Сверщик по-прежнему берёт на слово ядра 229 мест в 113 записях корпуса

## Шаги воспроизведения

1. Корпус — записи, которые сличает работа `checker:second`: все `*.record` под
   `flang/proof/checker/tests` и `flang/proof/forgeries` с исходником на месте.
2. `bootstrap/flang run-script checker:second`.
3. Строка «второй дал вердикт …: … НЕ ПРОВЕРЕНО N»; поимённо — строки `НЕ ВЗЯЛСЯ`
   ответа `flang/proof/checker/сверщик <исходник> <запись>` по каждой записи.

## Что происходит

12 октября 2026, ветка `a/the-checker-replays-what-it-took-on-the-kernel-word`:

```
$ bootstrap/flang run-script checker:second
записей 688, без исходника 52, сличено 636
второй дал вердикт 636: НЕ СОШЛОСЬ 250, ПРОВЕРЕНО 244, НЕ ПРОВЕРЕНО 142
расхождений 0
```

Сумма «мест на слово ядра» по прежним 634 записям — 229 в 113 записях. Самые крупные
виды (строк причин): узел вердикта без правила — 55; переписка допущением — 24;
«разбор цели по условию» — 24; «неотрицательность по построению» с непростым телом —
29; шаг «по предположению», выводимый лишь сведением, — 18. Таблица всех видов —
ADR-0103 §1.1.

## Что должно быть

Доказанным считается то, что проиграл сверщик (ADR-0073). Каждый вид места либо
переигрывается сверщиком по описанию формата, либо запись несёт ходы ядра, которые
сверщик сверяет.

## Обходной путь

Код 3 сверщика честно называет каждое место; ничего не принимается молча.

## Когда задача сделана

`bootstrap/flang run-script checker:second` печатает «НЕ ПРОВЕРЕНО» только у записей,
где место на слове ядра названо долгом с номером задачи; каждый снятый вид — строки
семьи в `flang/proof/checker/tests/probes.tsv` (честная → 0, подлог → 1) и тот же
приём во втором сличителе (`checker:second`, «расхождений 0»).

## Где живёт правка

`flang/proof/checker/checker.c`, `flang/proof/checker/second/*.lean`,
`docs/flang/proof/record-format.md`; для видов без печатных ходов — печать записи в
ядре (`flang/self/proof-record.flang`), то есть перепечатка семени.
