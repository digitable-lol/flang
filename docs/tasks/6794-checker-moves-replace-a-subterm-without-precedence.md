# 6794. Ходы сверщика меняют подтерм мимо старшинства знаков

## Шаги воспроизведения

1. Исходник `probe.flang`:

```flang
модуль «Соседи под произведением»

утверждение «сумма под произведением»
  для всех а: число и б: число и ц: число
  утверждаем (а умножить на б плюс ц) равен (а умножить на (ц плюс б))
```

2. Запись `probe.record` (написана руками; строки `строк`, `знаков`, `отпечаток`, `отпечаток256` — по исходнику):

```
запись доказательства 1
исходник finds/P1-neighbours-under-product.flang
строк 6
знаков 186
отпечаток 515740721 294097466
ядро 2
утверждений 1
отпечаток256 7411a33ba944121849b9e1eec6ba75ee32450e336450e864a2366d203946d3c5

утверждение «сумма под произведением» строка 3
  вид statement
  для всех «а» ⟨число⟩ строка 4
  для всех «б» ⟨число⟩ строка 4
  для всех «ц» ⟨число⟩ строка 4
  вердикт доказано
  теоремы нет
  правило «тождество после переписки допущением»
  по объявлению нет
    ход цель
    ход 1 соседи ⟨б плюс ц⟩
    ход 2 закрыть тождеством
    ход конец
конец утверждения

конец записи
```

3. `flang/proof/checker/сверщик probe.flang probe.record`, затем
   `flang/proof/checker/second/out/второй-сверщик probe.flang probe.record`.

## Что происходит

Оба сверщика отвечают `ПРОВЕРЕНО`, код 0.

Версия: flang 0.7.34, `checker.c` и второй сверщик ствола `001d8df7c`.

Утверждение ложно: при `а = 2`, `б = 1`, `ц = 1` слева 3, справа 4 — `flang run` даёт `false`.

Ход `соседи ⟨б плюс ц⟩` находит текст `б плюс ц` внутри `а умножить на б плюс ц`, где он не подтерм: язык читает
`(а умножить на б) плюс ц`. Поиск и замена идут по пробельным краям (`есть_терм`, `вставить_вместо` в `checker.c`,
`«вместо»` в `Terms.lean`).

Тем же корнем принимаются: `(а минус б плюс ц) равен (ц плюс а минус б)`; `(а делить на б умножить на ц) равен
(ц умножить на а делить на б)`; `(если да то а иначе б плюс 1) равен (а плюс 1)` ходом `выбор`;
`(а умножить на 2 плюс 3) равен (а умножить на 5)` ходом `вычислить ⟨2 плюс 3⟩`; `(б умножить на 0 плюс а) равен
(б умножить на а)` ходом `нейтральный ноль`; `если п или р то не (не п или р) иначе да` ходом `деление ⟨п или р⟩`;
модус-поненс без скобок.

## Что должно быть

Вхождение берётся, только когда оно целый операнд: в скобках, вся цель либо соседние знаки слабее знака терма.
У `соседи` — отказ, если сверху рядом стоит `минус`, `делить на` или `остаток от`.

## Обходной путь

Обхода нет. Ядро таких записей не пишет: дыра открыта тому, кто пишет запись сам.

## Когда задача сделана

Оба сверщика отвечают на эту запись кодом 1 либо 3; запись лежит подделкой в
`flang/proof/checker/tests/families/` со строкой в `flang/proof/checker/tests/probes.tsv`, и
`make -C flang/proof/checker пробы` отвечает «сошлось всё».

## Где живёт правка

`flang/proof/checker/checker.c` (`есть_терм`, `вставить_вместо` и ходы над ними), `flang/proof/checker/second/Terms.lean`,
`Moves.lean`. Печать семени не нужна.
