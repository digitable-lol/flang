# 6812. Семейство Пр

Решение: [ADR-0042](../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.

Места: `abilities` У23, `poddelka-protivorechie` «что угодно из несовместимой пары».
Шаг записи вида «Пр1 ⟨цель⟩ строка N строка M»: из `а меньше б` и `б не больше а` в
допущениях — любая цель. Строка ведомости (семейство Пр — первое, открытое сверх
закрытого списка, основание — ADR-0042), лемма Lean (обе посылки вместе ложны
при любых значениях модели, NaN включительно), ловушка (пара без противоречия —
`а меньше б` и `а не больше б`), случай в приёмке Lean, приём сверщика, печать
ядра, пробы и порча. Сделано — оба места переиграны, «калькулятором» у них ноль.
