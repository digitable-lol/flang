# 6892. Отрицание равенства длины минус нулю даёт непустой список

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/length-not-equal-negative-zero.flang`:

```flang
модуль «Длина против минус нуля»

тотальная функция «Длина или один»
  принимает элементы: список числа
  возвращает число
  обеспечивает «итог положителен» результат больше 0
  если (длина элементы) равен -0 то 1 иначе (длина элементы)
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/length-not-equal-negative-zero.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/length-not-equal-negative-zero.flang --function 'Длина или один' --args '{"элементы":[]}'`

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/typing-holes/programs/length-not-equal-negative-zero.flang --proof
… ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — … доказано
$ bootstrap/flang run flang/proof/probes/typing-holes/programs/length-not-equal-negative-zero.flang --function 'Длина или один' --args '{"элементы":[]}'
FLANG_PROPERTY: нарушено свойство «итог положителен» функции «Длина или один»                                  код 1
```

Версия: flang 0.7.34.

Длина пустого списка — `+0`, и `+0 равен -0` ложно: ветвь `иначе` берётся и на пустом списке. Правило Отр1
(«Длина не ноль», «Длина против нуля») узнаёт ноль числом («Это ноль ядра») и из отрицания равенства длины
литералу `-0` выводит строгую положительность длины. То же с `требует «…» не ((длина л) равен -0)` и со строкой.

## Что должно быть

Строгая положительность длины выводится только из отрицания равенства литералу плюс ноль.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check flang/proof/probes/typing-holes/programs/length-not-equal-negative-zero.flang --proof` не числит ложное утверждение доказанным.
Проба — строки этой программы в `flang/proof/probes/typing-holes/expected.tsv`
и строка ведомости `flang/proof/tables/typing-holes.tsv`: сегодня они держат ответ
двоичного 0.7.34, после правки строка `proof` меняется с «доказано 1» на «доказано 0», строка ведомости — на `закрыта`.

## Где живёт правка

`flang/self/proof-kernel.flang`, «Длина против нуля» (теперь «Ноль плюсом»): правка сделана в этой же ветке и ждёт
печати семени (партия 12).
