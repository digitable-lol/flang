# 6913. У печати в C# и у языкового сервера не названо, чем проверяется верность их вывода

Оба слоя проверялись побайтовой сверкой с реализацией на JavaScript: печать —
с генератором C#, сервер — с потоком JSON-RPC. Реализация на JavaScript из
дерева удалена; формулировки прежних критериев лежат в
`docs/journal-carried-out-of-sources.md`. Остальные слои держатся на примерах,
постусловиях и сверке с рантаймом цели.

## Шаги воспроизведения

1. `grep -c 'критери\|верност' flang/self/emit-csharp.flang flang/self/lsp.flang`
2. `grep -c 'пример «' flang/self/emit-csharp.flang flang/self/lsp.flang`

## Что происходит

```
$ grep -c 'критери\|верност' flang/self/emit-csharp.flang flang/self/lsp.flang
flang/self/emit-csharp.flang:0
flang/self/lsp.flang:0
$ grep -c 'пример «' flang/self/emit-csharp.flang flang/self/lsp.flang
flang/self/emit-csharp.flang:258
flang/self/lsp.flang:152
```

Примеры у обоих файлов есть, сервер гоняется в редакторе
(`scripts/editors/lsp-check.fscript`), но нигде не сказано, что из этого
считается критерием верности и что он покрывает. Напечатанный C# проверкой
дерева не собирается и не запускается.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Для каждого из двух слоёв в дереве названа проверка, которая краснеет на
неверном выводе, либо прямо записано, что верность вывода сегодня не несётся
ничем.

## Обходной путь

Нет.

## Когда задача сделана

Для `flang/self/emit-csharp.flang` и `flang/self/lsp.flang` в документации
слоя записано:

- чем несётся верность вывода: ярлык и файл проверки;
- числа: сколько постусловий у файла, сколько доказано, сколько примеров —
  с командой, которая их снимает;
- покрывает ли слой сверка неподвижной точки при перепечатке;
- подделка: испорченная строка печати C# и испорченный ответ сервера делают
  названную проверку красной.

## Где живёт правка

Проверка печати C# — в `scripts/targets/`, сервера — в `scripts/editors/`;
ярлыки в `ярлыки.flang`; запись о критерии — в `docs/flang/SPEC.md` или
рядом со слоем. Перепечатка не нужна, пока не правятся сами
`flang/self/emit-csharp.flang` и `flang/self/lsp.flang`.
