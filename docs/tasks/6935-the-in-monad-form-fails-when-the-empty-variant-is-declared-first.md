# 6935. Форма «в монаде» не собирается, когда вариант без поля объявлен в типе первым — FLANG_TYPE_PARAM на конструкторе, который автор не писал

## Шаги воспроизведения

1. Программа — `docs/examples/monad/order-total.flang`, в типе «Возможно» поменять
   местами две строки вариантов: сначала `вариант «Нет»`, затем
   `вариант «Есть» содержит значение: «А»`. Больше не менять ничего.
2. `bootstrap/flang check <файл>`.
3. Смотреть: диагностики на строках формы `в монаде` и код возврата.

## Что происходит

```
$ bootstrap/flang check docs/examples/monad/order-total.flang   # с переставленными вариантами
FLANG_TYPE_PARAM … строка 143, столбец 5: конструктор «Нет»: параметр типа «А» не определяется
  ни по аргументам, ни по ожидаемому типу
FLANG_TYPE_PARAM … строка 144, столбец 5: вызов «Сплющить»: параметр типа «А» не определяется …
                                                                       код 1
```

Строки 143–144 — это `пусть … равно …` внутри `в монаде «Возможно»`; конструктора
«Нет» на них нет, его подставляет разворот формы. С исходным порядком вариантов
(«Есть» первым) та же форма проходит. Исходный файл при этом кодом 0 всё равно не
отвечает: на `в монаде «Результат»` (монада от двух параметров, строка 195) тот же
`FLANG_TYPE_PARAM` на параметре «Беда» — вторая проба того же разворота.

Версия: `flang 0.7.25`.

## Что должно быть

Код 0 при любом порядке вариантов: `docs/ct/spec.md`, раздел «Свойства,
объявляемые отдельно от конструкции», обещает, что форма разворачивается в вызовы
объявленных `возврат` и `соединение`, а отображение эндофунктора компилятор
выводит «из устройства типа». Устройство типа не зависит от порядка строк в нём.

## Обходной путь

Объявлять вариант с полем первым: так сделано в `flang/ct/monad-maybe-monoid.flang`
и в `docs/examples/monad/order-total.flang`.

## Когда задача сделана

`bootstrap/flang check` на `docs/examples/monad/order-total.flang` с переставленными
вариантами отвечает так же, как на исходном; проба с переставленными вариантами
лежит рядом с пробами формы и краснеет, если порядок снова станет значим.

## Где живёт правка

Разворот формы `в монаде` в разборе (`flang/self/parser.flang`, поиск по
`inMonad`) — там, где из типа берётся вариант с полем; доезжает перепечаткой
семени, до неё — толкованием.
