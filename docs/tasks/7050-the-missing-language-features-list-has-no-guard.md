# 7050. Список «чего не хватает языку» ничем не проверяется: у записей нет программ, которые компилятор обязан отвергнуть

## Шаги воспроизведения

1. `python3 -c "import json; print(len(json.load(open('docs/examples/leetcode/index.json'))['чего не хватает языку']))"`
2. `python3 -c "import json; print(sum(1 for z in json.load(open('docs/examples/leetcode/index.json'))['чего не хватает языку'] if 'улики' in z))"`
3. `grep -rl 'чего не хватает языку' scripts flang/scripts flang/test .github`
4. `grep -c 'script.missing-features:check' .flangrc`

## Что происходит

```
$ python3 -c "import json; print(len(json.load(open('docs/examples/leetcode/index.json'))['чего не хватает языку']))"
16
$ python3 -c "import json; print(sum(1 for z in json.load(open('docs/examples/leetcode/index.json'))['чего не хватает языку'] if 'улики' in z))"
13
$ grep -rl 'чего не хватает языку' scripts flang/scripts flang/test .github
$ grep -c 'script.missing-features:check' .flangrc
0
```

В списке шестнадцать записей с полями «чего» и «пояснение»; у тринадцати есть
ещё «улики». Улики — это ссылки на уже написанные примеры, которые недостачу
ОБХОДЯТ, а не программы, которые компилятор обязан ОТВЕРГНУТЬ: ни у одной
записи такой программы нет. Ни одна проверка дерева этот ключ не читает, и в
самом списке запись «проверка самого этого списка» говорит прямо: «нужна
проверка, которая гоняет каждую запись программой и падает, когда недостачи
больше нет».

Версия: flang 0.7.23, 3 октября 2026.

## Что должно быть

У записи стоит программа на flang, которую компилятор обязан отвергнуть
названным кодом. Пока программа отвергается — недостача есть. Прошла — язык
дорос, и проверка краснеет, требуя снять запись.

Где программы быть не может — там вместо неё выписан довод, и проверка его
видит и считает: запись без программы И без довода краснит проверку. Молчащая
запись — то же, что нынешнее состояние, и именно её надо сделать невозможной.

## Обходной путь

Перечитывать список руками после каждого выпуска.

## Когда задача сделана

- `bootstrap/flang run-script missing-features:check` отвечает кодом 0, когда у каждой из
  шестнадцати записей есть одно из двух: программа, отвергаемая названным
  кодом, либо выписанный довод, почему программы нет. Проверка печатает, у
  скольких записей программа и у скольких довод, — молча довод принимать
  нельзя;
- проверка краснеет в двух случаях: программа прошла; программа отвергнута не
  тем кодом, что записан;
- подделка: в одну из программ дописана недостающая форма так, что она
  проходит, — проверка краснеет и называет запись.

Три записи программой не проверяются, и довод у них уже есть в «пояснении» —
их и надо перевести в ветку довода, а не выдумывать им отказ:

- «обработка ошибок» — перехвата отказа в языке «нет и не будет», отвергать
  нечего;
- «проверка самого этого списка» — недостача и есть эта проверка;
- «flang test не проверяет типы» — это расхождение двух команд на одной
  программе (`check` даёт `FLANG_TYPE`, `test` даёт зелёное), а не отказ
  компилятора; проба здесь — пара прогонов, а не один.

## Где живёт правка

`docs/examples/leetcode/index.json` (поле с путём программы и кодом отказа у
каждой записи), программы рядом в `docs/examples/leetcode/`, новая проверка в
`scripts/guards/`, ярлык `script.missing-features:check` в `.flangrc`.
Перепечатка не нужна.
