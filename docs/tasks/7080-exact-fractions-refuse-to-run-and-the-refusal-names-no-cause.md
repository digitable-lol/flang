# 7080. Запуск точных дробей отвергнут, а причину не называет ни один прогон

## Шаги воспроизведения

1. Программа — сложение денег точной дробью:

```flang
модуль «Money in fractions»
  использует «Rationals»

тотальная функция «Рубль десять»
  возвращает «Дробь»
  «Дробь из целых» от 110 и 100

тотальная функция «Рубль двадцать»
  возвращает «Дробь»
  «Дробь из целых» от 120 и 100

тотальная функция «Счёт записью»
  возвращает строка
  «Дробь записью» от («Сложить дроби» от («Рубль десять») и («Рубль двадцать»))
```

2. Команды:

```
bootstrap/flang run <файл> --function "Счёт записью"
bootstrap/flang check <файл> --proof
bootstrap/flang check <файл> --proof --strict
bootstrap/flang check flang/stdlib/bignum.flang --proof
```

## Что происходит

```
$ bootstrap/flang run <файл> --function "Счёт записью"
не доказано: утверждений 22: доказано 20, сетка 2, на веру 0 — запуск только по
явному согласию: --trust
недоказанное — поимённо, словами отчёта о доказательствах:
  ни одного пункта: утверждения доказаны все, и отказ идёт не от них — смотреть
  «flang check <файл> --proof»                                        код 3
$ bootstrap/flang check <файл> --proof
<файл>: ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — утверждений 0: доказано 0, условно 0, сетка 0,
объявлено, не доказано 0, отвергнуто 0, нарушено 0                    код 0
$ bootstrap/flang check <файл> --proof --strict
<файл>: НЕ УДАЛОСЬ ДОКАЗАТЬ — ПРОВЕРЕНО ВПУСТУЮ, ОБЯЗАТЕЛЬСТВ НЕТ ВОВСЕ —
утверждений 0: доказано 0                                             код 3
$ bootstrap/flang check flang/stdlib/bignum.flang --proof
  постусловие «ширина не меньше каждой длины» функции «Ширина» — сетка 2 значения
  постусловие «меньшее минус большее — ноль» функции «Вычитание» — сетка 3 значения
  утверждений 9: доказано 7 (из них индукцией 4) (из них без теоремы 3), сетка 2  код 0
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

Отказ запуска считает ЗАМЫКАНИЕ: 22 утверждения, из них 2 на сетке. Команда, на
которую он посылает, считает ОДИН ФАЙЛ: утверждений 0 и код 0. Два прогона об
одной программе не сходятся ни числом, ни кодом, и ни один из них не называет те
два постусловия, из-за которых отказ случился. Чтобы их увидеть, нужно заранее
знать, что смотреть надо в `flang/stdlib/bignum.flang`, — то есть знать ответ до
вопроса.

Цена вопроса названа прогоном: `(0.1 плюс 0.2) плюс 0.3` на типе `число` даёт
`0.6000000000000001`, а `0.1 плюс (0.2 плюс 0.3)` — `0.6`; те же три числа
дробью дают `3/5` и `3/5`, и сличение даёт `true`. Точная дробь — единственное
место в дереве, где скобки не меняют ответ, и единственный путь к ней —
`--trust`, то есть «на веру: доказанность не считалась».

## Что должно быть

1. Отказ `run` называет недоказанное поимённо: имя постусловия, имя функции и
   файл, где оно лежит, — для пунктов замыкания так же, как для пунктов файла.
   Строка «ни одного пункта: утверждения доказаны все» при `сетка 2` в том же
   отчёте неверна и печататься не должна.
2. Команда, на которую посылает отказ, отвечает тем же счётом и тем же кодом,
   что и отказ: либо `check --proof` читает замыкание, либо отказ посылает к
   команде, которая его читает.
3. Два постусловия «Bignum» доказаны, и тогда программа выше запускается кодом 0
   без `--trust`.

## Обходной путь

`bootstrap/flang run <файл> --function … --trust` — печатает `3/10` и `3/5`
верно, но отвечает `на веру: доказанность не считалась`, то есть ровно то, чего
программист про деньги знать не хотел. Либо вручную позвать
`check flang/stdlib/bignum.flang --proof` и прочесть два пункта сетки.

## Когда задача сделана

- `bootstrap/flang run <файл> --function "Счёт записью"` без `--trust` отвечает
  кодом 0 и печатает `"23/10"`;
- до того, как постусловия доказаны, тот же отказ называет оба пункта поимённо с
  файлом `flang/stdlib/bignum.flang`, и строки «ни одного пункта» в нём нет;
- `check <файл> --proof` и отказ `run` печатают одно и то же число утверждений;
- проба краснеет, если отказ снова перестанет называть причину.

## Где живёт правка

- `flang/self/io.flang` и `flang/self/cli.flang` — печать вердикта при запуске
  (ADR-0045, задача 8222);
- `flang/self/proof.flang` — счёт утверждений по замыканию против счёта по файлу;
- `flang/stdlib/bignum.flang` — доказательство двух постусловий: «ширина не
  меньше каждой длины» у «Ширина» и «меньшее минус большее — ноль» у «Вычитание».

Правки под `flang/self` доезжают до двоичного только пересборкой семени
(bootstrap regeneration); правка `flang/stdlib` — нет.
