# 7192. Проверка столкновений имён на flang не сходится с проверкой на JavaScript по числу объявлений и не доходит до конца прогона

Столкновения имён считают две проверки: `flang/scripts/link-collision-guard.mjs`
с ключом `--дерево` (ярлык `столкновения:проверка`) и
`scripts/guards/name-collision-guard.fscript` (ярлык `столкновения:пересчёт`).
Вторая должна заменить первую.

## Шаги воспроизведения

1. `node flang/scripts/link-collision-guard.mjs --дерево | head -5`
2. `bootstrap/flang io scripts/guards/name-collision-guard.fscript --на-веру`

## Что происходит

```
$ node flang/scripts/link-collision-guard.mjs --дерево | head -5
── сторож столкновений имён ──
вход: всё дерево: 291 программ с ввозами + вся библиотека одной программой (52 модулей)
замыкание: 1572 файлов, видимых объявлений 143134

── РАЗРЯД 1: в замыканиях настоящих программ — 0 ──                 код 0
```

Версия: flang 0.7.23, 30 сентября 2026 — первая команда, несколько секунд.

Вторая команда не перепроверена. Последний записанный прогон не дошёл до конца
за 50 минут (код 124, пик 6,4 ГиБ). В прогоне, который доходил, проверка на
flang видела 7 873 объявления против 57 516 у первой и отвечала «столкновений
0» там, где первая называла три.

## Что должно быть

На одном дереве обе проверки называют одинаковое число видимых объявлений и
одни и те же столкновения, и проверка на flang доходит до конца за время,
которое годится для ярлыка.

## Обходной путь

Гонять проверку на JavaScript; её нельзя удалять, пока числа не сошлись.

## Когда задача сделана

- найдено и названо место, где проверка на flang теряет объявления;
- два прогона подряд на одном дереве дают одинаковое число файлов,
  объявлений и столкновений обоих разрядов;
- подделка — одно имя объявлено в двух модулях одной программы — даёт код 1 у
  обеих;
- время и пик памяти прогона на flang записаны рядом с ярлыком.

## Где живёт правка

`scripts/guards/name-collision-guard.fscript` (обход замыкания и счёт видимых
объявлений), `ярлыки.flang`. Перепечатка не нужна.
