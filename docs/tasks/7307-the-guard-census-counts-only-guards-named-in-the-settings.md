# 7307. Перепись сторожей считает по настройкам, а не по дереву, и потому не видит 12 сторожей — среди них потолок доверенной базы

## Шаги воспроизведения

1. Прогнать перепись:

```
bootstrap/flang io scripts/guards/who-calls-the-guards.fscript --plan Check
```

2. Сосчитать сторожей по дереву и сверить с настройками:

```
git ls-files | grep -c -a -- '-guard\.fscript$'
for f in $(git ls-files | grep -a -- '-guard\.fscript$'); do grep -q -a -F "$f" .flangrc || echo "$f"; done
```

3. Взять одного из ненайденных — сторожа С-6, потолок доверенной базы — и
   поискать, кто его зовёт:

```
grep -c -a 'tables-guard' .flangrc
grep -rc -a 'tables-guard' .github/workflows .githooks
```

## Что происходит

```
$ bootstrap/flang io scripts/guards/who-calls-the-guards.fscript --plan Check
сторожа без зова: 28, все названы в ведомости — сходится                   код 0
$ git ls-files | grep -c -a -- '-guard\.fscript$'
53
$ for f in … ; done
flang/proof/tables-guard.fscript
flang/scripts/count-guard.fscript
… всего 12 имён …
$ grep -c -a 'tables-guard' .flangrc
0
$ grep -rc -a 'tables-guard' .github/workflows .githooks
0
```

Версия: flang 0.7.23. Дата прогона: 2 октября 2026, ствол `09bc6880`.

Перепись берёт список сторожей из `.flangrc` (строки `script.*`) и сверяет его с
работами `.github/workflows`. Сторож, у которого строки в `.flangrc` нет вовсе,
в список не попадает и «без зова» числиться не может: файлов `*-guard.fscript` в
дереве 53, в `.flangrc` не названы 12. Один из этих 12 —
`flang/proof/tables-guard.fscript`, сторож С-6 «потолок доверенной базы — строк
кода и примитивов сверщика на C» (замер 2 октября: код 0, «checker.c: 8127 строк
кода, до потолка 0 (потолок 8127); примитивов 15 (названо 15)», 112 опор правил).
Его не зовёт ни `.flangrc`, ни работа CI, ни хук; единственное упоминание вне
самого файла — строка подсказки в `flang/scripts/kernel-lines-to-trust.fscript`.
В ведомостях `scripts/ledgers/uncalled-guards.json` (43 имени) и
`scripts/ledgers/checks-nobody-calls.tsv` его тоже нет. Перепись при этом зелена.

## Что должно быть

Перепись считает сторожей по дереву (`git ls-files`), а не по настройкам, и
называет каждого, у кого нет ни строки в `.flangrc`, ни зова в работе CI или
хуке. Сторож С-6 либо зовётся, либо назван в ведомости с причиной.

## Когда задача сделана

- перепись отвечает числом сторожей дерева (53 на день правки) и называет
  `flang/proof/tables-guard.fscript` среди тех, у кого зова нет;
- план `Forgery` того же файла краснеет, если убрать зов у любого зовущегося
  сторожа, и краснеет, если из `.flangrc` убрать строку сторожа, оставшегося в
  дереве;
- `bootstrap/flang run-script guard-calls:check` отвечает кодом 0 на дереве, где
  все расхождения названы в ведомости.

## Обходной путь

Считать сторожей руками: `git ls-files | grep -- '-guard\.fscript$'` и сверять
с `.flangrc`, `.github/workflows` и `.githooks` по одному имени.

## Где живёт правка

`scripts/guards/who-calls-the-guards.fscript` (откуда берётся список) и его
ведомости в `scripts/ledgers/`. Пересборка семени (bootstrap regeneration) не
нужна. Что сторож С-6 стоит у исчерпанного потолка (запас 0 строк) — предмет
задачи 2159, здесь не решается.
