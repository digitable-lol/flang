# 7312. Равенство двух построенных записей доказывается при двух полях и молча не доказывается при трёх и больше

Заявка: https://github.com/digitable-lol/flang/issues/375

Та же цель, записанная конъюнкцией трёх равенств, доказана; записанная равенством записей из трёх полей — «объявлено, не доказано», и отчёт не называет причины.

## Шаги воспроизведения

1. Программа fields.flang:

```flang
модуль «Три поля»

объект «Два»
  «а»: признак
  «б»: признак

объект «Три»
  «а»: признак
  «б»: признак
  «в»: признак

утверждение «три равенства конъюнкцией»
  для всех х1: признак
  для всех ю1: признак
  для всех х2: признак
  для всех ю2: признак
  для всех х3: признак
  для всех ю3: признак
  утверждаем ((х1 и притом ю1) равно (ю1 и притом х1)) и притом ((х2 и притом ю2) равно (ю2 и притом х2)) и притом ((х3 и притом ю3) равно (ю3 и притом х3))

утверждение «два поля записью»
  для всех х1: признак
  для всех ю1: признак
  для всех х2: признак
  для всех ю2: признак
  утверждаем (запись «Два» с а равным (х1 и притом ю1) и б равным (х2 и притом ю2)) равно (запись «Два» с а равным (ю1 и притом х1) и б равным (ю2 и притом х2))

утверждение «три поля записью»
  для всех х1: признак
  для всех ю1: признак
  для всех х2: признак
  для всех ю2: признак
  для всех х3: признак
  для всех ю3: признак
  утверждаем (запись «Три» с а равным (х1 и притом ю1) и б равным (х2 и притом ю2) и в равным (х3 и притом ю3)) равно (запись «Три» с а равным (ю1 и притом х1) и б равным (ю2 и притом х2) и в равным (ю3 и притом х3))
```

2. `bootstrap/flang check fields.flang --proof`.

## Что происходит

```
$ bootstrap/flang check fields.flang --proof
  утверждение «три равенства конъюнкцией» — доказано сведением цели с телом функции: правило «разбор цели по условию», объявленные типы аргументов не понадобились — утверждение обо ВСЕХ входах, а не о написанных; теоремы при нём нет и не ну …
  утверждение «два поля записью» — доказано сведением цели с телом функции: правило «разбор цели по условию», объявленные типы аргументов не понадобились — утверждение обо ВСЕХ входах, а не о написанных; теоремы при нём нет и не нужно
  утверждение «три поля записью» — объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
fields.flang: НЕ ПРОВЕРЕНО — утверждений 3: доказано 2, условно 0, сетка 0, объявлено, не доказано 1, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 3
код 3
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Равенство построенных записей одного типа сводится к равенствам полей при любом числе полей. Если предел у ядра есть, отчёт называет его, как называет «предел переписки».

## Обходной путь

Сравнивать поля по одному конъюнкцией вместо равенства записей.

## Когда задача сделана

`bootstrap/flang check fields.flang --proof` — «доказано 3», код 0; та же проба на 2…6 полях — доказано на каждом.

## Где живёт правка

`flang/self/proof-kernel.flang` — сведение равенства конструкторов записи. Ждёт печати семени.
