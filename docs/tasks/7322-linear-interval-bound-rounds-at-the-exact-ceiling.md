# 7322. Граница отрезка линейной арифметики округляется у потолка

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/linear-bound-rounds-at-the-ceiling.flang`:

```flang
модуль «Строгий порядок у потолка»

тотальная функция «Плюс два»
  принимает а: неотрицательное
  возвращает число
  обеспечивает «плюс два больше плюс одного» результат больше (а плюс 1)
  а плюс 2
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/linear-bound-rounds-at-the-ceiling.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/linear-bound-rounds-at-the-ceiling.flang --function 'Плюс два' --args '{"а":9007199254740991}'`

## Что происходит

```
$ bootstrap/flang check … --proof
… доказано 1
$ bootstrap/flang run … --function 'Плюс два' --args '{"а":9007199254740991}'
FLANG_PROPERTY: нарушено свойство «плюс два больше плюс одного» функции «Плюс два»      код 1
```

Версия: flang 0.7.34.

При `а = 2⁵³−1` и `а плюс 1`, и `а плюс 2` равны 2⁵³. «Отрезок двоичного линейно» считает верх отрезка `а плюс 2`
в двойной точности: `9007199254740991 плюс 2` округляется до 2⁵³ и проходит «не больше края» — сторона числится
точной. Так же доказывается `((а плюс 2) плюс 1) равен (а плюс 3)`. Сверщик на C считал отрезок так же и принимал
запись кодом 0; второй сверщик считает в целых и отвергает.

## Что должно быть

Граница, посчитанная с округлением, точной не числится: сторона, чей отрезок выходит за 2⁵³, строгим порядком и
равенством не берётся.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check … --proof` не числит утверждение доказанным; строка `proof` этой программы в
`flang/proof/probes/typing-holes/expected.tsv` меняется, строка ведомости `flang/proof/tables/typing-holes.tsv` — на
`закрыта`.

## Где живёт правка

`flang/self/proof-kernel.flang`, «Отрезок двоичного линейно» и «Отрезок произведения линейно»: правка сделана в этой
же ветке («Верхняя граница суммы линейно», «Нижняя граница суммы линейно», «Граница произведения линейно») и ждёт
печати семени (партия 12). Сверщик на C (`ла_отрезок`, `ло_сумма`) исправлен и отвечает «НЕ СОШЛОСЬ» уже сейчас;
подделка — `flang/proof/checker/tests/families/linear-arithmetic/sum-bound-rounds-at-the-ceiling.record`.
