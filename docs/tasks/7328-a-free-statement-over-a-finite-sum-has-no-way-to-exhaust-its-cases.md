# 7328. Свободное утверждение над конечной объявленной суммой не закрывается ничем: перебор вариантов делается только постусловию

Тип из трёх вариантов — конечное множество, и свойство о каждом его значении
проверяется перебором трёх случаев. Ядро это умеет: ПОСТУСЛОВИЮ той же функции
оно так и отвечает — «доказано индукцией по «Цвет»: база 3 случая». Тому же
свойству, записанному свободным утверждением, оно отвечает «объявлено, не
доказано», и закрыть его автор не может ни одним словом доказательства:
`по предположению` в базе отказано, `по примеру` свободному утверждению
отказано поимённо, а индукции без ни одного `случай` отказывает разбор.

Версия: flang 0.7.24, дерево `5604556ef`. Дата прогона: 4 октября 2026.

## Шаги воспроизведения

1. Программа (`проба.flang`):

```flang
модуль «Проба»

тип «Цвет»
  вариант «Красный»
  вариант «Жёлтый»
  вариант «Зелёный»

тотальная функция «Номер»
  принимает ц: «Цвет»
  возвращает число
  разбор ц
    случай вариант «Красный»
      то 1
    случай вариант «Жёлтый»
      то 2
    случай вариант «Зелёный»
      то 3

утверждение «номер цвета не больше трёх»
  для всех ц: «Цвет»
  утверждаем («Номер» от ц) не больше 3
```

2. `bootstrap/flang check проба.flang --proof --строго; echo $?`
3. Дописать теорему и закрыть базы `по предположению` — тот же вопрос.
4. Дописать функции примеры на каждый вариант и закрыть базы
   `по примеру «красный»` и так далее — тот же вопрос.
5. Отрицательный контроль: то же свойство записать ПОСТУСЛОВИЕМ функции
   (`обеспечивает «номер не больше трёх» результат не больше 3`) — и сверить.

## Что происходит

| как записано свойство | как закрыто | код | ответ |
| --- | --- | ---: | --- |
| свободным утверждением | ничем | 3 | `объявлено, не доказано: ни теоремы, ни примеров` |
| свободным утверждением | теорема, базы `по предположению` | 1 | `FLANG_PROOF_INDUCTION_STEP … «по предположению» стоит в базе «Красный», где предположения индукции нет` |
| свободным утверждением | теорема, базы `по примеру` | 1 | `FLANG_PROOF_STEP … «по примеру» ссылается на пример функции, а свободное утверждение функции не принадлежит: пример здесь брать не у кого` |
| свободным утверждением | теорема, `индукция по ц` без случаев | 1 | `FLANG_PARSE … у индукции теоремы нет ни одного 'случай'` |
| **постусловием той же функции** | ничем, ядром | **0** | `доказано индукцией по «Цвет»: база 3 случая … правило «ограниченность точным потолком по построению»` |

Последняя строка — та, из-за которой задача существует. Перебор конечной суммы
в ядре ЕСТЬ и работает; он просто не зовётся, когда цель пришла не от функции.
Отказ второй строки сам называет три законных пути закрытия базы — «вычислением
(«по примеру»), предусловием «требует» или сводится самим ядром», — и для
свободного утверждения недоступен ни один: примера взять не у кого,
предусловий у него не бывает, а ядро к нему не приходит.

## Что должно быть

1. Свободное утверждение `для всех ц: «Т»` над объявленной суммой БЕЗ полей
   типа самой суммы закрывается ядром перебором вариантов, и ведомость называет
   правило по имени — ровно как сегодня называет его постусловию.
2. Ложное свойство над той же суммой (`не больше 2`) остаётся «объявлено, не
   доказано» и даёт код 3. Без этого пункта приёмка не отличит перебор от
   молчания.
3. Отказ там, где перебор невозможен (сумма с полем своего же типа, то есть
   настоящая индукция), по-прежнему честный и называет причину.
4. Записи переиграны независимой проверяющей программой, и в наборе подделок
   есть новая: перебор, у которого один вариант подменён.

## Обходной путь

Переписать свойство постусловием функции — тогда оно доказывается. Цена: о
свойстве нельзя говорить вне функции, и сослаться на него из другого модуля как
на свободное утверждение нечем.

## Когда задача сделана

1. Программа из шагов воспроизведения даёт «доказано 1», код 0 у
   `check --proof --строго`.
2. Та же программа с `не больше 2` даёт «объявлено, не доказано», код 3.
3. `bootstrap/flang io flang/proof/checker/tests/run.fscript` — код 0: честные
   записи приняты, подделки отвергнуты.
4. `bootstrap/flang io flang/proof/tables-guard.fscript` — код 0.

## Чего мы не смогли оценить

- **Надо ли свободному утверждению давать `по примеру`.** Сегодня отказ говорит
  «пример здесь брать не у кого», и это верно про САМО утверждение, но у
  функции, которую утверждение зовёт, примеры есть. Решение не принято, и от
  него зависит, нужен ли новый вид шага вовсе.
- **Сколько строк в ядре.** Перебор базы уже написан для постусловия; сколько из
  него переиспользуется, из анкеров не видно.
