# 7360. Длинные справки и шаблоны собираются из кусков `"…\n"`, а не блоками текста

[ADR-0052](../adr/0052-a-text-block-literal-strips-its-common-indentation.md) вводит
блок текста `"""` — литерал, у которого снимается общий отступ. Двоичный блок
читает (`bootstrap/flang check` над функцией, возвращающей блок, — «замечаний
нет»), но тексты дерева, ради которых литерал заведён, по-прежнему собраны из
списков строк.

## Что переписать

Списки из пяти и более подряд идущих строк вида `"…\n",` и число строк в них:

| файл | списков | строк |
|---|---:|---:|
| `flang/self/cli.flang` — справки команд (`«Справка проверки»`, `«Справка прогона»`, … `«Справка замка»`) | 13 | 207 |
| `flang/self/emit-rust.flang` — шаблоны печатаемого кода | 10 | 66 |
| `scripts/editors/vscode-rules.flang` — грамматика редактора, печатаемая в дерево | 2 | 61 |
| `scripts/editors/vim-rules.flang` — то же для Vim | 3 | 45 |
| `flang/self/repl/repl.flang` — `«Справка оболочки»` | 1 | 26 |
| `flang/test/jargon-guard.test.flang` | 1 | 12 |
| `flang/scripts/kernel-lines-to-trust.fscript` | 1 | 7 |
| `scripts/targets/region-in-c-target.fscript`, `flang/self/mcp.flang`, `flang/self/emit-js.flang`, `flang/concurrency/bench/gen.flang` | по 1 | по 5 |

Первой идёт `«Справка оболочки»`: значение её блока должно побайтово совпасть со
склейкой 27 кусков (1369 знаков). Шаблоны `emit-rust.flang` и грамматики
редакторов переписываются осторожнее: в них значим каждый пробел в конце строки,
а блок пробелы в конце строк хранит, но глазом их не видно.

## Порядок

1. Убедиться, что `scripts/guards/seed-parses-sources-guard.fscript` зелен.
2. Переписать функцию и посмотреть, что покраснеет: у справок есть примеры, у
   оболочки — сверка с двоичным в `flang/test`.
3. Сверять значение, а не вид: `bootstrap/flang run … --function «Справка …»` до и
   после, `cmp` двух выводов.

## Когда задача сделана

В файлах таблицы не осталось списков из пяти и более кусков `"…\n"`, а вывод
каждой переписанной функции побайтово равен прежнему.

## Что не входит

Подсветка блока на сайте (`docs/site/highlighting.mjs` ищет конец строки по одной
кавычке) и в строке ввода оболочки (`flang/src/emit/c/flang_repl.c`, раскраска по
одной строке) — отдельные правки, и первая упирается в запрет роста файлов `.mjs`.
