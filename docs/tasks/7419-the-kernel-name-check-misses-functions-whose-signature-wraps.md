# 7419. Сверка имён ядра не видит функций, чья подпись перенесена на вторую строку

## Шаги воспроизведения

1. На семени партии 9a (коммит c45d0faf2) или на семени 0.7.29 из dev:
   `sh scripts/bootstrap-reprint.sh --imena`.
2. То же с `--bystro --strogo`.

## Что происходит

Обе проверки отвечают «ЯДРО ИСХОДНИКОВ УШЛО ВПЕРЁД ЯДРА В СЕМЕНИ: имён 86 из
1610», код 1. Среди названных — «Вердикт без теоремы», а в
`bootstrap/compiler_flang.c` эта функция есть:

```
 * Функция flang «Вердикт без теоремы».
 ...
fl_status
compiler_flang_verdikt_bez_teoremy(fl_ctx *ctx, fl_value obyazatelstvo,
```

Печать переносит длинную подпись: тип результата стоит на своей строке, имя
функции — на следующей. `imena_semeni` в `scripts/bootstrap-reprint.sh` ищет
тип и имя на одной строке (`^(static )?тип \**compiler_flang_…\(`), поэтому
такие функции для неё не напечатаны. В семени 9a подписей с переносом 1360, в
семени 0.7.29 — 1328; 86 из них — функции ядра решений.

## Что должно быть

Сверка находит имя функции и тогда, когда тип результата стоит строкой выше.
На семени 9a и на семени 0.7.29 `--imena` отвечает «сошлось», код 0, а на семени
с действительно выброшенной функцией ядра по-прежнему краснеет (отрицательный
контроль: вырезать из копии `compiler_flang.c` одну функцию ядра).

## Когда задача сделана

1. `--imena` и `--bystro --strogo` зелёные на семени 9a и на семени 0.7.29.
2. Отрицательный контроль из раздела выше краснеет и называет вырезанное имя.

## Где живёт правка

`scripts/bootstrap-reprint.sh`, функция `imena_semeni`; семя не трогается.
