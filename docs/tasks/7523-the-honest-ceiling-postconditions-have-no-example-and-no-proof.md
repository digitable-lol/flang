# 7523. Четыре постусловия вне подделок не закрыты ни примером, ни доказательством

## Шаги воспроизведения

```
bootstrap/flang run-script traceability:check
grep -n 'обеспечивает «неотрицательно»' flang/test/fixtures/granica-nad-chislom-chestnaya.flang
grep -n 'вердикт' flang/proof/checker/tests/records/corpus/granica-nad-chislom-chestnaya.record
FLANG_TRACE='неотрицательно' bootstrap/flang run-script traceability:requirement
```

## Что происходит

```
  рода «требование → проверка»: в подделках 58 (...), вне подделок 4
  вне подделок — требования без примера и без доказательства:
      flang/test/fixtures/granica-nad-chislom-chestnaya.flang:6 функция «Четверть ната» — «неотрицательно»
      flang/test/fixtures/granica-nad-chislom-chestnaya.flang:18 функция «Только положительное» — «неотрицательно»
      flang/test/fixtures/granica-nad-chislom-chestnaya.flang:25 функция «Четверть неотрицательного» — «неотрицательно»
      flang/proof/map/sources.flang:15 функция «Без примеров» — «К2 объявлено, не доказано (примеров нет)»
```

Версия: flang 0.7.23.

Из 62 разрывов «требование → проверка» 58 приходятся на подделки, где
недоказанность и есть требуемый итог. Честных остаётся четыре, и они разной
природы:

- три в `flang/test/fixtures/granica-nad-chislom-chestnaya.flang` — файл проба
  ядра обязывает ПРОЙТИ (`flang/scripts/kernel-forgeries.fscript`, «Подделка
  прохода границ»), а три его постусловия «неотрицательно» в записи
  `granica-nad-chislom-chestnaya.record` стоят с вердиктом «нет вердикта»:
  граница над числом стала обязательством (ADR-0025), и обязательство это не
  закрыто. Проба ядра смотрит файл целиком и такого не видит;
- одно в `flang/proof/map/sources.flang` — показательное: функция так и
  названа, «Без примеров», и постусловие её говорит «К2 объявлено, не доказано
  (примеров нет)». Закрывать его доказательством нельзя: оно показывает
  читателю карты, как выглядит незакрытое требование.

## Что должно быть

1. Три постусловия «неотрицательно» закрыты — примером либо доказательством; у
   честного файла, который проба ядра гонит как проходящий, недоказанных
   обязательств не остаётся.
2. Показательное место в карте доказательств объявлено показательным там, где
   прибор это видит, а не только в прозе: либо у него появляется пример, либо
   оно выносится из счёта отдельной строкой ведомости с доводом.
3. Строка `требование → проверка вне подделок` в
   `scripts/ledgers/traceability-debt.tsv` опускается с 4 до 0.

## Обходной путь

Нет. Числа видны только прогоном `traceability:check`; поиск по тексту их не
даёт.

## Когда задача сделана

1. `bootstrap/flang run-script traceability:check` печатает «вне подделок 0» и
   выходит кодом 0.
2. Правка исходника и правка его записи сделаны одним заходом:
   `bootstrap/flang run-script record-source:check` остаётся кодом 0 (ADR-0030,
   задача 1000).

## Где живёт правка

- `flang/test/fixtures/granica-nad-chislom-chestnaya.flang` и его запись в
  `flang/proof/checker/tests/records/corpus/`;
- `flang/proof/map/sources.flang`;
- `scripts/ledgers/traceability-debt.tsv`.
