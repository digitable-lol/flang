# 7660. У восьми страниц карты сайта английской редакции нет

Проверка английской пары (`docs/site/build.mjs`) охватывает всю карту сайта:
пара обязана у каждой страницы, а снять требование может только объявленное поле
`безПары` с доводом. Восемь страниц стоят именно таким объявлением: английского
текста у них нет вовсе.

## Шаги воспроизведения

1. Команда:

   ```
   node docs/site/build.mjs --check
   ```

2. Смотреть строку «Английская пара» в выводе.

## Что происходит

```
$ node docs/site/build.mjs --check
…
Английская пара: страниц карты 57, сверено на пару 46, объявлено без пары 11 — из них печатаются 3, долг перевода 8; пар не хватает 0.
…                                                                      код 0
```

Долг перевода — 8 (строки — `wc -l` по восьми путям, 11 октября 2026):

| страница | строк |
|---|---|
| `docs/flang/self/SPEC.md` | 188 |
| `docs/glossary.md` | 219 |
| `docs/surfaces.md` | 228 |
| `docs/flang/proof/SPEC.md` | 1309 |
| `docs/ct/spec.md` | 1751 |
| `docs/flang/SPEC.md` | 2011 |
| `docs/flang/concurrency/SPEC.md` | 2757 |
| `CHANGELOG.md` | 3331 |
| **всего** | **11 794** |

Версия: flang 0.7.25, дерево 1149c78f7.

## Что должно быть

У страницы карты либо есть английская половина, либо довод, почему её не будет
никогда. «Ещё не написана» — не такой довод: это долг, и он назван числом в
выводе проверки, чтобы не зарастал молча.

`CHANGELOG.md` стоит в этом перечне особняком: это журнал коммитов, и у него
довод может оказаться постоянным, а не долговым. Решать это — частью работы.

## Обходной путь

Сайт показывает эти страницы только по-русски; английский читатель упирается в
русский текст.

## Когда задача сделана

```
node docs/site/build.mjs --check                                        код 0
```

и в его строке «Английская пара» долг перевода равен 0: у каждой из восьми
страниц либо появилась английская половина рядом с русской, либо вместо
долгового объявления стоит постоянный довод. Проба: снять любую появившуюся
английскую половину — проверка обязана покраснеть и назвать путь.

## Где живёт правка

Английские редакции — рядом с русскими, в тех же каталогах, по укладу
руководства (`docs/guide/limits.ru.md` русский, `docs/guide/limits.md`
английский): русский текст переезжает в имя с `.ru`, английский встаёт на старое
имя, и строка `из` в `docs/site/sitemap.mjs` меняется вместе с снятием
объявления `безПары`. Двоичного правка не касается, перепечатка семени
не нужна.

## Следующий шаг

Начать с самой короткой страницы — `docs/flang/self/SPEC.md` (188 строк): русский текст
в `SPEC.ru.md`, английский на старое имя, строка `из` у `spec-self.html` в
`docs/site/sitemap.mjs` (строка 307) без `безПары`; для `CHANGELOG.md` — решение
владельца о постоянном доводе. Проба, которая различает работу сегодня:
`node docs/site/build.mjs --check` печатает «долг перевода 8».
