# 7665. Ядро не доказывает включение списков: ни «для всех м из а: а содержит м», ни «старые элементы остаются после приписать»

Заявка: https://github.com/digitable-lol/flang/issues/378

Правило «вхождение по построению» закрывает только новый элемент `приписать`/`добавить`. Включение `для всех м из а: б содержит м` не доказывается даже при `б` = `а`; после `отфильтровать` не доказывается и вхождение прошедшего отбор элемента.

## Шаги воспроизведения

1. Программа inclusion.flang:

```flang
модуль «Вхождение»

тотальная функция «Копия»
  принимает а: список неотрицательное
  возвращает список неотрицательное
  обеспечивает «все входят» для всех м из а: результат содержит м
  пример «два»
    дано а равно [1, 2]
    ожидается [1, 2]
  разбор а
    случай пусто
      то []
    случай голова и хвост
      то приписать голова к («Копия» от хвост)

тотальная функция «Приписать один»
  принимает а: список неотрицательное, н: неотрицательное
  возвращает список неотрицательное
  обеспечивает «новый входит» результат содержит н
  обеспечивает «старые входят» для всех м из а: результат содержит м
  пример «один»
    дано а равно [1]
    дано н равно 2
    ожидается [2, 1]
  приписать н к а

тотальная функция «Добавить один»
  принимает а: список неотрицательное, н: неотрицательное
  возвращает список неотрицательное
  обеспечивает «новый входит» результат содержит н
  обеспечивает «старые входят» для всех м из а: результат содержит м
  пример «один»
    дано а равно [1]
    дано н равно 2
    ожидается [1, 2]
  добавить н к а

тотальная функция «Себя»
  принимает а: список неотрицательное
  возвращает список неотрицательное
  обеспечивает «все входят» для всех м из а: результат содержит м
  пример «два»
    дано а равно [1, 2]
    ожидается [1, 2]
  а
```

2. `bootstrap/flang check inclusion.flang --proof`.

## Что должно быть

Правила включения с перепроверкой сверщиком: рефлексивность; `приписать х к а` и `добавить х к а` содержат все элементы `а`; транзитивность для шагов теоремы; индукция по `разбор а` для постусловия `для всех м из а: результат содержит м`; элемент, проходящий отбор, остаётся в `отфильтровать`.

## Обходной путь

Нет.

`bootstrap/flang check inclusion.flang --proof` — «доказано 6», код 0; сверщик — код 0. Подделка: `для всех м из а: результат содержит м` при теле `[]` не доказывается.

## Где живёт правка

`flang/self/proof-kernel.flang`, `flang/self/proof-record.flang`, `flang/proof/checker/checker.c`. Ждёт печати семени.

## Чем закрыта

Ветка `a/kernel-proves-lists-and-chains`, коммит `feat(kernel): a list precondition reaches the head and the tail`, ADR-0175. Правила Вкл1 (список включает себя)
и Вкл2 (прибавка элемента прежних не вынимает) в ядре, печати и обоих сверщиках; печать
`В2` теперь знает и `приписать`. `inclusion.flang`: доказано 5 из 6, сверщик проиграл 5 из 5
(семья `list-inclusion`, три подделки → 1); подделки `inclusion-forgery.flang` не доказываются.
Ждёт печати семени.
