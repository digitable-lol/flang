# 7669. Проба проводника не проверяет его на awk, который не умеет многобайтные знаки

## Шаги воспроизведения

1. Собрать двоичный: `make -C bootstrap -j4 CFLAGS='-std=c99 -O2' flang`.
2. Прогнать пробу проводника как её зовёт CI:

   ```sh
   bootstrap/flang io scripts/tutor-probe.fscript --plan Check --timeout 120000 -- "$PWD/bootstrap/flang"
   ```

3. Посмотреть, есть ли среди её проверок хоть одна, которая зовёт проводника с `FLANG_AWK=mawk`
   или с `awk`, подменённым на mawk в `PATH`.

## Что происходит

```
$ bootstrap/flang io scripts/tutor-probe.fscript --plan Check --timeout 120000 -- …
проба проводника зелена                          код 0
```

Проверок восемь (`«Begin with» от 8` в `scripts/tutor-probe.fscript`), и ни одна не задаёт ни
локаль, ни awk: проба идёт в той среде, что ей досталась. Беда, из-за которой урок приходил
мусором (mawk режет закрывающую «»» по байту, и вместо текста печатается
`towc: multibyte conversion failure`), воспроизводится одной переменной среды — и зелёная проба
её не видит.

Версия: `flang 0.7.23`.

## Что должно быть

Девятая проверка: проводник зовётся дважды — с `FLANG_AWK=mawk` и с `PATH`, где `awk` подменён
на mawk, — и оба раза вывод остаётся целым UTF-8. При `FLANG_AWK=mawk` краска снята и сказано
об этом словом; при подмене в `PATH` краска на месте, потому что выбран другой awk.

## Обходной путь

Проверять руками: `FLANG_AWK=mawk flangtutor` и сверять вывод через `iconv -f UTF-8 -t UTF-8`.
Обход работает, но его никто не зовёт, а значит беда вернётся молча.

## Когда задача сделана

Проба краснеет, если убрать из `flang/bin/flangtutor` выбор пары «локаль + awk» (отрицательный
контроль обязателен), и зеленеет на нынешнем дереве.

## Где живёт правка

`scripts/tutor-probe.fscript` — новая проверка в череде стадий; перепечатки не требует.
