# 7683. Литерал точного целого и точного дробного пишется только разрядами по основанию 2²², десятичной записи нет

## Шаги воспроизведения

1. Программа:

```flang
модуль «Десятичный литерал»

тотальная функция «Два в пятьдесят третьей плюс один»
  возвращает точное целое
  9007199254740993
```

2. Команда: `bootstrap/flang check <файл>`.
3. Смотреть код возврата и замечание.

## Что происходит

```
$ bootstrap/flang check <файл>
FLANG_TYPE … строка 5: точное целое и число не смешиваются, нужен названный перевод
                                                                 код 1
```

Версия: `flang 0.7.26`. Единственная запись литерала — список разрядов младшим
вперёд по основанию 4 194 304: `[1, 0, 512]` (ADR-0036 §11, `docs/flang/SPEC.md`
«Точное целое»); у дроби — пара таких списков `[[3793356, 466], [1]]`
(ADR-0062). Голый десятичный литерал читается типом `число` и в точное целое не
втекает. ADR-0062 §7 называет десятичную запись «отдельным разговором о
синтаксисе»; разговора до сих пор не было — это та задача.

## Что должно быть

Решение по синтаксису (ADR): либо десятичный литерал в позиции типа `точное
целое` переводится в разряды компилятором при разборе (без округления через
`число`), либо вводится помеченная запись вроде `точно 9007199254740993`. Печать
`к строке` точного значения тогда тоже даёт десятичную строку. Пока решения нет,
обходной путь — разряды руками.

## Обходной путь

Писать разряды руками: `[1, 0, 512]`; считать их внешним калькулятором либо
`flang/stdlib/bignum.flang`.

## Когда задача сделана

Программа из шагов воспроизведения проверяется кодом 0, `bootstrap/flang run
<файл> --function «Два в пятьдесят третьей плюс один»` печатает значение, равное
`[1, 0, 512]`; строка в `flang/proof/probes/exact-integer/expected.tsv` держит
это; `docs/flang/SPEC.md` описывает запись.

## Где живёт правка

`flang/self/lexer.flang`, `flang/self/parser.flang`, `flang/self/types.flang`
(«Точный счёт»), печать литерала в десяти целях (`flang/self/emit-*.flang`),
`docs/flang/SPEC.md`, `docs/DESCRIPTION.md`. Доезжает до двоичного только
перепечаткой семени.
