# 7685. Цена перепечатки не разложена по стадиям, и горячая стадия не названа прибором

## Шаги воспроизведения

1. Взять журнал дошедшей печати с отметками хода (gpu, `/home/u/b-print-b9a-print.log`,
   19 октября 2026) и её ведомость `FLANG_TICKS_OUT` (`/home/u/b-print-b9a-ticks.tsv`).
2. Спросить дерево, чем разложить журнал по стадиям:

```
ls scripts/seed/ | grep -i stage
grep -n 'По стадиям' docs/reprint-cost.md
```

3. Посмотреть, что умеет `scripts/seed/print-progress.fscript`: он отвечает про
   ОДНУ текущую стадию против вшитого образца, а не про все стадии журнала.

## Что происходит

```
$ ls scripts/seed/ | grep -i stage
                                                   пусто
$ grep -n 'По стадиям' docs/reprint-cost.md
                                                   пусто
```

Ведомость `docs/reprint-ledger.tsv` даёт одно число на заход (5,3–7,8 ч по
строкам 2026-10-08…2026-10-18), раздел «Куда уходят шаги» в
`docs/reprint-cost.md` — доли заряда по функциям на всю печать. Ни то, ни
другое не говорит, какая стадия печати сколько длится и сколько памяти держит;
`docs/road-to-1-0.md` называет это словами: «Чего нет. Разбора, на какие стадии
печати уходит время, по каждой стадии».

Версия: flang 0.7.30, дерево ce6a2cb42.

## Что должно быть

Прибор, который по журналу печати (отметки `шагов … идёт «…», … ГиБ`, раз в
30 с, `flang_repl.c`) и, если дана, по ведомости `FLANG_TICKS_OUT` печатает
таблицу: стадия, отсчётов, секунд, доля, шаги на последнем отсчёте стадии,
пик памяти; и раздел «По стадиям» в `docs/reprint-cost.md` с таблицами двух-трёх
печатей, снятыми этим прибором, с датой и именем журнала у каждой.

## Обходной путь

Считать руками: `grep -c 'идёт «Проверить доказательства»' <журнал>` и
умножать на 30.

## Когда задача сделана

1. `bootstrap/flang io scripts/seed/print-stages.fscript --plan Check -- <журнал> [<тики>]`
   отвечает кодом 0 и таблицей по стадиям; на журнале без отметок — кодом 3 и
   `FLANG_PRINT_STAGES_NO_MARKS`, не пустой таблицей.
2. `bootstrap/flang check scripts/seed/print-stages.fscript` — «замечаний нет»,
   все функции с доказанным завершением; примеры прибора зелёные.
3. В `docs/reprint-cost.md` есть раздел «По стадиям» с таблицами не менее двух
   печатей, у каждой — дата и журнал; горячая стадия названа числом.

## Где живёт правка

`scripts/seed/print-stages.fscript`, `docs/reprint-cost.md`, `docs/road-to-1-0.md`.
Перепечатка не нужна: прибор исполняется семенем как план `io`.
