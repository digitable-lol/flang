# 7715. Релизный архив не повторим между машинами: версия gzip не закреплена, и тот же вход даёт другой sha256

## Шаги воспроизведения

1. `grep -n 'gzip' .github/actions/release-archive/action.yml`
2. Собрать архив той же командой на раннере GitHub и на машине разработки из
   одного дерева, сравнить sha256.

## Что происходит

```
$ grep -n 'gzip' .github/actions/release-archive/action.yml
35:#       --mtime=@0 --mode=u=rwX,go=rX -C output/release-c -cf - $files | gzip -9n
121:          | gzip -9n > "$arhiv"
132:        # Чем сжимали — называется вслух: `gzip -9n` у GNU и у Apple это РАЗНЫЕ
134:        gzip --version 2>&1 | head -1
```

Версия gzip печатается, но не закрепляется. Записанный прогон на выпуске
0.7.21, одно дерево и один список файлов:

```
раннер GitHub:                        sha256 a52de64106510fe0d91dd2d7d569ac33caf427f6290c98fd973c82630c019eb2
машина разработки, tar 1.35, gzip 1.14: sha256 4085bd7fe418adf8de404937c5628df3a3923a3489e9f61f970fdb5aba05c83d
```

На одной машине два прогона подряд дают один хеш, несжатый поток tar тоже
совпадает сам с собой.

Версия: не перепроверено (расхождение двух сред); `grep` снят на flang 0.7.23, 30 сентября 2026.

## Что должно быть

Архив, собранный из одного дерева в двух средах, совпадает побайтово. Тогда
`scripts/guards/homebrew-formula-guard.fscript` может подтвердить sha256 формулы
архивом, собранным на месте.

## Обходной путь

Брать sha256 из вывода работы выпуска на раннере. Проверку формулы не
ослаблять: число, которое нечем подтвердить, она отвергает правильно.

## Когда задача сделана

1. Сличён несжатый поток tar у себя и на раннере: совпал — виновато только
   сжатие.
2. Выбран и записан способ: закрепить версию gzip в работе выпуска, сжимать
   своим кодом, либо выпускать архив без сжатия (тогда замерить рост размера).
3. Есть проба: два архива из двух сред совпадают побайтово, и проба краснеет
   на подложенном расхождении.

## Где живёт правка

`.github/actions/release-archive/action.yml`, шаг сборки архива (строка с
`gzip -9n`); новая проба рядом с проверками выпуска в `scripts/release/`.
Перепечатка не нужна.
