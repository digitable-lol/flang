# 7718. Рекурсия через частичное применение не проходит проверку завершения, даже когда в замыкании лежит хвост списка

Заявка: https://github.com/digitable-lol/flang/issues/399

`«Затем» от … и (функция «Прибавить остальные» с остальные равным хвост)` замыкает цикл «Затем» → «Прибавить каждое» → «Прибавить остальные». Связанный довод — хвост параметра, но проверка завершения его не смотрит.

## Шаги воспроизведения

1. Программа closure.flang:

```flang
модуль «Рекурсия через частичное применение»

тип «Итог» от «А»
  вариант «Готово» содержит значение: «А», счёт: число
  вариант «Сбой» содержит причина: строка

тотальная функция «Затем» от «А» и «Б»
  принимает итог: «Итог» от «А», продолжение: функция из «А» и число в «Итог» от «Б»
  возвращает «Итог» от «Б»
  разбор итог
    случай вариант «Готово» с значение как значение и счёт как счёт
      то продолжение от значение и счёт
    случай вариант «Сбой» с причина как причина
      то вариант «Сбой» с причина равным причина

тотальная функция «Прибавить»
  принимает добавка: неотрицательное, счёт: число
  возвращает «Итог» от неотрицательное
  пример «два и три»
    дано добавка равно 2
    дано счёт равно 3
    ожидается вариант «Готово» с значение равным 2 и счёт равным 5
  вариант «Готово» с значение равным добавка и счёт равным (счёт плюс добавка)

тотальная функция «Прибавить каждое»
  принимает добавки: список неотрицательное, счёт: число
  возвращает «Итог» от неотрицательное
  пример «три»
    дано добавки равно [1, 2]
    дано счёт равно 0
    ожидается вариант «Готово» с значение равным 0 и счёт равным 3
  разбор добавки
    случай пусто
      то вариант «Готово» с значение равным 0 и счёт равным счёт
    случай голова и хвост
      то «Затем» от («Прибавить» от голова и счёт) и (функция «Прибавить остальные» с остальные равным хвост)

тотальная функция «Прибавить остальные»
  принимает остальные: список неотрицательное, значение: неотрицательное, счёт: число
  возвращает «Итог» от неотрицательное
  «Прибавить каждое» от остальные и счёт
```

2. `bootstrap/flang check closure.flang`.

## Что происходит

```
$ bootstrap/flang check closure.flang
closure.flang: не проверено — замечаний 1
FLANG_NOT_TOTAL в файле closure.flang, строка 12, столбец 10: тотальная функция «Затем» применяет функцию-значение «Прибавить остальные», и это замыкает цикл «Затем» → «Прибавить каждое» → «Прибавить остальные». Применение функции-значения не показывает, какие аргументы получит «Прибавить остальные» …
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Ребро цикла через частичное применение, связанный довод которого — часть параметра вызывающей функции, считается убывающим, как прямой вызов от этой части.

## Обходной путь

Обобщённая функция с прямой рекурсией по хвосту и шагом-значением.

## Когда задача сделана

`bootstrap/flang check closure.flang` — код 0, «Прибавить каждое» с доказанным завершением. Подделка `с остальные равным добавки` — `FLANG_NOT_TOTAL`.

## Где живёт правка

`flang/self/totality.flang`, `flang/self/defunc.flang`. Ждёт печати семени.
