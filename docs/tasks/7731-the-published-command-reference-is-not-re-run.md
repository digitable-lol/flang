# 7731. Справочник команд сверяют с двоичным рукой, и показанные в нём выводы расходятся с настоящими

`docs/site/cli.md` и `docs/site/cli.ru.md` описывают все команды двоичного:
вызов, ключи, вывод, код возврата. Шапка обещает, что каждый показанный вывод
прогнан на двоичном.

## Шаги воспроизведения

1. `grep -c '^\$ flang' docs/site/cli.ru.md`
2. `grep -n -A2 'plan Целость --trust' docs/site/cli.ru.md`
3. `bootstrap/flang io ярлыки.flang --plan Целость --trust`

## Что происходит

```
$ grep -c '^\$ flang' docs/site/cli.ru.md
21
$ grep -n -A2 'plan Целость --trust' docs/site/cli.ru.md
517:$ flang io ярлыки.flang --plan Целость --trust
518-на веру: доказанность не считалась — запуск по ключу --trust
519-{"plan":"Целость","result":"ярлыков 146; …
$ bootstrap/flang io ярлыки.flang --plan Целость --trust
на веру: доказанность не считалась — запуск по ключу --trust
{"plan":"Целость","result":"ярлыков 149; посмотрено 148: …                код 0
```

Страница сверена рукой с 0.7.17 и частично с 0.7.21. Пятнадцать примеров из
двадцати одного стоят на файлах привет.flang, плохо.flang, план.flang и
факты.json, которых в дереве нет: прогнать их нельзя.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Каждый пример `$ flang …` на обеих страницах снимается прогоном: проверка
читает блоки `bash`, зовёт двоичный и сверяет вывод и код возврата с
показанными. Вывод, сокращённый многоточием, сверяется по началу.

## Обходной путь

Сверять рукой при каждом выпуске.

## Когда задача сделана

1. Входные файлы примеров лежат в дереве (например, в `docs/site/examples/`),
   и прогоняемы все примеры страницы.
2. Проверка красна, если в `docs/site/cli.md` подменён один показанный вывод
   или код возврата, и зелена на нетронутом дереве.
3. Она красна на расхождении русской страницы с английской.
4. Проверка стоит ярлыком в `ярлыки.flang` и в работе `build` файла
   `.github/workflows/binary.yml`, где двоичный уже собран.
5. Шапка страницы называет эту проверку вместо сверки рукой.

Числа сайта (`docs/site/numbers.json`) задача не трогает: их сверяет
`scripts/guards/published-vs-tree.sh`.

## Где живёт правка

Новая проверка в `scripts/guards/`, строка в `ярлыки.flang`, шаг в
`.github/workflows/binary.yml`, обе страницы `docs/site/cli.md` и
`docs/site/cli.ru.md`. Перепечатка не нужна.
