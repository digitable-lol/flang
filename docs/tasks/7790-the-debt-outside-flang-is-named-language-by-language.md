# 7790. У файлов дерева, написанных не на flang, нет поимённой описи с доводом, почему каждый остаётся

## Шаги воспроизведения

1. `sh scripts/guards/published-vs-tree.sh --перепись`

## Что происходит

```
$ sh scripts/guards/published-vs-tree.sh --перепись
ЧТО В ДЕРЕВЕ НЕ НА FLANG (за утверждением «всё написано на flang»):
  ВСЕГО НЕ НА FLANG        файлов  226  строк  940799
  ДОЛГ                     файлов  137  строк   54514
  замеряемый материал      файлов   14  строк    1859
  напечатано компилятором  файлов   15  строк  821871
  рантайм цели печати      файлов   33  строк   52318
  хозяин узла на цели      файлов    8  строк    8731
  чужая среда              файлов   19  строк    1506
  НА FLANG                               строк  338972
```

Строка «долг» — одно число. Описи, где каждый из этих файлов назван с доводом,
в дереве нет: `docs/javascript-inventory.md` разбирает только JavaScript.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Перепись печатает `ДОЛГ файлов 0`, либо каждый оставшийся файл назван поимённо
с доводом, почему он не переводится, и опись в `docs/` повторяет этот список.

## Обходной путь

Нет.

## Когда задача сделана

1. Долг разобран по языкам. Переводимое (JavaScript, оболочка, Python, awk)
   переведено на flang или названо с препятствием.
2. Непереводимое по существу (пробы работы с памятью на C) названо поимённо с
   доводом.
3. `sh scripts/guards/published-vs-tree.sh --перепись` печатает `ДОЛГ файлов 0`
   или список, совпадающий с описью.

Храповик долга вне JavaScript (`scripts/guards/tree-inventory.fscript`) — другой
прибор с потолком, в эту задачу он не входит.

## Где живёт правка

`scripts/guards/published-vs-tree.sh` (функция `perepis`),
`docs/javascript-inventory.md` или новая опись рядом с ней, сами файлы долга.
Перепечатка не нужна.
