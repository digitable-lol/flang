# 7790. Поимённый список долга вне flang прогон печатает, а довода «почему этот файл остаётся» нет ни у одного из 53 файлов

## Шаги воспроизведения

1. `sh scripts/guards/published-vs-tree.sh --перепись`
2. `bootstrap/flang run-script inventory:languages`
3. `grep -c 'чем это держится' docs/tree-inventory.md`

## Что происходит

```
$ sh scripts/guards/published-vs-tree.sh --перепись
ЧТО В ДЕРЕВЕ НЕ НА FLANG (за утверждением «всё написано на flang»):
  ВСЕГО НЕ НА FLANG        файлов  189  строк  930708
  ДОЛГ                     файлов  101  строк   41097
  замеряемый материал      файлов   13  строк    1503
  напечатано компилятором  файлов   15  строк  823681
  рантайм цели печати      файлов   33  строк   54190
  хозяин узла на цели      файлов    8  строк    8731
  чужая среда              файлов   19  строк    1506
  НА FLANG                               строк  356314
$ bootstrap/flang run-script inventory:languages
… ДОЛГ ВНЕ JavaScript: файлов 53, строк 5708, потолок файлов 63
  · .githooks/commit-msg — оболочка, 2
  · .githooks/pre-commit — оболочка, 2
  …ещё 51 строка, по строке на файл
$ grep -c 'чем это держится' docs/tree-inventory.md
2
```

У переписи «долг» — одно число (101 файл, вместе с JavaScript). Поимённый
список **уже есть**, и заводить второй не надо: `inventory:languages` печатает
каждый файл долга вне JavaScript — 53 файла в 14 каталогах — с языком и числом
строк. Чего ни у одного из них нет, так это **довода**: прогон печатает имя,
язык и строки и ни слова о том, почему файл остаётся.

Довод в дереве записан, но не по файлу, а по месту: таблица «чем это держится»
в `docs/tree-inventory.md` даёт по строке на каталог — и она снята на 108
файлах при нынешних 53, то есть разошлась с деревом. Сама опись
прямо говорит: «Поимённый список даёт сам прогон… и другого списка заводить не
надо: второй счёт того же — та самая болезнь, а не лекарство». Значит довод
должен приехать в прогон, а не в новый документ.

Версия: flang 0.7.23.

## Что должно быть

Рядом с именем каждого файла долга стоит довод, почему он остаётся, — там же,
где прогон печатает имя, язык и строки. Отдельный список в `docs/` не
заводится: таблица «чем это держится» в `docs/tree-inventory.md` становится
источником доводов, с которым прогон сверяется, а перепись перестаёт быть
единственным местом, где долг виден только числом.

## Обходной путь

Читать поимённый список из `bootstrap/flang run-script inventory:languages`, а довод искать
глазами в таблице `docs/tree-inventory.md` по каталогу файла.

## Когда задача сделана

1. `bootstrap/flang run-script inventory:languages` печатает у каждого из 53 файлов долга
   вне JavaScript довод — строка вида `· путь — язык, строк, довод`. Файл без
   довода краснит прогон и назван по имени.
2. Доводы взяты из `docs/tree-inventory.md`: прогон читает их оттуда, а не
   держит вторую копию. Довод, которому в дереве не отвечает ни один файл, и
   файл, которому не отвечает ни один довод, — обе беды названы.
3. Подделка: у одного файла довод убран — прогон краснеет и называет этот файл;
   довод дописан на несуществующий путь — прогон краснеет и называет путь.
4. Перепись `sh scripts/guards/published-vs-tree.sh --перепись` рядом со строкой
   `ДОЛГ` говорит, чем смотреть поимённо, — одно число без адреса списка больше
   не печатается.

Перевод самих файлов на flang в эту задачу НЕ входит: 53 файла за один наряд не
переводятся, и это отдельная работа (5821 — скрипты оболочки). Храповик долга
(`scripts/guards/tree-inventory.fscript`) с его потолком — тот же прибор, но
другая его половина: здесь меняется только то, что он печатает про каждый файл.

## Где живёт правка

`scripts/guards/tree-inventory.fscript` (печать поимённого списка и чтение
доводов), `docs/tree-inventory.md` (таблица «чем это держится» — источник
доводов, переснять на нынешние 53 файла),
`scripts/guards/published-vs-tree.sh` (функция `perepis`, строка 530 — адрес
поимённого списка рядом с числом). Перепечатка не нужна.
