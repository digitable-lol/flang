# 7791. Сверщики переигрывают 7 из 14 задач, которые ядро доказывает в сравнении с Lean

Заявка: https://github.com/digitable-lol/flang/issues/391

## Шаги воспроизведения

1. Для каждой из 14 доказанных задач `flang/proof/parity/corpus.tsv` (столбец
   `expected` — `auto` или `by-hand`) снять запись:
   `bootstrap/flang check <файл> --proof --strict --record <запись>`.
2. `flang/proof/checker/сверщик <файл> <запись>` и
   `flang/proof/checker/second/out/второй-сверщик <файл> <запись>`.

## Что происходит

2 ноября 2026, двоичный 0.7.32 (dev `bc1652ff4`): оба сверщика отвечают кодом 0 на 7
задачах и кодом 3 («место на слове ядра») на семи — `nat-closed-power`,
`nat-order-chain`, `list-filter-length-bound`, `and-introduction`, `contradiction`,
`tree-mirror-mirror`, `nat-maximum-bound`. Ходов ядро под этими местами не печатает.

## Что должно быть

Каждое из 14 мест переиграно обоими сверщиками; подделка к каждому новому приёму
отвергнута (код 1, либо код 3 там, где опровергнуть нечем).

## Обходной путь

Код 3 честно называет место на слове ядра.

## Когда задача сделана

- Оба сверщика отвечают кодом 0 на всех 14 записях.
- `bootstrap/flang run-script checker:check` — «сошлось всё», семья
  `kernel-replay` в `flang/proof/checker/tests/probes.tsv`: 7 честных → 0, подделки → 1
  или 3, ни одна не принята кодом 0.
- `bootstrap/flang run-script checker:second` — «расхождений 0».
- `docs/lean-parity.md`: «переигрывает все 14».

## Где живёт правка

`flang/proof/checker/checker.c`, `flang/proof/checker/second/*.lean`; печать ядра не
меняется.
