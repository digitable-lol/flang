# 7826. «от голова и хвост» в доводах вызова читается как образец списка, и FLANG_PARSE советует несуществующее имя

Заявка: https://github.com/digitable-lol/flang/issues/393

В `«Сложить» от голова и хвост` три слова читаются одним словом образца, а не двумя именами, связанными этим образцом строкой выше.

## Шаги воспроизведения

1. Программа `pattern-words.flang`:

```flang
модуль «Слова образца в доводах»

тотальная функция «Сложить»
  принимает а: неотрицательное, б: список неотрицательное
  возвращает число
  пример «один»
    дано а равно 1
    дано б равно []
    ожидается 1
  а плюс (длина б)

тотальная функция «Первый плюс длина»
  принимает л: список неотрицательное
  возвращает число
  пример «пусто»
    дано л равно []
    ожидается 0
  разбор л
    случай пусто
      то 0
    случай голова и хвост
      то «Сложить» от голова и хвост
```

2. `bootstrap/flang check pattern-words.flang`.

## Что происходит

```
$ bootstrap/flang check pattern-words.flang
pattern-words.flang: не проверено — замечаний 1
FLANG_PARSE в файле pattern-words.flang, строка 22, столбец 23: не разобрана конструкция: неожиданное 'голова и хвост' — это слово занято языком, именем оно быть не может: напишите имя в ёлочках («голова и хвост») или переименуйте; а если с …
код 1
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

В позиции значения `голова` и `хвост` — имена, `и` — разделитель доводов; программа проходит `check`.

## Обходной путь

`«Сложить» от (голова) и хвост`.

## Когда задача сделана

`bootstrap/flang check pattern-words.flang` — код 0.

## Где живёт правка

`flang/self/parser.flang`, `flang/self/lexer.flang`. Ждёт печати семени.

## Правка

Причина: лексер склеивает `голова и хвост` в одно слово образца, и в позиции
значения разбор его не знал. Теперь «Слово внутри формулы» в
`flang/self/parser.flang` раскладывает это слово обратно на три — `голова`, `и`,
`хвост` с местами каждого («Поток со словами образца») — и разбирает первичное
заново: `голова` и `хвост` становятся локальными именами, `и` — разделителем
доводов.

Проба `flang/proof/probes/parse-and-import`, строка
`list-pattern-in-call-arguments.flang`: двоичный 0.7.28 — `FLANG_PARSE`, код 1
(красная до печати). Исходный компилятор (`bootstrap/flang run flang/self/bootstrap/check-with-source-compiler.flang` по исходникам ветки (свой вход на несколько файлов, `--trust`), 16 октября 2026): «ГОДНО», функций 2,
тотальных 2.
