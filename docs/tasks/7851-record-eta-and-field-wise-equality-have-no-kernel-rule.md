# 7851. Ядро не доказывает, что запись, собранная из полей «п», равна «п», и не выводит равенство записей из равенства полей

Заявка: https://github.com/digitable-lol/flang/issues/374

Две построенные записи с равными полями ядро считает равными, а запись-переменную и запись, собранную из её же полей, — нет. Правила «эта записи» и «равенство по полям» в ядре нет, и теорема его не запишет: индукции по записи нет.

## Шаги воспроизведения

1. Программа `eta.flang`:

```flang
модуль «Эта записи»

объект «Пара»
  «а»: признак
  «б»: признак

утверждение «конгруэнция построенных»
  для всех х: признак
  для всех ю: признак
  утверждаем (запись «Пара» с а равным (х и притом ю) и б равным х) равно (запись «Пара» с а равным (ю и притом х) и б равным х)

утверждение «эта записи»
  для всех п: «Пара»
  утверждаем (запись «Пара» с а равным п.а и б равным п.б) равно п

утверждение «равенство по полям»
  для всех п: «Пара»
  для всех д: «Пара»
  утверждаем (если (п.а равно д.а) и притом (п.б равно д.б) то п равно д иначе да)
```

2. `bootstrap/flang check eta.flang --proof`.

## Что происходит

```
$ bootstrap/flang check eta.flang --proof

  утверждение «эта записи» — объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
  утверждение «равенство по полям» — объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
eta.flang: НЕ ПРОВЕРЕНО — утверждений 3: доказано 1, условно 0, сетка 0, объявлено, не доказано 2, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 3
код 3
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

«эта записи» и «равенство по полям» доказаны, сверщик проигрывает оба шага. Правило 1: `запись «Т» с f1 равным п.f1 и … и fn равным п.fn` равно `п`, когда перечислены все поля. Правило 2: из `п.fi равно д.fi` для каждого поля следует `п равно д` для записей одного объявленного типа. Необязательные поля (`иногда является`) учитывают отсутствие поля.

## Обходной путь

Нет в доказательстве: держать поля отдельными параметрами вместо записи.

## Когда задача сделана

`bootstrap/flang check eta.flang --proof` — «доказано 3», код 0; сверщик на записи прогона — код 0. Подделка: запись, где одно поле взято у другой переменной (`б равным д.б`), не доказывается.

## Где живёт правка

`flang/self/proof-kernel.flang` (правила сведения), `flang/self/proof-record.flang` (ходы в записи), `flang/proof/checker/checker.c` (проигрыш). Правка в `flang/self` ждёт печати семени.
