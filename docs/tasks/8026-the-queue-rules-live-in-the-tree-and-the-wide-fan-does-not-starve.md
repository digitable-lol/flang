# 8026. Широкий прогон в очереди тяжёлых прогонов голодает за узкими: старшинства по числу мест нет

Очередь тяжёлых прогонов машины разработки (`/srv/flang-rabota/vorota/flang-vorota`)
раздаёт места и память. По памяти старшая просьба защищена: новичок не берёт
свободную память, если её ждёт более старая просьба. По числу мест такой защиты
нет.

## Шаги воспроизведения

1. `sed -n 1167,1173p /srv/flang-rabota/vorota/flang-vorota`
2. `sed -n 1085,1095p /srv/flang-rabota/vorota/flang-vorota` — что сравнивает
   `starshiy_golodaet`.
3. Свой пул через `VOROTA_KOREN`, два места заняты надолго, подана просьба на
   две ветви, через остальные места идёт поток коротких прогонов на одно место:

```sh
export VOROTA_KOREN=<свой каталог>; mkdir -p "$VOROTA_KOREN/sloty"
export PAMYAT=1G CHISLO=4 DOLYA_SLOTOV=8
V=/srv/flang-rabota/vorota/flang-vorota
VETVEY=1 ZHDAT=20 "$V" -- sleep 150 &   # два долгих занимателя
VETVEY=1 ZHDAT=20 "$V" -- sleep 150 &
sleep 5
( while :; do VETVEY=1 ZHDAT=30 "$V" -- sleep 6 & sleep 1; done ) &
sleep 12
VETVEY=2 ZHDAT=60 "$V" -- sleep 2; echo "код $?"   # широкая просьба
```

   Пул меньше восьми мест задать нельзя: строка 326 поднимает `DOLYA_SLOTOV`
   до 8, сколько бы ни попросили; без `DOLYA_SLOTOV=8` на машине разработки
   пул считается от памяти и упирается в 64 места (строки 324–325), и тогда
   широкая просьба получает места сразу. Опыт ставится на восьми.

## Что происходит

```
$ sed -n 1167,1173p /srv/flang-rabota/vorota/flang-vorota
  while [ "$i" -le "$ISKAT_DO" ] && [ "$nashli" -lt "$VETVEY" ]; do
    if mesto_svobodno "$i"; then
      svobodnye="$svobodnye$i "
      nashli=$((nashli + 1))
    fi
    i=$((i + 1))
  done
```

Цикл смотрит только, свободно ли место; на более старые просьбы он не
оглядывается. Старшинство считает `starshiy_golodaet` (строка 1085), и
сравнивает она ПАМЯТЬ: поле `nado` метки `.zhdyot.<номер>` — это `NADO_KIB`,
число мест в метку не пишется вовсе. Исход опыта шага 3:

```
широкая просьба на 2 ветви ждала 60 с и не получила НИЧЕГО — код 75
узких прогонов подано 100, не дождались места 7
ворота: нужно 2 мест из 8, свободно 0 — жду до 60 с
ворота: за 60 с место не освободилось, прогон не начат
```

Версия: ворота `/srv/flang-rabota/vorota/flang-vorota` (файл от 29 августа 2026, 1244 строки);
опыт повторён 11 октября 2026 на своём пуле с `DOLYA_SLOTOV=8`, цикл поиска мест — те же
строки 1167–1173, `starshiy_golodaet` — строка 1085.

## Что должно быть

Освободившееся место не отдаётся новичку, если его ждёт более старая просьба,
которой мест не хватает. Никто не держит места, пока ждёт, поэтому взаимной
блокировки нет.

## Обходной путь

Запускать широкий прогон, когда очередь не забита. В общем пуле 64 места:
`DOLYA_SLOTOV` берётся как `(ГиБ машины × 6 / 10) / 4` — на этой машине
`(499 × 6 / 10) / 4` = 74 — и упирается в потолок 64 (строки 324–325). Под
обычной нагрузкой упираются в память, а не в места.

## Когда задача сделана

1. Опыт шага 3 на своём пуле: широкая просьба получает места, код 0 (сейчас —
   код 75).
2. Контрольный опыт: узкие прогоны при этом продолжают проходить (сейчас из
   100 поданных места не дождались 7, и эту часть терять нельзя).
3. Запись о просителе в очереди имеет срок годности и убирается, если процесс
   мёртв.

## Где живёт правка

Файл очереди `/srv/flang-rabota/vorota/flang-vorota` (вне дерева): цикл поиска
мест и функция `starshiy_golodaet`, которая считает только память. Перепечатка не
нужна.

Следующий шаг: `/srv/flang-rabota/vorota/flang-vorota`, функция `starshiy_golodaet` (строка
1085) — писать в метку `.zhdyot.<номер>` число мест рядом с `NADO_KIB` и сравнивать его в цикле
поиска мест (строки 1167–1173). Проба, которая красна сегодня, — опыт шага 3 с
`DOLYA_SLOTOV=8`: код 75. Файл лежит вне дерева flang, правка в репозиторий не попадает.
