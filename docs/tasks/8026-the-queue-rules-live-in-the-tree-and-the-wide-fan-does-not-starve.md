# 8026. Широкий прогон в очереди тяжёлых прогонов голодает за узкими: старшинства по числу мест нет

Очередь тяжёлых прогонов машины разработки (правила — `docs/gate-rules.md`)
раздаёт места и память. По памяти старшая просьба защищена: новичок не берёт
свободную память, если её ждёт более старая просьба. По числу мест такой защиты
нет.

## Шаги воспроизведения

1. `sed -n 1167,1173p /srv/flang-rabota/vorota/flang-vorota`
2. Опыт из `docs/gate-rules.md`, раздел 10, пункт 1: свой пул из четырёх мест
   через `VOROTA_KOREN`, два места заняты надолго, подана просьба на две ветви,
   через оставшиеся два места идёт поток коротких прогонов на одно место.

## Что происходит

```
$ sed -n 1167,1173p /srv/flang-rabota/vorota/flang-vorota
  while [ "$i" -le "$ISKAT_DO" ] && [ "$nashli" -lt "$VETVEY" ]; do
    if mesto_svobodno "$i"; then
      svobodnye="$svobodnye$i "
      nashli=$((nashli + 1))
    fi
    i=$((i + 1))
  done
```

Цикл смотрит только, свободно ли место; на более старые просьбы он не
оглядывается. Записанный исход опыта:

```
широкая просьба на 2 ветви ждала 96 с и не получила НИЧЕГО — код 75
узких прогонов прошло за это же время: 32
ворота: нужно 2 мест из 4, свободно 2 — жду до 90 с
ворота: за 90 с место не освободилось, прогон не начат
```

Версия: не перепроверено (опыт с очередью); цикл прочитан 30 сентября 2026.

## Что должно быть

Освободившееся место не отдаётся новичку, если его ждёт более старая просьба,
которой мест не хватает. Никто не держит места, пока ждёт, поэтому взаимной
блокировки нет. Порядок расписан в `docs/gate-rules.md`, раздел 10, пункт 1.

## Обходной путь

Запускать широкий прогон, когда очередь не забита. В пуле 64 места, и под
обычной нагрузкой упираются в память, а не в места.

## Когда задача сделана

1. Опыт из раздела 10 на своём пуле: широкая просьба получает места, код 0.
2. Контрольный опыт: узкие прогоны при этом продолжают проходить.
3. Запись о просителе в очереди имеет срок годности и убирается, если процесс
   мёртв.
4. Раздел 10 в `docs/gate-rules.md` больше не называет это голодание.

## Где живёт правка

Файл очереди `/srv/flang-rabota/vorota/flang-vorota` (вне дерева): цикл поиска
мест и функция `starshiy_golodaet`, которая сегодня считает только память.
В дереве — `docs/gate-rules.md`. Перепечатка не нужна.
