# 8028. Проверка сведения считает «сверщику не хватило бюджета» и «сверщик поймал ложь» одним провалом

## Шаги воспроизведения

1. `sed -n 61,70p flang/proof/forgeries/reduction.sh`
2. `grep -cE '^\s*sverit .* 0$' flang/proof/forgeries/reduction.sh` и
   `grep -cE '^\s*poddelka ' flang/proof/forgeries/reduction.sh`
3. `grep -n -A3 '"сведение:проверка"' ярлыки.flang`
4. `bootstrap/flang run-script reduction:check`

## Что происходит

```
$ sed -n 61,70p flang/proof/forgeries/reduction.sh
sverit() {
  imya=$1; ish=$2; zap=$3; zhdyom=$4
  vyvod=$(sh "$SVERIT" "$ish" "$zap" 2>&1) && kod=0 || kod=$?
  if [ "$kod" -eq "$zhdyom" ]; then
    say "СОШЛОСЬ  $imya — код $kod"
  else
    say "ПРОВАЛ   $imya — ждали код $zhdyom, получили $kod"
    BAD=$((BAD + 1))
  fi
$ grep -cE '^\s*sverit .* 0$' flang/proof/forgeries/reduction.sh
4
$ grep -cE '^\s*poddelka ' flang/proof/forgeries/reduction.sh
20
$ grep -n -A3 '"сведение:проверка"' ярлыки.flang
202:   запись «Ярлык» с «имя» равным "сведение:проверка" и «команда» равным (соединить [
203-     "sh flang/proof/forgeries/reduction.sh"] по "") и «зачем» равным (соединить [
204-     "сведение, записанное по шагам, проигрывается сверщиком заново: две ",
205-     "честные записи приняты, четырнадцать подделок отвергнуты"] по ""),
```

Любой код сверщика, не равный ожидаемому, прибавляется к одному счётчику `BAD`,
и итог один: «опытов не сошлось» и код 1. Описание ярлыка называет две честные
записи и четырнадцать подделок, в файле честных опытов четыре, подделок
двадцать.

Сам прогон `bootstrap/flang run-script reduction:check` в минуту не укладывается; по записи
первая честная запись шла больше 50 минут и была снята по сроку.

Версия: не перепроверено (полный прогон); команды `sed` и `grep` сняты на flang 0.7.23, 30 сентября 2026.

## Что должно быть

Проверка печатает три числа врозь: сошлось, поймано лжи, не хватило бюджета.
Код возврата различает «поймана ложь» и «бюджет кончился». Описание ярлыка
называет те числа опытов, которые есть в файле.

## Обходной путь

Читать вывод каждого опыта глазами: строка под «ПРОВАЛ» несёт первую строку
ответа сверщика.

## Когда задача сделана

1. `bootstrap/flang run-script reduction:check` печатает «сошлось N, поймано лжи M, не хватило
   бюджета K»; коды возврата для M > 0 и для K > 0 разные.
2. Числа N, M, K сняты прогоном, проверка укладывается в свой срок.
3. Поле «зачем» ярлыка сходится с числом опытов в файле, и это расхождение
   ловит проверка.

## Где живёт правка

`flang/proof/forgeries/reduction.sh` (функции `sverit` и `poddelka`, итог в
конце файла), запись ярлыка `сведение:проверка` в `ярлыки.flang`. Перепечатка не
нужна.
