# 8121. Ядро решений, которому верят без доказательства, — 5137 строк при цели меньше 4000, и названные ходы до цели не доводят

Ядро решений — функции трёх файлов ядра (`flang/self/proofterm.flang`,
`flang/self/proof-kernel.flang`, `flang/self/proof-initial.flang`), достижимые
от поверхности и решающие, доказано утверждение или нет.

## Шаги воспроизведения

1. Замер прибором (полторы минуты своим прогоном):
   `bootstrap/flang io flang/scripts/kernel-lines-to-trust.fscript --plan 'Потолок не пробит' --max-steps 2000000000`
2. Сколько правил вывода стоит за этими строками:
   `awk -F'\t' 'NR > 1 { print $3 }' flang/proof/tables/inference-rules.tsv | sort | uniq -c`

## Что происходит

```
$ bootstrap/flang io flang/scripts/kernel-lines-to-trust.fscript --plan 'Потолок не пробит' …
  всего строк:                       17400
  КОД:                               9224   (функций 1290)
  достижимо от поверхности ядра:     8902   (поверхность — 7 имён, их зовёт compiler.flang)
  ЯДРО РЕШЕНИЙ — верить надо ему:    5137   (функций 737)
  только слова (текст отказов):      847   (функций 123)
  из ядра решений — разбор формы:    689   (13% ядра решений)
  функций с «Значением» в подписи:   574 из 737

потолок не пробит                                             код 0, 1 мин 23 с
$ awk -F'\t' 'NR > 1 { print $3 }' flang/proof/tables/inference-rules.tsv | sort | uniq -c
     15 ban
     97 rule
```

Разбор (не перепроверен на текущем ядре) называет три хода и их верхнюю границу:

| ход | снимает строк |
|---|---:|
| вынести из ядра функции-постоянные, возвращающие слово | 167 |
| свести функции, различающиеся только строковым литералом, в одну с доводом | 98 |
| типизированный терм вместо бесформенного узла «Значение» | 164–214 |

Вместе это снимает 429–479 строк, то есть оставляет 4658–4708 — выше цели на
658–708 строк. Остальное — сами правила вывода: в ведомости
`flang/proof/tables/inference-rules.tsv` 112 строк, 97 правил и 15 запретов, а
снимать правила нельзя: это ослабляет язык.

Версия: flang 0.7.23.

## Что должно быть

Число строк, которым верят, уменьшается, и каждое уменьшение разобрано: какие
функции ушли из круга решений и чем доказано то, чему раньше верили. Цель
«меньше 4000» либо взята, либо переписана решением владельца под то, что
достижимо без снятия правил.

## Обходной путь

Не верить ядру, а гонять независимый сверщик `flang/proof/checker/checker.c`:
он переигрывает записи ядра. Его собственный размер — отдельное число.

## Когда задача сделана

1. Ход «вынести работу из решающей функции в собирающую» (факты приезжают в
   решающую функцию данными) применён по ядру систематически, и выигрыш назван
   числом: прибор печатает «ЯДРО РЕШЕНИЙ» меньше 5137.
2. Три хода из таблицы выше либо сделаны, либо отвергнуты с замером.
3. Прогон плана «Потолок не пробит» отвечает кодом 1, кодом отказа
   `FLANG_VERIT_POTOLOK_USTAREL` и текстом «стало МЕНЬШЕ — перепишите потолок»,
   и в `flang/scripts/kernel-lines-to-trust-ceiling.json` стоит новое
   `"ядроРешенийСтрок"`.
4. Принято решение владельца о цели: оставить 4000, назначить достижимую, либо
   сменить предмет доверия на сверщик.

Не считается снижением: снятие правила вывода; перенос кода в четвёртый файл,
которого прибор не читает; подъём потолка без разбора прироста.

## Где живёт правка

`flang/self/proofterm.flang`, `flang/self/proof-kernel.flang`,
`flang/self/proof-initial.flang`; потолок —
`flang/scripts/kernel-lines-to-trust-ceiling.json`, прибор —
`flang/scripts/kernel-lines-to-trust.fscript`. Правка ядра требует перепечатки
самосборной части.
