# 8161. Сообщения компилятора зашиты в двоичный, и новый язык вывода требует перепечатки

Решение принято в `docs/adr/0024-the-settings-file-and-the-language-of-output.md`,
раздел 7: таблица сообщений лежит рядом с двоичным, каталог задаётся
переменной `FLANG_MESSAGE_DIR`. Работа не начата.

## Шаги воспроизведения

1. `grep -rn 'FLANG_MESSAGE_DIR' flang/src flang/self bootstrap`
2. `grep -rln 'FLANG_MODULE_DIR' flang/src/emit/c`

## Что происходит

```
$ grep -rn 'FLANG_MESSAGE_DIR' flang/src flang/self bootstrap
                                                            код 1
$ grep -rln 'FLANG_MODULE_DIR' flang/src/emit/c
flang/src/emit/c/flang_repl.c
```

Переменной среды и поиска таблицы сообщений в коде нет. Весь текст вывода —
литералы в слое C, справка `--help` и диагностика в `flang/self/**` — лежит
внутри двоичного и написан по-русски.

Версия: flang 0.7.23.

## Что должно быть

Двоичный ищет таблицу перевода в каталоге рядом с собой так же, как ищет
библиотеку, и в каталоге из `FLANG_MESSAGE_DIR`:

```
<каталог двоичного>/../share/flang/сообщения/<код языка>.txt
```

- строка таблицы — «исходная русская строка, табуляция, перевод»; ключом служит
  сама русская строка, отдельных идентификаторов нет;
- непереведённая строка печатается по-русски; без файлов перевода двоичный
  говорит по-русски, как сегодня;
- не переводятся коды `FLANG_*`, поля вывода `--json`, имена ключей и команд.

## Обходной путь

Нет: новый язык вывода — правка исходников и перепечатка.

## Когда задача сделана

1. Двоичный с положенным файлом перевода печатает сообщения на этом языке, без
   файла — по-русски.
2. Первый файл перевода — английский.
3. Есть проверка: строка перевода, которой в дереве больше нет, краснеет;
   двоичный этой проверке не нужен.
4. Отсрочка для `FLANG_MESSAGE_DIR` в `flang/scripts/code-guard.fscript` снята.
   Мест там три — пример, данные и список отсроченных имён, — и в заголовке
   примера набрано число записей: снимая запись, поправить и его.

## Где живёт правка

Поиск каталога и подстановка перевода — `flang/src/emit/c/flang_repl.c` рядом с
разбором `FLANG_MODULE_DIR`; тексты диагностики — `flang/self/**`. Перепечатка
нужна один раз, чтобы двоичный научился читать таблицу; дальше языки
добавляются без неё.
