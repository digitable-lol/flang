# 8211. Сторож транслита смотрит две трети латинских имён

## Шаги воспроизведения

1. Спросить сторож:

```
bootstrap/flang run-script transliteration:check
```

Отвечает кодом 0: «транслит в именах файлов: латинских имён 2467, с чужими
словами 104 — все в ведомости, новых нет».

2. Прочитать, что он при этом перечисляет (`scripts/guards/translit-file-names-guard.fscript:58`):

```
git ls-files -- scripts flang/test flang/scripts flang/proof docs/site docs/zettel .github
```

3. Посмотреть каталог, которого в этом перечне нет:

```
ls docs/design/
```

## Что происходит

Область сторожа — семь путей, вписанных в него строкой. Всё остальное дерево он
не видит, и зелёный ответ про 2467 имён читается как ответ про дерево.

Перечисление 4 октября 2026, двоичный 0.7.24, дерево `d27d0a7cb`:

| что | число |
|---|---|
| файлов под git всего | 3720 |
| латинских имён **в области** сторожа | 2467 |
| латинских имён **вне области** | **1248** |

Вне области по каталогам (первые места): `docs/examples` 326,
`docs/tasks` 183, `flang/self` 64, `flang/concurrency` 59, `docs/adr` 57,
`flang/stdlib` 54, `docs/flang` 48, `fspec/spec` 43, `flang/src` 35,
`docs/editors` 29, `docs/guide` 25, `docs/benchmarks` 22, `docs/design` 22.

**И транслит там действительно есть.** В `docs/design` из 22 имён на транслите
не меньше двенадцати: `6202-potolok-kak-obyazatelstvo.md`,
`6203-nositel-indukcii-iz-obyavleniya.md`, `nositel-tochnogo-celogo.md`,
`proof-object-blok-vyvoda.md`, `proof-object-hody-razbora-celi.md`,
`proof-object-lemma-po-svoystvu.md`, `proof-object-migration-po-primeru.md`,
`proof-object-migration-po-sluchayam.md`,
`proof-object-migration-po-svoystvu.md`,
`proof-object-migration-po-svoystvu-stdlib.md`,
`proof-object-migration-razbor-celi.md`,
`proof-object-po-obyavleniyu-trace.md`.

Нашлось это не сторожем, а попутно: сторож ссылок назвал
`docs/design/6202-potolok-kak-obyazatelstvo.md` как файл с битыми путями в
прозе, и имя бросилось в глаза.

## Чего задача НЕ утверждает

Что все 1248 имён вне области — транслит. Двенадцать в `docs/design` сосчитаны
глазами по одному; про остальные 1226 имён **не мерено**, и считать их
придётся тем же прибором, что область: словарём чужих слов
(`scripts/ledgers/file-name-words.txt`), а не на глаз.

## Что должно быть

Область сторожа — либо всё дерево, либо список ИСКЛЮЧЕНИЙ с доводом на каждое,
а не список включений. Разница в том, какая ошибка дешевле: при списке
включений забытый каталог молчит, при списке исключений — краснеет.

Переименование стоит отдельной цены: имена из `docs/design` стоят в ссылках и в
прозе, значит правка идёт вместе со сторожем ссылок (задача 9807).

## Когда сделана

1. Область сторожа покрывает всё дерево под git; прогон называет число имён,
   равное числу латинских имён дерева, а не 2467.
2. Переименованное названо в ведомости, и сторож ссылок после переименования
   не прибавил ни одной битой ссылки — сверено числом до и после.
3. Отрицательный контроль: новый файл с транслитным именем в `docs/design`
   обязан покраснить сторож. Без этого опыта задача не закрыта.
