# 8211. Сторож транслита смотрит не всё дерево, а семь вписанных в него путей

## Шаги воспроизведения

1. Спросить сторож:

```
bootstrap/flang run-script transliteration:check
```

Отвечает кодом 0 и называет число латинских имён, которые он просмотрел.

2. Прочитать, что он при этом перечисляет (`scripts/guards/translit-file-names-guard.fscript`,
строка с `git ls-files`):

```
git ls-files -- scripts flang/test flang/scripts flang/proof docs/site docs/zettel .github
```

3. Сосчитать латинские имена дерева вне этих путей:

```
git -c core.quotepath=false ls-files ':!scripts' ':!flang/test' ':!flang/scripts' \
  ':!flang/proof' ':!docs/site' ':!.github' | grep -v -P '[А-Яа-яЁё][^/]*$' | wc -l
```

## Что происходит

Область сторожа — семь путей, вписанных в него строкой (один из них —
каталог заметок, которого в дереве уже нет). Всё остальное дерево он не видит:
`docs/examples`, `docs/tasks`, `docs/adr`, `docs/flang`, `flang/self`,
`flang/stdlib`, `flang/src`, `fspec/spec` и другие. Зелёный ответ про
просмотренные имена читается как ответ про всё дерево.

Задача не утверждает, что вне области есть транслит: это не мерено, и считать
придётся тем же прибором, что в области, — словарём чужих слов
(`scripts/ledgers/file-name-words.txt`), а не на глаз.

## Что должно быть

Область сторожа — либо всё дерево, либо список ИСКЛЮЧЕНИЙ с доводом на каждое,
а не список включений. Разница в том, какая ошибка дешевле: при списке
включений забытый каталог молчит, при списке исключений — краснеет.

Переименование найденного стоит отдельной цены: имена стоят в ссылках и в
прозе, значит правка идёт вместе со сторожем ссылок (задача 9807).

## Обходной путь

Нет: вне области имена никто не проверяет.

## Когда задача сделана

1. Область сторожа покрывает всё дерево под git; прогон называет число имён,
   равное числу латинских имён дерева.
2. Переименованное названо в ведомости, и сторож ссылок после переименования
   не прибавил ни одной битой ссылки — сверено числом до и после.
3. Отрицательный контроль: новый файл с транслитным именем в каталоге, который
   сегодня вне области (например `docs/flang`), обязан покраснить сторож.

## Где живёт правка

`scripts/guards/translit-file-names-guard.fscript` — область и её примеры;
`scripts/ledgers/file-name-words.txt` — ведомость. Двоичный читает их с диска,
перепечатка не нужна.
