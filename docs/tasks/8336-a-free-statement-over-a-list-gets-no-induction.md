# 8336. Свободное утверждение над списком ядро индукцией не доказывает, а базу в теореме закрыть нечем

Заявка: https://github.com/digitable-lol/flang/issues/377

То же свойство, записанное постусловием функции, доказывается индукцией по «список»; записанное свободным `утверждение` — «объявлено, не доказано». В теореме база «пусто» не закрывается: `по примеру` свободному утверждению не принадлежит, `по закону` знает шесть правил.

## Шаги воспроизведения

1. Программа free.flang:

```flang
модуль «Только свободное»

тотальная функция «Найти»
  принимает л: список неотрицательное, н: неотрицательное
  возвращает признак
  разбор л
    случай пусто
      то нет
    случай голова и хвост
      то если голова равен н то да иначе «Найти» от хвост и н

тотальная функция «Отобрать»
  принимает л: список неотрицательное, н: неотрицательное
  возвращает список неотрицательное
  пример «пустой»
    дано л равно []
    дано н равно 0
    ожидается []
  разбор л
    случай пусто
      то []
    случай голова и хвост
      то если голова равен н то [голова] иначе «Отобрать» от хвост и н

утверждение «не нашли — пусто, свободно»
  для всех л: список неотрицательное
  для всех н: неотрицательное
  утверждаем если не («Найти» от л и н) то (длина («Отобрать» от л и н)) равно 0 иначе да
```

2. `bootstrap/flang check free.flang --proof`.

## Что происходит

```
$ bootstrap/flang check free.flang --proof
  утверждение «не нашли — пусто, свободно» — объявлено, не доказано: ни теоремы, ни примеров. Его считает рантайм после каждого возврата — на тех входах, которые придут
free.flang: НЕ ПРОВЕРЕНО — утверждений 1: доказано 0, условно 0, сетка 0, объявлено, не доказано 1, отвергнуто 0, нарушено 0; законов на сетке 0, на веру 0 — код возврата 3
код 3
```

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Свободное утверждение с квантором по списку (или сумме), тело которого зовёт функции с `разбор` по этой переменной, ядро пробует доказать той же индукцией, что и постусловие. В теореме база закрывается вычислением замкнутой после подстановки конструктора цели.

## Обходной путь

Завести постусловие у одной из функций: тогда свободное утверждение закрывается правилом «цель есть допущение».

## Когда задача сделана

`bootstrap/flang check free.flang --proof` — «доказано индукцией по «список»», код 0; тот же файл с теоремой индукцией — код 0.

## Где живёт правка

`flang/self/proof.flang` (кого ядро пробует индукцией), `flang/self/proofterm.flang` (база теоремы вычислением). Ждёт печати семени.
