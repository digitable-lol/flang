# 8337. Переводчик предложений требует объявления на каждое слово

Опытный модуль `flang/experimental/ru-morphology.flang` читает одну русскую
словоформу и отдаёт запись словаря того вида, который разбирает
`flang/proof/probes/syllogism/sentences/translator.flang`. Переводчик об этом
модуле не знает ни строкой: словарь он берёт только из объявлений
`Понятие:` / `Свойство:` / `Имя:`, написанных человеком перед текстом. Решение
[ADR-0060](../adr/0060-russian-morphology-fills-the-dictionary-and-the-declaration-becomes-a-correction.md),
раздел 9, оставляет эту работу на потом; она и есть эта задача.

Живой пример `flang/experimental/ru-syllogism-demo.fscript`
(`bootstrap/flang run-script ru-syllogism:demo`) показывает, что выводится, а
что нет: он берёт текст **без единого объявления**, наполняет словарь
морфологией и отдаёт готовый текст тому же судье отдельным процессом. Отдельным
процессом — потому что оба модуля в один файл не ввозятся.

## Шаги воспроизведения

1. Файл из двух строк:

   ```
   модуль «Both»
     использует «Russian morphology» из "ru-morphology.flang"
     использует «Reasoning sentences» из "../proof/probes/syllogism/sentences/translator.flang"
   ```

   положить в `flang/experimental/`.
2. `bootstrap/flang check flang/experimental/<имя>.flang`
3. Смотреть диагностику и код возврата.

## Что происходит

```
$ bootstrap/flang check flang/experimental/_probe_import.flang
FLANG_DUPLICATE_NAME, строка 708, столбец 1: тип «Reading» объявлен в двух модулях: …/flang/experimental/ru-morphology.flang и …/flang/proof/probes/syllogism/sentences/translator.flang
FLANG_DUPLICATE_NAME, строка 102, столбец 1: функция «Forms of» объявлена в двух модулях: …/flang/experimental/ru-morphology.flang и …/flang/proof/probes/syllogism/sentences/translator.flang
flang/experimental/_probe_import.flang: не проверено — замечаний 18                код 1
```

Выборочный ввоз (`только «Reading of»`) этого не обходит: он привозит названную
функцию без её соседей, и те же 38 замечаний приходят как
`FLANG_UNKNOWN_NAME` и `FLANG_NOT_TOTAL`.

Версия: flang 0.7.24.

Что при этом уже выводится, показывает прогон `ru-syllogism:demo` (код 0,
поручений 6, текстов 3): на тексте `texts/follows.txt` прибор собрал весь
словарь сам — `Имя: Барсик`, `Понятие: мохнатый, мохнатые`,
`Свойство: тих, тихи; она тиха; оно тихо` — и судья ответил «СЛЕДУЕТ». На
тексте `texts/asks-one-line.txt` остался **один** незакрытый вопрос, и пример
назвал ровно одну строку, которую дописать: `Понятие: человек, люди`.

Что не выводится и останется за человеком, показывает прогон
`ru-morphology:probe` (`слов 83, согласований 14, отказов 60, разошлось 0`):
класс слова у частых окончаний не читается у 60 слов из 83, множественное
существительного не выводится ни для одного слова.

Сколько объявлений стоит в корпусе силлогизмов:

```
$ grep -h "^\(Понятие\|Свойство\|Имя\):" flang/proof/probes/syllogism/sentences/texts/*.txt | wc -l
40
$ ls flang/proof/probes/syllogism/sentences/texts/*.txt | wc -l
14
```

## Что должно быть

Переводчик спрашивает словарь у морфологии и просит у человека строку только
там, где морфология отказалась: либо вернула чтений больше одного и место в
предложении не решает, либо назвала недостачу формы. Слова отказа у переводчика
уже есть и менять их не надо — «слово «X» не объявлено: впишите его в словарь
строкой «Понятие: …», «Свойство: …» или «Имя: …»»; нужно, чтобы эта просьба
приходила не на каждое слово.

Чтобы это стало возможно, сначала надо развести имена: тип `«Reading»` и
функция `«Forms of»` объявлены в обоих модулях. Опытный модуль на то и опытный —
имена в нём меняются без предупреждения, и переименовать надо его, а не
переводчик.

## Обходной путь

Судить отдельным процессом, как делает `flang/experimental/ru-syllogism-demo.fscript`:
словарь собирается морфологией в одном плане, текст с объявлениями пишется во
временный файл, а `run.fscript --plan Judge` зовётся на него поручением
«Запустить процесс». Работает, но стоит целого запуска двоичного на текст и
разбора JSON чужого вердикта строкой.

## Когда задача сделана

1. `bootstrap/flang check` на файле, который ввозит оба модуля, отвечает
   «замечаний нет», код 0 — имена разведены.
2. В текстах корпуса `flang/proof/probes/syllogism/sentences/texts/` объявлений
   стало меньше 40, и `bootstrap/flang io flang/proof/probes/syllogism/sentences/run.fscript --plan Binary`
   по-прежнему зелен: ни один из 14 приговоров `expected.tsv` не изменился.
3. Проба краснеет, если словарь перестанет выводиться: текст, где морфология
   закрывает весь словарь, лежит в наборе проб и судится без объявлений.

## Где живёт правка

`flang/proof/probes/syllogism/sentences/translator.flang` (источник словаря),
`flang/experimental/ru-morphology.flang` (развод имён),
`flang/experimental/ru-syllogism-demo.fscript` (пример перестаёт звать судью
процессом), `flang/proof/probes/syllogism/sentences/texts/*.txt` (объявления
убираются там, где прибор их выводит). Правка доезжает до двоичного без
перепечатки семени: `flang/self/**` она не трогает.
