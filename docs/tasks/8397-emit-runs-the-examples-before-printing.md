# 8397. flang emit печатает программу, не прогнав её примеры

## Шаги воспроизведения

1. Программа с ложным примером:

   ```
   модуль «Ложный пример»

   тотальная функция «Удвоить»
     принимает н: число
     возвращает число
     пример «два на два — пять»
       дано н равно 2
       ожидается 5
     н плюс н
   ```

2. `bootstrap/flang emit false-example.flang --target c --out <каталог>`.

## Что происходит

`check` отвечает кодом 1 (`FLANG_EXAMPLE`), а `emit` печатает файлы кодом 0 и
пишет «ПРИМЕРЫ НЕ ПРОГНАНЫ … Прогоните их отдельно: flang test <файл>».
Версия: flang 0.7.26.

## Что должно быть

`docs/flang/SPEC.md`, строка `FLANG_EXAMPLE`: пример «гоняется при КАЖДОЙ
проверке (`check`, `test`, `emit`)». Решение ADR-0099, раздел 2.3: `emit`
прогоняет примеры по умолчанию, ключ `--no-examples` (кириллицей
`--без-примеров`) отказывается от этого и называет это в выводе.

## Обходной путь

`bootstrap/flang test <файл>` перед `emit`.

## Когда задача сделана

На программе выше `bootstrap/flang emit … --target c` отвечает кодом 1 со словом
`FLANG_EXAMPLE` и не пишет ни одного файла; с `--no-examples` — печатает кодом 0 и
строкой «примеры не прогнаны: --no-examples». Печать семени
(`scripts/bootstrap-reprint.sh`) передаёт ключ, если двоичный его знает, и
проходит.

## Где живёт правка

Хозяин печати `flang/src/emit/c/flang_repl.c` (`repl_check_sources` в ветке
`emit`, флаг `examples`) и `scripts/bootstrap-reprint.sh`. Хозяин доезжает до
двоичного печатью семени.
