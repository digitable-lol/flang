# 8398. Компилятор отвечает «замечаний нет» на двенадцать нарочно сломанных объявлений «план»

Правила для объявления `план` написаны (`flang/self/io.flang`, модуль
«Проверка планов»), ввезены в компилятор и вызываются из функции проверки
исходников. Собранный двоичный при этом не отвергает ни одного образца.

## Шаги воспроизведения

1. `grep -n 'использует «Проверка планов»\|«Проверить планы» от' flang/self/bootstrap/compiler.flang`
2. `bootstrap/flang check flang/test/fixtures/plany/01-dvazhdy.flang` и так для
   каждого файла с 01 по 12.

## Что происходит

```
$ grep -n 'использует «Проверка планов»\|«Проверить планы» от' flang/self/bootstrap/compiler.flang
17:  использует «Проверка планов»
961:  пусть «с планами» равно («Слить беды» от «с процессами» и («Проверить планы» от («связано».«программа»)))
1590:  «Слить беды» от «с процессами» и («Проверить планы» от («связано».«программа»))
$ bootstrap/flang check flang/test/fixtures/plany/01-dvazhdy.flang
flang/test/fixtures/plany/01-dvazhdy.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет     код 0
```

В образце 01 план «Работа» объявлен дважды. Тот же ответ и код 0 дают все
двенадцать образцов с 01 по 12. Образец 13 отвергает проверка типов
(`FLANG_UNKNOWN_NAME`, код 1), и правила планов на нём обязаны молчать.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Каждый из двенадцати образцов отвергнут своим сообщением и кодом возврата 2;
верный образец 00 проходит. Сообщения, которые правила дают на этих образцах:

| образец | сообщение |
|---|---|
| 01 | план объявлен дважды |
| 02 | план не собран: в программе нет суммы «Отклик» |
| 03 | состояние плана — неизвестный тип |
| 04 | начальное состояние — неизвестная функция |
| 05 | функция начала принимает довод, а обязана быть без доводов |
| 06 | функция начала возвращает не тип состояния |
| 07 | шаг плана — неизвестная функция |
| 08 | шаг принимает один довод вместо состояния и отклика |
| 09, 12 | первый довод шага не тип состояния |
| 10 | второй довод шага не «Отклик» |
| 11 | шаг возвращает не «Продолжение» |

## Обходной путь

Нет: ошибка в объявлении плана видна только при запуске.

## Когда задача сделана

1. Найдено, почему правила, вызываемые в исходнике компилятора, не срабатывают
   в двоичном: доходит ли `flang check` до этой функции и доходит ли до неё поле
   `plans` разобранной программы.
2. `bootstrap/flang check` на образцах 01–12 отвечает кодом 2 и названным
   сообщением, на образце 00 — кодом 0.
3. Живые программы дерева с объявлением `план` по-прежнему проходят
   `bootstrap/flang check`: правила не отвергают верное.
4. Проба на четырнадцати образцах стоит ярлыком в `ярлыки.flang`.

## Где живёт правка

`flang/self/io.flang` (функции «Проверить планы», «Обход планов»),
`flang/self/bootstrap/compiler.flang` (функция со строкой 961, «Ключи судимых
планов»). Правка требует перепечатки самосборной части.
