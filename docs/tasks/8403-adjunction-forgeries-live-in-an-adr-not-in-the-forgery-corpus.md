# 8403. Десять подлогов законов сопряжений и Йонеды живут командами в ADR-0086, а не файлами в flang/test/fixtures/binary-rules: вернувшийся дефект судьи их не покраснит

Решение: `docs/adr/0086-an-adjunction-is-a-declared-unit-and-counit-with-the-triangle-identities-as-laws.md`,
раздел «Подлоги» — таблица из десяти правок с кодами, которыми они краснеют.

## Шаги воспроизведения

1. `ls flang/test/fixtures/binary-rules/ | grep -c -e adjunction -e yoneda -e triangle`.
2. Смотреть число.

## Что происходит

```
$ ls flang/test/fixtures/binary-rules/ | grep -c -e adjunction -e yoneda -e triangle
0                                                                      код 1
```

Подлоги воспроизводятся только по тексту ADR (копия честной программы плюс
`sed`), прогона по ним в дереве нет. Сторож `binary-rules:check` красен по делу
и в CI не стоит (`scripts/ledgers/uncalled-guards.json`), поэтому класть
подлоги в корпус без разбора его ожиданий нельзя: он считает поверхности по
ключам ответа двоичного, и лишний файл сдвинет его находки.

Версия: `flang 0.7.25`.

## Что должно быть

Каждый из десяти подлогов — файл в корпусе подделок, который двоичный обязан
отвергнуть кодом 1 с названным кодом (`FLANG_TRANSFORM_NOT_NATURAL` для
квадратов единицы и коединицы, `FLANG_PROPERTY` для треугольных тождеств и
закона Йонеды), и сторож корпуса знает о них.

## Обходной путь

Повторить команды из раздела «Подлоги» ADR-0086 рукой.

## Когда задача сделана

`ls flang/test/fixtures/binary-rules/ | grep -c -e adjunction -e yoneda -e triangle`
даёт 10; `bootstrap/flang run-script binary-rules:check` находок из-за них не
прибавляет, а снятие любого подлога из корпуса красит сторожа.

## Где живёт правка

`flang/test/fixtures/binary-rules/`, `flang/scripts/binary-rules-guard.fscript`
(ожидания по ключам). Двоичный не трогается.
