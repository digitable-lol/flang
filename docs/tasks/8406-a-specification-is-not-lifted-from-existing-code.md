# 8406. Спека из легаси не вынимается ничем

В дереве есть спеки на flang и сторож, ищущий между ними противоречия. Нет шага, который
делает первую спеку из существующего кода.

Решение — [ADR-0056](../adr/0056-a-foreign-language-enters-through-an-untrusted-translator.md):
переводчик стоит вне доверенной основы, черновик спеки судит ядро, недоказанное становится
вопросом человеку.

## Шаги воспроизведения

1. `find fspec -name '*.flang' | wc -l`
2. `bootstrap/flang --help` — искать команду, читающую чужой код.
3. Прочитать `docs/guide/foreign-code.ru.md` — раздел о том, что смотрит `check`.

## Что происходит

```
$ find fspec -name '*.flang' | wc -l
73
```

Спеки есть: `fspec/spec/` — правила предметной области, `fspec/guard.flang` — сторож,
не дающий новому правилу отменить старое, `fspec/clarifications.flang` — мастер вопросов
человеку из неудачи доказательства. Все 73 файла написаны руками.

Машины, которая прочитает чужой код и напечатает `fspec`-спеку, нет: входов в flang ноль
(задача о входе — рядом). Опыт ручного перевода в `docs/guide/foreign-code.ru.md`: при
переписке `bisect_left` из CPython всплыло 6 мест, и требование «список отсортирован»
не было записано в чужом коде нигде, кроме строки документации.

Версия: flang 0.7.23. Дата прогона: 2 октября 2026.

## Что должно быть

Шаг, который из чужого кода печатает черновик спеки на flang — утверждения о входах и
выходах, которые чужой код молча предполагает, — и называет про каждое, чем оно взято:
из кода, из проверки в коде, из имени, из комментария. Черновик недоверен: его судит
`flang check`, и то, что не доказалось, становится вопросом человеку через
`fspec/clarifications.flang`.

## Обходной путь

Переписывать руками и ловить несоответствия по ходу — так и сделано в
`docs/guide/foreign-code.ru.md`.

## Когда задача сделана

Прогон на названном корпусе чужих файлов печатает черновик спеки и число: сколько
утверждений вынуто, сколько из них доказано на переведённом коде, сколько стало
вопросами. Проба краснеет, если доля вынутых утверждений упала.

## Где живёт правка

Новый каталог вне `flang/self`, `fspec/clarifications.flang` (вопросы).
