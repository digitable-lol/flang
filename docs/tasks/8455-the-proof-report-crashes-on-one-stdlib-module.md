# 8455. Отчёт о доказательствах не печатается для одного модуля библиотеки

## Чем измерено

19 сентября 2026, ствол `a5609e322`, двоичный `bootstrap/flang` 0.7.20 собран
`make -C bootstrap CFLAGS='-std=c99 -O0'`.

```
$ flang check --proof flang/stdlib/math-classics.flang
FLANG_PROPERTY: нарушено свойство «чужой заголовок не признаётся своим»
функции «Это заголовок функции записи»
код 1
```

Стандартный вывод при этом ПУСТ: ведомости нет ни строки.

Обычная проверка того же файла зелена:

```
$ flang check flang/stdlib/math-classics.flang
модуль «Math classics»: функций 45, из них с доказанным завершением 42; типов 0
без доказанного завершения: «НОД по Евклиду» «НОД с самим собой» «НОД с единицей»
flang/stdlib/math-classics.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
код 0
```

Печать того же модуля в C тоже зелена: `flang emit … --target c --out …` — код 0,
33 проверки `fl_post` в напечатанном файле.

Беда воспроизводится и на другом двоичном (сборка из ветки `a/wp2-probe`), то
есть это не артефакт одной сборки.

## Где именно

Нарушенное постусловие — в самом компиляторе:
`flang/self/zapis.flang:750`

```
обеспечивает «чужой заголовок не признаётся своим» если результат
  то («строка» содержит («Слить строки записи» от ["функция ", («В ёлочках записи» от «функция»)]))
  иначе да
```

То есть сторож, оставшийся в собранном компиляторе от НЕДОКАЗАННОГО
постусловия, срабатывает на настоящем входе. Функция `«Это заголовок функции
записи»` решает, своя ли эта строка-заголовок, и на каком-то заголовке из
`math-classics.flang` её ответ разошёлся с обещанием.

## Что надо сделать

1. Найти вход, на котором обещание ломается: какой именно заголовок из
   `math-classics.flang` доходит до `«Это заголовок функции записи»` и что она
   на нём отвечает. Модуль большой (546 строк, 45 функций) — половинным делением
   это минуты.
2. Решить, что неверно: обещание или функция. Оба исхода законны, но их надо
   различить и назвать.
3. Починить. Если ломается функция — починить функцию; если обещание сказано
   неточно — переписать обещание и **доказать** его, а не ослабить до
   бессодержательного.
4. Пробу положить в дерево: модуль, на котором отчёт раньше падал, обязан
   печататься. Сегодня ни одна проверка дерева не гоняет `flang check --proof`
   по стандартной библиотеке — поэтому беда и дожила до сегодня.

## Чего НЕ надо делать

Не гасить сторож ключом и не снимать постусловие. Сторож здесь сработал
правильно: он поймал расхождение между обещанием и поведением — ровно то, ради
чего стоит.

## Цена правки семени

`flang/self/zapis.flang` — ПЕЧАТАЕМАЯ часть семени. Правка доезжает до
двоичного только перепечаткой (около 11 часов, `sh scripts/raskrutka.sh`), а не
быстрым пересевом. Планировать работу надо вместе с очередной партией
перепечатки.
