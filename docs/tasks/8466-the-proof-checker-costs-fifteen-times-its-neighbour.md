# 8466. Проверка записи доказательства за час не дошла до конца на примере из двух утверждений, а сосед не запускается вовсе

План `flang/proof/check.fscript` запускает проверяющую программу
`flang/proof/checker.flang` на исходнике и записи доказательства. Рядом лежит
`flang/proof/reduce.fscript` с `flang/proof/small-reducer.flang`: работа того же
рода на том же входе. Оба зовут программу через общий `flang/proof/errand.fscript`
и называют только её имя, ключи и коды отказа.

## Шаги воспроизведения

1. Доказать и записать доказательство:

```
bootstrap/flang check flang/proof/examples/stack.flang --proof --record <запись>
```

2. Переиграть запись проверяющей программой:

```
bootstrap/flang io flang/proof/check.fscript --max-steps 4000000000 -- flang/proof/examples/stack.flang <запись>
```

3. Прогнать на том же входе соседа:

```
bootstrap/flang io flang/proof/reduce.fscript --max-steps 4000000000 -- flang/proof/examples/stack.flang
```

## Что происходит

```
$ bootstrap/flang check flang/proof/examples/stack.flang --proof --record <запись>
flang/proof/examples/stack.flang: ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — утверждений 2: доказано 2 …   код 0
$ bootstrap/flang io flang/proof/check.fscript … -- …/stack.flang <запись>
шагов 22 678 746 573 из 4 000 000 000 000 (0 %), идёт «Шаг плана», 698 МиБ
                 прогон снят рукой на 62 мин 40 с, до конца не дошёл
$ bootstrap/flang io flang/proof/reduce.fscript … -- …/stack.flang
small-reducer.flang кончил кодом 3: не доказано: утверждений 52: доказано 50,
сетка 2, на веру 0 — запуск только по явному согласию: --trust
                              FLANG_SMALL_REDUCTION_NOT_MEASURED, код 3, 8,5 с
```

Проверка записи до конца не дошла. Прогон снят рукой на 62 мин 40 с — 35 мин
28 с своего времени и 27 мин 09 с системного, память ходила между 0,5 и 1,2 ГиБ.
Проверяющая программа к этому времени насчитала 22 678 746 573 шага, то есть
ноль процентов от напечатанного ею предела, и шла дальше. Дойдёт ли она вообще
и за сколько шагов — по-прежнему неизвестно; на то, сколько шагов уходит на
какую функцию, прогон не отвечает вовсе.

Сравнить проверку с соседом сегодня нечем: `reduce.fscript` не запускается
вовсе. В ключах его наряда стоит `--max-steps 2000000000 --max-depth 40000` и
согласия на запуск недоказанной программы нет, а у `check.fscript` в том же
месте стоит `--на-веру`. Сколько времени на такой прогон отпущено, в дереве уже
записано: оба вызова `check.fscript` — из `flang/proof/forgeries/run.fscript` и
`flang/proof/rules-match.fscript` — дают ему `--timeout 14400000`, то есть четыре
часа. `reduce.fscript` не зовёт никто.

Версия: flang 0.7.23. Дата прогона: 3 октября 2026.

## Что должно быть

`bootstrap/flang io flang/proof/check.fscript` на
`flang/proof/examples/stack.flang` доходит до конца и печатает число шагов.
Рядом записано, на какие функции проверяющей программы уходит разница с
`small-reducer.flang` на том же входе: число шагов на функцию, снятое прогоном.

## Обходной путь

Записи проверяет программа на C: `flang/proof/checker/checker.c`.

## Когда задача сделана

1. `bootstrap/flang io flang/proof/reduce.fscript -- flang/proof/examples/stack.flang`
   отвечает кодом 0 и печатает строки утверждений.
2. `bootstrap/flang io flang/proof/check.fscript -- flang/proof/examples/stack.flang <запись>`
   отвечает «сошлось: утверждений N» и кодом 0; число шагов прогона названо.
3. Цена обоих прогонов разложена по функциям тем прибором, который в дереве
   есть: `FLANG_WATCH=<файл> FLANG_PULSE=<N>` — рантайм сам пишет, сколько
   вызовов сделано, на какой глубине и в какой функции прогон сейчас. Названа
   функция, на которую уходит разница. Поднимать предел шагов вместо разбора
   цены не годится.

## Где живёт правка

`flang/proof/checker.flang` (сама цена); ключи наряда — `flang/proof/check.fscript`
и `flang/proof/reduce.fscript` (во втором нет согласия на запуск недоказанной
программы), общий запуск — `flang/proof/errand.fscript`. Перепечатка не нужна:
обе программы исполняются через `flang io`.
