# 8545. Образцы предложений для пользовательской истории есть в пробе, а в языке их по-прежнему ноль

Заявка: —

## Что сделано: девять образцов и проба на них

Образцы, переводчик и проба — `flang/proof/probes/story/`; описание для человека
— [`docs/fspec/user-story-sentence-forms.md`](../fspec/user-story-sentence-forms.md).
Приём взят у силлогизма ([ADR-0050](../adr/0050-a-reasoning-is-written-as-declared-words-and-fixed-sentences.md)):
**автор объявляет слова, язык не угадывает морфологию.**

| образец предложения | во что превращается |
|---|---|
| `Роль: <слово>` | объявление роли в словаре |
| `Величина: <им. форма>, <форма после «при»>` | объявление величины в словаре |
| `История: <имя>` | имя функции |
| `Как <роль>` | вход `«кто»: «Роль»` и `требует «как <роль>» «кто».«<роль>»` |
| `Хочу <величина> не больше <число>` | `обеспечивает «хочу: …» результат не больше <число>` |
| `Хочу <величина> не меньше <число>` | то же с `не меньше` |
| `Чтобы <зачем>` | строка отчёта о истории |
| `При <величина> не меньше <число>` | `требует «при: …» «<величина>» не меньше <число>` |
| `Тогда при <форма величины> <число> ответ <число>` | `пример` с входом и ожиданием |

Названный поимённо отказ стоит на каждой половине истории, которую разобрать
нечем, — как у переводчика силлогизмов. Десять из тринадцати образцов набора —
именно про это: роль не объявлена, величина не объявлена, у величины одна форма,
желание не того образца, у истории нет имени / желания / «зачем», условие о
другой величине, форма величины в примере не та, что объявлена, и ложная
история, которую отвергает ядро.

## Чем доказано

Прогон 4 октября 2026, двоичный `bootstrap/flang` этого дерева (`make -C bootstrap`
на `origin/dev` `4d76abd53`).

```
$ bootstrap/flang check flang/proof/probes/story/translator.flang
модуль «User story sentences»: функций 75, из них с доказанным завершением 75; типов 4
flang/proof/probes/story/translator.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет

$ bootstrap/flang check flang/proof/probes/story/run.fscript
модуль «User story in sentences»: функций 174, из них с доказанным завершением 174; типов 13
flang/proof/probes/story/run.fscript: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет

$ bootstrap/flang lint flang/proof/probes/story/
flang lint: файлов 2; max-line-length 120: 0; max-conditional-depth 2: 0; не разобрано 0

$ bootstrap/flang io flang/proof/probes/story/run.fscript --plan Binary --max-steps 40000000
story: проб 13, разошлось 0                                             код 0
```

**Образец разбирается** — примерами самого переводчика, которые проверяет
`flang check`, то есть они красны ещё до прогона набора. Каждая половина истории
снята отдельным примером на тексте: «Head lines» даёт девять строк объявления
роли и сигнатуры, «Need lines» — строку `требует`, «Goal line» — строку
`обеспечивает`, «Example lines» — четыре строки `пример`, «Body lines» — тело, а
«Program lines» складывает их в программу целиком. Примеры записаны литералами,
потому что язык примеры не вычисляет.

**Ложная история отвергается** — и отвергает её ядро, а не сверка строк.
`texts/the-shown-case-does-not-agree.txt` обещает «скидка не больше 30» и
показывает «Тогда при скидке 40 ответ 40»:

```
НЕ ЗАПИСАНО: «тогда» истории не сходится с её «хочу» — FLANG_EXAMPLE: пример
«тогда вход 40 ответ 40» функции «потолок скидки с примером против»: значение не
совпало с ожидаемым: ожидалось 40, получено 30                          код 1
```

**Отрицательный контроль прогнан.** Без него набор не отличить от выключенного.
В `texts/discount-cap.txt` подменено `Хочу скидка не больше 30` на `не больше 50`
— набор покраснел и назвал строку:

```
story: проб 13, разошлось 1                                             код 1
  · discount-cap.txt — ждали код 0 и слово «ЗАПИСАНО: цель «хочу: скидка не
    больше 30» доказана ядром обо всех входах», вышло: код 1,
    FLANG_STORY_NOT_WRITTEN … НЕ ЗАПИСАНО: «тогда» истории не сходится с её
    «хочу» — FLANG_EXAMPLE: пример «тогда вход 40 ответ 30» функции «потолок
    скидки»: значение не совпало с ожидаемым: ожидалось 30, получено 40
```

Подмена снята, текст восстановлен.

Зов набора вписан в `.github/workflows/binary.yml` рядом с набором силлогизма —
иначе проба осталась бы проверкой, которую никто не звал.

## Что осталось: поверхность языка

Слова `история`, `как`, `хочу`, `чтобы` лексеру по-прежнему неизвестны, и это
главный остаток задачи:

```
$ bootstrap/flang check story.flang
FLANG_PARSE в файле story.flang, строка 3, столбец 1:
  не разобрана конструкция: неожиданное 'история'
story.flang: не проверено — замечаний 1                                 код 1
```

Правка живёт в `flang/self/lexer.flang` и `flang/self/parser.flang`, и в
собранном двоичном её не будет до перепечатки самосборной части
(`sh scripts/bootstrap-reprint.sh`; цена захода 4 октября 2026 — 4736 с,
`docs/reprint-ledger.tsv`). До перепечатки поверхность проверяют зондом, как в
коммите `33859c9f2` «силлогизму дают два слова поверхности»: 12 строк в лексере,
35 в разборщике, плюс зонд в `flang/self/bootstrap/` (в стволе на 4 октября его
уже нет — зонд одноразовый, он нужен только до перепечатки). Истории нужен тот
же порядок, и 5309 — соседняя задача того же решения.

Ещё два остатка, названные вслух, чтобы их не приняли за сделанное:

- **Цели, которую ядро отвергает по сути, а не примером, в наборе нет.** Образец
  берёт одно `Хочу` на историю, и тело функции задаётся тем же образцом, поэтому
  цель всегда доказуема; ложь ловится «Тогда». Для отказа ядра нужна форма
  `Ещё хочу …`, дающая второе `обеспечивает`.
- **`Чтобы <зачем>` доезжает до отчёта, а не до ядра.** Связи между историями в
  языке нет, и «зачем ни на что не ссылается» проверяется только непустотой.

## Обязательств в плане нет — и это нарочно

У `run.fscript` ноль `обеспечивает`, как и у соседнего плана силлогизма: файл с
обязательством обязан нести строку в `scripts/ledgers/proved-share-ledger.txt`,
а доля доказанного по дереву считается именно по ней. Всё, что здесь можно
доказать, доказано примерами переводчика — их 75 функций и все с доказанным
завершением; план же только возит вопросы и складывает отчёт.

## Почему проба лежит не в `fspec/`

В `fspec/` нет формы «проба, которая пока краснеет»: запись истории в
`fspec/spec` или случай в `fspec/forgery.flang` сделали бы `specs:check` и
`specs:forgery` красными на ровном месте. Поэтому набор лежит там же, где лежит
набор силлогизма, — в `flang/proof/probes/`, и судит каждую историю тем же
вызовом `flang check … --proof --strict`, которым проверяется любая спека.

## Обходной путь

Писать требование записью языка: `тотальная функция «…» обеспечивает «…» …`.
История остаётся комментарием, и ни одна проверка её не читает — ровно это и
снимает набор `story`, пока у языка нет своих слов.

## Когда задача сделана

1. `bootstrap/flang check` на программе, записанной словами `история / как /
   хочу / чтобы`, даёт код 0 и печатает цель, выведенную из `хочу`; та же
   программа с незаявленной ролью даёт код 1 с отказом, который называет роль.
   **Не сделано:** нужна правка в `flang/self/**` и перепечатка.
2. Набор образцов записан, и проба на него краснеет, если разбор истории
   перестаёт давать цель. **Сделано:** 13 образцов, отрицательный контроль
   прогнан, зов в `binary.yml` вписан.
3. Образцы предложений названы поимённо в прозе, читаемой человеком.
   **Сделано:** `docs/fspec/user-story-sentence-forms.md`.
