# 8570. Перепечатка компилятора идёт десять часов при цели в два, и за это время ствол успевает её обогнать

Входы печати (`flang/self/**`) правят примерно раз в час. Перепечатка, которая
идёт дольше, кончается на дереве, которого в стволе уже нет. Темп правок менять
не нужно; нужно укоротить печать.

## Шаги воспроизведения

1. `tail -1 docs/reprint-ledger.tsv | cut -f1-4`
2. Поимённая ведомость на дороге печати:
   `FLANG_TICKS_OUT=<файл> bootstrap/flang emit flang/self/lexer.flang --target c --out <каталог>`
3. Поимённая ведомость на дороге суда:
   `FLANG_TICKS_OUT=<файл> bootstrap/flang check flang/self/tags.flang`
4. Доли по ведомости: `заряд` каждой функции против строки `заряда всего`.

## Что происходит

```
$ tail -1 docs/reprint-ledger.tsv | cut -f1-4
2026-09-17	печать	дошла	36839
```

Последняя ЗАПИСАННАЯ печать шла 36 839 секунд — 10 часов 14 минут. Печать
0.7.24, прошедшая после неё, шла 37 700–38 000 с (10 ч 28 мин — 10 ч 33 мин)
при пике 46,6 ГиБ — числа с захода на gpu, здесь своим прибором не снятые;
строки за эту печать в ведомости нет (задача 6704). Цель — два часа, и разрыв
пятикратный.

Куда уходит расход — снято ведомостью по именам, двумя прогонами, 3 октября
2026 на семени этого дерева.

Дорога печати, `emit flang/self/lexer.flang --target c`: 1 241 368 349 шагов,
7,3 с, заряда всего 1 225 645 027.

Три вещи, которые эта ведомость называет прямо:

1. **«Развернуть» главной строкой расхода не является** — 0,02 % заряда на
   дороге суда и 0,001 % на дороге печати. Перебор обрывается на первом
   совпадении («Первое определение по имени», `proof-kernel.flang:2024`), и
   обрыв стоит дороже самой «Развернуть» в сто раз.
2. **«Описания программы», «Описание с именем» и «Имена содержат имя» в
   ведомости НЕ ПОЯВЛЯЮТСЯ ни на одном из двух прогонов** — ноль входов при
   строке `не поместилось 0`. Повтор имени проверяется встроенной формой
   `содержит` над списком имён (`flang/self/interpret.flang:898`), словарь
   описаний у записи «Программа» уже есть (`Узел хеша`, строка 174), поиск
   описания идёт через «Найти описание», а подготовка программы делается ОДИН
   раз на программу (`flang/self/bootstrap/compiler.flang:1769`). Квадрата
   N·(N+1)/2 на подготовке программы здесь нет.
3. Дорогое — лексер (49,4 % заряда на дороге печати, 38,3 % на дороге суда) и
   печать строковых литералов (27,3 % на дороге печати).

Стадия, съедающая печать целиком, названа числом не здесь, а в
`docs/print-cost-measured.md`: «Проверить доказательства с кешем» — 85,79 %
шагов захода, и у неё есть выключенный файловый кеш. Порядок работ по этой
стадии — задача 5709.

Версия: flang 0.7.23, 3 октября 2026. Сама перепечатка этим заходом не
запускалась: обе ведомости сняты на малых прогонах, и переносить их на дерево в
54 раза больше линейно нельзя — цена суда растёт как квадрат числа обязательств
(`docs/print-cost-measured.md`, раздел 4).

## Что должно быть

Полная перепечатка идёт не дольше двух часов. Порядок замеров и прежние числа —
`docs/reprint-cost.md`, строки заходов — `docs/reprint-ledger.tsv`.

## Обходной путь

Разовая заморозка всех входов печати на время одного захода, объявленная
заранее. Как постоянный порядок не годится: останавливает работу над
компилятором.

## Когда задача сделана

1. Снята поимённая ведомость САМОЙ перепечатки — `FLANG_TICKS_OUT` в вызове
   `emit` внутри `scripts/bootstrap-reprint.sh`, а не перенос с малых прогонов;
   названы часы, шаги и загрузка машины на начало и конец захода (`uptime`).
   Часы разных дней без загрузки не сравнимы. Цена прибора измерена: 0,6 %.
2. Главная строка расхода по ЭТОЙ ведомости названа числом, и после правки её
   доля заряда на том же прогоне и тем же прибором НИЖЕ, чем до. Доли меньше
   процента в довод не берутся: прогон их уже показывает нулями.
3. В `docs/reprint-ledger.tsv` есть строка печати с числом секунд не больше 7200.
4. `sh scripts/bootstrap-reprint.sh --bystro` на стволе после вливания отвечает
   кодом 0.

## Где живёт правка

- `flang/self/lexer.flang`: «Первые слова», «Закрыть уровни», «Склеить»,
  «Читать имя» — первая по расходу семья на обеих дорогах. Ни одна из них не
  зовётся из ядра доказательств, это работа разбора, и она идёт заново на
  каждом разборе исходника.
- `flang/self/emit-c.flang` и печатник C: «Печать литерала без проверок»,
  «Печать литерала» — вторая семья, 27,3 % дороги печати.
- Стадия «Проверить доказательства с кешем» и её кеш — задача 5709, там же
  порядок «дешевле → дороже» и цена каждого шага.
- `flang/self/proof-kernel.flang` входит в ядро решений: рост числа строк
  требует довода в `flang/scripts/kernel-lines-to-trust-ceiling.json`.
- Запись замеров: `docs/reprint-cost.md`, `docs/reprint-ledger.tsv`.

Правка в `flang/self/**` доезжает до двоичного только перепечаткой.
