# 8570. Отказ рецепта перепечатки называет цену захода устаревшим числом, а поимённой ведомости расхода самой перепечатки нет

## Шаги воспроизведения

1. `tail -3 docs/reprint-ledger.tsv | cut -f1-4`
2. `grep -n 'Цена последнего дошедшего захода' scripts/bootstrap-reprint.sh`
3. `grep -n '^MEASURED_COST=\|^MAX_STEPS=' scripts/bootstrap-reprint.sh`
4. Поимённая ведомость на дороге печати:
   `FLANG_TICKS_OUT=<файл> bootstrap/flang emit flang/self/lexer.flang --target c --out <каталог>`
5. Поимённая ведомость на дороге суда:
   `FLANG_TICKS_OUT=<файл> bootstrap/flang check flang/self/tags.flang`
6. Доли по ведомости: `заряд` каждой функции против строки `заряда всего`.

## Что происходит

```
$ tail -3 docs/reprint-ledger.tsv | cut -f1-4
…	печать	дошла	4955
…	печать	дошла	4782
…	печать	дошла	4899
$ grep -n 'Цена последнего дошедшего захода' scripts/bootstrap-reprint.sh
3402:  err "Цена последнего дошедшего захода — 8 ч 34 мин (docs/reprint-ledger.tsv)."
$ grep -n '^MEASURED_COST=\|^MAX_STEPS=' scripts/bootstrap-reprint.sh
295:MEASURED_COST=2508501226319
296:MAX_STEPS=8000000000000
```

Версия: flang 0.7.25.

### Цена захода в отказе

Ведомость заходов называет печати около 4900 с (1 ч 22 мин), а отказ рецепта
(`scripts/bootstrap-reprint.sh`, строка 3402) печатает «8 ч 34 мин» — число,
вписанное в рецепт строкой, а не взятое из ведомости, на которую он ссылается.
Читает его именно тот, кто правил вход печати и решает, перепечатывать ли
сейчас. Шапка `docs/reprint-ledger.tsv` повторяет ту же устаревшую цену
(«сверка стоит 8 ч 34 мин»).

### Куда уходит расход: есть только малые прогоны

Поимённые ведомости сняты на двух малых прогонах; цена самого прибора
`FLANG_TICKS_OUT` — около 1 % на дороге печати и 0,3 % на дороге суда, у
обеих ведомостей `не поместилось 0`.

Дорога печати, `emit flang/self/lexer.flang --target c`: 1 445 152 091 шаг.

| доля заряда | функция | где живёт |
|---:|---|---|
| 24,81 % | «Первые слова» | `flang/self/lexer.flang` |
| 19,48 % | «Печать литерала без проверок» | печатник C |
| 15,70 % | «Закрыть уровни» | `flang/self/lexer.flang` |
| 10,33 % | «Склеить» | `flang/self/lexer.flang` |
| 5,33 % | «Читать имя» | `flang/self/lexer.flang` |
| 4,53 % | «Печать литерала» | `flang/self/emit-c.flang` |
| 3,28 % | «Читать в кавычках» | `flang/self/lexer.flang` |
| 3,05 % | «Печать значения в C без проверок» | печатник C |

Дорога суда, `check flang/self/tags.flang`: 737 525 154 шага.

| доля заряда | функция | где живёт |
|---:|---|---|
| 26,63 % | «Первые слова» | `flang/self/lexer.flang` |
| 24,36 % | «Закрыть уровни» | `flang/self/lexer.flang` |
| 8,64 % | «Склеить» | `flang/self/lexer.flang` |
| 7,54 % | «Прогон цикла» | `flang/self/interpret.flang` |
| 7,12 % | «Читать имя» | `flang/self/lexer.flang` |
| 3,62 % | «Печать значения» | `flang/core/json.flang` |
| 2,37 % | «Сканировать» | `flang/self/lexer.flang` |

Что эти ведомости называют прямо:

1. Лексер — первая семья расхода на обеих дорогах: четыре имени («Первые
   слова», «Закрыть уровни», «Склеить», «Читать имя») — 56 % заряда на дороге
   печати и 67 % на дороге суда.
2. Вторая семья — печать строковых литералов, и она целиком на дороге печати:
   «Печать литерала без проверок» и «Печать литерала» вместе — 24 %.
3. «Развернуть» и «Первое определение по имени» из ядра доказательств — сотые
   и тысячные доли процента.
4. «Описания программы», «Описание с именем» и «Имена содержат имя» в
   ведомостях не появляются при `не поместилось 0`, то есть не вызваны ни разу:
   квадрата N·(N+1)/2 на подготовке программы здесь нет.

Переносить эти доли на перепечатку линейно нельзя: дерево перепечатки в
десятки раз больше, а цена суда растёт как квадрат числа обязательств.
Поимённой ведомости самой перепечатки нет — её снимает `FLANG_TICKS_OUT` в
вызове `emit` внутри `scripts/bootstrap-reprint.sh`, и такого захода не было.

Стадийные счётчики (`FLANG_VITKI=1`) вложены друг в друга, поэтому долю
стадии в печати по ним складывать нельзя.

## Что должно быть

1. Цена захода в отказе рецепта и в шапке ведомости берётся из последней
   строки «печать … дошла» `docs/reprint-ledger.tsv`, а не вписана числом.
2. Главная строка расхода самой перепечатки названа по её собственной
   поимённой ведомости.

Порядок замеров — [`docs/reprint-cost.md`](../reprint-cost.md), строки
заходов — [`docs/reprint-ledger.tsv`](../reprint-ledger.tsv).

## Обходной путь

Цену захода смотреть в `docs/reprint-ledger.tsv`, а не в отказе рецепта.

## Когда задача сделана

1. Отказ рецепта называет цену последнего дошедшего захода по ведомости;
   проба с подменённой последней строкой ведомости меняет число в отказе.
2. Сторож потолка (`код 2`) проверен подлогом: `MAX_STEPS` ниже
   `MEASURED_COST` отвергается.
3. Снята поимённая ведомость самой перепечатки — `FLANG_TICKS_OUT` в вызове
   `emit` внутри `scripts/bootstrap-reprint.sh`. Главная строка расхода по ней
   названа числом; доли меньше процента в довод не берутся.
4. `bootstrap/flang run-script seed:fast` отвечает кодом 0.

## Где живёт правка

- `scripts/bootstrap-reprint.sh`: число цены в отказе (строка 3402);
  `docs/reprint-ledger.tsv` — шапка.
- `flang/self/lexer.flang`: «Первые слова», «Закрыть уровни», «Склеить»,
  «Читать имя» — первая по расходу семья на обеих дорогах; это работа разбора,
  и она идёт заново на каждом разборе исходника.
- `flang/self/emit-c.flang`: «Печать литерала» и её копия без постусловий —
  вторая семья.
- Стадия «Проверить доказательства с кешем» и её кеш — задача 5709.

Правка в `flang/self/**` доезжает до двоичного только перепечаткой; правка
рецепта и ведомости — без неё.
