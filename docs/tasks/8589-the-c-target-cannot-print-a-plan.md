# 8589. Цель «c» печатает объявление «план»

Вид: **возможность** (feature request), не дефект. Отказ сегодня честный и
названный — это не ложь, а отсутствие.

Заявка: https://github.com/digitable-lol/flang/issues/161 (пункт 2)

План с чтением файла нельзя собрать в C. Исполнить его можно только
интерпретатором `flang io`, и тогда вся работа плана идёт со скоростью
интерпретатора.

## Шаги воспроизведения

1. Взять пример дерева с планом: `docs/examples/io/binary-file-round-trip.flang`
   (план «Скопировать двоичный»: «Прочитать октеты из файла», затем «Записать
   октеты в файл»).
2. `flang emit docs/examples/io/binary-file-round-trip.flang --target c --out каталог`.

## Что происходит

```
$ flang emit docs/examples/io/binary-file-round-trip.flang --target c --out out161c
flang emit: печать отказала — FLANG_PLAN_UNSUPPORTED: цель «c» не умеет печатать объявление «план». В программе оно есть: «Скопировать двоичный». Напечатать программу и промолчать про объявление нельзя: модуль собрался бы, код возврата был бы нулевой, а исполнять план он бы не умел. Сегодня объявление «план» печатает одна цель — «js»; исполнить его умеет ещё «flang io».
                                                                  код 1, 0,31 с
```

Каталог `out161c` не заведён. Та же программа в `--target js` — код 0, файлов
4. Цели `go` и `rust` отвечают тем же `FLANG_PLAN_UNSUPPORTED`.

Версия: `flang 0.7.22`, двоичный из семени ствола `7b3a73873`. Прогон 27
сентября 2026.

Во что это обходится, одна и та же работа — `разделить … по
"Request for Comments:"` над текстом в 10 516 638 байт (RFC 8448, склеенный 66
раз):

| как | время | пик |
|---|---|---|
| `flang io`, план «Прочитать файл» → `разделить` | 1,83 с | 128 388 КБ |
| напечатанный C (`--no-cli`), свой хозяин зовёт функцию | 0,047 с | 10 240 КБ |

Оба прогона — рантайм ствола `7b3a73873`, до правки задачи 3509.

## Что должно быть

`flang emit … --target c` на программе с объявлением `план` печатает модуль и
исполнитель плана: начальная функция → функция шага → поручение исполняет
хозяин на C → отклик уходит в шаг, пока не придёт «Конец работы» или «Провал».
Исход печатается так же, как у `flang io` (`{"plan":…,"result":…}`), код
возврата тот же. Поручение, которое хозяин не знает, — отклик «Сбой» с
`FLANG_IO_UNKNOWN`, как у `io_perform` сегодня, а не тишина.

Минимум, о котором просит заявка, — файловые поручения. Отказ по остальным
допустим, если он назван так же честно, как нынешний `FLANG_PLAN_UNSUPPORTED`.

## Обходной путь

Печатать в C только чистые функции (`--no-cli`), а цикл поручений писать своим
хозяином на C. Так сделал автор заявки.

## Когда задача сделана

1. `flang emit docs/examples/io/binary-file-round-trip.flang --target c --out d`
   — код 0; `make -C d` без единого предупреждения (флаги Makefile — `-Wall
   -Wextra -Werror -pedantic`); запуск печатает тот же итог, что
   `flang io docs/examples/io/binary-file-round-trip.flang --plan 'Скопировать двоичный'`.
2. Прибор `scripts/targets/plan-across-targets.fscript` судит цель «c» словом
   «печатает», а не «отказывает»; остальные цели — прежний отказ. Код отказа
   назван там на строке 111, пример с целью «c» и кодом 1 — на строке 282: он
   остаётся примером суда, а не ожиданием о нынешней цели.
3. План с поручением, которого хозяин C не знает: напечатанное отвечает
   «Сбой» с `FLANG_IO_UNKNOWN`, а не падает.

## Где живёт правка

**Печать — `flang/self/**`, нужна полная перепечатка семени:**

- `flang/self/bootstrap/compiler.flang:318` `«Отказ по плану»`; для цели «c»
  его зовут `«Напечатать связанное»` (строка 412) и `«Напечатать связанное с
  протоколом»` (строка 420). Для «c» отказ снимается;
- `flang/self/emit-c.flang` — печать исполнителя плана: встроенные суммы
  «Поручение», «Отклик», «Продолжение» как значения C и главный цикл. Образец
  для другой цели уже есть: `flang/self/emit-js.flang:4862` (план в JS).

**Хозяин поручений — копируемый C, в вывод уезжает дословно:**

- в напечатанном C хозяин поручений уже есть — `fl_conc_perform`,
  `flang/src/emit/c/flang_conc.c:1731`; его кладёт в вывод
  `flang/self/emit-c.flang:5980`, только когда программа конкурентная. Либо
  взять его, либо вынести файловую часть `io_perform`
  (`flang/src/emit/c/flang_repl.c:15644`) в отдельный копируемый файл: сам
  `flang_repl.c` — оболочка компилятора, в печать он не годится.

Перепечатка — `sh scripts/bootstrap-reprint.sh`. Последний дошедший заход
23–25 сентября 2026 шёл **35 ч 45 мин** (коммит `6f98e66e8`), предыдущий
10–11 сентября — 7 ч 28 мин (`docs/reprint-cost.md`).

## Цена

Самая большая из трёх задач по заявке: печать трёх встроенных сумм и главного
цикла в `emit-c.flang`, хозяин, пробы на восьми целях не ломаются. Неделя
работы и одна полная перепечатка. Задачу 6772 (чтение окна) удобно брать
раньше: тогда напечатанный план сразу читает файл окнами.
