# 8589. Цель «c» не печатает объявление «план», и программу с планом нельзя собрать в C

Заявка: https://github.com/digitable-lol/flang/issues/161 (пункт 2)

Это возможность, которой нет, а не дефект: отказ сегодня назван прямо.

## Шаги воспроизведения

1. Пример дерева с планом: `docs/examples/io/binary-file-round-trip.flang`
   (план «Скопировать двоичный»).
2. `bootstrap/flang emit docs/examples/io/binary-file-round-trip.flang --target c --out out161c`

## Что происходит

```
$ bootstrap/flang emit docs/examples/io/binary-file-round-trip.flang --target c --out out161c
flang emit: печать отказала — FLANG_PLAN_UNSUPPORTED: цель «c» не умеет печатать объявление «план». В программе оно есть: «Скопировать двоичный». …
                                                                              код 1
```

Каталог вывода не создан. Отказом отвечают восемь целей — `c`, `cpp`, `csharp`,
`elixir`, `go`, `java`, `python`, `rust`: тот же `FLANG_PLAN_UNSUPPORTED`, код 1,
каталога нет. Печатают две: `js` — код 0, файлов 4, и `ts` — код 0, файлов 6.
Текст отказа выше называет печатающей одну цель «js»; это ошибка текста, а не
счёт целей.

Версия: flang 0.7.23.

## Что должно быть

`flang emit … --target c` на программе с объявлением `план` печатает модуль и
исполнитель плана: начальная функция, функция шага, поручение исполняет хозяин
на C, отклик уходит в шаг, пока не придёт «Конец работы» или «Провал». Исход
печатается так же, как у `flang io` (`{"plan":…,"result":…}`), код возврата тот
же. На поручение, которого хозяин не знает, ответ — отклик «Сбой» с
`FLANG_IO_UNKNOWN`.

Наименьший объём — файловые поручения. Отказ по остальным допустим, если он
назван так же прямо, как нынешний.

## Обходной путь

Печатать в C только чистые функции (`--no-cli`), а цикл поручений писать своим
хозяином на C.

## Когда задача сделана

1. `bootstrap/flang emit docs/examples/io/binary-file-round-trip.flang --target c --out d`
   отвечает кодом 0; `make -C d` проходит без предупреждений; запуск печатает
   тот же итог, что
   `bootstrap/flang io docs/examples/io/binary-file-round-trip.flang --plan 'Скопировать двоичный'`.
2. `scripts/targets/plan-across-targets.fscript` судит цель «c» словом
   «печатает»; из девяти целей его таблицы «js» остаётся «печатает», а остальные
   семь — «отказывает». Цели `ts` в таблице сторожа нет, хотя печатает и она.
3. План с поручением, которого хозяин C не знает: напечатанное отвечает «Сбой»
   с `FLANG_IO_UNKNOWN`, а не падает.

## Где живёт правка

- `flang/self/bootstrap/compiler.flang`: «Отказ по плану» (строка 318); для
  цели «c» его зовут «Напечатать связанное» (412) и «Напечатать связанное с
  протоколом» (420). Для «c» отказ снимается.
- `flang/self/emit-c.flang`: печать исполнителя плана — суммы «Поручение»,
  «Отклик», «Продолжение» как значения C и главный цикл. Образец для другой
  цели: «Печать одного плана» в `flang/self/emit-js.flang`.
- Хозяин поручений на C: либо `fl_conc_perform` из
  `flang/src/emit/c/flang_conc.c` (сегодня уезжает в вывод только у
  конкурентной программы), либо файловая часть `io_perform` из
  `flang/src/emit/c/flang_repl.c`, вынесенная в отдельный копируемый файл.

Правка в `flang/self/**` требует полной перепечатки. Задачу 6772 (чтение окна
файла) удобно сделать раньше: напечатанный план сразу читает файл окнами.
