# 8650. Справка и сообщения компилятора содержат внутренние слова проекта, и их долг в docs/jargon.json не убывает

Перечень внутренних слов («сторож», «ведомость», «корпус», `ledger` и другие) и
допущенный долг по файлам лежат в `docs/jargon.json`.

## Шаги воспроизведения

1. Файл-проба proba.flang:

   ```
   функция «Проба»
     возвращает число
     1
   ```

2. `bootstrap/flang emit proba.flang --target c --no-check --out out`
3. `grep -n 'flang_repl.c": ' docs/jargon.json`
4. `grep -c '"--ledger"' flang/src/emit/c/flang_repl.c`
5. `bootstrap/flang run-script jargon:check`

## Что происходит

```
$ bootstrap/flang emit proba.flang --target c --no-check --out out 2>&1 | grep -n 'СТОРОЖ\|сторож'
8:  * СТОРОЖА ОСТАЛИСЬ ВСЕ. Постусловия уехали в напечатанный код до одного,
11:    толще и на работе медленнее, но не слабее: лишний сторож стережёт то,
$ grep -n 'flang_repl.c": ' docs/jargon.json
486:    "flang/src/emit/c/flang_repl.c": 42,
$ grep -c '"--ledger"' flang/src/emit/c/flang_repl.c
1
$ bootstrap/flang run-script jargon:check
Сторож жаргона: поверхностей 153, внутренних слов 335 (долг по 25 файлам, расти не имеет права), новых 0.
  долг больше всего в: docs/flang/concurrency/SPEC.md (187), flang/src/emit/c/flang_repl.c (42), …
                                                                    код 0
```

Снято 11 октября 2026. Сторож зелен: долг `flang_repl.c` ровно 42, как дозволено, новых слов
нет. Но долг не убывает — 42 внутренних слова по-прежнему в справке и диагностике двоичного,
и напечатанный C по-прежнему говорит «СТОРОЖА ОСТАЛИСЬ ВСЕ».

Версия: flang 0.7.25.

## Что должно быть

Текст, который компилятор показывает пользователю, обходится без внутренних
слов проекта: «сторож» — это проверка постусловия в напечатанном коде, ключ
`--ledger` имеет имя, понятное без словаря проекта. Долг файла в
`docs/jargon.json` — ноль, кроме записей в «исключения» с названной причиной
(имена функций flang, уходящие в `repl_call`).

## Обходной путь

Нет. Слова объяснены в `docs/glossary.md`.

## Когда задача сделана

1. Вывод из шага 2 не содержит слова «сторож» ни в каком регистре.
2. Строка `flang/src/emit/c/flang_repl.c` в разделе «долг» файла
   `docs/jargon.json` равна нулю или снята.
3. `bootstrap/flang run-script jargon:check` отвечает кодом 0 и больше не называет
   `flang/src/emit/c/flang_repl.c` среди должников (сегодня код 0 держится на
   дозволенном долге 42, а не на его отсутствии).

## Где живёт правка

`flang/src/emit/c/flang_repl.c`: строки справки и диагностики (ключ `--ledger`,
сообщение при `--no-check`, сообщения о ключах `--json`, `--записать`,
`--быстро`, `--proof`), затем `docs/jargon.json` (`bootstrap/flang run-script jargon:debt`).

Двоичный собирается не из дерева, а из семенной копии: `bootstrap/Makefile`
берёт `bootstrap/flang_repl.c`, и перепечатка берёт оттуда же («версия ИЗ
ДЕРЕВА со старым компилятором НЕ СВЯЗЫВАЕТСЯ» — `scripts/bootstrap-reprint.sh`,
строка 365). Копии расходятся на 71 строку: у семенной шапка
«Сгенерировано … Не редактировать руками», в дереве — 50 строк комментариев;
кириллические советы и долг жаргона в обеих одни и те же. Значит правку в дереве
без семенной копии собранный компилятор не покажет.

Следующий шаг: `flang/src/emit/c/flang_repl.c` — текст, который печатается при `--no-check`
(«СТОРОЖА ОСТАЛИСЬ ВСЕ»), и имя ключа `--ledger`; после правки опустить строку файла в
`docs/jargon.json` (строка 486) с 42 до 0 через `jargon:debt`. Проба, которая красна сегодня:
`bootstrap/flang emit proba.flang --target c --no-check --out out 2>&1 | grep -ci сторож` — 2.
