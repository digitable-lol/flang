# 8806. «х равен х» не доказывается и на точных типах, и «если х равен х то а иначе б» не сводится к «а»

Заявка: https://github.com/digitable-lol/flang/issues/395

На `неотрицательное` NaN недостижим, но ядро не доказывает, что значение равно себе. Обход сравнением порядком в обе стороны работает, а голое `х не больше х` тоже не доказывается.

## Шаги воспроизведения

1. Программа self-equal.flang:

```flang
модуль «Равен себе»

тотальная функция «Сам себе»
  принимает х: неотрицательное
  возвращает признак
  обеспечивает «равен себе» результат равен да
  пример «два»
    дано х равно 2
    ожидается да
  х равен х

тотальная функция «Выбор по себе»
  принимает х: неотрицательное, а: неотрицательное, б: неотрицательное
  возвращает неотрицательное
  обеспечивает «берёт первое» результат равен а
  пример «два»
    дано х равно 2
    дано а равно 1
    дано б равно 5
    ожидается 1
  если х равен х то а иначе б
```

2. `bootstrap/flang check self-equal.flang --proof`.

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Для операндов точных типов (`неотрицательное`, `целое`, точные дроби, `признак`, `строка`) `Т равен Т` с одинаковыми сторонами — истина, `если Т равен Т то А иначе Б` сводится к `А`. Над `число` — прежнее.

## Обходной путь

`(а не больше б) и притом (б не больше а)` вместо `равен`.

## Когда задача сделана

`bootstrap/flang check self-equal.flang --proof` — оба доказаны; над `число` — не доказаны; подделка `х равен (х плюс 1)` — не доказана.
