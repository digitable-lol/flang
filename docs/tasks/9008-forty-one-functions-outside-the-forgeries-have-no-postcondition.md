# 9008. Сорок одна функция вне подделок не несёт ни одного постусловия

## Шаги воспроизведения

```
bootstrap/flang run-script traceability:check
FLANG_TRACE='flang/proof/examples/corpus-alphabet.flang:3' bootstrap/flang run-script traceability:line
```

## Что происходит

```
  разрывов код → требование (функций без постусловия): 68
  рода «код → требование»: в подделках 27, вне подделок 41
    (корпус примеров 26, карта доказательств 8, прочее 7)
```

Версия: flang 0.7.23. Дата прогона: 4 октября 2026.

Из 68 функций без постусловия 27 лежат в подделках: там постусловие ставить
нельзя — вход ядра подобран так, чтобы поймать ровно одно правило, и лишняя
строка ловушку портит. Остальные 41 — обычный код набора:

- 26 в корпусных примерах `flang/proof/examples/corpus-*.flang`: словари и
  вспомогательные обходы («Заглавные», «Знаки цифр», «Иероглифы»);
- 8 в карте доказательств `flang/proof/map/` («Положить в коробку», «Обратить»,
  «Все неотрицательны», «Упорядочен ли»);
- 7 прочих, среди них `flang/proof/examples/precondition.flang:33` и
  `flang/proof/checker/tests/programs/audit-2844/unfold3-difference.flang:4`.

Цена правки здесь не в постусловии, а в записи: каждый исходник набора назван
записью доказательства, и запись несёт его отпечаток. Правка исходника без
перепечатки записи краснит `record-source:check` (задача 1000), поэтому
закрывать этот долг надо файлами, а не строками: один файл — одна правка плюс
перепечатка его записи.

## Что должно быть

Порядок — от дешёвого к дорогому, по родам из прогона:

1. карта доказательств (8 мест): постусловия ставятся первыми — карта и есть
   то, что читают, чтобы понять язык;
2. прочие 7 мест разбираются поимённо;
3. корпусные примеры (26 мест) — последними: их записи самые дорогие.

Строка `код → требование вне подделок` в
`scripts/ledgers/traceability-debt.tsv` опускается по мере правки и обратно не
растёт.

## Обходной путь

Пока постусловия нет, вопрос «какое требование закрывает эта функция»
отвечается прогоном `traceability:line`: он называет функцию и печатает, что у
неё нет ни одного постусловия, — то есть отвечает честным «нечем», а не
молчанием.

## Когда задача сделана

1. `bootstrap/flang run-script traceability:check` печатает «вне подделок» со
   числом ниже прежнего и выходит кодом 0.
2. `bootstrap/flang run-script record-source:check` — код 0: у каждой правки
   исходника перепечатана его запись.

## Где живёт правка

- `flang/proof/map/*.flang`, `flang/proof/examples/corpus-*.flang` и их записи
  в `flang/proof/checker/tests/records/corpus/`;
- `scripts/ledgers/traceability-debt.tsv`.
