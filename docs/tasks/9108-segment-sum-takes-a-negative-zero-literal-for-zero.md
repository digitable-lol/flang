# 9108. Сумма над отрезком читает литерал минус ноль как ноль

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/segment-sum-negative-zero-literal.flang`:

```flang
модуль «Минус ноль слагаемым над отрезком»

тотальная функция «С минус нулём»
  принимает а: неотрицательное
  возвращает число
  обеспечивает «минус ноль как плюс ноль» результат равен (а плюс 0)
  а плюс -0
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/segment-sum-negative-zero-literal.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/segment-sum-negative-zero-literal.flang --function 'С минус нулём' --args '{"а":-0}'`

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/typing-holes/programs/segment-sum-negative-zero-literal.flang --proof
… НЕ СОШЛОСЬ СО СВЕРЩИКОМ — … доказано 1, код 3
$ bootstrap/flang run flang/proof/probes/typing-holes/programs/segment-sum-negative-zero-literal.flang --function 'С минус нулём' --args '{"а":-0}'
FLANG_PROPERTY: нарушено свойство «минус ноль как плюс ноль» функции «С минус нулём»                                  код 1
```

Версия: flang 0.7.34.

`−0 плюс −0` есть `−0`, `−0 плюс 0` есть `+0`. Правило Кол5 («Сумма над отрезком сошлась») сличает суммы литералов
числом и литерал `-0` считает тем же слагаемым, что `0`. Вердикт печатается именем правила «кольцо точного целого»;
сверщик такую запись не принимает (код 3), но ядро и `flang run` числят утверждение доказанным.
Тот же литерал читался бы и константой линейной формы (Лин).

## Что должно быть

Литерал минус ноль не берётся ни слагаемым суммы над отрезком, ни константой линейной формы.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check flang/proof/probes/typing-holes/programs/segment-sum-negative-zero-literal.flang --proof` не числит ложное утверждение доказанным.
Проба — строки этой программы в `flang/proof/probes/typing-holes/expected.tsv`
и строка ведомости `flang/proof/tables/typing-holes.tsv`: сегодня они держат ответ
двоичного 0.7.34, после правки строка `proof` меняется с «доказано 1» на «доказано 0», строка ведомости — на `закрыта`.

## Где живёт правка

`flang/self/proof-kernel.flang`, «Литерал в пределе отрезка» и «Целое в отрезке линейно»: правка сделана в этой же
ветке и ждёт печати семени (партия 12).
