# 9194. Тип стрелок представимого функтора пишется рукой и ни с чем не сверяется: перечисление «Стрелки из А в Б» может разойтись с категорией, и двоичный этого не видит

Решение: `docs/adr/0086-an-adjunction-is-a-declared-unit-and-counit-with-the-triangle-identities-as-laws.md`,
раздел «Представимость»: hom-функтор выражается перечислением
(`тип «Стрелки из А в Б» вариант …`) — по варианту на стрелку категории.

## Шаги воспроизведения

1. `flang/ct/yoneda-preorder.flang`; в `тип «Стрелки из черновика в согласован»`
   дописать второй вариант `вариант «Согласовать дважды»`, которому в категории
   «Этапы» никакая стрелка не отвечает.
2. `bootstrap/flang check flang/ct/yoneda-preorder.flang`.
3. Смотреть код возврата и список замечаний.

## Что происходит

```
$ bootstrap/flang check flang/ct/yoneda-preorder.flang
… преобразование «по черновику аренды»: … нарушений 0 …
flang/ct/yoneda-preorder.flang: проверено НЕ ДО КОНЦА                 код 2
```

Код тот же, что у честной программы; о лишнем варианте не сказано ни слова.
Разбор `случай` в «После согласовать» лишнего варианта не требует, пока функция
принимает тип стрелок в черновик, а не в согласован.

Версия: `flang 0.7.25`.

## Что должно быть

Функтор, объявленный как hom-функтор категории «Этапы» из объекта «Черновик»,
обязан иметь на объекте «Б» столько вариантов, сколько в категории стрелок из
«Черновик» в «Б», и ровно с теми именами. Сегодня связи «этот тип есть
hom-множество» в языке нет вовсе — функтор «Из черновика» для двоичного ничем не
отличается от любого другого, и `docs/ct/adjunctions.md` называет это границей.

## Обходной путь

Держать перечисления в согласии с категорией рукой; подлог ловится только
тогда, когда лишняя стрелка попадает в сетку компоненты.

## Когда задача сделана

Либо есть форма, которая называет тип hom-множеством категории из объекта
(и `check` отвечает кодом 1 на лишний или недостающий вариант), либо
`docs/ct/adjunctions.md` закрывает вопрос доводом «не делается» с ценой. Проба:
программа выше с лишним вариантом — код 1 с названным вариантом.

## Где живёт правка

`flang/self/types.flang` (проверка функторов), `docs/ct/adjunctions.md`.
Новое слово поверхности стоит перепечатки семени (задача 6375); форма без
нового слова — быстрым пересевом.
