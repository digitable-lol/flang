# 9211. Доказанное утверждение не применяется в шаге индукции: лемма не переписывает развёрнутую цель

Свободное утверждение доказывается индукцией, пока шаг сводится развёрткой и допущением
индукции. Если шагу нужна уже доказанная лемма — другое свободное утверждение того же
файла, — ядро её не применяет, и утверждение остаётся «объявлено, не доказано». Теорема
автора не помогает: `по свойству «лемма»` сличает лемму с целью случая до развёртки.

## Шаги воспроизведения

1. Программа `flang/proof/probes/lean-parity-gaps/programs/lemma-in-an-induction-step.flang`:

```flang
модуль «Лемма в шаге индукции»

тип «Нат»
  вариант «Ноль»
  вариант «После» содержит пред: «Нат»

тотальная функция «Сумма»
  принимает первое: «Нат», второе: «Нат»
  возвращает «Нат»
  пример «ноль и ноль»
    дано первое равно вариант «Ноль»
    дано второе равно вариант «Ноль»
    ожидается вариант «Ноль»
  разбор первое
    случай вариант «Ноль»
      то второе
    случай вариант «После» с пред как п
      то вариант «После» с пред равным («Сумма» от п и второе)

утверждение «ноль справа нейтрален»
  для всех н: «Нат»
  утверждаем («Сумма» от н и (вариант «Ноль»)) равен н

утверждение «следующий выносится из второго слагаемого»
  для всех н: «Нат» и м: «Нат»
  утверждаем («Сумма» от н и (вариант «После» с пред равным м)) равен (вариант «После» с пред равным («Сумма» от н и м))

утверждение «сложение перестановочно»
  для всех н: «Нат» и м: «Нат»
  утверждаем («Сумма» от н и м) равен («Сумма» от м и н)
```

2. `bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/lemma-in-an-induction-step.flang --proof --strict; echo $?`
3. Смотреть вердикт третьего утверждения и код возврата.

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/lean-parity-gaps/programs/lemma-in-an-induction-step.flang --proof --strict
  утверждение «ноль справа нейтрален» — доказано индукцией по «Нат»: база 1 случай, шаг при допущении на частях (1 случай) …
  утверждение «следующий выносится из второго слагаемого» — доказано индукцией по «Нат»: база 1 случай, шаг при допущении на частях (1 случай) …
  утверждение «сложение перестановочно» — объявлено, не доказано: ни теоремы, ни примеров …
… НЕ УДАЛОСЬ ДОКАЗАТЬ — ОБЪЯВЛЕНО, НЕ ДОКАЗАНО — утверждений 3: доказано 2 …                код 3
```

С теоремой автора (`flang/proof/parity/programs/peano-plus-commutative-by-hand.flang`):

```
FLANG_PROOF_STEP … шаг 2, шаг «После» теоремы «сложение перестановочно»: утверждение «следующий
выносится из второго слагаемого» к этому месту не прикладывается: цель места не получается из цели
утверждения подстановкой его переменных («н», «м»). Ядро подставляет, а не ищет …        код 1
```

Версия: flang 0.7.34 (`bootstrap/flang` из дерева, метка v0.7.34).

## Что должно быть

В шаге (и в базе) индукции после развёртки вызовов на конструкторе цель переписывается
слева направо доказанными равенствами-утверждениями того же файла и ввезённых модулей,
затем допущением индукции, затем сводится обычными правилами. Порядок: развёртка, леммы,
допущение, кольцо и линейная арифметика. Запас переписки — тот же, что у Переп1 (64 шага).
Запись называет применённое утверждение и подстановку, оба сверщика переигрывают ход.

Это то, что в Lean делает `simp [f, lemma, ih]`. Постусловие вызванной функции в том же
месте уже переписывает цель (Переп2): `flang/proof/probes/lean-parity-gaps/programs/rewrite-by-callee-postcondition.flang` — код 0.

Какое правило и где встанет. В `flang/self/proof-kernel.flang` — рядом с «Равенство
берётся перепиской» (строка 7571, Переп1) и «Постусловие берётся перепиской» (строка 7587,
Переп2): новая функция, которая применяет те же правила переписки к посылке индукции. Зов —
в `flang/self/proofterm.flang`, «Свести посылку» (строка 822): сегодня посылка сводится
без списка доказанных утверждений, а «Утверждение переписывает» (строка 4958) зовётся только
для цели без индукции. В `flang/proof/tables/inference-rules.tsv` — строка `Переп3` семьи
`Тожд` после `ПерепШ`, kernel-rule «переписка доказанными равенствами», и строка запрета на
лемму, которая не доказана к этому месту (подделка: шаг по недоказанной лемме даёт
«условно», не «доказано»).

## Обходной путь

Записать лемму постусловием функции, которую зовёт шаг, а само свойство — постусловием
рекурсивной функции: `flang/stdlib/list-facts.flang`, «Дописать» и «Развернуть ряд».
Для перестановочности сложения обхода нет.

## Когда задача сделана

`bootstrap/flang run-script lean-parity:gaps` краснеет на строке
`lemma-in-an-induction-step.flang` («утверждений 3: доказано 3», код 0), строку правят.
В `flang/proof/parity/corpus.tsv` задачи `peano-plus-commutative` и
`sort-insert-keeps-sorted` переходят из `none`, а `list-length-reverse`,
`list-count-reverse-permutation`, `list-rewrite-user-lemma`, `list-flatten-length`,
`tree-flatten-length`, `sort-insert-length` — из `by-hand` в `auto`.

## Где живёт правка

`flang/self/proof-kernel.flang`, `flang/self/proofterm.flang`,
`flang/proof/tables/inference-rules.tsv`, оба сверщика (`flang/proof/checker`). Требует
печати семени.
