# 9337. Ответы проверяющей программы на файлах библиотеки целиком не сняты, и неизвестно, остался ли код 1 на честном файле

Ядро (`flang check --proof`) печатает запись доказательства (`--record`).
Отдельная программа на C (`flang/proof/checker/checker.c`) перечитывает запись
и отвечает: 0 — проверила сама, 3 — не взялась, место оставлено на слове ядра,
1 — нашла ложь. Ложный код 1 на `flang/stdlib/optional.flang` и на индукции по
типу с параметром снят. Остальная библиотека после этого целиком не мерилась.

## Шаги воспроизведения

1. `make -C flang/proof/checker`
2. `bootstrap/flang check flang/stdlib/stats.flang --proof --record stats.record`
3. `bootstrap/flang check flang/stdlib/lists.flang --proof --record lists.record`
4. `flang/proof/checker/сверщик flang/stdlib/stats.flang stats.record`
5. `flang/proof/checker/сверщик --зависимость flang/stdlib/lists.flang lists.record flang/stdlib/stats.flang stats.record`

## Что происходит

```
$ сверщик flang/stdlib/stats.flang stats.record
НЕ СОШЛОСЬ: тотальность «Среднее»: «Сумма» не примитив и не имеет блока тотальности НИ в записи, НИ в поданном наборе — тотальность зовомого не доказана; …   код 1
$ сверщик --зависимость flang/stdlib/lists.flang lists.record flang/stdlib/stats.flang stats.record
НЕ ВЗЯЛСЯ (строк причин 14; мест на слово ядра 14): …                                     код 3
```

Ядро на обоих файлах отвечает кодом 0. Без записи ввезённого модуля проверяющая
программа отвечает кодом 1, с ней — кодом 3. На `optional.flang`,
`math-classics-lists.flang`, `lists.flang`, `registry.flang` ответ сегодня — код 3.
Файлы `hmac.flang` и `crl.flang` ядро за минуту не прошло, записи нет.

Версия: flang 0.7.23, 30 сентября 2026. Снято шесть файлов из 51.

Не перепроверено: на прежнем замере код 1 давали ещё `dns.flang` («тело зовёт,
а запись молчит»), `redis.flang` и `hmac.flang` (объявление типа довода),
`http.flang` (развёртка), `crl.flang`.

## Что должно быть

Честная запись ядра получает код 0 или код 3 с названной причиной, не код 1
(три исхода описаны в `flang/proof/checker/README.md`). Ни одна подделка из
набора при этом не уходит кодом 0.

## Обходной путь

Модулю, который ввозит другой, подавать запись ввезённого ключом `--зависимость`.

## Когда задача сделана

1. Для каждого из 51 файла `flang/stdlib/*.flang` сняты код ядра и код
   проверяющей программы, запущенной с записями ввезённых модулей.
2. Каждый код 1 разобран: настоящее расхождение ядра и записи заведено своей
   задачей, ложное обвинение починено и закреплено пробой в
   `flang/proof/checker/tests/run.sh`.
3. `sh flang/proof/checker/tests/run.sh` отвечает «сошлось всё»: ни одна
   подделка не принята кодом 0, ни одна честная запись не отвергнута.
4. Записано решение владельца: входят ли файлы библиотеки в набор, по которому
   считается доля проверенного.

Починка, после которой проверяющая программа отвечает 0 или 3 на подделку, —
снятие проверки, а не починка.

## Где живёт правка

`flang/proof/checker/checker.c`; пробы — `flang/proof/checker/tests/`; потолок
строк — `flang/proof/checker/ratchet.txt`; счёт подделок —
`flang/proof/forgeries/ratchet.txt`. Ядро и самосборная часть не затрагиваются,
перепечатка не нужна.
