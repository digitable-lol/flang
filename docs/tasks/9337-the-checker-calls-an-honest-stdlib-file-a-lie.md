# 9337. Честный файл библиотеки объявлен ложью

## Чем измерено

19 сентября 2026, ствол `b47e0f09c`, двоичный 0.7.20, сверщик собран из своего
исходника.

```
bootstrap/flang check flang/stdlib/optional.flang --proof --записать opt.запись   → код 0
flang/proof/checker/сверщик flang/stdlib/optional.flang opt.запись                  → НЕ СОШЛОСЬ
  теорема «у непустой опции значение есть», посылка «Нет»: закрыта сведением,
  а случая на вариант «Нет» в записи нет
```

Код 1 у сверщика значит НЕ «не смог проверить», а «нашёл противоречие» — то
есть обвинение. Файл при этом честный: он лежит в библиотеке дерева и проходит
ядро кодом 0.

Замер двадцати трёх программ с объявленными типами (задача 2748) нашёл ту же
беду ещё дважды, на законных формах языка:

| форма | ядро | сверщик |
|---|---|---|
| краткая запись случая `случай «Имя»` вместо `случай вариант «Имя»` | код 0 | **НЕ СОШЛОСЬ** |
| индукция по типу с параметром (`тип «Коробка» от «Т»`) | код 0 | **НЕ СОШЛОСЬ** |

## Почему это важнее, чем «место на слове ядра»

У сверщика три исхода, и они не равны:

* **код 0** — переиграл, сошлось;
* **код 3** — не взялся, место названо и уходит на слово ядра. Честно;
* **код 1** — НАШЁЛ ЛОЖЬ.

Долю корпуса считают по второму и третьему. Первый — приговор. Сверщик,
который объявляет ложью честную библиотеку, обесценивает и те 650 мест, где он
сказал «сошлось»: нельзя доверять судье, который не отличает «не проверил» от
«поймал».

Та же порода, что в задаче [4416](4416-the-checker-rejects-an-honest-instantiation-proof.md),
где доказано прогоном: честная корпусная запись с ПЕРЕСТАВЛЕННЫМИ блоками тоже
получает код 1.

## Что это говорит о 100 %

Доля 650 / 650 снята по набору записей корпуса
(`flang/proof/map/`, `flang/proof/examples/`, часть библиотеки). `optional.flang`
в этот набор не входит. Значит 100 % — не «вся библиотека переиграна», а «набор
переигран», и граница набора проходит по живым файлам дерева.

## Что сделать

1. Развести в сверщике «не взялся» и «поймал ложь» на этих трёх формах: краткая
   запись случая, индукция по типу с параметром, посылка, закрытая сведением без
   своего случая. Пока приёма нет — обязан быть код 3, а не 1.
2. Завести пробы: `optional.flang` с его записью ждёт код 3 (сегодня даёт 1);
   после появления приёма — код 0.
3. Померить, сколько ещё файлов `flang/stdlib/**` сверщик объявляет ложью:
   прогнать все, у кого есть `обеспечивает`, и назвать числом.
4. Решить, входят ли файлы библиотеки в набор доли — и если да, пересчитать долю.

## Фальсификатор

Починка, после которой сверщик отвечает 0 или 3 на ПОДДЕЛКУ, — снятие проверки,
а не починка. Набор подделок обязан остаться отвергнутым целиком.
