# 9408. Проверка «пустота:проверка» красная — девять файлов библиотеки не названы ни в одном из двух её списков

## Шаги воспроизведения

1. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script emptiness:check`

Версия: flang 0.7.23, 30 сентября 2026. В `flang/stdlib/` 51 файл.

## Что должно быть

Проверка отвечает кодом 0. Новый файл библиотеки не делает её красной сам по
себе: перечень файлов берётся из каталога `flang/stdlib/`, а руками ведётся
только список отложенных с названной причиной.

## Обходной путь

Нет.

## Когда задача сделана

```sh
FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script emptiness:check
sh scripts/guards/hand-written-lists.sh
```

Первая команда отвечает кодом 0; вторая показывает, что рукописный перечень не
вырос. Если рукописные списки остаются, девять файлов вписаны в «Отложенные» с
причиной, и в задаче сказано, почему перечень нельзя взять из каталога.

## Где живёт правка

`flang/scripts/emptiness-guard.fscript`: функции «Наши файлы» (строка 454) и
«Отложенные» (строка 459). Скрипт исполняется через `flang io`, перепечатка не
нужна.
