# 9408. Сторож пустоты красный — одиннадцать файлов библиотеки не названы ни в одном из двух его списков, а двенадцатой жалобой идёт `profiles.flangrc`

## Шаги воспроизведения

1. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script emptiness:check`
2. `ls flang/stdlib/*.flang | wc -l`

## Что происходит

```

                                                                          код 1
$ ls flang/stdlib/*.flang | wc -l
53
```

В `flang/stdlib/` 53 файла `.flang`. «Наши файлы» называют 26 имён,
«Отложенные» — 16, итого 42; не названы одиннадцать.

Двенадцатая жалоба — не про файл библиотеки вовсе: `flang/stdlib/profiles.flangrc`
попадает в разбор, потому что «Незваные» отбирают имя правилом
`имя содержит ".flang"`, а не «кончается на `.flang`».

Версия: flang 0.7.23.

## Что должно быть

Проверка отвечает кодом 0. Новый файл библиотеки не делает её красной сам по
себе: перечень файлов берётся из каталога `flang/stdlib/`, а руками ведётся
только список отложенных с названной причиной. Имя, в котором `.flang` стоит не
на конце, файлом библиотеки не считается.

## Обходной путь

Нет.

## Когда задача сделана

1. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script emptiness:check` отвечает
   кодом 0, и `profiles.flangrc` ни в одной строке жалобы не назван.
2. Отрицательный контроль на пропажу: имя, названное в «Наших», у которого файла
   в каталоге нет, даёт код 1 строкой «файл назван в «Наших», а в каталоге его
   нет». Без него проверка перестала бы различать.
3. Либо перечень взят из каталога — и тогда
   `cp flang/stdlib/logic.flang flang/stdlib/zzz-probe.flang` кода 0 не меняет
   (файл после прогона убрать); либо рукописные списки остаются — и тогда
   одиннадцать файлов вписаны в «Отложенные» с причиной, постусловия «длина
   постоянного списка …» пересчитаны, и в задаче сказано, почему перечень нельзя
   взять из каталога.

## Где живёт правка

`flang/scripts/emptiness-guard.fscript`: «Наши файлы» (строка 457, постусловие
«длина … равен 26»), «Отложенные» (строка 465, постусловие «длина … равен 16»),
«Незваные» (строка 478 — правило отбора имени) и «Пропавшие» (строка 486); у двух
последних примеры повторяют перечень дословно и правятся вместе со списком.
Скрипт исполняется через `flang io`, перепечатка не нужна.
