# 9448. Модуль, имя которого начинается с цифры, печатается в C, который не собирается

## Шаги воспроизведения

1. Программа `seven.flang`:

```
модуль «7 up»

функция «Удвоить»
  принимает x: число
  возвращает число
  x плюс x
```

2. Команды:

```
bootstrap/flang check seven.flang
bootstrap/flang emit seven.flang --target c --out out
cd out && cc -std=c99 -O2 -o run *.c -lm -lpthread
```

3. Смотреть: `check` и `emit` отвечают кодом 0, `cc` — ошибкой.

## Что происходит

```
$ cc -std=c99 -O2 -o run *.c -lm -lpthread
In file included from 7_up.c:9:
7_up.h:9:9: error: macro names must be identifiers
    9 | #ifndef 7_UP_H                                  код 1
```

Печать берёт имя модуля началом имён C: сторож заголовка `7_UP_H`, функции `7_up_udvoit`,
дверь `7_up_call`. Имя C с цифры начинаться не может. В корпусе так не собираются
`docs/examples/rosetta/hundred-doors.flang` и `hundred-doors-english.flang` (модуль «100 doors»,
18 функций): проверка перевода говорит о них «не собрано».

Версия: flang 0.7.34.

## Что должно быть

Программа, которую приняла `check`, печатается в C, который собирает `cc -std=c99`
(`docs/translation-validation.ru.md`, шаг 2 прогона). Имя модуля с цифры получает в C
допустимое начало — одно правило для сторожа заголовка, имён функций и двери `_call`.

## Обходной путь

Назвать модуль с буквы.

## Когда задача сделана

`bootstrap/flang run-script translation:validate -- --path docs/examples/rosetta/hundred-doors.flang`
не называет файл среди «не напечатано или не собрано», и его функции стоят в счёте
«СООТВЕТСТВИЕ ПРОВЕРЕНО». Проба: программа выше печатается и собирается.

## Где живёт правка

`flang/self/emit-c.flang` — имя модуля в именах C. Правка под `flang/self` доезжает до
двоичного перепечаткой самосборной части.
