# 9449. Замеры, на которых держатся решения, стоят без примет и тухнут молча

## Шаги воспроизведения

1. Сосчитать решения, которые ссылаются на замер, и решения с приметой:

   ```sh
   git ls-files docs/adr/*.md | wc -l
   git grep -li 'замер' -- docs/adr/ | wc -l
   git grep -l 'СНЯТО' -- docs/adr/ | wc -l
   ```

2. Взять опорное число любого решения и перемерить его прибором. Например ADR-0036 говорит,
   что теорем 284 и ни одна не связывает `целое`:

   ```sh
   grep -rhc '^теорема ' --include='*.flang' . | awk '{s+=$1} END {print s}'
   grep -rn -A6 '^теорема ' --include='*.flang' . | grep -E 'дано [^:]+: целое'
   ```

3. Сверить ответ прогона с тем, что написано в решении.

## Что происходит

```
$ git ls-files docs/adr/*.md | wc -l            53
$ git grep -li 'замер' -- docs/adr/ | wc -l     49
$ git grep -l 'СНЯТО' -- docs/adr/ | wc -l       4

$ grep -rhc '^теорема ' --include='*.flang' . | awk '{s+=$1} END {print s}'
354
$ grep -rn -A6 '^теорема ' --include='*.flang' . | grep -E 'дано [^:]+: целое'
flang/proof/checker/tests/families/hypothesis/type-does-not-carry-the-hypothesis.flang-13-  дано н: целое
```

Сорок девять решений из пятидесяти трёх держатся на замере, а примету несут **четыре**: сторож
прозы судит только помеченные числа, значит сорок пять решений он не судит вовсе. Довод ADR-0036
«теорем 284, и ни одна не связывает `целое`» сегодня не воспроизводится: теорем **354**, и одна
связывает — проба сверщика, заведённая 1 октября 2026, через две с лишним недели после замера.

Версия: `flang 0.7.23`. Прогон 2 октября 2026.

## Что должно быть

Опорное число решения стоит с приметой, и сторож прозы его судит — так же, как судит числа
задач и страниц. Решение, чей довод перестал воспроизводиться, краснеет при следующем прогоне,
а не обнаруживается случайно через три недели.

## Обходной путь

Перемерять опорные числа руками при каждом обращении к решению. Обход работает, но его никто не
обещал: за три недели никто не перемерил ни одного.

## Когда задача сделана

У каждого решения, которое ссылается на замер, стоит примета с датой и прибором (или названа
причина, по которой числа у него нет), `prose-numbers-guard` считает `docs/adr/` своей областью (задача 2235 про то же в прозе страниц,
пока лежит в заявке),
и подлог числа в любом решении краснеет поимённо.

## Где живёт правка

`docs/adr/*.md` — приметы; `scripts/guards/prose-numbers-guard.fscript` — область поиска;
перепечатки не требует.
