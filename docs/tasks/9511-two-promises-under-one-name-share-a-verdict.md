# 9511. Два обещания под одним именем делят вердикт

## Шаги воспроизведения

1. Программа `flang/proof/probes/typing-holes/programs/two-promises-under-one-name.flang`:

```flang
модуль «Два обещания с одним именем»

тотальная функция «Почти ноль»
  принимает х: неотрицательное
  возвращает число
  обеспечивает «итог назван» результат не меньше 0
  обеспечивает «итог назван» результат равен 0
  если х равен 1234567 то 1 иначе («Ноль» от х)

тотальная функция «Ноль»
  принимает х: неотрицательное
  возвращает число
  0

тотальная функция «Через почти ноль»
  принимает х: неотрицательное
  возвращает число
  обеспечивает «итог ноль» результат равен 0
  «Почти ноль» от х
```

2. `bootstrap/flang check flang/proof/probes/typing-holes/programs/two-promises-under-one-name.flang --proof`
3. `bootstrap/flang run flang/proof/probes/typing-holes/programs/two-promises-under-one-name.flang --function 'Через почти ноль' --args '{"х":1234567}'`

## Что происходит

```
$ bootstrap/flang check flang/proof/probes/typing-holes/programs/two-promises-under-one-name.flang --proof
… ПРОВЕРЕНО САМОСТОЯТЕЛЬНО — … доказано
$ bootstrap/flang run flang/proof/probes/typing-holes/programs/two-promises-under-one-name.flang --function 'Через почти ноль' --args '{"х":1234567}'
FLANG_PROPERTY: нарушено свойство «итог назван» функции «Почти ноль»                                  код 1
```

Версия: flang 0.7.34.

У функции два `обеспечивает «итог назван»`: верное `результат не меньше 0` и ложное `результат равен 0`. Ведомость
печатает оба с одним вердиктом, а вызывающая берёт ложное фактом («Ключ факта», «Постусловие по имени»,
«Утверждение по имени» в `flang/self/proofterm.flang` — по владельцу и имени). То же у двух `утверждение` с одним
именем и у закона интерфейса, чьё порождённое имя совпало с именем обещания метода.

## Что должно быть

Повтор имени обещания у функции и повтор имени утверждения — отказ проверки; разворот сахара отвергает имя,
совпавшее с порождённым.

## Обходной путь

Обхода нет: утверждение числится доказанным, и запуск идёт без согласия на недоказанное.

## Когда задача сделана

`bootstrap/flang check flang/proof/probes/typing-holes/programs/two-promises-under-one-name.flang --proof` не числит ложное утверждение доказанным.
Проба — строки этой программы в `flang/proof/probes/typing-holes/expected.tsv`
и строка ведомости `flang/proof/tables/typing-holes.tsv`: сегодня они держат ответ
двоичного 0.7.34, после правки строка `proof` меняется, строка ведомости — на `закрыта`.

## Где живёт правка

`flang/self/obligations.flang` рядом с «Беды одного имени», `flang/self/proofterm.flang`, `flang/self/sugar.flang`.
Правки в этой ветке нет. Требует печати семени.
