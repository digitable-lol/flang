# 9528. Обещание с меткой «en:» не сверяется с обещанием, которое оно переводит, и спецификация об этом молчит

В проектах на flang принят приём: рядом с обещанием ставят второе, с именем,
начатым меткой языка `en:`, чтобы английский читатель видел то же обещание
своими словами. Для компилятора метка — часть имени, и оба обещания независимы.

## Шаги воспроизведения

1. Файл-проба en.flang:

   ```
   тотальная функция «Смещение»
     принимает «х»: число
     возвращает число
     обеспечивает «смещение не отрицательно» результат не меньше 0
     обеспечивает «en: offset is not negative» результат не меньше -5
     если «х» меньше 0
       то 0
       иначе «х»
   ```

2. `bootstrap/flang check en.flang`
3. `grep -c 'en:' docs/flang/SPEC.md`

## Что происходит

```
$ bootstrap/flang check en.flang
en.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет     код 0
$ grep -c 'en:' docs/flang/SPEC.md
0                                                                                    код 1
```

Перевод слабее основного обещания (граница -5 вместо 0), и компилятор молчит.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Одно из двух:

1. компилятор знает метку языка и сверяет цель такого обещания с целью
   обещания, рядом с которым оно стоит; расхождение — диагностика с названным
   кодом;
2. в `docs/flang/SPEC.md` прямо сказано, что метка `en:` — часть имени и связи
   между обещаниями язык не устанавливает; каждый проект проверяет пары сам.

## Обходной путь

Своя проверка пар в проекте: сличать цели соседних обещаний текстом.

## Когда задача сделана

По первому пути: `bootstrap/flang check en.flang` отвечает кодом 1 и называет
расхождение; та же проба с равными границами — код 0. По второму пути:
`grep -c 'en:' docs/flang/SPEC.md` больше нуля, и абзац говорит, что метка —
часть имени.

## Где живёт правка

Первый путь: проверка обещаний в самосборной части (`flang/self/**`), точное
место не определено; нужна перепечатка. Второй путь: `docs/flang/SPEC.md`,
раздел об `обеспечивает`.
