# 9612. Ядро печатает шаг записи без терма рядом с номером строки, и сверять терм с исходником проверяющей программе не на чем

Шаг в записи доказательства может нести номер строки исходника и терм в
⟨уголках⟩ — само утверждение шага. Проверяющая программа на C сверяет их друг
против друга, когда оба стоят рядом. Ядро в строке шага печатает только номер.

## Шаги воспроизведения

1. `make -C flang/proof/checker`
2. `bootstrap/flang check flang/proof/examples/stack.flang --proof --record stack.record`
3. `grep -n ' шаг 1 строка' stack.record`
4. `flang/proof/checker/сверщик flang/proof/examples/stack.flang stack.record`

## Что происходит

```
$ grep -n ' шаг 1 строка' stack.record
19:    шаг 1 строка 25 закрывающий по примеру «у пустой стопки высоты нет» пример строка 11
21:    шаг 1 строка 27 закрывающий по предположению
50:    шаг 1 строка 48 закрывающий по примеру «копия пустой пуста» пример строка 34
52:    шаг 1 строка 50 закрывающий по предположению
$ сверщик flang/proof/examples/stack.flang stack.record
ПРОВЕРЕНО — запись сошлась с исходником, и всё доказанное проиграно заново:
утверждений 2, шагов сверено с исходником 4 … Шагов по примеру проверено по
существу 2. … Мест, сверенных ОБОИМИ свидетелями (термин и номер строки), 0.
…                                                                      код 0
```

Ни в одной из четырёх строк уголков нет, и счёт мест, сверенных обоими
свидетелями, — 0 при четырёх сверенных шагах.

Версия: flang 0.7.23, 3 октября 2026.

Вторая проверяющая программа, `flang/proof/checker.flang`, ветку «терм рядом с
номером» не получила: «Сверить шаг с привязкой» (строка 688) зовёт «Сверить
термин шага без номера» (строка 640) только тогда, когда номера строки у шага
НЕТ, — при номере терм не читается вовсе. Счёта «мест, сверенных обоими
свидетелями» в ней нет.

## Что должно быть

Строка шага несёт терм рядом с номером: номер привязывает шаг к строке
исходника, терм говорит, что именно там утверждается, и проверяющая программа
сверяет одно с другим. Расхождение — код 1 с названными местом, строкой, термом
и текстом исходника. Терм вместо номера не годится: такой шаг проверяется
меньше.

## Обходной путь

Нет.

## Когда задача сделана

1. Шаги 2–4 на `flang/proof/examples/stack.flang`: число «мест, сверенных обоими
   свидетелями» больше нуля, код 0.
2. Порча терма шага в записи (например, «по предположению» на «по свойству
   сложения») даёт код 1 с номером строки и обоими текстами.
3. `bootstrap/flang run-script checker:check` отвечает «сошлось всё».
4. Ответы обеих проверяющих программ на записях `flang/proof/examples` до и
   после правки сличены: на записях прежнего вида они не изменились.
5. `flang/proof/checker.flang` на записи нового вида отвечает так же, как
   программа на C, и называет то же число мест, сверенных обоими свидетелями.

## Где живёт правка

`flang/self/proof-record.flang`, функция «Строка шага записи» (строка 261) и её
примеры; правка доезжает до двоичного перепечаткой. Чтение нового вида в
`flang/proof/checker/checker.c` уже есть: `сверить_терм_и_номер` (строка 1826)
сличает терм с текстом названной строки и двигает счёт `сверено_обоими`, и шаг
через него уже проходит (строка 3729). `flang/proof/checker.flang` — завести ту
же ветвь при номере («Сверить шаг с привязкой», строка 688).
