# 9617. Сверка дерева разбора с исходником есть только прототипом на Python, и разбор остаётся в доверенной базе

Кругооборот «разбор → печать → разбор» сравнивает два дерева и на исходный
текст не смотрит, поэтому ошибку разборщика он не ловит. Поймать её может
только сверка мест узлов дерева с текстом исходника.

## Шаги воспроизведения

1. `ls flang/proof/binding/`
2. `grep -c 'binding.py' ярлыки.flang`
3. `bootstrap/flang ast flang/stdlib/optional.flang > optional.json`
4. `python3 flang/proof/binding/binding.py optional.json=flang/stdlib/optional.flang`
5. `bootstrap/flang emit flang/stdlib/optional.flang --target flang --out out`

## Что происходит

```
$ ls flang/proof/binding/
binding-by-file.py  binding.py  cycle.py  parse-cycle.fscript
$ grep -c 'binding.py' ярлыки.flang
0                                                                   код 1
$ python3 flang/proof/binding/binding.py optional.json=flang/stdlib/optional.flang
optional.flang  если: сошлось 1 разошлось 0 | в строку 5 | или/и-притом: сошлось 14 разошлось 0 | не: сошлось 6 разошлось 0 | не опознано 0
СОШЛОСЬ = 21 (100.0%)  РАЗОШЛОСЬ = 0  НЕ ОПОЗНАНО = 0
$ bootstrap/flang emit flang/stdlib/optional.flang --target flang --out out
flang emit: цели «flang» у этой сборки flang нет                     код 2
```

Сверка написана на Python, ярлыком не зовётся и в проверяющий
`flang/proof/checker/checker.c` не входит. «Если», записанные в одну строку
(здесь 5 из 6), она не сверяет вовсе: их привязку держат только скобки.
Печати из дерева разбора обратно в текст flang в дереве нет.

Записано прежним прогоном и не перепроверено (печатника в дереве нет): при
перестановке ветвей «то» и «иначе» в исходнике кругооборот сходится, то есть
подделку не видит.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

Сверка дерева разбора с исходником написана на flang, зовётся ярлыком и
краснеет на подделке. Она называет покрытие числом: сколько узлов ветвления
сверено с текстом и сколько оставлено без сверки. Пока покрытие неполное,
`docs/what-blocks-1-0.md` называет разбор частью доверенной базы и не выдаёт
результат кругооборота за ответ на гейт Г5.

## Обходной путь

Нет: разбору верят.

## Когда задача сделана

1. Сверка переписана с `flang/proof/binding/binding.py` на `.fscript` и стоит
   ярлыком в `ярлыки.flang`.
2. Проба-подделка: в копии исходника переставлены ветви «то» и «иначе»
   многострочного «если», дерево взято от исходного файла — сверка отвечает
   кодом 1 и называет строку.
3. Прогон по `flang/self/parser.flang` и по остальным файлам `flang/self`
   печатает покрытие; «если» в одну строку либо сверяются, либо названы числом
   как несверенные.
4. `docs/what-blocks-1-0.md` в разделе о гейте Г5 называет это число и то, что
   остаётся на веру.

## Где живёт правка

`flang/proof/binding/` (новый `.fscript` рядом с `parse-cycle.fscript`),
`ярлыки.flang`, `docs/what-blocks-1-0.md`. Перепечатка не нужна. Прибор
кругооборота и его числа — задача 1307.
