# 9622. Перепечатка кладёт семя в дерево файл за файлом, и обрыв оставляет в bootstrap смесь старого и нового

## Шаги воспроизведения

1. `grep -n 'cp "\$TMP/\$name"' scripts/bootstrap-reprint.sh`
2. `grep -c '^ *mv ' scripts/bootstrap-reprint.sh`
3. `grep -n '^stamp_now' scripts/bootstrap-reprint.sh`
4. `grep -n '^KEEP=\|^ *KEEP=yes\|^trap cleanup' scripts/bootstrap-reprint.sh`

## Что происходит

```
$ grep -n 'cp "\$TMP/\$name"' scripts/bootstrap-reprint.sh
3556:  cp "$TMP/$name" "$ROOT/$DIR/$name"
$ grep -c '^ *mv ' scripts/bootstrap-reprint.sh
0                                                                   код 1
$ grep -n '^stamp_now' scripts/bootstrap-reprint.sh
3583:stamp_now "$ROOT" "$KOMMIT" > "$ROOT/$SEED_STAMP"
$ grep -n '^KEEP=\|^ *KEEP=yes\|^trap cleanup' scripts/bootstrap-reprint.sh
3437:KEEP=no
3445:trap cleanup EXIT INT TERM
3534:  KEEP=yes
3541:  KEEP=yes
```

Три следствия:

1. Укладка пишет файлы на место по одному, без временного имени и без `mv`.
   Обрыв внутри цикла оставляет в `bootstrap/` часть файлов нового семени и
   часть старого; такое дерево собирается в двоичный, которого никто не
   проверял.
2. Отпечаток `scripts/seed-fingerprint` пишется после укладки: смешанное дерево
   несёт отпечаток прежнего коммита.
3. Готовое семя от конца печати до конца укладки лежит только во временном
   каталоге, а ловушка `cleanup` его стирает (`KEEP=yes` ставится лишь на путях
   отказа). Сигнал `TERM` в это окно стирает многочасовую печать.

Версия: flang 0.7.23, 30 сентября 2026. Сам обрыв не воспроизводился: не
перепроверено.

## Что должно быть

Длинные стадии и сегодня пишут только во временный каталог, и напечатанное
собирается и опрашивается до укладки — это сохраняется. Сама укладка видна
дереву либо целиком, либо никак, а готовое семя переживает обрыв.

## Обходной путь

Не прерывать перепечатку после строки «напечатанное собрано»; при обрыве
вернуть каталог командой `git checkout -- bootstrap scripts/seed-fingerprint`.

## Когда задача сделана

1. Каждый файл кладётся под временным именем в том же каталоге и
   переименовывается `mv`; в `bootstrap/` после обрыва нет файла нового семени
   рядом со старым.
2. Готовое семя до укладки сохраняется вне каталога, который стирает
   `cleanup`, либо `KEEP=yes` ставится сразу после успешной сборки и опроса.
3. Отпечаток пишется до укладки или вместе с ней.
4. Проба: перепечатка на малом входе, прерванная сигналом `TERM` во время
   укладки, оставляет `git status --short bootstrap` пустым или полным, но не
   частичным, и готовое семя на диске.

## Где живёт правка

`scripts/bootstrap-reprint.sh`: цикл укладки `for name in $PRINTED`, функция
`cleanup`, вызов `stamp_now`. Перепечатка для самой правки не нужна.
