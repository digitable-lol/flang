# 9674. Checker называет ложью шаг «дно суммы» за точным потолком

## Шаги воспроизведения

1. Программа `sum.flang`:

```flang
модуль «Probe»

тотальная функция «Ф»
  принимает н: неотрицательное
  возвращает число
  обеспечивает «за потолком» результат больше 9007199254740991
  9007199254740991 плюс 2
```

2. `bootstrap/flang check sum.flang --proof --strict --record sum.rec`, затем
   `flang/proof/checker/сверщик sum.flang sum.rec`.
3. Смотреть коды возврата и сообщение.

## Что происходит

```
$ bootstrap/flang check sum.flang --proof --strict --record sum.rec
sum.flang: ДОКАЗАНО — утверждений 1: доказано 1, … — код возврата 0           код 0
$ flang/proof/checker/сверщик sum.flang sum.rec
НЕ СОШЛОСЬ: утверждение «за потолком», вывод: шаг 3: Д3 — заявлено дно
«9007199254740992», а сумма написанных дон 9007199254740991 и 2 есть
9007199254740992                                                          код 1
$ bootstrap/flang run sum.flang --function '«Ф»' --args '{"н":0}' --trust
9007199254740992                                                          код 0
```

Версия: flang 0.7.25, checker собран из `flang/proof/checker/checker.c` того же
дерева.

Утверждение верно: `9007199254740991 плюс 2` даёт 9007199254740992. Шаг ядра
тоже верен: точная сумма не меньше суммы доньев, а округление к ближайшему
монотонно. Checker сверяет Д3 и Д5 только до 2⁵³−1 (`checker.c`, ветки «Д3» и
«Д5») и за этой границей отвечает кодом 1, печатая заявленное дно и сумму одним
и тем же числом.

## Что должно быть

За точным потолком checker либо сверяет дно с округлённой суммой (тем же
`double`, что считает ядро), либо отвечает кодом 3 «не взялся» с сообщением,
что сумма неточна. Код 1 — только когда заявленное дно больше округлённой суммы.

## Обходной путь

Нет.

## Когда задача сделана

`сверщик sum.flang sum.rec` отвечает кодом 0 или 3. Опровергатель перестаёт
находить причину `checker-calls-it-a-lie/НЕ СОШЛОСЬ: утверждение «…», вывод: шаг N: Д3`,
и её строка уходит из `flang/proof/probes/falsifier/expected-failures.tsv`.

## Где живёт правка

`flang/proof/checker/checker.c`, проверка шагов Д3 и Д5. Двоичный компилятора не
затрагивается.
