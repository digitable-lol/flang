# 9790. Замер «сколько-верим» красный: рукописный рантайм на C вырос на 409 строк сверх записанного потолка

Замер всего пути доверия написан и стоит ярлыком `сколько-верим`: одно число,
разбивка по кучам, потолок в `flang/scripts/lines-to-trust-ceiling.json`,
который ползёт только вниз. Открыто то, что он показывает сегодня.

## Шаги воспроизведения

1. `bootstrap/flang run-script trust:ceiling`
2. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script trust:ceiling`

## Что происходит

```
$ bootstrap/flang run-script trust:ceiling
СЕМЯ СВЕРИТЬ НЕ УДАЛОСЬ — судить о доказательствах нельзя: ярлык «сколько-верим» …
ОТПЕЧАТОК СНЯТ С ПРАВЛЕНОГО ДЕРЕВА.                                              код 3
$ FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script trust:ceiling
  ОДНО ЧИСЛО, читая исходники и веря печати:        84951
  ОНО ЖЕ, не веря печати, а читая напечатанное:     598834
  …
  3 рукописный рантайм на C                 20012   файлов 4, уезжают в печать дословно
  …
ВЕРИТЬ ПРИХОДИТСЯ БОЛЬШЕМУ, ЧЕМ ВЧЕРА:
  • runtimeCode: было 19603, стало 20012 (+409)
  • printedCCode: было 598425, стало 598834 (+409)                               код 1
```

Первый отказ (код 3) — предмет задачи 8567. Второй — рост четырёх файлов
рантайма в `flang/src/emit/c`, которые уезжают в напечатанное семя дословно.

Версия: flang 0.7.23, 30 сентября 2026.

## Что должно быть

`bootstrap/flang run-script trust:ceiling` отвечает кодом 0: каждая куча не больше своего потолка.
Рост кучи либо снят, либо записан в потолок вместе с доводом, почему строк,
которым приходится верить, стало больше.

## Обходной путь

Нет.

## Когда задача сделана

1. Названо, какая правка рантайма дала 409 строк, и решено одно из двух: строки
   убраны, либо потолок переписан планом «Переписать потолок всего пути» и
   довод роста записан в коммите.
2. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script trust:ceiling` отвечает кодом 0.
3. После закрытия задачи 8567 тем же кодом отвечает и прогон без переменной.

## Где живёт правка

`flang/scripts/lines-to-trust-ceiling.json` (ключи `runtimeCode`,
`printedCCode`, `totalSources`, `totalPrinted`), прибор —
`flang/scripts/kernel-lines-to-trust.fscript`; рантайм — `flang/src/emit/c`.
Правка потолка перепечатки не требует.
