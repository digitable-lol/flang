# 9790. Замер «сколько верим» красный: три кучи выросли сверх записанного потолка, рукописный рантайм на C — на 2151 строку

Замер всего пути доверия написан и стоит короткой командой `trust:ceiling`:
одно число, разбивка по кучам, потолок в
`flang/scripts/lines-to-trust-ceiling.json`, который ползёт только вниз.
Открыто то, что он показывает сегодня.

## Шаги воспроизведения

1. `bootstrap/flang run-script trust:ceiling`
2. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script trust:ceiling`
3. Разложить рост рантайма по коммитам: счётчиком кода на C из прибора
   (строка, на которой после снятия `/* */` и `//` остаётся непробельный знак)
   пересчитать четыре файла `flang/src/emit/c` из отпечатка на каждом коммите
   после того, на котором снят потолок.

Первый отказ — не этого замера: семя отстало от исходников на один файл
(`flang/src/emit/c/flang_repl.c` правлен после перепечатки), и прибор
отказывается судить, пока семя не перепечатано. Второй отказ и есть предмет
задачи: выросли три кучи сразу.

Рост рантайма раскладывается по коммитам поимённо — потолок 19603 снят на
`228ac8bea`, дальше своим прогоном счётчика:

Напечатанное семя растёт следом: четыре файла рантайма уезжают в него дословно.
А `checkerCode` разошёлся с другим потолком того же дерева: в
`flang/proof/ratchets.txt` стоит `checker-code-lines 8127`, то есть храповик
сверщика уже переписан на измеренное, а `lines-to-trust-ceiling.json` всё ещё
держит 7711.

Версия: flang 0.7.23. Дата прогона: 3 октября 2026.

## Что должно быть

`bootstrap/flang run-script trust:ceiling` отвечает кодом 0: каждая куча не больше своего потолка.
Рост кучи либо снят, либо записан в потолок вместе с доводом, почему строк,
которым приходится верить, стало больше.

## Обходной путь

Нет.

## Когда задача сделана

1. По каждой из трёх выросших куч — `runtimeCode`, `printedCCode`, `checkerCode`
   — названа правка, давшая прирост, и решено одно из двух: строки убраны, либо
   потолок переписан планом «Переписать потолок всего пути» и довод роста
   записан в коммите.
2. `FLANG_SEED_LAG_KNOWN=1 bootstrap/flang run-script trust:ceiling` отвечает
   кодом 0; подъём потолка без довода за ответ не считается.
3. `checkerCode` в `lines-to-trust-ceiling.json` и `checker-code-lines` в
   `flang/proof/ratchets.txt` называют одно число.

Отказ `FLANG_SEED_LAGS` из шага 1 этой задаче не принадлежит: его снимает
перепечатка семени, и до неё прогон без переменной зелёным быть не может.

## Где живёт правка

`flang/scripts/lines-to-trust-ceiling.json` (ключи `runtimeCode`,
`printedCCode`, `checkerCode`, `totalSources`, `totalPrinted`), прибор —
`flang/scripts/kernel-lines-to-trust.fscript`; рантайм — `flang/src/emit/c`,
сверщик — `flang/proof/checker/checker.c`. Правка потолка перепечатки не
требует.
