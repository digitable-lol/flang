# 9874. Сличитель перевода отвергает честную печать взаимной хвостовой рекурсии, а пять правил и место сторожа у чужого вызова не переигрывает

## Шаги воспроизведения

1. Программа `mutual.flang` — две функции зовут друг друга в хвосте:

```
модуль «Mutual step»

тотальная функция «Чётно»
  принимает н: число
  возвращает признак
  если н не больше 0
    то да
    иначе «Нечётно» от (н минус 1)

тотальная функция «Нечётно»
  принимает н: число
  возвращает признак
  если н не больше 0
    то нет
    иначе «Чётно» от (н минус 1)
```

2. Команды:

```
cc -std=c99 -O2 -o matcher flang/translation/matcher.c
bootstrap/flang emit mutual.flang --target c --out out --protocol out/mutual_step.protocol
./matcher mutual.flang out/mutual_step.c out/mutual_step.protocol
```

3. Смотреть код возврата сличителя и первую строку его вывода.

## Что происходит

```
$ ./matcher mutual.flang out/mutual_step.c out/mutual_step.protocol
НЕ СОШЛОСЬ: напечатанный C, строка 19: в файле «/* Шаг батута для «Чётно»: значение либо отскок к соседу по рекурсии. */», а протокол здесь печатает другое — вне узлов
                                                 код 1
```

Версия: `flang 0.7.26`. Тот же ответ и у сличителя до ADR-0104: текст батута
(шаги «Шаг батута для …») печатник кладёт в C, а в протокол — нет.

Сверх того на 49 примерах `flang/proof/examples/*.flang` и
`docs/examples/measure/*.flang` (прогон 12 октября 2026, сличитель ветки
ADR-0104) кодом 3 отвечают 25 программ: не переиграны правила «случай» (80 узлов
в 18 программах), «литерал» (63 в двух — строки с иными экранированиями),
«разбор» (31 в 18), «свёртка» (13 в 8), «список» (12 в двух — пустой список),
«отобразить» (3 в трёх). Правило «хвост-отскок» не переигрывается вовсе. У
взаимной рекурсии с постоянным шагом без хвоста сторож меры у вызова чужой
функции сличается только функцией сторожа: место узлов вокруг вызова не
сличено (6 узлов на паре «Вниз А» / «Вниз Б»).

## Что должно быть

Честная пара — код 0 или код 3 с названным непереигранным (ADR-0030 §1, шапка
`flang/translation/matcher.c`). Код 1 только у подделки.

## Обходной путь

Нет: у программы с хвостовой взаимной рекурсией сличитель на цели `c` пользы не
даёт.

## Когда задача сделана

Пара выше отвечает кодом 0 или 3, и в `flang/translation/run.fscript` есть
честная пара с батутом и подделка шага батута, отвергнутая кодом 1. Число
непереигранных правил в `flang/translation/PRINT-RULES.tsv` («НЕ
переигрывается» в столбце «сличение») меньше пяти.

## Следующий шаг

Протокол батута: печатник `flang/self/emit-c.flang` кладёт шаги батута в протокол
отдельным блоком (по образцу блока «диспетчер»), правило «хвост-отскок»
переигрывается по строкам `bounce->args[i] = …;`, `bounce->next = …;`; затем
образец сторожа ADR-0104 распространяется на вызов чужой функции.

## Где живёт правка

`flang/self/emit-c.flang` (блок батута в протоколе) — перепечатка самосборной
части и проверка замыкания; `flang/translation/matcher.c`,
`flang/translation/PRINT-RULES.tsv`, `flang/translation/run.fscript` — без
перепечатки.
