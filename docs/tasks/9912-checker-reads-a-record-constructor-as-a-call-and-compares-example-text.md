# 9912. Сверщик принимает конструктор записи «Х» в функции «Х» за рекурсию и сверяет пример с ветвью-вызовом по тексту

Заявка: https://github.com/digitable-lol/flang/issues/416

Причина 1: тело `запись «Язык» с …` функции «Язык» сверщик читает как вызов самой функции: «это НЕ композиция». Причина 2: шаг `по примеру` на ветви `«Сцепить» от вариант «Пусто» и вариант «Пусто»` сверщик сравнивает с ожиданием примера знак в знак, а не вычислением.

## Шаги воспроизведения

1. Программа `same-name.flang`:

```flang
модуль «Repro checker function named like object»

тип «Отметка»
  вариант «Есть»
  вариант «Нет»

объект «Язык»
  богатый является «Отметка»

тотальная функция «Язык»
  принимает признак_языка: «Отметка»
  возвращает «Язык»
  пример «есть»
    дано признак_языка равно вариант «Есть»
    ожидается запись «Язык» с богатый равным вариант «Есть»
  запись «Язык» с богатый равным признак_языка

тотальная функция «Богатый язык»
  принимает признак_языка: «Отметка»
  возвращает «Язык»
  обеспечивает «богатый язык строится функцией Язык» результат равно «Язык» от вариант «Есть»
  пример «есть»
    дано признак_языка равно вариант «Нет»
    ожидается запись «Язык» с богатый равным вариант «Есть»
  «Язык» от вариант «Есть»
```

2. Программа call-branch.flang:

```flang
модуль «Repro checker call in branch»

тип «Поток»
  вариант «Пусто»
  вариант «Звено» содержит хвост: «Поток»

тотальная функция «Сцепить»
  принимает первый: «Поток», второй: «Поток»
  возвращает «Поток»
  пример «пусто»
    дано первый равно вариант «Пусто»
    дано второй равно вариант «Пусто»
    ожидается вариант «Пусто»
  разбор первый
    случай вариант «Пусто»
      то второй
    случай вариант «Звено» с хвост как хвост_первого
      то вариант «Звено» с хвост равным («Сцепить» от хвост_первого и второй)

тотальная функция «Тождество через сцепление»
  принимает поток: «Поток»
  возвращает «Поток»
  обеспечивает «поток не меняется» результат равно поток
  пример «пустой поток»
    дано поток равно вариант «Пусто»
    ожидается вариант «Пусто»
  разбор поток
    случай вариант «Пусто»
      то «Сцепить» от вариант «Пусто» и вариант «Пусто»
    случай вариант «Звено» с хвост как хвост_потока
      то вариант «Звено» с хвост равным («Тождество через сцепление» от хвост_потока)

теорема «поток не меняется»
  дано поток: «Поток»
  утверждаем результат равно поток
  индукция по поток
    случай вариант «Пусто»
      то по примеру «пустой поток»
    случай вариант «Звено» с хвост как хвост_потока
      то по предположению
  следовательно доказано
```

3. `bootstrap/flang check same-name.flang --proof --record same-name.запись`, затем `flang/proof/checker/сверщик --строго same-name.flang same-name.запись`.
4. `bootstrap/flang check call-branch.flang --proof --record call-branch.запись`, затем `flang/proof/checker/сверщик --строго call-branch.flang call-branch.запись`.

Версия: flang 0.7.28 (`bootstrap/flang` из дерева).

## Что должно быть

Сверщик отличает конструктор записи от вызова одноимённой функции и сводит замкнутый вызов в ветви к значению; на обоих файлах код 0 или 3.

## Обходной путь

Переименовать функцию; в ветви писать литерал.

## Когда задача сделана

`flang/proof/checker/сверщик` на записях обоих файлов — код 0 или 3. Подделка: функция «Язык», которая в самом деле зовёт себя, — код 1.

## Где живёт правка

`flang/proof/checker/checker.c`. Без печати семени.
