# 9953. Поиск петель контракта при печати ищет рёбра линейным проходом по списку на каждое имя

Перед печатью компилятор для каждой функции с постусловием ищет, достижима ли
она из собственного постусловия. Таблица рёбер «имя → кого зовёт» считается
один раз, но поиск в ней остался линейным.

## Шаги воспроизведения

1. `grep -c 'отфильтровать «рёбра»' flang/self/bootstrap/compiler.flang`
2. `grep -c 'Положить в словарь\|Найти в словаре' flang/self/bootstrap/compiler.flang`

## Что происходит

```
$ grep -c 'отфильтровать «рёбра»' flang/self/bootstrap/compiler.flang
2
$ grep -c 'Положить в словарь\|Найти в словаре' flang/self/bootstrap/compiler.flang
0                                                                   код 1
```

Оба попадания — строки 1323 и 1328, тела функций «Имена тела функции» (1320) и
«Имена тела и постусловий» (1325): на каждое раскрытие имени они проходят всю
таблицу рёбер. Словарём файл не пользуется ни разу; слово «словар» в нём есть,
но дважды и оба раза в доводах, поэтому прибор ищет не слово, а два зова
библиотеки. Какую долю стадии печати занимает поиск петель сегодня, не
измерено: прежний замер (125,6 с из 171,6 с стадии на
`flang/self/parser.flang`) снят до того, как рёбра стали считаться один раз.

Версия: flang 0.7.23, 3 октября 2026. Время не перепроверено.

## Что должно быть

Ребро по имени находится за время, не зависящее от числа функций программы:
словарём из `flang/stdlib/hashmap.flang` («Положить в словарь», «Найти в
словаре») или иным индексом. Напечатанное не меняется ни на байт.

## Обходной путь

Нет; печать идёт дольше.

## Когда задача сделана

1. Снята доля поиска петель в стадии печати на `flang/self/parser.flang` до
   правки; если она мала, задача закрывается с этим числом без правки.
2. После правки та же стадия на том же входе быстрее, число названо.
3. `sh scripts/bootstrap-reprint.sh --check` сходится байт в байт.
4. Порядок имён в списке сохранён: он уезжает в напечатанное.
5. Если правка ввозит словарь, измерено, насколько ввоз расширил замыкание
   печати: сегодня `compiler.flang` из библиотеки ввозит только «Strings», а
   модуль словаря обобщённый.

## Где живёт правка

`flang/self/bootstrap/compiler.flang`, функции «Имена тела функции» и «Имена
тела и постусловий» и построение таблицы рёбер рядом с ними. Правка доезжает
до двоичного только перепечаткой самосборной части.
