# Задачи

В этом каталоге лежат только открытые задачи: одна задача — один файл. Закрытая
задача из дерева уходит; её текст остаётся в истории git, а номер — в
[`used-numbers.tsv`](used-numbers.tsv).

Правило о дефектах — [`docs/zero-bug-policy.md`](../zero-bug-policy.md): дефект
либо исправлен, либо закрыт с названной причиной; задача заводится, когда
сразу не чинится.

## Завести задачу

1. Воспроизвести на текущем двоичном. Не воспроизвелось — задачи нет.
2. Скопировать шаблон [`docs/templates/task.md`](../templates/task.md) в
   `docs/tasks/<английские-слова-через-черту>.md`, пока без номера, и заполнить.
3. Спросить номер и переименовать файл:

   ```sh
   bootstrap/flang run-script tasks:number
   git mv docs/tasks/<имя>.md docs/tasks/<номер>-<имя>.md
   ```

   Тот же номер вписать в поле `номер` и в заголовок первого уровня.
4. Проверить: `bootstrap/flang run-script tasks:check`.

Задача пишется коротко и в настоящем времени: что неверно или чего нет, шаги
воспроизведения, что происходит, что должно быть, обходной путь, когда задача
сделана, где живёт правка. Журнал работы, хронология и история замеров в
задачу не пишутся — для них есть сообщения коммитов.

## Шапка

| поле | что писать |
|---|---|
| `номер` | четыре цифры, те же, что в имени файла |
| `заголовок` | одно предложение: что неверно или чего нет |
| `статус` | `свободна` или `в работе` |
| `приоритет` | `P0`…`P3` по [`docs/zero-bug-policy.md`](../zero-bug-policy.md) |
| `исполнитель` | одно имя; у свободной — прочерк `—` |
| `ветка` | ветка, в которой идёт работа; у свободной — прочерк |
| `команда` | `первая` — компилятор, ядро, доказательство, библиотека; `вторая` — проверки, скрипты, документы; `любая` |
| `карта` | точный заголовок раздела [`docs/ROADMAP.md`](../ROADMAP.md) или прочерк |
| `рядом` | номера связанных задач через запятую или прочерк |
| `нужность` | одна строка: зачем это нужно |

Поля `приоритет` и `нужность` проверка не читает; остальные восемь обязательны,
пустое значение пишется прочерком.

## Статусы

- `свободна` — никто не взял.
- `в работе` — названы исполнитель и ветка. Взять задачу — вписать себя в шапку
  отдельным коммитом до начала работы.

Закрыть задачу — удалить файл и тем же коммитом дописать строку в
`used-numbers.tsv`: номер, состояние, заголовок по-английски в одну строку.
Состояний три: `done` — сделана, `rejected` — решено не делать, `dropped` —
перестала быть нужной без работы над ней (дубль, перекрыта другим решением).
Причина отказа пишется в сообщении коммита.

## Номера

Номер считается от английского имени файла, а не выбирается взглядом на
каталог: `bootstrap/flang run-script tasks:number` выдаёт число из полосы 1000…9999 и обходит
занятые — и открытые, и перечисленные в `used-numbers.tsv`. Выданный номер
второй раз не выдаётся никогда и при переименовании задачи не меняется.

## Проверки

```sh
bootstrap/flang run-script tasks:check              # шапки, карта, «рядом», двойные номера
bootstrap/flang io scripts/guards/task-numbers-guard.fscript --plan Check   # номера
bootstrap/flang run-script tasks:board                 # что в работе, что свободно
```

Проверки читают шапку, а не дерево: сделана ли задача на самом деле, показывает
только прогон из её раздела «Когда задача сделана».
