# 0011. Живучесть выражена имеющимися средствами, новых слов языка ноль

Безопасность (из годного состояния выходит годное) доказывалась и раньше — одной
строкой `обеспечивает`, без интерактивного доказателя. Не выражались утверждения
о бесконечной последовательности состояний: «упавший процесс будет перезапущен»,
«узел, потерявший связь, будет объявлен молчащим за конечное время», «процесс,
которому пришло письмо, получит его».

Вопрос стоял так: найти настоящее утверждение из своего дерева, которое сегодня
не записать, и если все они выражаются через инвариант одного шага плюс конечную
меру — задачу закрыть. Это и был лучший из возможных исходов.

## Чем закрыта

`8bb4078d proof(conc): живучесть трёх настоящих утверждений выражена имеющимися
средствами — восемь обещаний доказаны ядром, новых слов языка ноль` (ветка
`u/zhivuchest`). Решение записано в `docs/adr/0017-liveness-without-temporal-logic.md`.

Замер: `flang/conc/supervisor.flang` 42 → 45 доказанных,
`flang/conc/scheduler.flang` 43 → 46, `flang/conc/wire.flang` 27 → 29, потеряно
ноль. Временной логики не вводили, аксиом не прибавилось.
