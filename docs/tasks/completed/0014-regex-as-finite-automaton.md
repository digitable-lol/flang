# 0014. Регулярные выражения выражены конечным автоматом

Регулярок не было вовсе, и это числилось одной из четырёх дыр, из-за которых
часть оснастки остаётся на JavaScript. Обычный движок с возвратами в общем случае
не завершается — катастрофический откат — и собственную проверку языка не прошёл
бы.

## Чем закрыта

`b4a7a1ea feat(stdlib): регулярные выражения выражены конечным автоматом — 63
функции с доказанным завершением, миллион построчных решений сошёлся с чужими
движками`, затем `7f1d338e` и `447f0c3a proof(automaton): доказано 98 обещаний из
102 вместо нуля из пяти`.

Модуль — `flang/stdlib/automaton.flang`, производные Бжозовского, образец
приезжает строкой; завершение по построению — число шагов равно длине входа.
Рядом `flang/stdlib/образцы.flang`: пять видов образца без движка вовсе.

## Что осталось

Число «98 из 102» снято до последней перепечатки и ждёт перемера свежим
двоичным — это задача 0002.

`ROADMAP.md` всё ещё числит регулярки среди четырёх недостающих возможностей —
задача 0025.
