# 0027. Проверка задачника зовётся ярлыком, а не длинной строкой

Целость задачника проверяется строкой
`bootstrap/flang io flang/scripts/tasks.flang`, а все прочие проверки дерева
зовутся ярлыками. Ярлык нужен затем же, зачем он нужен остальным: набор проверок
гоняется списком, и проверка, которой в списке нет, тихо мертвеет — так проверка
слов была мертва восемь часов.

Вписать в `ярлыки.flang` две записи: `задачник:проверка` на план целости и
`задачник:доска` на план доски.

## Как понять, что сделано

`./ярлык задачник:проверка` возвращает 0 на целом задачнике и 1 на разъехавшемся;
`./ярлык ярлыки` (план «Целость») зелёный — каждый ярлык указывает на
существующий файл.

## Чем ограничено

`ярлыки.flang` 24 августа держал другой заход. Прежде чем править — свериться:
`/srv/priyom/claim`.

## Откуда

Заведено вместе с задачником: работа названа и не сделана, значит её место здесь,
а не в прозе.

## Чем закрыта

Коммит `fa1a53cf`: в `ярлыки.flang` вписаны две записи —

| ярлык | строка |
|---|---|
| `задачник:проверка` | `bootstrap/flang io flang/scripts/tasks.flang --plan 'Задачник цел'` |
| `задачник:доска` | `bootstrap/flang io flang/scripts/tasks.flang --plan 'Доска'` |

План назван у обоих: планов в файле несколько, и без `--plan` вызов отвечает
кодом 3 и `FLANG_UNKNOWN_PLAN`.

Прогоны, все через ворота (`PAMYAT=45G`):

```
./ярлык задачник:проверка                     код 0
  задачник цел: всего задач 54: свободно 26, в работе 7, сделано 19, отменено 2

./ярлык задачник:проверка  (временная копия,  код 1
   в ней нарочно заведён второй файл на номере 0038)
  задачник разъехался, замечаний 2
    · 0038-two-agents-grabbed-one-number.md: номер 0038 занят не одной задачей
    · 0038-task-numbers-collide-under-a-dozen-agents.md: номер 0038 занят не одной задачей

./ярлык ярлыки                                код 0
  ярлыков 85; посмотрено 84: по имени файла 83, по образцу 1 — всё нашлось
  в дереве; команд без файла дерева 1 — у них смотреть нечего
```

Число ярлыков в двух обещаниях файла поднято с 83 на 85.

Отдельно найдено и НЕ чинилось здесь: `bootstrap/flang test ярлыки.flang`
краснеет `FLANG_UNKNOWN_NAME: неизвестный тип «неотрицательное»` — и краснеет
так же на версии из ствола, до этой правки. Слово применено в файле, а ни одно
собранное семя дерева его не знает. Это остаток беды из задачи 0034, не этой.
