# 1430. Область сторожа транслита: треть дерева судится, две трети — нет

## Чем измерено

21 сентября 2026, ветка `a/derevo-revizia` от `gh/main`. Полная ревизия —
[docs/tree-layout-audit.md](../tree-layout-audit.md), раздел 2.

Сторож сегодня **зелёный**, и это не спор с ним:

```sh
sh scripts/guards/translit-file-names-guard.sh --check
  → транслит в именах файлов: латинских имён 1226, с чужими словами 67 — все в ведомости, новых нет
```

Область задана строкой 30 самого сторожа:

```sh
OBLAST="scripts flang/test flang/scripts docs/site docs/zettel .github"
```

| | файлов |
|---|---:|
| отслеживаемых файлов в дереве | **3680** |
| из них в области сторожа | **1252** (34 %) |
| **вне области — не судится ничем** | **2428 (66 %)** |

Снято так:

```sh
git -c core.quotepath=false ls-files | wc -l
git -c core.quotepath=false ls-files -- scripts flang/test flang/scripts docs/site docs/zettel .github | wc -l
```

Сколько транслита лежит за областью — до сих пор не мерили ни разу: задача 1428 вела
свой замер только по области («транслитных латинских имён в области сторожа — 150 → 67»).

| | имён |
|---|---:|
| латинских имён со словом не из `scripts/ledgers/file-name-words.txt`, всего по дереву | **1020** |
| из них в области сторожа | 67 — все в ведомости долга |
| **вне области** | **953** |
| из 953 — несущие транслитерированное русское слово (проба скелетов, см. ниже) | **234** |
| после ручного разбора выборки 47 из 234: 37 верных, 10 ложных | **≈ 185** |

Где: `docs/` 141, `flang/` 89, `fspec/` 4. Примеры —
`docs/design/proof-object-po-obyavleniyu-trace.md`,
`docs/tasks/1409-otsenka-vitkov-chislovaya-rekursiya-edinicy-sekundy.md`,
`flang/self/otkazy-totalnosti.flang`, `flang/proof/checker/tests/families/totality.flang`.

**Проба скелетов** — как отделён транслит от английского слова, просто не внесённого в
список: латинское слово и каждое русское слово от четырёх букв из всех 3673 текстовых
файлов дерева приводятся к общему огрублённому виду (`zh`/`kh`/`shch` → `zh`/`h`/`sh`,
`y`/`j` → `i`, `ya`/`yu`/`yo` → `a`, мягкий знак снимается); совпадение значит, что
латинское слово — транслитерация слова, которое дерево само пишет кириллицей. Проба
ловит лишнее — интернационализмы (`median`, `minimum`, `levenshtein`, `audit`, `agent`,
`format`), поэтому 185 — **оценка по выборке, а не пересчёт**, и брать её как пересчёт
нельзя.

## Что именно не так

Область **названа** («Область — стек инструментов», строка 18 сторожа), но нигде не
**обоснована**. Ни в шапке сторожа, ни в задаче 1428, ни в ADR не сказано, почему в
области оказались `docs/site/` и `docs/zettel/`, а остальные 1231 файл `docs/`, весь
`flang/src`, `flang/stdlib`, `flang/concurrency`, `fspec/`, `packaging/`,
`docs/examples/` и `docs/tasks/` — нет.

Сравнить есть с чем, в том же дереве. `scripts/guards/no-package-json-guard.sh` смотрит
только корень и прямо пишет в шапке, почему остальные пять `package.json` остаются:
«манифест расширения VS Code», «чужие проекты-примеры». Разница — ровно в этих двух
фразах.

Отдельно: соседний сторож кириллицы своё исключение **обосновывает** — `flang/proof/**`
вынесен с ссылкой на задачу 1420 и с названной ценой ошибки. Здесь такой ссылки нет.

## Что сделать

1. **Решить и записать, какой должна быть область**, и записать довод, а не только
   список путей. Три возможности, у каждой цена:
   * распространить сторожа на всё дерево — тогда ≈ 185 имён переименовать, остальные
     ~768 слов внести в закрытый список как английские; список вырастет с 1661 примерно
     вдвое;
   * оставить область как есть, но **вписать в шапку сторожа довод** — почему стек
     инструментов судится, а документы и примеры нет;
   * расширить область на названные каталоги по одному, каждый со своим заходом.
2. **Что бы ни выбрали — довод записывается** в шапке сторожа рядом со строкой `OBLAST`,
   как это сделано у соседей.
3. Если область расширяется — ведомость `scripts/ledgers/translit-file-names-debt.txt`
   пополняется **с причиной у каждой группы**, как заведено сейчас.

## Чего НЕ делать

* **Не переименовывать ничего до того, как решение записано.** Это прямо сказано в 6421 и
  верно здесь: переименование без правила перемешает беспорядок.
* **Не трогать `flang/proof/**`** — это задача 6421 и 1420, у них своя цена.
* Не вносить транслит в `file-name-words.txt`: список закрыт нарочно, транслитное слово
  туда не вписывают — файл переименовывают.
* Не трогать `flang/self/**` и `bootstrap/**`: любое переименование там стоит полной
  перепечатки семени (~10 часов), и два имени уже отложены по этой причине в ведомости.

## Как проверить, что сделано

* `sh scripts/guards/translit-file-names-guard.sh --check` — код 0;
* `sh scripts/guards/translit-file-names-guard.sh --подлог` — код 1, «подлог пойман»;
* область в шапке сторожа и строка `OBLAST` совпадают, и рядом стоит довод;
* число «файлов в области» пересчитано и вписано:
  `git -c core.quotepath=false ls-files -- $OBLAST | wc -l`;
* `sh .githooks/pre-push` — код 0.

## Чем кончилось

Приём задачи, прогнан 22 сентября 2026 на стволе `d0763e8b6`:

```
sh scripts/guards/translit-file-names-guard.sh --check
  → транслит в именах файлов: латинских имён 1225, с чужими словами 67 — все в
    ведомости, новых нет                                          код 0
sh scripts/guards/translit-file-names-guard.sh --подлог           код 1
git -c core.quotepath=false ls-files -- $OBLAST | wc -l           → 1251
```

Область не расширена — и это записанное решение, а не умолчание: строка 75 сторожа
говорит «область НЕ расширяется. Сначала число и довод, потом…», строка 85 несёт
пересчитанное число «отслеживаемых файлов в области — 1251», строка 87 — сам `OBLAST`.
Ровно этого задача и требовала: у области появился довод, а у того, что за ней, — число.
