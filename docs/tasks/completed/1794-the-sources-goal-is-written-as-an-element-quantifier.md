# 1794. К1 переписывается квантором после 7098

Решение: [ADR-0042](../../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2.
Порог: задача 7098 (квантор по элементам печатается во все десять целей) влита.
Сделать: цель `(«Все неотрицательны» от результат) равен да` у К1 переписать как
`для всех э из результат: э не меньше 0`; ядро закрывает её Э2/Э3; запись
печатается, сверщик переигрывает; компилятор печатает сам себя (`make -C bootstrap`
и проба перепечатки). Если функция «Все неотрицательны» после этого не нужна никому —
снять её.

### Что сделано

* Цель К1 в `flang/proof/map/sources.flang` — `для всех э из результат: э не меньше 0`.
  Функция «Все неотрицательны» в этом файле после этого не нужна никому и снята; у
  `substantive.flang`, `refusal-substantive.flang` и пробы `9991-rezultat-raven` —
  свои копии, их цели эта задача не трогает.
* Запись `sources.record` перепечатана семенем ствола (`check --proof --записать`,
  строка «исходник» оставлена прежней): правило «все элементы по построению», блок
  `вывод` — `Э1 ⟨для всех э из ( пустой список ) : э не меньше 0⟩ сам` и
  `Разв2 ⟨для всех э из результат : э не меньше 0⟩ из 1 строка 21`.
* Подделка исходника в `flang/proof/checker/tests/run.sh`

  пустой список ) : э не меньше 0»». Порча собралась — `diff` показывает ровно строку
  тела.
* Опись доказанного, карта целей (`docs/proof-goal-map.md`, раздел 7), указатель
  строки в README семьи `половина-б`, приметы строк оболочки.

### Два расхождения с ADR-0042 §2 и с шапкой задачи

* **Закрывает цель Э1, а не Э2/Э3.** Тело «Модули» — пустой список: отбора и
  прибавления в нём нет.
* **`sources.flang` не в `flang/self`**, а в `flang/proof/map/`; компилятор его не
  ввозит (имя модуля встречается в дереве один раз — в самом файле). Семя ствола
  квантор по элементам уже читает и доказывает: `check --proof` на новом файле —
  «доказано сведением цели с телом функции: правило «все элементы по построению»».
  Поэтому ни перепечатки, ни пробы печати компилятора самого себя правка не
  ждёт: `flang/self/**` не тронут.
