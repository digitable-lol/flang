# 2411. Отказ по недоказанности называет утверждения

## Почему эта задача есть отдельно от 1410

Работу вела задача 1410, и это было **ошибкой в подборе номера** (моей,
overagent'а). 1410 — про отказ ЖЕЛЕЗА: ввод-вывод, память, процесс, ADR-0034,
ветвь «Сбой», где отказ глотается. Здесь — про отказ ДОКАЗАТЕЛЬСТВА, ADR-0045,
код 3. Слово «отказ» в них разное, и приём у них разный. Три пункта 1410 не
тронуты и остаются за ней.

## Что было, снято прогоном на двоичном ствола 0190f16f9

`flang run flang/stdlib/numbers.flang --function Чётное` — весь ответ целиком:

```
не доказано: утверждений 58: доказано 39, сетка 19, на веру 0
  — запуск только по явному согласию: --на-веру
```

Ни одного имени, ни одной причины, ни слова о том, что дописать. При этом
`flang check … --proof` на том же файле называл **19 из 19** и приводил причину
у **19 из 19** — знание у двоичного было, до человека оно не доходило.

Беда общая, не одного файла:

| файл | утверждений | недоказанных | назвал `--proof` | назвал `run` |
|---|---:|---:|---:|---:|
| numbers | 58 | 19 | 19 | 0 |
| lists | 66 | 24 | 24 | 0 |
| optional | 22 | 7 | 7 | 0 |
| logic | 16 | 3 | 3 | 0 |
| result | 15 | 0 | — | отказа нет |

## Что сделано

Правлен только `flang/src/emit/c/flang_repl.c` — копируемая часть семени,
перепечатки не требует. При отказе с кодом 3 хозяин зовёт тот же отчёт о
доказательствах, что печатает `check --proof`, и берёт из его МАШИННОГО вида
(не из слов) номер, вид, имя, функцию и причину — **слово в слово полем отчёта**.
Ниже — строка «чем закрывается» на каждый род вердикта и команда для полного
отчёта.

Причина не переписана своими словами нарочно: человек, пришедший из отказа к
`--proof`, обязан прочитать там ту же строку. Своё — только «чем закрывается».

Закрытый список вердиктов взят из «Строки утверждения» в `flang/self/proof.flang`:
grid, declared, proved-conditional, refused, violated, assumed. Незнакомый
вердикт несётся латиницей и догадкой не подменяется.

## Приём — снято прогонами overagent'а, не только исполнителя

Число названных поимённо сошлось с числом ядра на пяти файлах: 19=19, 24=24,
7=7, 3=3, у доказанного `result.flang` — ноль лишних строк.

Вывод на `logic.flang` целиком:

```
не доказано: утверждений 16: доказано 13, сетка 3 — запуск только по явному согласию
недоказанное — поимённо, словами отчёта о доказательствах:
  1. постусловие «исключающее или есть неравенство признаков» функции «Ровно одно» — сетка 3 значения…
  2. постусловие «все верны ровно тогда, когда ложного среди значений нет» функции «Все верны»…
  3. постусловие «есть верное ровно тогда, когда истинное среди значений есть» функции «Есть верное»…
«сетка» закрывается так: написать при утверждении «теорема … утверждаем … следовательно…»
отчёт о доказательствах целиком: flang check <файл> --proof
```

Сторожа: пробы недоказанного — сошлось всё, проб 22, разошлось 0; жаргон —
код 0; числа в прозе — 231 примета, сошлось 231.

## Цена, числами

| | до | после |
|---|---:|---:|
| `run` numbers | 2,30 с | 7,39 с |
| `run` lists | 5,17 с | 15,33 с |
| `run` с замечанием проверки | 3,61 с | 2,43 с |

Отчёт — второй проход доказательства, и платится он ТОЛЬКО на отказе:
доказанная программа не дорожает (`result.flang` — 0,61 с). На программе с
замечаниями второй проход погашен: назвать поимённо там нечего, программа не
проверена вовсе.

## Чего НЕ сделано и почему

* **`flang io` списка не печатает.** Его строку снимает
  `run-verdict-debt-guard`, и риск для таблицы долга вердиктов не измерен.
  Трогать учёт вслепую хуже, чем оставить как есть.
* **Лад «предупреждение» списка не печатает.** Там программа работает, отказа
  нет, а второй проход платился бы каждый раз.
* **Обход списков законов и принятого на веру прогоном НЕ проверен.** Файла, где
  отчёт печатается и несёт непустые законы, в дереве не нашлось. Что все три
  вердикта в списке есть — видно чтением `flang/self/proof.flang`, но это довод
  от чтения, а не замер. Так и записано.
* **Страницы в `docs/guide/` не заводили.** Ответ «что дописать» теперь стоит в
  самом отказе и в отчёте; третье место с тем же ответом разошлось бы с ними
  молча.

## Что стоило бы сделать перепечаткой

«Итог запуска» несёт четыре поля, и посчитанный внутри вердикта отчёт наружу не
отдаёт. Пятое поле убрало бы второй проход целиком — это 5–10 с на файл по
замерам выше. Правка в `flang/self`, то есть перепечатка.
