# 2907. Терм, запись и приёмка — данные Lean; «принят — значит верно» — теорема

Решение: [ADR-0041](../../adr/0041-the-checker-is-proved-sound-against-a-mechanised-semantics.md).
Пишется в НОВЫХ файлах `flang/proof/lean/`; `Модель.lean` и `Правила.lean` не
правятся (их правит партия Э).

## Чем измерено

13 сентября 2026: `Модель.lean` 421 строка (значения, округление «грубое»,
списки, суммы, тексты, суждение «Судим»), `Правила.lean` 110 теорем по одной на
строку ведомости, `Ловушка.lean` 14 искажений; `сверщик.c` 6982 строки кода,
13 правил в `шаг_вывода`; формат записи — `ЧИТАТЬ.md` прозой; Lean на машине не
установлен (`прогон.sh` — код 2).

## Что сделать — по порядку ADR-0041 §2.4

1. `Терм.lean`: индуктивный терм в объёме ведомости и `оценить`; показать, что
   леммы `Правила.lean` переформулируются через `оценить` (хотя бы для семей Н, П,
   Т, Э) без потери.
2. `Запись.lean`: индуктивная запись по `ЧИТАТЬ.md`; расхождения прозы с
   `сверщик.c` — списком в задачу 1313 §3.
3. `Приёмка.lean`: `Принят` и разрешимая `принят?` для правил с приёмом в C — по
   одному, начиная с Т1/Т2, Н, Кон1, Э1–Э4; число покрытых правил — в шапку задачи.
4. `Состоятельность.lean`: теорема `Принят з → Судим (допущения з) (цель з)` для
   покрытого подмножества; подмножество названо.
5. Сверка вердиктов C ↔ Lean на 216 честных и 459 подделках — в `прогон.sh`,
   красит при расхождении; каждое расхождение — задачей.
6. Слово: `docs/road-to-1-0.md` §3 — числом; `docs/lean-checks-the-inference-rules.md`
   — новый раздел; `ЧИТАТЬ.md` ссылается на `Запись.lean`.

## Чего не делать

Не править `сверщик.c` иначе как чиня расхождение, найденное сверкой; не
верифицировать C как программу; не переписывать сверщик на Lean; не обещать
теорему о вычислителе (`interpret.flang`) — это §2.3 ADR-0041.

## Как поймём, что сделано

`прогон.sh` собирает четыре новых файла; теорема принята для N правил из 13,
N назван; сверка вердиктов — расхождений 0 или каждое задачей; §3
`road-to-1-0.md` переписан числом.

## Ход работы

**13–14 сентября, вехи 1–4** (исполнитель a): `Терм.lean`, `Запись.lean`,
`Приёмка.lean`, `Состоятельность.lean` — коммиты `8e8cb054`, `5850bccd`, `b2c25bfd`,
`2e43fd5c`. Покрыто 29 правил из 70 приёмов `шаг_вывода`, из 13 именованных — 11
(без Цел1 и Цел2).

**14 сентября, веха 5** — продолжена другим исполнителем: прежний остановился на
лимите API и оставил в клоне незакоммиченное начало вехи — терм с телом и вызовом
любого сорта (собирался) и разбор записи на Lean (в Lean 4.34.0 не собирался:
кириллица в локальных именах без «ёлочек», `String.drop` отдаёт срез). Разбор
доведён и назван по-английски — `RecordReader.lean`, к нему `VerdictCheck.lean` и
сверка в `прогон.sh`.

Парсер на Lean, а не переводчик скриптом: он был наполовину написан, читает
запись в те же типы, которые судит теорема, и один вызов `lean --run` судит весь
набор; переводчик скриптом был бы третьей реализацией чтения на третьем языке.
Парсер стоит вне теоремы и доверен — это названо в шапках `RecordReader.lean` и
`Запись.lean` и в ADR-0041 §2.3.

Первая сверка: 116 блоков Lean не прочёл, 8 блоков сверщик отверг, а Lean принял
(подделка без `вывод конец`). Все причины — в читателе Lean: строй блока не
проверялся; номер строки брался после первого «строка » заголовка, а имя
утверждения само может его содержать; выписанный список `[а, б]` делился по
« , » с пробелами; свёртка резалась по `плюс` внутри тела. После починки
расхождений 0.

**Итог сверки** (`sh flang/proof/lean/прогон.sh`: 820 вызовов сверщика на наборе
из 216 честных записей и 459 подделок, 176 пар «исходник + запись» с блоком
«вывод», 1291 блок):

| сверщик | Lean | блоков |
|---|---|---|
| принял | принял | 275 (212 из них — в записях, отвергнутых по другой причине) |
| отверг | отверг | 61 |
| отверг | не прочёл | 11 |
| принял / отверг | вне приёмки Lean | 860 / 84 |
| принял | отверг | 0 |
| отверг | принял | 0 |

Отрицательный контроль молчания: в отвергнутых записях у блока, о котором
сверщик промолчал, испорчен первый шаг — сверщик назвал каждый (5 из 5).

**Веха 6.** `road-to-1-0.md` §3 — «теорема о состоятельности есть для 29 правил
из 70»; `lean-checks-the-inference-rules.md` §7; `ЧИТАТЬ.md` ссылается на
`Запись.lean` как на спецификацию формата; задача 1313 §3 — семь расхождений
прозы и кода.

**Заведено:** 1130 — приёмка Lean растёт от 29 правил к 70 (944 блока вне
приёмки, частоты по правилам); 3855 — у Или1, Или2, И1, И2, Цел1, Цел2 нет леммы
в `Правила.lean`.
