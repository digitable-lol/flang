# 3449. Третье и четвёртое умения вычислителя примера

Решение: [ADR-0042](../../adr/0042-the-last-twelve-places-get-rules-not-exceptions.md) §2 —
правило, а не вынос из знаменателя. Предшественница — задача
[3448](../3448-the-example-evaluator-of-the-checker-reads-nul-strings-and-filter.md):
она научила вычислитель нулевому знаку и отбору и назвала стену, в которую
упёрся `corpus-cforms`, — «в счёте встретился разбор списка по звену».

Места: `corpus-cforms` — три шага «по примеру» («у каждой формы с помощником
есть арность», «синоним ведёт в форму с помощником», «разрешение синонима — один
шаг»). За отбором стоит цепочка «Первая из меток» — `разбор «метки»` по звену, её
итог — вариант с полем («вариант «Есть число» с «значение» равным …»), а
«Метка или ноль» разбирает этот вариант со связыванием поля.

Сделать: вычислитель считает `разбор` посчитанного списка (пусто — ветвь
`случай пусто`, звено — ветвь `случай голова и хвост` с первым звеном и
остатком) и вариант с полями (сборка — поля считаются, разбор — ветвь своего
варианта, поля на местах связанных имён). Строка ведомости «Выч», леммы Lean
«Выч-звено» и «Выч-вариант», ловушки из диапазона 50–59, согласованная подделка и
честная проба в наборе проб сверщика; строки кода — строкой бюджета в
`ratchet.txt` с доводом.

**Вычислитель.** Разбор посчитанного списка — ветвь «случай пусто» либо «случай
голова и хвост» (и «голова Г и хвост Х»), голова — первое звено, хвост — остаток тем
же текстом. Вариант с полями — новый вид значения 8: поля считаются при сборке и
пишутся литералом (строка, число, признак; минус ноль и поле-список — отказ), разбор
идёт в ветвь своего варианта, поля — на местах связанных имён. Равенства у вида 8
нет: текст полей в другом порядке разошёлся бы с равенством значений. Ветви читаются
только парами «случай»/«то» до конца блока: без этого ветвь вложенного разбора
читалась бы как своя.

**Правило.** Строка «Выч» ведомости расширена (новых строк нет), отпечаток переснят;
леммы «Выч-звено», «Выч-вариант», «Выч-первое-из-отбора» и встречные примеры
«Выч-встречный»; ловушки 50–52. Каждая ловушка отдельной пробой отвергается только
за ложное утверждение, а истинное тем же способом собирается кодом 0. «Выч» вне
приёмки Lean, как и прежде: нового правила блока «вывод» задача не заводит.

**Находка.** Ловушка 32 (PR #33) объявляла «разборСуммы» заново, хотя видит его
через импорты: проба падала первой ошибкой «has already been declared» и упала бы и
на истинном утверждении. Починено отдельным коммитом.

**Знаменатель.** 651 → 650 — не отсюда: задача 1794 сняла функцию «Все
неотрицательны», и её доказанная тотальность ушла из обеих частей дроби. Замер той
же ветки с функцией — 634 / 651 и на черновике 651 / 651.

**Бюджет.** +74 строки кода — больше оценки задачи 3448 (30–40): кроме двух
уравнений понадобились сторож «ветви парами» и отказ равенству у вида 8. Потолок
поднят на съеденное дополнением ADR-0042 §3; подпись — влитие PR.
