# 5822. Сверка двух печатей не сверяет напечатанный компилятор

## Шаги воспроизведения

1. Два дерева-близнеца: `bootstrap/*.c`, `*.h`, `Makefile`, `flang/src/emit/c`,
   `scripts/seed-fingerprint` и журнал `print.log` со строкой `ПЕЧАТЬ КОД=0` рядом с
   каждым деревом.
2. Во втором дереве дописать байт: `printf x >> second/tree/bootstrap/compiler_flang.c`.
3. `sh scripts/seed/two-prints-identical.sh first/tree second/tree` (ствол `7b3a73873`).

## Что происходит

```
$ sh scripts/seed/two-prints-identical.sh first/tree second/tree
печати совпали побайтово: файлов 4, байт 1414862                 код 0
```

То же при удалённом `second/tree/bootstrap/Makefile` — код 0, «файлов 4».

Версия: flang 0.7.22. Прогон 27 сентября 2026.

Причина: список сверяемых имён берётся `ls -A <дерево>/flang/src/emit/c` — это
копируемый рантайм, четыре файла. Напечатанная часть — `compiler_flang.c`,
`compiler_flang.h`, `Makefile` — в список не попадает никогда. Так с первого
коммита прибора (`365d0af1e`).

## Что должно быть

Две печати одного дерева совпадают во ВСЕХ файлах, из которых соберётся двоичный.
Их перечень задаёт сама печать: раздел «тело семени» в `scripts/seed-fingerprint`.

## Обходной путь

`cmp` каждого файла `bootstrap/` руками.

## Когда задача сделана

- `bootstrap/flang io scripts/seed/two-prints-identical.fscript --plan Check --timeout 1800000 -- first/tree second/tree`
  сверяет объединение рантайма и тела семени из отпечатка каждого дерева и называет
  сверенные файлы строкой «сверены: …». Отпечатка без тела нет — «НЕ ПРОВЕРЕНО», код 3.
- План `Forgery` того же файла строит близнецов из дерева и требует трёх ответов:

| опыт | ждём | план с правкой | план без правки (список только из рантайма) |
|---|---|---|---|
| два одинаковых дерева | код 0, «файлов 7», «сверены: …, Makefile, compiler_flang.c, compiler_flang.h» | код 0 | код 0, но сверены 4 файла — опыт красен |
| байт в `compiler_flang.c` | код 1, «РАЗОШЁЛСЯ: bootstrap/compiler_flang.c» | код 1 | код 0 |
| нет `Makefile` | код 1, «РАЗОШЁЛСЯ: bootstrap/Makefile» | код 1 | код 0 |

`bootstrap/flang io scripts/seed/two-prints-identical.fscript --plan Forgery --timeout 600000` —
код 0 за 27,9 с; с правкой, снятой обратно, — код 1 и все три опыта названы.

## Где живёт правка

`scripts/seed/two-prints-identical.fscript` (функции «Body names», «Side names»,
план `Forgery`). Двоичного не касается: ни пересева, ни перепечатки не требует.
