# 5823. Приёмка нового двоичного обрывается на четвёртой примете

## Шаги воспроизведения

1. Дерево с собранным `bootstrap/flang` (ствол `7b3a73873`).
2. `sh scripts/seed/new-binary-acceptance.sh <дерево>`.

## Что происходит

```
=== ПРИМЕТА 4 — правила ядра работают (прогон, а не таблица имён)
scripts/seed/new-binary-acceptance.sh: 92: PROBA: parameter not set      код 2
```

Строка 19 заводит `PROBE=…/new-binary-acceptance-probe.flang`, строка 92 читает
`"$PROBA"`; при `set -u` скрипт обрывается. Имя переменной сменили при переводе имён
на английский в одном месте из двух.

Версия: flang 0.7.22. Прогон 27 сентября 2026.

## Что должно быть

Все шесть примет сняты, итог — «принят» или «примет не сошлось: N».

## Обходной путь

Нет: приметы 4–6 руками.

## Когда задача сделана

`bootstrap/flang io scripts/seed/new-binary-acceptance.fscript --plan Accept --timeout 3600000 -- /srv/tmp/dokazuemyy/wScripts`
прошёл все шесть примет за 212 с: примета 4 — «правил ядра доехало 3 из 4», итог —
«примет не сошлось: 1» (строки хода в двоичном нет), код 1. Путь пробы в плане
строится одной функцией, второго имени у него нет.

## Где живёт правка

`scripts/seed/new-binary-acceptance.fscript`; скрипт оболочки снят (задача 5821).
