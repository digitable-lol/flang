# 6432. М1, М2, Разв3, К↑, Разв1 для суммы

**М1 в приёмке Lean — со второй стороной-литералом.** Длина списка модели не
ограничена, а «плюс» модели выше 2⁵³ округляет: равенство меры «плюс 1» держится
лишь до порога. С литералом меньше порога переписка верна и за ним — выше порога
округлённое не ниже порога («моно»), и посылка ложна либо заключение истинно
(«собрать-М1», «М1-значение»). Сверщик берёт любую вторую сторону: длина списка
языка меньше 2⁵³ — граница модели, названа в шапке `Acceptance.lean`.

**Приёмка Lean — у всех пяти правил.** Модель терма (`Term.lean`) выросла на три
вещи: списочную свёртку (М2); суммы автора — выписанный конструктор, поле
`( С ) .«п»`, разбор суммы в формуле, тело-сумму (К↑, Разв1); довод-вызов без
сорта — довод `( «Г» от … )` несёт итог вызова целиком и, подставленный на место
параметра, читается сортом этого места. Окружение утверждения узнало функции с
телом одной строкой — факт «функция равна своему телу» (Разв3; читаются только
функции, чью строку тела называет шаг Разв3 записи). Теорема состоятельности — для
71 правила из 81 приёма `шаг_вывода`, аксиомы три стандартные, ловушек 29 из 29,
сверка вердиктов — расхождений 0.

Блоки печати ядра у этих мест сверка по-прежнему ставит «вне приёмки»: первым
шагом у каждого стоит Выч, а его вычислитель модель не повторяет (PR #29).
Приёмку новых правил проверила отдельная проба: исходник, где база — допущение
(Т1), а не Выч, и за ней К↑, три Разв3 (два вызова и своё тело), Разв1 для суммы.
Lean — ПРИНЯЛ; порченые копии — ОТВЕРГ ровно на испорченном шаге, и сверщик
отказал на том же шаге. В дерево проба не легла: рукописный блок шапку сверщика
не пройдёт (отпечатки исходника, тотальности), в набор запись кладёт печать
зонда, а зонд базой печатает Выч.

Где модель строже сверщика — названо в шапке `Acceptance.lean` (пункты 4–8): М1 —
вторая сторона-литерал; М2 — шаг без вызова; К↑ — поле только числом; Разв1 — у
каждого имени ветви есть поле, пары чисты; Разв3 — вызов не под связывателем,
пары «параметр — довод» чисты. Мягче одно: Разв3 берёт за шаг любое число
вхождений вызова. На наборе ни одно место вердикта не развело.

Бюджет ADR-0042: +166 строк кода сверщика из +180 (вместе с Пр1 и 3448).
