# 8222. Запуск говорит, доказана ли программа, и не запускает недоказанную без согласия

## Чем измерено

17 сентября 2026, main `cbfaf3899`, двоичный `bootstrap/flang` 0.7.19 (собран из семени
`make -C bootstrap`): `flang/self/cli.flang:158` — «язык, проверяемый до запуска: типы и
доказанное завершение». Перед `run` и `io` проверяются типы и завершение; вердикта о
доказанности утверждений программы (всех «обеспечивает», «требует», «утверждение» файла и
замыканий) при запуске нет — его печатает только `flang check --proof`, и там три слова:
«доказано» (про все входы), «сетка N» (посчитано на N значениях), «на веру».

### Замер «до» — 17 сентября 2026, двоичный 0.7.19 (семя 12 сентября), копия `wK1`

`sh flang/proof/probes/run/run.sh` (двоичным): **проб 13, разошлось 13** — по
построению: недоказанное запускается кодом 0, ключа нет. Лог — `k1-proby-do.log`.

код 1 (`FLANG_BOUND_ON_NAN`); остальные — код 0, «доказано 1» (у `без-утверждений` —
«утверждений 0»).

Снимается `sh flang/proof/probes/run/run.sh --зондом` (толкование исходников

## Что сделать

1. ADR-0045 (docs/adr): вердикт при запуске — что считается «доказано» для файла целиком
   (все утверждения файла и замыканий — «доказано», ни одного «сетка N» и «на веру»);
   имя ключа явного согласия; код выхода; слово в выводе. Обсудить в ADR имена ключа.
2. `flang/self/cli.flang`: `run` и `io` печатают вердикт и без ключа отказываются
   запускать недоказанное — код ≠ 0 и слово «не доказано» в выводе.
3. `docs/flang/self/SPEC.md` — строка о вердикте; пробы (не менее трёх недоказанных и
   трёх доказанных программ).

## Как поймём, что сделано

- `flang run`/`flang io` недоказанной программы → код ≠ 0 и «не доказано» в выводе (3 пробы из 3);
- доказанной → код 0 (3 из 3); с ключом согласия недоказанная запускается;
- `flang check` не изменил ни одного вердикта корпуса: `sh flang/proof/corpus-share.sh
  --проигрыванием` даёт те же 633 / 650 на том же двоичном.

## Фальсификатор

Недоказанная программа с `flang run` даёт код 0 — ячейка провалена.

## Доводы, которые стояли комментариями в коде

В `.flang` комментариев не пишут — объяснения живут здесь. Ниже то, что было
набрано комментариями в `flang/self/bootstrap/compiler.flang`, `cli.flang`,
зондах и программах проб; сами правила — в ADR-0045, здесь только то, чего в
ADR нет: замеры и причины, по которым код устроен так, а не иначе.

**Почему ядро зовётся один раз.** «Проверить связанное» и «Итоги бинарника»
каждая звала «Проверить доказательства» сама, и позвать обе значило заплатить за
ядро дважды. Замер 17 сентября 2026, двоичный 0.7.19, по три прогона:
`check --proof` против `check` — 1,44 с против 0,84 с на `corpus-lists.flang`
(разброс 1,41–1,46) и 0,25 с против 0,13 с на `stack.flang` (разброс 0,24–0,25).
Поэтому свод обязательств и ответ ядра считаются раз и раздаются в обе стороны:
в замечания — через «Итог суда ядра», в итоги — через «Итоги проверок из ответа
ядра».

**Почему под `--на-веру` вердикт не считается вовсе, а не «считается и всё равно
запускает».** Вердикт — это ядро над ЗАМЫКАНИЕМ программы. У замыкания с самим
компилятором (зонды `flang/self/bootstrap/zond-*.flang`) ядро идёт 7 ч 33 мин
(«Суд ядра о программе», замер 31 августа 2026). Ключ, который стоил бы этих
часов ради строки, которую человек просил не печатать, никто бы не нажимал.

**Что показывает каждая программа проб** (`flang/proof/probes/run/programs/`):

| программа | чем она такая |
|---|---|
| `identity.flang` | постусловие доказано тождеством — «доказано: утверждений 1» |
| `by-type.flang` | постусловие доказано по объявленному типу довода |
| `induction.flang` | постусловие доказано индукцией по списку |
| `without-statements.flang` | утверждений нет вовсе — «доказано: утверждений 0», доказывать было нечего |
| `grid.flang` | постусловие ядро вывести не умеет (остаток от деления), но есть примеры — ведомость пишет «сетка N значения» |
| `on-trust.flang` | постусловие объявлено и не доказано ничем |
| `lie.flang` | постусловие ложно, проверка даёт замечание — вердикт «не доказано» ещё до утверждений |
| `plan-proved.flang` | план с доказанным утверждением, путь `flang io` |
| `plan-on-trust.flang` | план с утверждением на веру, путь `flang io` |

## 27 сентября 2026: пробы вердикта при запуске идут планом

Прогонщик набора — план `run.fscript`; общая часть всех наборов лежит в
`flang/proof/probes/table.fscript`. Таблица `expected.tsv` — строка заголовка с
английскими именами столбцов и строки данных; прочерк `-` в ячейке значит
«ничего». Объяснения, стоявшие в шапках таблицы, прогонщика на оболочке и над
шагом CI, перенесены сюда дословно; старые имена столбцов и файлов в них —
того времени.

Вызов: `bootstrap/flang io flang/proof/probes/run/run.fscript --plan Binary`. Код 0 — сошлось всё; 1 — расхождение, и оно названо
строкой; 3 — смотреть было нечем (нет двоичного, нет таблицы, проба убита).
Переменная среды `FLANG_BIN` подменяет двоичный.

Столбцы: `program`, `command` (run или io), `keys`, `code`, `word`.

### Что стояло в шапке таблицы

```
Пробы вердикта при запуске (ADR-0045). Поля: программа, путь (run|io), ключ
(0 — без --на-веру, 1 — с ним), ожидаемый код возврата, слово, которое обязано
стоять в выводе. У проб с ключом слово — «доказанность не считалась»: это
кусок строки «на веру», и печатают её ОБА пути (зонд — полем «вердикт»,
двоичный — в поток ошибок). Одна таблица на два пути: разъедься они, разошлись
бы молча. Что вычисление состоялось, говорит код 0 рядом: отказ несёт 3.
```

Что сверяется — expected.tsv: для каждой programs код возврата и слово в

### Путь толкованием исходников на план не перенесён

Прогонщик на оболочке умел второй путь, `--зондом`: тот же двоичный толковал
исходники компилятора программой `flang/self/bootstrap/zond-8222.flang`, около
десяти минут и 12 ГиБ на программу. Путь был заведён как замер до rebuild
семени; rebuild прошёл 25 сентября 2026, и двоичный отвечает сам. Вызов одной
пробы этим путём, если он понадобится снова:

```
bootstrap/flang run flang/self/bootstrap/zond-8222.flang --function '«Проба запуска»' \
  --max-steps 2000000000 --args '{"путь": "grid.flang", "текст": "<исходник>", "имя": "Ответ", "на веру": false}'
```

Для плана вместо «Проба запуска» зовётся «Проба плана», а имя пусто. Ответ несёт
строки «вердикт: …» и «код N»; с таблицей сверяются они.
