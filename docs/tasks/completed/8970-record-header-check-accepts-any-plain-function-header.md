# 8970. «Это заголовок функции записи» признаёт своим любой заголовок нетотальной функции

Найдено ревизией задачника 11 сентября 2026 (побочно, при проверке задачи 4543).

## Что видно

Проба из задачи 4543 (три функции `функция «Ход сам»`, `«Ход раз»`, `«Ход два»`,
не тотальные) на `flang 0.7.17`:

```sh
bootstrap/flang check проба.flang            # код 0, «замечаний нет»
bootstrap/flang check --proof проба.flang    # FLANG_PROPERTY: нарушено свойство
  # «чужой заголовок не признаётся своим» функции «Это заголовок функции записи»
```

То же на голом `dev`: `bootstrap/flang check --proof --json flang/self/interpret.flang`.

## Где

`flang/self/zapis.flang:735–748`, функция «Это заголовок функции записи». Тело:

```
(«строка» начинается с "функция «") или («строка» начинается с "тотальная функция «") и притом («строка» содержит … "функция «Имя»")
```

Свойство требует: если результат — да, то строка содержит `функция «Имя»`.
Для строки `функция «Ход сам»` и имени `Ход раз` первая скобка даёт «да», и
результат «да» без проверки имени — свойство нарушено. Оба примера функции
проверяют только `тотальная функция …`, поэтому дыра примерами не ловится.
Гипотеза: не хватает скобок вокруг `или` — проверить чтением правил
приоритета в `flang/self/parser.flang`, а не на глаз.

## Как понять, что сделано

```sh
bootstrap/flang check --proof проба.flang                          # код 0, свойство держится
bootstrap/flang check --proof --json flang/self/interpret.flang    # код 0 или 3, без FLANG_PROPERTY
bootstrap/flang check flang/self/zapis.flang                       # у функции есть пример с «функция «…»» и чужим именем → нет
```

Правка в `flang/self/**` доедет до двоичного только перепечаткой — до неё
прогон по семени её не увидит.

## Чем закрыта

Закрыла её работа по задаче 8455: коммит `61736da57` «fix(zapis): скобки вокруг
дизъюнкции в «Это заголовок функции записи»» (25 сентября 2026) взял в скобки
`(… начинается с "функция «") или (… начинается с "тотальная функция «")` и
завёл два примера на заголовок НЕтотальной функции. До собранного двоичного
правка доехала перепечаткой 0.7.22 (`508cadac7`). Задача та же, что 8455, но с
другой стороны: 8455 ловила беду на `math-classics.flang`, эта — на пробе 4543 и
`interpret.flang`.

Переснято 27 сентября 2026 на `dev` `7b3a73873`, `flang 0.7.22`, двоичный собран
`make -C bootstrap -j8`:

```
$ bootstrap/flang check --proof проба.flang          # проба из задачи 4543, три функции
…НЕ ПРОВЕРЕНО — утверждений 3: доказано 1, … объявлено, не доказано 2, отвергнуто 0, нарушено 0 … код возврата 3
$ grep -c FLANG_PROPERTY <вывод>
0
$ bootstrap/flang check --proof --json flang/self/interpret.flang
…НЕ ПРОВЕРЕНО — утверждений 256: доказано 167, … сетка 28, объявлено, не доказано 61, отвергнуто 0, нарушено 0 … код возврата 3
$ grep -c FLANG_PROPERTY <вывод>
0
```

Код 3 на пробе вместо обещанного выше кода 0 — не остаток этой беды. Два
«объявлено, не доказано» — это постусловия «Ход раз» и «Ход два» из круга
взаимной рекурсии, то есть предмет задачи 4543. Сама 4543 записывает у этой
пробы код 3. Ведомость теперь печатается, а раньше падала на FLANG_PROPERTY.

Третья строка приёмки проверена чтением, прогоном — нет. Примеры
«Заголовок нетотальной чужой функции своим не признаётся» (`функция «НОД по
Евклиду»` против имени «Сумма» → нет) и «…своей функции опознаётся» стоят в
`flang/self/zapis.flang:759` и `:763`. `bootstrap/flang check
flang/self/zapis.flang` за 20 минут не кончился (код 124), и
`flang run --function` тоже: он проверяет весь файл до вычисления.
