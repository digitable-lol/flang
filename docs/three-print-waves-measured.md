## 3. Почему печатник молчит — измерено толкователем

Прибор: `bootstrap/flang run flang/self/zapis.flang --function «Цепочка разбора записи»`
(34 с на место) и зонд `«Решить цель записи»` через обёртку вне дерева. Доводы
печатника собраны из исходника тем же приёмом, каким их собирает `zapis.flang`
(проверено положительным контролем: на `binder-hides-the-condition` цепочка вышла знак
в знак с той, что стоит в записи корпуса).

**Прогон по всем 49 открытым местам пяти правил, которые печатник разбора берёт**
(`«Правило разбора цели записи»`): цепочка вышла у **0 из 49**. То есть на всех
сегодняшних открытых местах планировщик доходит до цели и не закрывает её.

Разложение по цели после развёртки — три причины, суммы сходятся (17 + 5 + 27 = 49):

| почему цепочки нет | мест |
|---|---:|
| тела одной строкой у функции нет (`разбор` в теле) — печатник отказывает на воротах | 17 |
| заслон «Тело планировщику по силам» (свёртка, отображение, стрелка, длина > 300) | 5 |
| цель собралась, но планировщик её не закрыл | 27 |

Двадцать семь незакрытых целей — по тому, чего цели не хватает (разбор чтением целей,
не прогоном приёма, который бы их закрыл):

| чего не хватает | мест | пример цели |
|---|---:|---|
| факт о типе довода (Н3, П2, П3, П5, П6, Н8, Н9, Н10 ведомости) | 10 | `груз не меньше 0`; `н не больше 9007199254740991`; `( н остаток от 7 ) не меньше 0` |
| порядок и дно произведения под охраной | 4 | `если ( ( 1 не больше основание ) и притом ( 1 не больше второе ) ) то ( 1 не больше ( основание умножить на второе ) ) иначе да` |
| целость довода, прочитанная из охраны | 4 | `если ( ( ( н остаток от 1 ) равен 0 ) и притом ( н не меньше 0 ) ) то ( н остаток от 5 ) не меньше 0 иначе да` |
| исключённое третье | 3 | `( не ( х больше 0 ) ) или ( х больше 0 )` |
| строгий порядок под охраной | 2 | `если ( н больше 1 ) то ( 0 меньше н ) иначе да` |
| начало строки | 2 | `( соединить "*" с ( к строке ( длина [первый, второй] ) ) ) начинается с "*2"` |
| рефлексивность нестрогого порядка под охраной | 1 | `если ( ( х минус х ) равен 0 ) то ( х не больше х ) иначе да` |

Пятнадцать из этих 27 стоят в записях-подделках (`poddelka-*`) — это честные половины

**Прогон по 26 открытым местам правил, которых в списке печатника НЕТ вовсе**

хватает того же: факта о типе либо закона отношений.

## 4. Что сделано этой правкой и сколько это стоит мест

Правка одна и только в печати (`flang/self/zapis.flang`); `сверщик.c` не тронут ни строкой.

1. `«Правило разбора цели записи»` — добавлено имя `вхождение по построению`.
   Замер выше говорит, что цепочка при этом выходит ровно у У27 и У28, у прочих трёх
   мест того же правила печать молчит.
2. Новый печатник `«Ходы допущением постусловия записи»` — цель постусловия, слово в
   слово стоящая `требует` СВОЕЙ функции, закрывается ходом
   `закрыть требованием «имя» строка N`. Строка требования ищется в блоке функции
   (`«Номер требования функции записи»`, по образцу `«Номер примера записи»`) и сличается
   знак в знак, а не вхождением.

Согласие печатника с переигрывателем проверено ДО перепечатки семени, побайтно:

* печать снята толкователем с правленого исходника (`«Строки утверждения»` через обёртку
  `zond-utv.flang` вне дерева);
* ровно эти байты вставлены в записи корпуса и прогнаны чекером.

| место | что напечаталось | что ответил чекер |
|---|---|---|
| `types` Т5 | `ход цель / ход 1 закрыть требованием «список непуст» строка 54 / ход конец` | сведений 5 → 6, на слово 2 → 1, код 3 как был |
| `abilities` У27, У28 | цепочки из 3 и 8 ходов через `Вхождение в выписанный список` | сведений 35 → 37, на слово 22 → 20, код 3 как был |

Снос печати на нетронутых местах — пять контрольных утверждений (`abilities` У1, У3,
У25; `types` Т1; `binder-hides-the-condition`) напечатаны базовым и правленым
`zapis.flang` через один и тот же толкователь: **байт в байт, расхождений 0.**
Контроль обратный: на Т5 базовый печатник молчит, правленый печатает — значит подмена
модуля работала.

**Доля после перепечатки, померенная тем же прибором** (записи корпуса с вставленными
байтами печати, набор прогнан линейкой):

```
ЧИСЛИТЕЛЬ 520   ЗНАМЕНАТЕЛЬ 651   доля = 520 / 651 = 79.88 %
на слово ядра: посылок и утверждений 106 (было 109)
```

Знаменатель не двинулся ни на место: ходы печатаются под уже объявленными
утверждениями, новых обязательств не заводится.

## 5. Чего в ядре нет вовсе — названо прямо

* **Волна «тождество после переписки», 19 мест.** Все 19 — тела со `свёрткой` либо
  `разбором`. Печатник С2 (`«Ходы тождества постусловия записи»`) молчит по построению:
  он выпускает `развернуть → закрыть тождеством` только когда стороны после развёртки
  тождественны. Чтобы напечатать эти 19, печать обязана уметь развернуть свёртку и
  ветвь разбора НА ОДИН ШАГ и внести гипотезу индукции — этого в `zapis.flang` нет.
  Формат для такого хода есть (`ход дано N предположение по «х»`, `ход N замена по дано N`
  — стоят в `precondition` и `stack` и проигрываются), печатника нет.
* **Волна «разбор цели по условию», 23 места.** Нужен факт о типе довода. Это ровно то,
  ради чего заведён блок `вывод` (ADR-0022 §3.10) и ведомость `ПРАВИЛА-ВЫВОДА.tsv`;
  ни печатника, ни приёма `вывод` в дереве сегодня нет.
* **Волна «гипотезы индукции», 13 мест.** Печатать здесь нечего: шаг
  `по предположению` пишет АВТОР в исходнике, ядро его лишь переносит. Место снимается
  другим путём — когда `проиграть_узел` переиграл узел, чекер вычитает шаги этой теоремы
  (`сверщик.c`, `моих_не_проигрываемых`). Замер: на всех восьми записях с такими шагами
  узел либо «вне приёма сверщика» (7 записей), либо снял другие места. Значит волна
  упирается в приём УЗЛА, а не в печать, и печатника ей заводить не надо.

## 6. Где не уверен

1. Предсказанная доля 79,88 % снята подстановкой напечатанных байтов в записи корпуса, а
   не полной перепечаткой. Полная перепечатка меняет и другие разделы записи (секции
   тотальности); отсутствие сноса измерено на пяти утверждениях, а не на всех 242.
2. Разложение §3 «нужен закон отношений» (20 мест) сделано чтением целей, а не приёмом,
   который бы их закрыл: сколько из них закроется ведомостью правил вывода — не измерено.
3. Доля 24 мест правил вне списка печатника, которым «не хватает факта о типе», — тот же
   разбор чтением; прогоном подтверждено только то, что сегодняшний планировщик их не
   закрывает.
