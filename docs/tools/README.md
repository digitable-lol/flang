# docs/tools — два разреза доли доказанного

Две программы на Python, которыми снимали разрезы доли доказанного. Обе читают
готовый вывод двоичного (`flang ast` и `flang check --proof`), сами ничего не
собирают и в прогоны CI не входят.

| файл | что считает |
|---|---|
| [binder-goal-share.py](binder-goal-share.py) | долю доказанного в разрезе по первому слову тела функции и по форме цели |
| [binder-rule-reach.py](binder-rule-reach.py) | сколько недоказанных обязательств правило делает пригодными для пятого хода |

Читатель — тот, кто хочет повторить разрез. Приборы, которые гоняются постоянно,
лежат не здесь, а в `scripts/` и `docs/benchmarks/`.
