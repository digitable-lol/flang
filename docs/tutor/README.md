# flangtutor — уроки в терминале

`flangtutor` — двенадцать коротких уроков для тех, кто видит flang впервые.
Урок показывает готовую программу с одним-двумя пропусками. Вы вписываете
пропуски, а компилятор проверяет результат: разбор, типы, завершение, тесты и
значение функции. В уроках о доказательствах он проверяет ещё и отчёт
`flang check --proof`.

```sh
flangtutor
```

Программа ставится вместе с `flang` через `brew` или `asdf`. В репозитории она
запускается как `flang/bin/flangtutor`, перед этим соберите компилятор:
`make -C bootstrap`.

## Как проходит урок

Проводник выводит текст урока и шаблон программы. Пропуски в шаблоне помечены
⟨1⟩, ⟨2⟩, и проводник спрашивает их по очереди. После каждой строки он пишет,
какие слова языка, имена, числа и строки в ней распознал.

Пропуск в одну строку заканчивается клавишей Enter. Пропуск в несколько строк
заканчивается пустой строкой или точкой — об этом сказано в приглашении.
Отступ пропуска проводник добавляет сам. Вложенные строки (например, `дано`
под словом `пример`) набирайте на два пробела глубже.

Когда пропуски заполнены, проводник показывает программу целиком и отдаёт её
компилятору. Если проверка не прошла, он выводит сообщение компилятора и
спрашивает пропуски заново.

| Команда в уроке | Что делает |
| --- | --- |
| `.ответ` | показать правильное решение |
| `.шаблон` | показать шаблон ещё раз |
| `.бросить` | выйти; номер урока запоминается |

| Ключ | Что делает |
| --- | --- |
| `flangtutor` | начать или продолжить с урока, на котором вы остановились |
| `flangtutor --урок 3` | начать с указанного урока |
| `flangtutor --только 3` | пройти один урок |
| `flangtutor --сначала` | забыть пройденное |
| `flangtutor --список` | показать уроки и отметить пройденные |
| `flangtutor --язык en` | вести урок по-английски |
| `flangtutor --помощь` | справка |

Те же ключи латиницей: `--lesson`, `--only`, `--restart`, `--list`, `--lang`,
`--help`.

## Как набирать ёлочки

Имена функций, типов и модулей в уроках стоят в ёлочках: «Удвоить». Компилятор
принимает и прямые кавычки: "Удвоить". Ёлочки набираются так:

| Система | « | » |
| --- | --- | --- |
| Linux | Compose, затем `<` `<` (или Ctrl+Shift+U, `ab`, Enter) | Compose, затем `>` `>` (или Ctrl+Shift+U, `bb`, Enter) |
| macOS | Option+`\` | Option+Shift+`\` |
| Windows | Alt+0171 на цифровой клавиатуре | Alt+0187 на цифровой клавиатуре |

## Уроки

| № | О чём | Что проверяется |
| --- | --- | --- |
| 1 | модуль, функция, типы параметров и результата, вызов | `«Удвоить» от 21` равно 42 |
| 2 | несколько функций; одна вызывает другую | сумма квадратов 3 и 4 равна 25 |
| 3 | `пример` — тест внутри функции; ветвление | в функции есть хотя бы один тест, и все тесты проходят |
| 4 | список и `свёртка` (reduce) | сумма `[2, 3, 5]` равна 10 |
| 5 | `разбор` списка: пусто или голова и хвост; рекурсия по хвосту | произведение `[2, 3, 5]` равно 30 |
| 6 | тип с вариантами и `разбор` по ним | разобран вариант со строкой внутри |
| 7 | запись с полями; поле читается через точку | цена, умноженная на число штук, равна 60 |
| 8 | строки: склейка, длина, первый символ и остаток | `«Приветствие» от "мир"` равно "Привет, мир!" |
| 9 | постусловие (`обеспечивает`) и отчёт `flang check --proof` | в отчёте стоит «доказано 1» |
| 10 | предусловие (`требует`); коды возврата 0, 1 и 3 | постусловие доказано благодаря предусловию |
| 11 | теорема: доказательство по индукции | в отчёте стоит «доказано 1» |
| 12 | `flang run` и `flang emit`; вызов программы, переведённой на C | программа переводится на C и собирается |

## Язык уроков

Уроки написаны по-русски и по-английски. Язык задаёт ключ `--язык` или ключ
`language` в файле настроек [`.flangrc`](../guide/settings.ru.md). Если в
настройках выбран язык, на котором уроков нет, проводник сообщает об этом и
продолжает по-английски.

Код в уроках написан русскими ключевыми словами. Английские слова компилятор
принимает наравне с ними, их можно смешивать: `module`, `total функция`,
`accepts`, `returns`, `example`, `given`, `expected`. Имена в кавычках не
переводятся.

## Цвет

В терминале ключевые слова, имена в ёлочках, числа и строки выделяются разным
цветом. Цвет выключают переменная `NO_COLOR`, значение `TERM=dumb` и вывод не
в терминал.

## Где хранится номер урока

Номер последнего пройденного урока записывается в файл. Путь к файлу задаёт
переменная `FLANG_TUTOR_STATE`; значения «нет», «no», «0» и пустое выключают
запись. Без переменной берётся `XDG_STATE_HOME/flang/tutor`, а если и её нет —
`~/.local/state/flang/tutor`.

## Где проводник ищет уроки и компилятор

| Откуда запущен | Уроки | Компилятор |
| --- | --- | --- |
| из репозитория | `docs/tutor` | `bootstrap/flang` |
| из распакованного архива выпуска | `tutor` рядом с программой | `flang` рядом с программой |
| после установки | `../share/flang-tutor` | `flang` из `PATH` |

Переменная `FLANG` задаёт путь к компилятору и отменяет поиск.

## Формат урока

Урок — текстовый файл `NN-имя.lesson` с разделами `=имя раздела=`:

| Раздел | Что в нём |
| --- | --- |
| `номер`, `имя-ru`, `имя-en` | номер и название урока |
| `текст-ru`, `текст-en` | текст урока на двух языках |
| `шаблон` | программа; пропуск помечен `___` |
| `подсказки-ru`, `подсказки-en` | по строке на каждый пропуск |
| `впиши` | правильное решение: по строке на пропуск; многострочный пропуск кончается точкой |
| `хвост` | функция «Проверка урока», которую проводник дописывает к программе |
| `ждём` | значение, которое должна вернуть «Проверка урока» |
| `примеров` | сколько тестов должно быть в программе, не меньше |
| `отчёт` | строка, которая должна быть в выводе `flang check --proof` |
| последний раздел | язык, на который программа переводится командой `flang emit` |

Решение сравнивается не с текстом раздела `впиши`. Его проверяет компилятор,
поэтому засчитывается любая программа, которая проходит проверку и возвращает
нужное значение.

## Для разработчиков языка

Все уроки проверяются одной командой из корня репозитория:

```sh
bootstrap/flang io scripts/tutor-probe.fscript --plan Check --timeout 600000
```

Команда проходит все уроки с решениями из раздела `впиши`, затем каждый урок
отдельно. Потом она подаёт каждому уроку решение соседнего и ждёт ошибки.
Ещё она проверяет продолжение с запомненного урока, оба языка и цвет. Коды
возврата: 0 — всё прошло; 1 — есть расхождение, оно названо в выводе; 3 — нет
компилятора или уроков. Другой компилятор указывается полным путём после `--`.

Список ключевых слов для подсветки записан в `flang/bin/flangtutor`
(`LANGUAGE_WORDS`): в установленном пакете исходников компилятора нет. Та же
команда сравнивает этот список с таблицей лексера в `flang/self/lexer.flang`.

`flangtutor` — сценарий оболочки рядом с компилятором, как `vimtutor` рядом с
Vim. Ему нужны построчный вывод и чтение ответа с клавиатуры, а у `flang io`
их нет.
