# flangtutor — проводник по языку

Пять уроков для того, кто открыл flang впервые. Каждый урок — короткий текст,
задание и ваш ответ, который проверяет **сам компилятор**: разбор, типы,
завершаемость, прогон примеров и значение. Ничего не сличается со строками, и
списать нельзя — можно только написать работающую программу.

```sh
./flangtutor
```

Нужен собранный компилятор: `make -C bootstrap`.

Поставившему язык через `brew` набирать путь не нужно — проводник ставится
рядом с `flang` и зовётся одним словом:

```sh
flangtutor
```

Уроки он ищет сам: в дереве — рядом с собой в `docs/tutor`, в развёрнутом
архиве выпуска — в каталоге `tutor`, после установки — в `share/flang-tutor`.

## Как это устроено за столом

Проводник печатает урок и ждёт ответ. Ответ набирается целиком, начиная со
строки `модуль «Урок»`, и заканчивается строкой из одной точки. Пока ответ не
сошёлся, проводник печатает то, что сказал о нём компилятор, и спрашивает
снова.

| команда | что делает |
| --- | --- |
| `.ответ` | показать разбор урока |
| `.бросить` | выйти; место запомнится |

| довод | что делает |
| --- | --- |
| `./flangtutor` | начать или продолжить с того урока, где вы остановились |
| `./flangtutor --урок 3` | начать с названного урока |
| `./flangtutor --только 3` | пройти ровно один урок |
| `./flangtutor --сначала` | забыть пройденное |
| `./flangtutor --список` | перечислить уроки |
| `./flangtutor --язык en` | говорить по-английски |

Латиницей то же: `--lesson`, `--only`, `--restart`, `--list`, `--lang`,
`--help`.

## Уроки

| № | о чём | что проверяется |
| --- | --- | --- |
| 1 | модуль, функция, типы входа и выхода, вызов | значение: `«Удвоить» от 21` равно 42 |
| 2 | пример внутри функции; ветвление; циклов нет | компилятор насчитал хотя бы один пример и все они прошли |
| 3 | список и свёртка; изменения на месте нет | сумма `[2, 3, 5]` равна 10 |
| 4 | свой тип с вариантами и разбор по ним | разбор варианта со строкой внутри |
| 5 | обещание о результате и отчёт `flang check --proof` | в отчёте стоит «доказано 1» |

## Язык, которым с вами говорят

Уроки написаны по-русски и по-английски, а язык выбирается настройками —
файлом `.flangrc`, ключ `язык` (решение
[ADR-0024](../adr/0024-the-settings-file-and-the-language-of-output.md)).
Спросить, что выбрано сейчас:

```sh
sh scripts/flangrc.sh язык
```

Настройки допускают четыре кода, уроки написаны на двух. Выбран код, уроков на
котором нет, — проводник скажет об этом и продолжит по-английски.

Сами уроки написаны русскими словами языка. Английские слова flang принимает
наравне с ними, смешивать их можно, и ответ английскими словами засчитывается
так же: `module`, `total функция`, `accepts`, `returns`, `example`, `given`,
`expected`. Имена в ёлочках не переводятся ни в какую сторону.

Цвет выключается переменной `NO_COLOR` — достаточно её наличия.

## Где вы остановились

Номер последнего пройденного урока лежит в файле. Свой путь называет
`FLANG_TUTOR_STATE`; значения «нет», «no», «0» и пустое выключают запись вовсе.
Без него берётся `XDG_STATE_HOME/flang/tutor`, а если и его нет —
`~/.local/state/flang/tutor`.

## Как убедиться, что уроки проходятся

```sh
sh scripts/flangtutor-proba.sh
```

Проба гоняет проводника целиком верными ответами, потом каждый урок отдельно, а
потом подаёт каждому уроку ответ соседнего и требует отказа. Верные ответы
берутся из самих уроков, поэтому разойтись подсказке и проверке негде.
