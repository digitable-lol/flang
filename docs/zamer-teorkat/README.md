# docs/zamer-teorkat — две программы замера категорной поверхности

Две программы, на которых меряли категорную поверхность языка. Не прибор и не
набор проб: это материал замера, по одному файлу на вопрос.

| файл | что меряли |
|---|---|
| [class-string-to-string.flang](class-string-to-string.flang) | класс задач «строка в строку»: разбиение, замена, регистр, палиндром, префикс и суффикс, дополнение до ширины |
| [iso-object-to-category.flang](iso-object-to-category.flang) | изоморфизм объекта и категории на трёх модулях `flang/ct` — заказы, платежи, доставка |

Имя каталога транслитное (`zamer-teorkat` — «замер теоркат»), и это долг, а не
образец: правило имени и цена его починки — задачи 1419 и 1430. Переименование
здесь отложено нарочно, до записанного решения об области сторожа транслита.
