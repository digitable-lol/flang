# Проверка, зовущая свидетеля напрямую, не держит правило работающего слоя: изъятие не покрасило ничего

Две новые переписки ядра доказательств были вынуты по очереди — и **ни одна
проверка не покраснела**. Правила не было, а всё зелено. Причина не в правилах, а
в том, кого проверка спрашивает.

В рабочем пути доказательства считает слой, написанный на самом flang
(`flang/self/proof-kernel.flang`); `flang/src/proofterm.mjs` и
`flang/proof/reduce.mjs` — **свидетель**, по которому слой сверяется побайтово.
Проверка звала свидетеля напрямую:

```js
const об = obligations(программа, внешнее.results)
const ядро = checkProofs(программа, об.obligations)   // ← свидетель
```

Свидетеля я правил тоже, поэтому утверждения проходили. Работающий слой при этом
мог быть каким угодно.

**Как чинится.** Вердикт берётся оттуда же, откуда его берёт `flang check` и
ведомость, — из `внешнее.results.proofs`. Форма записи та же (`checked`,
`verdict`, `cases`), менять утверждения не пришлось, только источник.

**Чем подтверждено.** Ветка `vypusk/vyrazimost`, коммит `782d3639`. До правки
изъятие обеих переписок из `flang/self/proof-kernel.flang` красило **0**
утверждений; после — по 2 на каждую. Шесть правок работы проверены изъятием, все
шесть красят от 1 до 5 утверждений.

**Это тот же класс, что «проверка перестала сравнивать, но зеленеет».** Признак,
по которому третий случай ловится заранее, простой: **если у слоя есть свидетель,
спросите себя, кого зовёт проверка — и вынет ли изъятие из работающего слоя хоть
одно утверждение.** Если нет, проверка держит свидетеля, а не язык.

**Вторая дыра тех же утверждений, найденная тем же изъятием.** «Доказано»
проверялось без проверки того, что запись вообще проходит типы. Ядро работает по
дереву разбора, а `связь.ключ` разбирается всегда, поэтому при вынутом правиле
типов утверждение «правда доказана» оставалось зелёным — краснело только
утверждение про текст отказа. «Доказано» про программу, которая не собирается, —
не результат.
