# Указатель поиска по 244 страницам весит 371 КиБ, если класть заголовки и первые 700 знаков, а не весь текст

Сайт документации лежит на GitHub Pages: сервера нет, искать может только
браузер по заранее собранному указателю. Весь текст сайта в указатель не
помещается — он в восемь раз больше того, что мы кладём, и грузился бы дольше,
чем читается страница, ради которой его открыли.

**Чем подтверждено.** Замер снят `node docs/site/build.mjs` на дереве этой
работы, 244 страницы (189 из них — заметки этой базы):

| Что кладём | Знаков текста | Файл указателя |
|---|---|---|
| весь текст страниц | 1 817 915 | ≈ 2,9 МБ |
| заголовок + подзаголовки + первые 700 знаков | 170 800 | 371 КиБ (106 КиБ после gzip) |

Отбор по первым знакам работает не потому, что «обычно хватает», а потому что
так устроены наши тексты: заметка базы знаний начинается с утверждения, а
страница сайта — с того, о чём она. Проверено четырьмя запросами, у каждого
известен правильный ответ: «свёртка» находит справочник конструкций, «mkdtemp»
— заметку про макрос `_POSIX_C_SOURCE`, «сокращатель» — разбор случаев,
«тотальность» — страницу про признак «тотальная».

**Вторая измеренная вещь: одностороннего сравнения по началу слова для русского
мало.** Первая редакция сравнивала так: основа слова на странице обязана
начинаться с основы запроса. На «свёртка» → «свёртке» это работает, а на
«тотальность» → «тотальная» — нет: отсечение окончаний даёт «тотальност» и
«тотальн», и первое не начинается со второго ни в какую сторону. Запрос
«тотальность» не находил страницу «Что даёт признак „тотальная“» вовсе. Лечится
симметричным правилом (совпало, если любая из двух основ начинается с другой) с
порогом в четыре знака на короткую — без порога правило вырождается в «совпадает
всё».

**Чем ограничено.** Слово, которого нет ни в заголовках, ни в первых 700 знаках
страницы, поиском не находится — по нему страница молчит, хотя слово в ней есть.
Для длинных страниц вроде спецификации языка это заметно; лечится не увеличением
предела (вес растёт линейно), а отдельными записями на разделы страницы, если
такая нужда возникнет.

Числа привязаны к объёму дерева: 244 страницы на день замера. Указатель растёт
вместе с деревом линейно, поэтому его вес печатает сама сборка — рядом с числом
страниц.
