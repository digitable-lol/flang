# Список замыкания, взятый грепом, сторожит форму записи ввоза, а не ввоз, — и пустая база при этом читается как «столкновений нет»

Столкновение имён разводят двумя способами, и они не равны по цене:
переименовать в модуле, который пришёл последним (работает всегда, но копия
остаётся копией — замыкание двоичного растёт на весь модуль), или ввезти
(`использует … только «Имя»`) и своё объявление убрать. Так уже сделаны три
генератора из восьми: `emit-go.flang`, `emit-rust.flang` и `emit-js.flang`
ввозят помощников из `emit-c.flang`. Второе работает только если объявления
одинаковы — иначе это молчаливая подмена поведения.
`scripts/targets/identical-declarations.sh` отвечает, для скольких имён верно
второе. Одинаковость судится по разобранному дереву, а разбирает его flang:
`flang ast` даёт дерево одного файла без связывания; из дерева выбрасываются
места (`span`) — номер строки у копии другой, а объявление то же.

## Замыкание — у сторожа столкновений, не грепом

**Чем подтверждено.** Здесь стояло `grep -o 'из "[^"]*"'` по `compiler.flang`
— то есть замер сторожил форму записи ввоза, а не сам ввоз. Когда ввоз стал
писаться именем (`использует «Лексер flang»`, без `из "…"`), греп перестал
находить хоть что-нибудь: база оказывалась пуста, и замер уходил кодом 3 со
словами «смотреть нечем». Замерено на этом дереве: 27 строк `использует` в
`compiler.flang`, путей в них ноль. Замыкание теперь спрашивается у того, кто
разрешает имя в файл ровно так же, как двоичный, — у сторожа столкновений
(`flang/scripts/link-collision-guard.mjs`, функция «замыкание»). Одно место на
две работы: разойтись им нечем.

## Пустая база красная, а не ноль

Раньше здесь звался `flang ast -` со стандартного ввода, которого у двоичного
нет: он уходил кодом 2, отказ глотался в `/dev/null`, и отчёт печатал нули по
всем целям. Ноль от «чисто» неотличим, поэтому пустая база теперь — код 3
«НЕ СУДИЛ: смотреть нечем». Отсюда же образец отказа для переписи и замера
столкновений (задача 1312).

**Чем ограничено.** Сужение видимости (`только «А», «Б»`) не применяется:
берутся все свои объявления каждого модуля. Оттого «столкнулось» расходится со
связыванием на единицы имён — оно судит по суженному. Для вопроса «одинаково ли
объявление» это безразлично, а мера остаётся завышенной, не заниженной.
