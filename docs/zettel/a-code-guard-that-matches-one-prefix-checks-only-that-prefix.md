# Проверка кодов отказа смотрит только приставку `FLANG_`, поэтому восемь кодов из семнадцати обещаны прозой и не существуют нигде

В дереве есть проверка, которая требует, чтобы каждый код беды, названный
прозой, существовал в исходниках (`flang/scripts/code-guard.mjs`). Ищет она коды
одним выражением `/\bFLANG_[A-Z0-9_]+\b/`. Коды с другой приставкой она не
видит вовсе — то есть не проверяет, а молчит о них так же, как о тексте без
кодов.

**Чем подтверждено.** 20 августа 2026, дерево `github/main` `cb3b7a18`, ветка
`vypusk/bez-fts-v-proze`. Два прогона `git grep -hoE '\bFTS_[A-Z0-9_]+\b'` — по
`*.md` и `*.1` (проза) и по восьми расширениям исходников — и `comm` над
отсортированными списками:

- прозой названо **17** имён с приставкой `FTS_`;
- в исходниках существует **9** из них;
- **8 не существует нигде**: `FTS_COVERAGE_HOLE`, `FTS_PROPERTY_VIOLATED`,
  `FTS_PROPERTY_UNATTAINABLE`, `FTS_NO_UTILITIES`, `FTS_NO_UTILITY_EXAMPLES`,
  `FTS_UNKNOWN_UTILITY`, `FTS_UTILITY_INPUT_FIELD`, `FTS_UTILITY_INPUT_TYPE`.

Пять последних из восьми названы в `flang/core/SPEC.md` честно — как долг, «не
реализовано». А три первых стояли в `docs/overview.ru.md` и
`docs/guide/project-layout.ru.md` **как работающее поведение**: целый раздел
«Разбор суждений» с примером вывода, который сегодня не выдаёт ни одна команда.
Раздел прожил так весь срок после выноса старого проекта, потому что краснеть
было нечему.

**Чему учит.** Проверка, ищущая по приставке, проверяет ровно ту приставку и
создаёт впечатление покрытия для всех остальных. Дешёвая починка названа
числом: расширить выражение до `/\b(FLANG|FTS)_[A-Z0-9_]+\b/` — и сторож сам
предъявит те же восемь имён. Дороже, но правильнее — брать приставки не из
регулярного выражения, а из списка кодов, который печатает сам язык.

**Чем ограничено.** Замер — про коды отказа. Про переменные окружения то же
выражение не сказало бы ничего: `FTS_MODEL_PATH` попал в оба списка (в
исходниках он живёт только в комментарии, который объясняет, что переменная
УБРАНА), а прозой обещался как рабочий. Имена переменных этой проверкой не
покрыты вовсе.
