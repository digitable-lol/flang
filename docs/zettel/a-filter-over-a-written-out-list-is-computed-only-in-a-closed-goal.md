# Отбор по выписанному списку считается только у замкнутой цели

`отфильтровать [ … ] где …`, `голова [ … ]`, `пусто [ … ]` ядро СЧИТАЕТ — но
только правилом «вычисление замкнутой цели», то есть когда во всей цели не
осталось ни одного свободного имени. Достаточно одному имени попасть в ЗНАЧЕНИЕ
любого элемента списка — и ход останавливается, хотя предикат отбора от этого
имени не зависит.

**Чем подтверждено.** Две пробы одного дня, ветка `b/self-defunc`.

Замкнутая цель — считается:

```flang
тотальная функция «Пусто ли отбор»
  возвращает признак
  обеспечивает «отбор по несовпавшему ключу пуст» результат равен нет
  пусто (отфильтровать [(запись «Пара» с «ключ» равным "kind" и «значение» равным 1)] где «п» → («п».«ключ») равен "kind")
```
→ **доказано вычислением замкнутой цели**

Тот же отбор, но в элементе стоит параметр функции — не считается:

```flang
тотальная функция «Имя переменной П»
  принимает «имя»: строка
  обеспечивает «имя переменной сохраняется» («Строка П» от («Взять поле П» от результат и "name")) равен «имя»
  «Записью П» от [(«Текстом П» от "kind" и "var"), («Текстом П» от "name" и «имя»)]
```
→ **объявлено, не доказано**

**Что это стоит на живом файле.** В `flang/self/defunc.flang` этим заперты все
конструкторы узлов сразу: «у литерала числа вид literal», «у литерала лжи вид
literal», «у двучлена вид binary», «знак двучлена сохраняется», «тег становится
узлом вида construct», «узел переменной имеет вид var», «имя переменной
сохраняется», «сумма тегов печатается узлом вида sum», плюс «в отказе нет ни
программы, ни узла» в `hotswap.flang`. Девять обещаний, и все про одно и то же:
построили запись из выписанного списка полей — прочитали из неё поле по ключу.

**Чего не хватает ядру.** Считать `отфильтровать`/`голова`/`пусто` по
ВЫПИСАННОМУ списку, когда от свободных имён зависят только ЗНАЧЕНИЯ элементов,
а предикат отбора — нет. Это то же вычисление, что уже есть, только с разделением
«что считаем» и «что оставляем термом».

**Чем ограничено.** Замер про `отфильтровать` с предикатом по полю-строке.
Отбор, предикат которого сам зависит от свободного имени, сюда не относится и
считаться не может в принципе.
