# Сторож подделок обязан принимать код 3: с 0.7.17 «объявлено, не доказано» — это код возврата, а не только строка отчёта

`flang check --proof --json` в 0.7.17 отвечает кодом 3, если хоть одно
утверждение осталось «объявлено, не доказано» (справка: «уходит кодом 3 и БЕЗ
ключа»). Для подделки ядра это ожидаемый исход — её ложь ядро обязано не
взять. Отчёт при этом напечатан целиком. Сторож `kernel-forgeries.flang`
ждал нуля и назвал все двадцать честно отвергнутых подделок «отчёт о
доказательствах не сложился, компилятор ответил кодом 3» — двадцать ложных
нарушений при нуле настоящих.

Починка — функция «Отчёт сложился»: отчёт есть при кодах 0 и 3; 1 (отказ
проверки), 2 и обрыв отчёта не несут, и беда называется как раньше. Опасности
«принять пустой отчёт под кодом 3» нет: утверждение, пропавшее из отчёта,
ловит «Про пропажу» независимо от кода.

**Чем подтверждено.** dev `c8103f06d`: `bootstrap/flang check --proof --json
flang/test/fixtures/poddelka-istinnaya-vetv.flang` — код 3, отчёт 2
утверждения, оба «объявлено, не доказано». После починки план «Подделки
остаются недоказанными» — код 0; примеры файла — все; ведомость доказанного:
73 утверждения, доказано 69, сетка 4 (было 71/67/4).

**Чем ограничено.** Код честной половины («Подделки правды») тоже принимает 3,
но судит по вердиктам названных утверждений, так что недоказанная правда
краснеет по-прежнему — «Про мёртвое правило».
