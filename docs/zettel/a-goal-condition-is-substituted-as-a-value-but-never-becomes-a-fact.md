# Условие цели ядро подставляет значением, но фактом его не делает

Ход «разбор цели по условию» делит цель `если C то G иначе да` надвое,
ПОДСТАВЛЯЯ в неё значение `C` — `да` в одну половину, `нет` в другую. Никакого
факта из `C` при этом не выводится, и в половине «условие истинно» о `C` не
известно ничего.

Разница видна на двух пробах, отличающихся одним словом. Тело у обеих — `элементы`:

```
если (длина элементы) равен 0 то (длина результат) равен 0    иначе да  → ДОКАЗАНО
если (длина элементы) равен 0 то (длина результат) не больше 0 иначе да  → сетка
```

Первая проходит не потому, что ядро прочитало условие: после развёртки тела
заключение стало тем же самым выражением `(длина элементы) равен 0`, что и
условие, и подстановка `да` закрыла его как литерал. Второй нужен ФАКТ
«длина равна нулю», и его нет.

**Что из этого следует автору.** Условное утверждение доказывается тогда, когда
после развёртки тела его заключение либо совпадает с условием знак в знак, либо
от условия не зависит. Практически это значит: **пиши условие утверждения тем же
выражением, каким ветвится тело**. Так закрылось «при неположительном сколько не
отброшено ничего» у `«Отбросить первые»` (`flang/stdlib/lists.flang`): условие
утверждения `сколько не больше 0` — дословно условие `если` в теле.

**Чего это НЕ отменяет.** Заметка [[reading-if-conditions-closed-zero-goals]]
говорит про чтение условий `если` В ТЕЛЕ как фактов, и остаётся верной. Здесь
речь про условие САМОЙ ЦЕЛИ, и довод против него другой: не ловушка «не число», а
просто отсутствие такого хода.

**Чем подтверждено.** Обе пробы — два файла по десять строк, ветка
`u/dokazat-bibl`, `bootstrap/flang` 0.5.1. Целей формы `если C то G иначе да` в
`flang/stdlib` пятьдесят одна.
