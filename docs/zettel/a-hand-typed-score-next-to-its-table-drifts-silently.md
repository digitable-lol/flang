# Заголовок «ВЗЯТО N ИЗ M» рядом с таблицей, из которой он вычисляется, лжёт при первой же смене ряда

`scripts/guards/criterion-score-guard.fscript` пересчитывает счёт документа-критерия
по его же таблице.

**Зачем.** Заголовок «ВЗЯТО 2 ИЗ 7» — число, набранное руками, а рядом лежит
таблица, из которой оно вычисляется целиком. Стоит одному ряду сменить
состояние — и заголовок лжёт, а сказать об этом некому: заголовок с таблицей
ничем не связан, кроме памяти писавшего. Сторож даёт связь: рядов ровно M, ряды
пронумерованы Г1…ГM без пропусков и повторов, рядов в состоянии «взят» ровно N.

**Как узнаётся «взят».** В ячейке состояния есть «взят» и нет ни «не взят», ни
«снят», ни «пал». Ячейка, которую этим правилом не разобрать, красит сама:
состояние гейта, которое нечем прочитать прогоном, — то же самое число из
памяти.

**Чем подтверждено.** Документ-критерий `docs/КРИТЕРИЙ.md` (в дереве его может
не быть — тогда код 2, «судить нечем»).

**Чем ограничено.** Путь к документу подаётся доводом; без довода печатается
шапка и код 2.
