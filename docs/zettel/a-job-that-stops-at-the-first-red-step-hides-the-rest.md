# Работа CI останавливается на первом красном шаге и скрывает остальные — полный список красных даёт только локальный прогон всех шагов подряд

В `binary.yml` шаги работы идут по порядку, и работа падает на первом красном:
следующий красный виден только после починки предыдущего. Так за один день на
dev краснели «новыми» шагами три прогона подряд (34640121285, 34644149847 и
следующий), хотя ничего нового в них не было — они были скрыты с самого начала.

Метод, которым это снято: вынуть все `run:` пяти работ (`build`,
`guards-selftest`, `proof-checker`, `link-collisions`, `published-check`) из
YAML, положить каждый шаг отдельным файлом оболочки и прогнать пятью
очередями параллельно, не останавливаясь на красном; код и время каждого — в
свой файл. 46 шагов (сборка, кеш и учёт памяти пропущены) прошли за ~9 минут
стеной; самый долгий — потолок строк ядра (80 с) и «Опись дерева» (47 с).

Что показал прогон на dev `c8103f06d`: красных 5, из них один — известный долг
с `continue-on-error` («долг не вырос», потолок 63). Четыре настоящих, и
только один из них был виден в CI:

- «Расширения имени файла сведены к одному списку» — три файла на flang
  (`link-collision-tree`, `name-guard`, `word-occupancy`) отбирают по
  расширению, а в «Местах отбора» не названы (переписаны с `.mjs`, места не
  переехали); заодно у примера «Итог» число мест отставало на два выпуска
  (22 при 26 — `flang io` примеров не гонит, красным был только `check`);
- «Подделки ядра отвергнуты» — компилятор 0.7.17 отвечает кодом 3 на честно
  отвергнутую подделку, а прибор ждал нуля ([[a-forgery-guard-must-accept-exit-code-three]]);
- «Страница словаря покрывает таблицу» — К12 завёл три слова кванторов, а
  печатник словаря не знал, в какой раздел их класть;
- «Справочная страница (man) отвечает исходнику» — `flang.1` называет десять
  целей печати с `ts`, а `EMIT_TARGETS_WORDS` в `flang/src/emit/c/flang_repl.c`
  девять; цель `ts` двоичный печатает (проверено `emit --target ts` на
  `examples/leetcode/217-contains-duplicate.flang`: 4 файла), лгала строка
  справки. Сообщение «целей здесь ДЕВЯТЬ» там же оставлено: проза
  (`docs/README.ru.md:158`) его знает как вшитое в семя.

Плюс проба «Сторож обещаний о печати умеет краснеть»: её `sed` искал фразу
«из девяти», а проза с выпуска 0.7.17 говорит «из десяти» — подлог не
собирался. Проба с фразой, переписанной руками, устаревает вместе с прозой.

**Чем подтверждено.** Ветка `r/ci-zelenyy` над dev `c8103f06d`, 11 сентября
2026: после починок каждый из пяти шагов повторён той же строкой — код 0;
сайт: `node docs/site/build.mjs --check` — код 0.

**Чем ограничено.** Локальный прогон не равен раннеру: нет кеша двоичного,
другая машина (256 ядер, 499 ГиБ), `FLANG_TMP` свой. Шаги с `if:` на тег
(примеры stdlib) не гонялись.
