# Тип функции на английской поверхности не записывается словами: `to number` съедает встроенная форма

`функция из числа в число` разбирается. Дословный английский перевод
`function from number to number` — **нет**: лексер склеивает фразы от длинной к
короткой, и `to number` уходит целиком во встроенную форму «к числу»
(`toNumber`), а не в `to` + `number`. До проверки типов дело не доходит вовсе —
отказ приходит из разбора.

Лечится стрелочной записью того же типа: `number → number`.

**Чем подтверждено.** 19 августа при написании `docs/site/language.md`. Файл с
`accepts f: function from number to number` отвергнут:

```
FLANG_PARSE: у типа «функция» ожидалось 'to' и тип результата (строка 9, столбец 14)
```

Поток токенов той же строки, снятый `tokenize` из `flang/src/lexer.mjs`:

```
keyword:accepts | name:f | punct:: | keyword:function | keyword:from |
keyword:tNumber | keyword:toNumber | punct:, | name:x | punct:: | keyword:tNumber
```

`keyword:toNumber` вместо пары `to` + `tNumber` — вот вся беда. С
`accepts f: number → number` тот же файл проходит `flang check` зелёным.

**Чем ограничено.** На русской поверхности столкновения нет: «к числу» и «в
число» — разные слова, поэтому `функция из числа в число` разбирается. Проверено
только на этой паре фраз; других съеденных сочетаний не искали.

**Класс, а не случай.** Признак, по которому третье такое место находится
заранее: фраза одной поверхности начинается словом, которым на той же
поверхности **начинается более длинная встроенная фраза**. Найти кандидатов
можно сравнением столбцов `SURFACE_TABLE`: всякое многословное значение,
первое слово которого совпадает с однословным значением другого понятия.

**Рядом лежит вторая дыра той же таблицы, но другой природы.** У понятия `это`
(псевдоним типа, `alias`) английского написания нет вовсе — не занято, а не
заведено. Файл на английской поверхности пишет `тип «Invoice» это list «Line»`,
и это законно: поверхность не обязана быть полной. То же и у имён стратегий
надзора (`перезапустить`, `остановить`, `передать выше`) и у нормальной причины
остановки `норма` — это строки модели конкурентности, а не слова таблицы, и на
любой поверхности они пишутся по-русски.

**Число понятий таблицы — 149**, а не 148: `Object.keys(KEYWORDS).length` из
`flang/src/lexer.mjs`, и то же число печатает `docs/site/numbers.json`
(`словарь.понятий`).
