# `разбор` в цели даёт индукцию только при трёх условиях сразу, и нарушение любого роняет вердикт до сетки

Постусловие можно написать `разбор`ом по объявленной сумме — ядро тогда ведёт по
ней индукцию и печатает «доказано индукцией». Работает это в куда более узком
углу, чем кажется по удачным примерам. Условия три, и они независимы:

1. **результат функции — скаляр** (число или признак). Список — нет;
2. **в теле функции нет самовызова**;
3. **ни в одном случае цели не написано голое `да`.**

Нарушено любое одно — вердикт «сетка», даже если во всех случаях цели стоит `да`,
то есть доказывать нечего вовсе.

**Чем подтверждено.** Четыре выдуманных модуля, по одному различию в каждом;
`bootstrap/flang check … --proof --json` через ворота, ветка `b/sobraniya`,
основание `74bd0489`:

| что в функции | цель | вердикт |
|---|---|---|
| сумма из 3 вариантов, результат число, тела-константы | `разбор`, все случаи конкретны | доказано индукцией |
| то же, но один случай цели — `да` | `разбор` | сетка |
| то же, но результат — список | `разбор`, все случаи конкретны | сетка |
| то же, но в теле самовызов | `разбор`, все случаи конкретны | сетка |

Отдельная проба: у той же функции со списком-результатом цель
`результат равен пустой список` / `результат равен [о]` / `результат равен м` —
после подстановки тела ТОЖДЕСТВО в каждом случае, и всё равно сетка.

Обход для одного случая есть и работает: `если значение равен (вариант «Имя») то
… иначе да` доказывается там, где `разбор` уже нет. Годится только для варианта
БЕЗ полей — у варианта с полями равенство пришлось бы писать с конкретными
значениями полей, а их в постусловии взять неоткуда.

**Чего это стоит библиотеке.** В `flang/stdlib/hashmap.flang` три обещания
написаны `разбор`ом в цели — «Искать признак», «Звенья словаря», и они нарушают
все три условия разом: результат-список у одной, самовызов у обеих, и голое `да`
в случае «Четвёрка» у обеих. Оговорка «про „Четвёрку“ сказано „да“, там пришлось
бы звать себя» стоит не строки, а всего утверждения.

**Чем ограничено.** Мерено на суммах из трёх и четырёх вариантов и на результатах
типов «число», «признак», «список». Записи и объявленные суммы в результате не
проверялись.
