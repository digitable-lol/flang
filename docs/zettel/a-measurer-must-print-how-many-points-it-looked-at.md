# Замерщик обязан печатать, сколько точек ПОСМОТРЕЛ, а не только сколько прошло

«Чисто — 1 замер внутри порога» и «измерено 1 из 4, все внутри порога» — это два
разных сообщения об одном и том же прогоне, и первое читается как «всё хорошо».
Знаменатель обязан стоять в той же строке, что и числитель: без него неизмеренное
исчезает из вида, даже когда названо строкой выше.

**Чем подтверждено.** Ветка `u/port5`, перенос `flang/scripts/memory-guard.flang`.
Предшественница уже умела отличать ноль от замера — `/usr/bin/time -f %M` на этой
машине отдаёт `0` там, где ядро не даёт `getrusage`, и такие точки она называла
поимённо. Но последней строкой всё равно писала:

```
сторож пика памяти: НЕ ИЗМЕРЕНО 3 точ(ек) — «/usr/bin/time -f %M» дал 0: …
сторож пика памяти: чисто — 1 замер(ов) внутри порога            (код 0)
```

Смотрели одну точку из четырёх. Перенос печатает

```
сторож пика памяти: измерено 2 из 4, все внутри порога;
НЕ ИЗМЕРЕНО 2 …; пропущено точек «полного» прогона: 1            (код 0)
```

— и третье число тоже не молчание: у `flang io` нет доводов, поэтому ключа
`--полный` нет вовсе, и сколько точек из-за этого не тронуто, сказано числом.

**Порча, которой это проверено.** Мерка заменена на всегда отдающую ноль
(`/usr/bin/time -f 0`) — то есть машина сделана похожей на песочницу без
`getrusage`. Прогон НЕ позеленел: код 1, «НЕ ИЗМЕРЕНО НИЧЕГО — ни одна из 4
точек не снялась. «Чисто» здесь означало бы «смотреть перестал»».

**Чем ограничено.** Провалом отдельную неизмеренную точку делать нельзя: это не
беда дерева, а отсутствие мерки, и проверка, краснеющая на чужой песочнице,
будет выключена. Провал — только когда не измерено НИЧЕГО.

**Сколько точек снимется, на этой машине от прогона к прогону разное:** getrusage
отдаёт пик через раз. В одном прогоне снялась 1 точка из 4, в следующем 2. Это
довод к тому же правилу: число измеренных обязано печататься каждый раз, а не
считаться постоянным.
