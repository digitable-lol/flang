# Модуль, проходящий `flang check` в одиночку, всё ещё может сломать раскрутку столкновением имён

`flang check <мой-модуль>.flang` собирает замыкание ПО ЕГО СОБСТВЕННЫМ
`использует` — то есть видит мой модуль плюс тех, кого он сам ввозит. Столкнуться
там не с чем. Раскрутка собирает совсем другое замыкание: всё, что ввозит
`flang/self/bootstrap/compiler.flang`, — и мой модуль встаёт туда двадцать
восьмым соседом.

**Чем подтверждено.** 22 августа 2026, ветка `b/flang-dlya-ii`. Новый
`flang/self/mcp.flang` объявлял вспомогательную `тотальная функция «Сказать»`.
Сам по себе он проходил проверку начисто: «функций 39, из них с доказанным
завершением 39; замечаний нет», код 0. В раскрутке та же программа дала 27
замечаний за 865 секунд работы:

```
FLANG_TYPE: функция «Сказать» принимает 4 арг. («беды», «код», «сообщение», «узел»), а вызвана с 1
FLANG_TYPE: функция «Принять ведомость MCP» объявлена как «Шаг MCP», а тело даёт список «Беда»
flang emit: печать отменена — программа не проходит проверку, замечаний 27.
```

`«Сказать»` уже была — в `flang/self/types.flang`, четырёхаргументная. Связывание
взяло ЧУЖУЮ, и все мои вызовы поехали типами. Замечания при этом описывают
следствие, а не причину: ни одно из 27 не говорит слова «столкновение».

**Чем чинится за секунду вместо четверти часа.** Перед раскруткой сверить свои
объявленные имена со всеми именами дерева обходом текста:

```sh
grep -oP '^(тотальная функция|функция|объект|тип) «\K[^»]+' <мой>.flang | sort -u > мои
grep -hoP '^(тотальная функция|функция|объект|тип) «\K[^»]+' flang/self/*.flang \
  flang/self/bootstrap/*.flang flang/self/repl/*.flang flang/core/*.flang \
  flang/stdlib/*.flang | sort -u | grep -Fxf мои
```

На том же дереве это дало ровно одну строку — `Сказать`, — и переименование в
`«Сказать в MCP»` закрыло все 27 замечаний. Стоит проверка меньше секунды при
10 147 чужих именах.

**Чему учит.** «Проверено, замечаний нет» — утверждение о том замыкании, которое
собрала проверка, а не о дереве. Для файла, который поедет в раскрутку, зелёный
одиночный прогон не значит почти ничего: он не видел ни одного из соседей, с
которыми файлу предстоит делить пространство имён. Это тот же разряд, что и
сторож столкновений, обходивший один файл из тридцати шести и говоривший
«столкновений 0».
