# Цель, написанная через «не равен», ядру не видна: то же утверждение через «не (… равен …)» снимается разбором случаев — 12 обязательств из 24 на одном файле

Ядро снимает постусловие сведением цели с телом функции, и у него есть правило
«разбор случаев по внутреннему условию цели»: цель вида «если У то Ц иначе да»
при теле «если У то А иначе Б» разбирается по обеим ветвям. Правило читает
УСЛОВИЕ. Условие, написанное словами «не равен», для него другой узел — у
парсера это двучлен `neq` (`flang/self/parser.flang:1686`), а не отрицание
равенства, — и правило не срабатывает вовсе.

## Проба, 29 августа 2026

Двоичный `25605ce2dc63758bc8746e839a4e3481` (семя `bootstrap/compiler_flang.c`
и `.h` без правок, рантайм дерева `flang/src/emit/c`, блок настроек из шапки
семени). Три функции, одно и то же утверждение, три написания:

```
«Имя А»  обеспечивает если («Вид» от «т») не равен "named" то результат равен "" иначе да
         тело: если («Вид» от «т») равен "named" то "имя" иначе ""
         → объявлено, не доказано: ни теоремы, ни примеров

«Имя Б»  обеспечивает если не ((«Вид» от «т») равен "named") то результат равен "" иначе да
         тело то же
         → ДОКАЗАНО сведением цели с телом функции:
           правило «разбор случаев по внутреннему условию цели»

«Имя В»  цель как у А, и при ней пример
         → сетка 1 значение — пример подменяет приговор ровно там, где
           доказательства и не было
```

Два письма — одно утверждение. Сверено прогоном: функция, сравнивающая
`а не равен б` с `не (а равен б)`, на шести точках (минус ноль против нуля в
том числе) даёт «да» — `flang test`, примеров 6, прошло 6.

## Второе такое же место: пустой случай, вынесенный из свёртки

Цель «если пусто С то результат равен Н иначе да» при теле-свёртке не
снимается — ядро внутрь связывателя не заходит. Та же цель при теле

```
если пусто С
  то Н
  иначе свёртка С начиная с Н …
```

снимается правилом «разбор цели по условию». Значение тела не меняется: свёртка
пустого списка и есть начало. Меняется приговор — с «объявлено» на «доказано».

## Пример при доказанном приговор НЕ портит

«Имя Г» — цель через «не (…)» и при ней два примера — остаётся «доказано».
Значит доказывать с примером можно и нужно: пример не отнимает доказательства,
он отнимает только пустоту.

## Что это дало на настоящем файле

`flang/self/proof-initial.flang`, 94 своих обязательства. Шесть целей переписаны
с «не равен» на «не (… равен …)», у пяти свёрток вынесен пустой случай —
одиннадцать правок, ни одна не меняет значения ни цели, ни тела:

```
до    доказано 70, сетка 3, объявлено 21     (прогон 3327 с, 10,0 ГиБ)
после доказано 82, сетка 2, объявлено 10     (прогон 3993 с, 10,0 ГиБ)
```

**Двенадцать обязательств, а не одиннадцать.** Двенадцатое — «Есть имя
именованного»: его цель говорит о результате СОСЕДНЕЙ функции «Имя именованного»,
и оно снялось само, как только соседнее постусловие стало доказанным. Приговор
соседа — факт, на который ядро опирается; переписав одну цель, получаешь и те,
что на неё ссылаются.

Примеры файла при этом целы: `flang test flang/self/proof-initial.flang
--no-check` — примеров 687, прошло 687.

## Сколько этого в дереве

Строк обязательств, где в цели стоит «не равен»: 89 в 31 файле
(`grep -rE '^\s+(обеспечивает|требует)\b.*не равен' --include='*.flang'`).
Не всякая закрывается переписыванием — остальная часть цели тоже обязана
свестись, — но каждая из них сегодня не пробуется ВОВСЕ, и это свойство
написания, а не утверждения.
