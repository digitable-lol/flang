# Охрана равенством варианту открывает ветвь `разбор`, только если вариант НУЛЬМЕСТНЫЙ, а разбираемое — вызов

Приём «равенство варианту разводит цель по ветвям `разбор`» описан на странице
«Какие обещания ядро берёт» двумя половинами: нульместный вариант и вариант
с полем, восстановленным доступом. На телах, где разбирается **результат
вызова**, а не сам довод, работает только первая половина.

```flang
// разбираемое — ВЫЗОВ, груз варианта — запись
разбор («Найти процесс» от («бег».«процессы») и «имя»)
  случай «Нет процесса»      то «бег»
  случай вариант «Есть процесс» с «процесс» как «процесс»
                              то «С процессом» от «бег» и («С жизнью» от «процесс» и нет)
```

| охрана обещания | вердикт |
|---|---|
| без охраны | объявлено, не доказано |
| `если (…«Найти процесс»…) равен (вариант «Нет процесса») то Ц иначе да` | **доказано** |
| `если не ((…) равен (вариант «Нет процесса»)) то Ц иначе да` | объявлено |
| `если (…) равен (вариант «Есть процесс» с «процесс» равным («Процесс найденного» от (…))) то Ц иначе да` | объявлено |

То есть **дополняющая половина не берётся ни отрицанием, ни восстановлением
груза**, хотя вместе с первой она равносильна необходимому обещанию. Пара
пишется всё равно: первая половина даёт доказанное, вторая остаётся проверкой
при работе, и вместе они не слабее прежнего одного обещания.

**Чем подтверждено.** Прогон `bootstrap/flang check --proof` на пробном модуле
из восьми обещаний (ветка `b/conc-proof`, 24 августа 2026, двоичный семени
0.6.2): «А1 нет процесса» и «Б1 нет процесса» — доказано правилом «разбор цели
по условию»; «А2 есть процесс», «Б2 есть процесс», «Б0 без охраны» — объявлено.
Функция-доступ к грузу (`«Процесс найденного»`) в модуле есть, значит дело не
в том, что вариант «не восстановить термом».

**Две границы сверх этого, обе замерены на `flang/self/conc.flang`.**

1. **Ветвь берётся, только если её тело — ТЕРМ.** Довод (`«прогон»`, `«ход»`,
   `«сбор»`), литерал (`""`, `нет`) и плоская нульместная функция
   (`«Узел ничто»`) дают доказанное — восемнадцать мест. Ветвь, зовущая функцию
   с доводами, не даёт, **и даже когда постусловие вызванной само доказано**:
   так не взялись четыре, где ветви зовут `«Нет такого вида»`, `«Переполнил»`,
   `«Поставить таймер»` и `«Запись как узел»`.
2. **Только у цели-равенства.** Те же охраны над целью `не больше` дали ноль на
   четырёх местах: `(длина Т) не больше (длина Т)` этот двоичный семени не
   берёт, хотя в исходнике ядра правило рефлексивности с посылкой
   «не меньше 0» описано.

Итог доли: `flang/self/conc.flang` 101 → 123 доказанных при 186 → 200
обещаний, сетка 10 без изменений; по файлу вместе с ввезёнными
441 → 463 из 782 → 796.

**Чем ограничено.** Замер снят там, где разбираемое — ВЫЗОВ над проекцией
довода (`«Найти процесс» от («бег».«процессы») и «имя»`), а груз варианта —
запись объявленного объекта. Замеры страницы, давшие «26 из 26», сняты на
`monad-expand.flang` и `bounded.flang`, где разбирался САМ ДОВОД. Какая из двух
разниц решает — не выяснено; проверяйте прогоном, а не по правилу.
