# Обещание, дописанное звену хвостового круга, стирает батут из напечатанного кода — и главный цикл вычислителя становится рекурсией по стеку

Печать в C сворачивает хвостовую рекурсию двумя приёмами: самовызов в хвосте —
в `for (;;) … continue;`, взаимный хвостовой круг — в батут (`fl_trampoline`).
Оба приёма стоят на одном признаке, и он записан ДОКАЗАННЫМ обещанием в самой
печати (`flang/self/emit-c.flang`):

```flang
// Функция с постусловиями хвостовых вызовов не имеет: интерпретатор тоже не
// переиспользует кадр, которому есть что проверить после возврата.
функция «Хвостовые вызовы»
  обеспечивает «у функции с постусловиями хвостовых вызовов нет»
    если (длина («функция».«постусловия»)) больше 0 то результат равен пустой список иначе да
```

Отсюда цепочка, у которой нет ни одного лишнего звена:

```
дописали «обеспечивает» звену круга
  → у звена НЕТ хвостовых рёбер («Хвостовые вызовы» отдаёт пустой список)
  → в графе хвостовых рёбер круга больше нет
  → «Циклические функции» компоненту не берёт (в ней меньше двух имён)
  → батут не печатается
  → круг стал настоящей рекурсией по стеку хозяина
```

**Ничего в теле не изменилось. Изменилась только объявленная спека.**

## Как это выглядело на дереве

`flang/self/interpret.flang`: `«Прогон»` → `«Виток»` → `«Дальше после шага»` →
`«Прогон»`. Главный цикл вычислителя, зов на каждом ребре — в хвосте.

В напечатанном компиляторе дерева (`bootstrap/compiler_flang.c`, печать от
23 августа 2026 из `58b037c2`) стоит:

```c
/*
 * Функция flang «Прогон».
 * Взаимная хвостовая рекурсия с «Дальше после шага», «Виток»: вызовы идут через батут.
 */
```

В том дереве у всех трёх звеньев не было ни одного `обеспечивает`. 23 августа в
12:26 UTC коммит `ea59db47` «Вычислитель: утверждения о поведении у 158 функций»
дописал в файл 156 обещаний — по одному на каждое звено в том числе. С этого
момента круг печатается рекурсией: **три кадра стека хозяина на каждом витке
машины.**

## Счёт по дереву

Признак «даровое ребро» — зов в хвостовой позиции у зовущей БЕЗ постусловий,
тот же, по которому строит рёбра сама печать. Посчитано по всем
`flang/self/**`, `flang/stdlib/**`, `flang/conc/**`:

| | функций | в батутах (групп) | самовызовов в `for(;;)` |
|---|---:|---:|---:|
| 23 августа, `58b037c2` | 10 108 | 155 (57) | 318 |
| 27 августа | 11 589 | 87 (30) | 141 |

Плоский стек потеряли **262 функции**, распалось **30 батутных групп из 57**.
Разметка сверена с напечатанным C по именам: там батут у 145 функций, здесь по
тому же дереву 155, совпало 129 — расходятся однофамильцы из разных файлов и
функции вне замыкания одной точки входа. Оба числа таблицы сняты одной
разметкой.

Причина роста видна в том же счёте: доля функций с обещанием за четверо суток
поднялась с **7 % (667 из 9 636)** до **66 % (7 099 из 10 819)**.

## Что этим признаком НЕ ловится

Круг, у которого зов стоит не в хвостовой позиции — аргументом другого зова или
внутри `отобразить`, — платит кадром и без всяких обещаний, и снятие сторожа ему
не поможет. По дереву раскол ровный:

```
кругов всего                                        541
  даровых уже сейчас                                128
  платят ТОЛЬКО из-за обещаний                      214
  платят и без обещаний (зов не в хвостовой позиции) 199
```

Пример второго рода — `«Овеществить»` ↔ `«Овеществить поля»` в том же
`interpret.flang`: спуск идёт через `отобразить`, и постусловие там ни при чём
(замер соседей, `576149cf`: вложенный вход на 1 000 уровней даёт глубину 1001 и
с обещанием, и без него).

## Отчего это ловится поздно и не тем именем

Отказ приходит не от того, кто копил кадры, а от того, кому кадра не хватило
последним. Перепечатка 27 августа 2026 умерла так:

```
FLANG_RECURSION_LIMIT: функция «Овеществить» превысила предел глубины вызовов (200000) на глубине 200001
```

`«Овеществить»` столько кадров не берёт, и это снято прогоном на НАСТОЯЩЕЙ
функции (проба ввозит `flang/self/interpret.flang` модулем): список из 1 000
скаляров — глубина 4, из 10 000 — 5, запись с 1 000 полями — 5. Длина не стоит
ничего, потому что спуск идёт через `отобразить`, а `отобразить` и у
вычислителя (`«Кадр шага обхода»`), и у печати в C (`for (size_t …)`) — цикл.
Кадр берётся на ярус вложенности, а вложенность настоящих деревьев двузначная:
наибольшая вложенность скобок во всём дереве — 36, самый глубокий напечатанный
AST — 62 яруса JSON.

## Что с этим делать, не трогая обещаний

1. **Дать функции `пример`.** Снятие сторожа при печати
   (`flang/self/bootstrap/compiler.flang`) требует вердикта `доказано` И
   `grid > 0` — хотя бы одного `пример`. Снятое обещание в напечатанный код не
   едет, значит хвостовые рёбра на месте, значит батут возвращается. Обещание
   остаётся в исходнике и остаётся проверяемым у `flang run` и `flang test`.
   Замер: из 77 звеньев распавшихся групп **62 без единого примера**, готовых к
   снятию групп — **ноль**.
2. **Снять обещание с кольца, не убирая его:** тонкая обёртка с `обеспечивает`,
   тело без него, в круге — тело. Проверка становится разовой, а не пооборотной.
3. **Разрезать круг явным состоянием** — `«Словарь описаний»` (10 005 кадров →
   13) и коммит `3991810f` (круг печати литералов 51 → 46).
