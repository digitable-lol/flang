# Обещание с условием «аргумент равен вариант» разворачивает ветвь `разбор`а

Считалось, что к `разбор`у ядро цепляет только индукцию, а развернуть отдельную
ветвь в постусловии нечем. Это верно для условия `пусто X` и неверно для условия
по варианту суммы.

Замерено на `packaging/install-check.flang`, `scripts/storozh-ssylok.flang` и
`scripts/storozh-formuly.flang` (двоичный `bootstrap/flang`, август 2026).

**Разворачивается** (вердикт `proved`, правило «разбор цели по условию»):

```flang
обеспечивает «пока ничего — читаем settings.txt»
  если отклик равен (вариант «Пока ничего»)
    то результат равен (вариант «Сделать» с поручение равным … и потом равным …)
    иначе да
```

Тело при этом — `разбор отклик` с таким случаем. Ядро сводит цель к телу так же,
как разворачивает первую ветвь `если`. Работает и когда вариант с полями:
условие пишется с полями через `с … равным …`. Так закрылись все семь
разборов по `«Отклик»` в двух сторожах и обе развилки по `«Ход»`.

**Не разворачивается** (вердикт `declared`): то же по списочному `разбор`у,
когда условие — `пусто X`:

```flang
обеспечивает «пустой список шагов — провал со своим кодом»
  если пусто шаги то результат равен (вариант «Провал» с …) иначе да
```

Ядро отвечает «объявлено, не доказано: ни теоремы, ни примеров». Списочный
`разбор` и `если пусто` — разные формы, и сведения между ними нет.

Практический вывод: у функции-обработчика, разбирающей сумму, дешёвое доказуемое
обещание пишется по варианту, а не по `пусто`. У функции, разбирающей список,
дешёвого обещания о ветви нет — там берут длину.
