# Посылка, закрытая шагом автора, несёт правило сведения ровно так же, как закрытая ядром

Сверщик доказательств считал «принято на слово ядра» по полю `закрыта`: посылки
со значением `reduction` — на слово, посылки со значением `term` — проверены.
Это занижало долг.

Поле `by` (`term`/`reduction`) говорит, ЧЕМ закрыт случай — шагом, который
написал автор, или сведением, которое ядро нашло само
(`flang/self/proofterm.flang`, «Случай вердикта»). Но рядом в той же строке
записи стоит поле `rule`, и оно заполняется В ОБОИХ случаях. Причина простая:
шаг автора `по предположению` только ПОДАЁТ допущение; вывести из него
заключение посылки всё равно должно ядро, и правило, которым оно это сделало,
названо. То есть три тысячи строк сведения стоят и за посылками, закрытыми
шагами.

**Чем подтверждено.** `flang/proof/examples/stack.flang`: обе теоремы доказаны
шагами автора, все четыре посылки записаны как `закрыта term`, и у двух из них
стоит непустое `правило «неотрицательность по построению»` /
`правило «тождество после переписки допущением»`. Старый счёт печатал «принято
на слово ядра 0» — то есть молчал о двух настоящих долгах.

Исправлено: считаются посылки с НЕПУСТЫМ правилом.

**Чем ограничено.** Посылки с пустым правилом (`правило «»`) закрыты не
сведением, а вычислением замкнутой цели, и на слово там не принимается ничего.
