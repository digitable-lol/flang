# Функция-значение, применённая к записи с самой собой, проходит как тотальная и не останавливается

Комбинатор Ω, построенный ВНУТРИ программы, двоичный 0.7.23 принимает: оба тела
«доказано композицией: рекурсии нет», `flang check` — код 0, а `flang run` крутится
до снятия по сроку.

```flang
объект «Ящик»
  ф: функция из «Ящик» в число

тотальная функция «Омега»
  принимает ящик: «Ящик»
  возвращает число
  ящик.ф от ящик

тотальная функция «Запуск»
  возвращает число
  «Омега» от (запись «Ящик» с ф равным функция «Омега»)
```

**Чем подтверждено.** Ствол `9da348850`, двоичный 0.7.23: `flang check omega.flang`
— «проверено … замечаний нет», код 0; `timeout 30 flang run omega.flang --function
Запуск` — снят по сроку, код 143. `docs/archive/hof.md` утверждает обратное: «Программа,
которая строит тег «Ω» сама, ловится анализом: ребро «Ω» → «Ω» не убывает». В
двоичном такого ребра нет.

**Что видно рядом.** Нумералы Чёрча (`docs/examples/numbers/church-numerals.flang`):
«Следующее» применяет к аргументу тег, который может оказаться тегом «Следующее», и
анализ тоже пишет «рекурсии нет». Там это безвредно — вложенность тегов конечна и
убывает, — но значит, что ребра через применение тега анализ не строит вовсе.

**Чем ограничено.** Чинится в анализе завершаемости (`flang/self/totality.flang`,
вход печати): ребро от функции, применяющей значение типа «функция из Т в …», к
каждой функции, чей тег программа строит с подходящим типом. Без печати не чинится.
