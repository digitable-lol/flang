# Обход дерева надзора написан свёрткой, потому что взаимная рекурсия четырёх функций завершения не доказывает

Подъём по дереву надзора («отказал процесс → его надзор → выше → …») естественно
пишется четырьмя взаимно рекурсивными функциями — так он и написан в
`flang/self/conc.flang`, где все четыре объявлены как `функция`, а не
`тотальная функция`. Для узла нужна была тотальность: модуль печатается во все
восемь целей и не должен приносить туда недоказанное завершение.

**Что не сработало.** Топливо-список (обычный приём: параметр, у которого на
каждом витке берётся хвост) не помогает, если цикл проходит через несколько
функций. Анализ завершаемости требует убывания **на каждом ребре цикла**, а не
по циклу целиком, и честно это называет:

    тотальная функция «Ступень с надзирателем»: вызов «Ступень по стратегии»
    в цикле «Ступень надзора» → «Ступень по связи» → «Ступень с надзирателем»
    → «Ступень по стратегии» не убывает — аргумент 7 («запас») — это сам
    параметр «запас», а не его часть

Убывание есть ровно на одном ребре из четырёх — там, где список разбирается
образцом «голова и хвост». На остальных трёх убывать нечему по построению: они
только передают уже уменьшённое дальше.

**Что сработало.** Подъём переписан СВЁРТКОЙ по списку надзирателей: состояние
поиска («дерево», «цель», «это процесс», «ищем», «веления») сворачивается ровно
столько раз, сколько в дереве надзирателей. Свёртка тотальна по построению, и
взаимная рекурсия исчезает вовсе — вспомогательные функции становятся обычными
шагами, вызываемыми один раз.

Две мелочи, которые пришлось назвать явно:

- **свёртка не умеет останавливаться**, а решение обязано быть одно, — поэтому в
  состоянии есть признак «ищем», гасящий оставшиеся витки;
- **витков нужно N+1, а не N**: цепочка из N надзоров решает за N ступеней, а
  чтобы узнать, что над последним никого нет, нужна ступень N+1. Отсюда одна
  ступень поверх свёртки.

Тем же приёмом переписан обход подопечных: слой за слоем, по одному витку
свёртки на слой.

**Чем подтверждено.** `flang/conc/supervisor.flang`, ветка `u/uzel`, коммит
`c4ef71df`: 34 функции, **34 тотальных**, `flang check` без замечаний, 3 примера
из 3. Первая редакция с четырьмя взаимно рекурсивными функциями давала 2
замечания `FLANG_NOT_TOTAL` и 5 функций без доказанного завершения.

**Чем ограничено.** Приём годится, когда глубина обхода ограничена длиной
имеющегося списка. Где такой границы нет, свёртка не заменяет рекурсию.
