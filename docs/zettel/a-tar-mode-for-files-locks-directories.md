# Режим `--mode=u=rw,go=r`, заданный ради повторимости архива, запирает каталоги наглухо

Команда упаковки релиза задаёт права явно, чтобы архив был побайтово повторим:
`tar --sort=name --format=ustar --owner=0 --group=0 --numeric-owner --mtime=@0
--mode=u=rw,go=r`. Пока в архиве были одни файлы, это работало. Первый же
добавленный **каталог** приехал правами `0644` — то есть **без права входа**, — и
распаковавший получил «Permission denied» на первом же обходе.

**Лечится буквой `X`, как у chmod:** `--mode=u=rw,go=r,a+X`. Заглавная `X` даёт
право исполнения только каталогам, файлы оставляет `0644`.

**Чем подтверждено.** Ветка `vypusk/put-ustanovki`, 20 августа 2026. Прогон
проверки пути установки упал на распаковке словами
`filesystem error: directory iterator cannot open directory: Permission denied`.
После замены режима: `drwxr-xr-x` у трёх каталогов, `-rw-r--r--` у файлов.
Повторимость не пострадала — две упаковки одного дерева с `touch` между ними
дали один sha256.

**Чему учит шире.** Режим, придуманный для файлов, применяется и к каталогам, и
эта разница не видна, пока каталогов нет. Признак: любое место, где права
задаются одной строкой на весь набор, ломается ровно в тот день, когда в набор
кладут первый каталог.
