# Пробе под терминалом не нужен Python: `script` и подача со сроками нажимают те же клавиши

Проба оболочки (`scripts/repl-probe.fscript`) и проба проводника
(`scripts/tutor-probe.fscript`) судят то, что видно только под терминалом:
правку строки, дополнение по Tab, цвет. До 30 сентября 2026 псевдотерминал им
давал Python (`pty.fork`, 90 и 50 строк драйвера внутри `.sh`). Теперь его даёт
`script -qec "<команда>" /dev/null` из util-linux, а клавиши подаёт конвейер
слева от него: `{ sleep 1; printf '%b' '…'; sleep 0.3; …; } | script …`. Сырой
вывод терминала приезжает в план откликом «Процесс завершён», и всё остальное —
снять управляющие последовательности, найти строки-ответы, посчитать
перерисовки — делает сам план чистыми функциями с примерами.

**Чем подтверждено.** Дерево `gh/dev` `f6e8fe734`, двоичный 0.7.23, util-linux
2.41.3, 30 сентября 2026. Старая и новая пробы оболочки на одном дереве дали
один и тот же текст (разошлись две строки: подсказка с командой и хвост про
файл `pty.out`) и один код: 1 на стволе (отпечаток отстал, задача 5824), 0 на
копии с поправленным отпечатком. Время 80,5 с → 87 с; три прогона нового
подряд — текст совпал знак в знак. Четыре подложных двоичных покраснели каждый
своей строкой: чужой отпечаток в `--version`, ESC под трубой, снятый цвет,
оболочка без редактора строки (`cat | flang repl`).

Три вещи, которые пришлось выяснить прогоном:

- **Конец ввода подаёт сам `script`.** Когда подача кончилась, `script` получает
  конец файла на входе, шлёт терминалу знак конца ввода и ждёт, пока потомок
  выйдет. Поэтому подаче не нужно держать ввод открытым «на всякий случай»:
  проводник под терминалом кончает работу через полсекунды после ответа, а не
  через 20 с, как у драйвера на Python, который ждал срок и убивал.
- **Срок тишины хозяина плана — не предохранитель для зависшей оболочки.**
  По справке `flang io --help` убитый по `--timeout` потомок отдаёт «Сбой»
  `FLANG_IO_TIMEOUT` — без вывода, и судить становится нечего (прогоном здесь
  не снято, взято из справки). Предохранитель стоит внутри команды:
  `timeout -k 2 N script …`, и код 124 проба называет своей строкой.
- **Список правил вычисляется целиком.** `«Chosen»` из `scripts/rules.fscript`
  получает готовый список, то есть исход каждого правила посчитан до выбора.
  `подстрока` с концом за пределами строки в невыбранном правиле роняет пример
  (`FLANG_BUILTIN_ARGS: «подстрока»: конец -1 вне диапазона`). Вычисление,
  которое может отказать, ставится под `если`, а не в список правил.

**Чем ограничено.** `script` и `timeout` обязаны быть на машине; нет их — проба
оболочки отвечает кодом 3 («судить нечем»), а проба проводника называет строкой,
что цвет не судился, и судит остальное. Сроки подачи постоянные: на машине, где
выражение считается дольше 8 с, ответ не успеет, и проба покраснеет не по делу —
так же вёл себя и драйвер на Python. Журнал поручений плана несёт сырой вывод
терминала целиком (31 КБ у пробы оболочки): читать ответ глазами удобнее через
поле `result`.
