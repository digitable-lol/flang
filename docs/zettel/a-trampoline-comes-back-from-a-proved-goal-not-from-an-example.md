# Батут возвращает не пример, а доказанная цель: из семи распавшихся групп `types.flang` примера не ждала ни одна

Объявленное постусловие стирает у функции все хвостовые рёбра
(`flang/self/emit-c.flang:1411`, «Хвостовые вызовы»: `если (длина постусловия)
больше 0 то пустой список`). Компонента перестаёт быть кругом, «Есть батут»
отвечает нет, батут не печатается.

Обратный ход описан в `flang/self/bootstrap/compiler.flang`, «Постусловие
снимается», и условий там **два**:

1. вердикт ядра о цели равен «доказано» (или «доказано при условии»);
2. `grid` больше нуля — у функции есть хотя бы один `пример`.

Отсюда был сделан план: раздать примеры функциям, у которых обещание есть, а
примера нет, — и группы соберутся обратно. **План неверен, и вот чем это
снято.**

## Замер

Разбор `flang ast` для `flang/self/types.flang`, повтор «Обхода хвоста» знак в
знак и Тарьян по тем же рёбрам: групп взаимной хвостовой рекурсии ≥2 — 14, из
них распавшихся из-за обещания — 7. Ведомость (`flang check --proof`, 27 августа
2026, двоичный от 23 августа 16:00 UTC) даёт по ним такие вердикты:

```
Одинаковые виды                    сетка                  (примера не было)
Сопоставить                        сетка                  (примера не было)
Обойти элемент списка              объявлено, не доказано
Обойти элементы списка при проверке объявлено, не доказано
Связать поле варианта              объявлено, не доказано
Связать поля варианта              объявлено, не доказано
Собрать новое поле / поле / поля   объявлено, не доказано  (все три)
Собрать новый параметр / … / …     объявлено, не доказано  (все три)
Тип выражения / Тип пусть / Тип узла объявлено, не доказано (все три)
```

**Ни одного «доказано» среди ломающих обещаний.** Значит первое условие снятия
не выполнено нигде, и второе — примеры — ничего не решает: сторож остаётся,
рёбра остаются стёртыми, батута нет.

Проверено и прямо, а не только по ведомости: двум функциям («Одинаковые виды»,
«Сопоставить») дописано по два примера, `flang test` — 237 примеров, прошло 237.
После этого печать в C:

```
fl_trampoline 18   for(;;) 33   fl_post 464   _step( 28
проверок при работе снято 151
шаги батута наших групп: (пусто)
```

Ни `odinakovye_vidy_step`, ни `sopostavit_step` в напечатанном C не появились.
Примеры сетку с нуля значений подняли до двух — это настоящая проверка там, где
её не было, — но батут не вернули.

## Почему «объявлено, не доказано», а не «сетка»

У пяти групп из семи обещание одной формы:

```
обеспечивает «беды итога не убывают — Собрать поля»
  (длина («сбор».«беды»)) не больше (длина (результат.«сбор».«беды»))
```

Цель вида «не больше <выражение о результате>». Правил на форму цели у ядра три
— «не меньше 0», «не больше конечного литерала», «равно», — и этой формы среди
них нет. Ядро цель даже не берёт: не «посчитало на сетке», а «объявлено, не
доказано». Никакое число примеров этого не меняет.

У двух оставшихся вердикт «сетка», и разница с соседом по группе поучительна.
«Одинаковые типы» с почти такой же по смыслу целью — «доказано сведением цели с
телом функции: правило „разбор цели по условию“». Тело у неё начинается с
`если «Тип неизвестен» от «первый» то да иначе …`, и условие цели СОВПАДАЕТ с
условием `если` в теле — ядро делит цель по ветвям тела и закрывает обе. У
«Одинаковых видов» тело — `разбор «первый»`, а условие цели написано через
`(«Метка вида» от «первый») равен "unknown"`: делить нечего, и цель уезжает на
сетку.

То есть даже внутри одной группы одна и та же мысль в одной записи доказывается,
а в другой — нет. Это тот же класс, что
[[a-bare-boolean-goal-is-not-a-goal-kind-but-equals-yes-is]] и
[[a-bare-call-guard-blocks-the-goal-split-but-equals-yes-restores-it]].

## Что из этого следует для работы

Раздача примеров — не тот рычаг. Порядок обратный:

1. **сперва посмотреть вердикт** — `flang check --proof` и слово при цели;
2. «доказано» и нет примера — вот это возвращается одним примером;
3. «сетка» — переписать ЦЕЛЬ так, чтобы она делилась по телу (не тело!);
4. «объявлено, не доказано» — цель не той формы, и это упирается в три правила
   ядра. Либо цель меняется на выразимую, либо обещание снимается совсем.

И общее: **счёт «сколько групп ждут примера» надо снимать по ведомости, а не по
наличию слова `пример` в тексте функции.** Разница между этими двумя счётами
здесь — семь групп против нуля.
