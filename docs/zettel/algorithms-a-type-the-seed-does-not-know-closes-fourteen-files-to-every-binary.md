# Тип «неотрицательное» стоит в 14 файлах задачек, и его не знает НИ ОДИН двоичный в дереве — эти файлы сегодня нельзя ни проверить, ни доказать, ни напечатать

`AGENTS.md` рассказывает про 24 августа как про случай в прошедшем времени: слово
`неотрицательное` ввели в компилятор и применили в позициях типа одним
изменением, ствол перестал читаться, «полдня ушло на откат в 52 файлах». Откат
дошёл не везде.

**Замер 26 августа 2026.** Прогон
`flang check examples/leetcode/062-unique-paths.flang --proof` двоичным
`/srv/flang-rabota/w-predely/bootstrap/flang` отвечает не вердиктом, а отказом:

```
FLANG_UNKNOWN_NAME в файле examples/leetcode/062-unique-paths.flang,
строка 72, столбец 1: неизвестный тип «неотрицательное»
```

Слово стоит **типом** (`принимает ряды: неотрицательное`) в четырнадцати файлах:

```
examples/leetcode/  062 070 072 074 139 207 322 509 547 643 733 739
examples/rosetta/   factorial.flang  fibonacci.flang
```

**И это не про один отстающий двоичный.** Пересчитано по всем деревьям
`/srv/flang-rabota/*/bootstrap/`: строка `неотрицательное` не встречается в
напечатанном C **ни у одного** из них — ни у `w-predely`, ни у собранного
только что из своего семени. Слово живёт в `flang/self/**` и доедет до двоичного
только перепечаткой (`sh scripts/raskrutka.sh`).

**Чем это стоит платить.** 14 файлов из 110 — **12,7 % доли** — сегодня не
проверяются вовсе: не «доказано ноль», а отчёта нет, потому что типизация
отвергает файл целиком. Работать в них нельзя не потому, что ядро слабое, а
потому, что судить нечем: обещание, которое туда допишешь, не подтвердит и не
опровергнет ни один прогон.

**Что из этого следует делать.** Пока перепечатки нет — обходить эти файлы
стороной и **не дописывать в них обещаний**: непроверенное `обеспечивает`
уезжает в напечатанный код проверкой при работе, а здесь его даже не на чем
проверить. Английские близнецы пар при этом читаются: `fibonacci-english.flang`
несёт `nat`, а не `неотрицательное`, — то есть откат прошёл по одной поверхности
и не прошёл по второй.

**Чем подтверждено.** Отказ снят прогоном на четырёх файлах (062, 070, 322, 509)
в ходе доли `u/examples-algorithms-proved`; правки в них после этого откачены.
Список из четырнадцати — по `grep` слова в позиции типа, не в прозе: в 069
`неотрицательное` стоит только в комментарии, и файл проверяется нормально.
