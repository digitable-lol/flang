# Согласовать условие цели с телом не даёт ничего: из 189 «дешёвых» целей приём взял НОЛЬ, решает форма подцели

Прошлый счёт назвал 189 недоказанных условных целей, у которых тело уже
начинается с `если`, — и предположил, что им не хватает согласования условия цели
с условием тела. Образцом служила пара «Одинаковые типы» (доказано правилом
«разбор цели по условию») против «Одинаковых видов» (сетка).

**Предположение неверно. Проверено правкой и замером.**

## Опыт

В `examples/allocator/allocator.flang` пять целей записаны как
`если не X то P иначе да` при теле `если X то … иначе …`. Перестановка

```
если не X то P иначе да   →   если X то да иначе P
```

смысл сохраняет дословно: обе формы говорят «¬X влечёт P». После неё условие
цели совпадает с условием тела знак в знак — то самое согласование.

Ведомость до и после:

```
                 доказано  сетка  объявлено
до правки              82      7          1
после правки           82      7          1
```

Ни одна из пяти целей вердикта не сменила: как были «сетка», так и остались.
Правка откачена — она ничего не даёт и читается хуже исходной.

## Что решает на самом деле

Разбор одной функции решает вопрос целиком. У «Выдать из отрезка» **десять**
обещаний, и у всех десяти условие ОДНО И ТО ЖЕ —
`если не (отрезок.«длина» меньше сколько)`. Разделились они так:

```
доказано (5)                              подцель
  хватило — выдача удалась                результат.«удалось» равен да
  выданный адрес есть начало отрезка      результат.«адрес» равен отрезок.«начало»
  остаток начинается где кончается выданное  … равен …
  длина остатка есть прежняя без выданного   … равен …
  остаток равен вычисленному остатку      … равен …

не доказано (5)                           подцель
  адрес не левее начала отрезка           отрезок.«начало» НЕ БОЛЬШЕ результат.«адрес»
  конец выданного не правее конца отрезка  … НЕ БОЛЬШЕ …
  конец выданного не правее начала остатка … НЕ БОЛЬШЕ …
  выданное и остаток — по проверке        голый вызов-признак
  остаток плюс выданное — прежняя длина   равенство, требующее арифметики
```

Условие у всех одно, тело одно, разбор цели по условию работает одинаково.
**Решает форма подцели: «равен» ядро закрывает, «не больше ⟨выражение⟩» — нет.**

Это подтверждается и с другой стороны: из тех же 189 у **71** цели условие уже
совпадает с условием тела — и они всё равно не доказаны. Согласовывать там нечего,
а вердикта нет.

## Разбор 189 по классам

```
 94  условия разные по существу — трогать нельзя, это другое обещание
 71  условие УЖЕ совпадает — мешает не оно
 24  условие есть отрицание условия тела — безопасная перестановка
```

Из 24 «безопасных» проверено 5. Взято **0**.

## Что из этого следует

1. **189 было верхней границей, построенной на неверном механизме.** Настоящее
   число приёма — ноль. Месяц на переписывание условий сэкономлен.
2. **Рычаг остаётся прежним и он один** — правило на форму «⟨длина⟩ не больше /
   не меньше ⟨длина⟩»: [[one-goal-shape-blocks-a-fifth-of-all-unproven-promises]],
   446 целей, пятая часть всего недоказанного.
3. **Метод, который стоит перенять.** Чтобы отделить настоящую причину от
   правдоподобной, ищите место, где всё прочее совпадает: одна функция, одно
   условие, десять обещаний. Такая находка стоит любого счёта по дереву.
4. И про пару, с которой всё началось: «Одинаковые типы» доказаны не тем, что у
   них тело с `если`, а тем, что их подцель — `результат равен да`. У «Одинаковых
   видов» подцель та же, но тело `разбор`; значит там мешает третье, и мерить его
   надо отдельно, а не подводить под тот же приём.
