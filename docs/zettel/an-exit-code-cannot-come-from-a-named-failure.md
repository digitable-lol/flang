# Числовой код выхода нельзя вывести из именованного кода отказа — его берут из природы беды

Коды отказа языка — имена: `FLANG_IO_LIMIT`, `FLANG_PLAN`, и у варианта
`«Провал»`, которым программа сдаётся сама, поле `код` тоже **строка**.
Программа, которая хочет, чтобы CI на ней упал, обязана как-то дать процессу
ЧИСЛО, а числа у неё нет и взять его неоткуда.

Соблазн — завести таблицу «имя отказа → номер». Он отвергнут: это вторая таблица
кодов, которая начнёт расходиться с первой в тот день, когда кто-то добавит код
только в одну из них.

Соблазн второй — взять код выхода из результата плана, если результат оказался
числом. Тоже отвергнут, и довод сильнее «дорого»: результат плана — это ОТВЕТ, а
не вердикт о нём. План, честно посчитавший 7, вышел бы с кодом 7, и планам
пришлось бы запретить возвращать числа.

Работает третье: **число берётся не из значения, а из природы беды**. Место, где
известно, что решение приняла сама программа, ровно одно — ветка `«Провал»` в
цикле поручений. Там на брошенную беду ставится метка (символьный ключ, чтобы не
уехать в JSON вывода), а команда её читает и превращает в число. Программе для
нужного кода не надо знать ни одного числа — довольно вернуть `«Провал»`.

Разница, ради которой всё затевалось, — «нашёл беду» против «сам сломался». До
правки оба случая давали 1, потому что оба приезжали исключением, и красный CI
не говорил, чинить предмет или инструмент.

**Чем подтверждено.** Ветка `work/checks-in-flang`, коммит «Седьмое поручение и
код выхода…». `flang io` отвечает 0 — план дошёл до конца; 1 — план сдался сам;
2 — кривой вызов; 3 — сломался инструмент. Проверка «код выхода flang io: 0 —
дошли, 1 — программа сдалась сама, 3 — сломался инструмент» гоняет все четыре
через настоящий запуск команды. Снял различение (`return 1` вместо
`сдалсяСам(ошибка) ? 1 : 3`) — проверка краснеет: «предел поручений — это
сломался инструмент, а не нашлась беда», actual 1, expected 3.

**Чем ограничено.** Метка живёт на объекте беды и уезжает только внутри одного
процесса; хозяину в другой цели печати придётся завести свою — контракт здесь
не в поле словаря, а в описании кодов выхода. И `process.exit()` в команде
по-прежнему нет ни одного: код ставится один раз, `process.exitCode = await
main()`, иначе вывод не успевает уйти.
