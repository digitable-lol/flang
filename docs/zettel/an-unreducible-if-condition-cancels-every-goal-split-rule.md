# Условие `если`, которое не сводится к значению, отменяет ВСЕ правила разбора цели по выбору — даже те, которым условие не нужно

Ядро делит цель по условию тела-`если`, и делит хорошо: условие-ВЫЗОВ ему не
помеха, пока тело вызванной функции разворачивается на месте. Стоит телу
вызванной оказаться свёрткой — и отменяется не одно правило, а весь разбор по
выбору, включая правило «обе ветви под границей», которому значение условия не
нужно вовсе.

**Чем подтверждено.** Пара функций с телом `если <условие> то набор иначе
добавить что к набор`, различающихся ТОЛЬКО тем, чем записано условие. Прогон
`bootstrap/flang check … --proof --json` через ворота, ветка `b/sobraniya`,
основание `74bd0489`:

| условие | «не укорачивает» | «растит ровно на один» | «содержит новое» |
|---|---|---|---|
| встроенное `набор содержит что` | доказано | доказано | доказано |
| вызов функции с телом `набор содержит что` | доказано | доказано | доказано |
| вызов функции с телом-СВЁРТКОЙ | сетка | сетка | сетка |

Третья строка — не «свёртка мешает доказать про свёртку»: цели здесь про длину
РЕЗУЛЬТАТА, и свёртка стоит только в условии. Правило «выбор, у которого обе
ветви под границей» закрыло бы «не укорачивает» без всякого знания об условии
(`длина набор` не больше `длина набор` и не больше `длина набор плюс 1`), но
ядро до него не доходит: неразвернувшееся условие снимает разбор целиком.

**Чего это стоит библиотеке.** У `flang/stdlib/sets.flang` три обещания
«Добавить в множество» заперты ровно этим, и цена измерена подменой тела
«Есть в множестве» (только для замера, в дерево не внесено):

```
как в дереве                            доказано 4 из 18
тело «Есть в множестве» встроенным      доказано 7 из 18
то же плюс две перезаписи цели          доказано 8 из 18
```

Две перезаписи — `(длина множество) не больше (длина результат)` вместо
зеркального «не меньше» и голое `результат содержит новое` вместо
`(результат содержит новое) равен да`. При нынешнем теле обе по отдельности
дают ноль, проверено обеими.

**Чем ограничено.** Замер сделан на одной форме тела (`если` с двумя ветвями,
результат-список) и на одном модуле. Неизвестно, отменяются ли так же правила
разбора по выбору для целей о числах и признаках.

**Что из этого следует.** Заявка на правило ядра дешёвая и узкая: «если условие
выбора не сводится к значению, пробовать те правила разбора цели, которым
значение условия не нужно». На `sets.flang` она открывает три обещания, а с
двумя перезаписями цели — четыре.
