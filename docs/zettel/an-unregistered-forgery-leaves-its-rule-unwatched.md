# Подделка, не вписанная в сторожа, оставляет своё правило без надзора — таких оказалось пять из тринадцати

В `flang/test/fixtures/` лежало **13** файлов `poddelka-*.flang`, а в списках
`flang/scripts/poddelki-yadra.mjs` было названо **8** из них (плюс
`krug-tuda-i-obratno.flang` — честная половина одной пары, не подделка). Пять
подделок не проверялись ни разу: порядок соседних, индукция по строке,
вхождение по построению, упорядоченность сортировки, замкнутость цели у прямого
шага «по примеру».

Сторож при этом был **зелёный** и печатал «подделки отвергнуты: 9 файлов». Число
он брал из собственных списков, то есть отвечал «проверено столько, сколько я
собирался проверить» — утверждение, истинное всегда и не значащее ничего.

**Чем подтверждено.** Ветка `u/sostoyatelnost` над стволом `4c1b6aef`.
`ls flang/test/fixtures/poddelka-*.flang | wc -l` → 13; имена из списков сторожа
(`grep -oP '(?<=файл: ")[^"]+'` плюс имя из блока печати внизу) → 9 уникальных
путей. Пересечение считано скриптом: пять файлов мимо списка, **записей на
исчезнувшие файлы — ноль** (проверено `test -f` по каждому пути; предположение,
что часть записей висит на удалённых файлах, замером не подтвердилось).

**Что из этого следует для формы сторожа.** Список ожиданий и каталог обязаны
сверяться в обе стороны, и до запуска чего бы то ни было:

- файл `poddelka-*.flang` без записи → отказ словами «незарегистрированная
  подделка»;
- запись на файл, которого нет → отказ словами «запись на исчезнувший файл»
  (иначе такая проверка молчит вечно: она не может стать красной).

Обойти сверку можно ровно одним способом — вписать файл и сказать, чего от него
ждут. Разрешить «пропускать непонятое» нельзя: это и есть та самая зелёная
проверка, которая ничего не сравнивает.

**Итоговое число берётся из каталога, а не из списков.** Разница не
косметическая: счёт по каталогу — это утверждение «в дереве столько подделок, и
каждая под надзором», счёт по спискам — тавтология.

**Чем ограничено.** Сверка ловит только соглашение об имени `poddelka-*`.
Подделка, названная иначе (например `probe-forgery.flang` в
`benchmarks/proof-cost/`), в неё не попадёт. Имя — часть договора, и держится
оно тем, что все тринадцать файлов его соблюдают.
