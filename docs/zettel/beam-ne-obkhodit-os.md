# BEAM не обходит операционную систему, и C зависит от неё ровно так же

«Обойти ОС» означает работать на голом железе: свои драйверы сетевой карты,
диска, таймера, свой запуск процессора. Это и есть — написать операционную
систему.

**Ядра процессора принадлежат ОС.** Чтобы получить ядро, надо попросить у неё
поток. Другой двери нет.

**«C же не зависит»** — зависит. `printf` на Linux это системный вызов Linux,
`malloc` просит память у ядра. Скомпилируйте C для голого железа — не будет ни
печати, ни файлов, ни выделения памяти. Зависимость одинаковая; у C она просто
незаметна, потому что привычна.

**Юникернелы** — программа плюс минимальная ОС в одном образе, грузится прямо на
железе. Для Erlang такое есть (GRiSP). Но это не «обошли ОС», это «написали свою
маленькую».

**Что своё у BEAM — планировщик.** Он решает, какой процесс работает, сколько ему
дать, когда отобрать. У ОС планировщик про потоки, которых тысячи максимум. Свой
планировщик раскладывает миллионы лёгких процессов по десятку потоков ОС.
