# Жирный вокруг встроенного кода не собирался на сайте ни разу, и это было видно только глазом

Разметка `**`слово`**` в markdown сайта не превращалась в жирный: читатель видел
сами звёздочки текстом и `<strong>`, начатый не там, где надо. Причина —
в порядке разбора: строка резалась на куски по кавычкам встроенного кода, и
каждый кусок размечался ПОРОЗНЬ. Открывающие звёздочки оставались в одном
куске, закрывающие в другом, и пара не сходилась.

**Чем подтверждено.** Замер по собранному сайту до правки: **158 пар звёздочек
текстом на 40 страницах** из 145; после — 17 звёздочек на 5 страницах, и все
внутри `<code>` (шаблоны путей, `2**53`). Первой из сломанных шла «Первая
программа» — вторая страница, которую видит пришедший, и владелец назвал её
вёрстку «уебищной», не зная причины. Правка: код заменяется меткой U+0000,
разметка идёт по целой строке, код возвращается на место последним шагом
(`docs/site/markdown.mjs`, ветка `work/docs-razdely`).

**Чем ограничено.** Правка чинит разбор, а не оглавление: заголовок, в котором
стоит `**СДЕЛАНО**`, по-прежнему попадает в боковой список со звёздочками —
оглавление собирается из сырого текста заголовка, мимо разбора строки.

**Чему учит.** Ни одна проверка дерева не смотрела на СОБРАННЫЙ HTML: сборка
проверяла ссылки, числа и наличие английских пар, а как выглядит результат — не
проверял никто. Дефект прожил столько, сколько живёт разметка, и нашёлся не
проверкой, а взглядом владельца на страницу. Проверка вида «в собранном HTML не
должно остаться `**` вне `<code>`» стоит одну строку и ловит весь класс.
