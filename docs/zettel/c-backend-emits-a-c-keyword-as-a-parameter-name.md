# Печать в C ломается на параметре, чьё имя транслитерируется в ключевое слово C — но только у рекурсивной функции

Найдено прогоном при замере вычислителя. Программа из четырёх строк печатается
в C, и напечатанное **не собирается**.

```flang
модуль «Проба суммы»

тотальная функция «Сумма»
  принимает до: нат
  возвращает число
  если до не больше 0
    то 0
    иначе до плюс («Сумма» от (до минус 1))
```

`flang check` — «замечаний нет». `flang emit --target c` — печатает.
`make` — отказ:

```
proba_summy.c:13:63: error: expected ';', ',' or ')' before 'do'
   13 | static fl_status proba_summy_summa_body(fl_ctx *ctx, fl_value do, fl_value *result, fl_error *error) {
```

**Что происходит.** `до` транслитерируется в `do` — ключевое слово C. Экранирование
у печати ЕСТЬ: обёртка получает `do_2`, тело пользуется `do_2`, комментарий
`@param do_2`. Не экранирована **ровно одна позиция — список параметров функции
`_body`**, куда уехало сырое `do`. То есть имя переименовано всюду, кроме места
своего объявления.

**Граница ошибки — рекурсия.** Функция `_body` печатается только у рекурсивной
функции; у нерекурсивной тело уезжает прямо в обёртку. Проверено:

```flang
тотальная функция «Без рекурсии»
  принимает до: нат
  возвращает число
  до плюс 1
```

печатается как `klyuchevoe_slovo_bez_rekursii(fl_ctx *ctx, fl_value do_2, …)` и
собирается без замечаний.

Значит ловится это только сочетанием «рекурсивная функция + параметр, чей
транслит совпал с ключевым словом C». Слова-ловушки русские и обыденные: `до` →
`do`, и по тому же образцу `для`, `если`, `иначе` транслита в ключевые слова не
дают, а вот `до` даёт.

**Чему учит.** Экранирование имён проверяется на обёртке и на употреблениях, а
объявление параметра во вспомогательной функции — отдельная поверхность, и она
из-под проверки выпала. Ищите такие места по признаку «имя строится дважды
разными путями».

**Чем подтверждено.** Ветка `u/vm-zamer`, база `ff8ad5d0`, `bootstrap/flang`
0.5.1, `cc` с флагами печати по умолчанию
(`-std=c99 -Wall -Wextra -Werror -pedantic -O2 -flto`). Оба прогона — печать и
сборка — воспроизводятся с нуля из четырёх строк исходника.

**Чем ограничено.** Проверена только цель C. Остальные семь целей на это же имя
не пробовались: у них другие правила имён и другой набор ключевых слов.
