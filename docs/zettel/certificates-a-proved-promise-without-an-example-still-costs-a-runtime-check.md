# Доказанное обещание без примера всё равно стоит проверки при работе

Доказательство ядром — необходимое условие снятия сторожа, но не достаточное.
Критерий в `flang/self/bootstrap/compiler.flang:862-892` требует ТРОЙНОГО
совпадения: вид `postcondition`, вердикт «доказано» (или «доказано при условии»)
И **хотя бы один пример у функции** (`grid > 0`). Нет примера — доказанное
обещание уезжает в напечатанный код проверкой, которую рантайм считает после
каждого возврата.

Отсюда приём, не требующий ни теоремы, ни переписывания обещания: **найти
функции, у которых обещания уже доказаны, а примеров нет, и дописать по одному
примеру**. Прибавка идёт не в число `доказано`, а в число снятых сторожей.

**Чем подтверждено.** `flang/stdlib/tls.flang`, ветка `u/library-certificates`,
26 августа 2026. Разрыв между доказанным и снятым был виден в двух строках
одного и того же дерева:

```
flang check --proof : доказано 319
flang emit --target c: проверок при работе снято 211
```

Сто восемь доказанных обещаний считались в рантайме зря. Своих у `tls.flang`
среди них оказалось тридцать семь, и они разошлись на две ясные группы:

| группа | функций | обещаний | чем взялись обещания |
|---|---:|---:|---|
| метки расписания, приставка `tls13 `, секрет из журнала, первая закрытая запись | 11 | 24 | замкнутая цель — тела суть литералы |
| шаги свёрток, расширения ClientHello, тег записи, растяжка | 9 | 13 | разбор цели по условию и равенство терму |

Первая группа — самая обидная: функции возвращают литеральный список октетов,
ядро вычисляет про них ВСЁ («октетов ровно 12», «первый октет равен 99»), а
сторож всё равно печатается, потому что автор не счёл нужным писать пример к
функции без доводов. Пример там — одна строка `ожидается [ … ]`, дословно
повторяющая тело.

**Замер по всем четырём модулям доли:**

| модуль | снято до | снято после |
|---|---:|---:|
| `der.flang` | 34 | 52 |
| `x509.flang` | 205 | 223 |
| `crl.flang` | 256 | 276 |
| `tls.flang` | 211 | 239 и выше |

У `der`, `x509` и `crl` число снятых после правки СОВПАЛО с числом доказанных
(52, 223, 276) — разрыва не осталось вовсе. Это и есть признак, по которому
стоит искать работу: сравните два числа, и разность — ваш список.

**Как искать механически.** Взять `--proof`-отчёт, собрать имена функций со
словом «доказано», вычесть из них те, у кого в исходнике есть строка
`  пример`. Остаток и есть цель.

**Чего приёмом НЕ добиться.** Обещание со статусом «объявлено, не доказано»
примером не закрывается: оно переходит в «сетку», а `доказано` не двигается ни
на единицу, и сторож остаётся. В `tls.flang` таких тридцать один, и они не
тронуты нарочно — «объявлено» честнее «сетки», потому что рантайм проверяет его
на всём, что через функцию прошло, а сетка — на конечном наборе автора.
