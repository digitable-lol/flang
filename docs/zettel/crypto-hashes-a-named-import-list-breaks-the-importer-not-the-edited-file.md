# Модуль со списком `только` у ввозящих ломается НЕ там, где его правили: заводя функцию, снимай отчёт по каждому ввозящему

Строка ввоза вида

```flang
использует «HMAC» из "hmac.flang" только «Веса слова», «Бит», … , «Ход вывода»
```

перечисляет ввозимые имена ПОИМЁННО. Список этот не описание, а забор: имя, не
попавшее в него, для ввозящего модуля не существует. Поэтому функция, заведённая
в правленом модуле и позванная из его же тела, роняет ВВОЗЯЩИХ, а сам правленый
модуль проверяется чисто.

Отказ приходит не там, где правка:

```
flang check flang/stdlib/sha1.flang --proof
FLANG_NOT_TOTAL, строка 240, столбец 3: тотальная функция «Исключающее или
списков» вызывает неизвестную функцию «Готово слияния»: завершение доказать
нельзя
flang/stdlib/sha1.flang: не проверено — ведомость не печатается у программы
с замечаниями
```

Функция «Исключающее или списков» живёт в `hmac.flang`, «Готово слияния» — тоже
в `hmac.flang`, обе рядом, десять строк друг от друга. Ругается `sha1.flang`,
который `hmac.flang` даже не ввозит напрямую: он ввозит `kdf.flang`, а тот —
`hmac.flang`, и оба списками `только`.

**Отчёт не печатается вовсе.** Это тот же класс, что и расходимость от
охраны-варианта: вердиктов нет НИ У ОДНОГО обещания файла, и виновник назван
только в первой строке отказа.

**Чем подтверждено.** 26 августа 2026, доля `u/library-crypto-hashes`. Две
свёртки `hmac.flang` выведены из-под проекции в съёмники «Готово слияния» и
«Взятое начала». `flang check flang/stdlib/hmac.flang` — «проверено; замечаний
нет», `check --proof` того же файла напечатал полную ведомость (`утверждений
148: доказано 96, сетка 52`). И при этом `kdf.flang` и `sha1.flang` перестали
проверяться совсем. Поломка успела уехать в приёмную: между правкой и прогоном
по ввозящим стоял только прогон по правленому, и он был зелёный.

**Правило.** Правя модуль, у которого есть ввозящие со списком `только`,
отчёт снимают по КАЖДОМУ ввозящему, а не по правленому. Найти их дёшево:

```sh
grep -ln 'из "hmac.flang"' flang/stdlib/*.flang
```

**Чем ограничено.** Про ввоз без `только` (`использует «UTF-8»` целиком) это не
верно: там новое имя доезжает само. Забор ставит именно поимённый список, и
ставят его нарочно — в `kdf.flang` он вырезает семь дорогих примеров RFC 4231,
без чего прогон примеров не влезает в предел шагов.
