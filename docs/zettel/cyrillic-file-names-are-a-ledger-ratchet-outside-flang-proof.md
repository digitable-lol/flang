# Кириллица в именах файлов вне flang/proof не прибавляется — храповик по ведомости, а не запрет

`scripts/guards/cyrillic-file-names-guard.sh` сверяет отслеживаемые файлы с
ведомостью `scripts/ledgers/cyrillic-file-names-debt.txt`.

**Правило.** Имена файлов в дереве — английскими словами, без транслита
(задача 1419). Уже лежащие кириллические имена перечислены в ведомости и уходят
оттуда по одному, вместе с переименованием. Сверка идёт в обе стороны: новое
кириллическое имя — красно; запись, пережившая файл, — тоже красно, иначе
ведомость сама стала бы перечнем, пережившим дерево.

**Почему flang/proof не судится.** Там имя файла — ключ артефактов
доказательств (задача 1420): запись, ловушка и ведомость находят исходник по
имени, и переименование сломало бы связку.

**Почему по `git ls-files`.** Смотрятся отслеживаемые файлы: собранное и
временное в счёт не идут.

**Чем подтверждено.** Задачи 1419 и 1420; проба `--подлог` подмешивает
выдуманное имя и обязана покраснеть.

**Чем ограничено.** Сторож различает имена по буквам А–я и Ёё в последней
доле пути; каталоги с кириллицей выше по пути не судятся.
