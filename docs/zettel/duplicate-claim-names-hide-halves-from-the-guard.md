# Утверждения под одним именем сторож видит как одно — вписать подделку в список мало, надо развести имена

Сторож подделок (`flang/scripts/poddelki-yadra.flang`) сличает отчёт
`flang check --proof --json` со списком ожиданий **по имени утверждения**, и
«Вердикт по имени» берёт ПЕРВОЕ непустое совпадение. Значит несколько разных
утверждений, названных одинаково, для сторожа сливаются в одно: он читает
вердикт первого и о прочих не говорит ничего. Файл при этом честно стоит в
списке, счёт каталога сходится, сторож зелёный.

Это вторая половина беды «незарегистрированной подделки»: регистрация
необходима, но не достаточна. **Имя утверждения — часть договора о надзоре**,
а не подпись для человека.

**Чем подтверждено.** Ветка `b/storozh-poddelok` над стволом `571b5995`.
В `flang/test/fixtures/poddelka-protivorechie.flang` все ТРИ постусловия
звались «что угодно»: две лживые половины обязаны остаться `declared`, честная
обязана быть `proved`. Прогон
`bootstrap/flang check … --proof --json` даёт их в порядке
declared, declared, proved — то есть поиск по имени «что угодно» отдаёт
`declared` на любой из трёх запросов. Следствия оба измерены:

- вписать честную половину было **нельзя вовсе** — сторож прочёл бы `declared`
  и покраснел бы на исправном правиле;
- вписанная лживая половина стерегла только первую функцию из двух.

После разведения имён («что угодно из совместимых строгих», «…из двух
нестрогих», «…из несовместимой пары») надзор проверен порчей: в
`flang/self/proof-kernel.flang` у функции «Несовместимы» условие
`(«строгое».«вид») равен "lt"` заменено на `"lt-ПОРЧА"` (правило 8 перестаёт
срабатывать), семя перепечатано, сторож — код 1:

> flang/test/fixtures/poddelka-protivorechie.flang: «что угодно из
> несовместимой пары» НЕ доказано (declared) — правило … не работает, и
> подделка при нём ничего не меряет

Краснеет именно ЧЕСТНАЯ половина — та самая, которую под общим именем вписать
было невозможно. Под старыми именами эта порча прошла бы молча.

**Чем ограничено.** Сличение идёт `равен`, а не «содержит», поэтому имена-
префиксы безопасны: «одно из двух» и «одно из двух, и второе — ноль» в
`poddelka-razbor-vnutrennim.flang` различаются и обе видны. Беда возникает
только на ПОЛНОМ совпадении имён. Сторож её не ловит: он не считает, сколько
утверждений отозвалось на имя, — признака «имя в отчёте встретилось дважды с
разными вердиктами» у него нет.

**Побочно измерено.** Правка одних комментариев в замыкании печати НЕ меняет
напечатанный байт, но перепечатку всё равно требует: `bootstrap/` совпал байт
в байт (7 файлов, 26 598 071 байт), а в `scripts/otpechatok-semeni` сменилась
строка хеша `flang/self/proof-kernel.flang` — без перепечатки покраснел бы
`--bystro`. Для сравнения: смысловая порча правила даёт другой размер семени
(26 598 178 и 26 598 095 байт на двух порчах).
