# Динамический ввоз прячет мёртвый файл от обхода по «import»

Файл, который ввозит удалённый модуль формой `await import(new URL(…))`, обходом
по строкам `import … from "…"` не находится. Он выглядит живым в любом списке
зависимостей и умирает только при запуске.

**Чем подтверждено.** Ветка `u/port5`. Обход 50 файлов доли по `from "…"` назвал
мёртвыми 12. После того как каждый из оставшихся был ЗАПУЩЕН, мёртвых оказалось
15: `scripts/wasm-compare.mjs`, `scripts/wasm-ceiling.mjs`, `scripts/wasm-speed.mjs`
— все три с одной и той же строкой

```js
const { emitC } = await import(new URL("../flang/src/emit/c.mjs", import.meta.url).href)
```

и все три отвечают `ERR_MODULE_NOT_FOUND` кодом 1. Обход дал 12 из 15, то есть
пропустил каждый пятый.

**Хуже того, проза утверждала обратное.** `docs/wasm-via-c.md`, таблица
оснастки: «ни один из них не трогает `flang/src/emit/` — цель печати не написана
и не нужна». Неправда стояла ровно про то место, которым эти три и умерли, и
пережила их смерть на сутки.

**Чему учит.** Список мёртвых собирается ЗАПУСКОМ, а не чтением. Чтение годится
только чтобы решить, что запускать первым. То же правило, что и у сторожей: чем
проверка удобнее, тем охотнее ей верят вместо прогона.
