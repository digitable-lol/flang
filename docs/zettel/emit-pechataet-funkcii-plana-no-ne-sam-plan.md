# Генератор печатает все функции приложения и молча роняет объявление `план` — напечатанный модуль умеет считать, но не умеет работать

`flang emit web/shortener/klient.flang --target js` кончается **кодом 0, без
единой диагностики**, и печатает **66 экспортированных функций** — 32 функции
приложения, 2 фабрики записей и 32 конструктора вариантов, то есть всё
приложение целиком, включая `nachat()` (начальное состояние) и
`dalshe(состояние, отклик)` (обработчик). Объявления

```flang
план «Стойка ссылок»
  состояние «Стойка»
  начинает с «Начать»
  обрабатывает «Дальше»
```

в напечатанном модуле нет: **0 байт, 0 диагностик**. Четыре строки, которые
только и говорят, кто начальное состояние и кто обработчик, теряются, и
напечатанный модуль оказывается набором функций, про который снаружи нельзя
узнать, что это план.

**Почему это важнее, чем кажется.** Ровно против этого класса беды в дереве уже
заведён отказ: цель без планировщика, встретив процессы, обязана отказать
`FLANG_IO_UNSUPPORTED`, а не потерять их молча, — и заведён он потому, что шесть
целей из восьми когда-то ТЕРЯЛИ процессы, печатая ноль упоминаний имени процесса
и кончаясь кодом 0. С планом сегодня то же самое, и отказа нет.

**Что для этого нужно, по частям, с готовым образцом на каждую.**

| чего нет | сколько | образец рядом |
|---|---|---|
| описатель плана в модуле | 4 строки объявления + 2 ссылки на функции | `concPlan()` — конкурентность печатает свой план тем же генератором |
| исполнитель плана рядом с модулем | отдельный печатаемый файл | `flang/src/emit/js/flang_conc.js`, 39 485 байт, приезжает готовым |
| хозяин, не тянущий вычислитель | — | нет; сегодняшний тянет 15 модулей, 1 414 416 байт, 20 463 строки |

Третья строка — та, из-за которой печать плана сама по себе ничего не даст.
`flang/src/host/browser.mjs` (298 строк) ввозит `variant`, `сбой` и `makeRandom`
из второй реализации языка, и вместе с ними в браузер приезжает вся она. То есть
даже с напечатанным планом вкладка везла бы вычислитель — и весь выигрыш в весе
исчез бы.

**Числами, чего этот выигрыш стоит.** Страница клиента сокращателя, замерено в
браузере по всем ответам до готовности экрана: **19 ответов, 1 752 748 байт**, из
них **16 файлов и 1 692 153 байта — вторая реализация языка**. Напечатанный тем
же деревом модуль того же приложения: **53 877 байт, под gzip 8 596**. Разница
**32,5 раза**.

**Чем подтверждено.** Ветка `vypusk/frontend`, приложение
`web/shortener/klient.flang` (32 функции, все тотальные). Счёт экспортов и
поиск объявления — по напечатанному файлу; вес страницы — `page.on("response")`
в HeadlessChrome 151; вес напечатанного — `flang emit --target js --no-cli`.
Счёт слова «поручение» в восьми `flang/src/emit/*.mjs` и восьми
`flang/self/emit-*.flang` — **0**, тот же, что был записан раньше.

**Чем ограничено.** Замер снят на цели JavaScript. Цель C — единственная, у
которой в таблице возможностей стоит `поручения: "есть"`, но это про поручения
ПРОЦЕССОВ (конкурентность), а не про план ввода-вывода; печать объявления `план`
не проверялась ни у одной из восьми целей, кроме JavaScript.
