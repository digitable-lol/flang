# `если` внутри случая `разбор`а ПО СПИСКУ охраной обещания не отпирается, хотя внутри случая по ВАРИАНТАМ отпирается

На телах-`разбор` по вариантам правило известно и замерено на `aes.flang`:
если внутри случая стоит обычный `если`, охрана обещания, списанная с него
дословно, разбирается разбором цели по условию, и девять обещаний доказались
индукцией по типу хода. Отсюда напрашивается, что то же выйдет и на разборе по
СПИСКУ (`случай пусто` / `случай голова и хвост`), где `если` стоит в обоих
случаях сразу. **Не выходит**, и это замерено двумя пробами.

```flang
разбор знаки
  случай пусто
    то если сколько не больше 0
         то вариант «Набрано» с взято равным [] и остальное равным []
         иначе вариант «Байтов не хватило»
  случай голова и хвост
    то если сколько не больше 0
         то вариант «Набрано» с взято равным [] и остальное равным знаки
         иначе …
```

```flang
обеспечивает «нулевой запрос ничего не берёт и потока не трогает»
  если сколько не больше 0
    то (результат равен (вариант «Набрано» с взято равным [] и остальное равным знаки))
    иначе да                                                              // СЕТКА
```

**Чем подтверждено.** Прогон
`flang check flang/stdlib/wire.flang --proof --предел-шагов 8000000000`,
26 августа 2026, двоичный `/srv/flang-rabota/w-predely`, ветка
`u/library-encodings`. Две пробы, обе с охраной, списанной из тела знак в знак,
и обе с заключением-равенством варианту:

* «нулевой запрос ничего не берёт и потока не трогает» у «Набрать байты» — сетка;
* «нулевая ширина отдаёт накопленное и потока не трогает» у «Взять целое» — сетка.

Обе сняты. Прочие девять правок того же прогона доказались, так что дело не в
файле и не в двоичном: wire 85 → 96 утверждений, доказано 49 → 58.

**Почему так.** Разбор цели по условию берёт `если` ИЗ ТЕЛА, а тело здесь
начинается не с `если`, а с `разбор`а по списку — и ветвь `пусто` ядро в цель
не подставляет вовсе (то же замерено на `sets.flang`, `dictionary.flang` и
`strlists.flang`: восемнадцать обещаний про пустой вход, все сетка). Разбор по
вариантам ядро разводит индукцией по типу хода и уже ВНУТРИ ветви видит `если`;
у списка такого хода нет.

**Что делать вместо.** Если тело начинается разбором по списку, охрану искать
не в нём, а поднимать утверждение к вызывающему, у которого тело начинается с
`если`, — или довольствоваться тем, что даёт равенство варианту у функций,
ПРИНИМАЮЩИХ сумму: там в том же прогоне взялось пять из пяти.
