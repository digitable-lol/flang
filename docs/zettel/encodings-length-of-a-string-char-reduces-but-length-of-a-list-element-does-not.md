# Длина `символ N в строка` под охраной сводится, а длина `элемент N в [список]` — нет

Приём «под охраной пишите равенство конкретному значению» упирается в неожиданное
место: не в охрану и не в вид цели, а в то, ЧЕМ ветвь тела достаёт своё значение.
Достаёт из строки — длина сводится; достаёт из списка литералов — не сводится, и
никакая запись этого не меняет.

```flang
// СВОДИТСЯ: тело ветви — символ строки
если не (шестёрка меньше 0 или шестёрка не меньше 64)
  то ((длина результат) равен 1) иначе да        // тело: символ (шестёрка плюс 1) в («Азбука 64»)   ДОКАЗАНО

// НЕ СВОДИТСЯ: тело ветви — элемент списка
если (байт не меньше 0) и притом (байт меньше 128)
  то ((длина результат) равен 1) иначе да        // тело: элемент (байт плюс 1) в [128 литералов]   сетка
```

**Чем подтверждено.** Три замера одного дня, 26 августа 2026, ветка
`u/library-encodings`, двоичный `/srv/flang-rabota/w-predely`,
`flang check … --proof`:

| файл | функция | как ветвь достаёт значение | вердикт |
|---|---|---|---|
| `base64.flang` | «Знак 64» | `символ (шестёрка плюс 1) в («Азбука 64»)` | **доказано** |
| `base64.flang` | «Знак 64 для адреса» | то же, другая азбука | **доказано** |
| `wire.flang` | «Знак байта» | `элемент (байт плюс 1) в [список 128 литералов]` | сетка |
| `datetime.flang` | «Имя дня недели» | `элемент (номер плюс 1) в [семь имён]` | сетка |

Охраны у всех четырёх списаны из тела знак в знак, заключения — про длину,
формы прогонялись обе (условная и дизъюнктивная). Различает их только строка
против списка.

**Чем это важно за пределами длины.** Обещание про длину знака у «Знака байта»
держит целый столбик: «Код знака байта» и три обещания «Строки с нулём»
(`длиннее ровно на один знак`, `начинается тем же текстом`, `весит на один байт
больше`). Столбик этот **не чинится дописыванием нижнего звена** — звено
написано, и оно не берётся само. Чинить надо тело: доставать знак из строки, а
не из списка строк, — либо оставить столбик проверкой при работе.

**И вторая половина того же предела.** Под охраной, где тело сводится к
ЛИТЕРАЛУ, длина берётся всегда — но только РАВЕНСТВОМ:

```
если значение меньше 0 или значение больше 99 то ((длина результат) равен 2) иначе да   ДОКАЗАНО  // "??"
если не (номер меньше 0 или номер больше 6) то (5 не больше (длина результат)) иначе да  сетка
```

То есть «замкнутая цель считается даром» верно для равенства и неверно для
неравенства над длиной. Тот же результат снят в тот же день соседом на
словарных функциях `tls.flang` — шесть ярусов `(длина результат) больше 0`,
все шесть сетка.
