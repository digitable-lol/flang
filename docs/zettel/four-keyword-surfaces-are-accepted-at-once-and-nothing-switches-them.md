# Ключевых поверхностей четыре, все приняты одновременно, и переключателя нет ни одного

Не две поверхности, как думают со стороны, а четыре: русская, английская,
эсперантская, китайская. Одна таблица — `flang/self/lexer.flang`, функция
«Куски таблицы»: **640 фраз, 152 понятия** (счёт по файлу, 8 сентября 2026).

| поверхность | фраз |
| --- | ---: |
| русская | 187 |
| английская | 172 |
| китайская | 143 |
| эсперантская | 138 |

Понятий, открытых на всех четырёх, — 134. Только на русской и английской —
**10**, и это весь словарь доказательств: `требует`, `обеспечивает`,
`утверждаем`, `для всех`, `индукция по`, `по свойству`, `по примеру`,
`по предположению`, `убывает`, `следовательно доказано`. Только на русской —
одно (`это`).

## Переключателя нет, и смешивать законно

Прогон 8 сентября 2026, двоичный 0.7.14. Один файл, слова двух поверхностей
вперемешку ВНУТРИ одной функции:

```
модуль «Смесь»
total функция «Дважды»
  accepts н: число
  возвращает число
  example «два»
    дано н равно 2
    expected 4
  н plus н
```

```
$ bootstrap/flang check смесь.flang
модуль «Смесь»: функций 1, из них с доказанным завершением 1; типов 0
смесь.flang: проверено — разбор, типы, завершаемость, ядро и примеры; замечаний нет
```

Ни ключа, ни переменной среды, ни расширения файла, ни поля манифеста, которые
отбирали бы поверхность, в дереве нет: `--surface`, `--поверхность`, `--lang`,
`--язык` встречаются по всему дереву только как имена переменных CSS на
страницах сайта.

## Поверхность файла всё же считается — и уходит в ОДНО место

«Поверхность потока» (`flang/self/lexer.flang`) считает её большинством голосов
среди ключевых слов файла, при ничьей и пустом потоке — пусто, то есть русская.
Идёт это число в единственное место: **цитата ключевого слова внутри отказа
разбора**. Одна и та же ошибка, два файла:

```
англ.: не разобрана конструкция: в примере ожидаются 'given' или 'expected'
рус.:  не разобрана конструкция: в примере ожидаются 'дано' или 'ожидается'
```

Остальной текст сообщения русский в обоих случаях, и `FLANG_UNKNOWN_NAME`
поверхности не знает вовсе.

## Что из этого следует

Просьба «дать эсперанто» на уровне КЛЮЧЕВЫХ СЛОВ уже почти выполнена — 138 фраз
из 152 понятий есть. Не хватает десяти понятий словаря доказательств, и это не
забывчивость: у `требует`/`обеспечивает` есть прецедент в Eiffel, JML и Dafny
по-английски, а на эсперанто и китайском устоявшегося слова нет, и придуманное
хуже отсутствующего.

Просьба «дать эсперанто» на уровне ЯЗЫКА ОТВЕТА не выполнена ни на сколько:
отвечает flang только по-русски. Это соседняя заметка —
[[the-compiler-answers-only-in-russian-and-nothing-can-change-that]].
