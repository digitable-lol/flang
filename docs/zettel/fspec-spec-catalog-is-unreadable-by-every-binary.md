# Двадцать шесть спек из сорока двух не читаются НИ ОДНИМ существующим двоичным, и проверка спек красна — применили `неотрицательное`, не перепечатав семени

`fspec/spec/**` — каталог, который `fspec/guard.flang` обязан принимать только
целиком доказанным. Сегодня он не проверяется вовсе: в двадцати шести файлах из
сорока двух стоит тип `неотрицательное`, а напечатанное семя такого слова не
знает.

**Чем подтверждено.** `check --proof` по всем 42 файлам, двумя разными
двоичными, 26 августа 2026:

| двоичный | откуда | ответ на `03-urgency-markup.flang` |
|---|---|---|
| `/srv/flang-rabota/w-predely/bootstrap/flang` | общий, сборка 23 августа | `FLANG_UNKNOWN_NAME, строка 29, столбец 1: неизвестный тип «неотрицательное»`, код 1 |
| `bootstrap/flang` этого дерева | `make -C bootstrap -j8` на стволе `9b60d141`, версия 0.6.2 | то же слово, тот же код |

Шестнадцать оставшихся спек читаются и доказаны все: утверждений 53, доказано
53, сетка 0, объявлено 0. Двадцать шесть — не проверены ни на одно утверждение:
ведомость у программы с замечаниями не печатается.

**Это ровно та беда, которую AGENTS.md называет правилом вторым** — «ввести
слово и применить его — РАЗНЫЕ изменения». Слово `неотрицательное` введено в
исходники компилятора и ПРИМЕНЕНО в позициях типа в спеках, а узнать его семя
может только перепечаткой, которая читает эти же исходники. Разбор той истории —
задача 0034; здесь она видна не в `flang/self/**`, а в каталоге спек, и туда,
похоже, никто не смотрел.

**Что из этого следует для чисел.** Строка README `fspec/` «42 файла, 98
различных утверждений, все доказаны» и обещанный ответ сторожа «спек 42,
утверждений 295» сегодня прогоном не воспроизводятся. Воспроизводится другое:
53 утверждения на 16 файлах. Число 295 останется недостижимым, пока не пройдёт
`sh scripts/raskrutka.sh`.

**Чем ограничено.** Замер говорит про два двоичных, какие есть на машине. Он не
говорит, что спеки написаны неверно: слово `неотрицательное` в исходниках
компилятора есть, и после перепечатки семени каталог, вероятно, прочтётся
целиком. Проверяется это после перепечатки, и не раньше.
