# Предусловие принадлежит функции границы, а не внутренней: ветка «если» его не снимает

Писал стык «flang считает — хозяин на C исполняет» (задача 0017) и поставил
`требует` там, где оно читалось лучше всего, — на внутренней функции:

```flang
тотальная функция «Пропуск врат»
  принимает врата: «Врата»
  возвращает «Решение»
  требует «запас есть» врата.«запас» больше 0
```

Звалась она из-под ветки, которая ровно это и проверяет:

```flang
иначе (если не («Запас есть» от врата.«запас») то («Отказ врат» …) иначе («Пропуск врат» от врата))
```

Компилятор отказал, и отказ стоит целиком:

```
FLANG_PRECONDITION_CALL: вызов «Пропуск врат» в функции «Запрос к вратам» не
снимает предусловие «запас есть»: у цели этого случая нет вида, к которому у
ядра есть правило: правил шесть — «не меньше 0», «не больше конечного
литерала», «не больше терма», «равно», «содержит» и «не убывает» … Вида цели не
спрашивает только седьмое, «цель есть допущение», и оно тоже не прошло: ни одно
допущение не совпало с целью знак в знак. известно: 1 собственное предусловие
вызывающего
```

**Что здесь важно.** Ветка `если` в вызывающем допущением НЕ становится: в
списке известного стоит ровно одно — собственное `требует` вызывающего. То
есть предусловие снимается не тем, что вызов стоит в правильном месте, а
доказательством в месте вызова, и вид цели обязан быть одним из шести.
`больше 0` среди них нет — есть `не меньше 0`.

**Следствие, ради которого заметка.** `требует` — это договор с ТЕМ, КТО ЗОВЁТ
СНАРУЖИ. На внутренней функции оно оборачивается долгом, который нечем
заплатить, и его приходится снимать. На функции границы — той единственной,
которую зовёт хозяин, — оно ровно на месте: проверка в напечатанном коде
ставится там, куда значение приезжает извне, и хозяин её видит статусом
`FL_ERROR`, а не падением.

Так и вышло в примере: `требует «запас не выше ёмкости»` осталось на «Шаг
привратника», «Такт врат», «Запрос к вратам» и «Пополнить» — там оно снимается
знак в знак собственным предусловием вызывающего, — а с «Пропуск врат» снято, и
вместо него у функции семь постусловий, все доказанные.

**Чем подтверждено.** `examples/host-boundary/gatekeeper.flang`, отчёт
`flang check … --proof`: функций 8, тотальных 8; утверждений 31 — доказано 22,
сетка 9, объявлено и не доказано 0; проверок при работе 0 мест.
