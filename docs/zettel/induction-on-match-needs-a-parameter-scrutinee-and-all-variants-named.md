# Индукция по телу-`разбор` цепляется, только когда разбирают ДОВОД-сумму и названы ВСЕ варианты

Расхожее «внутрь `разбор` ядро не ходит» неверно наполовину. Ходит — но по
узкой дорожке: разбираемое обязано быть **доводом функции**, тип его —
объявленной суммой, и в теле обязан стоять случай на **каждый** вариант. Стоит
заменить один случай на `случай любое`, или разбирать выражение вместо довода —
и цель перестаёт браться, хотя ветви те же и вызванные в них те же.

**Чем подтверждено.** Проба из шести тел одной формы (`разбор X`, каждая ветвь —
вызов функции с доказанным «витков не тратит», цель — то же про результат).
Ветка `b/self-interpret`, двоичный `/srv/flang-rabota/b-svod/bootstrap/flang`,
`check --proof` через ворота:

| что разбирают | вердикт цели |
|---|---|
| **довод-сумма, все варианты названы** | **доказано индукцией по «Может»** |
| та же сумма, но один случай — `случай любое` | объявлено |
| выражение-вызов (`разбор («Найти П» от «зн»)`) | объявлено |
| тот же вызов, связанный `пусть`, и разбор имени | объявлено |
| поле записи (`разбор («м».«зн»)`) | объявлено |
| довод-строка со случаями-литералами | объявлено |

Замер на живом файле сходится с пробой знак в знак. В
`flang/self/interpret.flang` «Машина по итогу формы» и «Толкнуть» разбирают
довод-сумму целиком — оба доказаны индукцией по своему типу. «Шаг если», «Шаг
свёртки», «Шаг обхода при вычислении», «Проверить постусловие при вычислении» и
«Шаг поля при вычислении» разбирают ПОЛЕ машины и вдобавок несут `случай любое`
— все объявлены. «Двучлен над парой» и «Вычислить» разбирают строку — объявлены.

**Что из этого следует для работы.** «Толкнуть» сначала разгладили в `если` по
равенству варианту с отдельной функцией-доступом — и оно доказалось. Потом
правку откатили, потому что проба показала: разбор довода-суммы берётся сам.
Откат стоил ровно одного обещания (у снятой функции-доступа) и вернул горячей
функции вычислителя прежнее тело. **Прежде чем разглаживать тело-`разбор`,
посмотрите, что именно разбирают: довод — не разглаживайте.**

Обратное тоже полезно: `разбор` по ВЫРАЖЕНИЮ чинится не `пусть`ом (проверено —
не помогает), а выносом разбираемого в довод отдельной функции. Этот ход в
вычислителе не сделан: он открывает по одному обещанию на функцию и стоит
лишнего вызова на горячем пути, а цепочки над ними всё равно заперты строковым
`разбор`ом «Двучлена над парой» и «Вычислить».

**Чем ограничено.** Все шесть проб — на цели «поле результата равно полю
довода», ветви — только вызовы. Про цели других видов и про ветви со
вычислением на месте это не мерилось.
