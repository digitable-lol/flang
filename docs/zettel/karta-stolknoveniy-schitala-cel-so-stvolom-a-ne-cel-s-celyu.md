# Карта столкновений имён, снятая по каждой цели порознь, слепа к столкновениям целей МЕЖДУ СОБОЙ: у go с rust их пять

Семь генераторов кода (`flang/self/emit-*.flang`) втаскивались в замыкание
двоичного семью независимыми ветками. Каждая посчитала, какие её имена
столкнутся с уже собранной программой, и разведение имён шло по общей карте
`docs/vosem-celey-pereimenovaniya.tsv` — 1057 строк, снятых пересечением
объявлений цели с объявлениями СТВОЛА. Про карту было сказано: «из 1042
идентификаторов 0 занято и 0 совпало между целями».

Второе неверно. Карта считала пересечение каждой цели со стволом; пересечение
целей между собой в неё не попадало вовсе — на стволе одновременно их не было
никогда. При сборке всех семи в одну ветку первая же пара дала **пять**
столкновений: `emit-go.flang` и `emit-rust.flang` объявляют одинаково названные
«Снять двунаправленные», «Только цифры», «Похоже на временное», «Это
закодированный вариант» и «Первый процесс». Ни одно из пяти в карте не значится.

Причина ровно та же, по которой карта вообще понадобилась: генераторы кода —
братья одного строения, и общие для них части каждый автор назвал одинаково.
Развести цель со стволом мало; развести надо и цели друг с другом.

**Признак, по которому это ловится заранее и дёшево.** Пересечь множества
объявлений целей ПОПАРНО, а не только с замыканием. Если делать это в момент
сборки, ловит `flang check`, запущенный ДО перепечатки точки раскрутки: пять
столкновений он назвал поимённо за две минуты. Запусти его после — те же пять
доехали бы до `cc` кодом `redefinition`, то есть на четвёртой минуте сборки и
без имён на flang.

**Чем подтверждено.** Ветка сборки `vypusk/vosem-celey-svod`, коммит слияния
печати в Rust. `node flang/bin/flang.mjs check flang/self/bootstrap/compiler.flang`
на дереве с go+rust: пять диагностик `FLANG_DUPLICATE_NAME`, все пять — пара
`emit-go.flang` ↔ `emit-rust.flang`. После суффикса « Rust» у пяти имён —
`valid: true`, ноль диагностик. Остальные пять пар (java, js, elixir, python,
csharp с уже слитыми) дали по нулю: их авторы пометили суффиксом цели ВСЕ свои
объявления, а go и rust — только те, что столкнулись со стволом.

**Чем ограничено.** Пять — число для этой пары и этого дня. Общего правила
«сколько столкнётся у двух целей» отсюда не следует; следует правило, какой
проверкой это ищут. Правило «суффикс цели на все объявления дешевле разведения
по одному» ([[suffiks-celi-na-vse-obyavleniya-deshevle-chem-razvedenie-stolknoveniy]])
получает здесь второй, независимый довод: помеченные сплошь цели не столкнулись
ни разу ни со стволом, ни друг с другом.
