# Голая цель-признак берётся ИНОГДА, и решает это тело, а не вид цели

Страница приёмов говорит: «Обещание, чья цель — просто вызов функции-признака,
ядро не берёт **никогда**». Рядом в базе знаний лежит заметка того же
содержания. Оба утверждения опровергнуты одним двоичным в один день — двумя
пробами, где голая форма записана знак в знак, а тела разные.

## Два замера, оба честные

Двоичный `u-semya5/bootstrap-pechatnyy` (сборка 25 августа 2026 15:37), 27 августа:

```flang
// ПРОБА А — «объявлено, не доказано»
тотальная функция «Ф16 голый признак»
  принимает «текст»: строка
  возвращает строка
  обеспечивает «в отказе есть код» «Ф16 непусто» от результат
  соединить ["код: ", «текст»] по ""

// ПРОБА Б — ДОКАЗАНО, правило «вхождение по построению»
тотальная функция «П13 было — голая цель-признак»
  принимает «код»: строка
  возвращает «Узел пробы»
  обеспечивает «в отказе есть код» «Есть поле пробы» от результат и "code"
  запись «Узел пробы» с «поля» равным ["code"]
```

Форма цели у обеих одна: голый вызов функции-признака от `результат`. Разошлись
**тела**: у А тело — `соединить […] по ""`, и признак спрашивает о ДЛИНЕ; у Б
тело — выписанная запись с выписанным списком, и признак спрашивает о
ВХОЖДЕНИИ, которое ядро закрывает правилом «вхождение по построению».

## Что отсюда следует

**Вид цели «голый признак» сам по себе ничего не решает.** Решает, дотягивается
ли до подставленного тела хоть одно из девяти правил ядра. Дотянулось —
доказано без всякого `равен да`; не дотянулось — «объявлено», и `равен да` тоже
может не спасти.

Дописанное `равен да` при этом **не вредит**: в той же пробе пара
«голая / `равен да`» дала одинаковое «доказано», только разными правилами —
«вхождение по построению» против «равенство, решённое счётом замкнутых частей».

**Практический вывод, тот же, что у приёма 12 про запись охраны:** это два
разных прогона, а не правило. Прогоняйте обе записи и оставляйте ту, что
взялась. Планировать по «никогда» нельзя — на этом можно потерять уже стоящее
доказательство, переписав его в форму, которая у ЭТОГО тела не берётся.
