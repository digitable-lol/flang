# В примере годятся только литералы, и ошибка в нём выходит в конце многочасового прогона

Пример — это не выражение, а **значение**. Вызов функции в нём разбор отвергает,
и отказ называет закрытый список того, что годится:

```
FLANG_PARSE, строка 501, столбец 15: не разобрана конструкция: ожидалось
литеральное значение — примеры не вычисляются: годятся число, строка, 'да',
'нет', 'ничто', список из них, 'запись «Имя» с «поле» равным …' и
'вариант «Имя» с поле равным …'; одному имени в ёлочках нужно слово 'вариант'
или 'запись' впереди
flang/self/proofterm.flang: не проверено — ведомость не печатается у программы с замечаниями
```

Поймано на этом:

```flang
// НЕ РАЗБИРАЕТСЯ: («Узел ничто») — вызов
ожидается запись «Итог шага» с … и «факт» равным («Узел ничто») …

// РАЗБИРАЕТСЯ: та же величина, выписанная литералом
ожидается запись «Итог шага» с … и «факт» равным (вариант «Значение скаляра» с «скаляр» равным (вариант «Скаляр ничто»)) …
```

**В ТЕЛЕ функции вызов остаётся вызовом** — правило только про пример. То есть
одна и та же величина в теле пишется коротко, а в примере разворачивается до
конструкторов, и это не описка автора, а требование разбора.

## Почему это стоит дороже, чем кажется

**Ошибка в примере не ловится дешёвым прогоном.** Разбор примеров идёт не на
чтении файла, а позже — при построении обязательств. На ядре доказательств это
означает, что опечатка в одном примере выходит **в конце многочасового
прогона**: замер 26 августа 2026 — `check --proof` на `proofterm.flang` со всем
замыканием шёл **2 часа 22 минуты** и завершился одной строкой `FLANG_PARSE`.
Ведомость при этом не печатается вовсе — «не проверено», и числа теряются все
разом, по всем 285 обещаниям.

**Отсюда порядок для дорогих файлов:** прежде чем ставить многочасовой прогон,
разверните в примерах все вызовы до литералов **глазами**, по списку из отказа.
Проверка `grep` по своим правкам стоит секунду и экономит два часа:

```sh
grep -nE '^\s+(ожидается|дано)' <файл> | grep -E '«[А-Я][^»]*»\s*от'
```

Пустой вывод — вызовов в примерах не осталось.

**Чем подтверждено.** Прогон `check --proof flang/self/proofterm.flang`
двоичным `u-semya5/bootstrap-pechatnyy` (сборка 25 августа 15:37): 2 ч 22 мин,
единственная строка отказа — `FLANG_PARSE` на примере с вызовом `(«Узел ничто»)`.
После разворота семи таких мест до литеральных вариантов файл проверяется.
