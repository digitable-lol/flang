# Примеры бесплатны там, где в замыкании нет ни одной теоремы — и ядро как раз такое

Ходит опасение: «пример удорожает ведомость, а ядро — самый дорогой проверяемый
код дерева, значит один пример может сделать его непроверяемым». Опасение
законное — оно снято прогоном соседа, у которого один пример с настоящим
вектором HMAC-SHA1 уронил `sha1.flang` целиком. Но к ядру доказательств оно
**не относится**, и причина читается по коду за одну минуту.

## Условие, при котором примеры вообще считаются

`flang/self/bootstrap/compiler.flang:971`:

```flang
функция «Прогоны для ядра»
  принимает «программа»: «Значение»
  возвращает список «Значение»
  если пусто («Элементы поля» от «программа» и "theorems")
    то пустой список
    иначе (отобразить («Примеры программы» от «программа» и 1000000 и 10000) …)
```

**Нет ни одной теоремы — примеры не прогоняются вовсе.** Есть хоть одна — ядро
прогоняет ВЕСЬ корпус примеров программы, а не те пары «функция, пример», на
которые ссылаются обоснования «по примеру» в самих теоремах. Это и записано в
шапке `scripts/raskrutka.sh` как настоящая цена «Бед ядра»: 56 млн витков не
потому, что доказывать дорого, а потому, что оплачиваются все примеры разом.

## Замыкание ядра доказательств — ноль теорем

Замер `grep -cE '^\s*теорема '` по всему, что ввозится в три файла ядра:

```
proof-kernel.flang    0        interpret.flang   0
proofterm.flang       0        parser.flang      0
proof-initial.flang   0        emit-c.flang      0
obligations.flang     0        core/json.flang   0
```

Слово «теорема» в этих файлах встречается только в комментариях — объявленных
теорем нет ни одной. Значит `«Прогоны для ядра»` на ядре всегда отдаёт пустой
список, и добавленные примеры **не стоят ни витка** при `check`, `check --proof`
и `emit`. Они только считаются — чтобы поднять `grid` обещания выше нуля.

## Что из этого следует для работы

* **В ядро примеры дописывать безопасно.** Порог снятия сторожа
  (`compiler.flang:862-892`) требует `grid > 0`, то есть хотя бы один пример на
  функцию, — и этот порог здесь достаётся даром.
* **Опасность возвращается ровно в тот день, когда в замыкание ядра приедет
  первая теорема.** Тогда все примеры ядра начнут прогоняться при каждой
  проверке любого файла, который его ввозит, — то есть при каждой проверке в
  дереве. Тому, кто будет писать первую теорему в этих файлах, придётся сперва
  сузить `«Прогоны для ядра»` до названных пар.
* **Проверять это надо по ЗАМЫКАНИЮ, а не по файлу.** Теорема в любом
  ввезённом модуле включает прогон примеров у всех.

**Чем подтверждено.** Чтением `compiler.flang:971` и подсчётом объявленных
теорем во всех модулях замыкания ядра — ноль. Прогоном сходится: ведомость ядра
с 65 дописанными примерами идёт тем же порядком времени, что и без них.
