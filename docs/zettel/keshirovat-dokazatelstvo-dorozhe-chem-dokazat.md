# Кешировать доказательство сегодня дороже, чем доказать заново: 111 мс против 145 мс на всём корпусе

Довод, которым в ADR-0001 оправдана адресация по содержимому, звучит так:
«доказательство стоит на три порядка дороже теста, значит его надо кешировать по
адресу определения». Про **цену одного шага вывода** это верно. Про **сегодняшний
корпус flang** — нет, и разница не в разы, а в знаке.

Ключ кеша — тройка «адрес определения, адрес утверждения, адрес проверяющего».
Первый из них считается по нормализованному разбору ВСЕЙ программы. На нашем
корпусе этот подсчёт стоит дороже, чем вызов ядра, который он должен сберечь.

**Чем подтверждено.** Прогон 18 августа 2026 на ветке `work/pakety`, одним
процессом, на прогретом коде (по 20 повторов на файл, чтобы не мерить разогрев
JIT). Взяты все файлы дерева, у которых есть хоть одно обязательство, — 99 штук:

```
ЯДРО ДОКАЗАТЕЛЬСТВА  111 мс   ← всё, что кеш способен сэкономить
АДРЕСА ОПРЕДЕЛЕНИЙ   145 мс   ← всё, что кеш обязан потратить
```

Пофайлово картина та же и на самых нагруженных: `flang/stdlib/json.flang` —
ядро 2,3 мс, адреса 11,0 мс; `docs/examples/operations.flang` (99 функций, из
них 93 привезены импортом) — ядро 0,6 мс, адреса 12,0 мс. Отношение 5–20 раз не
в пользу кеша.

Это не новость, а **подтверждение чужого замера**: шапка
`flang/src/proofcache.mjs` уже говорит «кеш сегодня стоит дороже, чем экономит,
примерно втрое», и потому включается переменной `FLANG_CACHE`, а не по
умолчанию. Здесь то же самое перемерено другим измерителем и на другом наборе
файлов — сходится.

**Чем это решило спор про пакеты.** Пакет (`flang package`) мог бы везти с собой
вердикты ядра, чтобы вызывающий не доказывал заново. Он их НЕ везёт: везёт
`ведомость` — справку «что автор доказал», на которую ни одна проверка не
опирается. Пакет с вердиктами был бы медленнее И обязан был бы им верить.

**Чем ограничено.** Замер про НАШ корпус, где доказательства в один-два шага:
самое дорогое ядро на файле — 22,5 мс (`corpus-cforms.flang`, 4 обязательства).
Выигрыш начнётся не раньше, чем ядро подорожает, — то есть когда появятся
доказательства с настоящим поиском. Число названо здесь, чтобы следующий начинал
с него, а не с довода про три порядка.

Отдельно: измеряется ТОЛЬКО ядро и ТОЛЬКО адреса. Полный `flang check --proof`
на программе с тремя импортами идёт 0,89 с против 0,58 с без ключа, и уходят эти
0,3 с не в ядро — в загрузку модулей и построение ведомости. Кеш вердиктов не
трогает ни того, ни другого.
