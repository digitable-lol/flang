# Ключ `--предел-шагов` ЗАДАЁТ предел, а не поднимает его: значение ниже вшитого роняет прогон, который без ключа проходит

Справка компилятора говорит про `--предел-шагов N`: «поднять предел шагов
ПРОВЕРЯЮЩЕГО на этот прогон». Слово «поднять» читается как «не ниже
умолчания» — и это неверно. Ключ ставит предел РОВНО в названное число, в обе
стороны.

**Чем подтверждено.** Ведомость по библиотеке снималась
`flang check <модуль>.flang --proof --предел-шагов 400000000` — число взято
«с запасом» из головы, не из замера. Три модуля из первых пятнадцати ответили
кодом 1 и не напечатали отчёта вовсе:

```
kdf    код=1, 114 с   ЗАПАС ШАГОВ НА ИСХОДЕ: «Ведомость исходников» съел
                      400000001 витков из 400000000 (100 %)
                      FLANG_RECURSION_LIMIT: функция «Прогон» исчерпала лимит
                      шагов (400000000) на глубине вызовов 1
scram  код=1, 152 с   то же
json   код=1, 106 с   FLANG_RECURSION_LIMIT: функция «Шаг поля ядра» исчерпала
                      лимит шагов (400000000) на глубине вызовов 79
```

Умолчание, вшитое при перепечатке семени, — **4 000 000 000**
(`scripts/raskrutka.sh`, строка `MAX_STEPS=4000000000`), то есть в десять раз
больше названного ключом. Ключ его понизил — отсюда и отказ.

**Чему учит.** Ключ с числом «на глаз» опаснее, чем отсутствие ключа: без него
работает умолчание, снятое замером и записанное в `scripts/raskrutka.sh`, а с
ним — то, что вы вспомнили. Если предел нужен, берите его ОТТУДА и умножайте,
а не выдумывайте порядок величины.

**Чем ограничено.** Замер про двоичный
`/srv/flang-rabota/w-predely/bootstrap/flang` и про модули библиотеки. Про
`--предел-глубины` то же не проверялось.
