# Напечатать правила подсветки из таблицы языка мало: съедает слова сам редактор, и увидеть это можно, только спросив его о каждом слове

Подсветка, печатаемая из таблицы ключевых слов, кажется защищённой от
расхождения с языком: добавили слово — правила перепечатались. Защита неполная.
Между напечатанным файлом и раскрашенным текстом стоит РАЗБОРЩИК ПРАВИЛ самого
редактора, и он умеет молча выбросить строку целиком.

У Vim это делает `syn keyword`: он читает хвост своей строки как СВОИ ключи
(`contained`, `nextgroup`, `fold`…), и первое слово, похожее на ключ, обрывает
список. Английская поверхность flang содержит слово `contains` — настоящую фразу
понятия `contains`. Строка

```vim
syn keyword flangKeyword если то иначе fold contains add 如果 не меньше
```

регистрирует ЧЕТЫРЕ слова из тринадцати: `если`, `то`, `иначе`, `fold`. Всё,
начиная с `contains`, пропадает. Ни ошибки, ни предупреждения, ни ненулевого
кода — файл загружается, подсветка «работает».

**Чем подтверждено.** Ветка `vypusk/vim`, 20 августа 2026. Строка выше подана
Vim 9.2 (`vim -Nu NONE -es`), и вид каждого знака спрошен через
`synIDattr(synID(строка, столбец, 1), 'name')`: у первых четырёх слов —
`flangKeyword`, у остальных девяти — пусто.

**Чем чинится.** Все 629 фраз печатаются ОДНИМ `syn match` с перечислением
внутри `\%(…\)`: фраза попадает в шаблон в кавычках, и разбирать её как ключ
редактору нечем. Порядок ветвей при этом становится частью правильности — Vim
берёт первую подошедшую, а не самую длинную, — поэтому фразы печатаются от
длинных к коротким.

**Чем стережётся.** `flang io scripts/vim-highlight-check.flang` печатает файл со всеми
фразами таблицы, открывает его настоящим Vim и настоящим Neovim и требует, чтобы
каждая покрасилась целиком. На целых правилах: Vim 9.2 — 629 из 629, Neovim
0.12.4 — 629 из 629. Снятая из шаблона одна фраза `contains` даёт код 1 и строку
`ПРОПУЩЕНА: contains`.

Класс шире Vim: **всякий напечатанный файл правил проверяется тем, кто его
читает, а не глазами и не сравнением с источником.** Источник может быть верен,
печать — точна, а потребитель всё равно поймёт написанное иначе, и промолчит.

**Чем ограничено.** Проверено на Vim 9.2 и Neovim 0.12.4. Про другие редакторы
(tree-sitter, TextMate, Chroma) ничего не сказано — у них свои разборщики правил
и, скорее всего, свои способы промолчать.
