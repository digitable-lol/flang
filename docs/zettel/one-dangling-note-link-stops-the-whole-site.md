# Одна ссылка на ненаписанную заметку останавливает публикацию сайта целиком

Сборка сайта отказывает на ссылке `[[слаг]]`, которой не соответствует файл в
`docs/zettel/`. Отказ — это весь прогон: страница не собирается ни одна, GitHub
Pages не публикуется вовсе, и на сайте продолжает висеть предыдущая редакция.
То есть **одна строка «Связано:» в одной заметке замораживает публикацию всех
правок сайта**, которые делают в это время другие.

**Чем подтверждено.** 18–19 августа 2026 задание «Сайт документации» упало
четыре раза подряд за два с четвертью часа. Причина во всех четырёх — одна:
`битая ссылка базы знаний [[amend-cannot-catch-up-a-journal-that-records-hashes]]`
на странице заметки, приехавшей слиянием `2bfcb7d0`. Заметку с таким слагом никто
не написал. После снятия одной строки (`4aeb0798`) прогон на том же дереве стал
зелёным, и сайт опубликовался.

**Чем ограничено.** Отказ правильный: ссылка в никуда на опубликованной странице
хуже, чем красный прогон. Речь не о том, чтобы его ослабить, а о том, что цена
ошибки несоразмерна её размеру и платит её не тот, кто ошибся.

**Чему учит.** Указание базы знаний «ссылка на ещё не существующую заметку — не
ошибка, ставьте их щедро» верно ВНУТРИ дерева и ложно на границе публикации: эти
два правила противоречат друг другу, и противоречие ловится не на ревью, а через
два часа, красным Pages. Разрешается одним из двух — либо заметка приезжает тем же
коммитом, что и ссылка на неё, либо сборка печатает ссылку на ненаписанную заметку
как обычный текст и краснеет отдельным списком, не роняя выпуск. Пока выбрано
первое, и оно держится только вниманием пишущего.
