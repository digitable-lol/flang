# Ослабленное утверждение бывает несущим: оно даёт соседу ДНО

Утверждение «размер неотрицателен» у `«Размер дерева»` (`flang/stdlib/tree.flang`)
переживает подмену тела заглушкой `0`, то есть по счёту содержательности оно
ослабленное — верно про любую функцию этой подписи. Снимать его тем не менее
нельзя: без него не доказывается СОСЕДНЕЕ утверждение той же функции,
содержательное — «дерево с ненулевым приоритетом корня — не пустое»
(`если (не ((«Приоритет» от дерево) равен 0)) то (1 не больше результат) иначе да`).

Правилу «порядок по построению» на цели `1 не больше (1 плюс размер слева плюс
размер справа)` нужно ДНО у слагаемых: «литерал, не превосходящий дна границы
(дно даёт неотрицательность и сумма дон)». Дно оно берёт из доказанного
постусловия вызванной функции — то есть из ослабленного утверждения.

**Чем подтверждено.** Изъятием: с первой строкой ведомость `tree.flang` даёт два
доказанных, без неё — ноль. Ветка `u/dokazat-bibl`, `bootstrap/flang` 0.5.1.

**Почему нельзя обойтись типом.** Напрашивается `возвращает нат` вместо лишнего
утверждения — тип `нат` несёт дно сам. Так нельзя: тело `1 плюс («Размер дерева»
от л) плюс («Размер дерева» от п)` имеет тип `число` (сумма двух `нат` выходит за
потолок законно, и тип расширяется), и объявление даёт отказ
`FLANG_TYPE: функция «Размер дерева» объявлена как нат, а тело даёт число`. То же
и у «Глубина дерева», и у любого счётчика, который что-нибудь складывает.

**Что из этого следует счёту.** «Ослабленное» и «лишнее» — разные вещи.
Счёт содержательности отвечает на вопрос «что это утверждение говорит о функции»,
а не «нужно ли оно в файле».
