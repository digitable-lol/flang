# Пара живых узлов поднимается одним `sh -c`, а судит их flang по журналам

**Что измерено.** `flang/test/uzel-celi.test.mjs` (215 строк на JavaScript) снят
целиком и заменён планом `flang/scripts/uzel-celi.flang` (365 строк). Оба прогона
дают ОДНО: `ПОЛНЫЙ УЗЕЛ РАБОТАЕТ НА 5 ЦЕЛЯХ ИЗ 8: python, go, js, rust, c`,
те же три несошедшиеся цели (csharp, elixir, java — все три падают на пределе
памяти в воротах, а не на своём коде) и тот же код возврата **1**.

**Как обойдена нехватка языка.** Языку недостаёт разом четырёх вещей: фонового
запуска процесса, чтения потока живого процесса, сигналов и заведения каталога.
Всё это отдано ОДНОМУ поручению `«Запустить процесс»` с программой `sh`: оболочка
печатает узел в цель и в опору, собирает, поднимает опору в фоне, ждёт её порт из
её же журнала, поднимает узел цели, ждёт обоих и выкладывает оба журнала одним
потоком. Оболочка НЕ СУДИТ: все решения — тотальные функции плана, и снимаются
они с журналов. Приём тот же, каким мерку памяти ставит
`flang/scripts/memory-guard.flang` и каким PATH без Node собирает
`scripts/put-bez-node.flang`.

**Грабли, стоившие прогона.** Первая сверка искала в журнале одну длинную
подстроку с ключами в порядке python — и объявила цель `go` несошедшейся, хотя
пара у неё сходится. Причина: **go сортирует ключи JSON по алфавиту**
(`{"в":…,"сосед":…,"узел":…,"цель":…,"что":…}`), а python и js оставляют порядок
записи. Сверять надо НАБОРОМ кусков в пределах одной строки
(`«Есть строка со всеми»`), а не одной подстрокой: иначе сверка ловит печатника, а
не работу узла. Пробелы у печатников тоже разные (python ставит, остальные нет) —
поэтому текст сначала нормализуется `«Без пробелов»`.

**Что рядом.** `flang/test/nadzor-uzla.test.mjs` (224 строки) той же оснастки
ждёт того же приёма: разница только в трёх планах узла (`plan.json`,
`plan-bez.json`, `plan-porog.json`), трёх прогонах пары вместо одного и в том,
что третий исход меряется ВРЕМЕНЕМ («узел остановился, не дождавшись своих шести
секунд») — время обязана назвать оболочка числом, а судить его — план.
