# Принцип свёртки усилен пройденным куском списка: +2 доказанных, и это весь потолок формы

Стена, названная 22 августа: принцип индукции для тела-`свёртки` был инвариантом
НАКОПИТЕЛЯ, `P(И) ∧ (P(а) ⟹ P(Т)) ⟹ P(свёртка …)`. Цель, связывающая накопитель
со СПИСКОМ, им не бралась по форме принципа: её основание на пустом списке ложно.
См. [[left-fold-gives-no-list-induction]].

**Что сделано.** `P` говорит теперь о двух вещах — о накопителе и о пройденном
куске списка:

```
P(И, пусто) ∧ (для любых а, п и э: P(а, п) ⟹ P(Т, п ++ [э]))
            ⟹ P(свёртка L начиная с И …, L)
```

**Это теорема, а не аксиома, и выводится из тех же двух определяющих уравнений
левой свёртки.** Из них следует третье — `свёртка (п ++ [э]) начиная с И … =
Т[а := свёртка п начиная с И …, э := э]`, — и выводится оно индукцией по «п» при
допущении, годном при ЛЮБОМ начале. Полный вывод записан в шапке «ПРИНЦИПА ПО
СВЁРТКЕ» в `flang/self/proof-initial.flang`, рядом с правилом.

**Читается это подстановкой в цель на месте списка свёртки:** `пусто` в
основании, `добавить э к пройдено` в витке — в КОНЕЦ, потому что свёртка левая.
Обе подстановки (`результат` и список) кладутся одновременно, поэтому список,
упомянутый в начале свёртки или в теле витка, остаётся собой.

**Одного усиления не хватило, и это измерено.** Принцип по свёртке звали ТОЛЬКО
из написанной рукой теоремы. Сверка 67 утверждений `flang/stdlib`, стоящих на
теле-свёртке по параметру: приписать каждому теорему `индукция по <список>` и
спросить двоичный из ствола — берётся **2 из 67**, и обе взятые уже доказаны
другим правилом («результат не меньше 0»). То есть усиление само по себе давало
**ноль**. Поэтому тела-свёртки заведены на тот же путь БЕЗ ТЕОРЕМЫ, каким туда
попал `разбор` ([[auto-induction-on-match-closes-nine]]): «Свёрткой по телу» в
`flang/self/proofterm.flang`.

**Парный замер, одно дерево, два двоичных** (`flang check … --proof --json` по
всем 25 файлам `flang/stdlib`; `postgres.flang` отчёта не даёт и в счёт не
входит):

| | ДО (ствол 55292de6) | ПОСЛЕ |
|---|---:|---:|
| утверждений | 966 | 966 |
| доказано | 197 | **199** |
| из них индукцией | 46 | 48 |
| на сетке | 764 | 762 |
| убыло | — | 0 |

Прибавились ровно две, и обе — та самая форма, ради которой всё делалось:

* `dictionary.flang` «Размер» — «размер — это длина списка связей»;
* `sets.flang` «Размер множества» — «размер — это длина списка».

**Потолок формы, а не потолок принципа.** После правки на сетке осталось 63
утверждения при теле-свёртке по параметру, и они не берутся не принципом, а
видом цели: **41 из них — `если … то … иначе`**, 17 — равенство, 3 — «не больше»,
2 — «не меньше». Прогон двух из них называет причину поимённо:

* `sets «Из списка»` «множество из списка не длиннее списка»: **основание теперь
  проходит**, падает виток — нужен ВЕРХНИЙ предел на «Добавить в множество», а у
  него доказан только нижний («добавление не укорачивает»), точный же —
  условный и сам на сетке;
* `sets «Есть в множестве»`: основание `нет равен (пустой список содержит
  искомое)` остаётся со свободным «искомое», а сводить `содержит` над пустым
  списком ядро не умеет.

**Сверх автоматического пути написанная теорема не даёт ничего.** Та же сверка
67 утверждений новым двоичным: взято 11, из них 9 уже доказаны другими
правилами, а 2 — те же самые, что закрыл путь без теоремы. Библиотеку трогать
незачем.

**Цена.** `flang check flang/stdlib/hmac.flang --proof` 85,65 с → 87,25 с
(+1,9 %). Точка раскрутки перепечатана, и `sh scripts/raskrutka.sh --check`
отвечает «совпадает с печатью: 7 файлов, 26 211 234 байт» — то есть компилятор с
новым ядром остался неподвижной точкой.

**Подделка и честная половина.** `flang/test/fixtures/poddelka-svyortka-prefiks.flang`
— четыре лжи на четыре новых права: переворот, выдающий себя за тождество (виток
удлиняет пройденное С КОНЦА); шаг на два вместо одного; ложное основание при
честном витке; чужой список функции. Отвергнута обоими двоичными, кодом 1.
`flang/test/fixtures/svyortka-prefiks-chestnaya.flang` — три утверждения, которые
правило обязано взять: старым двоичным код 1 и шесть отказов
FLANG_PROOF_INDUCTION_STEP, новым код 0 и все три «доказано индукцией по СВЁРТКЕ
тела». Обе половины названы в `flang/scripts/poddelki-yadra.flang`; прогон
сторожа — «подделки отвергнуты: 14 файлов, аксиом ноль, нарушений 0», код 0.
