# Силлогизм доказывается из допущений сегодняшним ядром, а русские предложения читаются без словаря морфологии

Посылки силлогизма не надо протаскивать определением предиката (`тотальная функция … да`):
предмет рассуждения — `объект «Предмет»` с полем-признаком на каждое слово, общая посылка —
охрана `(если x.S то x.P иначе да)` на каждом названном предмете, и ядро доказывает пять
классических модусов (Barbara с единичной посылкой, Barbara, Celarent, Darii, Ferio), а пять
классических ошибок отвергает `FLANG_PROOF_STEP` на строке заключения. Слова рассуждения
объявляет автор — форма для одного, для многих и согласование через точку с запятой, — а
компилятор только сравнивает строки; шести образцов предложений хватает на всю силлогистику.

**Чем подтверждено.** Набор `flang/proof/probes/syllogism/assumptions/` — 31 проба;
набор `flang/proof/probes/syllogism/sentences/` — 62 текста, разошлось 0 (замер 4 октября
2026, `--plan Binary --max-steps 40000000`, код 0, 43 с); перебор 256 модусов
четырёх фигур порождёнными текстами — вердикт ядра сошёлся с учебным списком 15 правильных
во всех 256 (план `Binary` того же набора, `--max-steps 4000000000`, 4 мин 37 с). Решение —
ADR-0050.

**Чем ограничено.** Ядро делает один модус поненс на шаг — цепочку выписывает переводчик
строками `затем`; отрицания ядро не вводит — модусы второй фигуры доказываются только
опровержением (`утверждаем нет`); квантора в гипотезе нет — посылка подставляется в каждый
названный предмет, чего хватает лишь для одноместных предикатов и конечного числа имён.
Независимая проверяющая программа ни один вывод из допущений не переигрывает (код 3), а на
`есть такой … а именно` в теореме и на допущениях только из `таких что` отвечает кодом 1.

**Гипотеза теоремы.** Гипотеза `дано` обязана выводиться из `таких что` утверждения,
предусловий `требует` или объявленных типов; иначе ядро отвечает «гипотеза теоремы не является
допущением утверждения», а независимая проверяющая программа — кодом 1. Пробы
`socrates-with-premises-only-in-the-theorem.flang` и
`postcondition-with-a-hypothesis-only-in-the-theorem.flang` ждут отказа (задача 5311).
