# Поиск сведения стоит три тысячи строк, проверка найденного — пятьсот восемьдесят

Ядро доказательств решает вопрос «выводится ли эта цель из этих допущений»
поиском: перебирает случаи правил, разворачивает определения, откатывается,
тянет пределы. В `flang/self/proof-kernel.flang` это 3018 строк решений (строки
1–5460; за вычетом пустых, комментариев и блочных пояснений). Проверить УЖЕ
НАЙДЕННЫЙ путь стоит несравнимо дешевле: перебора нет, отката нет, состояния
почти нет — берёшь названный ход, применяешь к цели, смотришь, сошлось ли.

Замерено: проигрыватель сведения в `flang/proof/сверщик.flang` — **579 строк
решений** той же мерой (строгой мерой, только тела решений без подписей и
примеров: 331 против 1714 у ядра). Из них 189 — работа с термом как со строкой
(скобки, разрезы по верхнему знаку, подстановка), 346 — сама машина ходов, 36 —
два закона.

**Чем подтверждено.** Ветка `u/svedenie-poshagovo` поверх `422f42a3`. Считано
скриптом по одной и той же мере, которая на ядре даёт ровно 3018 — число, с
которого началась работа. Проигрыватель проверен настоящим прогоном:
`sh flang/proof/подделки/сведение.sh` — две честные записи приняты (6 посылок,
20 ходов), четырнадцать подделок отвергнуты кодом 1.

**Чем ограничено.** Проверка дёшева только там, где ход НАЗВАН. Правила ядра 1,
3, 4 и 6 — это перечни случаев (у правила неотрицательности их одиннадцать), и
каждый случай придётся завести отдельным названным законом строк на пять.
Оценка (не замер): ещё около 240 строк на полный перечень, то есть проигрыватель
целиком — порядка 820 строк против 3018. До трёх тысяч он не вырастает потому,
что в законе нет поиска: закон сличает форму цели и выписывает посылки, а не
пробует все свои случаи по очереди.
