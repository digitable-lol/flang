# Поиск по сайту не находил код отказа ни разу из тринадцати, и ломался он с двух сторон сразу

Человек копирует `FLANG_PROOF_INDUCTION_STEP` из терминала и вставляет в поиск
целиком — это самый естественный запрос, какой бывает у документации об
инструменте. Ни один из тринадцати кодов ядра доказательств не находил
страницу, где эти коды разобраны. Причин оказалось две, и они противоположные.

**Указатель рвал имя.** `голыйТекст` в `docs/site/poisk.mjs` заменял
подчёркивание пробелом наравне с `*`, `#` и `|` — как украшение строки.
`FLANG_PROOF_NO_GOAL` ложился в указатель четырьмя словами «FLANG PROOF NO
GOAL».

**Отбор имя сохранял.** `привестиПоЗнакам` в `docs/site/poisk.js` оставляет
`_` нарочно: код отказа — одно имя. Запрос приходил одной основой
`flang_proof_no_goal`, и совпасть с четырьмя словами указателя не мог никогда.

Хуже того, ответ был не пустым, а ложным. У совпадения есть обратное правило
(поле короче запроса, но является его началом) — оно заведено ради русской
морфологии, чтобы «тотальность» находило «тотальная». На запросе с
подчёркиванием это правило совпадало полем `flang`, то есть КАЖДОЙ страницей
сайта, где вообще есть слово «flang».

**Чем подтверждено.** Прогон по собранному указателю (`docs/site/out/poisk-ukazatel.js`,
487 страниц) на ветке `u/dokumentaciya`:

| | до починки | после |
|---|---|---|
| тринадцать кодов ядра находят свою страницу первым ответом | 0 | 13 |
| `FLANG_PROOF_INDUCTION_STEP` | embedding.html (28), en/embedding.html (25), index.html (24), en/index.html (21) | proof-refused.html |
| «тотальность» | totality.html | totality.html |
| «свёртка» / «свертка» / «сокращатель» / «mkdtemp» | свои страницы | свои страницы |

Починены обе стороны: в указателе пробелом заменяется только одинокое
подчёркивание, у которого сбоку не буква и не цифра; в отборе обратное правило
не работает на основе с подчёркиванием — морфологии в таком имени нет.

Сторож заведён в сборку шестым запросом (`docs/site/poisk-proverka.mjs`) и
умеет краснеть: со снятой починкой `node docs/site/build.mjs --check` отвечает
кодом 1 и строкой «поиск «FLANG_PROOF_INDUCTION_STEP» не нашёл
proof-refused.html (нашлось: ничего)», с починкой — кодом 0.

**Чем ограничено.** Найдётся только тот код, который стоит в имени страницы, в
её подзаголовке или в первых 700 знаках текста: дальше указатель страницу
обрезает. Тринадцать кодов ядра доказательств стоят в первом абзаце своей
страницы именно поэтому, а не ради красоты. Коды разбора и типов
(`FLANG_TYPE`, `FLANG_NOT_TOTAL`, `FLANG_MATCH_NOT_EXHAUSTIVE`) в первые 700
знаков ни одной страницы не попадают и находят сегодня только заметки базы
знаний. Имена из блоков кода не находятся вовсе — блоки выбрасываются из
указателя целиком, поэтому `fl_arena_init` не найдётся, хотя на странице
встраивания он есть.
