# Ёлочки внутри имени примера роняют разбор всего файла, и отказ не называет ни файла, ни примера

Имя примера пишется в ёлочках, как всякое имя языка:

```flang
пример «код остановки»
  ожидается "FLANG_STOPPED"
```

Соблазн назвать пример так, как называют функцию, — то есть с ёлочками внутри, —
велик, потому что в ЗНАЧЕНИЯХ так писать можно и это работает:

```flang
дано «что» равно "первый аргумент функции «шаг»"          ← годится
ожидается "первый аргумент «список», а ожидался «Ход»"     ← годится
```

**Внутри ИМЕНИ примера — не годится.** Вложенные ёлочки закрывают имя на первой
же внутренней `»`, и остаток строки лексер читать не умеет:

```
пример «отказ меры у «Шага»»
FLANG_LEX, строка 455, столбец 30: недопустимый символ '»'
flang/self/failures.flang: примеры не запускались — программа не прошла проверку
```

## Что в этом дорого

Отказ приходит **до** прогона примеров, то есть падает весь файл, а не один
пример. И диагностика не несёт имени файла — она сама об этом говорит:

```
место указано строкой и столбцом, но без файла: вместе с импортами проверено
файлов 4, а диагностика компилятора имени файла не несёт
```

С импортами файлов четыре, и номер строки без имени файла ничей. Ищется это
глазами, а один прогон при загруженных воротах стоит десятки минут ожидания.

## Дешёвая проверка перед прогоном

Одна строка, и она ловит все три случая, на которых я попался (`«отказ меры у
«Шага»»`, `«строковая «норма» и есть норма»`, `«в отличие от «равен»»`):

```sh
grep -nE '^\s*пример «[^»]*«' flang/self/*.flang
```

Пусто — значит имена примеров чисты. Проверять ДО прогона, а не после: цена
проверки — миллисекунды, цена отказа — очередь у ворот.

**Чем подтверждено.** Ветка `u/examples-service-files`, 26 августа 2026, прогон
`flang test flang/self/failures.flang` на `w-predely/bootstrap/flang`; после
переименования трёх примеров тот же прогон дал «примеров 72, прошло 72, не
прошло 0».

**Чем ограничено.** Про ёлочки в именах ФУНКЦИЙ и полей ничего не сказано — там
вложенности и не бывает. Про кавычки-лапки внутри имени примера не проверялось.
