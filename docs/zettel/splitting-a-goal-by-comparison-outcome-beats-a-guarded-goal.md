# Цель, разложенная по исходам сравнения, доказывается там, где та же цель с оговоркой остаётся сеткой

Обещание вида «если оба довода положительны, то …» ядро не берёт: цель
`если А то Б иначе да` оно делит по условию ТЕЛА, а условие тела — другое, и
связать одно с другим нечем. Та же мысль, записанная дизъюнкциями по исходам
сравнения из тела, берётся целиком и без теоремы.

```
если (первое больше 0) и притом (второе больше 0) то СУММА иначе да      сетка
(не (первое меньше второе)) или СУММА                                    доказано
(первое меньше второе) или ((не (первое больше второе)) или СУММА)       доказано
(не (первое равен второе)) или СУММА                                     доказано
```

Три строки вместе сильнее прежней одной: сумма сохраняется при любых сравнимых
доводах, а не только при положительных. Тройная дизъюнкция ядру не помеха —
проверено отдельно.

**Чем подтверждено.** `flang/stdlib/higher-order.flang`, функция «Меньшее»;
`bootstrap/flang check … --proof --json` через ворота, ветка `b/sobraniya`,
основание `74bd0489`: доказано 19 из 43 → 22 из 45. Все три новых
СОДЕРЖАТЕЛЬНЫ — с телом-заглушкой `0` отпадают все три.

**Почему это работает.** Разбирая цель по условию тела, ядро читает условие
ФАКТОМ и даже зеркалит его: из `слева не меньше справа` оно выводит
`справа не больше слева` (проверено отдельной парой на теле
`если слева не меньше справа то слева иначе справа`). Прежний ответ «условие
ветви ядро фактом не читает», записанный в `hashmap.flang`, этим прогоном
опровергнут.

**Чем ограничено, и это важнее успеха.** Приём закрывает ровно те случаи, где
после подстановки тела остаётся ТОЖДЕСТВО. Он НЕ даёт:

- рефлексивности `Е не больше Е` при посылке о конечности — правило ядра стоит
  под другой посылкой, «о границе доказано не меньше 0». Проба
  `не ((слева минус слева) равен 0) или (слева не больше слева)` — сетка. Этим
  одним заперто «больше из двух не меньше обоих» в `hashmap.flang`;
- трихотомии: из `не (а меньше б)` и `не (а больше б)` вывести `а равен б`;
- шага `а больше 0 ⟹ а не равен 0` — им заперто «положительно то, что больше
  нуля пересиливает» в том же файле.
