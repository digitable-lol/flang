# «Меньше» — это не «не больше И не равно»: разложение ложно на минус нуле

Ядру доказательств дописывали строгие неравенства как вид цели (задача 0008), и
первым напрашивалось разложение, записанное прямо в задании:

> `а меньше б` — это `а не больше б` И `не (а равно б)`

Оно **неверно во flang**. Прогон `bootstrap/flang run`, три однострочные функции,
двоичный 0.6.2, 24 августа 2026:

```
(минус ноль) не больше 0   → да
(минус ноль) равен 0       → нет
(минус ноль) меньше 0      → нет
```

То есть левая часть разложения на этой паре **истинна**, а «меньше» — **ложно**.
Правило, собранное разложением, доказало бы ложь на первом же минус нуле.

Корень тот же, что у всего класса [[minus-zero-is-a-class]]: порядок языка минус
ноль и ноль не различает, а `равен` различает. Разложение сшивает две операции,
которые по-разному отвечают на один и тот же вопрос, — и шов расходится ровно
там, где эти две расходятся.

**Зеркальное разложение верно и всё равно не годится.** `а меньше б` есть
`не (б не больше а)` — на числах это правда, но у ядра нет правила для цели под
отрицанием, а на не-числе оно ещё и ложно: `NaN не больше NaN` ложно, значит
отрицание истинно, а `NaN меньше NaN` ложно.

## Второе, что напрашивается и тоже ложно: прибавить положительное

`Е меньше (Е плюс Д)` при строго положительном конечном `Д` — тем же прогоном:

```
9007199254740992 не больше (9007199254740992 плюс 1)   → да
9007199254740992 меньше   (9007199254740992 плюс 1)    → нет
```

Округление к ближайшему съедает прибавку целиком: за точной сеткой сумма **равна**
слагаемому. Правило порядка (`не больше`) этот ход держит законно — ему довольно
нестрогого знака, — а строгому знаку он ложен. Отсюда общее наблюдение:
**ходы нестрогого порядка не переносятся на строгий поштучно**, каждый надо
пересчитать заново. Из четырёх ходов правила порядка на строгий знак переехал
один — литерал под дном, — и переехал он с двумя разными посылками.

## Чем строгость берётся вместо этого

Строгость обязана прийти **названной**, и источников у неё ровно два, оба —
транзитивность через число:

```
Л < К ≤ П    литерал СТРОГО ниже ДНА границы (дно даёт правило порядка)
Л ≤ К < П    литерал НЕ ВЫШЕ СТРОГОГО дна — числа К из допущения «К меньше П»
```

Не-число не проходит ни с одной стороны: у литерала оно отсечено сличением
`число не меньше число`, у границы — самим доказанным порядком (`К не больше NaN`
ложно, значит доказанным быть не могло).
