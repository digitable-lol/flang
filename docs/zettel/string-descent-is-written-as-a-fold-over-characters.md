# Спуск по строке в библиотеке пишут свёрткой по знакам, а не разбором — принцип строки к таким телам не цеплялся

Принцип индукции у строки есть с 20 августа 2026 (`c14cd749e`): разбор на `пусто`
и `голова и хвост`, голова — «строка длиной 1», место `X` — только хвост. Задача
7359 и ADR-0040 §2.5 заведены 13 сентября со старым доводом «голова строки — тоже
строка»; этот довод был снят за три недели до них. Недоказанность законов над
строками держалась на другом: спуск по строке в библиотеке пишут не разбором, а
свёрткой по знакам — `свёртка (разложить Т на символы) …`, — а принцип свёртки
брал только список-параметр, и обратного хода от знаков к строке у ядра не было.

**Чем подтверждено.** `grep` по `flang/stdlib/*.flang` на стволе `05e1c8c4d`:
свёрток по разложению 44, из них 19 — тело функции целиком. `strings.flang` семенем
того же ствола и компилятором ствола, напечатанным в JavaScript, — одно и то же:
утверждений 120, доказано 64 (индукцией по строке — одно, «Первый символ»), сетка
55, при условии 1. После двух правил задачи 7359 — Тожд3 (`соединить (разложить Т
на символы) по ""` есть `Т`) и Инд4 (принцип свёртки у тела-свёртки по знакам
строки-параметра, элемент — знак, пройденный кусок склеивается обратно в строку)
— доказано 67, сетка 53, при условии 0 (компилятор ветки в JavaScript, 15 сентября
2026).

**Чем ограничено.** Прирост — три утверждения из 55 стоявших сеткой, и два из них
держатся на одном правиле-тождестве, а не на индукции. Цели, связывающие
результат с длиной строки через пройденный кусок (`результат равен (длина текст)`
у счёта знаков), принцип подаёт, но ядро их не закрывает: равенства для `длина
(соединить (добавить э к п) по "")` у него нет. Узел fold по знакам строки сверщик
не переигрывает — место остаётся на слове ядра, как у свёртки по списку в домене
«не больше».

**Урок.** Прежде чем строить правило по доводу из шапки задачи, проверить довод
прибором: здесь довод был снят раньше, чем задача заведена, и работа оказалась про
форму тела, а не про принцип.
