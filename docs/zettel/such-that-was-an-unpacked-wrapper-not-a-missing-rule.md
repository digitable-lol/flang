# Отказ ядра «у цели нет вида» на ограничении `таких что` был не нехваткой правила, а нераспакованной обёрткой

Свободное утверждение с ограничением — `для всех кто: «Человек» таких что («Смертен» от
кто)` — не прикладывалось шагом `по свойству`, и ядро отвечало «ограничение «таких что»
после подстановки не выведено: у цели этого случая нет вида, к которому у ядра есть
правило: правил десять». Читалось это как **отсутствующее правило вывода на предикатное
ограничение** — то есть как работа ядра. Прочитано неверно.

Ограничение приезжает из разбора **обёрткой** `{expr, span}`, а не выражением. Кто её
распаковывает:

| место | берёт `expr` |
|---|---|
| `flang/self/obligations.flang:327` | да |
| `flang/self/types.flang:7612` | да |
| `flang/self/proofterm.flang:1263` | **нет** |

Третьему месту ядро получало запись без поля `kind`, и честно отвечало, что вида не
узнаёт. Правило, которое обязано было сработать, — одиннадцатое, «цель есть допущение»:
факт `(«Смертен» от кто)` в опоре УЖЕ лежал.

**Чем подтверждено.** Прогон 19 сентября 2026, двоичный 0.7.20, копия `wSil`.

1. `flang ast` на утверждении с `таких что` печатает
   `"such": [ { "expr": { "kind": "call", … }, "span": {…} } ]` — обёртка видна прямо;
2. изоляция: цепочка с промежуточным шагом
   `затем («Смертен» от кто) по свойству «все люди смертны»` оставляет **ровно один**
   отказ — на шаге 2, при том что тот же прогон печатает «известно: выписанный шагом
   факт по свойству «все люди смертны»». Сличить его знак в знак было нечем: сличалась
   обёртка;
3. правка — одна строка: `«Подставить начальной» от («Взять поле» от «о» и "expr")`.

**Почему это не ловил ни один прогон.** Свободных утверждений с `таких что` во всём
дереве вне `flang/self` **ноль** (`git ls-files` по всем расширениям языка, 19 сентября
2026). Путь честным прогоном не проходили никогда — а в `flang/self` слова `таких что`
встречаются только строками примеров печати записи, которые до ядра не доходят.

**Чем ограничено.** Правка живёт в печатаемой части семени: до `scripts/raskrutka.sh`
(около 11 часов) `bootstrap/flang` её не несёт, и проверена она толкованием исходников
зондом `flang/self/bootstrap/zond-k7.flang`, а не двоичным. И она не делает цепочку
посылок сахаром: слова поверхности у цепочки нет, потому что промежуточную цель
разборщик вычислить не может (ADR-0046).

**Общее правило, которое стоит унести.** Когда ядро говорит «нет вида цели», первый
вопрос — не «какого правила не хватает», а **что именно ему передали**: одно и то же
поле AST в разных местах компилятора может распаковываться по-разному, и расхождение
двух мест из трёх молчит ровно до того дня, когда по третьему пути кто-то пройдёт.
