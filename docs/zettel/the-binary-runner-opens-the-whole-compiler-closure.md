# Прогонщик двоичного открывает ВСЁ замыкание компилятора — новая команда нужна только там, где у ответа свой вид вывода

У двоичного `flang` два входа. Первый — человеческие команды (`check`, `ast`,
`emit`). Второй — прогонщик: без доводов и без терминала на входе бинарник читает
JSON со стандартного ввода, запрос на строку, ответ на строку, и зовёт **любую
функцию своего замыкания по имени**.

```
printf '{"fn":"Слово на поверхности","args":[{"s":"if"},{"s":"zh"}]}' | bootstrap/flang
{"ok":true,"value":{"s":"如果"}}
```

Через этот вход открыты лексер, разбор, слой типов, ядро доказательства и все
восемь генераторов — то есть почти всё, чего проверкам не хватало после удаления
реализации на JavaScript. **Заводить команду стоит только тогда, когда у ответа
есть свой вид вывода**, который иначе пришлось бы собирать зовущему: так вышло с
`flang tokens --json`. Таблица слов языка, порядок поверхностей и ответ «на какой
поверхности стоит это слово» никакой команды не потребовали вовсе.

**Замер (каталог `/srv/flang-rabota/tokeny`).** Одиночный вызов — 7,6 мс, и почти
всё это запуск процесса. Пачка из 500 запросов ОДНИМ процессом — 1,0 с, то есть
2 мс на вызов. Сборка сайта, которой нужно 300 коротких разборов, укладывается в
4 секунды целиком.

**Что разбирать на месте можно, а что нельзя.** Разбирать чужую ЗАПИСЬ данных
(строку `|фраза:идентификатор|`, JSON дерева) — то же, что `JSON.parse`: это
чтение собственных данных языка в его же записи. Переписывать к себе ОТВЕТ НА
ВОПРОС («какое слово у этого понятия по-китайски») нельзя: ответ зависит от
правил, правила живут в языке, и переписанное разъедется на первой же правке.

**Чем ограничено.** Прогонщик отвечает `{"ok":false,"code":…}`, когда программа
отказалась считать, и это ОТВЕТ ПРО ВХОД, а не поломка: текст `1e999` роняет
встроенную «к числу» прямо в лексере, и правильное прочтение такого ответа —
«целой программой этот текст не является». Отсутствие двоичного вовсе — другое
событие, и путать их нельзя: первое значит «нет», второе — «спрашивать было не у
кого».
