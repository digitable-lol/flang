# Точка раскрутки отстала от словаря на два поручения, и пример, положенный вместе с ними, не проходит проверку

Словарь ввода-вывода вырос с 18 поручений до 20 — добавлены `«Удалить файл»` и
`«Завести временный каталог»`. Слова вписаны в `flang/self/parser.flang` и в
хозяина двоичного, но **точка раскрутки не перепечатана**, поэтому компилятор,
который собирается из этого дерева, их не знает. Пример, положенный в дерево тем
же заходом, сегодня краснеет.

**Чем подтверждено.** Прогоны на ветке `b/granica-sloyov`, база `8e12cbae`,
компилятор собран `make -C bootstrap -j4` из этого же дерева.

```
$ bootstrap/flang check examples/io/temp-directory.flang; echo $?
модуль «Временный каталог»: функций 10, из них с доказанным завершением 10; типов 4
FLANG_UNKNOWN_NAME … строка 89: неизвестный конструктор варианта «Завести временный каталог»
… замечаний 14
1
```

Прямая улика: `grep -c "Завести временный каталог" bootstrap/compiler_flang.c`
даёт **0**, а тот же счёт по `flang/src/emit/c/flang_repl.c` — 2. Хозяин слово
знает, компилятор нет.

**Ни один хозяин не знает всех двадцати.** Счёт по вхождению имени поручения в
файл — это потолок того, что место умеет (`flang_conc.c` называет шесть
поручений соединения ради названного отказа, а не ради исполнения):

| место | из 20 | чего нет |
|---|---:|---|
| `flang/self/parser.flang` | 20 | — |
| `flang/src/emit/c/flang_repl.c` | 19 | «Запустить процесс с вводом» |
| `bootstrap/compiler_flang.c` | 18 | «Удалить файл», «Завести временный каталог» |
| `flang/src/emit/js/flang_host_browser.js` | 16 | октетная пара файлов и те же два |
| `flang/src/emit/c/flang_conc.c` | 15 | экран, каталог, запуск процессов |
| `flang/src/emit/js/flang_io.js` | 15 | то же плюс «Запустить процесс с вводом» |

То же говорит проверка, которая в дереве уже стоит: `./ярлык вкладка:проверка`
краснеет кодом 1 и словами «хозяин вкладки ОТСТАЛ от словаря: поручений 20, без
ветки 4».

**Чему учит.** Новое слово в словаре — это не одна правка, а четыре шага:
вариант в `parser.flang`, ветка у каждого хозяина, **перепечатка точки
раскрутки**, пример. Пропуск третьего оставляет язык в состоянии, где слово есть
в словаре и нет в работе, и обнаруживается это не сборкой, а красным примером.
Мера цены: расширение словаря стоит полного захода, а не половины, — и это довод
за то, чтобы каждое поручение проходило все четыре шага одним разом.

**Чем ограничено.** Счёт по вхождению имени — верхняя оценка: имя может стоять в
файле ради отказа. Точный ответ по каждому хозяину даёт `./ярлык вкладка:проверка`
и его соседи, а не грепом.
