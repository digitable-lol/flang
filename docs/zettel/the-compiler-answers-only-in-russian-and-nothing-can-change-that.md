# Отвечает flang только по-русски, и выбрать язык ответа сегодня нечем

Замер 8 сентября 2026, двоичный 0.7.14, дерево `gh/dev` `65c8ea54`.

`setlocale`, `LANG`, `LC_ALL`, `LC_MESSAGES`, `gettext`, `nl_langinfo` — **ноль
вхождений** в `bootstrap/*.c`, `bootstrap/*.h` и `flang/src/**`. Ключа языка
нет. Из **15** переменных среды с приставкой `FLANG_`, которые двоичный читает,
на язык не влияет ни одна; из пяти остальных (`TERM`, `COLORTERM`, `NO_COLOR`,
`PATH`, `TMPDIR`) три правят цвет.

**Цвет выбрать можно. Язык — нечем.**

Плюс `packaging/flang.1` — 927 строк, 518 с кириллицей, второй страницы нет.
Латинские строки среди 336 — не английские предложения, а форматные скелеты
(`"%s\n"`), каркас JSON и заголовок LSP.

Документация при этом двуязычна почти целиком: страниц сайта 77 — 39 английских
и 38 русских; без пары одна (`changelog.md`, печатается из `changelog.json`).

**Отсюда перекос:** человек читает сайт по-английски, пишет программу
английскими словами (что законно, см.
[[four-keyword-surfaces-are-accepted-at-once-and-nothing-switches-them]]) — и
получает русскую диагностику.

## Чем это дорого починить: 14 проверок сличают русскую прозу вывода

| круг | файлов |
| --- | ---: |
| строгий: русская фраза сличается С ВЫВОДОМ двоичного | **14** |
| средний: русский якорь + файл зовёт двоичный | 44 |
| широкий: любое русское слово вердикта вне примечаний | 49 |

Якоря: `"проверено — замечаний нет"`, `"постусловие «"`,
`"доказано ПРИ УСЛОВИИ"`, `"объявлено, не доказано"`, `"утверждений "`,
`"непонятный ключ"`, `"нарушено свойство «утверждение»"`.

## Удача, на которой стоит починка

Ответ УЖЕ расслоён на машинную часть и прозу, и машинная от языка не зависит:

* `flang check --proof --json` держит ЛАТИНСКИЕ коды вердиктов — `proved`,
  `proved-induction`, `proved-conditional`, `grid`, `declared`, `refused`,
  `violated`. Свод по всему дереву (`flang/scripts/proof-ledger.mjs`) читает
  именно их и переводу безразличен;
* но рядом в том же JSON лежит русский текст: `witness-ledger.json` — **5283**
  поля `says`; `proofterm-witness.json` — вердикт записан русским словом
  (`"verdict":"доказано"`), 144 ответа из 319.

Значит переводить надо прозу, а машинную часть не трогать, и 14 проверок
переводить на коды. Решение —
`docs/adr/0022-the-settings-file-and-the-language-of-output.md`.
