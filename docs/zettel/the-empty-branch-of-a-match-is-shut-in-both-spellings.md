# Ветвь «пусто» у тела-`разбора` закрыта ОБЕИМИ записями охраны, и литерал не помогает

Функция, чьё тело начинается с `разбор X` и чей первый случай — `случай пусто`,
не берётся обещанием об этой ветви **ни в одной из двух записей охраны**:

```flang
обеспечивает «…» если X равен (пустой список) то результат равен (Т) иначе да   // 0 из 60
обеспечивает «…» если пусто X то результат равен (Т) иначе да                   // 0 из 60
```

## Чем подтверждено

`flang/scripts/**`, 26 августа 2026, общий двоичный
`/srv/flang-rabota/w-predely/bootstrap/flang`, `check <файл> --proof` без ключа
`--предел-шагов`. Шестьдесят таких обещаний в двенадцати файлах, два прогона по
всем четырнадцати судимым файлам каталога.

**Отчёты двух прогонов совпали ЗНАК В ЗНАК** — все четырнадцать строк, все
четыре столбца (утверждений / доказано / сетка / объявлено). Значит расходятся
не записи: ядру не хватает не формы охраны.

Для сравнения, в тех же файлах и тем же прогоном:

| приём | всего | доказано |
|---|---:|---:|
| замкнутая цель: поле постоянной записи | 34 | **34** |
| формы 1+2: охрана из тела дословно | 31 | **31** |
| замкнутая цель: длина постоянной | 22 | **22** |
| приём 10: равенство варианту без полей | 12 | **12** |
| замкнутая цель: равенство варианту | 7 | **7** |
| **ветвь «пусто» у тела-`разбора`** | **60** | **0** |

То есть в одном и том же прогоне, по одним и тем же файлам, пять приёмов дали
106 из 106, а этот — 0 из 60.

## Что здесь опровергнуто

`docs/site/kak-dokazat.ru.md`, раздел «Замеры смены 26 августа 2026», говорит:

> **В случае `пусто` у тела-`разбора` заключение-ЛИТЕРАЛ берётся,
> заключение-ТЕРМ — нет.**

По шестидесяти обещаниям это не подтвердилось:

| заключение ветви «пусто» | всего | доказано |
|---|---:|---:|
| ЛИТЕРАЛ (`""`, `пустой список`, `нет`) | 16 | **0** |
| ТЕРМ (вызов, построение варианта) | 44 | **0** |

Замер `merge-sort.flang`, из которого поправка выведена, ей не противоречит: там
доказано **индукцией**, а не разбором цели по условию, и носителем было
объявление списка, а не охрана. Правило про литерал верно для индукции по типу и
неверно для той формы, что описана здесь.

Верным остаётся широкое утверждение той же страницы: «начало свёртки и ветвь
`пусто` из `разбор` ядро в цель не подставляет» — восемнадцать проб на
`sets.flang`, `dictionary.flang`, `strlists.flang`, шестьдесят здесь.

## Шестьдесят первый случай, на другом файле и по другому поводу

27 августа 2026 то же самое поймалось вне `flang/scripts/**` и не нарочно.
`«Размер по полям варианта»` (`flang/self/hotswap.flang`) — охрана-зеркало над
телом-`разбором`, заключение ветви `пусто` — ЛИТЕРАЛ `1`:

```flang
обеспечивает «у пустых полей варианта размер единица» если пусто «поля» то результат равен 1 иначе да
разбор «поля»
  случай пусто
    то 1
  …
```

Функции дописали два примера (задача 4837), чтобы снять сторожа при печати и
вернуть батут компоненте. Печать до и после сличена: `fl_post 174 → 174`, снято
ядром `130 → 130`, батут `1 → 1`. **Ни одного сторожа не снято — значит вердикта
`доказано` нет и здесь.**

Замер важен тем, что он из другой части дерева и с другой целью: правило шестьдесят
раз не сработало на `flang/scripts/**` и в шестьдесят первый — на `flang/self/**`.

## Что из этого следует для работы

**Не тратьте на эту форму прогонов.** Она выглядит самой дешёвой в каталоге
сторожей — почти каждый обходчик очереди начинается с `разбор очередь`, — и
именно поэтому её пробуют первой. Шестьдесят обещаний, дописанных по ней,
дали ноль и были сняты все до одного.

**Снимать, а не оставлять.** Недоказанное `обеспечивает` у сторожа — это
проверка при работе, то есть мина, а не задел на будущее: сторож упадёт
`FLANG_PROPERTY` и покрасит ленту не там, где беда.
