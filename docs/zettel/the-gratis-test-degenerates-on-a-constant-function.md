# У функции без доводов, чьё значение и есть заглушка, проверка на даровость не различает ничего — и это не повод не писать утверждение

Мерка «подмени тело заглушкой той же подписи» ([[darovoe-utverzhdenie-uznayotsya-podmenoy-tela-zaglushkoy]])
опирается на то, что заглушка отличается от настоящего значения. У постоянной
функции, возвращающей ровно нулевое значение своего типа, отличия нет: заглушка
СОВПАДАЕТ с телом, и всякое истинное утверждение о ней заглушку переживает.

Два таких случая в библиотеке:

- `«Пустое расписание»` (`sha256.flang`) — шестнадцать нулей;
- `«Начало разметки json»` (`json.flang`) — пустой список, четыре пустых строки.

Утверждение при них написано (перечисление всех полей), и оно даровое **по
мерке**, но не бесполезно: оно ловит правку, которая молча сдвинет начальное
значение, — а такая правка ломает весь модуль и никаким примером соседа не
видна.

**Отличать надо соседний случай, где даровости НЕТ.** `«Начальный свод»`
(sha256) и `«Начало счёта json»` — тоже постоянные функции, но их значения
ненулевые, и заглушка их роняет. При `«Начальном своде»` вместо перечисления
восьми чисел (это была бы дословная переписка тела) стоит другое утверждение:
все восемь слов — настоящие тридцатидвухразрядные слова и все восемь **различны**.
Заглушка из нулей роняет вторую половину сразу.

**Чем подтверждено.** Ветка `u/golye`, `flang/stdlib/sha256.flang` и
`json.flang`, двоичный из `bootstrap/`. Проверено подстановкой заглушки в копию
модуля: у `«Начального свода»` `FLANG_PROPERTY`, у `«Пустого расписания»` тишина.

**Чем ограничено.** Случаев два на 482 функции; правило выведено из них, а не
из перебора. Класс называется так: **постоянная функция, значение которой
совпадает с нулевым значением своего типа**.
