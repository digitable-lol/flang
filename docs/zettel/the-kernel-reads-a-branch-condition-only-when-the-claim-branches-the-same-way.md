# Ядро читает условие ветвления, только когда утверждение ветвится так же, как тело

«Наибольшее не меньше первого» над `если б больше а то б иначе а` ядро не
доказывает ни на одном виде чисел. Та же мысль, записанная ветвлением в самом
постусловии, доказывается:

```flang
обеспечивает «рекорд не убывает» если кандидат больше рекорд то (результат больше рекорд) иначе (результат не меньше рекорд)
```

Для `неотрицательное` и `вес` это то же утверждение, что «результат не меньше
рекорда»: не-числа в типе нет. Для `число` — нет, и так и должно быть.

**Чем подтверждено.** Двоичный 0.7.23. Пробы — `docs/number-kinds.md` (таблица
по пяти видам) и генетический алгоритм `docs/examples/genetic/evolution.flang`:
элитизм там доказан ровно этим приёмом, 9 постусловий из 9.

**Ещё три границы, снятые на тех же пробах.**

* Два постусловия вызванных функций ядро не сцепляет: «знак результата берётся
  из заказанного» у «Сократить» и «из двух неотрицательных — неотрицательный» у
  «Знак суммы» доказаны, а «сумма неотрицательных дробей неотрицательна» над ними —
  нет (`flang/stdlib/rationals.flang`).
* Предусловие `знаменатель больше 0` при вызове `«Строго» от 2` не снимается
  (`FLANG_PRECONDITION_CALL`), а `знаменатель не меньше 1` при `от 2` снимается.
* Свёртка, растущая ровно на один элемент, даёт доказанное «длина итога равна
  длине списка», только если накопитель — сам список, а не запись с ним
  («Дети» в генетическом примере).

**Чем ограничено.** Приём не делает доказательным утверждение, которое нужно
нести через свёртку: «максимум свёртки не меньше начала» остаётся сеткой.
