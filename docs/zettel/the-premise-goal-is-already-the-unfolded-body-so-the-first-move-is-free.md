# Заключение посылки — это уже развёрнутое тело ветви, поэтому первый ход записи ядру ничего не стоит

Чтобы ядро выписало ходы сведения, казалось, нужен печатник термов: сверщик ждёт
ход `развернуть ⟨терм⟩ строка N`, а терм — это текст на flang, которого у ядра
нет, у него дерево. Печатник дерева обратно в текст — это второй разборщик
языка, и писать его ради записи было бы дорого.

Он не понадобился. Слой начальной алгебры строит заключение посылки так, что
`результат` в цели УЖЕ ЗАМЕНЁН телом ветви разбора (`flang/self/proof-initial.flang`,
«Посылка принципа», поле `conclusion`). То есть развёртка определения в ядре уже
случилась — до всякого сведения, — и первому ходу записи остаётся её НАЗВАТЬ:

- **терм** `«Ф» от (конструктор)` собирается из имени функции и строки исходника
  того `случай`, на который отвечает посылка. Строку эту сверщик читает сам, и
  порознь: разойдутся — он откажет;
- **номер строки** берётся из места (`span`) левой стороны заключения — то есть
  того самого тела ветви, которое туда подставили.

Остальные ходы у цели «Т не меньше 0» термов не несут вовсе: `закон «сумма
неотрицательных»`, `закон «литерал неотрицателен»`, `закрыть дано 1` — это имена,
а цели, к которым они применяются, сверщик считает сам. Печатать оказалось нечего.

**Чем подтверждено.** Ветка `b/proigryvatel` поверх `571b5995`.
`flang/self/zapis.flang` выписывает ходы 173 строками решений (мера: без пустых,
комментариев, подписей и примеров), и ни одна из них не печатает выражение.
Прогон `sh flang/proof/подделки/сведение.sh`: запись снимается прямо в прогоне
(`flang check flang/proof/examples/stack.flang --proof --записать`) и
проигрывается сверщиком кодом 0; четыре порчи этой же свежей записи отвергнуты
кодом 1. На 37 программах каталога `flang/proof/examples` было 0 строк «ход»,
стало 58; посылок проиграно сверщиком 13, и 2 из 24 «на слово ядра» ушли из
доверия.

**Чем ограничено.** Приём работает ровно там, где заключение посылки — это цель с
подставленным телом, то есть у принципа по объявленной сумме. У принципа по
отрезку `нат` конструктора нет вовсе, и `случай 0` / `случай любое` под слово
`случай вариант` не подходят — ходы там не выписываются. И тело обязано быть
одной формой: `пусть` перед выражением даёт узел `let`, а его ни один из семи
ходов сверщика не читает.
