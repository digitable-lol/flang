# Пару живых узлов на проводе словарь поручений не поднимет: «Запустить процесс» ждёт конца, и всё же одна оболочка это делает

Прогоны `flang/test/uzel-celi.test.mjs` и `flang/test/nadzor-uzla.test.mjs` — не
сторожа, а настоящая работа: печать `flang/conc/uzel-zamer.flang` в цель, сборка
чужим тулчейном, подъём ДВУХ узлов сразу и разговор между ними по TCP. Вопрос
«переписать ли это планом ввода-вывода» упирается не в терпение, а в четыре
поручения, которых в закрытом наборе из восемнадцати нет вовсе:

- **запуска в фоне нет.** `«Запустить процесс»` отвечает `«Процесс завершён»`
  или `«Процесс убит»` — то есть ждёт конца. Опора же обязана СЛУШАТЬ, пока
  вторая сторона звонит;
- **чтения потока живого процесса нет.** Порт опоры (`--слушать 127.0.0.1:0`)
  приезжает строкой её журнала В ХОДЕ работы, и второй узел без него не звонит.
  Отклик несёт `вывод` целиком и только после конца;
- **сигнала нет.** `SIGKILL` по узлам в `finally` изобразить нечем;
- **каталогов нет.** Ни создать, ни удалить: есть `«Перечислить каталог»`,
  `«Записать файл»` — и всё. Уборка за собой (`rmSync`) не выражается.

**Что при этом ИЗМЕРЕНО как возможное.** План умеет позвать оболочку, а оболочка
умеет всё перечисленное. Проба (`sh -c "sleep 1 >файл 2>&1 & echo вперёд; wait;
echo позади"`, `bootstrap/flang io … --plan "Проба оболочки"`) вернула код 0 и
вывод `"вперёд\nпозади\n"` одним поручением. Значит пара узлов поднимается ОДНИМ
`«Запустить процесс»`, а план читает оба журнала с диска и судит их тотальными
функциями с примерами. Срок хозяина сборке больше не мешает: ключ
`flang io --timeout` есть (`examples/io/potomok.flang`), хотя в
`flang io --help` он по-прежнему не назван.

Цена честная и её надо называть вслух: рукопожатие по порту, фон и убийство
переезжают в строку оболочки, то есть из языка — в `sh`. Решение (какие
состояния сошлись, сколько целей работает) остаётся на flang; оркестровка — нет.

**Чем подтверждено.** Ветка `b/testy-3` от `f2c1a67e`, 23 августа 2026.
Эталонный прогон `node --test flang/test/uzel-celi.test.mjs` под воротами
`PAMYAT=8G`: код возврата **1**, «ПОЛНЫЙ УЗЕЛ РАБОТАЕТ НА 5 ЦЕЛЯХ ИЗ 8: python,
go, js, rust, c», начальных состояний сверено 2, расхождений 0. Три цели упали
НЕ на своём коде, а на пределе ворот: java — «insufficient memory for the Java
Runtime Environment», elixir — «Failed to create scheduler thread 145, error =
11», csharp — «terminate called after throwing an instance of 'P9Exception'».
То есть 5 из 8 — мера этой машины под воротами, а не мера узла.
