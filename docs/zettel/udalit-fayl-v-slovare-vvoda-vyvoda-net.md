# Поручения «Удалить файл» в словаре ввода-вывода нет, поэтому план не убирает за собой временные файлы

Словарь поручений языка знает шестнадцать действий, и запись файла среди них
есть («Записать файл» → «Записано»). Обратного действия нет ни одного: ни
удаления файла, ни удаления каталога, ни создания каталога. Значит план, которому
для работы нужен временный файл, оставляет его в дереве навсегда.

Это не мешает — но заставляет выбирать имя так, чтобы оставленное никому не
попалось. Счёт двадцати (`benchmarks/proof-cost/count-20.flang`) пишет два
файла рядом с собой и держит их под тремя правилами сразу:

- **имя с точки** — обход выборки `flang/test/glob.mjs` не заходит в имена с
  точки, если сам образец не начинается с точки;
- **без расширения `.flang`** — тогда файл не подберёт и обход по `**/*.flang`;
- **в `.gitignore`** — иначе он всплывёт в `git status` у каждого, кто прогнал
  меру.

Имена постоянные, а не случайные: файлов остаётся ровно два, они переписываются
поверх при каждом прогоне, и проверка временных каталогов
(`node flang/scripts/tempdir-guard.mjs`) на них не жалуется — она считает
каталоги, а не файлы.

**Чем подтверждено.** Ветка `u/schyot`, 20 августа 2026. Словарь —
`flang/self/parser.flang`, список вариантов «Поручение»; хозяин на C —
`bootstrap/flang_repl.c`, `io_perform`: тринадцать ветвей, удаления среди них
нет. Прогон меры оставляет `benchmarks/proof-cost/.proba-golyy` и
`.proba-zaglushka`; `git status` после прогона чист, `tempdir-guard` говорит
«чисто: прогон убрал за собой всё».

**Чем ограничено.** Про двоичного хозяина. Что умеет хозяин на Node, здесь не
мерено — но словарь у них общий, а словаря удаления нет.
