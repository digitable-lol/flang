# Unison установлен и измерен: ромб он решает не так, как обещает лозунг

Проверено прогоном, а не пересказано: `ucm release/1.3.0`, сценарии через
`ucm transcript -S`.

**Главное открытие.** Лозунг «конфликтов версий не бывает, потому что это разные
функции» на практике работает не полностью. Две версии действительно живут рядом
— но **при смешивании получается ошибка типов**. По существу это поведение cargo
с внятным сообщением, а не исчезновение проблемы.

**Место, в числах:**

| | |
|---|---|
| база со стандартной библиотекой `@unison/base` 7.19.2 | **16,7 МиБ** |
| вторая полная версия библиотеки | **+1,6 МиБ** |
| пять версий | **+1,9 МиБ** |
| для сравнения: `node_modules` сопоставимого проекта | 8 МБ |
| инструментарий TypeScript | 73 МБ |
| кеш npm | 254 МБ |

То есть **место — не проблема**: старые версии почти не стоят, потому что общее
содержимое переиспользуется. Опасение «база растёт вечно» замером не
подтверждается.

**Что у Unison действительно хорошо**: кеш по хешу (результаты тестов не
пересчитываются), бесплатное переименование, откат без усилий.

**Чем платит**: база данных вместо файлов, свой хостинг, ревью без обычного
диффа. Оценка переноса такой схемы целиком — 15–25 тысяч строк.
