# Отчёты пишутся простым инженерным языком, без проектного жаргона

Владелец просил дважды и резко: «вот я вроде тимлид с большим опытом, но половину
твоего текста не понимаю» и «как заебал же ты со всякими словами типа печатник и
прочее, пиши понятно для программистов».

**Слова, на которых он спотыкался**, и чем их заменять:

| Жаргон | По-человечески |
|---|---|
| печатник | генератор кода |
| сторож | проверка в тесте |
| изъятие | снять правку и посмотреть, что покраснеет |
| фронтенд | разбор языка |
| свод | ветка сборки |

**Почему это правило, а не вкус.** Жаргон, который агенты выработали внутри
проекта, для читателя — шум, и он перестаёт видеть суть отчёта. Термин можно
вводить только вместе с объяснением при первом употреблении.

**Как применять.** В переписке с агентами жаргон допустим — они в нём работают.
Их отчёты **переводить**, а не пересылать как есть.

**Правило продырявилось там, где его не проверяли: на публичном сайте.** Жаргон,
которым написаны задания агентам, переехал в тексты для людей. Померено на
`docs/site/*.md` (29 страниц, обе половины): в прозе — вне блоков кода, вне
`встроенного кода` и вне подстановок — **745 вхождений** одиннадцати внутренних
слов. Самые частые: «эталон» 190, «близнец» 130, «сторож» 124, «корпус» 113.
Владелец прочитал это на опубликованном сайте и сказал: «термины твои хуёвые из
разряда корпус, близнец и прочее типа свидетель, это оооочень хуёво».

**Замены, которыми чинилось:**

| Не писать | Писать |
|---|---|
| эталон, свидетель | реализация на JavaScript / компилятор из репозитория |
| близнец | компилятор, написанный на самом flang |
| корпус | программы репозитория / примеры / библиотека — смотря о чём речь |
| сторож | проверка |
| ведомость | отчёт о доказательствах |
| побайтовая сверка | сравнение байт в байт |
| неподвижная точка | компилятор печатает сам себя без изменений |
| изъятие | снять правку и посмотреть, что сломается |
| дефункционализация | компилятор заменяет функцию-значение меткой и разбирает по меткам |

**Чем ограничено.** 610 из 745 вхождений живут на одной странице — печатном
журнале вливаний (`docs/site/changelog.md`), и там их не вычистить: это
заголовки слияний из истории репозитория. Правильный ход для неё — не правка
текста, а место в меню: журнал адресован тому, кто развивает язык. Вручную
написанные страницы вычищены со 135 вхождений до 1 — оставшееся есть цитата
ответа компилятора, объяснённая тут же следующей фразой.

**Слово может течь и из самого инструмента.** `flang emit` печатает читателю
«таблицу объявленных типов строит слой типов **свидетеля**» — это не текст
страницы, это строка в `bootstrap/`. Пока её не переписали, слово будет
возвращаться на страницы вместе с прогонами.
