# Поддержка `.flang` в редакторах

## Что здесь лежит

```
editors/
  flang-lsp/   как настроить VS Code и Neovim на языковой сервер .flang
  linguist/    заявка в github-linguist на язык .flang
  README.md    этот файл
```

## Чего здесь нет

**Подсветки `.flang` в дереве нет ни одной** — ни tree-sitter, ни
TextMate/VS Code, ни Chroma, ни Vim. Это не забытая задача, а неоплаченный
долг: у языка есть языковой сервер, который даёт диагностики, подсказки и
переход к объявлению, а раскраски текста нет. Кому она понадобится раньше —
тому и писать, и работа это не маленькая: четыре грамматики на один язык — это
около двадцати одной тысячи строк, включая порождённый tree-sitter разбор.

## `flang-lsp/`

Единственное, что здесь про язык: как показать редактору `flang-lsp` — языковой
сервер `.flang`, который ставится вместе с пакетом (`flang/src/lsp.mjs`,
`flang/bin/flang-lsp.mjs`). Он даёт живые диагностики той же дорогой, что
`flang check`, дополнение, подписи при наведении и переход к объявлению. Это не
подсветка: сервер знает про смысл текста и ничего не знает про его цвет.
