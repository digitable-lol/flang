# Драйвер, который ничего не делает — и потому доказуем

`uart.flang` — образец того, как писать драйвер железа на языке, где каждая
функция обязана доказано завершаться.

## Приём

Драйвер — **чистая функция** «состояние и событие → новое состояние и список
записей в регистры». Он не пишет никуда. Он **отвечает, что записать**.

```flang
тотальная функция «Шаг драйвера»
  принимает порт: «Состояние UART», событие: «Событие»
  возвращает «Отклик драйвера»
```

Записывает хозяин на C, и вся его работа — цикл на шесть строк:

```c
while (1) {
    событие = ждать_прерывания();
    отклик = shag_drayvera(состояние, событие);
    for (i = 0; i < отклик.записей; i++)
        *(volatile uint32_t*)отклик.записи[i].адрес = отклик.записи[i].значение;
    состояние = отклик.состояние;
}
```

## Что доказано — прогоном, а не обещанием

```
flang check examples/driver/uart.flang --proof
утверждений 8: доказано 6, сетка 1, объявлено, не доказано 1
```

| обещание | вердикт |
|---|---|
| «ШАГ СОХРАНЯЕТ ГОДНОСТЬ: из годного состояния выходит годное» | **доказано** |
| «выключение пишет ровно в один регистр» | **доказано** |
| «выключенный порт байтов не копит» | **доказано** |
| «выключенный порт годен только с нулевой скоростью» | **доказано** |
| «адрес управления — шестнадцать», «адрес скорости — двадцать» | **доказано** |
| «ШАГ ПИШЕТ ТОЛЬКО В СВОИ РЕГИСТРЫ» | сетка |
| «адрес вне окна устройства чужой» | объявлено |

**Первое из них — это инвариант цикла.** В интерактивном прувере его пишут
теоремой вида «для любого годного состояния и любого события шаг вернёт годное
состояние». Здесь это одна строка `обеспечивает`, и ядро берёт её само.

## Чего не хватает, и это названо честно

**«ШАГ ПИШЕТ ТОЛЬКО В СВОИ РЕГИСТРЫ» не доказано.** В обещании стоит
`элемент 1 в результат.«записи»`, а переписки «элемент N в списке» у ядра нет.
Правило на неё написано и лежит в исходниках; до собранного компилятора оно
доедет перепечаткой семени.

Точнее, с 26 августа 2026 (задача 0050): нужное здесь равенство — четвёртое,
`элемент К в [Э₁, …, Эн]` при К литерале в границах, потому что
`результат.«записи»` тут ВЫПИСАННЫЙ список из одной записи. Раньше переписка
знала три равенства, и ни одно из них выписанного списка не читало. Проверено
прямым вызовом правила (`flang run` по «Развернуть элемент по номеру»): на
нетронутом ядре узел `элемент 1 в [а, б]` возвращается нетронутым, на правленом —
даёт `а`.

**⚠ Числа выше сняты заново 26 августа 2026 и сошлись знак в знак.** До этого
файл не проверялся ВОВСЕ ни одним существующим двоичным: в позициях типа у него
стояло слово `неотрицательное`, которого напечатанное семя не знает, и `check`
отвечал восемью `FLANG_UNKNOWN_NAME` и кодом 1, не напечатав ведомости. Откат к
`нат` — тот же самый, каким 24 августа чинили ствол (коммит `e6795b02`), просто
до этого файла он не дошёл.

**Живучести здесь нет вовсе.** Доказано, что каждый шаг переводит систему из
безопасного состояния в безопасное. Не доказано, что система вообще проснётся на
прерывание — это свойство бесконечной последовательности, а не одного шага, и
слов для него в языке пока нет.

## Почему это не хитрость

Обычно говорят: драйвер не доказать, там железо. Правда в том, что **железо —
это шесть строк, а остальное логика состояний**, и она доказуема целиком.

Если бы «Шаг драйвера» писал в регистры сам, ни одно из восьми обещаний не имело
бы смысла: про функцию с побочным действием ядру доказательств сказать нечего.
