# Библиотека — REST-сервис на flang и Node

Полноразмерный пример проекта: выдача книг, каталог, штрафы за просрочку.
Классический REST — шесть маршрутов, JSON, хранилище, коды ответов. Здесь нет
ничего игрушечного, кроме самого хранилища (оно в памяти процесса).

Пример существует ради одного вопроса: **что где лежит и почему именно там**.
Правила, выведенные из него, собраны в [docs/guide/project-layout.ru.md](../../docs/guide/project-layout.ru.md).

## Раскладка

```
examples/library-api/
  stdlib/                        flang: библиотека проекта, про область не знает
    text.flang                   модуль «Текст проекта» — списки строк
  lib/                           flang: чистые функции над данными
    isbn.flang                   модуль «ISBN» — контрольная цифра, ключ книги
    query.flang                  модуль «Строка запроса» — разбор «?a=1&b=2»
    catalog.flang                модуль «Каталог» — отбор, сводка, карточки
    fine.flang                   модуль «Штрафы» — сколько брать за просрочку
    loan.flang                   модуль «Выдача» — можно ли выдать книгу
    api.flang                    модуль «Прикладной слой» — единственный вход
```

Хозяина на Node здесь больше нет. Он был — `host/server.mjs`, `host/storage.mjs`,
`host/flang.mjs` и прогон `test/library-api.test.mjs`, — и снят 20 августа 2026
вместе с остальной оснасткой на JavaScript (коммиты `8f229280`, `501327bb`,
`22cff289`, `7d95994a`). Осталась половина на flang, и это ровно та половина,
ради которой пример писался: границу видно и по одному её краю.

## Разделение труда

| Кто | Что делает | Почему не сосед |
|---|---|---|
| **flang** (`lib/`, `stdlib/`) | тариф штрафа, право выдать книгу, разбор ISBN и строки запроса, отбор, сводка, печать карточки | у каждого куска есть пример, и пример выполняется набором |
| **хозяин** (был `host/` на Node) | HTTP-сервер, маршруты, хранилище, percent-декодирование | у сервера нет входа, на котором можно объявить пример: он ждёт входящих, а не считает ответ по доводам |

### Чего этот пример не показывает, хотя мог бы

**Право выдать книгу здесь просто СЧИТАЕТСЯ, а не доказывается.** Когда-то это
решение принимала не функция, а ДОКАЗАТЕЛЬСТВО: объявлялись два морфизма и
теорема, по снимку данных строился сертификат с отпечатком `sha256:…`, а хозяин
исполнял команду, названную выводом сертификата. Отказ при этом назывался не
«условие ложно», а «предпосылка не нашлась». Свидетельств по снимку данных
язык сегодня не строит: `lib/loan.flang` даёт тот же ответ на тех же входах, но
ответ этот подкреплён только телом функции и её примерами. Разница между
«доказано» и «посчитано» — единственное, ради чего этот репозиторий существует,
и прятать её в примере нельзя.

Граница проведена по одному правилу: **если у куска логики может быть пример —
он уезжает в модель или в модуль языка**, где пример выполняется набором. На
хозяине остаётся то, у чего примера быть не может.

Что это значило на практике: у хозяина не было ни одного числа из тарифа
штрафов, ни проверки ISBN, ни разбора строки запроса, ни условия «кому можно
выдавать книги». Всё это лежит в файлах, которые проверяются командой, — и
поэтому пример пережил снятие своего хозяина, не потеряв ни одного правила.

## Как запустить

Проверить модели и модули:

```bash
bootstrap/flang check examples/library-api/lib/api.flang
bootstrap/flang test  examples/library-api/lib/api.flang
```

`check` входного модуля собирает всю программу целиком — связывание идёт по
`использует «Модуль»`:

```
api.flang ──> catalog.flang ──> isbn.flang
          │                 └─> flang/stdlib/lists.flang  (только «Сумма», «Максимум», «Длина»)
          └─> query.flang ────> ../stdlib/text.flang      (только «Первая часть», «Хвост через», «Непустые»)
```

`test` прогоняет примеры всех собранных функций — своих и импортированных: 60
примеров на 27 функций из семи файлов.

## Что решала каждая сторона

Хозяин держал шесть маршрутов — `GET /health`, `GET /books` (в том числе с
отбором по автору и полке), `GET /books/summary`, `POST /books`, `POST /loans`,
`POST /returns` — и хранилище в памяти процесса. Из решения ему не принадлежало
ничего: разрешена ли выдача, верен ли ISBN, что означает `?author=…&shelf=yes`,
сколько взять за просрочку и как выглядит карточка книги — всё это считают
модули в `lib/`, и у каждого куска стоит выполняемый пример.

Когда-то ответ `POST /loans` нёс СЕРТИФИКАТ — имя выведенной команды, путь
вывода, список предпосылок и отпечаток `sha256:…`, — а отказ назывался
«предпосылка не нашлась». Сегодня этого нет; подробности — в шапке
`lib/loan.flang`.

## Библиотека проекта отдельно от хозяина

Хозяин в примере грузит `lib/api.flang` и вычисляет функции интерпретатором —
так короче и так виден исходник. Но библиотека проекта от хозяина не зависит и
печатается в целевой язык целиком:

```bash
bootstrap/flang emit examples/library-api/lib/api.flang --target js --out ./out-js
node -e 'import("./out-js/prikladnoy_sloy.js").then(m => console.log(m.kodVeren("978-5-17-118366-0")))'
# true
```

Получается обычный модуль: 27 функций программы и конструкторы её записей — без
зависимостей и без рантайма flang.
Целей восемь: `c`, `go`, `rust`, `python`, `java`, `csharp`, `elixir`, `js`.

## Где проходит граница честности

HTTP-сервер в этом примере писал хозяин, и это было не обходным путём, а
устройством: язык отвечает за то, что происходит с данными, и отвечает за это
примерами и доказанным завершением. Всё остальное — работа хозяина.

С 7 августа 2026 у языка появились эффекты — описанием, которое исполняет
хозяин (`flang/cat/SPEC.md`, «Эффекты и HTTP»). Тогда набор поручений описывал
только ИСХОДЯЩИЕ действия — прочитать файл, сходить по адресу, — и служба на
flang не писалась вовсе. Сегодня в словаре есть и ожидание входящих: «Принять
соединение», «Прочитать из соединения», «Ответить в соединение» и октетная пара
к двум последним (`flang/self/parser.flang`). Служба на них уже написана —
[`examples/web/shortener/`](../web/shortener), — но
поднимается она пока только на браузерном хозяине: хозяин на C отказывает всем
шести названно, потому что его планировщик синхронен и ждать сеть не умеет
(`flang/src/emit/c/flang_conc.c`). Этот пример на новые поручения не переписан.
