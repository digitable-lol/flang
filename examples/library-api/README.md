# Библиотека — REST-сервис на flang и Node

Полноразмерный пример проекта: выдача книг, каталог, штрафы за просрочку.
Классический REST — шесть маршрутов, JSON, хранилище, коды ответов. Здесь нет
ничего игрушечного, кроме самого хранилища (оно в памяти процесса).

Пример существует ради одного вопроса: **что где лежит и почему именно там**.
Правила, выведенные из него, собраны в [docs/rukovodstvo/project-layout.ru.md](../../docs/rukovodstvo/project-layout.ru.md).

## Раскладка

```
examples/library-api/
  stdlib/                        flang: библиотека проекта, про область не знает
    text.flang                   модуль «Текст проекта» — списки строк
  lib/                           flang: чистые функции над данными
    isbn.flang                   модуль «ISBN» — контрольная цифра, ключ книги
    query.flang                  модуль «Строка запроса» — разбор «?a=1&b=2»
    catalog.flang                модуль «Каталог» — отбор, сводка, карточки
    fine.flang                   модуль «Штрафы» — сколько брать за просрочку
    loan.flang                   модуль «Выдача» — можно ли выдать книгу
    api.flang                    модуль «Прикладной слой» — единственный вход
  host/                          Node: всё, чего в языке нет
    server.mjs                   HTTP, маршруты, коды ответов
    storage.mjs                  хранилище
    flang.mjs                    мост к flang
  test/
    library-api.test.mjs         прогон целиком: модули языка и живой сервер
```

## Разделение труда

| Кто | Что делает | Почему не сосед |
|---|---|---|
| **flang** (`lib/`, `stdlib/`) | тариф штрафа, право выдать книгу, разбор ISBN и строки запроса, отбор, сводка, печать карточки | у каждого куска есть пример, и пример выполняется набором |
| **Node** (`host/`) | HTTP-сервер, маршруты, хранилище, percent-декодирование | сервер — не эффект, а ожидание входящих: поручения такого рода в языке нет и не планируется |

### Что здесь было до 16 августа 2026

Каталог `domain/` держал две модели старого проекта FTS: тариф штрафа и право
выдать книгу. Проект вынесен из репозитория (тег `fts-pered-udaleniem`, дом —
[digitable-lol/fts](https://github.com/digitable-lol/fts)), и оба правила
переписаны на самом языке — `lib/fine.flang` и `lib/loan.flang`, один в один по
числам и примерам.

**Одно при этом потеряно, и это надо знать.** Право выдать книгу принималось не
функцией, а ДОКАЗАТЕЛЬСТВОМ: модель объявляла два морфизма и теорему, ядро
старого проекта строило по снимку данных сертификат с отпечатком `sha256:…`, а
хозяин исполнял команду, названную выводом сертификата. Отказ при этом назывался
не «условие ложно», а «предпосылка не нашлась». Свидетельств по снимку данных
язык сегодня не строит: `lib/loan.flang` даёт тот же ответ на тех же входах, но
ответ этот подкреплён только телом функции и её примерами. Разница между
«доказано» и «посчитано» — единственное, ради чего этот репозиторий существует,
и прятать её в примере нельзя.

Граница проведена по одному правилу: **если у куска логики может быть пример —
он уезжает в модель или в модуль языка**, где пример выполняется набором. На
хозяине остаётся то, у чего примера быть не может.

Что это значит на практике: в `host/server.mjs` нет ни одного числа из тарифа
штрафов, нет проверки ISBN, нет разбора строки запроса и нет условия «кому
можно выдавать книги». Всё это лежит в файлах, которые проверяются командой.

## Как запустить

Проверить модели и модули:

```bash
node flang/bin/flang.mjs check examples/library-api/lib/api.flang
node flang/bin/flang.mjs test  examples/library-api/lib/api.flang
```

`check` входного модуля собирает всю программу целиком — связывание идёт по
`использует «Модуль» из "путь"`:

```
api.flang ──> catalog.flang ──> isbn.flang
          │                 └─> flang/stdlib/lists.flang  (только «Сумма», «Максимум», «Длина»)
          └─> query.flang ────> ../stdlib/text.flang      (только «Первая часть», «Хвост через», «Непустые»)
```

`test` прогоняет примеры всех собранных функций — своих и импортированных: 60
примеров на 27 функций из семи файлов.

Поднять сервер:

```bash
node examples/library-api/host/server.mjs
# Библиотека: http://127.0.0.1:8797
```

Порт меняется переменной `LIBRARY_PORT`.

## Маршруты

```bash
curl -s http://127.0.0.1:8797/health
curl -s http://127.0.0.1:8797/books
curl -s -G --data-urlencode 'author=Стругацкие' --data-urlencode 'shelf=yes' \
  http://127.0.0.1:8797/books
curl -s http://127.0.0.1:8797/books/summary

curl -s -X POST http://127.0.0.1:8797/books -H 'content-type: application/json' \
  -d '{"код":"978-5-17-114589-7","автор":"Стругацкие","название":"Улитка на склоне","год":1968}'

curl -s -X POST http://127.0.0.1:8797/loans -H 'content-type: application/json' \
  -d '{"номер":"ВД-19","читатель":"Ковалёва А. П.","книга":"978-5-17-118366-0","долгов нет":true,"читатель допущен":true}'

curl -s -X POST http://127.0.0.1:8797/returns -H 'content-type: application/json' \
  -d '{"книга":"9785171183660","дней просрочки":14,"книга редкая":true}'
```

Ответ `POST /loans` говорит, разрешена ли выдача, и записывает её:

```json
{
  "выдача": { "номер": "ВД-19", "читатель": "Ковалёва А. П.", "книга": "9785171183660" },
  "разрешено": true
}
```

Если в заявке `"читатель допущен": false` или `"долгов нет": false`, сервис
отвечает 403 и `{"ошибка": "выдача не разрешена", "разрешено": false}`.

До 16 августа 2026 ответ нёс СЕРТИФИКАТ — имя выведенной команды, путь вывода,
список предпосылок и отпечаток `sha256:…`, — а отказ назывался словами ядра
(«предпосылка не нашлась»). Это была способность старого проекта FTS, и она
ушла вместе с ним; подробности — в шапке `lib/loan.flang`.

## Библиотека проекта отдельно от хозяина

Хозяин в примере грузит `lib/api.flang` и вычисляет функции интерпретатором —
так короче и так виден исходник. Но библиотека проекта от хозяина не зависит и
печатается в целевой язык целиком:

```bash
node flang/bin/flang.mjs emit examples/library-api/lib/api.flang --target js --out ./out-js
node -e 'import("./out-js/prikladnoy_sloy.js").then(m => console.log(m.kodVeren("978-5-17-118366-0")))'
# true
```

Получается обычный модуль: 27 функций программы и конструкторы её записей — без
зависимостей и без рантайма flang.
Целей восемь: `c`, `go`, `rust`, `python`, `java`, `csharp`, `elixir`, `js`.

## Где проходит граница честности

HTTP на flang не написан и написан быть не может. `host/server.mjs` — обычный
модуль Node, и это не обходной путь, а устройство. Язык отвечает за то, что
происходит с данными, и отвечает за это с примерами и доказанным завершением.
Всё остальное — работа хозяина.

С 7 августа 2026 у языка появились эффекты — описанием, которое исполняет
хозяин (`flang/cat/SPEC.md`, «Эффекты и HTTP»). Здесь это ничего не меняет, и
причина стоит того, чтобы её назвать: набор поручений закрыт и описывает
ИСХОДЯЩИЕ действия — прочитать файл, сходить по адресу. Сервер — это обратное:
ожидание входящих. Поручения «слушать порт» в наборе нет и не будет, потому что
исполнить его обязан был бы каждый из восьми хозяев, включая напечатанного в C.
