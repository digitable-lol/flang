# Решение ADR-0023 §6, сторожа 3 и 4. Набор, вынесенный из знаменателя доли,
# перестаёт быть виден в проценте, а невидимое ветшает. Здесь стоит то, что
# делает убыль набора ГРОМКОЙ: scripts/доказуемость.sh, проверка 4, сличает эти
# два числа с сегодняшним замером и при недоборе печатает НЕ ДОКАЗУЕМ, назвав,
# на сколько просело.
#
# ХРАПОВИК КРУТИТСЯ ТОЛЬКО ВВЕРХ. Поднять число вправе только человек и только
# вместе с доводом в сообщении коммита. Опустить его нельзя ничем: снижение —
# это и есть та беда, ради которой файл заведён.
#
# ДВА ЧИСЛА, И ОНИ СТЕРЕГУТ РАЗНОЕ:
#
#   подделок   — сколько строк в flang/proof/подделки/НАБОР.tsv. Стережёт от
#                исчезновения подделки: убрал строку — вердикт покраснел.
#
#   числитель  — сколько мест честных половин подделочных файлов чекер
#                ПРОИГРАЛ заново (ходами и тотальностью + по существу + узлы),
#                сложенное по всем строкам манифеста. Стережёт от беды, которой
#                счёт строк не видит: файл остался в манифесте, а его честная
#                половина тихо перестала проигрываться.
