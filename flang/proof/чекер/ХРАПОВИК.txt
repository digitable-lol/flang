# Строка кода — строка `сверщик.c`, на которой после снятия комментариев
# (`/* … */` где угодно, в том числе через строки, и `//` до конца строки)
# остаётся хоть один непробельный знак. Комментарии — за читаемость, не против
# проверок, и с проверками за место не соперничают. Считает ОДНА функция
# сторожа, и снять число может любой той же командой:
#
#     sh flang/proof/сверка-ведомости.sh --строки-кода
#
# ДОВОД, ПОЧЕМУ ДОВЕРЕННАЯ БАЗА МЕРЯЕТСЯ ТАК. База меряется ПРАВИЛАМИ ведомости
# (flang/proof/ПРАВИЛА-ВЫВОДА.tsv): у каждого правила — строка ведомости и лемма
# Lean, и код сверщика лишь переигрывает написанное. Строки кода — мера того,
# сколько такого переигрывания человек прочтёт; комментарий, объясняющий, почему
# проверка такова, читать помогает, а не мешает.
#
# ХРАПОВИК ДЕРЖИТ СВЕРХУ, а не снизу, — в отличие от храповика набора подделок
# (flang/proof/подделки/ХРАПОВИК.txt), который не даёт числу ПАДАТЬ. Потолок =
# база + сумма бюджетов решений; каждый бюджет — СТРОКА В ADR, и двигается он
# только правкой той строки (и этой таблицы вслед за ней). Ячейка, которая в
# потолок не влезает, останавливается и докладывает — потолок не двигается
# молча под работу. Опустить потолок — кто угодно, вместе с сокращением файла.
