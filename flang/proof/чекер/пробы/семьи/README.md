# Золотые сертификаты семей С1/С2 (задача 4104, Половина А)

Рукотворные сертификаты (исходник + запись), которыми проверено, что след
семей **С1 «соседи»** и **С2 «рефлексив»** проигрывается СЕГОДНЯШНИМ чекером
(`сверщик`, 7 существующих ходов) — без правки ядра и без перепечатки. Это
доказательство ВИДА следа до правки; цель — Половина Б (печать этих следов из
`zapis.flang`).

Записи собраны руками (тела/постусловия сняты знак в знак с настоящих мест
корпуса; шапка — строк/знаков/два отпечатка/sha256 — посчитана `shapka.py`
образца 4101). В `прогон.sh` НЕ вплетены — гонять напрямую:

    make -s -C flang/proof/чекер
    ./flang/proof/чекер/сверщик <исходник.flang> <запись>

## Верные сертификаты → КОД 0

- `sosedi.flang` / `sosedi.запись` — С1, 3 места (У1 «Сумма наоборот»,
  У2 «Произведение наоборот», Р3 «Удвоить»). Цепочка `развернуть → соседи →
  закрыть тождеством`. Прогон: КОД 0, 9 ходов проиграно.
- `refleksiv.flang` / `refleksiv.запись` — С2, 7 мест из 8 (Р7, Т4, В10, В11,
  «Удвоить», «Возвести в квадрат», «Заглавная точка»). Цепочка `развернуть →
  закрыть тождеством`. Прогон: КОД 0, 14 ходов проиграно.

## Порча хода → КОД 1 с называнием (`порча/`)

- `sosedi-podmena-tela.запись` — подменено тело развёртки; чекер называет:
  «запись несёт тело ⟨б плюс а⟩, а в строке 20 исходника написано «а плюс б»».
- `sosedi-bez-soseda.запись` — выброшен ход `соседи`; тождество не сходится:
  «закрыть тождеством: у цели «( а плюс б ) равен ( б плюс а )» стороны разные».
- `refleksiv-podmena-tela.запись` — подменено тело развёртки В11 (0→1); чекер
  называет строку исходника.

## Граница «сетки» (`granica/`)

- `r2-setka-distributivnost.*` — Р2 «Удвоить» (`н умножить на 2` = `н плюс н`):
  это дистрибутивность, не перестановка соседей. `соседи` её НЕ закрывает →
  КОД 1. Негативный контроль: сертификаты С1 не проходят даром.

## Место, которое НЕ легло на существующие ходы (`ne-lozhitsya/`)

- `r6-dlina-skobki.*` — **Р6 «Тот же список»** (`(длина результат) равен
  (длина элементы)`, тело `элементы`). План 4103 отнёс Р6 к С2. ПРОГОН
  ОПРОВЕРГАЕТ: развёртка вставляет тело в скобках внутрь `длина (…)`, цель
  становится `( длина ( элементы ) ) равен ( длина элементы )`, а `закрыть
  тождеством` снимает только ВНЕШНИЕ скобки (`uzhat`), внутренние `( элементы )`
  — нет. Ни один из 7 ходов внутренние скобки не убирает → КОД 1.
  Итог: С2 кроется существующими ходами на **7 из 8** мест, не на всех 8.
