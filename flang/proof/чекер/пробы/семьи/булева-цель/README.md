# Разбор по случаям: БУЛЕВА цель случая (не «результат не меньше 0»)

Инкремент 2. Золотой сертификат на узел **«разбором по случаям»** (носитель
`algebra`), где цель — БУЛЕВА (`результат`, `результат равен да`, связки да/или/не),
а не `результат не меньше 0`.

## Что было

Ветка `algebra` в `proigrat_uzel_algebra` бралась ровно за одну цель —
`результат не меньше 0` (неотрицательность по построению). Всякая ДРУГАЯ цель
падала на входном сторо́же `strcmp(cel, "результат не меньше 0") != 0` в «вне
приёма сверщика» → узел оставался на слове ядра, КОД 3.

Правка (`сверщик.c`, `proigrat_uzel_algebra`): у узла теперь ДВА домена цели.
`результат не меньше 0` — прежняя ветка `neotricatelno_algebra`. Всякая другая —
БУЛЕВА: тело случая подставляется вместо `результат`, и цель замыкается тем же
`polovina_zakryta`, каким `razborom_celi` закрывает половины разбора по условию
(да/нет, связки да/или/не, `равен`-тождество, замкнутый счёт). Входной фильтр по
правилу посылки расширен закрытым списком булевых правил (`bulevo_pravilo`).
Замыкание СОУНДНО: ложную цель оно не закроет — место лишь останется на слове
ядра, ложно не примется.

## Верный сертификат → КОД 0

- `priznak.flang` / `priznak.запись` — «Всегда истинно» над типом «Сигнал» из трёх
  вариантов, постусловие `результат`. Тела случаев — `да`, `(нет или да)`,
  `(не нет)` — все сводятся к `да` тремя РАЗНЫМИ законами замыкания (литерал,
  связка `или`, отрицание `не`). Запись снята двоичным `flang 0.7.13`, привязка
  криптографическая. Новый сверщик: КОД 0, узлов «разбором по случаям» проиграно
  заново 1. Старый сверщик (до правки): КОД 3.

## Сломанный разбор → КОД 1 (правка одной строки записи, вплетена в `прогон.sh`)

- посылка случая «Три» названа ЧУЖИМ вариантом «Раз» — разбор не покрывает
  объявленную сумму. КОД 1.
- посылка случая «Три» выброшена — принцип покрывает 2 варианта из 3. КОД 1.

## Ложь под самой целью → КОД 3 (сторож замыкания, `порча/`)

- `порча/lozh.flang` / `порча/lozh.запись` — исходник, где случай «Правый»
  возвращает `нет` под целью `результат`, и РУКОТВОРНАЯ запись, лгущая «вердикт
  доказано» тем же узлом algebra. Двоичный такую не запишет (цель нарушена), потому
  запись собрана руками; шапка её ЧЕСТНА (снята двоичным на отвергнутом проходе,
  отпечаток256 сходится). Замыкание обязано НЕ закрыть `нет`: сверщик называет
  «случай «Правый»: булева цель «нет» не замкнулась», узел не проигран, КОД 3 —
  ложь кодом 0 не принята. Это сторож соунднос­ти самого замыкания (branch-level
  ложь даёт третий исход, а не единицу; структурную ложь ловят две подделки выше).

Гонять напрямую:

    make -s -C flang/proof/чекер
    ./flang/proof/чекер/сверщик flang/proof/чекер/пробы/семьи/булева-цель/priznak.flang \
                                flang/proof/чекер/пробы/семьи/булева-цель/priznak.запись
