# Разбор по случаям: ветвь-случай — скобочное «если (У) то … иначе …»

Придирка Б. Золотой сертификат (исходник + запись) на узел **«разбором по
случаям»** (носитель `algebra`), где тело ОДНОГО случая — однострочное и есть
ЦЕЛИКОМ скобочное `если (У) то А иначе Б`. Эту форму сверщик прежде обрывал.

## Что было сломано

`тело_случая` снимал ведущее слово `то ` вызовом `хвост_после(telo, "то ")`,
а тот режет по КАЖДОМУ вхождению `то `. У однострочной ветви-выбора
`то (если У то А иначе Б)` слово `то ` стоит и внутри, поэтому бралась середина
между первым и вторым `то ` — тело обрывалось на первом же условии (`(если У`).
`неотрицательно_algebra` получал огрызок, форма ему была незнакома, узел уходил
«на слово ядра»: КОД 3, «форма «( если … » сверщику незнакома».

Правка (`сверщик.c`, `тело_случая`): ведущее `то ` уже подтверждено
`nachinaetsya`, поэтому режется ровно его длина, а не найденное вхождение. Тело
читается целиком, `разрез_выбора` берёт обе ветви, каждая — `(«Высота» от X)
плюс 1` — проигрывается неотрицательной по построению (вызов той же функции
неотрицателен по предположению, литерал 1 неотрицателен).

## Верный сертификат → КОД 0

- `vysota.flang` / `vysota.запись` — «Высота» двоичного дерева, постусловие
  `результат не меньше 0`, доказанное индукцией по «Дерево». Тело случая «Узел» —
  однострочное `то (если («Высота» от л) больше («Высота» от п) то («Высота» от л)
  плюс 1 иначе («Высота» от п) плюс 1)`. Запись снята двоичным `flang 0.7.13`
  (`check … --proof --записать`), привязка криптографическая (`отпечаток256`).
  Прогон доработанного сверщика: КОД 0, узлов «разбором по случаям» проиграно
  заново 1. Старый сверщик (до правки) на той же записи даёт КОД 3.

## Сломанный разбор → КОД 1 (правка одной строки записи, вплетена в `прогон.sh`)

- посылка ветви-случая «Узел» названа ЧУЖИМ вариантом «Лист»: разбор не покрывает
  объявленную сумму, «вид step» лжёт о варианте без поля своего типа. КОД 1.
- посылка ветви-случая «Узел» выброшена вовсе: принцип покрывает 1 вариант из 2.
  КОД 1.

Гонять напрямую:

    make -s -C flang/proof/чекер
    ./flang/proof/чекер/сверщик flang/proof/чекер/пробы/семьи/ветка-если/vysota.flang \
                                flang/proof/чекер/пробы/семьи/ветка-если/vysota.запись
