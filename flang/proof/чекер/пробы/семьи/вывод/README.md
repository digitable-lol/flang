# Семья «вывод»: факт о типе едет в записи выводом

Задача [6131](../../../../../../tasks/6131-sverschik-proigryvaet-blok-vyvoda.md),
основание — [ADR-0022](../../../../../../docs/adr/0022-a-type-fact-travels-as-a-derivation.md)
§3.10; форма блока и границы приёма расписаны в
[docs/design/proof-object-blok-vyvoda.md](../../../../../../docs/design/proof-object-blok-vyvoda.md).

## Что здесь лежит

| файл | что это |
|---|---|
| `vyvod.flang` | восемь функций — по одной на вид вывода: сумма двух объявленных, литерал, встроенная мера, довод под допущением, цель словом в слово допущением, имя точной сетки, разность под потолком, литерал под потолком |
| `vyvod.запись` | честная запись: у каждого утверждения блок вывода, всего десять правил ведомости |
| `порча/vychitanie-zapretom.запись` | вычитание названо запретом ведомости |
| `порча/vychitanie-pod-vidom-summy.запись` | вычитание выдано за сумму |

Записи РУКОТВОРНЫЕ: печать вывода в ядре — другая задача (6132), и приём обязан ехать
первым, иначе запись с блоком вывода была бы отвергнута как незнакомая.

## Мерило

Честная запись — код 0, восемь мест сняты со слова ядра («выводов факта о типе
проиграно заново 8»), долг ноль. Две подделки над `vychitanie-ne-sohranyaet` — код 1, и
причину называет проверка вывода, а не имя файла. Ещё семнадцать подделок собираются
порчей одной строки честной записи прямо в прогоне (`прогон.sh`, раздел «семья
„вывод“»): на каждый вид отказа своя проба и своя названная причина.
