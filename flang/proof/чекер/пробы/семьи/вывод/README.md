Записи РУКОТВОРНЫЕ: печать вывода в ядре — другая задача (6132), и приём обязан ехать
первым, иначе запись с блоком вывода была бы отвергнута как незнакомая. Строку
`обязательство вход` ядро сегодня не печатает тоже (6202-И3) — по тому же правилу
«сверщик раньше ядра» она читается уже сейчас. Шапки записей посчитаны по файлу
(строк, знаков, два отпечатка, sha256).

## Мерило

Честная `vyvod.запись` — код 0, восемь мест сняты со слова ядра («выводов факта о типе
проиграно заново 8»), долг ноль. `pred-zov` — код 0, одно место снято. `pred-zov-nechem`
— код 3, место на слове ядра, причина названа строкой «обязательство входа … сверщик
закрыть не смог». Подделки — код 1, и причину называет проверка вывода либо сверка
обязательств, а не имя файла. Ещё двадцать четыре подделки собираются порчей одной
строки честной записи прямо в прогоне (`прогон.sh`, раздел «семья „вывод“»): на каждый
вид отказа своя проба и своя названная причина; семь из них — о посылке П3 и
обязательстве входа (6202).
