// ПОЛ ДОКАЗАННОГО ПО ДЕРЕВУ. Строка:
//   «md5|написано|доказано|сетка|объявлено|без приговора|путь».
// Только файлы, в которых написано хоть одно обязательство: остальные в долю
// не входят. Список берётся из дерева (`git ls-files '*.flang'`), а не из
// прежней описи: файл, заведённый после прошлого замера, обязан появиться сам.
//
// «доказано», «сетка», «объявлено» — приговор СВОЕМУ файлу: строка приговора
// относится к файлу по имени функции, объявленной в нём. Складывать строки
// «итог:» нельзя — они берут замыкание ввоза и завышают (по дереву в 2,47
// раза, на ядре доказательств в 34,2).
//
// «без приговора» — обязательства, которых ведомость не судит вовсе: «требует»
// (предусловие) и «закон». Поле это считается ПО ИСХОДНИКУ, и двоичный для него
// не нужен: в ЭТОМ поле прочерк значит ноль, а не «не мерено», — и потому оно
// проставлено числом и там, где ведомость не снята вовсе. Таких строк 12, они
// несут 30 из 97; остальные 67 стоят у файлов с ведомостью. Сумма поля по описи
// обязана сходиться со счётом по дереву, и сегодня сходится: 97 и 97.
//
// ────────── ⚑ 5 сентября 2026: опись сведена с деревом, 194 беды → 3 ──────────
//
// ГЛАВНОЕ: врала не опись, а прибор сверки. Он искал `^ *обеспечивает `, а
// язык пишет обязательство и второй формой — с квантором:
//
//     для всех элементы обеспечивает «длина неотрицательна» результат не меньше 0
//
// Таких в дереве 165 в 94 файлах, и 79 файлов несут ТОЛЬКО её. Прибор считал
// их пустыми и объявлял их строки лишними. Из 71 «лишней» 69 приходились на
// живые файлы, и ВСЕ 69 были этой породы.
//
// Старший прибор `scripts/proved-share-of-a-file.py` квантор знал с самого
// начала (строки 31-34). Разошлись две редакции одного счёта — ровно то, от
// чего сверка и заведена.
//
// ЧТО ИЗМЕНЕНО В ОПИСИ:
//
//   «написано»          55 строк пересчитаны по исходнику
//   «без приговора»      1 строка
//   убрано                2 строки — файлов нет в дереве с 3 сентября (5d876b0e)
//   добавлено 31 строку   с полным приговором, ведомость снята прогоном
//   добавлено 38 строк    с «×» — ведомости у них быть НЕ МОЖЕТ
//
// ПОЧЕМУ «×» У ЭТИХ 38, а не «не мерено». Это пробы и подделки: `flang check`
// отвергает их по замыслу — `FLANG_PARSE` у файла с нарочно сломанным
// синтаксисом, `FLANG_PROOF_STEP` у пробы на плохой шаг доказательства.
// Проверено прогоном на выборке. Шапка ниже предупреждает, что прочерк
// когда-то оказался «не мерено», а не «мерить нечем», — здесь наоборот, и это
// установлено, а не предположено.
//
// ЧИСЛИТЕЛЬ СТАРЫХ СТРОК НЕ ТРОНУТ НИ РАЗУ. «Доказано», «сетка», «объявлено» —
// приговор ядра; переписать их без прогона значило бы соврать в приборе,
// которым потом меряют. По той же причине не тронут md5: он ДАТИРУЕТ числитель.
// Протухших строк как было 155, так и осталось — это честный долг, а не беда
// сверки.
//
// ЦЕНА, померена прогоном: все 72 недостающие ведомости — 6,4 минуты вместе.
// Шапка пугала 999 секундами на один файл (`sets-oracle`); на этой выборке
// такого не встретилось.
//
// ТРИ ПОСЛЕДНИХ ВЗЯТЫ, И СРОК БЫЛ МОЙ, А НЕ ИХ. На сроке 90 с они давали
// код 124, и первый вывод был «не уложились». Неверно: при сроке 900 с все
// три досчитались — sqlite-insert 170 с (код 3), sqlite-overflow 168 с

// полными. Урок ровно тот же, что и с «×»: «не уложился в МОЙ срок» — это не
// свойство файла.
//
// ИТОГ: опись сходится с деревом, бед 0.
//   «обеспечивает» по дереву 13811 = «написано» по описи 13811
//   «требует»+«закон» 102 = «без приговора» 102
//   строк 585, с ведомостью 483, с «×» 102
//
// ────────── 97 без приговора: две кучи, и они разные ──────────
//
// Снято 30 августа 2026 на стволе `5c0d35c9`, двоичный собран из семени этого же
// ствола (`make -C bootstrap -j8`, md5 4e32f9f76d8215c3b5df1b6abe0b6a68).
// Счёт по дереву: «требует» 88 строк в 32 файлах, «закон» 9 строк в 4 файлах,
// итого 97 при 13 484 «обеспечивает» — знаменатель дерева 13 581. Оба прибора

// названное в задаче 1729, к 30 августа уже закрыто.
//
// «НЕ ДОКАЗАНО» И «ДОКАЗАТЬ НЕЛЬЗЯ» — РАЗНЫЕ ВЕЩИ, и из знаменателя выносится
// только второе. Иначе доля лжёт в другую сторону.
//
// НИКОГДА — 92 строки. Вынесены из знаменателя доли.
//
//  • 88 «требует» в 32 файлах. Предусловие — ДОПУЩЕНИЕ, а не утверждение о
//    функции, и судится оно НЕ ПО СТРОКЕ, А ПО МЕСТУ ВЫЗОВА. Механика, снятая
//    прогоном: список приговоров строится фильтром `kind == "postcondition"`
//    (`flang/self/proof.flang:2629`); предусловие ядро кладёт в ФАКТЫ, из
//    которых доказывается постусловие (`flang/self/proofterm.flang:806` —
//    «ПРЕДУСЛОВИЕ ФУНКЦИИ — ТОЖЕ ДОПУЩЕНИЕ», и `Факт предусловия` строит запись
//    `kind: "precondition"`); наружу по предусловиям уезжают не вердикты, а СЧЁТ
//    МЕСТ — `{sites, discharged, diagnostics}`
//    (`flang/self/proofterm.flang:3496`). Единица суда видна и в отказе:
//    `FLANG_PRECONDITION_CALL … строка 17, столбец 3: вызов «Узкая» в функции

//    строка `требует`. Одна строка `требует` даёт столько судов, сколько у
//    функции мест вызова: ноль, один или сто. Приговора у самой строки нет и
//    быть не может — числитель считает строки, а не места.
//    Прогон 30 августа: из 36 файлов с «требует»/«закон» ведомость напечаталась
//    у 24, в них 67 строк «требует» — приговоров 0, и у всех 305 приговоров этих
//    файлов `kind` равен `постусловие`, ни одного `precondition`.
//
//  • 4 «закон» в двух ПОДДЕЛКАХ каталога `flang/test/fixtures/binary-rules/`:
//    `equality-not-symmetric.flang` (1) и `iso-mismatch.flang` (3). Файлы эти
//    написаны затем, чтобы быть отвергнутыми: первый объявляет равенством
//    несимметричное отношение и ждёт `FLANG_EQUALITY_NOT_SYMMETRIC`; второй —
//    посимвольная копия честного `examples/cat/order-shipment.flang` с ОДНОЙ
//    правкой (`обратный морфизм «по накладной»` → `«отгрузить»`). У программы,
//    которую двоичный обязан отвергнуть, ведомости не бывает и не будет никогда.
//
// НЕЛЬЗЯ СЕГОДНЯШНИМ ДВОИЧНЫМ — 5 строк. Остаются в знаменателе.
//
//  • 5 «закон» в двух честных примерах: `examples/cat/order-shipment.flang` (3)
//    и `examples/cat/modules/orders.flang` (2). Оба отвечают кодом 2:
//    «ведомость не печатается: в программе объявлено то, чьи законы бинарник не
//    считает — isomorphisms, categories, morphisms … У названного судьи нет
//    вовсе: правил, которые сверяли бы эти объявления, в дереве не написано ни
//    одной строкой». Это долг дерева, а не свойство обязательства, — и потому
//    из знаменателя они НЕ выносятся.
//    ⚠ Но и вшивание судьи их в числитель не приведёт: у закона алфавит
//    вердиктов ровно двухбуквенный — `"grid"` и `"violated"`, и другого места,
//    где собиралась бы `Строка закона ведомости`, в `flang/self/proof.flang`
//    нет. Ведомость говорит об этом сама: «законы (сетка конечна,
//    доказательством не является)», и считает их отдельной строкой итога
//    («законов на сетке»), а не в «утверждений N». Чтобы закон попал в
//    числитель, нужен НОВЫЙ род вердикта у закона, а не подключение оракула.
//
// Как это считать прогоном: `sh scripts/published-vs-tree.sh --доля` печатает
// разложение знаменателя и знаменатель доли отдельной строкой.
//
// ────────── прочерк у flang/self/distributed.flang снят ключом, а не правкой ──
//
// Тем же заходом 30 августа 2026 выяснилось, что этот прочерк был «не мерено», а
// не «мерить нечем». Файл отвечал `FLANG_RECURSION_LIMIT: функция «Прогон»
// превысила предел глубины вызовов (20000)` — это предел САМОГО КОМПИЛЯТОРА, и
// у двоичного есть ключ, которым он задаётся. Прогон
// `./bootstrap/flang --предел-глубины 200000 check flang/self/distributed.flang
// --proof --json` (ворота PIK=12G PAMYAT=60G) — код 0, 75,11 с, пик 810 МБ,
// ведомость печатается: 54 доказано, 6 сетка, 21 объявлено при 81 постусловии,

//

//
// ────────── сколько прочерков ключ снимает: померено по всей описи (9204) ────
//

// СНЯЛ НИ ОДНОГО. Двоичным, собранным из перепечатанного семени e053c01e (md5

// семени: коммит 43bf2f25 откатил перепечатку, и сборка ствола (md5
