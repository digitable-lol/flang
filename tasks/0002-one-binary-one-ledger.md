# 0002. Отчёт о доказательствах всего дерева снят одним двоичным за один заход

Числа расходятся: один заход называет +341 по компилятору, другой — больше
пятисот по обоим деревьям. Складывать их нельзя — так уже было, когда двое
взяли `http.flang` порознь, и оба числа пришлось выбросить.

Снять отчёт по всему дереву ОДНИМ свежим двоичным, одним заходом, и объявить
это число единственным. Все прежние — рабочие, не отчётные.

## Как понять, что сделано

Одно число на дерево, снятое одной командой, с именем двоичного и датой рядом.
Прежние числа названы устаревшими там, где они напечатаны.

## Чем ограничено

Отчёт по одному файлу берёт минуты и гигабайты (`scram.flang` — 271 секунда и
2,1 ГиБ). Снимать по одному файлу за раз. Ждёт задачи 0003: до перепечатки
двоичный судит по старым правилам ядра.

Сюда же входит перепроверка числа `automaton.flang`: было «0 из 5», стало
«98 из 102» — страница поправлена, число свежим двоичным не перемерено.

## Чем закрыта

**Одно число — доказанных обязательств 3961 из 13341 написанных в дереве,
то есть 29,7 %.** Снято 28 августа 2026 одним двоичным за один заход.
Учтено файлов: 177 из 431 — те, где сошлись два независимых
счёта; остальные названы поимённо, с причиной.

Двоичный — `bootstrap/flang`, md5 `82f9ac4018e795ec19955a7ce2a9c1a8`,
14 068 112 байт, версия 0.6.2, собран `make -C bootstrap -j8` (62,67 с, пик
1,04 ГиБ) из семени ствола `da47cbdf`; семя менялось последний раз коммитом
`58b037c2`. Вшитый предел шагов — 1 000 000 000
(`bootstrap/flang_runtime.h:11`), и **задать его у `check` этой сборки нечем**:
ни `--step-limit`, ни `--предел-шагов`, ни `--max-steps` она не понимает.
Поэтому имя коммита определяет число целиком.

```sh
./bootstrap/flang check <файл> --proof
python3 flang/scripts/per-file-proof-share.py . отчёты/
```
