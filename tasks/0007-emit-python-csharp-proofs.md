# 0007. Обещания «emit-python.flang» и «emit-csharp.flang» доказаны

Два генератора кода, за которыми на 24 августа никто не числился:
`flang/self/emit-python.flang` — около 60 недоказанных, `emit-csharp.flang` —
около 101. Файлы меньше трёх больших из задачи 0006, и потому годятся, чтобы
проверить приёмы на короткой дистанции.

## Как понять, что сделано

Число доказанных до и после по каждому файлу.

## Чем ограничено

Из восьми целей печати важна только C, остальное отложено
(`docs/zettel/what-is-deferred.md`). Прибавка тут — в удешевлении перепечатки, а
не в самих целях.

## Откуда

`/srv/work/zadachi-vypusk-0-7-0.md` (пункт 5).
