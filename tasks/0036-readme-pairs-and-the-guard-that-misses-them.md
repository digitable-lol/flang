# 0036. У каждого README есть английская пара, и сторож двуязычности смотрит не только в «docs/site»

Открыв `web/shortener` на GitHub, англоязычный читатель видит **279 строк
по-русски** в файле, который называется `README.md`. И так почти везде.

## Замер

**27 README в дереве. Английская пара есть ровно у одного — корневого.**

| файл | строк |
|---|---:|
| `flang/stdlib/README.md` | 819 |
| `docs/zettel/README.md` | 616 (печатается, руками не трогать) |
| `fspec/README.md` | 473 |
| `examples/driver/msi/README.md` | 363 |
| `web/shortener/README.md` | 279 |
| `web/wasm/README.md` | 211 |
| `examples/web/shortener/README.md` | 210 |
| `examples/rosetta/README.md` | 205 |
| остальные 19 | ~2200 |

Итого около **5400 строк русского текста в файлах с английскими именами**.

## Почему это не ловится

Сторож двуязычности есть, но ограничен одним каталогом, и это нигде не сказано.
`docs/site/build.mjs:151`:

```js
const обязана = с.из.startsWith(СВОИ) && !с.печатается;   // СВОИ = 'docs/site/'
```

Освобождение `печатается` рядом объяснено врезкой — а про `startsWith(СВОИ)` не
объяснено ничего. Из-за этого **всё вне `docs/site/` освобождено молча**:

```
нет английской пары: docs/guide/project-layout.md   (361 строка по-русски)
нет английской пары: docs/guide/mcp.md              (95 строк)
```

Это страницы руководства — второе, что читает человек после README, — и они
проходят сборку зелёными.

## Почему одной ссылки на сайт не хватит

Первая мысль — поставить в README ссылку на GitHub Pages, где обе версии. Не
работает по двум причинам:

1. **Вести некуда.** Карта сайта (`docs/site/sitemap.mjs`) берёт 50 источников,
   все из `docs/` плюс `CHANGELOG.md`. Ни один README из `web/`, `examples/`,
   `editors/` не публикуется вовсе.
2. **GitHub показывает README прямо на странице каталога.** Человек, открывший
   `web/shortener`, читает его там же и по ссылке не пойдёт, если первый экран
   на непонятном языке. Ссылка помогает тому, кто уже решил читать дальше.

## Что делать

Уклад уже есть и работает — корневой README показывает его строкой сверху:

```
**English** · [Русский](README.ru.md) · [Documentation site](https://digitable-lol.github.io/flang/en/index.html)
```

Порядок:

1. **Английский текст в `README.md`, русский в `README.ru.md`**, строка-переключатель
   сверху у обоих. Начинать с тех, что видны первыми: `examples/`, `web/`,
   `editors/`, `docs/` — их открывают чаще вложенных.
2. **Расширить сторожа за пределы `docs/site/`** и объявить его границу словами, а
   не выводить её из одной строки кода. Освобождения — только названные:
   `печатается` (перевод приходит из печати), машинный вывод (`bootstrap/`).
3. **Добавить README в карту сайта** — тогда ссылка на Pages обретает смысл, и
   двуязычность начинает сторожиться тем же прогоном, что и остальное.

Порядок важен: пункт 2 без пункта 1 покрасит сборку на 26 файлах разом.

## Как понять, что сделано

```sh
node docs/site/build.mjs --check          # 0, и он ловит непарность вне docs/site
```

Плюс показ порчи: снять английскую пару у любого README — сборка обязана
покраснеть с названным файлом. Сегодня она этого не делает.
