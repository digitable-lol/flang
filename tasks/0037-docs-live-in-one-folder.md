# 0037. Документация живёт одной папкой «docs», а README каталогов — короткие указатели туда

Открыв `web/shortener` на GitHub, англоязычный читатель видит **279 строк
по-русски** в файле, который называется `README.md`. И так почти везде.

## Замер

**27 README в дереве. Английская пара есть ровно у одного — корневого.**

| файл | строк |
|---|---:|
| `flang/stdlib/README.md` | 819 |
| `docs/zettel/README.md` | 616 (печатается, руками не трогать) |
| `fspec/README.md` | 473 |
| `examples/driver/msi/README.md` | 363 |
| `web/shortener/README.md` | 279 |
| `web/wasm/README.md` | 211 |
| `examples/web/shortener/README.md` | 210 |
| `examples/rosetta/README.md` | 205 |
| остальные 19 | ~2200 |

Итого около **5400 строк русского текста в файлах с английскими именами**.

## Почему это не ловится

Сторож двуязычности есть, но ограничен одним каталогом, и это нигде не сказано.
`docs/site/build.mjs:151`:

```js
const обязана = с.из.startsWith(СВОИ) && !с.печатается;   // СВОИ = 'docs/site/'
```

Освобождение `печатается` объяснено рядом целой врезкой. Ограничение каталогом
объявлено **одной строкой и в другом файле** — `docs/site/sitemap.mjs:15`: «Для
страниц вне `docs/site/` пара берётся по наличию». Довода при ней нет, и рядом с
самим условием в `build.mjs` о ней не сказано, поэтому вне `docs/site/`
непарность проходит незамеченной:

```
нет английской пары: docs/guide/project-layout.md   (361 строка по-русски)
нет английской пары: docs/guide/mcp.md              (95 строк)
```

Это страницы руководства — второе, что читает человек после README, — и они
проходят сборку зелёными.

## Почему одной ссылки на сайт не хватит

Первая мысль — поставить в README ссылку на GitHub Pages, где обе версии. Не
работает по двум причинам:

1. **Вести некуда.** Карта сайта (`docs/site/sitemap.mjs`) берёт 50 источников,
   все из `docs/` плюс `CHANGELOG.md`. Ни один README из `web/`, `examples/`,
   `editors/` не публикуется вовсе.
2. **GitHub показывает README прямо на странице каталога.** Человек, открывший
   `web/shortener`, читает его там же и по ссылке не пойдёт, если первый экран
   на непонятном языке. Ссылка помогает тому, кто уже решил читать дальше.

## Решение владельца: одна папка вместо двадцати шести

Не заводить двадцать шесть английских пар по каталогам, а **вынести содержимое
README в `docs/`**, где оно печатается на сайт обеими версиями. В каталоге
остаётся короткий указатель со ссылками туда.

Тогда обновляется **одна папка**, и незачем помнить, что где-то в глубине лежит
README, который устарел полгода назад.

### Дублирование уже есть, и в одной паре хвост виляет собакой

| README каталога | строк | страница сайта | строк |
|---|---:|---|---:|
| `flang/stdlib/README.md` | 819 | `docs/site/stdlib.ru.md` | 1275 |
| `fspec/README.md` | **473** | `docs/site/fspec.ru.md` | **101** |
| `web/wasm/README.md` | 211 | `docs/site/embedding.ru.md` | 422 |
| `editors/README.md` | 69 | `docs/site/editor.ru.md` | 247 |
| `examples/README.md` | 58 | `docs/site/learning.ru.md` | 141 |

У `fspec` README **вчетверо подробнее страницы сайта**: источник правды сейчас
в каталоге, а на сайте огрызок. Это ровно та беда, ради которой задача заведена.

### Короткий указатель двуязычен в одном файле

Ему не нужна английская пара, а значит и сторож на него не покраснеет:

```markdown
# flang · shortener

**[Documentation](https://digitable-lol.github.io/flang/en/shortener.html)** ·
**[Документация](https://digitable-lol.github.io/flang/shortener.html)**

Client of the URL-shortener service, written entirely in flang.
Клиент службы-сокращателя, целиком на flang.
```

Три строки, устаревать нечему.

### Обратная ссылка сторожится в обе стороны

Документ в `docs/` называет путь, который описывает, — и это проверяется:

- **путь, названный документом, обязан существовать**, иначе документ переживёт
  удалённый каталог;
- **каталог с кодом обязан быть описан**, иначе новый каталог тихо останется без
  документации.

Вторая половина важнее первой: она ловит то, чего ещё нет, а первая — то, что
уже сгнило.

### Три каталога вынести НЕЛЬЗЯ, и вот почему

- **`editors/vscode/README.md`** — VS Code Marketplace рендерит его как описание
  расширения. Ссылка вместо текста означает пустую страницу в маркетплейсе.
- **`docs/zettel/README.md`** — печатается прогоном (`указатель:печать`), руками
  не правится вовсе.
- **`bootstrap/README.md`** — объясняет машинный вывод, лежащий в том же
  каталоге; его читают, уже открыв каталог, и обычно без сети.

Спорный четвёртый — `tasks/README.md`: устройство задачника нужно тому, кто уже
работает с `tasks/`. Решить при работе и записать довод.

### Порядок

1. Перенести содержимое в `docs/`, обеими версиями, и вписать страницы в карту
   сайта (`docs/site/sitemap.mjs`).
2. Заменить README каталогов короткими указателями.
3. Завести сторожа обратной ссылки — обе стороны.
4. **Расширить сторожа пар за пределы `docs/site/`** и объявить его границу
   словами. Делать это раньше пункта 1 нельзя: покрасит сборку на двадцати шести
   файлах разом.

## Как понять, что сделано

```sh
node docs/site/build.mjs --check          # 0, и он ловит непарность вне docs/site
```

Плюс показ порчи: снять английскую пару у любого README — сборка обязана
покраснеть с названным файлом. Сегодня она этого не делает.

## Откуда

Владелец открыл `web/shortener` на GitHub 24 августа 2026 и увидел русский текст.


## Чем закрыта

Первый пункт порядка — перенос — сделан на пяти README из двадцати шести, и это
те, что владелец открывает чаще прочих. Второй — короткий указатель — сделан на
тех же пяти.

**Переехало содержимое, парами:**

| откуда | строк | куда | адрес |
|---|---:|---|---|
| `web/shortener/README.md` | 279 | `docs/site/shortener.ru.md` + `.md` | `shortener.html` |
| `examples/web/shortener/README.md` | 210 | туда же | `shortener.html` |
| `web/app/README.md` | 156 | `docs/site/browser-app.ru.md` + `.md` | `browser-app.html` |
| `examples/README.md` | 58 | `docs/site/examples.ru.md` + `.md` | `examples.html` |
| `editors/README.md` | 69 | вписано в `docs/site/editor.ru.md` + `.md` | `editor.html` |

Три новые страницы вписаны в карту сайта — раздел «Что язык умеет», с доводом на
месте. Английская редакция написана переводом русской, а не заново.

**Что сведено в одно, а не положено рядом.** Клиент и служба сокращателя
описывали ОДНУ демонстрацию двумя файлами и повторяли друг друга: раскодирование
процентов, довод «поручение несёт текст, а не разметку», перечень расхождений
браузера и службы. Повтор выброшен, осталось по одному разу; страница одна на обе
половины, указателя два — по одному в каждом каталоге. У `editors/README.md`
выброшены как повтор три куска, стоявшие в `editor.ru.md` дословно: абзац о трёх
расширениях имени файла, строка «подсветка есть для Vim 8/9, Neovim и VS Code» и
пересказ сборки расширения VS Code. Осталось и вписано то, чего на странице не
было: раскладка каталога `editors/`, замер печатаемой подсветки (46 строк у Vim,
60 у VS Code, обе из таблицы языка) и неоплаченный долг по tree-sitter и Chroma.

Попутно снято одно расхождение между двумя README: `web/app` говорил «печать
планов в цели — 0 из 8», `web/shortener` — что для цели `js` это закрыто тремя
правками. Правда вторая, и на странице стоит она.

**`tasks/README.md` решено НЕ выносить**, довод тот же, что у `bootstrap/README.md`:
его читают, уже открыв каталог, и читают ДО того, как появится повод открыть сайт.
Это инструкция к работе — «свериться со стволом, вписать себя в шапку, объявить
доли», — и нужна она ровно тому, кто сейчас в `tasks/` и берёт задачу. Ссылка
вместо текста здесь стоила бы похода в сеть посреди действия, которое без сети
делается целиком.

## Что осталось

Двадцать один README из двадцати шести. Три из них выносить нельзя (названы выше),
`tasks/README.md` решено не выносить. Остальные ждут своей очереди, и у двух
причина названа:

- **`fspec/README.md` (473 строки) — не тронут, потому что файл держит доля другой
  ветки** (`b/targets-cyrillic`). Это ровно тот README, ради которого задача и
  заведена: он вчетверо подробнее `docs/site/fspec.ru.md`, и сводить их надо
  вместе. Брать чужую долю нельзя, поэтому работа отдельная и первая в очереди.
- **`web/wasm/README.md` (211 строк) — не тронут по существу дела.** Его настоящий
  сосед по содержанию не `docs/site/embedding.ru.md`, а `docs/wasm-via-c.md`
  (534 строки): §7 той страницы разбирает ту же ловушку теневого стека теми же
  таблицами. Свести их — значит переименовать `docs/wasm-via-c.md` в
  `.ru.md` и написать английскую редакцию на 534 строки; это отдельная работа, и
  делать её мимоходом нечестно.

Пункты 3 и 4 порядка (сторож обратной ссылки, расширение сторожа пар за пределы
`docs/site/`) не начаты — по условию задачи четвёртый нельзя делать раньше
первого, а первый сделан на пятой части.

## Найдено попутно

- `docs/site/sitemap.flang` — близнец карты сайта на flang — не читается ничем и
  уже разъехался с `sitemap.mjs` независимо от этой работы: у `dlya-ii.html` в нём
  имя «flang и ИИ» против «Служба для ИИ-помощника», у `case-studies.html` —
  «Разборы настоящих случаев» против «Разбор: 82 задачи с leetcode». Второе
  описание без сторожа расходится с первым; сторожа у этой пары нет.
- Корневые `README.md` и `README.ru.md` говорят «наборы перечислены в
  `examples/README.md`». Файл на месте, ссылка цела, но перечня в нём больше нет —
  он на `examples.html`. Оба корневых README держит доля `b/docs-roadmap`, поэтому
  фраза не поправлена.
