# 0043. Новый двоичный принят по четырём приметам, а не на слово

Перепечатка семени 25 августа 2026 идёт (дерево `/srv/flang-rabota/u-semya5`,
печатник `bootstrap-pechatnyy/flang`, журнал `/srv/work/semya5.log`, ход
`/srv/work/hod-semya5.log`). **Как только она дойдёт, двоичный надо принять
проверками, а не радостью.**

Готовый разбор лежит в `/srv/work/posle-perepechatki.sh` — семь шагов. Здесь
записано, ЧТО именно каждый шаг обязан показать, чтобы не пришлось вспоминать.

## Почему это отдельная задача

За сутки перепечатка гибла **четыре раза**, и один раз дошла, но дала двоичный,
который падал на первом же файле. То есть «печать кончилась кодом 0» само по
себе ничего не значит.

## Четыре приметы

### 1. Печать конкурентности в C появилась

```sh
nm -a bootstrap/flang | grep -o 'compiler_flang_[a-z_]*konkurentnost[a-z_]*' | sort -u
```

**Было** (elixir, js, java — и ни одного `…_c`):
```
compiler_flang_chast_konkurentnosti_java
compiler_flang_pechat_konkurentnosti_elixir
compiler_flang_pechat_konkurentnosti_js
```

**Обязано появиться** имя с `_c`. Без него многоядерность языка остаётся
недоступной, хотя замерена: восемь процессов дают **7,92× на восьми ядрах**.

Дальше — прогон: `flang emit flang/conc/examples/counter.flang --target c`
обязан положить `flang_conc.c` в вывод, `grep -c flang_conc <кат>/Makefile`
больше нуля, и собранная программа работать.

### 2. Вердикт «доказано ПРИ УСЛОВИИ» появился

```sh
grep -c 'ПРИ УСЛОВИИ' bootstrap/compiler_flang.c    # было 0
```

Пока его нет, двоичный складывает условные в «доказано», и **все наши числа —
верхняя оценка**. Найдено 27 условных при неполном обходе, то есть просядет не
меньше чем на 6,6 %.

### 3. Строка хода появилась

```sh
strings bootstrap/flang | grep -c 'шагов .* из .*, идёт'    # было 0
```

Тогда девятичасовая работа перестанет быть слепой: строка раз в полминуты через
`alarm`, счёт витков не тронут (задача 0031).

### 4. Видов цели девять, а не семь

Правило 11 «строгий порядок по построению» влилось 25 августа. Проверить прямым
прогоном: строгое неравенство над ТЕРМОМ (не замкнутой целью) обязано браться.

## И сразу — не сломан ли он

```sh
flang check flang/stdlib/hashmap.flang --proof
```

Прошлый двоичный на этом падал: `FLANG_PROPERTY: нарушено свойство «беды не
убывают — Только диагностики»`. Проверка идёт секунды и стоит того.
