# 0045. Старый сторож жаргона на JavaScript снесён — новый сошёлся знак в знак

Сторож жаргона переписан на flang (задача 0016, влито 25 августа 2026):
`flang/scripts/jargon-guard.flang`, 107 функций, **у всех завершение доказано**,
`flang check` чистый за 0,4 с.

**И он сошёлся со старым знак в знак на ВСЁМ дереве**, трижды:

```
node scripts/jargon-guard.mjs   → код 1
flang io …jargon-guard.flang    → код 1, 221 с
diff staryy.txt novyy.txt       → пусто
```

Все 51 поверхность, 17 бед, те же файлы, номера строк, порядок и код возврата.

**Строк JavaScript из дерева при этом ушло ноль** — старый на месте.

## Почему не снесли сразу

Снос — **восемь мест-ссылок**, включая тест, который его ввозит. Делать это на
хвосте смены, не прогнав после `./ярлык тесты` и `./ярлык сторожа:проверка`,
значит отдать сырое. Тем более что в тот же день новый сторож **едва не уехал
сломанным**: первый полный прогон дал 18 бед вместо 17 — заслонённый знак в
строке снова открывал заслон, и `"\\"` не закрывал литерал.

## Что сделать

1. Найти все восемь мест-ссылок (`grep -rn 'jargon-guard.mjs'`).
2. Перевести каждое на `flang io flang/scripts/jargon-guard.flang`.
3. Прогнать `./ярлык тесты` и `./ярлык сторожа:проверка` — оба должны отвечать
   так же, как до сноса.
4. Только потом удалить `scripts/jargon-guard.mjs` (475 строк).

## Цена, которую надо назвать в отчёте

Новый сторож **в семьсот раз дороже**: 0,3 с против 221 с. Две трети времени —
посимвольный разбор двух исходников на C (589 КБ). Следующий шаг за этой
задачей: заменить посимвольный обход делением по литералам.

## Как понять, что сделано

`grep -rn 'jargon-guard.mjs'` пуст, `./ярлык тесты` и `./ярлык
сторожа:проверка` отвечают прежними кодами, файла нет.
