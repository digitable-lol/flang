# 0062. Расширения имени файла — один список, и «.фланг» в нём есть

Владелец 26 августа 2026: к `.flang`, `.fp` и `.фп` добавить `.фланг`.

**Прежде чем добавлять — замер, и он оказался неожиданным.**

## Что происходит сегодня

`flang check <файл>` **берёт любое расширение и не смотрит на него вовсе**.
Проверено прогоном, пять файлов с одним содержимым:

```
.фланг    проверено — замечаний нет
.fp       проверено — замечаний нет
.flang    проверено — замечаний нет
.фп       проверено — замечаний нет
.ерунда   проверено — замечаний нет      ← и это тоже
```

То есть у передней двери списка расширений **нет**: назвал файл — он прочтётся.

**А обход каталога берёт ТОЛЬКО `.flang`.** Тот же опыт, четыре файла в одном
каталоге:

```
$ flang test /srv/tmp/rasshirenie
корпус: файлов 1, взято 1, примеров 1, прошло 1
```

**Файлов было четыре. Взят один.** Остальные три — `.fp`, `.фп`, `.фланг` — не
отвергнуты с отказом, а **пропущены молча**.

## Значит задача не «добавить .фланг»

`.фланг` уже работает, если файл назвать явно. Настоящая беда другая, и она хуже:
**два разных ответа на один вопрос «это файл языка?»**, и один из них — тихий
пропуск.

Тихий пропуск дороже отказа: положил модуль в каталог, прогнал корпус, увидел
«прошло всё» — а модуль не смотрели вовсе.

## Что сделать

1. **Найти, где обход каталога решает, брать файл или нет** — там сейчас `.flang`
   поимённо. Найти ВСЕ такие места: не только `flang test`, но и сторожа
   (`grep -rn "\.flang" flang/scripts/`), сборку сайта, опись корпуса, `files` в
   `package.json`.
2. **Свести в один список** и назвать его один раз — в языке, а не в каждом
   обходчике. Сегодня их несколько, и они разошлись.
3. **Добавить `.фланг`** в этот список.
4. **Решить, что делать с чужим расширением у передней двери.** Два ответа
   годятся, но выбрать надо один и записать почему: либо брать что дают (как
   сейчас), либо отказывать с названным списком. Молчаливого пропуска не должно
   быть нигде.

## Осторожно

**Имена файлов в дереве — английские**, это правило приёмной. `.фланг` — не имя
файла, а расширение, и оно кириллическое так же, как кириллические ключевые слова
языка. Правилу не противоречит, но сказать об этом в решении надо, чтобы не
спорили потом.

**Не переименовывать существующие файлы.** В дереве больше тысячи `.flang`, и
трогать их незачем: список расширений нужен, чтобы принимать НОВЫЕ имена, а не
чтобы менять старые.

## Как понять, что сделано

Четыре файла с одним содержимым и разными расширениями в одном каталоге:

```
flang test <каталог>  →  файлов 4, взято 4
```

И пятый, `.ерунда`, либо взят по объявленному правилу, либо отвергнут с
названным списком — но не пропущен молча.
