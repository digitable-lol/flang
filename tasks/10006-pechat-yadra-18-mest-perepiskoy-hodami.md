# 10006. Печать ядра — 18 мест `perepiskoy` ходами

## Откуда

Карта калькулятора (`ПЕРЕДАЧА/karta-kalkulyatora.md`, §0 п. 3–4, §2 Б1/Б1+): переигрыватель
в сверщике для всех 18 мест `perepiskoy` **уже готов** — golden-сертификаты
`пробы/семьи/{sosedi,refleksiv,половина-б/dlina,element,arithmetic}` проигрываются кодом 0.
Отстаёт **печать ядра** (`flang/self/zapis.flang`, семьи С1–С5, строки 1596–1990):

- **Б1, 11 мест** (У1, У2, У4–У7 в `abilities`; Р3, Р4, Р6, Р7 в `equality`; Э1 в
  `element-po-nomeru-chestnaya`): печать написана, но печатник С2 «голое тождество»
  (`Ходы тождества постусловия записи`) выпускает `развернуть → закрыть тождеством` для ЛЮБОГО
  однострочного тела — и там, где стороны после развёртки не тождественны (У3 свёртка, Р1 круг,
  К1 квантор). Сверщик честно отвечает кодом 1, и красная запись прячет 11 верных цепочек.
- **Б1+, 7 мест** (Э2, Э3 ×2, Э4 ×2, Э2+Э4 в `element-po-nomeru-chestnaya`; нульарная «Азбука
  проверки» в `poddelka-slovo-o-dokazannosti`): печать не написана.

## Что делается

1. **Печатник С2 молчит, где стороны не тождественны.** Печать строит цель ТОЙ ЖЕ нормализацией,
   что у сверщика (`term` = `uzhat` ∘ `rasstavit`, `vstavit_vmesto`, `v_skobki`, `razdelit_sverhu`
   — `flang/proof/чекер/сверщик.c:470–560`), подставляет вызов вместо `результат`, разворачивает
   тело и печатает `закрыть тождеством` ТОЛЬКО когда обе стороны равенства после `uzhat` совпадают
   знак в знак. Иначе — пустой список: место уезжает именем правила (на слово ядра, код 3), как
   и задумано шапкой С2.
2. **Э2–Э4 (С4).** Зеркало `forma_elementom` (сверщик.c:3826) текстом: номер К−1 при
   `приписать`, `( длина Х ) плюс 1` при `добавить`, К-й член выписанного списка; цепочка
   продолжается, пока левая сторона — форма `элемент … в …`; при номере `длина результат`
   сначала «Мера прибавления» (ровно как в golden `половина-б/element.запись`). Каждый ход
   проверяется той же симуляцией: правая пересобирается печатью так же, как её пересоберёт
   сверщик, и цепочка выпускается только если она замыкается тождеством.
3. **Нульарная функция + С5 после развёртки.** Вызов без « от ( … )» (`развернуть ⟨«Азбука
   проверки»⟩ строка N ⟨"абвг"⟩`), затем `вычислить ⟨длина "абвг"⟩ = ⟨4⟩` — только для
   `длина "литерал"` (число кодовых точек литерала), затем `закрыть тождеством`.
4. Семьи С1 (соседи), С3 (длина, Д1–Д5), С4-Э1 и С5 (замкнутая цель) печатают ТОТ ЖЕ текст,
   что и прежде: незатронутые записи корпуса обязаны остаться байт в байт.

Комментариев в `.flang` не пишется (владелец снимает их по репо); пояснения — здесь.

## Как проверяется без перепечатки семени

Собранный `bootstrap/flang` печатает СТАРЫМ семенем, правка `zapis.flang` до двоичного доедет
только перепечаткой (~4,7 ч, только с «го» владельца). Поэтому запись печатается
ИНТЕРПРЕТИРУЕМО: `bootstrap/flang run <обёртка>.flang --function «Напечатать запись» --args …`
— обёртка (в scratchpad, вне дерева) зовёт `«Ведомость исходников»` из
`flang/self/bootstrap/compiler.flang` по ИСХОДНИКАМ дерева (`FLANG_MODULE_DIR` на
`flang/self/bootstrap:flang/self:flang/stdlib:flang/core`), и `.«запись»` итога — та самая
строка, которую `flang check --proof --записать` кладёт в файл (шапка «исходник» делается
относительной, как `proof_head_relative` в `flang_repl.c`). Прибор: `scratchpad/pechat/w/run.py`; одна запись — 602…758 с и ~15 ГиБ памяти.
Это медленно (минуты на запись) — прогоняются 19 записей с калькуляторными местами (§1 карты)
плюс выборка незатронутых для сверки байт в байт.
