# 2915. Три счёта хода вывода не сходятся

Чтобы независимый checker мог **переиграть** вывод, а не поверить компилятору,
объект доказательства должен нести ход вывода. Сколько объектов его несут —
сегодня **неизвестно: три замера дали три числа.**

| замер | результат |
|---|---|
| по 43 объектам | ход не найден **ни в одном** |
| по 86 записям корпуса | ходы несут **9** |
| по счёту в `docs/what-blocks-1-0.md` | **16 из 74** |

## Отчего разошлись — по меньшей мере одна причина известна

Первый замер искал русскую строку в напечатанном seed, **а имена в seed
транслитерируются**: `«Мера склейки»` становится `compiler_flang_mera_skleyki`.
Grep по русскому имени не мог найти того, что искал, — прибор был слеп по
построению. При проверке обеих форм `ход конец` в `bootstrap/compiler_flang.c`
**находится**.

Остальные два расхождения не разобраны: у них разные знаменатели (43, 86, 74) и,
возможно, разные предметы — «ход» и «ход, который checker умеет переиграть» это
не одно и то же.

## Чем закрыта

- одна линейка, объявленная письменно до счёта: что считается ходом, что
  знаменателем, каким двоичным снимается;
- три прежних числа пересчитаны ею и объяснены — либо сведены, либо названы
  разными величинами с разными именами;
- сказано числом, сколько объектов корпуса checker может переиграть **сам**, и
  сколько ему для этого не хватает.

## Ловушка, на которую уже попались дважды

Не делать вывод «в файле этого нет» по grep одной формы имени. Искать обе:
русскую и транслитерированную.

## Сведено 1 сентября: три числа мерили три разные вещи

Замер Ч154, ветка `a/линейка-ходов`, коммит `96a69668`, не влита.

### Почему числа расходились

**«0 из 43»** (Ч126, повторено Ч130) — замер ВЕРЕН, но другого предмета:
считались строки `след ядра`, а не `ход`. Это две разные строки записи. Следа в
дереве и правда нет ни одной; ходы есть. В наряд вечера 31 августа замер попал
как «derivation trace нет нигде», оттуда — как «ходов нет». Знаменатель 43 —
записи, которые ядро печатает по `flang/proof/examples` (45 файлов, на двух
печать отказывает).

**«9 из 86»** — знаменатель верный (весь корпус: 43 examples + 8 map +
35 fixtures), **числитель завышен на единицу**: `grep -a -l 'ход '` ловит
подстроку и цепляет слово «в**ход**» в именах теорем (6 срабатываний,
настоящих ходов 0). Верно **8**. Это тот же изъян, за который чекеру заведена
задача 1302, — повторённый в самой мерке.

**«16 из 74»** (`docs/what-blocks-1-0.md` §2.4) — единица и знаменатель верные,
дерево другое: 13 на стволе, 15 с правкой Ч24, 16 с обеими. Правка `8a3b8ea9` в
исходниках есть, но семя `c15f669f` напечатано раньше неё и до двоичного не
доехала. Сегодняшним двоичным — **13**.

### Одна линейка

`flang/proof/линейка-ходов.sh`, 303 строки, `/bin/sh`. Ход вывода — строка
записи, первое слово которой после отступа есть «ход»; считается на четырёх
единицах сразу (запись, утверждение, посылка, строка), знаменатель печатается
рядом с числителем, `след ядра` считается ОТДЕЛЬНЫМ числом.

Есть `--самопроверка`: подстрока против слова, не слепа, изъятие в обе стороны —
все три целы. Сторож, зелёный по построению, здесь бы и завёлся, поэтому
проверка проверки обязательна.

    make -C bootstrap && make -C flang/proof/чекер
    sh flang/proof/линейка-ходов.sh --чекер

### Числа ствола

Двоичный `05b2e008…b93ee95c`, чекер `39be36a5…`: 45 примеров → 43 записи.

| | |
|---|---:|
| записей с ходами | **8 из 43** |
| утверждений с ходами | **8 из 129** |
| посылок с ходами | **13 из 74** |
| строк хода | 58 |
| строк `след ядра` | **0** |

Чекер переигрывает ровно **13 сведений** — то же число другим прибором — и
оставляет на слово ядра 61 посылку и 93 шага.

**Кодом 0 не проходит ни одна запись, и не из-за ходов: всем 43 не хватает
строки `отпечаток256`.** Её добавляет заплата Ч48, приложенная Ч147 (коммит
`38f6819e`), но до двоичного она доедет только перепечаткой.

### Снято подозрение к корпусу

43 записи сегодняшнего двоичного **побайтово равны** 43 в
`flang/proof/чекер/пробы/записи/корпус` (различается одна строка `исходник`).
Скриптами там не дописано ничего. Дописано было в наборе Ч111 — ровно 605 строк
`след` и 93 переписанных строки `шаг`.

### Не сделано

Не мерено, что напечатает двоичный из нынешних исходников — нужна перепечатка
(задача 0003), поэтому «15…16 после перепечатки» взято из отчётов Ч24/Ч60.
Сторож лицензий и сторож ссылок красные ДО этой работы (`direct-run.mjs` без
SPDX; 1930 битых ссылок на удалённые `*.mjs`), разность «до/после» не мерена.
`flang/proof/SPEC.md` — долг №1 «Ходы никто не пишет» стоял с 22 августа и
неверен.
