# 1722. Временный каталог в корне дерева, который никто не убирает и никто не видит

## Чем измерено

Снято 30 августа 2026 на стволе `f9e67fa6`.

**Ярлык 40 `поиск:различающий`** (`ярлыки.flang:118`,
`node flang/scripts/discriminating-search.mjs`) заводит каталог **в корне
репозитория**:

```js
// flang/scripts/discriminating-search.mjs:254
const ГНЕЗДО = mkdtempSync(join(КОРЕНЬ, ".flang-razlichitelnyy-"))
```

Уборка ровно одна — `rmSync(ГНЕЗДО, …)` на строке **560**, и она **вне
`try`/`finally`**. Обработчика сигнала в файле нет вовсе: `process.on` не
встречается ни разу. Оборвали — каталог остался.

**Маска в `.gitignore` не совпадает с именем.** В `.gitignore` стоит
единственный образец `.flang-storozh-*` (строка 20). `.flang-razlichitelnyy-*`
под него не попадает, то есть брошенный каталог виден в `git status` и уезжает
в чужие доли.

**Сторож времянок этого не ловит по устройству.**
`flang/scripts/tempdir-guard.flang:22–41` — он считает только
`<TMPDIR>/flang-run-<pid>-*` и то, что появилось прямо в `TMPDIR`. Корень дерева
он не смотрит ни одной мерой. Вдобавок он и не бежит — соседняя задача о трёх
ярлыках, которые не заводятся вовсе.

**Это не один случай, а порода.** Тот же разбор
(`/srv/flang-rabota/m-guard-audit-1-66/tasks/1389-…md`, **в ствол не влита**)
называет ещё три места, пишущие в корень дерева:

| образец | кто пишет |
|---|---|
| `.flang-razlichitelnyy-*` | `flang/scripts/discriminating-search.mjs:254` |
| `.flang-slova-*` | `flang/scripts/target-words.mjs:155`, `:179`, `:270`, `:288` |
| `.flang-storozh-*` | `flang/scripts/binary.mjs` |
| `proba-zanyatosti.flang` | `scripts/occupancy-check.flang:193–198` |

Из четырёх в `.gitignore` назван **один**.

## Что сделать

1. Убирать в `finally` и по сигналу, а не одной строкой в конце удачного пути.
2. Свести четыре образца к одному месту: либо все под один префикс, названный в
   `.gitignore` одной маской, либо — лучше — все в `TMPDIR`, где их уже умеет
   считать сторож времянок.
3. Научить `tempdir-guard.flang` смотреть корень дерева, а не только `TMPDIR`:
   сегодня он по построению слеп ровно к тому месту, куда пишут четверо.

## Как понять, что сделано

```sh
./ярлык поиск:различающий &   # оборвать на середине
git status --porcelain        # пусто
./ярлык времянки:проверка     # код 0
```

и обратная проба: нарочно оставленный каталог `.flang-razlichitelnyy-проба` в
корне даёт **красный** `времянки:проверка` с этим именем в выводе. Сегодня он
даёт код 3 и `FLANG_UNKNOWN_PLAN`, то есть не отвечает вовсе.

## Что от неё зависит

Доли на файлы (`/srv/priyom/claim`) и всякий свод: брошенный каталог в корне
попадает в чужой `git status` и читается как чужая правка. И задача о ярлыках,
которые не бегут: пока сторож времянок не заводится, эта беда невидима по
устройству, а не по недосмотру.
