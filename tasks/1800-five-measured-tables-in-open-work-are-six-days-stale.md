## Приметы поставлены там, куда дотягиваются приборы, и только там

Приборов у сторожа чисел прозы **четыре, список закрыт** нарочно
(`prose-numbers-guard.sh:34`: «открытый список означал бы, что примета
может позвать что угодно, — тогда сторож стал бы способом выполнить чужую
команду из документа»): `строк`, `файлов`, `строк-в`, `список`.

Под примету взяты четыре числа:

```
docs/gate-rules.md              1027 → 1027   (единственное, что НЕ устарело)
flang/self/io.flang              785 →  788
flang/self/processes.flang       463 →  679
flang/self/emit-*.flang            8 →    9
```

Проза правлена вместе с приметой: сторож сверяет примету и с деревом, и с
прозой, и правка одного оставила бы место красным с другой стороны.

**Остальным числам приборов в дереве нет вовсе.** «Сколько ярлыков»,
«сколько сторожей», «доля доказанного», «строк ядра решений» — всё это
меряется отдельными приборами, но не теми четырьмя, что понимает примета.
Это НЕ повод расширять список: он закрыт по названному доводу. Это повод
знать, что под присмотром у сторожа прозы — четыре числа из четырнадцати
перемеренных.

## Побочно, и это оказалось срочнее задачи

**Сторож чисел прозы был СЛЕП на `gh/dev`** — код 3, «НЕ ДОСМОТРЕНО —
негодных примет 3. Судить нечем». Проверено на чистом worktree от `gh/dev`,
без единой моей правки.

Ослепила его задача **3841**, влитая часом раньше: она написала в своём
тексте три строки вида «СНЯТО ГГГГ-ММ-ДД примеров-в …» с настоящей
датой вместо букв. Прибора
`примеров-в` в закрытом списке нет — сама задача 3841 об этом и говорит,
это было ПРЕДЛОЖЕНИЕ будущего прибора и ЦИТАТА чужой приметы. Но сторож
обходит всё дерево по `git grep 'СНЯТО [0-9][0-9][0-9][0-9]-'` и цитату от
приметы не отличает.

**Одна негодная примета отключает сторожа целиком** — не свою строку, а
весь прогон: код 3 вместо 1, «судить нечем».

Обезврежено заменой даты на `ГГГГ-ММ-ДД` в трёх местах: образец и цитата
перестали быть приметами, оставшись читаемыми.

```
на чистом gh/dev   код 3, примет 131, негодных 3 — судить нечем
после починки      код 0, примет 132, разошлось 0, негодных 0
подлог             код 1, разошлось 1 — проба собирается
```

Число 132 = 131 − 3 негодные + 4 мои.

**Что из этого следует для дерева.** Сторож, который от одной кривой
приметы перестаёт судить всё, — это сторож, которого легко выключить
случайно. Стоило бы: негодную примету называть и пропускать, а код 3
оставить для «прибора нет вовсе». Здесь не чинилось: `prose-numbers-guard.sh`
не мой файл.

## И та же ловушка поймала меня саму

Первая редакция этой задачи цитировала негодную примету ДОСЛОВНО, с
настоящей датой. Пока файл был вне учёта, сторож её не видел: `git grep`
смотрит только отслеживаемое. После `git add` — код 3, «судить нечем», и
уже по моей вине.

```
до git add    код 0, примет 132, негодных 0
после git add код 3, примет 133, негодных 1 — моя же цитата
после правки  код 0
```

Значит правило шире, чем «не пиши кривых примет»: **любое упоминание
образца приметы с настоящей датой становится приметой**, где бы оно ни
стояло — в кавычках, в блоке кода, в задаче, объясняющей эту самую беду.
Писать дату буквами.
