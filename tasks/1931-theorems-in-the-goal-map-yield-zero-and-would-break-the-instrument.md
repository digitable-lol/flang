# 1931 — писать теоремы в `flang/proof/map/**` нельзя, и это доказано замером

## Что поручалось

Задача 4635 назвала потолок Г4 — 125 из 240 = 52,1 % — и единственную
дорогу вверх: дописать теоремы там, где их можно написать. `flang/proof/map/**`
держит 62 утверждения «доказано» без теоремы, больше всех в дереве, и работа
началась с них.

**Итог: отсюда не берётся ни одного утверждения. Причин три, все померены.**

## Причина 1. Из 62 спуск есть у шести, а не у половины

Признак 4635 — рекурсивна ли функция либо ходит ли она по структуре.
Применён к телу, а не ко всему объявлению, и это важно: первый счёт дал
восемь, потому что признак ловил ложное.

```
«Себя же» от «А»            — «от» здесь ПАРАМЕТР ТИПА, а не рекурсия
«Обернуть в успех»          — «разбор» стоит в ПОСТУСЛОВИИ, а не в теле
```

Честно:

```
всего без теоремы   62
спуск есть           6   свёртка 1, разбор 4, разбор+рекурсия 1
спуска нет          56
```

Пятьдесят шесть — это законы примитивов. `Сумма наоборот` при теле `а плюс б`
обещает `результат равен (б плюс а)`; написать теорему значило бы вписать
коммутативность `плюс` обратно в дерево, у которого «аксиом ноль».

## Причина 2. Г4 — всё или ничего, и НИ ОДНА запись карты не выигрываема

Запись идёт в долю, только когда в ней не осталось ни одного места на слово
ядра. Значит выигрываема запись, у которой писабельны ВСЕ такие места:

```
запись                    без теоремы   из них можно   выигрываема
abilities.запись                   28              2   нет
boundaries.запись                   8              0   нет
equality.запись                     6              0   нет
forms.запись                        9              0   нет
order.запись                        2              0   нет
sources.запись                      3              2   нет
substantive.запись                  3              2   нет
types.запись                        3              0   нет
```

Ни одной. Проверено не рассуждением, а работой: теорема к `С5` написана,
ядром принята («доказано индукцией по «список»: база 1 случай, шаг при
допущении на частях»), запись пересобрана — **доля не сдвинулась**:

```
до     33 из 240 = 13,75 %
после  33 из 240 = 13,75 %
```

## Причина 3. Карта — это ПРИБОР, и теорема его ломает

`flang/proof/map/README.md`: «маленькие программы, каждая из которых меряет
ОДНУ клетку карты — что ядро умеет доказывать, а что нет». Шапка
`substantive.flang`: «здесь и видно границу целиком: сохранение МЕРЫ
доказывается, а квантор и порядок — нет».

Файл меряет, что ядро доказывает САМО. Дописать туда теорему значит
заменить вопрос: файл начнёт мерить, что ядро доказывает с помощью автора.
Про `abilities.flang` README говорит прямо: «Все 28 утверждений обязаны быть
„доказано": одно „на сетке" здесь значит, что умение пропало из ядра».

**И сторож этого НЕ ловит.** Проба: теорема к `У3` дописана в
`abilities.flang`, `flang check` — код 0, `scripts/kernel-abilities-guard.flang`
— **код 0**. Прибор переназначен молча. Сторож следит, что все 28 «доказано»,
но не за тем, что доказаны они ЯДРОМ, — а в этом весь смысл файла. Правка
отменена, в дереве её нет.

## НАСТОЯЩИЙ ПОТОЛОК ВДВОЕ НИЖЕ НАЗВАННОГО

4635 считал потолок по УТВЕРЖДЕНИЯМ: 81 с теоремой плюс 44 писабельных =
125 из 240 = 52,1 %. Но Г4 всё-или-ничего ПО ЗАПИСИ, и запись с одним
непишущимся местом не берётся, сколько ни пиши остальные. Счёт по записям,
по всему корпусу:

```
выигрываемых записей       5, и они несут 20 утверждений
невыигрываемых            33, и они несут 151 утверждение
```

Из пяти выигрываемых **три — подделки** (`poddelka-builtin-emptiness-fact`,
`poddelka-razbor-spiska`, `poddelka-svyortka-nad-pustym`): писать в них
теоремы бессмысленно, они на то и подделки. Остаётся две честные —
`corpus-lists` (1 место) и `if-over-a-segment` (3 места), вместе 6
утверждений.

```
Г4 сегодня                        33 из 240 = 13,75 %
потолок теоремами, честные        39 из 240 = 16,25 %
потолок теоремами, с подделками   53 из 240 = 22,10 %
потолок по утверждениям (4635)   125 из 240 = 52,10 %
приговор требует                             95 %
```

**Разница между 52,1 % и 16,25 % — не спор о признаке, а разница между счётом
мест и счётом записей.** Оба числа верны, отвечают на разные вопросы, и в
приговор входит второе.

## ЖИВАЯ НАКРУТКА В ОСНАСТКЕ, найдена попутно

`flang check --proof --записать` кладёт в запись **АБСОЛЮТНЫЙ** путь
исходника. Одно это поднимает Г4, ничего не доказав:

```
запись из дерева                         33 из 240 = 13,75 %
она же, пересобранная (путь абсолютный)  33 из 237 = 13,92 %
она же, путь заменён на относительный    33 из 240 = 13,75 %
```

Опыт-контроль: пересобрана БЕЗ всякой теоремы — доля всё равно выросла.
Запись с относительным путём **побайтно равна** лежавшей в дереве
(`cmp -s` — совпало), то есть отличие ровно одно: путь.

Знаменатель падает на три, доказанность не меняется, число растёт. Это
ровно «рецепт накрутки», про который предупреждает КРИТЕРИЙ.md, и он не
теоретический: любой, кто пересоберёт запись, поднимет Г4 просто так. Плюс
запись становится машинно-зависимой и в другом клоне не сойдётся.

Не чинилось: `flang/src/emit/c/flang_repl.c` — не мой файл.

## Как пишется теорема — три правила, стоившие прогонов

1. **`дано` — по одному на строку.** `дано а: число, б: число` даёт
   FLANG_PARSE «неизвестная строка теоремы».
2. **Называть надо только те случаи, которые ядро само закрыть не может.**
   База закрывается сведением ядра; назвать её нельзя, `по примеру` там
   отвергается, когда в цели свободно имя. Ядро говорит это дословно: «о
   каждой посылке принципа обязано быть сказано — случаем автора ИЛИ
   СВЕДЕНИЕМ САМОГО ЯДРА».
3. **`случай любое` для списка не годится** — ядро отвечает
   FLANG_PROOF_INDUCTION_CASES «не покрывает „список" точно… лишних случаев
   1: „любое"».

Рабочая форма, принятая ядром:

```
теорема «С5 сохранение: длина выросла на один»
  дано значение: число
  дано элементы: список числа
  утверждаем (длина результат) равен ((длина элементы) плюс 1)
  индукция по элементы
    случай голова г и хвост х
      то по предположению
  следовательно доказано
```

## Не сделано, и почему

* **Теорем в дерево не внесено ни одной.** Не потому, что не пишутся, а
  потому, что в карте они дают ноль и портят прибор. Написанная `С5`
  проверена и отменена.
* **Две честные выигрываемые записи не тронуты** — `corpus-lists` и
  `if-over-a-segment` лежат в `flang/proof/examples/`, это чужой стек.
  Там теоремы дадут настоящие 6 утверждений, и это единственное место в
  корпусе, где сегодня они что-то дают.
* Сторож умений не научен отличать «доказано ядром» от «доказано с
  теоремой» — беда названа, не чинилась.
