# 2072. Запись ядра несёт ходы сведения, и чекеру есть что проигрывать

Чекер умеет проигрывать сведение по шагам — но только когда оно **записано
ходами** (`flang/proof/чекер/ЧИТАТЬ.md`, пункт 10 списка проверяемого). Записей
с ходами почти нет, поэтому почти всё уходит в третий исход.

Снято по корпусу записей, лежащему в дереве:

```sh
d=flang/proof/чекер/пробы/записи/корпус
ls $d | wc -l                                          # 86
/usr/bin/grep -a -l 'ход ' $d/*.запись | wc -l          # 9
```

**86 записей, ходы есть у 9, не несут ни одной строки хода 77.** Всего строк
`ход` по корпусу — 64 (`grep -a -c` с суммированием). Прогон набора проб той же
даты кончается так:

```
ПРОВЕРЕНО    (код 0): 1
НЕ ПРОВЕРЕНО (код 3): 96
НЕ СОШЛОСЬ   (код 1): 59
```

То есть код 0 получает **одна** проба из 156.

Второе, и оно про доставку. Слово, которым ход кончается, есть в исходнике
семени и нет в собранном двоичном:

```sh
/usr/bin/grep -a -c 'ход конец' bootstrap/compiler_flang.c   # 1
/usr/bin/grep -a -c 'ход конец' bootstrap/flang              # 0
```

Двоичный в рабочей копии напечатан 23 августа, семя перепечатано 30-го
(`c15f669f`), а сегодня `8a3b8ea9` добавил «сведено ядром» ходами уже в
исходники. Значит запись, снятая **сегодняшним** двоичным, ходов не несёт по
построению, и никакой формат записи этого не лечит — лечит перепечатка (0003).

## Чего эта задача НЕ утверждает

Наряд говорит: «derivation trace не написан нигде — ни в исходниках, ни в seed,
ни в двух binary; из 43 proof object'ов trace нет ни в одном». Обе команды выше
это опровергают: в семени слово есть, и 9 записей корпуса ходы несут. Число 43
к корпусу дерева не относится — в дереве записей 86. Что именно меряли эти 43,
я не установил.

Отдельно: `docs/what-blocks-1-0.md`, раздел 2.4, называет третье число —
«след ходов есть у 16 посылок из 74» (замеры Ч24 и Ч60). Три счёта об одном и
том же не сходятся, и первый шаг работы — свести их к одному.

## Как понять, что сделано

```sh
sh scripts/raskrutka.sh                       # ходы доезжают до двоичного
bootstrap/flang check flang/proof/stack.flang --proof   # запись снимается заново
sh flang/proof/чекер/пробы/прогон.sh
```

1. Три счёта сведены к одному, и он назван командой: сколько записей несут
   ходы, сколько посылок ими закрыто, сколько остаётся «на слово ядра».
2. Доля записей корпуса с ходами выросла против сегодняшних **9 из 86**, и
   рост назван разностью.
3. Число «ПРОВЕРЕНО (код 0)» в наборе проб выросло против сегодняшней **1**.
4. Строка «честных отвергнуто 0» держится.

## Чем ограничено

Упирается в 0003: пока перепечатка не дошла, ходы, дописанные сегодня в
`flang/self/zapis.flang`, до двоичного не доедут, и переснимать корпус нечем.
Мерить долю по старым записям можно и сейчас — двигать её нельзя.
