# 2416 — подделки в набор, потолок доли Г4 до 100 %

Решение и все замеры —
[ADR-0023](../docs/adr/0023-forgeries-live-in-a-set-not-in-the-metric-corpus.md).
Здесь порядок работ и приёмка. Числа сняты 8 сентября 2026 на `gh/dev`
`5f679521` и на снимке `r/batch-rebuild` `c817ed39`; перепечатка корпуса идёт,
поэтому каждый шаг пересчитывает числа, а не переписывает их отсюда.

Прежде чем брать — прочесть закрытую задачу
[4258](completed/4258-forgery-fixtures-in-the-g4-denominator-are-honest-halves.md):
она отвечала на этот же вопрос «оставить как есть», и её доводы разобраны в §8
решения. Главный из них в силе: подделочные файлы несут честные половины, и на
сегодня из 201 подделочного места **143 уже лежат в числителе**.

## Зачем

В знаменателе доли Г4 лежат обязательства записей, которые чекер отверг: в
числитель они не попадают никогда, по устройству. Отсюда потолок 97,89 %, а не
100 %, и порог 95 % берётся только конвертацией ≥25 подделочных мест, которых
конвертировать нечем.

Замер на копии линейки (дерево не трогалось):

| дерево | как сейчас | без недостижимых мест | только честные записи |
|---|---|---|---|
| `gh/dev` | 409 / 617 = 66,29 % | **409 / 597 = 68,51 %** | 274 / 419 = 65,39 % |
| `r/batch-rebuild` | 507 / 665 = 76,24 % | **507 / 651 = 77,88 %** | 364 / 464 = 78,45 % |

Оба правых столбца снимают потолок до 100 %. Средний — рекомендованный: он не
выносит из числителя ни одного проигранного места. Правый — буквальное «вынести
подделки»: он выносит 143 места на батче и 135 на `dev`, и на стволе доля от
него **падает** на 0,90 п.п. Выбор столбца — за владельцем, и до его слова
шаг Ш3 не берётся.

## Шаги

Порядок жёсткий: Ш3 без Ш2 оставляет набор без сторожа ровно на время переезда.

### Ш1 — манифест, ничего не двигаем

Завести «flang/proof/подделки/НАБОР.tsv» (31 строка, состав — §2.3 решения) и
«flang/proof/подделки/ХРАПОВИК.txt» (число подделок и числитель набора).
Столбцы: имя, исходник, запись, что стережёт, ожидаемый исход, класс, дата.

Класс подтвердить **чтением шапки каждого из 31 исходника**, а не выводом
линейки: прогон сегодня считает настоящими подделками только
`poddelka-svyortka-nad-pustym` и `poddelka-svyortka-shagom`, остальные 29 — это
честные записи ложных программ.

*Приёмка:* `sh flang/proof/доля-корпуса.sh --набор корпус --проигрыванием`
печатает то же число, что до шага, место в место.

### Ш2 — прогон читает манифест

В `flang/proof/чекер/пробы/прогон.sh` завести семью «набор подделок»: строка
манифеста — проба; строка без файла на диске — провал; файл в наборе без строки
в манифесте — провал; `лжёт-запись`, принятая кодом 0, — провал;
`лжёт-программа`, отвергнутая кодом 1, — тоже провал (честная половина файла
перестала доказываться).

*Приёмка:* `sh flang/proof/чекер/пробы/прогон.sh` даёт код 0, печатает как
сегодня «подделок 195: отвергнуто 146, ушло в третий исход 49, ПРИНЯТО кодом 0 —
0» и «честных 126 … отвергнуто 0», плюс новую строку набора. Доля не двинулась.

### Ш3 — знаменатель сужается (только по слову владельца)

Вариант (2), рекомендованный: `proigrat_dolyu()` не кладёт в знаменатель
обязательства записей класса `лжёт-запись` и печатает их отдельной строкой
«обязательства подделок, вынесенные из знаменателя: N».

Вариант (3): 31 запись переезжает `git mv` в
«flang/proof/чекер/пробы/записи/подделки/»; линейка меряет два каталога.
Исходники не трогать: их путь заверен ведомостью коммита.

*Приёмка — баланс, а не проценты.* Прежние числитель и знаменатель обязаны
собраться обратно из напечатанных частей:

```
вариант (2):  507 + 0   = 507      651 + 14  = 665
вариант (3):  364 + 143 = 507      464 + 201 = 665
```

Не сошлось — откат шага.

### Ш4 — вердикт берёт числа прогоном

В `scripts/доказуемость.sh`:

* проверка 2 перестаёт быть `DOLYA_PROIGRYVANIEM=0`, вписанным руками, и берёт
  число из `доля-корпуса.sh --набор корпус --проигрыванием`; `POROG=95` не
  меняется;
* проверка 3 (набор проб цел) становится **безусловной** — гоняется и печатается
  всегда, даже когда проверки 1 или 2 красны; сегодня она замыкается накоротко;
* заводится проверка 4: число строк манифеста и числитель набора не ниже
  «ХРАПОВИК.txt».

*Приёмка:* `sh scripts/доказуемость.sh` печатает **НЕ ДОКАЗУЕМ** (проверка 1
красна: `перепиской(` в чекере), называет числами все четыре проверки, код 1.

### Ш5 — старые правила снять

Из `flang/proof/доля-корпуса.sh` убрать регулярное выражение
`/poddelka|forgery|подделк/` и список `PUSTO_V_CHISLITELE_ZAKONNO`: их работу
взял манифест, и имя файла перестаёт что-либо решать.

*Приёмка:* `sh flang/proof/доля-корпуса.sh --самопроверка` зелена,
`sh flang/proof/чекер/пробы/прогон.sh` код 0, `sh .githooks/pre-push` код 0.

## Как понять, что сделано

```sh
sh flang/proof/доля-корпуса.sh --набор корпус --проигрыванием   # доля + строка набора
sh flang/proof/доля-корпуса.sh --самопроверка                   # код 0
sh flang/proof/чекер/пробы/прогон.sh                            # код 0, «сошлось всё»
sh scripts/доказуемость.sh                                      # четыре проверки числами
sh .githooks/pre-push                                           # код 0
```

Работа сделана, когда доля печатается только вместе со строкой «поймано подделок
N из N», потолок доли равен 100 %, а вердикт ДОКАЗУЕМ невозможен при N ниже
храповика.

## Чего эта задача НЕ делает

* Не двигает исходники подделочных программ и не правит ведомость коммита.
* Не меняет порог Г4: он остаётся 95 %.
* Не делает из набора пакет `.flang-package`: `flang package` сегодня не собирает
  ни одного пакета (задача 3401). Манифест написан переносимым.
* Не берётся раньше конца идущей перепечатки корпуса — Ш3 трогает те самые файлы.
* Не решает за владельца, какой вариант знаменателя брать: до его слова шаги
  идут до Ш2 включительно.
