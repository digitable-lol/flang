приговоров на dev») прибавил +93 к достижимому и **ничего** к ядру

```
Из кеша          → «Ответ кеша»        Ключ кеша      → строка
Спросить кеш     → «Ход без теорем»    Номер корзины  → строка
Сложить в кеш    → «Ход без теорем»    Кеш с новыми   → «Значение»
Проверить доказательства с кешем       → «Итог с кешем»
```

## Это НАСТОЯЩЕЕ расширение, а не изъян прибора

Проверено по объявлениям: семья альфа-инвариантного сличения отвечает
да/нет, то есть попадает в ядро решений **по построению**, а не по
случайности чтения имён:

```
Одинаковы с переименованием         → признак
Списки одинаковы с переименованием  → признак
Имена соответствуют                 → признак
Оба простое имя                     → признак
Простое имя связывателя             → признак
Поля сходятся с переименованием     → признак
```

Смысл тоже настоящий: сличение решает, одна ли это цель с точностью до
переименования связанных имён. Соврёт «да» — примется шаг, который
приниматься не должен. Верить этому приходится.

Сравнение с прошлым разом полезно: 30 августа прибор врал на 218 строк,
потому что считал обещания и примеры кодом. Здесь ничего похожего —
объявленный тип возврата не оставляет места для такого прочтения.

## Работа, которая числу не помогла

`ad6f4d84` вынес из `proof-kernel.flang` **108 строк комментариев** в
задачу 9958. Комментарии в ядро решений не входят по устройству прибора
(«ошибиться в комментарии нельзя, и верить ему не надо»), поэтому вынос
дал **ноль**: 4638 и до него, и после. Это не упрёк — вынос делался ради
читаемости, — но как способ снизить Г3 он не работает, и следующему это
стоит знать.

## Что можно вынести, и это НЕ сделано

Один честный ход виден, но он не «перенести файл», а «переписать метод».
Сличение сегодня ИЩЕТ переименование и само себе верит. Можно разделить:

* **поиск** соответствия имён — вне ядра решений: он лишь предлагает
  отображение;
* **проверка** предложенного — в ядре: применить конечное отображение к
  одной стороне и сравнить с другой.

Проверка короче поиска, и тогда доверять пришлось бы ей одной. Это ровно
«доказать вместо поверить», как в наряде 8121 к самому потолку.

**Не сделано намеренно.** Правка в `flang/self/**` не действует до
перепечатки (она идёт), и это решение владельца, а не работника. Сколько
строк снял бы такой ход — НЕ ИЗМЕРЕНО.
