## Улика до правки

Папка `flang/ct/` — восемь реализаций на настоящих задачах: заказы и отгрузки
(категория), учёт в рублях и копейках (функторы и естественное преобразование),
свод и пропуски (моноид и монада), слияние реплик (решётка). Ни одной из
«школьных» категорий — множеств, векторных пространств, групп, порядков —
в папке нет, и читатель, знающий теорию категорий по учебнику, не видит,
как знакомое ему ложится на язык.

Что двоичный `0.7.14` (собран из семени этого дерева) судит на категорной
поверхности — замерено прогоном по всем восьми файлам и четырьмя пробами
во времянке:

| что объявлено | что делает `flang check` | проба |
|---|---|---|
| `категория` с `объект … даёт «Равны»` | считает на сетке: равенство есть эквивалентность, композиция его уважает, ассоциативность; печатает размер сетки | `order-shipment` без изоморфизма — код 0 |
| `морфизм … из функтора … в функтор …` | считает квадрат естественности на сетке, подделка — `FLANG_TRANSFORM_NOT_NATURAL`, код 1 | `natural-square` с наценкой 100 вместо 1000 — код 1 |
| `закон` при морфизме | НЕ судит: ложное `ожидается` в законе — код 0, `flang test` считает 0 примеров | `order-shipment` с 501 вместо 500 — код 0 |
| `обеспечивает` при функции с `пример` | судит: ложное обещание — `FLANG_PROPERTY`, код 1; верное — ведомость называет «доказано» или «на сетке» | функция с обещанием `х плюс 1` при теле `х умножить на 2` — код 1 |
| `моноид`, `функтор`, `свойство`, `изоморфизм`, `вложение`, `пересечение` | разбирает, типы сверяет, законов не судит; код 2 «проверено НЕ ДО КОНЦА» с именами поимённо | все 8 файлов папки сегодня — код 2 |

Отсюда правило этой работы: закон считается **проверенным**, если его
подделка краснеет у `flang check`. Таких способов у двоичного три —
равенство категории, квадрат естественного преобразования и `обеспечивает`
при функции с примером. `закон` при морфизме сегодня красить нечем, и в новых
файлах он не пишется, чтобы не читаться как гарантия.

## Что сделать

По одному файлу на категорию, каждая — на настоящей задаче, в стиле папки:

| файл | категория | задача | чем проверяется |
|---|---|---|---|
| `set-mail-routing.flang` | **Set** — множества и функции | внутренняя почта: сотрудник → отдел → корпус; пропуск ↔ сотрудник | категория с равенствами (сетка); биекция — обещание «владелец пропуска от выданного пропуска есть сотрудник» |
| `vect-plane.flang` | **Vect** — векторы над числами | плоскость чертежа: масштаб, поворот, проекция; матрицы 2×2 | категория (сетка); обещания: «композиция стрелок есть произведение матриц», линейность |
| `grp-clock-shifts.flang` | **Grp** — группа как категория с одним объектом | циферблат: сдвиги по кругу из 24 часов, обратный сдвиг; гомоморфизм из сдвигов в часах | категория (сетка); обещания: обратимость, закон гомоморфизма |
| `pos-approval.flang` | **Pos** — частичные порядки и монотонные отображения | согласование договора: три подписи, этап, готовность | категория (сетка); обещания: рефлексивность, антисимметричность, транзитивность, монотонность |
| `mon-free-forgetful.flang` | **Mon ⇄ Set** — свободный и забывающий функторы | теги на заявках: тег → список тегов, кодирование поэлементно | естественное преобразование — единица присоединения (сетка); моноид склейки; обещание гомоморфности поэлементного кодирования |

**Top не выражается честно, и вот почему.** Непрерывность — утверждение о
прообразах ВСЕХ открытых множеств кодомена, а законы поверхности считаются на
значениях примеров: квантора по подмножествам у языка нет, и у морфизма нет
места для побочного условия на стрелку. Конечные T0-пространства при этом
суть частичные порядки (порядок специализации, топология Александрова), а
непрерывные отображения между ними — ровно монотонные. Значит
`pos-approval.flang` и есть конечный Top; общий Top остаётся за границей, и
README это называет.

## Порог приёмки

- каждый новый файл проходит `bootstrap/flang check flang/ct/<файл>.flang`:
  разбор, типы, завершаемость, ядро и примеры прошли, у категорий и
  преобразований «нарушений 0». **Код 0 недостижим ни для одного файла с
  `категория`** — это замерено уже после спеки: `order-shipment.flang` без
  изоморфизма отвечает кодом 2 с фразой «УСТРОЙСТВО этих объявлений бинарник не
  судит вовсе — categories, morphisms». Значит код 2 — свойство двоичного, а
  не файла, и порог — «код 2 ровно с теми именами, что двоичный называет
  несудимыми, и ни одного замечания»;
- законы объявлены словами поверхности (`категория`, `объект … даёт`,
  `единица`, `после`, `функтор`, `морфизм из функтора`, `моноид`,
  `обеспечивает`) и на каждый файл показана одна подделка во времянке,
  которая краснеет с кодом диагностики;
- каждая функция несёт `пример`; `обеспечивает` — только при функции с
  примером (иначе обещание уезжает проверкой при работе);
- новые `.flang` без комментариев; пояснения — в `flang/ct/README.md`;
- опись `scripts/proved-share-ledger.txt` пополнена строками новых файлов,
  `sh scripts/pol-dokazannogo-sverka.sh` зелёный; `sh .githooks/pre-push`
  — код 0.
