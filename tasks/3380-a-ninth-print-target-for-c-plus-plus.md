# 3380. Девятая цель печати — C++

## Чем измерено

Снято 30 августа 2026 на стволе `f9e67fa6`.

**Целей печати ровно восемь**, все написаны на flang и лежат в `flang/self/`:

```
emit-c  emit-csharp  emit-elixir  emit-go  emit-java  emit-js  emit-python  emit-rust
```

C++ среди них нет. Число «восемь» стоит независимо ещё в шести местах прозы
(`docs/README.md:45`, `docs/overview.ru.md:149`, `:258`, `:279`, `:439`,
`docs/lockfile-without-store.md:84`, `:177`, `docs/HANDOFF.md:103`) — то есть
девятая цель тронет и их.

**Задачи на C++ в задачнике нет ни одной:** `grep -rin 'c++\|cpp' tasks/` — ноль
совпадений. Про девятую цель заведено ровно два довода, и оба **не про C++**:

* `tasks/0029-typescript-target-buys-almost-nothing.md` — **отменена**, довод:
  «JavaScript — синтаксически годный TypeScript, покупать почти нечего».
  На C++ этот довод не переносится: у C++ своя объектная модель и свой ABI, и
  ни в одну из восьми целей он не стирается.
* `docs/wasm-via-c.md` и `docs/HANDOFF.md:111` — «девятая цель печати не нужна:
  наш C собирается в wasm без единой правки, 94 программы из 94, расхождений 0».
  И этот довод не переносится: он держится на том, что **C уже собирается**
  в wasm, а C++ из C сам собой не получается.

**Чем подтверждено, что цель достижима.** Соседнее дерево `/home/m/ouroboros`
держит C++ сквозным путём и проверяет его сборкой `g++`
(`/home/m/ouroboros/ARCHITECTURE.md:88`): общее представление значения через
`operator<<`/SFINAE, полные имена `ns::C::m`, выход с оглядкой на исключения
(`std::uncaught_exceptions`), `capture()` на любой возвращаемый тип, рантайм
заголовком `_cpp/ouroboros_runtime.hpp`. То есть механизм не выдуман: он
написан и проверен на другом дереве.

## Что сделать

1. `flang/self/emit-cpp.flang` — цель печати на flang, как остальные семь.
2. `flang/src/emit/cpp/` — рантайм цели. Он уезжает в вывод **дословно**
   (`AGENTS.md`), значит пишется один раз и правится только вместе с целью.
3. Занятые слова цели: `слова:проверка` и `занятые:проверка` (ярлыки 24 и 23)
   считают, сколько модулей столкнулось бы с именами, занятыми целью. Для C++
   список занятых слов больше, чем у C, — его надо снять прогоном, а не
   переписать из C.
4. Пересчитать восьмёрку в семи местах прозы, названных выше, — их сверяет
   `подсчёты:проверка` (ярлык 5).

## Как понять, что сделано

```sh
./ярлык печать:проверка      # числа прозы о печати перемерены прогоном ДЕВЯТИ целей
./ярлык закон:проверка       # печать не печатает того, что проверка того же двоичного отвергает
```

и корпус целиком:

```sh
flang emit <каждая программа корпуса> --target cpp | g++ -x c++ - && ./a.out
```

Число, при котором задача считается сделанной: **столько же программ проходит
на `cpp`, сколько сегодня проходит на `c`** — не «почти столько же». Сегодня на
`cpp` проходит ноль из них, потому что цели нет.

## Что от неё зависит

Ничего. Это лист: ни одна другая задача за девятой целью не стоит, и потому её
можно брать в любой день. Обратное неверно — она сама ждёт, пока `emit-c`
никто не переписывает, иначе рантайм придётся сводить дважды.
