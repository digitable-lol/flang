# 4025. Ствольный компилятор печатает программу, молча выбросив конкурентность

## Чем измерено

Снято 29 августа 2026 на стволе `5f1078e1`. В закоммиченном семени
`bootstrap/compiler_flang.c` нет ни одного из трёх движков:

```
$ for s in fl_conc_plan fl_conc_process fl_conc_supervisor; do
    printf '%s: ' "$s"; grep -ac "$s" bootstrap/compiler_flang.c; done
fl_conc_plan: 0
fl_conc_process: 0
fl_conc_supervisor: 0
```

Символа печати конкурентности в C там тоже нет — а для трёх других целей есть:

```
$ grep -ao 'compiler_flang_[a-z_]*konkurentnost[a-z_]*' bootstrap/compiler_flang.c | sort -u
compiler_flang_chast_konkurentnosti_java
compiler_flang_fayl_konkurentnosti_elixir
compiler_flang_obyavlenie_konkurentnostyu

compiler_flang_pechat_konkurentnosti_elixir

compiler_flang_slovo_o_konkurentnosti
```

`compiler_flang_pechat_konkurentnosti_c` — **ноль вхождений**.

**Причина названа временем двух коммитов, и она сходится до минуты:**

```
$ git log -1 --format='%H %ci %s' 9b4f5307
9b4f5307 2026-08-23 02:03:31 +0000 Печать в C кладёт в вывод движок процессов: два процесса живут без единой строки руками

$ git log -1 --format='%H %ci %s' -- bootstrap/compiler_flang.c
58b037c2 2026-08-23 00:20:28 +0000 Слияние ветки u/bez-javascript-3 в main
```

Печать конкурентности в C легла в исходники на **1 ч 43 мин 03 с ПОЗЖЕ**
последнего коммита в семя. Семя её просто не застало.

**Что теряет собранная служба.** Владелец 29 августа: пять поручений из
двадцати — «Показать», «Ждать событие», «Перечислить каталог», «Запустить
процесс», «Запустить процесс с вводом». Рабочая копия с разбором —
`/srv/flang-rabota/m-network-and-processes`.

## Почему это тише всех прочих бед

Компилятор **не отказывается**. Он печатает программу, и напечатанное собирается
и работает — только без процессов, надзора и прогонов. Программа, которая на
входе объявляла службу под надзором, на выходе становится программой без
надзора, и никакой строки об этом не печатается.

## Что сделать

Перепечатать семя (0003). Отдельной правки эта задача **не требует вовсе** —
исходники правильные с 23 августа. Требуется только, чтобы семя их застало.

До перепечатки — поставить заслон: печать в C, не нашедшая в себе движка
процессов при том, что программа их объявляет, обязана **отказаться**, а не
напечатать половину. Молчаливая потеря половины программы хуже отказа.
