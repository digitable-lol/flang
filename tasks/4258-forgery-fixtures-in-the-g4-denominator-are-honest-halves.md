# 4258 — «подделки» в знаменателе Г4 оказались честными половинами

## Вопрос

Знаменатель Г4 — 240 утверждений «доказано» в 86 записях корпуса. Разбор по
происхождению исходника:

```
род                 «доказано»   без теоремы   числитель
proof/map                  62           62          11
proof/examples            108           31           7
fixtures прочее            19           15           8
ПОДДЕЛКИ                   51           51           7
ИТОГО                     240          159          33
```

Пятьдесят одно утверждение приходит из `flang/test/fixtures/poddelka-*`.
Спрошено: место ли им в знаменателе.

## Ответ: ДА, и опасение было основано на неверном допущении

**Эти файлы — не подделанные записи.** Каждый несёт ДВЕ ПОЛОВИНЫ: ложные
функции, которые правило обязано отвергнуть, и честные, которые оно обязано
доказать. Шапка `poddelka-razbor-spiska.flang` говорит это прямо:

> Честные половины лежат в этом же файле ниже: правило, молчащее ВСЕГДА,
> прошло бы все шесть лжей знак в знак — и подделка не мерила бы ничего.

**Ядро доказало ровно честные и отвергло ровно лгущие.** Проверено по всем
29 записям; на самой крупной видно поимённо:

```
НЕТ вердикта   «разбор пустого берёт ветвь звена»    (ЛОЖЬ 1)
НЕТ вердикта   «разбор звена берёт ветвь пустоты»    (ЛОЖЬ 2)
НЕТ вердикта   «голова звена есть второй элемент»    (ЛОЖЬ 3)
НЕТ вердикта   «хвост звена держит голову»           (ЛОЖЬ 4)
НЕТ вердикта   «пустота чужого списка…»              (ЛОЖЬ 5)
НЕТ вердикта   «под известной пустотой…»             (ЛОЖЬ 6)
доказано       «разбор выписанного пустого…»         (ПРАВДА 1)
доказано       «голова выписанного звена…»           (ПРАВДА 2)
доказано       «хвост выписанного звена длиною один» (ПРАВДА 3)
доказано       «список, равный пустому…»             (ПРАВДА 4)
доказано       «список нулевой длины…»               (ПРАВДА 5)
доказано       «пустая строка…»                      (ПРАВДА 6)
```

Правило держится и там, где заголовка «честные половины» нет: у
`poddelka-dlina` доказаны «Первый знак», «Снова целое», «Склеить», а
отвергнуты «Врёт о голове», «Врёт о звене», «Врёт о склейке» — видно прямо
по именам. У `poddelka-nachalo-po-postroeniyu` доказано одно «Обещает
первый знак», отвергнуты все пять «Врёт про…».

Итог по 29 записям: **доказано 51, без вердикта 75.** Ни одного случая,
где ядро выдало бы «доказано» лгущей функции.

## Опасение про накрутку снято ЗАМЕРОМ, а не рассуждением

В постановке сказано: выбросить их — и доля подскочит с 13,75 % до 17,46 %
даром. **Это неверно**, потому что считает, будто числитель останется 33.
Не останется: подделки дают **7 и в числитель**.

```
как есть          33 / 240 = 13,75 %
без подделок      26 / 189 = 13,76 %
разница                     +0,01 п.п.
```

То есть по самому числу Г4 вопрос ничего не решает. Решать надо по смыслу.

## По смыслу — тоже (а)

1. **Исключение шло бы ПО ИМЕНИ ФАЙЛА, а не по свойству.** Утверждение
   «хвост выписанного звена длиною один» доказано ядром, честно и
   проверяемо; единственная причина его выбросить — что соседняя функция в
   том же файле лжёт нарочно. Это не свойство утверждения.
2. **Выбросили бы 7 уже проигранных чекером утверждений** — то есть
   отказались бы от сделанной работы ради неизменившегося числа.
3. **Гейт спрашивает про долю корпуса, а корпус — это то, что ядро
   доказало.** Половина пробы, которую ядро доказало, доказана ровно так
   же, как строка из `proof/examples`.

## Чем бы каждый вариант накручивали

| вариант | накрутка |
|---|---|
| **(а) оставить** | добавлять пробы, чьи честные половины проигрываются чекером тривиально. Защита: это не накрутка, а рост корпуса — но добавляющий обязан показать, что новые честные половины НЕ тривиальны |
| **(б) выбросить** | **переименовать файл в `poddelka-*`** и он выпадет из знаменателя. Отбор идёт по приставке имени, а имя свободно менять — накрутка в одно движение |
| **(в) разделить** | класть трудные утверждения в «прочую» корзину, а лёгкие в ту, по которой считают гейт |

Накрутка варианта (б) — самая дешёвая из трёх и самая незаметная в диффе.

## Побочно, и это крупнее вопроса задачи

**`flang/proof/map` — 62 утверждения «доказано» и НИ ОДНОЙ теоремы.** Целый
род корпуса, четверть знаменателя, не несёт ни одного авторского
доказательства. Ни в задаче 4635, ни здесь не разобрано, почему: то ли эти
файлы такого рода, что теорему им написать нечем (как 111 из 4635), то ли
их просто не писали. Отдельный вопрос, крупнее этого.

Заодно видно, чего стоит вариант (б) для потолка «с теоремой»:

```
с теоремой, как есть      81 / 240 = 33,75 %
с теоремой, без подделок  81 / 189 = 42,86 %
```

Здесь разница уже настоящая (+9,11 п.п.) — и достигнута она была бы тем же
переименованием файла. Ещё один довод против (б).
