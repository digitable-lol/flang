# 4543. Обещание в круге взаимной рекурсии недоказуемо, и это не свойство языка, а дыра в ядре

## Короче некуда

Ядро доказывает постусловие рекурсивной функции индукцией по объявленной сумме:
«база N случаев, шаг при допущении на частях». Допущение на частях даётся
**только самозову**. Стоит тот же самый спуск по той же самой сумме разложить на
ДВЕ функции, зовущие друг друга, — и допущение не даётся никому, а вердикт
падает с «доказано индукцией» до «объявлено, не доказано».

Следствие, ради которого это записано: **горячий цикл в этом языке нельзя
одновременно сделать быстрым и обвесить постусловиями.** У функции с
постусловием хвостовых вызовов нет (наряд 1477), круг без хвостовых зовов теряет
батут (наряд 1600), а вернуть батут через «доказать и дать пример» (наряд 4837)
у звена круга НЕЛЬЗЯ: доказать нечем. Остаётся вынести обещание из круга или
снять его.

На это уже наступили: `ea59db47` дописал постусловия всем четырём функциям
горячего цикла вычислителя, регенерация компилятора стала умирать по пределу
глубины на 20 000, на 200 000 и на миллионе одинаково, и чинить пришлось
выносом обещания из круга (`m/tail-call-in-the-hot-loop`, коммит `74ae40c2`),
а не доказательством.

## Улика: два спуска, различие ровно одно

Проба целиком — ниже; снята 30 августа 2026 двоичным `bootstrap/flang`,
собранным из семени ствола (`make -C bootstrap`), командой
`flang check <проба> --proof`.

```flang
тип «Цепь»
  вариант «Пусто цепи»
  вариант «Звено цепи» содержит «дальше»: «Цепь»

// спуск по части — САМОЗОВ
функция «Ход сам»
  принимает «ц»: «Цепь»
  возвращает число
  обеспечивает «ход сам неотрицателен» результат не меньше 0
  разбор «ц»
    случай «Пусто цепи»
      то 0
    случай вариант «Звено цепи» с «дальше» как «дальше»
      то «Ход сам» от «дальше»

// ТОТ ЖЕ спуск по ТОЙ ЖЕ части, но через круг из двух
функция «Ход раз»
  принимает «ц»: «Цепь»
  возвращает число
  обеспечивает «ход раз неотрицателен» результат не меньше 0
  разбор «ц»
    случай «Пусто цепи»
      то 0
    случай вариант «Звено цепи» с «дальше» как «дальше»
      то «Ход два» от «дальше»

функция «Ход два»
  принимает «ц»: «Цепь»
  возвращает число
  обеспечивает «ход два неотрицателен» результат не меньше 0
  «Ход раз» от «ц»
```

Ведомость:

```
постусловие «ход сам неотрицателен» функции «Ход сам» — доказано индукцией по
  «Цепь»: база 1 случай, шаг при допущении на частях (1 случай), правила
  сведения: неотрицательность по построению; цель есть допущение
постусловие «ход раз неотрицателен» функции «Ход раз» — объявлено, не доказано:
  ни теоремы, ни примеров
постусловие «ход два неотрицателен» функции «Ход два» — объявлено, не доказано:
  ни теоремы, ни примеров
```

Тип один, спуск один, цель одна. Разница только в том, что рекурсивный зов идёт
не себе, а соседу.

## Четыре опыта вокруг, чтобы не спутать причину

| опыт | что стоит в круге | вердикт |
|---|---|---|
| зов вне круга, у вызванного обещание ДОКАЗАНО | ничего | **доказано**, правило «цель есть допущение» |
| зов вне круга, у вызванного обещание НЕ доказано (он самозовный) | вызванный | объявлено, не доказано |
| круг из двух, у обоих ОДНО И ТО ЖЕ равенство поля записи | оба | объявлено, не доказано |
| круг из трёх — настоящий горячий цикл вычислителя | все три | объявлено, не доказано |

То есть седьмой ход («по свойству») берёт постусловие вызванного, но цепочка
рвётся на первом звене, у которого своего вердикта нет, — а в круге своего
вердикта нет ни у кого и быть не может: каждый опёрся бы на соседа.

## Что надо решить

1. **Чинится ли это в ядре.** На бумаге — да: нужна одновременная индукция по
   кругу (все звенья доказываются вместе, допущение на частях даётся всем
   сразу), это стандартный приём, а не открытие. В ядре сегодня такого хода
   нет: среди 28 умений (`flang/proof/map/abilities.flang`) нет ни одного про
   круг.
2. **Сколько это стоит.** Работа в `flang/self/proof-kernel.flang` и
   `flang/self/proofterm.flang`; заранее не мерено. Мерить надо ДО того, как
   кто-нибудь снова обвесит горячий цикл обещаниями.
3. **Что писать в правилах, пока хода нет.** Одна строка в `AGENTS.md` или в
   `docs/`: обещание у звена круга взаимной рекурсии стоит батута и доказано
   быть не может — либо выноси его на внешний вход круга, либо не пиши.

## Чем закрывать

Закрыть можно двумя разными исходами, и оба честные:

* **ход добавлен** — та же проба выше даёт «доказано» у «Ход раз» и «Ход два»,
  и число батутов в напечатанном компиляторе не убывает;
* **ход признан неподъёмным** — тогда в теле задачи стоит замер цены, а правило
  «в круг обещаний не писать» записано там, где его прочтут до, а не после.
