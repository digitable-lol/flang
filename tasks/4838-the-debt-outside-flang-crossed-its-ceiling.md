## Два пункта из списка НЕ сделаны, и причины измерены, а не предположены

### `take-proof-ledger.sh` — «ничего не мешает» неверно: мешают четыре вещи

В таблице ниже стояло «гонять процессы `flang io` умеет». Процессы умеет.
Довода принять не умеет, и этого хватает. Проверено на двоичном этого ствола,
а не вычитано:

```
$ ./bootstrap/flang io examples/io/child-process.flang --plan '…' лишний-довод
flang io: непонятный ключ «лишний-довод»
$ ./bootstrap/flang io examples/io/child-process.flang --args '{"файл":"x"}'
flang io: непонятный ключ «--args»
```

Четыре препятствия, каждого из которых хватило бы по отдельности:

1. **Довода нет.** Весь смысл прибора — `sh scripts/take-proof-ledger.sh
   <файл>`: имя файла приходит доводом. У `flang io` доводов нет вовсе (`--args`
   — ключ команды `run`, а не `io`; см. шапку `ярлык`, пункт 1). План может
   только зашить имя файла в себя, то есть перестать быть этим прибором.
2. **Обстановки нет.** Шесть переменных (`DVOICHNYY`, `VYHOD`, `PAMYAT`, `PIK`,
   `PREDEL_SHAGOV`, `PREDEL_GLUBINY`) задают прогон; `docs/kernel-ledger.md`
   зовёт прибор именно так. Среди восемнадцати поручений
   (`flang/cat/SPEC.md`) чтения переменной среды нет.
3. **Экрана нет.** Прибор печатает ход: «снимаю ведомость», отпечаток
   двоичного, строку `.kod`, долю. `«Показать»` у двоичного хозяина отвечает
   `FLANG_IO_NO_SCREEN` — это сказано в справке самой команды `flang io`.
4. **Кода возврата потомка нет.** Прибор кончает `exit "$kod"` — кодом
   `flang check`. У `flang io` коды свои и закрытые: 0 дошёл, 1 «Провал»,
   2 кривой вызов, 3 сломался инструмент.

Пятое, не препятствие, но поправка к записанному: срок потомка у `flang io`
**двигается** ключом `--timeout` (`scripts/child-timeout.flang`), и без него
умолчание в 30 000 мс убило бы всякую ведомость — `docs/kernel-ledger.md`
называет 399,17 с на `flang/stdlib/aes.flang`. Строка «Ключа, двигающего этот
срок, у команды нет» в шапке `scripts/corpus-runner.flang` устарела.

Перевод, дающий ТОТ ЖЕ ответ на тех же входах, сегодня невозможен. Перевод,
меняющий способ вызова, — это другой прибор, и заводить его вслепую нельзя:
`take-proof-ledger.sh` назван в `docs/kernel-ledger.md` шесть раз и в задачах
6128 и 7205.

### Два счётчика доли — они НЕ накладываются, они дают разный ответ

В таблице стояло «накладываются». Замер говорит обратное. Один и тот же файл,
один и тот же прогон `check --proof` двоичного этого ствола:

```
$ python3 scripts/proved-share-of-a-file.py flang/proof/examples/precondition.flang ведомость.json
flang/proof/examples/precondition.flang: написано 8 (постусловий 3, без приговора 5); приговоров своих 3, ввезённых 0
  доказано 1, сетка 1, объявлено 1
  два счёта сошлись: доказано 1 из 8 = 12,5 %

$ python3 flang/scripts/per-file-proof-share.py . отчёты/
      7 обязательств  счёты не сошлись   flang/proof/examples/precondition.flang (приговоров 3)
```

Первый файл **засчитывает** и даёт 12,5 %. Второй **выбрасывает** его из суммы
целиком. Расходятся оба конца дроби:

| | `proved-share-of-a-file.py` | `per-file-proof-share.py` |
|---|---|---|
| вход | `--proof --json`, поле `claims` | `--proof` текстом, раздел «что высказано» |
| охват | один файл | всё дерево разом |
| знаменатель | постусловий 3 + без приговора 5 = 8 | обязательств 7 |
| «требует» и «закон» | считаются отдельно, в приговоры не идут | идут в обязательства наравне |
| приговоров | 3 (сошлось с постусловиями) | 3 при 7 — не сошлось, файл выброшен |
| видов приговора | три | четыре, есть «доказано ПРИ УСЛОВИИ» |

Даже число написанных обязательств у них разное — 8 против 7: второй не видит
`для всех н обеспечивает …`, первый видит.

**Слить их в один прибор — значит решить задачу 1729**, а она ровно об этом
знаменателе («97 обязательств, которым в числитель не попасть никогда, вынесены
из знаменателя») и **в работе у исполнителя `b`**; `tasks/1729…md:58` ссылается
на `flang/scripts/per-file-proof-share.py:35` и `:111` по номерам строк. Задача
3022, тоже у `b` и тоже в работе, собирается перенести этот счёт ВНУТРЬ
компилятора (`tasks/3022…md:145`) — тогда оба файла уйдут сами, и обгонять её
переводом значит делать работу, которую она выбросит.

Доля в книге (`/srv/priyom/claim чей`) на оба файла **свободна** — но свободна
она потому, что `b` ведёт эти задачи, не объявляя долей на приборы, а не потому,
что приборы ничьи. Отбирать не стал; решать владельцу.
