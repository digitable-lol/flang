# 5204. «Каждый файл проверок дерева» — это сегодня четыре файла из шестидесяти с лишним

## Чем измерено

Снято 30 августа 2026 на стволе `f9e67fa6`.

Ярлык `сторожа:проверка` — `ярлыки.flang:177`,
`bootstrap/flang io flang/scripts/guards-start.flang`. Поле «зачем» обещает
дословно:

> каждый файл проверок дерева ЗАВОДИТСЯ; не завёлся — назван поимённо и дословно

**Смотрит он только `*.test.mjs`** — сказано его же шапкой
(`flang/scripts/guards-start.flang:25–41`), там же признание: подлог в
`scripts/homebrew-formula-guard.flang` даёт «заводятся 15; НЕ ЗАВОДЯТСЯ 0» и
код 0.

**Сегодня таких файлов в дереве четыре:**

```sh
git ls-files '*.test.mjs'
  flang/test/jargon-guard.test.mjs
  flang/test/nadzor-uzla.test.mjs
  flang/test/planirovshchik-celi.test.mjs
  flang/test/svyaz-celi.test.mjs
```

В шапке при этом всё ещё стоит «15» — проза отстала от дерева.

**Знаменатель.** За 99 ярлыками стоят **76 различных файлов команд**, из них
сторожей — около **69**. То есть ярлык обещает 69 и смотрит 4.

## Осторожно с номером ярлыка

Владелец называет его «ярлык 93». По нынешнему списку 93 — `раскрутка`. Разбор
сторожей писан по списку из 95 ярлыков, где `сторожа:проверка` был 93-м.
**Брать по имени.**

## Что сделать

1. Расширить `guards-start.flang` с `*.test.mjs` на **все файлы команд ярлыков**
   — их список уже есть, он и есть `ярлыки.flang`, и брать его надо оттуда, а не
   писать вторым списком: второй список разъедется за неделю.
2. Пока охват не полон — **поле «зачем» обязано говорить правду**: «каждый файл
   проверок» при четырёх из шестидесяти девяти это не оговорка, а неверное
   утверждение, и оно видно в выводе `./ярлык` каждому.
3. Поправить «15» в шапке: сегодня их четыре.

## Как понять, что сделано

```sh
./ярлык сторожа:проверка
```

называет число просмотренных, и оно равно числу файлов команд из `ярлыки.flang`.
Обратная проба: сторож, нарочно сломанный так, что не заводится (например
`scripts/homebrew-formula-guard.flang`), **назван поимённо** — сегодня он даёт
код 0 и «НЕ ЗАВОДЯТСЯ 0».

## Что от неё зависит

Задача о шести тяжёлых сторожах, которых ни разу не досмотрели: её знаменатель
берётся отсюда. И задача 0049 (последний JavaScript уходит из дерева): пока
охват меряется по `*.test.mjs`, снятие последнего `.mjs` обнулит охват и никто
не заметит.
