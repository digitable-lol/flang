# 6132. Ядро выписывает вывод, по которому оно и так шло

Основание — [ADR-0022](../docs/adr/0022-a-type-fact-travels-as-a-derivation.md)
§2.2 (правила уже выведены, теряется путь), §6 (цена), §7 (что даёт).

Делать ТРЕТЬЕЙ, после 6130 и 6131. **Требует двух перепечаток семени по ≈8 часов
каждая** (`docs/reprint-ledger.tsv`; оборванных заходов 4 из 11) — планировать
как двухзаходную работу, а не как правку.

## Что сделать

1. `flang/self/proofterm.flang` — `Вердикт по объявлению` (`:2646`) возвращает
   ДЕРЕВО применённых правил, а не строку с именем. Сегодня та же цель сводится
   дважды (второй раз с пустым списком объявлений — ради одного бита
   `по объявлению да|нет`); путь обоих прогонов теряется в возврате.
2. `flang/self/proof-kernel.flang` — свёртки замыканий (`Неотрицательно` `:2664`,
   `Ограничено` `:2831`, `По порядку` `:3307`, `Стоит по построению` `:6181`,
   `Начинается по построению` `:6462`, `Соседние по построению` `:6701`,
   `Есть допущением` `:7625`) накапливают путь. Логика не меняется — меняется
   возврат.
3. `flang/self/zapis.flang` — печать блока `вывод` рядом со «Строки объявленного
   правила» (`:1453`). Образец в том же файле: семья С2 уже печатает цепочку
   ходов.
4. **Печатник молчит, где не уверен**: не напечатать вывод (место уйдёт именем
   правила, как сегодня) лучше, чем напечатать неверный — неверный вывод на
   честной записи даёт код 1, то есть падение доли.
5. Заход 1 — только правило Т1 («цель есть допущение», 1 место): проверить
   сквозной путь ядро → запись → сверщик. Заход 2 — остальные семейства.
6. Перевыпустить 86 записей корпуса (`flang check <файл> --proof --записать`,
   секунды). ≈198 рукописных проб-записей править руками.

## Критерии приёмки

* После захода 1: запись места Т1 несёт блок `вывод`, сверщик его проигрывает,
  доля +1 место, ни одна проба не покраснела.
* После захода 2: **51 место** класса К2 (`ПЕРЕДАЧА/karta-95.md` §2) несёт блок
  `вывод`; разряд «на слово ядра: посылок и утверждений» уменьшился на 51.
* `sh flang/proof/доля-корпуса.sh --набор корпус --проигрыванием` печатает долю
  и, **отдельной строкой, число «мест, закрытых именем правила без вывода»**.
  По восьми семействам оно равно нулю.
* Доверенная база НЕ выросла: `ПРАВИЛА[]` и `ПРИМИТИВЫ[]` прежней длины,
  `flang io flang/scripts/kernel-forgeries.flang --plan 'Аксиом ноль'` — код 0.
* Числитель разложен по правилам: видно, какое правило закрыло сколько мест.
  Без этой разбивки волна неотличима от накрутки (`karta-95` §6.2 п. 4).
* Записи без блока `вывод` читаются по-прежнему; номер версии формата не менялся.
* `sh flang/proof/чекер/пробы/прогон.sh` зелен; `sh .githooks/pre-push` — код 0.
