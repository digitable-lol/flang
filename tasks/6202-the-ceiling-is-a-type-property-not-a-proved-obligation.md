# 6202. Первый шаг ADR-0025: правило семейства П получает посылку

Решение ADR-0025 говорит: верхняя граница числового типа перестаёт быть
свойством типа и становится обязательством, которое доказывают. Задача — первый
шаг, за которым можно снять честное число.

## Что известно из замера ADR-0025

Подмена, снятая 9 сентября 2026: та же независимая проверяющая программа собрана
из копии исходника, где имя правила «ограниченность точным потолком по
построению» заменено на несуществующее.

```
как есть    доля-проигрыванием = 567 / 651 = 87,10 %
без правила доля-проигрыванием = 495 / 646 = 76,63 %
```

**72 проверенных места из 567 стоят на потолке. Прямо этим правилом закрыто 14
утверждений в пяти записях; остальные уходят потому, что одно несошедшееся
утверждение роняет всю запись.**

В таблице правил вывода `flang/proof/ПРАВИЛА-ВЫВОДА.tsv` — 78 правил.
Семейство П (7 строк: П1–П6 и запрет П✗) названо этим правилом целиком.
Семейство Кон (3 строки) называет его одним из двух допустимых. Остальные 68
потолка не касаются.

## Что сделать

1. **Взять ОДНО правило — П3** («ограниченность точным потолком по построению»
   от объявленного типа, `flang/self/proof-kernel.flang:2735` `«Ограниченное по
   типу»`, в проверяющей программе `flang/proof/чекер/сверщик.c:6509–6514`).
   У него сегодня в колонке «посылки» стоит «—»: заключение `Γ ⊢ Т ≤ К` следует
   из объявления и больше ни из чего.
2. **Дать ему посылку.** Заключение то же, но следует оно теперь из доказанного
   факта, а не из имени типа. Написать это надо в трёх местах сразу: строка
   таблицы правил, ядро, независимая проверяющая программа.
3. **Пересчитать долю.** Ожидание: она просядет, а потом вернётся, когда записи
   пяти названных мест будут пересняты с новым ходом. Число снимается прогоном
   `sh flang/proof/доля-корпуса.sh --проигрыванием`, не оценкой.
4. **Завести подделку.** Утверждение о границе, у которого посылки нет, обязано
   быть отвергнуто. Сегодня оно проходит: границу даёт тип.

## Чего эта задача НЕ делает

Не трогает остальные шесть правил семейства П, не трогает представление числа и
не заводит длинную арифметику. Всё это — отдельные работы, и ADR-0025 говорит
прямо: длинная арифметика этим решением не покупается.

## Как понять, что сделано

- у строки П3 колонка «посылки» перестала быть «—»;
- ядро и независимая проверяющая программа согласны в том, что П3 требует
  посылки, — проверено подделкой, которая раньше проходила;
- `sh flang/proof/доля-корпуса.sh --проигрыванием` даёт число не ниже
  567 / 651 после пересъёмки записей;
- `SVERSCHIK=… sh flang/proof/чекер/пробы/прогон.sh` печатает «сошлось всё».
