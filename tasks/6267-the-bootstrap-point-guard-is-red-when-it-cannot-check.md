# 6267. Сторож круга раскрутки зелен, когда проверить нечем

## Чем измерено

Снято 30 августа 2026 на стволе `f9e67fa6`.

Ярлык `точка:проверка` — `ярлыки.flang:173`,
`bootstrap/flang io scripts/bootstrap-point-by-binary.flang --timeout 2400000`.
Стережёт он круг раскрутки, и сказано это его же шапкой
(`scripts/bootstrap-point-by-binary.flang:15–18`).

**Порог 32 ГиБ зашит и закреплён обещанием** — строки 133–140:

```
обеспечивает «порог назван тридцатью двумя гигабайтами в килобайтах»
  результат равен 33554432
```

**Печатая «НЕ ПРОВЕРЕНО», он отдаёт код 0.** Функция `«Не проверено»`
(строка 184) строит `вариант «Конец работы»` — то есть успех. Ветвей, уходящих в
неё, три:

| строка | случай |
|---:|---|
| 195 | в `/proc/meminfo` нет строки `MemTotal` |
| 197 | памяти меньше 32 ГиБ |
| 223 | двоичного нет — «соберите его: `make -C …`» |
| 226 | каталога нет — «двоичный не собран» |

То есть **на любой машине меньше 32 ГиБ и на любом дереве без собранного
двоичного ярлык зелен**. Оба случая — обычные: свежий клон и слабая машина.

## Почему это опаснее красного

Тот же довод, что и у планов (задача 8398): зелёный ответ неполного судьи хуже
красного ответа полного — он закрывает вопрос, не ответив на него. Здесь цена
выше обычного: стережёт он **круг раскрутки**, то есть то самое место, где
дерево перестаёт быть проверяемым само собой. Разомкнётся круг — скажет об этом
код 0.

## Осторожно с номером ярлыка

Владелец называет его «ярлык 91». По нынешнему списку 91 — `выпуски:страница`.
Разбор сторожей писан по списку из 95 ярлыков, и там `точка:проверка` был 91-м.
**Брать по имени.**

## Что сделать

1. Развести три исхода: «проверено, сошлось» (0), «проверено, разошлось» (1) и
   «проверить нечем» (свой код, не 0 и не 1).
2. Причину «нечем» называть словом: мало памяти / нет двоичного / нет
   `MemTotal` — это три разные причины, и лечатся они по-разному.
3. Порог 32 ГиБ оставить, но сказать в выводе, сколько памяти на машине есть:
   сегодня он молчит и об этом.

## Как понять, что сделано

```sh
./ярлык точка:проверка                       # на машине с памятью и двоичным: код 0
rm bootstrap/flang && ./ярлык точка:проверка # НЕ 0, названо «двоичный не собран»
```

Сегодня второй прогон даёт код 0 и слова «НЕ ПРОВЕРЕНО».

## Что от неё зависит

Задача 0003 (перепечатка) и 8721 (заход из чистой копии): обе опираются на то,
что круг раскрутки сторожится. И 0043 — приёмка двоичного: у неё та же беда, но
своя, и чинить их надо порознь, чтобы не сложить две правки в одну и не потерять
ни одной.
