# 6329. Окрестность ядра: 161 обязательство в четырёх файлах

## Чем измерено

Шесть файлов вокруг ядра держат **343 обязательства** — счёт по исходникам
29 августа 2026 (`grep -acE '^\s*(обеспечивает|требует|закон)\s'`):

| файл | обязательств | ведомость снята |
|---|---:|---|
| `flang/self/proofterm.flang` | 138 | **да**, 29 августа: 46 доказано из 138 = 33,3 % |
| `flang/self/proof-kernel.flang` | 44 | **да**, 29 августа: 44 из 44 = 100 % |
| `flang/self/proof-initial.flang` | 94 | нет |
| `flang/self/obligations.flang` | 44 | нет |
| `flang/self/grid.flang` | 21 | нет |
| `flang/self/obyazatelstva-i-yadro.flang` | 2 | нет |
| **итого** | **343** | снято 182, осталось **161** |

Все шесть числятся в `docs/zettel/one-binary-one-ledger-the-whole-tree.md:100`
в куче «упёрся в предел шагов — 25 файлов, 1081 обязательств», то есть до
29 августа не снимался ни один из них.

Замеры снятых лежат в `/srv/tmp/m-kernel/yadro/`; способ описан соседней
задачей о приёме снятия ведомости.

## Что сделать

Снять ведомость с четырёх оставшихся тем же приёмом: двоичный из семени плюс
дословный рантайм дерева, ключ `--предел-шагов 400000000000`, ворота с
`PAMYAT=45G`.

Порядок — по возрастанию цены, чтобы дешёвое не ждало дорогого:
`obyazatelstva-i-yadro` (2), `grid` (21), `obligations` (44),
`proof-initial` (94).

Ожидаемая цена — по снятым: ядро при 44 обязательствах шло 52 мин при пике
9,65 ГиБ. Цена определяется замыканием, а не числом обязательств, поэтому
запас памяти брать по замеру, а не по числу из таблицы.

## Как понять, что сделано

Для каждого из четырёх файлов есть выход `check --proof` с кодом 0 и приговор
по САМОМУ файлу, посчитанный отдельно от ввезённого:

```sh
python3 <приём>/dolya-fajla.py flang/self/grid.flang <выход>.out
# ДВА СЧЁТА СОШЛИСЬ. Доказано N из 21 = …
```

Строка «итог:» из отчёта в счёт НЕ идёт: она берёт замыкание. На ядре она
завышает в 34,2 раза (1503 приговора против 44 своих), на `proofterm` — в
12,9 раза (1779 против 138).

## Что от неё зависит

Задача 0002 (один двоичный — одна ведомость на всё дерево) и всякое число вида
«доля доказанного»: пока шесть файлов ядра не судятся, доля считается по дереву
без своего доказателя.
