# 6526. Проверка страницы выпусков не бежит, а добежав — не проверяет

## Чем измерено

Снято 30 августа 2026 на стволе `f9e67fa6`.

Ярлык `выпуски:страница:проверка` — `ярлыки.flang:170`,
`bootstrap/flang io scripts/releases-page-verify.flang`. **Ключа `--max-steps` в
строке нет**, значит действует умолчание `io` — **10 000 000** шагов
(`flang/src/emit/c/flang_repl.c:12083`; таблица в `ярлыки.flang:38–40`).

**В это умолчание он не влезает, и это снято прогоном:**

```
docs/ci-inventory.md:142   выпуски:страница  3, 16 с,
                           FLANG_RECURSION_LIMIT: «Шаг разметки json» исчерпала 10000000 шагов
docs/ci-inventory.md:143   75 выпуски:страница:проверка — то же
```

Точного числа **11–13 млн в дереве не записано** — это замер владельца, и первое,
что делает задача, — снимает его и заносит.

**А добежав, он не проверил бы ничего на клоне без тегов.**
`scripts/releases-page-verify.flang:91`:

```
вариант «Конец работы» с значение равным … " — клон без тегов."
```

`«Конец работы»` — это успех, код 0. Шапка файла (строка 14) эту ветвь
оправдывает, но оправдание не отменяет того, что зелёный ответ выдаётся там, где
сверять было не с чем.

## Осторожно с номером ярлыка

Владелец называет его «ярлык 88». По нынешнему списку 88 — это
`журнал:проверка`, и описание к нему не подходит: `журнал:проверка` зовёт
`node`, у которого предела шагов flang нет вовсе. Разбор сторожей писан по
списку из 95 ярлыков, а там этот ярлык и был 88-м. **Брать по имени, а не по
номеру.**

## Что сделать

1. Снять, сколько шагов ему нужно на самом деле, и вписать `--max-steps` в
   строку ярлыка **числом от замера**, а не «с запасом».
2. Ветвь «клон без тегов» перевести из успеха в названный отказ: «сверять не с
   чем» — это не «сверено». Код должен отличаться и от 0, и от кода настоящего
   расхождения.
3. Ту же пару правок проверить у соседа `выпуски:страница` (ярлык 91): он падает
   на том же месте и по той же причине.

## Как понять, что сделано

```sh
./ярлык выпуски:страница:проверка                    # код 0, дошёл
git clone --no-tags . /tmp/проба && cd /tmp/проба
./ярлык выпуски:страница:проверка                    # НЕ 0, названо «сверять не с чем»
```

Сегодня первое даёт `FLANG_RECURSION_LIMIT`, а второе — код 0.
