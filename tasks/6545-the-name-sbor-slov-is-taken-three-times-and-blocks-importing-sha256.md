# 6545. Имя «Сбор слов» занято трижды, и из-за него ядро не может ввезти SHA-256

Строка `использует «SHA-256» из "sha256.flang"` втягивает в связывание весь
`flang/stdlib/sha256.flang`, а в нём объявлен тип с именем, которое в ядре уже
занято. Заплата, которой нужен настоящий отпечаток, из-за этого не связывается.

Три объявления одного имени, снято чтением дерева:

```sh
/usr/bin/grep -a -rn 'тип «Сбор слов»\|объект «Сбор слов»' flang/ --include='*.flang'
```

```
flang/self/bounded.flang:318:объект «Сбор слов»
flang/self/emit-c.flang:454:объект «Сбор слов»
flang/stdlib/sha256.flang:70:тип «Сбор слов»
```

Два первых — накопитель разбиения на слова (`emit-c.flang:453` прямо это
поясняет: «слово, которое сейчас набирается, и уже закрытые»). Третий —
накопитель блока SHA-256, у которого поля совсем другие: `расписание`,
`копилка`, `набрано`.

Кто уже ввозит SHA-256 сегодня и живёт с этим:

```sh
/usr/bin/grep -a -rn 'использует «SHA-256»' flang/ --include='*.flang'
```

```
flang/stdlib/hmac.flang:2
flang/stdlib/aes.flang:2
```

Оба — библиотека, ни один не ядро. Из `flang/self/**` SHA-256 не ввозит никто.

**Число заплат, которые это рубит, — десять** — названо нарядом ячейке Ч141 от
31 августа 2026; сами заплаты лежат в клонах ячеек, и своим прогоном я их не
считал. Столкновение имён я подтвердил чтением; десятку — нет.

## Как понять, что сделано

```sh
/usr/bin/grep -a -rn 'тип «Сбор слов»\|объект «Сбор слов»' flang/ --include='*.flang'
bootstrap/flang check <файл ядра с «использует «SHA-256»»>
```

1. Имя «Сбор слов» объявлено в дереве **один** раз, а не три. Какое из трёх
   переименовано — решение задачи, но переименование в `flang/stdlib/sha256.flang`
   ломает меньше: его ввозят два файла, а не двенадцать.
2. Файл ядра со строкой `использует «SHA-256»` связывается и проверяется — код
   возврата и вывод в теле задачи.
3. `./ярлык столкновения:проверка` — код 0, и число объявлений в его отчёте
   уменьшилось ровно на два.

## Закрыта 1 сентября 2026 — переименовано другое из трёх, и это лучше

Решение принято НЕ то, что предлагала задача: переименован не тип в
`flang/stdlib/sha256.flang`, а объект в `flang/self/emit-c.flang` — «Сбор слов»
→ **«Сбор слов C»**, коммит `ef718648`. Довод: имя названо по тому, чьё оно, и
обещание совместимости библиотеки (оговорка «Чем ограничено» ниже) не задето
вовсе — правка целиком внутри компилятора.

Три условия, каждое прогоном:

1. **Объявлений три → два**, и оставшиеся два не сталкиваются: это `объект` и
   `тип`, разного вида.

        /usr/bin/grep -a -rn 'тип «Сбор слов»\|объект «Сбор слов»' flang/ --include='*.flang'
        # flang/self/bounded.flang:318:объект «Сбор слов»
        # flang/stdlib/sha256.flang:70:тип «Сбор слов»

   Условие наряда «объявлено ОДИН раз» буквально не выполнено, и это не
   недоделка: третье объявление — то самое, что мешало, — снято, а два
   оставшихся сторож столкновений не считает бедой (см. пункт 3).

2. **Файл ядра со строкой `использует «SHA-256»` связывается И ПРОВЕРЯЕТСЯ.**
   `flang/self/zapis.flang:3` несёт эту строку — влито коммитом `841c3f38`
   (печать ходов, +481 строка). Прогон целиком, 1 сентября 2026:

        ./bootstrap/flang check flang/self/zapis.flang
        # модуль «Запись доказательства»: функций 342, из них с доказанным
        # завершением 310; типов 35; файлов вместе с импортами 7
        # flang/self/zapis.flang: проверено — разбор, типы, завершаемость,
        # ядро и примеры; замечаний нет
        kod=0

   `FLANG_DUPLICATE_NAME`, ради которого задача заведена, больше не приходит.

3. **Сторож столкновений зелен:**

        node flang/scripts/link-collision-guard.mjs --дерево
        # столкновений всего: 54 = 0 настоящих + 54 в слитой библиотеке
        # Новых настоящих столкновений нет.                       код 0

Этим же разблокированы десять заплат ядра — разбор в задачах 1300 и 1174.
Столкновений того же рода за день сняли три: `de3fef84`, `ef718648`, `cd5a9f26`.

## Чем ограничено

Переименование в библиотеке — это правка поверхности, за которую отвечает
обещание совместимости (`docs/adr/0010-compatibility-promise-for-0-x.md`). Имя
типа в `sha256.flang` наружу не торчит — оно не в списке «1.0 обещает не
ломать», — но проверить это надо до правки, а не после.
