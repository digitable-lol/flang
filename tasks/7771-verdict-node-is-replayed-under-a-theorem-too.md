# 7771 — дорога вверх была закрыта одной строкой

## Что было

Задача 3009 нашла: написанная теорема ОПУСКАЕТ долю Г4. Замер воспроизведён
своими руками на `flang/proof/examples/if-over-a-segment.flang`:

```
без теоремы   ПРОВЕРЕНО     код 0, на слово ядра 0
с теоремой    НЕ ПРОВЕРЕНО  код 3, на слово ядра 2
flang check                 код 0 — ядро теорему ПРИНИМАЕТ
```

Чем честнее теорема, тем сильнее падала доля. Дорога к потолку 52,1 %
(задача 4635) была закрыта наглухо: единственный названный путь наверх —
дописывать теоремы — работал ровно в минус.

## Причина — не там, где её искали

Постановка называла причиной шаг `по предположению`: будто
`vid_stroki_teoremy` (`сверщик.c:562`) узнаёт его, но проиграть не умеет.
**Это не так**, и вот чем видно:

```
с теоремой: НА СЛОВО ЯДРА посылок и утверждений 2, ШАГОВ 0
```

Шагов ноль — счётчик шагов не при чём. Выросло число посылок.

Настоящая причина — **строка 3462**: на дороге с теоремой
`sverit_pokrytie` получала `proigran = 0` ЖЁСТКО ЗАШИТЫМ. Узел вердикта
«разбором по случаям» при этом тот же самый: тот же принцип
(`носитель segment`), те же две посылки, та же цель — но проигрывать его
никто не звал, и обе посылки уходили в долг по правилу
`posylki_na_slovo` (правило названо, ходов под ним нет).

Разница видна и по счёту узлов:

```
без теоремы   узлов проиграно 3, снято мест 9
с теоремой    узлов проиграно 2, снято мест 6
```

Утверждение, получившее теорему, просто выпадало из проигрывания.

## Починка

На дороге с теоремой узел проигрывается тем же `proigrat_uzel`, что и на
дороге без неё. Цель берётся оттуда же, откуда её берут шаги, — из строки
`утверждаем` исходника, прочитанной так, как её читает язык.

**Приём законен ровно потому, что `proigrat_uzel` не верит записи**: он
читает ТЕЛО ФУНКЦИИ из исходника и сам сверяет дно и спуск. Написана
теорема или нет, тело функции одно и то же, и проигрыш от неё не зависит.

Второй и третий подмаршруты (`perepiskoy`, `razborom_celi`) на этой дороге
НЕ зовутся нарочно: их узлов у теоремы в записи нет ни строкой, и звать их
значило бы снимать места, которых никто не проигрывал.

## Замер A/B

Один и тот же корпус, одна дописанная теорема, два сверщика:

```
                                   по УТВЕРЖДЕНИЯМ      по ЗАПИСЯМ
корпус без теорем, оба сверщика    43 из 242 = 17,77 %  33 из 86
корпус с одной теоремой, ДО        40 из 242 = 16,53 %  32 из 86
корпус с одной теоремой, ПОСЛЕ     43 из 242 = 17,77 %  33 из 86
```

**Одна честная теорема стоила −1,24 процентных пункта. Теперь не стоит
ничего.**

На нынешнем корпусе дерева доля не меняется (13,75 % до и после) — и это
верно: **ни одна запись корпуса теорем не несёт**. Правило ничего не
добавляет, оно СНИМАЕТ ШТРАФ. Его цена — открытая дорога, а не пункт доли.

## Пробы

Раздел «8615» в `прогон.sh`, две пробы, обе прогнаны:

```
честная теорема, спуск убывает        сверщик ДО → 3,  ПОСЛЕ → 0
честная запись + порченый исходник
  («н плюс 1» вместо «н минус 1»)     код 1
правило посылки переименовано         код 1
носитель принципа подменён            код 1
```

Проба несущая: со старым сверщиком набор краснеет именно ею —
«ПРОВАЛ 8615 теорема настоящая — ждали 0, вышло 3».

Набор целиком после правки: код 0, «сошлось всё», подделок 136 —
принято кодом 0 ноль, честных 110 — отвергнуто ноль.

## Не сделано

* `по предположению` как шаг по-прежнему не проигрывается — он и не был
  причиной, но правило для него не написано; шаг остаётся сверенным с
  исходником по номеру, а не проигранным.
* Теоремы в корпус не дописывались: корпус — измерительный прибор, решение
  о его правке за владельцем (задача 8690).
* Второй и третий подмаршруты под теоремой не зовутся; надо ли — не мерено.
