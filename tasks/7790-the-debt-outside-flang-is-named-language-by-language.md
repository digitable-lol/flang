# 7790. Долг «всё написано на flang» назван по языкам

## Чем измерено

Прогон 29 августа 2026 на нынешнем стволе, разбор по кучам
(`scripts/published-vs-tree.sh --перепись` из ветки `m/sverka-opublikovannogo`,
8,5 с):

```
  ВСЕГО НЕ НА FLANG        файлов  208  строк  597687
  ДОЛГ                     файлов  106  строк   23728
  замеряемый материал      файлов   31  строк    3970
  напечатано компилятором  файлов    9  строк  514051
  рантайм цели печати      файлов   31  строк   45306
  хозяин узла на цели      файлов    8  строк    8701
  чужая среда              файлов   23  строк    1931
  НА FLANG                               строк  268659
```

Долг по языкам, тот же прогон:

| язык | файлов | строк | переводимо |
|---|---:|---:|---|
| JavaScript | 35 | 15 060 | да |

| HTML и CSS | 5 | 1 785 | да |

| Python | 3 | 514 | да |
| awk | 1 | 79 | да |
| Erlang | 1 | 69 | да |
| **итого** | **106** | **23 728** | |

Владелец 29 августа назвал 207 файлов / 596 998 строк, долг 23 592 строки в 105
файлах, C 13 / 642, Python 2 / 378. **Мои числа на день свежее: дерево прибавило
один файл на C (+32 строки) и один на Python (+136).** Остальные девять чисел
сошлись знак в знак.

## Что в долг НЕ входит и почему

* **напечатано компилятором — 514 051 строка в 9 файлах.** Это вывод языка, а не
  код на чужом языке. Но напечатать её заново нечем, **пока не идёт
  перепечатка**: это самая крупная строка переписи и она заложница задачи 0003.
* **рантайм цели печати — 31 файл, 45 306 строк.** Уезжает в вывод дословно; на
  стороне цели, а не языка.
* **хозяин узла на цели — 8 файлов, 8 701 строка.**
* **замеряемый материал — 31 файл, 3 970 строк.** Это то, ПРОТИВ чего меряют.
* **чужая среда — 23 файла, 1 931 строка.** Запускатели, до которых flang в
  системе ещё нет.

Каждая из этих строк имеет довод, снятый прогоном, и разбор их —
`docs/javascript-inventory.md`.

## Что сделать

Долг делится на две неравные половины, и браться надо порознь:

1. **Переводимое — JavaScript и оболочка: 82 файла, 20 607 строк, 87 % долга.**
   Ход и препятствия названы в `docs/javascript-inventory.md` и задаче 0016
   (сторожа) и 0049 (последний JavaScript).
2. **По существу нельзя** — 14 файлов на C (пробы работы с памятью: программа
   без побочных действий не измерит арену изнутри).

Перед началом — переснять числа: они меняются каждый день.

## Как понять, что сделано

```sh
sh scripts/published-vs-tree.sh --перепись
```

печатает `ДОЛГ файлов 0`, либо — если часть долга признана непереводимой —
каждый оставшийся файл назван поимённо с доводом, и опись это повторяет.
Число без описи не считается: опись 24 августа называла 53 файла и была неверна
дважды.

## Что от неё зависит

Утверждение «всё написано на flang» стоит на главной странице сайта и в
описании пакета. Пока долг 23 728 строк, это утверждение неверно.
