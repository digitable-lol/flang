# 8596 — десятая цель печати: TypeScript, рабочий, тем же генератором, что и JavaScript

Просьба владельца: «в `flang/src/emit` сделать TypeScript ещё, чтобы рабочий
был». Рабочий — значит напечатанное проверяется `tsc --strict` кодом 0 и
исполняется тем же прогонщиком с тем же выводом, что у цели `js`.

## Что измерено до кода (2026-09-08, карта `/srv/tmp/dokazuemyy/ПЕРЕДАЧА/karta-emit-ts.md`)

* Цель регистрируется в ДВУХ местах, и оба нужны: строка таблицы
  `EMIT_TARGET_TABLE` в `flang/src/emit/c/flang_repl.c` (имя цели → имя функции
  flang, поля настроек, файлы рантайма) и точки входа в
  `flang/self/bootstrap/compiler.flang` («Напечатать связанное в TS»). Первое
  пересобирается `make -C bootstrap`, второе доезжает до двоичного ТОЛЬКО
  перепечаткой семени.
* `flang/self/emit-js.flang` — 4654 строки, 381 объявление, 93 куска рантайма
  литералами. Типы для подписей она УЖЕ считает: JSDoc `@param {number}`,
  `Array<число>`, `(X|null)`, имена записей и сумм. Тела стрелочных функций не
  печатают вовсе (14 `=>` в файле — все в рантайме и таблицах).
* Проба `tsc --allowJs --checkJs --strict` на напечатанном `factorial.js`:
  все замечания — TS7006 «неявный any» В РАНТАЙМЕ; в программной части — ноль.
* `tsc` 5.9.3 на машине есть (не на PATH:
  `/home/m/agent-heavy/flang/node_modules/typescript/bin/tsc`), node v26.7.0
  ввозит `.ts` со снятием типов без флага.

## Решение

TypeScript — это JavaScript плюс типы, и генератор это повторяет буквально:

1. в «Общее JS» заведён признак «типизировано»; при нём печать подписей идёт
   с типами: `export function f(n: number): number`, `export type Zapis =
   { "поле": number }`, `export type Summa = $FlangVariant`, фабрики
   `(fields: Partial<Zapis> = {}): Zapis`, конструкторы вариантов
   `(fields: { "поле": T }): $FlangVariant`, таблица `$PROGRAM`, хвосты
   планов и конкурентности;
2. рантайм в `.ts` не вшивается: он печатается ВТОРЫМ ФАЙЛОМ
   `flang_runtime.js` теми же кусками, тем же текстом, плюс строка `export`;
   `.ts` его ввозит, а `tsc` при `allowJs` выводит типы из JS сам. Второй
   правды о рантайме нет ни строки;
3. `$callDeep` в `.ts` — обёртка с `import.meta.url` над `$callDeepAt`
   рантайма: поток обязан ввозить модуль ПРОГРАММЫ;
4. прогонщик, планировщик, исполнитель и хозяин — те же файлы `js/`;
   `tsconfig.json` (strict, allowJs, noEmit, types: []) едет из
   `flang/src/emit/ts/` полем настроек и печатается рядом;
5. `flang/self/emit-ts.flang` — тонкий модуль: «Настройки TS» (14 полей),
   «Итог печати TS», «Печать программы TS». Копии 4654 строк нет.

Вывод цели `js` обязан остаться байт в байт прежним — это сверяется печатью
двоичным из старого семени против печати нового исходника.

## Как проверяется без перепечатки семени

Двоичный не знает новой цели, пока семя не перепечатано. Поэтому пробы идут
через `flang/self/bootstrap/emit-from-source.flang`: план `flang io`,
который ввозит «Compiler flang» ИЗ ИСХОДНИКА, читает заказ
`tmp/pechat-iz-istochnika/zakaz.txt` (куда, вход, файлы ввоза), зовёт
«Печать в TS от исходников» и пишет файлы. Медленно, но честно: работает тот
код, который поедет в семя.

Приёмка на каждом примере, который в CI печатает цель `js`:

* напечатано;
* `tsc -p . --noEmit` (strict) — код 0;
* `node flang_cli.js ./<имя>.ts` на тех же вопросах даёт тот же вывод, что
  `node flang_cli.js ./<имя>.js` цели `js`, байт в байт.

## Что доедет до двоичного только перепечаткой

`bootstrap/flang emit --target ts` заработает после `scripts/raskrutka.sh`
(~4,7 ч, только с «го» владельца): строка таблицы в `flang_repl.c` уже есть и
собирается, а функции «Напечатать связанное в TS» в семени нет — до перепечатки
двоичный отвечает отказом с именем функции. Поэтому в `ci.yml`,
`*-across-targets.flang` и `target-function-drift.flang` цель `ts` НЕ добавлена:
они зовут двоичный и покраснели бы до перепечатки. Добавить их — отдельная
строка после перепечатки, названа в «Чего не сделано».

## Чего не сделано и почему

* Точные размеченные объединения по вариантам (`{ variant: "Лист" } | …`) —
  тела обращаются к полям через помощников рантайма и `instanceof`, строгий
  разбор объединения дал бы красное там, где код верен. Сегодня сумма — это
  `$FlangVariant`.
* Типы рантайма — выведенные из JS (`any` в параметрах), не объявленные
  `.d.ts`: объявления были бы второй правдой о 93 кусках.
* Цель `ts` в пробах CI, в `*-across-targets` и в сторожах-двойниках — после
  перепечатки семени: они зовут двоичный и покраснели бы сегодня же.
* `flang/conc/node-benchmark.flang` (шесть модулей, процессы) в таблицу не
  попал: компилятор на JavaScript печатает его дольше двадцати минут. На
  прежнем прогоне он печатался и отвечал 135/135 совпадений, а `tsc` давал
  замечания, которые с тех пор вылечены; пересдать его дешевле всего после
  перепечатки семени, обычным двоичным.
* Интерпретирующая проба (`flang io emit-from-source.flang`) сходится на
  factorial байт в байт с печатью через компилятор-на-JavaScript; на
  `flang/conc/scheduler.flang` она за полчаса не закончилась — названо ценой,
  а не замолчано.
