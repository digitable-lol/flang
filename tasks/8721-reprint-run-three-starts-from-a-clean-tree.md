# 8721. Третий заход перепечатки пускается из чистой копии ствола

## Чем измерено

Рабочая копия `/srv/flang-rabota/m-reprint-2` держит **правленые руками файлы
семени**. Снято 29 августа 2026:

```
$ git -C /srv/flang-rabota/m-reprint-2 status --short -- bootstrap/
 M bootstrap/flang_runtime.c
 M bootstrap/flang_runtime.h

$ git -C /srv/flang-rabota/m-reprint-2 diff --stat -- bootstrap/
 bootstrap/flang_runtime.c | Bin 173362 -> 269485 bytes
 bootstrap/flang_runtime.h | Bin  61209 ->  71592 bytes
```

Правки не мелкие: `flang_runtime.c` вырос в 1,55 раза, заголовок — в 1,17.

Почему это тупик, сказано в `AGENTS.md`, раздел «Три правила, за которые платят
дороже всего», правило 1: `bootstrap/**` печатается перепечаткой, и **приёмная
отвергает коммит, который их трогает.** Довод там же и он не про придирку: git
сливает эти файлы без единого знака конфликта и разводит ствол молча.

Значит из `m-reprint-2` результат захода сдать нельзя ни при каком исходе:
удачный заход даст ветку, которую приёмная отвергнет целиком.

## Что сделать

Завести чистую копию ствола и внести в неё **только** правку в
`flang/self/**` — ту, ради которой заход делается:

```sh
git clone /srv/flang-priyom.git /srv/flang-rabota/<своё-имя>
cd /srv/flang-rabota/<своё-имя>
git fetch /srv/flang-priyom.git main && git checkout -B main FETCH_HEAD
```

Если правка в `bootstrap/flang_runtime.*` из `m-reprint-2` нужна по существу —
её надо сначала объяснить и провести через `flang/src/emit/c/`, откуда рантайм
уезжает в вывод дословно, а не через правку семени. Иначе следующая
перепечатка её сотрёт, и никто не заметит.

## Как понять, что сделано

```sh
git status --short -- bootstrap/     # пусто
sh scripts/seed-freshness.sh          # честный ответ о свежести семени
```

Заход пущен из дерева, в котором `git status -- bootstrap/` молчит, и ветка
захода проходит приёмную (`git push /srv/flang-priyom.git HEAD:refs/heads/…`
без отказа).

## Что от неё зависит

Всё, что ждёт перепечатки: задачи 1853 (процессы), 6818 (список препятствий),
работа над правилами процессов и планов. Пока заход идёт из грязного дерева,
даже удачный заход не превращается в семя.
