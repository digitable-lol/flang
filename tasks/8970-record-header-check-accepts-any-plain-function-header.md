# 8970. «Это заголовок функции записи» признаёт своим любой заголовок нетотальной функции

Найдено ревизией задачника 11 сентября 2026 (побочно, при проверке задачи 4543).

## Что видно

Проба из задачи 4543 (три функции `функция «Ход сам»`, `«Ход раз»`, `«Ход два»`,
не тотальные) на `flang 0.7.17`:

```sh
bootstrap/flang check проба.flang            # код 0, «замечаний нет»
bootstrap/flang check --proof проба.flang    # FLANG_PROPERTY: нарушено свойство
  # «чужой заголовок не признаётся своим» функции «Это заголовок функции записи»
```

То же на голом `dev`: `bootstrap/flang check --proof --json flang/self/interpret.flang`.

## Где

`flang/self/zapis.flang:735–748`, функция «Это заголовок функции записи». Тело:

```
(«строка» начинается с "функция «") или («строка» начинается с "тотальная функция «") и притом («строка» содержит … "функция «Имя»")
```

Свойство требует: если результат — да, то строка содержит `функция «Имя»`.
Для строки `функция «Ход сам»` и имени `Ход раз` первая скобка даёт «да», и
результат «да» без проверки имени — свойство нарушено. Оба примера функции
проверяют только `тотальная функция …`, поэтому дыра примерами не ловится.
Гипотеза: не хватает скобок вокруг `или` — проверить чтением правил
приоритета в `flang/self/parser.flang`, а не на глаз.

## Как понять, что сделано

```sh
bootstrap/flang check --proof проба.flang                          # код 0, свойство держится
bootstrap/flang check --proof --json flang/self/interpret.flang    # код 0 или 3, без FLANG_PROPERTY
bootstrap/flang check flang/self/zapis.flang                       # у функции есть пример с «функция «…»» и чужим именем → нет
```

Правка в `flang/self/**` доедет до двоичного только перепечаткой — до неё
прогон по семени её не увидит.
