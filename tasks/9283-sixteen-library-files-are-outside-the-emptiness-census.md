# Перепись пустоты меньше того, что вне неё

## Что сторож говорит

`./ярлык пустота:проверка` — **код 1 за 4 секунды**, прогон без конвейера
(после `| tail` код был бы от `tail`, на этом за сутки попались трое).
Шестнадцать имён, дословно:

```
aes  automaton  crl  der  ecdsa  math-classics-lists  math-classics
registry  rsa  sqlite  tls-handshake  tls  trust-store  x25519  x509  образцы
```

**Поправка к 3397**, которая назвала их «криптографической библиотекой»:
крипто/TLS/PKI среди них **десять**, а шесть — другого рода
(`automaton`, `math-classics`, `math-classics-lists`, `registry`,
`sqlite`, `образцы`). Перепись отстала не от одной библиотеки, а от
роста дерева вообще.

## Две кучи значат не то, что мы думали

Постановка задачи предполагала «наши = настоящие, отложенные =
заготовки». Чтение сторожа это опровергает.

* **«Наши файлы»** (18 имён, `emptiness-guard.flang:590`) — те, которые
  сторож **реально судит**: подставляет телу заглушку той же подписи и
  смотрит, переживёт ли утверждение подмену.
* **«Отложенные»** (8 имён, там же:595) — исключённые **с названной
  ценой**. Каждая запись вида `имя.flang|почему`, и причины замерены:
  `scram` — «28,7 ГиБ и 14,5 минуты на ОДНУ ведомость»; `kdf` — «668 с и
  не укладывается в 20 ГиБ»; `sha1` — «419 с при 16 функциях»; `json`,
  `lists`, `postgres`, `utf8` — «НЕ ПРОВЕРЯЕТСЯ ВОВСЕ на этом стволе» с
  названным кодом отказа.

То есть вторая куча — не «потом сделаем», а **«вот сколько стоит, и
поэтому не судим»**. Заготовок среди 16 нет ни одной.

## Почему их не внесли — цена, а не небрежность

Простая проверка проходит, дело не в сломанности, и у большинства она
**дёшева** — обход девяти из шестнадцати (срок 90 с на файл):

```
math-classics-lists  код 0,   1 с     registry   код 0,  3 с
math-classics        код 0,   2 с     x25519     код 0,  5 с
der                  код 0,   8 с     образцы    код 0,  8 с
rsa                  код 0,  11 с     ecdsa      код 0, 12 с
automaton            код 0,  24 с     sqlite     код 0, 86 с
trust-store          код 0,  88 с     x509       код 0, 89 с

crl  код 124        tls-handshake код 124
tls  код 124        aes           код 124     — все четверо не уложились в 90 с
```

**Двенадцать из шестнадцати проверяются, и почти все дёшево** — восемь за
двенадцать секунд и меньше. **Четверо в срок не уложились**: `crl`,
`tls-handshake`, `tls`, `aes`. Их цену надо мерить отдельно, и они
кандидаты в «Отложенные» по той же причине, что `json` и `lists`, если
окажется, что не проверяются вовсе, — но это ещё не установлено, срок в
90 с мог просто не хватить на машине под перепечаткой.

Дорога **ведомость**, и вот замер по самому малому из шестнадцати:

```
flang check flang/stdlib/trust-store.flang --proof
  код 3, 165 секунд, утверждений 23: доказано 15
```

А сторож, по своей же шапке, ставит **заглушку по одной функции за раз**
(иначе замер врёт: «удвоение есть сложение с самим собой» выглядит
даровым, потому что заглушается и «Сложить»). Значит внести в перепись
самый малый файл стоит примерно **15 × 165 с ≈ 41 минуту**. Файл `aes`
крупнее его в шесть раз по строкам и в девять по обещаниям.

Это ровно тот порядок цены, по которому в «Отложенные» уже попали
`scram` (14,5 минуты на одну ведомость) и `kdf` (668 с).

## Чего я НЕ сделал и почему

**Не внёс шестнадцать в «Отложенные».** Каждая запись там несёт
**замеренную** цену, и написать шестнадцать причин, померив одну, значит
подделать происхождение — ровно то, за что в этом дереве бьют. Померено
трое из шестнадцати простой проверкой и один ведомостью.

Честный путь для следующего — один из двух, и это решение владельца:

1. **Померить и внести.** Шестнадцать ведомостей по 165 с и больше, плюс
   заглушки по одной функции — часы машины. Зато перепись накроет всю
   библиотеку, и число «пусто ли доказанное» станет про всё дерево.
2. **Внести с общей причиной** «библиотека выросла быстрее переписи, цена
   замера — от 41 минуты на файл», сославшись на замер `trust-store` как
   на нижнюю границу. Дешевле, но слабее: цена каждого останется
   неизвестной.

Первый путь честнее, второй — сегодня выполним.
