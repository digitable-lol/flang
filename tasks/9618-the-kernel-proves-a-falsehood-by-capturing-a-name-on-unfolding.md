# 9618. Ядро печатает «доказано обо ВСЕХ входах» про ложное утверждение

Найдено ячейкой Ч347, подтверждено ведущим Б, **воспроизведено старшим
самостоятельно с изъятием**. Это не «чекер пропустил подделку» и не «спецификация
разошлась с ядром». Это ядро выводит ложное.

## Происхождение

Дерево `/srv/tmp/dokazuemyy/peredacha`, ветка `dev`; двоичный `bootstrap/flang`
md5 `ec9c290568b4b4d2b03d68cb5bcd4a7a` — тот же у ведущего и у ячейки, значит
двоичный не переменная. Улика: md5 `c3c6c45379028d71d4946277563ea943`, 12 строк.

## Улика целиком

```
модуль «Захват»

тотальная функция «Сколько равных»
  принимает х: число
  возвращает число
  длина (отфильтровать [1, 2, 3] где эл → эл равен х)

тотальная функция «Проверка»
  принимает эл: число
  возвращает число
  для всех эл обеспечивает «равно трём» результат равен (длина (отфильтровать [1, 2, 3] где эл → эл равен эл))
  «Сколько равных» от эл
```

## Что говорит ядро

```
bootstrap/flang check .../zahvat.flang --proof     →  код 0

  постусловие «равно трём» функции «Проверка» — доказано сведением цели с телом
  функции: правило «тождество после переписки допущением», объявленные типы
  аргументов не понадобились — утверждение обо ВСЕХ входах, а не о написанных;
  теоремы при нём нет и не нужно
```

## Что происходит на самом деле

```
run --function «Проверка» --args '{"эл":1}'  →  код 1  нарушено свойство «равно трём»
run --function «Проверка» --args '{"эл":2}'  →  код 1  нарушено свойство
run --function «Проверка» --args '{"эл":5}'  →  код 1  нарушено свойство
```

Ложно при каждом испробованном входе — при том, что «доказано обо ВСЕХ».

## Механизм: захват имени

Связыватель лямбды в `«Сколько равных»` зовётся `эл`. Довод вызова тоже зовётся
`эл`. Ядро разворачивает вызов и подставляет `х := эл` — **под связыватель того
же имени**. Цель после подстановки совпадает с телом посимвольно, и правило
«тождество после переписки допущением» её закрывает.

Внутри постусловия `эл равен эл` истинно всегда, значит правая часть равна 3 при
любом входе. Тело же считает совпадения с настоящим `эл`: при `эл=2` это 1.

## Изъятие, сделанное старшим

Убран ВЫЗОВ — тело записано на месте, всё прочее слово в слово то же:

```
check → код 0, но: постусловие «равно трём» — ОБЪЯВЛЕНО, НЕ ДОКАЗАНО
```

Значит маршрут — именно развёртка вызова, а не форма постусловия. Соседний
маршрут (захват при подстановке без развёртки) ядро отвергает правильно —
проверено ведущим.

## Спецификация обещает защиту, которой нет

`flang/proof/SPEC.md` описывает **ОГРАНИЧИТЕЛЬ 4** как существующую защиту

**Поправка 3 сентября (Ч357).** Прежде тут стояло `flang/SPEC.md:1036–1052`
и `proofterm.flang`. Обе ссылки неверны: слова «ОГРАНИЧИТЕЛЬ» в
`flang/SPEC.md` нет вовсе, а вся машинерия живёт в `proof-kernel.flang`.
Ячейка нашла это сама и сказала, вместо того чтобы чинить не тот файл.
ровно от этого. Значит беда двойная: ядро выводит ложное И спецификация обещает
несуществующее.

## Чего НЕ измерено, и это главное

**Сколько мест дерева идут через захват — числа нет.** Показан один маршрут на
одной программе. Пока числа нет, ширина беды неизвестна, и решение о выпуске без
него принимать нельзя.

## Что проверено про печать

Проверка постусловия из напечатанного кода **не снимается**: `emit --target c` на
улике и на честном файле даёт побайтово одну и ту же строку
`FL_TRY(fl_post(ctx, …, "равно трём", …))`, вхождений 3 и 3 (замер ведущего Б,
он же снял свой прежний неверный довод про `пример`). Значит вред ограничен:
ложно «доказанное» всё равно проверяется при работе.

**Но обобщать нельзя:** `AGENTS.md` говорит, что прошлая перепечатка сняла 181
проверку. Показан один случай, не правило.
