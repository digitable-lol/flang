# 9790. Сколько строк приходится принять на веру, названо по всему пути, а не по одному ядру

Сегодня дерево меряет доверие одним числом — **ядро решений**:

```sh
/usr/bin/grep -a -n 'ядроРешенийСтрок' flang/scripts/kernel-lines-to-trust-ceiling.json
```

```
"ядроРешенийСтрок": 4628,
```

Само дерево говорит, что этого мало. `flang/proof/чекер/ЧИТАТЬ.md` пишет прямо:
«4548 строк по трём файлам, и это число занижено — вычислитель, парсер и лексер,
на которые ядро опирается, в него не входят (полоса 4548…6710)». То есть у
границы доверия объявлена полоса, а не число, и верхний конец полосы никто не
стережёт.

А за flang стоит ещё C, и он в счёт не входит вовсе. Снято по дереву:

```sh
wc -l bootstrap/*.c bootstrap/*.h            # 726 169
wc -l flang/src/emit/c/*.c flang/src/emit/c/*.h   # 27 914
wc -l flang/self/parser.flang flang/self/lexer.flang   # 8708 и 2308
```

Наряд ячейке Ч141 от 31 августа 2026 называет свои числа: **26 234 LOC на flang
плюс 517 099 LOC рантайма на C, доля parser 20,2 %.** Ни одно из трёх моими
командами не воспроизводится: `wc -l` по `bootstrap/` даёт 726 169, по
`flang/src/emit/c/` — 27 914; `parser.flang` — 8708 строк, что от 26 234 даёт
33,2 %, а не 20,2 %. Значит наряд считал ДРУГИМ прибором — вероятно, снимая
комментарии и пустые строки, как это сегодня делает счётчик ядра
(`a9d6a95e`: «счётчик строк ядра снимает блочные комментарии сам»). Прибор не
назван, и в этом вся задача: числа есть, а команды при них нет.

## Как понять, что сделано

```sh
./ярлык сколько-верим
```

1. Печатается **одно** число «сколько строк придётся принять на веру» и его
   разбивка по кучам: ядро решений, вычислитель, парсер, лексер, рантайм на C.
2. У каждой кучи стоит команда, которой она снимается, и сказано, что именно
   считается строкой (снимаются ли комментарии, пустые, блочные).
3. Полоса 4548…6710 из `ЧИТАТЬ.md` заменена числом, либо сказано, почему она
   остаётся полосой.
4. Потолок ползёт только вниз — как у нынешнего сторожа: рост даёт код 1 с
   именем кучи, которая выросла.
5. Числа наряда (26 234 / 517 099 / 20,2 %) либо повторены этим прибором, либо
   названы неверными с разностью.

## Чем ограничено

Не сливать с задачей 8121: та требует **снизить** ядро решений ниже 4000, эта —
**назвать** всё, что за ним стоит. Снижение по одной куче при растущей другой не
считается.

И не подменять предмет: чекер на C (1566 строк) доверие не снимает, а
переносит — с ядра на себя. Его строки в счёт входят так же, как остальные.
