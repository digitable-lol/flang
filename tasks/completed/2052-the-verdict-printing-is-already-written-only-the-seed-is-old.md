# Печать вердикта: чинить нечего, ждать надо перепечатки

Задание было прямое, от владельца: «чини печать». Предпосылка задания —
что маршрут «по объявлению» даёт узел вердикта, из которого «до записи не
доезжает ни байта», и что не хватает 12–20 строк новой печати.

**Предпосылка устарела. Печать написана, подключена верно, и недостающих
полей, которые стоило бы печатать, нет.** Ниже — чем это измерено.

## Что несёт узел вердикта и что из этого печатается

`«Вердикт по объявлению»` (`flang/self/proofterm.flang:2649`) собирает
десять полей: `kernel`, `verdict`, `by`, `byType`, `rule`, `steps`,
`cases`, `refusals`, `says` и — не всегда — `calls`.

Счёт по `flang/self/zapis.flang`, сколько раз печать читает каждое:

| поле | читается | вывод |
|---|---:|---|
| `by` | 22 | печатается |
| `rule` | 17 | печатается |
| `steps` | 8 | печатается |
| `verdict` | 7 | печатается |
| `induction` | 5 | печатается |
| `cases` | 3 | печатается |
| `byType` | 2 | печатается |
| `kernel` | 0 | печатается ИНАЧЕ — строкой `ядро 2`, образец у чекера есть |
| `refusals` | 0 | по построению пустой список на этом маршруте |
| `says` | 0 | проза, выводится из `rule` + `byType`, проверять в ней нечего |
| `calls` | 0 | **в корпусе не заполняется никогда — замер ниже** |

## Замер по `calls` — единственному полю, которое стоило бы печатать

`calls` — не проза: это список записей `{of: функция, name: постусловие}`,
то есть «цель закрыта постусловием вызванной функции». Такое чекер мог бы
проверять по существу.

Прогон `check --proof --json` по 25 файлам корпуса:

```
узлов с by=declaration: 73
из них с полем calls:    0
```

Поле стоит под условием `если пусто «факты»` (`proofterm.flang`), и в
сегодняшнем корпусе факты по вызову не понадобились ни разу. Печатать
строку, которая не появится, — работа без предмета; к тому же образца для
неё у чекера нет, а `сверщик.c` принадлежит другому работнику, и печать
без образца заново поставила бы мину задачи 9997.

## Почему записи всё-таки пусты — и это НЕ вина печати

Утверждение из настоящей записи (`пробы/записи/корпус/abilities.запись`):

```
утверждение «У1 сумма читается в обратном порядке» функции «Сумма наоборот» строка 29
  вид postcondition
  вердикт доказано
  теоремы нет
конец утверждения
```

Три строки, и ни одной о том, ПОЧЕМУ доказано. Это и есть порода из 146.

А узел этого же утверждения, снятый `--proof --json` сегодня, несёт всё:

```
verdict = 'доказано'
by      = 'declaration'
rule    = 'тождество после переписки допущением'
byType  = False
says    = 'доказано сведением цели с телом функции: правило «…»,
           объявленные типы аргументов не понадобились'
```

**27 из 28 обязательств этого файла закрыты маршрутом `declaration`.**

Печать для них написана: `«Строки объявленного правила»`
(`zapis.flang:1355`, коммит `818a2a7c`, Ч414) даёт `правило «…»` и
`по объявлению да|нет`. И она **подключена верно** — проверено чтением
места вызова (`zapis.flang:1441`):

```flang
пусть «с объявлением» равно (если «Это запись» от «вердикт»
  то (… «Строки объявленного правила» от «вердикт») иначе «с принципом»)
```

Условие — только «вердикт есть запись». Теоремы оно не требует, значит для
У1 сработает. Проверено и с другой стороны: `discharge` у У1 **является**
записью с полями выше.

## Единственная причина, по которой этого не видно

Функции нет в семени:

```
«Строки объявленного правила» в flang/self/zapis.flang : 2
                              в bootstrap/compiler_flang.c : 0
sh scripts/chto-otstalo-ot-semeni.sh →
  zapis.flang   1 из 86   Строки объявленного правила
```

Печатает семя, а не исходник. Пятый случай этой породы за сутки после
9985, 9996, 9997 и 10004.

## Что отсюда следует

1. **Правки в `zapis.flang` не нужно** — ни одной строки. Кода не написано
   намеренно.
2. **Рычаг — перепечатка.** Она принесёт `правило «…»` и `по объявлению`
   в записи всюду, где ядро закрыло цель объявлением, то есть в те самые
   42 записи / 91 утверждение породы П1.
3. **После перепечатки доля Г4 сама по себе не вырастет.** Чекер эти строки
   узнаёт (работник A5, коммит `7c73aa2d`), но не читает — это задача 9616,
   и она остаётся настоящей работой.

Порядок такой: перепечатка → строки появились → 9616 учит чекер их читать
→ доля движется к 37,92 %.

## Не сделано

Поля `says` и `calls` не печатаются, и это решение, а не пропуск: первое
проверять нечем, второе в корпусе не встречается. Если факты по вызову
когда-нибудь появятся, печать `calls` станет осмысленной — и тогда её
обязан сопровождать образец в `сверщик.c`, иначе повторится мина 9997.
