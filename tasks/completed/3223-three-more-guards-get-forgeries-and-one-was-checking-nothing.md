# 3223 — трое, которых R1 не поставил в CI

Задача 9220 поставила в CI троих сторожей с подлогом и честно оставила
троих: `занятые:проверка`, `слова:проверка`, `слово:занятость`. Причина
названа была верно — сторожу верят только после красноты на подлоге
(задача 1389), а подлог за один заход не построился.

Разобрано по одному. Итог разный у всех троих.

## 1. `слова:проверка` — ПРОВЕРЯЛ ПУСТОТУ, починено

**Подлог:** подделка `flang/test/fixtures/poddelka-slova-celey.flang`
заменена тривиальным модулем без единого занятого слова.

**Сторож остался ЗЕЛЁНЫМ, код 0**, и написал: «занятые слова экранированы:
подделка и списки собраны всеми восемью целями (8 из 8)». Утверждение
пустое — показывать экранирование было не на чем.

Разделы 2 и 3 при этом работу делали: они порождают программы из списков
самой печати (`«Зарезервировано в C»` и прочие) и от потрошения подделки не
страдают. Выпотрошился ровно раздел 1, и сказать об этом было некому.

**Соседний сторож той же семьи от того же защищён:**
`scripts/occupied-names-guard.flang` даёт `FLANG_ZANYATOE_VHOLOSTUYU` —
«НИ ОДНА ПРОБА НЕ ОКАЗАЛАСЬ ЗАНЯТОЙ — сверка снятия прошла вхолостую».
Здесь защиты не было. Одна семья, разная дисциплина.

**Починено** (`062b6e80`): каждая живая цель обязана дать в подделку хоть
одно своё занятое слово. Правило не число с потолка — замерено:

```
c 20, go 18, rust 16, java 21, js 18, elixir 11, python 15, csharp 22
всего 38 разных слов из 354 во всех списках
```

Счёт по целям печатается всегда — подделка, худеющая понемногу, видна
числом задолго до нуля.

**Проба в обе стороны:**

```
подделка цела         код 0, строка счёта напечатана
подделка выпотрошена  код 1, «ПОДДЕЛКА ВЫПОТРОШЕНА» по каждой из 8 целей
```

Опорный прогон — 59 с, все восемь целей на машине есть.

## 2. `занятые:проверка` — подлог на обещание НЕ СТРОИТСЯ, и вот почему

Сторож судит **обход занятых целью имён**: тождествен ли он на свободном
имени и снимает ли занятость на занятом. Пять исходов провала, каждый
назван (`FLANG_ZANYATOE_NECHEM`, `_RAZOSHLOS`, `_VHOLOSTUYU`).

Вопрос к двоичному он строит так:

```
{"fn":"Змейка","args":[{"s":"JSON"}]}
```

**Имени файла в вопросе нет.** Двоичный отвечает из ВШИТЫХ в семя функций
компилятора. Значит правка `flang/self/emit-c.flang` на ответ не влияет
никак, и подлог, который сломал бы обещание, требует ПЕРЕПЕЧАТКИ семени —
это не подлог на один заход, а отдельная работа.

Заголовок соседней подделки говорит то же самое прямо: «Снимите
экранирование в печатнике — и сторож покраснеет». Печатник в семени.

Из корпуса (единственное, что сторож читает свежим) достижим только исход
«КОРПУС ПОТЕРЯН», и то ценой снятия шапки `модуль` со 104 файлов из 223 —
условие `без шапки > модулей`. Для CI это не подлог, а погром.

**Что вместо этого сделано:** задача 6551 нашла и починила в этом стороже
две настоящие беды (падал в свежей выкладке; неудачную запись не проверял),
и ВТОРАЯ починка снабжена своим подлогом — `mkdir` убран, проверка отклика
оставлена, сторож называет причину и место. То есть подлогом накрыта
починка, а не исходное обещание. Разницу называю прямо, чтобы её не
приняли за большее.

## 3. `слово:занятость` — это ПРИБОР, а не сторож

Ярлык `слово:занятость` (`flang/scripts/word-occupancy.mjs`) отвечает на
вопрос «если сделать это слово ключевым, сколько программ сломается».
Его **код 1 означает „слово занято“ — это ответ, а не беда**
(`process.exitCode = записи.some(…) ? 1 : 0`). Воротами в CI его ставить
нельзя: он покраснеет на всяком занятом слове, что и есть его работа.

Сторож семьи — другой ярлык, `слово:занятость:проверка`
(`scripts/occupancy-check.flang`): самопроверка прибора.

**Подлог, и он удался с первого настоящего захода** — один знак в приборе,
`итог.вЁлочках += 1` → `итог.голым += 1`, то есть имя в ёлочках начинает
считаться голым:

```
код 1
замер занятости ОТКАЗЫВАЕТ, расхождений 2
  · прибавилось голых от подлога, где слово стоит только в безопасных
    местах: ждали 0, вышло 1
  · прибавилось вхождений в ёлочках: ждали 1, вышло 0
```

Опорный прогон — код 0, «ловит, узнаёт, молчит и различает фразу —
расхождений 0», 86 с. Сторож надёжен, чинить нечего.

### Поправка к себе

Первый мой подлог был ХОЛОСТЫМ, и зелёный сторож был прав. Я сняла на
строке 183 условие `токен.quoted === true`, ожидая, что закавыченные имена
начнут считаться голыми. Они до этой строки не доходят: ветвь на строке 164
перехватывает их раньше и делает `continue`. Записываю, потому что ровно
так рождается ложное «сторож слеп»: подлог не собрался, а вывод сделан.

## Врезка в CI — готова, поставить одним движением

`ci.yml` не мой файл. Ниже готовый кусок; `слова:проверка` — 59 с плюс
подлог, пара около двух минут.

```yaml
      - name: сторож слов краснеет на выпотрошенной подделке
        run: |
          set -u
          podlog=flang/test/fixtures/poddelka-slova-celey.flang
          cp "$podlog" "$podlog.do"
          printf 'модуль «Проба занятых слов»\n\nтотальная функция «Слова простой»\n  принимает первое: число\n  возвращает число\n  пример «Просто складывает»\n    дано первое равно 2\n    ожидается 3\n  первое плюс 1\n' > "$podlog"
          if cmp -s "$podlog.do" "$podlog"; then
            rm -f "$podlog.do"; git checkout -- "$podlog"
            echo "ПОДЛОГ НЕ СОБРАЛСЯ: подделка уже такая — поправить подлог, сторож ни при чём" >&2
            exit 1
          fi
          rm -f "$podlog.do"
          if ./ярлык слова:проверка; then
            git checkout -- "$podlog"
            echo "сторож промолчал на подлоге — проверять им нечего" >&2
            exit 1
          fi
          git checkout -- "$podlog"
      - name: занятые слова целей экранированы
        run: ./ярлык слова:проверка

      - name: замер занятости краснеет, когда ёлочки считаются голыми
        run: |
          set -u
          podlog=flang/scripts/word-occupancy.mjs
          cp "$podlog" "$podlog.do"
          sed -i '165s/итог.вЁлочках += 1/итог.голым += 1/' "$podlog"
          if cmp -s "$podlog.do" "$podlog"; then
            rm -f "$podlog.do"; git checkout -- "$podlog"
            echo "ПОДЛОГ НЕ СОБРАЛСЯ: строка 165 уже не та — поправить подлог, сторож ни при чём" >&2
            exit 1
          fi
          rm -f "$podlog.do"
          if ./ярлык слово:занятость:проверка; then
            git checkout -- "$podlog"
            echo "сторож промолчал на подлоге — проверять им нечего" >&2
            exit 1
          fi
          git checkout -- "$podlog"
      - name: замер занятости различает голое имя и ёлочки
        run: ./ярлык слово:занятость:проверка
```

`занятые:проверка` в врезку НЕ включён: подлога на его обещание нет
(раздел 2), и ставить его воротами без подлога значит нарушить правило
задачи 1389. Починка 6551 делает его пригодным для CI технически — решение
о том, ставить ли сторожа без подлога, за владельцем.
