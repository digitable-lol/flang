# 3488 — номер задачи перестал помещаться в четыре знака

## Улика до починки, числом

```
./ярлык задачник:проверка   → код 1, замечаний 5
  · 10001-forma-...md: номер шапки «10001» не сходится с именем файла
  · 10002-dokazatelstvo-...md: то же
  · 10003-poryadok-rabot-...md: то же
  · 10004-celey-devyat-...md: то же
  · 9984-sverit-shagi-...md: названо больше одного исполнителя: A1, A4
```

Причина четырёх из пяти — `flang/scripts/tasks.flang`, функция
`«Начало имени»`: она брала **ровно четыре знака** имени файла. Для
`10001-forma-...md` это давало `"1000"`, что не сходилось с шапкой `10001`.
Всякая следующая заведённая пятизначная задача красила бы сторож снова.

## Починка: цифры до первого дефиса, а не первые четыре знака

Тело переписано на `голова (разделить файл по "-")`. Помощники уже были в
файле — `разделить … по` и `голова` используются в `«Цифра числом»`, новых
писать не пришлось.

**Ветвь «нет дефиса» оставлена намеренно, хотя обе ветви дают одно значение.**
Старое постусловие `«Начало имени: первая ветвь»` ядро ДОКАЗЫВАЛО — «разбор
цели по условию», то есть сведением цели с телом. Проверено прогоном на
выделенном файле: у бесусловного тела то же по смыслу утверждение ядро уже не
доказывает и оно уезжает в проверку при работе. `если` в теле оставлено ради
того, чтобы цель было с чем сводить; новое постусловие
`«Начало имени: имя без дефиса»` доказывается тем же правилом:

```
постусловие «Начало имени: имя без дефиса» функции «Начало имени» —
доказано сведением цели с телом функции: правило «разбор цели по условию»
```

Постусловие теперь говорит о новом поведении прямо: **имя без дефиса
возвращается целиком**. Примеров стало четыре вместо двух — четырёхзначный
номер, пятизначный, имя без дефиса, пустое имя. В `«Номер из имени»` добавлен
пятизначный пример: без него новый путь не был бы покрыт.

## Пятое замечание: 9984 с двумя исполнителями

Правило `«Исполнителей больше одного»` краснеет, если в поле есть запятая или
пробел. Задачу вели две ячейки подряд: A1 закрыл ложный приём на
`segment`/`fold`, A4 добил `algebra`.

Правило не ослаблялось. В дереве **уже есть прецедент**: задача 9987, которую
вели четыре ячейки, несёт `исполнитель: Ч9987` и четыре ветки в поле «ветка».
9984 приведена к тому же виду — `исполнитель: Ч9984`, обе ветки на месте, а кто
сделал какую половину, записано в её ⚑-разделах и повторено врезкой в шапке
тела. Смысл правила — чтобы было у кого спросить; список из двоих на этот
вопрос не отвечает, тело отвечает.

Менять конвенцию всего дерева работник не стал: следовать уже поставленному
прецеденту — его дело, вводить новый — нет.

## Побочно: полоса номеров НЕ кончалась

В постановке было сказано, что четырёхзначные номера исчерпаны. Это неверно, и
проверено прогоном плана `Номер`:

```
номера из полосы 1000…9999, занятых номеров было 204
```

Занято 204 из девяти тысяч. Номера 10001–10004 **проставлены руками мимо
плана**, а не выданы им. Починка нужна была всё равно — сторож не должен
падать от номера любой длины, — но причина другая, и её стоит знать: если
номера продолжат ставить руками, план и каталог разойдутся ещё где-нибудь.
Задача этого не чинит: решать, загонять ли пятизначные обратно в полосу или
расширить полосу в плане, — не работнику.
