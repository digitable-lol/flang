# 4271. Печатник Elixir печатает мёртвую строку результата на каждое постусловие

Замер 8 сентября 2026, дерево `/srv/tmp/dokazuemyy/volna-pechat`, двоичный
`bootstrap/flang` 0.7.14 из семени этого же дерева.

## Что видно

`«Шаг постусловия Elixir»` (`flang/self/emit-elixir.flang`) заканчивал свой блок
пустой строкой и строкой с именем результата. Шаг этот зовётся СВЁРТКОЙ по всем
постусловиям функции — значит имя результата печаталось столько раз, сколько у
функции постусловий, а нужно оно ровно одно: последнее, оно и есть значение
тела. Все прочие — выражения без действия.

Elixir на такое выражение отвечает предупреждением
«variable t1 in code block has no effect as it is never returned», а напечатанный
`Makefile` собирает цель ключом `--warnings-as-errors` — и это не придирка, так
написано в его же шапке: «напечатанный код обязан быть чистым».

Замер на том самом файле, который печатает работа CI `link-across-targets`
(`bootstrap/flang emit flang/conc/link.flang --target elixir`):

```
elixirc --warnings-as-errors -o _build flang_runtime.ex svyaz_uzlov.ex flang_cli.ex
предупреждений 17, и все семнадцать — «has no effect as it is never returned»
```

## Чего замер НЕ показал

На этой машине Elixir 1.20.3, и `elixirc --warnings-as-errors` **выходит кодом
0** даже при предупреждении (проверено отдельной пробой с неиспользованным
именем: предупреждение есть, код 0). Значит краснота работы
`link-across-targets` на раннере GitHub (там Elixir из образа ubuntu) здесь **не
воспроизведена** — воспроизведён только сам дефект и его семнадцать
предупреждений. Утверждение «из-за этого красна ci/link-across-targets»
остаётся **непроверенным на этой машине**.

## Что сделано

Строка результата вынесена из шага в `«Тело с постусловиями Elixir»` и
печатается ОДИН раз после свёртки. Пустая строка после `end` осталась в шаге —
она разделяет блоки постусловий.

## Чем проверено

1. **Толкователем, до перепечатки.** Обёртка вне дерева (`zond-elx.flang`,
   `FLANG_MODULE_DIR` на `flang/self:flang/core:flang/stdlib`) строит функцию с
   ТРЕМЯ постусловиями и зовёт `«Тело с постусловиями Elixir»` через
   `bootstrap/flang run`. До правки — три строки `t1`; после — одна, последняя.
   Перед правкой обёртка дала ровно то, что печатает семя, — печатник и
   толкователь согласны.
2. **Сборкой и прогоном напечатанного.** Тот же `svyaz_uzlov.ex`, из которого
   механически убраны ровно те 17 строк, что печатник больше не печатает:
   `elixirc --warnings-as-errors` — код 0, предупреждений **0** (было 17).
   Четыре вопроса той же формы, что шлёт сторож связи («Связь заново», «Связь
   замолчала», «Почему замолчала», «Шаг связи»), — ответы старой и новой сборки
   **байт в байт одни и те же**, обе код 0.
3. **Самим компилятором.** `bootstrap/flang check flang/self/emit-elixir.flang`
   после правки — код 0, «проверено — разбор, типы, завершаемость, ядро и
   примеры; замечаний нет».

## Приёмка

- после перепечатки `bootstrap/flang emit flang/conc/link.flang --target elixir`
  даёт файл, который `elixirc --warnings-as-errors` собирает с нулём
  предупреждений;
- работа CI `link-across-targets` зелена и говорит «9 целей из 9»;
- ответы цели elixir на вопросник сторожа не изменились.
