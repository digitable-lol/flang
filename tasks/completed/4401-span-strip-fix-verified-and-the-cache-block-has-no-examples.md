# 4401 — проверка починки «Значение без мест рекурсивно»

Перепечатка 5 сентября упала на `FLANG_NOT_TOTAL`, строка 3159. Починку
написал другой работник; здесь она проверена **независимо**, своими
прогонами, без правок в дереве.

## 1. Спуск правда выводится — A/B на одном прогоне

Ключ `--быстро` спрашивает ровно связывание, типы и завершаемость, без
стадии доказательств. Одиночный файл проверяется без ввозов, поэтому три
`FLANG_UNKNOWN_NAME` про «Это число» и две тотальности как их следствие
стоят в обоих прогонах — они к делу не относятся.

```
ДО (gh/dev)      FLANG_NOT_TOTAL 3159 · 436 · 450   FLANG_UNKNOWN_NAME 436 · 450 · 600
ПОСЛЕ            FLANG_NOT_TOTAL        436 · 450   FLANG_UNKNOWN_NAME 436 · 450 · 600
разница          ровно одна строка: FLANG_NOT_TOTAL 3159
```

## 2. Множество на выходе то же — по объявлению типа, а не по рассуждению

```flang
объект «Поле значения»
  «ключ»: строка         ← по нему идёт отбор; отображение копирует его БЕЗ изменений
  «значение»: «Значение»  ← его меняет отображение; отбор на него не смотрит
```

Полей ровно два, смотреть больше не на что. Отбор `не ((«ф».«ключ») равен
"span")` глядит только на `«ключ»`, а отображение задаёт `«ключ» равным
(«п».«ключ»)` дословно. Значит перестановка отбора и отображения множество
не меняет.

## 3. Примеров у функции НЕТ — и это находка крупнее самой починки

У функции нет ни одного `пример`. Больше того:

```
последний пример ДО блока кеша     строка 2925
первый пример ПОСЛЕ блока кеша     строка 3661
```

**Семьсот тридцать шесть строк без единого примера**, и весь кеш
приговоров внутри: «Корзин кеша», «Номер корзины», «Отпечаток строки
кеша», «Значение без мест рекурсивно», «Отпечаток узлов кеша», «Отпечаток
поля кеша», «Основа кеша». Примеров со словом «кеш» во всём файле — ноль.

Прогонять было нечего, поэтому и не поймали.

## 4. Не регресс — функция такой родилась

```
git log -S'Значение без мест рекурсивно' — РОВНО ОДИН коммит
d621bda9  fix(proofterm): strip span recursively from verdict-cache key
          добавленных строк с этим именем 5, убранных 0
          4 сентября 2026, 18:06
```

Тотальной она не была никогда: до этого коммита её не существовало.
`d621bda9` — **предок коммита печати `fece2542`** (проверено
`git merge-base --is-ancestor`). То есть перепечатку на четыре с половиной
часа запустили из дерева, где эта функция ни разу не проходила проверку.

Круг замкнулся и виден числом: `sh scripts/chto-otstalo-ot-semeni.sh`
показывает `proofterm.flang — 1 из 287, Значение без мест рекурсивно`.
Семя отстаёт из-за неё, а перепечатать семя нельзя, пока она не проходит.

## 5. Цена выбранной формы — 1,35× лишнего обхода, и она измерена

Выбранная форма (сперва отображение, потом отбор) заходит рекурсией
ВНУТРЬ каждого места, прежде чем его выбросить. Замер по разбору двух
файлов:

```
proofterm.flang  узлов 202 145 · мест 89 756 · ячеек в них 179 512 · лишку 1,33×
parser.flang     узлов  80 166 · мест 36 707 · ячеек в них  73 414 · лишку 1,37×
```

Место — это `{"line": N, "column": M}`, две скалярные ячейки, но их по
одной почти на каждый узел, поэтому лишку не константа, а треть обхода
сверху.

**Форма без лишнего обхода существует и тоже проходит завершаемость** —
проверено отдельным файлом: отбор оставить после, но в отображении не
спускаться в место:

```flang
«значение» равным (если («п».«ключ») равен "span"
                     то («п».«значение»)
                     иначе («Значение без мест рекурсивно» от («п».«значение»)))
```

Что выбрать — решать владельцу. Довод за простую форму: короче и понятнее.
Довод за форму с условием: кеш приговоров уже показал себя бесполезным
(перепечатка с ним вышла на 56 секунд ДОЛЬШЕ бескешевой), и утяжелять его
ключ на треть незачем.

## Чего эта проверка НЕ говорит

Полный `flang check` со всеми ввозами до конца не доведён: стадия
доказательств идёт часами, и прогон снят по PID, когда `--быстро` уже дал
ответ по завершаемости. Про доказательства и примеры файла целиком здесь
не сказано ничего.

Поведение функции в работе не проверялось и не могло: правка лежит в
`flang/self/**`, а двоичный собран из семени и увидит её только
перепечаткой.

## Не сделано

* Правок в `flang/self/proofterm.flang` не вносилось — починка чужая.
* Примеры блоку кеша не написаны. Это отдельная работа, и она нужна:
  без них та же порода вернётся.
