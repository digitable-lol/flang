# 4635 — 95 % по Г4 недостижимы, и вот чем это меряется

## Зачем задача

Приговор КРИТЕРИЙ.md требует Г4 не ниже **95 %**. Сегодня 33 из 240 = 13,75 %.
Задача 8429 показала, что дорогой «правила в чекере» выше 38–39 % не подняться.
Здесь установлено, ПОЧЕМУ, и назван настоящий потолок.

## Главное, чего в постановке не было: «теорема» пишется АВТОРОМ

Порода П1 — «в записи стоит „доказано", а теоремы нет». Читалось это как
дефект ядра: ядро, мол, не кладёт своё доказательство в запись.

**Это не так.** `теорема` — конструкция ИСХОДНИКА, которую пишет человек:

```
теорема «факториал неотрицателен»
  дано н: нат
  утверждаем результат не меньше 0
  индукция по н убывает н
    случай любое
      то по предположению
  следовательно доказано
```

Ядро своё доказательство не записывает и записать не может: оно сводит цель
с телом функции, и «доказательство» тут — само вычисление. Ядро об этом
говорит прямо (`flang/self/proof.flang:2555`), дословно:

```
доказано сведением цели с телом функции: правило «…», объявленные типы
аргументов не понадобились — утверждение обо ВСЕХ входах, а не о написанных;
ТЕОРЕМЫ ПРИ НЁМ НЕТ И НЕ НУЖНО
```

Значит П1 — не пропуск ядра, а отсутствие написанной человеком теоремы.

## Замер: 240 утверждений разложены

Правило счёта названо, чтобы его можно было перепроверить: блок утверждения
в записи корпуса, где есть строка `вердикт доказано` и строка `теоремы нет`.

```
359 утверждений в 86 записях корпуса
  240  вердикт «доказано»        ← знаменатель Г4
  119  «нет вердикта»            ← в знаменатель не входят

из 240:
   81  теорема ЕСТЬ — чекер может проиграть заново
  159  теоремы НЕТ
```

## Разбор 159 — и вот где потолок

Первый признак («тип довода простой или индуктивный») оказался НЕВЕРЕН, и я
его отбросила: индукция по числу возможна, `индукция по н убывает н` при
`дано н: нат` (`corpus-factorial.flang`). Дело не в типе, а в том, есть ли по
чему вести спуск.

Правильный признак — рекурсивна ли функция либо ходит ли она по структуре:

```
  111  НИ РЕКУРСИИ, НИ ОБХОДА — писать нечего
   32  свёртка / обход / разбор — индукция по структуре возможна
   12  функция рекурсивна — индукцию писать есть по чему
    4  функцию по имени не нашла (остаток, не разбирала)
```

**Потолок: 81 + 44 = 125 из 240 = 52,1 %.**
**Не пишется в принципе: 111 из 240 = 46,25 %.**

## Почему 111 не пишутся — выборка, не рассуждение

Взяты три случайных из 111:

* `Разность пары` (`первое минус второе` не больше 2⁵³−1) — граница берётся
  из объявленного типа. Спускаться не по чему;
* `Выбор при условии-допущении` — ветвь закрыта противоречием с предусловием;
* `Круг через коробку` (`Достать(Положить(н))` равно `н`) — разворот двух
  вызовов.

Написать теорему для них значило бы записать семантику примитива или
разворот вызовов — то есть ровно то, что делает доверенное ядро. У дерева
«аксиом ноль»; вписать их обратно теоремами было бы обманом.

## Накрутка, которую я проверила и которая УЖЕ ПЕРЕКРЫТА ЯДРОМ

Очевидный способ поднять число — написать теорему `по примеру` на всё
подряд. Проверено прогоном: ядро отказывает и говорит, почему.

```
FLANG_PROOF_STEP: в цели функции «Сумма наоборот» свободны «а», «б», поэтому
значений у неё бесконечно много, а пример — одно. Примером закрывается цель,
у которой свободного имени не осталось ни одного; с живым именем её закрывает
«индукция по», сведение или «по предположению».
```

Заслон стоит. Отдельного сторожа под эту накрутку заводить не нужно.

## Расхождение приборов 91 против 94 — снято, конфликта нет

Оба прибора правы, они отвечают на РАЗНЫЕ вопросы:

* `доля-корпуса.sh`, «П1 → 42 записей, 91 утверждений» — это **сколько
  утверждений добавится, если простить П1**: 42 записи, у которых П1
  единственная порода, несут 91 утверждение. Счёт ПОЗАПИСНЫЙ, потому что
  Г4 — всё или ничего (`доля-корпуса.sh`, карта работ, восемь строк);
* 94 у задачи 8429 — счёт по другому правилу, мне неизвестному;
* 159 здесь — счёт МЕСТ: сколько утверждений поодиночке упираются в П1.

Числа 91, 94 и 159 не противоречат друг другу — они про разное. Ошибкой было
класть их рядом как одно.

## Что это значит для приговора — решать владельцу

Приговор требует Г4 ≥ 95 %. Потолок 52,1 %. Три честных выхода, и ни одного
я не выбираю:

1. **Снизить порог** до достижимого, назвав в приговоре, почему именно
   столько: 46 % доказательств — само вычисление, и записывать их нечем;
2. **Считать Г4 по другому знаменателю** — только те утверждения, у которых
   теорема в принципе может быть. Опасно: это тот самый «рецепт накрутки»,
   знаменатель падает, доля растёт, доказанность не меняется. Если брать —
   знаменатель обязан печататься рядом и сторожиться от падения;
3. **Признать, что «сведение с телом» — это доказательство**, и Г4 мерит не
   то. Тогда вопрос не «сколько чекер проиграл заново», а «сколько ядро
   доказало без сетки значений», и это уже другой гейт.
