# 5275 — цена слияния main в dev измерена, а не предсказана

## Почему задача заведена

Расхождение main и dev называли трижды и каждый раз как СЛЕДСТВИЕ, а не
причину: задача 4970 («v0.7.10 не предок dev»), задача 3515 («заметки о
выпусках искали на dev, а они на main»), задача 5209 («одиннадцать тегов без
заметок»). Слияние никто не делал и цену его никто не мерил. Здесь она
померена — пробным слиянием, сборкой и прогоном сторожей.

## Расхождение числами

```
общий предок  d583157b
main → dev    32 коммита (нет на dev)
dev → main    70 коммитов (нет на main)
файлов задето на main   20
файлов задето на dev   225
пересечение             15
```

Пересечение в пятнадцать файлов пугает зря: **git разводит двенадцать из них
сам, конфликтов ровно три.**

## Роды тридцати двух коммитов main

| род | сколько | что это |
|---|---:|---|
| работа выпуска | 24 | версии 0.7.0…0.7.10, sha256 формулы Homebrew, release-notes |
| слияние dev в main | 1 | `b843cc44` — обратное направление, оно и делалось |
| правки кода и сторожей | 5 | надзор на js, сторож чисел, CI по SHA, отпечаток семени |
| задачи | 2 | 8650 и 9959 — на dev их нет вовсе |

Направление одностороннее: `b843cc44` показывает, что **dev в main вливали, а
main в dev — ни разу.**

## Три конфликта, и все три решаются в пользу dev

| файл | main | dev | брать |
|---|---|---|---|
| `package.json` | без `private: true`, без C++ в списке целей | и то и другое есть | **dev** |
| `docs/tree-inventory.md` | замер 2026-09-03 | замер 2026-09-04 | **dev** |
| `bootstrap/flang_repl.c` | 720 571 б | 810 478 б | **dev** |

Семя — не спор о вкусе: у main оно на 90 килобайт меньше, в нём нет всей
работы dev. Взять сторону main значило бы стереть перепечатку.

## Главное: слияние ЧИНИТ сторож версии, а не ломает

```
          источник   package.json   семя
база      0.7.0      0.7.0          0.6.2
main      0.7.10     0.7.10         0.7.10   ← согласованы
dev       0.7.0      0.7.10         0.7.0    ← РАЗОШЛИСЬ
```

Прогон, свой, двоичным из этого же дерева:

```
чистый dev:     код 1  «FLANG_VERSION «0.7.0», а package.json объявляет «0.7.10»»
слитое дерево:  код 0  «сторож версии: package.json и FLANG_VERSION совпадают — 0.7.10»
```

То есть **на dev прямо сейчас лежит ровно тот дефект, который чинили хотфиксом
0.7.1** (`99f97b7f`: «flang --version говорил 0.6.2 — на два релиза позади»).
Собранный из dev двоичный назвал бы себя 0.7.0. Слияние это закрывает —
одной строкой, приезжающей из main.

## Что слияние меняет относительно dev — пять файлов, и всё

```
docs/zettel/README.md                 +2
flang/src/emit/c/flang_repl.c         +1 -1   ← та самая версия
scripts/otpechatok-semeni            +31 -18
tasks/8650-…md                       +62      новый
tasks/9959-…md                       +48      новый
5 файлов, +144 -19
```

**Из dev не теряется ничего.** Девятнадцать удалённых строк — это одна строка
версии и переписанный на main отпечаток семени; ни одной строки работы dev
среди них нет.

## Цена: четыре новых замечания задачника, и задачник — ворота CI

Сторож задачника (`./ярлык задачник:проверка`, он же `ci.yml:259`):

```
чистый dev:     5 замечаний
слитое дерево:  9 замечаний
```

Все четыре новых — в двух приезжающих задачах, и обе беды известного рода:

```
8650: статус «открыта» не из четырёх          ← словарь, который 9990 свёл к канону на dev
8650: в дорожной карте нет раздела «Как мы обманываем сами себя»
9959: статус «закрыта» не из четырёх          ← то же
9959: в дорожной карте нет раздела «Как мы обманываем сами себя»
```

Раздела «Как мы обманываем сами себя» нет **ни в одной** из двух карт —
проверено обеими ветвями. Задачи писали на main уже после того, как раздел
из карты ушёл.

Починка обеих — четыре строки в шапках: `открыта` → `свободна`, `закрыта` →
`сделана`, `карта:` — на существующий раздел. Ровно то же лечение, что задача
9990 применила к тридцати семи файлам dev; main этой правки не получал.

**Их надо внести тем же коммитом, что и слияние — иначе CI краснеет.**

## Отдельная ловушка: отпечаток семени

`scripts/otpechatok-semeni` приезжает с main без конфликта, а семя остаётся
от dev. У отпечатка main есть раздел `# ── тело семени ──`, которого у dev нет
вовсе, и он хеширует `bootstrap/*`:

```
ОК   bootstrap/Makefile          ≠  bootstrap/compiler_flang.c
ОК   bootstrap/flang_cli.c       ≠  bootstrap/compiler_flang.h
ОК   bootstrap/flang_runtime.h   ≠  bootstrap/flang_repl.c
                                 ≠  bootstrap/flang_runtime.c
```

Четыре из семи не сойдутся: отпечаток описывает семя main, а в дереве будет
семя dev.

**Оговорка, снимающая половину тревоги.** Хеши ИСХОДНИКОВ в отпечатке
расходятся с деревом и без всякого слияния — у dev 42 расхождения из 46 со
своим же деревом. Это по устройству: отпечаток — снимок момента печати, а не
текущего дерева (см. `docs/zettel/a-seed-guard-asking-about-the-current-tree-is-red-by-construction.md`).
Нового здесь только одно — пара «отпечаток ↔ ТЕЛО семени», которой у dev
раньше не было. Её закрывает та же перепечатка, что идёт сейчас: она
переставит и семя, и штамп.


## Прямой ответ на вопрос «безопасно ли»

**Да, и оно нужнее, чем казалось.** Слияние маленькое (5 файлов), ничего из
dev не теряет, чинит красный сторож версии и стоит четырёх правок в шапках
двух задач. Оно не «долг гигиены» перед тегом — оно закрывает дефект, из-за
которого собранный сегодня двоичный назвал бы себя 0.7.0.

## Обратное направление — не нужно

На main нет ничего, чего не должно быть на dev: все 32 коммита либо работа
выпуска (ей место в обеих ветвях), либо правки кода, уже проверенные на main.

## Не сделано

* Само слияние не делалось и не заливалось — это решение владельца.
* Не проверено, чинит ли перепечатка пару «отпечаток ↔ тело семени» на деле;
  сказано только, что по устройству должна.
* Не решено, куда переставить поле `карта:` у задач 8650 и 9959 — раздела
  «Как мы обманываем сами себя» нет ни в одной карте, и вернуть его или
  перецелить задачи — разные решения.
