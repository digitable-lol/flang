# 6255 — числа прозы отстали за один день работы

## Как найдено

`sh scripts/prose-numbers-guard.sh` — **код 1, мест 20** из 126 примет. Сторож
красен и на `main`, и на `dev`. Приметы датированы 3–4 сентября, а дерево росло
весь день 5 сентября.

## Проверено: дерево выросло ЗАКОННО, число правит только оно

Сторож советует «почините число ИЛИ примету», и первый вопрос — не выросло ли
лишнее. Проверено по каждому крупному скачку:

```
*.flang    1245 → 1255   ровно +10, все добавлены с 4 сентября:
           девять проб чекера (8615, 9951, 9991, 10003, v1-g2, типы-доводов)
           и scripts/version-guard.flang
*.sh         94 →  101   десять новых приборов: kto-zovet-storozhey,
           storozha-bez-podloga, pol-dokazannogo-sverka, semya-rantayma-eto-
           istochnik, vedomost-soglasna-s-check, chto-otstalo-ot-semeni,
           print-launch и три в benchmarks/кеш-приговоров
*.py         18 →   21   привязка.py, привязка-по-файлу.py, кругооборот.py
           (приборы Г5, внесены задачами 7855 и 9751)
*.rb        237 →  271   один файл: packaging/homebrew/flang.rb, вырос с
           работой выпуска
```

**Ни одного случая «наплодили зря».** Все двадцать мест — «дерево выросло,
примета отстала», и лечатся обновлением числа и даты.

## Что сделано

Восемнадцать мест сведены. В каждом правится ДВОЕ: число в прозе и примета
рядом с ним — сторож сверяет и примету с деревом, и прозу с приметой, так что
поправить одно значит оставить его красным с другой стороны.

| файл | мест | что |
|---|---:|---|
| `docs/tree-inventory.md` | 9 | заголовок 255→265; оболочка 94/15260→101/16618; C 773495→774066; Python 18/6036→21/6619; JS 28292→28327; Ruby 237→271; рантайм целей 45262→45463 |
| `.github/workflows/binary.yml` | 3 | 94/15260→101/16618, 255→265 |
| `docs/javascript-inventory.md` | 2 | 255→265, 28292→28327 |
| `flang/scripts/count-guard.mjs` | 1 | 1245→1255 |
| `flang/scripts/name-guard.mjs` | 1 | 1245→1255 |
| `scripts/seed-knows-type-words-guard.sh` | 1 | 1245→1255 |
| `docs/course/README.md` | 1 | 113→122 файлов доказательств |

Даты примет обновлены вместе с числами: число без свежей даты — та же ложь,
только незаметная.

## Поправлено сверх сторожа

В `flang/scripts/name-guard.mjs` проза говорила «300 файлов из 1245. Остальные
889». При 1255 остаток становится **955**, а сторож этого не ловит: у числа 889
приметы нет. Исправлено вместе с прочим — иначе сведение чисел оставило бы
рядом с ними новую неправду.

Так же поправлена дата словами в `docs/javascript-inventory.md`: «4 сентября
2026: 255 файлов» → «5 сентября 2026: 265 файлов».

## Проба порчи — в обе стороны, с числом

Сторож сам велит гонять подлог ПЕРЕД сверкой, иначе сломанный сторож в ленте
неотличим от чистого дерева.

```
ДО работы    --подлог  код 1, «первой примете число подкручено на единицу»
ДО работы    сверка    код 1, мест 20
ПОСЛЕ работы сверка    код 1, мест  2   (оба — в ci.yml, чужой файл)
ПОСЛЕ работы --подлог  код 1, мест  3
```

Последняя строка и есть доказательство, что подлог СОБРАЛСЯ: мест стало на
одно больше, чем без него. Порча, которая не собралась, не доказывает ничего.
