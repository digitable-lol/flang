# 6275 — сторож судил сто сорок примет и называл свой приговор несостоявшимся

## Две беды, а не одна

Наряд говорил: «одна негодная примета отключает проверку всех 136 чисел».
**Проверено — не отключает.** Остальные проверяются исправно. Врёт не
проверка, а ПРИГОВОР, и это оказалось хуже.

### Беда первая: приговор объявлял себя несостоявшимся

Подложена пара «одна негодная примета + одно настоящее расхождение»:

```
примет 142: сошлось 140, разошлось 1, негодных 1
docs/…:3: РАЗОШЛОСЬ С ДЕРЕВОМ — в примете 999, снято сегодня 3
сторож чисел: НЕ ДОСМОТРЕНО — негодных примет 1. Судить нечем.
```

Сторож просудил сто сорок примет, нашёл настоящую ложь — и назвал свой же
приговор несостоявшимся. В коде это стояло дословно: проверка `NEGODNYH`
шла ПЕРЕД проверкой `RAZOSHLOS` и выходила кодом 3, не дав второй
сработать. Читающий видит «судить нечем», идёт чинить примету, а
расхождение остаётся.

**Починка.** «Судить нечем» — только когда судить вправду нечем, то есть
годных примет нет ни одной. Кривая примета — беда наравне с расхождением
(она не стережёт того, что автор думал) и даёт код 1, а не 3. Оба числа
называются порознь.

### Беда вторая, корневая: цитата не отличалась от приметы

Сторож брал `СНЯТО ГГГГ-` где угодно в дереве. Значит **любое упоминание
образца приметы с настоящей датой становилось приметой** — и 5 сентября
2026 сторож дважды стоял ослеплённым, оба раза никем не замеченный:

* задача **3841** показывала в тексте, как будет выглядеть будущая примета
  прибора `примеров-в`, и цитировала чужую. Строки стояли в блоках кода и
  в обратных кавычках;
* задача **1800** наступила на то же, описывая эту же беду.

**Правило было записано в шапке сторожа с самого начала**: «примета живёт
в КОММЕНТАРИИ того языка, на котором написан файл». Сторож это обещал и не
проверял.

**Починка.** Для Markdown — где цитаты и случаются — примета считается
приметой, только если она вне блока тройных кавычек и внутри `<!-- -->`.

## Решающая проба: исходный текст 3841 без правки

```
исходный текст 3841 · СТАРЫЙ сторож → КОД 3, негодных 1, «Судить нечем»
исходный текст 3841 · НОВЫЙ сторож  → КОД 0, все 132 приметы сошлись
```

Текст задачи при этом **не переписывался** — ослепление снято сторожем, а
не переписыванием того, кто на него наступил.

## Границы названы

**Файлы кода оставлены на прежнем правиле.** В `.mjs`, `.js`, `.flang`,
`.c` приметы живут и после `//`, и внутри `/* … */` без звёздочки в начале
строки (`docs/site/sitemap.mjs:70`). Отслеживать состояние блочного
комментария ради беды, которой там не случалось, — цена без причины.

**Настоящая примета в Markdown без `<!-- -->` теперь не стережёт ничего.**
Молча этого не происходит: такие строки считаются отдельно и печатаются
сведением в итоге («строк «СНЯТО» вне комментария — 8: это цитаты,
приметами не считаны»), но кода не портят — иначе всякая цитата краснила
бы сторожа, и мы вернулись бы к тому, от чего ушли.

## Ни одной настоящей приметы не потеряно

Восемь отсеянных проверены поимённо, все — цитаты:

```
docs/prose-numbers.md:60,61,62   образец трёх языков в блоке кода
tasks/3841:36,196,197,199        врезки в блоках кода
tasks/3841:177                   цитата в обратных кавычках
```

## Своя ошибка по дороге, и она стоила двух настоящих примет

Первая редакция считала ограждением всякую строку, начинающуюся с трёх
обратных кавычек. `docs/course/README.md:61` содержит ``` ВНУТРИ прозы —
чётность сбилась на весь файл, и две настоящие приметы в таблице ниже
(строки 171-172) молча выпали из-под присмотра. Поймано счётом: примет
стало 127 вместо ожидаемых 132.

Признак исправлен по правилу CommonMark: после открывающих кавычек в
строке не должно быть новых. **Порода ровно та, которую эта задача чинит:**
починка сторожа сама на минуту сделала его слепее.

## Пробы — пять, в обе стороны

```
чистое дерево                          КОД 0, примет 132, цитат 8
негодная примета в комментарии         КОД 1, названа, прочие 132 проверены
негодная примета + расхождение         КОД 1, ОБА названы порознь
--подлог                               КОД 1, ровно одно место
все приметы негодны (отдельное дерево) КОД 3, «судить нечем» — верно
```

## Не сделано

* Числа `docs/prose-numbers.md:60-62` были под присмотром по случайности и
  теперь не под ним. Это правильно — они образец, а не утверждение о
  дереве, — но если кто-то захочет их стеречь, примету надо вынести из
  блока кода.
* Правило «примета живёт в комментарии» для файлов кода не проверяется.
  Если цитата заведётся там, беда повторится, и признак придётся достроить.
