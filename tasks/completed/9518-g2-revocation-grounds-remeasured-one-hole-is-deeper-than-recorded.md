# 9518 — что из доводов снятия Г2 ещё стоит

Гейт снят 31 августа. С тех пор в чекере многое починено, но доводы снятия
никто не проверял ПОДРЯД, одним заходом. Здесь они перемерены — каждый
своим прогоном, чекером, собранным из `dev 7f09a4dc`
(`cc -std=c99 -Wall -Wextra -Werror -pedantic -O2`, 3711 строк).

**Гейт этой задачей НЕ БЕРЁТСЯ.** Итог — какие доводы сняты, какой стоит.

## Довод 1 (Ч119): «чекер читает исходник иначе, чем язык» — СНЯТ

Приём Ч119 воспроизведён своими руками: исходник подделан так, что язык
видит `второе: целое`, а за примечанием `//` спрятано `второе: нат`.

```
честная запись corpus-natural против подделанного исходника  → КОД 1
  «в записи знаков 2435, а в исходнике 2454 — запись не от этой программы»
подделка без правки примеров, только скрытый тип             → КОД 1
ядро на подделке А                                            → КОД 1
  FLANG_EXAMPLE … FLANG_PROPERTY: нарушено свойство
```

**Проверено и на самом свежем коде.** Правило «цель следует из объявленного
о доводах» пришло в чекер 5 сентября (`f5d378a1`) и читает типы доводов из
исходника — то есть ровно там, где порода Ч119 могла бы воскреснуть. Опыт
на одну переменную:

| объявление | код | что сказал чекер |
|---|---:|---|
| `второе: нат` честно | **0** | ПРОВЕРЕНО, правило сработало |
| `второе: целое // второе: нат` | **3** | «разобрано, но не закрылось 1» |

Правило читает строку так же, как её читает язык. Порода Ч119 через него
не проходит. Файлы опыта:
`flang/proof/чекер/пробы/записи/v1-g2/tip-za-primechaniem.{flang,запись}`
(ядро на этом файле молчит — код 0, «замечаний нет», — а прогон на
`{"первое":2,"второе":-3}` даёт код 1: постусловие ложно).

## Довод, который СТОИТ: дыра 9984 — и она глубже, чем записана

### Воспроизведена дословно

```
честная substantive.запись            код 3, числятся доказанными 3, на слово ядра 6
подделка c1-lozhnyy-reduction.запись  код 3, числятся доказанными 4, на слово ядра 9
```

Подделка меняет `вердикт нет вердикта` → `вердикт доказано` и дописывает
посылки `закрыта reduction шагов 0`. Причина в коде названа точно
(`сверщик.c:3227`): для ветки `reduction` проверяется РОВНО `шагов == 0`,
и к исходнику проверка не обращается вовсе. **Довода нет — есть учёт.**

### НОВОЕ: пустой блок ходов прячет долг

Записанная дыра говорит только «счёт вырос». На деле подделыватель может и
СПРЯТАТЬ долг. Достаточно дописать под каждую поддельную посылку пустую
строку `ход конец`:

```
подделка как есть           числятся доказанными 4, НА СЛОВО ЯДРА 9
подделка + «ход конец»      числятся доказанными 4, НА СЛОВО ЯДРА 3
честная запись              числятся доказанными 3, НА СЛОВО ЯДРА 6
```

Подделка выглядит ЛУЧШЕ честной по тому самому числу, которым меряют долг:
3 против 6. Причина — `posylki_na_slovo` (`сверщик.c:1997`): посылка идёт в
долг, только если у неё названо правило И нет `ход конец`. Пустой блок ходов
снимает её с учёта, а закрытой она остаётся.

Файл опыта: `flang/proof/чекер/пробы/записи/v1-g2/9984-hody-pryachut-dolg.запись`.

### Но до кода 0 приём НЕ доводит — граница найдена и названа

Код 0 чекер даёт при двух условиях сразу: привязка криптографическая И мест
«на слово ядра» ноль. Пробовано на `corpus-brackets` — записи, которая
СЕГОДНЯ даёт код 0 и содержит утверждение, не доказанное ядром:

```
честная corpus-brackets                      код 0, доказанными 0, на слово ядра 0
+ вердикт перевёрнут на «доказано»           код 3, доказанными 1, на слово ядра 1
+ принцип с чужой переменной индукции        код 1  «принцип ведёт индукцию по
                                                     «строка», а постусловие
                                                     исходника — по «итог»»
+ выдуманная теорема                          код 1  «строка 68 исходника — не
                                                     «теорема …»»
```

Заслон один и он держит: утверждение, объявленное `доказано` без теоремы,
ВСЕГДА добавляет место на слово ядра, а выдумать теорему нельзя — чекер
сверяет её со строками исходника по номеру.

## Прямой ответ на вопрос «живой ли это довод против Г2»

**Да, живой.** Гейт своими словами требует «отвергает подделку». Здесь чекер
подделку НЕ отвергает: он молча засчитывает поддельный вердикт доказанным и
позволяет спрятать долг ниже честного уровня. Что подделка остаётся на коде 3
— смягчение, а не оправдание: гейт говорит об отвержении, а не о том, что
сертификат всё-таки не выдан.

**Чем это НЕ является:** сертифицированным ложным приёмом. Кода 0 подделка
не получает — проверено четырьмя опытами выше.
