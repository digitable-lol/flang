# 9977 — описательная статистика над списком чисел

Вытекает из 9962 (средний уровень, «математика»: владелец спрашивал «то,
чего не хватает в `math-classics*.flang` (статистика? комплексные числа?
матрицы?)» — вопросом, не утверждением). Ответ на этот вопрос требует
прочесть, что такое `math-classics*.flang` на самом деле, а не только
список функций.

## Честная поправка к посылке

`flang/stdlib/math-classics.flang` и `math-classics-lists.flang` —
прочитаны целиком, обе шапки — это НЕ библиотеки общего назначения, а
ИЗМЕРИТЕЛЬНЫЙ СТЕНД: дословный перевод классических лемм арифметики и
списков из исходников Coq (`coq/coq`, тег V8.19.2) и Lean/Mathlib4,
заведённый ЦЕЛЬЮ снять вердикт ядра доказательств поимённо на каждой
лемме, «ради ЗАМЕРА», по словам самой шапки. Внутри — только сложение,
умножение, сравнение, чётность и НОД над `нат`, плюс склейка/обращение/
отображение/свёртка списков — вручную переписанные заново, СОЗНАТЕЛЬНО не
переиспользующие `lists.flang`, чтобы измерение не унаследовало чужих
постусловий. Статистики, комплексных чисел, матриц там нет и не может
появиться без порчи смысла файла: дописать в него «Среднее» значило бы
испортить измерительный стенд посторонней функцией.

Значит верный ответ — не «дописать в math-classics», а «завести
статистику отдельным, новым модулем `flang/stdlib/`» — и настоящий пробел
именно такой: ни «статистика», ни «среднее», ни «дисперсия», ни
«медиана» не встречаются НИГДЕ в `flang/stdlib/` (проверено грепом по
всем 42 файлам).

## Что она даёт

- Среднее арифметическое, медиана, мода — над `список числа`.
- Дисперсия и стандартное отклонение (по совокупности и по выборке —
  разница в делителе, n против n−1, — назвать обе явно, не молчать про
  выбор).
- Перцентиль/квантиль по отсортированному списку.

## Почему этот уровень сложности

Среднее, медиана, мода — простая свёртка/сортировка, дёшево тотальны, тем
же приёмом, что уже доказан в `lists.flang` («Сумма», «Сортировать»).
Настоящий дракон — стандартное отклонение: оно квадратный корень, а
КОРНЯ В ЯЗЫКЕ НЕТ. Полный список арифметики языка — ровно шесть слов
(`плюс`, `минус`, `умножить на`, `делить на`, `остаток от`, `процентов
от`, см. `flang/SPEC.md`), извлечения корня среди них нет, и ни одна
существующая библиотека его не реализует (в `numbers.flang` есть
«Степень» — целая степень повторным умножением, — но не обратная
операция). Значит стандартное отклонение обязано либо принести СВОЙ
корень (метод Ньютона с фиксированным числом витков или объявленной
мерой убывания — тот самый «постоянный шаг» / «объявленная мера» способ
тотальности, которых в библиотеке уже 64 штуки), либо честно остаться
без него и отдавать только дисперсию, а извлечение корня назвать
отдельным, отдельно оцениваемым довеском. Это решение — и есть настоящая
работа среднего уровня, не арифметика вокруг него.

## На что опереться

- `flang/stdlib/lists.flang`, «Сумма», «Длина», «Сортировать» — прямая
  опора для среднего, медианы, перцентиля.
- `flang/stdlib/numbers.flang`, «Степень» — образец приёма для нового
  «Корень» (метод Ньютона: то же семейство «шаг + оговорка о числе витков
  при печати», что уже применено в `numbers.flang` к «Степени» и
  «Факториалу», по словам его шапки — «постоянный отрицательный шаг плюс
  проверка-неравенство»).
- `flang/SPEC.md`, таблица «Как доказывается тотальная» (пять способов) —
  прочитать перед тем, как выбирать способ доказательства для «Корня»:
  «объявленная мера» самая дорогая (тройной счёт времени при работе),
  «точный шаг» — дешевле, если получится под неё подвести.

## Что не входит

- Комплексные числа, матрицы, линейная алгебра — из вопроса владельца
  подтверждено отсутствие, но не входит в объём ЭТОЙ задачи: три разные,
  плохо связанные темы в одном файле хуже, чем три отдельные будущие
  задачи. Если понадобятся — заводить отдельно, не сюда.
- Регрессия, корреляция и прочая многомерная статистика — не входит.

## Порог

- Среднее/медиана/мода/дисперсия — с примерами и доказанной тотальностью
  без объявленной меры (свёртка/сортировка достаточно).
- Явное, названное решение по стандартному отклонению: либо со своим
  «Корнем» (с указанием способа доказательства тотальности и оговоркой
  про точность приближения, проверенной прогоном против известных
  значений — 2, 3, 10 — не только «выглядит похоже»), либо без него, с
  прямо написанной причиной в шапке модуля, по образцу того, как
  `datetime.flang` называет вслух свои границы, а не молчит о них.
- Хотя бы один пример, разоблачающий IEEE-754 (пустой список, список из
  одного числа, список с NaN — что вернёт «Среднее» и «Дисперсия» на
  каждом, названо и проверено, а не оставлено на волю случая).

## Чем закрыта

- `ab05c9768` — новый модуль `flang/stdlib/stats.flang` («Statistics», 16 тотальных функций, ввозит «Lists»
  целиком): «Среднее», «Медиана», «Мода» (при равенстве частот — наименьшее, примером), «Дисперсия по
  совокупности» и «Дисперсия по выборке» (делители n и n−1 названы постусловиями «делитель — счёт элементов,
  n» / «…без одного, n минус 1», оба доказаны ядром), «Стандартное отклонение по совокупности/по выборке»,
  «Квантиль» (линейная интерполяция, тип 7; половина совпадает с медианой — примером), «Корень», «Корень
  близок», «Это число».
  Эталонные векторы (сняты python3 `statistics`): медиана [1, 2, 3, 4] = 2.5 и [3, 1, 2] = 2; на
  [2, 4, 4, 4, 5, 5, 7, 9] среднее 5, дисперсия по совокупности 4, по выборке 4.571428571428571 (точно),
  отклонение по совокупности 2; мода [1, 2, 2, 3] = 2.
  `flang check` — «замечаний нет»; `flang test` — 140 из 140 (58 своих примеров по `grep -c '^ *пример «'`,
  остальные — ввезённого «Lists»); `--proof`: утверждений 43, доказано 24, сетка 19, нарушено 0;
  сторожей при работе 0 — `убывает` не понадобился.
  Улика «до»: на заглушках (0/нет/да) тот же файл краснел 43 примерами из 56 (`FLANG_EXAMPLE`).

Решения по драконам задачи, названные вслух:
- **Корень — свой**, метод Ньютона, старт (значение плюс 1) делить на 2, ровно 48 витков; тотальность — «точным
  шагом» по `витков: неотрицательное` (бесплатно при работе, не объявленная мера). Точность проверена прогоном
  против `math.sqrt`: 4 → 2, 9 → 3, 1e12 → 1e6 ровно; 3 → 1.7320508075688772 ровно; 2 и 10 — на 1–2 младших
  разряда ниже эталона, поэтому стоят примерами через «Корень близок» (разность меньше 1e-12), и это сказано в
  имени примера. Отрезок сходимости 48 витков назван примерами-краями (1e-6 и 1e26). Отрицательное — 0 охраной.
- **IEEE-754 разоблачён примерами**: пустой список — среднее 0 и медиана 0 охраной, не 0/0; дисперсия по выборке
  от одного элемента — 0 охраной, не деление на n−1 = 0; список с не-числом — «Среднее с не-числом» даёт
  не-число, и «Это число» это показывает. Важная находка: в этом двоичном `равен` на не-числе ИСТИНЕН
  (проба `(0 делить на 0) равен (0 делить на 0)` → да), поэтому «Это число» — `(значение минус значение)
  равен 0` (конечное число), а не `значение равен значение`.
- Минус ноль: «Среднее» [0, -0] = 0 без правок — сумма стартует с +0.
