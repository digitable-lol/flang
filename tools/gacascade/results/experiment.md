# Результаты вычислительного эксперимента gacascade

Числа получены прогоном стенда `tools/gacascade` на **синтетических сценариях**.
Они характеризуют свойства модели и алгоритма и **не являются утверждением о промышленном эффекте**.

## Параметры серии

| Параметр | Значение |
| --- | --- |
| Прогонов на конфигурацию | 30 |
| Начальное семя | 1 (прогон i использует seed = 1 + i) |
| N_max (бюджет оценок) | 1200 |
| c_min | 0.85 |
| Доля бюджета на один пилот GA1 | 0.08 (не менее 128 оценок) |
| Уровень значимости | 0.05 |
| Модель FTS | `tools/gacascade/models/assignment.fts` |
| Примеров модели пройдено | 15/15 |
| Время стенда | 296.9 с |

Обозначения метрик — по разделам 2.3 и 3.3.1 диссертации:

- c — вычислительная готовность (больше — лучше);
- τ — время расчёта, мс (меньше — лучше);
- σ — нормированная дисперсия загрузки (меньше — лучше);
- Δ — штраф нарушений ограничений (меньше — лучше);
- J_p — итоговый функционал (меньше — лучше);
- N — число оценок целевой функции (меньше — лучше);
- доля допустимых — планы с V_skill = 0 и V_over ≤ 0,05.
